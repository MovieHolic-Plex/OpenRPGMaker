# Reward And Growth Loop

Rewards are what make actions matter.

## Reward Types

Immediate:

- gold,
- item,
- heal,
- short success dialogue.

Growth:

- EXP,
- level,
- skill learned,
- stat increase,
- equipment upgrade.

Access:

- key item,
- opened path,
- new map transfer,
- removed blocker.

Narrative:

- NPC dialogue changes,
- town state changes,
- new rumor,
- next quest opens.

## Reward Contract

Every reward must have:

- a source action,
- a visible confirmation,
- a project state change,
- and a reason it matters next.

## Bad Rewards

Avoid rewards that only change hidden numbers unless the next scene uses them. A demo feels flat when the player wins a battle and nothing in the world acknowledges it.

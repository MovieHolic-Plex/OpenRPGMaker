# Encounter Balance Kit

Create battles as teachable moments.

## Encounter Contract

Each encounter needs:

- reason to fight,
- enemy role,
- player action choice,
- readable risk,
- reward,
- and aftermath.

## Early Battle Baseline

For a first demo battle:

- Enemy survives 2-4 normal attacks.
- Enemy can threaten but should not kill from full HP without warning.
- One skill or item should feel meaningfully better than attack.
- Reward should unlock or complete something.

## Enemy Roles

Blocker:

- Guards a path or object.
- Defeat opens progress.

Tutorial target:

- Weak to one showcased skill.
- Teaches the skill's purpose.

Resource tax:

- Costs HP/MP before a reward.
- Should be followed by healing or payoff.

Mini-boss:

- Has pre-battle warning.
- Defeat changes map/story state.

## Required Aftermath

After battle, set at least one switch or variable and make an NPC, object, or path react to it.

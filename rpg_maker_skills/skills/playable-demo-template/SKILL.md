# Playable Demo Template

Use this package when a demo needs to feel like a game instead of a feature test.

## 10-Minute Demo Loop

1. Player starts in a safe village pocket.
2. Guide NPC gives a problem and names a landmark.
3. A blocked route or object requires action.
4. Player finds a chest, sign, or key object.
5. Player encounters one purposeful enemy.
6. Battle uses the edited database troop.
7. Victory sets a completion switch.
8. Reward changes growth or access.
9. Quest giver reacts to completion.
10. A new path, NPC line, or object proves the world changed.

## Required Editor Evidence

Capture screenshots of:

- database actor/enemy/skill/troop edits,
- map with route/gate/reward,
- quest NPC event pages,
- object or gate event pages,
- battle processing command,
- play dialogue,
- play battle,
- post-completion state.

## Minimum Content

- 1 start map.
- 1 quest giver.
- 1 interactable object.
- 1 battle encounter.
- 1 reward.
- 1 post-completion page.

## Failure Condition

If the demo can be summarized as "talk, fight, stop", it fails this template. Add state, reward, and aftermath.

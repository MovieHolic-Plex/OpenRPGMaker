# Map Purpose Stamps

Maps need verbs, not just tiles.

## Stamps

Start pocket:

- Safe spawn point.
- Shows at least one goal direction.

Landmark:

- Distinct object, building, shrine, bridge, sign, or terrain change.
- Used in NPC directions.

Blocker:

- Locked door, enemy, broken bridge, guard, cliff, or dense forest.
- Explains required condition.

Reward nook:

- Short detour with chest, NPC, or item.

Return line:

- Path back to quest giver or next gate.
- Avoid forcing blind backtracking.

Encounter pocket:

- Space where battle trigger has visual warning.

Recovery point:

- Safe area after risk.

## Layout Rule

A small demo map should support:

- one main route,
- one optional detour,
- one gate,
- one reward,
- and one return.

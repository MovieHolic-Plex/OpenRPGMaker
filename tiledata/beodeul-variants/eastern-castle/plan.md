# 동양풍 성·닌자 마을 (eastern-castle) — 야외 64x48 + 실내 26x16 (한 렌더 92x48)

## 용도
전국시대풍 성하 한 판. 일행은 남쪽 흙길(38,47)로 들어와 닌자 마을(초가·너와 민가, 도장, 우물, 물레방아)을 지나
해자 다리를 건너 성문 망루(야구라몬) 문길로 성 마당에 들어가고, 판석 길 끝 **천수각 기단 문**(38,13)으로 들어간다 → 실내 판(성 안 대청).
곁길: 서쪽 대숲 오솔길 → 사당 언덕 돌계단 → 도리이·사당. 동쪽 널다리 → 대숲 → **판자벽 숨은 회전문**(56,40) → 닌자 은신 마당.
실내는 같은 성 안의 다다미 방(서)과 대청(동)이 칸막이 남쪽 끝 통로로 이어진다(ㅁ자 고립 방 없음).
버들항 팔레트·결(칩셋 기와·풀·흙·물·돌 램프)을 그대로 쓰고 색만 동양풍(짙은 회청 기와, 흰 회벽, 검은 판벽, 붉은 칠)으로 변주했다.
jp_city 번들과는 별개(그 그림을 쓰지 않는다). 글자·상표·사람 없음.

## 앵커 (6)
1. **천수각** (11x12) — 휜 돌 기단 + 검은 판벽 + 흰 회벽·격자창, 층층 기와 처마 셋, 치도리 박공, 꼭대기 팔작지붕 + 금 귀면 장식.
2. **해자·성문 망루·흙벽** — 돌담 기단 위 흙벽(총안 셋 꼴), 모서리 망루, 붉은 난간 해자 다리.
3. **사당 언덕** — 돌계단·도리이·사당·고마이누.
4. **도장** — 큰 기와 지붕 + 장지문 여섯 + 툇마루 + 수련 마당.
5. **물레방아** — 개울 위 바퀴 + 너와 오두막.
6. **숨은 회전문 판자벽 + 은신 마당**.

## 동선
남쪽 입구 (38,47) → 흙길 북 → 해자 다리 (38,21~23) → 문길 (37~39, y15~20) → 판석 길 → 천수각 문 (38,13).
골목(y33~34) 서쪽 → 오솔길(x4~7) 북 → 도리이 → 돌계단 (5~7, y9~10) → 사당 (6,6). 골목 동쪽 → 널다리 → 대숲 길 → 숨은 문 (56,40) → 은신 마당.

## QA 기록 (2026-10-08)
1. 조각 판 1회차: 천수각 3층 벽이 처마에 거의 가려짐 → 3층 높이 +6px. 처마 끝 휨이 약함 → sori 5·flare 4. 돌담이 벽돌처럼 고름 → 줄 높이·돌 폭 해시 폭을 넓히고 모서리 깎기·쐐기돌.
   초가 윗경사가 너무 밝은 노랑 → 뒤 경사 +1 빼고 톤 5 상한, 대나무 녹색 마룻대 → 짙은 짚 마루 + 누름 가위 막대. 너와 지붕이 벽과 같은 갈색 → 바랜 회갈 너와 램프(ita).
2. 대나무가 「막대 위 둥근 활엽수 덩이」 → 마디마다 처진 가는 잎 다발(잎 4~8장) + 성긴 뒤 잎 덩이로 다시. 소나무 잎뭉치가 매번 같은 배치 → 씨앗마다 높이·폭·좌우 바꿈.
   맹장지 금 구름이 레몬 덩이 → 가로로 끌린 금 안개 띠 둘. 다다미 결이 체크 무늬 → 결 방향 줄 + 바느질 줄.
3. 지도 1회차: 성 마당 전부 흰 자갈 → 넓고 납작한 판(빈 판처럼 읽힘) → 천수각 앞 광장·둘레 길·곳간 앞 길만 자갈, 나머지는 버들항 풀.
   사당 오솔길이 판석 오토타일 1칸 직선(흰 관처럼 보임) → 2칸 흙길이 조금씩 굽고 디딤돌을 엇갈리게.
   빈 창 0.70 → 집 마당 대나무 울타리, 밭 둘(버들항 밭 그림 재사용), 가장 빈 창에 덩이 메우기(길·문 앞·물가 피함, 놓을 때마다 BFS 확인) → 0.40.
   메우기가 쌀가마를 아무 데나 흩뿌림 → 마을 메우기 목록에서 뺐다.
4. 비교 시트 1회차: 흰 자갈이 납작한 회색 잡음 → 굵은 자갈 알(2x2 빛 + 아래 그늘)과 잔 그늘 점. 다다미가 두꺼운 검은 테로 세로 사다리 무늬 → 테 1px, 48 덩이마다 좌우 뒤집어 깔기.
   붉은 방석이 마루 위 빨간 네모로 튐 → 짙은 쪽빛 방석. 2회차: 대청 병풍이 기둥과 겹침 → 칼걸이로 바꿈, 천수각 옆 봉 걸이가 울타리처럼 보여 뺐다, 실내 고립 칸 2 → 칼걸이 자리 옮김.

## 남은 차이(솔직하게)
- 대숲은 버들항 숲(덩어리 수관이 겹쳐 땅을 덮는다)보다 성기다 — 줄기 사이로 풀이 많이 보여 덤불이 「기둥 묶음」 줄처럼 읽히는 곳이 있다(동쪽 대숲).
- 기와 결은 칩셋 파란 기와를 옮긴 것이라 1x 에서 지붕이 조금 시끄럽고, 버들항 붉은 지붕의 큰 경사면 빛 구배보다 명암 단이 좁다.
- 천수각은 앞 처마 셋이 거의 같은 꼴(사다리꼴 + 박공)이라 층마다 개성이 약하다. 가라하후(둥근 박공)는 없다.
- 실내 벽(맹장지)은 거의 흰 면이라 오페라 극장 벽돌 벽보다 결이 적다. 실내 좌우 벽은 천장 띠뿐(옆벽 깊이 없음).
- 메우기 덤불이 남쪽 마을에 고르게 퍼져 「덩이」보다 흩뿌림에 가깝다. 물레방아는 한 판(돌아가는 판은 함수 인자로만).
- 도장 앞 흙 마당·골목이 빈 창 기준선(0.40)에 걸려 있다.

### 고친 곳(규칙 2)
- 한 가지 초록 바닥 → 잔디 변형 표본 3종 `ground-grass-short`(성 마당 전체), `ground-grass-clover`(마을 마당에 덩이로), `ground-grass-leaves`(사당 언덕·대숲).

  도장 수련 마당에 대련 기둥·단련 기둥 하나씩 더(빈 창 0.41 → 0.39).

### QA 기록
1. 오토타일 시험 1회차: 이끼 흙 속 칸이 같은 무늬로 격자처럼 되풀이(방석 모양·낙엽 자리) → 속 칸은 잔결 낙엽 흙만, 이끼는 가장자리에서 번지게. 2회차 4x2 잎이 벽돌 무늬 → 4x4 블록마다 흔든 자리의 작은 잎으로.

2. 지도 1회차: 오목 모서리 틈(위) 수정. 연잎이 곧은 둑 칸마다 같은 자리 → 모서리·끝 칸에만. 논 안에 활엽수·덤불 셋이 서 있음 → 뺐다. 논 사이 두렁길이 울타리에 갇혀 고립 6칸 → 울타리 한 칸 텄다.
3. 비교 시트 1회차: 사당 낙엽 풀이 주황 색종이처럼 시끄러움 → 칸당 1~3장, 갈색 비중↑. 동쪽 대숲 이끼 흙이 긴 세로 띠(길·개울처럼 읽힘) → 덩이 9칸 상한. 마을 북줄 집 마당까지 이끼 흙 → 대숲 구역을 y≤27 로.
   2회차에서 대숲 바닥이 작은 덩이 여럿으로 갈라지고, 사당·성 마당이 한 톤 초록에서 벗어남.

### 남은 차이(솔직하게)
- 4방향 오토타일이라 오목 모서리는 모양을 모른다 — 틈은 막았지만 연못·논 윤곽은 여전히 칸 계단이 보인다(덩이를 둥근 모양으로 칠해야 한다).
- 잔디 변형은 덧그림이라 1x 에서 차이가 작다(짧은 풀은 조금 거친 결 정도). 클로버·낙엽 칸 경계는 칸 단위로 끊긴다.
- 연못 속 칸(15)은 고른 물이라 큰 연못 한가운데가 밋밋하다 — 잉어·연잎 장식을 직접 얹어야 한다. 낙엽 흙 속 칸은 되풀이가 가까이서 보인다.
- 정원석 무리는 3x2 라 마을에서 자리를 못 찾아 성 마당에만 하나. 대숲은 여전히 버들항 숲보다 성기다.

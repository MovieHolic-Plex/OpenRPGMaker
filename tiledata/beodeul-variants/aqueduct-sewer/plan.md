# 버들항 지하 수도교·하수도 (aqueduct-sewer) — 계획

60×44칸 (960×704px). 버들항 도시 밑을 흐르는 로마식 수도교의 배수로. 3/4 시점, 1칸=16px=1m, 빛 왼쪽 위.

## 목적
- 버들항 대로 밑으로 내려와(입구 계단) 수도교 본수로를 따라 걷고, 다리로 건너, 교단이 숨긴 제단(비밀문)에 닿는 던전.
- 플레이어가 배우는 것: 물길은 못 건넌다 → 다리를 찾는다 / 벽 앞면 이음매가 다른 돌은 비밀문 / 밸브방은 수위(물길) 장치.

## 앵커(눈에 띄는 것)
1. 본수로 한복판 섬의 밸브 바퀴(작은 다리 둘로만 닿는다).
2. 밸브실 남북으로 가로지르는 구리 매니폴드.
3. 저수조 가운데를 가르는 긴 돌다리.
4. 교단 전실 북벽 앞면의 비밀문(닳은 돌 4개).
5. 제단 위 교단 제단 + 깃발 3.

## 동선
- 주 동선: 입구(7,35) → 복도 북(8–9, 28–33) → 본수로 남 보도 → 동쪽 다리(x38–39) → 북 보도 동쪽 → 복도(50–51,18–19) → 교단 전실 → 비밀문(54,15–17) → 제단(54,13).
- 곁길: 입구 → 동 복도 → 창고 → 북 복도(24–25) → 남 보도 (고리). 수문실 → 북 복도(44–45) → 남 보도. 수문실 → 폐기 구덩이.
- 밸브실·저수조는 본수로 북 보도에서 각각 복도(14–15 / 35–36, y13–17)로 들어간다. 다리 x15–16은 밸브실 복도와 맞닿는다.
- 막힌 방 없음: 비밀문 3칸(54,15–17)을 통행 가능으로 잡아 BFS를 돌린다 (grid.json 에 `hidden_cells`, `reachable_without_hidden` 표기).

## 규칙 확인
- 천장 밑 벽 앞면: 홀 3칸, 복도·소방 2칸 — 모든 열린 칸의 북쪽에 앞면이 있고, 사슬 위는 어두운 천장이다.
- 빈 바닥 20×15 화면당 ≤ 40 % (script 가 측정해 grid.json `extra.emptiness` 에 남긴다). 소품은 줄줄이가 아니라 덩이.

## QA 기록 (적대적 검수)
- 원본 크기 4분면 + 제단 방 2x 확인. 상자 모양 방 없음: 방 9개가 복도 9줄로 이어지고 BFS 컴포넌트 1개(804칸). 입구→제단 경로 78칸, 비밀문(54,15~17)을 빼면 제단 도달 불가(의도).
- 수정한 것: 본수로 홀이 10줄이라 빈 바닥 53% → 8줄로 줄이고 덩이 소품(통·상자·뼈 무더기)을 덩어리로 배치 → 최대 0.400 (창 20×15, 기준 ≤0.40), 평균 0.286.
- 수정한 것: 소품이 2칸 보도를 끊는 자리 7곳(기둥 옆 붕괴 기둥, 통, 양동이 등)을 차단 없는 잔해로 교체. 한 칸 고립 (3,41) 제거. 횃불이 복도 위에 떨어진 것 2개 이동.
- 남은 어색함: 천장 색이 약간 녹색으로 떠 보임(버들항 천장 단계 유지). 이끼 장식은 이 맵에서 거의 안 보임. 동쪽 다리·서쪽 다리가 같은 그림 반복.

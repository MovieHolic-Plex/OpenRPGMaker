# 설원 마을 「서리목」 (snowfield) — 56x44

## 용도
북쪽 절벽 밑 얼어붙은 항구(호수)에 기대어 사는 겨울 마을. 플레이어가 남쪽 길로 들어와
(1) 광장 모닥불과 촌장 큰집, (2) 서쪽 온천 목욕탕, (3) 동쪽 얼음 부두·낚시 오두막, (4) 남서쪽 나무꾼 마당을 돌아보는 탐험/거점 마을.

## 구역
| 구역 | 좌표(칸) | 내용 |
|---|---|---|
| 북쪽 절벽 | y0~6 | 눈 덮인 고원 + 세로결 절벽 앞면 3줄. 소나무 숲이 그 밑을 두른다 |
| 광장 | x21~34, y20~27 | 돌 바닥 + 눈, 모닥불, 게시판, 우물(분수 소품), 등불 |
| 촌장 큰집 | x24~30, 광장 북쪽 | 2층 목조 큰집, 광장을 내려다본다 |
| 온천 | x6~16, y9~19 | 뜨거운 물 웅덩이 + 돌 테두리 + 김, 목욕탕(북쪽) |
| 얼음 항구 | x41~55, y15~35 | 언 호수. 부두 널, 얼어붙은 배 3척, 얼음낚시 구멍·의자 |
| 나무꾼 마당 | x3~12, y32~42 | 창고 오두막, 장작더미 다섯 곳, 통나무 밑동, 썰매 |
| 주거 | 광장 둘레 | 돌집·목조 눈집 12채(단층 눈 덮인 지붕, 고드름, 큰집만 2층 목조) |

## 앵커(랜드마크)
1. 광장 모닥불 (27,24)  2. 촌장 큰집  3. 온천 김  4. 얼음 부두 끝  5. 장작더미 마당

## 동선
- 입구 (28,43) 남쪽 → 큰길(폭 3~4) 북쪽 → 광장
- 광장 → 동쪽 길 y22 → 부두(얼음 위 널)
- 광장 → 서쪽 길 → 온천 → 목욕탕 앞
- 큰길 y33 서쪽 갈래 → 나무꾼 마당
- 집마다 문 앞에서 가까운 길로 짧은 밟은 눈 길

## 원칙
- 빈 눈밭은 소나무 덩이·바위·눈더미로 자연스럽게 채우되, 일렬은 금지. 한 화면 빈 눈 ≤ 40%.
- 새 땅 조각(눈·밟은 눈·얼음·절벽·뜨거운 물·널)은 버들항 땅과 같은 7단 램프, 1화소 윤곽, 위왼쪽 빛.

## 만든 것 요약
- 집 12채: 촌장 큰집(hall), 서 2·동 2·서남·남 2·오두막·창고·목욕탕·북 1. 지붕은 눈 덮개(snowcap)로 윗면을 덮고 앞면만 버들항 목조/돌/통나무 벽.
- 길은 폭 1~2의 밟은 눈 길과 광장 포석, 큰길만 넓다. 새 땅 재료 9종(눈·서리·밟은 눈·포석·얼음·온천물·널·절벽·고원 눈).
- 빈칸 측정: 20x15 창 최악 0.16(≤0.40). 4칸 넘는 덩이 1곳(8칸, 나무꾼 마당 안 — 마당이라 일부러 비움).

## QA 기록 (적대적, 원 해상도 사분면 4장 + 2x)
1. 줄 맞춤: 남동 사분면에서 작은 눈더미 5개가 세로 한 줄로 섰고 위 가장자리 바위도 가로로 늘어섰다 → 눈더미 크기 4종(10/12/14/16)·높이 2종, 칸 안 가로·세로 랜덤 어긋남, 바위 dx/dy 랜덤으로 고침. 눈더미 74→55개. 줄 맞춤 사라짐.
2. 통행: BFS 입구 (28,43) → POI 16곳(집 12·모닥불·부두 끝·마당·온천가) 전부 도달. 처음에 온천가 점을 물 위에 찍어 막힘으로 나와 육지로 옮겼다. 도달 1643/1659칸.
3. 나무: 지도 위 가장자리에서 수관이 잘리던 것 → y<0 거부. 줄기·수관 밑변 같은 폭(소나무 틀 그대로).
4. 경계: 길 끝이 들쭉날쭉한 곳이 있지만 눈 경계 디더 결과 같다. 서쪽 나무꾼 마당 가는 길은 폭 1이라 가늘고 끊겨 보일 수 있다(통행은 이어져 있음).
5. 남은 어색함: (a) 온천 북동쪽에 떨어진 작은 물 점 하나, (b) 절벽 윗단 사이 1픽셀 옅은 줄, (c) 집 지붕이 전부 같은 하얀 면이라 단조롭다(눈이라는 재료 한계, 고드름·처마 색으로만 변화).

# 마법사의 탑 (wizard-tower) — 계획

## 용도
숲 속 정원 한가운데 서 있는 마법사의 탑. 플레이어가 남쪽 석문으로 들어와 별무늬 광장을 지나 탑 문으로 들어가는 "랜드마크 목적지" 장소.
바깥(정원)과 탑 안 3개 층 평면도(서재 → 연금실 → 천문대)를 한 그림에 놓는다(아래 띠).

## 크기
바깥 40×34칸(640×544px), 안쪽 층 3개(각 16×14칸, 256×224px)를 아래 띠에 나란히(768×224). 전체 768×776px. 처음 48×40 으로 깔았다가 빈 바닥이 63.7% 라 40×34 로 줄였다.

## 구역 · 앵커
- 북쪽 숲(0~5행): 빽빽한 참나무·덤불. 탑 뒤 배경. 서·동 가장자리도 숲.
- 탑 광장(11~23행): 앵커 A = 푸른 원뿔 지붕 탑(80×210 손 도트 재채색). 발치 8각 별 상감 돌바닥(중심 (20,19)), 혼천의(가운데)·달 오벨리스크 넷.
- 서쪽 약초원(20~29행): 온실(앵커 B, 문 (5,23)), 약초밭 덩이(손 도트 밭 조각), 약초 걸이, 가마솥, 벤치, 사이프러스 화분.
- 동쪽 정원(19~30행): 분수(앵커 C)·현자 조각상, 해시계(35,21), 벤치, 꽃밭·푸른꽃밭 덩이.
- 남쪽 담(32~33행): 낮은 돌담 두 줄 + 철문(18~22열). 안쪽에 낮은 산울타리 덩이와 등롱 둘.

## 동선
입구(20,33) 철문 → 흙길 북쪽으로 → 별 광장 → 탑 문(20,15). 길 중간(행 28)에서 서쪽 갈래 → 온실 문·약초밭, 동쪽 갈래 → 분수·해시계.
탑 안: 1층 서재 문(아래 중앙) → 계단 위로 → 2층 연금실 → 3층 천문대.

## 안쪽 층 (3/4 재작업: 둥근 탑 안쪽)
모든 방은 타원 바닥 + 뒤쪽으로 휘어진 벽면 2칸(32px) + 바깥 윗띠 8px + 벽 밑 그림자. 벽은 바닥보다 두 단 이상 어둡고 결이 다르다.
- 1층 서재(회반죽 벽 + 널 징두리, 마루): 서가 둘(벽), 긴 책상+의자, 지구본, 양탄자, 상자.
- 2층 연금실(돌 벽·깃돌): 증류기(연금로), 난로, 가마솥, 병 선반, 통·자루.
- 3층 천문대(돌 벽·깃돌): 창 셋, 별지도(벽), 망원경, 혼천의, 탁자.
계단은 세 층 같은 자리(9,5)의 나선 계단(위/아래 조각), 바닥 위.

## QA 기록
- 3/4 재작업: 검사기 위반 7건 → 0건 (탑 2건은 검사기 오탐으로 기록, view34-audit.md).
- 탑: 사각 정면도였음 → 처마 타원 윗면 + 몸통 원통 음영 + 원뿔 지붕(wt_tower34.py). 해시계는 정면 받침뿐 → 윗면 타원 원반. 별지도·약초밭은 T/F 비율 교정.
- 통행 BFS(입구 (20,33) 기준): 철문·탑 문·온실 문·약초밭·분수·해시계·광장 중심 전부 도달(걸을 수 있는 1094칸).
- 한 화면(20×15) 빈 바닥 최악 38.7% (8,12 부근) — 기준 40% 이내.
- 이전 기록: 처음 48×40 은 비어서 40×34 로 축소·덩이 추가 / 남쪽 담은 낮은 돌담 두 줄+철문.
- 검사기 오탐(눈으로 확인한 것): wizard-tower.png / wizard_tower.png 는 원통 탑이라 T(처마 타원)/F 비율이 검사기 범위 밖으로 나온다(FRONT 10/219). 검사기에 탑 예외가 없다.
- 스스로 보기에 어색한 곳: wizard_tower.png 는 wizard-tower.png 와 같은 그림의 옛 이름 복제(삭제 금지 규칙 때문에 남김) / 탑 안 세 층의 벽 재질은 돌 위주라 층 구분이 색보다 가구에 의존 / 해시계 금색 점 하나 튐 / 풀밭 들꽃 덩이 모양이 서로 비슷함 / 별 광장 가장자리 타원이 다소 매끈함.

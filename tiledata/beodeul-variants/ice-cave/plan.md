# 얼음 동굴 「서리 굴」 (ice-cave) — 48x36

## 용도
JRPG 얼음 던전 한 판. 입구(남서) 야영 자리에서 시작해 얼어붙은 호수 홀을 지나, 막다른 복도 끝 얼음 문 너머 보물 방에서 상자를 얻고, 남동 뼈 쉼터의 내려가는 계단으로 다음 층에 간다. 서쪽 고드름 회랑은 곁길(결정·뼈 소품).

## 구역
| 구역 | 좌표(칸) | 내용 |
|---|---|---|
| A 입구 동굴 | x4~18, y22~33 | 출구 계단(북벽 앞면), 야영 모닥불, 상자·통, 눈 바닥 |
| B 호수 홀 | x19~39, y14~27 | 얼어붙은 호수(오토타일), 얼음 기둥 5, 결정 무리, 얼어붙은 폭포(북벽), 푸른 화로 |
| C 보물 방 | x28~43, y3~8 | 얼음 문(복도 끝) 너머, 결정·상자 2 |
| D 고드름 회랑 | x2~16, y5~14 | 고드름 달린 벽, 결정, 뼈, 서쪽 곁길 |
| E 뼈 쉼터 | x31~46, y28~33 | 갈비뼈 뼈대, 내려가는 계단 |
| 연결 | A-B x17~22 y27~29, 남쪽 우회 y31~33 (순환), B-E, B-C 복도 x31~34 y11~14, D-B 세로 통로 | |

## 앵커
1. 입구 야영 모닥불 2. 얼어붙은 폭포 3. 얼음 문 4. 뼈 쉼터의 내려가는 계단

## 동선
입구(11,31) → 야영 → 동쪽 통로 → 호수 홀(호수는 걷기 가능한 언 얼음) → 북동 복도 → 얼음 문 → 보물 방. 호수 홀 → 남동 → 뼈 쉼터 → 계단. 남쪽 우회로가 A-E 를 잇는다.

## 규칙 확인
- 벽: 닫힌 칸 중 열린 칸 바로 위 2줄 = 앞면(face_ice/face_rock 섞음), 그 위는 천장. 열린 칸 위 닫힌 줄이 3칸 미만이면 열어 합쳤다(thicken).
- ㅁ자 고립 방 없음(방 6개 모두 통로로 이어짐, 남쪽 우회로로 순환).
- 빈 바닥: 20x15 최악 0.37(≤0.40). 빈 창은 석순·결정·눈 더미 덩이로 메웠다(일렬 금지, 길 칸 예약).
- 오토타일 3종(frozenlake·snowdrift·crack)은 16칸 변형 시트로 지도에 실제로 깔았다.

## QA 기록
1. BFS: 입구 → 표지 10곳 모두 도달. 도달 531칸, 막힌 작은 주머니 15칸(기둥·상자에 둘러싸인 구석, grid.json 에서는 막힘 처리).
2. 처음에 호수 오토타일 속이 칸마다 반복돼 격자 줄이 보였다 → 가장자리 3화소 안쪽은 전역 좌표 질감으로 다시 칠함(시트 속은 균일 얼음).
3. 처음 복도 위 벽이 1줄만 나와 문 앞면이 어긋났다 → thicken 에서 문 열 보호, 앞면 2줄 확인.
4. 남은 어색함: (a) 금간 얼음(보로노이)이 넓은 면에서 거미줄처럼 빽빽함, (b) 눈 바닥 덩이가 구름 같은 얼룩, (c) 횃불이 검 모양으로 읽힐 수 있음, (d) 천장은 단색에 가까워 큰 암흑 면이 있다.

# 고대 숲 (ancient-forest) — 64×48칸 야외 던전 (재작업 2: 버들항 질감 기준, 2026-10-07)

목적: 남서 입구(고목 아치)에서 흙길을 따라 버섯 공터·쉼터·샘 공터를 지나 북동 「숲속의 옛 제단」에 닿는 한 방향 탐험 맵.
시점: 16px, 3/4, 왼쪽 위 광원. 나무·기둥·석상은 밑동 줄만 막고 윗부분은 뒤로 걷는다(SPEC §2).

## 왜 다시 짰나 (사용자: 「질감이 버들항과 너무 달라 당혹스럽다. 파괴된 재단/신전은 뭔지 모르겠고 엉망」)
앞 판은 바닥을 자체 잡음 램프로 만든 납작한 얼룩(위장무늬), 채도 높은 만화 잎 덩이, 윤곽만 있는 「벽돌 상자 방」 유적이었다.
이번 판은 **새 바닥·새 나무 질감을 발명하지 않고** 버들항 파이프라인을 그대로 쓴다.

| 요소 | 쓰는 것 |
|---|---|
| 풀 바닥 | `city_v6/ground.render` — 칩셋 잔디·초원·그늘 풀·꽃 풀을 덩이 잡음으로 섞는 버들항 땅. 나무 밑은 그늘 풀 |
| 흙길 | `terrain7.sand_variants` 16변형(가장자리 풀 번짐은 그늘 풀로) |
| 샘·개울 | `water6` 자연 물 + `v6pieces.beach_layer` |
| 유적 단 | `terrain.render` 단(level)·남향 앞면 3줄·옆 테·돌계단 — 버들항 성 테라스와 같은 방법. 앞면 그림만 `ruin_ash`(=`castle6.ash` 마름돌을 녹회로 바래고 이끼가 흘러내림), 계단은 `terrain.stair` 를 바래고 이끼 |
| 단 윗면 판석 | `roman.tex_flag`(버들항 광장 판석) 바램 + 줄눈 이끼, 가장자리는 풀이 먹어 들어가게 들쭉날쭉 |
| 참나무·덤불 | 칩셋 oakA/oakB/bushC/D/E(깊은 숲길과 같은 `tree_look` 4변형) |
| 거목·고목 아치 | 새 조각: 수관 = `roman.clumps`(칩셋 참나무 잎 질감을 덩이마다 다시 명암), 줄기 = 칩셋 참나무 줄기 색 6단 + 세로 결, 갈래 V, 판근, 덩굴 |
| 기둥·제단·석상 | `roman` 기둥 비례(TRV 대리석 바램), `px2.C` 상자/원기둥(칩셋 돌 램프), 수호상 = 버들항 「현자 동상」을 옛 돌로 |
| 고사리·버섯(숲 바닥) | 깊은 숲길(`_lib-5/parts5`)의 고사리·붉은 버섯 — 다시 내보내지 않음 |

## 검사 (make 가 출력, grid.json 에 기록)
- 통행 BFS: 입구 (9,47) 에서 마크 7곳(제단·단·광장·샘·두 공터·입구) 모두 도달. 층 이동은 계단 칸으로만.
- 빈 바닥: 20×15 창 최악 26.3%, 전체 10.6%. 판석 면(단 윗면·광장)은 길처럼 구조로 센다(`s.fill`).
- 결정적: 두 번 돌려 render·grid·조각 해시 같음.

## QA 기록 (2026-10-07, 눈으로 본 것)
비교 시트 `compare-ref.png` — 윗줄 [깊은 숲길 | 고대 숲], 아랫줄 [버들항 성 석재·계단 | 고대 숲 유적], 둘 다 2배.
1. 1차: 거목 수관이 층층 납작(분재 모양)·덩이 ^ 표식 → 칩셋 참나무식 격자+가장자리 덩이 수관, 갈래 V 로. 줄기 이끼 체크 무늬 → 단색 덩이.
2. 1차: 길이 대각선 계단 무늬 → 직교 마디 + 1칸 굽이로 다시 깔기(깊은 숲길과 같은 결).
3. 1차: 단 앞면 「빠진 돌」이 검은 창문처럼 읽힘 → 뺌. 큰 계단이 새것처럼 하얌 → 바램·이끼.
4. 1차: 이끼 오토타일이 잔디와 같은 색이라 윤곽 네모만 보임 → 짙은 이끼 깔개 + 칸마다 둥근 방석 4개로 새로 그림.
5. 1차: 빛 버섯이 흰 「전등」·막대 벌레처럼 보임 → 청록 갓(윗면 밝음·아래 테) 무리로, 큰 버섯은 손으로 둥근 갓.
6. 1차: 낙엽 오토타일이 갈색 네모 얼룩 → 폐기. 큰 고사리 조각이 거미줄처럼 보임 → 폐기(숲 바닥은 깊은 숲길 고사리).
7. 2차: 덤불이 길 따라 한 줄로 늘어섬 → 길 둘째 칸은 반만 채움. 판석 이끼 덩이 과다(위장무늬 느낌) → 드물게·어둡게.
8. 2차: 단 윤곽이 반듯한 네모 → 세 모서리 무너뜨려 앞면 어긋남 + 북서 모서리 고목.

## 아직 다른 점·약한 곳 (솔직하게)
- 유적 돌은 버들항 성 마름돌보다 어둡고 녹회색이다(의도한 「옛 돌」이지만 밝은 성 돌 옆에선 한 단 칙칙하다).
- 단 윗면의 옆 테(terrain 의 가는 밝은 선)가 네모 윤곽을 남긴다. 버들항 고원과 같은 그림이라 그대로 뒀다.
- 수호상은 작아서 2배에서도 지팡이 든 사람 형태 정도만 읽힌다.
- 이끼 오토타일 방석 4개가 칸마다 같은 자리에 있어 넓게 칠하면 격자 반복이 보인다(3칸 이하 덩이 권장).
- 샘 물가가 칩셋 물 파이프라인 특유의 각진 모양이다.
- 거목은 1배 전체 그림에서 보통 참나무와 크기 말고는 크게 구별되지 않는다.

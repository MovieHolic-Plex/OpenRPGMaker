# 등불 수향 마을 (lantern-river-town) — 무협 장르 장소 팩, 데모 맵 64x48

## 용도
운하가 마을 한가운데를 가로지르는 강남풍 물마을 한 판. 흰 회벽에 검은 기와를 얹고 양 끝에 계단식 마두벽을 세운 민가가 운하 둑을 따라 줄지어 서고, 홍등 줄이 걸린 화강암 판석 거리, 아치 돌다리와 남북 돌다리, 나룻배가 매인 부두와 물가 돌계단, 포목점 천막·찐빵·등 노점이 늘어선 장터 광장, 2층 목조 객잔, 연못가 찻집, 쪽빛 천을 내건 염색 마당, 버드나무 찻뜰이 있다. 무협 이야기의 첫 마을·객잔 싸움·장터 의뢰·배 타고 떠나는 장면에 쓴다. 이 팩 하나로 닫혀 있다 — 바닥 표본(풀·흙·판석·벽돌·부두 널)과 땅 덩이 오토타일(운하 물·젖은 석판·연잎·판석 연석)이 모두 들어 있다.

## 칠하는 순서 (조수가 따라 할 순서)
1. 맨 바탕: `ground-grass` 로 맵 전체 → 길·광장 `ground-flagstone`(물가·찻뜰 `ground-flagstone-moss`), 객잔 앞 `ground-brick`, 남쪽 물가 판잣길 `ground-dock`, 뒷골목 `ground-dirt`, 나무 밑 `ground-grass-shade`, 가장자리 `ground-grass-meadow` 덩이.
2. 땅 덩이 오토타일: 판석 칸 전부에 `autotile-flagstone-curb`(풀과 닿는 쪽에 연석) → 물가·우물 둘레에 `autotile-wet-flagstone` 덩이 → `autotile-canal`(운하 3~4칸 폭 띠, 연못은 둥근 덩이, 곳곳 한 칸 부풂) → 물 안쪽에 `autotile-lotus`(위층).
3. 다리·부두·계단 → 건물(문은 남쪽, 문 앞 1칸 길) → 노점·소품 → 나무 → 맨 위 `lantern_string`.

## 앵커 (5)
1. **2층 목조 객잔** (8x8) 2. **물가 찻집** (6x6, 연못 북쪽 기슭) 3. **아치 돌다리** (6x5, 갈래 운하) 4. **패루** (6x6, 남쪽 들머리) 5. **염색 천 말림대** (4x5, 둘) — 그 밖에 운하·연잎·홍등 줄이 장소 성격을 만든다.

## 동선
남쪽 패루 (29~30,47) → 큰길(x28~30) 북으로 장터 광장 → 남북 돌다리 (x28~30, y21~26) → 운하 북쪽 둑 거리 → 큰길 → 북쪽 동서 거리(y12~13).
동서 거리 동쪽 → 아치 돌다리 (x43~48, y12~13) → 동쪽 마을. 서쪽 끝 (8,13) → 이끼 판석 (8,14~16) → 연못가 찻집 툇단.
광장 동쪽 → 객잔 문 (39~40,36). 광장 서쪽 → 이끼 판석 길(y38) → 남서 찻뜰·뜰 정자. 남쪽 둑 거리 동쪽 → 염색 마당.

## 걷기·가림
- 건물: 앞면 벽 아래 2줄 막힘, 문 칸 걷기, 지붕 칸 걷기 + 위층. 찻집: 앞 기둥 칸·뒷줄 막힘, 툇단 가운데 4칸 걷기.
- 아치 돌다리: 2·3번째 줄(디딤) 걷기, 북 난간 줄·남 난간·앞면 줄 막힘. 남북 돌다리·널다리·부두·잔교: 칸 전부 걷기(물 위). 물가 계단: 윗줄 + 아랫줄 가운데.
- 운하·연잎 칸 막힘. 배는 물 위라 원래 막힘. 버드나무·대나무·매화·홍등 기둥·깃발·돌사자: 밑동만 막힘. 노점: 판대 줄 막힘, 차양 걷기 + 위층.
- 홍등 줄: 맨 위 층(밑을 지나간다).

## QA 기록 (2026-10-08)
1. 오토타일 시험(check-autotile.png) 1회차: 젖은 석판의 빗물 웅덩이가 넓은 청록 띠(물처럼 읽힘) → 판마다 작은 타원 하나로. 판석이 흰 벽돌처럼 밝고 짧았다(ST 램프 3↔4 간격이 커서 얼룩) → 버들항 길 포석 톤을 넣은 화강암 램프 gran + 판 폭 16~30.
2. 판석 표본과 젖은 석판·연석 오토타일의 판 줄이 달라 겹치면 어긋남 → 셋이 같은 판 줄 씨앗(16 주기, 표본은 톤만 48 주기)을 쓰게 바꿈. 판 금(대각선)이 16px 마다 같은 자리에 반복돼 무늬가 됨 → 오토타일에서 금 뺌.
3. 판석 길이 풀과 칼로 자른 직선 경계 → `autotile-flagstone-curb`(연석 + 틈 풀) 추가, 판석 칸 전부에 덧칠.
4. 마두벽 1회차: 지붕 처마선 위 흰 상자 둘로 보였다 → 3/4 로 다시 생각해 지붕 양 끝을 따라 처마선에서 용마루 위까지 오르는 「흰 턱 + 위에서 본 기와 갓」 계단 기둥으로. 집 지붕이 얕아 납작 → 지붕 깊이 30 → 40px.
5. 아치 돌다리 1회차: 회색 상자 + 아치(다리 윗면·난간 구분 안 됨) → 가운데 9px 솟음 + 북 난간 갓돌 · 디딤 돌계단 · 남 난간 판 · 앞면을 차례로, 5줄 높이로 다시(걷기 줄이 2칸 폭 길과 맞게).
6. 지도 비교(compare-ref.png) 1회차: 내 잔디가 동양풍 성 잔디보다 납작(한 장 무늬) → ground-grass 표본 안에서 잔디·들풀을 덩이 잡음으로 섞고 칸마다 클로버·잎 덧그림. 젖은 석판 덩이가 판석 위에서 점선 고리처럼 보임 → 판 한 장 단위로 적시게(판 가운데로 판 전체 결정).
7. 빈 바닥 1회차 0.62(집 뒤 띠) → 집 뒤 대숲 띠(그늘 풀 + 대나무 엇갈림)로 집 뒤를 「대숲」이라는 목적 있는 구역으로, 남서·남동은 맨 풀 대신 찻뜰 이끼 판석 길·뜰 정자, 염색 마당 판석 → 0.40. 그늘 풀을 칸마다 흩뿌렸더니 체크 무늬 → 띠로 되돌림.
8. 전투 배경 1회차: 바닥 전체가 어두운 판석 한 장 + 큰 젖은 얼룩 → 한 단 밝게, 얼룩 빼고 양쪽 아래 구석에 풀 둔덕 + 연석, 버드나무 양쪽. 다리 뒤 빈 하늘에 민가 하나 더.

## 남은 약점 (솔직하게)
- 운하 물 속 칸(15)이 고른 한 톤이라 넓은 운하는 버들항 운하(세로 물결 결·움직임)보다 밋밋하다. 움직이는 물 띠는 없다.
- 막돌 둑 윤곽이 16px 주기라 긴 곧은 운하에서 같은 둑 모양이 되풀이된다(16변형 오토타일의 한계 — 곳곳에 한 칸 부풀려 끊었다).
- 판석이 16px 주기 판 줄이라 넓은 광장에서 줄눈 격자가 고르게 보인다(톤은 48 주기로 흔들었다).
- 노점 2줄째 소품(찻물·우산·손수레)이 1배에서 작다. 2층집 2층 창이 지붕 바로 밑에 붙어 처마 밑 벽 띠가 없다.
- 남북 돌다리는 난간 판석 띠뿐이라 아치 다리보다 단순하다. 집 문은 모두 남쪽(3/4 규칙)이라 집 뒤가 운하를 향하는 「물가 집」은 문 없는 판(house_white_canal)만 있다.

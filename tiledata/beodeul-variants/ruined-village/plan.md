# 폐허 마을·유령 마을 (ruined-village) — 64x48 야외

## 용도
습격(불)과 세월로 버려진 마을. JRPG 의 「폐촌 조사」·「유령 마을」 필드. 남쪽 어귀로 들어와 광장을 지나 불탄 교회 뒤 묘지의
지하 묘소 입구(다음 던전 연결)까지 간다. 길가 폐가 7채는 각각 조사·이벤트 자리(문 앞 칸이 길에 붙어 있다).

## 구역 · 앵커
1. **남쪽 마을 어귀** (x 29..33, y 42..47) — 무너진 문기둥(왼쪽 머리돌 기둥, 허리에서 부러진 오른 기둥, 떨어진 들보, 기운 이름 판) + 좌우로 끊긴 울타리(빈 칸 앞 쓰러진 울타리).
2. **마른 우물 광장** (x 21..40, y 20..31) — 금 간 포석(풀 먹은 가장자리, 빠진 판석·풀 섬), 가운데 마른 우물, 동쪽 찢어진/무너진 노점,
   서쪽 뒤집힌 수레, 찢긴 게시판, 휜 가로등 둘, 부러진 의자, 까마귀, 안개.
3. **불탄 교회** (x 26..35, y 6..16) — 꼭대기 무너진 종탑(종실의 기운 종) + 박공 정면 신랑(장미창 구멍, 지붕은 타서 숯 서까래 뼈대),
   오른쪽 박공 어깨가 무너져 교회 돌 잔해가 땅까지 쏟아졌다. 앞에 떨어진 종·숯 들보·그을린 땅.
4. **폐가 7채** (광장 둘레) — 반목조 폐가(지붕 꺼짐·구멍), 기운 돌벽 폐가, 박공 정면 폐가 둘(반목조·돌벽), 기운 통나무 폐가, 불탄 돌집 둘(박공 돌벽만 남음).
5. **교회 뒤 묘지 + 지하 묘소 입구** (x 39..62, y 1..13) — 남쪽 무너진 묘지 돌담(틈은 잔해 더미로 묻힘), 흐트러진 줄의 금 간·부러진 비석과 기운 나무 십자, 고목, 지하 계단 입구(55,5).
6. **남동 버려진 밭** (x 53..62, y 37..45) — 시든 밭이랑, 누더기 허수아비, 까마귀 앉은 말뚝, 끊긴 울타리.
7. **북서 마른 과수원** — 죽은 나무가 흐트러진 마른 풀밭(맵의 숨 쉴 자리).

## 동선
남쪽 어귀(31,47) → 잡초 흙길(폭 3) → 광장 남쪽(31,31) → 우물 → 포석 길(31..33, 17..21) → 교회 문(32,17)
→ 광장 북동(38,21) → 교회 동쪽 흙길(38..39, 9..21) → 묘지 길(39..55, 8..9) → 지하 묘소 입구(55,7).
샛길: 광장 → 서쪽 폐가들 / 동쪽 불탄 돌집 / 남동 폐가·밭 / 남서 통나무집.

## 바닥 · 재질
- 바탕 = 버들항 잔디(ground.render). 넓은 마른 풀 덩이(ground-drygrass, 가장자리 2화소 디더), 불탄 자리 그을린 땅(ground-ash).
- 길 = 새 오토타일 autotile-weedydirt(버들항 흙길 + 투명 풀 테 + 잡초), 광장 = autotile-crackedpave(버들항 회색 판석 톤·줄눈, 테 없이 풀에 묻힘),
  울타리 = autotile-brokenfence(위층, 레일 빠짐·기운 기둥).
- 건물은 버들항 집 재료(pj 기와 짝, pv 벽 칸, ph2 가파른 지붕, sto 대성당 돌, castle6 마름돌)로 새로 지은 폐허.

## 걷기 · 가림
- 건물: 벽 줄(집 2줄, 교회 3줄)만 막힘, 지붕·뒷벽·서까래 줄은 걷기+가림.
- 나무(살아 있는 버들항 나무·새 고목): 줄기 칸만 막힘. 비석·말뚝·가로등: 밑 1칸. 담: 남은 돌 칸만, 틈은 걷기.
- 통행 BFS: 남쪽 어귀에서 교회 문·우물·광장·폐가 7채 문 앞·밭·묘지·지하 입구 모두 도달(grid.json `reach_from_south_gate`).
- 빈 바닥: 20x15 창 최악 0.38(≤0.40), 전체 0.31.

## QA 기록 (원 해상도 사분면 + 2x 앵커 + 버들항 비교 시트를 직접 봄)
1회차(비교 시트 전):
- 광장 포석이 칩셋 자갈을 그대로 쓰고 금·빠진 돌·잡초를 칸마다 넣어 위장무늬처럼 얼룩졌다 → 버들항 회색 판석(roman.tex_flag 톤 규칙) 16주기 판석으로 바꾸고, 금·빠진 판석은 덧그림 조각(pave_crack/pave_hole)으로 몇 군데만.
- 흙길 가장자리를 노이즈로 먹여 흐릿했다 → 버들항 sand_variants(들쭉날쭉 풀 테)를 그대로 쓰고 풀 테 화소만 투명으로.
- 재 바닥이 큰 검은 얼룩(위장무늬) → 그을린 잔디(숯 램프로 밝기 순위 유지) + 재 가루 점.
- 마른 풀 얼룩 지붕에 대각 무늬 반복 → 잡음 진폭·이삭 점 줄임. 채움 풀 장식 689 → 약 400.
- 북서 무너진 담 토막이 떠 있었다 → 지우고 마른 과수원으로. 묘지 담의 터진 틈·끝은 잔해 더미로 땅까지 이었다.
- 밭이 납작한 흙 직사각형 → 타원 덩이 + 시든 이랑 줄 + 울타리. 밭 위에 나무가 서던 것 금지.
- 혼자 선 세로 울타리(x 49) 제거.
2회차(비교 시트 compare-ref.png 2회 이상):
- 교회가 너무 멀쩡했다 → 오른쪽 박공 어깨를 크게 무너뜨리고 교회 돌 색 잔해 더미, 그을음 강화.
- 비석이 어두운 상자처럼 보였다 → 묘지 담과 같은 창백한 마름돌 둥근 비석(윗면 두께·새긴 십자·금)으로 다시 그림.
- 교회 앞 그을린 땅이 회색 자갈 깔개처럼 보였다 → 작은 두 덩이 + 그을린 잔디 질감.

## 아직 약한 곳(솔직하게)
- 불탄 집·교회의 그을음이 버들항 돌 질감(분홍 벽돌)에 비해 옅다 — 먼 배율에서는 「불탔다」보다 「무너졌다」로 먼저 읽힌다.
- 지하 묘소 입구가 3x3 안에 들어가 작고, 계단이 문간 앞 상자처럼 읽힐 때가 있다.
- 뒤집힌 수레는 바퀴가 없으면 상자로 보일 만큼 단순하다. 안개는 일부러 옅게 두어 분위기보다 장식에 가깝다.
- 마른 풀 장식이 화면 전체에 고르게 흩어져 버들항보다 잔 무늬가 많다.

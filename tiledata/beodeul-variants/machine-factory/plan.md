# 기계 공장 + 지하 연구소 (machine-factory) — 97x40 실내 던전 (두 층 나란히)

## 용도
아직 돌아가는 증기·기계 공장. 일행은 남쪽 하역장으로 들어와 컨베이어 홀을 지나, 북쪽 보일러실의 기계 구덩이 격자 통로를 건너
제어실에서 승강기 전원을 켜고(이벤트 자리), 승강기 홀의 승강기나 방폭 철문 뒤 내림 계단으로 **지하 연구소**에 내려간다.
연구소에서는 승강기 도착 방 → 방폭 철문 → 배양관 홀(깨진 배양관·분석 기계) → 연구실(서버·실험대)로 간다.
한 맵에 두 층을 나란히 둔다: **공장 층 x0~55 (56x40)**, **지하 연구소 층 x57~96 (40x32, y4~35)**. 가운데 x56 은 천장(빈 덩이).
기계 재질은 `future-ruins/plan.md` 「기계 재질 규약」과 그 그리기 함수(`fr_base` 램프·`fr_mat` 톤 캔버스·`panels` 판 줄눈·리벳·
`rustify` 녹·`pipe_h/pipe_v` 관 지름 6/12·`cable`·`box`·`hazard`·`glass_pane`)를 **읽기만 하고 그대로** 쓴다(`mf_kit.py` 머리말).
새로 더한 램프는 배양액 `bio`, 연구소 흰 판 `lab`, 꺼질 듯한 초록 화면 `scr` 셋 — 같은 7단 규칙.

## 앵커 (5)
1. **컨베이어 라인** — 3/4 윗면 고무 벨트(가로살)·올리브 강철 테·롤러 축 머리 앞면(오토타일 16변형), 투입 호퍼·찍기 프레스·검사 문틀, 벨트 위 상자·부품 판, 조립 로봇 팔.
2. **대형 증기 보일러·피스톤·톱니 기계** — 화구 창살 문·드럼·압력계 셋·수위 유리관·급수 펌프 / 쌍 실린더·피스톤 막대·플라이휠 / 큰 톱니·사슬·감속기.
3. **유리 배양관 열** — 초록 배양액·거품·흐린 그림자(형체·얼굴 없음), 빈 관·깨진 관 + 웅덩이.
4. **제어반 벽** — 화면 셋(막대·파형·꺼짐, 글자 없음)·압력계·단추 줄·레버·표시등 띠·열린 점검 문 속 색 전선.
5. **연구소 입구** — 승강기(닫힘/열림 짝)·방폭 철문(열린 문틀 둘·잠긴 문)·경보등(켜짐/꺼짐 두 프레임)·철 계단 짝.

## 걷기·가림
- 배양관·압력 탱크·증기관 기둥·서버·냉장함·조작대·로봇 팔: 밑동 줄만 막힘, 위 칸 걷기 + 가림.
- 보일러·피스톤·톱니 기계·분석 기계·실험대: 아래 2줄 막힘. 상자 더미·책상·의자·통·깔판: 몸통 줄.
- 컨베이어·난간 오토타일: 모든 칸 막힘. 그 위의 호퍼·프레스·검사 문틀·벨트 위 상자는 막힘 없이 얹는다.
- 방폭 철문 문틀: 양옆 기둥 = 벽, 가운데 2칸 통로 걷기(위 2줄은 걷기 + 가림). 구덩이 칸 막힘, 그레이팅·경고선·전선·웅덩이는 걷기.
- 계단은 바닥 위(내림 = 계단 앞 방 바닥, 오름 = 도착 방 북쪽 벽 바로 아래), 승강기는 벽 앞면 장식 + 아래 가운데 바닥 칸이 이동 칸.

2. 구덩이 난간이 구덩이 칸 위에 떠 있었다(기둥이 허공에 섬) → 통로를 3줄 그레이팅으로 넓히고 난간을 그레이팅 위에 세움. 구덩이가 빈 검은 상자 → 속에 어두운 플라이휠·호박빛.
3. 녹슨 발전기가 라인 B 벨트를 덮음 → 하역장·라인 끝으로 옮김. 의자·통으로 막힌 고립 칸 둘 → 배치 이동.
4. 컨베이어 앞면이 바닥 철판과 같은 강철 톤이라 바닥의 홈처럼 보였다 → 테·앞면을 올리브 도장(drab)으로, 벨트 톤 한 단 밝게, 롤러 축 머리 강철.
5. 콘크리트 벽 칩셋 결이 소금처럼 거칠었다 → 결을 두 단으로 줄임. 체크 철판 낟알이 안 보였다 → 4px 엇갈림 낟알 격자, 어두운 판 비율 12% → 6%.
6. 연구소 바닥이 밝고 어두운 판의 욕실 바둑판 → 판 톤 흔들림 제거, 잔 점·긁힘 줄임. 승강기 앞마당 녹 많은 철판 → 공장 철판으로.
7. 승강기·방폭 철문에 녹 흘러내린 줄이 지저분 → 줄 없이 덩이만, 양 줄임. 경보등이 분홍 흰 덩이 → 붉은 5·4단 + 왼쪽 위 빛 점. 철문 판이 덩이로만 보임 → 보강 띠 셋·볼트·아래 톱니 이.

## 남은 차이 (솔직하게)
- 빈 바닥 40% 를 넘는 20x15 창이 공장 108개·연구소 34개 남는다(최악 0.45). 기계 사이 통로 줄(컨베이어 사이·배양관 줄 사이)이 넓은 창에 겹친다.
- 체크 철판은 칸마다 리벳·줄눈이 있어 넓게 깔면 격자가 또렷하다(future-ruins 강철판과 같은 결이지만, 버들항 돌바닥보다 바둑판이 눈에 띈다).
- 보일러(6x5)는 맵 넓이에 비해 작고, 피스톤 기관의 플라이휠은 1x 에서 작은 놋쇠 원으로만 읽힌다.
- 방폭 철문 문틀의 기둥은 콘크리트 상자 + 판이라 면이 납작하다. 로봇 팔 아래팔이 두꺼워 1x 에서 노란 막대 느낌.
- 연구소 흰 판 벽·바닥은 버들항에 없는 차가운 회백이라 옆에 두면 채도가 낮고 밝기가 한 단 높다.
- 조각 판(번호 붙인 시각 페이지)은 만들지 않았다(감독자가 모은다).

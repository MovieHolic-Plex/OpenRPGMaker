# 원시 시대 마을 + 화산 계곡 입구 (prehistoric-village) — 72x52 JRPG 필드

## 용도
가죽 천막·움집이 모인 원시 부족 마을. 남쪽 엄니 문으로 들어온 일행이 모닥불 광장(족장·주술사 이벤트 자리)을 지나
토템 한 쌍 사이 북쪽 길 → 개울 징검돌 → 붉은 띠 돌탑 한 쌍이 선 **화산 계곡 어귀**(다음 던전·화산 지대로 이어지는 출구)에 닿는다.
곁길: 마당 서쪽 → 고사리 숲 속 **거대 짐승 뼈 발굴터**(사냥·발굴 퀘스트), 마당 동쪽 → **벽화 바위**(의식 자리).

## 앵커 (5)
1. 가죽·뼈대 천막과 움집(마을) 2. 모닥불 광장(돌 화덕·꼬챙이 고기·건조대·가죽 틀·토기) 3. 고사리·소철 숲과 거대 짐승 뼈대(+뿔 머리뼈·딱정벌레 껍질)
4. 벽화 바위·절벽 벽화·토템 기둥 둘(글자·얼굴 없는 추상 무늬) 5. 화산 계곡 어귀(분화구 산·돌탑) + 개울 징검돌 (+ 엄니 문)

## 재질 · 오토타일
- 바탕 = 버들항 잔디(ground.render, 숲 밑은 버들항 그늘 잔디가 저절로 깔림). 숲 바닥 ground-fernlitter(그늘 잔디 + 흙 + 떨어진 잎),
  발굴터·바위 앞 ground-darkearth(버들항 고운 흙을 짙게 + 점박이 흙 + 자갈 알 + 잔풀), 분지 ground-ashgrit(점박이 흙 → 화산재 램프).
- 길 autotile-dirtpath(버들항 sand_variants 의 들쭉날쭉 풀 테 그대로, 다진 짙은 흙), 마당 autotile-yardedge(풀↔흙), 울타리 autotile-stakefence(위층).
- 새 재료 7단: 가죽·그을린 가죽·털가죽·붉은 흙물감·토기·소철·딱정벌레 껍질·말린 고기·상아·사암 바위. 나무·껍질·짚(이엉)은 버들항 램프(wood/bark/rope=thatch).

## 걷기 · 가림
- 천막·움집: 아래 2줄 막힘, 지붕 줄 걷기+가림. 엄니 문: 양 밑동만 막힘(가운데 3칸 길). 나무고사리·소철: 줄기 칸만 막힘. 토템·돌탑·독: 밑 1칸.
- 개울 막힘, 징검돌 4칸 걷기. 절벽 앞면 막힘. 울타리 칸 막힘(틈 둘은 걷기).
- 통행 BFS: 남쪽 어귀에서 이름 붙은 16곳 전부 도달(grid.json `reach_from_south_gate`). 산 뒤 분지 꼭대기는 막힘으로 적음.
  북쪽 고원(457칸)은 절벽 위 배경 숲이라 닿지 않는다(계단 없음 — 의도).
- 빈 바닥: 20x15 창 최악 0.36, 평균 0.30 (마당·흙길·화산재·짙은 흙은 「채움」으로 셈).

## QA 기록 (원 해상도 사분면 + 2x 앵커 + 비교 시트 compare-ref.png 를 직접 봄)
1회차(첫 렌더):
- 숲 바닥을 칩셋 점박이 흙 큰 덩이로 깔아 붉은 얼룩(위장무늬) → 숲 밑은 버들항 그늘 잔디(canopy 상자 등록)로, 숲 바닥 표본은 그늘 잔디 바탕으로 다시.
- 고원 절벽이 한 칸씩 들쭉날쭉(상자 계단) → 출렁임을 4칸 이상 유지. 분지 안에 절벽 기둥 토막이 생김 → 분지 가장자리를 위로 갈수록 넓게(단조).
- 나무가 평평하게 흩어지고 작은 고사리·속새가 소금·후추처럼 뿌려짐 → 엇갈린 격자 숲 덩이(수관 겹침) + 채움은 고사리 포기·덤불 덩이 위주.
- 부들이 개울 따라 일렬 → 5칸 단위 덩이로. 개울이 두 줄 한꺼번에 꺾여 네모 홈 → 한 줄씩만 꺾이게.
- 마당 윗변이 칼로 자른 직선 → 타원 셋을 겹친 덩이. 곁길이 두 줄 직사각 띠 → 한 칸씩 굽는 오솔길.
- 울타리가 숲에 끊겨 토막(벤치처럼 보임) → 울타리 자리를 숲보다 먼저 잡음.
2회차(조각 2x 판 + 비교 시트):
- 바람막이(hide_lean_to)가 탁자·상자로 읽힘 → 지도·조각에서 뺌. 벽화 바위가 사발 모양 → 덩이 바위로 다시, 흰 소용돌이·점이 얼굴(눈·이)처럼 읽힘 → 점 세로 줄로.
- 나무고사리 잎이 실가닥(버드나무) → 잎마다 채운 칼날 모양 + 묶음별 윤곽. 앞 잎이 커튼처럼 늘어짐 → 앞 잎 짧게·덜 처지게. 소철이 야자(코코넛)로 읽힘 → 셔틀콕 모양 뻣뻣한 잎, 솔방울 대신 연두 새 잎.
- 공룡 뼈 갈비가 동그라미 고리 → 한쪽으로 휜 갈비(앞 밝게·뒤 어둡게), 흙 둔덕은 낮게. 뿔 머리뼈가 가면처럼 → 옆모습.
- 뼈 토템 머리가 살아 있는 짐승 얼굴 → 텅 빈 눈구멍·코 구멍 세모. 절벽 벽화의 흰 소용돌이·숯 줄이 글자처럼 → 흰 고리·숯 점.
- 속새·부들이 윤곽 때문에 검은 줄 → 초원 하이로드 키 큰 풀처럼 윤곽 없이 2화소 줄기. 징검돌이 흰 점 → 사암빛 큰 돌.
- 짙은 흙이 칩셋 자갈 덩이로 거칠고 줄무늬 → 버들항 고운 흙을 짙게 + 성긴 자갈 알.
- 공룡 뼈를 나무가 가림 → 발굴터 둘레를 숲에서 뺌. 천막 문 앞에 고사리가 앉아 막힘 → 문 앞 칸 예약.

## 아직 약한 곳(솔직하게)
- 나무고사리가 멀리서 야자나무처럼 읽힌다(깃꼴 잎 결이 1x 에서 잘 안 보인다). 수십 그루가 같은 두 모양이라 숲이 다소 단조롭다.
- 분화구 산은 화산 지대 필드의 광선 그림 조각이라 다른 손 도트보다 결이 곱다. 분지가 고원 절벽을 네모나게 끊은 모양이 남아 있다.
- 마당이 넓은 빈 흙이 남는다(버들항 야영지와 비슷한 밀도지만 소품이 작다). 돌 걸상은 아직 벤치처럼 보일 때가 있다.
- 울타리 세로 팔은 말뚝 줄이 좁아 기둥처럼 보인다. 짙은 흙 덩이 윗변이 곧게 보이는 곳이 있다.
- 고원 숲은 닿지 않는 배경이다(계단·경사로 조각은 만들지 않았다).

# 전투 배경 특수 7장 (웨이브 5, WAVE-BRIEF-3 A절)

1배 캔버스 320×180 에 각 장소 그림 함수(복사본 `src/<장소>/`, `vendor.py` 로 생성)를 그대로 찍고 정수 2배 → 640×360. 낮·맑음.
지평선 1배 y≈86~96(2배 172~192), 배틀러 자리(2배 x 120~560, y 190~330)에는 키 큰 물체·밝은 점을 두지 않는다. 재생성: `python3 make_battle_bg.py`.

- `ghost-train` — 원경: 띠 하늘·손 구름, 전나무·참나무 숲 줄, 본선 철로 위 무너진 객차(왼쪽)·전신주·전신선·완목 신호기, 숲 가장자리 안개 / 바닥: 자갈 도상(gravel_px) + 가장자리 버들항 풀 / 가장자리: 급수탑·푸른 가스등·짐 더미·침목·고사리·도깨비불. 맵과 같은 ghost_grade(0.8).
- `opera-stage` — 원경: 검은 가림막 주름 뒤벽, 붉은 주름 띠, 넓힌 배경 그림판(산·강·해) / 바닥: 짙은 무대 널 / 가장자리: 양옆 걷힌 붉은 막, 그림판 나무·성·바위, 조명등, 소품 궤짝·모래주머니·밧줄, 맨 앞 각광 줄(HUD 띠).
- `veldt-coliseum` — 원경: 맑은 하늘, 경기장 북쪽 반 둥근 관람석(build_shell 을 전투 화면 상수로), 지도자 발코니·깃대·걸개 / 바닥: 경기장 모래(갈퀴 줄) / 가장자리: 화로 둘·큰 깃발·승자 기둥·무기 걸이·방패 더미·떨어진 방패·뼈.
- `cultist-tower` — 원경: 교단 돌 벽 앞면, 검붉은 둥근 창, 보라 휘장 넷, 보라 벽등·탈·사슬, 높은 제단·제기 항아리 / 바닥: 의식실 판석 + 3/4 타원 마법진(가운데 눈 문장은 뺌) + 맵과 같은 보라 방 조명 덧칠 / 가장자리: 수정 화로 둘(brazier_big 의 불 자리에 보라 수정), 보라 불 화로·해골 촛대·바닥 초·두루마리·무릎 방석.
- `desert-castle` — 원경: 띠 하늘, 먼 모래 언덕, 사암 성벽(성가퀴·걸린 천)과 양 끝 둥근 탑(몸통 32줄 줄임), 성벽 밑 모래 비탈 / 바닥: 모래(sand_rgb 잔물결) / 가장자리: 왼쪽 아래 오아시스 못·풀밭·야자 셋·갈대, 오른쪽 망루 그루터기·모래 바위·선인장·덤불·해골.
- `prehistoric-village` — 원경: 띠 하늘, 먼 현무암 화산(응회암 띠·용암 줄기)과 연기 기둥 둘, 소철빛 숲 띠 + 나무고사리·소철·덤불 덩이, 가죽 천막·움집·장작 / 바닥: 다져진 마당 흙 + 짙은 흙 덩이 + 가장자리 고사리 숲 바닥 / 가장자리: 모닥불·토기·토템·뼈 무더기·속새·고사리.
- `wasteland-world` — 원경: 먼지 낀 하늘, 옅은 먼 능선, 균열 협곡 벼랑(chasm_render 지층)과 벼랑을 가르는 V 자 틈·깊은 골, 벼랑 위 바위·고사목 / 바닥: 갈라진 붉은 흙(ground_render) + 재 쌓인 자리 + 골에서 이어진 땅 틈 + 바랜 풀 / 가장자리: 큰 마른 고목·부러진 기둥·붉은 바위·기운 고목·그루터기·재 바위.

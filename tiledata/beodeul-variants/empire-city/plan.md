# 제국 도시 (empire-city) — 80x56 JRPG 마을 (강철과 석재의 군사 도시)

## 용도
성벽으로 둘러싼 제국의 수도 한 구역. 일행은 남쪽 성 밖(서치라이트·모래주머니·대전차 장애물이 지키는 흙길)에서 성문 문길을 지나
**철판 대로**를 북으로 걸어, 대로 가운데 구역(동쪽 병기 격납고·보급 창고, 서쪽 병영)을 거쳐 **광장**(얼굴 없는 투구 동상, 확성기 기둥, 깃대)에 닿고,
돌계단을 올라 **성채 정문**으로 들어간다. 성채 문·공장 문 셋·병영 문 둘·격납고 셔터·창고 문은 다른 맵(실내)으로 가는 문이다.
버들항(밝은 석재·붉은 기와·초록 마을)과 대비되는 건축 언어를 확립하는 기준 장소다:
**아래 단 회색 마름돌 + 위 단 회청 리벳 철판 + 층 띠 + 검은(병영·주택·공장)/회청(성채) 슬레이트 지붕, 강철 마룻대·추녀**, 아치 없는 사각 강철 창,
깃발·걸개는 단색 진홍(문장·글자 없음).

## 앵커 (5)
1. **철골 + 석재 대형 성채** (25x15칸) — 3층 본채(위 철판·아래 마름돌·처마 밑 내민 받침 띠·회청 모임지붕·굴뚝 둘과 연기), 큰 겹 철문, 단색 걸개 둘, 네모 탑 둘(검은 뾰족 지붕 + 단색 삼각 깃발), 날개 둘.
2. **대로 가운데 병기 격납고 + 병영** — 반원통 골판 지붕 격납고(셔터문 반쯤 열림·경고 띠 문틀·경고등) + 경계 표시 띠 앞마당 + 보급 창고·상자 더미·연료 통·탄약 상자 / 맞은편 2층 병영.
3. **증기 굴뚝과 관이 얽힌 공장 지구** — 톱날 지붕 공장 셋, 굴뚝, 관 다리, 가스 탱크, 증기 기관, 밸브 장치, 변압기.
4. **성문 + 감시 포탑 + 서치라이트** — 성문 탑, 포탑 넷, 성 밖 서치라이트 둘과 빛줄기.
5. **광장 동상 받침(얼굴 없는 투구 형상) + 확성기 기둥** — 네 단 받침 위 닫힌 투구 갑옷 전신(눈 틈만, 얼굴 없음), 확성기 넷.

## 동선
남쪽 입구 (40,55) → 성문 문길 (39~41, y46~51) → 철판 대로 북쪽 → 광장 의례 길 → 동상 (40,25) 둘레 → 돌계단 (38~42, y15~16) → 성채 정문 (39~41, y14).
곁: 대로 가운데 동서 길(y39~40) → 서쪽 병영 문 (30,36)·공장 C 문 / 동쪽 격납고 셔터 (48~53, y37)·창고 문 (58~59, y34).
광장 남쪽 길(y27~28) → 서쪽 공장 지구(공장 B 문) · 동쪽 병영 문 (61~62, y25). 북쪽 거리(y12~15) → 공장 A 문.

## 걷기·가림
- 성채: 앞면 아래 9줄 막힘, 정문 3칸만 걷기(문). 성문 탑: 문길 3칸 6줄 걷기, 나머지 막힘. 성벽: 칸 전부 막힘(지도 끝 성벽).
- 포탑: 앞면 아래 4줄 막힘, 위 걷기 + 가림. 주택·병영·격납고·공장: 앞면 줄 막힘(2층 4줄, 3층 6줄, 단층 2줄), 지붕 걷기 + 가림, 문 칸 걷기.
- 동상: 받침 아래 2줄 막힘. 가로등·깃대·확성기·서치라이트·쇠 화분 나무: 밑동 칸만 막힘, 위 칸 걷기 + 가림. 관 다리: 기둥 밑동만 막힘(관 아래 지나감).
- 철제 울타리 칸 막힘, 울타리 화단 속은 들어가지 않는다. 바닥 장식(맨홀·배수 창살·기름 얼룩·경계 띠·연석)은 걷기.

## 바닥·재질
- 철판 대로 = 기계 재질 규약 바닥판(16x16·모서리 리벳·미끄럼 돌기 다섯에 하나·녹 없음, 미래 폐허 마당보다 한 단 밝다), 가장자리 = `autotile-curb`.
- 광장·큰 길 = 회색 판석(32px 네모 큰 판, 칩셋 모래흙 결을 회색 석재 톤으로 좁게, 판마다 결 위치를 옮긴다). 거리 = 버들항 거리 돌(칩셋 160,160) 그대로.
- 공장 마당 = 그을린 콘크리트(칩셋 모래흙 결 + 32px 줄눈 + 그을음 점 덩이). 풀 = 버들항 ground.render(한 단 차갑게). 성 밖 흙 = 칩셋 흙.
- 새 재질 램프(7단, ec_base): 회색 석재 gst, 회청 지붕 roofb, 검은 지붕 roofk(둘 다 칩셋 슬레이트 타일 결을 밝기 순위대로), 단색 깃발 flag, 검은 청동 bronze.
  강철·놋쇠·유리·경고 도장·신호등은 미래 폐허 fr_mat 을 그대로 불러 쓴다(파일 수정 없음, 실행 중에만 재질 표에 덧붙임).

## QA 기록 (2026-10-08)
1. 첫 렌더: 성채 탑·본채·날개 사이에 2~4px 빈 틈(배경이 비침) → 면을 칸 끝까지 잇고 경계 1px 어둠 + 탑 오른쪽 이웃에 그늘 3px(탑이 한 걸음 앞).
   굴뚝이 모임지붕 경사 밖에 떠 있음 → 굴뚝을 마룻대 구간 안으로. 포탑 돔이 작고 서치라이트가 따로 떠 있음 → 돔 키우고 돔 위 받침에.
2. 소품 판: 동상이 망토 덩어리로 어둡게 뭉개짐 → 청동 램프 한 단 밝게, 망토 좁히고 흉갑·어깨 빛 면. 서치라이트가 「막대 위 유리공」 → 받침·갈퀴·냉각 테 원통 등으로 다시. 깃발이 평평한 붉은 판 → 접힌 골·등 명암 + 물결.
3. 지도 1회차: 성 안 대부분이 풀밭 위 건물 → 버들항 거리 돌 길·판석 큰 길·콘크리트 마당으로 길 구조를 짜고 풀은 화단·뒤뜰로. 주택 줄이 같은 집 반복 → 폭 3~5·층 1~3·모임/박공·회청/검은 지붕·뒤집기 + 골목 소품.
   남쪽 2층 집 지붕이 격납고 앞마당을 덮음 → 남쪽 줄은 단층으로(지붕이 y41 위로 안 넘는다).
4. 콘크리트 마당이 큰 얼룩(위장무늬) → 그을음을 4px 점 덩이로 드물게, 판 흔들림 3%. 둥근 돌 길이 16px 반복 무늬로 시끄러움 → 거리는 버들항 거리 돌 그대로.
5. 비교 시트 1회차: 광장 판석이 판마다 어두운 얼룩 → 판 흔들림 제거. 2회차: 광장 판석(칩셋 판석 결)이 벽돌 줄쌓기처럼 읽혀 「바닥이 벽」 → 32px 네모 큰 판(결은 모래흙)으로 다시 — 포장으로 읽힘.
   광장을 가로지르는 철판 의례 길을 더해 대로 → 동상 → 계단 축이 한눈에 읽히게. 하늘 도시 비교 크롭 자리를 신전으로 고침.
6. 동쪽 보급 마당 상자가 흩뿌려짐 → 보급 창고(새 건물)를 두고 상자는 문 곁 덩이로.

## 남은 차이(솔직하게)
- 성채 마름돌은 버들항 성 돌보다 두 단 어둡고 돌마다 명암 차가 커서 탑 앞면이 조금 소란하다. 버들항 성의 세로 리듬(높은 아치 창 줄)에 비해 창이 작고 가로 띠가 강하다.
- 지붕 슬레이트 결은 버들항 타일 결을 옮긴 것이지만 검은 램프에서는 뒤·앞 경사 대비가 약해 1x 에서 지붕이 납작한 검은 판처럼 보일 때가 있다(박공 끝 지붕이 특히).
- 공장 톱날 지붕은 채광 띠 셋이 가로 줄무늬로만 읽힌다(톱날 입체가 약하다). 굴뚝 연기·김은 반투명이라 1x 에서 거의 안 보인다. 서치라이트 빛줄기도 옅다.
- 거리 돌(어두운 버들항 거리 돌)이 넓게 깔린 곳(격납고 위·병영 앞)은 검은 면이 넓다. 공장 마당 콘크리트는 32px 판 경계가 격자로 보인다.
- 동상은 5x7 이지만 사람 크기 형상이라 광장에 비해 작고, 1x 에서는 「투구 쓴 기사」 정도로 읽힌다(2x 에서 칼·어깨 갑옷이 읽힘).
- 주택은 한 함수의 변형이라 창 배치가 비슷하다. 단층 집 줄은 아직 줄지은 느낌이 남는다(골목 소품으로만 끊었다).

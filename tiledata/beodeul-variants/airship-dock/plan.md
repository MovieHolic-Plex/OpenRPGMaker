# 비행선 정박 부두 (airship-dock) — 장르 steampunk · 장소 팩

## 용도
구름 바다 위로 깎아지른 절벽 끝에 선 증기 시대의 비행선 정박 부두. 격자 쇠 계류 탑에 기수를 매단 화물 비행선, 낭떠러지 위로 내민 나무·철 잔교 둘, 증기 짐 기중기와 화물 상자 더미, 창이 부두를 내려다보는 관제 오두막, 그을린 벽돌 석탄 창고와 석탄 가루 마당, 예비 기낭을 매단 기낭 걸이, 바람에 날리는 깃발·바람 자루까지 한 팩에 들어 있다. 바닥 표본 6종(고지 풀밭·맨 바위·포석 길·석탄재 마당·부두 널·리벳 강철 받침)과 땅 덩이 오토타일(구름 낀 낭떠러지·석탄 가루·부두 빗물 웅덩이)·절벽 무쇠 난간으로 이 팩 하나만으로 하늘 항구 마을, 비행선 출발 장면, 절벽 위 산업 기지 맵을 완결해 깔 수 있다.

## 맵 (데모, 54×36)
- 칠하는 순서: ① `ground-highland-grass` 로 전체 → 바위·석탄재·부두 널·포석 길·강철 받침 표본을 덩이로 ② `autotile-cloud-cliff`(동쪽·남쪽 낭떠러지, 맵 밖도 같은 덩이) → `autotile-coal-dust`·`autotile-plank-puddle` ③ 잔교(`pier_root`→`pier_span`×n→`pier_head`)·건물·소품 ④ 위층 `cloud_puff*`. 난간 `autotile-iron-railing` 은 부두 쪽 턱에만.
- 구역: 북서 석탄 창고 마당(창고·석탄 더미·수레·보일러) / 서→동 포석 길(가스등) / 가운데 관제 오두막 / 동쪽 부두 널 마당(급수탑·보일러·기중기·상자 더미·빗물) / 동쪽 끝 계류 탑 + 정박 비행선 + 잔교 A(북) · 잔교 B + 소형 비행정(남) / 남쪽 기낭 마당(기낭 걸이·프로펠러·가스통·공구 선반) / 남쪽 바위 턱.
- 앵커: 계류 탑과 정박 비행선, 잔교 둘, 증기 짐 기중기, 관제 오두막, 석탄 창고, 기낭 걸이(6개).
- 동선: 서쪽 들머리(0,18) → 포석 길 → 오두막 문 / 북쪽 갈래 → 석탄 창고 입구 / 동쪽 → 부두 널 마당 → 잔교 A·B 머리 / 남쪽 갈래 → 기낭 마당. grid.json `reach_from_west_entry` 모두 true.

## QA 기록 (고친 것)
1. 낭떠러지 오토타일 3회: ① 구름을 작은 구슬로 찍어 진주 목걸이처럼 보임 → ② 이어진 구름 둑 + 북쪽 바위 앞면으로 다시 → 오목 모서리에서 둑이 끊겨 네모 홈 → ③ 덩이 골을 칸 경계(0·8·16px)에 맞춰 둑이 칸 모서리에서 가늘게 끝나게. 속 하늘이 깊은 파랑(SK1)이라 호수로 읽혀 → SK3 트인 하늘로 밝힘.
2. 벽돌이 원색 빨강(RD) → 한 단 탁한 벽돌 램프, 관제 오두막 지붕 타르 검정 덩이 → 버들항 슬레이트 박공(놋쇠 용마루).
3. 비행선 꼬리가 몸에서 따로 노는 원뿔 → 기수 둥글고 꼬리로 길게 좁아지는 옆모습, 기낭 걸이의 상자 같은 기낭 → 둥근 두 끝 + 처진 몸 + 주름.
4. 맵 64×44 에 빈 풀밭이 넓어 → 54×40 → 54×36 으로 줄이고 자연 덩이(소나무·덤불·바위)로 가장자리를 닫음. 석탄재·바위 표본이 버들항보다 시끄러워(점 대비) 램프 폭을 좁힘. 풀포기를 칩셋 작은 덤불 결의 덩이로 다시 그림.
5. 탑승 사다리가 곤돌라에 가려 안 보여 맵에서 뺌(조각은 남김). 떠 있던 증기 관·줄 깃발 제거, 권양기 북이 양털처럼 보여 강철 북 + 밧줄 띠로.

## 아직 다른 점·약점 (솔직하게)
- 빈 바닥: `_qa_empty.py` 기준 최악 화면이 약 53%(북서 석탄 마당·서쪽 풀밭) — 40% 를 넘는다. 풀포기 덮임을 빈칸으로 치는 엄한 잣대지만 버들항보다 성기다.
- 낭떠러지 북쪽 바위 앞면이 한 칸 안(약 10px)이라 얕다. 4비트 오토타일이라 오목 모서리에서 앞면이 끊긴다.
- 석탄재·바위 마당의 경계는 칸 계단(표본 덩이) — 땅 경계 오토타일이 없다.
- 소나무 수관이 층층 원판이라 버들항 활엽수보다 단순하다. 탐조등·예비 톱니는 작아 읽기 어렵다.
- 전투 배경 바닥이 넓은 같은 널 결이라 단조롭다.

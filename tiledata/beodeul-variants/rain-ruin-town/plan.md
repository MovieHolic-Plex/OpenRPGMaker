# 비 내리는 수직 폐허 도시 (rain-ruin-town) — 72x56 야외, 밤비

## 용도
가파른 언덕 남쪽 비탈에 다섯 단으로 층층이 지은 유럽풍 돌 도시. 사람이 거의 떠난 폐허지만 창 몇 개와 가로등은 아직 켜져 있다.
JRPG 의 「비 오는 밤에 도착한 낡은 도시」·「언덕 위 시계탑으로 올라가는 조사」 필드. 남쪽 선착장으로 배를 타고 들어와
계단을 지그재그로 올라 언덕 꼭대기 시계탑·옛 극장(다음 던전/이벤트 입구)까지 간다. 비 줄기는 그리지 않았다(런타임 오버레이 몫) —
정지 그림은 젖은 윗면의 하늘빛 맺힘·웅덩이·홈통·배수로·이끼·빗물 얼룩으로만 「비」를 말한다.

## 단 구조 (위가 북쪽 = 높은 곳)
| 단 | 줄 | 내용 |
|---|---|---|
| L4 언덕 위 | 0~12 | 극장·시계탑·폐가, 언덕 광장(큰 판석), 뒤로 언덕 숲 |
| L3 윗길 | 13~23 (앞면 13~15) | 집 줄 + 자갈 윗길, 동쪽 둑 빨래 골목 |
| L2 가운데 | 24~34 (앞면 24~26) | 서쪽 집 · 분수 광장(가운데) · 동쪽 둑 집 |
| L1 아랫길 | 35~45 (앞면 35~37) | 집 줄 + 자갈 아랫길(처마 낙수 배수로) |
| L0 부두 | 46~55 (앞면 46~48) | 부두(49~51) · 항구 물(52~) · 선착장 · 하수구 물홈 |
동쪽 둑(x50~64)은 단 끝줄이 서쪽보다 한 줄씩 높아 강을 사이에 두고 단이 엇갈린다. 바깥 가장자리(x0~3, 65~71)는 바위 절벽 + 젖은 풀·덤불.

## 앵커 (5)
1. **바깥 계단·발코니 집** — 1층 벽을 따라 오르는 돌 바깥 계단(쇠 난간) → 2층 층계참(문·빨래) → 3층 작은 쇠 발코니, 덧문 창, 집 사이 골목 빨랫줄 7곳. (L1 서쪽·동쪽, L2 서쪽)
2. **언덕 위 시계탑 + 무너진 옛 극장** — 숫자 없는 시계판·종실·슬레이트 첨탑의 회색 마름돌 탑, 그 왼쪽 기둥 현관·꺼진 지붕·무너진 모서리의 극장, 앞에 닳은 석상·넘어진 기둥. (L4 x17~33)
3. **젖은 돌길 + 배수구 + 웅덩이** — 자갈 거리·큰 판석 광장(분수 둘레 밝은 돌 고리), 판석마다 젖은 정도와 윗모 하늘빛, 웅덩이 오토타일 덩이, 아랫길 처마 밑 돌 배수로 → 배수구, 등불 비친 웅덩이.
4. **돌 아치 다리·고가 통로 + 켜진 가로등** — 강(x46~47) 위 다리 셋: 부두 다리(49), 아랫길 다리(43), 윗길 고가 통로(21, 폭포 바로 위). 다리 끝 기둥 등·가로등·두 갈래 등·벽 등의 노란 불빛 웅덩이.
5. **절벽 옆 폭포·하수구 물줄기** — 강이 네 옹벽을 차례로 떨어지는 폭포 넷, 부두 옹벽의 돌 아치 하수구가 항구 물로 쏟아지는 물줄기.

## 동선
서쪽 선착장(4,54) → 부두 동쪽 → **계단 A**(x13, 부두→아랫길) → 아랫길 동쪽 → **계단 B**(x39, →분수 광장) → 광장 서쪽 →
**계단 C**(x13, →윗길) → 윗길 동쪽 → **계단 D**(x38, →언덕 광장) → 시계탑 문(31,11)·극장 현관(21,10).
돌아가는 길: 아랫길 다리 → 동쪽 골목 → 계단 E(x56) → 동쪽 L2 → 계단 F(x61) → 동쪽 윗길 → 고가 통로 → 윗길. 언덕 광장 서쪽 끝 녹슨 쇠 대문 → 언덕 숲.

## 바닥 · 재질
- 바탕: 버들항 잔디(ground.render)·자갈(칩셋 160,96)·판석(roman.tex_flag 규칙)·옹벽(castle6.ash 마름돌)·물(water6/canal6)·폭포·돌계단(terrain)을 낮 재료로 깔고 `night()`(채널별 단조 변환: 감마 0.92 → 채도 25% 덜기 → ×(0.37,0.44,0.63) + 남색 바닥)로 옮겼다 — 7단 밝기 순위가 그대로 남는다.
- 밤 공간 새 램프(7단): LIT(켜진 창·등), SHEEN(젖은 윗면 하늘빛), PUD(웅덩이·하수 물), IRON(젖은 쇠), 낮 SLATE(칩셋 보랏빛 슬레이트를 청회색으로).
- 젖음 규칙: 위를 향한 면(판석·갓돌·난간 손잡이·지붕 기와 줄 윗모)만 하늘빛 맺힘, 세로 벽은 더 어둡고 빗물 얼룩·아랫단 이끼.
- 오토타일: autotile-puddle(아래층 웅덩이), autotile-gutter(아래층 돌 배수로), autotile-ironrail(위층 쇠 난간).

## 걷기 · 가림
- 집·극장·시계탑: 아래 2줄(벽)만 막힘, 지붕·윗벽은 걷기+가림. 집 문 앞 칸은 모두 선착장에서 닿는다(`--doors` 검사).
- 가로등·광고 기둥·화분 측백·석상: 밑 1줄만 막힘, 위 칸 걷기+가림. 나무: 줄기 칸만. 분수: 아래 2줄.
- 쇠 난간 칸 막힘(계단 머리 칸은 비움). 다리 바닥 줄·선착장 판은 물 위 걷기 칸(`deck`).
- BFS: 선착장에서 marks 전부(극장 문·시계탑·언덕 광장·쇠 대문·윗길·광장·아랫길·동쪽 골목·하수구 앞·고가 통로) 도달 — grid.json `reach_from_dock`.
- 빈 바닥(포장·물·옹벽·계단 제외, 20x15 창): 최악 0.36(언덕 숲 북동), 전체 0.13.

## QA 기록 (원 해상도 사분면 · 2x 크롭 · compare-ref.png 를 직접 봄)
1회차
- 밤 등급 첫 값(×0.46/0.54/0.74)은 판석이 밝은 라벤더색이라 밤으로 안 읽혔다 → ×0.37/0.44/0.63 로 낮췄다.
- 칩셋 슬레이트가 보랏빛으로 튀었다 → 낮 단계에서 청회색 SLATE 7단으로 옮긴 뒤 등급.
- 창유리 찾기가 보랏빛 지붕·돌 줄눈까지 잡아 다락 지붕 전체가 불빛이 됐다 → 유리 = 파랑>빨강+12 이고 초록≥빨강.
- 바깥 나무 계단 두 줄이 X 자로 엉켰다 → 1층 벽을 따라 오르는 돌 계단(옆면 마름돌로 채움) 하나 + 2층 층계참 + 3층 작은 발코니.
- 빨래가 네모 상자로 보였다 → 셔츠·홑청·바지·수건 모양 + 빨래집게.
- 마을 안이 풀밭 위에 집이 떠 있었다 → 마을(x4~64) 전부 포장, 풀은 언덕 숲·바깥 가장자리에만.
- 광장 판석(16x8)이 옹벽 마름돌과 똑같아 바닥이 벽처럼 보였다 → 24x24 큰 판석 + 분수 둘레 밝은 돌 고리, 세로 옹벽은 더 어둡게(젖은 세로 면).
- 반짝임 점이 너무 많아 눈 내린 것처럼 보였다 → 판석·자갈 반짝임을 윗모 줄에만, 확률 1/5 로.
- 웅덩이가 밝은 테두리 알약/ㄱ자 덩이로 아이콘처럼 보였다 → 가장자리 잔물결 줄이고 테두리 대신 짙은 젖은 돌, 덩이는 동서로 길쭉하게.
- 위층 광장 마크가 난간 칸에 있어 BFS 거짓 실패 → 마크를 걷는 칸으로. 언덕 쇠 대문이 가로등·넘어진 기둥에 갇혔다 → 등 위치 이동.
2회차(compare-ref 다시)
- 지붕이 전부 청회색이라 버들항(밤 등급) 옆에서 단조로웠다 → 붉은 기와 지붕 4채를 섞었다(밤에는 검붉은 갈색).
- 분수 수반 앞벽이 양 끝에만 그려져 「탁자 다리」처럼 보였다 → 타원 앞 가장자리 전체에 앞벽, 넘친 물 자국은 벽 안에서 끝냄.
- 넘어진 기둥이 상자 셋 → 원통 명암 + 둥근 단면 두 토막. 폐가 1층 창이 없었다 → 창 둘.
- 서쪽 L1·L3 에 같은 바깥 계단 집이 같은 열로 쌓였다 → 윗길 서쪽은 붉은 지붕 박공 집 + 화분·빗물통으로 바꿨다.

## 아직 약한 곳(솔직하게)
- 단이 동서로 곧게 이어져 멀리서 보면 「층층 띠」가 반듯하다(한 줄 들고 남·동쪽 둑 엇갈림만 있다). 진짜 비탈처럼 굽은 단은 아니다.
- 집 줄이 단마다 같은 밑줄에 서서 여전히 줄지어 보인다. 크기·지붕·폐가 섞기로 덜었지만 버들항 블록 집 계열이라 실루엣 종류가 넷뿐이다.
- 전체가 푸른 단색이라 큰 배율에서 재질 구분(판석·자갈·옹벽)이 약하다. 켜진 창·등만 따뜻한 점이다.
- 하수구 물줄기·폭포는 정지 그림(애니메이션 프레임 없음). 폭포는 버들항 terrain 폭포를 등급만 했다.
- 바깥 가장자리 바위 절벽(칩셋 흙바위 띠)은 밤에도 갈색 네모 띠로 읽힌다.
- 광장 가운데(분수 동쪽)가 아직 조금 비어 보인다.

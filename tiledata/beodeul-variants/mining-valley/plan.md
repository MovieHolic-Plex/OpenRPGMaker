# 산골짜기 광산 마을 「검은재골」 (mining-valley) — 58x46

## 용도
북쪽 큰 산비탈에 갱구를 뚫고 사는 광산 마을. 플레이어가 남쪽 골짜기 길로 올라와
(1) 광석 마당(레일 종점·선광장), (2) 제련소와 슬래그 더미, (3) 북쪽 갱구와 승강 탑, (4) 양옆 계단밭처럼 깎은 단 위 돌집 동네,
(5) 동남쪽 침전 연못을 돌아보는 탐험/거점 마을.

## 구역
| 구역 | 좌표(칸) | 내용 |
|---|---|---|
| 북쪽 산 | y0~9 | 바위 윗면 + 세로결·지층 절벽 앞면 4줄. 그 밑에 갱구·승강 탑 |
| 갱구 앞마당 | x19~42, y10~15 | 광재 섞인 다진 흙. 갱구(통나무 틀+검은 구멍), 승강 탑(나무 탑+바퀴), 광차 |
| 레일 | x33 세로(y11~24) → 모서리 → 가로 y25(x33~43) | 갱구에서 제련소 앞까지. 광석 실은 광차 둘 |
| 광석 마당 | x22~36, y22~31 | 큰길과 레일이 만나는 곳. 광석 통·가마니·연장걸이·등불 |
| 제련소 | x36~45, y24~32 | 돌 가마 집 + 굴뚝 + 화덕. 슬래그 더미(검은 땅) 동남쪽 |
| 서쪽 단 | x1~17, y12~20 (절벽 앞면 y20~21) | 돌집 4채. 절벽 사이 트인 곳으로 비탈길 |
| 동쪽 단 | x43~57, y12~20 | 돌집 3채 + 감독관 2층 집 |
| 동남 단 | x46~57, y30~35 | 광부 숙소 2채 |
| 침전 연못 | x44~56, y38~45 | 회청색 물, 홈통(세척 통로), 널 다리 |
| 남쪽 입구 | x26~32, y36~45 | 여관(2층), 대장간, 입구 표지 |

## 앵커(랜드마크)
1. 갱구 (30,10)  2. 승강 탑 (22,12)  3. 광차 레일 모서리 (33,25)  4. 제련소 굴뚝  5. 슬래그 더미

## 동선
- 입구 (29,45) 남쪽 → 큰길(폭 2) 북쪽 → 광석 마당 → 갱구 앞마당
- 큰길에서 서쪽 갈래 → 서쪽 단 비탈길, 동쪽 갈래 → 동쪽 단, 제련소 길, 침전 연못 길
- 집마다 문 앞에서 가까운 길로 짧은 흙길
- 레일은 길과 따로(걸어서 건널 수 있음, 광차와 탑만 막음)

## 원칙
- 새 땅(광재 섞인 흙, 광재 땅, 자갈길, 레일 바닥 3종, 침전 물, 바위 윗면, 지층 절벽, 깎은 단 윗면)은 버들항 땅과 같은 7단 램프·1화소 윤곽·위왼쪽 빛.
- 빈칸은 소나무·바위·광재 돌무더기 덩이로, 일렬은 금지. 한 화면 빈 땅 ≤ 40%.

## 배치 보정 (실제 그림 기준)
- 남서쪽 넓은 빈 땅을 줄이려고 광부 집 3채와 숙소 홀(2층)을 큰길 서쪽에 덩이로 더했다 (s1·s2·s3·hall).
- 제련소 굴뚝은 집 뒤에 가려져 집 동쪽 옆(tx45)으로 옮겼다. 연기는 오버레이.
- 광석 더미는 붉은 녹색(호박처럼 보임)이라 석탄 몸통+녹·금 반점으로 다시 찍었다.
- 마당·광재 땅에는 나무를 심지 않고 바위도 40%만 허용했다(자라는 숲이 갱구 앞마당을 덮던 문제).

## QA 기록 (적대적 검수)
- 원 해상도 사분면 4장 + 2x 확대(갱구·레일 모서리, 제련소·연못, 동쪽 단)를 직접 봤다.
- 찾아 고친 것: ① 바위 윗면이 눈처럼 밝음 → 톤을 낮춤 ② 주황 광석 더미 53개가 호박 밭처럼 깔림 → 색 교체, 자동 채움에서 제외(7개) ③ 굴뚝이 지붕 뒤에 숨음 ④ 마당 한가운데 전나무 숲 ⑤ 연못 다리 끝 POI 가 물 위 → 다리 위로 이동.
- 통행 BFS: 입구(29,45)에서 POI 전부(집 17·갱구·승강 탑·레일 모서리·다리·홈통 등) 도달, 막힌 POI 0. 걸을 수 있는 칸 1575/1576 도달.
- 빈 땅 한 화면 최대 21% (기준 40% 이하).
- 남은 어색함: ① 땅 흙색이 전체적으로 한 가지라 서쪽 들이 단조롭다 ② 큰길이 폭 2로 곧아 조금 넓어 보임 ③ 산 위 바위 면에 전나무가 얹혀 있어 뿌리 자리가 절벽 위 평지로 보임 ④ 연기 오버레이가 옅음.

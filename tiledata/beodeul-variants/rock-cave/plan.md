# 일반 암석 동굴 (rock-cave) — 계획

기준: 버들항 v6~v8 (16px 손 도트, 3/4, 빛 왼쪽 위). 던전 한 장 **48×40칸**. 생성 그림·트레이싱 없음.
가장 흔한 JRPG 동굴: 입구 → 갈림길 → 석순 회랑 / 지하 호수 / 보물 방 / 아래층 계단. 톤은 차분한 회갈색, 이끼·박쥐 정도.
렌더·배치·조각은 모두 `make_rock_cave.py`(+ `rc_base.py` 재료·오토타일·지도, `rc_props.py` 조각)가 만든다. 다시 돌리면 같은 그림.

## 버들항 재사용 (새로 발명하지 않은 것)
- 물체: 버들항 `px2.C` 볼륨 페인터(재료 grain + 6단 양자화 + 색 윤곽)와 버들항 재료 램프(wood·iron·gold·fire·bone·leaf·rope·bark·dark)를 그대로 쓴다.
  새 재료는 동굴 바위 `crock`(버들항 돌 램프 ST 를 회갈색으로 옮긴 7단, 그림자 보랏빛·빛 노란빛) 하나와 그 젖은 판·이끼 판뿐.
- 벽 앞면: 버들항 `terrain.render` 절벽의 「세로 갈비(rib) 왼쪽 밝음·오른쪽 그늘 + 갈비 사이 틈 + 밑동 그늘」 결을 동굴 바위 램프로.
- 지도 틀: `_lib3/dlib` 던전 지도(천장 밑 앞면 사슬, 천장 띠) + `graveyard-crypt/gc_*`(조각 등록·오토타일·발자국 규약). 읽기만 하고 확장은 이 폴더 안에서.
- 바닥: 넓은 얼룩 없이 「주조 한 단 + 점·3/4 잔돌(윗면 밝음·앞면 어둠·윤곽)·짧은 실금」. 조각 표본은 주기 48, 지도는 같은 함수를 주기 768 로 써서 지도 전체가 한 장(반복 무늬 없음).
  바닥 종류 경계는 화소 단위로 흔들어 칸 격자가 안 보이게 한다.

| F 내림 계단 굴 | 남쪽 가운데 x20~29, y32~37 | **앵커 ⑤-b 부서진 내림 계단**(바닥에 뚫린 구덩이 안 돌계단, 디딤판 이 빠짐), 해골 말뚝, 돌무더기·균열 자갈밭, 매달린 박쥐 |
| 북쪽 고리 | x17~29, y6~8 | D ↔ C 를 잇는 통로(갈림길로 돌아가지 않고 도는 고리) |

## 동선
입구 (9,29) → 북동 통로 → B 갈림길 → (북서) D 석순 회랑 → 북쪽 고리 → C 호수 → 다리로 시냇물 건너 B 로 돌아오는 고리.
B → 동쪽 구불 통로 → E 보물 방. B → 남쪽 → F 계단(아래층). A ↔ F 남쪽 통로로 두 번째 고리. C 서안 → 징검돌 → 섬.

## 원칙
- 방 사이 바위는 4줄 이상(천장 띠 1 + 앞면 3). 1~2줄 얇은 바위·사방이 열린 1칸 천장·작은 바위 섬은 지도 정리에서 연다(떠 있는 벽 토막 금지). 3줄이면 앞면 2줄 + 띠 1줄.
- 키 큰 부드러운 물체(석순·석주·횃불·말뚝·표지)는 아랫줄만 막힘, 위는 걷기+가림. 단단한 몸통(상자·바위·짐·돌무더기)은 몸통 줄만.
- 빈 바닥은 소품으로 메우지 않고 방을 줄이고 암반 턱(오토타일)으로 벽선을 깬다. 한 화면 20×15 빈 바닥 ≤ 40%.
- 계단은 바닥 위, 시트 모양 그대로(2×3, 남쪽 문지방). 사람 얼굴·글자 없음(표지판은 새긴 화살만).

## QA 기록
수치: 입구→9개 지점 모두 도달(BFS), 걷는 덩어리 1개(584칸), 20×15 창 빈 바닥 최대 0.39(40% 넘는 창 0). `grid.json` 에 기록.
눈 검수(원 해상도 사분면 `_qa/quad-0..3.png`, 2배 크롭, `compare-ref.png`):
1. 1판: 방이 서로 겹쳐 한 덩어리 광장이 됨(빈 바닥 47%) → 행마다 열린 구간을 손으로 설계, 방 사이 바위 4줄.
2. 1판: 바닥·벽 명도가 같아 벽이 묻힘 → 바닥 주조 3.7단·벽 1.9단으로 2단 차, 잔돌을 한 단 밝게.
3. 1판: 입구 앞 흙 바닥이 갈색 네모로 보임 → 흙 바닥 지움, 아치 그림 아랫줄의 흙 번짐만 남김.
4. 1판: 암반 턱이 베이지 상자·떠 있는 벽 토막처럼 보임 → 둥근 바위 덩이 무늬 + 볼록 모서리 깎기 + 들쭉날쭉 가장자리로 다시 그림. 시냇물 둑의 소시지 모양 턱은 바위 소품으로 바꿈.
5. 2판: 얇은 바위(띠 없이 앞면만 선 판)·1칸 상자 천장이 여럿 → 지도 정리 규칙(위 원칙) 추가.
6. 2판: 바닥 48px 무늬가 지도에 반복(S자 실금) → 지도는 같은 함수를 주기 768 로 한 장에 칠함. 넓은 밝기 얼룩 진폭을 반으로.
7. 2판: 호수가 네모, 물 잔물결이 칸마다 이음새 → 물을 주기 16 잡음 + 엇갈린 잔물결 줄로, 물가 볼록 모서리 둥글게, 섬 모서리 두 칸 깎음.
8. 2판: 징검돌이 하얀 알약 줄 → 젖은 바위 램프, 크기·자리 변형.
9. 석순이 너무 희고 매끈 → 원통 명암(왼쪽 밝은 띠→오른쪽 그늘)·흐름돌 고리·grain 키움, 한 단 어둡게. 박쥐(폭탄처럼 보임) 다시 그림. 버섯 주황 → 갈색.
남은 약점(솔직히): 천장 띠의 밝은 테두리는 기존 던전(바다 동굴 등)과 같은 결이지만 버들항 지상 그림보다 단조롭다. 칸 격자 모양 동굴 윤곽(계단식 모서리)은 여전하다.
빛줄기·벽 횃불 빛무리는 약하게만 보인다. 큰 석주 꼭대기는 천장 그늘로 끝나 벽 앞면에 붙여 써야 자연스럽다.

# 대나무 숲 계곡 (bamboo-valley) — 장르 wuxia · 장소 팩 전용

## 용도
안개 낀 대숲 속으로 개울이 굽이쳐 흐르는 무협풍 계곡 필드 팩이다. 하늘을 가릴 만큼 빽빽한 대숲, 폭포에서 흘러내린 개울과 강돌 둑,
돌 아치 다리·죽교·징검다리, 은자가 사는 초가와 약초 마당, 폭포 웅덩이 곁의 주칠 기둥 정자, 대숲 속 돌 감실과 글자 없는 비석,
낙엽 깔린 죽림 오솔길을 한 팩으로 담았다. 은둔 고수를 찾아가는 길, 수련 장면, 대숲 속 결투, 물가 쉼터 장면에 쓴다.
바닥 표본(풀·고사리 풀·대숲 그늘 풀·다진 흙·대나무 잎 땅·화강암 판석·물가 자갈)과 땅 덩이 오토타일(개울 물·대나무 잎 땅·이끼·
낙엽 오솔길·대나무 난간 울타리)이 모두 들어 있어 이 팩 하나만으로 계곡 지도를 처음부터 끝까지 깔 수 있다. 전투 배경 1장 포함.

## 지도 (64x48, 필드)
- 칠하는 순서(`render-stages.png`): ① 맨 바탕 표본(풀 전체 → 마당 흙 · 정자 앞 판석 · 감실·징검다리 끝 물가 자갈) →
  ② 땅 덩이 오토타일(대숲 밑 대나무 잎 땅 · 물가·감실 이끼 · 낙엽 오솔길 · 개울) → ③ 건물·다리·대숲·소품 → 안개(맨 위).
- 구역과 앵커
  1. 북: 작은 폭포(39,0~3) → 웅덩이(35~45, 4~9) · 죽림 정자(47~51, 7~12, 앞 판석 + 돌등 둘) · 바위 소나무 · 바위 무리 · 안개.
  2. 서: 은자의 초가(19~23, 10~14) + 헛간 + 약초 채반·바구니·항아리·장작·물대롱·수련 기둥, 대 난간 울타리와 사립문(23,21) + 장대 등롱 둘.
  3. 가운데: 돌 아치 다리(개울 y30) — 남쪽 입구에서 서쪽 초가·감실로 건너는 길목.
  4. 서쪽 대숲 속: 돌 감실 터(4~10, 23~27) — 감실·비석 둘·향로·돌등 둘, 자갈 마당 + 이끼.
  5. 남서: 징검다리(y41) 건너 물가 쉼터 — 돌 탁자와 의자, 바둑판 바위, 너럭바위, 단풍, 갈대.
  6. 나머지: 빽빽한 대숲(덩이 4x7·3x6 를 3줄 간격 엇갈림 + 덤불·홀로 선 대·어린 대), 빈터마다 바위·쓰러진 대·고사리·죽순.
- 동선: 남쪽 입구(47,47) → 오솔길 북 → (46,35) 갈림 → 서: 돌다리 → 초가 사립문 / 감실 터, 북: 정자 · 죽교(y18) 건너 초가 동쪽 마당,
  동: 징검다리 → 쉼터. BFS: 걷는 칸 전부(2122칸)가 입구에서 닿는다(grid.json `reached`), 표식 10곳 모두 닿음.
- 빈 바닥: 20x15 창 최악 0.28(기준 ≤ 0.40), 평균 0.14.

## 걷기·가림
대나무 덩이·덤불·홀로 선 대·어린 대·갈대·단풍·돌등·장대 등롱·비석·감실은 맨 아랫줄(밑동)만 막히고 위 칸은 걷기 + 위층(가림).
초가·헛간·정자는 아래 2줄 막힘(문·계단 칸만 걷기). 돌 아치 다리는 가운데 줄만 걷기, 죽교는 아랫줄(바닥)만 걷기. 징검다리 돌을 얹은 물 칸은 걷기.
대숲 수관은 길·개울 바로 위 4줄을 덮지 않게 놓았다.

## 장르 규격
`tiledata/beodeul-kits/genres/wuxia.md`: 회청 기와(KAWARA) + 주칠 기둥(SHU) + 회색 석재(버들항 돌) + 먹빛 원경 + 대나무 TAKE.
이 장소 새 재질 = 마른 대나무 잎(kare) · 안개(kasumi, 체크 디더 단색) · 젖은 바위 물때(sei). 그 밖은 버들항·eastern-castle 램프 그대로.

## 고친 기록(compare-ref.png 아래 BEFORE/AFTER 줄, history-v1.png = 첫 판)
1. 대나무 잎 땅·이끼 오토타일: 첫 판은 잎 획마다 그늘 점을 찍어 갈색 잡음 카펫 + 칸마다 같은 얼룩이 격자로 보였다 → 마른 잎 켜 바탕 + 그늘 없는 획, 세로 획 제거.
2. 개울 둑: 돌이 너무 희고 들쭉날쭉(가시) → 들쭉날쭉 폭 2.9→2.0, 윗면 돌만 한 단 밝게.
3. 대숲: 버들항 나무 옆에서 연두 잡음으로 튀었다 → 가운데 잎 덩이 한 단 어둡게, 처진 잎 절반은 그늘 톤.
4. 감실 터: 판석 네모 판이 벽 토막처럼 보였다 → 부드러운 가장자리 자갈 마당. 물가 자갈은 그물 무늬 → 모래 바탕 위 떨어진 강돌.
5. 판석: 가장자리 턱 선·아래 그림자를 빼고 대비를 낮췄다(바닥이 벽처럼 서 보이지 않게).

## 전투 배경 (battle-bg.png)
원경 = 연한 청회 하늘 띠 4단 + 손 구름 셋 + 먹빛 봉우리 실루엣 두 겹, 지평선 = 대숲 벽(뒤 줄 한 단 어둡게) + 붉은 단풍 하나.
바닥 = 이 장소 오토타일(가운데를 가로지르는 낙엽 오솔길 + 양옆 대나무 잎 땅·이끼). 가장자리 = 대숲 덩이·덤불·돌등 짝·바위·고사리.
`check-overlay.png` 에 적 3·아군 4 표식 — 가운데 배틀러 자리(x120~560, y190~330)에 키 큰 물체 없음. 640x360 · 불투명 · 96색.

# 사막 성 (desert-castle) — 모래에 반쯤 잠긴 사암 성 외관 56x40 + 성 밑 지하 기계실 40x30 (한 맵 98x40)

## 용도
사막 왕국의 버려진 성. 남쪽 사막 길로 와서 성문(문루)으로 안뜰에 들어가 마른 분수·기둥열·그늘 천막을 지나 잠긴 본관 문 앞에 선다.
본관 문은 잠겨 있고, 진짜 길은 성 밖 — 무너진 동쪽 성벽 틈으로 안뜰의 모래가 폭포처럼 쏟아지는 자리 곁, 모래 속으로 내려가는 계단이다.
계단은 성 밑 지하 기계실(옛 물 펌프·문 기계)로 이어지고, 그 안 북쪽 벽에 대형 기어 문(봉인, 이벤트)이 있다. 성 밖 남서쪽엔 오아시스 한 점(낙타 말뚝·물통).
야외(x0~55)와 지하(맵 x58~97, y5~34, 둘레는 천장)는 같은 맵에 나란히 놓고 계단 한 쌍으로 잇는다.

## 앵커 (5)
1. **사암 성채** — 성가퀴 성벽 + 둥근 탑 넷 + 문루(아치·쇠창살) + 돔 본관, 서쪽 아래층이 모래에 묻혀 창 머리만 보인다.
2. **모래 폭포와 모래 속 내림 계단** — 무너진 동쪽 성벽 틈으로 안뜰 모래가 굵은·가는 줄기로 앞면을 타고 흐르고, 곁에 사암 계단 구멍이 어둠으로 내려간다.
3. **성 안뜰** — 마른 분수, 기둥열(참배 길)·주랑 둘, 그늘 천막.
4. **지하 기계실** — 대형 기어 문, 피스톤 기관, 보일러, 톱니 구덩이와 놋쇠 난간, 벽 틈에서 새는 모래.
5. **오아시스 한 점** — 못·야자·낙타 말뚝·물통.

## 동선
야외: 남쪽 입구 (27,39) → 화톳불 기둥 사이 → 문루 통로 (26~27, 19~23) → 참배 길 → 본관 문 앞 (27,12) [잠긴 문].
곁: 길 서쪽 → 오아시스 (17,33). 길 동쪽 → 모래 폭포 곁 계단 (45,25) ⇒ 지하 계단 위 (맵 90,10).
지하: 계단 → 홀 동쪽 → 기어 문 앞 (맵 74,11) / 홀 서쪽 기관 → 서쪽 통로 → 펌프실 → 남쪽 복도 → 창고 → 동쪽 통로 → 홀 (고리). ㅁ자 고립 방 없음.

## 걷기 규약
성벽·탑·문루 탑 열·본관 = 칸 전체 막힘(문루 가운데 두 열은 통로, 탑 꼭대기 2줄 걷기+가림). 계단: 가운데 두 열 걷기, 난간 열 막힘.
기둥·깃대·화톳불·야자·밸브 = 밑동 한 칸만 막힘(위는 걷기+가림). 분수·톱니 구덩이·우물 = 칸 전체. 기관·보일러·조종대·작업대·관성 바퀴 = 아래 2줄.
모래 번짐·모래 더미·깔개·창살·쇠사슬 = 걷기. 성 뒤·옆 깊은 모래 = 막힘. 지하 벽 장식은 앞면 위(막힘).

데모: 오아시스 못을 손으로 그린 칸 마스크(북쪽 혹·남쪽 만·남동 코)에 pond 오토타일, 둘레 풀밭(못을 2~3칸 넓힌 마스크 + 옛 풀밭)에 grass 오토타일. 옛 화소 덩이 못·젖은 테·풀 술은 뺐다.
언덕 오토타일 덩이 둘(남동 사막 38,34 / 성 앞 서쪽 14,25).

### 규칙 2 — 고친 곳
1. **안뜰 둘레 회색 네모 테**: 원인 = 옆 성벽 통로(`wall_side`)와 성벽(`wall_front*`) 그림이 꽉 찬 직사각형인데 pz.fin 이 그림 네 둘레에 1px 윤곽(×0.62, 파랑 ×1.1)을 그렸다.
   밝은 사암(SS[6]) 가장자리가 (158,148,130) 회색 줄이 되어 안뜰 판석·모래 몸 둘레에 직사각형으로 보였다(동쪽 x=800 세로줄, 앞 성벽 윗줄 y=304 가로줄 등).
   → `fin_sel`: 그림 속 투명 구멍 둘레는 윤곽, 그림 둘레는 고른 쪽만. `wall_front` = 아래(땅)만, `wall_side` = 없음(바깥 가장자리는 짙은 사암 1px 로 직접).
   윤곽색은 ×0.62 밝기에 맞는 사암 램프 색(따뜻한 갈색). 같은 회색 테가 있던 문루·본관·모래 속 계단·안뜰 사암 소품(기둥·주랑·분수·화분·벤치)도 같은 윤곽으로 다시 그렸다(이름 그대로 덮어씀).
   덤: 서쪽 남서 탑이 묻힌 성벽에 드리운 그늘이 모래 비탈 위까지 세로 띠로 칠해지던 것 → 모래 높이 위만.
   덮어쓴 조각: wall_front, wall_front_buried, wall_front_breach, wall_side, gatehouse, keep_hall, sand_stairwell, 안뜰 사암 소품 7종(column·column_broken_tall·column_toppled·stoa·dry_fountain·dry_planter·stone_bench).
2. **성벽 정면이 평평함** → 새 앞면 변형 3종(새 이름): `wall_face_repair`(2x2, 작은 8x4 새 돌 보수 자국 = 줄눈 변화, 이음 금, 옛 큰 돌 하나),
   `wall_face_crack`(2x3, 계단꼴 균열 + 떨어진 모서리 + 발치 조각·모래), `wall_face_lattice`(2x3, 내민 나무 살창 덧창 — 처마판·마름모 살·까치발·그늘).
   데모: 북쪽 성벽 서·동, 무너진 앞 성벽에 각 3개(균열·살창·보수를 엇갈려, 깃발과 안 겹치게).
3. **데모 오아시스** → 위 오토타일로 다시 렌더(render-1x/2x).
통행 BFS 다시: 남쪽 입구 → 야외 표지 전부, 지하 표지 전부, 계단 짝 연결, 고립 걷는 칸 0. 빈 창 최악 야외 0.357 / 지하 0.397.

### 아직 다른 점(솔직히)
- 4비트 오토타일이라 오목 모서리에서 물가 빛 테가 2~3px 끊긴다(작은 진한 물 귀퉁이). 칸마다 같은 물결이 16px 주기로 되풀이된다.
- `autotile-dune-crest` 는 가장 약하다: 기존 모래 언덕 물체(gen_dune)보다 비탈이 얇아 「모래 계단 턱」처럼 읽힐 때가 있고, 1칸 폭 띠는 마루 없이 그늘만 남는다. 넓은 덩이(3칸 이상)로만 칠할 것.
- 보수 자국은 2배에서 「다른 돌로 메운 자리」로 읽히지만 1배에서는 얼룩에 가깝다.
- 이전 판의 남은 약점(대칭 성곽 실루엣, 계단꼴 길 갈래, 지하 아래 검은 띠, 작은 피스톤 기관)은 이번 보정 범위 밖이라 그대로다.

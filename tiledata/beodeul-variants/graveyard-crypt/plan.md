# 공동묘지와 지하 묘소 (graveyard-crypt) — 56×46

## 용도
외곽 마을의 낡은 공동묘지. 플레이어는 남쪽 정문으로 들어와 광장(천사 석상)을 지나 북쪽 영묘에서 지하 묘소로 내려가는 야외+던전 한 판이다.
지상 사건(파 놓은 무덤, 해골 손, 도깨비불, 까마귀 비석)과 지하 탐색(납골실·석관 홀·깊은 묘실)을 한 맵에서 잇는다.

## 동선
- 지상: 정문 밖(27,25) → 정문 → 길(27~28열) → 광장 → 영묘 문(27~28,8). 동서 흙길 y14~15 가 두 묘역으로 갈라진다.
- 지하(영묘 문 이벤트): 안뜰(27,32) → 서(가족 납골실) / 동(석관 홀) / 남 복도 → 깊은 묘실 → 계단(27,41).
- 지하는 ㅁ자 고립 방이 없다. 방마다 천장 밑 벽 앞면 3줄, 복도 2줄.

# 대초원·투기장 (veldt-coliseum) — 80×61 (대초원 필드 80×48 + 투기장 지하 대기실 40×10)

## 용도
마른 풀이 끝없이 이어지는 대초원 한가운데 돌로 쌓은 원형 투기장이 서 있다. 일행은 서쪽 끝 짐승 길·남쪽 끝 옛 돌길·동쪽 끝 짐승 길 중 하나로
들어와 초원(바위 언덕·고사목·야영 흔적·물웅덩이)을 지나 **투기장 앞마당**에 닿고, **정문 아치**(문길 2칸, 외피에 가림)를 지나 **경기장 모래** 위에 선다.
북쪽 **지도자 발코니** 아래 **쇠창살 문**이 지하 대기실(쇠창살 감방·무기 걸이·갑옷 받침·숫돌)로 가는 계단과 이어진다(LINKS).
실내는 같은 투기장의 지하라 맵 아래 띠에 따로 놓았다(검은 바탕).

## 앵커 (7)
1. **원형 투기장 외관** — 3/4 시점 타원 외벽: 받침 띠 + 2단 아치(반기둥·아치돌·안쪽 회랑 어둠) + 돌림띠 + 위층 작은 창 + 갓돌 윗길, 깃대 열셋(붉은/청보라 삼각기).
2. **정문 아치** — 큰 반원 아치(아치돌 방사 줄눈·들어 올린 쇠창살), 위 걸개 둘, 문길 2칸.
3. **경기장 안** — 10단 관중석(5단째 넓은 통로 + 출입구 어둠), 안쪽 경기장 담, 모래 바닥(갈퀴 줄)·모래 자국·떨어진 방패·부서진 전차.
4. **지도자 발코니 + 쇠창살 문** — 담 위로 내민 귀빈석(붉은 천 덮개·금 술·기둥 둘·좌석 둘, 사람 없음), 아래 아치 쇠창살 문 + 걸개 둘.
5. **앞마당** — 판석 마당, 화로·걸개 기둥·승리 기둥(금 투구·엇갈린 칼)·노점(줄무늬 차양)·무기 걸이·갑옷 받침.
6. **초원 야영 흔적·물웅덩이·바위 언덕** — 가죽 천막·식은 모닥불, 물웅덩이와 짐승 뼈, 둥근 바위 더미.
7. **지하 대기실** — 쇠창살 감방(16변형 오토타일 + 감방 문), 무기 걸이·갑옷 받침·숫돌, 벽 속 계단.

## 걷기·가림
- 투기장 외피: 외벽·관중석·담 칸 막힘, 외피가 덮는 북쪽 칸도 막힘. 경기장 모래 중 보이는 칸은 걷기, 남쪽 관중석에 가린 칸은 막힘.
  정문 문길 2칸(x55·56, y16~26)은 걷기 + 가림(외피 위층). 북쪽 쇠창살 문 칸 (55~56, 11) = 지하 문 이벤트 칸(걷기), LINKS → 지하 계단 위 (55,52).
- 키 큰 부드러운 물체(우산나무·고사목·걸개 기둥·화로·승리 기둥·갑옷 받침·허수아비·창 통·개미탑·억새·갈대): **맨 아랫줄만 막힘**, 위 칸 걷기+가림.
  우산나무는 밑동 가운데 2칸만, 수관 4칸 폭은 열려 있다.
- 단단한 몸통(천막·바위 언덕·노점 계산대·전차·갈비뼈·무기 걸이·의자·통·상자): 몸통 줄만 막힘(천막·바위 언덕 2줄, 나머지 1줄).
- 물웅덩이: 물·둑 칸 막힘(네 모서리 걷기). 쇠창살 칸 막힘, 감방 문 둘은 닫힘(이벤트), 가운데 감방 문만 열림.

## 바닥·재질
- 초원 = 버들항 `ground.render`(칩셋 풀 타일 섞기) 결을 그대로 두고 색만 마른 풀 램프로(밝기 순위 보존). 그늘 풀 덩이(위장무늬가 되는 짙은 덩이)는 잔디 결로 바꿨다.
  그 위에 잔 풀·씨앗 풀·마른 풀 덤불·들꽃 장식을 덩이로 찍는다(plains-highroad 와 같은 채움 방식).
- 키 큰 마른 풀 덩이 = 칸 마스크를 둥글리고 화소 단위로 흔든 덩이(세로 줄기 결 + 윗가장자리 이삭 끝) + 억새 장식 30%. 붓·조수용은 `autotile-drygrass`.
- 짐승 길·밟힌 흙 = 다진 흙 결(굽 자국)을 화소 단위로 흔든 덩이. 붓·조수용은 `autotile-gametrail`.
- 판석(앞마당·돌길) = 버들항 칩셋 판석(192,176), 칸마다 뒤집어 16px 반복을 깸, 굵은 연석 없이 가장자리 1화소 + 마른 풀 잔털.
- 투기장 석재 = 버들항 성 마름돌 `castle6.ash`(16×8 줄쌓기), 관중석은 크림 섞은 밝은 돌, 아래 단 흙먼지. 경기장 모래 = 칩셋 모래(64,224) 결을 밝은 모래 램프로.
- 지하 = 같은 마름돌·판석을 지하 조도로 낮추고 횃불 둘레만 따뜻하게 밝힘.
- 새 재질 램프(7단, vc_base): 마른 풀 dry, 올리브 풀 olive, 경기장 모래 sandA, 무두질 가죽 hide, 초원 바위 sstone, 바랜 고사목 gwood, 바랜 뼈 bonew, 다진 흙 trail.

## QA 기록 (2026-10-08)
1. 첫 외피: 경기장이 흰 돌 덩이로만 보임 → 아치 안쪽 회랑(바닥 띠·더 깊은 안쪽 아치), 관중석 디딤 크림 섞기 + 단 번갈아 명암, 챌면 어둡게, 아래 단 흙먼지.
2. 발코니가 경기장 담 줄 조각보다 먼저 그려져 쇠창살 문·걸개가 사라짐 → 발코니 정렬 키를 담 줄 다음으로.
3. 문길이 남쪽 관중석 칸에서 끊겨 경기장에 못 들어감(BFS) → 문길 2칸을 경기장 가운데 줄부터 외벽 발치까지 연다. 대기실 앞 복도가 통·상자에 막힘 → 서쪽 구석으로 옮김.
4. 땅: 길가 닳은 풀(칩셋 회색 결)이 회색 계단 줄로 보임 → 땅 렌더에 길 마스크를 주지 않는다. 그늘 풀 덩이가 올리브 위장무늬 → 잔디 결로 바꿈. 밝은 풀밭 덩이 대비 낮춤.
5. 키 큰 마른 풀(오토타일로 깐 첫 판)이 칸 경계 직사각형 덩이 → 마스크를 둥글리고 화소 단위로 흔든 덩이로, 아랫가장자리 짙은 줄 제거, 억새 장식을 뒤집기·넓은 덤불 섞어 30%.
6. 짐승 길(오토타일)이 대각 굽이에서 계단 모양 + 굽 자국 사다리 무늬 → 지도는 흔든 흙 덩이로, 굽 자국은 5px 격자 안 무작위 자리.
7. 판석 돌길이 굵은 연석 때문에 낮은 담처럼 읽힘 → 연석 제거(가장자리 1화소 + 풀 잔털), 칸마다 결 뒤집기.
8. 비교 시트 1회차: 성 돌 대비 돌 크기가 작고 흐림 → 16×8 줄쌓기 + 외피 안쪽 윤곽. 지하가 묘소보다 밝고 납작 → 벽·바닥·천장 조도 낮춤, 방 높이 11→10.
   2회차: 초원이 하이로드 풀밭보다 밋밋 → 들꽃 장식, 채움 목표 0.36→0.30, 야영지·물웅덩이·바위 언덕에 밟힌 흙 바닥(하이로드 야영지와 같은 구조). 뼈가 풀에 묻힘 → 흙 바닥 위로, 그림자 진하게.
   3회차: 흙 바닥이 회갈색으로 차가움 → 따뜻한 흙 램프. 우산나무가 같은 그림 반복 → 뒤집기·색조 변형 넷.
9. 소품: 털가죽 깔개가 빵 덩이처럼 보임 → 다리 자락·꼬리 있는 털가죽. 허수아비 머리가 흰 초처럼 → 자루 머리 + 끈. 숫돌이 부채처럼 → 테·굴대 있는 바퀴. 고사목·뼈가 분홍 윤곽(회벽 램프) → 바랜 나무·뼈 램프.

## 남은 차이(솔직하게)
- 투기장 마름돌은 버들항 성보다 깨끗하고 납작하다(돌마다 명암 차·얼룩이 적다). 외피가 커서(32×26칸) 1x 에서 아치 리듬이 기계적으로 고르다.
- 관중석은 사람·천막 없이 빈 돌 계단이라 단조롭다(5단째 통로와 출입구로만 끊었다). 남쪽 관중석은 3/4 각도 때문에 얇은 띠로만 보인다.
- 초원 바닥은 버들항 잔디 결을 옮긴 것이라 바닥 자체 질감이 약하고, 질감은 대부분 장식(잔 풀) 몫이다. 키 큰 풀 덩이 속은 세로 줄 결이 고르게 반복된다.
- 물웅덩이(6×4)는 지도 크기에 비해 작고, 짐승 뼈는 1x 에서 작게 읽힌다.
- 지하 대기실은 묘소 기준작보다 아직 밝은 편이고, 남쪽 줄이 비어 보인다. 계단 위쪽은 어둠으로만 처리했다.
- `autotile-gametrail`·`autotile-drygrass` 16변형 시트는 붓·조수용이고 이 지도에서는 같은 결의 흔든 덩이로 깔았다(지도에서 시트 그대로 쓰면 칸 경계가 더 각진다).

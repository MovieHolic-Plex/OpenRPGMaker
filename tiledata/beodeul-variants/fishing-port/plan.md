# 어촌 포구 마을 (52x40) — plan

## 용도
버들항(로마풍 대도시 항구)의 작은 이웃. 사는 곳 겸 일터인 소박한 포구. 플레이어는 서쪽 길로 들어와 시장 마당 -> 잔교 -> 등대 길목으로 흐른다.

## 구역
- 북쪽 살림 구역: 집 13채(3x6 오두막 위주, 6x5 돌담 집 셋 섞음), 밭 두 곳(밀 이랑 / 채소 이랑), 빨래 널이, 우물.
- 중앙 시장 마당(포장): 생선 시장 좌판이 마당 남쪽 물가에 걸쳐 앉는다. 생선 상자·통·안내판.
- 서쪽 자갈밭: 그물 말림대 3, 그물 틀, 엎어 둔 배, 통발 더미.
- 남쪽 바다(약 45%): 잔교(T자 머리) 하나, 서쪽 작은 부두 하나, 어선 6척·거룻배 3척.
- 동쪽 곶: 등대 + 자갈 발치, 사이프러스.

## 앵커
1. 생선 시장(96x88) 2. 잔교 T자 머리 3. 등대(48x144) 4. 그물 자갈밭.

## 동선
서쪽 입구(0,13) -> 굽은 도로(폭 2) -> 시장 마당 -> (a) 잔교 몸통 -> T머리 (b) 동쪽 굽은 길 -> 밭집 골목 / 등대 발치. 서쪽 자갈밭 옆에 작은 부두.
직선 구간 <= 45칸(가장 긴 도로가 약 20칸).

## 새로 찍은 조각
잔교·서쪽 부두·말뚝·등대·생선 시장·말림대 2·엎어 둔 배·통발 = 10종 142칸 (parts.md).
재사용: h* 집 13종, well_roofed, field1/2, laundry_rack, fish_crates/fish_barrel/crate_fish, sandwich_board, mooring_bollard, door_pots, 어선/거룻배, 나무 4종.

## QA 기록
- 도달 BFS(입구 -> 시장·잔교 끝·서쪽 부두·그물 말리는 곳·등대 문·집 13채 문): 전부 True.
- 빈칸: 한 화면(20x15) 최대 15%, 마을 빈 덩이 최대 6칸, 5~6칸 덩이 12곳이 남음(기준 4). 나무·덤불 자동 채움(fill_patches)이 도달을 깨는 자리는 되돌려서 그렇다. 집 사이 잔디라 자연 마당으로 본다.
- 발견 후 고침: (1) 잔교 몸통이 14칸으로 너무 길어 7->10칸으로 줄이고 바다 높이를 유지한 채 서쪽 부두와 배를 늘림. (2) 채소 밭 위에 참나무가 얹혀 옮김. (3) 초판 56x44는 북쪽이 텅 비어(창 83%) 52x40 으로 다시 짬. (4) 시장·집 몇 채가 도로 막힘이라 BFS로 찾아 옮김.
- 남은 어색함: 북쪽 나무가 빽빽해 숲 마을 같이 보임. 잔교 몸통이 여전히 조금 긴 편. 해안선이 완만한 사인 곡선이라 단조로움. 어선이 돛 하나 모양뿐(변형 1종).

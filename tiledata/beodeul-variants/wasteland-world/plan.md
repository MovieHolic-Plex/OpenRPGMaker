# 세계 붕괴 후 황폐 필드 (wasteland-world) — 80x56 걸어 다니는 JRPG 필드

## 용도
재앙 뒤 갈라진 붉은 갈색 대지. 남쪽 입구로 들어온 일행이 생존자 야영지(정보·휴식)와 마른 호수 바닥(난파선·뼈 — 보물/이벤트 자리)을 지나,
대지를 동서로 끊은 **깊은 골**을 **부서진 옛 돌다리** 하나로 건너 북쪽 폐허(반쯤 묻혀 기운 옛 망루·기울어 가라앉은 옛 회당)에 닿고,
죽은 숲을 지나 북쪽 출구로 나간다. 화산 지대(검은 재)와 구분되는 붉은 갈색 톤.

## 앵커 (5)
깊은 골 + 부서진 돌다리 · 반쯤 묻혀 기운 옛 망루(담 줄과 함께) · 기울어 가라앉은 옛 회당 · 마른 호수 바닥(난파선·거대 물고기 뼈·끊긴 부두) · 생존자 야영지(천막·모닥불·고철 울타리). (+ 죽은 숲)

## 동선
남쪽 입구 (40,55) → 큰길 → 33줄에서 동쪽 → 부두 (60,39) → 마른 호수 바닥(난파선 (57,49), 물고기 뼈 (67,51)).
큰길 41줄에서 서쪽 → 야영지 입구 (23,41) → 모닥불 (15,42).
큰길 → 다리 남쪽 끝 (39,29) → 다리 → 북쪽 끝 (39,20) → 망루 앞 (38,13). 16줄에서 서쪽 → 회당 앞 (9,15). 망루 길에서 동북 → 죽은 숲 → 북쪽 출구 (66,0).

## 규칙 확인
- 고목·부러진 기둥·신호 장대·바위 기둥: 줄기/밑동 1칸만 막힘, 위 칸 걷기+가림(고목 가지끼리는 겹쳐도 된다 — 숲).
- 망루: 몸통 아래 4줄(칠해진 칸만) 막힘, 위 3줄 걷기+가림. 회당: 앞벽 아래 3줄 막힘. 천막: 아래 2줄 막힘. 담·울타리: 아랫줄 막힘.
- 골(앞면 + 골 속) 막힘, 다리 판석 칸 걷기(머리 기둥 밑 두 칸 막힘). 균열 칸 막힘. 부두 널 칸 걷기, 끝 한 줄 막힘.
- 통행 BFS: 남쪽 입구에서 이름 붙은 11곳 전부, 걷는 칸 3534 전부(고립 칸 0 — 물체를 놓을 때마다 고립 칸이 생기면 되돌린다).
- 빈 바닥: 20x15 창 최악 0.377, 평균 0.31(마른 풀 덩이 자리·진흙·재·야영지 마당은 「채움」으로 셈).

## QA 기록
1. 바닥 첫 렌더: 갈라진 틈이 칸마다 다각형으로 촘촘해 포석처럼 보임 → 틈 칸을 30px 로 키우고 좌표를 흔들고 덩이로만 남김.
   마른 호수 판이 자갈길처럼 보임(판마다 톤 차·모난 모) → 판 속은 칩셋 모래흙 결 그대로, 틈은 1px, 말린 판만 위 모 밝게.
2. 첫 지도: 「다져진 땅」 덩이가 밝은 주황 얼룩(위장무늬) + 재가 회색 융단 → 다져진 땅 톤을 흙과 거의 같게, 재 덩이는 크게 줄이고
   재 오토타일을 반투명 알갱이로 바꿈(밑 흙 결이 비쳐 칸 무늬가 안 남는다).
3. 마른 풀·바위 기둥이 지도 전체에 고르게 뿌려짐(소금·후추) → 풀은 낮은 주파수 잡음이 큰 곳에만 덩이로, 바위 기둥은 바위 덩이 곁에만.
4. 망루 양쪽 담이 놓이지 않음(탑 칸과 겹쳐 거부) → 담을 탑 몸통 뒤로 겹쳐 그리는 전용 놓기, 붙는 끝은 온전한 줄로 다시 그림.
5. 회당·망루 밑 흙 둔덕 아래에 곧은 어두운 줄(턱처럼 보임) → 밑자락은 체커로 땅에 녹아들게. 그림 밑 빈 줄 때문에 회당이 떠 보임 → 밑변 자르기.
6. 야영지 안을 균열이 가로지름 → 균열 위치 옮김. 야영지 바닥은 재 대신 밟아 다진 흙 마당. 천막이 하나라 약함 → 반대로 기운 천막 추가.
7. 부두 끝이 진흙에 닿지 않음 → 부두를 두 줄 남쪽으로. 북동·남쪽 고립 칸 10 → 고립 금지 놓기.
8. 비교 시트 `compare-ref.png` (2배: 버들항 절벽·계단 | 골·다리 / 초원 하이로드 망루 | 묻힌 망루·담 / 폐허 마을 집 | 기운 회당 /
   폐허 마을 고목 | 죽은 숲 / 난파 암초 | 마른 호수 / 초원 하이로드 야영지 | 생존자 야영지) 3회. 1회차 위 1~5, 2회차 담 떨어짐·재 융단, 3회차 같은 화풍으로 읽힘.

## 남은 차이(솔직하게)
- 바닥 붉은 흙은 버들항 풀보다 명암 단이 좁아(2~4단) 넓게 보면 단조롭다. 검붉은 고목이 흙과 명도 차가 작아 숲이 다소 어둡게 뭉친다.
- 망루는 초원 하이로드 망루를 재색칠·기울인 것이라 새 형태는 아니다. 마름돌이 바랜 분홍 황토라 붉은 땅 위에서 밝게 뜬다(의도: 눈에 띄는 앵커).
- 부러진 고목 줄기(dead_snag)·바위 기둥은 멀리서 말뚝처럼 보인다. 야영지 소품(모닥불·쇠통)은 작아 2배에서야 읽힌다.
- 골 가장자리는 칸 단위 계단(1줄씩 오르내림)이라 직각 꺾임이 보인다(화산 지대 절벽과 같은 한계).
- 재 오토타일은 지도에서 아주 좁게만 썼다(넓게 깔면 칸 반복이 보인다).

### 아직 다른 점
- 오토타일 속은 16px 마다 같은 무늬라 큰 재 평원·점토판은 가까이서 칸 반복(물결·금)이 보인다.
- 재 평원은 밝은 회색이라 붉은 땅 위에서 눈 덮인 자리처럼 보일 수 있다. 자갈 띠는 1배에선 거의 안 읽힌다.
- 남쪽 웅덩이 서쪽 가장자리는 큰길 한 칸 여백 때문에 곧게 끊긴다.

# 전투 배경 — 필드 계열 6장 (battle-bg-field, 웨이브 5)

640×360 · 불투명 · 색 ≤ 96 · 낮·맑음(늪은 안개, 화산은 연기). 구도: 위 ~y176 = 하늘·원경, 아래 = 3/4 탑뷰 전투 바닥.
배틀러 자리(x 120~560, y 190~330)에는 키 큰 물체·밝은 점이 없고, 맨 아래 20px 는 HUD 가림이라 중요한 그림이 없다.
다시 만들기: `python3 make_battle_bg.py` (장소마다 `bg_<장소>.py` 를 따로 실행 → 규격 검사 → `compare-ref.png`·`check-overlay.png`).
바닥·물체는 각 장소 폴더의 그림 모듈을 `src-<장소>/` 로 복사해(경로 한 줄만 고침) 그대로 부른다. 공용 하늘·능선·합성은 `bgkit.py`.

## QA 기록
- 1회차 비교(`compare-ref.png`): 평야 길이 칸 계단으로 꺾여 상자처럼 보임 → 곧은 길. 망루 입구 계단 없음 → ruin_steps. 숲 제단이 풀 위에 떠 보임 → 이끼 판석 단. 숲 바닥 이끼 오토타일 큰 덩이가 위장무늬 → 외톨이 방석. 낙엽 자리가 네모 띠 → 뺌. 숲 위가 수관 벽뿐 → 줄기 기둥 벽.
  설원 눈길 띠가 울타리처럼 보임 → 빼고 발자국만. 사막 길 꺾임 → 곧게. 피라미드가 언덕 위에 붙여 놓은 듯 → 밑동 모래 더미. 화산 작은 분화구 산이 잘려 사다리꼴 → 밑동·높이 인자. 화산 바닥 잔 재 덩이 얼룩 → 뺌.
  늪 바닥 밝은 풀+진흙 얼룩 → 그늘 풀·물가 진흙만, 웅덩이가 네모 → 화소 흔들림 큰 웅덩이, 안개 속 나무가 너무 하얘 → 안개 램프 대비 올림.
- 2회차: 숲 판석이 지평선 위(먼 바닥)에서 짙은 물처럼 보임 → 판석을 지평선 아래로만. 화산 왼쪽 용암 갈래가 계단 상자 → 곧은 갈래.
- `check-overlay.png`: 배틀러 자리 안 물체를 밖으로(평야 선돌, 설원 엄니·언 풀, 숲 고사리, 늪 석등·고사목, 화산 유황 분기공·용암 갈래·두개골).

# 광산 갱도 (mine-tunnels) — 계획

기준: 버들항 v6~v8 (16px 손 도트, 3/4, 빛 왼쪽 위). 던전 방 묶음 범위 안의 **48×36칸 한 장**. 생성 그림·트레이싱 없음. 색은 버들항 돌·나무 램프에서 따뜻한 쪽으로 옮긴 갱도 바위 + 결정 3색(청록·보라·호박).
렌더·배치·조각은 모두 `make_mine_tunnels.py`(+ `mt_base.py`·`mt_pieces.py`·`wavekit.py`)가 만든다.

## 용도
버려진 구리·철 광산. 입구 홀에서 시작해 레일 홀을 지나 수정 동굴(앵커 1), 저장고의 수직 갱(앵커 2), 광부 숙소(앵커 3)를 도는 JRPG 던전/거점 한 장. 레일은 입구 → 레일 홀 → 저장고로 이어져 길 안내가 된다.

## 구역 (칸 좌표 대략)
| 구역 | 자리 | 용도 |
|---|---|---|
| A 입구 홀 | 남서 (x3~19, y24~33) | 시작. 북벽에 갱도 입구, 등불 기둥 둘, 운반로 + 레일 시작, 광차·곡괭이·상자 |
| B 레일 홀 | 중앙 (x13~31, y11~21) | **갱목 지지대** 두 쌍, 레일 가로 구간, 광차, 광석 더미, 북벽 전체 갱목 덧댐 |
| C 수정 동굴 | 북동 (x33~47, y2~15) | **앵커 1**: 청록·보라 결정 군락, 젖은 바닥, 깊은 물, 사다리(위층), 레일 끝막이 |
| D 저장고 | 남동 (x28~46, y22~33) | **앵커 2**: 수직 갱(도르래+감개), 화약통·상자 줄, 계단(아래층), 호박 결정 |
| E 광부 숙소 | 북서 (x2~12, y8~19) | **앵커 3**: 갱목 널벽 숙소, 궤짝·통·곡괭이, 웅덩이 |
| 붕괴 갱도 | 남서 복도 (x22~24, y28~29) | 지름길이 무너져 막혔다(낙반 자갈 번짐 + 광부 유골) |
| 복도 | A↔B, B↔C, B↔D | 폭 2~3칸 |

## 동선
입구 (7,25) → 운반로·레일 → B 레일 홀 → 동쪽 복도 → C 수정 동굴 (사다리). B 에서 남쪽 레일 → D 저장고 (수직 갱·계단). A 에서 서쪽 → 숙소 E. 붕괴 갱도는 막다른 볼거리.

## 원칙
- 천장 밑 벽 앞면 2~3줄(걷는 칸 북쪽 어디나), ㅁ자 고립 방 금지(걷는 덩어리 1개), 빈 바닥은 소품으로 메우지 않고 덩이로.
- 키 큰 부드러운 물체(결정·등불·석순)는 아랫줄만 막힘, 위는 걷기+가림. 단단한 몸통(광차·상자·통·광석)은 몸통 줄만 막힘.
- 새 조각은 `parts/`·`partmeta.json`·`parts.md` (공용 시트에는 아직 굽지 않음).

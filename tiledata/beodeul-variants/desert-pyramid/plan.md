# 사막 필드 + 피라미드·고분 (desert-pyramid) — 84x56 야외 던전 입구

## 용도
마을(남쪽)에서 카라반 길을 따라 사막으로 나와, 오아시스에서 쉬고(우물·상인 천막·낙타 쉼터), 북쪽 계단식 피라미드의
어두운 입구로 들어가는 던전 입구 필드. 곁가지로 서쪽 고분 터(흙무덤·마스타바·묘비)와 동쪽 발굴터가 있다.
기존 `desert-oasis`(모래샘 마을)와 같은 모래·사암 램프 — 그 마을의 바깥 사막으로 이어 붙여도 같은 게임.

## 앵커(알아볼 것)
1. 계단식 사암 피라미드(앞면 줄눈·디딤·가운데 계단·어두운 입구·무너진 오른쪽 위)
2. 오아시스(대추야자 숲·돌우물·청록 못)
3. 상인 천막·낙타 쉼터
4. 반쯤 묻힌 석상·오벨리스크(광장 길목·동쪽 사막)
5. 모래 언덕 능선과 바람 잔물결(바닥 질감)
6. 고분 터(흙무덤 돌 입구·마스타바)

## 동선
남쪽 입구 (36,55) → 카라반 길(폭 2) → 오아시스 우물 곁 (33,37) → 시장 골목(39~50, y38) / 낙타 쉼터(y43) →
북동으로 광장 남쪽 끝 (44,28) → 포석 광장 → 피라미드 입구 (44,20). 광장 서쪽 길 → 고분 터 (15~32, y21~25). 광장 동쪽 길 → 발굴터 (57~66, y23~25).

## 걷기 규약
피라미드·마스타바·흙무덤 = 칸 전체 막힘(입구 칸만 걷기). 야자·선인장·오벨리스크·석상·기둥 = 밑동 줄만 막힘, 위는 걷기+가림.
천막: 상인 = 좌판 줄, 유목·발굴 = 아래 두 줄. 언덕 능선·깔개·마른 풀·잔돌·토기·머리뼈·회전초 = 걷는 장식. 못·절벽 = 막힘.

## QA 기록 (적대적 검수, 2026-10-08)
수치: BFS 남쪽 입구 → 표지 12곳 전부 도달(grid.json reach). 20x15 창 빈 바닥 최악 0.38(기준 0.40, 언덕 능선·암반·포석·길을 채움으로 셈, 오아시스 풀밭은 빈 바닥으로 셈).
비교 시트 `compare-ref.png`(2배, [버들항 성 석재 | 피라미드], [사막 오아시스 | 이 맵 오아시스·시장], [버들항 절벽 | 고분 터·절벽]) 3회 반복:
1. 1회차: 피라미드 마름돌이 6px 줄에 줄눈이 옅어 성 석재보다 흐릿함 → 성 마름돌처럼 줄눈을 1단 어둡게, 돌 크기 18x9·20x10, 돌마다 톤 차 키움.
   절벽이 세로 갈비 줄무늬라 나무 울타리처럼 보임 → 가로 지층이 주인공인 사암 절벽으로 다시(두께 다른 층, 층 사이 오목 선은 토막, 바위 결 얼룩).
   길이 얼룩덜룩(저주파 잡음) → 고른 다진 모래 + 낱 알갱이, 가장자리는 버들항 흙길처럼 눌린 띠(2).
2. 2회차: 절벽 층이 판자처럼 고르게 보임 → 층 경계를 잡음으로 흔들고 끊음. 같은 바위가 나란히 둘 → 같은 조각 2칸 안 금지·좌우 뒤집기 섞음.
3. 3회차(최종): 석재 결·명암 단 수·윤곽은 같은 게임으로 읽힘. 오아시스 줄은 사막 오아시스와 같은 야자·모래 램프.
원 해상도 사분면·앵커 2배 크롭에서 찾아 고친 것:
- 못·풀밭이 칸 계단 모양 → 화소 단위 모양(타원+잡음)으로 만들고 칸 막힘은 덮임 비율로.
- 암반 덩이: 처음엔 자갈밭처럼 보였고(판 금이 촘촘), 오토타일 가장자리가 칸마다 같은 톱니 → 판 금을 드물게, 지도에선 같은 재질·가장자리 규칙을 화소 모양으로(오토타일 시트는 조수용으로 따로 둠). 위에 날린 모래 점은 얼룩이 돼 줄임.
- 고원 윗면이 암반/모래 위장무늬 얼룩 → 모래로 덮고 절벽 끝 3~5px 만 암반.
- 빈 바닥 채우기가 선인장·작은 바위를 전역에 뿌려 동전 무늬 → 낱 물체 뿌리기를 없애고 언덕 능선(같은 그리기, 마루선만 무작위·겹침 금지)과 암반 덩이(4개 한도, 서로 3칸 떨어짐)로만 채움.
- 언덕 능선이 같은 도장 반복·뾰족한 톱날 → 활꼴 마루선을 매번 새로 그림.
- 고분 터 길이 ㅁ자로 돌아 상자처럼 보임 → 광장에서 흙무덤 문 앞까지 한 줄로 휘고, 마스타바 갈래만 짧게.
- 광장이 평판 → 가운데 참배 길(큰 판석+연석), 오벨리스크(길목 왼쪽, 오른쪽은 기운 것), 수호상 한 쌍 엇갈림, 모래 더미를 남·동 가장자리에 몰아 묻음.
- 바위 기둥이 모래시계·구슬 쌓기처럼 보임 → 붉은 기둥 + 밝은 덮개돌(후두).
- 흙무덤이 접시처럼 납작 → 높은 돔 + 꼭대기 둘레돌.
- 열린 오벨리스크가 피라미드 칸과 겹쳐 안 놓였던 것, 사당 터가 채우기에 막혀 못 가던 것 → 자리 옮김·진입 칸 비움.
남은 약점(솔직히):
- 언덕 능선이 빈 사막 전체에 고르게 깔려 조금 무늬처럼 보인다(빈 바닥 40% 규칙을 맞추려고). 맵을 더 줄이는 쪽이 나을 수도 있다.
- 피라미드 디딤(윗면)이 앞면보다 확실히 밝지만 기준 성탑만큼 그림자 대비가 크지 않다. 오른쪽 위 무너짐은 심석이 어두운 삼각 띠로 보여 무너진 돌무더기 느낌이 약하다.
- 카라반 길·고분 갈래는 칸 단위 오토타일이라 꺾이는 곳이 계단처럼 각지다.
- 작은 소품(마른 덤불·밧줄 사리·짐승 수호상)은 1칸 안에서 알아보기 어렵다. 앉은 석상의 팔·몸은 단순한 기둥처럼 보인다.
- 발굴 구덩이는 판 구덩이보다 낮은 상자처럼 읽힐 때가 있다.

# 탑 내부·계단 던전 (tower-interior) — 100×26

## 용도
한 탑의 세 층을 한 맵에 나란히 놓은 실내 던전 판. 플레이어는 1층 남쪽 출입구로 들어와 카펫을 따라 홀 북쪽의 직선 오름 계단을 오르고,
중간층 계단참에 도착해 서재·기계실을 지나 기계실 북서 모서리의 나선 계단으로 꼭대기 방에 오른다. 꼭대기 방은 장미창 아래 제단과 수정구가
있는 의식실이고, 남쪽 아치 너머 발코니에서 하늘이 보인다. 1층 동쪽에는 함정 회랑과 열쇠로 여는 잠긴 문 너머 보물실이 곁길로 붙는다.

층은 같은 탑의 다른 높이라 맵 위에서는 x 0~31(1층) · x 34~65(중간층) · x 68~99(꼭대기)에 나란히 놓고, 각 층 안 지역 좌표가 같은
자리에 계단 한 쌍을 둔다(직선 오름 1층 (14~17, 6~9) ↔ 직선 내림 중간층 같은 칸, 나선 오름 중간층 (22~24, 5~8) ↔ 나선 내림 꼭대기 같은 칸).

## 앵커 (알아볼 수 있는 구조물)
① 직선 석조 계단 쌍(오름 = 난간벽 사이 8단 + 벽 앞면 계단 아치 / 내림 = 바닥에 뚫린 계단 구멍), 나선 계단 쌍(오름 = 둥근 받침단 위 기둥을 감아 오르는 단 / 내림 = 어둠으로 감아 내려가는 둥근 구멍)
② 창빛 홀(높은 아치 창 둘, 바닥에 창살 십자 빛 무늬가 카펫 쪽으로 모인다)
③ 서재(벽 책장·책상·독서대·촛대) + 기계실(벽 톱니바퀴·시계 톱니 기계·바닥 톱니판)
④ 꼭대기 방(장미창·제단·수정구 받침·발코니 난간과 하늘)
⑤ 함정 회랑(구덩이·가시·압력판)과 잠긴 문

## 동선
1층 입구(15,21) → 카펫 → 오름 계단 위(15,6) ⇒ 중간층 내림 계단(15,9) → 서쪽 통로 → 서재 / 동쪽 통로 → 기계실 → 나선 계단 입구(23,8)
⇒ 꼭대기 나선 계단 입구(23,8) → 제단 앞 → 발코니 아치 → 발코니. 서재 남쪽 ↔ 남쪽 회랑 ↔ 기계실 남쪽으로 고리.
1층 곁길: 홀 서쪽 → 경비실, 홀 동쪽 → 함정 회랑 → 잠긴 문(열쇠 이벤트) → 보물실. ㅁ자 고립 방 없음(모든 방이 통로·계단으로 이어짐).
방 북쪽 벽 앞면 3줄(통로·발코니 바깥벽 2줄), 계단은 모두 바닥 위에 시트 모양 그대로.

버들항 성 지붕 슬레이트 보라(`castle6.SL`), 금은 `castle6.GOLD`, 깃발은 버들항 원본(`roman.banner_hanging`, 다시 내보내지 않음).

## QA 기록 (2026-10-08)
- 1차 렌더: 방이 너무 크고 비었다(20×15 창 빈 바닥 최대 74%), 나선 계단이 「선풍기·접시」로 읽힘, 창빛이 안 보임, 홀 상감이 보라 점 격자.
  → 방을 줄이고(홀 14×16 → 10×11, 서재·기계실 7×13, 꼭대기 방 19×11 → 19×9, 현관 6칸 폭 → 4칸, 맵 28줄 → 26줄) 목적 있는 소품만 더함.
- 나선 계단 세 번 다시 그림: 부채꼴 → 높이만큼 위로 밀어 쌓은 3/4 단(고리가 단 위에 그려져 끊김) → 그리기 순서(뒤 단 → 기둥 → 앞 단) 정리 +
  둥근 돌 받침단 + 단 밑 쌓은 돌 몸통 + 위층으로 뚫린 어둠. 내림은 구멍 속 어둠 위에 단을 그리고 고리가 앞을 가린다.
- 꼭대기 층: 하늘을 아래 띠에만 두었더니 「붙여 넣은 상자」 같아서, 방·발코니를 두른 벽 윗면 띠 1칸 바깥을 모두 하늘로(탑 꼭대기). 하늘은 96px 주기
  줄무늬가 보여 세 단 그라데이션 + 둥근 덩이 구름(윗가 흰빛·아랫가 그늘)으로 다시 칠함. 발코니 턱 까치발이 가시처럼 보여 둥근 돌로.
- 창빛: 벽·천장 위로 번지고 석상 뒤에 숨어 있었다 → 바닥 칸으로만 자르고, 오른쪽 창빛은 좌우 뒤집어 두 빛이 카펫 쪽으로 모이게, 석상 아래 열린 줄에 떨어지게 내림.
- 함정 구덩이가 「별 박힌 검은 상자」였다 → 북쪽 가장자리에 구덩이 안벽 앞면(아래로 어두워짐), 바닥에 희미한 가시 끝.
- 쇠사슬 도르래가 침대처럼 읽혀 A자 쇠 받침 + 가로 나무 북 + 감긴 사슬 + 손잡이 바퀴로 다시 그림.
- 판석마다 같은 사선 금이 있어 반복 무늬로 보였다 → 열 장에 한 장꼴로 시작점·기울기·길이가 다른 금. 판석 톤을 버들항 포장 쪽으로 조금 따뜻하게.
- 고립 칸: 홀·계단참 모서리가 석상·촛대·계단 난간에 갇혔다 → 촛대·항아리 자리 이동, 계단참 석상 대신 항아리. 서재 독서대 뒤 2칸 → 촛대 이동.
- 꼭대기 방 남쪽 모서리를 깎았더니 천장 칸이 검은 구멍으로 보여 남쪽 모서리 깎기를 뺌.
- BFS(계단 고리 포함): 입구(15,21) → 이름 붙은 지점 16곳 전부 도달(발코니까지 47걸음), 걷는 칸 559 전부 도달, 잠긴 문을 닫으면 보물실은 도달 불가(의도).
- 빈 바닥(층마다 그 층 32칸 안 20×15 창, 1칸 간격 전부): 1층 최대 0.377 · 중간층 0.400 · 꼭대기 0.367, 0.40 초과 창 0개(공용 dcheck 2칸 간격도 최대 0.400).
  카펫·창빛은 빈 바닥으로 센다(소품으로 치지 않음).
- 비교 시트 `compare-ref.png`(2회 반복): [버들항 성 석재 | 1층 홀 | 함정 회랑], [마왕성 알현실(웨이브 1 기준) | 서재·내림 계단 | 기계실·나선 계단],

## 아직 다른 점 · 약한 곳 (솔직하게)
- 벽 앞면은 버들항 성 바깥벽보다 두 단 어둡다(실내 규약: 벽이 바닥보다 어둡게). 그래서 버들항 바깥 성벽의 흰 하이라이트만큼 밝지 않다.
- 벽 윗면 띠 안쪽에 공용 천장 함수의 2px 보라 윤곽선이 남아 꼭대기 층 둘레가 「두 겹 선」처럼 보인다.
- 기사 석상·갑옷은 작아(2×3, 1×2) 2배에서도 세부가 적다. 창빛 무늬는 반투명이라 1배에서 은은하다.
- 나선 오름 계단은 기계실 북쪽 벽 앞면 위로 윗부분이 겹친다(키 큰 물체처럼). 나선 내림 계단은 1배에서 「어두운 우물」로 먼저 읽힌다.
- 오토타일 시트의 카펫 속 금 점은 16px 마다 같은 자리라 넓게 깔면 격자로 보인다. 돌 난간의 가로 난간동자는 2배에서 촘촘한 사슬처럼 보인다.
- 층 셋을 한 맵에 나란히 놓았으므로 실제 게임에서는 계단 칸에 층 이동 이벤트를 붙여야 한다(맵 위에서는 걸어서 이어지지 않는다).

# 성 지하 감옥·카타콤 (castle-catacombs) — 계획

- 크기 56×42 (16px 칸, 1칸 = 1m). 3/4 시점, 빛은 왼쪽 위.
- 목적: 버들항 성 밑 감옥에서 시작해 고문실을 지나 카타콤 안쪽 뼈의 방 제단까지 내려가는 던전 한 판. 위쪽(성)은 석재 앞면(castle), 아래쪽(카타콤)은 벽감 앞면(cata).
- 규칙: 천장 밑에는 반드시 앞면 2~3칸(방 3, 복도 2). 천장은 어두운 3단 명암. 방은 복도로만 이어지고 고립 방 없음. 20×15 화면당 빈 바닥 40% 이하.

## 동선 (2칸 폭 복도)
입구 E → (23~24,30~34) → CB 홀 → (22~23,14~19) → NG → (31~35,9~10) → BC 최종.
지름길·순환: E → (31~32,30~34) → TR → (45~46,16~19) → BC. E → (36~37,37~38) → OS → (44~45,30~33) → TR. E → (16~19,37~38) → GR.
입구에서 최종 지점까지 grid.json BFS 로 걷힌다. 칸막이 벽은 벽 위 얇은 조각(앞면 세 칸)으로 남기고 감방은 홀 쪽으로 열려 있다.

## 새 조각 (버들항 결로 손 도트)
성 석재·카타콤 벽감·감옥 바닥·뼈 바닥은 공용 렌더러에 이미 있는 것을 쓰고, 새로 찍은 소품은 parts/ 에 모은다.

## QA 기록

- 원해상도 사분면 4장 + 2배 렌더 확인. 경로: 입구(27,38) → 감방동 홀 → 벽감 복도 → 벽감 회랑 → 뼈의 방 복도 → 뼈의 방 제단(45,9). BFS 47칸, 연결 성분 1개(1150칸), 이름 붙은 지점 12곳 전부 도달.
- 빈 바닥: 20×15 창 최대 0.400, 평균 0.347, 0.40 초과 창 0개. 줄 세우기 대신 덩이 채움(147)만 사용.
- 천장 밑 벽면: 방마다 2~3칸 벽면 확인. 칸막이 벽은 남쪽 끝에만 벽면 3칸.
- 고립 방 없음(ㅁ자 방 없음). 감방 3칸은 홀로 열림, 고문실·납골당은 고리 통로(입구-고문실-납골당)로 이중 연결.
- 정리: 스크립트의 죽은 코드(`if False else None`) 6줄 제거, 재실행 결과 이미지 동일(md5 일치).
- 남은 어색한 곳: 벽감 회랑의 벽감 줄과 기둥 줄이 규칙적, 뼈의 방 바닥이 자잘하게 어수선하고 해골 무더기 타원이 도드라짐, 감방 바닥이 누렇고, 고문실이 매우 어두움.

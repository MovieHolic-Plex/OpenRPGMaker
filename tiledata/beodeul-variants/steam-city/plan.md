# 증기 도시 거리 (steam-city) — 64x48 JRPG 마을 구역 (장르 steampunk: 증기·황동·톱니)

## 용도
증기 기관으로 돌아가는 벽돌 도시의 한 구역을 통째로 까는 장소 팩. 그을린 붉은 벽돌 줄집·가게(벽을 타는 놋쇠·구리 관, 걸개 그림 간판),
가운데 **시계탑 광장**(큰 놋쇠 시계판의 시계탑, 증기 분수, 톱니 기념비, 쌍 가스등, 가로수), 서쪽 **보일러 집 공장 마당**(둥근 벽돌 굴뚝,
증기 저장 탱크, 길 위를 건너는 관 다리, 증기 기관), 동쪽 **석탄 마당**(석탄 깔때기, 석탄 창고, 급수탑, 석탄 마차·더미)으로 짜여 있다.
바닥 표본(젖은 검은 자갈 차도·벽돌 보도·광장 판석·철판 마당·석탄 재 마당·연석 본보기)과 땅 덩이 오토타일(기름 번짐·증기 고인 물·
석탄 가루·무쇠 난간)이 들어 있어 이 팩 하나로 길·보도·마당·웅덩이까지 닫힌다. 증기 도시의 마을, 공장가, 산업 혁명풍 수도, 기차역 앞 거리,
비행선 부두로 가는 도시 구역에 쓴다. 글자·사람·상표 없음.

## 장르 규격
`tiledata/beodeul-kits/genres/steampunk.md` (같은 장르 clockwork-tower·airship-dock 과 공유). 놋쇠 `BRASS`(관 이음·톱니·계기 테·리벳),
구리 = `RUST` 톤 3~6 + 녹청 줄 `cyan` 2~3, 검은 무쇠 = `STEEL` 낮은 톤(가스등·난간·탱크·철판), 호박빛 `amber`(가스등·창), 증기 = 흰 회색 손 도트 덩이.
벽돌 = 규격 1 확정값 `BRK`(그을린 벽돌 7단) 8×4 줄쌓기·줄눈 `GST` — clockwork-tower 와 같은 램프·같은 크기. 기름 번짐 = 규격 4 의 `OIL` + 탁한 `SHEEN` 짧은 활.
구리 지붕 = 세로 이음 구리판(점토 기와 비늘 결 아님), 녹청은 이음 줄을 따라 흘러내린 `cyan` 줄만.

## 앵커 (4)
1. **시계탑** 5x14칸 — 벽돌 받침·몸통(모서리 돌), 돌 시계 단의 놋쇠 시계판(숫자 없음), 종 다락, 녹청 줄 구리 뾰족 지붕. 물러난 단마다 3/4 윗면.
2. **보일러 집 + 굴뚝 + 증기 탱크** — 둥근 벽돌 굴뚝 둘과 증기, 루버 환기 탑, 누운 구리 보일러 통, 관 다리.
3. **석탄 마당** — 다리 위 석탄 깔때기 밑에 석탄 마차, 열린 석탄 창고, 급수탑.
4. **벽돌 줄집 거리** — 벽을 타는 관이 처마 밑 벽으로 들어가고, 가스등이 젖은 자갈 길을 비춘다.

## 동선
남쪽 입구 (31,47) → 입구 골목 → 남쪽 큰 길 → 광장 남쪽 → 분수 둘레 → 시계탑 문 (31,24).
곁: 남쪽 큰 길 → 서쪽 길(관 다리 밑) → 공장 마당 → 보일러 집 문 (4·5, 22) / 동쪽 길 → 석탄 마당 입구(46, y20~24) → 깔때기 밑.
북쪽 큰 길 → 북쪽 줄집 문 17. 남쪽 줄집 문 15는 남쪽 끝 보도에서.

## 걷기·가림
- 2층 집·가게: 앞면 아래 4줄 막힘, 3층 공동주택 6줄, 문 칸 걷기, 지붕·굴뚝 걷기+가림. 시계탑 받침 3줄, 보일러 집 4줄(문 2칸), 석탄 창고 2줄, 증기 탱크 2줄.
- 석탄 깔때기: 다리 밑동 두 칸만 막힘(깔때기 밑을 지난다). 관 다리: 양 끝 기둥 밑동만 막힘(관 아래 지나감).
- 가스등·거리 시계·광고 기둥·가로수·급수탑·우편 기둥: 밑동 칸만 막힘, 위 칸 걷기+가림. 증기 배출구: 아래 칸 막힘(뜨겁다), 김 칸 걷기+가림.
- 오토타일: 기름 번짐·석탄 가루 = 걷기, 증기 고인 물 = 막힘(물), 무쇠 난간 = 막힘.

## 바닥·재질 (칠하는 순서 = 맨 바탕 표본 → 땅 덩이 오토타일 → 건물·소품)
- 젖은 검은 자갈 = 버들항 칩셋 둥근 돌(208,160) 결 → soot 램프(선형), 젖은 돌 윗면 빛 점. 벽돌 보도 = 바구니 짜임(바닥으로 읽히게, 벽 줄쌓기와 다름).
- 광장 판석 = 제국 도시 판석 규칙 한 단 어둡게. 철판 마당 = 기계 재질 규약 바닥판(검은 무쇠 톤), 배수 창살 판 드물게. 석탄 재 마당 = 칩셋 흙 결 → soot.
- 보도·광장은 차도보다 한 단 높다 → 가장자리 2px 연석 + 남쪽 앞모 + 차도 쪽 그늘(ground-curb-edge 가 본보기).

## QA 기록 (2026-10-08)
1. 집 시험판: 구리 지붕이 진흙 기와처럼 밝음 → 톤 +1 올림 제거, 녹청 점 흩뿌림(잡음) → 판 이음에서 흘러내린 세로 줄로. 증기 탱크가 은색 → 검은 무쇠로 두 단 내림.
2. 바닥: 자갈이 자갈밭 잡음 → 대비 좁히고 빛 점 성글게, 칸마다 어두운 얼룩 제거. 벽돌 보도가 벽처럼 읽힘 → 바구니 짜임. 재 마당이 새까맘 → 밝힘.
3. 오토타일: 석탄 덩이가 5x4 격자로 줄지어 비늘 무늬 → 칸 안 고정 자리 넷. 기름 속 무지개 점이 격자 → 제거. 증기 물 김 줄이 줄무늬 → 8줄 걸러.
4. 지도 1회차: 집 터 아래 벽돌이 지붕 위로 비침 → 지붕 뒤는 자갈. 광장이 너무 넓어 비어 보임 → 22→18칸, 가로수·벤치·기념비 재배치. 골목 양쪽 보도가 기둥처럼 보임 → 제거.
   가스 쌍등 빛이 네모로 보임(glow 인자 순서 오류) → 고침. 관 다리 왼쪽 기둥이 탱크에 가림 → 두 줄 위로. 같은 이름 집이 남북 줄에서 같은 x 라 문 표시가 덮여 가스등이 문 앞을 막음 → 키에 y 포함.
5. 비교 시트 2회차(compare-ref.png, 버들항 city6_base 집 줄 옆): 버들항 가게는 그림 간판·화분으로 표정이 있는데 우리 줄집은 관만 반복 → 걸개 그림 간판(찻잔·톱니·열쇠·장화, 글자 없음)·창 화분 추가.
6. 전투 배경: 시계탑 시계판이 줄집 뒤에 가려 종 다락만 보임 → 오른쪽 끝 빈 곳으로 옮겨 꼭대기 = 화면 위 끝, 받침은 지평선 뒤. 96색·640x360·불투명 확인, 가짜 전투원 자리(x120~560, y190~330)에 키 큰 물체 없음.

7. **적대 검수(`tiledata/beodeul-kits/qa/steam-city.md`, 조건부) 반영:** ① 장르 규격을 벽돌 `BRK` 8×4·기름 `OIL`/`SHEEN` 으로 확정(`genres/steampunk.md`, clockwork-tower 와 같은 값), 기름 번짐을 반투명 막 + 탁한 무지개 활로 다시 그림(1px 점선 없앰).
   ② 줄집에 물러섬·사이 골목·폭 섞기, 가스등 간격을 4~12칸으로 흔듦, 광장 모서리 깎기·남쪽 판석 골목, 공장·석탄 마당 경계를 줄마다 들쭉날쭉(난간이 따라 꺾임), 철판 32x16 엇갈림, 광장 판석 폭 섞어 엇갈림.
   ③ 석탄 마당 바닥을 따뜻한 회색 재(콘크리트 램프)로 밝혀 석탄 가루·더미가 읽히게. ④ 구리 지붕을 세로 이음 구리판으로(집·시계탑·판매대, 판매대 녹청 점 제거).
   ⑤ 입구 골목의 증기 물·우편 기둥 몰림을 치우고 골목을 판석으로 이어 가운데 4칸을 비움, 북쪽 뒤뜰을 재 바닥으로(지붕 뒤 자갈 띠 없앰) → 빈 바닥 0.38.
   의존 파일 고정: 제국 도시 ec_fix.py 가 바뀌어 `sc_edge.py` 에 가장자리 도구 사본을 둔다.
8. 판정표 WEAK 항목: 젖은 자갈 한 단 밝게·빛 점 성글게(TV 잡음 줄임), 벽돌 보도 한 단 밝게(낮은 담처럼 안 보이게), 석탄 산을 3x3 덩이 낱알(윗왼 빛 면)로(검은 돔 → 무더기),

   전투 배경 아래쪽을 보도 → 차도 3줄 → 광장 판석으로 나눠 단조로움을 줄였다(가운데 배틀러 자리는 판석뿐).

## 아직 약한 곳
- 석탄 램프가 원래 어두워 석탄 산은 여전히 어두운 덩이다(재 바닥 위에서는 읽힌다). 1x1 손수레는 16px 라 작다.
- 줄집 몸채 문법(벽돌 + 아치 창 + 관)은 하나다. 물러섬·골목·지붕으로 섞었지만 1층 기둥 상점가·철골 유리 지붕 시장 같은 다른 몸채가 없다.
- 젖은 자갈 차도가 넓게 깔리면 단조롭다(바퀴 자국·전차 선로 표본 없음).
- 사람·말이 없어 석탄 마차는 끌채만 있다(규칙상 캐릭터 미작성).

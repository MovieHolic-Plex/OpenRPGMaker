# 화산 동굴 (volcano-cave) — 계획

기준: 버들항 v6~v8 (16px 손 도트, 3/4, 빛 왼쪽 위, 1칸=16px=1m). 던전 방 묶음 범위(40×30~64×48) 안의 **56×44칸 한 장**.
생성 그림 없음 · 트레이싱 없음. 색은 버들항 칩셋 램프에서만 고른다. 용암은 **빨강(RD)·짚(SR) 램프만** 쓴다.

## 용도
식은 화산 밑을 걷는 한 판짜리 던전. 입구 → 옛 대장간 폐허(볼거리 1) → 용암 폭포 동굴(볼거리 2) → 바위다리로 강 건너 → 재 벌판·흑요석 제단(끝) → 다시 입구로 도는 고리.
초보 모험가가 「열기 → 폐허 → 폭포 → 다리 → 제단」 순서로 읽히게 한다.

## 구역 (칸 좌표 대략)
| 구역 | 자리 | 용도 |
|---|---|---|
| A 입구 동굴 | 남서 (x3~21, y31~42) | 시작. 남쪽 가장자리가 출입구. 횃불 2, 표지 돌무더기 |
| AB 통로 | x8~12, y22~31 | 세로 좁은 길. 오른쪽에 용암 호수 물가 |
| B 대장간 폐허 | 북서 (x4~24, y8~21) | **앵커 1**: 북벽에 붙은 큰 화덕, 모루·풀무·석탄·무너진 기둥 |
| BC 통로 | x23~29, y12~16 | B→C |
| C 폭포 동굴 | 북중~북동 (x24~47, y9~21) | **앵커 2**: 북벽에서 쏟아지는 용암 폭포와 웅덩이, 웅덩이에서 강이 남쪽으로 |
| 용암 강 | 웅덩이 → 동쪽 가장자리 → 서쪽으로 꺾어 호수(x15~21,y26~31) | 동선을 가르는 장애물. 두 번째 작은 폭포가 호수로 |
| 바위다리 | x32~35, y23~29 (세로) | C ↔ D 를 잇는 돌판 다리. 난간 낮은 돌 |
| D 재 벌판 | 남동 (x23~53, y28~42) | 재 바닥, 김 뿜는 틈, 흑요석 뾰족돌, **앵커 3**: 흑요석 제단 |

## 동선
입구(A 남쪽) → 통로 → B(대장간) → 통로 → C(폭포) → 바위다리 → D(제단) → 서쪽 넓은 길(x20~26,y33~40)로 A 로 돌아옴. 고리라서 막다른 곳 없음(호수 물가 자락은 볼거리).

## 규칙 메모
- 천장 아래는 반드시 **벽면 2칸**(열린 칸 북쪽 2칸). 벽면이 1칸밖에 못 나오는 얇은 바위는 자동으로 녹여 이어 붙인다.
- 빈 바닥은 소품으로 메우지 않는다. 한 화면 20×15 창 안 빈 바닥 ≤40% 를 재서 넘으면 지도를 줄이거나 구조(바위 덩이·용암)를 쓴다.
- 나무 없음(화산 속). 소품은 자연 덩이로: 석순·재 무더기·뼈는 3~5개씩 무리.
- 용암 애니메이션: 4프레임, `parts/lava-strip.png`(가로 4칸) 와 폭포 `parts/lava-fall-strip.png`. 렌더는 0번 프레임.
- 열기: 용암 곁 바닥/벽면에 붉은 디더 빛, 위로 불티, 배경에만 1px 아지랑이.

## QA 기록 (적대적 검수)
- 빈칸: 20x15 창을 stride 3x4 로 훑어 최악 38.7% (24,27), 40% 초과 창 0. 구조 바닥(대장간 벽돌·흑요석·용암·솥)과 소품 상자를 「채워진 칸」으로 센다.
- 통행 BFS(입구 11,43 기준): 대장간·폭포 웅덩이·다리 북/남·제단·호숫가·B-C 통로·남쪽 길·동쪽 둑 9곳 전부 도달. 걸음칸 699.
- 첫 렌더에서 고친 것: 빈 창 76.7% → 바위 섬 22개로 큰 열린 공간을 자연 덩이로 자름 / 동쪽 둑이 잘린 주머니였음 → 연결 검사로 못 가는 주머니를 바위로 채움 / 자동 채움이 남쪽 길을 막아 `south_road` 표식이 고립 주머니(23,37)에 떨어져 False → 주 통로(16,37)로 옮김(고립 주머니는 소품 사이 한 칸짜리라 실제 길이 아님) / 섬 안에 소품이 박히던 것 → 발판 검사로 건너뜀.
- 천장 밑 벽면: 모든 바위 아래 2칸 앞면. ㅁ자 고립 방 없음(연결 검사 통과 영역만 열림).
- 스스로 보는 어색한 곳: ① 다리가 회색 판석 한 장으로 평평하다(난간 기둥·그림자 없음). ② 폭포 웅덩이가 납작한 주황 사각으로 보인다. ③ 바위 섬이 약간 네모난 갈색 판. ④ 왼쪽 아래 A 구역 소품이 다소 빽빽하고 종유석 무리가 비슷하게 반복. ⑤ 위쪽 8줄이 통째 바위 여백. ⑥ 일부 소품 사이에 한 칸짜리 고립 걸음 주머니가 남는다.

## 3/4 재작업 QA (2026-10-01)
- 검사기 전 13건 → 후 0건 (`view34-audit.md`). 다리를 판+난간+앞 벽돌벽(16px)으로, 증기구멍은 타원 림+앞 입술로, 뿔·석순은 평평한 끝을 줘 다시 그림.

# 시간의 틈·허공 쉼터 (time-rift) — 40x32 판타지 장소(필드형 작은 지도)

## 용도
세계 여러 곳의 포털이 모이는 「시간의 틈」. 어두운 허공(별 점·성운) 속에 떠 있는 둥근 돌 단이 한가운데 있고, 동서남북 갈래 끝마다
다른 색 포털이 서 있다. 일행은 남쪽 청록 포털로 도착해 곧은 돌 길로 중앙 돌 단에 오르고, 가운데 「시간의 받침」(빛 구슬)을 조사한 뒤
갈래 길 셋 중 하나로 다음 장소(파랑=북·보라=서·금빛=동)로 넘어간다. 남동 작은 섬은 벤치와 가로등이 있는 허공의 쉼터(저장·회복 자리),
남서 작은 섬은 무너진 아치가 남은 곁길(보물·이벤트 자리).

## 앵커 (알아볼 수 있는 구조물)
① 중앙 돌 단 + 시간의 받침(윗면 추상 원형 무늬, 앞면 매끈한 띠, 바위 뿌리) ② 포털 넷(기둥 한 쌍 + 빛 소용돌이, 갈래마다 색이 다르다)
③ 떠 있는 부서진 돌기둥·아치 조각들(돌 단 가장자리의 부러진 기둥, 남서 무너진 아치 문, 허공의 기둥 토막·아치 조각) ④ 허공 속 가느다란 돌 길과 별빛 다리·징검돌
⑤ 허공의 쉼터(벤치·가로등·빛꽃 화분) + 멈춘 시계 고리(시간의 틈 표지)

## 동선
도착 (20,28) → 남쪽 길 → 돌 단 → 시간의 받침 앞 (20,14).
돌 단 → 북쪽 길 → 별빛 다리 → 파랑 포털 (20,4) / 돌 단 서쪽 → 별빛 다리 → 보라 포털 (4,12) / 돌 단 동쪽 → 굽이진 돌 길 → 금빛 포털 (35,8).
돌 단 남동 → 징검돌 → 쉼터 벤치 앞 (31,22). 도착 단 서쪽 → 징검돌 → 폐허 섬 아치 밑 (9,22).

## 그리는 법 (버들항 재사용)
- 돌 윗면: 버들항 광장 판석 `roman.tex_flag`(돌 램프 ST) 그대로, 허공 빛에 7% 식힘. 중앙 단은 같은 판석 규칙(돌마다 톤·왼위 밝은 모서리·점·잔금·닳은 얼룩)을 동심 고리로 짰다.
- 앞면·뿌리: 버들항 절벽 `terrain.render` 의 칩셋 바위 타일 밝기 순위 + 갈빗대 결(왼쪽 밝고 오른쪽 그늘)을 돌 램프로. 뿌리는 덩이 결 + 아래로 허공 빛에 식는다. 섬이 클수록 길고 끝은 종유석.
- 기둥: 버들항 `roman.column` 짜임(기둥머리·홈 두 줄·받침)을 고대 숲 옛 기둥처럼 네모 받침 + 8px 기둥으로. 소품은 `px2` 볼륨 페인터 + `pz.fin` 윤곽.
- 새 재료 7단: 허공 남색·성운 보라/청록·발광 파랑/보라/금/청록·별빛(`tr_base.NEW`). 성운은 탑 꼭대기 층 구름처럼 둥근 덩이 + 왼위 밝은 테 + 바이어 디더 가장자리.

## 규칙 확인
- 허공 칸 막힘, 돌 윗면(칸 3/4 이상)·별빛 다리·징검돌 걷기. 섬 남쪽 앞면·뿌리 칸 막힘.
- 기둥·가로등·수정·다리 기둥·포털 기둥: 아랫줄만 막힘, 위 칸 걷기+가림. 포털은 아랫줄 양 끝(기둥)만 막히고 가운데 두 칸이 이동 이벤트 칸.
  벤치·화분·돌무더기·쓰러진 토막: 몸통 줄 막힘. 시간의 받침: 아랫줄 두 칸 막힘.
- 빈 바닥(걷는 칸 중 장식·물체·빛 번짐 없는 칸, 20x15 창): 최악 0.357 (15,7), 평균 0.252.
- BFS: 도착 (20,28)에서 걷는 칸 237 전부, 이름 붙은 9곳 전부. 물체 사이 갇힌 칸 1개(13,21)는 막힘으로 돌렸다.

## QA 기록
1. 허공 첫 렌더: 성운이 전 화면을 덮고 짙은 초록 반점(성운 안개가 덩이 밖 전체에 번짐 — 덩이 마당 초깃값 0 버그) → 초깃값 -1, 성운 줄 수·밝기 단을 줄임(최대 4단).
   성운이 구슬 꿰듯 따로 노는 덩이 → 줄마다 덩이를 촘촘히(9px 간격) + 작은 곁 덩이. 표본(주기 48)의 큰 십자 별이 격자로 반복돼 보여 표본에서는 큰 별을 뺐다.
2. 돌 단 뿌리가 빗살(1px 가시) → 7px 덩이 잡음 + 드문 종유석으로. 초록빛 도는 칩셋 돌 어두운 단 → 뿌리는 깊을수록 허공 남색에 식힘. 뿌리 길이가 줄 반폭 기준이라 타원 바닥에서 짧았다 → 둥근 단은 너비 기준(사인 꼴).
3. 돌 단 앞면 톤 경계가 세로 줄눈처럼 보였다(「앞면 줄눈 없음」 위반) → 원통 명암을 바이어 디더로 이어 칠함. 대리석 띠가 너무 노래 케이크 같아서 대리석과 돌 램프 사이 흰 회색으로.
4. 길·포털 단이 서로 다른 섬으로 그려져 이음 자리에 테두리 선이 겹침 → 같은 높이 돌은 한 섬 + 구역(재질·뿌리 길이만 다름)으로 그려 이음새 없앰. 재질이 바뀌는 자리엔 경계석 줄. (이때 길이 돌 단 무늬로 칠해지는 구역 번호 버그도 고침.)
5. 빛 번짐 오토타일이 2x2 네모 상자로 보임 → 성긴 점무늬 + 가장자리 7px 에 걸쳐 성기게, 포털 앞 1x2 로만.
6. 동쪽 길이 직각 복도 → 한 칸 폭으로 한두 칸씩 굽는 돌 길. 북쪽 길은 가운데를 끊고 한 칸 별빛 다리로 이었다(2칸 폭 다리는 십자 기둥처럼 보여 뺐다).
7. 징검돌이 버섯·잔처럼 보임(밝은 테 + 좁은 뿌리) → 크기·자리 흔들기, 바위 결 윗면, 바위는 두께 띠 빛을 덜, 뿌리 짧게.
8. 남동 쉼터 섬이 넓고 비어 보임 → 섬을 줄이고 빛꽃 화분·가로등 발치 빛 번짐. 남서 허공이 텅 비어 → 곁길 폐허 섬(무너진 아치·기둥·돌무더기)을 징검돌로 잇는 목적 있는 자리로.
9. 시간의 받침이 돌 단에 비해 너무 작음 → 2x3 두 단 받침 + 큰 구슬 + 엇갈린 놋쇠 고리. 무너진 아치가 고리 모양 갈고리로 읽힘 → 기둥 높이를 낮추고 아치를 기둥머리에서 솟게, 이맛돌까지 남김.
10. 비교 시트 `compare-ref.png`(2배: 버들항 성 앞뜰 | 중앙 돌 단 / 탑 꼭대기 방 | 북쪽 포털 단 / 고대 숲 옛 유적 | 폐허 섬 / 화산 지대 현무암 절벽 | 돌 단 뿌리):
    1회차 돌 단 고리 판석이 너무 크고 매끈해 벡터 그림처럼 보임, 빛 상감 고리가 굵고 채도 높음 → 고리를 다섯 줄로 쪼개 돌 수를 늘리고(12~42), 점·닳은 얼룩·드문 금, 상감은 홈 안의 가는 빛 줄로.

## 남은 차이(솔직하게)
- 장소 전체가 회색 돌 + 푸른 빛 두 가지 색이라 버들항(붉은 지붕·풀빛)보다 단조롭다. 포털 넷·성운이 색을 맡는다.
- 무너진 아치 문(3x3)은 고대 숲의 「무너진 아치」보다 작고 가늘다. 폐허 섬은 앵커라기보다 곁 장소 수준.
- 성운 띠는 여전히 덩이가 줄지어 놓인 느낌이 조금 있다. 먼 섬 그림자는 일부러 어둡고 흐리게 둬서 작게만 읽힌다.
- 한 칸 폭 동쪽 돌 길은 꺾이는 자리마다 두께 띠·뿌리가 생겨 계단처럼 보일 수 있다(높이는 같다).
- 멈춘 시계 고리는 바늘이 있어 「시계」로 바로 읽히지만 장식 양식은 단순하다.

# Pixel Art World 카탈로그 다운로드

확인일: 2026-09-24. 첨부 `pixel_art_world_catalog.md`의 32항목을 기준으로 제작자 페이지 30곳, 자료 링크를 따라간 3곳, 이용조건 2곳을 직접 조회했다. 모든 페이지는 HTTP 200이었다. 페이지 내 실제 `a[href]`와 `img[src]`에서 링크를 수집했으며 숨겨진 다른 이미지 속성은 없었다. 사이트 전체 크롤링이나 카탈로그 밖 모든 상품 수집은 아니다.

- `catalog-assets.csv`: 통합 874행. 이름, 종류, 출처 페이지, 직접 다운로드 URL, 파일명, 절대 로컬 경로, 실제 너비/높이, SHA-256, 상태, 조건/설명, 바이트 수, HTTP 상태, ZIP 내부 경로.
- `catalog-coverage.csv`: 카탈로그 32항목별 직접 링크 수, 저장 수, ZIP 이미지 수, 제외/실패와 근거.
- `direct-downloads.csv`: 직접 링크 515개 + 링크가 없는 XP 카페 종료 공지 1개.
- `archive-images.csv`: ZIP 속 이미지 358개. 샘플 게임 이미지 66개는 `sample_package_image`로 명확히 분리.
- `archive-inventory.csv`: ZIP 안 모든 파일의 이름·바이트·해시. 이미지 외 게임 실행파일·스크립트·데이터는 추출하거나 실행하지 않았다.
- `summary.json`: 기계 판독용 개수와 검증 결과.

CSV는 모두 Excel에서 한글·일본어를 읽을 수 있는 UTF-8 BOM이다. `download_url`은 추측한 주소가 아니라 현재 공식 페이지에서 얻었다. ZIP 이미지 행의 URL은 ZIP 자체이며 `archive_member`가 내부 파일을 식별한다. 같은 그림이 개별 URL과 ZIP에 중복되므로 행 수는 고유 그림 수와 다르다.

## 저장 결과

원본 위치: `/home/main/.local/share/oprn/pixel-art-world-downloads/`.

직접 파일 512개 = PNG 505개 + ZIP 7개. 기존 SHA-256 일치 이미지 210개 재사용, 새 파일 302개 다운로드. ZIP은 소재 묶음 5개(타일셋 2, 오토타일 3)와 샘플 게임 2개다. 소재 ZIP에서 이미지 292개, 샘플 게임 ZIP에서 이미지 66개를 추출했다. 소재 이미지 행은 797개이며 SHA-256으로 중복을 없애면 556개다. 샘플 게임의 66개 이미지는 이 556개 집계에서 제외했다.

직접 소재 분류: 타일셋 43, 오토타일 187, 문 49, 개별 칩/소품 155, 연출/캐릭터 스프라이트 58, 음식 11, 아이콘 2. 메인 페이지의 실제 링크를 따라간 WorldMap VX와 和室追加素材도 별도 출처로 포함한다.

모든 저장 행의 파일을 다시 읽어 SHA-256을 대조했고, 모든 이미지는 PIL로 픽셀 전체를 디코딩하고 치수를 확인했다. ZIP 7개는 전체 멤버 CRC를 검증했다. 이는 파일 수집 검증이며 에디터 임포트·타일 좌표·프레임 애니메이션·게임 실행 검증은 아니다.

## 누락·제외

- 학교 페이지의 `SC-Door-Schl03.png`는 HTTP 404. [문 전용 페이지](https://yms.main.jp/dotartworld/page3/door01.html)에 공개된 `SC-Door-SchlG01.png`를 별도로 정상 확보했다. 원래 깨진 링크도 삭제하지 않고 실패 행으로 남겼다.
- 구형 XP 카페와 빵집은 [제작자 메인](https://yms.main.jp/dotartworld/)의 2016-04-17 배포 종료 공지에 따라 제외. 옛 빵집 URL은 HTTP 200이지만 종료 공지가 있으므로 이번 정상 목록에 포함하지 않았다. 이전 작업의 로컬 `ST-Bakery-I01.png`는 기존 파일이어서 삭제하지 않았다.
- `SC-Funassi01.png`는 HTTP 200이나 카탈로그의 후낫시 제외 권고와 원문의 자기 책임 사용 표기를 따라 제외했다.
- 사이트 로고·배너·다운로드 버튼·예시 화면·축소 썸네일은 소재로 집계하지 않았다. `excluded-links.json`에 근거 링크를 보관했다.

## 조건

[제작자 이용조건](https://yms.main.jp/dotartworld/page1/rule.html)에 따라 원본·가공본의 소재 재배포는 금지되며 공개 작품에는 사이트 크레딧이 필요하다. 이미지와 ZIP은 사용자 로컬에만 저장했고 Git/public/dataURL 번들에 넣지 않았다. XP RTP 개변 구역 9개 이미지는 XP 소유자 한정으로 표시했다. 일본식 문 일부는 アトリエ・ヤオヨロヅ 제공 표기와 별도 조건 확인 필요를 기록했다. 샘플 게임 패키지 안 이미지는 일반 소재처럼 이용 허가가 검증되었다고 간주하지 않는다.

원본 페이지 HTML/텍스트 증거는 로컬 폴더 `_catalog-evidence/`에 저장했다. 이 작업은 프로젝트 SQLite·에디터·정본 콘텐츠를 수정하지 않는다.

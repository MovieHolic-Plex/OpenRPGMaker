## 빠뜨리기 쉬운 범위

- 오토타일 임포터는 등록된 **96×128 정적 XP와 384×128 4프레임 XP**를 허용한다. VX A1/A2/A4·지형 묶음/카운터 등 다른 규격은 이 경로로 지원되지 않는다.
- 문49 + 연출/캐릭터58 직접 PNG는 프레임/방향/애니메이션 계약이 카탈로그에 없다. 모두 움직인다고 단정하지 말고 정적 문·방향별 그림도 파일별 구분해야 한다.
- MV 이름 표기7파일은 48px/확대본 검토 대상이다. pot·레이스·Wall01은 혼합 크기/합본 가능성을 별도 확인해야 한다. 파일 가로세로가 32의 배수라는 이유로 XP 시트로 취급하면 안 된다.
- XP RTP 개변9개는 XP 소유자 제한. 샘플게임 이미지66개는 개별 저작권 미검토로 일반 소재와 분리했다. 학교 외관·목조학교 복도·주택가 개가 나오는 예시는 RTP 병용 안내가 있다. 일본식 문 일부는 외부 제공자 조건 확인 대상이다.
- 학교문 Schl03 원 URL은404, SchlG01 대체 원본은 확보. XP 카페·빵집은 종료 공지에 따라 활성 지원에서 제외. 후낫시도 카탈로그 권고로 제외.
- 기존 타일셋 생성은 `tilesPerRow: 8`, 32px 등록 원본 중심이며 사전 밖 타일은 미검토다. 새 크기·새 문법 파일에 단순 등록만 해도 완전 지원된다고 볼 수 없다.

실제확보 경로/치수/해시, 32항목별 미등록 주요 타일셋, 형식/권리 플래그는 `catalog-audit.json` 참고. 중복 URL·ZIP 때문에 항목별 개수 합계는 전체 고유 파일 수와 다르다.

## 공용 AI 문서 작업 (2026-09-24)

로컬 공용 라이브러리 `pixel-art-world-local`: 원본 타일셋 14 + 도시/학교 합성 2,
오브젝트 163, 저장된 맵 12, 장소 13(4층 학교의 부모 포함), 지역 1.
이 수치는 고유 원본 지원 수가 아니며 전체 카탈로그 지원 완료를 뜻하지 않는다.
검토 완료 루트는 도시·4층 학교·축소 도서관 3개다. 시설 6개는 `review-pending` 문서를 갖고
루트에서 제외한다. 사무실의 업무 소품, 의원 대기석/접수원 동선, 두 상점 POS,
주택 복제를 수정해야 한다. 도서관은 14×12에서 12×10으로 줄이고 대출대와 독서석을 배치했다.

미완료: 나머지 원본의 정확한 조립 사전, VX/MV/문·소품 형식 지원,
용도별 실제 배치·적대적 그림 검토, 신규 프로젝트에서 복사한 학교의 이벤트 재생,
다운로드 버튼에서 공용 문서까지 전체 설치 흐름. 원본 배포 종료/404/개별 이용 조건은
활성 지원과 구분해서 기록하며 확보하지 못한 파일을 지원했다고 주장하지 않는다.

실제 그림/비공개 프로젝트 사본은 사용자 로컬 DB와 output에만 둔다.
저장소에는 좌표·규칙·생성 스크립트·출처 메타데이터만 둔다.

## 저장·확인 근거

공용 라이브러리는 사용자 로컬 `shared-content.sqlite`에 저장 후 재로드했다.
정본 프로젝트 `6ae74f7a-23a2-449b-8171-5afb5dff532b`의 SQLite 저장소에도
13개 공용 타일셋 정의와 문서를 저장하고 revision 18에서 재로드 일치를 확인했다.
기존 12개 맵의 배열과 이벤트는 변경하지 않았다.

새 프로젝트 팩토리와 기존 프로젝트의 공용 자료 적용은 각 13개가 연결됐고,
두 번째 적용은 변경을 만들지 않았다. AI 문서는 6000자 페이지와 별도 이미지
블록으로 읽혔다. 이는 신규 SQLite 프로젝트의 전체 설치·플레이 확인을 대신하지 않는다.
빌드와 브라우저 관찰을 수행했으며 전체 테스트·게이트는 실행하지 않았다.
개인 경로·실제 그림·저장 영수증은 Git 제외 `output/paw-shared-library/`에 보관한다.

2026-09-24 후속: 도서관/사무실과 도시의 출현 위치를 정본 revision 20에 저장·재로드했다.

## XP 전체 원본의 공용 설치 (후속)

XP 140개 원본을 `pixel-art-world-xp-local`에 8개 아틀라스로 저장·재로드했다.
고정 4×3 재료 조립 오브젝트 139개를 제공한다. GroundBase 편집 템플릿은 오브젝트에서 제외한다.
기존 공용 PAW 자료와 합계는 타일셋24·오브젝트302이며, 원본 파일 지원 수는 여전히154다.
타일 문서428개를 AI 도구의732페이지로 끝까지 읽었고 이미지428개와 오브젝트139개의 실제 그림 조회를 확인했다.
전체8시트 적대적 검토에서 발견한 Carpet08ST/09ST 분류를 세로 러너로 수정했다.
현재98종 자동 성형·42종 수동 조립이다. 창문/커튼은 중앙 벽지, 난간은 지붕,
반투명 Pool은 콘크리트 받침을 문서·배열·그림에서 동일하게 사용한다.

정본 project id `6ae74f7a-23a2-449b-8171-5afb5dff532b`, 사용자 SQLite 프로젝트의
revision25에서8타일셋의 저장·재로드 일치와 기존12맵 보존을 확인했다.
기존 문서까지 포함된 저장 요청이64MiB를 넘어 실패했던 문제는 인증된 project.save의
압축 전송과 제한된256MiB 해제 한도로 해결했다. 정본 저장에서gzip 전송29,365,015바이트를 관찰했다.
자료집에서 Pool의 명시 받침 문서와 러너의 수동 조립 표시를 확인했으며 브라우저 오류0개다.

이 추가분은 **타일·오브젝트 조립 자료**다. 140종 전체를 쓴 완성 장소/지역·실행 게임을 만든 것은 아니다.
새 프로젝트 팩토리와 직렬화 왕복에는24공용 타일셋이 연결됐다. 별도 SQLite 신규 프로젝트의 첫 시도에서는
공용 스냅샷이 빠져 있었고, 원인은 아직 확정하지 않았다. 다시 읽은 팩토리에는24종이 모두 들어왔으며
최초 누락을 숨기지 않고 후속 확인 대상으로 둔다. 같은 신규 SQLite 프로젝트에는 명시적 호스트 설치로24종·302오브젝트를 저장하고 revision2에서 재로드했다. 전체 신규 자동 설치 경로가 항상 성공한다고 주장하지 않는다.

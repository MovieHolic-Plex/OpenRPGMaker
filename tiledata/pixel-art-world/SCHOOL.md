# Pixel Art World 학교 기본 세트 — 사용자 PNG 조립 사전

확인일 2026-09-24. [제작자 학교 페이지](https://yms.main.jp/dotartworld/page2/tile-school01.html),
[이용 조건](https://yms.main.jp/dotartworld/page1/rule.html). 제작자: Pixel Art World / ドット絵世界.
공용으로 배포하는 것은 좌표·해시·조립 배열·생성 코드다. 원본/가공 그림은 Git·번들·public에 넣지 않는다.
사용자가 제작자 페이지에서 받은 PNG를 로컬에서 가져올 때 그림을 생성한다.

32px, 8열, 0기준 `tileId=y*8+x`. 사각 좌표/크기는 **칸** 단위며 픽셀 좌표는 각각 32배다.
다른 판본·스케일·특별교실 세트에 이 ID를 재사용하지 않는다. 원본의 알파와 픽셀을 그대로 사용한다.
식별 SHA가 다르면 적용하지 않는다. 검토 밖 타일은 차단·미검토로 시작한다.

공식 샘플 `smp-shol07.jpg` 및 교탁 방향 샘플 `smp-shol12.jpg`, `smp-shol13.jpg`를 함께 보았다.
샘플은 원본 시트 외 별도 오토타일/문/RTP도 사용하므로 샘플의 모든 조각이 기본 PNG에 있다고 추정하지 않았다.
이 교실은 공식 샘플 복제가 아니라 원본 시트만 사용하는 별도 배열이다.

## 완성 교실 — `school-classroom-north`

입력은 `school.json`의 `scenePlans`. 컴파일된 전체 lower/upper 행 우선 배열은
`src/assets/pixelArtWorldSchoolCatalog.json`의 `scenes`에 있다. 예제 크기는 17×20칸, 544×640px다.
`-1`은 상위 공백. 좌표는 완성 맵 기준 0부터이며 원점은 왼쪽 위다.

1. 하위 6을 전체에 반복한다. 바닥 6만 통행 허용이다.
2. 북쪽 벽 y=0,1,2에 각각 41,49,57을 가로 반복한다. x=0,16의 y=3..19에 세로 목재 2를 놓는다.
3. 남쪽 테두리 y=19에 x=1..7,10..15만 가로 목재 1을 놓는다. x=8,9는 바닥 6인 출입구다.
4. 칠판 (7,1), 창 (1,0),(13,0), 게시판 (11,1), 시계 (5,1), 교탁 (8,3), 화분 (15,17)에 각 고정 배열 전체를 상위에 놓는다.
5. 책상 원점은 `(3+3*c,6+4*r)` (`c=0..3`, `r=0..2`). 의자는 해당 원점 `(x,y+2)`에 253을 놓는다.
6. 책상 접근칸 `(x+1,y+1)` 12개와 교탁 접근 (8,5), 남쪽 접근 (8,18), 출입 (8,19)를 비워 둔다.

고정 벽/테두리 1,2,41,49,57은 하위지만 차단이다. 모든 상위 부품도 차단이다.
벽/창/칠판의 각 칸은 미리 정의된 하나의 상위 ID만 가진다. 창과 칠판을 겹쳐 놓지 않는다.
테두리는 일반 목재 타일이며, 별도 XP 벽/천장 오토타일을 합성했다고 주장하지 않는다.
의자는 그림이며 앉기 이벤트가 아니다. 남쪽 두 칸은 열린 출입구이며 문/이동 이벤트가 아니다.

## 그림 생성과 확인

```bash
node scripts/content/prepare-pixel-art-world-school.mjs
node scripts/content/render-pixel-art-world-school.mjs /absolute/path/to/user-png-folder
```

두 번째 명령에는 위 원본 PNG 2개가 필요하다. 네트워크 요청은 없다. 원본 SHA/크기를 다시 확인한다.
출력은 gitignored `output/paw-school/`에만 둔다:

- `school-classroom-north.png`: 실제 원본 픽셀의 완성 교실, 원본 해상도.
- `school-classroom-north-comparison.png`: 왼쪽 정상, 오른쪽 실제 변조.
- `school-classroom-north-arrays.json`: 정상/오류 전체 배열, 코드와 맵 좌표.
- `paw-school-interior-parts.png`, `paw-school-exterior-parts.png`: 번호 모형이 아닌 실제 부품 그림.
- `report.json`: 원본 해시와 오류 목록.

오류 예제는 칠판 하단 (7,2) 누락, 출입구 접근 (8,18) 점유, 책상 하단 (3,7)을 상위에서 하위로 옮겨 바닥 제거다.
검출은 `UPPER_CELL`, `LOWER_CELL`, `APPROACH_BLOCKED`다. 생성기는 원본 좌표 범위, 상위 겹침,
동일 ID의 홈 레이어 충돌, 남쪽 출입에서 모든 접근칸까지의 4방향 경로를 확인한다.
그림에서 실제로 잘못 붙은 벤치 옆 생울타리와 나무 밑 벽을 발견해 각각 x=4, height=6으로 정정했다.

한계: 맵을 정본 프로젝트에 저장한 증거가 아닌 코드/배열 fixture다. 런타임 이벤트, 미적 평가,
모델의 배치 성공률은 확인하지 않았다. 외관 완성 교사·운동장·체육관·수영장,
내장 계단·특별교실은 아직 조립 사전 범위 밖이다.

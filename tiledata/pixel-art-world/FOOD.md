# 음식 소품 전판 사전 — 카탈로그29

2026-09-24. 직접 원본10개 / 156칸 / 153완전 그림 묶음. 검토된 식탁 합성150개. 매달린3객체의 고정점 조립은 미검토. 이 문서의 객체는 하나의 완전한 그림 묶음이며 여러 작은 소품이 함께 그려진 셀을 임의 분해하지 않는다.

## 원본과 이용 조건

[제작자 음식 페이지](https://yms.main.jp/dotartworld/page3/food01.html)와 [규약](https://yms.main.jp/dotartworld/page1/rule.html)을 확인했다. 일반 게임 도구/상업 게임 사용 및 수정 허용, 소재 재배포 금지, 공개 배포 게임에 Pixel Art World 또는 ドット絵世界 크레딧 필요. 음식 페이지의 이미지 목록에는 별도 RPG Maker 전용 표시가 없었다. 파일명 Cninese/IstNudle/susi는 원본 철자를 유지한다. 같은 폴더의 Ozen.png는 이 항목의 직접10PNG가 아니므로 이번 범위에서 제외한다.

[별도 받침 원본](https://yms.main.jp/dotartworld/page2/tile-fastfood01.html): ST-Icecream-I01.png,256×640, SHA-256 f25b67886a656df2e1a63df8861b9a4aab8adfa27a21d6024304a12a23d8585a. 원본 식탁(0,512)96×64와 바닥(0,0)32×32만 사용한다. 이 받침 원본은 음식10파일 수에 포함하지 않는다.

## 전체 객체·받침 조립 계약

원본은32px·4열. sourceRect는 칸, pixelRect/alphaBounds/anchor는 픽셀이다. 투명 여백은 삭제하여 원본을 다시 격자로 만들지 않는다. 원본 타일셋은 전체 PNG 그대로이며 원본 번호=y*4+x. 합성 단계에서만 음식의 실제 비투명 경계를 잘라 받침 위에 놓는다. 음식의 밑변 중심을3×3캔버스(48,55)에 고정하고 먼저 그린 식탁을 알파 합성으로 보존한다. 큰 피자 뚜껑·그림자·젓가락도 전체 원본에 포함된다. 그림자 alpha76도 보존한다.

합성 atlas는32px·12열. 첫칸0은 바닥, 첫행 나머지는 예약빈칸. i번째 객체의 원점은 x=(i%4)*3,y=1+floor(i/4)*3, 완전3×3이다. 식탁합성제외객체를 걸러낸 순서로 i를 매긴다. lower는5×5전부0, upper는전부-1로 시작해(1,1)에3×3객체 전체를 넣는다. 남쪽(2,4)는 비워 접근한다. 개별 음식 upper로 기존식탁 upper를 덮지 않는다. 원본 타일셋 번호와 합성 번호를 섞지 않는다.

원본소품은upper/passable(받침충돌별도), 합성객체는upper이고 위 첫행은음식돌출/통과, 아래 두행은식탁차단. 원본은바닥/가구가아니다. 매달린 고기·소시지·장갑은상판물건이아니므로식탁합성제외; 고정점/벽걸이/이용이벤트미검토. 음식 이름은보이는형상기술이며정확한재료를추정하지않는다. 빈접시/먹고남음/포장을모두보존하고자동애니메이션으로묶지않는다.

## 생성·검토

`prepare-pixel-art-world-food.mjs`는메타데이터만생성하며칸중복/전판누락/좌표/기준점/받침크기를검사한다. `render-pixel-art-world-food.mjs`는사용자원본과승인된dev서버로실제브라우저prepare를호출한다. SHA/decode/alpha경계/문서계약검사,모든조립정상그림·식탁다리누락/접근차단오류비교와전체배열,카드스크린샷을개인output에남긴다. Git/public에는메타데이터만커밋한다.

prepare출력은20타일셋·20용도·323MD·313이미지다. 원본153그룹/식탁150그룹이며게임맵·먹기/판매/상태변화이벤트가아니다. 공용게시·정본등록은root후속단계.

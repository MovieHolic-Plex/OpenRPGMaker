## `home-compact` 완성 배열

14×16칸=448×512px. 전체 행 우선 lower/upper 배열은 `src/assets/pixelArtWorldHomeCatalog.json`에 있다.
-1은 상위 공백. 저작 원본 `home.json`의 `scenePlans`와 placements로부터 결정적으로 생성한다.

1. 하위에 카펫 4를 반복한다. 북쪽 y=0,1,2는 벽 17,25,33. 바닥은 y=3부터다.
2. 주방은 x=0..6,y=0..5, 침실은 x=8..13,y=0..5, 거실은 y=10..15다.
3. x=7,y=0..6의 세로 벽과 y=6..9의 가로 벽으로 방을 구획한다. y=6은 천장, y=7,8,9는 북벽과 같은 3칸 정면이다.
   주방 문 x=5..6, 침실 문 x=10은 y=6..9을 바닥으로 열어 둔다.
4. `ceilingCells`의 정확한 칸 목록은 **별도 사용자 원본 SA-WallA01의 XP47 변형**으로 치환한다.
   하위 17은 그 위치의 정면 벽 받침이며 천장 그림이 아니다. 기본 PNG만의 scene 참고 그림은
   받침까지 보여 준다. 완성 도시는 저작기가 천장 연결을 적용하고 실제 완성 배열/PNG를 추가한다.
5. 싱크 (1,1), 레인지 (3,2), 옷장 (8,1): 실제 밑동을 y=3 바닥에 걸친다.
   창 (11,0), 시계 (4,1)는 벽 부착물이다. 이 둘을 바닥으로 내리지 않는다.
6. 침대 (11,2): 머리판만 벽에 겹친다. 양 옆과 발치 y=5에서 접근한다.
7. 거실 TV (1,9), 유리 테이블 (1,12), 북향 소파 (1,14). y=13 접근 통로 유지.
   오른쪽 식탁 (9,11), 동향 의자 (8,12), 서향 의자 (12,12)는 서로 마주보며 y=14에서 접근한다.

남쪽 문 **(6,15)**, 스폰 **(6,14), 북향**. `approachCells`에 모든 접근칸을 싣는다.
4/11은 하위 통과,17/25/33 및 XP 천장은 하위 차단, 상위 가구는 차단이다.
**목재 바닥 1/2를 벽으로 쓰던 이전 12×11 배치는 반려했다.** 가구 접지와 방의 실제 경계를
확인하지 않은 이전 미리보기는 승인 기준으로 재사용하지 않는다. 요리·TV·수면 이벤트는 별도다.

## 생성·픽셀 검토

```bash
node scripts/content/prepare-pixel-art-world-home.mjs
node scripts/content/render-pixel-art-world-home.mjs /absolute/user-png-folder
```

네트워크 요청은 없으며 로컬 원본 해시/크기를 다시 확인한다. 출력은 gitignored `output/paw-home/`:

- `home-compact.png`: 실제 원본 해상도 주택 그림.
- `home-compact-comparison.png`: 왼쪽 정상, 오른쪽 실제 조각 누락/접근 막힘/하위 덮어쓰기.
- `home-compact-arrays.json`: 정상/오류 전체 배열과 오류 좌표.
- `paw-home-parts.png`: 실제 원본으로 만든 부품 모음.
- `report.json`: 출처 해시, 문/스폰, 오류 코드/좌표.

생성기는 원본 좌표 범위, 상위 겹침, 동일 ID의 레이어 충돌, 남쪽 출입에서 모든 접근칸까지의
4방향 경로를 검사한다. 그림 생성기는 모든 하위 타일의 실제 alpha가 255인지 확인해 바닥 구멍을 막는다.
오류 그림에는 첫 상위 조각 누락, 문에 실제 부품 추가, 통과 바닥 위 첫 부품을 하위로 옮기는 변조를 수행한다.
검출 범위는 `UPPER_CELL`, `LOWER_CELL`, `APPROACH_BLOCKED`다.

이 자료는 코드/배열 fixture이며 정본 저장이나 이벤트 실행 증거가 아니다. 실제 프로젝트 저장/재로드와
이벤트 연결은 사용하는 저작 작업이 수행한다. AI 배치 성공률이나 미적 평가를 구조 검사로 대신 주장하지 않는다.

## 현재 분리형 주택 세 유형 (2026-09-25)

위14×16 원형 도안과 현재 저장된 주택 평면을 혼동하지 않는다.

- `home-compact-5`: 13×16, 북쪽 침실·주방과 남쪽 식사 거실.
- `home-compact-6`: 13×15, 서쪽 거실과 동쪽 분리 침실·주방.
- `paw-home-two-bedroom`: 15×15, 동쪽 독립 침실2개와 서쪽 주방·식사·거실.
  북서 조리대 옆에 식탁을 붙이고 남서 TV→유리탁자→북향 소파를 배치한다.
  침실 입구 `(9,6)` / `(9,12)`는 각각 거실에서 직접 접근한다.
  옷장 밑동은 y11, 남쪽 접근행은 y12다. y12를 옷장으로 막으면 두 번째 침실이 단절된다.
  조리대 앞 y5에서 남쪽 y6으로 빠져나오므로 TV는 y7부터 둔다.
  TV를 y6으로 올리면 식탁 의자와 함께 주방 접근칸을 가둔다.

기존 두 주택은 `compact-homes.json`, 세 번째는 `house-variants.json`과
`dense-interiors-compiled.json`에 전체 배열·방·문·객체 원점·천장 좌표를 둔다.
`prepare-pixel-art-world-dense-interiors.mjs`는 현재 정본의 아틀라스 SHA를 대조하고,
모든 가구 지지칸·상위 겹침과 엔진 통행의16개 접근 목표를 확인한다.
정본 타일 참고문서와 사용자 로컬 공용 DB에 실제 타일 그림과 같은 배열을 함께 넣는다.
새 유형은 독립 표본이며 도시 출입·수면·요리 이벤트는 아직 없다.
세 유형의 재사용을 지원하는 것이 임의 평면 설계의 모델 성공률을 증명하지는 않는다.

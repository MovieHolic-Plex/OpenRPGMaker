## 정확한 부품 사전

좌표는 0기준 원본 칸이다. 1칸=32px, 픽셀 좌표는 각 값을 32배, `tileId=y*8+x`.

TV/유리테이블의 투명 가장자리를 잘라서 폭을 줄이지 않는다. 싱크대는 2×3 전체,
레인지는 옆에 독립 1×2로 놓아 높이를 맞춘다. TV 밑 콘솔장을 같은 상위 칸에 겹치지 않는다.

## `home-compact` 완성 배열

12×11칸=384×352px. 전체 행 우선 lower/upper 배열은 `src/assets/pixelArtWorldHomeCatalog.json`에 있다.
-1은 상위 공백. 저작 원본 `home.json`의 `scenePlans`와 placements로부터 결정적으로 생성한다.

1. 하위에 카펫 4를 반복한다. 북쪽 y=0,1,2는 벽 17,25,33으로 채운다.
2. 좌우 x=0,11의 y=3..10은 목재 2. 남쪽 y=10은 x=1..5,7..10에 목재 1.
3. 침실 파티션 x=7,y=3..7에 목재 2. 입구 (7,8)은 바닥 4 그대로 둔다.
4. 주방: 싱크대 (1,0), 레인지 (3,1). 앞 x=1..3,y=3은 회색 바닥 11.
5. 창 (5,0), 시계 (4,1), 옷장 (8,0).
6. 거실: TV (3,4), 테이블 (3,6), 북향 소파 (3,8). y=7 한 칸 접근 통로를 보존한다.
7. 침대 (8,4). 오른쪽 접근 (10,5), 발치 (9,7), 옷장 앞 (8,3)을 비워 둔다.

남쪽 문은 **(6,10)**, 권장 스폰은 **(6,9), 북향**이다.
`approachCells[0]`은 문, `[1]`은 스폰. 모든 접근칸은
(6,10),(6,9),(1,3),(3,3),(2,5),(2,6),(3,7),(10,5),(9,7),(8,3),(7,8)이다.
중앙 x=6과 거실 왼쪽 x=2 통로를 통해 주방·거실·침실을 연결한다.

하위 4와 11만 통과한다. 벽/목재 1,2,17,25,33은 하위 차단, 모든 상위 가구는 차단이다.
문·침실 입구는 빈 칸이며 실제 문/전이 이벤트가 아니다. 요리·TV·수면 이벤트는 별도 저작한다.

## 생성·픽셀 검토

```bash
node scripts/content/prepare-pixel-art-world-home.mjs
node scripts/content/render-pixel-art-world-home.mjs /absolute/user-png-folder
```

네트워크 요청은 없으며 로컬 원본 해시/크기를 다시 확인한다. 출력은 gitignored `output/paw-home/`:

- `home-compact.png`: 실제 원본 해상도 주택 그림.
- `home-compact-comparison.png`: 왼쪽 정상, 오른쪽 실제 조각 누락/접근 막힘/하위 덮어쓰기.
- `home-compact-arrays.json`: 정상/오류 전체 배열과 오류 좌표.
- `paw-home-parts.png`: 실제 원본으로 만든 부품 모음.
- `report.json`: 출처 해시, 문/스폰, 오류 코드/좌표.

생성기는 원본 좌표 범위, 상위 겹침, 동일 ID의 레이어 충돌, 남쪽 출입에서 모든 접근칸까지의
4방향 경로를 검사한다. 그림 생성기는 모든 하위 타일의 실제 alpha가 255인지 확인해 바닥 구멍을 막는다.
오류 그림에는 첫 상위 조각 누락, 문에 실제 부품 추가, 통과 바닥 위 첫 부품을 하위로 옮기는 변조를 수행한다.
검출 범위는 `UPPER_CELL`, `LOWER_CELL`, `APPROACH_BLOCKED`다.

이 자료는 코드/배열 fixture이며 정본 저장이나 이벤트 실행 증거가 아니다. 실제 프로젝트 저장/재로드와
이벤트 연결은 사용하는 저작 작업이 수행한다. AI 배치 성공률이나 미적 평가를 구조 검사로 대신 주장하지 않는다.

# 햇살학교 — 4층 건물과 방 구조

32px 사용자 다운로드 원본을 사용한다. 그림을 재배포하지 않는다.
학교 한 층은 32×31의 단일 맵이며, 실제 벽으로 구획한 7실과 중앙 2칸 복도를 가진다.
일반교실16개(각6석), 특별·관리실8개, 화장실4개 = 총28실이다.
1층 보건실/교무실, 2층 과학실/도서실, 3층 음악실/미술실, 4층 학생회실/교장실.

각 방은 천장 아래 한 칸 출입구를 통해 같은 층의 복도로 걸어서 출입한다. 방마다 맵을 바꾸지 않는다.
북쪽 방의 남벽은 천장(y12)·3행 정면(y13..15), 남쪽 방은 천장(y18)·정면(y19..21)이다.
목재 바닥을 벽으로 쓰지 않는다. 동서 계단은 층마다 같은 위치에 있으며 1↔2↔3↔4층으로 연결한다.
1층 서쪽 복도 끝 (0,17)으로 동네에 돌아간다. 계단은 현재 action(조사)로 작동한다.

`school-building-layout.json`은 층별 방 용도, `school-building-parts.json`은 추가 조립 부품 정본이다.
`prepare-pixel-art-world-school-building.mjs`가 전체 배열·가구·문·계단·접근 좌표를
`src/assets/pixelArtWorldSchoolBuilding.json`으로 생성한다. 번호는 여러 원본으로 합성한 atlas 전용이다.
현재 프로젝트의 `학교 · 4층 구조와 부품` 및 층별 문서에 실제 이미지와 전체 배열이 함께 저장된다.
공간 설계 데이터에도 4개 `interiorLayout`과 시설의 층 연결을 기록한다.

배치 순서: 원본 해시 확인 → 방/복도 바닥 → 3행 정면벽 → XP47 천장 연결 → 전체 가구 배열 → 계단 이벤트.
학교 기본벽41/49/57, 바닥6은 ST-Schl-I01 전용이다. 다른 시트의 동일 번호를 혼용하지 않는다.
상행 계단은112/-1/114,120/121/122,128/129/130의3×3다. 가운데120/121/122를 반복하는3×4 변형도 사전에 보존하지만 현재 층에는3×3을 쓴다.
하행은115/116/117,123/124/125의3×2다. 양옆 난간은 막고 중앙만 연다.
[-1] 자리는 원래 바닥을 남기며, 하행의 반투명 암부도 바닥 위에 그린다.
정확한 근거: [제작자 계단 조립](https://yms.main.jp/dotartworld/page2/tile-schlxp01.html),
[학교](https://yms.main.jp/dotartworld/page2/tile-school01.html),
[특별실](https://yms.main.jp/dotartworld/page2/tile-school02.html),
[화장실](https://yms.main.jp/dotartworld/page2/tile-toilet01.html).

문을 막았을 때 각 방에서 복도로 나갈 수 없어야 벽 경계가 성립한다.
문을 열면 모든 방·학생 좌석 접근칸·계단이 현관과 이어져야 한다.
가구 상단은 벽에 걸쳐도 되지만 지지칸/실제 발판은 바닥에 놓는다.
공용 구조 검사는 미적 승인이나 런타임 층 전이 성공을 대신하지 않는다.
정본 저장·재로드 후 실제 플레이어에서 계단 양방향과 방 보행을 따로 확인한다.

2026-09-25 재배치: 40×31에서32×31로 줄였다(1240→992칸, 면적20% 감소).
복도는 x1..30/y16..17의2칸이고 서쪽 계단은 뒤벽 안에 넣어 두 행을 모두 비웠다.
일반교실은6×11, 3열×2행=6석이다. 책상 상대 x=[0,2,4], 시작 y=[4,7], 의자 y=[6,9].
좌석 옆 x=[1,3,5] 및 뒤 y10을 비운다. 좌석 접근은 각 의자의 오른쪽 칸으로 검사한다.
교탁(1,2)은 첫 바닥 행y3에 밑동을 놓는다. 칠판(0,0), 북쪽 창문(3,0)은 겹치지 않는다.
남쪽 교실 시계(4,1)와 출입구 상대x5는 칠판을 가르지 않는다.
서쪽 상행 조사(4,15)/접근(4,16), 하행 조사(8,15)/접근(8,16).
동쪽은 남동쪽7×7 계단실이며 문(27,18..21), 상행 조사(25,24)/접근(25,25),
하행 조사(29,24)/접근(29,25)다. 맞은편 층의 반대 계단 접근칸으로 전이한다.
동서 판정은 맵 폭의 절반을 기준으로 한다. 1층에는 하행,4층에는 상행이 없다.
교무실·교장실 의자는ST-Office-I01의196(북향 등받이)이며 책상 조작면을 향한다.

특별실은 폭8, 보건/미술 높이10, 과학11, 교무9, 음악/도서/학생회/교장8다.
북측은 남벽에 맞추고 남측은 북벽에 맞춘다. 남는 바깥 면적을 방 바닥으로 칠하지 않는다.
방 높이는 실제 가구 그룹과 마지막 횡단 통로에 맞춘다. 빈 곳을 채우기 위한 장식 추가는 하지 않는다.
화장실은 7×8, 두 변기와 세면대 및 원본의 얇은 개방형 칸막이다.
`washroom-open-stalls`는 ST-Toilet-I01의 원본 행12..16을 합성한 5×5다.
행17은 다음 닫힌문 변형이므로 붙이면 바닥에 문짝 조각이 생긴다. 반드시 제외한다.
칸막이 상대 행0..1 중앙은 -1로 두어 변기를 넣고, 행2..4의 중앙 두 열만 통과시킨다.
아래 전체 배열은 공유 사전에 있으며 좌표 단위는 32px 타일이다.

```json
[[96,-1,98,-1,100],[104,-1,106,-1,108],[114,115,112,115,116],[122,123,120,123,124],[130,131,128,131,132]]
```

문 위 천장 띠는 인접 천장과 연결된 상위·통과 타일이다. 그 아래 바닥과 세 행의 문 통로를
비우므로 같은 맵에서 보행하며 벽의 천장 선은 끊기지 않는다. 가구로 문을 가리면 안 된다.
정상/오류 비교는 사용자 원본을 조립한 층별 그림과 원본 칸막이 접사에서 확인한다.

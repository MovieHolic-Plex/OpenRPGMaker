## 원본과 공식 근거

2026-09-25에 [제작자 TOP](https://yms.main.jp/dotartworld/)과
[이용규약](https://yms.main.jp/dotartworld/page1/rule.html)을 다시 읽었다.
TOP의2016-04-09 갱신에서 Eu-Easel01/Jukebox01,2016-03-17에서 Eu-Pillar01,
2016-01-25에서 Statue02,2015-09-21에서 Eu-Statue01의 원본 링크를 확인했다.
기둥/흉상의 MV확대판은 별도 파일이며 이번 판본과 혼용하지 않는다.
이5원본 바로 옆에는 Maker전용 표기가 없으며 규약의 일반 자작소재 조건을 적용한다.
소재/가공소재 재배포는 금지이고 공개 게임에는 Pixel Art World 크레딧이 필요하다.
앞으로의 권리 변경이나 다른 판본까지 허용한다고 일반화하지 않는다.

## 객체 경계와 지지

- 칠판3은 전체 벽 받침을 요구한다. 이젤3은 양다리 마지막 행이 바닥에 놓인다.
  빈 거치대는 판이 없는 정면 거치대이며 후면이라고 단정하지 않는다.
- 기둥6은 머리·몸통·주초를 통째로 보존한다. 부러진 것은 정적 상태다.
  원형 대칭 장식이며 남쪽 접근을 선택했을 뿐 방향변형을 생성하지 않는다.
- 큰 석상의 둘째 객체는 x52..95이고, 셋째 팻말은 x93..143이다. y49에서
  sourceParts를 나눠 팻말과 이웃 석상 그림자가 섞이지 않게 한다. 실제 객체의
  가로/세로 비율과 주초2칸을 보존하며 새64px캔버스에는 투명 여백만 더한다.
- 주크박스의 원본 아래14px투명을 위로 옮겨 실제 밑동을32px칸 끝에 맞춘다.
  앞 조작부의 남쪽 접근을 비우되 음악 재생 이벤트는 만들지 않는다.
- 흉상 원본 왼쪽 완성체와 가운데 빈 기둥은 그대로다. 오른쪽 분리형A/B는
  각각 원본상대 y3/y0에 기둥 다음으로 겹쳐 그린다. 여기에 전체y5패딩을 더한다.
  이는 기존 완성체의 목·상판 접합을 참고한 **고정 조합**이며 공식 상태명이나
  파괴 전후 순서가 아니다. 파편군 전체64×32는 바닥2칸을 보수적으로 막는다.

맵의 앞뒤 레이어는 둘 다 상위에 단일 합성으로 출력하며, 물리적으로 흉상은 기둥 앞이다.
빈받침+소품을 개별 상위 타일로 겹쳐 찍으면 받침이 지워진다. 전체kit를 사용한다.
차단은 명시한 실제 주초/다리/밑동이며 알파255그림자를 자동으로 발로 보지 않는다.

## 조립 표본과 한계

표본은7×5/13×5/10×6/5×4/12×4이다. 입구에서 각 지정 남쪽 접근칸까지
연결된 작은 받침·방향 예제이며 완성 시설/게임맵이 아니다. place5와preview5로
등록해도 완성 시설5개로 세지 않는다. regions/maps/events는 만들지 않는다.
객체kit23개는 하위-1/전체상위, 표본raster5개는 전체하위/전체상위이며 각각
원본·read-first·정상오류MD와 실제그림을 소유한다. 모든 픽셀 자료는 private output과
사용자 로컬 저장에만 존재한다. 공용 메타데이터만 Git에 들어간다.

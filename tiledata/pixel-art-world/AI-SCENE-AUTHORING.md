# 학교·교실·실내·도시를 실제 구현하는 조수 경로

380개 사용자 다운로드 원본 범위는 그대로다. 이 문서는 새 소재 배포가 아니다.
원본/파생 그림과 실제 예제는 사용자 로컬 `shared-content.sqlite`에 보관한다.
Git에는 조립 원문·번호·생성 코드만 둔다. 미설치 사용자는 먼저 자료집에서 다운로드해야 한다.

## 무엇을 만들 수 있는가

공용 **78개 장소**를 독립된 편집 가능 맵으로 재현한다. 기존74개에 독립 침실2 주택과
촘촘한 이자카야 저장 맵에 이어 서점·8석 아이스크림점 두 저장 맵을 추가했다. 이자카야 정적 조립과 저장 맵 모두 분리 조리실·다다미 개인실·천장/남쪽 벽 포함14×24이다.

| 대상 | 검색/선택 | 생성 범위 |
|---|---|---|
| 도시 | `shared_paw_city` | 50×50 도시 + 출입으로 연결된 시설/학교, 총12맵 (`include`) |
| 학교 전체 | `shared_paw_school_building` | 32×35 네 층, 교실16·특별관리실8·화장실4, 계단6방향 |
| 학교 층 | `shared_paw_school_floor_1` … `_4` | 층 하나; 외부 계단 목적층은 `include` 또는 명시적 `omit` |
| 교실 | `교실` 검색, `shared_paw_room_school_1_0` 등16개 | 칠판·교탁·6석·뒤 사물함·연결 벽·1칸 출입구 |
| 특별실 | 과학실/보건실/교무실/도서실/음악실/미술실/학생회실/교장실 | 각 실제 방 전체, 8개 |
| 학교 화장실 | `washroom` 검색 | 층별4개; 세면대·두 변기·통과 가능한 칸막이 |
| 생활/상업 실내 | 주택·도서관·병원·편의점·패스트푸드·사무실 | 저장된 시설 내부, 외부 전이는 명시적으로 처리 |
| 새 가게 | `shared_paw_bookshop_shop`, `shared_paw_icecream_shop` | 각10×15 실제 저장 맵, 천장 아래 벽·진열/좌석·직원/손님 통로, 판매/도시 연결 별도 |
| 기타 실내/외관 | 체육관·목욕·센토·이자카야·다다미·맨션·레트로 거리 등 | 공용에 저작한 완전 조립 표본; 없는 동작은 별도 저작 |
| 보완 장소 | 간판·신호·주방·유리·사당·장식·목조학교·하수도 등 | 해당 로컬 라이브러리의 정적 표본 |

현재 목록은 `list_shared_scenes`가 정본이다. 한 번에20개이며 `nextOffset`까지 조회한다.
`reviewPending`은 미승인 상태다. 자료가 있다는 이유로 미적 검토를 통과했다고 말하지 않는다.
개별 소품 전체 목록은 기존 `list_structure_kits`/타일 참고문서에서 따로 찾는다.

## 도구 순서

1. `list_shared_scenes(query)`로 실제 설치된 장면을 찾는다. 없는 ID를 추측하지 않는다.
2. `inspect_shared_scene(id, links)`로 맵·출입 연결·정적 예제 여부·revision을 확인한다.
3. 반환된 `reference`의 `read_spatial_reference` 목록 → MD(`nextOffset`까지)와 실제 이미지를 읽는다.
   학교 전체에는 네 층 하위 장소가 있으며 층별 전체 배열·부품·접근 좌표도 읽을 수 있다.
4. `build_shared_scene(id, namespace, revision, links, setStart?)`를 호출한다.
   모든 포함 맵/타일셋/그림을 독립 ID로 복사하고 내부 전이 mapId를 연결한다.
   타일 번호는 바뀌지 않는다. 반환된 `tilesetIdMapping`을 이후 도구에 사용한다.
5. 반환된 새 mapId로 `show_map_region`을 호출한다. 후속 변경은 해당 사본의 타일 참고문서를 읽은 뒤 일반 편집 도구로 한다.
6. 실제 프로젝트 저장 브리지로 저장하고 같은 SQLite를 다시 읽는다. 이미지/JSON만 만든 것을 저장 완료로 보고하지 않는다.

`links`는 필수다. `include`는 실제 전이로 연결된 맵을 재귀적으로 모두 포함한다.
학교만 선택해도 외부 도시 연결을 따라 도시/다른 시설이 포함될 수 있으므로 inspect의 맵 수를 먼저 확인한다.
`omit`은 외부 목적맵을 참조하는 **이벤트 전체**를 제외하며 `omittedEvents`로 보고한다.
이는 문장/조건 일부를 잘라 잘못된 이벤트를 남기지 않기 위함이다.
`reject`는 외부 연결이 있으면 생성 전에 거절한다. 단독 학교는 `omit`으로 도시 출구1개를 제외해도 층간6방향은 보존한다.
정적 실내에 판매·입욕·악기 연주·문 개폐 이벤트가 자동 생성되지는 않는다.

## 조립을 수정할 때의 판단 기준

- **도시:** [CITY-50](CITY-50.md), [CITY-LAYOUT](CITY-LAYOUT.md), [CITY-KITS](CITY-KITS.md).
  도로→건물 입구→시설 내부→거리 복귀를 연결한다. 실내 전체를 도시 외관에 찍지 않는다.
  사각형을 키워 빈 공간을 만드는 대신 건물·보행 목적에 맞는 범위를 사용한다.
- **학교/교실:** [SCHOOL-BUILDING](SCHOOL-BUILDING.md), [SCHOOL-STAIRWELL](SCHOOL-STAIRWELL.md).
  복도2칸, 방 출입구1칸. 교실6×13 내부에6석과뒤 사물함3×2를 보존한다.
  계단 사이 벽은 북천장에 연결하고 아래 두 행의 계단참을 비운다.
  사물함 남쪽 조작면과 우회통로를 책상/의자로 막지 않는다.
- **주택:** [HOME](HOME.md), `compact-homes.json`의 현재 저장 배열/rooms/doorways.
  거실·침실 등 용도와 방 구획을 유지한다. 한 넓은 바닥에 가구를 흩뿌려 주택이라고 하지 않는다.
  세 번째 평면은 `house-variants.json` → `dense-interiors-compiled.json`의15×15 독립 침실2형이다.
  각 침실에 거실에서 직접 진입한다. 기존 두 유형과 방 구성·주방 위치가 다르다.
- **시설:** [FACILITIES](FACILITIES.md), `compact-civic.json`.
  카운터 직원/손님 양쪽 접근, 의자 방향, 대기석/진료 구획과 출입구를 확인한다.
- **기타 실내:** [BATH-GYM](BATH-GYM.md), [JAPANESE-INTERIORS](JAPANESE-INTERIORS.md),
  [MANSION-INTERIORS](MANSION-INTERIORS.md), [HOSPITALITY-COMPLEMENTS](HOSPITALITY-COMPLEMENTS.md).
  활동 공간은 필요한 빈 공간이다. 휴게/탈의/목욕·운동/보관·식사 구획과 문턱을 유지한다.
  이자카야는 부스·테이블 하나씩만 전시하지 않는다. 분리 조리실·다다미 개인실·천장/남쪽 벽 포함14×24에 부스2·개인실 방석6·바 의자6을
  배치하고 연속 주통로x5와 대부분의 보조 통로x4, 조리실 문(6,4)/(6,5), 직원 작업행y4..5와 의자 뒤y11을 보존한다.
  `izakaya-kitchen-layout.json`의 내벽x6/y6과 정면 벽17/25를 유지한다. 문을 닫으면 주방만 고립되어야 한다. 통행 검사 통과만으로 좌석 밀도를 승인하지 않는다.
  **이 표본의 다다미는 독립 개인실이다.** 내부(7,15)6×6, 탁자(8,16)4×4, 문(6,18)/(6,19).
  북벽y12/13/14와 서벽x6 및 외벽으로 둘러싼다. 문을 막으면 개인실만 고립되어야 한다.
  홀 마루0/1·조리실6·개인실 다다미2×3 반복을 구분한다. 방석만 놓은 열린 홀을 개인실로 부르지 않는다.
  **천장 아래에는 반드시 벽이 있어야 한다.** 세로 연속 천장 덩어리의 남쪽 끝부터
  벽 몸통·하단 두 행을 둔다. 맵 남쪽 끝과 내벽 끝도 생략하지 않는다. 문 틈 위 천장을
  길게 내려놓고 바로 바닥 통로로 잇지 않는다. 벽 높이가 부족하면 끝을 올리거나 문을 옮긴다.
  `pixel-art-world-ceiling-walls.mjs`로 실제 누락을 검출한다. 외곽 천장과 출입구 좌우 끝도 필수다. `izakaya-ceiling-compiled.json`의480..526 변형과
  `paw-wall-a01` 연결 그룹을 사용한다. 천장 없는 중간 도안을 완성 실내로 복제하지 않는다.
- **새 가게:** [RETAIL-INTERIORS](RETAIL-INTERIORS.md)의 서점·아이스크림점과
  `retail-interiors-compiled.json` 전체 배열을 사용한다. 서점 벽25/33과 아이스크림 벽17/25를
  혼동하지 않는다. 직원/손님 접근과8석의 의자 뒤를 보존한다. 원본 그림은 사용자 로컬 전용이다.
- **모든 바닥형 가구:** 상체가 벽에 겹치는 것은 가능해도 밑동 전부가 벽 위에 있으면 오류다.
  객체 전체 배열과 밑동·접근칸을 읽는다. 상판/문짝을 임의로 자르거나 두 upper 객체를 덮어 지우지 않는다.
  벽걸이 장식은 별도 설치 종류다. 투명·레이어·통행은 서로 다른 속성이다.

독립 학교 방은 현재 저장된 층에서 경계를 추출한다. 북측 방은 남벽 정면3행까지,
남측 방은 북벽과 남천장을 포함한다. 모든 가구가 완전히 포함되는지 검사하며 부분 절단이면 발행을 거절한다.
원본→상대좌표 원점, 전체 두 레이어, 부품별 원점, 출입/접근 좌표와 실제 그림은 각 장소의 `room-layout` 문서에 있다.
사물함 정상/벽 위 오류 그림과 계단 정상/끊긴 벽/막힌 계단참 비교는 학교 타일셋 소유문서에 남아 있다.

## 확인 범위

이전 `scripts/qa/pixel-art-world-scenes.mts` 실행은 당시74장소를88맵으로 재현하여49,606개 레이어 칸과
학교 방 접근242곳을 확인한다. 중복 namespace·낡은 revision·외부 링크 거절 시 원본이 불변임도 확인한다.
실제 production 도구 runner는 도시/학교/교실/과학실/주택/체육관6사례를 통과했다.
현재 정본 프로젝트(공간 계층 활성화)에서 교실 생성 dry-run도 통과했다.
새 주택/이자카야2개와 수정된 이자카야는 이 모델 실험의 대상이 아니었다.
추가 작성분은 현재 엔진 충돌 판정·실제 타일 그림·정본과 공용 저장 재로드로 별도 확인한다.

실제 모델 확인은 별도 `scripts/qa/pixel-art-world-scenes-live.mts`의 결과를 사용한다.
결정론 도구 통과는 모델 성공률이 아니다. 이 경로는 **저작한 예제의 재현과 후속 편집**이며
원하는 크기/평면을 무엇이든 처음부터 설계하는 능력을 증명하지 않는다.

# 개별 소품 전체 원본·고정 조립 — 카탈로그 28

2026-09-24. chips01 직접 PNG **106개**를 실제 다운로드 CSV와 원본 SHA/디코딩/그림으로 대조했다. 전체 원본 보존 106개, 수동 픽셀 영역 550개, 고정 조립 539개, 고정점·교체 조합을 보류한 영역 11개다. 19개 원본에는 수동 영역 밖의 불투명 픽셀이 남는다. 이 수치는 카탈로그 전체 조립 완료 또는 게임 기능 구현을 뜻하지 않는다.

## 출처와 배포 경계

[제작자 소품 페이지](https://yms.main.jp/dotartworld/page3/chips01.html) · [이용 규약](https://yms.main.jp/dotartworld/page1/rule.html). 일반 게임 도구·상업 게임 사용과 수정 허용, 소재 재배포 금지, 공개 배포 게임에는 Pixel Art World / ドット絵世界 크레딧. 해당 페이지는 세트에 넣기 전 개별 소재와 변경 가능한 디자인임을 설명한다. 별도 RPG Maker 전용 표시가 있는 소재로 추정하지 않는다. 원본 전체·파생 그림은 사용자가 제공한 로컬 파일에서만 만든다. Git/public에 픽셀을 넣지 않는다.

받침은 별도 [아이스크림점 원본](https://yms.main.jp/dotartworld/page2/tile-fastfood01.html) ST-Icecream-I01.png 256×640, SHA-256 `f25b67886a656df2e1a63df8861b9a4aab8adfa27a21d6024304a12a23d8585a`. 식탁 (0,512,96,64), 바닥 (0,0,32,32), 벽 몸통 (32,96,32,32), 벽 상단 (32,64,32,32). 106개 개별 원본 수에는 포함하지 않는다.

## 실제 규격

RGBA 62개·팔레트 PNG 44개, 캔버스 치수 조합 44개. 캔버스가 32의 배수인 101개도 자동 32px 객체 시트로 취급하지 않는다. syomeisyasinki는 64×80 부스 3상태, Chandelier는 96×80 전체 걸이 그림, Olympia는 80×64 그림, SB-Spider04는 128×80 단일 거미, SI-Unko01은 **24×24 아이콘 4열×2행**이다. SB-Spider01은 256×160 단일 거미다. 크기나 파일명에서 16/32/48px 또는 애니메이션을 추정하지 않는다.

원본 참고 타일셋의 16px 칸은 전체 PNG를 손실 없이 표시하기 위한 보존용 격자다. 객체 분해 단위가 아니다. 실제 객체는 `pixelRect` 전체를 크기변경 없이 복사하고, 출력 32px 칸에 투명 여백만 추가한다. `alphaBounds`/`anchor`는 원본 사각 안 상대 픽셀 좌표다. 원본 타일 번호와 출력 atlas 번호는 다르다.

## 받침·레이어·전체 배열

출력 atlas는 8열, 첫 행의 0=바닥, 1=벽 몸통, 2=벽 상단. 수동 객체를 각 행의 x=0에 순서대로 포장한다. 물건 크기에 따라 다음 객체의 y가 달라진다. 소품 식탁은 3×3이며 원본 3×2 식탁을 (0,32)에 먼저 그린 뒤 소품 alpha 경계의 밑변 중심을 (48,55)에 합성한다. 다른 객체는 가로 중앙·세로 하단 여백만 넣는다.

고정 조립은 `structureKits`와 `tileGroups` 양쪽에 들어간다. 실제 스탬프 하위 전체는 -1, 상위는 객체 전체 배열이다. 기존 바닥/벽을 보존한다. **상위 대상 영역을 먼저 비운다.** 투명 칸도 전체 스탬프에 포함되므로 다른 상위 가구와 겹치면 덮어쓴다. 식탁 소품은 이미 상판과 합성되어 있으므로 식탁 위에 소품만 추가하는 방식으로 사용하지 않는다.

벽 장식은 기존 벽면을 받침으로 요구한다. 일반 가구는 알파가 있는 출력 칸을 보수적으로 차단한다. 문틀·나무·식물은 반투명 그림자와 여백을 제외한 마지막 완전불투명 원본 줄이 걸친 행의 불투명 칸을 차단한다. 문틀 중앙의 투명 구멍은 통과한다. 지면 그림·정적 효과·아이콘은 통과형 상위 덮개다. 상태 그림은 자동 전환·잠금문·비행·애니메이션·상호작용을 만들지 않는다.

객체별 AI 문서는 정확한 원본/출력 사각, 방향, 받침, 충돌, 정상 하위·상위 전체 배열, 한 조각 삭제와 접근 칸 침범 오류 배열/좌표, 원본 자르기 이미지 및 정상/오류 비교 이미지를 가진다. 각 kit가 자기 문서와 이미지, source/support read-first를 직접 소유한다. 표본의 외곽 한 칸은 방향별 접근을 설명하는 학습 그림이며 방/게임맵이 아니다.

## 명시적 보류

`source-only` 11영역: kingyocho 모빌 1, oinarisama 신사 교체 하부·분리 문 2 및 금줄·방울·천 3, ohaka 묘비 위/아래 교체 조각 2, Chandelier 걸이 1, BlackMagic02 샹들리에 점등 상태 2. 고정점·합성·가림 순서가 없는 이 조각은 오브젝트로 등록하지 않는다. 전체 원본과 영역 메타데이터는 볼 수 있다.

SC-Candle04는 받침 없는 제단용 불꽃 덮기 프레임 전체를 보류했다. SC-Candle03의 완전 촛대 16상태는 정적 조립으로만 등록한다. 원본 설명의 좌/우 제단 합성과 재생 타이밍은 별도 미검토다.

잔여 영역은 `loose.json`의 `holds`와 `remainingOpaqueBounds` 및 등록 `pixelRect`의 **차집합**이다. 넓은 보류 상자 안에 이미 등록된 완전 객체가 있을 수 있다. 아래 파일별 수치를 구분한다. source-only 영역은 수동 영역으로 식별됐으므로 잔여 픽셀 수에 중복 합산하지 않는다.

## 생성·일반 가져오기

`prepare-pixel-art-world-loose.mjs`는 메타데이터만 생성한다. 브라우저 `preparePixelArtWorldLoose`는 두 원본의 SHA, 크기, 실제 alphaBounds를 확인한 후 개인 메모리에서 그림·문서·객체를 만든다. UI는 기존 외부 칩셋 모달에 106개 카드로 연결된다. 일반 가져오기는 prepared의 asset/tileset/structureKits를 한 번의 undo 가능한 프로젝트 변경으로 추가하며 프로젝트 전환/취소를 감지한다.

`render-pixel-art-world-loose.mjs`는 사용자 로컬 파일을 이용해 실제 브라우저 pure prepare만 호출한다. private `output/paw-loose/browser/`에 prepared JSON, 원본별 atlas/완성 조립 이미지와 install-plan을 만든다. 네트워크 쓰기·프로젝트 import·DB 저장을 호출하지 않는다. 공용 게시와 정본 설치는 감독자가 별도로 수행한다. 임의 UUID를 공용 ID로 바꾸면 타일셋 본문, 객체 kit의 참고문서 본문에 들어 있는 tilesetId도 함께 바꾼다.

독립 검토 정정: koji1의 (32,0/32/64,32,32) 세 바리케이드는 두 다리가 있는 바닥 자립형이다. 벽 장식/통과형으로 취급하지 않으며 밑동 칸을 차단한다. koji2의 (192,64,96,96) 큰 돌더미는 입체 장애물로, 알파가 있는 3×3 출력 칸을 차단한다. 작은 지면 장식과 충돌 정책을 혼동하지 않는다.

독립 검토 정정 2: studio의 079-17은 캔버스 후면(north). 079-19/21과 20/22는 각각 오른쪽/왼쪽 가장자리가 높은 사선 보기로, 확정되지 않은 월드 동서 방위 대신 `oblique-*-edge-high`와 남쪽 접근 예제를 명시한다. skull01의 각 행은 정면/화면 오른쪽3/4/왼쪽3/4 보기(south/east/west)다. tree01과 momiji의 보라 그림자는 alpha255이므로 자동 불투명 밑동 판단을 적용하지 않는다. `blockingCells`가 있으면 최우선이며 각각 (2,7),(3,7) / (1,3),(2,3)만 차단한다.

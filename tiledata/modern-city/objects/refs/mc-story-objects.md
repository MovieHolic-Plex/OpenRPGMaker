# modern_city · 이야기 기물 5종(보관함·잔해·쪽지·기계 장치·장부)

현대 도시(도쿄풍) 칩셋 `modern_city`, 16px 칸, 시트 48열. 거리 보도와 실내 바닥 어디에나 쓰는 위층 키트다.

게임들이 바랐는데 그림이 없던 물건이다. **이 5장은 3/4 관문 미통과 — 오너 면제 그림**(면제 묶음 fable-oneshot-2026-11-12, Claude Fable 5.2 한 방 그림)이다 — 관문 영수증이 없고 스토어로는 나가지 않는다. 그림 정본 `tiledata/modern-city/objects/pieces/`, 정의 `spec.json`, 굽기 `scripts/content/modern-city-street/bake_story.py`(그림을 그대로 굽는다 — 한 화소라도 바꾸면 면제가 풀린다).

## 2. 실행 순서

1. 바닥(보도·실내 바닥)을 먼저 깐다 — 구성 도구 `compose_modern_city_street` 이 지은 맵이면 그대로 둔다.
2. `stamp_tileset_object({ mapId, objectId: "mc-prop-…", base })` — **base = 맨 아래 줄의 왼쪽 칸**(왼쪽 위가 (x,y)·높이 h 면 base = (x, y+h−1)). 조수 v2 는 `place_object({ mapId, objectId, at })`. 도구는 통째로 놓거나 거절한다.
3. 서 있는 것(보관함·기계 장치 1×2, 잔해 2×1)은 보도의 건물 쪽 줄이나 실내 벽가에 — 차도(아스팔트)·횡단보도·건물 문 앞 접근칸에는 놓지 않는다(놓기 도구가 차도 위 서 있는 기물을 거절한다). 잔해는 일부러 길을 막을 때만 통로 가운데에 둔다.
4. 바닥 그림(쪽지·장부)은 보도·실내 바닥 어디든 — 흰 타일 바닥에서는 쪽지가 묻히니 어두운 바닥에 둔다.
5. 그림일 뿐이다 — 읽기·줍기·조작은 이벤트를 따로 둔다(막힌 칸의 이벤트는 «같은 높이·결정 키», 바닥 그림은 그 칸 «플레이어 아래»).
6. 빈 땅 채우기에 흩지 않는다(키트 태그 «주제 소품») — 이야기가 부를 때만 놓는다. 조각별 자리는 키트 `placementRules`.

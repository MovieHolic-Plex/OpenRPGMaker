# 외부 공간 개선 02

비교 증거의 “성 밖 생활 장면 부재”, “외부 길 경계”, “수변에 따로 놓인 소품”을 대상으로 수정했다.

## 적용

- 작은 석성형 관리소를 확인한 Hyptosis 지붕 조각과 목재 조각으로 조립한 작은 목재 건물로 교체. 실내 전환은 없고 문 앞까지 접근 가능하다.
- 벤치2, 모닥불, 장작, 물건 상자, 화분, 끊긴 낮은 담장을 한 휴식 공간으로 묶었다.
- 주변 나무를 건물 지붕에서 비켜 배치. 지붕의 투명 하단 때문에 생긴 녹색 틈을 벽과 겹쳐 제거했다.
- 원본 풀/흙 전이 띠와 풀 조각을 외부 길 주변·뒤뜰·수목 아래에 배치. 정확한 참고의 밝은 잔디 소재를 찾았다는 의미는 아니다.
- 강 건너 벤치·석상·덤불로 작은 경관 지점을 만들고, 나루에 소품을 묶었다. 강 건너 자리는 이번에 길을 연결한 플레이 목적지가 아니라 배경 경관이다.
- 물 위에 걸친 서쪽 강안 돌무더기를 육지 방향으로 이동.

## 소재 조립 주의

`source-parts.json`에 원본 좌표·해시·마스크를 남겼다.
지붕 `(128,416,96,96)`은 Hyptosis batch3, 목재는 같은 시트 `(480,672,32,32)`.
지붕 사각형의 하단에 투명 부분이 있어 벽과 겹쳐야 한다. 단순히 h만큼 아래에서 벽을 시작하면 틈이 생긴다.
모닥불은 batch1 `(192,896,32,32)`. 배경색 두 개 `(32,29,32)`, `(48,40,48)`를 알파 제거했다.
원본이 투명한 완성 모닥불인 것처럼 기록하지 않는다. 남은 픽셀을 확대 검토했다.
길 전이 `(480,864,64,32)`는 완성된 짧은 띠이며 범용 9-slice/오토타일이 아니다.

## 남은 미달

참고보다 건물이 작고 소박하며, 녹지의 밝기·흙/풀 연결·포장 반복이 아직 다르다.
전이 띠를 몇 곳 배치한 것으로 길 전체의 자연스러운 경계를 해결했다고 하지 않는다.
강 건너 새 쉼터는 조경만 추가됐고 플레이 경로/상호작용은 없다.
이전 미달 판정과 `density-01/` 증거를 덮어쓰지 않았다.

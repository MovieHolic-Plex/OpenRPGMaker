# 입력·출력 전체 예제

20×12 맵의 지면은 모두 1145, upper는 모두 -1에서 시작합니다. 입력은 아래와 같습니다. 생략된 배열 요소가 없습니다.

```json
{
  "mapId": "forest-assembly-example",
  "x": 3,
  "y": 2,
  "width": 14,
  "height": 6
}
```

## 실행 계획
```json
{
  "stamps": [
    {
      "partId": "forest:left",
      "x": 3,
      "y": 2
    },
    {
      "partId": "forest:body",
      "x": 7,
      "y": 2,
      "fromColumn": 3,
      "columns": 3
    },
    {
      "partId": "forest:body",
      "x": 10,
      "y": 2,
      "fromColumn": 0,
      "columns": 3
    },
    {
      "partId": "forest:right",
      "x": 13,
      "y": 2
    }
  ],
  "entrances": [
    {
      "x": 10,
      "y": 9,
      "fromX": 10,
      "fromY": 10
    }
  ]
}
```

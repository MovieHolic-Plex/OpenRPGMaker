# 공용 장소: 강변 성채

사용자가 개선1의 성 밖 구역을 선호하여 셀 `(16,122,88,22)`를 개선1 저장본에서 정확히 복원했다.
추가했던 목재 건물·모닥불·낮은 담장·길 조각은 이 구역에서 제거하고 원래 석조 건물·장작·길·수목을 보존했다.
복원 구역 밖은 개선2를 유지한다. 서로 다른 합성 아틀라스의 타일 번호를 그대로 복사하지 않고 원본 셀 픽셀과 통행 메타데이터를 함께 옮겼다.

- 공용 장소 id: `river-fortress-160x144`, 이름 **강변 성채**.
- 위치: 자료집 → 맵 → 장소 → 기본 설계(또는 모두).
- 160×144 성채 전체 맵. 프로젝트 전용 library.places가 아니라 `PLACE_REFERENCES`에 등록.
- 칩셋 포함 다운로드: `public/assets/region-references/river-fortress.oprn.json`.
- 독립 원격 저장본: `oprn-place-river-fortress-v1` (저장 후 재로드 동등성 확인).
- 원본 프로젝트: `castle-fortress-city-20260921`; SQLite id `b4706a77-9a38-4dcc-a89d-36244da53967`.
- 빈 프로젝트에서 카드·미리보기·칩셋 포함 다운로드 확인: `catalog-proof.json`, `shared-place.png`.

공용 장소는 기존 제품의 읽기 전용 배치 사례 계약을 따른다. 현재 맵에 자동으로 붙여넣는 기능을 새로 추가한 것은 아니다.
다른 프로젝트에서도 확인하고 칩셋과 맵을 포함한 파일을 내려받을 수 있다.

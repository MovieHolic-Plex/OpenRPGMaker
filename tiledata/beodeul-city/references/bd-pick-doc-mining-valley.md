# 산골짜기 광산 마을 「검은재골」 (mining-valley) — 58x46 (2026-10-01 다시 짬: 사용자가 맵 구성 자체를 redo)

## 용도
북쪽 큰 산 절벽에 뚫은 갱구에서 광차 레일이 윗단 끝까지 내려오고, 갱 물은 골짜기 가운데로 흘러 남동쪽 침전 연못에 모인다.
플레이어는 남쪽 입구 → 여관·아랫동네 → 굽은 자갈길 → 윗단 비탈 → 갱구 앞마당(회관·승강 탑) 순으로 오르고, 다리를 건너 제련소로 간다.
- 이전 판이 거절된 이유: 평평한 갈색 땅에 같은 상자 집을 격자로 흩음, 네모 마당, 띠 같은 산, 타일 기와 지붕.
  → 골짜기 지형(윗단·골바닥 두 높이, 큰 마디로 꺾이는 단 절벽), 풀밭 바탕 + 밟힌 흙은 집·길 둘레에만(화소 단위로 부드럽게),
    산줄기에 전나무 숲, 나무 건물은 판자 지붕, 집은 단 끝 골목·골바닥 굽은 길을 따라 남향으로 엇갈려 앉는다.

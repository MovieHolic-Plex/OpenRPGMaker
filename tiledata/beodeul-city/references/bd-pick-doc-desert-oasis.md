# 사막 오아시스 마을 「모래샘」 — 계획 (2026-10-01 다시 짬: 사용자가 맵 구성 자체를 redo)

- 크기: 60×46칸 (16px, 1칸=1m). 입구: 남동쪽 끝 (58,44) — 카라반이 모래길로 들어온다.
- 이야기: 북쪽 사암 메사 절벽 밑 골짜기에서 샘이 솟아 개울로 흘러 오아시스 못을 이룬다. 못물은 남쪽 물길 밭으로 나뉘어 흐르고,
  대추야자 숲이 못 북·서쪽을 둘러싼다. 마을(흙집 동네)은 못 동쪽에, 카라반 길은 남동쪽에서 대상 숙소 앞을 지나 마을로 든다.
- 이전 판이 거절된 이유(사용자 redo): 네모난 못·네모 광장·격자처럼 흩어진 같은 상자 집·전역에 뿌린 선인장/바위(동전 무늬)·얇은 띠 절벽.
  → 못은 콩팥 모양 두 덩이 + 개울, 광장은 둥근 덩이, 집은 남향 거리 두 줄에 벽을 맞대고, 소품은 목적 있는 덩이로만, 절벽은 3칸 지층 벽.

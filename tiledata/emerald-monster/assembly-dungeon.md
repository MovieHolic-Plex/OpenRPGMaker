# Emerald 원본 도트 조립 계약

7종의 신규 atlas는 16px, 16열이며 원본 monster-kit의 번호·통행·홈층·오토타일·구조 킷을 그대로 공유합니다. 기존 저작 원본은 유지합니다.

## 순서
1. 이 안내 → 해당 `emerald-monster-dungeon-dict` 칸 사전 → `-kits` 전체 lower/upper 배열 → `-ex-*` 전체 맵 배열과 실제 새 atlas 그림을 읽습니다. 번호는 0기준, 픽셀은 x=(n%16)*16,y=floor(n/16)*16입니다.
2. lower 바닥 → 그룹 full을 칠해 47이웃 변형 → 킷 lower/upper 배열 순서입니다. -1은 비움이며 투명 upper 아래에는 실제 바닥을 둡니다. 층·alpha·통행은 서로 다른 속성입니다.
3. 문칸에 전이 이벤트, 문 아래 접근칸은 비웁니다. 센터·마트 입구폭을 그대로 유지합니다. 숲은 2×2 반복 수관과 최하단 줄기, 절벽은 윗면+남쪽 두줄 앞면과 2×2계단입니다. 임의로 줄기를 생략하거나 한줄 절벽을 걷는 땅으로 바꾸지 않습니다.
4. 해안의 shore/quay 연결과 낮은쪽 갓돌, 용암 비물지형, 눈의 미끄럼·정지바위, 회전 장치와 전기벽을 원본 사전 그대로 적용합니다. 연구소 시작탁자와 리그 복도를 장식으로 막지 않습니다.

## 실제 변경
좌표 레시피 `emerald_monster.py`가 잔디를 넓고 드문 덩이로, 물을 4프레임 짧은 수평 물결로, 수관을 큰 잎 덩이로, 지붕을 두 면과 넓은 엇갈린 기와로 그립니다. 한 장 전체에 색 필터를 씌우지 않습니다. 사막/눈/회황 재/적주황 용암과 청회 연구소·4리그 테마를 구분합니다.

## 정상/오류와 한계
뒤 용도의 각 정상 예제는 실제 새 atlas로 전체 배열을 렌더했습니다. 정상/오류 진단쌍의 오류 그림은 현재 정본 원본색 그대로 유지하며 동일 통행표의 막힌 문·끊긴 다리·잘못된 얼음 정지바위를 보여줍니다. 새 atlas의 구조/번호 보존은 자동 대조했지만 이벤트 실행이나 미적 동등성을 보증하지 않습니다. 드래곤관·일부 체육관/FRLG 실내 구조는 기존 게임 고유 구성으로, Emerald 지도 복사본은 아닙니다.

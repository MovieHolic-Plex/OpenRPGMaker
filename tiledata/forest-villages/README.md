# 숲과 마을 — 다음 에이전트를 위한 저작 자료

이 자료는 이 작업에서 사용자가 직접 고친 배치와 반복 검수 결과를 정리한다. **먼저 승인본 이미지를 보고, 그 맵의 타일 배열과 메타데이터를 함께 읽는다.** 타일 번호만 다른 칩셋에 대입하지 않는다.

## 읽는 순서

1. [핵심 배치 규칙](PLACEMENT.md) — 16px, 13칸 수관, 줄기, 절벽, 길, 다리.
2. [검수와 실패 사례](ACCEPTANCE.md) — 승인/금지 소품, 잘못된 판단, 실제 검수 순서.
3. [승인본 목록](references.json) — 13개 공용 장소의 맵·칩셋·이미지·원격 스냅샷 위치.
4. [실행과 저장](WORKFLOW.md) — 실제 에디터 저작, 로컬/원격 저장, 그림 캡처.
5. [마을 10종](villages/README.md) — 이번에 새로 만든 서로 다른 구성과 전체 이미지.

## 먼저 기억할 것

- 1칸은 16×16px. RPG Maker 2000 원본 칩셋은 480×256px(30×16칸). 479×255로 잘린 이미지는 정규 시트로 취급하지 않는다.
- `1617`(굽이숲 수관 2568)은 **나뭇잎 내부**다. 그 면을 큰 덩어리로 깔고 열린 공간 쪽을 향하는 외곽·안쪽 모서리를 붙인다. 2026-09-24부터 이 내부는 검은 판이 아니라 가장자리와 같은 잎으로 채워져 있고, 속 칸은 깊이별 변형(얕은 속·깊은 속 각 6칸)을 쓴다 — [수관 잎 채움](canopy-leaves/README.md).
- 남향 나뭇잎 아래 줄기는 필수다. 승인 조립의 첫 줄은 수관 외곽과 **같은 행**, 뿌리까지 3행이다.
- 숲은 벽 같은 ㅡ자 띠 여러 개보다 큰 연속 덩어리와 빈터·오솔길로 구성한다.
- `defaultLayer`(저작 위치), `priority`(★/통행), 받침 타일은 별도 계약이다.
- 승인본의 빈터, 뿌리·줄기, 집 전체 발자국을 보존한다. 검수하지 않은 수동 픽셀 보간·그림자로 이음새를 숨기지 않는다.

## 자료의 범위

원본 프로젝트는 `oprn-hill-forest-harmony-20260918-a4e1`이다. 이전 완성 맵 13개는 PR #1052로 공용 장소에 등록했다. 비교용 맵 6개는 공용 장소에서 제외했다. “등록됨”은 새로운 미술 품질 승인을 의미하지 않는다. 원본 출처는 [ATTRIBUTION](../../public/assets/ATTRIBUTION.md)을 따른다.

이 기록의 수학적 규칙은 이 타일셋에서 실제 연결·통행을 확인하기 위한 것이다. 논문의 최신성이나 모든 타일셋에 대한 보편적 최적해를 주장하지 않는다.

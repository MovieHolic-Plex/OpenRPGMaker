# 배치 규칙

## 픽셀과 칩 좌표

`i = y × tilesPerRow + x`. 30열 칩셋에서 원본 사각형은 `(16(i mod 30), 16 floor(i/30), 16, 16)`이다. 확장 아틀라스는 높이가 달라질 수 있으므로 480×256을 강제로 재적용하지 않는다. 타일 크기·열 수·아틀라스 해시를 먼저 확인한다. 오브젝트는 여러 칸을 사용해도 된다. 발자국 너비·높이는 16의 정수배이며 가장자리 픽셀과 원근 기준이 승인본과 맞아야 한다.

## 수관: 3×3 + 안쪽 모서리 4칸

사용자가 설명한 986/987/988, 1016/1017/1018, 1046/1047/1048의 3×3 조합은 **그 당시 시트 좌표**다. 현재 확장본에서는 `forest_harmony_canopy_47` 그룹을 조회한다. 9개 기본 조각과 4개 안쪽 모서리로 표현하고, 1×1·3×1 등 좁은 형태는 8×8 쿼터 조합에서 파생한다. 이미지가 비슷하다는 이유로 독립 칩을 계속 추가하지 않는다.

8방향 이웃 마스크 → `autotileVariantForMask`로 47가지 유효 연결을 결정한다. 대각 이웃은 직교 두 이웃과 함께 판단한다. 검은 중앙 면을 포함한 수관 마스크가 먼저이고, 외곽은 마스크와 빈터 사이에만 생긴다. 외곽 방향을 뒤집으면 숲이 빈터가 아니라 바깥을 향해 벌어진다.

```
###########   # = 검은 수관 내부
###┌───┐###   외곽은 가운데의 열린 공간을 향한다
###│ 집│###
###└ 길┘###   남향 노출 외곽에는 온전한 줄기 조립
###########
```

## 줄기와 뿌리

`complex-forest-plan.mjs::trunkPlan`이 사용자가 수정한 `map_forest_cabin_autotile`에서 좌·우 캡과 반복 2열을 읽는다. 반복 2열의 3행은 현재 `[1425,1350]`, `[1429,1428]`, `[1433,1432]`다. 숫자와 원본 행이 다르면 자동 진행을 멈추고 새 기준을 확인한다.

남향 노출 조건은 `forest(x,y) && !forest(x,y+1)`이다. 이 행부터 3행 전체를 깐다. 좌우 끝의 3/4열 캡, 가운데 2열 반복을 조합한다. 끝 캡이 들어가지 않는 짧은 돌출부는 **수관 마스크 형태를 수정**한다. 뿌리를 자르거나 가운데를 비워 폭만 맞추지 않는다. 초기 Dark tree 2×4는 2×2 두 묶음(한 묶음은 오토타일용)이었으므로 하나의 독립 나무로 분류하면 안 된다.

## 숲의 형태

타원 빈터의 내부 판정은 `((x-cx)/rx)^2 + ((y-cy)/ry)^2 < 1`이다. 빈터와 통로 거리장을 합친 뒤 숲을 그 여집합으로 둔다. 2열×3행 단위 샘플링은 승인 캡·뿌리 조립에 맞는 실용 제약이다. 약한 결정론적 요철을 더해도 통로 폭과 집 발자국을 우선 보존한다.

집·샘·입구를 그래프 정점으로 두고 필요한 연결을 먼저 정한다. 연결 그래프에서 순환 수는 `E−V+1`이다. 모든 마을을 십자 길로 만들지 말고, 고리·사슬·두 덩어리 연결·가지 길 등 서로 다른 그래프를 사용한다. 최종 통행은 그림이나 그래프만으로 판정하지 않고 엔진 `canMove`로 BFS한다.

## 절벽

`forest_high_cliff_river` 기준: 뒤 윤곽 504·505·559, 옆 588·590, 전면 윗선 618·619·620, 면 651·652·653, 아랫선 681·682·683. 대각 윗선 498·499, 면 711·712, 아랫선 528·529. 아랫선은 같은 x의 윗선에 높이를 더해 계산한다. 대각 하강 구간의 한 행 오프셋도 함께 적용한다.

집 전체가 정상 대지 안에 있어야 한다. 계단 854는 전면 윗선부터 아랫선까지 연속으로 놓고, 위·아래 착지 지점을 길에 연결한다. 큰 절벽은 단순한 두꺼운 갈색 직사각형 대신 수평과 대각 윤곽을 섞고 높이를 바꾼다. 과도하게 긴 다리와 노출된 잔디는 높이감을 약하게 만들 수 있다. 솔바람 협곡은 보존된 사례지만 사용자가 어색하다고 지적했음을 기억한다.

## 물·길·다리

길 `forest_harmony_road_47` seed 1516, 물 `forest_harmony_lake_47` seed 1563, 짙은 풀 70, 긴 풀 304. 모두 그룹을 확인한 후 엔진으로 연결한다. 복사된 직사각형 길을 최종 결과로 두지 않는다.

물은 다리 밑까지 하위 레이어에서 이어진다. 판자 171·172·173은 현재 전용 칩셋에서 `userLocked: true`, `defaultLayer: upper`, `priority: lower`, 통행 O다. 물 위 다리는 상판을 없애면 강 건너편이 끊겨야 한다. 난간 바깥으로 빠지지 않아야 한다. 절벽 접근로를 열다가 아래 평면을 통한 우회로를 만들지 않는다.

`paintTilesBulk(..., {preservePattern:true})`도 타일의 홈 레이어를 따른다. 요청한 layer만 믿으면 판자가 하위로 내려가 물을 덮는다.

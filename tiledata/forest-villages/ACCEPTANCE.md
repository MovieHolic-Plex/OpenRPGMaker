# 검수 기준과 실패 기록

## 소품

원본 RM 계열과 같은 위에서 내려다보는 전면 중심의 시점을 지킨다. 윗면·앞면이 읽히되 좌우 면을 과도하게 비틀어 등각 투영으로 바꾸지 않는다. 픽셀 윤곽은 끊기지 않고, 큰 색 덩어리와 음영 군집이 먼저 읽혀야 한다. 흐릿한 축소나 한 픽셀 점무늬의 과밀함을 디테일로 평가하지 않는다.

생성은 **한 번에 오브젝트 하나**. 원본 시트에서 실제 오브젝트를 잘라 레퍼런스로 제공한다. 복수 오브젝트를 한 판에 생성한 뒤 자르는 방식은 원근·배율·픽셀 규칙이 흔들렸다. 검수 시 원본과 같은 타일 배율에서 나란히 보고, 원본 크기와 정수배 확대를 모두 확인한다.

새 생성/변형 에셋의 최종 검수는 사용자가 지정한 **GPT-6 Astra 서브에이전트**가 맡아야 한다. 이 지시는 새 에셋 검수에 해당하며, 기존 승인 타일로 맵을 배치하는 작업에 새 에셋 생성을 요구하지 않는다. 사용자 최종 검수가 우선이다. Tibo 사용법은 기존 생성 스크립트와 사용자 노션을 실제로 읽고 실행해야 하며, 사용하지 않았는데 사용했다고 말하지 않는다.

## 금지했던 오브젝트

물통/물통 급수대, 장작 보관대, 꽃 수레, 버섯과 통나무 묶음, 종, 여관 앞 벤치, 가마, 잘못된 적재 상자·수레, 실패한 벌통·도구걸이 등은 재사용하지 않는다. 정확한 이력은 `scripts/asset-gen/village-prop-banlist.json` 및 `openwiki/village-prop-visual-acceptance.md`와 대조한다. 금지 이미지를 새 이름으로 돌려 넣지 않는다.

현재 재사용 후보는 낮은 돌우물, 정원 아치, 매다는 등, 낚시 바구니, 돌 디딤판, 허수아비, 씨앗 자루, 석등, 새집, 약초 화분, 과일 바구니 및 원본 꽃상자·빨랫줄·게시판·작은 울타리다. 실제 그룹의 `previewMap` 전체를 복사한다.

## 반복해서 틀렸던 점

| 실패 | 올바른 대응 |
|---|---|
| 검은 숲 내부를 잘못된 그림자로 판단 | 생략된 수관 내부로 보존 |
| 잎 외곽 방향이 반대 | 빈터 방향과 수관 마스크를 대조 |
| 2×4를 한 나무로 처리 | 2×2 두 묶음과 오토타일 역할 분리 |
| 줄기가 한 칸 아래에서 시작 | 남향 수관과 같은 행부터 3행 배치 |
| 가로 반복 중간이 잘리거나 비어 보임 | 온전한 반복 2열과 좌우 캡을 연결 |
| 짙은 사각 그림자로 이음새를 가림 | 실제 캡과 잎 경계를 수정 |
| 모든 숲을 ㅡ자로 배치 | 큰 수관 덩어리, 빈터, 비직선 통로 |
| 절벽 위 잔디와 기본 바닥이 다름 | 승인된 합본 마을/레트로 월드맵 조합 보존 |
| 불필요한 중복 칩 대량 추가 | 기본 조각·쿼터·그룹을 재사용 |
| 스크린샷 없이 “좋다” 평가 | 전 구역을 실제 이미지로 확인 |

## 맵마다 확인

1. 전체 이미지: 숲의 연속성, 집/길/물의 의미, 빈 공간과 소품의 균형.
2. 정수배 확대: 수관의 볼록·오목 모서리, 줄기 양끝과 뿌리, 집의 지붕·벽·문 전체.
3. 엔진 판정: 출입구와 모든 집 앞 도달, 물/벽 누출, 다리의 필요성, 계단 위·아래 연결.
4. 오토타일 마스크와 실제 변형의 일치. 줄기 원본 3행의 일치.
5. 원격 저장 후 다시 load. 로컬 파일만으로 완료를 선언하지 않는다.
6. 이전 승인본·사용자 수정을 덮어쓰지 않았는지 확인.

이전 13종은 보존/참고용이다. 새 10종은 이번 생성 결과이며 사용자의 추가 검수 전이다.

## 10종 검수에서 확인한 추가 실패

길 A*가 계단을 통과할 수 있다는 사실과 계단을 길 타일로 대체해도 된다는 것은 다르다. `854` 계단은 통과 경로에 포함하되 도로 페인트에서 제외한다. 높은 절벽에서 길이 수직 모래 띠로 보이면 먼저 계단 원본 열이 덮였는지 확인한다. 10종 중 층층 정원·바람등성이에서 이를 발견해 계단 전폭을 복원했다. 수정 후 도로 오토타일·집 앞·출구 도달성을 다시 확인한다.

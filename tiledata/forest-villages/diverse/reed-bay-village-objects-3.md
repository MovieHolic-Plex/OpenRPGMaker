# 실제 소품의 완전한 두 레이어 배열

각 항목 (x,y,w,h)는 맵 절대 좌표다. 하위는 정답 바닥 포함. upper=-1은 빈 칸이다. 다른 곳에 상위 소품만 복제할 때 하위 바닥은 유지한다.
## 계류 말뚝
```json
{
  "name": "계류 말뚝",
  "x": 62,
  "y": 41,
  "w": 1,
  "h": 1,
  "kind": "harbor-prop",
  "owner": "dock",
  "upper": [
    2717
  ],
  "width": 1,
  "height": 1,
  "lowerTiles": [
    [
      1563
    ]
  ],
  "upperTiles": [
    [
      2717
    ]
  ]
}
```

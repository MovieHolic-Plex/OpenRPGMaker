# 조선 실내 — 방별 계획 (민가·상점·관아 6장)

원칙(사용자 격언): **공간이 남으면 방이 너무 큰 것이다.** 방은 용도에 맞게 줄이고, 잔소품은 앵커 곁에만 둔다.
구조 문법: 북벽 아래 벽면 2줄(위 줄 창방 띠 + 아래 줄), 칸막이는 고체 칸 + 2줄 벽면, **두꺼운 벽 통로는 3줄**(벽면 2 + 바닥 1),
ㅁ자 한 칸 방 금지(ㄱ·알코브·칸막이·상부 단), 계단은 북벽에 3칸 폭. 남벽은 천장 띠만 보이고 출입구는 남벽 한 칸(출구 이벤트 자리).
시점: 정면-위 3/4, 빛 왼쪽 위. 모든 조각 접두 `in_`, 조선 팔레트 91색 잠금.

공통 키트(조립식, 크기·모양을 바꿔 다시 조립): 바닥 6(온돌 장판·마루·흙바닥·돌바닥·전돌 + 이음/그늘 변형), 천장 블롭 47(창방 띠),
벽면 1×2 (회벽·목재·황토·돌·창호 × m/l/r/lr), 창·미닫이문 변형, 기둥·들보, 문턱·출구, 계단·단(壇).
`demo_interior.py` 의 `build_room(plan, ...)` 이 평면도 문자열에서 벽면·천장·바닥 그늘을 자동 유도한다(손으로 벽을 칠하지 않는다).
나중에 「궁 내부」(정전·어좌·회랑)가 같은 키트로 크기만 키워 올라간다.

## 1. joseon_in_house — 온돌 민가 (14×12)
- 이야기: 사는 살림집 한 채. 안방(온돌, 이불장·반닫이·병풍)이 북서, 대청 마루(뒤주·평상)가 북동 가운데, 부엌(흙바닥, 부뚜막·솥·독)이 남서.
- 앵커: 안방=병풍+이불장(북벽), 마루=쌀뒤주+베틀, 부엌=부뚜막. 곁들이: 상·방석·등잔·화로.
- 동선: 남벽 출입구(마루 앞 현관) → 마루 → 안방 문(칸막이 3줄 통로) / 부엌 문.
- 문: 남벽 x=7 (마루 남쪽).

## 2. joseon_in_inn — 주막 내부 (22×16)
- 이야기: 길손이 앉아 술·국밥을 먹는 큰 마루방. 북서 부엌(부뚜막·솥·독·술독), 북벽 중앙 주모 카운터(술독+선반), 가운데 평상 둘+상, 동쪽 방 둘(손님방, 칸막이).
- 앵커: 주모 상(카운터)·부뚜막. 곁들이: 술독, 상 위 술병, 방석, 등잔.
- 동선: 남벽 출입구 → 평상 사이 통로 → 카운터 앞 / 동쪽 방 문.
- 문: 남벽 x=10.

## 3. joseon_in_smith — 대장간 (16×12)
- 이야기: 흙바닥 작업장. 북벽 가운데 화덕(풀무 붙임), 모루·담금물통 앞, 연장 걸이, 숯더미 곁, 남쪽 판매 상. 돌벽.
- 앵커: 화덕. 곁들이: 모루, 숯, 담금 통, 연장대, 쇳덩이.
- 동선: 남벽 출입구 → 판매 상 옆 → 화덕 앞 작업 칸(모루–화덕–물통 삼각).
- 문: 남벽 x=8.

## 4. joseon_in_pharmacy — 약방 (14×10)
- 이야기: 마루방 약방. 북벽 약장(2칸) + 선반, 약연·약탕관 화로, 진료 상(방석 둘), 약초 말리는 횃대.
- 앵커: 약장. 곁들이: 약연, 약탕관, 약초 걸이.
- 동선: 남벽 출입구 → 진료 상 앞 → 약장.
- 문: 남벽 x=7.

## 5. joseon_in_school — 서당 (18×12)
- 이야기: 훈장님 자리(북, 단 위, 서가·병풍) 앞에 학동 책상이 두 줄. 창호 벽면.
- 앵커: 훈장 단(壇)+책상+서가. 곁들이: 회초리 통, 방석, 족자.
- 동선: 남벽 출입구 → 가운데 통로 → 훈장 단 앞.
- 문: 남벽 x=9.

## 6. joseon_in_office — 관아 동헌 (24×18)
- 이야기: 북쪽 높은 단(壇) 위 원님 자리(병풍·책상·북), 전돌 바닥의 넓은 마당 마루, 양옆 형틀·곤장 틀과 서리 책상. 단은 3칸 계단으로 오른다.
- 앵커: 원님 단(병풍+책상). 곁들이: 북, 형틀, 서리 책상, 등잔·촛대.
- 동선: 남벽 출입구 → 중앙 통로 → 단 앞 계단.
- 문: 남벽 x=12 (두 칸 폭).

## 자동 점검 (`interior_checks.py`)
출입구 앞 칸 BFS 도달 · 기물이 입구/통로를 막지 않음(기물 칸을 막힘으로 보고 모든 용도 칸 도달) · 같은 기물 셋 일렬 금지 ·
천장 밑 벽 규칙(벽면 2줄·통로 3줄) · 맨바닥 10칸 이상 연속 금지(가로·세로).

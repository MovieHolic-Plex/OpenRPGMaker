# monster — 몬스터 수집 (19장, problems 0, 새 색 8)

- capital 대도시: 적백 라디오 타워·흰 고층 백화점·주황 지붕 체육관(문장)·회복소·사무동·광장 분수·집·나무.
- fort_city 체육관 도시: 가운데 초록 지붕 큰 체육관(몬스터 볼 문장) + 집 다섯 + 흰 울타리(앞 길 비움).
- harbor_city 항구 도시: 창고 둘·회복소·상점·컨테이너 + 앞 부두·여객선 + 방파제 끝 등대.
- castle 리그 본부: 계단식 돌 기단 + 흰 기둥 석조 본관 + 파란 우진각 지붕·금 문장 + 큰 계단 + 깃발 둘.
- large_town 회복소 마을: 견본 그대로.
- large_town_b 농장 마을: 붉은 헛간·흰 날개 풍차·파란 지붕 살림집·목장 울타리·건초.
- village 시작 마을: 견본 그대로.
- village_b 숲속 오두막: 통나무 오두막 둘(초록·빨강 지붕) + 침엽수 셋 + 굴뚝 돌.
- camp 캠핑장: 파랑·주황 A자 천막 + 안내 간판 + 돌 두른 모닥불.
- tower_small 등대: 바위 위 적백 등대·불 켜진 등실.
- tower_great 방울탑: 돌 기단 위 오층 목탑(붉은 기둥·기와 처마) + 금 방울.
- cave 달맞이산 동굴: 현무암 바위산 + 아치 입구 + 사다리 + 달 바위.
- ruin 알프 유적: 계단식 돌 기단 + 기호 새긴 석판 셋.
- ruin_city 버려진 발전소: 녹슨 톱날 지붕 공장(깨진 창·구멍)·굴뚝 둘·녹슨 탱크·무너진 사무동·송전 철탑.
- shrine 전설 사당: 둥근 돌 단 + 제단(파란 구슬) + 기둥 원 + 뒤 신목(금줄) + 앞 계단.
- landmark_nature 열매 거목: 굵은 줄기·뿌리 + 수관 다섯 덩이 + 빨강·파랑 열매.
- circle 바위 원: 둥근 큰 돌 넷 + 가운데 납작돌.
- volcano 불꽃섬 화산: 잘린 현무암 화산·용암 화구·줄기·연기 + 기슭 연구소.
- floating 하늘 기둥 섬: 구름 위 바위섬 + 옥색 층진 돌탑 + 침엽수.

## 남은 아쉬움
- shrine: 기둥이 가늘고 단색이라 1배에서 제단·기둥 원이 덜 또렷하다.
- harbor_city: 부두 널판이 넓어 배와 겹치고, 물이 없어 「항구」는 배·등대에만 기댄다.
- circle: 둥근 돌 넷이 회색 덩어리라 다른 세트의 바위와 구별이 약하다.
- 체육관 문장(몬스터 볼)은 4~5px 라 1배에서는 빨강·흰 점으로만 읽힌다.

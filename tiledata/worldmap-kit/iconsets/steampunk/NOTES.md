# steampunk — 스팀펑크·마도 (20장, problems 0, 새 색 14)

재질: brass(놋쇠, 새 4) · soot(검댕 벽돌, 새 3) · magi/magiglow(마석 보라, 새 4) · copper·iron·canvas·coal 은 World 색. modsf_kit glass(유리 돔)에서 3색.
도구: hcyl_x(누운 원통: 보일러·관·포신), disc_y(앞을 보는 원판), gear(톱니), clock(시계판), plates(리벳 철판), chimney(굴뚝+증기), CEllip(땅 아래를 자른 타원체), _lift(섬 위로 올리기).
키 큰 가는 부품(굴뚝·시계탑 윗단·계류탑·비행선)은 role='nocast' — 원래 해 각도면 그림자가 칸 밖으로 20px 넘게 나간다.

- capital: 왼쪽 뒤 시계탑(구리 돔), 뒤 톱날 공장과 굴뚝 둘, 오른쪽 철골 정박탑에 묶인 비행선, 가운데 구리 돔 관청, 앞 리벳 철판 성벽·톱니 문·원뿔 지붕 포탑.
- fort_city: 톱날 지붕 벽돌 공장 셋, 굴뚝 넷, 녹슨 가스 탱크, 구리 증기관, 앞 벽돌 담과 철문(톱니 문장).
- harbor_city: 외륜 증기선(빨간 굴뚝 둘·흰 선실·나무 외륜), 나무 부두, 놋쇠 데릭 크레인, 벽돌 창고 셋.
- castle: 리벳 철판 성벽, 둥근 포탑 둘(대포), 톱니 문장 철문, 굴뚝 달린 본루.
- castle_b(변형): 철골 계류탑 + 묶인 비행선 + 녹슨 반원통 격납고 + 철책·초소.
- large_town: 바위 언덕 갱도 입구, 권양탑(놋쇠 바퀴), 광차 레일, 함석 오두막 셋, 등불.
- village: 시계 단 벽돌 역사, 놋쇠 기둥 승강장 차양, 앞 선로의 작은 증기 기관차(빨간 운전실).
- village_b(변형): 벽돌 풍차(놋쇠 날개) + 톱니 단 공방과 굴뚝 + 오두막.
- camp: 범포 천막 둘, 증기 기관 발전기(구리 보일러·플라이휠·굴뚝), 상자·깃발.
- tower_small: 놋쇠 띠 벽돌 굴뚝탑 + 철판 받침 + 증기.
- tower_great: 3단 벽돌 시계탑, 큰 시계판, 톱니 둘, 구리 돔과 첨탑.
- cave: 팔각 바위산 + 버팀목 갱도 + 레일·광차·등불.
- ruin: 주저앉은 기낭(놋쇠 이음) + 뼈대만 남은 갈비뼈 아치 + 빨간 꼬리 날개 + 부서진 곤돌라·불씨·검은 연기.
- ruin_city: 윗면이 부서진 공장 둘, 꺾인 굴뚝 밑동, 쓰러진 굴뚝, 꺾인 구리관, 터져 나온 마석 결정, 잔해.
- shrine: 마도 연구소 — 벽돌 연구동 + 놋쇠 리브 유리 돔(속에 마석 빛) + 테슬라 코일 둘.
- landmark_nature: 회색 바위산 비탈에 반쯤 묻힌 거대 구리 톱니 + 꺾인 관.
- landmark_magi(변형): 바위 언덕을 뚫은 보랏빛 마석 결정 무리.
- circle: 철판·놋쇠 원판 위 마석 기둥 다섯 + 가운데 떠 있는 마석.
- volcano: 현무암 화산, 화구 용암빛, 구리 관 셋과 증기, 비탈 펌프 오두막.
- floating: 거꾸로 선 바위섬 + 밑 마석 부유석 + 양끝 프로펠러 붐 + 위 공장·집·시계탑(그림자 없음).

## 남은 아쉬움
- village·camp·ruin 은 높이 채움 70% 안팎(납작한 내용). 1배에서 village 는 기관차와 역사가 겹쳐 조금 복잡하다.
- floating 프로펠러가 노처럼 보인다(앞을 보는 날개 두 개만).
- 증기(modsf steam)는 밝은 하늘색 덩이라 1배에서 「연기」보다 「얼음」에 가깝게 읽힐 수 있다.
- 원뿔대(Frustum)에는 벽돌 결이 안 먹어서 tower_small·풍차 몸통은 띠·창으로만 결을 냈다.
- 비행선(capital·castle_b)은 모양이 같다 — 크기만 다르다.

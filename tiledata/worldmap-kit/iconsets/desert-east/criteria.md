# 사막·동양풍 — 3/4 기준과 「이게 뭐로 보이나」 판정

## 기준과 보장 방식

| # | 기준 | 어떻게 보장하나 |
|---|---|---|
| 1 | 윗면이 보인다 (지붕은 위에서 내려다본 경사면, 탑 꼭대기·처마는 윗면 띠) | `lib/oblique.py` 가 화면 픽셀마다 광선을 쏴 입체와 교차시킨다. 투영 `u = x + .28y, v = z + .5y` 이라 뒤로 갈수록 위·오른쪽으로 밀리고, 보이는 면은 윗면·앞면·오른쪽면뿐이다. 지붕 면은 입체(우진각·팔각뿔)의 기울어진 평면이라 정면 박공 한 장이 나올 수 없다. |
| 2 | 윗면 밝음 / 앞면 중간 / 오른쪽면 어둠, 빛은 왼쪽 위 | 면 법선과 광원 `L=(-.5,-.35,.8)` 의 내적으로 자동 결정 |
| 3 | 밑변 발자국 + 오른쪽 아래 그림자(키 색) | 지면 점에서 광원 쪽으로 쏜 광선이 입체에 닿는지로 정해 키 색(254,103,139)을 칠한다 |
| 4 | 지도 1배(16px 칸)에서 읽힌다 | `preview/ctx-*-1x.png` 와 8배 카탈로그를 같이 본다 |

면별 픽셀 수는 `stats.md`. 새 색 0개(전부 원본 월드 칩셋 색), `sheet-check.json`.

### 1라운드 (처음 그린 것) — 발견한 ✗

- tower_small: 어두운 회색 덩어리 더미로 읽혀 탑이 안 보임 ✗ (기와 색이 몸통과 같은 계열이라 층 구분이 안 됨)
- large_town: 회색 모자 여섯 개가 한 덩어리로 겹쳐 「기와 장벽」처럼 보임 ✗ (앞줄 지붕이 뒷줄 벽을 가림)
- camp_b: 갈색 건초 더미/피라미드 ✗ (원뿔이 너무 낮고 문이 없음)
- volcano: 위가 잘려 산 반쪽 ✗ → 캔버스 밖으로 나감
- harbor_city: 돛이 흰 계단/경사로로 읽힘 ✗
- large_town_b: 파란 덧창과 문이 사람 얼굴처럼 보임 ✗ ("귀여운 얼굴 상자")
- fort_city·castle_b·ruin_city: 오른쪽/왼쪽 탑이 캔버스 밖으로 잘림 ✗

## 지도 맥락 (원본 월드 칩셋 풀밭·사막 위, `preview/ctx-*-2x.png`)

- 풀밭 위(ctx-grass): 기와 대사원·기와집 마을·탑·게르·석굴이 한 동아시아 문화권으로 읽힌다. 청회 기와와 옥색 기와 두 가지, 붉은 기둥이 공통 모티프다.
- 사막 위(ctx-sand): 흙집·돔·초가·천막·바오바브가 사막 대상로 마을로 읽힌다.
- 섞임(ctx-mix, ctx-coast, ctx-all): 동양 성벽 도시(청회)와 사막 천막이 한 지도에 있어도 문화권이 구분된다. 월드 칩셋 풀밭의 채도와 아이콘 색이 어긋나지 않는다(전부 원본 칩셋 색).
- 한계: 원본 월드 칩셋 풀 칸은 질감이 거칠어 아이콘이 상대적으로 깔끔하게 보인다. 아이콘 윤곽선은 칩셋 나무와 같은 어두운 테를 쓴다.

# alien — 외계 행성 (19장, problems 0, 새 색 20/24)

새 재질: purp(보라 식물 5색) · crys(청록 수정, 새 3 + 눈색) · pink(생물 발광 1) · orock(주황 바위, World 색만) · chitin · pale · ice · basalt2.
modsf_kit 의 강철·유리·네온·켜진 창·산업 주황(11색)도 쓴다.

- capital 이주민 돔 도시: 가운데 큰 유리 돔(패널 줄·첨탑), 왼쪽 뒤 관측탑, 오른쪽 작은 유리 돔·흰 돔·접시, 앞 왼쪽 팔각 착륙장+착륙선, 거주동, 보라 식물·수정.
- fort_city 방어 기지: 콘크리트 방벽(철조망)·경고띠 강철 문·네 귀 원통 포탑(포신·표지등)·유리 돔·마스트 건물·접시.
- harbor_city 우주항: 주황 발사탑과 적백 로켓(날개), 흰 연료 탱크 둘, 격납고(반원통), 착륙장 둘에 흰·주황 착륙선, 안테나.
- castle 여왕 둥지: 낮은 키틴 언덕 위 휘어진 첨탑 7개, 발광 끝 곁가지, 점박이 알주머니, 분홍 발광 입구.
- castle_b 군 전초기지: 감시탑(왼쪽)·창 격자 사령동·앞 방벽과 강철 문·모래주머니·접시·주황 깃발·보급 상자.
- large_town 버섯 마을: 보라·주황 갓 버섯 집 셋(문·불빛 창·갓 반점), 작은 버섯 둘, 발광 식물.
- village 캡슐 마을: 누운 반원통 캡슐 셋(창 띠·띠색)·급수탑·식물.
- village_b 수정 마을: 주황 바위 둥근 움집 셋(어두운 입구) + 지붕 수정 다발.
- camp 조사 캠프: 주황·흰 돔 텐트, 6륜 탐사차(조종석 유리·안테나), 작은 접시, 노란 상자.
- tower_small 통신 안테나: 주황 줄 원뿔대 탑 + 접시 + 표지등.
- tower_great 고대 오벨리스크: 주황 바위 계단 기단 + 청록 문양이 빛나는 검은 첨탑 + 꼭대기 수정, 발치 빛 구슬. (윗부분은 그림자 제외 — 칸 안에 맞추려고)
- cave 수정 동굴: 주황 바위 언덕의 아치 입구(속은 짙은 청록) + 입구 둘레·꼭대기 수정.
- ruin 추락한 우주선: 기울어 박힌 강철 선체·흰 조종석·꺾인 날개·꼬리 지느러미·주황 띠·연기·파편.
- ruin_city 고대 문명 유적: 계단 단 위 서로 휘어 만나는 아치(꼭대기 수정), 휘어진 기둥 열(일부 부러짐), 쓰러진 토막, 문양 판.
- shrine 외계 신전: 흰 돌 계단 기단 + 검은 단 + 수정 기둥, 세운 청록·네온 고리 둘과 누운 분홍 고리, 가운데 분홍 빛 구슬, 양옆 검은 첨석.
- landmark_nature 촉수 나무: 뿌리 촉수가 퍼진 줄기 + 위로 솟아 말린 촉수 가지 부채 + 발광 끝.
- circle 공명석 원: 바닥에서 떠 있는 검은 수정 돌 7개(끝 빛) + 바닥 빛 고리 + 가운데 수정.
- volcano 얼음 화산: 현무암 밑동 + 청록 줄 얼음 원뿔 + 꼭대기 청록 분출.
- floating 중력 이상 부유섬: 거꾸로 선 주황 바위섬(보라 숲·관측 돔·안테나·수정) + 떠도는 조각 넷. 전부 그림자 없음(떠 있음 표현 겸 칸 맞춤).

## 남은 아쉬움
- ruin: 선체가 1배에서 대포·통처럼 읽힐 수 있다. 우주선 실루엣(날개 펼침)이 약하다.
- volcano: 얼음 원뿔이 흰 텐트처럼 보일 수 있다 — 분출이 작다(칸 높이 한도).
- floating: 땅 그림자가 없어 지도 위에서 붕 떠 보이는 대신 위치감이 약하다.
- village(캡슐)·camp 는 작은 칸에서 흰 덩어리끼리 비슷하다.
- tower_small 은 칸 폭의 60% 정도만 채운다(그림자 여유).

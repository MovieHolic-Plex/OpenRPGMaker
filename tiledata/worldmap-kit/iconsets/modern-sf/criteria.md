# 현대·SF 세트 — 「이게 뭐로 보이나」 판정 (8배 PNG 를 직접 열어 본 것)

숫자가 아니라 한 줄 판정이다. 면 px 는 `stats.md` (렌더러가 센 값). 3/4 시점은 `lib/oblique.py` 의 투영 규칙(u = x + 0.28y, v = z + 0.5y)이 보장한다 — 보이는 면은 윗면·앞면·오른쪽면뿐이라 정면 입면 한 장은 구조적으로 나올 수 없다. 눈으로는 「뭘로 읽히나」만 본다.

## 1라운드 (첫 렌더 — 실패가 많았다)
| 아이콘 | 읽힌 것 | 판정 |
|---|---|---|
| capital | 고층 군 | ✓ |
| fort_city | 방벽 상자 + 고층 | 약함(방벽이 그냥 회색 상자), 이후 감시탑·철문·방벽 띠로 보강 |
| harbor_city | 크레인 + 컨테이너 | ✓, 단 배가 물과 섞여 안 보임 ✗ |
| large_town_a/b | 앞줄 지붕이 뒷줄을 가려 지붕 더미 | ✗ (행 간격 부족) |
| village_a | 알록달록 얼룩 | ✗ (물탱크가 컨테이너를 덮음) |
| camp_a | 돔 텐트 | ✓ |
| camp_b | 파란 납작 판 + 트럭 | ✗ 「그냥 판」 (마루가 가로인 박공은 앞에서 경사 한 장만 보임) |
| tower_small_b | 풍차 같은 선 | ✗ (날개 하나가 수평이라 십자로 읽힘) |
| ruin | 프리즘 / 기울어진 상자 | ✗ |
| shrine | 흰 알 / 돌덩이 | ✗ 「그냥 흰 덩어리」 |
| circle | 흰 양배추 / 타이어 | ✗ |
| volcano(지열) | 흰 연필 한 자루 | ✗ (증기 덩이가 한 캡슐로 합쳐짐) |
| 그 밖 | castle_a 격납고+레이더 ✓, castle_b 포탑 요새 ✓, village_b 농가 ✓, tower_small_a 송신탑 ✓, tower_great ✓, cave 벙커 ✓, landmark_nature ✓, floating ✓ | |

고친 것: A자 텐트(마루 y 방향, 앞 삼각 박공에 출입구)·가로 박공 천막 폐기 / 증기를 좌우로 엇갈린 구름 덩이로 / 접시를 오목(가운데 어둡고 가장자리 밝음 + 허브 + 급전 팔)으로 / 관측 돔에 리브와 앞쪽 개구부 / 폐허는 창 파손·앞면 구멍·부서진 윗면·박힌 슬래브·철근 / 행 간격 12→15 / 선체를 붉게 / 날개 120° 간격으로 위쪽 하나.

## 지도 맥락 (`preview/map-ctx-*`, 12x9칸 ×2배, 원본 월드 칩셋 타일 위)
- 초원: 한 세트로 읽힌다. 차가운 청회색 금속·유리가 초원의 따뜻한 초록과 분리되어 눈에 띈다(묻히지 않음).
- 사막: 밝은 모래 위에서도 또렷하다. 흰 돔·접시류는 모래와 명도가 비슷해 약간 덜 튄다.
- 언덕(갈색 산 타일): 아이콘이 산 위에 얹혀도 윤곽이 산다. 지열 발전소 증기가 눈에 띈다.
- 황무지(갈색): 폐허류가 어울린다.
- 한계: 청회색 팔레트는 원본 월드 칩셋의 건물(붉은 지붕·갈색 나무)과는 **다른 시대 느낌**이다. 이 세트는 현대·SF 월드맵 전용이고 원본 중세 건물과 섞어 쓰는 용도가 아니다.

## 못 한 것 / 정직한 한계
- 1배에서 접시(circle)·송신탑류는 작아서 종류 판별이 어렵다.
- 폐허(ruin)·동굴(cave)은 「읽힌다」보다 「그럴듯하다」에 가깝다.
- 땅 그림자는 세트 전용으로 해를 높게(−0.32, 0.22, 1) 잡았다. 원본 아이콘의 +6,+3 고정 그림자보다 짧다.

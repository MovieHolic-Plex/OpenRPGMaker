# 세트 joseon — 조선

## 테마
조선 시대 한국. 기와(청회)·초가·흰 회벽·붉은 기둥(단청은 절제)·돌담. 사막·동양풍 세트(desert-east)의 동양 장면이 바탕 — 결은 따르되 중국·일본풍이 섞이지 않게(처마 곡선 완만, 탑은 석탑·목탑, 문루는 홍예문).

## 역할별 내용
- capital 6x6 한양 도성: 궁궐(근정전풍 큰 전각·월대)·사대문 중 남대문·도성 성곽
- fort_city 4x4 읍성: 돌 성곽·홍예 문루·안의 동헌(관아)·민가
- harbor_city 5x4 포구 고을: 돌 성곽 일부·포구·판옥선(조선 전선)·창고
- castle 3x3 산성: 산 위 석축 성벽·장대·암문
- large_town 3x3 양반 마을(기와집·담장·정자) + 변형: 장터 마을(초가·장터 천막·주막)
- village 2x2 초가 마을(초가 셋·장독대·감나무) + 변형: 어촌(초가·그물·작은 배)
- camp 2x2 보부상 야영(천막·지게·모닥불)
- tower_small 1x2 봉수대(돌 연대 위 연기 다섯 줄은 하나로)
- tower_great 2x4 목탑(5층 목탑, 법주사 팔상전풍)
- cave 2x2 석굴(바위 절벽 + 석굴 입구 + 작은 처마)
- ruin 2x2 무너진 석탑(3층 석탑 밑동·흩어진 옥개석)
- ruin_city 4x3 폐허가 된 옛 궁터(주춧돌·무너진 담·잡초)
- shrine 3x3 산사(대웅전·석탑·일주문)
- landmark_nature 3x3 당산나무(느티나무·금줄·돌무더기 서낭당)
- circle 2x2 고인돌(탁자식 고인돌 둘)
- volcano 2x2 백두산풍 화산(천지 호수가 있는 분화구 — 용암 대신 물)
- floating 5x4 신선 봉우리(구름 위 바위 봉우리·정자·소나무)

# 세트 steampunk — 스팀펑크·마도

## 테마
FF6 마도·스팀펑크. 놋쇠·구리·녹슨 철·검댕 벽돌, 증기·톱니·굴뚝, 비행선, 기차. 연기는 modsf_kit steam 사용.

## 역할별 내용
- capital 6x6 마도 제국 수도: 시계탑·거대 공장 굴뚝·비행선 정박탑
- fort_city 4x4 공업 도시: 벽돌 공장·굴뚝·증기 파이프
- harbor_city 5x4 증기선 항구: 외륜 증기선·크레인·창고
- castle 3x3 마도 요새(철판 성벽·대포·톱니 문장) + 변형: 비행선 기지(계류탑·비행선)
- large_town 3x3 탄광 마을(갱도 입구·광차 레일·오두막)
- village 2x2 철도역 마을(작은 역사·선로) + 변형: 풍차·수차 공방 마을
- camp 2x2 조사단 캠프(천막·증기 기관 발전기)
- tower_small 1x2 증기 굴뚝 탑 / 송신탑
- tower_great 2x4 거대 시계탑
- cave 2x2 광산 갱도 입구
- ruin 2x2 추락한 비행선 잔해
- ruin_city 4x3 마도 폭주로 무너진 공장 지대
- shrine 3x3 마도 연구소(유리 돔·코일)
- landmark_nature 3x3 거대 톱니 유적이 박힌 바위산 / 마석 수정 언덕
- circle 2x2 마석 원(빛나는 수정 기둥)
- volcano 2x2 지열 증기 화산(파이프가 꽂힌 화구)
- floating 5x4 부유 대륙(프로펠러·부유석)

# 세트 fantasy-dungeons — 판타지 던전·신전 입구 (판타지 확장)

## 테마
젤다(신들의 트라이포스)처럼 던전 입구가 장소마다 다른 판타지 확장. 판타지 세트(EasyRPG 월드 시트 화풍: 밝고 채도 높은 동화풍)와 섞여 쓰인다 — EasyRPG 색 위주, 새 색 최소. **부분 세트**: SET 에 partial=True, extends="fantasy" 를 넣는다(17 역할을 다 채우지 않는다).

## 역할별 내용
12장 (역할 · 내용):
- cave 2x2 불의 던전(붉은 바위 입구·용암 빛)
- cave 2x2 물의 던전(물가 동굴·물줄기)
- cave 2x2 숲의 던전(거대 나무 뿌리 사이 입구)
- cave 2x2 얼음 던전(얼음 아치 입구)
- shrine 3x3 바람의 신전(흰 기둥·회오리 장식·높은 계단)
- shrine 3x3 빛의 신전(금빛 돔·흰 계단)
- shrine 3x3 어둠의 신전(검은 첨탑·보라 불)
- ruin 2x2 사막 신전 입구(모래에 반쯤 묻힌 피라미드 입구)
- ruin 2x2 봉인된 문(돌문·문장·쇠사슬)
- circle 2x2 요정의 샘(물웅덩이·빛 기둥·꽃)
- tower_small 1x2 마법사의 외딴 탑
- circle 2x2 마스터 검의 대좌(돌 대좌에 꽂힌 검·숲 빈터)

# 세트 snow-north — 설원·북방

## 테마
눈 덮인 북방·바이킹. 눈 쌓인 지붕(지붕 윗면은 흰 눈, 처마 아래 나무색), 통나무·돌, 얼음 푸른빛, 롱하우스·용머리 배.

## 역할별 내용
- capital 6x6 얼음 왕성: 눈 덮인 성벽·높은 탑·얼음 궁전 돔
- fort_city 4x4 통나무 요새 도시: 뾰족 말뚝 목책·롱하우스들·망루
- harbor_city 5x4 피오르 항구: 롱쉽(용머리 배) 둘·나무 부두·롱하우스
- castle 3x3 얼음 성(투명한 푸른 얼음 첨탑) + 변형: 바이킹 장군 전당(큰 롱하우스·방패 벽)
- large_town 3x3 눈 마을(눈 쌓인 박공집·장작더미)
- village 2x2 이글루 마을(이글루 셋) + 변형: 롱하우스 마을
- camp 2x2 순록 유목 천막(원뿔 천막·썰매)
- tower_small 1x2 얼음 등대 / 봉화탑
- tower_great 2x4 얼음 첨탑
- cave 2x2 얼음 동굴(푸른 얼음 입구·고드름)
- ruin 2x2 룬석 무덤(눈 덮인 봉분·룬석)
- ruin_city 4x3 얼어붙은 폐허 도시(눈에 묻힌 지붕·얼음 기둥)
- shrine 3x3 오딘 신전(목조 스타브 교회풍·용머리 장식)
- landmark_nature 3x3 세계수(눈 덮인 거대 물푸레나무)
- circle 2x2 룬 돌원(눈 위 선돌)
- volcano 2x2 설산 화산(눈 덮인 비탈 + 붉은 화구)
- floating 5x4 오로라 아래 떠 있는 빙산섬

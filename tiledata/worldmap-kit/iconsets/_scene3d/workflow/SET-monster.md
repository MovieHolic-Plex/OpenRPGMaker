# 세트 monster — 몬스터 수집

## 테마
포켓몬 3세대(GBA)풍 몬스터 수집 RPG 세계. 밝고 깨끗한 색, 빨강·파랑 지붕, 흰 벽. 견본 monster/scenes.py 의 village·large_town·home·center·mart·lab 을 그대로 이어서 쓴다(이 두 장면은 사용자에게 보인 견본이라 크게 바꾸지 말 것).

## 역할별 내용
- capital 6x6 대도시: 고층 백화점·라디오 타워·체육관·회복소가 모인 큰 도시(금빛 시 같은)
- fort_city 4x4 체육관 도시: 가운데 큰 체육관(문장 간판·큰 지붕) + 둘레 집·울타리
- harbor_city 5x4 항구 도시: 등대·여객선 부두·창고·회복소, 남쪽이 물가(부두가 칸 아래로)
- castle 3x3 리그 본부: 기둥 늘어선 웅장한 석조 본관과 계단(챔피언 로드 끝)
- large_town 3x3: 견본 그대로 (회복소 마을) + 변형 하나: 농장 마을(목장 울타리·헛간·풍차)
- village 2x2: 견본 그대로 (시작 마을) + 변형 하나: 숲속 오두막 마을
- camp 2x2 캠핑장·사파리 입구: 천막 둘·안내 간판·모닥불
- tower_small 1x2 등대
- tower_great 2x4 방울탑(오층 목탑, 꼭대기 방울)
- cave 2x2 달맞이산 동굴 입구(바위산 + 어두운 입구 + 사다리)
- ruin 2x2 알프 유적(돌 기단 + 기호 새긴 석판)
- ruin_city 4x3 버려진 발전소(녹슨 공장·굴뚝·철탑)
- shrine 3x3 전설 사당(돌 제단·기둥 원·신목)
- landmark_nature 3x3 거대 나무(열매 열린 큰 나무)
- circle 2x2 바위 원(둥근 큰 돌 넷)
- volcano 2x2 불꽃섬 화산
- floating 5x4 하늘 기둥 섬(구름 위 떠 있는 섬 + 탑)

# 세트 modern-town — 현대 소도시

## 테마
마더·페르소나풍 현대 소도시(일본·한국·미국 교외가 섞인 무국적). 따뜻한 색, 학교·병원·상가·신사·주유소·놀이공원. 현대·SF 세트(modern-sf)보다 덜 미래적이고 생활감 있게.

## 역할별 내용
- capital 6x6 도심: 역 빌딩·백화점·방송탑·교차로
- fort_city 4x4 신도시 단지(아파트 동·놀이터)
- harbor_city 5x4 항구 마을(여객선 터미널·어시장·등대)
- castle 3x3 학교(본관·운동장·체육관) + 변형: 병원
- large_town 3x3 상점가(아케이드 지붕·간판)
- village 2x2 교외 주택가(마당 있는 집 둘) + 변형: 시골 정류장 마을
- camp 2x2 캠핑장(캠핑카·텐트)
- tower_small 1x2 송전탑 / 소방망루
- tower_great 2x4 방송 타워
- cave 2x2 지하철 입구 / 터널
- ruin 2x2 폐공장
- ruin_city 4x3 폐쇄된 놀이공원(관람차)
- shrine 3x3 동네 신사·절
- landmark_nature 3x3 큰 공원 나무 / 호수 공원
- circle 2x2 스톤헨지풍 관광지 / 원형 광장 분수
- volcano 2x2 온천 화산(김 나는 온천)
- floating 5x4 비행장(활주로·관제탑) — 떠 있는 땅 대신 공항

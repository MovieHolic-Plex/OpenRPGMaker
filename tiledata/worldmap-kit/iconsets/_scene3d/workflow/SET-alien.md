# 세트 alien — 외계 행성

## 테마
외계 행성 지표. 이질적인 색(보라 식물·청록 수정·주황 하늘빛 바위), 착륙선·돔 기지와 외계 원주민 구조물이 섞인다. 현대·SF 재질(modsf_kit) 사용.

## 역할별 내용
- capital 6x6 이주민 돔 도시(큰 유리 돔·관측탑·착륙장)
- fort_city 4x4 방어 기지(방벽·포탑·돔)
- harbor_city 5x4 우주항(로켓 발사대·착륙선·연료 탱크) — 남쪽 물가 대신 착륙장
- castle 3x3 외계 여왕 둥지(유기물 첨탑) + 변형: 군 전초기지
- large_town 3x3 원주민 버섯 마을(거대 버섯 집)
- village 2x2 정착 캡슐 마을(캡슐 주거 셋) + 변형: 수정 마을
- camp 2x2 조사 캠프(텐트·탐사차)
- tower_small 1x2 통신 안테나
- tower_great 2x4 고대 외계 오벨리스크(빛나는 문양)
- cave 2x2 수정 동굴
- ruin 2x2 추락한 우주선
- ruin_city 4x3 고대 외계 문명 유적(휘어진 기둥)
- shrine 3x3 외계 신전(떠 있는 고리·빛)
- landmark_nature 3x3 거대 외계 식물(촉수형 나무)
- circle 2x2 공명석 원(떠 있는 돌)
- volcano 2x2 얼음 화산(청록 분출)
- floating 5x4 중력 이상 부유섬

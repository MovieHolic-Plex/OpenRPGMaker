# 세트 starmap — 성계 지도

## 테마
우주 성계 지도용 아이콘. 땅·바다 대신 검은 우주 배경 위에 놓인다(지형층은 감독이 따로 만든다). 행성(구 E.Ellip / M.Dome 로 구체)·우주정거장·함대·소행성. 각 역할을 우주 대응물로 바꾼다. 우주에는 땅 그림자가 없다 — 모든 입체 role 을 "nocast" 로.

## 역할별 내용
- capital 6x6 모항성계 수도 행성(고리 있는 큰 행성 + 궤도 도시 고리)
- fort_city 4x4 요새 정거장(링 정거장·포대)
- harbor_city 5x4 우주 조선소(건조 중인 함선·도크 골조)
- castle 3x3 적 기함(거대 전함) + 변형: 군 요새 위성
- large_town 3x3 개척 행성(초록 행성 + 작은 위성)
- village 2x2 소행성 채굴촌(소행성 + 돔) + 변형: 얼음 위성
- camp 2x2 보급선 정박지(작은 배 둘)
- tower_small 1x2 항법 부표(빛나는 비콘)
- tower_great 2x4 궤도 엘리베이터(행성에서 뻗은 줄·정거장)
- cave 2x2 웜홀 / 점프 게이트(링 문)
- ruin 2x2 함선 잔해
- ruin_city 4x3 파괴된 행성(쪼개진 행성 파편)
- shrine 3x3 고대 외계 유물(떠 있는 구조물)
- landmark_nature 3x3 가스 거인(줄무늬 큰 행성)
- circle 2x2 소행성 고리
- volcano 2x2 용암 행성
- floating 5x4 다이슨 고리 조각 / 성운 속 거대 구조물

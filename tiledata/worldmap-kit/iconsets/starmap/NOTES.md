새 입체(scenes.py 안): Chunk(타원체 ∩ 반공간 — 행성·쪼갠 조각·지평선 자르기), Ring(두꺼운 고리·원판·부채꼴, 아무 축),
ship_poly(위아래·앞뒤로 뾰족한 함선 쐐기). 행성은 y·z 반지름을 1/√(1+KY²) 로 줄여 화면에서 둥글게.
고리 문(바퀴 정거장·점프 게이트)은 축 (0,-.49,1) — 이 기울기에서 원이 화면에서 둥글다.

- capital: 대양·대륙·구름·밤 불빛의 푸른 큰 행성 + 바위 고리 + 반대로 기운 궤도 도시 고리(모듈 14개·창 불빛) + 크레이터 위성.
- fort_city: 바퀴 고리 정거장(붉은 띠·창 불빛) + 바퀴살 6 + 가운데 축 + 네 방위 포대.
- harbor_city: 주황 골조 도크 안 건조 중인 함선(뒤 철판·앞 늑골·용골) + 크레인 셋(용접 불빛) + 관제동.
- castle: 붉은 띠 검은 쐐기 전함(층진 상부·함교탑·포탑 둘·추진 불꽃).
- castle_fortmoon(변형): 회색 위성 + 적도 참호 불빛 + 거대 포구 접시(청록 가운데) + 꼭대기 포탑·안테나.
- large_town: 초록 대륙 행성 + 작은 위성 + 개척 정거장.
- village: 바위 소행성(덩이 넷) + 유리·흰 돔 + 채굴 탑·팔.
- village_ice(변형): 푸른 금이 간 얼음 위성 + 기지 돔·안테나.
- camp: 연료 탱크 정박탑 + 양쪽 보급선 둘(흰·주황, 회·파랑).
- tower_small: 붉은 띠 돛대 + 태양 날개 + 빛나는 비콘(빛살).
- tower_great: 행성 지평선(자른 구) + 줄 + 승강기 둘 + 중간·꼭대기 고리 정거장 + 바위 평형추.
- cave: 빛 마디 금속 고리 문 + 자주 소용돌이 웜홀(성운 색 5) + 기둥 셋.
- ruin: 두 동강 선체(뱃머리 아래로·고물 위로) + 삐져나온 늑골 + 불꽃·파편.
- ruin_city: 네 조각으로 흩어진 행성 껍질(자른 면 = 녹은 암석) + 빛나는 핵 + 부스러기.
- shrine: 빛 문자 자주 팔면체 + 금 고리 + 떠 있는 돌기둥 넷.
- landmark_nature: 줄무늬 가스 거인 + 붉은 대폭풍 + 얼음 위성.
- circle: 얼음 왜행성을 도는 바위 17덩이 고리.
- volcano: 용암 균열·호수의 현무암 행성 + 분출 덩이.
- floating: 별 위를 활처럼 감싼 다이슨 고리 조각(안쪽 태양판·윗면 불빛·탑 넷·끊긴 끝 골조) + 홍염 별.

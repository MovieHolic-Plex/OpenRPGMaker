# 공용 실제 지형 사례 참고문서

호스트 공용 DB의 조선·유카탄 지역 사례가 소유하는 안내 원문이다. 정본 프로젝트를 API로 재로드하여 읽은 설정이며, `publish-worldmap-shared.mjs`가 같은 내용을 만든다.

- 선택 아이콘 그림·학습 자료는 기존 `selected/` 및 공용 `worldmap_selected` 번들이 소유한다.
- 두 지역 사례는 `worldmap-real-joseon` / `worldmap-real-yucatan`으로 공용 SQLite에 등록한다.
- 실제 프로젝트 폴더, source map/atlas SHA256, 공용 판본, 픽셀 동등성 근거는 `verify-shots/worldmap-shared-db/publication.json`.
- PNG 전체 지도는 공용 DB에 있으며 참고 이미지 사본은 768×576, 미리보기는 384×288이다.
- 지역 사례는 map source/통행/지형 설정을 포함한다. 완성 게임과 마야 건축 고증은 포함하지 않는다.

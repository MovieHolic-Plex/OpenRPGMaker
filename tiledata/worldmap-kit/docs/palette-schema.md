# 팔레트 스키마 — `palettes/<id>.json` (`worldmap-palette/1`)

팔레트는 **지형 그림의 색 표**다. 지형 모양·경계·길·절벽은 그대로이고, 아이콘은 팔레트가 건드리지 않는다(`--tint-icons` 만큼만 빛을 입힌다).
빌더는 지형 그림(아이콘 없음)의 색마다 「어느 칸 종류에서 나왔나」를 센 표(색 → role)를 지형 코드 배열(바닥·물체·절벽·길)에서 자동으로 만들고(role 순도 약 0.85),
팔레트는 **role 마다 색을 어떻게 바꿀지**만 적는다. 같은 색은 항상 같은 색으로 가므로 원본이 가진 명암 단 수는 줄 수만 있고 늘지 않는다.

## 파일 형식

```json
{
  "schema": "worldmap-palette/1",
  "id": "winter",                    // 파일 이름(winter.json)과 같아야 한다
  "name": "③ 한겨울",
  "desc": "한 줄 설명",
  "light": { "lk": 1.0, "sh_a": -0.004, "sh_b": -0.02, "cs": 0.98 },   // 장면 전체의 빛(모든 role 에 마지막으로 적용). 생략 가능
  "roles": {
    "snow":   { "ramp": ["c4d6e6", "e2edf7", "ffffff"] },
    "forest": { "ramp": ["0b3331", "17524a", "2f7a62", "74b08f"], "pos": [0, 0.4, 0.7, 1] },
    "toxic":  { "cs": 0.8, "lk": 0.92 }
  },
  "icon_tint": 0.25                  // 선택: --tint-icons 를 안 줬을 때 쓸 기본값(없으면 0.25)
}
```

- `roles` 에 없는 role 은 색이 바뀌지 않는다(`light` 만 적용). `roles` 와 `light` 가 둘 다 비면 **항등**(= `original`, 화소 그대로).
- 알 수 없는 role·연산 키는 빌더가 시작할 때 거절한다.

### role (지형 종류, 20개)

| role | 뜻 | role | 뜻 |
|---|---|---|---|
| `sea` | 바다(3띠 수심 포함, 화면의 절반) | `snow` | 설원·빙하 |
| `river` | 강·호수·연못 | `forest` | 숲(활엽·침엽·정글) |
| `lava` | 용암 | `deadwood` | 고사목 |
| `toxic` | 독수 | `mount` | 산(물체) |
| `grass` | 초원·정글 바닥 | `volcano` | 화산 덩이 |
| `farm` | 밀밭 | `rock` | 절벽·고원 면과 윗면 |
| `savanna` | 사바나 | `badlands` | 붉은 협곡·메사 |
| `sand` | 사막·모래언덕(사구 후처리 색 포함) | `ash` | 화산재·현무암 |
| `dirt` | 황무지 | `swamp` | 늪(서쪽 늪·동쪽 독늪) |
| `tundra` | 툰드라 | `road` | 길·다리 |

### role 규칙의 연산(한 role 안에서 이 순서로 적용)

| 키 | 값 | 의미 |
|---|---|---|
| `ramp` + `pos` | hex 배열(어두움→밝음), `pos` 0..1 같은 길이(생략 시 등간격) | **role 안의 밝기 순위**를 램프에 대응시킨다. role 밝기의 2%~98%(화소 가중)를 램프 전체에 펴므로 화면의 대부분을 차지하는 서넛 색이 램프의 서로 다른 단에 놓인다. `ramp` 가 있으면 아래 연산은 무시한다. **3~4단 이상**을 적어라. |
| `hue`, `hue_amt` | 도(OKLCH), 0..1 | 색상각을 목표 쪽으로 `hue_amt` 만큼 끌어간다 |
| `dh` | 도 | 색상각 평행이동 |
| `cs`, `co` | 배율, 가산 | 채도(chroma) |
| `ct` | 배율 | role 평균 밝기를 기준으로 한 대비 |
| `lk`, `lo` | 배율, 가산 | 밝기(L) |
| `tint` | `["hex", 0..1]` | (a,b) 색상 평면에서 hex 쪽으로 옮긴다 |

### `light` (장면 전체)

`lk`·`lo`(밝기), `cs`(채도), `a`·`b`(전체 색 치우침), `sh_a`·`sh_b`(그림자에 더하는 치우침: 어두울수록 강함), `hi_a`·`hi_b`(하이라이트에 더하는 치우침). 단위는 OKLab 값이다(0.01~0.03 이 눈에 보이는 크기).

### `regional` (지역 마스크, 한 팔레트가 다른 팔레트를 번지게 한다)

```json
{ "schema": "worldmap-palette/1", "id": "regional", "name": "...", "desc": "...",
  "regional": { "base": "ruin", "levels": 5, "width": 0.5, "warp": 3.0, "seed": 40, "core": 0.45, "reach": 9.0,
                "seeds": [[80, 25, 24, 1.0], [72, 16, 15, 1.0]] } }
```
`base` 팔레트의 roles/light 를 물려받아 원본 색 → base 색으로 `levels` 단계에 걸쳐 번진다. `seeds` = `[칸 x, 칸 y, 반경(칸), 세기 0..1]`, `warp` = 마스크 윤곽을 노이즈로 휘는 정도(칸), `reach` = 바다에서 해안을 따라 번지는 거리(칸), `width` = 단 사이 베이어 디더 폭.

## 아이콘 틴트 (`--tint-icons 0..1`, 기본 0.25)

아이콘 화소(키색·그림자 키 제외)의 색을 **팔레트의 `light` 만 적용한 색**과 `amount` 만큼 섞는다. role 규칙은 쓰지 않는다 — 아이콘은 자기 색을 유지하고 장면의 빛(황혼의 주황·그림자의 남보라 등)만 얹는다.
0 이면 아이콘은 한 화소도 안 변한다. `original` 팔레트는 항상 그대로다.

## 결과 지표 (`out/build-report.json`)

빌더가 팔레트마다 계산해 쓴다 — 눈으로 보기 전에 뭉침을 먼저 잡는 숫자다.

- `steps`: role 별 **명암 단 수** — 그 role 화소의 0.5% 이상을 차지하는 색을 OKLab L 간격 0.03 이상으로 서로 다른 단으로 센 것. 주요 지형(`KEY_ROLES`)이 3 미만이면 지형이 한 색으로 뭉친 것이다.
- `min_pairs` / `key_min_pair`: role 별 평균색의 쌍별 OKLab 거리 중 가장 가까운 쌍(주요 지형끼리). 원본의 값은 약 0.037 이다.
- `icon_metrics`: 아이콘 화소 중 둘레 2칸 고리의 평균색과 OKLab 거리 0.08 이상인 화소 비율(낮을수록 묻힘). 원본 최저 0.67.
- `role_purity`: 색 → role 대응이 실제 칸 종류와 맞는 화소 비율(지형 코드 기준, 약 0.845).

## 새 팔레트 만들기

1. `palettes/<id>.json` 을 쓴다(위 형식). 지형 종류마다 램프를 두는 것이 가장 안전하다 — `hue`/`cs` 연산은 원래 색 차이를 그대로 끌고 가므로 서로 비슷한 role 이 계속 비슷하다.
2. `python3 kit/build_world.py --iconset fantasy --palette <id> --journey fantasy-5act --out /tmp/x --cache /tmp/wmk-cache` (캐시가 있으면 팔레트 하나가 몇 초).
3. `build-report.json` 의 `steps`·`key_min_pair` 를 보고, **PNG 를 직접 연다**(지표가 좋아도 형광·채도 폭주는 눈으로만 잡힌다).
4. 평지 종류(초원·밀밭·사바나·툰드라·모래·황무지)가 서로 다른 색상으로 남는지, 눈·산·숲이 서로 구별되는지, 아이콘이 묻히지 않는지를 본다.

## 이번에 정한 6개

| id | 의도 | 방식 |
|---|---|---|
| `original` | 항등 | roles·light 비움 |
| `ruin` | FF6 후반부식 무너진 세계: 탁한 녹청 바다·마른 풀·재 낀 산 | hue/cs/lk 연산 + 바다 램프 |
| `dusk` | 해 질 녘: 그림자 남보라·하이라이트 주황, 평지 종류가 서로 다른 색상 | 지형 종류별 램프 |
| `winter` | 눈이 내려앉은 대륙. **지형 종류마다 명암 3단 이상을 유지** | 지형 종류별 램프 |
| `ashfall` | 재가 내려앉은 땅 + 또렷한 용암 | 지형 종류별 램프 + 용암·독수 보정 |
| `regional` | `ruin` 이 원본 색에서 지역 마스크로 번진다 | `regional` |

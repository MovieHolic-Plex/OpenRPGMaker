# 테마와 그림의 준비 상태

17개 테마 JSON은 지형 구조·팔레트·덧칠·여정 템플릿을 고른다. 그림의 사람 선택과 게임 이벤트 완성을 뜻하지 않는다.
현재 확정된 월드맵 아이콘은 판타지 36·사막/동양 21·현대/SF 22개다. 우주 등 다른 14개 세트의 후보는 별도 선택이 필요하다.

호스트 저작은 `--selected-icons ../selected/selected.json`을 준다. 빌더는 선택 파일의 SHA256과 크기를 검사하고
발자국과 맞는 원본 RGBA만 붙인다. 선택하지 않은 그림과 발자국이 다른 그림은 `icon_selection.pending`에 남는다.
이 경우 장소 이름·좌표·논리 여정 검사는 존재하지만 실제 거점 그림과 이동 이벤트는 없다.
후보용 전체 세트를 보는 하네스는 이 옵션을 생략한다. 후보 미리보기를 자동으로 공용에 설치하지 않는다.

우주 `starmap`은 galaxy 구조·space-5act 여정이다. 항행 공간(땅), 공허(바다), 소행성대(산), 이온 폭풍(사구),
초공간 항로를 그린다. 외계 행성 `alien`은 육지 지도다. 성운이나 검은 배경만 바꾸어 같은 상태로 취급하지 않는다.
정거장 내부나 워프 해금 게임 로직은 월드맵 지형 생성과 별도 저작이며, 현재 전용 완성 거점 자료는 없다.

에디터 조수는 `list_worldmap_themes`에서 구조와 선택 수를 먼저 찾는다. `worldmap_<theme>`라는 타일셋 ID를 추측하지 않는다.
전용 타일셋 `worldmap_<mapId>`는 실제 생성 후 생긴다. 모든 결과의 여정 검사를 읽고 실패를 완료로 보고하지 않는다.
실측과 재현 명령은 저장소의 `verify-shots/worldmap-theme-readiness/README.md`에 있다.

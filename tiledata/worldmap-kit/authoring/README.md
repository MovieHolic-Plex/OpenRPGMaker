# 월드맵 연결 붓

worldmap_authoring, tex_worldmap_authoring, 16px, 12열, 3823칸. 출처는 완성 지도 크롭이 아니라 terrain_v4의 현재 질감·숲/산 사분면과 authoring/pixels.json의 새 경계·길·다리 픽셀이다. PNG SHA256=d2d32963d30fe828e440c5f488d6b858619faf92d20e5e9cdf06bcb9d5e82f26.

1. 빈 맵을 worldmap_authoring으로 만들고 바다(0)로 채운다. 편집기의 빈 월드맵은 48×36이다. 기존 생성 지도에는 이 소스가 이식되므로 이 문서의 번호를 그대로 쓰지 말고 tileGroups의 worldmap-brush-*를 찾는다.
2. 바다 배경의 초원/사막/설원 해안 붓으로 육지와 섬을 칠한다. 외곽·오목 코너·한 칸 통로는 8방향 256 입력에서 47개 연결 상태를 고른다. 바다 붓으로 해협/만을 다시 깎으면 이웃 해안도 바뀐다.
3. 편집기는 바탕 자동이 기본이다. 지형 탭에서 붓 하나로 초원·사막·설원을 가로질러 칠하면 칸마다 현재 바탕의 변형을 고른다. 바탕을 직접 지정하려면 바탕 설정을 펼친다. 지형과 숲·산을 함께 고를 수 있고 층은 자동으로 전환된다. 위층 숲·산은 RGBA 투명이며 현재 아래 땅을 보존한다.
4. 강은 막힌 아래층이다. 어귀는 바다와 연결된다. 길은 사방 16가지 끝/모퉁이/T/십자로 연결되며 서로 다른 배경의 길도 만난다. 자동 길 붓과 fill_region(material=길,path,width=1)은 강을 건너는 칸을 진행 방향에 맞는 다리로 바꾼다. 바다 횡단은 직접 다리로 설계한다. 가로/세로 다리 붓도 사용할 수 있다. 다리는 수면의 47개 연결 상태를 따라 밑의 강둑을 다시 맞춘다. 가로 다리는 좌우, 세로 다리는 위아래로만 이동한다. 강·바다는 ×. 자동 모드에서는 다리도 강의 바탕에 맞춘다. 다리를 지우면 강으로, 길·강·호수를 지우면 해당 바탕으로 되돌린다.
5. 숲·산은 위층 ×. 고개/도시 자리의 위층을 지운다. 지우기와 채우기도 연결을 다시 맞춘다. 거점은 36개 사람 선택 판타지 키트 중 전체 배열로 놓는다. 원본 선택은 wmi-fantasy 문서와 실제 그림을 읽는다. 아래 지면과 이벤트는 별도다.
6. 조수는 fill_region(material=강/길/호수/숲/산맥/사막/설원)처럼 재료 이름만 써도 바탕과 기본 층이 맞는다. 길·강은 path와 width로 곡선이나 연결 경로를 한 번에 깐다. 숲·산은 layer를 생략하면 위층에 놓인다. 강 · 초원 / 길 · 사막처럼 바탕을 명시한 기존 이름은 그 바탕으로 칠한다. 거점 탭에서는 이름과 전체 그림을 보고 고르며 stamp_worldmap_icon을 쓴다. 같은 일반 타일 도구에서도 이 타일셋의 autotileGroups를 쓴다. 숲/산을 lower로 합성하거나 거점 일부 칸만 떼어 쓰지 않는다. 저장 후 같은 SQLite 대상에서 다시 읽는다.

![실제 대표 붓: 배경별 지형, 숲/산, 다리](image:wmi-authoring-brushes)

팔레트에 대표가 하나인 것은 모든 변형이 variantMap에 있기 때문이다. 스포이트는 실제 변형을 고른다. 기존 완성 대륙은 원본 재료로 보존되며, 새 붓으로 기존 절벽과 고원을 모두 재현한다는 뜻은 아니다. 고원·절벽/높이 지우기/고개·경사로 버튼은 에디터의 실제 relief 붓이다. 바닥 그림을 보존하며 높이 데이터를 저장한다.

## 전체 배열: 연결된 3×3 섬

원점 (0,0), lower=[[35,46,41],[39,61,57],[31,53,49]] / upper=[[-1,-1,-1],[-1,-1,-1],[-1,-1,-1]] / 오른쪽 오류 lower=[[15,15,15],[15,15,15],[15,15,15]]. 자동 연결을 생략하면 각 칸이 고립된 섬이 된다. 정상과 오류 배열을 원본 시트 좌표와 대조한다.

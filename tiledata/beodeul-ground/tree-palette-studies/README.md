# 나무 색상만 비교 (2026-10-04)

요청: 집 옆에서 나무가 뜨는 느낌의 팔레트 영향을 분리한다. 이전 tree-studies의 current 원본 세 나무를 형태 기준으로 사용한다. 나무의 불투명 픽셀 RGB만 단일 색상 치환표로 바꾸며 위치/알파/픽셀 패턴/뿌리 형태/공용 땅 그림자/집/기초/잔디/포석은 고정한다. 각 원본 색은 모든 좌표와 세 나무 종류에서 같은 색으로 치환된다. 공간 필터/흐림/수관 모양 변경을 사용하지 않는다.

현재 원본 + 다섯 후보:
- muted: 잎 밝기는 유지하고 채도만 56%로 줄인다.
- warm: 같은 밝기의 황록/올리브 색조.
- cool: 밝기를 유지하며 어두운 잎에 청록 색조.
- contrast: 잎 색의 밝기 범위를 압축, 밝은 점과 어두운 점 차이를 줄인다.
- balanced: 낮춘 녹색 채도/명암과 따뜻한 목재 색 조정.

scripts/content/beodeul-tree-palette-studies.mjs가 paletteMapping 전체와 투명 source body PNG, 집 옆 한 그루/세 그루 비교 PNG를 만든다. 원본 비교는 이전 집 옆 current PNG와 모든 픽셀이 일치한다. inspection.json은 모든 알파/좌표 동일, 위치와 무관한 치환표, 땅 그림자 바이트 동일, 집/잔디/길 동일의 근거다. 픽셀 시안은 기존 프로젝트 소유 버들항 그림의 RGB 보정으로 외부 픽셀을 포함하지 않는다. 비교 후보이며 게임/SQLite/공용 타일 id는 아직 변경하지 않는다.

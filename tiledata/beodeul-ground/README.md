# 버들항 밝은 잔디 · 접지와 꾸미기

사용자가 승인한 방향: 밝은 잔디 유지, 얇은 흙빛 기초, 풀에 일부 묻힌 물체 하단,
퍼지는 나무 뿌리, 풀·꽃·잔돌의 작은 군락, 집 곁 화단·통·장작과 밟힌 흙.
사용자 참고 그림은 형태 판단에만 사용했고 픽셀은 복사하지 않았다. 코드는 직접 도트 저작이다.

## 실제 적용

`dress_beodeul_ground({mapId,style:"living",seed:1004})`를 사용한다.
`style:"natural"`은 풀·꽃·잔돌·낙엽, `living`은 집 곁 화단·통·장작도 넣는다.
집/길/나무 배치와 출입 연결 뒤 실행한다. 기존 맵의 크기·타일셋·잔디색·집/문/길 원본은 유지한다.
재호출은 같은 맵에 꾸밈을 중복하지 않는다. 이전 판의 나무는 빠진 수관·줄기 연결을 보강하고 지원하는 다른 집에는 빠진 기초도 보충한다.

도구는 밝은 잔디 원본 `beodeul_city` 737인 칸만 일반 꾸밈에 쓴다.
임의 칸 번호를 추측하거나 맵을 새로 만들지 않는다. 사막·눈·늪에 이 잔디 꾸밈을 강제하지 않는다.
층별 기존 그림과 높이가 있는 칸을 피하고, 이벤트·시작점·전이 착지 주변을 보존한다.
비어 있는 잔디를 남기며 군락 사이 2칸 이상 간격을 둔다. 꽃은 풀보다 드물게,
통/장작은 집 곁 3칸 이내에만 놓는다. 문 앞과 길 위에 소품을 놓지 않는다.

## 재료와 층

tilesetId `beodeul_ground`, image `tex_beodeul_ground`, 시트 `chipset.png` 128×736,
칸 16px·8열·368칸. 기초/꾸밈/그림자는 RGBA 투명 덧그림이다. 길/마당용 1층 칸은 잔디와 연결하는 전체 바닥이다.
0기준 칸 n의 원점은 `(n%8*16, floor(n/8)*16)`.
전체 사전·각 레시피의 배열은 같은 용도의 「정확한 칸 배열」 문서에 있다.

- 1층 `lowerTiles`: 원래 잔디·길. 도구는 변경하지 않는다.
- 2층 `lowerOverlayTiles`: 기존 뿌리 아래 그림자·낙엽·밟힌 흙.
- 3층 `upperTiles`: 기존 집·나무·문. 도구는 변경하지 않는다.
- 4층 `upperOverlayTiles`: 작은 풀·꽃·잔돌·화단·통·장작, 지원하는 기초·밑동·수관 안쪽 줄기.

`translateTiles`로 실제 그림을 현 칩셋 뒤에 이식한다. 이미 이식된 그림은 재사용한다.
자료의 source 번호와 대상 map 번호는 다를 수 있으므로 도구 반환 placements와 grafts를 읽는다.
투명 여부, 홈 레이어, 렌더 우선순위, 통행은 서로 다른 정보다.
풀/꽃/흙/낙엽/뿌리는 통과, 통·장작은 몸통 칸 차단. 기초의 벽 줄은 ★ 우선순위로 원래 벽 통행을 따른다. 기존 구조의 통행은 유지한다.

## 접지 보강 범위

- `bd-house-h101_0`: 아래 벽 줄 `(x,y+5)`에서 얇은 따뜻한 기초와 풀 경계를 7×2로 덧그린다.
  문 열림 5743/2333 또는 공용 `beodeul_door` 이식 칸은 그대로다. 기초 그림의 문 열 2는 완전 투명이다.
  h104_0/h107_0/h112_0은 마지막 벽 줄부터 전용 기초 2행을, h109_1은 (y+5)의 뒤채와 (y+7)의 앞채를 따라 4행, cathedral은 마지막 벽 줄부터 2행을 보강한다. 모든 문 열은 투명하고 새 기초 칸은 ★로 기존 통행을 따른다. 공용 bd-house-village-* 6종도 원본 sourceKit에 대응하는 전용 기초를 적용한다. 원본 지붕·윤곽은 보존하며 측면은 강제하지 않는다.
- `bd-tree-03a8f7`, `bd-tree-3e8732`: 3×3 수관 바로 아래 `(x,y+3)`에 3×1 밑동을 놓고 `(x,y+2)`의 가운데 칸에 줄기 연결을 겹친다. 연결 칸은 ★라서 원래 수관의 통행을 따른다.
  기존 수관 전체 배열이 일치할 때만 추가한다. 마른 덤불에 줄기를 임의로 붙이지 않는다.
- `bd-tree-1a786c`: 원래 3×4 그림의 마지막 줄 `(x,y+3)` 아래층에 그림자를 붙인다.
  기존 줄기/뿌리는 새 그림으로 덮지 않는다.

알려진 집/나무는 원본 시트 또는 같은 원본에서 이식된 칸으로 검출한다.
작가가 칠해서 구조가 바뀐 건물/나무에는 강제 보강하지 않는다.
위 범위는 세 나무와 한 집의 검토 결과다. 모든 버들항 집·나무의 미적 합격을 뜻하지 않는다.

## 조립과 오류

`example.json`은 3×4 맵 전체 네 층과 tileGrafts의 정답이다.
3×3 원본 수관 아래 마지막 행에 밑동을 잇는다. `example-native.png`는 그 실제 픽셀 합성이다.
`normal-error.png`는 왼쪽 정상 / 오른쪽 밑동을 빠뜨린 변조본이다.
검출 코드 `missing-root`, 좌표 `(1,3)`. 기초 문 열은 알파가 하나라도 있으면
`door-overlay`, 좌표 `(2,0)`로 실패한다. 원본 문과 전이 이벤트는 그림과 별개다.

생성 명령: `python3 scripts/content/build-beodeul-ground.py` →
`node scripts/content/prepare-beodeul-ground-references.mjs` →
`bun scripts/content/prepare-beodeul-small-village-references.mts` (작은 마을 자료 추가).
새/기존 프로젝트 등록, 정본 저장·재로드 및 실제 조수 호출 근거는 `verify-shots/beodeul-ground/README.md`.
자동 검사는 배열·덧그림·통행과 왕복을 확인한다. 실제 미적 품질은 화면으로 별도 확인한다.

건물 3/4 시점/창문·벽 콘셉트 공용 자료는 `tiledata/beodeul-architecture/README.md`, 하네스 `beodeul-architecture`를 따른다. `node scripts/content/prepare-beodeul-architecture-references.mjs`로 같은 용도에 추가한다.

## 공용 일광 보정

밝은 잔디의 집/나무 배치와 꾸밈을 끝낸 뒤 `harmonize_beodeul_daylight({mapId})`로 바닥의 짧은 그림자·낮춘 연석·큰 저대비 잔디 변화를 적용한다. 집·나무 도트와 원점·문 앞길 연결은 유지한다. 작은 마을 시공 도구는 이 보정을 마지막에 자동 적용한다.
source 0..111은 그대로 두고 112..303에 일광 레시피를 추가했다. 하네스 `beodeul-architecture build → validate → review`로 함께 저작·검사한다. 상세 일광 배치 계약은 DAYLIGHT.md와 전체 source 사전에 있다.

## 작은 마을 구도

naturalize_beodeul_hamlet은 지원하는 작은 마을에서 큰길/광장·흙 접근로·집 앞 마당·텃밭·식생 군락을 적용한다. 새 houseCount 마을은 자동 적용한다. 원본 304칸을 보존하고 304..361 칸을 공용에 추가했다. 상세 범위/층/연결/오류는 HAMLET.md를 읽는다.

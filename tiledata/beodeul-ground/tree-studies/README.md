# 나무 접지 픽셀 시안 (2026-10-04)

사용자 요청: 현재 마을 나무의 떠 있는 느낌을 도트 단위로 고친 다섯 방향을 비교한다. 정본 project id 3dd2427f-38dc-46e5-925b-a717dbe5bb03, SQLite revision18의 원본 칩셋/ground 참고문서를 추출해 확인했다. 이는 선택 전 비교 시안이며 게임 맵/기존 공용 칸/정본 SQLite는 변경하지 않는다. 게임 설치 때는 선택한 source 그림을 공용 번들/배치 규칙으로 배선하고 저장·재로드한다.

그림 소유: 기존 프로젝트 소유 버들항 원본 세 나무 + 정수 좌표의 코드 픽셀 보정. 입력 원본 아틀라스 해시는 inspection.json. 제작기 scripts/content/beodeul-tree-studies.mjs. 그림을 보간하거나 흐림 처리하지 않는다.

- current: 현재 원본 세 종류, 짧은 두 수관에 기존 neck/roots, 기존 일광 그늘.
- contact: 뿌리 끝 색을 낮추고 좁은 밑동 접촉과 수관 모양의 투영 그림자를 붙인다.
- roots: 수관 안쪽까지 연결한 줄기, 넓어지는 밑동과 가늘어지는 뿌리, 전경 풀.
- volume: 2×2 잎 묶음으로 작은 반짝임을 줄이고 세 잎 덩어리에 좌상단 광원과 하부 음영을 준다. 정수 픽셀 팔레트 치환이며 blur가 아니다.
- squat: 수관을 가로로 넓히고 세로로 줄여 낮고 넓은 윗면 비례를 시험한다. 픽셀 샘플링만 사용한다.
- integrated: 뿌리/줄기/수관 명암을 합치고 낙엽·풀을 실제 뿌리 앞에 겹친다.

각 방향은 원본 세 종류를 모두 보정하며 body/shadow/foreground 세 투명 그림으로 분리한다. 그림자는 땅(2층), 수관/줄기는 본체(3층), 앞 풀은 덧그림(4층) 후보지만 아직 tile id/통행을 배정하지 않았다. 줄기 X와 잎/풀 ★ 계약은 설치할 때 유지한다. 모든 시안의 바닥과 나무 좌표/합성 순서는 동일하다. studies.json은 native pixel 전체 palette-index 배열이다. contact-sheet.png는 current/contact/roots, volume/squat/integrated 순서의 실제 3배 픽셀 비교다.

후속 비교: 다섯 후보와 원본 모두 같은 돌벽집 bd-house-village-stone(원본 64×96px)을 옆에 두었다. 집과 한 그루 나무의 바닥선 y=100, 원본 16px 축척, 동일한 기초/좌상단 광원/포석 접근로다. 그림 비교 후보만 갱신하며 원본 집/마을/SQLite는 변경하지 않았다. 밑동 확대에서도 집의 기초와 나무 뿌리가 함께 보인다.

# 장르 steampunk (증기·황동·톱니) — 재질 규격 (장소 셋: steam-city · clockwork-tower · airship-dock)
1. 주 재질 램프는 기존 7단을 그대로 가져다 쓴다(새로 발명 금지): 황동 = `future-ruins/fr_base.py` `BRASS`(관 이음·톱니·계기 테, 원통 6단 음영) · 구리 = `empire-city/ec_roofs.py` `COPR`(관·보일러 몸통·리벳 띠) · 녹청 = `VERD`(구리 지붕·오래된 관 겉, 줄눈·아래 가장자리부터 번짐) · 검은 철 = `ec_base.py` `ROOFK`(주물 기둥·난간·가로등·톱니 바퀴·철판 지붕, 리벳 톤 6 한 점) · 벽돌 = `ec_roofs.py` `BRK` 그을린 붉은 벽돌(8×4 줄쌓기, 줄눈 톤 1) · 석재 받침 = `ec_base.py` `GST` · 나무 = 버들항 wood.
2. 팔레트 키워드: 그을린 붉은 벽돌 + 검은 철 + 황동 반짝임(톤 5~6 은 관 위 1/4 빛줄·리벳·계기 바늘에만 점으로) + 녹청 지붕. 증기 = 흰 회색 덩이(투명 아님, 4~5단 손 도트 구름, 가장자리 디더 없음) · 불빛 = `SIGNAL['amber']` 따뜻한 호박색(가로등·보일러 창). 채도는 황동만 높고 나머지는 낮게(매연 낀 도시).
3. 기계 어휘: 톱니(이 수 8~16, 허브 황동·몸통 검은 철), 압력계(둥근 황동 테 + 흰 판 + 검은 바늘, 글자 없음), 관(지름 4~6px, 이음 테 = 지름 +2px, 16px 간격), 밸브 바퀴, 굴뚝 머리 갓, 피스톤. 관은 반드시 벽·기계·땅으로 들어가거나 이음 테로 끝난다(허공에서 끊김 금지).
4. 땅: 젖은 검은 자갈(버들항 포석 결을 어둡게), 철판 바닥(`fr_mat.panels`), 석탄 가루·기름 웅덩이(무지개 띠는 톤 2~3 에 1px 만)·증기 고인 물. 하늘(전투 배경) = 매연 낀 황회 띠 3~5단 + 굴뚝 실루엣 2겹 + 손으로 찍은 증기 덩이.
5. 금지: 글자·숫자(계기판·간판은 무늬만), 사람·캐릭터, 원작 고유 디자인·문장, 네온·형광, 그라데이션 번짐, 안티앨리어싱.

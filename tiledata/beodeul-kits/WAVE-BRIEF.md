# 버들항 화풍 장소 웨이브 — 작업자 지침 (감독자, 2026-10-07)

사용자 목표: 「버들항을 근거로 판타지 장소를 만들고, JRPG 대부분을 이 그래픽으로 만들 수 있어야 한다.」
너는 아래 담당 장소 2곳의 **조각(parts)과 데모 맵**을 만든다. 조각은 나중에 공용 시트(`beodeul_city`)에 구워져 조수(AI)가 `stamp_object` 로 찍는다.

## 먼저 읽는다 (너의 워크트리 안, 필요한 절만 grep -n + 범위로)
1. `tiledata/beodeul-kits/SPEC.md` — 키트 규약(걷기·가림, 메타, 16변형 오토타일). **어기면 불합격.**
2. `tiledata/beodeul-variants/BRIEF.md` — 앞 20곳 작업 지침(화풍·팔레트·3/4·맵 규칙). 이번에도 같다.
3. 기준 작업 하나를 열어 본다: `tiledata/beodeul-variants/snowfield/` (`make_snowfield.py`, `parts.md`, `plan.md`, `parts/`, `render-1x.png`) 와 `volcano-cave/`, `castle-catacombs/` (던전). 공용 라이브러리 `tiledata/beodeul-variants/{varlib,vprops,dprops,mprops,place,bdv}.py` 와 `_lib3/`. 새 재료는 같은 7단 명암 팔레트(0=윤곽,1~6)로 추가한다.
4. 기준 그림을 직접 연다: `/tmp` 가 아니라 `python3 scripts/content/beodeul-kits/gallery.py --out tiledata/beodeul-kits/_out-<너> --prefix bd-pick-snowfield --name ref --cols 8` 로 갤러리를 만들어 본다. 네 그림은 이 옆에 놔도 같은 화풍이어야 한다.

## 규칙
- 3/4 시점(윗면+앞면, 옆면 없음), 빛 왼쪽 위, 16px 칸, 손 도트. **생성 이미지·트레이싱 금지.** 외부 게임 픽셀 복사 금지.
- **걷기·가림(SPEC §2):** 나무·덤불·기둥·동상·등롱 같은 키 큰 부드러운 물체는 맨 아랫줄(줄기·밑동)만 막힌다. 위 칸은 걷기+가림. 단단한 몸통(관·제단·광차·상자)은 몸통 줄만 막는다.
- 던전·실내 조각: 천장 밑에는 벽 앞면 2~3줄, ㅁ자 고립 방 금지, 계단은 바닥 위·시트 모양 그대로.
- 맵: 목적 먼저(plan.md), 빈 바닥은 메우지 말고 줄인다, 한 화면(20×15) 빈 바닥 ≤40%, 자연 덩이 배치(일렬 금지).
- 사람 얼굴·글자·상표·실제 게임 고유 요소 금지(「원작 이름·고유 디자인」을 흉내 내지 않는다 — 일반 JRPG 어휘로).

## 산출물 (장소마다 `tiledata/beodeul-variants/<slug>/`)
1. `plan.md` — 용도·구역·앵커·동선(맵 크기: 필드 64×48~96×64, 던전 40×30~64×48).
2. `make_<slug>.py` — 다시 돌리면 같은 그림.
3. `parts/*.png` — **새로 그린 조각만**(기존 버들항 그림은 다시 내보내지 않는다). 16의 배수 크기(`pad` 로 맞춘다, 물체는 왼쪽 아래 정렬). 종류와 최소 수:
   - 물체·식생·소품 **25개 이상**, 키가 큰 것은 3/4 로 윗면이 보이게.
   - **바닥 표본** 3×3칸(48×48) 이어 붙여도 이음새가 안 보이는 것 2~4종(`ground-*.png`).
   - **벽 앞면·절벽·천장 표본**(`face_*`, `ground-cliff`, `ceiling_*`) 던전은 필수.
   - **16변형 오토타일 시트** 1~3개: `autotile-<이름>.png` = 64×64(4×4칸). 칸 번호 = 위쪽 이웃 1 + 오른쪽 2 + 아래 4 + 왼쪽 8 (0~15, 왼쪽 위 칸이 0, 가로로 4칸씩 번호 증가). 걷는 땅 위에 덧그리는 **투명 가장자리** 오토타일(눈이 풀 위로 번진 자리, 흙길, 이끼, 균열, 용암 자국, 울타리·담 등 — 이웃이 없는 쪽은 들쭉날쭉한 가장자리 또는 테두리). 번호 0 은 이웃이 없는 외톨이 조각, 15 는 속 칸.
   - 문·계단·다리 등 입구 조각(해당될 때).
4. `partmeta.json` — 조각별 메타(굽는 스크립트가 읽는다):
   ```json
   {"<파일 이름(확장자 없이)>": {"kind": "object|tree|floor|wall|liquid|decal|walk|autotile",
     "ko": "한글 이름", "desc": "무엇이고 어디에 쓰는지 한 문장", "rules": "놓는 법: 발자국·놓을 땅·피할 곳·덩이 규칙",
     "brows": 1, "layer": "lower|upper (autotile 만)", "role": "fence|terrain|wall|prop"}}
   ```
   `brows` = 막히는 아랫줄 수(키 큰 부드러운 물체 1, 단단한 몸통 1~2, 칸 전체 막힘은 높이). **모든 조각에 ko/desc/rules 필수.**
5. `parts.md` — 조각 목록(`- \`parts/x.png\` (WxH px) — 설명 / WxH칸` 형식, 앞 20곳과 같다).
6. `render-1x.png`, `render-2x.png`, `grid.json`(걸음/막힘).
7. 시각 검증 페이지: `~/claude-viz/beodeul-wave-<slug>.html`(자체완결, 데이터 URI 또는 같은 폴더 사본): 맵 1x 전체, 2x 확대 2곳, **조각 판(번호 붙임)**, 오토타일 16칸 시트, 통행 격자 겹침. 적대적 QA: 원 해상도 사분면을 직접 보고 박스 모양·반복 무늬·어색한 경계·잘린 물체·길 끊김·통행 막힘을 찾아 고친다(고친 목록을 보고).

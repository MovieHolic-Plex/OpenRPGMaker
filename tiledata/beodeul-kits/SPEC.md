# 버들항 키트 규약 (2026-10-07)

버들항(`beodeul_city`) 그림을 근거로 판타지 장소·JRPG 맵을 계속 늘리기 위한 키트 규약. 조각을 새로 그리는 사람·에이전트와
조수(스탬프 도구)가 같은 약속을 쓴다. 검사·소급 적용은 `scripts/content/beodeul-kits/contract.py`, 갤러리는 `gallery.py`.

## 1. 시점·화풍 (그림)
- 16px 칸, 3/4 탑뷰: 물체 = 앞면 + 윗면이 보인다(옆면 없음). 빛은 왼쪽 위. 윤곽은 색 윤곽, 시트 팔레트만.
- 나무·건물은 기존 원본 픽셀을 보존한다. 새 조각은 `tiledata/beodeul-variants/_lib` 의 그리기 함수·팔레트를 쓴다.
- 눈으로 기준 그림 옆에 놓고 판정한다. 기계 통과는 시각 합격이 아니다.

## 2. 걷기·가림 규칙 (walk-behind)
- **키 큰 부드러운 물체**(나무·덤불·가로등·동상·기둥·표지판·전나무)는 **맨 아랫줄(땅에 닿는 칸)만 막힌다.**
  그 위 칸(수관·등·꼭대기)은 지나갈 수 있고, 위층(`priority:"upper"`)이라 캐릭터를 가린다. 나무 뒤로 걸어 지나갈 수 있다.
- 아랫줄에서도 아래 반이 실제로 칠해진 칸만 막는다(줄기·밑동). 수관 가장자리 칸은 열려 있다.
- 노점·탁자·우물·받침처럼 **단단한 몸통**은 몸통 줄(보통 아래 1~2줄)이 막히고 차양·윗면은 ★(걷기+위층).
- 건물 벽은 막히고 처마·지붕 칸은 걷기(기존 건물 번들 규칙). 건물 앞 한 칸(문 앞)은 키트 밖 길이다.
- 땅 장식(풀·꽃·자갈·뼈)은 걷기 + 사람 아래.
- 타일 한 장은 한 통행 값을 가진다(같은 그림 = 같은 칸 번호). 그래서 수관 칸을 연다는 것은 그 칸이 어느 나무에서나 열린다는 뜻이다.
  규약 적용은 `contract.py apply` → `footprintOpened` 에 열린 칸 번호를 남기고 `beodeulCity.ts` 가 기존 프로젝트에도 맞춘다.
- 시트·표를 다시 구우면(`build-beodeul-city.py`·`bake_picks.py`) 규약이 자동으로 다시 적용된다.

## 3. 키트 메타 (조수가 읽는 것)
모든 키트에 `ai.description / placementRules / tags / role` 이 있어야 한다(`contract.py check` 가 센다).
- `role`: building · prop · tree · wall · terrain · water · decal. `layerHome`: 물체 `upper`, 바닥 표본 `lower`, 섞이면 `perCell`.
- `placementRules` 한 줄에 **발자국(막힘 줄)·놓을 땅·피할 곳**(문 앞·길·다리 끝)·덩이 규칙(일렬 금지)을 쓴다.
- 이어 찍는 물체는 `repeatability` 와 반복 축. 울타리·돌담은 §4.

## 4. 울타리·담·길 (이웃으로 모양이 바뀌는 것)
- **오토타일 16변형.** 칸마다 위 N=1 · 오른쪽 E=2 · 아래 S=4 · 왼쪽 W=8 이웃이 있는지로 번호(0~15)를 정한다.
  4칸 이웃이면 2의 4제곱 = 16가지뿐이라 16칸이면 모든 모양이 닫힌다(8방향이면 47가지).
- 위층 투명 오토타일(`layer:"upper"`, `neighborhood:4`)로 등록하면 붓·채우기·`lay_path` 가 이웃에 맞춰 칸을 고른다. 땅을 지우지 않는다.
- 모든 변형 칸은 막힘(문 칸은 별도 게이트 키트).

## 5. 번들 소유 참고문서 (AGENTS.md 하드 룰)
새 조각·새 장소는 `bake_picks.py` 가 시트 꼬리·키트·참고문서(`beodeulCityReferences.json`, 용도별 MD + 칸 배열 + 조각 판 그림 + 오류 그림)에 같이 굽는다.
한 프로젝트 행에만 넣고 끝내지 않는다. 문서 한도: 용도 32 · 문서 64/용도 · 그림 256 · 그림 합 4MB.

## 6. 장소(맵) 규약 요약
목적 먼저(plan.md: 용도·구역·앵커·동선) → 빈 바닥은 메우지 말고 맵을 줄인다 → 한 화면(20×15) 빈 바닥 ≤40% →
던전은 천장 밑에 벽 앞면 2~3줄, ㅁ자 고립 방 금지 → 나무는 덩이로(일렬 금지), 줄기는 밑변과 같은 폭.

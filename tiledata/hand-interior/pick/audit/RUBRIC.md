# 실내 기물 3/4 시점 엄격 검수 규칙 (적대 검수자용)

당신은 **떨어뜨리는 쪽**이다. 「물건으로 읽힌다」는 합격 사유가 아니다. 시점만 본다. 애매하면 FAIL.

## 시점 계약
- 바닥은 칸당 1:1 위에서 본 판(16px=1칸). 카메라는 남쪽 위에서 비스듬히 내려다본다(정면 고정, 광원 왼쪽 위).
- 바닥에 서는 물건은 **윗면(T) + 앞면(F)** 두 면이 보여야 한다. 옆면은 안 보인다(오른쪽 옆 1~2px 어둠만 허용).
- 종류별 기준 (T=윗면 px, 앞 가장자리 하이라이트 행까지):
  | 종류 | T(윗면) | F(앞면) |
  |---|---|---|
  | 벽 붙은 키 큰 가구(옷장·책장·찬장·진열장·벽난로·사물함·자판기·시계·금고·난로) | 4~6px, 앞 가장자리 하이라이트 1행, 처마 그림자 2px, 앞면은 안으로 들어감 | 나머지 |
  | 기둥·석주·목주·비석·룬석·오벨리스크 | **맨 위에 윗면이 보여야 함 — 둥근 단면은 타원 캡 3~4px(위 반원 밝음+아래 반원 테두리), 각진 단면은 윗면 판** | 키 |
  | 탁자·침대·카운터 | 상판이 깊이의 0.5~1.0배(8~14px+) | 다리·앞판 8~14px |
  | 의자·벤치·소파·회중석·좌석·왕좌 | **좌판 윗면 4~6px 가 보여야 함**, 등받이는 좌판 뒤(위쪽)에서 솟음, 앞에 다리/앞판 | 6~8px |
  | 상자·궤짝·관·석관·통·항아리 | 뚜껑/입구 윗면 4~8px (관·석관처럼 긴 상자는 뚜껑 윗면이 깊이만큼) | 8~16px |
  | 벽 부착물(액자·창·깃발·벽선반·벽걸이) | 평평해도 정상 (단 벽에서 튀어나온 선반판은 윗면 1~2px) | |
  | 바닥 깔개·마법진·배수구 | 위에서 본 판이 정상 | |
  | 생물·조각상·사람형·가는 막대(촛대·스탠드·횃대)·악기 | EXEMPT 가능 — 단 받침대·좌대가 있으면 그 윗면은 봐야 함 | |

## 금지 (FAIL 사유 코드)
- FRONT: 정면 도면 — 앞면만 있고 윗면이 없거나 1~3px 띠뿐.
- THIN: 윗면이 기준보다 얇음(예: 기둥 캡이 그냥 가로 띠, 상자 뚜껑 2~3px, 좌판 안 보임).
- SIDE: 옆에서 본 입면(옆 실루엣·L자 의자·옆에서 본 계단·옆판만 보이는 긴 의자).
- TOPDOWN: 위에서만 본 판 — 앞면(밑단 F)이 없음.
- CAP: 기둥류인데 위쪽 단면(타원/판)이 안 보임.
- MIXED: 한 기물 안에서 부분마다 시점이 다름(예: 몸통은 정면, 계단은 옆).

# v6 소품 다시 그리기에서 배운 것 (2026-09-29)

규칙 원본(gg-houses 워크트리 easyrpg-craft-study.md)에 덧붙일 후보다. 감독자가 합친다.

1. **윤곽을 자동으로 그을 때는 재질을 기억하는 캔버스가 필요하다.** 색이 아니라 (재질, 단)을 칸마다 적어 두면
   실루엣 테두리를 "그 칸 재질의 0단"으로 한 번에 바꿀 수 있다. 나무는 짙은 고동, 천은 짙은 적색이 저절로 나온다.
2. **2px 폭 부재(의자 다리·등받이 기둥)는 자동 윤곽에 통째로 먹힌다.** 양쪽이 다 투명과 닿기 때문이다. 밝은 가운데 줄을 남기려면 3px 로 그리거나 윤곽을 건너뛴다.
3. **가는 잎은 0단 윤곽을 주면 까맣게 뭉친다.** 식물은 화분만 0단으로 긋고, 잎 테두리는 한 단 어두운 1단으로 긋는다. 원본 크기에서 "화분 위 검은 덩어리"가 "잎 다발"로 바뀌었다.
4. **통 뚜껑 타원의 가로 반지름은 몸통 윗줄 반폭과 같아야 한다.** 몸통 윗줄이 좁으면 뚜껑이 챙 넓은 모자처럼 튀어나온다.
5. **바구니 엮음은 1px 점이 아니라 2칸씩 엇갈린 블록이다.** 3칸마다 한 점 찍은 눈은 치즈 구멍처럼 보였고, 세로 살만 넣으면 나무 궤짝으로 읽혔다.
6. **천 가구(소파·안락의자)는 두 톤만으로는 부위가 합쳐진다.** 틀·앞면 = 2단, 등받이·팔걸이 윗면 = 3단, 방석 = 4단처럼 부위마다 한 단씩 두고, 부위 안은 두 톤을 지킨다.
7. **자동 타일 조각(카운터)의 결은 x%16 으로 해시해야 L/M/R 이 이어진다.** 절대 x 로 해시하면 가운데 조각을 되풀이할 때 결이 끊긴다(v5 paint_slab 과 같은 규칙).
8. **색 줄은 남겨 둔 v5 가구와 맞춰 당긴다.** 사용자가 v5 식탁을 남겼으므로 나무 3·4단을 v5 식탁 윗면(#b77246) 쪽으로 옮겼다. 규칙 9(어두운 쪽 붉게)와 부딪히지 않게 0~1단만 붉게 두었다.
9. **"안쪽 조용함" 수치는 상품을 얹은 가구에서 거의 줄지 않는다.** 상품 그림(v5)의 대비가 그대로 남기 때문이다. 몸통과 상품을 나눠 재야 효과가 보인다(몸통만: 명도차가 크게 준다, results.json).
10. **애니메이션 가구는 v5 의 paint(t) 함수를 새 몸통 위에 다시 돌리면 된다.** 불꽃 자리만 같게 그리면 주기·이음새 검사가 그대로 통과한다. 단 v5 paint 가 장작 줄을 v5 색으로 덮는 경우(벽난로)는 paint 를 옮겨 적었다.

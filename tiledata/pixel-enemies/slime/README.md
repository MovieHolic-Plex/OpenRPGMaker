# 슬라임 측면 전투 시트

**직접 도트, AI 생성물 아님** — Python/Pillow로 정수 좌표를 직접 지정한 원화.
기존 64px 시트를 축소하거나 리샘플하지 않고, 원래 청록색 팔레트·기울어진 눈·반사광·기포를 48px 셀에서 다시 찍었다.

- 파일: `public/assets/generated/pixel-enemies/slime.png`
- RGBA **144×144**, **48×48 셀 3열×3행**, 원본 1:1 도트, 알파는 0/255만 사용.
- 오른쪽을 향한다. 대기 실루엣의 수평 중심은 **x=24**(픽셀 경계 좌표 기준).
- 접지 칸의 마지막 불투명 행은 **y=44**. 이동 칸은 y=39로 기준선보다 5px 떠 있다.
- 대기 몸통은 **18~20×14~16px**. 이동·공격·착지에서는 같은 크기의 몸을 늘이거나 눌렀다.
- 모든 셀 가장자리에 최소 1px 투명 여백. 왼쪽 위 광원, 6색, 3px 흰 반사광, 디더·안티앨리어싱 없음.

| 칸 (열,행) | 이름 | 동작 | 불투명 bbox | 크기 |
|---|---|---|---|---|
| (0,0) | idle_a | 가장 높고 좁게 부푼 숨 | (15,29)–(32,44) | 18×16 |
| (1,0) | idle_b | 1px 낮아지고 2px 넓어진 중간 숨 | (14,30)–(33,44) | 20×15 |
| (2,0) | idle_c | 다시 1px 눌린 낮은 숨 | (14,31)–(33,44) | 20×14 |
| (0,1) | windup | 뒤로 당겨 웅크림, 가는 눈 | (13,33)–(34,44) | 22×12 |
| (1,1) | move | 오른쪽 위로 도약, 뒤쪽 물방울 둘 | (12,23)–(35,39) | 24×17 |
| (2,1) | attack | 오른쪽 면으로 박치기, 열린 입과 물방울 셋 | (17,25)–(42,44) | 26×20 |
| (0,2) | recover | 바닥에 넓게 퍼지는 착지 | (12,33)–(35,44) | 24×12 |
| (1,2) | hit | 머리가 왼쪽으로 젖혀짐, > < 눈 | (13,29)–(34,44) | 22×16 |
| (2,2) | dead | 높이 5px 웅덩이로 녹음, X 눈 | (11,40)–(36,44) | 26×5 |

bbox는 **셀 내부 좌표, 양 끝 포함, 떨어진 점액 방울 포함**이다.
방울을 제외한 move 몸통은 (15,23)–(35,39), 21×17px이고 attack 몸통은 (17,28)–(38,44), 22×17px이다.
대기 루프는 `a → b → c → b`. 프레임별 윤곽은 직접 지정한 행별 구간이며 다른 프레임을 리사이즈하지 않는다.

| 문자 | 색 | 용도 |
|---|---|---|
| D | `#173451` | 청남색 외곽선·눈·입 |
| S | `#2d719b` | 그림자·빛 받는 외곽선 |
| B | `#299fb8` | 청록 몸통 |
| L | `#70d0d2` | 왼쪽 위 밝은 면·작은 기포 |
| H | `#b5ece4` | 기포·반사광 주변 |
| W | `#effff0` | 3px 흰 반사광 |

재생성: 저장소 루트에서 `python3 scripts/asset-gen/pixel-enemy/slime.py`.
Python 3와 Pillow만 필요하다. 원화 생성에는 이미지 입력·네트워크·난수를 사용하지 않는다.
아군 시트는 크기 비교판을 만들 때만 읽으며 슬라임 제작에는 사용하지 않는다.
스크립트가 크기·알파·팔레트·bbox·중심·기준선·여백·연결 성분·흰 반사광과 GIF 색/시간을 검사한다.
저장한 PNG도 다시 읽어 칸 배치와 원본 프레임 픽셀의 일치를 확인한다.

검토용 출력은 `.omo/pixel-enemy-slime/`에만 둔다(커밋 제외).

- `preview.png`: 경계선과 y=44 아래의 접지선을 표시한 **4배, 576×576** 시트.
- `cycle.gif`: #202840 배경 위 **4배, 192×192** 애니메이션. 대기 루프 2회 → windup → move → attack → recover → idle_a → hit → idle_a → dead.
- `scale.png`: **384×192** 비교판. `public/assets/generated/charset-battlers/actor1-0.png`의 (0,0) 48px 칸과 slime idle_a를 나란히 **동일한 4배율**로 표시한다. 아군의 마지막 불투명 행을 y=44에 맞추되 크기는 바꾸지 않는다. 현재 아군 bbox는 (10,21)–(31,44), 22×24px(무기 포함), 수직 이동은 0px이다. 슬라임 idle_a는 18×16px이다.
- `gif-*.png`: 실제 GIF에서 다시 읽은 주요 프레임.
- `validation.json`: 칸별 전체/몸통 bbox, 알파·크기·기준선 및 비교판 정렬 결과. 같은 결과를 표준 출력에도 출력한다.

새 초안을 `view_image`로 확인한 뒤 **두 차례 수정**했다. 첫 수정은 눈썹의 기울기와 기포를,
두 번째 수정은 얼굴 쪽 그림자·입 위치·공격의 열린 입·쓰러진 눈 주변 명암을 다듬었다.
각 수정 후 preview/scale을 다시 확인했고, 최종 GIF의 공격·쓰러짐 디코딩 이미지도 확인했다.
중간 비교판 `v1-*.png`, `v2-*.png`는 `.omo/pixel-enemy-slime/`에 남겼다.

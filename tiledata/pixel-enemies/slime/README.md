# 슬라임 측면 전투 시트

**직접 도트, AI 생성물 아님** — 이미지 생성 모델 없이 Python/PIL로 정수 픽셀 좌표를 직접 지정한 원화.
기존 starter 슬라임은 열거나 트레이스·축소하지 않았다. Monster1.png는 도트 밀도와 외곽선의 톤만 참고했으며 픽셀을 복사하지 않았다.

- 파일: `public/assets/generated/pixel-enemies/slime.png`
- RGBA 192×192, 64×64 셀 3열×3행, 원본 1:1 도트, 알파는 0/255만 사용.
- 오른쪽을 향한다. 대기 실루엣의 수평 중심은 셀 좌표 x=32(픽셀 경계 좌표 기준).
- 접지 프레임은 마지막 불투명 행 y=60, 이동 프레임은 y=50로 10px 떠 있다.
- 왼쪽 위 광원, 몸 5단 명암과 3px 흰 반사광. 디더·안티앨리어싱 없음.

| 칸 (열,행) | 이름 | 동작 | 불투명 bbox | 크기 |
|---|---|---|---|---|
| (0,0) | idle_a | 가장 높고 좁게 부풀어 오른 숨 | (15,31)–(48,60) | 34×30 |
| (1,0) | idle_b | 2px 낮아지고 2px 넓어진 중간 숨 | (14,33)–(49,60) | 36×28 |
| (2,0) | idle_c | 다시 2px 눌린 낮고 넓은 숨 | (13,35)–(50,60) | 38×26 |
| (0,1) | windup | 뒤로 당겨 웅크림, 가는 눈; idle_a 대비 폭 +6/높이 −8 | (9,39)–(48,60) | 40×22 |
| (1,1) | move | 오른쪽 위로 늘어나 도약, 뒤쪽 물방울 둘 | (9,22)–(53,50) | 45×29 |
| (2,1) | attack | 평평한 오른쪽 면으로 박치기, 큰 입과 점액 방울 셋 | (23,26)–(61,60) | 39×35 |
| (0,2) | recover | 바닥에 넓게 퍼지는 착지, 정상 눈 | (12,37)–(52,60) | 41×24 |
| (1,2) | hit | 머리가 왼쪽으로 젖혀짐, > < 눈 | (11,33)–(50,60) | 40×28 |
| (2,2) | dead | 높이 8px 웅덩이로 녹음, x x 눈 | (10,53)–(54,60) | 45×8 |

bbox는 **셀 내부 좌표, 양 끝 포함, 떨어진 점액 방울 포함**이다.
대기 루프는 `a → b → c → b`. 프레임별 윤곽은 직접 지정한 행별 구간이며, 다른 프레임을 리사이즈하지 않는다.

| 문자 | 색 | 용도 |
|---|---|---|
| D | `#173451` | 청남색 외곽선·눈·입 |
| S | `#2d719b` | 그림자·빛 받는 외곽선 |
| B | `#299fb8` | 청록 몸통 |
| L | `#70d0d2` | 왼쪽 위 큰 밝은 면 |
| H | `#b5ece4` | 작은 기포·반사광 주변 |
| W | `#effff0` | 3px 흰 반사광 |

재생성: 저장소 루트에서 `python3 scripts/asset-gen/pixel-enemy/slime.py`.
Python 3와 Pillow만 필요하다. 이미지 입력·네트워크·난수는 사용하지 않는다.
스크립트가 크기·알파·팔레트·bbox·중심·기준선·여백·고립 픽셀과 GIF 색/시간을 검사한다.

검토용 출력은 `.omo/pixel-enemy-slime/`에만 둔다(커밋 제외).
`preview.png`는 경계선을 표시한 4배 시트이며, `cycle.gif`는 #202840 배경 위 4배 확대다.
GIF 순서: 대기 루프 2회 → windup → move → attack → recover → idle_a → hit → idle_a → dead.
`gif-*.png`는 실제 GIF에서 다시 읽은 주요 프레임, `validation.json`은 규격 검사 결과다.
초안 이후 실루엣·배색 수정과 호흡·표정 수정을 두 차례 거쳐 육안 검토했다.

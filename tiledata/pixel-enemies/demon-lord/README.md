## 제작·규격

Python 3 + Pillow로 최종 96px 격자에 부위 마스크(다각형·타원·둥근 끝 선)를 그리고, 마스크 경계에 1px 외곽선, 안쪽에 왼쪽 위 밝은 테·오른쪽 아래 어두운 테를 칠하는 방식으로 직접 찍은 OPRN Studio 원작이다. 해골 견갑·눈·입·징은 손으로 친 픽셀 격자다.
AI 이미지 생성은 쓰지 않았다. 아군 비교 그림(actor1-0)은 검토 보드에만 쓴다(출처: `assets/easyrpg/AUTHORS.md`).

- 셀 96×96, 3열×3행, 시트 288×288 RGBA, 실제 사용 16색(투명 제외), 알파 0/255, 고립 픽셀 0.
- 오른쪽(아군 쪽) 보기: 몸은 3/4 정면, 얼굴·입·턱을 오른쪽으로 1~2px 틀어 오른쪽 눈이 더 보이고, 공격은 오른쪽으로 뿜는다. 몸 중심 x≈48, 모든 칸 바닥 y=92.
- 광원 왼쪽 위: 왼쪽 망토 날개에 밝은 주름, 먼 쪽(오른쪽) 날개는 그늘. 근육·뿔·장화는 위/왼쪽 밝은 테, 아래/오른쪽 어두운 테.
- 크기: idle_a 경계 87×90px(망토 폭 87, 뿔 끝~발 88). 망토·뿔 제외 몸은 머리칼 끝~발 약 81px, 얼굴 위~발 약 73px. actor1-0 대기 칸 몸(23×24px)의 높이 3.75배.

## 디자인

사용자가 준 디자인 참고(쯔꾸르 2000 RTP Demon Lord 원화 확대본)에서 **디자인 요소만** 가져왔다: 날개처럼 좌우로 펼친 찢어진 붉은 망토(검은 윗단·갈퀴 같은 끝·구멍), 팔짱 낀 보라 근육질 거구, 위로 휜 금색 황소 뿔, 검은 가시 머리칼과 뾰족 귀, 붉은 눈, 양어깨 해골 견갑, 가슴 쇠사슬, 검은 샅가리개, 징 박힌 허벅지 띠, 검은 정강이, 은색 발목 고리, 끝이 말린 붉은 뾰족 장화.
**원화 픽셀은 재료로 쓰지 않았다**(축소·트레이스·팔레트 교체 없음, 생성기는 원화 파일을 읽지 않는다). 형태·비율·자세는 96px 격자에 맞춰 좌표로 새로 설계했고, 원화는 `.omo/demon/compare.png` 비교 보드에만 나란히 놓았다.

## 아홉 칸

| 행/열 | 0 | 1 | 2 |
|---|---|---|---|
| 0 | idle_a | idle_b | idle_c |
| 1 | windup | move | attack |
| 2 | recover | hit | dead |

- idle a→b→c→b: 팔짱, 몸 1px 들썩, 망토 찢긴 끝이 2~3px 펄럭이고 날개 끝이 1~2px 들림.
- windup: 팔짱을 풀고 주먹을 쥐며 망토가 가장 크게 부풂(폭 94px), 눈·입에 보라 빛, 양손에 보라 불티.
- move: 먼 쪽 손을 오른쪽으로 뻗어 손끝에 보라 암흑 구슬을 모음(제자리).
- attack: 몸을 뒤로 조금 빼고 손에서 칸 오른쪽 끝까지 굵게 퍼지는 보라 불꽃 줄기(어두운 보라 외곽, 톱니 불꽃 혀, 물결치는 보라 띠, 흰 심지, 칸 끝에서 잘림).
- recover: 주먹을 거두는 중간 자세, 남은 불티.
- hit: 몸·머리를 뒤로 젖히고 눈을 질끈 감음, 뿔이 뒤로 기울고 망토가 몸 쪽으로 접힘. 가까운 팔은 배를 감싸고 먼 팔은 턱 앞을 가드.
- dead: 무릎 꿇고 앞으로 고꾸라짐, 망토가 등을 덮으며 바닥에 무너지고 뿔 끝이 바닥에 닿음, 눈이 꺼짐, 암흑 잔불.

칸별 경계(폭×높이): idle_a 87×90, idle_b 91×91, idle_c 91×91, windup 94×92, move 91×91, attack 94×90, recover 91×90, hit 57×83, dead 87×55. 가장 비슷한 두 칸도 996px 다르다(idle_b/idle_c).

## 재생성·직접 검토

```sh
python3 scripts/asset-gen/pixel-enemy/demon-lord.py
```

생성기가 검사해 한 줄로 출력하고, 어기면 exit 1: 시트 크기, 알파 0/255, 색 수 ≤16, 빈 칸 없음, 칸끼리 모두 다름, 칸 밖 침범 없음, 바닥선 y=92, 고립 픽셀 0, PNG 재로드 일치, GIF 시간축 대조.
검토 산출물(세션 로컬, Git 제외): `.omo/pixel-enemy-demon-lord/` 의 preview·cycle·scale·validation.json, 재작업 보드 `.omo/demon/` 의 preview.png·cycle.gif·scale.png·compare.png 와 회차별 이전 판 `round0/`~`round4/`.

## 수정 기록

2026-09-28 전면 재작업. 이전 판(작은 판금 갑옷 인간 + 가시 왕관 + 숫양 뿔, 몸 50×81)은 보스 위압감이 없다는 평가로 폐기하고 새로 설계했다. 이전 시트는 `.omo/demon/round0/old-sheet.png`.

직접 `view_image` 로 본 뒤 고친 기록:
1. 1차 초안: 펼친 망토·근육질 거구·팔짱 기본형. 망토 주름이 부채살처럼 규칙적이라 굴곡을 불규칙하게 하고, 광원 쪽(왼쪽) 날개만 밝은 주름, 먼 날개는 그늘로. 뿔을 굵게, 얼굴을 오른쪽으로 치우침.
2. dead 가 형체 없는 덩어리라 무릎 꿇고 고꾸라진 자세로 다시 그림(망토가 등을 덮고 뿔이 바닥에). attack 불꽃을 손 쪽으로 당김. 가슴 근육 가르는 선.
3. dead 손가락·머리칼 정리, hit 머리를 더 젖힘.
4. 감독 피드백 반영: attack 불꽃을 칸 끝까지 굵게 퍼지는 줄기로(톱니 불꽃 혀·어두운 외곽·흰 심지), hit 의 떨어진 막대 팔을 몸 앞 가드로, 얼굴·눈을 1~2px 오른쪽으로, idle 망토 펄럭임 폭을 키움(최소 칸 차이 501 → 996px).
5. 줄무늬 원뿔처럼 보이던 불꽃에 불규칙한 혀·물결 띠를 넣고, hit 가드 손이 해골 견갑 앞에 보이도록 그리기 순서 조정.

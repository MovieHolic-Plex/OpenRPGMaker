# 박쥐 측면 전투 시트

**직접 도트, AI 생성물 아님**: 기존 박쥐의 보라색 날개·붉은 눈·갈색 털·송곳니와
14색 팔레트를 유지하며 문자 그리드와 정수 좌표를 48px 셀에 새로 저작했다.
64px 원본의 축소 리샘플·트레이스·이미지 생성 모델을 사용하지 않았다.

재생성: `python3 scripts/asset-gen/pixel-enemy/bat.py` (Python 3 + Pillow).
출력: `public/assets/generated/pixel-enemies/bat.png`, **RGBA 144×144**,
**48×48 셀 3열×3행**, 1:1 도트. 오른쪽을 보며 기준 중심 **x=24**,
바닥 기준선 **y=44**(사망 칸의 마지막 불투명 행), 왼쪽 위 광원, 그림자 없음.
알파는 0/255만 사용하고 셀 테두리 1px는 비워 둔다.

좌표는 셀 내부의 0부터 시작하는 **양 끝 포함** 불투명 bbox다.
크기는 날개·귀·발톱을 모두 포함한 외곽이며, 귀~발 몸 높이는 살아 있는 모든 칸에서 16px다.

| 칸 (열,행) | 이름 | 동작 | bbox (x0,y0,x1,y1) | 전체 폭×높이 |
|---|---|---|---|---|
| (0,0) | idle_a | 날개를 올리고 공중에 뜬 자세 | (8, 12, 39, 29) | 32×18 |
| (1,0) | idle_b | 날개를 수평으로 펴며 몸이 1px 내려옴 | (8, 15, 39, 31) | 32×17 |
| (2,0) | idle_c | 날개를 내리며 몸이 다시 1px 내려옴 | (8, 16, 39, 33) | 32×18 |
| (0,1) | windup | 몸을 왼쪽으로 당기고 날개를 올리며 입 벌림 | (8, 13, 39, 30) | 32×18 |
| (1,1) | move | 몸을 오른쪽 아래로 보내며 비대칭 날개로 활공 | (8, 16, 39, 31) | 32×16 |
| (2,1) | attack | 오른쪽으로 입과 발톱을 내밀어 물어뜯음 | (9, 14, 40, 31) | 32×18 |
| (0,2) | recover | 날개를 내려치며 위로 되돌아오름 | (8, 13, 39, 31) | 32×19 |
| (1,2) | hit | 왼쪽으로 튕겨 날개가 흐트러지고 눈을 감음 | (8, 15, 39, 33) | 32×19 |
| (2,2) | dead | 배를 위로 하고 날개·귀를 접어 y=44에 쓰러짐 | (9, 35, 39, 44) | 31×10 |

대기 루프는 a→b→c→b. 몸통 폭 9px(돌출된 주둥이 제외), 귀~발 16px,
펼친 날개 폭 32px다. 대기 몸 중심 y는 21.5→22.5→23.5이며,
각 대기 칸의 최하단 y는 29/31/33으로 모두 34 이하다. 사망 칸만 바닥 y=44에 닿는다.
회복·피격 칸의 전체 높이 19px에는 아래로 뻗은 날개 끝이 포함된다.

| 용도 | 문자 → HEX |
|---|---|
| 외곽선·털 5단 | o `#201b30`, s `#383044`, b `#544453`, h `#77616c`, l `#a18a91` |
| 날개 막 (o와 함께 5단) | v `#37304e`, m `#51416d`, p `#71568b`, q `#9573aa` |
| 귀 안쪽 | i `#a35c7b` |
| 눈·입 | r `#b33353`, e `#ff6b72` |
| 발톱·송곳니 | t `#b9aab0`, w `#f0dfc2` |

스크립트는 크기·알파·팔레트·셀 여백·전체 폭(30~34px)·중심 정렬·몸통 폭·몸 높이·
대기 고도·사망 기준선 및 각 칸이 하나의 8방향 연결 덩어리인지 검사한다.
저장 PNG를 재로드해 같은 검사를 수행하고 원본 바이트와 비교한다.
GIF도 재로드해 모든 프레임 픽셀과 시간을 확인한다. 결과는 `validation.json`에 기록하고 출력한다.

검토 산출물은 `.omo/pixel-enemy-bat/` 안에 생성한다.

| 파일 | 내용 |
|---|---|
| `preview.png` | 576×576, 4배 정수 확대, 셀 경계와 동작 이름 |
| `cycle.gif` | 192×192, 4배, 배경 `#202840` |
| `scale.png` | 432×456, 아군 actor1-0의 (0,0) 48px idle 칸과 박쥐 idle_a를 각각 같은 4배로 비교 |
| `gif-keyframes.png` | 저장한 GIF에서 추출한 주요 동작 |
| `validation.json` | 크기·알파·칸별 bbox·몸 치수·기준선·연결 검사 |

`scale.png` 위쪽 비교는 실제 발 최하단을 y=44에 맞춘다. 아군은 y=44라 이동 0px,
박쥐 idle_a는 y=29라 **비교판에서만 아래로 15px** 이동한다.
아래쪽 비교는 공통 바닥 y=44를 두고 박쥐의 원래 부유 위치를 유지한다.
아군 idle 불투명 외곽은 무기 포함 22×24px, 박쥐는 날개 포함 32×18px이며 몸통은 9×16px다.

GIF 순서: 대기 2회 → windup → move → attack → recover → 대기 → hit → 대기 → dead.
미리보기만 nearest-neighbour로 확대하며 배포 PNG에는 확대·축소·보간을 적용하지 않는다.

48px 초안과 비교판을 `view_image`로 직접 확인한 뒤 두 차례 수정했다.
1. 붉은 눈·털 하이라이트를 정리하고 이동·사망 날개 폭을 계약에 맞춤.
2. 준비 날개를 낮추고 공격 발톱의 밝은 고리를 제거하며 입 안과 접힌 날개·발의 명암을 정리.

최종 시트·비교판·GIF 추출 프레임을 다시 시각 검토했다.
초안 증거는 `review-0-*.png`, 1차 수정 증거는 `review-1-*.png`에 보존했다.
미리보기·중간안은 커밋하지 않는다. 런타임 코드는 변경하지 않는다.

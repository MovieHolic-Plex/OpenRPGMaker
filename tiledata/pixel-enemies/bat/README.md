# 박쥐 측면 전투 시트

**직접 도트, AI 생성물 아님**: 이미지 생성 모델을 사용하지 않았다. 코딩 에이전트가
문자 그리드와 정수 픽셀 좌표를 직접 저작한 원본이다. 기존 그림의 참고·트레이스·축소·복사 없음.

재생성: `python3 scripts/asset-gen/pixel-enemy/bat.py` (Python 3 + Pillow).
출력: `public/assets/generated/pixel-enemies/bat.png`, RGBA 192×192,
64×64 원본 픽셀 3열×3행. 오른쪽을 보는 보라색 박쥐, 기준 중심 x=32,
왼쪽 위 광원, 그림자 없음. 불투명 14색 + 투명 1색, 알파는 0/255만 사용한다.

좌표는 각 셀 내부의 0부터 시작하는 **양 끝 포함** 불투명 bbox다.

| 칸 (열,행) | 이름 | 동작 | bbox (x0,y0,x1,y1) |
|---|---|---|---|
| (0,0) | idle_a | 날개를 올리고 공중에 뜬 자세 | (5,8,58,36) |
| (1,0) | idle_b | 날개를 수평으로 펴며 몸이 1px 내려옴 | (5,11,58,41) |
| (2,0) | idle_c | 날개를 내리며 몸이 다시 1px 내려옴 | (7,12,58,47) |
| (0,1) | windup | 왼쪽으로 몸을 당기고 날개를 치켜들며 입 벌림 | (4,3,50,37) |
| (1,1) | move | 날개를 뒤로 접고 오른쪽 아래로 활공 | (4,15,46,40) |
| (2,1) | attack | 머리·송곳니·발톱을 앞으로 내밀어 물어뜯음 | (7,11,60,40) |
| (0,2) | recover | 날개를 내려치며 왼쪽 위로 되돌아오름 | (4,8,58,43) |
| (1,2) | hit | 왼쪽으로 튕겨 날개가 흐트러지고 눈을 질끈 감음 | (5,11,54,44) |
| (2,2) | dead | 배를 위로 하고 날개·귀를 접어 y=60에 쓰러짐 | (10,45,54,60) |

대기 루프는 a→b→c→b. 몸통 이동은 칸마다 1px이며 펼친 날개 폭은 52~54px.
날개·몸통은 각각 어두운 외곽선부터 밝은 면까지 5단 계조를 공유한다.

| 용도 | 문자 → HEX |
|---|---|
| 외곽선·털 5단 | o `#201b30`, s `#383044`, b `#544453`, h `#77616c`, l `#a18a91` |
| 날개 막 (o와 함께 5단) | v `#37304e`, m `#51416d`, p `#71568b`, q `#9573aa` |
| 귀 안쪽 | i `#a35c7b` |
| 눈·입 | r `#b33353`, e `#ff6b72` |
| 발톱·송곳니 | t `#b9aab0`, w `#f0dfc2` |

스크립트는 크기·알파·색 수·셀 여백·대기 폭/높이·사망 기준선과 각 칸이
하나의 8방향 연결 덩어리인지 검사한다. 저장 PNG를 재로드해 원본 바이트와 비교하고,
GIF도 재로드해 모든 프레임 픽셀과 시간을 확인한다.

미리보기는 `.omo/pixel-enemy-bat/preview.png` (4배, 셀 경계),
`cycle.gif` (4배, 배경 `#202840`), `gif-keyframes.png`와 `validation.json`에 생성한다.
GIF 순서: 대기 2회 → windup → move → attack → recover → 대기 → hit → 대기 → dead.
미리보기만 nearest-neighbour로 확대하며 시트에는 확대/보간을 적용하지 않는다.

시각 검토 후 2회 수정: ① 날개 끝과 골격선 연결, 턱/입 실루엣 수정
② 털 명암을 연결된 면으로 정리, 공격 머리 전진, 쓰러진 날개의 접힘과 감은 눈 보강.
미리보기·중간안은 커밋하지 않는다. 런타임 연결은 별도 작업이다.

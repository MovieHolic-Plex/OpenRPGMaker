# 대형 보스 8종

원본: `scripts/asset-gen/pixel-enemy/refresh/bosses.py`. 전부 native96px이며 각 관절과 표면 군집을
해당 칸의 좌표에서 다시 그린다. `refresh/run.py --group bosses`로 재생성한다.

| 종 | 실루엣과 표면 |
|---|---|
| dragon | 황토빛 두 발 체형, 짧은 앞팔, 자주 피막 날개, S자 목과 배판 |
| dragon-red | 굵은 네 다리, 큰 턱과 뒤로 뻗은 뿔, 산호 비늘과 큰 등판 |
| dragon-blue | 길게 선 목, 은빛 가시, 고리로 감긴 꼬리, 넓은 푸른 날개 |
| dragon-bone | 빈 눈구멍, 노출된 갈비뼈/척추, 뼈 손가락과 찢긴 날개 피막 |
| wyvern-cliff | 날개를 앞다리로 사용, 두 뒷다리, 갈고리 손가락과 길게 뾰족한 꼬리 |
| minotaur-maze | 비대칭 두 뿔과 넓은 주둥이, 어깨/전완 근육, 허리 가죽과 양날 도끼 |
| troll-cave | 굽은 등, 이끼 어깨, 두꺼운 팔과 앞쪽 엄니, 큰 맨발 |
| demon-lord | 관/긴 뿔과 보랏빛 얼굴, 붉은 피막 날개, 어두운 흉갑과 분절된 허리 갑옷 |

대기에는 몸/목/날개/손의 변화가 있고 준비·공격은 턱과 앞쪽 관절을 크게 바꾼다.
미노타우르스의 도끼는 손과 함께 휘두른다. 쓰러진 뼈 드래곤은 떨어진 뼈와 두개골,
살이 있는 용은 누운 몸/접힌 날개/닫힌 턱을 새로 그린다. 모든 접지 칸의 끝은 y=92다.
지금 계약은 9개의 키 포즈이며 연속 보간 애니메이션을 그린 시트는 아니다.
실제 전투 대기 표시는 런타임 증거, 나머지 저작 동작은 포즈 보드/GIF로 확인한다.

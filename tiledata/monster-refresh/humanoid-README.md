# 공용 몬스터 손 도트 새 판 — humanoid 담당 29종

## 저작 원본과 재생성

`python3 scripts/asset-gen/pixel-enemy/refresh/humanoid.py`

공통 출력기는 `refresh/common.py`, 입력 목록은 `refresh/manifest.json`이다. 공개 함수는
`draw(slug, pose, cell) -> PIL.Image(RGBA)`이며 매번 빈 최종 48/64/96px 격자에 직접 그린다.
기존 그림을 입력하거나 축소·회전·통째 이동하여 포즈를 만들지 않는다. 좌표는 해부 구조의 관절과
윤곽을 직접 정의하며 최종 그림을 칠하기 전에 정수로 반올림한다. 원본 PNG는 확대하지 않는다.
검토용 GIF/보드만 nearest로 확대한다.

29종×9포즈=261칸, 기존 공용 ID·파일 경로·셀 크기·motion은 유지한다.
초상은 새 idle_a 픽셀과 동일하다. 수집 하네스에서 사람이 선택한 별도 sparkit-fire와 승인받은
hydra-three는 이 원본에 포함하지 않는다.

## 그림과 동작

- 고블린/오크/오거: 종에 따라 가슴·어깨·머리 비율을 달리한다. 오크의 큰 주둥이와 두 엄니,
  전사의 넓은 방패/축 방향에 맞춘 도끼날, 부족장의 통통한 몸과 곤봉, 샤먼의 뿔과 붉은 의복.
  어깨·팔꿈치·손목, 허벅지·무릎·발을 각각 움직여 준비·행동·타격·피격을 그린다.
- 인간/파충류 전사: 가면, 후드, 붉은 망토, 강철 갑옷, 코볼트의 긴 주둥이/광부 모자/곡괭이,
  리자드맨의 창/꼬리, 캇파의 등껍질/머리 접시/부리 등 실제 그림의 장비를 구분한다.
- 하피/타락천사/가고일/임프: 서로 다른 깃털·가죽·돌막 날개와 머리 장식.
  단단한 날개 덩어리에 짧은 덮깃과 겹치는 긴 비행깃을 층으로 그린다.
  각 포즈마다 날개 끝·어깨·다리·머리·장비 좌표가 달라지며 쓰러짐은 접은 별도 윤곽이다.
- 그리핀: 밝은 독수리 머리와 갈고리 부리, 큰 황갈색 날개, 근육질 사족 몸과 넓은 발바닥.
  부리는 준비/공격에서 벌어진다. 베히모스: 보라색 몸과 솟은 목/어깨, 둥근 넓적다리,
  큰 뿔과 위로 휜 엄니, 청동색 어깨 판. 센타우르스는 말의 몸/4다리와 인간 상체가 연결된다.
- 로크/불사조: 부리·머리 볏·긴 꼬리깃·가슴 깃의 방향을 따로 정의한다.
  불사조는 붉은 꼬리와 주황/금색 날개, 로크는 청회색 깃을 쓴다.
- 샐러맨더: 넓적한 허벅지와 펼친 발, 굽은 꼬리와 볼/주둥이의 면.
  일반 종은 지느러미/아가미 부채, 화염 종은 등에서 높게 솟는 세 갈래 화염 윤곽을 가진다.
  새끼용은 푸른 비늘, 작은 가죽 날개와 뿔, 금갈색 배판을 별도로 그린다.
- 잎/불꽃/물 정령: 잎의 각진 얼굴과 잎맥, 번개 무늬의 불꽃 정령,
  물방울의 둥근 얼굴과 밝은 물빛 가장자리로 몸 윤곽과 장식을 구분한다.

## 근거와 범위

`verify-shots/monster-refresh/humanoid/report.json`에 각 포즈의 bbox·픽셀 해시,
시트 해시·색 수·알파를 기록한다. 출력기에서 저장 PNG를 다시 열어 그림 바이트와 비교한다.
알파는 0/255, 종별 모든 포즈를 합친 팔레트는 최대 17색(계약 상한 32색)이다.
모든 그림에 여백이 있고 지상/쓰러짐의 바닥은 cell−4, 비행/정령은 공중에 놓인다.

`contact-1.png`/`contact-2.png`는 29종 idle 그림이다.
`all-poses-1.png`부터 `all-poses-4.png`까지는 261포즈를 native 크기로 한꺼번에 보며,
각 종의 `*-poses.png`는 2배 보드다. 저작 중 전 포즈를 확인했고 큰 짐승의 허벅지·발,
오크의 주둥이·도끼·방패, 날개 깃의 덩어리, 샐러맨더의 화염 윤곽을 보강했다.
GIF는 저작 포즈 미리보기이며 실제 게임 녹화가 아니다.

48px 종의 얼굴·손가락 표현은 격자 크기에 따른 한계가 있다. 일반 JRPG 9칸 시트이므로 별도의
연속 걷기/비행 프레임은 추가하지 않았다. 런타임 연결·접촉 경계·캐시·자료집 변경은 부모가
통합한다. 이 담당 작업에서 사용자 프로젝트 SQLite, 커밋/원격 저장, gates/vitest/typecheck는
다루지 않았다.

## 종 인식 검토 후 머리 보강

그리핀은 높은 둥근 이마를 낮은 경사면으로 바꾸고 독수리의 굽은 부리, 짙은 눈썹과
볼/목의 층진 깃 끝을 더했다. 불사조의 뿔처럼 보이던 머리 윤곽은 뒤로 겹친 계단형 볏깃과
볼 부채깃, 굽은 새 부리로 바꿨다. 얼굴 뒤의 반대쪽 날개 끝이 뿔로 읽히던 부분은 볼 아래로
낮춰 얼굴과 분리했다. 두 종 모두 쓰러짐을 포함한 9포즈·초상·원본 칸·검토 그림을 다시
만들었으며 2배 포즈 보드를 열어 확인했다.

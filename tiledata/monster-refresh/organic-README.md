# Organic monster refresh — 직접 저작한 46종 / 414포즈

원본은 `scripts/asset-gen/pixel-enemy/refresh/organic.py`다. 기존 사진·일러스트·스프라이트를 읽거나
생성형 모델을 부르지 않는다. Pillow의 불투명 정수 점·선·다각형으로 최종 48px 또는 64px 칸에
직접 찍는다. 근육·털·껍질·지느러미의 밝은 면과 어두운 면도 같은 그리드에서 저작했다.

```bash
python3 scripts/asset-gen/pixel-enemy/refresh/organic.py
```

`draw(slug, pose, cell)` → RGBA 원본 칸. `common.run_group`이 기존 리소스 ID 경로에 3×3 시트와
idle_a 초상을 저장하고, 같은 PNG를 다시 열어 바이트 일치를 확인한다. 이미지 확대는 검토용
보드/GIF에서만 nearest-neighbor로 한다. 원본 그림에 회전·보간·리샘플·전체 비트맵 이동은 없다.

## 종별 조형

동물 계통은 관절 저작 코드를 공유하지만, 같은 윤곽의 색만 바꾸지 않는다.

- 늑대 3종: 작은 은회색 늑대, 흰 뺨털이 긴 큰 늑대, 머리를 낮춘 굵은 검은 갈기의 다이어울프.
- 고양이 계통: 짧은 주둥이와 둥근 눈의 황갈색 고양이, 낮게 웅크린 보라색 그림자고양이,
  어깨가 높고 두 개의 곡선 상아 송곳니가 드러나는 줄무늬 검치호랑이.
- 말·유니콘: 긴 비스듬한 얼굴과 주둥이 평면, 높은 목과 갈기, 길고 가는 발굽 다리.
  산양은 턱수염과 뒤로 굽은 뿔, 사슴은 반점과 갈래 뿔로 구분한다.
- 멧돼지는 둥근 큰 몸·뻣뻣한 등갈기·크게 휘어 오른 엄니, 곰은 둥근 귀와 무거운 앞발,
  쥐는 분홍 귀와 가는 긴 꼬리로 구분한다.
- 잎여우는 잎 모양 큰 꼬리와 등잎, 불강아지는 주황 털과 밝은 불꽃 꼬리,
  지옥개는 짙은 털과 등불꽃을 가진 긴 사냥개다.
- 거미 3종: 길고 낮은 동굴거미 배, 넓은 털배와 굵은 관절의 타란툴라, 높은 둥근 배와
  붉은 무늬의 과부거미. 여덟 다리는 앞·뒤 관절을 따로 그린다.
- 게 2종: 청회색 돌덩이 껍질과 붉은 유기 껍질. 두 집게 크기와 여닫는 끝 관절이 다르다.
- 전갈 2종: 가는 세운 모래색 꼬리와 머리 위로 큰 아치를 그린 청회색 꼬리.
  공격에서 독침 관절을 앞으로 내려 찍는다.
- 사마귀 2종: 밝은 칼날과 등날개가 큰 종류, 초록 몸과 휜 앞낫이 긴 종류.
- 장수풍뎅이는 남색 쌍갑판과 두 뿔, 병정개미는 구릿빛 둥근 배·가느다란 허리·긴 더듬이.
- 지네 2종: 수평으로 이어진 분홍 갑판과 수많은 다리, 아치형 붉은 갑판과 금빛 열가시.
- 벌은 줄무늬 배와 침, 나방은 넓은 네 날개의 눈무늬, 기생충은 이빨이 둘러진 둥근 흡착 입.
- 박쥐 3종: 보라색 몸과 살구 날개막, 붉은 날개막과 흡혈 송곳니,
  청회색 날개막과 매우 긴 붉은 속귀. 날개는 손가락 뼈와 막의 오목한 윤곽을 저작한다.
- 독사는 낮은 얼룩 코일, 코브라는 높은 후드와 배판. 모래벌레는 넓은 마디와 왕관형 이빨 입.
- 매는 비행 깃털과 앞으로 내민 발톱, 코카트리스는 볏·닭발·말린 가시 꼬리.
- 물고기는 긴 푸른 몸과 부채 꼬리. 피라냐는 더 깊은 압축 몸, 붉은 등가시와 넓은 이빨 턱.
- 육상상어는 큰 등지느러미와 여섯 보행 다리, 전기뱀장어는 금빛 톱니지느러미가 따라가는
  긴 곡선 몸, 오징어는 긴 외투막과 독립된 여덟 흡반팔이다.
- 돌유인원은 돌조각이 붙은 회녹색 근육과 큰 주먹을 갖고, 공격에서 앞팔을 가슴 위로 내민다.

정확한 46종 이름과 현재 그림의 한 문장 관찰은
`verify-shots/monster-refresh/organic/observations.json`에 있다.

## 원본과 검토 근거

- `public/assets/generated/pixel-enemies/<slug>.png`: 기존 48/64px 규격과 경로 유지.
- `public/assets/generated/pixel-enemy-portraits/<slug>.png`: idle_a와 바이트가 같은 원본 초상.
- `tiledata/monster-refresh/<slug>/<pose>.png`: 414개의 최종 원본 칸.
- `verify-shots/monster-refresh/organic/contact-1.png`~`contact-3.png`: 46종 idle 전체.
- `review-poses-1.png`~`review-poses-6.png`: 모든 종의 9포즈. 전량 시각 확인 후
  피라냐·다이어울프·말·검치호랑이 차별화와 쓰러진 꼬리·목·나방·오징어를 정정했다.
- `<slug>-poses.png`, `<slug>-cycle.gif`: 각 종의 저작 검토용 보드/움직임. 게임 녹화는 아니다.
- `report.json`: 46 시트 모두 기준선 SHA와 다름, 각 9칸 해시가 모두 다름,
  binary alpha 0/255, 팔레트 6~11색, 네 변 여백, 원본 재로드 동등성.
- 지상 포즈와 모든 dead 포즈의 실제 불투명 마지막 픽셀은 `cell-4`다.

이 작업은 공용 PNG 저작이다. 개별 사용자 프로젝트 DB 저장·실제 전투 플레이·런타임 메타데이터
갱신은 통합 담당자가 수행한다. 커밋·push·PR·merge·stash·gates·vitest·전체 typecheck는 하지 않았다.

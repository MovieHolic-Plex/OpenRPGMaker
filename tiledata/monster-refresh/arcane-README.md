# 공용 몬스터 손 도트 리프레시: Arcane 56종

## 저작과 재현

```bash
python3 scripts/asset-gen/pixel-enemy/refresh/arcane.py
```

`arcane.py`가 분류별 손 도트 소스를 선택한다. 모든 도형·외곽선·빛 덩어리·얼굴·무기·관절을 **최종 48/64px RGBA 캔버스에서 정수 좌표로 그린다**. 기존 그림을 읽어서 이동/회전/확대/축소하거나 생성형 이미지 서비스를 호출하지 않는다. `arcane_core.py`의 좌표 사상은 손으로 저작한 정점의 최종 픽셀 좌표 계산이며 비트맵 리샘플링이 아니다. 확대는 검토용 시트와 GIF에만 nearest를 쓴다.

각 종은 `idle_a / idle_b / idle_c / windup / move / attack / recover / hit / dead` 9포즈를 갖는다. 도트 시트는 3×3, 초상은 첫 셀의 바이트와 동일하다. 종의 리소스 ID·셀 크기·motion·idleFrameMs는 유지한다. 전투 수치와 기술 정의는 바꾸지 않는다.

## 종별 형태

- 슬라임: 물방울 기본형, 뾰족한 붉은 불꽃형, 점 기포가 있는 파랑형, 잎 볏 초록형, 날카로운 은빛 물방울, 세 갈래 왕관의 파랑 왕, 보석 장식 둥근 모자의 보라 왕, 투시가 있는 젤리 큐브, 낮게 퍼진 검은 우즈, 높이 솟은 기포와 산성 촉수를 가진 우즈. 몸을 눌러 준비하고 길게 늘여 뛰고 입을 벌려 공격하며 바닥 웅덩이로 무너진다.
- 골렘: 이끼 볏과 가슴 청록 보석의 바위 거인 / 회색 층리와 넓은 갈라진 암석의 돌 골렘 / 둥근 항아리 몸통·도기 손잡이 팔·뚜껑 머리의 점토 골렘 / 굴뚝과 붉은 보일러 중심의 철 골렘 / 큰 비대칭 자수정 어깨와 빛나는 결정 흉곽 / 다리 없이 분리된 돌과 잎 덩굴이 떠 있는 대지 정령. 광물 종의 준비는 주먹을 올리고 공격은 앞으로 내려찍는다. 죽음은 독립적으로 배치한 파편이다.
- 뼈와 언데드: 늑골·흉골·골반·팔꿈치·무릎을 따로 그린다. 궁수의 활과 화살, 기사의 십자 방패와 칼, 기본 해골의 뼈 몽둥이, 뿔 달린 부유 두개골과 척추, 두 두개골과 여러 뼈 다리의 크롤러는 장비와 몸의 형태가 다르다. 썩은 좀비는 붉은 찢긴 옷과 벌어진 턱, 구울은 엄니와 노출된 갈비뼈, 무덤 구울은 낮게 굽은 머리·흙 망토·큰 갈고리 손, 미라는 붕대 띠와 느슨한 끈, 리치는 보라 로브와 얼음 결정 지팡이, 복수자는 붉은 망토와 뿔 투구·핏빛 칼을 갖는다.
- 정령: 푸른 불꽃 도깨비불, 주먹 끝까지 불꽃이 갈라진 화염 정령, 뒤쪽 파도가 말려 올라간 물 정령, 수평으로 도는 바람 소용돌이, 별·광륜·큰 빛 날개의 빛 정령, 여섯 그림자 팔과 초승달 볏의 어둠 정령을 별도로 설계했다. 창백 유령은 넓은 수의, 기본 유령은 좁고 뒤로 말린 꼬리, 가면 정령은 긴 두 귀, 스펙터는 해골 후드, 레이스는 긴 낫, 밴시는 긴 머리카락과 갈라진 치마이다. 잎날개 실프와 긴 바람 리본·옆으로 뻗은 깃날개·쓸린 볏의 바람 실프를 구분한다. 운디네는 조개 왕관과 물고기 꼬리를 갖는다.
- 사물: 미믹의 목재 결·금속 띠·뒤쪽 뚜껑 경첩·양쪽 이빨·혀, 룬 소용돌이 주위의 다섯 부유 돌, 양옆으로 꺾인 호박의 빛나는 절개와 덩굴, 보석 가드와 해골 장식의 부유 검, 짚모자·삼베 얼굴·찢긴 붉은 코트의 허수아비, 네 관절 줄과 위쪽 십자 조종판의 인형, 서로 다른 폭의 나무 가면 세 층과 잎 볏의 토템을 그렸다.
- 생물: 카벙클은 청록 털·크게 말린 꼬리·긴 귀·이마 금색 보석, 말벌은 네 장의 길고 가는 날개·줄무늬 배·굽은 침·여섯 다리, 두 식충 식물은 잎 모양의 큰 위아래 턱과 둥근 붉은 꽃잎 가면으로 각각 구별한다. 레모라는 파랑 S자 목·넓은 아래 코일·금색 배판·붉은 지느러미를 갖는다.

## 검토와 증거

`verify-shots/monster-refresh/arcane/`:

- `contact-1.png` ~ `contact-4.png`: 56종 전체 기본 자세.
- `all-poses-1.png` ~ `all-poses-14.png`: 각 종의 9포즈를 네 종씩 묶은 검토판. 전 페이지를 시각 검토했다. 각 종 별 `*-poses.png`도 제공한다.
- `*-cycle.gif`: 자세 순환 확대 예시. 실제 게임 녹화가 아니다.
- `report.json`: 최종 PNG 재로드·알파 0/255·전체 9포즈의 실제 사용색 6~16색·셀 경계 여백·종 내부 9개 고유 프레임의 바이트 SHA 근거.
- `idle-uniqueness.json`: 56개 기본 셀의 RGBA 바이트가 모두 다르며 완전히 같은 셀은 없다.
- `observations.json`: 기본 자세에서 실제 보이는 형태를 설명하는 한국어 종별 문구.

그림 검토에서 골렘 실루엣, 실프 날개, 구울의 자세를 다시 설계했다. 골렘 준비/타격의 팔 진행과 미믹의 경첩도 수정했다. 포즈 수나 해시가 그림 품질의 근거를 대신하지 않는다.

이번 분할 작업은 공용 에셋과 재현 소스의 로컬 변경이다. 정본 프로젝트 DB 저장이나 실제 게임의 전 포즈 동작을 검증한 작업이 아니다. 런타임 접촉 경계·공용 카탈로그 배선·전투 화면 검토는 통합 담당자가 진행한다. 커밋·푸시·PR·머지 및 gates/vitest/typecheck는 실행하지 않았다.

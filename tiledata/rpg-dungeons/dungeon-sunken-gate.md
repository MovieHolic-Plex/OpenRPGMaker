# 해저 신전 · 물에 잠긴 입구 회랑

해저 동굴 북쪽 굴길에서 남쪽 문 틈으로 들어오는 신전 입구 회랑. 가고일 둘이 지키는 문 틈을 지나면 무늬 석판 참배길이 북쪽으로 곧게 가고, 양옆에 석주 두 줄이 선다. 회랑 허리를 물길이 가로질러 판자 다리로 건너고, 참배길 끝 북쪽 벽의 석조 아치로 대전에 든다. 바닥이 꺼져 물이 찬 웅덩이 넷(네 모서리), 석주 밑동이 웅덩이에 닿는 두 곳(북서·남동)에만 붉은 산호 무리, 벽엔 해초가 늘어졌다. 36×23, tilesetId=oprn_dungeon_sea. 입구 (17,22). 통행 검사 목표 [[17,5],[18,12],[9,14],[27,14]].

출구: (17,22) → dungeon-sea-cave (15,1) 남쪽 문 틈 → 해저 동굴 북쪽 · (17,5) → dungeon-sunken-hall (19,27) 북쪽 벽 아치 → 산호 기둥 대전

![해저 신전 · 물에 잠긴 입구 회랑](images/dungeon-sunken-gate.png)

# 일본 세트 「새 결(v2)」 — 결 규칙과 전체 재작업 절차

> 발단(사용자): 「일본 칩을 보고 있는데 너무 '강남 결'을 따라한 것 같다. (스팀 상점 스크린샷) 이런 느낌은 힘든가? 데모 견본 함 만들어 봐」
> 참고 그림은 **보기만 했다** — 화소 복사·트레이싱 없음, 저장소에도 넣지 않았다(로컬 사본 `~/third-party-assets/refs/`).
> 배운 것은 **질감·색 배분·밀도·시점·구도**이고, 아래 규칙은 전부 우리 말로 다시 적은 것이다.
> 산출: 팔레트 `palette/jp2.pal`(`make_jp2_palette.py`), 데모 `style-demo-jp2/street/dm2-D.pxg`(`jp_style_demo.py`),
> 비교용 현재판 조립 `dm1-gangnam.png`(`jp_style_gangnam.py`), 비교 페이지 `~/claude-viz/jp-style-demo.html`.

## 1. 참고 그림에서 잰 것

- 참고 그림은 816×624 로 줄어든 사본이고, 캐릭터 키 ≈ 32px · 건물 한 층 ≈ 24px · 가드레일 한 마디 ≈ 2칸 · 가로수 ≈ 2×4칸 (24px 칸 기준 약 34×26칸 화면).
- **우리는 16px 칸을 유지한다.** 비율은 ×2/3: 캐릭터(원본 32px) → 약 21px, 층 높이 24px → 16px(=1칸), 가드레일 마디 2칸 = 32px, 가로수 2×4칸 → 우리 칸으로 2칸 폭 · 4칸 키(나무 몸통 포함 약 3칸 높이 수관은 30~40px).
- 즉 **건물 한 층 = 정확히 1칸(16px)**, 가게 1층 = 3칸(48px, 간판띠 1칸 + 진열창 2칸). 데모(512×384 = 32×24칸)는 가로 한 화면 = 참고 그림 한 화면과 같은 정보량이 되도록 잡았다.
- 간판 글자: 원본 가타카나 높이 ≈ 10px → 16px 칸에서 **7px 높이**(가로 간판 6×7 칸틀, 세로 간판은 획 2px 굵은 변형). 읽히는 최소 크기이므로 이보다 작게 찍지 않는다.

## 2. 결 규칙 (다섯 줄 요약)

1. **바탕은 저채도 보라회색 황혼.** 벽은 연보라 회색(`usu`), 그늘 쪽(오른쪽·아래)은 더 차가운 보라. 아스팔트 `yoru`, 보도 `hodo`(차도보다 한 단 밝게). 순백·순흑을 쓰지 않는다(가장 밝은 것은 보라 기운 흰색 `shiro` 5번 #fbfafe(창틀·난간 하이라이트 한두 픽셀에만), 가장 어두운 것도 보라 `sumi` #141020).
2. **윤곽은 검정이 아니라 재료의 어두운 보라 단**(`sumi` 또는 그 재료의 0~1단). 그림자 색도 같은 보라 계열.
3. **채도 높은 색은 작은 덩이에만**: 세로 네온 간판·가로 간판·자판기·신호등·차양. 넓은 면(벽·바닥·지붕)은 채도를 낮게 둔다. 창은 옅은 노란 불빛(`mado`) 또는 하늘색 유리(`garasu`)가 번갈아.
4. **재료마다 4~6단**, 단 사이 간격을 고르게 한다. 밝은 쪽은 왼쪽 위, 사각형 덩이에 1px 하이라이트 줄 + 아래·오른쪽 1px 어두운 줄로 넣는다(보간·그라데이션 함수 없음, 단은 손으로 놓는다).
5. **밀도가 높다**: 건물은 4~5층으로 층마다 창·실외기·발코니(남색 빈칸 + 흰 난간)를 채우고, 가게 1층은 간판·차양·자판기·자전거로 빈틈이 없다. 반대로 **바닥(아스팔트·보도)은 조용하게** — 결이 지저분해지지 않도록 균열·표식은 한두 개만.

## 3. 시점과 구성

- **3/4 위에서 본 시점**: 건물 정면 + 낮은 건물은 **옥상 윗면이 보인다**(크림 난간띠, 물탱크, 실외기 줄, 계단실, 안테나, 태양광 패널, 환기팬, 천창). 데모의 아래 3동이 이것.
- 보도 가장자리: 크림색 아치 가드레일(마디) ↔ 생울타리 상자를 번갈아, 사이사이에 둥근 가로수(진초록 수관 + 라임 하이라이트, 몸통 가늘게).
- 차도: 보라회색 아스팔트 + 노란 중앙 점선 + 흰 횡단보도 줄 + 맨홀 하나. 신호등은 작게, 아래 보도 쪽에 둔다.
- 철도: 자갈 + 침목 + 레일 두 줄 + 철망 + 전신주(전선은 2px 선). 위쪽 건물 그림자와 분리되도록 한 줄 골목을 둔다.
- 데모 칸 배치(px, y): 0~96 가게 줄(4개 층 + 1층) · 96~128 보도 · 128~192 차도 · 192~208 아래 보도 · 208~320 낮은 건물 옥상 · 320~336 골목 · 336~384 철도.

## 4. 팔레트 `jp2.pal` (25램프, 어두운 → 밝은)

`sumi`(윤곽) · 바탕 `yoru` `hodo` `jari` `makura` · 벽 `usu` `conc` `kinari` `renga` `momo` `kon` `moku` `tekko` `shiro` · 창 `mado` `garasu` · 식생 `ki` `lime` · 채도색 `aka` `sora` `kii` `midori` `pinku` `mura` `daidai`.
단 개수: `sumi` 3, `makura` 4, `jari` 5, `usu` 7, `ki` 8, 나머지 6(번호 0~5). **램프 단 범위를 넘는 번호는 못 쓴다**(6단짜리에 6번을 부르면 「램프 밖 단」 오류). 색을 더하려면 `make_jp2_palette.py` 를 고쳐 다시 생성한다(jp.pal 은 손대지 않았다).
`jp.pal`(현재 강남 결)과는 **호환하지 않는다** — 현대 칩셋과 섞어 깔 수 없게 된다는 것이 새 결의 대가다(§7).

## 5. 손 도트 글자 규칙

- 가로 간판 글자는 6×7 칸틀(가타카나·한자·로마자·숫자) 손 도트 표 `G`(jp_style_demo.py). 글자 사이 1px, 진짜 글자만(가짜 글리프 금지), 상표·로고 금지.
- 세로 간판: 같은 글자를 위→아래로, 획 2px 굵은 변형(가로 1px 두 배). **함정:** 두 배 굵기는 획이 촘촘한 글자(M `##.##` 등)를 뭉갠다(MART 의 M 이 H 로 보였다) — 촘촘한 글자는 굵기 변형 없이 pitch 7 로.
- 탁점·반탁점 글리프는 아직 없다(표의 글자만 가능).

## 6. 일본 세트 전체를 이 결로 다시 찍는 절차

현재 세트는 후보 기물 약 70종 + 킷 10종(`sets.json` `jp`, 절차 `WORKER-JP.md`·`WORKER-JP-KIT.md`)이다. 결을 바꾸는 작업은 **기물 도트를 새 팔레트로 다시 찍는 것**이지 색만 치환하는 것이 아니다(윤곽·명암 배분·밀도가 다르다).

1. **팔레트 교체**: `sets.json` 의 `jp` `palette` 를 `jp2.pal` 로 바꾸고(또는 `jp2` 세트를 새로 추가), `make_jp_jobs.py`·`jp_kit_compose.py` 가 복사하는 `jp.pal`(각각 131행 · 70행 부근)을 `jp2.pal` 로 바꾼다. `check_candidate.py` 는 `set_conf(st).palette` 를 그대로 읽는다.
2. **바닥부터**: 보도·차도·횡단보도·맨홀·철도 바닥은 결이 약해서 가장 먼저 갈아 끼워도 위에 얹은 물체가 어색하지 않다. 현대 칩셋 3076(보도)·3136(차도) 칸을 쓰는 곳(`jp_kit_compose.py` 의 `PAVE`·`ASPH`)은 새 바닥 칸으로 교체하거나, 바닥도 후보 기물(`ground` 층, 불투명)로 찍어 대체한다.
3. **킷 부품 재작성**(가장 큰 일): `kit_shopfront`·`kit_bldg`·`kit_signal`·`kit_pole`·`kit_crossing` 을 §2·§3 규칙으로 다시 그린다. `jp_style_demo.py` 의 그리기 함수(`shop_A~D` `upper_A~D` `sign_vertical_C`/`vsign` `signal` `utility_pole` `crosswalk` `tree` `guard_arch` `water_tank` `outdoor_ac` `solar` …)는 **(x, y) 기준점만 받는 독립 조각**이라 부품 칸(16px 배수)으로 잘라 옮길 수 있다 — 부품 시트 규격은 `kits-jp.json`(8열, 캔버스 128×48~112 등), 부품 이름·통행 칸은 그 파일과 `jp_kit_compose.py` 의 `parse_example` 를 따른다. 조립 예제(`ex-*`)와 통행 검사(`walk-*`)는 그대로 돌아간다.
4. **단품 재작성**: 자판기·가로 간판·세로 간판·차양·에어컨 실외기·자전거·표지판 등은 `WORKER-JP.md` 절차로 후보 3안씩 다시 찍는다. 사용자가 이미 고른 후보(`picks-jp.json`)는 형태·이름을 유지하고 결만 바꾼다.
5. **옥상 기물 추가**: 강남 결 세트에는 없는 옥상 조각(물탱크·실외기 줄·계단실·태양광 패널·천창·환기 상자·안테나)을 `jobs-jp.json` 에 새 기물로 등록한다(`make_jp_jobs.py`).
6. **검사**: 단품은 `check_candidate.py`(팔레트 색·알파·EasyRPG/REFMAP 근사 검사·메모). 장면 한 장은 `check_candidate.py` 가 폴더를 세트 기물 slug 로만 받아 직접 돌지 않는다 — 그 안의 `allowed`·`easy_check`·`refmap_check` 를 불러 부른다(이번 데모: 램프 밖 색 0, 반투명 0, easyrpg 최대 0.312, refmap 최대 0.297).
7. **비교**: `jp_style_gangnam.py` 로 현재판을 같은 구도로 조립해 두면 결 차이를 한눈에 본다.

## 6-2. 공간감 규칙 (2차 데모에서 추가 — 「벽이 평평하다」 지적)

1차 데모의 약점: 벽 = 한 색 채움 + 창 격자, 낮은 건물 옥상 = 판때기 위에 소품이 흩어짐, 가로수 = 1칸짜리 덩이. 참고 그림(낮은 해상도 사본, 눈으로만 봄)에서 다시 읽은 것과 2차 데모(`jp_style_demo2.py` → `style-demo-jp2/street/dm3-D.*`)에 적용한 것을 아래에 적는다. 모든 그림자는 **같은 램프의 단을 손으로 1~2단 내린 칸**이다(반투명 없음, 보간·난수 없음).

1. **층띠와 튀어나온 기둥.** 벽은 층마다 슬래브를 낀다: 층 맨 아래 3줄 = 슬래브(윗면 밝게 t+2 · 앞면 t+1 · 아래 모서리 t-2), 그 바로 아래 3줄 = 슬래브가 드리운 그림자(t-2, t-1, t-1). 사무실 벽은 창 사이에 폭 5(앞면 3·옆면 2)짜리 기둥을 세워 앞면은 밝게, 옆면은 t-2 로. 패널 줄눈은 「어두운 한 줄 + 옆의 밝은 한 줄」(파낸 홈).
2. **창의 깊이.** 창 = 틀 밖에 어두운 테(t-3) · 유리 안쪽 위 2줄·왼 1줄은 한 단씩 어둡게(틀 그늘) · 안쪽 물건(화분·반쯤 친 커튼·꺼진 창의 어두운 실루엣) · 유리 반사는 대각선 밝은 점 · **문턱**(윗면 t+3 밝게 · 앞면 · 밑에 그림자 한 줄). 창 옆에 물때 줄(세로 t-1) 하나로 오래된 벽을 만든다.
3. **발코니·실외기·배관.** 발코니는 슬래브 윗면(밝은 줄) + 난간 윗대 + 세로 살 + 살 옆 1px 어두운 그림자 + 안쪽 어두운 방(위·왼쪽이 더 어두움). 벽걸이 실외기는 윗면 밝게 · 앞면 · 오른쪽 옆면(2칸, 어둡게) · 벽에 드리운 그림자(아래·오른쪽) · 아래로 내려가는 관. 세로 배관은 왼쪽 밝게(t+5) 오른쪽 어둡게, 16px 마다 고정쇠, 오른쪽 벽에 그림자 한 줄.
4. **건물 사이 앞뒤.** 건물 경계에 튀어나온 모서리(앞면 3 + 옆면 3~5)를 세워 한 건물이 앞으로 나온 것처럼 보이게 하고, 옆 건물 벽에 2칸(-2)+3칸(-1) 그림자를 드리운다. 앞으로 나올수록 옆면을 넓게(아파트 5, 잡거 3).
5. **1층 가게.** 가게 입구는 벽 안으로 들어간다: 위 2줄(-2)·다음 2줄(-1)·왼쪽 2칸(-1)의 그늘을 입구 재료(창·목재)에만 얹는다. 윗층 슬래브 그림자가 가게 윗부분 전체에 내려온다. 벽 밑은 주춧돌(윗면 밝은 줄 3줄). 차양·간판은 아래에 -2 그림자 2줄.
6. **지붕(옥상) 면 분리.** 난간에 두께를 준다: 뒷난간 = 윗면 2줄 + 보이는 안쪽 벽면 6줄(t 3→1 로 어두워짐, 줄눈 있음) · 좌우 난간 = 윗면 3칸(왼쪽은 밝게·오른쪽 어둡게)과 안쪽 면 1칸 · 앞난간 = 윗면 3줄. 난간 바로 안쪽 바닥에는 그림자(뒤 2줄 -2/-1, 왼쪽 -1, 앞 2줄 -1). 바닥은 방수 시트 이음(세로 두 줄)·얼룩(t-1 덩이)으로 깨서 평면을 죽인다. 옥상 색은 벽과 같은 램프 계열(회보라)로, 초록 같은 튀는 색 금지.
7. **옥상 기물은 바닥 위에 선다.** 모든 기물 = 윗면(밝게) + 앞면 + 오른쪽 옆면(t-2) + **오른쪽 아래로 길게 드리운 그림자**(`cast_r`: 두 칸마다 한 줄 내려가며 앞 60% -2단, 뒤 -1단, 바닥·난간 재료에만). 물탱크 = 원통을 다섯 띠(t5→t1)로 나누고 가로 테 3줄, 뚜껑, 다리 사이 어둠, 사다리. 실외기 = 윗면 3줄·앞면 7줄·팬 원·발. 계단실 = 문 위 차양 + 문 안쪽 어두운 면. 채광창 = 위 유리 밝게·앞 유리 어둡게·반사 점. 태양광 패널 = 아래 앞면 두께 + 뒤 그림자. 기와 지붕 = 용마루(윗면 밝게·앞면 어둡게) → 기왓줄 → 처마 끝 두께 5줄 · 돌출 다락창은 작은 지붕+앞면+옆면.
8. **빛은 왼쪽 위.** 면별 규칙 고정: 윗면 · 왼쪽 면 = 밝게(t+1~+3), 앞면 = 기본 t, 오른쪽 면 · 아래 모서리 = 어둡게(t-2~-3). 그림자는 항상 오른쪽 아래로 떨어진다. 한 화면에서 이 방향이 한 번이라도 뒤집히면 공간감이 깨진다.
9. **재료당 4~6단은 실제 벽에서 이렇게 쓴다.** 한 벽 면을 기본 단 하나로 끝내지 말고 **(위 그늘 t-2 → 본체 t → 아래 슬래브 t+2 → 슬래브 밑 t-2)** 를 층마다 반복하고, 줄눈 t-1/t+1 쌍과 물때 t-1 줄을 더한다. 단이 5개 이상 쓰이는 면이 화면에 넓게 있으면 벽이 살아난다(1차 벽은 단 2개).
10. **가로수는 크게.** 수관 폭 약 34 · 높이 약 48(1차 수관은 26×30 정도), 가는 줄기(폭 4) 위에 뒤쪽 어두운 덩어리 8개 → 앞쪽 밝은 덩어리 7개, 덩어리마다 왼쪽 위 밝게·오른쪽 아래 어둡게, 손으로 놓은 잎 점, 아래쪽 어두운 틈, 화분 + 보도에 드리운 그림자. 수관이 간판을 가리지 않게 건물 경계 쪽(가게 사이 틈)에 세운다.

## 7. 알려 둔 한계 (정직한 목록)

- **킷 시트 변환(후보 「D 새 결」)은 1·2차 모두 하지 않았다.** 데모는 킷 구조를 따르는 독립 조각을 손으로 배치한 한 장이다. 절차 3번이 그 일이며, 2차 결에는 걸림돌이 하나 더 있다: 데모의 한 층 = 16px(1행)인데 `kits-jp.json` 의 `kit_bldg` 벽 부품은 한 층 = 32px(2행)·`wall_l/m/r` = 1×2칸이라 슬래브·창·발코니의 세로 배분을 32px 층으로 다시 짜야 한다. 부품 파일명은 `WORKER_RE`(`j1-D.pxg` 꼴) 를 지켜야 하고 컴포저가 복사하는 팔레트는 `jp.pal` 이라 `jp2.pal` 로 바꾼 뒤에야 검사가 통과한다.
- 2차 그림자는 `sh()` 로 **이미 그려진 픽셀의 단을 내려서** 굽는다. 킷 부품으로 옮기면 부품 안에 미리 구워 넣어야 하고, 부품 경계를 넘는 그림자(기둥이 옆 벽에, 슬래브가 아래 가게에)는 이음 칸 규칙으로 따로 맞춰야 한다.
- 새 결은 현대 칩셋(강남 결) 바닥·소품과 **한 화면에 섞으면 튄다** — 세트 전체를 같이 갈아야 한다.
- 글자: 탁점 없음, 표에 있는 글리프만. 데모의 신호등은 작고, 보도 촉지 블록이 자전거 쪽을 스친다.
- 참고 그림은 낮은 해상도 사본으로 봤고, 색은 눈대중으로 잰 것이라(화소 추출 아님) 수치가 참고 그림과 같다고 주장하지 않는다.

# 월드맵 확장 아이콘 — 원본 EasyRPG World 의 결 (8배로 읽은 실측)

원본은 `public/assets/easyrpg-chipset-world.png` (480x256, 16px 칸, 30열x16행, 칸 번호 = 행*30+열, 분홍 키 255,103,139).
확장 아이콘은 이 결을 **수치로** 맞춘다. 좌표는 원본 시트 절대 픽셀이다.

## 2. 1판 확장 시트가 안 어울린 이유 (진단)

1. **팔레트**: 채도 높은 밝은 빨강·파랑 원뿔 지붕. 원본은 채도를 눌러 보라 회색 위주(`mute_pixel` 이후 값).
2. **윤곽**: 가늘고 깨끗한 선. 원본은 1px 111618 굵은 외곽 + 안쪽 짙은 이음.
3. **디테일 밀도**: 디더·얼룩·이끼 없음. 원본은 면마다 체커와 갈색 점이 있다.
4. **원근·실루엣**: 뾰족 원뿔 첨탑. 원본은 밝은 고리가 얹힌 드럼 탑(윗면이 살짝 보이는 3/4 시점).
5. **크기**: 소형 아이콘에 여백. 원본은 칸을 채운다.
6. **결과**: 시트 오른쪽 절반이 비었고, 3x3·5x5 는 원본 성을 「키운」 게 아니라 다른 게임 그림처럼 보였다.
7. **땅 가장자리**: 1판의 땅 킷 다시 그리기가 원본의 둥근 굴곡을 네모 계단으로 바꿔 놓았다 → 되돌림(아래 4절).

## 3. 새 방식 (2판): 원본 모듈을 자르고 늘린다

이 스타일은 손으로 새로 그려서는 맞추기 어려워, **원본 아이콘 픽셀을 반복 가능한 띠로 잘라 늘리고 재배치**한다.
새 색은 추가하지 않았다(전부 원본 팔레트 + 시트 전체에 적용한 같은 `mute_pixel`). 예외 없음.
생성 이미지·트레이싱 없음. 다른 게임 픽셀 복사 없음.

- 성 3x3(48x48): 뚱뚱한 둥근 탑 둘(원본 20,12-13) + 원본 벽 22행에서 **무늬 없는 벽돌 3행만** 세로 늘린 성채(2x4 화살 구멍은 111618 + 받침 8ca9a3 로 손 좌표 찍음).
- 성 5x5(80x80): 안쪽 성 + 앞 성벽(문은 한 번만, 화살 구멍 2x3 8칸 간격) + 네 귀퉁이 탑. 계단식 실루엣.
- 마을 3x3: 원본 집 칸(22,8) (22,9) 을 겹쳐 촘촘히, 덤불(19,9)(18,9)·나무(18,8) 사이사이. 종탑 마을은 원본 둥근 탑을 옆에 세움. 설원 마을은 눈 집(23,8)(23,9)만.
- 촌락 2x2: 집 세 채 + 덤불.
- 1x2 탑·신전·동굴은 원본 그대로가 이미 있어 **다시 그리지 않았다**(적은 수의 좋은 아이콘이 낫다).
- 1판 방식은 `make_world_ext.py`(SUPERSEDED, `--force-old`)와 `world-plus-ext-v1.png` 로 남겼다.

## 4. 땅 가장자리 (회귀 수정)

`make_world_plus.py` 의 땅 킷 다시 그리기 `do_land` 는 이제 `--land` 옵션일 때만 돈다(기본 꺼짐).
기본 실행은 흙·모래·늪·눈·풀 킷 40칸을 **원본으로 되돌리고 팔레트 눌림만 적용**한다. 산 재조명 11칸과 다듬음 2칸은 유지.
전후: 원본 / `world-plus-v1.png`(네모 계단) / `world-plus.png`(지금).

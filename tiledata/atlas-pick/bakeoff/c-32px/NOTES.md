# C군 — 32px, 이미지 생성(Tibo) + 도트화 (2026-09-30)

결과: `scene.png` (512x448, modern3 밖 0색, 146색) / `scene-1.5x.png` / 원본 `raw/` / 스크립트 `scripts/content/atlas-pick/bakeoff_c.py`.
참고 스크린샷은 모델에 넣지 않았고 저장소에도 없다. 틀(`frames/`)은 회색 매싱 + 마젠타 배경.

## 방법
- 왼 건물 L / 오른 건물 R / 소품 시트 P 를 틀 참조로 각각 생성 -> 셀 중앙값 도트화(K=4, 히어로 5, 자판기 5) -> modern3 Lab 최근접(네온 램프 제외) -> 마젠타 투명.
- 인도·차도·횡단보도·맨홀·균열·그림자·간판 글자(Galmuri11)는 코드로 그림. 모델은 글자를 그리지 않는다.
- 캔버스는 512x448 (요청 384 높이보다 큼: 인도+차도 여유). 편차로 기록.

## 생성 횟수·합격률·시간 (Tibo 14회, sunburst, 50~190초/회, 병렬)
| 구성 | 회차 | 생성 | 엄격 사후검사 통과 | 채택 |
|---|---|---|---|---|
| L | r1 | 3 | 1/3 | r1-1 |
| L | r2 | 2 | 0/2 (창 폭 -25%, boxes 미달) | 없음(r1-1 유지) |
| R | r1 | 3 | 3/3 | r1-2 |
| P | r1 | 3 | 측정 불가·시각 판정 | 폐기(분홍 나무·꼬마 히어로) |
| P | r2 | 3 | 측정 불가·시각 판정 (r2-2 검은 배경 불용) | r2-1 대부분, r2-3 택시·난간 |
합계 건물 8회 중 통과 4, 통과 산출물만 사용. 소품(P)은 모델이 틀 칸보다 크게 그려 칸별 IoU 지표가 전부 누출로 잡혀 자동 판정이 무의미했다 -> 시각 판정으로 대체(편차). 생성 벽시계 약 9분(10:49~10:58) + 도트화·합성 반복.
음성 대조(틀 원본·5% 이동·상하반전)는 모두 불통과 확인.

## 3회전 "레퍼런스보다 허접한 곳" -> 조치
1. 벽 잔 노이즈, 분홍 나무, 꼬마 히어로, 소품이 작고 뭉침, 횡단보도 굵음, 마젠타 테두리, 밋밋한 인도/차도 -> (r1 산출)
2. 나무 재생성(초록), 히어로 비꼬마, 겹침 배치, 테두리 제거(네온 램프 제외·중앙값), 순흑 채움 0, 소품 잘림(크롭 확장), 크기 보정(히어로·자판기 K 개별) -> 반영
3. 횡단보도 줄무늬 8->6px, 정지선 얇은 흰 선, 도로 균열 4줄·보수 패치 -> 반영 (코드 드로잉)

## 남은 약점 (레퍼런스 대비)
1. 도로·인도가 여전히 단조: 전선·전신주·간판 잡동사니·사람·주차 차량 없음, 택시 1대뿐.
2. 히어로 16x39 저해상도, 소품 K 혼용(4/5)으로 도트 크기 불일치(믹셀).
3. 가드레일이 작고 노란 볼라드가 점자블록 옆에서 어색.
4. L 벽면 잔 노이즈, 창 디테일이 레퍼런스보다 얇음(2회 재생성으로도 못 잡음).
5. 두 건물 사이·옥상 소품의 질감 결이 서로 다름(모델 생성 결 vs 코드 그림 지면).

## 전 타일셋을 이렇게 만들 때 비용·위험
- 화풍 표류: 호출마다 결(선 굵기·채도·창틀)이 달라 같은 타일셋 안에서 어긋난다. 통과율 L 33%·소품 자동 통과 0.
- 틀 추종은 건물엔 되나 소품은 크기·종·배경을 자주 어김(회색 상자, 검은 배경, 사다리꼴 지붕). 재생성 비용이 통과 수의 2~3배.
- 도트화는 셀 중앙값이라 32px 타일 격자와 무관하게 대는 맞음(경계 이음새는 별도 보정 필요). 이음(타일링)이 되는 바닥·벽은 코드/손 도트가 낫다.
- 팔레트 강제 양자화가 안전망이지만 명암 단계 의도(면별 톤)는 모델이 지키지 않아 손 보정 필요.
- 시간: 호출당 50~190초, 성공 1건에 평균 ~3.5회 시도. 수백 타일이면 사람 검수가 병목.

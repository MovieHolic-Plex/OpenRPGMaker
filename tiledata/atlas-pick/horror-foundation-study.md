# 호러 세트 2판 — 「기본 타일」 조사 (2026-09-30)

사용자 판정(원문): 「호러도 마찬가지다. 일단 이런저런 시도를 한 건 좋은데, 우선은 '기본' 이 되어야 할 타일들을 만들어야 하지 않겠냐 ....
이브나 마녀의 집 어떻게 만들었는지 생각해봐...」

1판 호러 세트(66개, `jobs-horror.json` version 1)는 초상화·인형·핏자국·떨어진 샹들리에 같은 **연출 기물**이 대부분이었다.
방을 실제로 깔 바탕(벽면·천장 테·바닥·문·창·계단·기본 가구)이 없어서 v5 실내 조각을 빌려 깔아야 했다.
이 문서는 쯔꾸르 인디 호러 네 편이 방을 어떻게 쌓았는지 보고, 2판 「1단계 기본」의 근거를 적는다.

> 저작권: 아래는 공개 스크린샷·해설·기억을 보고 **짜임(칸 수·층·밀도)** 만 적은 것이다. 그림은 저장소에 넣지 않았고 화소를 옮기지 않는다.
> 캐릭터(아오오니·게르테나 작품·마녀의 집 인형 등)는 그리지 않는다. 칸 수는 어림이다.

## 2. 방의 뼈대 — 네 편이 공통으로 한 것

1. **천장·벽 윗면은 검정.** 방 밖은 전부 검정(또는 검정에 가까운 한 색)이고, 방 쪽 가장자리에만 얇은 테(1~3px)가 있다.
   방의 모양을 만드는 것은 이 검정 덩이다 — 복도·알코브·ㄱ자 방이 검정 속에 파인 구멍처럼 읽힌다.
2. **북쪽 벽면은 두 칸(RM2000 16px·XP/VX 32px 모두 2줄) 높이.** 위에서 아래로 몰딩/천장 그늘 → 벽지(또는 칠) 넓은 면 → 징두리·걸레받이 → 바닥.
   벽면이 방에서 **가장 밝은 넓은 면**이고, 바닥은 그보다 어둡고 조용하다. 옆벽·남벽은 벽면 없이 검정 테만 보인다(정면-위 시점).
3. **바닥은 방마다 한 종류**: 저택 = 마루(널)·카펫, 미술관 = 밝은 마루·회색 돌판 + 긴 카펫 러너, 병원 = 타일·리놀륨, 지하 = 돌·흙.
   **카펫 러너(자동 타일)** 가 복도의 방향을 잡아 준다 — Ib 미술관·저택 복도 모두 러너 하나로 동선이 선다.
4. **문은 북쪽 벽면에 그려진 한 칸 폭 문**(벽면 2줄 높이)이거나 옆·남벽의 **틈**(검정 테가 끊긴 곳)이다. 잠긴 문은 모양이 같고 자물쇠·사슬만 더한다.
5. **창은 벽면 윗줄**에 작게. 밤 창 = 짙은 남청 유리 + 달빛 한두 점, 또는 닫힌 커튼. 창 아래 바닥에 달빛 번짐을 까는 경우가 있다.
6. **계단은 북쪽 벽 속으로 오르거나(오름), 바닥의 검은 구멍(내림).** 옆벽을 따라 사선으로 오르는 계단도 쓴다(REFMAP 작가 견본의 마녀의 집 결 조립: 옆벽 사선 계단).
7. **복도 폭은 2~3칸.** 복도 끝은 벽이 아니라 **어둠으로 사라진다**(남쪽 틈 + 어둠 덮개). 방 하나는 화면 한 장(20×15 / 17×13칸) 안팎 — 넓으면 무섭지 않다.

REFMAP 작가 견본(`~/.local/share/oprn/refmap-downloads/reference/test/2019-11-03_*組み見本.png`, **보기만**)에서 본 저택 결 조립:
크림 회벽 2줄 + 나무 걸레받이 + 위 몰딩, 검정 천장 + 짙은 갈색 테, 방마다 바닥 재질이 다름(보라 카펫 / 밝은 마루 / 돌판), 벽 옆 사선 계단,
그리고 **벽 쪽에 가구를 몰고 가운데를 비운다**.

## 3. 방 하나당 기물 밀도

| 게임 | 방 하나(한 화면)에 놓인 것 | 공포를 만드는 것 |
|---|---|---|
| Ib | 벽에 액자 2~5개, 바닥 기물 0~3개(받침대·조각·마네킹), 카펫 러너 | 그림이 바뀌고, 벽·바닥에 글씨가 나타나고, 액자에서 손이 나오는 **이벤트**. 장미(체력) |
| 마녀의 집 | 가구 3~8개(책장·탁자·곰 인형·상자), 대부분 벽에 붙음 | 방이 좁아지고 벽이 다가오는 **이벤트**, 갑작스러운 죽음, 소리 |
| 아오오니 | 가구 0~4개(RTP 옷장·침대·피아노), 거의 빈 방 | 쫓아오는 괴물 하나(추격 **이벤트**), 옷장 숨기, 문 잠김 |
| 유메닛키 | 기물 0~몇 개, 넓은 빈 바닥 | 추상(반복 무늬·이상한 NPC 하나), 이어짐이 없는 공간 |

- 화면의 **90% 이상은 기본 타일**(천장 검정·벽면·바닥)이다. 연출 기물은 방마다 **한두 개**, 그 방의 「이상한 한 점」.
- 조명은 타일이 아니라 **화면 덮개(그림/색조)** — 어둡게 눌러 두고 손전등·촛불 둘레만 밝힌다. 그래서 기본 타일은 **어두워도 모양이 남아야** 한다(명도 폭).
- 핏자국·글씨는 이벤트로 **나타나는** 것이라 바닥·벽 기본 위에 얹히는 덧칠(decal·wall)이다. 기본이 없으면 얹을 곳이 없다.

## 4. 우리에게 옮기면 (16px 손 도트 실내 v5 체계)

v5(`tiledata/hand-interior/v5/room2.py`, 스킬 `assistant-skills/interior-room-authoring/SKILL.md`)가 이미 같은 문법을 쓴다:
- 평면 `#` = 막힌 칸 → **실내에 닿는 막힌 칸 = 천장 띠(어두운 덮개 + 방 쪽 밝은 테)**, 나머지 = 공허(검정).
- 막힌 칸 **바로 아래 두 줄 = 벽면**(못 걸음). 벽면 무늬는 32px 폭 반복(월드 좌표). 벽면 밑 접촉 그림자, 서쪽 벽 덩이 옆 5px 그림자(자동).
- 두꺼운 벽 통로는 3줄, 동서 칸막이 틈 1칸 = 문. 오름 계단 = 북쪽 벽 앞 3칸 폭(첫 바닥 줄 + 벽면 두 줄), 내림 = 바닥 1×1 구멍.
- 걸이(창·그림)는 벽면 **윗줄**만. 벽 가구는 북쪽 벽면 앞만. 바닥은 조용하게(4~5단), 가구는 대비 크게.

그래서 호러 기본 타일은 v5 에 **그대로 끼우는 꼴**로 정한다(2판 절차서 3절):

| 기본 | 칸·꼴 | v5 에서의 자리 |
|---|---|---|
| 벽면 | 2×2(32×32) 불투명, 가로로 32px 마다 이어짐. 위 몰딩 → 넓은 면 → 징두리 → 걸레받이 3px | `wall:*`(faceRows 2) |
| 천장 윗면(벽 윗면) | 4×3(64×48) **자동 타일**: 3×3 덩이(모서리·변·속) + 오른쪽 위 1칸 안쪽 모서리. 조립기가 8px 사분면으로 이어 붙인다 | v5 천장 띠(평면에서 자동) |
| 바닥 | 2×2(32×32) 불투명, 사방 이어짐(`@tile`) | `floor:*` |
| 카펫 러너 | 4×3(64×48) 자동 타일(같은 사분면 규칙), 투명 바탕 | `line:rug *` |
| 문 | 1×2(16×32) 벽 걸이, 벽면 두 줄을 채우고 바닥 줄에 닿음. 양문 2×2 | (v5 에는 벽면 문이 없다 — 새로) |
| 창 | 1×1 벽 걸이(벽면 윗줄) | `window` `curtained window` |
| 계단 | 오름 3×3(북쪽 벽 앞), 내림 1×1 구멍 | `stairs up wood/stone` `stairwell down` |
| 어둠 경계 | 1×1 가장자리·모서리, 3×3 빛 구멍, 2×2 출구 어둠(반투명 어둠 4단만) | (새로 — 조명 덮개) |

## 5. 결론 — 2판 순서
1. **1단계 기본 한 벌**(벽면·천장 테·바닥·러너·문·창·계단·기둥·어둠 경계·기본 가구)을 장면별 묶음(저택·미술관·병원·지하)으로 먼저.
   고르기는 **한 벌 단위**: 같은 방향 글자(A·B·C)의 조각으로 방 세 개(저택 복도·미술관 전시실·병원 병실)를 깔아 나란히 보고 고른다(`horror_room_compose.py`).
2. **2단계 연출**(초상화·인형·핏자국·부서진 가구 …, 1판 대부분)은 기본이 선 뒤. 방마다 한두 개만 얹는다.
3. 공포는 타일이 아니라 **기본 위의 한 점 + 어둠 덮개 + 이벤트**로 만든다. 기본 타일에 피·금을 미리 칠하지 않는다(얼룩 변형은 따로).

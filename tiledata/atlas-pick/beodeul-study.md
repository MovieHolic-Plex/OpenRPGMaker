## 1. 버들항에서 잰 것

### 1-1. 크기와 사람 대비
| 항목 | 실측 |
|---|---|
| 칸 | 16px (칩셋 `tex_beodeul_city` 2048×2992, 128열) |
| 주인공 | 그림 약 15×23 (프레임 24×32) |

### 1-2. 킷 구조와 lo/up 분리 (`beodeul-study/04`)
- 킷 = `<id>.json` + `.lo.png` + `.up.png`. json 은 `id·name·w·h·walk[]·description·rules·tags·role(building|part)·doors[{dx,dy,note}]·assembly[{kit,x,y}]`.
- lower = 지면에 깔린 것, upper = 지면과 다른 픽셀만. 건물은 거의 통째로 up 에 있다(뒤에 선 주인공은 up 의 y 정렬로 가려진다).
- 통행 문법: `F` lower 통행 · `X` lower/upper 막힘 · `C` upper 이지만 통행(지붕 끝·나무 윗부분, 플레이어 위에 그려짐) · `S` upper 막힘 · `.` 빈칸.
- 문은 건물 조각 맨 아랫줄에 있고, 그 아래 한 칸이 문 앞 길 타일이다.
- 부품은 16px 폭 세로 기둥 조각(`mparts`, `beodeul-study/05`): 처마 어두운 선 2px + 좌대 약 4px 로 위·아래 이음이 정해져 있다.

### 1-3. 3/4 건물 규칙 (`beodeul-study/01·02·03`)
- 지붕 윗면이 건물 높이의 약 절반(깊은 박공/우진각). 기와 주기 4px.
- 벽 앞면은 층당 약 33~40px. 옆면은 그리지 않는다.
- 처마는 어두운 선 2px, 창은 아치형 약 10~11×22~24 + 화분대 16×4, 목조 기둥 2px.
- 바닥 그림자: 어두운 선 → 청회색, 아래 2~4px, 오른쪽 약 4px (빛은 왼쪽 위).

### 1-4. 길 위계와 블록 배치 (`beodeul-study/06·07`)
- 대로 3~4칸(가로등·가로수가 5칸 간격 교대), 거리 2칸, 골목 1칸.
- 블록 킷은 맞붙이지 않는다: 2칸 거리 또는 1칸 골목을 사이에 둔다.
- 가로수는 석재 화분 안에 선다.

### 1-5. 바닥 오토타일·팔레트
- 포장 길은 차가운 청록회색 계열: (55,66,67) / (91,102,103) / (119,117,121) / (144,146,143).
- 2칸 자갈길 + 밝은 연석선, 횡단보도 줄무늬.

## 2. 우리 강남 조각이 이것과 다른 점 (의도적)
| 버들항 | 강남 v2 | 이유 |
|---|---|---|
| 깊은 박공/우진각 지붕 | 평지붕 판(윗면 T=14~16) + 실외기·물탱크 | 현대 도심 |
| 기와 주기 4px | 콘크리트·벽돌 벽면 + 층 띠 | modern3 팔레트(색 91개, 밖 0) |
| 목조 기둥 2px | 필라스터 + 간판띠 | 상가 건물 |
| 아치 창 + 화분대 | 사각 창 + 창턱 + 실외기 | |
| 가로등·가로수 5칸 교대 | 가로등 2 · 가로수 1 · 자판기 · 버스정류장 | 인도 폭이 2칸(32px)뿐 |
| 포장 길 2칸 | 인도(포장 2줄) → 연석 → 차도 5줄(중앙 점선) → 횡단보도 | 자동차 도로 |
| 주인공 15×23 | 16×24, 문 16×28, 층 32 | 버들항 층 약 33~40 → 도심 층고 32 |

같은 것: 위 윗면 T + 앞면 F 분리, 옆면 없음, 아래 2~4px 그림자, 16px 기둥 조각 + 해시 중복 제거, up 은 건물 앞면 전체·통행 X 는 앞면 아래 D×16.

## 3. 적대적 검토 3회 기록
- (a) 3/4 문법이 버들항과 나란히 놔도 맞는가 — 카페 crop 을 3× 로 나란히 놓고 봄. 윗면+앞면·옆면 없음·바닥 그림자·기둥 조각 구조가 같다. 다른 것은 지붕 형태뿐(의도).
- (b) 벽·바닥이 평평한가 — 뒷골목이 단색 회색 면이었다. 맨홀 3, 주차선 6, 얼룩 3, 배수 줄을 넣음. 벽은 처마띠·필라스터가 이미 있다.
- (c) 사람 대비 크기 — 주인공 16×24, 문 16×28, 층 32, 자판기 16×32, 택시 64×36. 버들항 벽 1.4× 규칙과 같다.

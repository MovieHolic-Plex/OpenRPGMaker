# infirmary 자기 검수 노트

형식: 무엇으로 읽히나 / 윗면 비율 / 사람 대비 크기 / native 와 같은 화풍인가 / 고친 점

- wz-inf-wall-n: 밝은 석회색 병동 북벽(윗면 두께 + 실내 정면 큰 비정형 블록) / 윗면 띠 1행(25%) / 4칸=64px, 사람 32px 의 두 배 / 성벽과 같은 구조, 색만 밝게 / 블록 줄눈을 불규칙하게, 잡음 제거
- wz-inf-wall-n-window: 높은 첨두 아치 창, 차가운 하늘빛 + 짧은 1px 반사, 깊은 창턱 / 윗면 25% / 창 높이 약 28px, 사람 키와 비슷 / 같은 화풍 / 창살 선을 1px 로 줄이고 창턱 그림자 추가
- wz-inf-wall-n-window-big: 2칸 폭 큰 아치 창(병동 중앙 창) / 윗면 25% / 폭 32px, 사람 어깨폭의 약 1.5배 / 같은 화풍 / 아치 정점 대칭 맞춤, 창틀 3단 명암
- wz-inf-door-closed: 밝은 오크 첨두 문, 쇠 경첩·손잡이 / 윗면 25% / 폭 16px 높이 40px 이내, 사람보다 한 뼘 큼 / 성 문과 같은 구조 / 판자 결 세로 방향, 손잡이 황동
- wz-inf-door-open: 문이 안쪽으로 열린 어두운 통로, 문짝은 왼쪽 가장자리에 모임 / 윗면 25% / 닫힘과 같은 크기·피벗 / 같은 화풍 / 아래 3칸 통행(S,C,C,C)으로 맞춤
- wz-inf-door-locked: 닫힘 문 + 쇠 자물쇠와 가로 빗장 / 윗면 25% / 닫힘과 같은 크기 / 같은 화풍 / 자물쇠를 황동 큰 덩이로 해서 한눈에 구분
- wz-inf-wall-w: 서벽 윗면 띠, 석재 블록 위에서 본 면 / 윗면 전체 / 1칸 / 성벽 띠와 같은 결 / 세로 이음새 없이 16 주기 맞춤
- wz-inf-wall-e: 동벽 윗면 띠(서쪽의 짝, 그늘 쪽 한 단 어둡게) / 윗면 전체 / 1칸 / 같은 화풍 / 빛 방향(왼쪽 위)에 맞춰 안쪽 가장자리 명암 조정
- wz-inf-wall-s: 남쪽 낮춘 절단벽(윗면 + 낮은 정면) / 윗면 50% / 2행=32px 이하, 사람 키와 같음 / 같은 화풍 / 정면 블록 높이를 윗면과 구분
- wz-inf-wall-sw: 남서 모서리(서벽 띠가 남벽으로 꺾임) / 윗면 50% / 2행 / 같은 화풍 / 서벽 띠와 남벽 이음새를 맞춤
- wz-inf-wall-se: 남동 모서리(그늘 쪽) / 윗면 50% / 2행 / 같은 화풍 / 동벽 띠와 남벽 이음새를 맞춤
- wz-inf-wall-nw: 북서 바깥 모서리, 북벽 정면이 서쪽 끝에서 끊김 / 윗면 25% / 4행 / 같은 화풍 / 북벽과 블록 줄 높이 맞춤
- wz-inf-wall-ne: 북동 바깥 모서리 / 윗면 25% / 4행 / 같은 화풍 / 우측 가장자리 어둡게
- wz-inf-floor-a: 밝은 큰 석판 바닥 / 해당 없음(바닥) / 1칸 / 성 바닥과 같은 결, 색만 밝게 / 16 주기 이음새 없이, 잡음 제거
- wz-inf-floor-b: 작은 석판 바닥(a 와 섞어 쓰는 변형) / 해당 없음 / 1칸 / 같은 화풍 / a 와 줄눈 간격 다르게 해 반복이 덜 보이게
- wz-inf-bed-shadow: 불투명 판·디더 제거. 침대 발치(남쪽)·동쪽·서쪽 가장자리에만 얇은 어두운 투명 띠(f). 나머지는 바닥이 그대로 보인다.
- wz-inf-bed-empty: 철제 머리판 + 오크 다리 + 백색 린넨 침대, 접힌 담요 / 윗면(머리판+이불 윗면) 약 30% / 2x3=32x48, 사람(24x32)이 누울 만한 길이 / native 가구와 같은 화풍 / 머리판 철 반사를 좁은 1px 로, 린넨 주름 2단
- wz-inf-bed-patient: 머리와 담요 덮인 몸 실루엣이 누운 침대 / 윗면 약 30% / 2x3 / 같은 화풍 / 얼굴을 작게, 베개 윤곽 분명히(얼굴 부분이 약간 네모난 것은 남은 약점)
- wz-inf-curtain-closed: 닫힌 흰 린넨 커튼, 세로 주름 2단, 위쪽 레일 / 윗면(레일) 약 10% / 1x3=48px, 사람보다 큼 / 같은 화풍 / 주름 선 색을 린넨 3단(푸른빛)이 튀지 않게 조정
- wz-inf-curtain-open: 한쪽으로 모아 묶은 커튼, 아래가 부드럽게 퍼짐 / 윗면(레일) 약 10% / 닫힘과 같은 크기·피벗 / 같은 화풍 / 거침없는 곡선(거듭제곱 곡선)으로 모양을 다시 그림, 통행 CCC
- wz-inf-screen: 접이식 3폭 지그재그 칸막이, 중앙 폭 밝게 / 윗면 약 15% / 2x2=32x32, 사람 키 정도 / 같은 화풍 / 창이나 장으로 읽혀서 지그재그 계단 모양으로 다시 설계, 패널 색 통일
- wz-inf-cart: 바퀴 달린 황동 카트 + 위쪽 약병과 붕대 / 윗면(상판) 약 25% / 1x2=16x32, 허리 높이 / 같은 화풍 / 바퀴와 하단 선반 추가(상판이 넓고 손잡이 없음은 남은 약점)
- wz-inf-bandage: 바닥에 놓인 붕대 두루마리, 풀린 끝자락 / 윗면 위주 / 1칸 이하 / 같은 화풍 / 풀린 끝을 둥글게(종이 두루마리처럼 읽힐 수 있음)
- wz-inf-splint: 바닥의 나무 부목 두 개와 천 끈 / 윗면 위주 / 1칸 이하 / 같은 화풍 / 나무 결 방향을 긴 쪽으로 정리
- wz-inf-basin: 오크 받침 위 흰 도기 대야와 물 / 윗면(물 면) 약 35% / 16px / 같은 화풍 / 물 면을 타원으로, 짧은 1px 반사
- wz-inf-shelf: 약병이 줄지어 선 오크 선반(2단) / 윗면 약 15% / 2x2=32x32, 사람 키 정도 / 같은 화풍 / 병 색을 선반 칸마다 달리하고 병 높이를 3종으로
- wz-inf-chart: 벽걸이 환자 기록판(나무 판 + 종이 + 붉은 표시선) / 해당 없음(벽걸이) / 1칸 / 같은 화풍 / 종이 선을 3줄로 줄여 잡음 제거
- wz-inf-candle: 키 큰 철 촛대와 촛불 / 윗면 약 10% / 16x32 내외, 사람 키 정도 / 같은 화풍 / 철 줄기를 좁게, 불꽃을 두 단 밝기로
- wz-inf-table: 오크 작은 탁자, 위에 물컵 / 윗면 약 35% / 16px, 상판 높이 14~16px / 같은 화풍 / 서랍을 하나만 보이게
- wz-inf-example-ward: 병상 6개 두 줄 + 커튼 + 선반 + 카트 + 아치 창 + 열린 문의 병동 14x12 / 해당 없음 / 병상 2x3 이 사람 키 1.5배 / 벽·바닥이 성 키트와 같은 구조 / 두 병상 줄 사이 통로가 없음(바닥 6행뿐)은 남은 약점, 북벽 아래 기록판·촛대·탁자로 통로 위쪽을 채움

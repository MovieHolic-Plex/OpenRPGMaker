# postoffice 자기 검수 노트 (작업자 자기 점검, 판정 아님)
- wz-post-snow-a / snow-b: 쌓인 눈 바닥 / 평면 바닥(윗면 100%) / 사람 발밑 크기 / 같은 화풍 / 가로 띠 반복을 없애고 덩이 2개로 줄임
- wz-post-floor: 우체국 판자 바닥 / 윗면 100% / 판자 1칸=한 장 폭 / 실내 목재 톤 일치 / 이음매 엇갈림 정리
- wz-post-snowcobble(오토타일): 눈길 자갈 포장 / 윗면 100% / 사람 한 걸음 폭 / 돌 4톤 / 테두리 눈 번짐 조정
- wz-post-print-a / print-b: 눈 위 발자국 / 윗면 / 신발 크기 정합 / 같은 화풍 / 좌우 발 교차·그늘 1px
- wz-post-puddle: 녹은 물웅덩이 / 윗면 / 사람 발 두 배 / 같은 화풍 / 얼음 테두리 추가
- wz-post-threshold: 눈에서 문턱으로 / 윗면+앞 돌 한 줄 / 문 폭 1칸 / 같은 화풍 / 예제에서 문 아래 칸으로 이동
- wz-post-plinth: 돌 밑동 / 앞면 짧은 돌줄 / 벽 아래 한 단 / 같은 화풍 / 돌 이음 엇갈림
- wz-post-wall-l / wall-m / wall-r / wall-w: 하프팀버 벽(왼끝·가운데·오른끝·창) / 앞벽 2단 / 사람 키 2칸 / 같은 화풍 / 사선 보강재 방향 정리
- wz-post-roof-ridge / ridge-l / ridge-r: 눈 덮인 용마루 / 윗면 비중 높음 / 벽 위 한 줄 / 같은 화풍 / 끝 모서리 눈 처짐
- wz-post-roof-a / roof-b / roof-c: 가파른 슬레이트 지붕 3종 / 윗면 100% / 건물 높이 / 같은 화풍 / 눈 덩이를 타일당 1개로 줄여 잡음 제거
- wz-post-roof-l / roof-r: 지붕 좌우 가장자리 / 윗면 / 건물 폭 / 같은 화풍 / 테두리 1px 정리
- wz-post-eave-l / eave-m / eave-r: 처마 줄 / 윗면+앞 눈 턱 / 벽과 지붕 사이 한 줄 / 같은 화풍 / 고드름 간격 불규칙화
- wz-post-door-closed / door-ajar / door-open: 문 3상태 / 앞면(건물 벽 정면은 허용) / 사람 키보다 약간 큼 / 같은 화풍 / 열린 문 안쪽 어둠, 조금 열림 하단 색 블록 정리
- wz-post-window: 격자창 / 앞면 / 사람 가슴 높이 / 같은 화풍 / 불빛 2톤
- wz-post-bay: 우체국 퇴창(2칸) / 앞면+눈 턱 / 사람 키 절반 / 같은 화풍 / walk 'SS' 로 정정
- wz-post-sign: 부엉이 우체국 간판(2칸) / 앞면 / 처마 높이 / 같은 화풍 / 판 배경을 린넨 2~3톤으로 정리
- wz-post-slot: 편지 투입구 / 벽 부착 / 손 크기 / 같은 화풍 / 황동 테두리
- wz-post-mailbox: 눈 쌓인 우체통 / 윗면 눈 캡+앞면 / 사람 허리~가슴 / 같은 화풍 / 빨강 4톤
- wz-post-lamp: 눈 덮인 가로등 / 3칸 높이 기둥 / 사람보다 약 1.5배 / 같은 화풍 / 불빛 크기 축소
- wz-post-barrel: 눈 얹은 통 / 윗면 타원+앞 테 / 사람 허리 / 같은 화풍 / 테 간격
- wz-post-crate: 눈 얹은 상자 / 윗면 눈+앞면 / 사람 무릎~허리 / 같은 화풍 / 널 이음
- wz-post-chimney: 눈 얹은 붉은 벽돌 굴뚝 / 앞면+눈 캡 / 지붕 위 2칸 / 같은 화풍 / 등불 모양으로 읽히던 것을 넓은 벽돌 몸통으로 다시 그림
- wz-post-gable: 박공 정면 / 앞면 삼각 / 건물 폭 3칸 / 같은 화풍 / 창 불빛 2톤
- wz-post-kit-office: 우체국 건물 5칸 완성 키트 / 지붕 윗면 4행+벽 / 건물 규모 / 같은 화풍 / 굴뚝 위치·눈 덩이 정리
- wz-post-kit-house: 작은 집 3칸 완성 키트 / 지붕 윗면+벽 / 건물 규모 / 같은 화풍 / 굴뚝 위치 맞춤
- wz-post-sort: 편지 분류 선반(3칸) / 앞면+윗판 / 사람 키 / 같은 화풍 / 칸 속 편지 점 정리
- wz-post-letters: 밀봉 편지 더미 / 윗면 / 사람 손 크기 / 같은 화풍 / 봉랍 빨강 점
- wz-post-sack: 배달 자루 걸이 / 앞면+윗면 / 사람 허리 / 같은 화풍 / 올리브 톤을 손으로 보정
- wz-post-perch: 부엉이 횃대 / 앞면 기둥+발판 / 사람 키 / 같은 화풍 / 받침 폭
- wz-post-counter: 우체국 카운터(3칸) / 윗면 상판+앞 패널 / 허리 높이 / 같은 화풍 / 상판 소품 배치
- wz-post-parcel / parcels: 소포 더미·무더기 / 윗면+앞면 / 사람 무릎 / 같은 화풍 / 끈 십자 표현
- wz-post-iwall / ibeam / iwall-win: 실내 목재 벽 1x4·1x1·1x2(창) / 앞벽 / 천장 높이 / 같은 화풍 / 기둥 쇠띠 톤

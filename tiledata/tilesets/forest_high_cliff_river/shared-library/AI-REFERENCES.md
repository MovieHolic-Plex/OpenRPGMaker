# 공용 숲마을 사용 안내

## 범위와 저장

이 자료는 16px `forest_high_cliff_river` 칩셋으로 만든 숲마을 전용이다.
타일 번호는 이 시트에서만 유효하다. 다른 타일셋에서는 그룹·이미지·열 수부터 확인한다.
현재 로컬 프로젝트의 정본은 `.oprn-projects/<project-id>/project.sqlite`다.
AI 참고문서도 `tilesets[id].referenceDocuments`에 들어가 SQLite와 프로젝트 내보내기에 함께 저장된다.
공용 장소·오브젝트의 앱 번들은 모든 프로젝트가 사용하는 배포본이다.
Supabase 스냅샷은 별도 원격 보존본이며 로컬 정본을 대체하지 않는다.

## 공용 장소의 선택

자료집 → 장소 → 공용에서 다음 7개 완성 외관을 참고한다.
등록은 새로운 미술 품질 승인을 뜻하지 않으며, 집 내부·NPC·상호작용은 포함하지 않는다.

| 장소 | 참고할 배치 |
|---|---|
| 달물 호반마을 | 큰 호수를 감싸는 C자 동선 |
| 두갈래 물길마을 | 갈라진 물길과 다리의 연결 |
| 층층 정원마을 | 높이가 다른 단구, 계단, 정상 위 집 |
| 긴숲 오솔마을 | 큰 연속 숲 사이의 좁고 굽은 취락 |
| 열매뜰 마을 | 과수원을 두르는 고리 길 |
| 잔물결 어촌 | 호숫가 마당과 선착장 |
| 다섯숲 숨은마을 | 중앙 숲을 보존한 여러 빈터 연결 |

집 앞·입출구·다리·계단의 착지를 먼저 연결하고, 그 경로를 따라 빈터를 만든다.
모든 마을을 십자형이나 일렬 도로로 만들지 않는다. 큰 숲 덩어리는 보존한다.
첨부 이미지는 선별 당시 동결한 전체 화면이다. 현재 편집 중인 맵과 혼동하지 않는다.

## 검수 순서

1. 실제 아틀라스와 16×16 칩 좌표를 확인한다.
2. 수관 내부 → 외곽/inner corner → 온전한 줄기/뿌리 순서로 구성한다.
3. 남향 수관의 같은 행에서 줄기가 시작하고, 끝 캡·반복부·뿌리가 잘리지 않았는지 확대한다.
4. 집, 계단, 다리와 길의 접속을 확인한다. 길/물은 오토타일로 계산한다.
5. 전체 사진과 확대 사진을 함께 보고, 엔진 통행 판정으로 집 앞과 출입구의 연결을 확인한다.
6. 편집기 저장 후 SQLite 재로드로 문서·맵이 보존되었는지 확인한다.

소품은 별도 칩셋 **숲마을 · 선별 소품 19종**의 AI 참고문서를 읽고 사용한다.
그 칩셋은 6열로 재배치되어 원본 30열의 타일 번호를 그대로 사용하면 안 된다.

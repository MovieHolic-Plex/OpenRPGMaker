# 숲 strip

타일셋 forest_harmony; 원점 (x,y); 전체 폭 14, 높이 6.

## 입력
```json
{
  "mapId": "실제맵ID",
  "placement": {
    "recipeId": "forest-strip",
    "x": 2,
    "y": 2
  }
}
```
요청 영역은 원점 (2,2)에서 이 문서에 명시한 전체 폭·높이이다. mapId를 실제 값으로 바꾼다.

각 행은 좌→우, 행 순서는 위→아래. 맵 좌표는 원점+(열,행).

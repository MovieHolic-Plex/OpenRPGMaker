**OPRN Studio 是一款内置 AI 助手的图块式 JRPG 制作工具。**
绘制地图、放置事件，立即试玩——或者直接对助手说
*「做一个有教堂和酒馆的港口小镇」*，它就会帮你铺好图块、门和 NPC。
地图由 16px 像素图块搭建，编辑器支持四种语言，你做出的游戏完全属于你。

## 最近新增

自 2026 年 10 月初首次公开以来加入的内容：

- 🎮 **手机和平板也能玩。** 导出的游戏支持触屏操作：屏幕摇杆、点击行走和对话、适合手指的菜单，并会根据竖屏或横屏调整布局。OPRN PLAY 上的游戏支持云存档。
- 🎵 **助手帮你挑素材。** 按场景和氛围搜索素材商店，安装音乐并接到你的地图上。它还能阅读玩家对你游戏的评价，起草回复，撰写更新公告。
- 🏰 **主题地下城。** 森林、冰窟、沼泽、金字塔、熔岩、矿坑、地下墓穴、法师之塔等，带楼梯、拉杆、关卡门和首领房间。
- 🧩 **助手能接更大的活。** 带开关谜题的分队行动、潜入与巡逻、有篝火对话的伙伴羁绊、雪路和林间路线、战斗中途加入的客串角色。
- ⚔️ **更有深度的战斗。** 最多四人的合体技、打断敌人蓄力、要打了才知道的弱点、物理与魔法伤害倍率，以及切入演出编辑器。
- 🛠️ **工坊。** 用一句话或一张照片做出地图物件、行走角色或地形，再从候选中挑你喜欢的。
- 🛒 **不断壮大的素材商店。** 目前有 40 个免费素材——其中音乐包 18 个、图块集 5 个、头像与立绘包 15 个。

## 下载

Windows 和 Linux 桌面版附在每个[发布](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases)里。顶部的按钮会下载最新版本。

- **Windows** —— 运行 EXE，或解压 ZIP 后运行 `OPRN Studio.exe`。
- **Linux** —— 用 `chmod +x` 给 AppImage 加上执行权限，然后运行。
- **macOS** —— 暂无安装包，请使用下面的源码命令。

如果按钮打开后显示「Not Found」，说明新版本还在上传。请到[发布列表](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases)下载上一个版本。

## 快速开始

适用于 macOS，或想从源码运行时。需要 [Node.js 24 LTS](https://nodejs.org/)。

```bash
npm ci
npm run mac:launch   # macOS / Linux —— 询问项目文件夹后打开 http://127.0.0.1:9999
```

首次启动时，请输入一个**新**文件夹的完整路径；项目会以 SQLite 和素材文件的形式保存在那里。
点击右上角的 AI 标签登录。

全部 281 首背景音乐不在上面的桌面安装包里，而是公开的 [bgm-v1 发布](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases/tag/bgm-v1)（`rpg-zzu-bgm-v1.tar`）。在源码目录运行 `npm run bgm:install` 会通过 HTTPS 下载，并用仓库里提交的 SHA-256 校验。只有这次下载被拒绝时才会用到 GitHub CLI。

## 开发者

```bash
npm ci
npm run dev              # 开发服务器 (http://localhost:9999)
npm run build:packaged   # 托管 / 桌面版渲染构建
npm run build:player     # 独立网页游戏播放器
npm start -- --project-dir /path/to/project   # 打开现有 SQLite 项目
npm test                 # 单元测试（在 GitHub CI 上运行。本地未设置 OPRN_LOCAL_TESTS=1 时会直接退出）
```

- 架构、数据与编辑器文档位于 [`openwiki/`](openwiki/)（目前为韩语）——请从 [`openwiki/quickstart.md`](openwiki/quickstart.md) 和 [`openwiki/PROJECT_WIKI.md`](openwiki/PROJECT_WIKI.md) 开始。
- 编程智能体请先阅读 [`AGENTS.md`](AGENTS.md)。
- 技术栈：Phaser + 原生 TypeScript DOM、SQLite 项目文件夹、Electron 桌面外壳。
- 世界地图地点图标在单独的公开仓库 [oprn-worldmap-kit](https://github.com/MovieHolic-Plex/oprn-worldmap-kit) 里。

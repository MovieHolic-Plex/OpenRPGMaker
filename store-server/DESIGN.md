# OPRN 에셋 스토어 웹 — 디자인 기준

웹 화면(`src/web/pages.ts` + `public/app.css`)과 에디터 안 스토어 창(`src/styles/database/assetStore/assetStore.css`)이 같이 따른다.

## 방향: 밤의 상점 진열대

- 상품은 거의 전부 도트 그림이다. 화면은 그림을 띄우는 **어두운 진열대**이고, 장식은 그림보다 앞에 나서지 않는다.
- 도트 그림은 언제나 `image-rendering: pixelated` 로, 어두운 체크 바탕 위에 둔다.
- 도트 글꼴(Galmuri11 Bold, SIL OFL)은 **제목·라벨·단추**에만 쓴다. 문단은 읽기 쉬운 고딕(Pretendard → Noto Sans KR → 시스템)으로 쓴다.
- 모서리는 둥글리지 않는다. 단추·표시는 2px 계단 모서리(`clip-path`)로 도트 느낌을 낸다. 카드는 2px 테두리에 모서리 2px.

| `--gold` | `#e7b24c` | 유일한 강조색(단추·선택·hover) |

| `--red` | `#e3705f` | 의미 색: 숨김·내림·오류 |

- 간격 단위 4px. 본문 15px/1.65. 제목 도트 글꼴 크기는 16의 배수 근처(16·24·32)로 맞춰 픽셀이 뭉개지지 않게 한다.
- 그림자는 흐림 없는 도트 그림자(`4px 4px 0`)만 쓴다.

## 상태와 움직임

- hover: 카드는 테두리를 금색으로 바꾸고 `translate(-2px,-2px)` 와 금색 도트 그림자를 준다. 그림은 움직이지 않는다(도트가 번지지 않게).
- 누름: `translate(0,0)` 로 그림자 위에 내려앉는다.
- 포커스: 금색 2px 외곽선, 2px 띄움.
- `prefers-reduced-motion` 이면 이동 없이 색만 바꾼다.

## 쓰지 않는 것

- 보라·파랑 그라데이션, 글자 그라데이션, 흐린 그림자, 둥근 알약 표시를 카드마다 여러 개 붙이기.
- 카드에는 표시를 최대 하나(「조수 사용 가능」)만 그림 위에 둔다. 라이선스·AI 여부는 글줄로, 자세한 건 상품 화면에서.
- 받기 0 같은 의미 없는 숫자. 받기 수가 0이면 「새로 올라옴」으로 쓴다.

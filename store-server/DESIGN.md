# OPRN 에셋 스토어 웹 — 디자인 기준

웹 화면(`src/web/pages.ts` + `public/app.css`)과 에디터 안 스토어 창(`src/styles/database/assetStore/assetStore.css`)이 같이 따른다.

## 방향: 그림이 주인공인 어두운 상점 (2026-10-06 두 번째 개편)

- 상품은 거의 전부 도트 그림이다. 화면은 그림을 크게 거는 **어두운 상점**이고, 크롬은 조용하게 둔다.
- 도트 그림은 언제나 `image-rendering: pixelated`, 그림 칸 바탕은 `#0b0d11` 한 색이다. 표지는 4:3 으로 맞춰 올린다.
- 글꼴은 언어별 시스템 고딕(한국어 Pretendard → Apple SD Gothic Neo → Malgun Gothic → Noto Sans CJK KR, 일본어 Hiragino → Yu Gothic → Meiryo, 중국어 PingFang SC → Microsoft YaHei). 도트 글꼴 Galmuri11 은 로고 「OPRN」에만 쓴다.
- 모서리는 카드 10px, 단추·입력 6px, 큰 덩어리 14px, 표시·칩은 알약.
- 첫 개편(도트 글꼴 제목·계단 모서리·도트 그림자)은 사용자가 「허접하다」고 해서 걷어 냈다.

## 토큰

| 이름 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#0f1116` | 바탕 |
| `--bg-2` | `#161922` | 카드·패널 |
| `--bg-3` | `#1e222e` | hover·올라온 면 |
| `--bg-4` | `#272c3b` | 꺼진 스위치 |
| `--line` / `--line-2` | `#262b38` / `#363d50` | 테두리 |
| `--text` / `--text-2` / `--muted` | `#eceef3` / `#c3c8d4` / `#8a91a2` | 글 |
| `--gold` | `#f0b54a` | 유일한 강조색(주 단추·가격·선택 밑줄) |
| `--teal` | `#4fc3a1` | 의미 색: 「조수 사용 가능」·공개 |
| `--plum` | `#b994e0` | 의미 색: 「AI 생성」 |
| `--red` | `#ef7a68` | 의미 색: 숨김·내림·오류 |

- 간격 단위 4px. 본문 15px/1.6(편집기 창 14px).
- 그림자는 떠 있는 것(언어 메뉴·창)에만, 카드에는 쓰지 않는다.

## 상태와 움직임

- 카드 hover: 바탕만 `--bg-3`, 그림은 1.04배. 이동·그림자 없음.
- 선택: 금색 2px 테두리(편집기 카드) 또는 금색 밑줄(종류 줄)·왼쪽 3px 금색 막대(옆 목록).
- 포커스: 금색 2px 외곽선.
- `prefers-reduced-motion` 이면 확대·전환·진열 자동 넘김을 끈다.

## 쓰지 않는 것

- 보라·파랑 그라데이션, 글자 그라데이션, 유리 효과. 그라데이션은 그림 위 이름표 받침 한 곳뿐이다.
- 카드 그림 위 표시는 「조수 사용 가능」 하나. 라이선스·AI 여부는 글줄로, 자세한 건 상품 화면에서.
- 받기 0 같은 의미 없는 숫자. 받기 수가 0이면 「새로 올라옴」.
- 문장을 조각으로 이어 붙인 번역. 문구는 언어별 통문장(`src/web/i18n.ts`)으로 둔다.

**OPRN Studio は AI アシスタントを内蔵したタイル式 JRPG メーカーです。**
マップを描き、イベントを置いて、すぐにテストプレイ。あるいはアシスタントに
*「教会と酒場のある港町を作って」* と頼めば、タイルや扉、NPC まで配置してくれます。
マップは 16px のドット絵タイルで組み、エディタは 4 か国語に対応。作ったゲームはあなたのものです。

## 新しくなったこと

2026 年 10 月初めの初公開から加わったもの：

- 🎮 **スマホとタブレットで遊べる。** 書き出したゲームにタッチ操作が入りました。画面スティック、タップで歩く・話しかける、指で押しやすいメニュー。縦画面にも横画面にも合わせて配置されます。OPRN PLAY のゲームはクラウドセーブに対応。
- 🎵 **アシスタントが素材を選んでくれる。** 場面と雰囲気でアセットストアを探し、音楽をインストールしてマップにつなぎます。あなたのゲームに付いたプレイヤーレビューを読み、返信の下書きやアップデートのお知らせも書きます。
- 🏰 **テーマ別ダンジョン。** 森・氷・沼・ピラミッド・溶岩・鉱山・地下墓地・魔法使いの塔など。階段・レバー・関門・ボス部屋まで備えたダンジョンを作ります。
- 🧩 **アシスタントに任せられる仕事が増えた。** スイッチ謎解き付きのパーティー分割、潜入と巡回、焚き火の会話がある仲間の絆、雪道・森の道のルート、戦闘中に加わるゲスト。
- ⚔️ **戦闘がより深く。** 最大 4 人の連携技、敵のため行動を中断させるブレイク、殴って初めてわかる弱点、物理・魔法の被ダメージ率、カットイン演出エディタ。
- 🛠️ **工房。** マップの物、歩くキャラクター、地形を、一行の説明や写真から作り、気に入った候補を選べます。
- 🛒 **広がるアセットストア。** 現在、無料アセット 40 点——音楽パック 18、タイルセット 5、顔・立ち絵パック 15。

## ダウンロード

Windows・Linux のデスクトップ版は各[リリース](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases)に添付されています。上のボタンはいちばん新しいビルドをダウンロードします。

- **Windows** —— EXE を実行するか、ZIP を展開して `OPRN Studio.exe` を実行してください。
- **Linux** —— AppImage に `chmod +x` で実行権限を付けてから実行してください。
- **macOS** —— パッケージ版はまだありません。下のソースからの起動を使ってください。

ボタンを押して「Not Found」と出たら、新しいリリースをアップロード中です。[リリース一覧](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases)から一つ前のものを選んでください。

## クイックスタート

macOS の方、またはソースから動かす場合です。[Node.js 24 LTS](https://nodejs.org/) が必要です。

```bash
npm ci
npm run mac:launch   # macOS / Linux —— プロジェクトフォルダを尋ねたあと http://127.0.0.1:9999 を開きます
```

初回起動時は**新しい**フォルダのフルパスを入力してください。プロジェクトはそこに SQLite とアセットファイルとして保存されます。
右上の AI チップを押してログインしてください。

全281曲の音楽は、上のデスクトップ版とは別の公開 [bgm-v1 リリース](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases/tag/bgm-v1)（`rpg-zzu-bgm-v1.tar`）です。ソースから `npm run bgm:install` を実行すると HTTPS で受け取り、コミット済みの SHA-256 で検証します。GitHub CLI は、そのダウンロードが拒否されたときだけ使います。

## 開発者向け

```bash
npm ci
npm run dev              # 開発サーバー (http://localhost:9999)
npm run build:packaged   # ホスト / デスクトップ用レンダラーのビルド
npm run build:player     # 単体の Web ゲームプレイヤー
npm start -- --project-dir /path/to/project   # 既存の SQLite プロジェクトを開く
npm test                 # ユニットテスト（GitHub CI。ローカルは OPRN_LOCAL_TESTS=1 がないとすぐ終了）
```

- 設計・データ・エディタの資料は [`openwiki/`](openwiki/) にあります（現在は韓国語）。まず [`openwiki/quickstart.md`](openwiki/quickstart.md) と [`openwiki/PROJECT_WIKI.md`](openwiki/PROJECT_WIKI.md) から。
- コーディングエージェントは最初に [`AGENTS.md`](AGENTS.md) を読んでください。
- 技術スタック：Phaser + 素の TypeScript DOM、SQLite プロジェクトフォルダ、Electron デスクトップシェル。
- ワールドマップの場所アイコンは別の公開リポジトリ [oprn-worldmap-kit](https://github.com/MovieHolic-Plex/oprn-worldmap-kit) にあります。

# knownTowns.json 출처

배치 구조 지문(덩어리 위치·크기·채움)만 담는다. 건물 그림이나 맵 원본은 없다.

- 만든 곳: assistant-reward 레인의 보상 DB(`~/.dori/state/lanes/assistant-reward/rdb.py` 의 `town_struct`) — 맵마다 바닥 타일의 60% 를 덮는 바탕 타일을 빼고 남은 칸·위층 칸의 4방향 이어진 덩어리(6칸 이상)를 맵 크기로 나눈 (x, y, 크기) 로 적는다. `src/ai/v2/townStructure.ts` 의 `townStructOf` 가 같은 계산이다.
- 날짜: 2026-11-09. 원천은 번들 데모 게임(c8-hero·c9-sea 의 마을·항구 맵)과 조수 기준선 판(asst:base/*)이다.
- 걸러낸 것: 덩어리 4개 미만, 맵의 40% 를 넘는 덩어리, 거의 같은 지문(유사도 0.95 이상), 마을이 아닌 맵(여관 안·우주정거장·거의 빈 맵).
- 다시 만들려면 같은 계산을 `townStructOf` 로 돌려 JSON 을 덮어쓰면 된다(조건: 마을로 지은 맵, 600칸 이상). 추출용 스크립트는 레인 내부 보상 DB 에 묶여 있어 저장소에 넣지 않았다 — 위 지문 계산이 정본이다.

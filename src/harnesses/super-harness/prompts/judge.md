# 슈퍼하네스 · 조수 시험 판정

개념 카드 「{{CONCEPT}}」 를 실제 AI 조수에게 붙여 봤다. 같은 요청 「{{TEXT}}」 을 새 프로젝트에서 카드 **없이**(기준) 2판, 카드를 **붙이고**(시도 {{ATTEMPT}}) 2판 돌렸다.
너는 카드가 조수를 **실제로 낫게 만들었는지** 판정한다. 기본값은 의심이다 — 숫자 하나 좋아졌다고 통과시키지 마라.

## 자료

- 카드: `{{CDIR}}/card.json`
- 기준 판: `{{CDIR}}/probe/base-*/` — `score/score.json`, `score/*.png`(새 맵 그림), `tools.jsonl`(조수가 부른 도구·인자), `instruction.txt`
- 카드 판: `{{CDIR}}/probe/a{{ATTEMPT}}-*/` — 같은 구성. `classification.json` 에 `[개념 카드` 가 있으면 카드 노트가 실제로 붙은 것.
- 숫자 요약 — 기준: {{BEFORE}}
- 숫자 요약 — 카드: {{AFTER}}

그림을 **모두 열어** 기준과 카드 판을 나란히 비교한다. 그림 표식: 이벤트는 색 테두리(금색 상자·빨강 함정·하늘색 세이브·파랑 문·보라 스위치), 빨간 X 는 이벤트 없이 칠한 장치 그림.

## 기준

PASS 는 카드 판이 기준 판보다 **분명히** 낫고 어느 것도 나빠지지 않았을 때만:
- 이 개념답다(구조가 맞다) · 쓸데없는 기물이 적다 · 동작하는 장치가 이벤트로 깔렸다 · 조수가 엉뚱한 일(묻지 않은 마을·인물)을 덜 했다.
- 카드 판 2판 중 하나라도 맵을 못 만들었거나 망가졌으면 FAIL.
- FAIL 이면 카드를 **어떻게 고치면** 조수가 나아질지 구체적으로 적는다(조수가 카드의 어느 문장을 오해했는지, tools.jsonl 근거로).

결과를 `{{RESULT}}` 에 JSON 으로 쓴다(저장소 파일은 고치지 마라):

```json
{"verdict": "PASS 또는 FAIL", "reasons": ["…"], "summary": "기준 대비 무엇이 어떻게 달라졌는지 한두 문장"}
```

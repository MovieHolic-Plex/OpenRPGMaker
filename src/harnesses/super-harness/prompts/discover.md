# 슈퍼하네스 · 낱말 발견

RPG 에디터 OPRN 의 AI 조수는 「미궁을 만들어줘」 같은 공간·장소 낱말을 들으면 재료·구조를 몰라 엉뚱한 맵을 만든다.
슈퍼하네스는 이런 낱말마다 **개념 카드**를 만들어 조수에게 준다. 너는 **다음에 만들 개념**을 고른다.

## 이미 있는 개념 (다시 내지 마라 — 폐기된 것도)

```json
{{EXISTING}}
```

## 조수 실패 흔적 (실제 로그에서 뽑은 것)

```json
{{FINDINGS}}
```

- `zeroHitSearches`: 조수가 공용 장소·오브젝트를 이 낱말로 찾았는데 0건이었다.
- `layoutRepairRequests`: 조수가 맵을 깔았다가 「빈칸이 많다」는 수리 지시를 받은 요청.

## 낱말 은행과 방향

```json
{{SEED}}
```

## 고르는 기준

1. 실패 흔적에 나온 것 먼저(source:"log").
2. RPG 쯔꾸르류 사용자가 실제로 자주 칠 공간·장소 낱말(source:"vocab"). 세계관(중세·현대·일본·조선·호러·SF)을 고루.
3. 지금 칩셋으로 **지을 수 있는 것** 먼저 — 실내형은 손 도트 실내 v5(`{{ROOT}}/src/assets/handInteriorSpec.json` 의 기물 사전을 훑어 재료가 있는지 본다).
   재료가 거의 없는 것은 priority 를 낮게 하되 넣어도 된다(부족분이 드러나는 것도 가치다).
4. 이미 있는 개념과 겹치면 내지 마라(같은 것의 다른 이름이면 별칭일 뿐이다).

5. 이미 있는 개념의 **하위 공간**(카타콤 → 카타콤 2층)은 슈퍼하네스가 따로 낸다 — 너는 새 뿌리 개념을 고른다.
   큰 것(성도·수도·대미궁·학교·병원)과 작은 것(교실·여관방)을 섞는다.

6~10개를 골라 `{{RESULT}}` 에 JSON 배열로 쓴다(저장소 파일은 고치지 마라):

```json
[{"id":"kebab-case-english","title":"한국어 이름","aliases":["한국어","영어","변형"],"why":"근거 한 문장","source":"log|vocab|gap","priority":0.0}]
```

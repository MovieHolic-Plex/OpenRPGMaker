재료 자료 받기불러오는 중…

프로젝트를 다시 열고 타일셋 「실내 · 사용자가 고른 공용 기물」에서 사용하세요. 기존 지도에 배치한 기물이 자동으로 이 칩셋으로 바뀌지는 않습니다.

저장 위치와 적용 범위

선택·메모는 선택 DB, 제작·검수는 하네스 DB에 저장됩니다. 확정한 그림과 배치 지침은 같은 호스트의 공용 SQLite에 게시됩니다.

프로젝트는 공용 자료를 불러올 때 갱신됩니다. 이미 열린 프로젝트는 다시 열어 최신 자료를 받아야 해요. 공간 제작에 사용할 때는 용도·시대별 재료 검수를 거칩니다.

원본 앱 번들, 다른 서버의 DB, 기존 지도에 찍힌 다른 칩셋을 덮어쓰는 기능은 아닙니다.

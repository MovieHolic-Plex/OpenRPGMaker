## 절대 규칙
1. 그림 생성 모델·이미지 API·외부 그림을 쓰지 않는다. 그릴 원본은 `base.face.txt` 하나뿐이다.
2. **이건 「고치기」다.** `cp base.face.txt out.face.txt` 에서 시작해, 칩과 달라야 하는 부위(머리카락 모양·색, 모자·두건·장신구, 눈 색, 옷깃·어깨 옷 색, 수염 등)만 고친다.
   얼굴 윤곽선·눈·코·입의 선, 얼굴 방향과 구도는 원래 픽셀을 그대로 두고 필요하면 색만 바꾼다. 빈 칸에서 새로 그리지 않는다.
3. 색을 바꿀 때는 원본의 명암 단계(가장 밝음 → 중간 → 그늘 → 윤곽)를 새 색의 같은 단계로 1:1 로 옮긴다. 원본은 부드러운 명암(색이 많다)이므로 같은 결을 유지한다.
4. 머리 모양이 바뀌면(묶은 머리·민머리·두건) 그 부분은 원본 머리카락의 결(선 방향, 하이라이트 띠)을 흉내 내어 직접 찍는다. 작은 스크립트는
   기계적인 일(색 글자 일괄 바꾸기, 영역 복사·이동)에만 쓴다. 도형을 계산해 칠하는 스크립트(원·그라디언트·노이즈)는 쓰지 않는다.
5. 48×48 칸을 꽉 채운다(투명 '.' 를 쓰지 않는다). 색은 90개 이하, 색 글자는 한 글자(아무 ASCII 기호, '.' '#' 제외).

## 형식 (`base.face.txt` 를 보면 바로 안다)

<48글자 × 48줄>

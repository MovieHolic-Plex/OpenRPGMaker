# 기존 인물의 행동 포즈 — GPT 6.1 sol high 직접 도트

주문: {REQUEST}
검증된 걷기 원본: {SOURCE}
출력 폴더: {OUTPUT}

주문의 poses 전체를 만든다. 걷기 원본의 `views/sheet_rgba.png`와 각 방향 정지를 실제로 연다.
새 사람을 만들지 않고 같은 머리·얼굴·옷·신발의 인물이 팔/손/도구로 지정 동작을 하도록 저작한다.
원본 격자·걷기 시트·기존 선택·하네스 코드를 변경하지 않는다.

## 원본/접지 계약

- 출력은 `actions.px.json`이다. 형식은 {FORMAT}, width/height는 주문 canvas, maxColors는 주문 palette 수다.
- 프레임 ID는 poses 순서대로 `pose.id-0`, `pose.id-1`, … 이다. durationMs와 anchor는 주문 값과 같아야 한다.
- 24×32 원본의 정지(`direction` 1)를 (origin.x-12, origin.y-31)에 놓는다.
  원본 bbox 위부터12행 이내 머리와 아래3행 발/신발은 화소·위치를 보존한다. 몸/팔/도구를 그려 행동을 만든다.
- 머리/발을 이동시키거나 인물 전체를 늘려 접합을 맞추지 않는다. 추가 캔버스는 팔·도구가 뻗는 공간이다.
- 팔레트는 주문의 색만 쓰고 `.`만 투명이다. 각 행동 프레임에 정지와 다른 직접 저작 픽셀이 있어야 한다.
- 완전한 행 문자열/명시 좌표 패치로 그린다. 원본의 고정 부분을 복사하는 것은 가능하다.
  팔·지팡이·줄자의 새 형태와 각 중간 프레임은 직접 찍는다. 도형/선 함수·회전·보간·노이즈로 만들지 않는다.
- 준비→동작→유지/복귀 단계에서 손과 도구의 부착이 끊어지지 않게 한다. 움직이지 않는 몸체에 색만 깜빡이는 것은 동작이 아니다.
- 행동별 설명과 한계는 notes.md에 남긴다. 공간 안에서 실제 접촉했거나 전체 맵을 완성했다고 주장하지 않는다.

## 확인

`python3 {GRID} inspect {OUTPUT}/actions.px.json`으로 좌표/행을 확인한다.
`python3 {TOOL} check {REQUEST} --out {OUTPUT}`를 실행한다.
views의 1배 sheet.png, 확대 contact-grid, 밝은/어두운/체커 GIF를 열어 모든 프레임을 확인한다.
기계 검사가 실패하면 직접 원본 행을 고치고 다시 실행한다. 검사 JSON을 수정하지 않는다.
검사 통과는 미감/공간 검수나 사용자의 Allow가 아니다. 하위 모델을 시작하지 않는다.

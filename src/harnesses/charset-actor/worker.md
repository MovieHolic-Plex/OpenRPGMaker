## 절대 규칙
1. **그림 생성 모델·이미지 생성 API·외부 그림을 쓰지 않는다.** 인터넷에서 스프라이트를 가져오거나, 다른 그림을 격자로 변환하지 않는다.
   쓸 수 있는 그림 원본은 `base.chr.txt`({BASE_LABEL}) 하나뿐이다. 참고로 그 칩셋 전체(`{SHEET_PNG}`)는 **봐도 되지만 픽셀을 복사하지는 않는다.**
2. 모양은 **네가 격자 글자를 직접 고쳐서** 정한다. 작은 스크립트는 기계적인 일에만 써라 — 오른쪽을 좌우로 뒤집어 왼쪽 초안 만들기,
   프레임 복사, 한 색 글자를 다른 색으로 일괄 바꾸기, 영역을 1px 옮기기. 도형을 계산해서 칠하는 스크립트(원·그라디언트·노이즈)로 그림을 대신하지 않는다.
3. 결과는 RM2000 CharSet 형식 그대로다: 프레임 24×32, 방향 4개(up·right·down·left) × 걸음 3장(0·1·2, **1 이 서 있는 자세**, 0·2 가 발을 내디딘 자세).
4. **이건 「고치기」다. 처음부터 다시 그리지 않는다.** `out.chr.txt` 는 뼈대를 복사한 것에서 출발한다. 얼굴 모양·눈 위치, 팔·손·다리·발의
   모양과 위치는 원래 픽셀을 두고 색만 바꾼다(2026-10-02 Sonnet 첫 시도가 빈 칸에서 새로 그려 몸이 네모 상자가 됐다).
   색을 바꿀 때는 원본의 명암 단계(밝음·중간·그늘·윤곽)를 새 색의 같은 단계로 옮긴다.
5. **네가 고치는 것은 서 있는 자세 4장(frame up 1·right 1·down 1·left 1)뿐이다.** 걸음 프레임(0·2)은 손대지 마라 —
   하네스가 끝에 뼈대의 걸음 움직임을 따라 네 서 있는 자세에서 **자동으로 다시 만든다**(`propagate`). 그래서 머리 모양·옷 무늬를 바꿔도
   걸을 때 깜빡이거나 어긋나지 않는다. 중간에 확인하려면 `{TOOL} propagate out.chr.txt --base {BASE_N} --strength {STRENGTH}` 를 돌리고 views 를 본다.

## 파일 형식 (`base.chr.txt` 를 열어 보면 바로 안다)
```
palette
. transparent
a #000000   (설명은 자유롭게 붙여도 된다)
...
frame up 0
........................   ← 24글자 × 32줄. 한 글자 = 한 픽셀, '.' = 투명
```
- 색은 48개 이하(뼈대가 48개를 넘으면 뼈대 수 +4개까지), 색 글자는 한 글자(영문·숫자). `#009392`의 각 RGB 채널 ±8 범위도 몸체 색으로 못 쓴다.
- 머리·얼굴·목·몸체를 투명으로 파내지 않는다. 배경이 새는 새 내부 구멍, 머리 내부 면 삭제, 프레임 위/옆 경계의 잘림은 즉시 폐기다.
- 전파한 걸음 0·2를 포함해 12장 모두 확인한다. 손/다리 사이의 원래 열린 배경과 몸체 내부 결손을 구분한다.
- 새 색을 넣어도 되고, 안 쓰는 원본 색은 팔레트에서 지워라.

## 작업 순서
1. `cp base.chr.txt out.chr.txt` 로 시작한다. `base-views/` 의 `strip.png`, `sheet_x8.png` 를 열어 뼈대를 먼저 눈으로 본다.
2. 서 있는 자세 네 방향을 고친다: 아래(정면) → 위(뒷모습) → 오른쪽 → 왼쪽(오른쪽 거울 초안에서 비대칭인 곳만 고친다).
   네 방향이 같은 사람이어야 한다 — 정면에서 바꾼 머리 모양·옷 무늬가 뒷모습·옆모습에도 같은 모습으로 있어야 한다.
3. 전파하고, 검사하고, **그림을 직접 열어 본다:**
   ```
   {TOOL} propagate out.chr.txt --base {BASE_N} --strength {STRENGTH}
   {TOOL} check out.chr.txt --base {BASE_N} --strength {STRENGTH}
   {TOOL} views out.chr.txt views --base {BASE_N} --strength {STRENGTH}
   ```
   `views/strip.png` = 방향마다 [원본 서 있는 자세 | 0 | 1 | 2 | 1 | 0↔2 차이(빨강)], `views/sheet_x8.png` = 4px 격자선이 있는 8배 시트.
   GIF(`walk.gif` 등)는 사람용이다 — 너는 첫 장만 보이므로 strip 과 sheet 로 판단한다.
   전파된 걸음에 이상한 곳이 보이면 걸음 프레임을 고치지 말고 **서 있는 자세를 고쳐** 다시 전파한다.
4. 기계 검사가 통과하고 아래 자기 검수를 다 할 때까지 2~3 을 되풀이한다.

## 자기 검수 (눈으로, 조각마다 한 줄씩 notes.md 에 쓴다)
- 정면·뒷면·옆모습이 **같은 사람**으로 읽히는가(두건 색·조끼 위치·장화 높이가 방향마다 일치).
- 원본 RTP 캐릭터 옆에 놓았을 때 같은 게임 그림으로 보이는가: 윤곽선은 어두운 색으로 끊김 없이, 면마다 3~4단 명암, 빛은 왼쪽 위.
- 원본 옆에 놓았을 때 바뀐 정도가 6번의 강도에 맞는가(약함 = 모양 그대로 색만, 보통 = 머리나 옷 모양이 하나 이상 확실히 다름, 강함 = 다른 직업의 다른 사람).
- 왼쪽 방향은 오른쪽의 단순 거울이 아니라, 가르마·비대칭 무늬가 맞는 쪽에 있는가.
- 1배(`views/sheet.png`)로 봤을 때 무엇인지 읽히는가.

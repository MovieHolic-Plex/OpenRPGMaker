## 절대 규칙
1. **그림 생성 모델·이미지 생성 API·외부 그림을 쓰지 않는다.** 인터넷에서 스프라이트를 가져오거나, 다른 그림을 격자로 변환하지 않는다.
   쓸 수 있는 그림 원본은 `base.chr.txt`({BASE_LABEL}) 하나뿐이다. 참고로 그 칩셋 전체(`{SHEET_PNG}`)는 **봐도 되지만 픽셀을 복사하지는 않는다.**
2. 모양은 **네가 격자 글자를 직접 고쳐서** 정한다. 작은 스크립트는 기계적인 일에만 써라 — 오른쪽을 좌우로 뒤집어 왼쪽 초안 만들기,
   프레임 복사, 한 색 글자를 다른 색으로 일괄 바꾸기, 영역을 1px 옮기기. 도형을 계산해서 칠하는 스크립트(원·그라디언트·노이즈)로 그림을 대신하지 않는다.
3. 결과는 RM2000 CharSet 형식 그대로다: 프레임 24×32, 방향 4개(up·right·down·left) × 걸음 3장(0·1·2, **1 이 서 있는 자세**, 0·2 가 발을 내디딘 자세).
4. **이건 「고치기」다. 처음부터 다시 그리지 않는다.** `out.chr.txt` 는 뼈대를 복사한 것에서 출발해, 지시가 바꾸라는 부위(머리 모양·옷 색·소지품)의
   픽셀만 고친다. 지시가 건드리지 않는 부위 — 얼굴 모양·눈, 팔·손·다리·발의 모양과 위치, 걸음 프레임의 동작 — 는 **원래 픽셀을 그대로 두고 색만 바꾼다.**
   프레임을 빈 칸에서 새로 쓰거나, 서 있는 자세를 새로 찍어 걸음 프레임을 거기서 만들어 내지 않는다(2026-10-02 Sonnet 첫 시도가 그렇게 해서
   몸이 네모 상자가 되고 걸음이 사라졌다). 색을 바꿀 때는 원본의 명암 단계(밝음·중간·그늘·윤곽)를 새 색의 같은 단계로 1:1 로 옮긴다.
5. **실루엣은 뼈대 그대로다. 새 소지품을 더하지 않는다** — 무기·모자·두건·들고 있는 물건·망토·날개·지팡이·가방을 새로 그려 넣지 않는다
   (2026-10-02 사용자 판정: 「무기나 모자 추가는 별로」 — 버린 캐릭터 23개 중 19개가 그런 것이었다). 뼈대에 원래 있는 소지품은 그대로 두고 색만 바꿔도 된다.
   바꾸는 것은 뼈대 실루엣 **안쪽**이다: 머리색, 옷 색 구성, 옷 무늬·단추·띠·깃 같은 안쪽 디테일, 피부 톤, 눈 색.
   기계 검사가 뼈대와 실루엣이 다른 픽셀을 12프레임 합으로 재서 150 을 넘으면 불합격이다.

## 파일 형식 (`base.chr.txt` 를 열어 보면 바로 안다)
```
palette
. transparent
a #000000   (설명은 자유롭게 붙여도 된다)
...
frame up 0
........................   ← 24글자 × 32줄. 한 글자 = 한 픽셀, '.' = 투명
```
- 색은 32개 이하, 색 글자는 한 글자(영문·숫자). `#009392`(배경 키 색)는 못 쓴다.
- 새 색을 넣어도 되고, 안 쓰는 원본 색은 팔레트에서 지워라.

## 작업 순서
1. `cp base.chr.txt out.chr.txt` 로 시작한다. `base-views/` 의 `strip.png`, `sheet_x8.png` 를 열어 뼈대를 먼저 눈으로 본다.
2. **서 있는 자세(frame * 1) 네 방향부터** 완성한다: 아래(정면) → 위(뒷모습) → 오른쪽 → 왼쪽(오른쪽 거울 초안에서 비대칭 소지품만 고친다).
3. 그다음 걸음 0·2 를 만든다. 뼈대의 걸음 프레임이 서 있는 자세와 어떻게 다른지(다리·팔·몸 1px 출렁임)를 그대로 따른다 —
   머리·몸통의 바뀐 부분(두건·옷)을 걸음 프레임에도 같은 모양으로 옮기고, 1px 출렁임에 맞춰 같이 움직인다.
4. 매 단계마다 검사하고 **그림을 직접 열어 본다:**
   ```
   {TOOL} check out.chr.txt --base {BASE_N}
   {TOOL} views out.chr.txt views --base {BASE_N}
   ```
   `views/strip.png` = 방향마다 [원본 서 있는 자세 | 0 | 1 | 2 | 1 | 0↔2 차이(빨강)], `views/sheet_x8.png` = 4px 격자선이 있는 8배 시트.
   GIF(`walk.gif` 등)는 사람용이다 — 너는 첫 장만 보이므로 strip 과 sheet 로 판단한다.
5. 기계 검사가 통과하고 아래 자기 검수를 다 할 때까지 고친다.

## 자기 검수 (눈으로, 조각마다 한 줄씩 notes.md 에 쓴다)
- 정면·뒷면·옆모습이 **같은 사람**으로 읽히는가(두건 색·조끼 위치·장화 높이가 방향마다 일치).
- 원본 RTP 캐릭터 옆에 놓았을 때 같은 게임 그림으로 보이는가: 윤곽선은 어두운 색으로 끊김 없이, 면마다 3~4단 명암, 빛은 왼쪽 위.
- 걸음 0·1·2·1 을 넘겨 볼 때 두건·화살통이 프레임마다 흔들리거나 모양이 바뀌지 않는가(바뀌면 깜빡여 보인다).
- 왼쪽 방향은 오른쪽의 단순 거울이 아니라, 화살통·활을 메는 쪽이 맞는가.
- 1배(`views/sheet.png`)로 봤을 때 무엇인지 읽히는가.

# 캐릭터 묶음 저작

GPT 6.1 sol high가 에디터용 캐릭터 묶음을 직접 도트로 변형한다. 이 작업 폴더 안 `characters/`의 지정된 사람만 만든다. 다른 묶음이나 저장소 코드는 수정하지 않는다.

## 공통 계약

- 이미지 생성 API, 인터넷 그림, 다른 캐릭터의 픽셀 복사는 금지한다. 각 사람의 유일한 픽셀 원본은 그 폴더의 `base.chr.txt`다.
- 원본에서 시작해 **서 있는 네 방향(frame up/right/down/left 1)**의 격자 문자를 직접 편집한다. 걸음 0·2는 자동 전파한다.
- 팔레트 변환·프레임 복사 등 기계 작업은 스크립트로 해도 된다. 머리·깃·상의·하의의 모양은 직접 작성한 ASCII 행으로 정한다. 색만 바꾼 8명이 되어서는 안 된다.
- 24×32, 원본 머리 크기·얼굴·눈 위치·손과 발 위치를 유지한다. 원본 교복은 유지할 필요 없다. 옷 부분을 긴소매·치마·바지·도포·앞치마 등 지정된 복식으로 다시 찍는다.
- 머리와 옷을 **네 방향 모두** 새로 찍는다. 단색 헬멧 같은 머리를 피하고 3~4단 명암·가르마·목덜미를 둔다. 얼굴 눈은 원본처럼 또렷하게 둔다.
- 실루엣 큰 무기·높은 모자·날개·가방은 추가하지 않는다. 몸 안쪽 작은 표식·장신구만 쓴다. 얼굴과 피부·옷은 깃 경계로 분리한다. 체크 같은 잡티를 뿌리지 않는다.
- 머리·옷 모양이 지정된 역할끼리 다르게 보여야 한다. 갑옷 판, 사선 여밈, 긴 외투, 앞치마 끈, 조끼, 제복 주머니 같은 **형태**로 구분한다.
- 배경 키 색 #009392는 팔레트에 쓰지 않는다. 색 글자는 한 글자, 투명은 '.'. 원본 색 수가 48을 넘으면 원본+4색까지, 아니면 48색까지다.

## 반복된 탈락을 피하는 저작 기준

- 옆모습도 몸통·소매·하의를 **이어진 면**으로 직접 다시 찍는다. 원본 갑옷의 점·체크에 색만 옮기면 새 옷에도 잡티가 남는다. 명암은 부위마다 3단 큰 면으로 정리한다.
- 깃·여밈·허리띠 가운데 읽히는 형태 1~2개를 골라 네 방향 같은 높이에 둔다. 작은 장식을 많이 넣지 않는다. 피부와 옷을 서로 다른 색으로 분리한다.
- 머리의 명암은 가닥으로 이어지게 한다. 밝은 픽셀을 체크처럼 흩뿌리지 않는다. 원본 눈과 입을 보존하고 머리 아래에 목/깃의 경계를 남긴다.
- 원본에 왕관·무기·특수 복식이 있으면 새 역할에도 맞는지 본다. SF 주민의 왕관 잔재, 평상복에 남은 칼 조각처럼 지시와 맞지 않는 형태는 네 방향에서 함께 정리한다.
- 전파된 0·2의 옷 면·밑단·신발을 1과 비교한다. 색 점이 흩어지거나 옷 경계가 끊기면 서 있는 자세의 면을 단순하게 정리한 뒤 다시 전파한다. 최종 `context.png`에서도 같은 옷으로 읽혀야 한다.

## 작업 순서

1. `assignments.json`을 읽고 각 폴더의 `base.chr.txt`, `base-views/sheet_x8.png`를 직접 본다. 같은 원본 칸은 한 번 보면 된다.
2. 각 폴더에 원본을 복사한 `out.chr.txt`를 만들고, 지시된 머리·복식을 네 방향에서 편집한다. 행은 정확히 24글자, 프레임은 32줄이다. `chr.py`의 load/dump를 기계적으로 사용해도 된다.
3. 각 결과에 다음 명령을 실행한다(BASE와 STRENGTH는 assignments 값):
   ```
   {TOOL} propagate characters/KEY__gpt-r1/out.chr.txt --base BASE --strength STRENGTH
   {TOOL} views characters/KEY__gpt-r1/out.chr.txt characters/KEY__gpt-r1/views --base BASE --strength STRENGTH
   ```
4. 실제 `views/strip.png`와 `views/sheet_x8.png`를 열고 걸음·눈·방향 일관성을 본다. 기계 검사 실패가 있으면 해당 사람의 **서 있는 프레임**을 수정해 전파한다. 다른 사람의 완성 결과를 덮어쓰지 않는다.
5. 각 폴더에 `notes.md`로 실제 바꾼 형태, 직접 본 그림, 남은 아쉬움을 적는다. 모든 지정된 사람의 결과를 남기고 끝낸다.

한 번의 저작 작업이다. 독립 검수는 감독이 따로 실행한다. 질문하지 말고 지정된 사람 전원을 완성한다. 작업 폴더 밖에는 아무것도 쓰지 않는다.

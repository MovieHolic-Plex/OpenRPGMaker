# 새솔 RED · 첫 번째 배지

에디터에서 편집하는 5개 맵·33개 이벤트의 약 10분 목표 모험입니다. 첫 동료 선택, 소포 배달, 라이벌/수련생 전투, 동굴 탐사, 배지 도전을 포함합니다. 3장면 오프닝과 맵별 BGM이 지정돼 있습니다. 플레이 시간은 사람 기준으로 계측하지 않았습니다.

`project.json.gz`는 전체 이미지와 문서를 포함하는 이동 가능한 프로젝트 JSON입니다. 실행 중인 서비스나 사용자 홈 디렉터리 없이 새 SQLite 프로젝트로 복원할 수 있습니다:

```sh
npx vite-node scripts/content/import-saesol-red.mts /absolute/path/to/new-saesol-project
```

대상 디렉터리가 이미 있으면 덮어쓰지 않습니다. 복원한 디렉터리를 에디터에서 여십시오. 게임 상태는 처음부터 시작하며, 문 칸으로 걸어 들어가면 이동합니다. 방향키 이동, Z/Enter 대화, Esc 메뉴/오프닝 건너뛰기입니다.

그래픽: Isaiah658 Pixel Pack #2, CC0. 출처: https://opengameart.org/content/isaiah658s-pixel-pack-2 . 교정된 이미지는 `project.json.gz`에 포함돼 있습니다. BGM은 저장소의 CC0 카탈로그를 사용하므로 해당 음악 파일이 설치된 에디터가 필요합니다.

검증: SQLite 저장/재열기, 연구소·상점 왕복, 동료 없는 전투 차단, 시작 동료 3종의 전투 뒷모습, 오프닝 전체 진행. 에디터 엔진 수정은 캐릭터·몬스터 알파 보존, 좌우 방향 변환, ref 자산 로딩과 편집 화면 방향 표시를 포함합니다.

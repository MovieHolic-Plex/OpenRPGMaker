# 직접 도트 저작

윤곽, 색 덩어리, 명암과 가장자리의 **최종 픽셀을 직접 결정**한다. 원본은 팔레트 글자로 쓴 격자다.
코드는 그 격자를 읽고, 요청한 좌표를 적용하고, 그림을 굽고, 검사 결과를 보여준다.

## 적용 범위와 원본

- 먼저 프로젝트 지침과 해당 자산의 하네스를 확인한다. RM2000 캐릭터처럼 별도 하네스가 필수이면 그 하네스의 격자/좌표 도구를 사용한다. 이 도구로 사람의 선택이나 정본 게시를 우회하지 않는다.
- 기존 그림을 고치면 원본을 보고 해당 크기·팔레트·레이어·접지 계약을 따른다. 사용자가 직접 찍는 방식을 요청한 작업에 이 스킬의 저작 방식을 적용한다.
- 새 그림은 목적에 맞는 **실제 작은 해상도**를 정한다. 보통 24/32/48/64px에서 읽히는 형태를 먼저 만든다. 큰 자산 계약에서는 내부 구역을 나누어 찍는다. 작게 그려 확대했거나 팔레트를 줄였다는 이유만으로 완성이라고 판단하지 않는다.
- 원본 격자는 사람이 읽을 수 있는 행 문자열이다. 기존 전용 형식이 없으면 [픽셀 원본과 도구](references/pixel-source.md)의 JSON 형식을 사용한다.

## 픽셀을 찍는 순서

1. 그릴 물체의 실루엣, 광원, 재질을 짧게 정한다. 참고 그림이 있으면 실제 이미지를 보고 특징을 적는다. 기억이나 이름만으로 화풍을 단정하지 않는다.
2. **윤곽부터 행 문자열로 찍는다.** 머리·몸·손·무기, 불꽃의 갈래, 얼음 면처럼 중요한 형태의 경계 좌표를 직접 고른다. 한 색 실루엣을 원본 크기에서 열어 알아볼 수 있는지 확인한다.
3. 연결된 색 덩어리로 큰 명암 면을 찍는다. 기본색·그림자·빛을 물체의 부피에 맞춰 배치한다. 같은 재질의 명암과 광원을 유지한다. 무조건 같은 폭으로 윤곽 안쪽을 채우면 계단식 테두리만 남는다.
4. 픽셀 줄의 길이를 바꾸며 곡률과 모서리를 정리한다. 의도 없는 돌기, 평행한 가짜 외곽선, 띠처럼 반복되는 명암, 1px 잡티를 **위치를 지목해서** 고친다. 무작위 노이즈로 표면을 풍부하게 보이게 만들지 않는다.
5. 작은 눈·이빨·손·금속 반사처럼 실제로 읽히는 세부만 넣는다. 면마다 다른 재질을 만든다. 모든 면을 같은 반짝이와 점으로 덮지 않는다.
6. 원본 크기와 최근접 확대를 둘 다 연다. 어두운/밝은/체커 배경에서 윤곽과 투명을 본다. 고칠 곳을 `frame, x, y, pixels`로 기록하고 실제 격자를 수정한 뒤 다시 연다.

## 직접 저작의 경계

- **허용:** 내가 쓴 전체 행 문자열, 내가 고른 좌표의 단일 픽셀 또는 짧은 가로 색 문자열, 명시한 기존 글자열의 교체. 여러 픽셀을 한 번에 쓰는 것은 좋다. 한 픽셀마다 별도의 툴 호출을 할 필요는 없다.
- **보조 코드:** 파일 읽기·쓰기, 빈 캔버스 초기화, 색상표 출력, 좌표 패치, PNG/GIF 굽기, 확대 확인판, 차이/해시 계산.
- 직접 저작 작업에서는 이미지 생성 API나 자동 이미지 트레이싱으로 격자를 만들지 않는다. 참고 이미지는 관찰하고, 최종 픽셀은 내가 고른다.
- **직접 저작을 대체하지 않는 것:** 원/다각형/선 마스크로 본체를 생성하는 코드, 수식으로 실루엣·명암·불꽃을 합성하는 코드, 반복 프레임의 자동 변형, 자동 구멍 채우기·윤곽 정리·색 양자화, 생성 이미지를 축소해 도트라고 부르기. 직접 픽셀을 요청한 작업에는 이런 지름길을 사용하지 않는다.
- 렌더러나 저작 기록은 예술적 품질이나 사람이 직접 고른 사실을 증명하지 않는다. 격자도 모델이 수식으로 만들어 놓으면 같은 문제가 생긴다. **내가 읽고 고른 픽셀 배열**을 원본으로 남긴다.
- 사용자가 특정 변환이나 다른 저작 방식을 명시하면 그 요청을 따른다. 이 스킬로 허용 범위를 임의로 넓히거나 좁히지 않는다.

## 검토와 납품

팔레트/알파/크기 검사는 파일 계약 확인이다. 그림 검토에서는 알아볼 수 있는 윤곽, 설명과 같은 외형,
명암의 부피, 가장자리와 작은 요소의 가독성을 따로 본다. 흩어진 빛 입자가 의도일 수 있으므로 연결 요소 검사를 미감 점수로 쓰지 않는다.

새 스타일의 대량 저작은 대표 하나를 먼저 제대로 마무리해서 실제로 보고 기준으로 삼는다.
사용자 검토가 요청되거나 하네스가 요구하면 그 판단을 보존한다. 반려된 그림은 반려로 표시하고 기준작/승인작으로 재사용하지 않는다.

원본 격자, 1배 PNG, 확대 확인판과 남은 표현 한계를 함께 남긴다. 애니메이션은 `pixel-fx-animation`도 읽는다.
자산 등록·프로젝트 저장·라이선스는 해당 프로젝트의 절차를 따르고, 파일 형식 통과를 완료나 그림 승인으로 보고하지 않는다.

# FF6 SNES 연출을 참고할 때

2026-10-05 직접 조사. 명칭/순서만 외워서 FF6풍이라고 단정하지 않는다.

- [원본 전투 시연](https://www.youtube.com/watch?v=XSoHSGRyNPo): 공격 마법 2:29, 보조 4:57,
  환수 7:01, 필살검 10:54, 기계 12:11, 필살기 12:49, 청마법 13:41.
- [홀리 3:39](https://www.youtube.com/watch?v=XSoHSGRyNPo&t=219s): 푸른 전장 물결 →
  세 구슬의 나선 하강 → 큰 흰 착탄 → 흰 전장 → 복귀. 작은 금색 창과 다른 연출이다.
- [바하무트 5:43](https://www.youtube.com/watch?v=Shu1GcI9FIw&t=343s): 몸 구조가 읽히는 큰 원화 →
  푸른 파동 → 적진 연속 착탄 → 소환체 소멸. 원화가 여러 박자 동안 유지된다.
- [전투 스크립트 역분석](https://github.com/everything8215/ff6/blob/main/src/btlgfx/attack_anim_script.asm):
  `HOLY_SPRITE/BG1/BG3`, `BAHAMUT_SPRITE/BG1/BG3`, `FIRA_SPRITE`, `BLIZZARA_SPRITE`를 찾는다.
  공격 효과의 그림, 대상 색, 화면 층, 소리/대기를 함께 제어한다. 공식 소스라는 뜻은 아니다.

이 조사에서 얻은 저작 기준:

- 캐릭터/적이 있는 실제 전투 크기에서 최고점을 먼저 본다. 투명 배경의 독립 아이콘만으로 판단하지 않는다.
- 핵심 실루엣이 읽히는 범위로 화면을 쓴다. 큰 빈 칸 속 10px 기호를 프레임 수로 보완하지 않는다.
- 소환은 얼굴/턱/목/가슴/관절/발/날개 막의 연결과 재질을 원화에서 확인한다. 부위가 뜨거나 형태가 읽히지 않으면 모션 제작에 앞서 다시 찍는다.
- 직접 쓴 효과 셀과 런타임 층의 배치/노출/대상 색/소리 제어를 각각 저작한다. 런타임 연출을 사용했다고 중간 그림을 직접 찍었다고 보고하지 않는다.
- 모든 기술을 동일한 8칸/60ms/별 입자 마무리로 채우지 않는다. 원본 장면과 해당 엔진의 계약을 보고 필요한 셀과 시간을 고른다.

영상 표본의 시각은 녹화의 시간이며 엔진의 정확한 프레임/밀리초 규격이 아니다.
픽셀 리마스터/모바일/GBA 자료를 섞으면 어떤 판을 참고했는지 따로 적는다.

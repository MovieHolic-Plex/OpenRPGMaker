## Native media flags and picture completion (2026-09-06; U04)

- **Show Picture (`showPicture`, G3-F10):** the native form exposes `waitForPicture` through its completion-wait toggle. Coordinate edits retain authored true or false, including at `durationMs: 0`; omission remains omission unless the toggle changes. Editing X retains picture ID, resource ID, Y, scale, raw opacity, rotation and duration.
- **Actual completion, not a duration timer:** an uncancelled picture wait now resumes only after `RuntimeDomOverlay` writes the final transform, including the final transform of a same-generation retarget. The additional renderer/interpreter race found during G3-F10 verification is fixed under the same finding: elapsed duration alone must not release a command while its final frame is still pending. No timer padding or opacity tolerance was added, and the existing interpolation/opacity math is unchanged.
- `RuntimeDomOverlay.waitForPicture(pictureId)` observes the current generation after `syncPictureLayer` and resolves `completed` or `cancelled`. Authored object/resource replacement or erase cancels prior observers; a same-object/resource target change keeps them through the retargeted final update. Missing pictures cancel; settled/zero-duration pictures complete immediately. `clearPictures()` cancels the picture rAF and observers and removes picture slots without clearing unrelated HUD/effects. Restored state without transition intent renders its saved target immediately.
- The interpreter owns scene shutdown/destroy bindings for consumed picture steps, including still-animating non-waiting steps. It checks the captured session and scene lifetime before continuing. Picture-operation cancellation releases the wait but preserves following commands in the same live event. It is distinct from event-lifetime cancellation: shutdown/session replacement still cannot execute a stale following command. Cutscene skip keeps its existing end-label behavior and does not allocate a picture timer.
- **Play Movie (`playMovie`, G5-F2):** omitted `wait` and `skippable` mean true. The form displays those defaults as enabled, and explicitly selecting off serializes `false`, not omission. All four combinations survive Confirm and project serialization/deserialization. Native movie skipping uses confirm keys such as Z; Escape may open the general menu but does not skip the movie.
- Map command Confirm updates the draft; Apply saves it. Space reopens the selected command; Cancel discards a subsequent edit. U04 covers real file import, a second unchanged event as a wrong-target guard, native media decoding and dedicated `player.html` playback.
- Coverage: `test/eventCommandRemediation/U04.test.ts`, `test/pictureWeatherDom.test.ts`, the adjacent picture/movie tests, `test/e2e/event-command-remediation-U04.spec.ts`, and `scripts/qa/runtime/event-command-remediation-u04.scenario.mjs`. Deterministic renderer tests advance timer time without delivering the final rAF, then verify release only after the final DOM update. Async fake-DOM generation tests mount the live form and subscribe before triggering generation; detached forms still unsubscribe.

## Ownership note for later units

The exact API/lifecycle contract is recorded in `.omo/evidence/event-command-remediation/U04/api-ownership.md`. Completion bookkeeping is runtime-only; project/save schema and `pictures/pictureTween.ts` are unchanged. Independent renderer consumers must wire `clearPictures()` to their own teardown. U04 did not add a generic scheduler or edit `playSceneSchedulers.ts`.

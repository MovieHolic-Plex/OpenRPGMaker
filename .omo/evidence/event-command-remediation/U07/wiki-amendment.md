## Stable M2 selections and field labels (U07)

The same-kind command dialog deliberately retains its form. Generic resource/record controls
must refresh local names/previews when staging a new value rather than relying on a form remount.
Switch/variable names resolve from actual records on first render. Missing IDs remain explicit.
`recordPicker.setResourcePickerValue` inserts late picker/AI callback IDs before assigning native
select.value; actor/parallax previews read the current store. This does not change media filters.
`dom.field` associates its label with the actual input/select/modal trigger using a unique ID,
including wrapped numeric and switch/variable controls. Existing custom-select focus forwarding
and U05 actor validity guards remain authoritative.

The explicitly authorized player extension resolves genuine uploaded `charset` IDs using their
asset-id texture key. `bundled.ts` queues referenced uploaded charsets through the canonical URL
resolver, preserves upload alpha (no bundled color-key pass), and registers the existing canonical
24x32 charset frame geometry. Bundled aliases, wrong-kind/missing fallbacks and existing texture
ownership remain intact; repeat registration retains texture/frame identity.

Evidence: original22 RED17/control5 -> GREEN22; final focused/adjacent GREEN130; 17 real editor
Confirm/Apply/reopen/Cancel/export/import flows; three player scenarios/11 beats. Real ArrowRight
uses the loaded uploaded texture's walk frame12 and returns to idle13; the untargeted party
actor retains state established through actual commands. Parallax, escape location, vehicle
graphic and checkpoint remain intentionally record-only; no new runtime consumers are claimed.

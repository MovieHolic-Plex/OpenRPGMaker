# AI tool reach vs. authored-data surfaces (2026-08-27)

Scope: every top-level `Project` field (`src/project/types/project.ts:383-419`), every collection in
`ProjectDatabaseRecords` (`src/project/types/database.ts:677-873`), and every `SystemRecords` field
(`src/project/types/database.ts:1026-1090`) checked against the live tool registry
(`src/editor/tools/toolRegistry.ts:5-56`, families exported through `src/editor/tools/index.ts`).

Method notes that matter for reading the table:
- `src/editor/tools/changeset.ts:86-101` merely *counts* diffs for the change summary; a name appearing
  there is not a write facade. Same for `src/editor/tools/emptyProject.ts` (blank-project seed).
- Tool names were enumerated with `rg -oN 'name: "([a-z0-9_]+)"' src/editor/tools/`; every "none" claim
  below was re-grepped field-by-field against `src/editor/tools/` after excluding those two files.

# Mixed spatial composition — 2026-09-13

Editor/engine change only. All fixtures are isolated test data; no live Supabase project was authored or overwritten.

## Behavior

Objects retain their own tileset browser and tile painter. Spaces accept tiles + objects; places accept tiles + objects + spaces; regions add places; worlds add regions. Direct components share a canvas with the original generated base. Click/drop placement, keyboard movement, deletion, tile painting/erasing/restoration, zoom/fit and draft preview/apply are supported.

One canvas currently uses one tileset and level zero. Incompatible atlas assets are disabled. Existing multilevel recipes and overview routes are explicitly rejected by the mixed compiler, rather than silently flattened. Legacy records without composition continue using their original compilers. No bulk migration is performed.

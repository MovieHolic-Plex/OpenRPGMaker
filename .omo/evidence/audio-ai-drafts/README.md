# Shared audio AI drafts

This change accounts for all 1,049 built-in audio IDs. It publishes 1,016 unverified AI drafts and retains original metadata for 33 entries: 30 MIDI files not rendered by the batch and three withheld vocal-claim BGM descriptions.

Most outputs were generated by gemini-3.8-flash-high, not Pro. Three failed-access effects were recovered with gemini-3.1-pro-high. Vanguard Signal uses the Pro draft with the user-confirmed false vocal claim removed. The first SE was restored verbatim from its successful session smoke transcript after the earlier temporary JSONL was deleted; two later Pro access failures are not successes. Model confidence, frequency and duration prose are not independently measured facts.

The editor labels these values AI 분석 초안. Project overrides, including an empty string, win over drafts. Reset restores the draft when present; otherwise the creative brief/derived metadata remains. Nothing is written to project defaults or LegacyDb. Runtime audio assets and generated catalogs are unchanged.

`provenance.json` records input hashes and inclusion/exclusion decisions; `coverage.json` is the lead ID/body audit against original manifests. Full local analysis and QA logs remain in `output/evidence/audio-ai-final/`. Final validation receipts are recorded in `verification.md`.

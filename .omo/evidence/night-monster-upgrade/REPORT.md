# 밤의 괴물 · 공용 공포 제작 기능 개정

정본: `rpg-zzu-night-monster-20260905`. 초기판의 불합격 판정은
`../night-monster-review/REPORT.md`에 보존한다. 실행 성공을 장르/미술 완성도 합격으로 바꾸지 않는다.

## 변경

- 에디터 이벤트 페이지: 연결 방 추격, 문 대기, 수색 시간, 수색 후 대기/진입점 복귀.
  밀 수 있는 가구와 방향 제한, 실제 은신처. 기존 초안·저장·편집 감사 경로 사용.
- 런타임: 같은 이벤트 ID의 문 이동 대기열, 시야 차단, 수색과 은신 목격 판정.
  가구 위치·추격·은신은 세이브에 보존한다. 기존 프로젝트의 선택하지 않은 기능은 켜지지 않는다.
- 저작 도구: AI가 같은 속성을 설정한다. 실내 평가가 구조/통행 검사임을 명시하고
  그림 반복·바닥 한가운데 출입구·정적 가구와 동작 충돌을 검증 패널에 경고한다.
- 게임: 방별 가구/조사물 재배치, 벽의 문, 순환 복도, 의자 3개와 은신처 2개,
  안전지대/즉사 발판 제거. 지하실 상자 뒤 시야 차단 동선.

## 시각 검토

PNG는 전용 `player.html`의 게임 화면과 실제 에디터 모달로 각각 캡처했다.
현관의 식탁 반복, 서재/지하실의 책장 반복, 동일 조사 그래픽으로 다른 물건을 표현하던
문제는 개선했다. 침실은 작아졌고 침대·보관함·옷장을 구별할 수 있다.
복도 중앙 벽은 순환 동선을 만든다. 여전히 방은 단순하고 빈 바닥이 넓으며,
옷장은 제공 charset의 문 형태를 사용한다. 아트 완성도나 공포감 전체가 검증됐다고 주장하지 않는다.

에디터 1440×900 및 1024×768에서 설정·저장 버튼이 보인다. 좁은 레일에서 잘리던
옵션은 세로 배치로 수정했다. 복귀 옵션의 긴 문구는 네이티브 select에서 끝이 생략될 수 있다.

## 검증 근거와 범위

- `runtime/review.json`: 복도 달리기의 실제 방향 입력, 의자 이동, 숨은 플레이어 스프라이트,
  실제 문 통과 후 같은 괴물 진입과 수색. 중간 셋업만 QA teleport이며,
  한 칸 왕복 이동으로 논리 좌표와 스프라이트 발 위치를 맞춘다.
  셋업 왕복과 지하실 은신 접근은 기존 `playerRoute`로 걷는다. 충돌·추격은 그대로 진행하며
  대시보다 느린 일반 보행이다. 키보드 반응성 전체를 이 증거로 보증하지 않는다.
- `editor/`: 실제 모달에서 추격 범위 변경→저장→재열기 값 유지와 방향 제한 설정.
  UI 검증은 원격 저장을 끈 격리 세션이다. 게임 원격 저장과 혼동하지 않는다.
- `progression.json`: 실제 통행/이벤트 분기로 구출과 단독 탈출 결말을 확인한다.
  이 시뮬레이터는 실시간 추격 생존을 증명하지 않는다.
- `persistence.json`: 저장 후 Supabase 재로드 맵의 정렬 SHA-256 비교.
- 관련 계약 테스트: 구버전 JSON, 새 속성 왕복, 실제 세이브 저장/읽기,
  밀기 충돌/제한, 미목격/목격 은신, 수색/복귀, 문 대기/연속 전이/소거.

자동 캡처 시행 중 호스트 네트워크 변경으로 Chromium 요청이 중단되었다.
최종 캡처는 소유 Vite 응답만 Node fetch로 전달한다. 엔진이나 이동 결과를 모킹하지 않는다.
부하가 큰 프레임에서 방향 키 해제 관측이 늦어 추가로 걷던 자동 입력도 보정했다.
`witnessed-hiding.json`/`witnessed-capture.png`는 이전 시행에서 숨는 모습을 본 괴물의
포획 증거다. 그 시행의 오류 문구 “without witnessing”는 잘못됐고 실제 `witnessedBy`가
비어 있지 않다. 최종 검사는 목격 여부를 명시적으로 확인한다.

## 최종 브라우저 결과

미목격 은신 `witnessedBy=[]`, 수색 종료 `active=false`를 확인했다.

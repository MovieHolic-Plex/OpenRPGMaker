Remaining GREEN "dead" 10, each triaged:
  window-fullscreen x3        environment: headless Chromium's Fullscreen API is a no-op. Works in a real browser.
  map-quick-add-child-*       harness: hover-only `+` on map tree rows; the audit clicks without hovering.
  tile-search-input x2        harness: <input>; clicking focuses it, typing is the real interaction.
  map-tree-filter x2          same.
  map-set-start x2            REAL -> fixed. setStartMap no-ops silently when the map is already the
                              start map, and the row context menu hides the item in that case, so only
                              the header button was inconsistent. Now toasts either way.
                              Failing-first proof: test/mapList.test.ts (RED: toast spy 0 calls).

Harness fidelity fixes made while triaging (each removed a class of false verdicts):
  - snapshot records which popup is OPEN -> a popup swap (parent menu -> submenu) no longer nets a
    zero delta. This is what made menu-project-samples read as dead.
  - `already-active` verdict: clicking the tool/layer/facet that is already selected is a no-op,
    not a dead control.
  - input focus counts as an observable effect.
  - CustomEvent detail.kind joins the fingerprint (plain test play vs random battle are different).
  - only an OPENING popup identifies an action; every menu item closes its own menu, and treating
    the close as identifying made all 11 panel-menu items one bogus duplicate group.
  - boot() waits for the left dock: one run enumerated ZERO leftSidebar controls because the
    sidebar mounts after the menubar. Added a coverage guard that throws in that case.

Bug I introduced and fixed before shipping: the samples submenu could not be dismissed with Escape.
The main menus rely on the trigger keeping focus, but opening a submenu removes the clicked item so
focus falls to body; the popup then sits over the left sidebar and swallows clicks. Fixed with a
document-level Escape handler (covers every popup, not just submenus). Test: "예제 하위 메뉴도
Escape 로 닫힌다" captured RED first.

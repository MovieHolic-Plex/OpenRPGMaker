# RM2003 Database UI Coverage Matrix

이 매트릭스는 RM2K3/RM2003 Database 매뉴얼의 각 페이지가 에디터 UI에서
어떤 탭/패널에 매핑되는지 추적한다. 증거 수집(capture-db-ui.mjs)은
각 행의 탭을 열어 스크린샷을 캡처한다.

| Database Settings | 시스템 탭 — 타이틀/메뉴/용어 기본값 |
| Actors | 액터 탭 — 파티 구성원, 파라미터 곡선, 초기 장비 |
| Classes | 직업 탭 — 스킬 학습, 전투 명령, 능력치 |
| Skills | 스킬 탭 — 효과/소모/명중/분산 |
| Items | 아이템 탭 — 가격/효과/사용처 |
| Enemy Battlers | 적 탭 — 적 능력치/보상/액션 패턴 |
| Enemy Troops | 적 그룹 탭 — troop 구성과 배틀 이벤트 |
| Elements | 속성 탭 — 속성 유효도 |
| States | 상태 탭 — 상태 효과/해제/회복 |
| Battle Animation | 배틀 애니메이션 탭 — 프레임/셀/타이밍 |
| Battle Animation 2 | 배틀러 애니메이션 탭 — 포즈 시트 |
| Battle Screen | 전투 화면 설정 탭 — 레이아웃/배경 |
| Terrain | 지형 탭 — 지형 태그/인카운터 |
| Tilesets | 타일셋 탭 — 패스/우선순위/지형 |
| Terms | 용어 탭 — UI 문자열 |
| System | 시스템 탭 — 타이틀/시스템 그래픽/초기 파티 |
| System 2 | 시스템 2 탭 — 배틀 레이아웃/테스트 |
| Common Events | 공용 이벤트 탭 — 자동/병렬 이벤트 |
| Supplementary Windows | 보조 창 탭 — 메뉴 하위 화면 |

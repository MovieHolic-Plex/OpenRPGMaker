# 소규모 마을 생활 공간

정본: LegacyDb `rpg-zzu-house-template-gallery` (호수 마을), 19개 맵.
마을: `spatial-geography:30:small-village:example:20260913`.
공간 갤러리: `map_village_decoration_catalog`.

## 결과

실외 오브젝트 16종, 생활 공간 20종을 등록했다. 기존 집 26채의 위치와 외형,
단층 23채 + 2층 이상 3채, 큰집 제한은 유지했다. 20종 모두 실제 마을에 사용됐고,
총 40곳(집 주변 21, 공용 공간 3, 장터 4, 호숫가 4, 길가 8)에 152칸을 추가했다.
공간이 부족한 다섯 집은 기존 마당 상태를 유지한다. 새 묶음 때문에 집이나 도로를 옮기지 않는다.

장식은 SpaceDesign의 고정 오브젝트 슬롯을 소비하는 공용 생성기 기능이다.
설계서의 구역·최대 반복 수를 읽고, 출입구·길·시장 중앙 통로·기존 통행 영역을 보호한다.
도구 `author_village`, 설계서 미리보기와 지역 재시공이 같은 로직을 사용한다.
LLM 제공자의 자연어 대화 세션을 실행했다는 뜻은 아니다.

`index.html`은 20종의 독립 확대 보기, `catalog.png`는 전체 카드 그림이다.
`render/index.html`은 마을 확대 보기, `render/detail-01.png`는 장터,
`detail-02.png`는 물가, `detail-03.png`는 주택 주변이다. 그림은 실제 에디터 타일 렌더러 결과다.

## 검증

- 최종 원격 CAS 저장 및 재로드, 독립 재조회: `legacy-db-proof.json`, `final-remote-check.json`.
  최종 서버 SHA: `5dc3f0706bbe05a878796084de162afba088c8bdd1560f052f78f80eb44b52ca`.
- 동결 공간 래스터 40곳/152칸 일치, 현관·가판·쉼터·새 공간 71곳 도달 가능.
- `focused-tests.json`: 13개 검사 통과. IO, 실패 원자성, 기존 통행 보존, 잔교 전체 도달,
  결정성, 카탈로그 재등록 안정성, 저장 공간 단독 시공, 실제 AI 마을 도구 경로 포함.
- `space-preview-proof.json`: 저장 공간 20종을 일반 `preview_spatial_build`로 컴파일, 원본 불변.
- `typecheck-proof.json`: 최종 앱 타입 검사 0 오류.
- 실제 원격 에디터: 19맵/30번호집/12소형집, 집 구성과 20개 장식 반복 한도 표시,
  실제 생성 미리보기 통과, 콘텐츠 쓰기 0. 해당 PNG와 editor proof 참조.
- 출하 `player.html`: 14/14 비트, 73걸음. 집/장터/호숫가/우물/천막/잔교 끝.
  SUMMARY부터 읽었으며 즉시 열람 지시 PNG 0개, 런타임 오류 0.
  시각 검토는 별도로 native 전체 맵, 장터·호숫가 상세와 공간 카드에서 수행했다.
- 첫 저장 후 실외 `wall` 값을 `none`으로 보완해 개별 공간 컴파일도 가능하게 했다.
  최종 저장·에디터·런타임 검증을 다시 수행했다. `metadata-polish-proof.json`은
  이 보완 전후 실제 래스터·이벤트·배치가 동일함을 증명한다.

전체 게이트 결과는 `gate-comparison.json`과 `gates-proof.json`에 별도로 기록한다.
기존 저장소의 빨간 기준선과 비교하며 전체 통과로 해석하지 않는다.

전체 `npm run gates -- --json`은 exit 1이다. 직전 실측 688 실패/22,962 통과에서
522 실패/23,131 통과로 바뀌었다. 새 실패는 `spatialCombinedAuthoring` 시간 초과
1건(18.65초)이며, 코드를 바꾸지 않은 단독 재검에서 파일 전체 3/3 통과했다.
이번 집·장식·설계서 관련 새 실패는 없으며, 앱 타입/CSS는 통과했다. 기존 surface
축과 테스트 실패가 남아 있어 전체 게이트 통과로 보고하지 않는다. 전체 게이트 실행 중
마지막 재사용 검증과 실외 메타데이터 보완이 있었으며, 최종 코드의 타입 검사·관련 검사와
최종 원격 프로젝트의 에디터·런타임 QA를 별도로 완료했다.

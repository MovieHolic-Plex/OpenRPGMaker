**OPRN Studio is a tile-based JRPG maker with an AI assistant built in.**
Draw maps, place events and test-play instantly — or tell the assistant
*"build a harbor village with a church and a tavern"* and watch it lay the tiles, doors and NPCs for you.
Maps are built from 16px pixel-art tiles, the editor speaks four languages, and the games you make are yours.

## What's new

Since the first public release in early October 2026:

- 🎮 **Play on phones and tablets.** Exported games have touch controls — an on-screen stick, tap-to-walk and tap-to-talk, touch-sized menus — and the layout fits portrait and landscape screens. Games on OPRN PLAY keep cloud saves.
- 🎵 **The assistant picks assets for you.** It searches the asset store by scene and feel, installs music and wires it into your maps. It can also read player reviews of your game, draft replies and write update news.
- 🏰 **Themed dungeons.** Forest, ice, swamp, pyramid, lava, mines, catacombs, wizard towers and more, with stairs, levers, gates and a boss room.
- 🧩 **Bigger jobs for the assistant.** Party splits with switch puzzles, stealth patrols, party bonds with campfire talks, snow and forest routes, and mid-battle guests.
- ⚔️ **Deeper battles.** Combo techs for up to four party members, interrupting enemy charge-ups, weaknesses you discover by hitting them, physical and magic damage rates, and a staging editor for cut-ins.
- 🛠️ **Workshop.** Make a map object, a walking character or a terrain from one line of text — or from a photo — and pick the version you like.
- 🛒 **A growing asset store.** 40 free assets today, including 18 music packs, five tilesets and 15 face and portrait packs.

## Download

Desktop builds for Windows and Linux are attached to each [release](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases). The buttons at the top download the newest one.

- **Windows** — run the EXE, or unzip the ZIP and run `OPRN Studio.exe`.
- **Linux** — `chmod +x` the AppImage, then run it.
- **macOS** — no packaged build yet. Use the source command below.

If a button shows "Not Found", a new release is still uploading. Pick the previous one from the [release list](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases).

## Quick start

For macOS, or to run from source. You need [Node.js 24 LTS](https://nodejs.org/).

```bash
npm ci
npm run mac:launch   # macOS / Linux — asks for a project folder, then opens http://127.0.0.1:9999
```

On first launch, enter the full path of a **new** folder; your project is saved there as SQLite plus asset files.
Click the AI chip at the top right to sign in.

The full 281-track music pack is the public [bgm-v1 release](https://github.com/MovieHolic-Plex/OpenRPGMaker/releases/tag/bgm-v1) (`rpg-zzu-bgm-v1.tar`), separate from the desktop downloads above. From a source checkout, `npm run bgm:install` downloads that asset over HTTPS and checks the committed SHA-256. The GitHub CLI is only a fallback.

## For developers

```bash
npm ci
npm run dev              # dev server (http://localhost:9999)
npm run build:packaged   # hosted / desktop renderer build
npm run build:player     # standalone web-game player
npm start -- --project-dir /path/to/project   # serve an existing SQLite project
npm test                 # unit tests (GitHub CI; locally exits unless OPRN_LOCAL_TESTS=1)
```

- Architecture, data and editor guides live in [`openwiki/`](openwiki/) — start with [`openwiki/quickstart.md`](openwiki/quickstart.md) and [`openwiki/PROJECT_WIKI.md`](openwiki/PROJECT_WIKI.md).
- Coding agents: read [`AGENTS.md`](AGENTS.md) first.
- Stack: Phaser + vanilla TypeScript DOM, SQLite project folders, Electron desktop shell.
- World map place icons live in their own public repo: [oprn-worldmap-kit](https://github.com/MovieHolic-Plex/oprn-worldmap-kit).

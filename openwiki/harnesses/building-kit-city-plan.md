## 0. 전제 (이미 정한 것)

- 시점: 박공 정면·용마루가 뒤로 물러나는 높은 3/4(사용자 기준 그림), 빛 왼쪽 위. 날개는 본채 지붕에 골로 이어진다(A16).
- 화소: 테마 잠금 팔레트 + 행 문자열 손 도트. 그리기·배치·마감은 Opus 5.5 high(사용자 규칙).
- 걸러 내기: 기계 관문 → 조립 관문 → 독립 검수(숨은 함정, 무효 회차 버림, 유효 3회 다수결) → 사람 pick. 기준 완화 금지.
- 품질: 조립 뒤 「마감 손질」(Opus 5.5 high, 질감·꽃상자·간판·풍화, 실루엣 고정) — 버들항급 질감은 여기서 낸다.

## 1. 건물 100종 → 부품 문법으로 옮기기

100종은 모두 아래 **덩어리 원소 9개**의 조합이다. 레시피는 원소를 고르고 크기·깊이·재질만 정한다.

| 원소 | 부품(테마마다 손 도트) | 쓰는 건물 예 |
|---|---|---|
| 상자 몸통(층 = 2칸) | 벽 끝·반복·창·문·층 띠·기단(선택) | 거의 전부 |
| 박공 정면 덩어리 | 정면 박공·사면 띠·뒤 끝·골(v4~v6)·계단/종 박공 | 박공 오두막, 운하 주택, 길드 회관 |
| 용마루 옆 덩어리 | 모임/박공 지붕 끝 2칸·가운데 반복 | 롱하우스, 여관 본채 |
| 외쪽 지붕 | 외쪽 지붕 좌/우/앞 | 마구간, 헛간, 대장간 작업장 |
| 원통·원뿔 | 원통 몸통 3폭, 원뿔·돔·첨탑 | 망루, 비둘기탑, 풍차, 마법탑 |
| 총안·성벽 | 성벽 끝·반복·총안·회랑 덧대기·문루 | 성벽, 바비컨, 성탑 |
| 아케이드·기둥 열 | 기둥·아치 반복 | 시장홀, 시청, 신전, 바스티드 |
| 덧붙이 | 굴뚝·지붕창·간판 걸이·발코니·들보·바퀴 | 장식·용도 표시 |
| 바닥 도형 | 마당·광장·물길·해자·계단 | 안마당, 분수, 해자 |

순서(테마마다 같은 판 흐름 r8~):
1. **r8 원소 판** — 위 9원소의 부품을 줄 A·B·C로 그린다(이미 있는 r5~r7 부품은 reuseParts). 검수는 원소를 쓴 대표 건물 6채.
2. **r9 민가·상가 판(약 30종)** — 1부 20종 중 민가 + 2부 A·B 그룹.
3. **r10 용도 판(약 30종)** — 대장간·여관·방앗간·양조장·시장홀·시청·교회 등 2부 D·E + 3부 일부.
4. **r11 성채 판(약 25종)** — 성벽 키트·문루·바비컨·탑·아성·대회당·병영·무기고·예배당(3부 C01~C13) + 2부 F.
5. **r12 랜드마크 판(약 15종)** — 대성당·종탑·궁전·마법탑·천문대·투기장·수도교·집이 선 다리.
각 판: 그리기 → 관문 → 조립 → 독립 검수 → 마감 손질 → 사람 pick. 100종 × 3줄 = 최대 300채이므로 **줄은 테마마다 사람이 고른 1~2줄만** 끝까지 간다(화풍 판에서 고른 줄).

## 2. 성 — 내부가 복잡한 성을 만드는 규칙 (조사 종합)

1. **단(tier) 3~7개, 기본 3.** 플레이어가 구분하는 높이는 3개(레벨 디자인 북). 미나스 티리스식 7단은 랜드마크 도시 하나에만.
2. **문은 서로 마주보지 않는다.** 단마다 문을 좌/우 번갈아(미나스 티리스), 정문 + 숨은 옆문(스톰베일·하이랄 성).
3. **주로는 꺾인다.** 문을 지날 때마다 방향이 바뀌는 지그재그·나선 외곽로.
4. **성벽은 길이다.** `wall_top_walk`(걸음) 칸과 `wall`(막힘) 칸을 따로 둔다. 성벽 산책로가 지상 길과 나란한 두 번째 동선.
5. **초크 3중.** 외곽 토루/해자 → 바비컨·문루 → 안쪽 계단·다리(헬름 협곡). 배수구·옆문 같은 약점 1칸을 일부러 둔다.
6. **같은 자리 세 층.** 지상 대로 / 지붕·성벽 / 지하 수로·감옥(레인델·야남). 맵은 층마다 따로 깔고 사다리·리프트·구멍 칸으로만 잇는다.
7. **랜드마크 하나.** 백탑·아성 탑 하나가 도시 어디서나 보이게 가장 높다. 나머지는 1~2칸 낮게.
8. **모듈 9~12개로 닫는다**(캐슬바니아 방 목록): 입구·외벽·대계단·안마당·예배당·대회당·왕좌실·탑·부엌·감옥·수로·도서관.

성 레시피(새 문법 `castle`):
`{tiers:[{ring: arc|rect|poly, wall:'curtain', gates:[{side, offset}], houses:density}], keep:{...}, sidepath:{from, via:[lift|stairs|wallwalk]}, layers:['ground','wall','under'], chokes:[...]}`
조립기가 단마다 성벽 키트를 둘레에 깔고, 문 위치 규칙(엇갈림·최소 거리)을 지키는지 관문으로 본다.
관문 추가: 문↔랜드마크 도보 경로 존재(BFS), 단마다 문 정확히 1개 이상, 문끼리 같은 축에 정렬 금지, 성벽 산책로가 끊기지 않음, 층 연결 칸 ≥1.

## 3. 도시 — 생성 순서 (Watabou 소스 + 레벨 디자인 북)

```
1 지형    물·절벽·언덕 먼저(언덕 = 성 자리, 강 = 다리·항구)
2 성벽    도시 외곽선 → 문 후보 = 구역 두 개 이상이 만나는 꼭짓점 → 문끼리 최소 거리 → 나머지 꼭짓점에 탑
3 대로    문마다 광장/성까지 최단 경로(폭 2), 성 밖으로도 한 줄
4 구역    가중치로 배정 — 성채(가장 높은 곳), 성전(광장과 축), 시장(문에서 가까운 광장, 다른 시장과 인접 금지),
          장인(시장 옆·물가), 빈민(중심에서 가장 먼 곳, 성벽 밖으로도), 항구(물가·가장 낮은 곳), 군사(문 안쪽)
5 골목    블록 재귀 이등분, 폭 3단(대로 2 · 길 1 · 샛길 0.6→1칸)
6 필지    정면 폭 2·3·4칸 번갈아, 깊이 6~12칸, 용마루 방향 2:1로 섞기, 4~6채마다 교차 박공·탑
7 건물    구역별 목록에서 고르고, 높이 1-2-3-2-1(광장 쪽 높고 바깥 낮게), 모퉁이는 모퉁이 전용
8 밀도    중심·대로에서 멀수록 확률 제거, 성벽 밖 30~50%
9 랜드마크 가장 높은 것 1~2개만, 대로 끝이 항상 랜드마크
10 검증   모든 문→광장→랜드마크 경로, 모든 구역 대로 접속, 고립 블록 0, 문 앞 칸 전부 걸음
```

배치는 **Opus 5.5 high 에이전트가 이 순서를 코드로 짜고 그림을 보며 다듬는다**(사용자 규칙). 절차 코드는 뼈대·검증만, 결과는 사람이 본다.
마을 크기 단계: 마을(집 10~20, 성벽 없음) → 성곽 소도시(문 2·광장 1) → 도시(문 3~4·구역 5~7) → 수도(성 3단 이상·강·항구).

## 4. 편집기로 가는 길

1. 사람이 pick 한 건물만 3/4 관문(`object-gate`, kind `structure`) 영수증을 받는다.
2. 테마별 공용 번들 시트로 굽는다(`src/assets/bundled.ts`, `defaultAssets.ts` `ensureBundledTilesets`) — 키트 = 건물, 칸 통행은 kit `walkGrid`.
3. 참고문서(용도: 건물 목록·배치 규칙·도시 생성 순서)를 번들에 넣어 조수가 읽게 한다.
4. 편집기 도구 `author_city`(가칭): 위 3절 순서로 맵을 짓고 SQLite 정본 저장·재로드까지(AGENTS.md 정본 저장 규칙).

## 5. 비용·순서 판단

- 그리기 1회(줄 하나, 판 하나) ≈ Opus 5.5 high 30~120분, 검수 1회 ≈ 10~40분. 테마당 판 5개 × 줄 1~2 → 테마당 대략 하루.
- 먼저 **판타지 1테마로 r8~r12 + 도시 1장**을 끝까지 보낸 뒤, 같은 문법을 북방·사막·귀족에 복사한다.
- 성은 미나스 티리스식 1채를 랜드마크로, 스톰베일식·헬름 협곡식은 던전 입구 맵으로 쓴다.

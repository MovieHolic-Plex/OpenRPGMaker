# 직접 픽셀 저작 스킬 — 2026-10-05

FF6 전투 그래픽을 참고한4종 합성 시안은 사용자에게 반려됐다. 팔레트/알파 규격은 통과했지만
도형과 수식으로 만든 본체·명암이 조악했다. `docs/experiments/ff6-battle-fx-20261005/`는 반려 기록이며 기준작이 아니다.
사용자는 조수가 픽셀을 하나하나 결정해 찍는 스킬들을 요청했다.

## 스킬 원본과 설치

- `assistant-skills/pixel-dot-authoring/SKILL.md`: 실루엣·색 덩어리·명암을 직접 쓴 행 문자열과 좌표 패치로 저작한다.
- `assistant-skills/pixel-fx-animation/SKILL.md`: 마법·타격·소환의 핵심/중간 프레임을 각각 찍고 실제 속도/접촉 앵커를 검토한다.
- `assistant-skills/pixel-dot-authoring/scripts/pixelgrid.py`: 빈 격자 초기화·읽기·좌표 패치·PNG/GIF 출력. 본체나 동작을 생성하지 않는다.
- `assistant-skills/pixel-dot-authoring/references/pixel-source.md`: 전용 하네스가 없는 경우의 JSON 원본과 출력 형식.

두 폴더를 Codex 개인 스킬 폴더(`~/.codex/skills/`, 또는 설정된 `CODEX_HOME/skills/`)에도 복사해 설치했다.
`$pixel-dot-authoring`, `$pixel-fx-animation`으로 호출한다. 설치 파일은 개인 설정이며 커밋하지 않는다.
저장소의 위 경로가 스킬 원본이다. **편집기 조수에 스킬을 배포/배선한 작업은 아니다.**

## 핵심 계약

색은 원본 팔레트, 투명은`.` 하나, 프레임은 생략 없는 문자 행 배열이다. 가로 색 문자열로 여러 픽셀을 한 번에
찍을 수 있다. 모든 툴 호출을1px씩 쪼갤 필요는 없다. 원·다각형·선 마스크/자동 변형/보간/노이즈로 본체나
중간 프레임을 만들어 직접 저작이라고 보고하지 않는다. 확대·격자선은 검토판에만 붙인다.

형식 검증과 그림 검토를 구분한다. 원본 크기의 가독성, 연결된 명암 면, 가장자리, 프레임별 몸 구조,
실제 재생에서의 형태 변화와 접촉 위치를 보고 좌표를 고친다. 픽셀 변경 수와 색 수는 품질 점수가 아니다.

캐릭터/타일 등 별도 하네스가 필수인 자산은 그 하네스와 원본 형식을 우선한다. 스킬을 만들었다는 이유로
사람의 선택, 공용 게시, 실제 프로젝트 저장, 런타임 QA 계약을 우회하지 않는다.

## FF6 조사 후 재저작 · 직전 반려 판의 기록

`scripts/asset-gen/pixel-fx/snes_study_redraw.py`의 직접 쓴 행/좌표가 최신 원본이다.
`--install`로 10개 층 시트와 완전한 `*.study.px.json`을 만든다.
화염/빙결/번개는 서로 다른 재질 변화 프레임, 홀리는 앞뒤 구슬과 별도 착탄, 용권은
머리/목/가슴/발/날개막이 연결된 한 원화를 유지하는 구성이다.
배경의 32px 직접 도트 타일을 128px 셀로 반복 조립하는 것은 프레임 직접 저작과 구분한다.
형태를 수식/도형으로 생성하거나 몸을 보간하지 않는다. 장면의 이동/합성은 재생기 책임이다.

공용 프리셋 5개를 수정했고 반려된 24종은 재등록하지 않았다. 기본 `anim_px_*` 17종은 별도다.
기존 개별 생성기 5개가 새 원본을 읽고, 중앙 패킹의 바이트 재현과 개별 출력의 RGBA 일치를 확인했다.
당시 사용자 검토 대기였으며 후속 평가로 반려됐다. 원화가 보인다는 사실을 FF6급 완성으로 보고하지 않는다.
실제 플레이어/자료집/대화 검토판 근거는 `verify-shots/snes-study-redraw-20261005/SUMMARY.md`.

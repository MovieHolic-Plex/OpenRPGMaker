# 공용 아이템 효과·경제 기준 (2026-10-02)

대상은 **새 프로젝트 기본 데이터**의 아이템 1,000종이다. 기존 프로젝트를 불러올 때 저자가 정한 효과·가격을 바꾸지 않는다. 장비 레코드 86종은 별도이며 이 경제 정책의 대상은 아이템 컬렉션이다.

## 소유 경로

- `scripts/content/prepare-shared-item-catalog.mjs`: 772종의 ID·이름·그림 요청을 만들고 `scripts/content/lib/shared-item-effects.mjs`로 최종 역할을 저작한다. 이어 `scripts/content/prepare-shared-item-prices.mts`가 공용 가격 권위자를 사용해 JSON 가격을 갱신한다. 저장소의 `node_modules`가 필요하다.
- `src/project/defaults/defaultItemBalance.ts`: 기존 228종을 포함한 1,000종의 새 프로젝트 가격을 산출한다. `defaultItemRecords`에서만 적용하고 정규화·로드 수렴에서는 호출하지 않는다.
- `src/project/defaults/defaultSharedItemSkills.ts`: 투척물 전용 스킬 48종. `defaultSkillRecords`에 포함한다. 기존 직업·몬스터 기술의 위력·MP 비용은 바꾸지 않는다.
- 예제는 `npm run fixture:sync`로 동기화한다. 빈 프로젝트와 예제의 아이템 배열이 완전히 같아야 한다.

## 효과 역할

| 계열 | 구분한 선택지 |
|---|---|
| HP 약초 | 고정 회복, 비율 회복, 전투 공격 강화, 해독, 전체 회복, 각성, HP·MP 복합, 시야 치료 |
| MP 약 | 고정량, 비율, 침묵 치료, 전체 회복, 전투 마법 방어막, 필드 전용 고효율 |
| 영약 | 단일 복합 회복, 전체 복합 회복, 전투 재생, 비율 복합 회복 |
| 치료제·강장제 | 단일/전체, 회복 추가, 관련 약화 해제, 물리·마법 방어막, 반격·감싸기·회피 |
| 투척물 | 원소 6종 × 경량·약화·집중·확산·복합·관통·연발 확산·비전 복합 역할 8종 |
| 씨앗 | 단일 능력치 또는 공격+방어 / 정신+민첩의 영구 성장 |
| 비전서 | 실제 기술 48종, 원래 직업 한정 사용 |
| 몬스터 돌봄 | 친밀도 중심과 EXP 중심 사료, 친밀도만 주는 장난감 |
| 음식·수확물 | 필드 회복, 일부 파티 식사·상태 치료. 수확물은 먹거나 판매할 수 있다 |

투척물 아이템의 `scope: none`은 연결 스킬의 `enemy/allEnemies` 범위를 따른다. 전체 공격을 아이템의 `enemy`로 덮어쓰면 한 명만 맞으므로 이 계약을 유지한다. 포획구는 RM 호환 배율과 Gen1 포획구 등급을 함께 설명한다. 새 포획구에는 확정 포획을 넣지 않는다. 돌봄 아이템에는 적용되지 않는 일일 한도를 설명에 쓰지 않는다.

열쇠·제작 재료·미끼의 이벤트는 제작자가 연결한다. 농사 도구의 재질별 성능 차이는 엔진 계약에 없으므로 동일 작업의 도구는 가격도 같다. 그림·이름 차이를 성능 상승으로 주장하지 않는다.

## 가격 기준

실제 기본 배우 성장: HP 514→5,140, MP 43→430. HP 고정 회복 등급은 100/180/280/420/650/950/1,400/2,100을 기준으로 역할별 배분한다. 비율 회복은 8/12/16/20/25/32/40/50%다.

가격은 HP 5,200·MP 450을 후반 기준으로 삼는다. HP 회복 1당 0.9G, MP 회복 1당 4G에 치료·강화·소생·대상 범위의 가치를 더한다. 필드 전용은 0.65배, 파티 약은 3.5배, HP+MP 동시 회복은 1.12배다. 재생은 지연되는 최대 HP 8% 회복 3회의 예산을 적용한다. 소생은 별도 비용을 더한다.

영구 성장은 능력치 합계의 1.2승 × 900G를 적용해 대량 구매로 초반 성장을 우회하기 어렵게 한다. 유한 충전품은 사용 횟수만큼 비용을 지불하고 6%만 묶음 할인한다. 기본 약·충전품·옛 엘릭서도 같은 계산을 사용한다. 완전 회복 엘릭서 600G가 고급 고정 회복약을 모두 이기던 가격 문제를 제거했다. 최종 엘릭서는 7,275G다.

이 기준은 출하 기본 성장·골드 보상에 맞춘 공용 시드다. 제작자가 다른 성장 곡선·전투 길이·상점 재고를 저작하면 그 게임의 경제도 함께 조정한다. 1,000종을 시작 상점에 자동 진열하지 않는다.

## 확인 근거

`assets/item-catalog/balance-report.json`에 소스 SHA와 수치를 보관한다.

- 효과 설정 조합 404→627, 메뉴·전투·농사 사용이 가능한 레코드 660→708.
- 전체 약 4→50, 비율 약 21→45, 상태 효과를 갖는 약 84→156.
- 투척물 전용 효과 48종: 단일 피해 30, 전체 피해 12, 약화 전용 6. 기술서 직업 제한 48종.

## 현재 적용한 변경과 범위

사용자 방향: 시장을 자동으로 만들지 않고, 새 마을의 기본형은 가운데를 흐르는 강과 주변의 집으로 잡는다.

**암묵적 시장 기본값 제거**와 **강변형 1차 구현**을 적용했다.

## 장기 설계 방향: 강을 따라 자란 마을

새 빈 지도에서 별도 배치 요청이 없으면 강변형을 선택한다. 기존 지도와 선택 영역에서는
기존 강·건물·사용자 범위를 먼저 존중한다. 산골·항구·농촌 등 명시한 유형은 기본형보다 우선한다.

1. **강과 강변 예약.** 화면 중앙 부근을 지나는 연속 수로와 여유 공간을 계획한다.
   강의 굽이와 폭을 변화시키되 정확한 중앙선이나 좌우 동일 면적을 강제하지 않는다.
   현재 타일 맵에 실제 고도·홍수 모형은 없으므로 강변 이격은 저작 규칙으로 표현하며 물리 시뮬레이션으로 주장하지 않는다.
2. **건널목과 큰길.** 강폭·장애물·이동 거리를 보고 건널목 후보를 선택하고 마을 진입부와 연결한다.
   다리는 실제 통과 가능한 연결이어야 한다. 다리 수를 장식 숫자로 고정하지 않는다.
3. **생활권과 필지.** 길에 접근할 수 있는 땅에 집 무리를 단계적으로 만든다.
   양안에 똑같은 줄을 복사하지 않는다. 현관은 실제 연결 가능한 골목을 향하게 하고,
   지원 칩셋의 문 방향 제약도 함께 고려한다.
4. **작은 공용 공간과 생업.** 길이 만나는 곳에 쉼터·우물 같은 공동 공간 후보를 두고,
   집 마당·텃밭·숲 경계를 연결한다. 시장은 명시한 요청·프리셋에 있을 때 넣는다.
5. **완성 검사.** 물길, 건널목, 집 입구, 주민 동선이 함께 작동하는지 검사한다.

위 단계는 **계획 의존 순서**다. 실제 타일 시공은 기존 정본인
**집 → 길 → 나무 → 물·마당·꾸미기**를 유지한다. 먼저 예약한 수역에 집·나무가 들어가지 않게 한다.
주택 보호 계약과 선택 영역의 경계도 그대로 적용한다.

## 구현 경로와 소유권

| 함수 | 책임 |
|---|---|
| `withVillageMorphologyDefault` | 명시적 스타일·프리셋·기존 콘텐츠를 존중하고 빈 전체 맵에만 기본형 부여 |
| `resolveVillageContract` | 선언한 형태·테마와 기본형을 실행 계약으로 고정 |
| `planVillageRiver` | DB 강 폭으로 연결 수역, 양쪽 강변길, 2칸 폭 건널목 계획 |
| `planVillageMorphology` → `planRiverVillage` | 강 점유를 먼저 예약한 뒤 양안 필지와 옆길을 계획 |
| `buildMorphologyVillage` | 강변형은 집 → 길 → 나무/필지 순서로 시공. 강 칸에는 길도 미리 칠하지 않음 |
| `finishWater` → `paintOrganicVillageLake` | 동일한 예약 칸에 마지막으로 물을 칠하고 상층 199 판자 다리를 얹음 |
| `assertRiverVillage` | 장식 후 실제 수로 보존·다리 존재·양안 출구와 모든 문 앞 도달을 검사 |

숲 띠 패스에는 강의 전체 경계를 예약 영역으로 전달하여 미리 나무를 심는 충돌을 막는다.
기존 지형·타일 스택·이벤트·집 보호와 선택 영역 경계는 유지한다. 빈 전체 시작 맵의 시작점은 필요 시 강변 길로 옮기며,
기존 저작 시작점이나 선택 영역 안의 시작점은 강이 지나가지 못하게 한다.
`layoutPlacementValidate`는 합본 마을 칩셋의 통행 가능한 199 판자를 물 위 소품으로 지우지 않는다.
다른 물 위 소품·나무 검사는 유지한다. `assertRiverVillage`는 정리 후에도 다리가 남았는지 다시 검사한다.

모델은 마을의 목적·규모·유형을 정하고, 좌표·충돌·길 연결은 seed로 재현 가능한 알고리즘이 담당한다.
기존 지형어 판정은 DB 생성 규칙을 그대로 쓴다. 프롬프트 정규식이나 별도 미리보기 계산기를 추가하지 않았다.

## 수용 기준과 다음 검증

- 물 타일 수만으로는 강의 연속성이나 다리 기능을 증명할 수 없다.
  연결된 예약 수역 전체를 시공하고, 모든 칸 보존과 실제 건널목 도달을 검사한다.
- 양안에 집을 배치했다면 시작점에서 건널목을 거쳐 모든 현관까지 갈 수 있어야 한다.
- 주택·주민 수, 대사, 기존 집 보호, 범위 준수는 기존 완료 계약으로 유지한다.
- 외관은 같은 규모·여러 seed로 비교한다. 강의 형태에 따라 필지와 길이 달라지는지,
  집 무리와 빈 공간의 차이가 읽히는지, 물길을 장식처럼 덧칠하지 않았는지 본다.
- 「집 간격 몇 칸」「숲 몇 %」같은 수치는 논문이 보증한 값으로 쓰지 않는다.
  DB에서 조절하는 후보값으로 두고 실제 칩셋·작은 지도·큰 지도로 비교한다.
- 추가한 회귀 계약은 `test/villageRiver.test.ts`(연속 수로·오프셋 범위·기본값 제외·다리 제거 검출)이며 이번 턴에서는 실행하지 않았다.
- 기본 8채·seed 17 외의 모든 규모·시드에 대한 성공을 이번 실행으로 보장하지 않는다.

관련 정본: [세계 생성 규칙](world-generation-rules.md), [시공 순서](large-village-generation.md).

## 장소 라이브러리의 기준 도안

사용자 승인 후 현재 실외 마을을 「장소 → 마을·도시 → 강변 숲마을」에 등록했다.
공용 장소 `place_river_forest_village`와 새 마을 기본값은 `RIVER_VILLAGE_STYLE`을 공유한다.
조수 컨텍스트와 도구 설명에도 이 기준을 전달한다. 실제 생성은 집 수·seed에 맞춰 기존
`author_village`가 시공하며 도안 8채를 그대로 복제하도록 강제하지 않는다.
[장소 카탈로그 정본](spatial-catalog-ui.md)의 2026-09-21 절에 등록·저장 경로를 기록했다.

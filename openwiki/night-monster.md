  현관문과 결말 문은 북쪽 벽에 배치했다. 복도는 가운데 벽을 돌아가는 순환 동선이다.

  침실 (6,6) 보관함에서 호루라기를 얻는다. 지하실 책상 (10,6) 기록을 읽고

- 기존 안전구역과 즉사 압력판은 제거했다. 아래 초기판 공략의 좌표/기능은 역사 기록이다.

## 초기판 게임 구성과 공략 (현재 개정본에는 적용하지 않음)

1. **비 내리는 현관**: 오프닝, 조작 안내, 잠긴 현관과 끊긴 전화. 아래 통로로 서재에 간다.
2. **잠긴 서재**: 움푹 팬 초상(10,8)에서 황동 열쇠를 얻고 문고리(16,10)에 사용한다.
   버튼은 가운데(10,10) → 왼쪽(7,10) → 오른쪽(14,10). 오답은 진행을 0으로 돌린다.
   두 조건을 만족하면 중앙 아래 복도 문이 열린다.
3. **숨죽인 침실**: 서재 오른쪽 끝 통로. 민서의 가방(6,6)을 조사하면 호루라기 획득
   스위치가 켜진다. 옷장과 쪽지에 대사가 있다. 옷장은 실제 은신 기능이 아니다.
4. **괴물의 복도**: 왼쪽 입구 x=2..6, y=8..10은 안전지대. 붉은 압력판
   (9,8)/(14,6)/(20,8)은 즉사, 보라색 괴물은 시야 범위 안에서 장애물을 우회해 추격한다.
   북동쪽 (25,4)이 지하실 입구. 진입 체크포인트와 사망 시 재시도를 지원한다.
5. **지하 격리실**: 녹음기(10,5)를 조사하고 침실의 호루라기를 챙겼으면 왼쪽(7,10)에서
   친구를 구출한다. 오른쪽 비상문(13,10)은 언제든 혼자 탈출하는 결말이다.

방향키/WASD 이동, Shift 달리기, Enter/Z 조사, Esc 메뉴. 전투와 랜덤 인카운터는 사용하지 않는다.
조사 표식·퍼즐 버튼·압력판·괴물·결말 선택물은 실제 charset 그래픽을 가진다.
모든 방에 손전등 조명을 명시해 이전 맵의 어둠이 뜻하지 않게 남지 않도록 한다.

## 초기판 검증과 발견한 함정

- 저장 전과 LegacyDb 재로드 후에 다섯 시나리오를 실행한다: 다섯 방 연속 보행과 구출,
  열쇠/암호/문 통과, 추격 사망과 재시도, 구출 엔딩, 단독 탈출 엔딩.
- 전체 보행은 `walk`로 실제 통행성과 전이를 거친다. 이 시뮬레이터의 보행은 벽시계 기반
  플레이 숙련도나 공포감을 재지는 않는다. 추격의 시간 진행은 별도의 `wait` 사망 검증이다.
- `projectLint`의 구조 경고는 0이어야 한다. 기존 명령 분류기의 `runtime-support:*`
  경고는 보고서에 그대로 남기고, 사용한 명령의 실제 동작은 시나리오와 플레이어 QA로 확인한다.
- `place_examine_hotspots`는 맵마다 `ev_examine_1`부터 ID를 만들지만 런타임 이벤트 위치
  색인은 맵 사이에 같은 ID를 공유한다. 이 콘텐츠는 다른 방의 조사 ID에 map id를 붙여
  잘못된 방의 좌표/이벤트가 선택되는 것을 막는다. 엔진 자체는 수정하지 않았다.
- `create_transfer_pair`는 요청 좌표를 통행 가능한 문으로 조정할 수 있다. 현관→서재
  실제 착지점은 (2,12)이며 요청 좌표 (3,14)를 QA 기대값으로 사용하면 안 된다.
- DB JSONB는 객체 키 순서를 바꾼다. 저장 검증 해시는 배열 순서를 유지하고 객체 키를
  정렬한다. 맵 타일, 전체 이벤트 명령, 조명, 음악, 안전지대와 시작점이 일치해야 한다.
- 게임 화면 QA: `npm run qa:runtime -- --scenario night-monster`.
  LegacyDb에서 다시 읽어 저장한 JSON을 `player.html` 출하 경로로 실행한다.
  `verify-shots/runtime-qa/night-monster/SUMMARY.md`를 먼저 읽고 표시된 PNG를 확인한다.

런타임 오류 0건이었다. 움직이는 괴물의 포획, 포획 SE, 재시도, 압력판 사망 SE와

`.omo/evidence/night-monster/`에 둔다. 21개의 기존 `runtime-support:*` 분류 경고는

세션 상태를 성공 상태로 덮지 않고 실제 입력을 사용했다. 증거는

### 사용자 플레이 후 체험 QA 정정 (2026-09-05)

**판정: 요구한 저택 탐색·추격 게임으로서는 불합격.** 위의 5개 진행 시나리오와

- 옷장은 텍스트만 출력한다. 은신 상태 전환, 탐지 해제, 괴물의 수색이 없다.

  실제 문으로 복도에 돌아가면 괴물이 초기 위치로 돌아온다. 현재 추격은 맵에 종속되어 있다.

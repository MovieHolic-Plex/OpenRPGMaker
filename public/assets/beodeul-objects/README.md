# 버들항 기본 기물

버들항 칩셋을 쓰는 맵에서 왼쪽 **기물**의 검색창에 `버들항 기본 기물`이나 기물 이름을 입력해 찍는다. `실내`, `자연`, `생울타리`, `부두`로도 찾을 수 있다. 조수는 `list_tileset_objects`로 찾고 `stamp_tileset_object`로 찍는다.

[카탈로그](catalog.json)에 포함된 131개 PNG는 승인 매니페스트에서 가져왔다. `sourceFile`에 매니페스트에 적힌 원본 파일명을 기록한다. 승인본은 바이트 그대로 복사하고 `_r2`, `_r3`, `_v2`, `_v3` 접미사가 붙은 대체본은 기본 ID로 등록한다. 이후에도 승인본을 추가할 때 기존 ID와 저장된 맵이 참조하는 PNG 안 칸 배치를 유지한다.

- `nameKo`는 한국어 이름이다. `category`는 실내 가구(`indoor`), 자연물(`nature`), 시설과 연결 조각(`structure`), 기타 기물(`prop`)이다.
- `widthPx`와 `heightPx`에는 원본 크기를, `widthTiles`와 `heightTiles`에는 16px 단위로 올림한 칸 수를 적는다. 예를 들어 작은 둥근 관목은 20×16px이고 맵에서는 두 칸을 사용한다.
- `footprint`는 왼쪽 위에서 읽는 칸별 통행표다. `X`는 막힘, `*`는 바닥의 통행을 따르는 머리 위 그림, `.`은 밟고 지나가는 그림, 공백은 그림이 없는 칸이다.
- 맵을 누른 칸에 그림의 맨 아래 가운데 칸이 놓인다. 폭이 짝수면 가운데 두 칸 중 오른쪽 칸을 쓴다. 조수 도구의 `at`은 왼쪽 위, `base`는 왼쪽 아래 칸이다.
- 생울타리와 부두의 직선 킷은 `growthAxis` 방향으로 이어 찍을 수 있다. 모서리·끝·갈림·문·계류 조각은 이름으로 골라 붙인다. 부두 칸은 물 위에 놓으며 걸을 수 있다.

그림의 출처와 라이선스는 [에셋 크레딧](../ATTRIBUTION.md)에 있다.

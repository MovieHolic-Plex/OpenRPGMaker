# 버들항 기본 기물

버들항 칩셋을 쓰는 맵에서 왼쪽 **기물**을 열면 분류별 묶음과 기물 수가 표시된다. 묶음 이름을 눌러 펼치거나 접는다. 검색창에는 한국어 이름, ID, 태그의 일부를 입력할 수 있다. 검색하면 일치하는 묶음이 펼쳐진다. `버들항 기본 기물`로 이 카탈로그의 기물을 모두 찾을 수 있다. 조수는 `list_tileset_objects`로 찾고 `stamp_tileset_object`로 찍는다.

## 기물 추가

1. 승인된 투명 PNG를 이 폴더에 `<id>.png`로 복사한다. `id`는 소문자로 시작하며 영문 소문자, 숫자, 밑줄을 쓴다. 원본이 `_r2`, `_v3`, `_hq`, `_hq2`, `_hq3`, `_sz` 같은 판본 접미사로 끝나면 파일명과 ID에서 떼고 `sourceFile`에 승인 매니페스트의 원본 파일명 전체를 기록한다. 그림은 바이트 그대로 복사한다.
2. [catalog.json](catalog.json)의 배열에 아래 필드를 갖춘 항목 하나를 추가한다. 기존 기물의 승인된 대체본은 저장된 맵이 참조하는 ID를 유지하고 같은 항목을 갱신한다. 같은 크기의 대체본은 PNG 안 칸 배치를 보존하고, 크기가 달라지면 실제 그림에 맞춰 치수와 통행표를 갱신한다. 에디터와 번들 등록은 이 배열을 읽는다.
3. 기물 팔레트 연동 테스트가 포함된 체크아웃의 저장소 루트에서 카탈로그 검사를 실행한다.

   ```sh
   OPRN_LOCAL_TESTS=1 npm run test:unit -- test/beodeulPlaceableObjectsCatalog.test.ts
   ```

검사는 기물 PNG와 항목의 일대일 대응, 고유 ID, 실제 픽셀 크기, 16px 칸의 투명 영역과 통행표, 그룹 참조와 세트의 필수 조각을 확인한다. 기존 도로·점자블록처럼 바닥을 덮는 PNG는 통행표가 모두 `.`인 경우 불투명해도 된다. 하이픈이 들어간 참고 이미지는 별도로 보관하는 배치 예시다.

| 필드 | 값 |
| --- | --- |
| `id`, `sourceFile` | 판본 접미사 없는 고유 ID와 승인 매니페스트의 원본 파일명 |
| `nameKo`, `tags` | 표시할 한국어 이름과 검색어 배열. 한국어 동의어와 영어 태그를 넣을 수 있다. |
| `category` | 배치·구조 킷 호환 분류. `prop` 기타 기물, `indoor` 실내 가구, `nature` 자연, `structure` 시설과 연결 조각 |
| `group` | 팔레트에 표시할 [manifest.json](manifest.json)의 `groups[].id` |
| `widthPx`, `heightPx` | PNG의 실제 픽셀 너비와 높이 |
| `widthTiles`, `heightTiles` | 각 픽셀 크기를 16으로 나누고 올림한 칸 수. 예를 들어 20×16px는 2×1칸이다. |
| `footprint` | 왼쪽 위부터 한 행에 문자열 하나. `X` 막힘, `*` 바닥의 통행을 따르는 머리 위 그림, `.` 밟고 지나가는 그림, 공백은 완전히 투명한 칸. 각 문자열에 빈 칸의 공백까지 포함해 너비를 맞춘다. |
| `set` (선택) | 연결 조각이면 `category`를 `structure`로 두고 `{ "id": "hedge", "piece": "corner_ne" }`처럼 세트와 조각 이름을 적는다. 세트 안에서 조각 이름은 고유하다. |
| `growthAxis` (선택) | 이어 찍는 방향. `horizontal`, `vertical`, `both` 중 하나 |
| `surface` (선택) | `water` 물 위, `wall` 벽면. 생략하면 바닥에 놓는다. |

기존 분류에 넣는 기물은 PNG와 카탈로그 항목만 추가하면 된다. 새 분류가 필요하면 매니페스트 `groups`에 `id`, `labelKo`, `order`를 추가한다. 순서 값이 작은 묶음부터 표시된다. 새 연결 세트가 필요하면 `sets`에 `id`, `role`(예: `fence`, `wall`, `water`), `requiredPieces` 배열을 추가하고 필수 조각마다 PNG와 카탈로그 항목을 함께 넣는다.

`crate_stack`은 승인된 대체본에서 2×2칸에서 3×2칸으로 넓어졌다. 기존 배치는 새 그림의 왼쪽 두 열을 같은 자리에 표시하고, 새로 찍으면 세 열이 모두 놓인다.

맵을 누른 칸에 그림의 맨 아래 가운데 칸이 놓인다. 폭이 짝수면 가운데 두 칸 중 오른쪽 칸을 쓴다. 조수 도구의 `at`은 왼쪽 위, `base`는 왼쪽 아래 칸이다.

그림의 출처와 라이선스는 [에셋 크레딧](../ATTRIBUTION.md)에 있다.

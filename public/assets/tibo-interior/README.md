# Restored Tibo furniture

357 object PNGs: all 353 previously registered objects plus the last four approved
warm-wood furniture variants. Atlas geometry: 480×1056, 16px cells, 30 columns,
1980 slots. Prior 353 kit IDs, anchors, dimensions and passability are retained.

The deleted workspace's source images survive in the generation server and
conversation. Prior packed sprites were recovered from their integer-scaled PNG
contact sheets, keyed against their uniform beige backdrop. These are recovered
raster pixels, not regenerated artwork; byte identity with deleted individual
PNGs cannot be established. The four new props were extracted from their approved
source sheet. Rejected iterations are not replacements for the existing IDs.

Default metadata is src/assets/tiboRecoveredTileset.json. Original generation
sheets and recovery provenance are in recovered-assets/tibo-20260917. A separate
archive is held in /home/main/asset-recovery-backups.

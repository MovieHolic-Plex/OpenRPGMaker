# 별빛섬 오프닝 그림

내장 imagegen으로 이 프로젝트를 위해 새로 생성한 원본 그림이다. 기존 게임의
캐릭터나 로고를 사용하지 않는다. 프롬프트·출처·SHA·검수 범위는
`starlight-prologue.provenance.json`에 있다. PNG는 후처리하지 않았다.

`uploaded-art.json`은 같은 PNG의 휴대 가능한 업로드 데이터다. 게임 프로젝트에
등록하고 SQLite 저장 서비스로 보내면 호스트의 `assets/`가 그림을 소유한다.
배포 시 동일 SHA의 휴대용 바이트를 사용한다. 타이틀은 기존 섬 전경을 유지한다.
오프닝은 섬 전경(4초) → 꺼지는 등대(5초) → 연구소의 세 첫 동료(9초)로 구성한다.
새 두 그림은 `storyboard-20261003/`, 등록 바이트는 `storyboard-uploaded-art.json`이다.
세 장면의 단일 오리지널 음악과 재생성 소스·측정은 `score/`에 있다.
정지 그림의 pan/zoom을 사용하며 몬스터 행동 애니메이션은 아니다.
첫 동료는 실제 연구소 선택 후 지급한다. 그림의 별 개수는 배지 수 UI가 아니다.

# New-game interview scene art

45 AI-generated narrative reference illustrations approved during the 2026-10-02 interview design session. These are UI key art, not playable tiles, species battle sprites, or author-selected protagonist designs.

`reviews.json` binds each shipped WebP to its SHA-256, the reviewed original PNG's SHA-256, the manual visual checks and notes. The 20 new images passed six checks (pixel geometry, discrete shading, pixel density, choice semantics, distinct composition, no overlay); the 25 reused scene cuts passed their recorded five-check review; rejected generations were redrawn before packaging. Existing source reviews were verified again when copying into the app. “16-bit” describes the visual style, not a hardware certification. Resizing used nearest-neighbor sampling; no photographic or painted substitutes are included.

The world motion video and poster derive from the user's supplied `녹음 2026-10-01 090619.mp4`. The short, muted clip is used only on interview entry; still scenes replace it upon selection. No remote asset server is required.

Source session: `2026/10/02/01a0fbfa-b0ef-7e73-bda8-a21f68121718`, `genre-interview` (20 new images) and `scene-cuts` (25 reused images). Originals and generation prompts remain in that session artifact. This folder contains only the derivatives needed by the app. To change an asset, review its full original and a source-pixel crop again; changing bytes without a corresponding review invalidates the approval.

The module is a documentation-only package consumed by other agents; it has no source code. `manifest.json` (versioned schema) is the single registry listing every skill (`skills/<id>/SKILL.md`) and feature spec (`features/*.md`) with an `id`, `path`, and `useWhen` clause. `catalog.md` enforces the two-bucket taxonomy — `skills/` for reusable authoring recipes that guide content generation without changing app code, and `features/` for product/editor capabilities requiring UI, runtime state, persistence, or inspection tools. `building/` and `tilesets/` hold legacy asset/reference skills. Each SKILL.md follows a front-matter header (`name`, `description`) plus sections for purpose, required editor evidence (screenshots), minimum content, and failure conditions, making them machine-parseable inputs for agent-driven demo generation.

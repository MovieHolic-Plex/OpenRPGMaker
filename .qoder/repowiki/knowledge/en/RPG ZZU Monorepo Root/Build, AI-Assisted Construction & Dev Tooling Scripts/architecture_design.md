Flat collection of executable entry points plus three small sub-packages:
- Top-level `*.mjs` / `*.mts` / `*.cjs` / `*.py` files are one-shot CLIs invoked via `npx tsx scripts/<name>.mts` or `node scripts/<name>.mjs`. Each script is self-contained: it imports shared runtime from `src/` (e.g. `AssistantSession`, `Project` types, `createBlankProject`) and writes artifacts under `output/evidence/...`.
- `scripts/rm2k3-parity/` is a tiny CLI library split into `cli.mjs` (arg parsing + secret redaction), `checks.mjs` (contract/matrix validators), `evidence.mjs` (JSON evidence writer), and `io.mjs` (file helpers); the root `check-rm2k3-parity.mjs` wires them together and exits with distinct codes for parity failure vs input error.
- `scripts/supabase-resource-root/` exposes constants (`RESOURCE_SLICING`, `DEFAULT_PROJECT_ID`) and helpers (`rootResourceFiles`, `pngDimensions`, `sha256Buffer`) consumed by other scripts to upload generated assets to Supabase.
- `scripts/natural-village/` is a deterministic reference-builder: `blueprint.ts` declares stage IDs, `build.ts` composes maps through staged `paint*` functions and `events.ts`, producing a multi-map Project used as an AI prompt reference.
- `scripts/assets/` and `scripts/lib/` hold reusable image-processing utilities (chroma key, pixel PNG, magenta post-process) imported by multiple top-level scripts.
- `scripts/_start-dev-hard.ps1`, `_start-dev-hard.cmd`, `dev-keepalive.mjs`, `dev-keepalive-supervisor.mjs`, `dev-keepalive-watchdog.cmd` form a Windows-friendly process supervisor that spawns Vite on port 9999, health-checks HTTP, kills zombie processes, and supports `--detach` via PID lock file in `output/dev/`.
Dependency direction is strictly outward: scripts import from `src/` and from sibling sub-packages; no cross-import between unrelated top-level scripts.

Requires a local `.env.local` containing `VITE_LLM_API_KEY` (and optionally `VITE_LLM_MODEL`, `VITE_LLM_API_URL`, `EVAL_MAX_TOOLCALLS`, `EVAL_MAX_TOKENS`, `EVAL_TASK_TIMEOUT_MS`). Run the full LLM suite via `node evals/run.mjs [N]` (defaults to top 4 tasks) or directly with `npx vitest run --config evals/vitest.config.mjs evals/*.eval.ts`. Offline golden-task scoring uses the regular `npm test -- evals` target (see README).

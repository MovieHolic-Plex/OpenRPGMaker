MODULE = honeydukes (space honeydukes; 허니듀크 지하 창고). id 접두 `wz-hd-`.
- 지하 석벽(1×4 북벽, 거친 돌 + 오크 보 걸림), 오크 천장 보(위층 C 띠 1×1 가로·세로·교차 — 사람 위로 지나감), 내려오는 계단(2×3 위층 가게에서 내려오는 나무 계단), 비밀 가림 패널 3상태(1×4: 닫힘=석벽처럼 보이는 패널, 이동=반쯤 밀린 패널 뒤 어둠, 열림=패널이 옆으로 비켜 석재 통로 입구가 드러남 — 열림은 통행), 그 뒤 석재 통로 입구·문턱(1×2 바닥).
- 바닥: 설탕 가루 흩어진 판재 1×1 2종, 포장 작업 바닥 덧그림 f(끈 조각·종이 부스러기).
- 과자 포장 작업대(3×2), 저울(f), 사탕 항아리(1×1 유리 항아리 3색), 초콜릿 개구리 포장 상자(1×1 오각형 상자, 개구리 문양), 백미향 젤리빈 상자(1×1 줄무늬 상자), 포장지 두루마리(f), 끈 뭉치(f), 완성 과자 상자 적치(1×2, 2×2), 나무 선반(2×3 과자 상자 가득), 술통형 사탕 통(1×1).
예제: `wz-hd-example-cellar` 12×10 지하 창고(계단·비밀 패널·작업대·적치).

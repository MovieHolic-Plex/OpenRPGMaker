MODULE = library (space library 도서관 제한 구역 + space wandshop 보강). id 접두 `wz-lib-`, `wz-wand-`.
도서관:
- 성채 도서관 아치(2×4 열린), 어두운 마모 포석 1×1 반복 2종(공용 포석보다 어둡고 닳음), 납살 창은 공용 id 사용.
- 제한 구역 철제 출입문 3상태(2×4: 닫힘=철창 격자, 열림=문짝 젖힘, 잠김=쇠사슬+맹꽁이자물쇠), 철제 울타리(1×2 가로 반복, 끝).
- 사람 높이를 넘는 다칸 오크 서가(2×3, 3×3: 위 행 C·밑 S) 책마다 개별 쇠사슬이 서가 고리에 걸림(쇠사슬이 분명히 읽혀야 함), 쇠사슬 없는 일반 서가 2×3 도 1개.
- 잠금 마법서(f 탁상, 쇠 띠·자물쇠), 열린 위험 마법서(f, 펼친 쪽에 어두운 문양), 검사 열람대(1×2 비스듬 독서대 — 3/4 로 읽힘), 사다리(1×3 서가에 기대는), 촛대(공용 사용 가능), 양피지 기록 탁자(2×2), 사서 열쇠 꾸러미(f).
지팡이 가게 보강(먼저 `tiledata/wizarding/native/wandshop/*.png` 를 전부 보고 같은 화풍으로):
- 시험실 문 3상태(1×4, 지팡이 가게 판벽 재질), 그을린 시험 바닥 덧그림 f 3종, 오크 시험 바닥 1×1 반복(native aged_dark_boards 와 같은 결 — 그 그림을 칸 질감으로 빌려도 된다), 긴 지팡이 상자 벽(2×4 천장까지 쌓인 가는 상자), 서로 다른 손잡이 지팡이 3종 진열(f), 황동 줄자(f).
예제: `wz-lib-example-restricted` 14×10 제한 구역, `wz-wand-example-shop` 10×9 지팡이 가게(native 에 없는 부분만 써도 된다).

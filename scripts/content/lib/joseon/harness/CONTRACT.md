# 조선 칩셋 하네스 계약

버들항(`beodeul_city`)과 **같은 게임 안에 놓였을 때 이질감이 없는 것**이 기준이다. 취향 판정은 사용자가 한다 — 이 하네스는
(1) 위반을 기계가 먼저 거르고 (2) 에이전트가 기준 조각 옆에서 직접 보고 한 줄 판정을 남기게 하고 (3) 사용자가 고를 수 있게 증거를 쌓는다.

## 1. 팔레트 잠금 (`palette.json`, `lock_palette.py`)
- 허용 색 = 버들항 시트 **상위 256색(화소의 84%) ∪ RAMPS_CHIP 57색** = 267색. 이 밖의 색은 한 화소도 안 된다.
- 조선 램프 7개(`giwa 기와·earth 황토·straw 볏짚·dgreen/dblue 단청·persimmon 감·pine 솔잎`)는 허용 색 안에서만 골랐고,
  `lock_palette.py` 가 하나라도 밖이면 실패한다. 목재·돌·물·잎·회벽·붉은색은 버들항 램프 그대로.
- 그리기 도구(`tk.py`)는 허용 밖 색이 들어오면 `VIOLATIONS` 에 센다 → 게이트 P 가 막는다. **색을 코드에 직접 쓰지 마라.**
- 새 색이 필요하면 램프를 발명하지 말고 `lock_palette.py` 의 `JOSEON_RAMPS` 에서 허용 색을 골라 바꾼다.
- 실측(2026-10-02): 잠금 전 초안은 불투명 67색 중 31색(화소 34%)이 허용 밖이었다.

## 2. 시점 계약 (3/4)
- **정면-위 3/4, 좌우 대칭(건물), 빛은 왼쪽 위, 그림자는 오른쪽 아래.** 물체를 비스듬히 돌리지 않는다.
- 앞면은 전체 높이, 윗면(지붕 앞사면·마루·덮개)은 짧게. 지붕은 가파르게(용마루가 실루엣 꼭대기), 처마는 벽 밖으로 튀어나오고 아래에 그늘.
- 윗면이 원래 안 보이는 정면 소품(장승·솟대·석등)은 `user` 판정으로 표시하고 사용자에게 보여 판정받는다.
- 이건 숫자로 못 줄인다. **눈으로 본다**: `python3 harness/gate.py --sheets` → `tiledata/joseon-demo/review/<조각>.png`
  (내 조각 | 버들항 기준 조각 ×3, 3배)을 읽고 `verdict.py` 로 조각마다 한 줄 판정(윗면이 얼마나 보이나·기준과 무엇이 다른가)을 쓴다.

## 3. 화풍 계약 (자동 검사, 통과선은 버들항 객체 112개 실측: `calibration.json`)
| 항목 | 게이트 | 통과선 |
|---|---|---|
| P 팔레트 | 허용 밖 색 0 | 0 |
| E 외곽선 | 가장자리/안쪽 밝기비 중앙값(안쪽 inset ×0.62, 바깥 링 금지) | ≥ 0.36 (버들항 p5, 중앙 0.62) |
| T 가는 줄 | 폭 1px 화소 비율 | ≤ 0.046 (버들항 p95×2+0.02), `thin_ok` 조각은 이유 필수 |
| L 빛 | 왼쪽 반 − 오른쪽 반 밝기 | ≥ −0.09 (front_only 제외) |
| S 그림자 | 반투명 그림자 무게중심 | 본체보다 아래 |
| V 판정 | 현재 그림 해시에 묶인 판정 | 없음/바뀜/`redo` 이면 막음 |
| 결·대칭 | grain, built 좌우 비대칭 | WARN |
- 외곽선은 실루엣 **안쪽**을 어둡게 하고 허용 색으로 맞춘다(`build.outline`). 바깥에 어두운 링을 덧대지 않는다.
- 한 화소 밀도: 1px 얼룩·1px 줄 금지, 잎은 깨끗한 덩어리(puff) 클러스터. 기능은 ≥2px.

## 4. 조선 형태 규칙
- 기와집: 팔작지붕(양옆 추녀), 기왓골은 세로, 처마 끝 막새 띠, 용마루+치미, 처마 끝 들림, 창호(한지+살), 석축 기단+디딤돌.
- 초가: 둥근 어깨 지붕, 새끼줄 그물, 용마름, 황토 벽, 낮은 돌 기단, 굴뚝.
- 단청은 대문·정자 처마 밑 띠로만. 일반 살림집에는 안 칠한다.
- 마을 규칙은 버들항과 같다: 문마다 길망에 닿고, 길은 흙, 광장·마당만 다진 바닥, 소품은 사람이 일하는 곳에 무리지어.

## 5. 절차
1. `python3 harness/lock_palette.py`(팔레트 바뀔 때만) → 2. 그린다 → 3. `python3 harness/gate.py --sheets` →
4. 시트를 눈으로 보고 `python3 harness/verdict.py <조각> <pass|note|user|redo> "<한 줄>"` → 5. `python3 demo.py`(게이트 통과 때만 굽는다) →
6. 사용자가 고른다(후보가 여럿이면 후보별로 1~5 를 돌려 판을 만든다).

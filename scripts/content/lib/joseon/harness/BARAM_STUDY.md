# 바람의나라 타일셋 연구 → 조선 칩 반영 (2026-10-02)

원본 스크린샷 3장(국내성 북쪽 문루, 마을 건물 배치, 초가 마당)을 확대해서 읽은 규칙. 그림 자체는 타사 자산이라 저장소에 넣지 않았다(`~/third-party-assets/baram/`). 아래는 **규칙**만 적는다.

## 읽은 것
| 대상 | 원본에서 본 것 | 반영 |
|---|---|---|
| 기와 지붕 | 몸채 앞사면은 **세로 기왓골**이 촘촘, 양옆 **날개면은 다른 방향(가로) 결**. 날개가 위 모서리에서 오목하게 걸려 바깥·위로 **치켜 올라간다**(앙곡). 면 경계는 **굵고 밝은 추녀마루 선**. 용마루는 얇은 밝은 띠, 양끝에 **둥근 마루 끝**. 처마 아랫선은 **가운데가 낮고 양끝이 들린 곡선**. 처마 끝 **막새 점열**. | `roof3d.py roof()`, `blocks.roof_baram` |
| 처마 그림자 | 지붕 아래 벽면이 **체크무늬 디더**로 어두워진다(알파 그림자가 아니라 격자 점). | `blocks.dither_under` |
| 지붕 색 구분 | 건물 기능마다 지붕 색이 다르다(청록·갈색·회청). 기둥은 청록 몸체에 붉은·금 무늬(단청). | `roof_baram(style=giwa/brown/dg)`, `pavilion_open` |
| 초가 | **사다리꼴이 아니라 위아래가 둥근 납작한 방석**(슈퍼타원). 붉은 주황 톤, 짚결은 **세로로 일어난 짧은 획**, 둘레에 불룩한 단, 아래는 그늘, 가장자리 털. | `thatch3d.py dome`, `blocks.thatch_baram` |
| 담 | 위는 **두툼한 주황 갈색 기와·흙 덮개**(기왓골 홈, 모서리가 둥글게 꺾임), 아래는 **어두운 막돌**. 덮개가 담 폭보다 굵다. | `props3.wall_h2/wall_v2/wall_corner2` |
| 정자·문루 | 벽이 없고 **굵은 단청 기둥 사이로 어두운 안쪽**이 보인다. 돌 기단 위에 마루. | `blocks.pavilion_open` |
| 마을 배치 | 건물이 흙바닥에 **각기 떨어져** 있고, 건물마다 앞 석등·울타리·현판·꽃나무가 붙는다. 맵 가장자리는 붉은 장식 띠. | 지도 밀도·터 울타리(기존), 현판·꽃나무는 다음 |

## 하지 않은 것(정직하게)
- 바람의나라 그림의 **색 수는 훨씬 많고 흐릿**하다. 우리 팔레트는 버들항 시트 267색 잠금이라 그 색감은 따라가지 않았다(결·구조만 반영).
- 디더 그림자는 지붕 아래 4행만. 맵 전체 디더 그림자(나무 밑·담 밑)는 아직.
- 현판(간판)·꽃나무(분홍)·붉은 맵 테두리 띠·홍살문은 미반영.

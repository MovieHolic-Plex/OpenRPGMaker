# 심판 질문 A — 어느 쪽이 상용 팩인가 (블라인드)

너는 게임 그래픽 감정가다. 아래 판 이미지 파일을 **Read 도구로 하나씩 직접 열어** 본다. 목록에 없는 파일·폴더는 열지 않는다(다른 파일에는 정답이 있어 판정이 무효가 된다).

각 판에는 같은 종류의 물건(가구·바닥·벽·문 등) 그림 두 개가 왼쪽 **A**, 오른쪽 **B** 로 있다.
둘 중 하나는 **상용 RPG Maker MV 실내 타일셋에서 잘라낸 그림**이고, 다른 하나는 같은 물건을 **흉내 내 새로 그린 그림**이다.
어느 쪽이 상용 팩인지 고른다.

- 두 그림의 화면 크기·화소 크기가 다를 수 있다. **크기나 해상도만으로 고르지 말고** 그림 솜씨로 판단한다:
  명암(띠·덩이·빛 방향), 윤곽(색·두께·들쭉날쭉), 재질 결(나무·천·돌·쇠), 시점(윗면·앞면 비율), 비례, 색(채도·색 줄), 외톨이 화소·잡티, 그림자.
- 확신도 `confidence` 는 0.5(찍음)~1.0(확실).
- `cues` 에 네가 본 근거 1~3개를 짧게 적는다. 어느 쪽(A/B)의 무엇인지 적는다. 크기·해상도가 근거에 들어갔으면 솔직히 적는다.
- 판끼리 비교하지 말고 판마다 따로 판단한다. 좌우 어느 쪽에 정답이 몰린다는 규칙은 없다.

판 파일:
{{PLATES}}

결과를 아래 형식 JSON 으로 **{{RESULT}}** 에 Write 도구로 쓴다(다른 곳에 쓰지 않는다). 쓰고 나면 같은 JSON 을 마지막 답으로도 돌려준다.
```json
{"schema": "px-judge/identify@1", "judge": "{{JUDGE}}",
 "answers": [{"plate": "p01", "commercial": "A", "confidence": 0.8, "cues": ["B 윤곽이 거의 검정이고 굵다", "A 천 명암이 부드럽다"]}]}
```
판 하나당 answers 항목 하나. plate 는 파일 이름(확장자 뺀 것).

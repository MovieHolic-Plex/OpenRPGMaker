# 심판 질문 B — 화소 결함 찾기

너는 도트 그래픽 검수자다. 아래 판 이미지 파일을 **Read 도구로 하나씩 직접 열어** 본다. 목록에 없는 파일·폴더는 열지 않는다.

각 판에는 게임용 도트 그림 하나가 확대돼 있다. 왼쪽은 그냥 확대, 오른쪽은 같은 그림에 **원본 화소 좌표 눈금**(노란 숫자 = 원본 화소 x·y, 굵은 선 8px 마다, 옅은 선 4px 마다)이 있다.
판 왼쪽 위 글자는 원본 크기와 배율이다. 목표 품질은 상용 RPG Maker MV 캐릭터 소재(48px 칸, 2~2.5등신) 수준이다. 그림은 걷기 한 프레임이다. 그 기준에서 눈에 띄는 결함을 찾는다.

결함 종류 `type` (하나 고른다):
- `banding` 명암 띠가 계단처럼 딱딱 끊기거나 평행 줄무늬로 보임
- `pillow_shading` 베개 명암(윤곽 따라 가장자리만 어둡고 빛 방향이 없음)
- `orphan_pixel` 외톨이 화소·잡티·뜬금없는 점
- `jaggy_line` 들쭉날쭉한 선(곡선·사선의 계단 크기가 고르지 않음), 두께가 흔들리는 윤곽
- `perspective` 시점 틀림(윗면·앞면 비율, 원근이 다른 물건과 안 맞음, 떠 보임)
- `proportion` 비율(부품 크기·두께, 사람 키 대비 크기)
- `material_texture` 재질 결이 틀리거나 없음(나무·천·돌·쇠로 안 읽힘, 잡음 같음)
- `color` 색(채도 과다, 윤곽이 검정, 색 줄이 탁함, 색끼리 안 맞음)
- `other` 위에 없는 것

감독 기준(교정에서 맞춘 것): 세부가 적은 것 자체는 결함이 아니다. 낮은 가구(탁자·침대·깔개)는 윗면이 넓게 보여야 하고 옆면·다리가 크면 `perspective` 다.
벽·바닥은 되풀이 깔리는 바탕이라 한 장마다 센 테·줄눈으로 도드라지면 `material_texture`(시끄러움)다. 윤곽이 검정에 가까우면 `color` 다.

각 결함은 `rect: [x, y, w, h]` 를 **원본 화소 좌표**로 준다(확대 화면 좌표가 아니다. 눈금 숫자를 읽어라). 결함 부위를 딱 감싸게.
`severity` 1(작음)~3(첫눈에 보임). 판마다 결함 0~6개, 진짜로 보이는 것만. `note` 는 한국어 한 줄.
`overall` 은 상용 팩 대비 완성도 1~10 (10 = 상용과 구별 불가).

판 파일:
{{PLATES}}

결과를 아래 형식 JSON 으로 **{{RESULT}}** 에 Write 도구로 쓴다. 쓰고 나면 같은 JSON 을 마지막 답으로도 돌려준다.
```json
{"schema": "px-judge/defects@1", "judge": "{{JUDGE}}",
 "answers": [{"plate": "d01", "overall": 5, "defects": [{"type": "pillow_shading", "rect": [4, 10, 12, 8], "severity": 2, "note": "베개 가장자리만 어둡다"}]}]}
```

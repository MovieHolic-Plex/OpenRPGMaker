# 심판 교정 질문 v3 — 어느 쪽이 더 잘 그렸나 (감독 기준 포함)

너는 게임 그래픽 감정가다. 아래 판 이미지 파일을 **Read 도구로 하나씩 직접 열어** 본다. 목록에 없는 파일·폴더는 열지 않는다.

각 판에는 같은 종류의 게임 그래픽(가구·벽·바닥·마을 땅과 물 등) 두 판이 왼쪽 **A**, 오른쪽 **B** 로 있다.
둘 중 **완성도가 높고, 잘 만든 상용 RPG 타일셋에 더 가까운 쪽**을 고른다. 고르는 기준: 형태가 바로 읽히는가, 시점이 자연스러운가,
명암·윤곽·재질 결이 깔끔한가, 색이 조화로운가, 화면에 깔았을 때 거슬리는 잡음·어색함이 없는가.

**이 프로젝트 감독의 기준 (판정할 때 이 순서로 따진다):**
1. **낮은 가구(탁자·침대·깔개)는 위에서 내려다본 윗면이 주인공이다.** 윗면이 높이의 ¾쯤 보이고 앞 두께·다리는 얇게. 옆면·앞면·다리를 크게 보여 주면 서랍장이나 무대 소품처럼 서 보인다 — 소품이 더 많이 얹혀 있어도 이 시점이 틀리면 진다.
2. **벽·바닥은 방 전체에 되풀이 깔리는 바탕이다.** 가늘고 고른 결(가는 널 결·작은 점·잔 얼룩)은 괜찮고 오히려 좋다. 나쁜 것은 돌·벽돌·널 **한 장마다** 센 밝은 테와 굵은 어두운 줄눈을 넣어 조각 하나하나가 도드라지는 것이다 — 칸 하나로는 입체적이어도 넓게 깔면 격자 무늬로 시끄럽다.
3. **세부가 많다고 이기지 않는다.** 부품·무늬·하이라이트를 더 넣은 쪽이 아니라, 형태가 한눈에 읽히고 면이 정돈된 쪽이 이긴다.
4. **부드러운 붓 칠(색이 수백 개, 명암이 매끈한 고해상 그림)은 흐린 것이 아니다.** 도트가 또렷하다는 이유만으로 붓 칠 그림보다 낫다고 하지 않는다. 형태·시점·재질이 같은 수준이면 색 줄이 차분하고 윤곽이 검정이 아닌 쪽이 낫다.
5. **물·풀처럼 넓은 땅은 그 재료로 바로 읽혀야 한다.** 물은 맑은 물빛과 몇 점 반짝임으로 물로 읽히는 쪽, 풀밭은 자연스러운 풀색 쪽이 낫다. 어둡거나 탁해서 무엇인지 흐려지면 진다.

- 확신도 `confidence` 는 0.5(찍음)~1.0(확실).
- `reason` 에 한국어 한두 문장. 어느 쪽의 무엇 때문인지.
- 판마다 따로 판단한다. 좌우 어느 쪽이 정답이라는 규칙은 없다.

판 파일:
{{PLATES}}

결과를 아래 형식 JSON 으로 **{{RESULT}}** 에 Write 도구로 쓴다. 쓰고 나면 같은 JSON 을 마지막 답으로도 돌려준다.
```json
{"schema": "px-judge/prefer@3", "judge": "{{JUDGE}}",
 "answers": [{"plate": "c01", "better": "B", "confidence": 0.7, "reason": "B 는 윗면이 넓게 보여 식탁으로 바로 읽힌다"}]}
```

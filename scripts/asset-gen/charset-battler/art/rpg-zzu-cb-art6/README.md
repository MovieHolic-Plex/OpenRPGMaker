# Actor4-2~7 전투 도트 납품

원본 `public/assets/easyrpg/charset/Actor4.png`의 왼쪽 방향 픽셀을 머리·머리카락·흉부·목도리·치마 무늬에 보존했다. 팔꿈치, 손, 무릎, 발목과 무기는 정수 좌표의 `putpixel`로 다시 저작했다. 얼굴을 닫는 포즈는 흰자와 홍채 영역만 수정한다. 전투 불능은 머리와 몸통을 개별 90도 회전하고 구부린 다리·배 위의 팔·떨어진 무기를 조합했다. 확대나 보간을 원본 셀에 적용하지 않는다.

캐릭터당 전투 포즈 20칸을 재작성했다. 걷기 3칸과 정면 1칸은 원본 패턴과 픽셀 단위로 같다. 미완성 기준선 포즈는 없다.

| 캐릭터 | 의상·장비 판단 | 추가색 수 |
|---|---|---:|
| actor4-2 | 금발·붉은 이마 장식·초록 바지, 검 | 5 |
| actor4-3 | 실제 원본의 파란 머리·검정 옷, 청록 수정 지팡이 | 2 |
| actor4-4 | 자주색 머리·붉은 목도리, 금빛 지팡이 | 3 |
| actor4-5 | 금발·갑옷·초록 어깨, 검과 작은 초록 방패 | 5 |
| actor4-6 | 검은 보라색 머리·푸른 체크 치마, 자수정 지팡이 | 3 |
| actor4-7 | 붉은 고깔모자·청록 머리, 붉은 보석 지팡이 | 3 |

`charsetSemantics.ts`의 actor4-3 설명은 보라 머리라고 되어 있으나 실제 시트는 파란 머리다. 도트는 실제 원본을 따른다.

## 재현

저장소 루트에서 다음 순서로 실행한다. Python 3와 Pillow가 필요하다. 작업 환경 Pillow 12.1.1에서 실행했다. `--manifest`는 사용하지 않는다.

```sh
python3 scripts/asset-gen/charset-battler/art/rpg-zzu-cb-art6/draw.py
python3 scripts/asset-gen/charset-battler/build.py actor4-2 actor4-3 actor4-4 actor4-5 actor4-6 actor4-7
python3 scripts/asset-gen/charset-battler/art/rpg-zzu-cb-art6/audit.py
```

`draw.py actor4-5`처럼 담당 캐릭터 일부만 다시 그릴 수도 있다. 다른 캐릭터나 공용 도구·manifest는 쓰지 않는다. 생성기는 저장소의 원본 Actor4.png만 읽으며 AI 생성 캐릭터 이미지를 참조하지 않는다.

## 검토와 증거

- 공용 `build.py`: 여섯 캐릭터 모두 **통과**, 종료 코드 0.
- `audit.json`: 144칸 모두 48×48, 알파 0/255, 마지막 불투명 행 정확히 y=44, 추가색 6색 이하. 시트는 144×384이며 24개 포즈 좌표가 원본 셀과 일치한다.
- 캐릭터마다 24포즈가 서로 다른 픽셀 데이터를 가진다. 걷기 3칸·정면 1칸은 각각 원본 왼쪽 0/1/2·아래 1과 정확히 일치한다.
- 여섯 명의 최종 `_board.png`와 `_motion.png`를 직접 열어 검토했다. `_motion_detail.png`는 같은 시퀀스를 다섯 줄로 나눠 4배 확대 검토하기 위한 추가판이다.
- `_motion.png`: 걷기 a→b→c→b, 공격 준비→중간→착탄→마무리, 마법 준비→들기→방출, 대기→피격→대기, 승리↔승리b를 한 줄에 배치했다. 각 셀은 nearest 4배이며 위쪽 20px은 포즈 이름표다.
- `_motion.gif`: 위와 같은 16칸, 192×212, 각 120ms. GIF 각 프레임과 동작 PNG 각 칸의 RGB를 비교해 순서와 색 손실 없음까지 확인했다.
- 시각 검토: 원본 머리/모자/목도리/치마의 정체성 유지. 공격은 뒤·위→앞·위→왼쪽 수평→왼쪽 아래로 이어지고, 앞발은 착탄 위치에 고정된다. 영창에서는 손을 모았다가 올리고 전방으로 방출한다. 방어는 몸 높이가 낮아지며 전투 불능은 머리를 오른쪽으로 둔다. 승리 두 칸은 팔 각도와 상체 높이가 달라진다.
- 검토 중 낮은 자세의 방패·지팡이 밑동·떨어진 검이 발 기준선을 넘던 문제와 감은 눈에 홍채가 남던 문제를 수정했다.

이 작업은 그림 파일과 개인 재현 스크립트만 변경한다. 런타임 화면 QA, 앱 타입 검사, 전체 테스트/게이트, 프로젝트 DB 저장, manifest 통합은 실행하지 않았다. 공용 도구는 변경하지 않았다.

# 버들항 소품 3/4 시점 재저작 지시서 (라운드 2)

너는 16px 손 도트 소품을 **원본 픽셀을 보존하면서** 탑다운 3/4 시점으로 고친다. 새로 처음부터 그리지 않는다 — 원본 그림이 이미 잘 그려져 있고, 문제는 **윗면(위에서 보이는 면)이 없다**는 것뿐이다.

## 시점 규칙 (사용자 판정, 어기면 반려)
- 3/4 탑다운: 앞면(정면)이 크게 보이고 **윗면이 짧게(앞면 높이의 약 1/3) 같이 보인다**. 정면 사진처럼 평면이면 안 된다.
- 좌우 대칭인 인공물은 비스듬히 돌리지 않는다. 광원은 왼쪽 위: 윗면 가장 밝음, 왼쪽 밝음, 오른쪽·아래 어두움.
- 윗면이 없는 것 = 위반. 예) 노점의 차양과 진열대는 위에서 보이는 면이 있어야 한다(차양 윗면은 줄무늬가 이어지는 경사면이 위쪽에 짧게, 진열대 윗면은 밝은 판자면).
- 옆모습으로 그린 나무(좁은 사이프러스)는 둥근 수관이 **위에서 내려다보인 모양**(수관 윗부분이 타원으로 보임)이어야 한다 — 같은 시트의 다른 나무(`REFERENCE-good-34.png`의 큰 나무·덤불)처럼.
- 기준이 되는 올바른 3/4 예는 `round2/REFERENCE-good-34.png` (벤치·수레·탁자·우물·나무). **반드시 Read 로 열어 보고** 윗면이 얼마나 보이는지 눈으로 익힌다.

## 규칙
- 팔레트: 원본 그림의 색만 쓴다(같은 시트의 색). 새 색을 만들지 않는다. 필요하면 원본 색을 한 단계 밝게/어둡게 고르는 정도(이미 쓰인 색 안에서).
- 외곽선은 그 재질의 가장 어두운 색(검정 금지). 1px 가느다란 선 남발 금지, 질감은 원본의 군집 결을 따른다.
- 크기는 16의 배수. 윗면을 더하느라 키가 커지면 위쪽에 16px(1칸) 단위로 늘린다. 투명 배경 PNG, 칸 가장자리가 잘리지 않게.
- 접지: 바닥에 닿는 부분은 원본의 맨 아래줄을 그대로 둔다(발이 바뀌면 안 된다). 원본이 땅에서 뜨지 않게.
- 스크립트(Python PIL)로 찍는다. 원본 PNG 는 `round1/existing-*.png`. 원본 파일을 덮어쓰지 않는다.

## 산출물
각 항목마다 `round2/<id>.png` (결과)와 `round2/<id>-compare.png` (왼쪽 원본 · 오른쪽 결과, **잔디 위 4배 확대**, 라벨 없이 그림만). 그 비교 그림을 **직접 Read 해서** 윗면이 보이는지, 원본과 같은 결인지, 기준 예(`REFERENCE-good-34.png`)와 나란히 놓아도 이질적이지 않은지 한 줄씩 판정하고, 마지막에 항목별 판정을 `round2/<네 이름>-verdict.md` 에 쓴다(PASS/수정함/못 고침과 이유). 통과율 숫자로 자기 평가하지 말고 눈으로 본 것을 쓴다. 못 고치겠으면 그대로 못 고쳤다고 쓴다 — 억지로 통과시키지 않는다.
- 저장소의 다른 파일은 건드리지 않는다. git 명령 금지. 테스트·게이트 실행 금지.

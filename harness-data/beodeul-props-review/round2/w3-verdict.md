# w3 판정 (눈으로 본 compare 그림 기준)

- out-hanging-sign (16x16): PASS. 쇠 막대 윗면(밝은 회색 띠)과 간판 판 윗 모서리 두께면(밝은 갈색 2줄)이 보인다. 칼 교차 그림·금 모서리·팔레트는 원본 그대로. 고리는 1줄로 짧아짐.
- out-signpost (16x32): PASS. 기둥 윗단면과 두 팻말의 윗면(밝은 줄)이 보인다. 글자 점·기둥 아랫부분·바닥 풀은 원본 유지. 두 팻말 사이 기둥이 원본보다 짧다.
- out-woodpile (32x32, 원본 32x16): 수정함. 위 통나무 3개의 둥근 윗면 몸통이 단면 원 위로 보이고 앞쪽 단면 원 쌓기는 원본 그대로 유지. 키가 커져 16px 한 칸을 위에 추가함. 한계: 아래 단의 바깥쪽 통나무 윗면은 따로 그리지 못함.
- gate-wood (32x16): 수정함. 기둥은 원본(울타리 연결칸과 같은 x=6..9, 22..25) 유지. 가로대에 밝은 윗면 줄을 넣었고 대각 버팀목은 간략화. fence-wood-set의 가로대(3줄)보다 한 줄 굵다.
- tree-eef4bc / tree-28ad5e / tree-c27062 (16x48): 수정함. 원본 색만 사용, 폭 16·높이 48 유지, 옆모습 대신 위가 밝은 타원 수관 + 층층이 밝은 윗가장자리 + 줄기. 한계: 원본보다 조금 뭉툭하고 층 구분이 규칙적이다. 기준 큰 나무보다는 단순하다.
- mpart-cypress-tub (16x48): 수정함. 수관은 위와 같은 방식, 통은 윗면(어두운 흙 + 밝은 테두리)이 보이고 앞면 쇠띠 2개는 원본 색 그대로. 한계: 통 앞면 높이가 원본 11행에서 9행으로 줄었다.

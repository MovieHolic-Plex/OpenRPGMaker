# w2 판정 (compare 그림 4배 확대를 Read 로 직접 보고 작성)

크기는 전부 원본과 같음(32x32 x4, 16x32, 16x16). 빈 윗칸에 윗면을 넣어 키울 필요가 없었다. 팔레트는 같은 시트의 기존 색만 사용.

- anchor_display: 수정함. 받침 윗면(밝은 판자면 2줄 + 뒤 모서리 어두운 선)을 추가하고, 닻·밧줄을 1px 위로 올려 닻 축이 윗면 안에 서 있게 했다. 받침 앞면과 맨 아랫줄·그림자는 원본 그대로. 닻 주조·밧줄 결은 원본과 같다. 다만 닻 전체가 원본 대비 위로 1px 이동했다.
- net_rack: PASS. 맨 위 가로대 윗면(밝은 면 2줄 + 뒤 외곽선)과 기둥 윗단면이 보인다. 그물·접지 원본 그대로. 기준 예의 노점 윗판과 같은 결.
- cloth_stand: PASS. 가로대 윗면이 3줄(뒤 외곽선 + 밝은 2줄, 오른쪽 한 단계 어둡게)로 보인다. 천·기둥·접지 원본 그대로. 윗면이 다소 넓어 상판 같은 인상이지만 이질적이지 않다.
- laundry_rack: PASS. 얇은 빨랫줄 가로대에 윗면 2줄, 기둥은 윗단면 2x2가 보인다. 가로대가 원본보다 두꺼워 보이는 부작용이 약간 있다. 천·접지 원본 그대로.
- bread_rack: 수정함(약함). 각 선반판 뒤에 윗면(밝은 판 2줄 + 뒤 외곽선)을 넣고 빵을 1px 올려 윗면 위에 놓이게 했다. 기둥 윗단면 추가. 왼쪽 기둥이 빵에 가려진 부분은 기둥 색으로 재구성했다. 윗면은 보이나 폭이 좁고 빵과 겹쳐 다소 빽빽하다. 왼쪽 기둥 재구성부는 원본 픽셀이 아니다.
- sandwich_board: 수정함(약함). 판 윗 모서리 두께면을 2줄(뒤 외곽선 + 밝은 면) 추가했다. 16x16 안에 남은 위쪽 여백이 2줄뿐이라 윗면이 얇고, 작은 뚜껑처럼 보인다. 앞면 칠판·접지 원본 그대로.

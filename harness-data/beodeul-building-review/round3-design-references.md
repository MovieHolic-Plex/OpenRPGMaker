# 추가 후보의 용도·지붕·간판 설계 근거

사용자 2026-10-05: UI가 불편하고 건물이 뻔함. 간판과 지붕을 바꾸며 다른 게임을 조사해 참고할 것. 기존 4개 Allow를 보존하고 다른 형태 10개를 추가한다. 사람 검수와 기존 적대적 Visual QA는 유지한다.

## 조사한 자료

- Final Fantasy 공식 설명서(닌텐도 공개): https://www.nintendo.co.jp/clv/manuals/en/pdf/CLV-P-NABJE_en.pdf — p6~7 마을 시설과 검/방패/여관 등의 작은 표식. 용도 이름을 읽기 전에 그림 기호로 기능을 찾게 한다.
- Stardew Valley 피에르 상점: https://wiki.stardewvalley.net/Pierre%27s_General_Store — 출입구 옆 게시판·가족 주거와 가게의 결합. 상점과 주택의 공간 관계를 외관에도 표현하는 설계 참고.
- Stardew Valley 대장간: https://stardewvalleywiki.com/Blacksmith — 문 오른쪽 진열 선반의 광물 같은 용도 소품. 본체 외에 작은 물건도 용도 표식이다.
- Chrono Trigger 실제 게임 장면 모음: https://rpg.retropixel.net/chronotrigger/images.html — Lucca/Melchior 장면은 실내 참고이며 외관 지붕 표본이라고 주장하지 않는다. 기계/작업대/물건 배치로 직업을 읽히게 한다.
- Secret of Mana 실제 장면: https://rpg.retropixel.net/mana/images/ — Kakkara/Todo 장면을 브라우저에서 직접 열었다. Kakkara의 둥근 옅은 지붕과 탑 모양 몸체, INN 작은 간판 등 실루엣과 시설 표식이 구분된다.

게임 장면의 도트를 추출하거나 재배포 자산으로 쓰지 않는다. 화면 확인은 output의 브라우저 캡처로 남겼고 저장소에 게임 스크린샷을 커밋하지 않는다. 아래 후보는 기존 버들항 원본 부품·선택한 팔레트 변환·독자적인 간판 격자를 쓴다. 게임에서 본 설계 차이를 버들항 표현으로 번역한 것이며, 동일 그림의 복제가 아니다.

## 10개 설계

| 후보 | 실루엣 | 지붕 | 표식 |
|---|---|---|---|
| r3-01 여관 | T자 돌출 현관 | 붉은 기와 | 침대 |
| r3-02 여관 | 쌍박공·후면 연결 | 황동색 박공 + 원본 뒤채 | 열쇠 |
| r3-03 빵집 | 깊은 기와 차양·기둥·마루 | 원본 기와 | 빵 |
| r3-04 약방 | 높은 본채 + 낮은 옆채 | 올리브색, 명암 유지 | 물약 |
| r3-05 마법사 | 푸른 첨탑 + 낮은 석조 박공 | 높이·색이 다른 두 지붕 | 책 |
| r3-06 회관 | 넓은 박공 + 긴 이층 옆채 | 원본 기와 | 저울 |
| r3-07 큰 여관 | 두 날개 + 넓은 안마당 | 원본 쌍박공 | 침대 |
| r3-08 무기점 | 낮은 점포 + 높은 주거동 | 청회색 높은 박공 | 방패 |
| r3-09 제분소 | 둥근 탑 몸체 | 원본 원뿔 기와 | 곡물 자루 |
| r3-10 서점 | 낮은 좁은 박공 + 넓은 본채 | 황동색 넓은 지붕 | 깃펜 |

원뿔 탑도 원본 픽셀이며 측면을 새로 강요하지 않는다. 원본 3/4 시점, 입구 하나, 단일 벽 재질을 따른다. 간판은 출입구를 가리지 않게 16×24 격자에서 아이콘 8×8로 저작했다. 받침 목재·철 지지대·나뭇결과 명암은 명시한 행 문자열로 남긴다.

`round3-detail-sources.json`에 원본 조립 레시피, 간판 전체 행/팔레트/좌표, 지붕 팔레트 사전과 변경 좌표를 저장한다. 지붕 색을 변경해도 기와의 좌표·윤곽·입자 해상도를 유지한다. 올리브/황동의 별도 변환은 원본 픽셀의 명도값을 유지하는 색상표 변환이며 신규 도트 질감을 절차적으로 그리지 않는다. 재현기는 이 최종 색상표와 좌표를 읽는다.

현재 public의 review-* PNG는 **후보 소스**이며 공용 런타임 번들/기본 타일셋에 등록하지 않는다. 사용자 Allow 후에 원본 출처와 함께 공용 번들·참고문서·새/기존 프로젝트 배선을 한다. 기존 승인 4개의 그림/레시피/해시/선택은 이번 추가 작업에서 바꾸지 않는다.

## 실제 검수에 따른 수정

첫 질감 검사가 제분소의 둥근 갈색 지붕(roof_grain 55), 큰 회색 기초(wall_grain 88)를 반려했다. 원본에 있던 그림도 면제하지 않는다. 원본 저택 탑의 원뿔 기와로 교체하고, 회색 기초의 선택 좌표에 원본 석재 입자를 옮겼다. 다시 전체 검사를 통과해야 공개한다.

두 번째 질감 검사는 약방/서점의 색상 마스크 경계(89/90), 제분소 원뿔 지붕의 큰 기와 입자(82)를 잡았다. 두 지붕의 팔레트 영역을 완전히 연결하고, 제분소 원뿔 내부의 선택 행 구간에 원본 민가의 촘촘한 기와를 1:1 좌표로 옮겼다. 오른쪽 면의 선택 하이라이트 5픽셀은 기존 기와 음영색으로 낮췄다. 이 좌표 전송과 색 편집도 출처 JSON에 남겨 재현한다.

구조 검사에서 서점의 뒤채 문(앞채와 별개)이 남은 것을 실제 그림으로 찾아냈다. 원래 뒤채 부품의 문은 조립 결과 (80,96)이므로 이 16×32 전체를 원본 창으로 교체했다. 앞채 (16,96)의 문만 남긴다.

완료된 20종 구조 검사에서 18종이 통과했고 빵집의 가려진 문(79), 약방 옆채의 배경 틈(roof_joints 78)이 반려됐다. 빵집은 차양 밖의 왼쪽 문 (16,64,16,32)으로 옮기고, 중앙의 남은 문 조각은 원본 창 아래 조각으로 대체했다. 약방은 옆채를 완전히 불투명한 원본 벽/창 영역으로 이어 한 픽셀 틈을 닫았다. 수정한 2종의 그림/레시피는 새 검사 대상이며, 동일한 다른 묶음은 서명된 실제 판정·이미지·로그가 일치할 때만 이어간다.

옆채 교체 후에도 원본 본채 끝의 x78~79, y64~95에 투명 2열이 남았다. 실제 알파 배열을 확인하여 원본 목재 기둥 픽셀 64개로 메웠고, x77~82 전32행이 불투명한지 확인했다. 별개로 검수자 한 회차가 중복 문 대조군의 single_door를 잘못 통과시켜 보정 검사 자체가 실패했다. 이 판정은 공개에 쓰지 않는다. 수정된 실제 그림은 새 이미지 해시로 다시 검수한다.

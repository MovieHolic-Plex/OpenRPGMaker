### 산 mountain

#### M12. [중] 맵 네 변이 모두 열려 있다 — 출입구가 없고 어디로든 걸어 나간다
- **위치**
  - 위 끝 (0..21,0) 전부.
  - 아래 끝 (0..21,16) 전부.
  - 왼 끝 (0,3..5)·(0,8..9)·(0,12..16).
  - 오른 끝 (21,3..5)·(21,8..9)·(21,12..16).
- **그림:** `qa-l6/m_edges.png`(열린 경계 칸을 빨간 상자로 표시), `m_tl.png`·`m_bl.png`·`m_br.png`
- **문제**
  - 세 단의 옆 사선 벼랑 사슬이 모두 맵 왼·오른 끝에서 그대로 잘린다. 단마다 바닥이 맵 밖으로 열려 있다.
  - 위·아래 끝은 22칸 전체가 맨땅이다.
  - 그 결과 「어디가 길이고 어디로 나가는가」가 읽히지 않는다.
  - 다른 견본 맵 넷(숲·늪·정원·강)은 모두 숲벽이 맵을 감싸고 출구를 2칸 틈으로 둔다. 같은 시트에서 산만 문법이 다르다.
- **원작 근거**
  - R112·R114 산지는 맵 테두리를 벼랑 벽이나 나무 줄로 닫는다. 출구는 길 폭 틈으로 정해져 있다(L5 `qa-l5/m_vs_r112.png`·`m_vs_r114.png` 왼쪽 끝 벼랑·나무).
  - 채점표 「원작 배치 문법(벽 두께·출입구)」.
- **고침**
  - 왼·오른 끝 열(x0, x21)을 바위 벼랑 옆면이나 침엽수 줄로 닫는다. 침엽수는 N2 를 고친 본 시트 `pine_a` 를 쓴다.
  - 출구를 정해서 남긴다.
    - 꼭대기 단 위 끝은 표지판 (10,1) 앞 2칸 (10..11,0) 만 연다.
    - 맨 아래 단은 2~3칸 틈 하나만 연다. 예를 들어 표지판 (13,15) 아래 (12..13,16).
  - 나머지 위·아래 끝은 침엽수 줄이나 벼랑 윗면 테로 막는다.

#### N2. [중] 침엽수가 본 시트 침엽수 `pine_a` 와 다른 그림이다
- **위치:** (3..4,0..1)·(7..8,0..1)·(16..17,0..1)·(19..20,0..1)·(0..1,2..4) 의 침엽수 5그루. 시트 `conifer.*`.
- **그림:** `qa-l6/pines.png`
  - 왼쪽부터 w111 시트에 물려받은 본 시트 `pine_a`, 야생 `conifer`, 옛 본 시트 d32 `pine_a`(참고), `tree_a` 두 벌.
- **문제**
  - 본 시트 `pine_a` 는 넓은 3단 치마다. 단 밑마다 짙은 선반 그늘이 한 줄씩 매끈하게 들어가고, 발밑 그림자는 풀색 타원이다.
  - 야생 `conifer` 는 좁은 4단 톱니다. 단 끝이 4px 주기 톱니로 늘어지고, 꼭대기가 더 길고 가늘며, 발밑 그림자는 흙색이다.
  - 같은 「침엽수」인데 실루엣·단 수·단 끝이 다르다.
  - 원인 코드: `monster_wild.py:152` 의 `wm.conifer(PC, …)` 가 수관을 새로 그린다. 본 시트 `trees.pine_tiered` 를 쓰지 않는다.
  - REGIONS 2-1 정본 표의 「나무 = 본 시트」를 어긴다.
  - 같은 시트 안에 `pine_a` 가 이미 물려받아져 있는데도 쓰지 않는다.
- **원작 근거:** 같은 게임의 도로·산 침엽수는 한 그림이다. RSE 의 산과 도로 나무는 같은 메타타일이다.
- **고침**
  - 산 맵 침엽수를 `pine_a.*` 로 바꾼다. 흙 바닥용 발밑 그림자만 색 인자(바닥 최암 톤)로 준다.
  - `wm.conifer` 는 지운다.

## 검수 범위와 확인한 사실

- **본 그림이 맞는지**: 맵 PNG 8장은 04:25~04:32 에 만들어졌고, bake.log 의 c93·k93 와 시각이 같다. 3배 PNG 를 1배로 줄여서 봤다.
  `qa_lib` 의 run 표는 c93·k93·d92·w191·u95·r97·g96 으로 바꿨다(`lib.py`).
- **맵 전체 확대**: 8맵을 반씩 잘라 4배로 키우고 분홍 16px 격자와 칸 번호를 넣었다(`q_<맵>_<j><i>.png` 26장). 모든 칸을 한 번씩 봤다.
- **I1 → I2 에서 바뀐 칸** (`diff.py`, RGBA 전체 비교):
  - 해안 30칸: tree_a·tree_b 12(+새 4), mart 2, searock·searock_big·searock_big_m·rockmass 16.
  - 기후 443칸 + 새 262칸: 벼랑 4벌 전부(윗면 47 + 앞면 47 + 속 변형 + 돌계단 2×2), sforest 48, spine_a, atree_a(2×3 → 2×4), 눈 지붕 집 3종, ash 4, aforest 36, 온천·모래찜질·재 길 오토타일.
  - **주의**: PIL `getbbox()` 는 RGBA 에서 알파만 본다. 처음에 이것 때문에 「안 바뀌었다」로 잘못 나왔다. `alpha_only=False` 로 다시 쟀다.
- **같은 이름 칸의 바이트 대조**: 해안·본 시트 1080칸, 해안·야생 223칸, 기후·본 시트 336칸, 기후·야생 19칸이 모두 차이 0 이다.
- **정본 대조**는 알파 일치율·같은 자리 색 대응률로 쟀다.
  - 해안 tree_a/b = 본 tree_a/b(바이트) = 야생 forest_o(tree_a 바이트 / tree_b 는 거울 변형).
  - 기후 atree_a ↔ forest_o: 색 대응 0.94. spine_a ↔ pine_a: 알파 1.00, 색 대응 0.79.
  - dface/vface ↔ 야생 gface: 색 대응 평균 0.97. dcliff/vcliff ↔ cliffg: 0.85.
  - aforest_c ↔ forest_c: 1.00. ice_rock·ice_at ↔ 던전: 바이트 같음.
  - snow_pile ↔ ic_drift, steam_vent ↔ lv_vent: 1.00. ruin_pillar ↔ ru_pillar: 0.88. palm_a ↔ palm: 바이트 같음.
- **물체 온전성 검사** (`objcheck.py`): 맵마다 `이름.x.y` 물체의 원점을 구해, 모든 조각이 제자리에 있는지 셌다. 숲 벽은 뺐다.

  - 서로 다른 물체가 한 칸에 겹친 곳은 8맵 모두 0 이다.
- **통행 겹침**(`pass_<맵>.png`): 빨강은 막힘, 초록은 열림, 파랑은 얼음, 주황은 턱이다. 원 크기 맵 위에 겹쳐서 봤다.
  - 벼랑 앞면은 막혀 있다. 돌계단·문·잔교는 열려 있다. 얼음 판은 미끄럼, 얼음 바위는 막힘이다. 턱 방향은 아래다.
  - 얼음 고원 윗면은 전부 막힘이다. 그러나 오를 계단이 없는 둔덕이라 문법에 어긋나지 않는다.

  - 사막 앞면은 낱칸을 3×3 으로 깔면 격자로 보인다. 맵에서는 열 해시로 변형을 섞어 격자가 보이지 않는다(`q_desert_*`).

## 지적

#### Y1. [치명] 해안 port 의 외톨이 나무 윗줄이 숲 벽 칸에 지워져, 수관 위가 평평하게 잘렸다
- **위치**: port tree_b 는 원점 (8,2)이고 2×4 다. 윗줄 (8,2)·(9,2) 에 tree_b.0.0·1.0 대신 forest_br.0.2·1.2 가 깔려 있다.
- **그림**: `y_tree_cut8.png` 왼쪽(맵) · 가운데(온전한 tree_b), `q_port_00.png`
- **문제**:
  - 나무 그림이 2×3 → 2×4 로 커지면서 수관 꼭대기가 (8–9,2) 줄로 올라갔다. 그런데 그 줄은 북쪽 숲 벽의 밑동 줄이 그대로 차지한다.
  - 그래서 수관이 3행 위 경계에서 칼로 자른 듯 수평으로 끝난다. 1배에서는 둥근 나무가 아니라 **네모난 산울타리·덤불**로 읽힌다.
  - 물체 조각이 다른 물체에 지워졌으니 채점표 기준 [치명]이다.
  - 해안 커밋(872369a2)의 「port·city 나머지 나무는 새 크기로 겹침 0 확인」은 사실이 아니다.
- **원작 근거**: 원작 외톨이 나무는 수관이 한 칸도 잘리지 않는다. 숲 벽 아래 줄과 떨어지거나, 벽에서 튀어나온 그루로 그려진다.
- **고침**(둘 중 하나):
  - (a) 원점을 (8,3) 으로 내려 (8–9,3–6) 에 온전히 놓는다. 그 자리의 꽃밭 (8–9,6) 은 (8–9,7) 로 옮기고, 흰 꽃 둘은 지운다. 표지판 (8,8) 은 그대로 둔다.
  - (b) 이 나무를 빼고 (8–9,3–5) 를 풀·꽃으로 채운다.
  - 어느 쪽이든 `objcheck.py` 처럼 「물체 조각이 모두 제자리에 있는가」를 쇼케이스 검사(`k.check`)에 넣어 다시 새지 않게 한다.

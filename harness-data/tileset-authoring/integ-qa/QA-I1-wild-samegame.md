# 통합 검수 I1 — 야생 시트 monster-wild 전체 + 7장 「같은 게임」 대조표

- **대상:** `public/assets/monster-kit/monster-*.png` 7장. 7장 모두 `qa-runs/.../<시트>/<run>/candidate.png` 과 바이트가 같다(cmp 확인). run 은 본 시트 d90 · 해안 c90 · 기후 k91 · 던전 u94 · 실내 r93 · 체육관 g95 · 야생 w190.
  - 야생 맵 5장: `/tmp/viz/monster-wild/{forest_maze,mountain,swamp,garden,river}.png`(03:42, 3배)
  - 다른 시트 맵: `/tmp/viz/monster-*/<맵>.png`, 본 시트는 `/tmp/viz/{town_b,route_b,cave_map,room_*}.png`(03:40)
  - 칸 이름은 각 run 의 `tiles.json`, 맵의 칸 배치는 `bake/verify-<맵>.json` 에서 읽었다.
- **근거로 쓰지 않은 것:** 검사 통과, 작업자 보고, 지난 점수(QA-L9). 아래 판정은 모두 내가 직접 확대해 본 그림에 근거한다.
- **기계 대조(보조):**
  - 7장에 같은 이름으로 들어간 칸 1,564개를 시트끼리 바이트로 대조했다. 다른 칸은 **0개**다.
  - 그래서 「같음」인지 「다름」인지는 **이름이 다른 짝**에서만 갈린다. 이 짝들은 바이트가 같은지 보고, 바이트가 다르면 「색만 바꾼 같은 그림인가」(같은 자리 픽셀끼리 색이 1:1 로 대응하는가)를 쟀다. 그다음 모두 눈으로 확인했다.
- **확대 그림:** 1배로 되돌린 뒤 4~8배로 키우고 분홍 16px 격자를 그었다.
  - 야생: `/tmp/viz/integ/wild/` — `m_tl/tr/bl/br`, `forest_maze_00..22`, `swamp_00..11`, `garden_00..11`, `river_00..21`(4배 칸 번호), `vs_<맵>.png`(같은 배율 원작 R112·Petalburg·R120·R123·R119 나란히), `tile3x3.png`
  - 대조표: `/tmp/viz/integ/same-game/<물체>.png` — 물체 하나당 한 장이다. 윗줄은 시트마다 한 칸(4배, 없는 시트는 「(없음)」), 아랫줄은 각 시트 맵에서 그 칸이 쓰인 자리다.
- **좌표:** 칸 (x,y), 0부터 센다.

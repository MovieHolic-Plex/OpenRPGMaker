## 열람 범위와 근거

- 증거 기준 경로: `verify-shots/tileset-i6/`. 현재 공용 번들의 run을 읽어 생성했다.
- 정상 견본 54장의 원 크기·2배 모음과 모든 맵의 4배 분홍 격자 조각 14장을 직접 열람했다. 오류 예시는 정상 맵 점수에 포함하지 않았다.
- 구조 킷 437개를 모두 조립했다. 사용 중인 낱칸 소품·장치도 추가하고 같은 픽셀 조립을 합친 422개 그림을 4배 모음 36장에서 열람했다. 물체별 읽힘은 `QA-I6-objects.md`.
- 바닥·고원 윗면·앞면·액체의 607개 반복 그림(픽셀 중복 제거 397개)을 3×3 이어 붙여 4배 모음 17장에서 열람했다. 실내 줄눈·판자·다다미의 규칙 무늬와 벽 밑 그늘 변형은 용도가 있는 반복이다. 자연 바닥은 여러 속 변형을 섞은 정상 맵도 같이 판단했다.
- 같은 이름 칸 대조: 7시트의 21쌍, 중복 포함 2,609칸 대조에서 다른 픽셀 0건. 색만 다른 눈·재·사막 재료는 물체·반복 모음으로 형태와 빛 방향을 비교했다. 이 수치는 시각 점수의 근거를 대신하지 않는다.
- GBA 비례 대조: 미로마을(Oldale), 잿빛마을(Fallarbor), Slateport, Magma Hideout 4F, Birch Lab, Lavaridge Gym 1F, Route 114를 같은 16px 칸 크기로 나란히 열람했다. 임시 대조 그림 `/tmp/viz/tileset-i6-study/`는 학습 전용이며 저장소에 넣지 않는다.
- `manifest.json`의 `changed_cells`는 칸 이름의 차이, `changed_render_pixels`는 최종 RGBA 픽셀 차이이다. 바다굴은 칸 이름이 그대로여도 5,322픽셀이 바뀌었으므로 수정 누락으로 오인하지 않는다.

## 남은 경미한 한계

- 고원 어깨는 연결을 우선하는 각진 픽셀이 일부 남는다. 재료가 떨어지거나 바닥으로 오독되는 쐐기는 없다.
- 용암 물결은 유한한 변형이다. 같은 칸을 연속 반복하면 자국 반복이 보이므로 정상 견본처럼 곧은 변 세 벌과 속 변형을 섞는다.
- 건물과 일부 소품의 그림은 단순화되어 있다. 원작과 같은 세부 밀도·완성도 9~10점이라는 판정은 아니다.
- 캡슐·체육관 장치는 이벤트를 올릴 타일 자리다. 아이템 획득·체육관 진행 이벤트를 새로 작성한 결과로 설명하지 않는다.

## 제작 단계 확인

- `integ.sh`의 I6 draw → bake → showcase → wire → wire_check: 종료 0. 파이프 실패를 숨기지 않도록 `set -euo pipefail`을 적용했다.
- 본 시트 제작용 통행 확인 337건, 실패 0. 새 마을은 실제 엔진 `canMove`로 네 문·남북 출구·화단 도달을 확인했다.
- 공용 배선 확인: 7시트의 그림·칸 수·타일셋 정의·참고문서·새/기존 프로젝트 심기·저자 자료 보존을 기존 제작 도구로 확인했다.
- 마지막 배선 점검에서 체육관의 용암 가장자리 변형도 `connectTiles`에 등록했다. 해당 시트의 bake·showcase·wire와 7시트 배선 확인을 다시 완료했다. 시트·정상 견본 픽셀 해시는 검수 증거와 현재 공용 번들이 모두 일치한다.
- 진행 페이지의 전체 54견본 → 기후 4견본 필터 → 확대 대화상자·배율 → 전체 복귀를 실제 브라우저에서 확인했고 페이지 오류는 없었다. `progress-page.png`, `progress-page-check.json`.
- 전체 gates·Vitest·typecheck는 실행하지 않았다. 이 보고는 공용 타일 제작·배선·시각 품질 범위의 결과이다.

# c03 (large two-storey half-timber house with hip roof and gabled entrance porch)

A (3/4 view): The main hip roof is a large real surface. The south-projecting entrance gable roof shows its own two slopes and ridge and joins the main roof. Only the south facade is visible. The wings and porch read as one building with no ground between them.
B (structure): No transparent holes. The bottom edge meets the ground along the whole facade and the porch. There is exactly one door (in the porch). A lantern is a small bracket on the porch. Nothing is cut off. There is a dim shadow wedge beside the porch roof, but it reads as shading, not a hole.
C (style): The roof has varied tile courses with lit and shaded zones. The timber and braces are in a brown tone, not black. The plaster is a large light area with light stipple, similar to the Beodeul reference. The windows have flower boxes in the same style. Colours harmonise. The windows in the wings are evenly spaced, which looks slightly repetitive but not an obvious stamp.

MAJOR: none
VERDICT: PASS

# 자세 순서와 유지 의도

여기의 유지 길이는 연출 의도다. 제작 GIF의 실제 프레임 시간은 하네스가 공급하며, 이 문서는 런타임 전투 타이밍을 검증한 근거가 아니다. 제공된 대기 기준은 프레임당 240ms다.

| 묶음 | GIF 자세 순서 | 유지 의도 |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 각 240ms 기준, 소매·손·검끝과 머리 끝의 미세한 호흡 |
| 공격 | idle_a → windup → move → attack → recover → idle_a | 준비를 읽을 한 박자, 이동·베기는 짧게, 회수는 베기보다 길게 |
| 피격 | idle_a → hit → recover → idle_a | 움찔은 짧게, 체중을 되찾는 회수는 한 박자 |
| 쓰러짐 | hit → dead | 쓰러진 마지막 자세 유지, 눈은 닫힘 |
| 청룡검기 | idle_a → skill_a → skill_b → skill_c → idle_a | 응축을 길게, 접촉을 가장 짧게, 끊어지는 회수를 중간 길이로 |
| 독 | poison_a → poison_b → poison_a | 두 자세를 비슷한 길이로 유지, 두 번째에서 더 깊게 굽힘 |
| 기절 | stun_a → stun_b → stun_a | 처진 몸을 두 박자로 유지, 별의 높이·간격이 바뀜 |
| 수면 | sleep_a → sleep_b → sleep_a | 상태 중 가장 느린 호흡, 두 자세 모두 눈을 감음 |

## 청룡검기 실제 고정점

좌표는 0부터 시작하는 원본 픽셀이다. 효과는 입에서 나오지 않는다.

- **skill_a / 응축:** 오른 검손 피부 군집은 x38..41, y33..35, 금색 코등이는 x37..43, y34..36 부근이다. 검날을 앞쪽 위로 세우며 x41..47, y25..34의 옥청 기운이 실제 검끝과 손의 연장에 붙는다. 검결인 손은 x32..36, y37..40에 올라와 작은 응축 군집에 닿는다.
- **skill_b / 접촉:** 뻗은 오른손은 x40..45, y32..34, 코등이는 x44..46, y32..35다. 검날의 밝은 면은 x46..54, y33..34를 지나 오른쪽으로 이어진다. 두 옥청 줄기는 y17..35에서 위쪽으로 굽고, 아래 줄기는 y35..41에서 둥글게 되감긴다. 짧은 금빛 핵은 x51..53, y33이며 검날과 같은 접촉 높이에 있다. 검결인 손은 x22..29, y36..38에서 몸 앞을 받친다.
- **skill_c / 회수:** 검손은 x31..37, y38..40, 코등이는 x36..39, y38..40이다. 낮아진 검은 x38, y40에서 x58, y50까지 이어진다. 남은 기운은 검날 중간 x46..53, y45..48에 감겼다가, x54..59, y32..40의 끊긴 군집으로 가늘어진다. 몸·옆자락·손도 회수 자세로 별도 저작되어 있다.

효과 세 단계는 같은 고리를 확대하거나 이동한 것이 아니다. 응축의 짧은 굽이, 접촉의 긴 두 갈래와 아래 되감김, 회수의 끊어진 잔광을 각 원본 행에 따로 지정했다.

# 백의 검선 — 직접 픽셀 저작

## 보존한 원본

중단 시점의 팔레트 18색, 기본 9자세와 청룡검기 3자세를 보존했다. 기존 `progress/idle.png`와 얼굴 확대를 먼저 확인하고 이어서 작업했다. 최종 원본은 `poses/*.pxgrid`와 `actions/*.pxgrid`의 64×64 ASCII 행이다. 저작 스크립트의 중간 단계는 승인 기록이 아니다.

반묶은 풍성한 흑발, 작은 금·옥 관식, 미백 겉도포와 청록 안감, 넓은 금테, 옥 매듭, 짧은 어두운 허리 소품과 분리된 신발이 정체성이다. 서 있는 대기 자세는 머리부터 발끝까지 52px이며 머리는 약 19px 폭이다. 두 눈과 별도 눈썹은 앞볼 쪽에 있고 코와 시선은 오른쪽을 향한다. 참고 그림은 관찰만 했다.

## 이번에 직접 추가한 군집

- `poison_a`: 허리와 목을 앞으로 굽히고, 검결인 손을 배에 붙였다. 좁아진 눈꺼풀과 굳은 입, 좌상단의 열린 기포와 오른쪽의 작은 기포를 각각 ASCII 행에 지정했다.
- `poison_b`: 더 낮은 머리, 앞으로 처지는 어깨, 굽은 두 무릎과 달라진 소매·앞자락을 그렸다. 눈을 더 감고 입을 눌렀다. 기포는 머리 오른쪽과 허리 왼쪽에 새 모양으로 그렸다.
- `stun_a`: 어깨를 낮추고 검손을 허리 아래로 늘어뜨렸다. 눈은 열고 입은 작은 피부색 내부를 가진 갈색 틈으로 벌렸다. 머리 양쪽에 금빛 십자 별을 직접 그렸다.
- `stun_b`: 머리를 더 숙이고 무릎을 굽혔다. 팔꿈치·검손·금띠·옷의 접힘을 새 행으로 지정했다. 별 두 개는 다른 높이와 간격에 각각 그렸다.
- `sleep_a`: 두 눈의 갈색 닫힌 눈꺼풀, 낮춘 검, 배 위에 쉬는 손과 긴 차분한 옷자락을 그렸다.
- `sleep_b`: 앞으로 기운 머리, 조금 넓어진 가슴 소매, 바뀐 손·검 경사와 무릎 접힘으로 두 번째 호흡 상태를 그렸다. 두 눈은 계속 닫혀 있다.
- 독 두 자세와 깊은 기절 자세의 왼쪽 신발을 별도 행으로 마무리해 양쪽 밑창을 y=60에 붙였다.

머리카락은 K/H/M/L의 연결된 어두운 면, 천은 W/V/C/B의 넓은 밝은 면, 청록은 T/J/A, 금테는 G/Y, 피부는 S/P/R, 검과 기운의 밝은 핵은 I/E로 구분한다. 새 색이나 전면 색조 변경은 없다. 전신 이동·회전·보간, 도형 채우기, 자동 음영과 이미지 생성은 쓰지 않았다. `status_author.py`는 직접 적은 행과 투명 여백만 저장한다.

## 확인과 남은 시각적 한계

18개 원본을 그대로 PNG로 해독해 native 1×와 최근접 3× 전체판, 상태 8×판, 얼굴·쓰러짐·검기 확대를 직접 열었다. 64행×64열, 18색 공유, 투명 가장자리와 y≤60을 해독 과정에서 확인했다. 모든 프레임은 서로 다르며 idle_a 밑창은 y=60이다. `progress/contact.png`가 전체 확인판이다.

독의 찡그림과 수면의 감긴 눈은 원본에서 2~3px 눈꺼풀로 표현되어 작은 표시 크기에서는 비슷하게 읽힐 수 있다. 기절의 열린 입도 작은 점 크기다. 긴 도포가 무릎 관절을 일부 가리며, 검기 접촉 자세는 효과가 얼굴보다 먼저 읽힌다. GIF의 연결감은 후속 실제 렌더링과 독립 검수에서 판단해야 한다. 사용자 선택이나 승인을 받은 후보로 주장하지 않는다.

## 2026-10-05 — QUALITY_REPAIR.md의 두 칸 보수

위의 초안 저작 기록은 그대로 보존했다. 이번 작업은 지정된 투명 결손만 보수했다. 첨부된 네 참고 이미지와 현재 격자를 읽었고, 참고 이미지의 픽셀은 추출하거나 원본으로 사용하지 않았다.

- `poses/dead.pxgrid`, 0부터 시작하는 좌표 `(24,50)`: `.` → `P` (`#d7a078`). 기존 턱 아래 피부 그림자가 목으로 이어지도록 직접 선택했다.
- 같은 격자의 `(25,50)`: `.` → `B` (`#718f90`). 피부 옆에서 밝은 도포로 내려가는 옷깃의 어두운 접힘을 연결했다.
- y=50의 x=23..27은 `K..KK`에서 `KPBKK`로 바뀌었다. 이 두 칸 이외의 원본 픽셀과 줄바꿈은 모두 보존했다.

`repair_neck.py`는 위 두 좌표와 두 기호만 기록하는 작은 보수 도구다. 기존 `author.py`, `status_author.py`, `inspect.py`는 수정하거나 실행하지 않았다. 팔레트와 나머지 17개 격자는 작업 전후 바이트가 같다. 전후 해시와 실제 두 픽셀 차이는 `progress/repair/repair-record.json`에 남겼다. 64×64 캔버스, 투명 가장자리, y≤60과 idle_a의 y=60 밑창에는 변화가 없다.

18개 격자를 직접 팔레트로 해독한 원본 크기 PNG, 전체 1×/3× 확인판 `progress/repair/suite.png`, 쓰러짐 전후 8× 확인판 `progress/repair/dead-comparison.png`를 저장하고 두 확인판을 직접 열었다. 확대는 최근접 표시용 사본이며 원본 픽셀 저작에 사용하지 않았다. 쓰러짐의 목·옷깃 사이 두 투명 칸이 색으로 연결된 것을 확인했다.

남은 시각적 한계는 기존 초안과 같다. 작은 눈꺼풀 때문에 독과 수면의 표정 차이가 약하고, 긴 도포가 무릎을 가리며, 검기의 밝은 효과가 얼굴보다 강하게 읽힌다. 이번 보수에서는 이 부분을 재저작하지 않았다. GIF나 런타임은 실행하지 않았고 테스트·게이트도 실행하지 않았다. 이 기록은 사용자 승인, Modify 선택 또는 검수 의견의 자동 재시도 기록이 아니다.

# 금갑 무장 — baram-wuxia-v1

## 원본과 실루엣

- 독창적인 중년 남성 정예 무장. 관찰한 검객의 성인 SD 비례를 기준으로 낮은 금투구, 뒤로 묶인 짙은 붉은 술, 노출된 우향 3/4 얼굴과 작은 콧수염을 직접 저작했다.
- 원본은 `poses/` 9개와 `actions/` 9개의 64×64 ASCII pxgrid. `palette.json`의 18색을 공유한다. 점은 투명이며 팔레트에 없다.
- 대기 자세는 술의 y8부터 신발 바닥 y60까지 53px. 투구 포함 머리는 약 20px, 피부 면은 약 13px 폭. 넓은 어깨판, 층진 흉갑 띠, 갈라진 금테 전포와 두 남색 신발로 무게를 나눴다.
- 모든 잉크는 x1..62, y1..60 안에 있다. 대기 신발 두 바닥은 y60에 닿는다.

## 직접 선택한 픽셀과 재질

- 얼굴 앞쪽에 떨어진 두 눈썹을 놓고, 각 눈의 밝은 부분 오른쪽에 같은 방향의 동공을 놓았다. 콧수염은 입 위의 짧은 연속 덩어리이며 코의 밝은 끝과 분리했다.
- 금은 넓은 연노랑 반사와 황갈색 접힘, 강철은 긴 차가운 밝은 날과 짙은 뒷날, 붉은 천은 넓은 붉은 면과 자주색 골, 안감은 남색 면으로 나눴다. 광원은 왼쪽 위다. 무작위 장식 점은 없다.
- `idle_b/c`는 지정한 눈꺼풀·소매·흉갑 반사·전포·술의 짧은 행만 바꿨다. `windup`은 팔과 장도를 머리 위로, `move`는 벌어진 다리와 왼쪽으로 펼친 망토, `attack`은 전방으로 뻗은 손과 아래 사선의 장도로 따로 그렸다.
- `recover`는 낮춘 팔과 회수한 전포, `hit`는 뒤로 쏠린 머리와 찡그린 눈·벌어진 입, `dead`는 닫힌 눈·접힌 갑주·누운 망토·바닥 장도로 따로 저작했다.
- 독은 배를 누르는 손에서 입을 가리는 손으로 바뀐다. 기절은 열린 입과 늘어진 팔, 더 깊이 꺾인 무릎으로 바뀐다. 수면은 두 눈을 닫고 가슴의 팔과 무릎을 낮춰 호흡 차이를 그렸다.
- 마지막 시트에서 낮춘 장도들의 가드와 칼날 사이 빈 곳을 확인하고 해당 좌표에 직접 연결 픽셀을 추가했다. 돌진의 팔·손과 투구 술 연결도 직접 다듬었다.

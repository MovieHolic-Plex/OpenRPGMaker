# baram-wuxia-v2 시간표와 실제 픽셀 앵커

좌표는 native64 격자의 0 기준이다. 아래 ms는 수리 후 저작 권장 유지 시간이다. 이번 작업에서는 GIF를 만들거나 연속 재생을 검수하지 않았다. 실제 하네스 GIF 설정과 런타임 판정 시간으로 확정한 값은 아니다. 대기 240ms는 주어진 계약을 따른다.

## GIF 순서와 유지 의도

| 동작 | 순서와 각 프레임 유지 시간 |
|---|---|
| 대기 | idle_a 240ms → idle_b 240ms → idle_c 240ms → 반복 |
| 돌격/공격 | windup 240ms → move 100ms → attack 100ms → recover 220ms → idle_a 240ms |
| 피격 | hit 180ms → recover 220ms → idle_a 240ms |
| 쓰러짐 | hit 180ms → dead 900ms; 마지막 dead 유지, 자동 대기 복귀 없음 |
| 패왕참 | skill_a 320ms → skill_b 160ms → skill_c 240ms → idle_a 240ms |
| 독 | poison_a 460ms → poison_b 340ms → 반복 |
| 기절 | stun_a 380ms → stun_b 460ms → 반복 |
| 수면 | sleep_a 680ms → sleep_b 720ms → 반복 |

기술은 충전을 오래 잡고, 넓은 검기를 한 번 읽을 160ms를 두고, 조각으로 붕괴한 회수를 보여 주는 의도다. 공격의 넓힌 앞 신발은 attack y60 x31..42에 닿는다. 수면/독의 원래 팔 동작과 눈/기포는 유지했으며 기절은 따로 늘어진 팔로 구분한다.

## 패왕참 앵커와 변화

| 프레임 | 손 피부 | 가드 중심 | 실제 강철/입 앵커 |
|---|---|---|---|
| skill_a | 검을 쥔 밝은 피부 x44..45,y26..27. 반대 손은 x28..33,y37..38. | (45,24) | 검끝 강철 (39..40,8). 입의 짙은 픽셀 (36,31). |
| skill_b | 손 x40..43,y35와 이어진 피부 x37..40,y36. | (42,34) | 금빛 면의 뿌리와 접하는 강철 핵 (49..50,24), 아래 강철 (48..50,25). 입 (35,31). |
| skill_c | 손 x38..41,y43..44. | (43,45) | 낮춘 날 시작 x43,y46, 끝 (55..57,58). 입 (37,30). |

- 입은 얼굴 위치를 설명하는 앵커다. 이 기술의 기운은 입에서 나오지 않는다. 실제 장도 날에 연결된다.
- skill_a는 손 → 가드 → 넓어진 강철 → 원래 끝의 충전을 읽는다. 두 충전 갈래를 이미지 변형으로 새로 만들지 않았다.
- skill_b는 손/가드 (42,34)에서 우상향으로 뻗은 날을 따른다. 금빛 검기 전체는 x45..62,y7..27이고, 넓은 본체는 주로 y16..27이다. 첫 파편 궤적의 끝은 (59,7), 둘째는 (62,10)이다. 별도로 찍은 두 궤적 사이의 투명 틈은 y15까지 유지하며 y16 x54..62에서 본체와 연결된다.
- skill_c는 장도를 내려 회수하면서 이전 본체의 우상향 경로에만 세 조각을 남긴다: x58..61,y15..18; x54..58,y20..23; x49..53,y25..28. y34..37의 별도 장식과 아래 날끝 부근 y52..54의 잔광은 삭제했다. 조각을 전체 이동/축소하거나 공격 프레임에서 자동 생성하지 않았다.

## 기절과 다른 상태의 접속

- stun_a 목 피부는 x27..30,y36..37. 늘어진 왼손은 x22..26,y46..48이고 오른손은 x36..39,y46..48이며, 가드 중심 (40,49)로 이어진다.
- stun_b 목은 y40..41에서 피부가 오른쪽으로 기울어 이어진다. 왼손은 x25..30,y50..52, 오른손은 x39..43,y50..52이며 가드 중심 (44,53)으로 이어진다. 밝은 전방 어깨판은 뒤 판보다 낮다.
- 독의 기포 두 묶음은 기존의 위치/행 변화 그대로이며, 몸을 짚는 손과 입을 가리는 손을 바꾸지 않았다. 기절의 기존 별 두 묶음도 위치를 바꾸지 않았다. 수면 두 자세의 닫힌 눈과 낮은 검/호흡을 보존했다. 글자 효과는 없다.
- 게임 이동 거리, 충돌/피해 판정, 음성·효과음 동기, 실제 사용자 선택은 이 시간표의 근거가 아니다.

아래는 이전 초안의 의도와 앵커 기록이다. 현재 수리본의 좌표/권장 ms는 위 표를 따른다.

# 자세 순서와 앵커

좌표는 64×64 원본의 0부터 시작한다. 아래 유지 길이는 저작 의도다. 실제 제작 GIF의 ms는 하네스가 공급하며, GIF의 표시 시간은 실전 피해·충돌 판정 시간의 증거가 아니다.

| 동작 | 순서 | 유지 의도 |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_a | 계약의 프레임당 240ms. 작은 호흡과 눈꺼풀 변화. |
| 돌격/공격 | windup → move → attack → recover → idle_a | 준비를 잡고, 돌진과 베기는 짧게, 회수는 충분히 보여 준다. |
| 피격 | hit → recover → idle_a | 찡그린 얼굴과 뒤로 쏠린 무게를 잠시 유지한다. |
| 쓰러짐 | dead | 끝 자세 유지. 닫힌 눈이며 자동 대기 복귀를 의도하지 않는다. |
| 패왕참 | skill_a → skill_b → skill_c → idle_a | 충전이 가장 길고 접촉이 가장 짧다. 회수에서 잔광이 읽힐 시간을 둔다. |
| 독 | poison_a → poison_b → poison_a | 배를 누르는 호흡을 길게, 입을 가리는 수축은 짧게. |
| 기절 | stun_a → stun_b → stun_a | 힘 풀린 서 있음에서 무릎이 더 꺾였다가 돌아온다. |
| 수면 | sleep_a → sleep_b → sleep_a | 두 자세 모두 느리게 유지. 두 눈은 닫힌 채 어깨·팔·무릎이 내려간다. |

## 패왕참의 실제 연결

- **skill_a / 충전:** 오른손 피부는 대략 x44..45, y26..27. 손 위의 가드 중심은 (45,24), 칼날은 그 위로 연결되어 끝의 강철 핵 (39..40,8)에 닿는다. 두 갈래 금빛 기운을 이 실제 검끝 둘레에 직접 그렸다. 반대 손은 흉갑 위에서 올라온 팔의 끝에 붙는다.
- **skill_b / 접촉:** 앞으로 내민 손은 x41..42,y35..36, 가드 중심은 (42,34). 강철 날은 우상향으로 이어져 (51,24)에 닿으며, 금빛 검기는 그 끝부터 x50..61,y15..27에 걸친 넓고 밝은 면으로 뻗는다. 첫 파편 궤적은 x55..60,y7..11, 둘째는 x58..61,y10..14의 별도 짧은 행들이다. 양쪽 궤적은 검기 선단의 진행 방향을 따른다.
- **skill_c / 회수:** 팔과 망토를 낮추고 손에서 가드 (43,45)와 우하향 장도를 연결했다. 이전 선단 방향의 x54..57,y23..26 및 x57..60,y34..37에 짧은 잔광을 남겼고, 내려오는 날 옆 x56..58,y52..54에는 마지막 파편을 따로 찍었다. 충전 모양을 축소하거나 이동한 효과가 아니다.

독의 두 청록 기포 묶음과 기절의 두 별 묶음은 프레임별로 다른 위치·행을 직접 선택했다. 수면에는 글자나 상태 문자를 넣지 않았다. 런타임의 공격 판정·이동 거리·사운드 동기화는 이 원본 작업의 검증 범위가 아니다.

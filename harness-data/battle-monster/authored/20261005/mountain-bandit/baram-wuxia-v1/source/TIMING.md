# 동작 순서와 앵커

아래 hold는 저작 의도이며 제작 하네스가 공급하는 실제 GIF 시간값이 우선한다. 게임의 공격 판정·피해 적용·런타임 전투 시간은 이 파일이나 정지 그림으로 검증하지 않았다. 좌표는 0부터 시작한다.

| 검토 동작 | 그림 순서 | 저작 의도 hold |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 각각 220ms |
| 공격 | windup → move → attack → recover → idle_a | 180 / 100 / 120 / 180 / 220ms |
| 피격 | hit → recover → idle_a | 220 / 160 / 220ms |
| 쓰러짐 | hit → dead | 140ms / 마지막 자세 유지 |
| 난도질 | skill_a → skill_b → skill_c → idle_a | 260 / 120 / 260 / 220ms |
| 독 | poison_a ↔ poison_b | 각각 340ms |
| 기절 | stun_a ↔ stun_b | 각각 360ms |
| 수면 | sleep_a ↔ sleep_b | 각각 600ms |

## 난도질의 실제 그림 앵커

- **skill_a / 힘 모으기:** 오른손은 (49,24–25)의 손잡이를 감싼다. 철테 가드가 y23, 날이 x48–54, y5–22로 연결된다. 방패를 든 반대 팔은 y32–38에 벌어진다. 첫 붉은 기운은 날의 오른쪽 (55–58,7–18)에 짧게 붙는다.
- **skill_b / 횡베기·접촉:** 손은 (44–46,38–40), 손잡이는 (46,38–39), 가드는 x45–49에 연결된다. 횡방향 날은 x49–60, y36–39에 놓인다. 가장 밝은 붉은 접촉은 날 끝 (60–62,37–38)에 있으며 위쪽에서 넘어와 아래쪽으로 찢기는 궤적을 직접 저작했다.
- **skill_c / 낮은 방어 회수:** 손 (28–31,43–44) → 손잡이 (29,45) → 가드 y46 → 낮춘 날 y47–59. 방패는 x28–44 부근에서 몸 앞을 보호한다. (57–59,31–33), (57–59,38–40), (52–56,44–46)의 잔광은 서로 다른 짧은 조각이며 접촉 궤적을 축소하거나 이동해 만들지 않았다.

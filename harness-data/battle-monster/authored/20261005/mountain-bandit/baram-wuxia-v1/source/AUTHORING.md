# 산적 칼잡이 — 원본 후보

- 정본: `palette.json`, `poses/*.pxgrid` 9장, `actions/*.pxgrid` 9장. 모두 64×64 전체 ASCII 행이며 공통 18색을 사용한다. 사용자의 선택·승인 기록은 없다.
- 첨부된 최신 검객을 눈·얼굴 크기와 옷의 덩어리 읽기에만 관찰했다. 공식 직업 그림은 의복·무기 어휘만 관찰했다. 참고 픽셀 추출, 트레이싱, 생성 이미지, 도형 채우기, 프레임 이동·회전·보간을 사용하지 않았다.
- 독자적인 외형: 작고 각진 상투, 뒤로 흐르는 붉은 머리띠, 굵은 코와 작은 성인 눈, 넓은 어깨의 짧은 갈색 저고리, 붉은 겹허리띠, 청회색 넓은 바지, 분리된 검은 신발. 긴 검객 도포와 갓을 가져오지 않았다.
- 얼굴: 앞볼 쪽의 분리된 두 눈썹과 작은 눈. 대기·공격의 흰자 오른쪽에 각각 한 동공을 놓았다. 눈·코·입의 위치를 자세별 행에서 직접 골랐다. 독·피격은 압박된 눈꺼풀, 기절은 벌어진 입, 수면·쓰러짐은 동공 없는 닫힌 눈이다.
- 재질: 왼쪽 위의 따뜻한 피부 광면, 넓은 황갈색 옷면과 방향성 짙은 주름, 나무 방패의 판재·중앙 금속못·가느다란 철테, 철도의 밝은 날과 청회색 옆면. 금속과 피부의 밝은 색을 구별했다.
- 동작: 준비에서 팔꿈치를 올리고 방패를 끌어당김 → 돌진에서 뒤 저고리 자락·앞뒤 무릎을 벌림 → 내려베기에서 어깨·팔을 펴고 넓은 날을 아래로 보냄 → 회수에서 팔을 낮춤. 피격은 머리를 뒤로 젖히고 방패를 몸 앞에 올린다. 쓰러짐은 옆으로 접힌 몸과 바닥의 철도·방패를 별도로 저작했다.
- 난도질: 벌린 두 팔과 머리 위 철도 / 전진 횡베기와 날 끝에 붙은 붉은 궤적 / 방패 뒤의 낮은 회수와 세 갈래로 끊긴 잔광. 효과도 개별 문자 덩어리를 직접 선택했다.
- 독 2장은 배를 감싸기·입을 가리기, 기절 2장은 풀린 턱과 좌우 어깨의 기울기, 수면 2장은 닫힌 눈과 더 깊은 무릎·호흡의 옷면으로 나뉜다. 색조 교체만으로 만든 상태는 없다.
- 확대 확인에서 발견한 대기·돌진·공격·회수·기술의 손잡이 연결 간격은 지정한 팔·손·손잡이 행으로 메웠다. 첫 대기 체크포인트는 `progress/idle.png`와 `progress/face.png`; 최종 확인 시트는 `progress/suite.png`다.

## 남은 시각적 한계

짧은 저고리와 방패가 겹쳐 뒤쪽 팔·가슴의 일부는 가려진다. 작은 원본에서 코가 강한 특징으로 읽히며, 기술 접촉의 횡방향 철도는 대각 날보다 얇게 보인다. 이러한 표현과 실제 연결 동작은 후속 독립 검수·GIF에서 판단할 대상이다. 정지 시트 관찰을 런타임 동작 검증이나 사용자 승인으로 표현하지 않는다.

`draw_*.py`, `refine_idle.py`, `literals/`는 직접 고른 행·짧은 좌표 수정의 저작 과정이다. 최종 수정이 반영된 `.pxgrid`가 정본이며 옛 작성 스크립트를 재실행해 덮어쓰지 않는다. `author.py`는 문자 디코딩과 검사 그림 저장용 보조 도구다.

# 비연 자객 — 원본 도트 후보

64×64 ASCII pxgrid 18장, 공유 팔레트 18색. 오른쪽을 보는 성인 SD 자객.
참고 그림은 관찰만 했으며 그 픽셀을 추출하거나 옮기지 않았다.

## 보존한 정체성

복구 시 존재한 기본 9자세, 기술 3자세를 이어서 작업했다. 기본 9장과 팔레트는 그대로 보존했다.
비스듬한 검은 앞머리, 긴 땋은 머리와 자주색 끝 매듭, 좁은 목수건,
짧은 청록 겹도복, 허리띠와 좁은 바지, 분리된 어두운 신발, 회백 손목 감개와 은색 쌍검.
idle_a의 본체는 y8..60, 총 53px이며 두 신발 바닥이 y60에 닿는다.
눈썹과 작은 두 눈을 앞쪽 얼굴 면에 분리하고, 열린 눈의 눈동자는 오른쪽에 유지했다.
기본 얼굴 아래쪽은 복면이다.

## 이번 명시적 저작

- `poison_a`: 배를 감싸는 팔, 넓게 굽힌 무릎, 내려든 단검, 찡그린 눈과 세 독방울.
- `poison_b`: 앞으로 숙인 머리·가슴, 복면에 올린 손, 더 접힌 앞 무릎,
  배 옆의 쌍검과 위치·크기가 다른 세 독방울을 별도로 그렸다.
- `stun_a/b`: 내려간 복면 위에 실제 열린 입을 찍었다. 서로 다른 머리 기울기,
  늘어진 두 팔과 손목, 꺾이는 무릎, 손에서 이어지는 낮은 칼과 서로 다른 별 묶음.
- `sleep_a/b`: 두 눈 모두 닫힌 눈꺼풀. 숨을 내쉴 때 머리·어깨·손·앞 무릎이 더 낮아지고
  옷 주름과 땋은 머리의 매듭 위치도 별도로 바뀐다. 칼은 두 손에서 아래로 이어진다.
- `skill_a`: 손잡이에서 두 번째 칼날이 충전 덩어리로 이어지도록 짧은 행을 고쳤다.
  중복된 아래 칼날을 지우고 바닥 y60의 신발 픽셀을 명시했다.
- `skill_b`: 얼굴을 덮던 잔상을 지우고 원래 얼굴을 복구했다.
  두 손목과 교차 검기를 연결하고 청록 꼬리는 얼굴 밖의 두 검기 끝에 그렸다.
  `skill_c`의 낮은 회수와 끊어진 잔상은 보존했다.

빛은 왼쪽 위. 청록 옷은 넓은 G/I 밝은 면과 방향성 F/E 주름,
머리는 H/J의 절제된 광택, 피부는 U/T/S, 강철은 W/V/K로 구분한다.
효과는 P/Q/W 중심과 F/G/I 꼬리이며 본체를 색으로 물들이지 않았다.

## 원본과 확인

정본은 `palette.json`, `poses/*.pxgrid`, `actions/*.pxgrid`의 완전한 64행이다.
`statuses.py`, `repairs.py`는 지정한 좌표와 짧은 문자열만 기록한 저작 메모다.
전체 프레임 변형, 마스크/도형 채우기, 자동 명암, 보간은 없다.
격자를 직접 디코딩한 1× PNG와 최근접 확대 시트를 확인했다.
모든 그림·효과는 x1..62, y1..60 안에 있고 알파는 0/255다.
`progress/idle.png`와 `progress/face.png`는 보존한 첫 idle 체크포인트,
`progress/contact-sheet.png`는 완성 18자세의 1×/4× 확인판이다.

## 남은 시각 검수

복면과 작은 눈 때문에 독·수면의 표정 차이는 1×에서 작으며 몸 자세와 독방울이 먼저 읽힌다.
충전에서는 두 짧은 칼이 근접하므로 1×에서 겹쳐 보일 수 있다.
땋은 머리의 관성, 교차 검기의 순간 가독성, 회수 박자는 후속 실제 GIF 검수 대상이다.
독립 검수 및 사용자 선택은 아직 없으며 승인된 결과라고 주장하지 않는다.

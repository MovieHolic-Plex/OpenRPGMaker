# 비연 자객 — 검수 GIF 순서와 앵커

아래는 저작한 자세의 순서와 hold 역할이다. 실제 제작 GIF의 ms 값은 하네스가 공급한다.
이 문서나 확인 PNG는 런타임 공격·피해 시점의 증거가 아니다. 이번 작업에서는 GIF를 렌더하지 않았다.

| 묶음 | 자세 순서 | Hold 의도 |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | brief의 프레임당 200ms, 작은 호흡·소매·머리 변화 |
| 공격 | idle_a → windup → move → attack → recover → idle_a | 준비를 읽히게 유지, 돌격·교차 베기는 짧게, 회수는 중간 |
| 피격 | idle_a → hit → recover → idle_a | 반동이 읽히는 hold 뒤 복귀 |
| 쓰러짐 | idle_a → hit → dead | 마지막 dead 유지 |
| 비연살 | idle_a → skill_a → skill_b → skill_c → idle_a | 충전은 길게, 접촉은 가장 짧게, 낮은 회수는 중간 |
| 독 | poison_a → poison_b | 배를 움켜쥠과 복면에 손을 올림을 각각 유지 |
| 기절 | stun_a → stun_b | 늘어진 팔과 무릎의 두 상태를 각각 유지 |
| 수면 | sleep_a → sleep_b | 감긴 눈을 유지하며 들숨·날숨을 느리게 교대 |

## 비연살의 실제 그림 앵커 (0-based 좌표)

- `skill_a`: 첫 손은 x40..42/y36, 다른 손은 x37..39/y38에 있다.
  첫 칼의 손잡이/가드는 x41..43/y35, 다른 칼의 가드는 x41..43/y38.
  두 날이 위쪽 x48/y28과 x50..52/y33..35의 보라 충전 덩어리로 이어진다.
  효과는 실제 칼끝의 압축이며 입·허공 중앙에서 나오는 발사체가 아니다.
- `skill_b`: 앞 손은 x42..44/y37, 다른 손은 x37..41/y42..43.
  가드 x44..47/y36과 x41..44/y40에서 시작한 두 사선이 x47..50/y36..38에서 교차한다.
  위쪽 밝은 끝 x57/y25와 아래쪽 x57/y46, 두 끝 바깥의 짧은 청록 꼬리로 분리된다.
- `skill_c`: 두 손과 두 단검을 허리 앞으로 낮게 회수한다.
  가드 x43..44/y41과 x41..42/y45에서 각 칼날로 이어지고,
  오른쪽 x53..60/y29..40의 두 보라 조각 및 x44..54/y45..50의 청록 잔상이 끊어진다.

독은 눈꺼풀·눈썹과 배/복면에 닿는 손이 바뀐다. 기절은 열린 입과 내려간 복면,
수면은 실제 감긴 두 눈 및 낮아지는 팔·무릎이다. 어느 상태에도 문자 효과를 쓰지 않았다.

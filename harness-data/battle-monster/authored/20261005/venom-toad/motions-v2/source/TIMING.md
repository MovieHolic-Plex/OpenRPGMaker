# 추가 동작 재생 시간표

64×64 네이티브 셀. 오른쪽을 바라보고 접지선은 y=60이다. 좌표는 0부터 센다.
아래 순서는 GIF 저작용 제안이다. 이번 작업에서는 GIF나 게임 저장소를 만들거나 수정하지 않았다.
프레임을 보간하거나 전체 몸을 이동시키지 않고, 기재한 원본을 해당 시간 동안 유지한다.

| 재생 | 원본 순서와 유지 시간 | 반복 |
|---|---|---|
| 기존 대기 | `poses/idle_a` 240ms → `idle_b` 240ms → `idle_c` 240ms → `idle_b` 240ms | 반복 |
| 독침뱉기 | `poses/idle_a` 240ms → `actions/skill_a` 360ms → `skill_b` 120ms → `skill_c` 240ms → `poses/idle_a` 300ms | 시연만 반복; 게임은 기술 1회 |
| 독 상태 | `actions/poison_a` 420ms → `poison_b` 480ms | 반복 |
| 기절 상태 | `actions/stun_a` 300ms → `stun_b` 340ms | 반복 |
| 수면 상태 | `actions/sleep_a` 760ms → `sleep_b` 620ms | 반복 |

## 기술과 신체 앵커

- 무기나 사람 손은 없는 두꺼비다. 기술의 발사 기관은 입이며 앞발은 체중을 지탱한다.
- `skill_a`: 팽창된 볼 중심 약 (46,48). 분비샘의 밝은 중심 (45,47)이 준비 효과다. 닫힌 볼·목의 피부에 붙어 있다. 가까운 앞팔은 y=55–59에서 오른쪽 바닥 발로 이어진다.
- `skill_b`: 입 안 중심 (45,43), 혀/독침 시작 (44,43), 바깥 입술 경계 (47,43), 발사체 출구 (48,43). 오른쪽 독침은 y=43을 축으로 (60,43)까지 이어진다. 검은 입 안에서 밝은 축이 연속하므로 몸 옆에서 갑자기 생기지 않는다.
- `skill_b`의 발사 시점은 이 원본이 표시되는 첫 순간, 기술 시연 시작 후 600ms다. 이 셀의 독침은 발사 직후를 표현한다. 별도 원거리 접촉 좌표나 게임 피해 시점은 정하지 않았다.
- `skill_b`: 가까운 앞팔은 목 아래 y=54–58에서 발 x=43–50,y=59–60으로 이어진다. 몸이 서도 접지가 남는다.
- `skill_c`: 닫히는 입 중심 약 (45,50), 독액 방울 중심 (49,52). 목과 볼이 줄어드는 회복이며 새 발사나 상태 거품이 아니다.

## 상태 효과의 리듬

- 독: `poison_a`의 윗거품은 `poison_b`에서 갈라지고 새 거품이 아래에서 떠오른다. 턱·배·앞발도 함께 움츠린다. 기술 독침과 독 상태 적용은 별개다.
- 기절: 별의 크기/좌표가 서로 바뀌고 머리·앞팔이 느슨하게 꺾인다. 몸이나 효과를 자동 회전시키는 동작은 없다.
- 수면: `sleep_a`는 내쉰 낮은 배와 작은 호흡방울, `sleep_b`는 부푼 등·배와 넓은 방울이다. 눈은 두 장 모두 닫히고 발은 몸 아래에 접혀 있다. 텍스트 기호는 없다.
- 독침의 120ms 강조와 느린 상태 유지 시간을 구분했다. 실제 GIF 속도와 런타임 표시 크기에 대한 검토는 남아 있다.

# 독두꺼비 추가 동작 저작 기록

## 범위와 보존

- `actions/`에 64×64 ASCII 팔레트 인덱스 원본 9장을 직접 저작했다. 각 파일은 전체 64행이다.
- `palette.json`과 `poses/`의 기존 9자세는 수정하지 않았다. 기존 팔레트의 15색만 사용하며 점은 투명이다.
- 기존 그림의 낮고 넓은 올리브 몸통, 둥근 볼, 왼쪽 위 광원, 오른쪽을 보는 눈, 접힌 뒷다리와 네 발의 겹침을 기준으로 삼았다.
- 기존 행에서 몸통의 안정된 부분을 참고하고, 변화하는 윤곽·눈·목·볼·다리·효과의 최종 행을 직접 썼다. 전체 몸 이동/회전/보간, 자동 명암, 도형 생성, 이미지 생성은 사용하지 않았다.
- 게임 저장소, 저장소 코드, 후보 brief, ledger, 다른 후보는 변경하지 않았다. 원본 저작 단계이며 사용자 승인이나 게임 설치를 뜻하지 않는다.

## 확인과 남은 시각적 문제

- ASCII 행 길이·색 기호·투명 가장자리·최하단 위치를 읽어 확인하고, 원본 크기 접촉 시트를 메모리에서 펼쳐 보았다. 검토용 그림 파일을 추가로 저장하지 않았다.
- 테스트나 게이트는 실행하지 않았다. GIF와 실제 런타임 재생은 실행하지 않았으며 시간표는 후속 하네스용 제안이다.
- 기존 팔레트에는 보라/청록 독색이 없어 독침과 기포가 황록색으로 읽힌다. 상태 구분은 색 변경이 아니라 자세와 효과 형태에 의존한다.
- 64px 셀에서 실제 몸은 약 35–40px 너비다. 기절의 눈과 수면의 눈꺼풀 차이는 작아서 별/거품과 함께 읽어야 한다.
- 수면은 낮은 복부와 수납된 발로 구분했지만 한 장만 보면 기존 쓰러짐의 낮은 실루엣과 가까울 수 있다. 감긴 눈, 살아 있는 목·볼, 호흡 2장으로 구분한다.
- 독침의 오른쪽 끝은 x=60에서 끝난다. 셀 안에 발사 직후 짧은 구간만 보이며 대상 접촉, 상태 적용, 피해 판정은 여기서 검증하지 않았다.
- 먼 쪽 두 발은 기존 3/4 구도처럼 몸과 가까운 발에 일부 가려진다. 새 팔다리나 사람이 쓰는 무기를 추가하지 않았다.
- 사람이 선택한 결과가 아니다. 별도 독립 검수와 사용자 검토가 남아 있다.

# 사교 술사 — native64 후보 저작 기록

이 후보는 사용자 검토 대기 상태다. 사용자 승인이나 독립 검수 합격을 뜻하지 않는다.
기존 source에는 포즈 원본이 없었으므로, 팔레트와 기본 9자세·추가 9자세를 새로 저작했다.

## 직접 저작 방식

- 최종 원본은 `poses/*.pxgrid`, `actions/*.pxgrid`의 64×64 리터럴 ASCII 행이다. `.`은 투명이며 팔레트에 없다.
- 18색을 공통으로 사용한다. 외곽 K, 머리 h, 피부 s/t/u, 수염 v/w/W, 도포 g/m/l, 안감 r/R, 청동 b/B/Y, 혼불 e/E.
- 행 안의 최종 픽셀 군집을 직접 정했다. 재사용한 부분은 고정된 발·하체·머리의 변경 없는 픽셀이다. 바뀐 머리, 소매, 손, 무기, 옷 주름, 효과는 각 자세의 행으로 다시 적었다.
- 이미지 생성·도형 마스크·자동 명암·프레임 이동·회전·보간으로 원본을 만들지 않았다. 검토 PNG/GIF는 격자의 기호를 같은 팔레트 색으로 옮긴 것이다. 확대 PNG의 최근접 확대는 관찰용이며 64px 원본이나 GIF에 쓰지 않는다.
- 투명 외곽을 유지하고 발/밑단/무기의 최하단을 y≤60에 두었다. `idle_a`의 신발 밑창은 y=60이다. 좌표는 왼쪽 위가 (0,0).
- 저장 범위는 이 후보의 `source`뿐이다. 게임 저장소·원장·brief·다른 후보에는 쓰지 않았다. 테스트/게이트는 실행하지 않았다.

## 실루엣과 재질

맨머리의 작은 상투와 오른쪽으로 나온 코, 좁고 긴 흰 턱수염을 고정된 정체성으로 삼았다.
도포는 탁한 녹색의 긴 A형 밑단과 넓은 소매를 가진다. 안감의 붉은 색은 앞섶과 팔목의 접힌 면에 둔다.
왼쪽 위의 빛은 왼쪽 어깨·소매 능선·치맛자락의 꺾인 면에 l을, 우측과 깊은 주름에 g를 쓴다.
청동 방울은 윗면의 Y, 몸통의 B, 아래와 안쪽의 b로 작은 둥근 금속 덩어리를 나타냈다.

수면 지팡이의 대각선은 손에서 방울까지 직접 이어지는 픽셀 계단이며 회전된 원본이 아니다.

## 관찰 근거와 남은 시각적 문제

native PNG 접촉 시트와 최근접 확대 시트에서 전체 실루엣, 수염, 안감, 손/무기 연결, 상태 구분을 직접 보았다.
GIF에는 원본 자세만 사용하며 실제 전투 엔진이나 피해 판정과 연결해 확인하지 않았다.

- 대기 3장의 호흡 차이는 작다. 작은 게임 표시 크기에서는 주로 손끝과 방울의 변화로 읽힌다.
- 64px 안에 세 갈래를 넣어 혼불 끝이 짧고 각지다. 실제 화면에서 큰 장거리 마법으로 보이는지는 별도 판단이 필요하다.
- 도포의 긴 앞섶은 좁은 붉은 띠로 읽힌다. 넓은 안감은 소매와 쓰러짐에서 더 뚜렷하다.
- 기절 별은 작은 십자와 마름모 군집이라 고해상도 별 장식처럼 세밀하지 않다.
- 수면의 작은 숨결은 밝은 배경에서 희미할 수 있다. 핵심 구분은 감긴 눈·내린 팔·낮은 지팡이다.
- 3개의 스킬 핵심 자세 사이에 중간 프레임은 없으며, 긴 지팡이를 세우고 낮추는 전환은 끊어 보일 수 있다.

사람이 최종 후보를 보고 선택하거나 수정을 요청해야 한다.

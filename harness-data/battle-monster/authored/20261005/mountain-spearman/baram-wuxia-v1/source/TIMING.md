# 자세 순서와 관찰용 유지 시간

아래 시간은 저작 의도를 설명하는 **검토용 제안**이다. 제작 GIF의 최종 시간은 하네스가 정하며, 이 문서는 실제 전투의 공격 판정·피해 발생 시점이나 런타임 타이밍을 검증한 증거가 아니다.

| 동작 | 순서 | 검토용 유지 시간 |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 각 220ms (브리프) |
| 돌격·공격 | idle_a → windup → move → attack → recover → idle_a | 220 / 180 / 100 / 120 / 180 / 220ms |
| 피격 | idle_a → hit → recover → idle_a | 220 / 180 / 160 / 220ms |
| 쓰러짐 | hit → dead | 140 / 800ms, 마지막 자세 유지 |
| 삼단찌르기 | skill_a → skill_b → skill_c → idle_a | 300 / 120 / 240 / 220ms |
| 독 | poison_a ↔ poison_b | 각 300ms |
| 기절 | stun_a ↔ stun_b | 각 280ms |
| 수면 | sleep_a ↔ sleep_b | 각 440ms |

## 삼단찌르기의 실제 픽셀 앵커

좌표는 왼쪽 위가 (0,0)인 원본 64×64 격자 기준이다.

- **skill_a / 응축:** 앞손은 (38,42) 부근, 뒷손은 (30,45) 부근에서 나무창을 잡는다. 실제 철색 창끝 (55,35) 주위의 (53..61,32..40)에 각각 선택한 푸른 점·밝은 핵을 모았다. 양무릎을 굽힌 준비 자세다.
- **skill_b / 접촉:** 앞손 (47,43), 뒷손 (38,43) 부근에서 수평 창을 연결한다. 실제 창끝 (60,43)에 붙는 밝은 기운이 접촉 앵커다. (51..60,37), (52..60,47), (54..60,51)의 짧은 직선 잔상 세 줄을 따로 찍었다. 상체가 낮아지고 뒷다리가 펴진다.
- **skill_c / 회수:** 앞손 (45,44), 뒷손 (40,50) 부근으로 창을 회수한다. 팔꿈치에서 손까지 소매가 연결된다. 실제 창끝 (58,31) 주변의 (53..60,27..44)에 소수의 끊긴 기운만 남으며, 찌르기의 세 줄을 축소하거나 이동해서 만들지 않았다.

독방울과 기절 별도 각각의 프레임에서 직접 정한 위치·행으로 저작했다. 수면은 글자·기호 없이 눈꺼풀과 낮아진 창, 천의 호흡 변화로 표현했다. 제작 GIF 렌더링과 독립 검수는 후속 하네스 단계다.

# 포즈 순서와 효과 앵커

좌표는 native 64×64의 0부터 시작하는 (x,y)다. 아래 노출은 저작자의 **검수용 제안**이다. 실제 제작 GIF의 시간은 하네스가 공급한다. 런타임 전투의 피해·음향·이동 시점을 확인한 자료가 아니다.

| 클립 | 순서 | 검수용 홀드 제안 |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 각 220ms (브리프 대기 값) |
| 공격 | windup → move → attack → recover → idle_a | 180 / 90 / 110 / 180 / 220ms |
| 피격 | hit → recover → idle_a | 150 / 180 / 220ms |
| 쓰러짐 | hit → dead | 150ms / 마지막 자세 유지 |
| 그림자살 | skill_a → skill_b → skill_c → idle_a | 260 / 120 / 220 / 220ms |
| 독 | poison_a ↔ poison_b | 280 / 320ms |
| 기절 | stun_a ↔ stun_b | 240 / 280ms |
| 수면 | sleep_a ↔ sleep_b | 450 / 500ms |

## 그림자살

- **skill_a / 모음:** 올린 손의 두 손가락은 (41,32)와 (43,32). 손목은 (40,36), 역수 손잡이는 (43,35) 부근이다. 손가락 왼쪽과 위에서 보라색 짧은 갈래가 모인다. 반대 손의 단검은 허리 아래로 내리고, 결인하는 손의 단검은 손잡이에서 바깥 아래로 연결된다.
- **skill_b / 접촉:** 오른손 (38,33)에서 사선으로 올라간 강철 칼끝은 (48,22). 그 칼끝의 밝은 중심을 잇는 보라색 갈래는 위쪽 긴 갈래, 오른쪽 짧은 갈래, 아래로 찢어진 갈래로 분리했다. 넓어진 다리와 앞으로 기울인 몸이 찌르기를 받친다. 입에서 나오는 효과가 아니다.
- **skill_c / 회수:** 오른손 (37,40) 부근으로 칼을 당겨 아래로 낮춘다. 바깥쪽 (45..62,32..47)의 몇 갈래 잔광은 끊어진 불균등 덩어리로 무너진다. 접촉 효과를 확대·축소한 프레임이 아니다.

독 방울은 서로 다른 위치·크기·명암 덩어리를 따로 찍었다. 기절의 별은 두 상태에서 위치와 높이가 다르다. 수면 두 장에는 글자나 효과를 넣지 않고 눈꺼풀, 어깨 처짐, 무릎과 손 위치로 호흡을 표현했다.

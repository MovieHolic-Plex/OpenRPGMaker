# 흑건 자객 — 원본 저작 기록

판정 상태: **사용자 검토 대기. 승인 또는 선택을 기록하지 않았다.**

## 작업 범위와 방식

이번 작업 시작 시 source에 기존 원본 격자가 없어 전체 후보를 새로 저작했다.
수정 요청 「follow the silhouette and action brief」를 실루엣·행동의 기준으로 삼았다.
저장 대상은 이 후보의 source 폴더뿐이다.

- poses 9장, actions 9장. 각각 64×64, ASCII 팔레트 인덱스 전체 64행.
- palette.json: 불투명 18색. 점은 투명이며 팔레트에 등록하지 않았다.
- 모든 유색 행과 효과 조각의 최종 픽셀을 직접 지정했다. 쓰기 보조는 투명 캔버스 여백과 파일 저장만 담당했다.
- 전신 이동·회전·보간, 도형 래스터화, 자동 명암 또는 생성 이미지를 사용하지 않았다.
- native PNG와 GIF는 격자 색을 그대로 표시한다. 확대·축소·중간 프레임 합성을 하지 않았다.

## 실루엣과 재질

오른쪽을 향한 3/4 두건, 보이는 좁은 눈 틈, 턱을 덮는 검은 복면을 공통으로 유지했다.
목 뒤의 짧은 매듭 꼬리와 좁은 먹청 도복, 두 갈래 바짓단으로 날렵한 사람 체형을 구성했다.
검은 두건의 밝기는 낮게 유지하고 왼쪽 위 두건·어깨·허벅지에 연결된 청색 면을 직접 배치했다.
흰 손목 감개는 어두운 소매와 피부 사이에 놓고, 가죽 허리끈은 갈색 두 줄과 한쪽 밝은 면으로 구분했다.
단검은 검은 외곽, 청회색 면, 짧은 밝은 날을 사용하며 손과 자루가 연결되도록 그렸다.

## 자세별 저작

| 원본 | 직접 바꾼 덩어리와 동작 |
|---|---|
| idle_a | 양발을 벌린 준비 자세. 손목 아래로 내려가는 역수 단검 두 자루. 발바닥 최하단 y=60. |
| idle_b | 어깨의 천 접힘과 소매 면, 목 뒤 매듭 꼬리를 다시 찍은 작은 들숨. 발 위치 유지. |
| idle_c | 두 팔꿈치를 안쪽으로 좁히고 손목·단검을 각각 새 좌표로 저작한 날숨. |
| windup | 머리와 가슴을 숙이고 두 손을 배 앞에 모음. 무릎을 굽혀 두 단검의 끝이 가까워지는 준비. |
| move | 목·가슴·골반의 기울기, 뒤로 뻗은 팔과 벌어진 다리를 새로 그림. 앞발 접지와 뒤꿈치 들림으로 낮은 질주. |
| attack | 앞쪽 두 손에서 이어지는 칼날을 교차시킴. 두 팔의 경로를 정리하고 불필요한 뒤쪽 손·칼 덩어리를 제거. 넓은 보폭에서 발끝을 y=60 안으로 다시 저작. |
| recover | 낮아진 무릎과 접힌 뒷다리, 내려오는 두 칼을 새로 구성한 회수. |
| hit | 머리·가슴이 뒤로 젖혀지고 양팔·칼이 벌어지는 반동. |
| dead | 두건 옆면, 복면, 눕힌 몸통과 겹친 다리, 손에 남은 낮은 단검을 별도로 저작한 쓰러짐. |

## 기술과 상태

- skill_a: 한 손의 두 손가락을 세운 결인, 반대 손의 역수 단검, 결인 손 아래의 두 번째 칼. 손 옆과 발치에서 짧은 보라색 그림자 갈래를 직접 찍었다.
- skill_b: 상체가 앞으로 파고들며 오른손 칼이 오른쪽 위로 사선 찌르기. 접촉 끝의 갈라진 먹빛 기운과 보라색 가장자리를 새로 저작했다. 다른 손에는 가슴 앞의 짧은 역수 칼을 유지했다.
- skill_c: 오른손 단검을 몸 가까이 회수하고 무릎을 낮춤. 발치의 기운을 서로 다른 작은 끊어진 조각으로 붕괴시켰다.
- poison_a/b: 움츠린 가슴, 배 앞에 붙인 손, 내려간 칼과 불안정한 굽은 다리. 두 번째 그림은 더 좁은 허리와 감긴 눈으로 악화된 자세를 표현했다. 초록 기포의 크기·속 빈 부분·위치를 프레임마다 각각 지정했다.
- stun_a/b: 팔과 칼이 처지고 무릎이 꺾인 자세. 두 번째 그림은 목·어깨·허리·발의 지지 형태를 별도로 바꾸었다. 머리 위 별은 큰 별과 작은 별의 위치 및 가지 길이를 각각 직접 찍었다.
- sleep_a/b: 복면 위 눈을 가로로 감고 무기를 낮춤. 들숨에서는 가슴 앞 청색 면과 어깨·팔의 접힘을 넓히고, 날숨에서는 다시 좁힌다. 문자나 수면 글자 효과는 사용하지 않았다.

## 원본 관찰과 남은 시각 문제

원본 크기 poses-native.png와 actions-native.png를 열어 자세, 눈 틈, 손목 및 무기의 연결을 확인했다.
그 과정에서 공격 발끝과 교차 베기의 불필요한 손·칼을 고쳤고, 기술 두 단계의 두 번째 단검을 보완했다.
테스트/게이트 및 실제 게임 재생은 실행하지 않았다. 이 폴더의 미리보기는 후보의 원본 동작만 보여 준다.

남은 표현 한계:

1. 64px에서 결인의 손가락과 역수 쥠은 1~3px 단위여서 축소 표시에서는 구분이 약해질 수 있다.
2. 짧은 보라색 갈래의 어두운 면은 어두운 전투 배경에서 덜 보일 수 있다. 밝은 가장자리의 비중은 사용자 시각 판단이 필요하다.
3. 쓰러짐의 겹친 소매와 다리는 작은 눕힌 면 안에 압축되어 있다. 회복·기절·수면의 낮은 자세도 옷의 검은 면이 겹치므로 실제 표시 크기에서 비교가 필요하다.
4. 3프레임 기술과 단일 질주·접촉 자세는 핵심 동작만 표현한다. 게임 내 이동 거리나 피해 타이밍은 이 후보에서 결정하지 않았다.

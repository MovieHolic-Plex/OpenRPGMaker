# 흑건 자객 — native GIF 시간표

모든 좌표는 각 64×64 원본의 왼쪽 위 (0,0) 기준이다.
GIF는 저작한 프레임을 그대로 재생한다. 프레임 사이의 보간이나 전신 이동은 없다.
각 원본의 최하단 잉크는 y≤60이며 idle_a의 발바닥은 정확히 y=60이다.

## 시트 순서

poses-native.png는 3×3 행 우선이다.

| 1열 | 2열 | 3열 |
|---|---|---|
| idle_a | idle_b | idle_c |
| windup | move | attack |
| recover | hit | dead |

actions-native.png도 3×3 행 우선이다.

| 1열 | 2열 | 3열 |
|---|---|---|
| skill_a | skill_b | skill_c |
| poison_a | poison_b | stun_a |
| stun_b | sleep_a | sleep_b |

## 재생 순서와 유지 시간

| GIF | 순서: 프레임 이름(밀리초) |
|---|---|
| idle.gif | idle_a(220) → idle_b(220) → idle_c(220) → 반복 |
| attack.gif | idle_a(180) → windup(200) → move(100) → attack(120) → recover(180) → idle_a(220) → 반복 |
| skill.gif | idle_a(220) → skill_a(300) → skill_b(120) → skill_c(240) → idle_a(220) → 반복 |
| poison.gif | poison_a(320) → poison_b(320) → 반복 |
| stun.gif | stun_a(220) → stun_b(220) → 반복 |
| sleep.gif | sleep_a(600) → sleep_b(700) → 반복 |
| hit.gif | idle_a(220) → hit(160) → recover(180) → idle_a(220) → 반복 |
| dead.gif | idle_a(220) → hit(140) → dead(900) → 반복 |

idle의 계약 간격은 220ms다. sleep_b는 들숨, sleep_a는 날숨이다.
공격 접촉은 attack, 그림자살의 사선 찌르기 접촉은 skill_b에서 읽도록 한다.
이 시간표는 후보 검토용이며 게임 엔진에 등록하지 않았다.

## 그림자살의 손·복면·무기 기준점

좌표는 작은 덩어리의 시각 중심 또는 칼날 끝을 가리킨다.

| 단계 | 손 기준 | 입 기준(복면) | 무기·효과 기준 |
|---|---|---|---|
| skill_a 준비 | 결인 손가락 (40,28), 손바닥 (42,30); 반대 손 (29,36) | (35,24) | 결인 손 아래 자루 (45,33), 끝 (49,39); 반대 단검 자루 (29,37), 끝 (23,43). 보라색 준비 갈래 중심 (47,29), 발치 (16,57)/(43,56). |
| skill_b 시전/접촉 | 찌르는 오른손 (48,34), 가슴 앞 반대 손 (35,39) | (45,32) | 오른손 자루 (49,34)에서 날 끝 (56,25)으로 사선 진행. 접촉 갈래 (57,23), 짧은 보조 갈래 (60,21). 반대 칼 자루 (34,40), 끝 (29,46). |
| skill_c 회수 | 돌아온 오른손 (37,41), 낮아진 반대 손 (26,41) | (38,29) | 오른손 자루 (37,42), 끝 (42,48); 반대 칼 자루 (25,42), 끝 (21,48). 붕괴 조각 (14,59)/(49,59). |

손목의 흰 감개에서 피부와 자루로 연결되는 부분을 유지했다.
그림자살의 기운 시작점은 결인 손과 단검이며, 복면 좌표는 얼굴 정렬을 위한 기준이다.
접촉 이후 그림자 조각은 원래 갈래의 축소본이 아니라 새로 찍은 끊어진 덩어리다.

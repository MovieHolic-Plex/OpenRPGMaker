# 눈 위치 추가 1px 수정

요청: 「1px 더 이동해봐」.

기존 eyes-right-v3의 18개 프레임에 `chosen-eye-runs.json`의 지정된
0기준 좌표와 ASCII 팔레트 문자열을 그대로 적용했다. 두 눈과 동반 눈썹을
화면 오른쪽으로 네이티브 1px 추가 이동했다. 눈 크기, 표정과 시선은 유지하며,
피격·중독 눈썹의 찡그림과 수면·사망의 닫힌 눈꺼풀도 유지했다.

`apply_eyes_right_v4.py`에 전체 literal 패치 사전과 바이트 단위 쓰기 도우미를
기록했다. 지정된 짧은 구간만 교체하므로 구간 밖 픽셀과 행 끝 형식은 그대로다.
교체 문자열은 모두 불투명 팔레트 문자이며 원래 구간도 불투명하므로 알파
실루엣은 동일하다. 얼굴 윤곽, 다른 피부, 코·입·머리·갓, 몸·옷·사지·무기·효과,
팔레트와 타이밍은 보존했다. 기존 비격자 파일과 AUTHORING.md/TIMING.md도
바이트 그대로 보존했다.

남은 시각적 판단: 추가 이동 후 눈과 얼굴 오른쪽 윤곽 사이 간격이 적절한지는
렌더링 비교로 판단할 사항이다. 기존 다른 표현상의 한계는 이번 수정 범위에
포함되지 않는다. 테스트·게이트와 비교판 생성은 실행하지 않았으며 사용자
승인을 주장하지 않는다.

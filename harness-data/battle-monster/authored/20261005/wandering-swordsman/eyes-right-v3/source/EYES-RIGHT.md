# 눈 위치의 최소 수정

사용자 요청 「좀 더 눈을 오른쪽으로 옮겨라」에 따라 기존 18개 프레임에
`chosen-eye-runs.json`의 지정된 짧은 픽셀 문자열만 적용했다.
좌표는 0부터 시작하는 원본 64×64 격자의 (x, y)이다.

두 눈과 해당 눈썹을 화면 오른쪽으로 원본 1픽셀 옮기는 수정이다.
눈의 크기와 표정, 시선을 유지하며, 수면·사망 프레임의 눈꺼풀은 닫힌 상태로 유지한다.
첨부 비교 그림의 오른쪽 fresh-eyes-v2를 기존 모습의 참고로 확인했다.

`apply_eyes_right.py`에 모든 지정 좌표와 최종 ASCII 문자열을 그대로 기록했다.
파일 쓰기는 지정 구간만 치환하고 나머지 바이트와 원래 줄 끝을 보존한다.
지정 구간 밖의 픽셀과 투명 실루엣, 얼굴 윤곽, 몸, 무기, 효과는 그대로 유지했다.
팔레트와 기존 모든 비격자 파일(AUTHORING.md, TIMING.md, 이전 inspect 도구 포함)은 보존했다.

추가 시각적 문제에 대한 재검토는 하지 않았다. 기존 저작 기록의 문제는 이번 좁은 수정의 범위에 포함하지 않는다.
테스트·게이트·검토판 생성은 수행하지 않았으며, 사용자 승인을 주장하지 않는다.

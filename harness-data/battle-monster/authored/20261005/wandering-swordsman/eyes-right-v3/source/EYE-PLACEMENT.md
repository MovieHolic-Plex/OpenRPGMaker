# 방랑 검객 — 눈 위치 수정 기록

사용자 지적: 「눈의 위치가 좀 이상하다야」.

기존 18개 완성 격자의 지정 눈 영역만 수정했다. `reference.png`의 얼굴 확대와 `references/current18.png`의 실제 18프레임을 시각적으로 살펴본 다음, 작은 ASCII 눈 영역과 주변 피부를 읽어 좌표를 선택했다. 참고 이미지의 픽셀을 추출하거나 원본으로 사용하지 않았다.

## 수정 순서와 픽셀 선택

먼저 `idle_a`를 수정하고 원본 크기 및 최근접 8배 비교를 열어 확인했다. 이어 나머지 17프레임의 실제 얼굴 좌표와 표정에 맞춰 각각 명시한 짧은 ASCII 문자열을 적용했다. 머리나 눈 덩어리의 이동·회전·복사로 자세를 만들지 않았다. 기존 얼굴 비율이 같은 정상 표정은 같은 비율을 유지하며 각 파일의 좌표를 따로 지정했다.

- `idle_a`의 먼 눈은 기존 x26–27에서 x28–29로 안쪽에 배치했다. 가까운 눈은 x32–33의 두 칸으로 정리했다.
- 두 눈의 어두운 `k` 동공을 각각 x29와 x33에 두고 y22–23에서 세로로 맞췄다. 이전 가까운 눈의 어긋난 어두운 칸과 세 칸 폭을 제거했다.
- 먼 눈은 위쪽 `ek`, 아래쪽 `uk`의 작은 덩어리로, 가까운 눈은 위쪽 `ek`, 아래쪽 `wk`로 골랐다. 밝은 칸은 가까운 눈 아래쪽 한 칸만 사용해 눈 크기를 억제했다.
- 따뜻한 `p` 눈썹을 새 눈 위에 놓고 피부 한 줄을 사이에 남겼다. 머리카락 옆까지 이어지던 눈썹은 끊었다.
- 피격·중독의 눈썹은 `t/p`의 서로 다른 온도로 찡그린 표정을 유지했다. 해당 얼굴 아래 눈 줄의 기존 왼쪽 `t` 피부 그림자도 보존했다.
- 기절의 두 눈은 열린 상태를 유지하며 아래쪽의 밝은 흰 칸을 생략했다. 동공의 세로축은 다른 열린 눈처럼 맞췄다.
- 수면·사망에는 `e`의 짧은 감긴 눈꺼풀만 사용했다. 수면의 먼 눈꺼풀을 얼굴 안쪽으로 옮기고, 사망의 먼 눈꺼풀을 두 칸으로 줄여 두 감긴 눈의 간격을 정리했다. 열린 동공이나 흰 칸을 추가하지 않았다.
- 없앤 눈·눈썹 칸은 해당 위치 주변의 `u` 피부, 수면의 왼쪽 `t` 그림자, 사망의 오른쪽 `t` 피부 면으로 복원했다. 경계의 머리카락과 피부 외곽 칸은 유지했다.

## 최종 좌표

좌표는 0부터 시작한다. 열린 눈의 x는 두 눈 각각의 어두운 동공 열이며, 해당 y의 두 줄에서 같은 열을 사용한다. 감긴 눈은 눈꺼풀의 가로 범위다.

## 보존 범위와 비교 보드

지정 사각형 밖의 원본 바이트와 각 행의 줄 끝은 그대로 보존했다. 사각형 안에서도 투명 칸, 머리카락·얼굴 외곽, 코·입·갓은 바꾸지 않았다. 몸·옷·팔다리·칼·칼집·효과, 1px 투명 여백, y60의 기본 자세 신발, 18색 팔레트 및 알파를 보존했다.

`AUTHORING.md`, `TIMING.md`, `REPAIR.md`, `WEAPON-REPAIR.md`는 기존 작업 기록으로 수정하지 않았다. `AUTHORING.md`의 이전 idle_a 보존 설명과 해시는 이번 눈 수정 전 상태에 대한 기록이며, 현재 변경 내용은 이 문서에 기록한다. 기존 타이밍이나 다른 산출물은 다시 작성하지 않았다.

`inspection/eye-placement-review.png`는 모든 18프레임의 수정 전/후를 나란히 보여 준다. 각 칸 위쪽은 실제 64×64 원본 크기, 아래쪽은 얼굴의 최근접 8배 확대다. 참고 이미지는 이 보드에 재배포하지 않았다.

`inspect_eye_placement.py`에는 수정 전의 작은 눈 영역 문자열과 각 파일의 명시적인 `(x, y, ASCII 문자열)` 수정 목록이 있다. 인수 없이 실행하면 비교 보드만 다시 만든다. `--apply`는 명시한 짧은 문자열을 원본 격자에 기록한다. 보드 확대는 확인용이며 원본 격자에 리샘플링을 적용하지 않는다.

## 남은 표현 한계

- 1배에서는 먼 눈의 흰 칸을 생략한 작은 덩어리가 짧은 어두운 획처럼 보일 수 있다. 성인 인상과 작은 눈 크기를 유지하기 위해 선택했다.
- 고정된 코·볼·얼굴 외곽 때문에 3/4 원근의 세부 표현은 제한된다. 이번 수정은 이 영역을 보존하면서 눈의 간격과 시선을 정돈한 것이다.
- 피격·중독의 미세한 눈썹 색 차이는 확대에서 더 잘 보인다. 기절 역시 열린 눈을 유지하므로 표정과 기존 자세·별 효과를 함께 읽어야 한다.
- 감긴 눈은 작고 단순한 따뜻한 두 획이다. 수면·사망의 의미는 기존 자세와 함께 전달된다.

비교 보드의 18개 수정 전/후를 시각적으로 확인했다. 테스트·게이트·게임 실행·저장소 통합은 수행하지 않았으며, 사용자 승인이나 선택을 주장하지 않는다.

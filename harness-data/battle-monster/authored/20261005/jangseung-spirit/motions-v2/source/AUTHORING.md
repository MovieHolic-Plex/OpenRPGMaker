# 장승귀 추가 동작 저작

## 범위와 원본

`actions/`의 추가 동작 9장을 64×64 ASCII 팔레트 인덱스 행으로 직접 저작했다. 기존 `palette.json`과 `poses/` 9장은 바이트 그대로 보존한다. 새 색은 추가하지 않았다. 점은 투명이며 각 파일은 전체 캐릭터와 해당 효과를 포함한다.

그림 생성, 도형 마스크, 프레임 이동·회전·보간, 자동 명암은 사용하지 않았다. 각 자세의 윤곽, 나뭇결 명암, 얼굴, 가지 팔, 뿌리 발, 효과 덩어리를 해당 행에 직접 지정했다. 기존 몸통의 읽히는 명암 행은 재사용하되 관절·머리 기울기·가슴·발·효과가 변하는 곳은 개별 저작했다. 행 끝 투명 칸의 길이 오타만 보정했다.

좌표는 좌상단 `(0,0)` 기준이다. 모든 추가 프레임은 1px 이상 투명 테두리를 가지며 가장 아래 잉크는 `y=60`이다.

## 명시한 픽셀 변화

| 동작 | 몸과 효과의 변화 |
|---|---|
| skill_a | 긴 몸을 세우고 양쪽 가지 팔을 얼굴 아래로 들어 올린다. 팔은 어깨의 나무 면에 연결된다. 입 안을 벌리고 작은 울림 조각을 찍었다. 앞쪽 뿌리는 `(36..42,55..58)`에 접어 올려 내려찍기 준비를 만든다. |
| skill_b | 꼭대기를 `y=19`로 낮추고 상체를 압축했다. 큰 입의 오른쪽에서 연결된 밝은 조각과 두 겹의 소리 파문이 나온다. 앞쪽 뿌리는 `(37..44,60)`에 펼쳐 접지한다. 뿌리 옆의 어두운 균열과 밝은 흙 조각을 `y=57..60`에 개별 배치했다. |
| skill_c | 머리를 다시 펴고 턱의 이빨을 정리했다. 가지 팔은 준비 때보다 낮고 앞쪽으로 풀린다. 양쪽 뿌리가 원래 높이로 돌아오며 오른쪽 바닥에 작은 잔여 조각만 남는다. |
| poison_a | 머리가 앞으로 처지고 눈이 가라앉는다. 벌어진 턱 아래 두 개의 탁한 방울, 아래로 늘어진 가지 팔, 구부러진 몸통을 그렸다. 서로 다른 크기의 독 거품 세 덩어리가 머리 주위에 있다. |
| poison_b | 가슴과 허리가 더 크게 구부러지고 왼쪽 가지는 배 가까이, 오른쪽 가지는 아래로 처진다. 턱 안과 흐르는 방울을 다시 찍었다. 큰 거품을 왼쪽 위로, 작은 거품을 얼굴 오른쪽으로 새로 배치했다. 전체 몸을 이동시킨 프레임이 아니다. |
| stun_a | 머리가 왼쪽으로 기울고 눈은 초점 없이 어두워진다. 팔을 아래로 떨어뜨렸다. `(44,12)`와 `(18,27)` 중심의 서로 다른 크기 별을 찍었다. |
| stun_b | 머리와 몸통의 연결을 다시 세우되 어깨는 여전히 처진다. 손 끝과 팔 길이를 다시 그렸다. 별은 `(21,14)`와 `(47,25)`로 바뀌며 이전 별을 복사·이동하지 않았다. |
| sleep_a | `(29..30,27)`과 `(35..36,27)`에 짧은 닫힌 눈꺼풀을 그렸다. 입은 얕게 닫고 가지 팔은 밑으로 내렸다. 가슴이 좁아진 호흡 자세와 입 옆의 작은 숨 구름을 찍었다. |
| sleep_b | 머리와 발은 같은 자리에 두고 `y=39..47`의 가슴·왼쪽 어깨 윤곽과 밝은 나무 면을 넓혔다. 내려놓은 가지 팔 연결도 다시 찍었다. 숨 구름은 더 멀리 퍼지는 불규칙한 밝은 덩어리이며 글자나 수면 기호를 넣지 않았다. |

비대칭 새긴 얼굴, 왼쪽 위의 나무 밝은 면, 오른쪽의 붉은 갈색 그림자, 새끼줄 띠, 갈라진 뿌리 발을 전 동작에서 유지했다. 무기는 없는 종이므로 손에 해당하는 가지 끝을 움직인다. 상태 동작은 공격 자세의 색 교체로 만들지 않았다.

## 시각 확인과 남은 문제

메모리에서 원본 1배와 픽셀 확대 접촉 시트를 렌더링하여 직접 확인했다. 소리 파문이 번개처럼 꺾여 보이던 부분은 바깥으로 퍼지는 두 겹의 곡선 덩어리로 수정했다. 수면의 구불거리는 숨은 글자처럼 읽히지 않도록 불규칙한 구름으로 수정했다. 저장된 원본은 문자 격자이며 미리보기 그림은 파일로 남기지 않았다.

- 고정 팔레트에 녹색·보라색이 없어 독 거품은 탁한 회갈색이다. 독의 의미는 아픈 자세, 거품의 테두리와 변화, 턱 아래 방울에 의존한다.
- 1배에서는 작은 숨 구름과 바닥 잔여 조각의 변화가 약하다. 수면은 감은 눈과 가슴 폭 변화가 주된 단서다.
- 스킬은 세 장뿐이어서 준비에서 내려찍기로 넘어가는 동작이 빠르다. 권장 홀드는 `TIMING.md`에 적었으며 실제 재생에서의 느낌은 후속 GIF 검토가 필요하다.
- 전원 지진의 피해·접촉·화면 흔들림·음향은 이 격자만으로 구현되지 않는다. 실제 전투 연동은 확인하지 않았다.

테스트와 게이트는 실행하지 않았다. 사용자 승인이나 독립 검수 통과를 주장하지 않는다.

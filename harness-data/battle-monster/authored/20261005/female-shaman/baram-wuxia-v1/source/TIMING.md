# 홍련 무녀 동작·검수용 시간 의도

좌표는 원본 64×64의 0부터 시작하는 (x,y)다. 아래 홀드는 시각 검수용 제안이다. 실제 제작 GIF 시간은 하네스가 공급하며, 이 문서는 런타임 전투의 피해·투사체·음향 타이밍을 입증하지 않는다. GIF는 이 작업에서 제작하지 않았다.

| 묶음 | 자세 순서 | 제안 홀드(ms) |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 각 240 |
| 부적 공격 | windup → move → attack → recover → idle_a | 240 / 120 / 140 / 220 / 240 |
| 피격·쓰러짐 | hit → dead | 180 / 마지막 자세 유지 |
| 홍련화 | skill_a → skill_b → skill_c → idle_a | 320 / 140 / 260 / 240 |
| 독 | poison_a ↔ poison_b | 320 / 360 |
| 기절 | stun_a ↔ stun_b | 280 / 320 |
| 수면 | sleep_a ↔ sleep_b | 520 / 600 |

## 홍련화의 실제 그림 앵커

- **모으기 / skill_a:** 손 덩어리는 (42,31)에서 종이를 감싸고 다른 손은 (43,34)에 있다. 종이의 윗모서리 (45,28)에 작은 불씨의 밝은 핵 (46,27)이 닿는다. 청동 방울은 (50,29) 부근에서 종이와 나란히 놓인다. 팔·소매가 가슴 앞으로 올라온다.
- **접촉·펼침 / skill_b:** 앞 손은 (45,29), 종이 모서리는 (49,29), 세 갈래의 분기 핵은 (52,29)다. 위쪽 혀는 (57,17), 가운데 혀는 (60,29), 아래쪽 혀는 (57,39) 방향으로 각각 직접 찍었다. 세 갈래는 손의 종이에서 시작하는 연속된 빨강·금빛 덩어리다. 반대 손은 몸 앞의 방울 손잡이를 잡고 보폭은 넓어진다.
- **부서짐·회수 / skill_c:** 팔과 소매를 내리며 방울을 허리 아래로 회수한다. 종이·불씨는 (52,22), (58,28), (50,32), (55,35) 등에서 크기와 방향이 다른 작은 잔재로 끊어진다. 주 불꽃을 축소하거나 옮긴 프레임이 아니다.

독의 두 프레임은 눈·목·배를 누르는 손과 기포 모양이 바뀐다. 기절은 눈꺼풀·입·어깨와 별의 위치가 바뀐다. 수면은 두 눈이 닫힌 채 머리가 더 숙여지고 가슴·소매가 내려간다. 상태 프레임 사이에 공격 자세를 끼우지 않는 시각 의도다.

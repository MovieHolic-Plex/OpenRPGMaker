# 홍련 무녀 — baram-wuxia-v1

신규 원본 후보. 사용자 선택·승인 및 하네스 독립 검수는 아직 이루어지지 않았다.

## 실루엣과 재질

- 64×64 원본, 공통 18색. 대기 본체 y8–60, 높이 53px. 검은 반묶음 머리, 작은 붉은 매듭과 뒤로 이어진 머리카락, 미색 넓은 소매, 남색 교차깃·허리띠, 금빛 허리 매듭, 홍색 치마와 두 남색 신발.
- 얼굴은 좁은 성인 SD 우향 3/4. 밝은 앞볼에 두 눈과 별도 갈색 눈썹을 두고, 두 동공을 눈의 오른쪽에 놓았다. 코의 살색 돌출과 작은 입은 머리 외곽선과 구별했다.
- 좌상광: 소매 윗면은 밝은 미색 덩어리, 아래 접힘은 회갈색; 치마 왼쪽은 넓은 산호홍색 면, 안쪽 주름과 오른쪽 면은 자주색 그림자. 검은 머리에는 제한된 남색 반사만 썼다. 방울은 청동 외곽·노란 반사·작은 밝은 핵, 손잡이는 짙은 갈색이다.
- 손은 소매에서 이어지는 살색 짧은 덩어리. 종이는 연노랑 좁은 직사각형이며 글자가 없다. 목걸이·무작위 장식 점·검·지팡이는 추가하지 않았다.

## 직접 선택한 동작

- idle_b/c: 가슴·소매 가장자리와 주름, 머리 매듭·꼬리의 짧은 픽셀 변화. 발과 시선은 안정적으로 유지.
- windup: 머리를 낮추고 부적과 방울을 가슴 앞으로 모았다. move: 앞 무릎과 발을 오른쪽에 내딛으며 뒷 치맛자락이 들린다. attack: 부적을 보내는 팔을 뻗고 방울 팔은 아래로 이어졌다. recover: 소매를 내리고 방울을 허리 아래로 회수.
- hit: 얼굴을 뒤로 젖히고 두 눈을 찡그리며 입을 벌린다. dead: 머리·상체·치마를 가로로 새로 그려 두 감긴 눈, 옆으로 접힌 소매와 몸 아래 주름을 넣었다. 바닥의 방울·종이는 손에서 놓친 소품이다.
- skill_a/b/c: 부적 옆 불씨를 모으는 두 손 → 펼친 팔과 종이 모서리에 연결된 세 갈래 불꽃 → 내려가는 팔과 분리된 따뜻한 종이·불씨 잔재.
- poison_a/b: 배를 누르는 손, 내려간 방울, 서로 다른 굽힌 목·얼굴과 독 기포. 기포는 흰 핵과 탁한 녹색 가장자리이며 얼굴 전체를 색칠하지 않았다.
- stun_a/b: 벌어진 입, 서로 다른 눈꺼풀과 기운 머리, 늘어진 두 소매·손, 각기 다른 위치와 모양의 금빛 별.
- sleep_a/b: 두 눈을 실제로 닫고 손과 방울·종이를 낮췄다. 두 번째는 더 숙인 머리와 눌린 가슴·소매로 숨 내쉬는 상태를 그렸다.

## 원본과 확인

`poses/` 9개와 `actions/` 9개는 각각 64행 × 64개의 ASCII 팔레트 인덱스다. `author.py`에는 직접 고른 행과 짧은 좌표 패치가 남아 있다. 보조 코드는 행 저장, 원본 해독, 최근접 확인판 제작만 수행한다. 참고 그림에서 픽셀을 추출하지 않았다.

`progress/idle.png`, `idle-8x.png`, `face.png`를 먼저 저장해 1배·8배로 확인했다. 최종 `progress/contact-sheet.png`에는 18개의 원본 크기와 확대본이 있다. 18개 모두 서로 다른 격자이며, 모든 잉크는 x1–62/y1–60 안에 있고 대기 발바닥은 y60이다. 렌더 이미지의 알파는 0/255다. 이 확인은 파일·시각 확인이며 미술 승인이나 실제 전투 검증을 뜻하지 않는다.

## 남은 시각적 한계

- 1배에서 3px 폭의 종이와 작은 청동 방울은 작은 화면에서 구분이 약해질 수 있다. 상호 위치·밝기·손잡이로 구별했으나 실제 GIF 검수에서 다시 볼 부분이다.
- 넓은 보폭에서 들린 뒤 치맛자락과 깊은 안쪽 주름은 분할된 무협 의복처럼 읽힐 수 있다.
- 그림 시트로 검토했다. 하네스의 GIF 연결과 실제 표시 크기에서의 시간·접촉 가독성은 후속 검수 대상이다.

## baram-wuxia-v2 — QUALITY_REPAIR 한정 수선 기록

위의 v1 초안 설명과 당시 남은 문제는 이력으로 보존했다. 현재 결과는 이 절과 아래 PNG를 기준으로 읽는다. 수선 전 18개 격자·팔레트·문서·기존 확인판은 `history/before-quality-repair/`에 바이트 그대로 보관했다. 기존 `author.py`와 `inspect.py`는 수정하지 않았다. `author.py`는 v1 초안의 저작 기록이므로 실행하면 이번 수선 격자를 덮어쓴다. 현재 정본은 `poses/`와 `actions/`의 완전한 리터럴 행이다.

### 실제로 바꾼 클러스터

- **치마:** 서 있는 자세의 y54–57에서 두 다리처럼 내려가던 자주색 띠를 사선으로 접히는 홍색 천으로 연결했다. 밑단 안쪽의 검은 홈을 자주색 천으로 바꾸어 한 장의 치마가 두 신발 위에 내려오도록 했다. 굽힌 자세에서는 y57의 가운데 투명 구간을 겹친 어두운 밑단으로 채웠다. `move`, `attack`, `skill_b`는 y51–57의 안쪽 주름·갈라진 윤곽을 각각 직접 다시 찍었다. 뒷발 위의 높게 들린 자락에서 앞발 위의 낮은 자락으로 천이 이어지며, y54–56의 투명 갈라짐은 사라졌다. 기존 신발 픽셀과 접지선은 유지했다. `dead`는 y60/x44–46의 검은 안쪽 홈만 자주색 밑단으로 연결했다.
- **방울:** 자세별 손 위치에 맞춰 3px의 둥근 윗면, 5px의 가운데 두 행, 3px의 아래 그림자 클러스터를 직접 골랐다. 좌상단의 `f/w`, 청동 몸체의 `g`, 아래와 오른쪽의 `k`가 금속 부피를 만든다. 길게 뻗은 금빛 끝과 비스듬히 흩어진 반사점을 지우고, 손가락에 닿는 짧은 갈색 손잡이를 남겼다. 쓰러짐의 방울은 손에서 놓친 바닥 소품으로 유지했다.
- **부적:** 연노랑 `f` 면의 위·왼쪽 경계와 접힌 아래 모서리에 갈색 `k`를 찍었다. 이미 있던 갈색 세로 가장자리는 유지하고, 미색 소매와 맞닿던 밝은 끝을 갈색으로 구분했다. `skill_b`의 종이 시작점은 (49,28), (48,29), (49,30)의 갈색 가장자리로 정리했다. `skill_c`는 이미 종이가 불씨·파편으로 갈라진 회수 단계이므로 별도의 온전한 종이를 추가하지 않았다. 부적에 글자를 넣지 않았다.

| 자세 | 바뀐 원본 픽셀 수 |
|---|---:|
| idle_a / idle_b / idle_c | 30 / 32 / 34 |
| windup / move / attack | 34 / 70 / 68 |
| recover / hit / dead | 37 / 42 / 15 |
| skill_a / skill_b / skill_c | 33 / 64 / 30 |
| poison_a / poison_b | 37 / 46 |

| sleep_a / sleep_b | 32 / 37 |

`QUALITY_REPAIR.md`는 관련 18자세 전체의 치마·소품을 지정하므로 모든 격자에 해당 클러스터 수선을 적용했다. 얼굴과 눈 간격, 눈썹·코·입 좌표, 머리와 매듭, 상체·소매의 정체성, 기존 살색 손가락 픽셀은 보존했다. 주문 불꽃의 세 갈래와 파편, 독 기포, 기절 별, 수면의 감긴 눈과 호흡 차이도 보존했다. 팔레트와 두 기존 보조 파일은 수선 전 SHA-256과 같다.

### 저작과 PNG 확인

이번 수선은 자세별로 직접 선택한 `(y, x, ASCII 문자열)`을 기존 행의 해당 위치에만 썼다. 저장된 모든 `.pxgrid`는 생략 없는 64행 × 64열이다. 수식으로 형태나 명암을 만들거나 프레임 전체를 이동·회전·보간하지 않았다. 참고 4장은 눈·손·소매·금속의 가독성 관찰에만 사용했고, 어느 이미지에서도 원본 픽셀을 얻지 않았다.

- `progress/<자세>.png`: 현재 18개 격자를 팔레트로 직접 해독한 투명 native64 PNG.
- `progress/repair-suite.png`: 전체 18자세의 1배와 정확한 최근접 3배 확인판. 실제로 열어 치마, 손·방울·부적, 얼굴과 상태 차이를 확인했다.
- `progress/repair-before-after.png`: 보존 격자와 현재 격자를 각각 해독한 6자세의 최근접 4배 비교판. 이동·공격·시전의 천 연결과 작은 소품을 다시 열어 확인했다.
- `progress/repair-inventory.json`: 렌더 과정에서 읽은 크기·잉크 범위·수선 픽셀 수·현재 격자 해시. 18개 모두 서로 다른 격자다.

격자는 모두 64×64이며, 잉크 범위는 x1–62/y1–60 안에 있고 `idle_a` 신발 바닥은 정확히 y60이다. PNG는 원본 팔레트 18색과 알파 0/255를 사용한다. 확대와 체크 배경은 확인판에만 적용했으며 격자 저작에 되먹이지 않았다. 기존 `idle.png`, 확대·얼굴 PNG 등의 호환 이름도 현재 격자로 다시 렌더했다. 테스트·게이트는 실행하지 않았다.

### 현재 남은 시각적 문제

- 치마는 이제 연결된 천으로 읽히지만 넓게 내딛는 3자세에는 강한 대각 주름이 남는다. 1배의 빠른 재생에서 무릎 형태가 지나치게 강조되는지는 후속 GIF 검수에서 볼 부분이다.
- 방울 몸체는 5×4px, 부적 면은 약 2–3px 폭이다. `skill_a`와 `poison_b`에서는 손·종이·방울이 가까워 작은 화면에서 구분이 약해질 수 있다.
- 부적 공격의 `attack` 종이는 손을 떠나는 기존 단계이며, `skill_c`는 파편만 남는다. 각 단계의 원래 연결·분리 시점은 이번 수선에서 바꾸지 않았다.
- 이번에는 정지 PNG를 확인했다. 실제 속도의 GIF, 하네스 독립 검수, 전투 표시·접촉 시점은 확인하지 않았다. 사용자 Allow/Modify/승인을 주장하거나 생성하지 않았다.

# 자세 순서와 앵커

좌표는 native 64×64의 0부터 시작하는 `(x,y)`다. 아래 홀드는 저작용 제안이며 하네스가 공급하는 제작 GIF 시간이 정본이다. 런타임 전투에서 재생·발사·피해 시점을 측정하거나 검증하지 않았다.

| 클립 | 순서 | 저작용 홀드 제안 |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 각 220ms, 반복; 계약의 idleFrameMs 사용 |
| 부적 투척 | windup → move → attack → recover → idle_a | 220 / 110 / 140 / 220 / 220ms |
| 피격 | hit → recover → idle_a | 180 / 220 / 220ms |
| 쓰러짐 | hit → dead | 160 / 800ms; dead 유지 |
| 금화부 | skill_a → skill_b → skill_c → idle_a | 260 / 160 / 260 / 220ms |
| 독 | poison_a → poison_b | 각 360ms, 반복 |
| 기절 | stun_a → stun_b | 각 300ms, 반복 |
| 수면 | sleep_a → sleep_b | 각 650ms, 반복 |

## 금화부

- `skill_a`: 종이는 x42–47/y26–29, 손이 만나는 부분은 x36–43/y31–33. 앵커 `(42,32)`. 왼쪽 소매가 몸 앞을 가로질러 오고 반대 손이 종이 아래를 받친다. 종이 위 x41–43/y23–25에 짧은 주홍 점화 덩어리를 찍었다.
- `skill_b`: 앞으로 뻗은 손의 접점 `(48,33)`, 종이의 왼쪽 가장자리 x49/y31–35. 세 불꽃은 낮은 왼쪽 갈래(x48–51/y23–28), 긴 중앙 갈래(x54–57/y18–28), 굽은 오른쪽 갈래(x59–62/y24–29)로 각각 다른 끝·외곽·밝은 핵을 그렸다. 이 프레임은 접촉/최대 발광 표시다. 입에서 발사하는 기술이 아니다.
- `skill_c`: 내려온 손 `(42,39)`. 종이 조각은 x57–60/y28–37와 x58–59/y45–46, 잔불은 x48–54/y25–43에 끊어진 별개 덩어리로 남는다. 손·소매·도포는 회복 자세로 다시 그렸다. 큰 불꽃을 축소하거나 옮겨서 만든 잔상이 아니다.
- 양손 결인 동안 목검은 왼쪽 허리의 가드 x18–23/y40에 끼워 아래로 내려간다. 회복에서는 왼손이 다시 가드를 잡는다.

## 일반 투척과 상태

`windup`은 얼굴 앞 부적, `attack`은 x46–53/y31–33의 뻗은 손과 x55–60/y27–30의 떨어진 부적을 보여 준다. 작은 불씨는 x54–57/y31–33이다. 피해 판정이나 투사체 속도를 그리드의 홀드 시간으로 추정하지 않는다.

독의 두 기포군은 복통 → 입 가림 사이에서 모양과 위치가 바뀐다. 기절 별은 서로 다른 위쪽 위치에서 빛나며 머리와 팔도 바뀐다. 수면은 두 프레임 모두 닫힌 눈이고, 목검의 끝은 각각 `(49,59)`, `(50,60)`까지 낮아진다. 호흡은 머리·소매·허리·도포의 선택한 행 변화로 표현했다.

# 타락 도사 — 직접 픽셀 저작 후보

## 범위와 저작 방식

- 제공된 `source/poses`는 비어 있었다. 이번 후보의 팔레트와 기본 9자세, 추가 9자세를 새로 저작했다.
- 64×64 원본의 최종 팔레트 기호를 행 단위로 직접 지정했다. 변경 프레임은 유지할 행을 재사용하고, 바뀌는 행의 최종 64픽셀을 직접 지정했다. 저장된 모든 pxgrid는 64개의 완전한 ASCII 행이다.
- 몸체·무기·효과에 도형 래스터화, 전체 몸 이동·회전·보간, 자동 명암을 사용하지 않았다. 팔레트는 18색이며 `.`은 투명이다.
- `REVIEW.png`는 원본을 디코드한 3배 최근접 확인판이다. `previews/*.gif`는 원본 64×64 픽셀과 같은 팔레트를 사용하는 재생 참고 자료다. 확인판의 이름표는 그림 원본에 들어 있지 않다.
- 후보의 source 안에만 저장했다. 사람의 승인이나 게임 설치를 뜻하지 않는다. 테스트·게이트·하네스 검사·독립 검수는 실행하지 않았다.

## 실루엣과 재질

- 오른쪽을 보는 3/4 얼굴, 비대칭 복건 앞면과 뒤쪽 늘어진 끈, 드러난 코와 한쪽 눈을 그렸다. 복건은 K/N/H의 검은 계열이며 밝은 면은 왼쪽 위에 있다.
- 자주색 긴 도포는 어깨에서 발등까지 내려온다. y=42–57의 사선 주름, 중앙 겹침과 오른쪽 어두운 면을 직접 지정했다. 옷자락이 짧게 드러난 신발보다 훨씬 크다.
- 회색 긴 수염은 W/D/G의 연결된 덩어리로 턱 아래에서 가슴까지 이어진다. 털 끝과 겹침은 각 동작의 손과 소매 앞뒤 관계에 맞춰 바꿨다.
- 왼손 나무 검은 A/B 두 색으로 밝은 나무 면과 어두운 측면을 나눴다. 오른손 부적은 Y의 연노랑 종이와 어두운 모서리로 그렸고 글자를 넣지 않았다.
- idle_a 신발 바닥은 정확히 y=60이다. 모든 자세의 가장 아래 잉크는 y≤60이며 가장자리에는 투명 여백을 두었다.

## 추가 9자세에서 직접 바꾼 부분

- **skill_a:** 부적 아래에서 받치는 손과 옆에서 결인하는 손을 모두 소매에 연결했다. 나무 검은 왼쪽 허리에 내려 붙이고 작은 황금 점 하나만 준비 효과로 그렸다.
- **skill_b:** 두 손을 종이 아래와 옆으로 전진시켰다. 서로 다른 높이와 꺾임의 세 불꽃을 종이 위에 연결했다. 주홍 F의 바깥면과 Y의 밝은 중심을 각 행에 직접 지정했다. 양쪽 옷자락을 펼쳤다.
- **skill_c:** 손과 도포가 돌아오는 회복 자세에 작은 종이 조각 네 덩어리와 끊어진 주홍 불씨를 새로 그렸다. 공격의 온전한 부적을 재사용하지 않았다.
- **poison_a/b:** 머리를 낮추고 어깨를 굽혀 배를 움켜쥐게 했다. 나무 검과 부적은 아래에 있다. 두 프레임의 녹색 거품은 위치·크기·빈 중심·밝은 가장자리를 각각 그렸다. 입과 수염, 복부 손도 변한다. 몸 전체를 녹색으로 물들이지 않았다.
- **stun_a/b:** 머리가 아래로 처지고 두 팔이 늘어진 자세, 낮은 검과 부적을 그렸다. 별은 서로 다른 위치에 직접 찍었다. 수염 끝·손의 높이·도포 주름도 바뀐다.
- **sleep_a/b:** 눈꺼풀을 닫고 두 팔을 허리 앞에서 접었다. 나무 검은 손에서 아래로 내려간다. 어깨·가슴·수염의 숨쉬는 변화와 작고 큰 숨결 덩어리를 각각 그렸다. 글자나 Z 기호를 그리지 않았다.

## 눈으로 확인한 내용과 남은 표현 문제

18자세 확인판을 직접 열어 실루엣, 색, 손과 소매의 연결, 효과 차이를 보았다. 기본 공격의 짧은 불씨와 금화부의 세 갈래 불꽃은 서로 다른 크기와 형태다.

- 1배에서 idle의 숨쉬는 변화는 작다. 눈에 띄는 몸 흔들림보다 수염과 소매의 작은 변화를 선택했다.
- 결인하는 손가락은 64px 한계 때문에 작은 살색 덩어리로 읽힌다. 특히 skill_a에서 손·종이·수염이 가까워 손가락별 동작은 단순하다.
- 검은 좁은 나무 면 두 색으로 표현했다. 허리에 내린 skill_a/b에서는 칼날보다 짧은 목검 또는 목제 의식 도구처럼 보일 수 있다.
- dead는 무너진 다음의 한 자세다. 넘어지는 중간 연결은 기본 9자세 계약 안에서 생략했다.
- GIF는 저작된 자세의 순서 참고 자료다. 실제 전투의 투사체·착탄·피해 시점과 독립 시각 검수는 확인하지 않았다. 사용자 판단 대기 후보다.

# 초롱도깨비 · 지적 부위 직접 픽셀 교정

## 현재 범위와 보존

- 기존 후보의 기본 9자세(`poses/`)와 기술·상태 9자세(`actions/`)를 모두 유지했다. 각 파일은 완전한 96행×96 ASCII 글자의 pxgrid다. `.`은 투명이고 팔레트에 없다.
- 이번 수정은 `sleep_a`, `sleep_b`, `dead`, `skill_b` 네 자세에 한정했다. 다른 14자세와 18색 팔레트는 교정 직전 사본과 바이트가 같다. 얼굴, 단일 뿔, 머리, 조끼, 초롱, 기존 공격 자세의 정체성을 보존했다.
- 교정 직전 원본 18개, 팔레트, 저작 보조 코드와 문서를 `originals/before-anatomy-emission-repair/`에 보존했다. `source-hashes.json`은 그 사본의 실제 파일 해시다. 이전 `first-complete`, `before-grip-outlet-repair` 사본도 그대로 있다.
- `repair_anatomy.py`는 직접 고른 `(x, y, ASCII 색 문자열)`만 기록한다. `author_pixels.py`의 마지막 저장 전에 이번 좌표를 적용하도록 연결했다. 원본을 보조 코드에서 다시 기록해도 교정이 보존된다.
- PNG/GIF, 확대 진단, 차이 기록과 이 문서는 모두 `source` 안에 저장했다. 저장소·게임 저장소·ledger·brief·검수 결과·다른 후보에는 쓰지 않았다.

## 참고 관찰과 저작 방식

첨부된 현재 18자세 시트와 `references/human-size.png`를 실제로 먼저 열었다. 붉은 피부, 검은 머리/한 뿔, 남색 조끼와 금색 여밈, 갈색 바지, 맨발과 초롱을 관찰했다. 검객 참고는 작은 눈·목·손/무기 연결의 시각 관찰에만 사용했다. 참고 픽셀을 추출·추적·재샘플링하거나 source에 재배포하지 않았다.

수정 픽셀은 직접 선택한 짧은 ASCII 문자열이다. 원/다각형/수식 실루엣, 자동 명암, 프레임 전체 이동/회전/보간, 이미지 생성, 자동 연결 또는 구멍 채움을 사용하지 않았다. 각 현재 pxgrid에는 효과까지 포함한 전체 캐릭터가 저장되어 있다. 읽기·PNG/GIF 렌더링·진단 배경/라벨·최근접 확대·차이와 해시 계산만 코드가 보조한다.

좌표는 0부터 시작한다. 변경 수와 범위는 교정 직전 격자와 현재 격자를 직접 비교한 결과다. 완전한 좌표/이전/현재 색은 `previews/anatomy-diff.json`에 있다.

### 수면 팔꿈치와 여밈

- 기존 y77의 x55..56 검은 연결을 실제 붉은 피부로 교체했다. y75..77의 윗팔에는 왼쪽 위를 받는 살구빛 면을 찍고, y77에서 윗팔 x53..56과 전완 x57..60이 연속된 피부 면으로 만난다.
- y78..79의 안쪽 굽힘은 붉은 그림자로 접었고, y80의 x54..57은 바깥 아래 윤곽으로 정리했다. 확대 확인 후 y79의 기존 전완 대각선과 손 쪽 배열을 보존하도록 직접 수정했다.
- 손/초롱의 원래 접합은 그대로 두었다. 팔 아래의 의도된 빈 공간은 남겼다. 검은 윤곽만 맞닿아 팔을 이어 보이게 하지 않았다.
- sleep_b의 x43..44, y75..76과 x42..44, y77을 `YK`, `KYK`로 직접 복원했다. 금색 여밈 x43은 두 자세 모두 y74..83에 연속한다.
- sleep_b의 기존 작은 어깨/접힌 손/핵 변화는 보존하고, x40, y73..75의 연결된 가슴 밝은 면을 한 칸 넓혔다. 호흡 때문에 금색 여밈의 색이 바뀌지 않는다. 눈은 계속 감겨 있으며, 자세는 누운 dead와 다른 앉은 자세다.

### 쓰러짐 다리

- 기존 남색 몸통 끝 x63..65, y79..81에서 이어지는 갈색 바지 윗면과 그늘을 직접 그렸다. 초롱 위/뒤를 지나 x69..74, y82..85로 내려온다.
- x71..75, y85..90의 갈색 천 → 붉은 피부를 찍어 원래 발목과 뒤꿈치에 이어 주었다. 초롱의 종이/테두리와 발끝, y91..92 바닥 접촉은 보존했다.
- 발을 이어 보이게 하는 근거는 이제 바닥의 검은 줄뿐 아니라 위쪽의 실제 천/피부 면이다. 감긴/흐려진 눈과 가로로 내려온 본체는 그대로다.

### 기술 발사구

- 손잡이 오른쪽 기둥 x73과 실제 쥔 손을 보존했다. 기둥 바로 오른쪽 x75..77, y48에 금갈색/어두운 윗입술을 찍었다.
- y49의 x74..78에는 금색 입구와 상아빛/황금 불꽃 목을 직접 찍었다. 내부 핵에서 올라오는 y50의 밝은 면이 이 입구를 지나 기존 오른쪽 세 갈래에 이어진다.
- y51의 x73..76에는 아래 테두리와 종이 외벽을 정리했다. x77, y51..58의 기존 투명 공기 틈과 오른쪽 불꽃은 남겼다. 기존 밝은 접점만 두었던 y50에서 한 행 위로 출구가 열리고, 위·아래 테두리가 그 입구를 구분한다.
- skill_a의 모으기와 skill_c의 회수/두 잔불은 바꾸지 않았다. 효과는 초롱 입구에서 나온다.

## 실제로 열어 확인한 그림

- 수정 전 `anatomy-before.png`, 수정 후 `anatomy-after.png`, 좌표가 붙은 `anatomy-coordinate-details.png`를 열었다. 팔꿈치의 피부 면, 바지/발목, 발사구 테두리와 실제 손/손잡이 연결을 확인했다.
- 현재 18자세의 밝은/어두운/체커 원본 1배 시트와 최근접 3배 시트를 모두 실제로 열었다. 의도한 팔/다리 사이와 손잡이 빈 공간은 남아 있다. 수정 부위에 의도하지 않은 투명 사각 홈이나 떠 있는 피부/발을 새로 발견하지 않았다.
- 8개 GIF를 현재 격자로 다시 저장하고 실제 저장 파일을 디코딩했다. idle/attack/hit/dead/skill/poison/stun/sleep의 디코딩 확인판을 모두 열어 자세 순서와 연결부, 변경 프레임의 차이를 확인했다. 모든 저장 프레임은 동일 배경 위의 원본과 색 차이 0픽셀이며, 저장된 유지 시간은 `TIMING.md`와 같다.
- 이 확인은 저장된 GIF 프레임 확인판의 관찰이다. 브라우저 연속 재생이나 실제 전투 영상에서 점프/접촉 시간을 평가한 기록은 아니다.
- `render.py`의 원본 읽기에서 96행×96열, 투명 테두리, y≤92, idle_a 최하단 y=92를 확인했다. idle_a 잉크 범위는 x25..80, y10..92다. 18개 완전한 배열은 서로 다르며 모두 ASCII다. 색은 기존 18색이다. 이것은 자산 형식 진단이고 테스트/게이트 실행이나 미감 통과 선언이 아니다.
- `previews/source-image-hashes.json`, `gif-decoded-report.json`, `anatomy-diff.json`의 해시는 실제 현재 파일에서 계산했다. 모델 출처나 독립 검수 binding을 작성하거나 수정하지 않았다.

## 남은 시각 한계와 검수 상태

- 수면 호흡은 어깨/가슴 면/접힌 손/핵의 작은 변화이며 1배에서는 미세하다. 얼굴과 앉은 기본 실루엣은 안정적으로 유지한다.
- 발사구는 작은 두 행의 밝은 목이다. 밝은 배경에서는 종이/황금 핵과 밝은 불꽃의 대비가 낮고, 어두운 윗입술/아랫입술이 읽기를 보조한다.
- 어두운 배경에서는 머리와 조끼 외곽의 대비가 낮다. 기존 몸통의 재질 명암은 단순하며 이번 수정 범위 밖이다.
- 초롱이 쓰러진 골반 일부를 가린다. 바지에서 발목으로 내려오는 연결은 이번에 추가했지만 전체 다리를 드러내는 자세는 아니다.
- 기존 준비→전진에서 초롱의 위치 변화가 크고, 머리 움직임은 어깨/발에 비해 절제되어 있다. 중간 자세를 추가하거나 전체 프레임을 변형하지 않았다.
- 이번 source는 검수에 다시 제출할 수정 후보다. 별도 검수자를 호출하지 않았고 하네스의 새 독립 검수 결과를 만들지 않았다. 사용자 승인·Allow·전종 통과를 선언하지 않는다. 테스트/게이트는 실행하지 않았다.

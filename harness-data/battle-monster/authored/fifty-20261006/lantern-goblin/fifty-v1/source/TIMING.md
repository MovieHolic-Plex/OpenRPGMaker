각 원본은 native 96×96이고 시간 단위는 ms다. 아래 순서/시간을 `previews/*.gif`에 저장했다. 검토용 GIF는 어두운 불투명 배경으로 반복하며 pxgrid/PNG는 투명을 유지한다. 추가 보간 프레임은 없다.

## 공격의 지지와 연결

- windup: 뒤쪽 왼편으로 든 초롱. 오른쪽 손잡이 기둥 x21, y41 부근을 손가락 x21..24, y40..43이 감싼다. 손목 x23..29, y44..45 → 전완 x25..43, y46..53 → 가슴 앞 팔꿈치/어깨로 이어진다. 벌린 무릎과 뒤 지지발이 준비를 받친다.
- move: 뒤꿈치를 들고 앞 정강이와 발을 내딛는다. 초롱 손은 골반 옆으로 내려와 휘두르기를 준비한다.
- attack: 어깨/팔꿈치를 오른쪽으로 열고 앞발에 하중을 둔다. 팔/손이 초롱 손잡이에 이어진 접촉 자세다.
- recover: 팔꿈치를 접어 손/초롱을 배 앞으로 당기고 발을 몸 쪽으로 회수한다.

## 등화격 · 손/초롱/효과 앵커

좌표는 0부터 시작한다. 입이나 뿔에서 나오는 기술이 아니라 실제 쥔 초롱의 입구에서 발사하는 기술이다.

| 단계 | 손/초롱 앵커 | 핵과 효과 |
|---|---|---|
| skill_a · 모으기 | 그립 x59..65, y45..50 → 뒤쪽 손잡이. 반대 손 x58..63, y62..66이 밑면을 받친다. | 내부 x64..69, y54..58의 상아/황금 핵. 기존 준비 배열을 유지했다. |
| skill_b · 발사/접촉 | 그립 x61..67, y48..53 → 손잡이. 받치는 손 x60..64, y61..65. 오른쪽 기둥 x73, y45..49도 연결을 유지한다. | 내부 핵 x68..72, y55..59 → 상승하는 밝은 면 x69..73, y51..54 → y50의 밝은 목 → 입구 x74..77, y49 → 기존 갈래. 윗입술 x75..77, y48은 금갈색/어두운 색, 아랫입술 x73..76, y51은 금갈색/어두운 색이다. x77, y51..58의 공기 틈은 종이 외벽과 아래 갈래를 구분한다. 위 갈래 y26..50, 짧은 오른 갈래 y43..53, 아래 갈래 y54..71. 최대 x93으로 투명 테두리를 남긴다. |
| skill_c · 회수 | 당긴 손 x45..51, y67..70 → 낮아진 초롱 손잡이. | 큰 갈래를 거두고 x80..84, y48..53과 x85..88, y67..71의 서로 다른 잔불 두 개. 기존 회수 배열을 유지했다. |

기술 효과는 각 완전한 action 격자의 리터럴 픽셀이다. 원 오라나 생성 효과를 합성하지 않았다. 이번 수정은 skill_b의 입구만 변경한다.

## 상태의 자세와 호흡

- poison_a/b: 낮춘 머리, 턱을 받친 팔과 아픈 어깨. 눈/턱/팔의 작은 배열과 독 방울 위치/크기가 바뀐다.
- stun_a/b: 처진 머리/팔/초롱. 두 별의 위치와 크기, 손과 턱의 처짐이 다르다.
- sleep_a/b: 감은 눈과 접은 다리의 앉은 자세, 내려둔 초롱. x53..60, y75..79의 굽힌 팔은 실제 피부 면으로 이어지고 그립/초롱에 연결된다. 금색 여밈 x43, y74..83은 두 자세 모두 연속된다. sleep_b는 기존 어깨/접힌 손/핵 변화와 가슴 밝은 면 x40, y73..75의 작은 확장으로 호흡을 표시한다. 죽음의 가로로 누운 자세와 구분된다.

## 저장 프레임 확인

현재 8 GIF를 실제 파일에서 다시 읽어 프레임 수/유지 시간/크기/해시를 `previews/gif-decoded-report.json`에 기록했다. 저장된 전 프레임의 원본 대비 색 차이는 0픽셀이다. 8개 `gif-decoded-*.png` 확인판을 실제로 열어 순서와 연결을 관찰했다. 원본 배열은 18개 모두 서로 다르다.

관찰은 정적 디코딩 확인판이다. 브라우저 연속 재생이나 실제 전투에서 이동 곡선·타격 시점을 확인한 것은 아니다. 시간표와 파일 진단은 독립 검수 통과 또는 사용자 승인 선언이 아니다.

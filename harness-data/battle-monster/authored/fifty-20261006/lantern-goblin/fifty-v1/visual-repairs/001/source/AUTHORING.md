# 초롱도깨비 · fifty-v1 저작 기록

## 납품 범위

- `poses/`: 기본 9자세. `actions/`: 기술·독·기절·수면 9자세.
- 전부 96×96, 매 행 96 ASCII 글자의 완전한 리터럴 원본이다. `.`은 투명이며 팔레트에 없다.
- `palette.json`: 18색. PNG 알파는 0/255. 모든 원본의 최하단 잉크는 y≤92이며 `idle_a`의 양발 바닥은 y=92다.
- `idle_a`의 잉크 범위는 x=25..80, y=10..92. 뿔부터 발까지 83px 높이로, 캔버스 안에 작은 몸을 확대해 넣지 않았다.
- `previews/`: 18 native PNG, 투명 3×3 자세/동작 아틀라스, 8 native GIF, 1배 확인판, 밝은/어두운/체커 3배 확인판, 저장된 GIF를 다시 읽은 프레임 확인판, 해시·연결 진단 JSON, `index.html`.
- `originals/first-complete/`: 최초 18자세가 모두 존재하던 시점의 원본과 팔레트. 마지막 피격 손목/수면 호흡 교정 전 스냅샷이다. 그 이전 저작 행과 교정 좌표도 `author_pixels.py`에 남아 있다.

## 참고와 직접 저작

제공된 `references/human-size.png`를 실제로 열어 작은 눈, 얼굴 앞의 코 공간, 목/옷깃, 손과 무기의 접합을 관찰했다. 참고 파일을 추출·추적·축소·복제하거나 source에 재배포하지 않았다.

본체, 얼굴, 단일 뿔, 귀, 옷, 맨발, 초롱 및 효과는 직접 선택한 ASCII 행과 짧은 좌표 문자열로 저작했다. 안정된 머리의 행은 일부 서 있는 자세에서 그대로 유지하고, 어깨/팔꿈치/손목/골반/다리/초롱의 변화는 별도 행으로 그렸다. 독·기절·수면·쓰러짐은 낮아진 머리와 새로운 몸통 행을 따로 저작했다. 상태 동작은 공격 복사에 색조만 바꾼 것이 아니다.

`author_pixels.py`는 명시된 행·좌표를 빈 96px 캔버스에 기록하고 완전한 격자를 저장하는 보조 코드다. 형태 마스크, 원/다각형, 수식 명암, 프레임 통째 이동/회전, 보간, 자동 빈 구멍 채움은 없다. `render.py`는 원본을 읽고 굽거나 진단한다. 최근접 확대는 확인판에만 사용하며 native PNG/GIF는 96px 그대로다.

## 외형과 재질

- 오른쪽으로 좁아진 먼 눈과 근안 눈썹, 오른쪽으로 튀어나온 코, 흰 송곳니로 3/4 붉은 도깨비 얼굴을 잡았다.
- 머리는 검은 자주빛 세 면, 뿔은 따뜻한 상아/금빛, 피부는 붉은 기본/그림자/살구빛 면이다.
- 조끼는 남색의 넓은 왼쪽 밝은 면과 오른쪽 그늘, 바지는 갈색의 굽은 무릎 면, 초롱은 종이의 넓은 밝은 면과 금갈색 골격으로 분리했다.
- 광원은 왼쪽 위. 초롱 핵은 작은 추가 발광 표현이며 피부 전체를 자동으로 밝히지 않았다.

## 실제 확인 뒤 직접 고친 곳

좌표는 모두 0부터 시작한다.

1. 얼굴 y=33..41, x=33..55: 대칭처럼 보이던 눈을 좁은 먼 눈/긴 근안 눈썹으로 다시 찍고 코·입 앞 공간을 오른쪽으로 정리했다.
2. `windup`, x=22..52, y=46..62: 겹쳐 그리는 팔의 배경 점이 가슴을 지워 생긴 직각 빈 홈을 발견했다. 원래 저작한 천 행을 보존하고 실제 팔의 불투명 클러스터만 겹쳤다. x=43..58, y=52..62의 윗팔도 직접 그려 팔꿈치를 어깨에 이어 주었다.
3. `move`, x=59..66, y=71..73 및 `attack`, x=66..76, y=60..63: 손가락→손잡이로 연결되는 손목/그립 행을 추가했다.
4. `idle_b/c`, x=67..80, y=73..84: 처음 핵/술 수정의 문자열이 종이 외곽까지 침범했다. 외곽 행을 복원하고 핵 변화는 내부의 짧은 문자열로 한정했다.
5. `hit`, x=52..65, y=75..77: 실제 그림과 읽기 전용 연결 진단에서 떨어져 있던 손/초롱을 확인했다. 세 줄의 붉은 손목과 손가락, 금갈색 손잡이 접점을 직접 그렸다.
6. `sleep_b`, x=34..51, y=70..77 및 x=37..42, y=84..85: 처음 호흡 행이 금색 옷 여밈을 중복시켰다. 앉은 원본을 다시 기준으로 삼고 어깨·옷깃·접힌 손의 짧은 좌표만 수정했다.

팔 아래, 다리 사이, 손잡이 안의 의도한 빈 공간은 남겼다. 연결 진단은 source 픽셀을 수정하지 않는다. 최종 본체·팔·발·초롱은 모든 자세에서 한 개의 4방향 연결 성분이다. 별도 성분은 독 방울, 기절 별, 기술 회수의 두 잔불이다.

## 열어 본 결과

- 최종 18자세를 `sheet-native.png` 원본 1배와 `sheet-light.png`, `sheet-dark.png`, `sheet-checker.png` 최근접 확인판으로 열었다.
- 실제 저장된 8 GIF를 다시 디코딩한 idle/attack/hit/dead/skill/poison/stun/sleep 확인판을 모두 열어 순서·팔다리 접합·프레임 간 변화와 저장된 시간을 확인했다.
- 렌더러에서 96행×96열, 팔레트 글자, 테두리, 바닥과 18개 원본의 서로 다른 배열을 확인했다. 이것은 형식 진단이며 독립 미감 검수나 사용자 승인 판정이 아니다.
- `previews/source-image-hashes.json`, `gif-decoded-report.json`에는 현재 실제 파일의 SHA-256을 계산해 기록했다.

## 남은 표현 한계와 판정 상태

- 공격 동안 머리의 기준 위치를 유지하므로 어깨와 발의 변화에 비해 머리의 따라 움직임은 절제되어 있다. 점프를 여러 중간 프레임으로 늘린 연속 동작은 이 9자세에 포함하지 않았다.
- 기술의 불꽃은 96px 테두리 안에서 세 갈래를 펼친다. 밝은 배경에서는 상아/황금 내부 면의 대비가 낮아 주홍 윤곽이 더 두드러진다.
- 쓰러짐은 초롱이 가까운 골반 일부를 가린다. 수면 호흡은 어깨와 손의 작은 변화라 1배에서 미세하다.
- 게임 런타임에 설치하지 않았으며 전투 안의 타격 시점은 확인하지 않았다.
- 별도 검수자를 호출하지 않았다. 독립 검수는 하네스가 수행할 대상이며, 사람 승인·Allow·통과 판정을 이 source에서 선언하거나 작성하지 않았다. 모델 실행 출처는 하네스의 실제 실행 기록에 맡긴다.

요청 범위에 따라 모든 작성 파일은 이 후보의 `source` 안에만 있다. 저장소·게임 저장소·ledger·brief·다른 후보는 수정하지 않았고 테스트/게이트를 실행하지 않았다.

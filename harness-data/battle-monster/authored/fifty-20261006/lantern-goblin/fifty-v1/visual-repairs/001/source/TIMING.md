# 초롱도깨비 · GIF 시간표

각 원본은 96×96이며 시간 단위는 ms다. 아래 순서 그대로 `previews/*.gif`에 저장했다. GIF는 검토용 어두운 불투명 배경으로 반복하며, native PNG/pxgrid의 투명 배경은 유지된다. 추가 보간 프레임은 없다.

| GIF | 자세 순서 | 각 자세 유지 시간 | 한 주기 |
|---|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 | 960 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240 / 260 / 130 / 170 / 210 / 300 | 1310 |
| hit | idle_a → hit → recover → idle_a | 250 / 300 / 210 / 300 | 1060 |
| dead | idle_a → hit → dead | 250 / 220 / 1200 | 1670 |
| skill | skill_a → skill_b → skill_c → idle_a | 420 / 260 / 350 / 280 | 1310 |
| poison | poison_a → poison_b | 420 / 420 | 840 |
| stun | stun_a → stun_b | 480 / 480 | 960 |
| sleep | sleep_a → sleep_b | 650 / 650 | 1300 |

쓰러짐 GIF의 마지막 뒤 첫 자세로 돌아가는 것은 반복 검토용이다. 게임에서는 dead를 마지막 유지 자세로 사용한다.

## 공격 자세와 하중

- `windup`: 초롱을 몸 뒤 왼쪽으로 높이 든다. 가까운 팔은 가슴 앞에서 접히며 손은 초롱 손잡이를 잡는다. 무릎을 벌리고 뒤 지지발로 준비한다.
- `move`: 뒤꿈치를 들고 앞 정강이와 발을 내딛는다. 초롱 손은 골반 옆으로 내려오며 다음 휘두르기를 준비한다.
- `attack`: 가까운 어깨·팔꿈치를 오른쪽으로 열고 앞쪽 발에 하중을 둔다. 초롱을 앞쪽에서 접촉 자세로 잡는다.
- `recover`: 팔꿈치를 접고 손과 초롱을 배 앞으로 당긴다. 벌어진 발을 몸 쪽으로 되돌린다.

## 등화격 앵커

좌표는 0부터 시작한다. 몸/손/초롱이 실제로 이어진 행과 효과의 접점을 기술한다.

| 단계 | 손/초롱 앵커 | 핵/효과 |
|---|---|---|
| skill_a · 모으기 | 오른손 그립 x=59..65, y=45..50 → 뒤쪽 손잡이. 반대 손은 초롱 하단 x=58..63, y=62..66을 받친다. | 초롱 내부 x=64..69, y=54..58에 상아/황금 핵. 초롱 입구는 위쪽 금갈색 테두리다. |
| skill_b · 발사/접촉 | 오른손 x=61..67, y=48..53은 앞으로 든 손잡이에 연결된다. 반대 손은 x=60..64, y=61..65에서 밑면을 받친다. | 입구 오른쪽 끝 x=75..77, y=50..53에서 불꽃이 이어진다. 위 갈래 y=26..50, 짧은 오른 갈래 y=43..53, 아래 갈래 y=54..71. 효과의 최대 x=93으로 오른쪽 테두리를 남긴다. |
| skill_c · 회수 | 오른손 x=45..51, y=67..70으로 당긴다. 초롱의 낮아진 손잡이와 연결된 상태다. | 큰 갈래는 사라지고 x=80..84, y=48..53 및 x=85..88, y=67..71의 서로 다른 두 잔불만 남는다. |

입/뿔은 이 기술의 발사점이 아니다. 실제 발사점은 쥔 초롱의 입구다. 효과는 캐릭터와 함께 각 action의 완전한 리터럴 격자에 있으며 별도 생성 오라를 합성하지 않는다.

## 상태 동작

- 독: 낮춘 머리와 턱을 받친 팔. 세 독 방울의 위치/크기가 바뀌며 눈·턱·어깨 클러스터도 달라진다.
- 기절: 처진 머리·팔·초롱. 두 별의 위치와 크기, 손과 턱의 처짐이 바뀐다.
- 수면: 감은 눈, 앉아 접은 다리, 내려 둔 초롱. 어깨/옷깃/접힌 손과 작은 핵이 호흡 박자로 달라진다. 가로로 누운 dead와 다른 자세다.

`previews/gif-decoded-report.json`은 저장된 GIF를 실제로 다시 읽어 얻은 프레임 수·지속 시간·파일 해시다. `gif-decoded-*.png`는 그 저장 프레임의 확인판이다. 시간표는 저작 제안이며 사용자 승인이나 런타임 적용을 뜻하지 않는다.

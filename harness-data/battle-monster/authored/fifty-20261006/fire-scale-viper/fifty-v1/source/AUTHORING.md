# 화린독사 — fifty-v1 직접 도트 원본

## 범위와 참고 관찰

이 후보의 `source`만 작성했다. 기존 격자가 없는 상태에서 새로 시작했다. `references/human-size.png`를 실제로 열어 검객의 64px 캔버스 안 크기, 작은 얼굴, 넓은 밝은 면과 어두운 면, 손과 칼의 접속을 관찰했다. 참고 픽셀을 추출하거나 복사하지 않았다. 화린독사에는 인간의 팔·다리·도구·뿔을 추가하지 않았다.

팔레트는 투명 점을 제외한 15색이다. 모든 최종 pxgrid는 64행 × 64열의 완전한 ASCII 원본이다. `author_native.py`에는 최초로 고른 행과 후속 좌표 교정을 모두 보존한다. 직접 선택한 x 위치와 문자열을 빈 native 캔버스에 쓰며, 대기 호흡과 수면은 고정된 자체 저작 군집을 보존하고 명시한 행만 바꾼다. 몸 생성식, 도형 마스크, 자동 음영, 전체 프레임 이동·회전·보간, 자동 연결/구멍 메우기는 사용하지 않았다.

## 본체·재질

- 삼각 머리의 넓은 뒷면, 우향 주둥이, 짧은 검은 눈 군집, 금빛 아래턱을 먼저 저작했다. 눈에는 흰자나 큰 둥근 반짝임을 넣지 않았다.
- 왼쪽 위에서 받는 복숭아빛/주황빛 등 면, 넓은 주홍 기본 면, 자주빛 적갈색 아래 그림자, 금빛 배를 구분했다. 코일에는 직접 고른 짧은 비늘 경계를 추가했다.
- 굵은 목은 S자 굽힘을 거쳐 아래 코일에 이어진다. 왼쪽 말린 꼬리와 코일 중심의 빈 공간을 유지했다. 중심 빈 공간은 의도한 투명이고 자동으로 채우지 않았다.
- `idle_a` 본체 범위는 x=5..51, y=9..60이다. 마지막 교정 후 모든 자세의 낮은 코일이 y=60에 접지한다. 모든 잉크는 x=1..62, y=1..60 안이다.

## 18자세

| 자세 | 직접 바뀐 구조 |
|---|---|
| idle_a/b/c | 고정된 아래 코일 위에서 목의 붉은 면·배 폭·꼬리 끝·눈 주변이 작게 바뀐다. |
| windup | 머리를 왼쪽 뒤로 낮추고 목을 뒤로 굽혔다. 하단 코일은 두껍게 압축된다. |
| move | 꼬리를 뒤에 남기고 아래 몸을 오른쪽으로 길게 펴며 머리를 전진시킨다. |
| attack | 목을 길게 펴서 실제 열린 위아래 턱과 송곳니로 접촉한다. 전체 프레임 이동으로 만들지 않았다. |
| recover | 입을 닫고 머리를 들어 올리며 목과 코일을 회수한다. |
| hit | 머리와 눈을 움츠리고 목을 역으로 기울였다. |
| dead | 목을 바닥에 눕혀 머리를 오른쪽 아래로 뻗는다. 흐린 눈, 별도 꼬리와 코일 경계를 유지한다. |
| skill_a/b/c | 턱 아래 붙은 작은 황금 불씨 → 실제 벌린 입에서 위·앞·아래로 갈라지는 주홍 독불 → 닫힌 입과 떨어지는 잔불. |
| poison_a/b | 아픈 눈·내려간 턱·짧게 접힌 목을 직접 찍었다. 거품은 위치와 터지는 배열이 다르다. 본체 색을 물들이지 않았다. |
| stun_a/b | 더 처진 머리와 짧은 흐린 눈, 코일 위로 숙인 목. 두 별은 반대 위치로 각각 저작했다. |
| sleep_a/b | 코일 위에 머리를 올려 안정되게 감았다. 왼쪽 꼬리와 코일의 동일 경계를 보존하며 등·가슴 밝은 면만 작게 부푼다. |

## 실제 그림에서 지목하고 교정한 좌표

좌표는 0부터 시작한다. 교정 전 행도 `author_native.py`에 남아 있다.

1. 독·기절 아래 배에서 직각으로 패인 옆면을 확인했다. `poison_a/b`의 y=41..44, `stun_a/b`의 y=42..44를 직접 새 행으로 찍어 금빛 배가 코일에 둥글게 이어지게 했다.
2. 수면 눈은 열린 3×2 검은 눈을 사용하지 않는다. `sleep_a/b`의 (43,45)에 한 행 두 픽셀 `ee`를 찍고 (42,44), (43,46)에 얼굴색을 골라 짧은 수평 눈꺼풀을 분리했다. native 1배 시트에서 닫힌 눈을 확인했다.
3. `skill_a` y=22..28에 턱 아래에서 붙어 자라는 불씨를 다시 저작했다. 처음에는 턱과 불씨 사이에 빈 공간이 있었다.
4. `skill_b` y=14..36의 독불 경계를 주홍·주황으로 직접 다시 찍었다. 밝은 배경의 희미한 금빛 선을 보완했다. (52,28)의 `oYR`는 아래 갈래를 입에서 나온 덩어리에 잇는다. y=32의 불필요한 떠 있는 짧은 점은 명시한 새 행으로 제거했다.
5. 물기 송곳니 끝의 고립된 윤곽 (47,33)을 발견했다. `attack` y=31..33의 송곳니를 (50,31), (49,32), (49,33)에 직접 가늘게 이어지도록 다시 저작했다.
6. 준비·피격의 코일이 y=58에서 끝나 GIF 순서 비교에서 들려 보였다. 이 두 자세 y=56..60과 회수·불씨·쓰러짐의 y=59..60을 직접 보완했다. 마지막에는 준비·피격 y=59..60의 오른쪽 네모 돌출도 안으로 좁혀 고쳤다.

## 확인한 산출물

`render_preview.py`는 원본을 읽어 그대로 RGBA PNG와 팔레트 GIF를 저장한다. 확대는 진단판에서만 최근접으로 한다. 실제 열린 확인판은 `previews/native.png`, `board-light.png`, `board-dark.png`, `board-checker.png`와 `gif-decoded-contact.png`다. 각 GIF를 다시 읽어 모든 프레임의 RGBA 픽셀 및 hold를 원본과 비교했다. 비교 근거는 `previews/gif-report.json`, 파일별 실제 해시는 `previews/pixel-report.json`에 있다.

연결 진단은 의심 좌표를 찾는 읽기 전용 보조로만 사용했다. 실제 수정은 위 행/좌표를 직접 골랐다. 밝은/어두운/체커 바탕에서 코일 빈 공간, 목 연결, 송곳니, 효과의 접속과 가장자리를 확인했다. 최종 파일에 승인·독립 검수 판정을 기록하지 않았다. 독립 검수는 상위 하네스의 별도 단계다.

## 남은 시각 한계

- 공격·기술은 정해진 핵심 자세로 연결되므로 고속 전진에서 머리 이동이 분명하다. 보간 프레임은 없다.
- S자 목의 굽힘은 native64의 계단식 윤곽이다. 코일은 굵게 읽히도록 단순화했고, 비늘을 전신의 작은 점으로 도배하지 않았다.
- 가장 긴 독불 갈래는 x=62까지 닿아 한 픽셀 투명 여백을 남긴다. 64px 안에서는 더 긴 불줄기나 세밀한 잔불을 추가하기 어렵다.
- 수면 호흡은 작은 등과 가슴 면의 변화다. 빠른 동작과 비교하면 변화가 작으며, 눈꺼풀도 1배에서 짧은 선이다.
- 여기서 확인한 것은 원본 및 GIF에서 재읽은 비교판이다. 게임 런타임에서 재생하거나 별도 검수자를 호출하지 않았다.

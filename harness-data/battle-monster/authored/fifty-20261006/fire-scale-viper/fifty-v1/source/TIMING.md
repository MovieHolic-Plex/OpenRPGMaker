# 화린독사 GIF 시간표

모든 GIF는 64×64 native 원본, 팔레트 원색, 0/255 알파다. 임의 이동·회전·중간 프레임 없이 아래 격자만 사용한다. PNG 시트는 같은 픽셀의 3×3 배열이다. GIF의 투명 바탕은 프레임마다 disposal=2로 비워 이전 불씨·거품이 남지 않게 한다. 시간 단위는 ms이고 저장 후 실제 GIF에서 모든 hold를 다시 읽었다.

| GIF | 순서와 hold |
|---|---|
| idle.gif | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 |
| attack.gif | idle_a 240 → windup 280 → move 100 → attack 180 → recover 220 → idle_a 320 |
| hit.gif | idle_a 300 → hit 180 → recover 160 → idle_a 400 |
| dead.gif | idle_a 300 → hit 150 → dead 1400 |
| skill.gif | idle_a 240 → skill_a 360 → skill_b 260 → skill_c 280 → idle_a 320 |
| poison.gif | poison_a 420 → poison_b 420 |
| stun.gif | stun_a 440 → stun_b 440 |
| sleep.gif | sleep_a 650 → sleep_b 650 |

8개 GIF는 비교용으로 반복 재생한다.쓰러짐 GIF의 긴 마지막 hold 뒤 처음으로 돌아가는 것은 비교 루프다. 게임에서 죽은 몸이 다시 일어난다는 의미는 아니다.

## 실제 입 앵커와 기술 단계

좌표는 (x,y), 0부터 시작한다.

- **skill_a — 모으기:** 닫힌 입 아래 (41,22)에서 시작한 금빛 불씨가 y=23..28로 내려간다. 턱과 연결된 뿌리는 작고 아래쪽 끝은 얇다. 목은 평상시보다 낮고 짧게 접힌다.
- **skill_b — 내뿜기/접촉:** 열린 실제 입의 (39,26) 부근에서 f/Y의 뜨거운 핵이 오른쪽으로 이어진다. 위 갈래는 (58,14), 앞 갈래는 (60,20) 부근, 아래 갈래는 (62,36)로 각각 달리 휘어진다. (52,28)의 직접 저작 군집은 아래 갈래의 연결부다. 전신을 뒤덮는 원형 오라는 없다.
- **skill_c — 회수:** 입을 닫고 머리를 다시 든다. 떨어진 불씨는 x=53..61, y=14..29에 따로 남고 몸에 연결되지 않는 것이 의도다. 마지막 idle에서 잔불이 사라진다.

## 물기와 상태 변화

준비에서 아래 몸의 압축을 280ms 보여 준 뒤 100ms 전진한다. 접촉은 실제 열린 입과 아래/위 송곳니를 180ms 유지한다. 회수는 입을 닫은 채 머리를 들어 220ms 보인다. 모든 자세의 아래 몸은 y=60에 접지한다.

독은 눈/턱/목의 병든 자세와 거품 배열이 바뀐다. 기절은 더욱 처진 머리와 서로 위치가 다른 금빛 별이다. 수면 두 자세는 같은 말린 꼬리/아래 코일/짧은 닫힌 눈꺼풀을 유지하고 등·가슴 면에 작은 숨 변화만 준다. 수면은 쓰러짐처럼 머리를 바닥 밖으로 길게 뻗지 않는다.

`motions.json`은 이 시간표의 기계가 읽을 수 있는 사본이다. `previews/gif-decoded-contact.png`는 실제 저장된 GIF에서 재읽은 프레임을 시간 순서로 보여 준다. `gif-report.json`은 저장된 GIF의 실제 해시·프레임 이름·hold·원본과의 픽셀 일치 여부를 보존한다.

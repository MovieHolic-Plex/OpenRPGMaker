# 산야약객 — fifty-v1 원본 저작 기록

## 납품 범위

- 이 후보의 `source/` 안에서 기본 9자세와 추가 9자세를 새로 저작했다.
- 정본 원본은 `palette.json`, `poses/*.pxgrid`, `actions/*.pxgrid`다. 모든 격자는 리터럴 ASCII 64행 × 64열이다.
- 18색을 공유하며 `.`은 투명이다. 원본 PNG 알파는 0/255뿐이다.
- `author_rows.py`에는 각 자세를 따로 선택한 `(y, x, ASCII 행)` 좌표 문자열을 보존했다. 보조 코드는 투명 캔버스에 이 문자열을 쓰고 64열로 보존한다. 본체 생성 수식, 도형 래스터화, 자세 복사/회전/보간, 명암 합성, 자동 구멍 채우기를 사용하지 않았다.
- `render.py`는 격자 읽기, 팔레트 해석, PNG/GIF 출력, 진단 배경/라벨, 최근접 진단 확대와 GIF 재읽기만 수행한다. 4배 이미지는 검토용이며 게임 원본은 64px이다.
- 참고 `human-size.png`를 실제로 열어 성인 SD 비율, 작은 우향 눈, 목·옷깃·손·무기 연결을 관찰했다. 참고 픽셀을 추출하거나 복제하지 않았다.

## 본체와 재질

대기 본체는 y=8..60의 53px 높이이며 두건·머리의 주 너비는 약20px, 피부 얼굴의 주 너비는12~14px다. 갈색 넓은 두건 아래 검은 머리, 회백 저고리, 녹청 조끼, 청회색 바지와 검은 신을 유지했다. 등에는 갈색 바구니와 녹색 약초를 붙였다.

왼쪽 위 빛을 기준으로 천에는 `L/w/W`, 조끼에는 `v/g/G`, 피부에는 `l/s/S`, 바구니·지팡이에는 `t/b/B`의 넓은 면을 직접 골랐다. 바구니의 짜임은 짧은 가로 군집으로만 제한했다. 나무는 세로 밝은 면과 갈색 중심을 유지하고, 금속 같은 흰 반사점을 넣지 않았다.

대기 눈썹은 x26..27/y18, 작은 눈은 x28/y19 부근이며 코 앞 공간을 남겼다. 검은 동그란 눈이나 흰자는 만들지 않았다. 목의 피부는 옷깃 사이에서 실제 폭을 가지며 저고리 내부를 투명 사각형으로 비우지 않았다.

## 자세별 저작

| 구간 | 직접 고른 구조 |
| --- | --- |
| idle_a/b/c | 같은 발 지지와 얼굴을 유지하고, 가슴 면·소매 너비·손/지팡이의 작은 이완을 각 격자에 별도로 기록했다. |
| windup | 무릎을 굽히고 오른손을 뒤로 당겼다. 오른쪽 어깨에서 넓은 위팔→팔꿈치→가슴을 가로지르는 아래팔→뒤쪽 손의 경로를 그렸다. 반대 손은 배 가까이 둔다. |
| move | 뒤 다리를 밀고 앞 다리를 내딛으며 같은 오른손·지팡이를 위로 들었다. 소매와 위팔/아래팔의 면을 따로 그렸다. |
| attack | 앞 무릎에 무게를 싣고 오른손으로 지팡이를 내려쳤다. 손목 아래 자루는 바닥 근처 y58까지 이어진다. 실제 앞 신발과 뒤 지지 신발이 y60에 닿는다. |
| recover | 팔을 당기고 다리를 다시 모으며 지팡이를 대각선으로 회수한다. |
| hit | 머리와 어깨가 뒤로 기울고 눈썹·눈·입을 아픈 표정으로 바꿨다. 무릎이 꺾여도 허벅지 면과 신발을 보존했다. |
| dead | 옆으로 내려온 몸·접힌 두 다리·바구니·닫힌 눈·피부 목을 남겼다. 몸과 신의 하중 윤곽이 y60에 닿는다. |
| skill_a/b/c | 지팡이의 실제 끝에서 잎 핵을 모으고 세 잎을 상·중·하 방향으로 갈라 낸 뒤, 지팡이를 낮추고 조각난 잎 잔기를 남긴다. |
| poison_a/b | 턱을 짚는 아픈 팔과 배를 움켜쥔 팔을 각각 그렸다. 고개·어깨·무릎도 바뀌고 서로 다른 위치/크기의 독 방울을 직접 썼다. |
| stun_a/b | 목·어깨·팔이 처지고 지팡이를 느슨하게 낮게 잡는다. 별의 위치/형태와 고개/소매 윤곽이 다르다. |
| sleep_a/b | 앉아 접힌 무릎과 두 신발을 보존했다. 짧은 닫힌 눈꺼풀만 x27..28/y33 또는 y34에 남겼고, 그 아래 대기 눈은 없다. 두 번째 자세는 턱이 낮아지고 어깨·가슴·소매 윤곽이 압축된다. |

## 실제 그림을 열고 고친 부위

1. **대기 지팡이 y33..57:** 첫 원안의 손 아래 자루가 옆으로 꺾여 보였다. idle_a/b의 자루를 x47..50의 하나의 축으로, idle_c는 자신의 x46..49 축으로 각 행을 따로 기록했다. 손 위 자루/손가락/손 아래 자루를 분리해 읽히게 했다.
2. **공격 손목 x44..51/y39..42:** 소매 끝과 손 사이의 한 칸 간격 및 그립 아래 돌기를 확인했다. `W/l/s/S`의 손목·손바닥 면을 직접 쓰고 y42의 손 그림자와 자루 출구를 x46..53으로 정리했다. 자동 연결 채우기가 아니다.
3. **회수 지팡이 끝 x52..59/y53..57:** 대각선 지팡이가 길어 보여 끝을 직접 줄이고 x52..55/y53에 나무 끝을 다시 그렸다.
4. **쓰러짐 머리·목 x31..48/y41..57:** 첫 쓰러짐의 머리 아래 연결이 길고 가늘었다. 몸 가까운 위치에 머리 윤곽·두건·눈꺼풀·턱을 새 행 문자열로 다시 그렸다. 목은 피부 중간색과 그림자가 실제 면으로 몸과 턱을 잇는다.
5. **준비 위팔 x30..37/y31..38:** GIF 순서를 펼쳐 보았을 때 앞쪽 소매와 뒤쪽 손의 역할이 모호했다. 앞쪽 돌출 소매/여분 손을 지우고, 오른쪽 위팔이 팔꿈치에서 뒤손 쪽 아래팔로 접히는 면을 해당 자세의 좌표로 새로 썼다.
6. **수면 쌍:** 실제1배와4배에서 닫힌 눈, 같은 접힌 무릎/신발, 소매 손목과 지팡이 파지를 비교했다. 두 번째의 얼굴/턱과 가슴·소매 경계는 내부 색만 바꾸지 않고 따로 저작했다.

한 자세의 수정 좌표를 다른 자세에 자동 복사하지 않았다. 다른17자세의 같은 부위를 PNG 시트에서 같이 확인했다. 팔 사이와 다리 사이의 의도한 바깥 빈 공간은 보존했다.

`history/`에는 목/손목/지팡이/준비 팔을 고치기 직전의 네 원본을 보존했다. 현재 납품은 `poses/`와 `actions/`이며 history는 자세 목록에 포함하지 않는다.

## 관찰과 출력 근거

- 기본/추가 3×3 PNG 시트를 밝은·어두운·체커 배경, 1배/4배로 실제 열었다.
- 실제8GIF를 다시 읽어 각 프레임의 RGBA와 노출 시간이 리터럴 격자의 PNG와 같음을 확인했다. 그 GIF에서 읽은 순서대로 만든 필름스트립도 실제 열어 관절과 프레임 간 위치 변화를 보았다.
- `previews/inventory.json`은 실제 원본 RGBA의 범위와 해시, `previews/gif-readback.json`은 실제 GIF 바이트 해시/순서/노출/픽셀 일치 기록이다. 이는 파일 출력 근거이며 미감 판정이 아니다.
- 18개 모두64×64이며, 기본/상태의 실제 몸·신발은 y60을 유지한다. 효과의 최대 x는 skill_b의62, 최고 y는3으로 투명 테두리를 남긴다.

## 남은 시각적 한계

- 바구니는1배에서 작은 갈색 약통처럼도 읽힐 수 있다. 엮은 결을 더 촘촘하게 추가하면 잡음이 될 수 있어 현재 작은 테두리/짜임 군집으로 남겼다.
- 대기 호흡은 작고 차분하다. 수면은 턱·가슴·소매의1px 압축/이완으로 읽히는 작은 호흡이다.
- 공격은 원본 준비/전진/접촉/회수의 핵심 자세 네 장이다. 뒤에서 당긴 지팡이가 머리 위로 올라가는 구간은 빠른 자세 교체이며 추가 중간 자세는 없다.
- 쓰러짐의 두 번째 다리는 접혀 겹치므로 짧은 바지 경계와 신발 끝으로 구별된다.

독립 검수는 아직 이 저작 턴에서 실행하지 않았다. 하네스의 현재 실제 독립 검수와 사용자 판단을 기다리는 후보이며 통과/승인/사용자 선택을 선언하지 않는다. 모델 실행 정보는 하네스가 관리하는 실제 기록을 따른다.

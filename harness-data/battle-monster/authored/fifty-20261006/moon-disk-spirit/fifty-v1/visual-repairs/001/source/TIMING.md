# 월륜정령 — native GIF 시간표

각 GIF는 96×96 원본 팔레트/투명도 그대로이며 반복 재생한다. 확대·회전·보간 프레임은 없다.
아래 시간은 실제 GIF에서 다시 읽은 노출 시간과 일치한다.

| 파일 | 프레임 순서와 노출(ms) | 읽히는 동작 |
|---|---|---|
| `gif/idle.gif` | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 | 원반은 안정적으로 떠 있고 두 비단 끝이 각기 벌어졌다 접힌다. |
| `gif/attack.gif` | idle_a 240 → windup 280 → move 140 → attack 220 → recover 220 → idle_a 360 | 두 팔을 접음 → 팔 벌림과 숄 뒤로 젖힘 → 오른 손바닥 접촉 → 팔과 숄 회수. |
| `gif/hit.gif` | idle_a 300 → hit 260 → recover 220 → idle_a 440 | 얼굴·목·어깨가 무너지고 비단은 오른쪽으로 휘었다 돌아온다. |
| `gif/dead.gif` | idle_a 300 → hit 220 → dead 1100 | 반동 후 바닥 가까이 내려앉은 원반, 닫힌 눈과 펼쳐진 비단. |
| `gif/skill.gif` | skill_a 360 → skill_b 260 → skill_c 300 → idle_a 440 | 손바닥 은빛 핵 → 서로 크기가 다른 두 초승달 날빛 → 손끝의 깨진 잔광. |
| `gif/poison.gif` | poison_a 420 → poison_b 420 | 턱을 감싼 손과 아래 팔의 압축 변화, 서로 다른 기포 위치·크기. |
| `gif/stun.gif` | stun_a 480 → stun_b 480 | 고개와 팔이 처지고 손가락이 느슨해짐, 세 별의 위치 변화. |
| `gif/sleep.gif` | sleep_a 720 → sleep_b 720 | 낮은 안정 자세, 닫힌 눈 유지, 가슴·목의 밝은 천 면과 감긴 숄의 작은 숨 변화. |

## 기술 앵커 (0부터 세는 native x,y)

- `skill_a`: 오른손은 (65,36) 부근에서 은빛 핵을 받친다. 핵 중심은 (66,32–34)이며 손바닥과 직접 닿는다. 왼손은 원반 앞에서 오른팔 아래를 받친다.
- `skill_b`: 펴진 오른 손바닥은 (71–75,40–47). 날빛 뿌리는 (73–76,41–47)에서 시작한다. 위 날은 (76,12)까지, 아래 날은 (64,72)까지 서로 다른 굽은 날로 직접 저작했다. 원반 자체의 회전이나 효과 배율 변화는 사용하지 않았다.
- `skill_c`: 접혀 돌아오는 손끝 (64–66,51–54)에 작은 은빛 군집을 연결했다. 그 옆 (70,53)과 더 멀리 있는 조각들은 떨어져 나간 잔광이다.
- 이 종에는 입/뿔/무기 앵커가 없다. 짧은 팔과 손바닥이 공격·기술의 실제 기점이다.

## 전환 관찰 범위

실제 GIF를 열고, GIF에서 복호화한 모든 native 프레임을 `png/gif-decoded-frames.png`로 다시 열어 순서와 접촉/회수 연결을 확인했다. 노출 시간을 다시 읽고 원본의 불투명 픽셀과 알파가 일치하는지 기록했다. 게임에 설치하거나 전투 런타임을 실행한 결과는 아니다.

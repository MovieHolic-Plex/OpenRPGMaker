# 월륜정령 — 수정본 GIF 시간표

8개 GIF는 현재 96×96 완전한 리터럴 격자를 그대로 사용한다. 18색 팔레트와 투명도는 유지했다. 프레임 이동·회전·확대·보간으로 동작을 합성하지 않는다. 확대는 PNG 진단판에만 쓴다.

| GIF | 프레임 순서와 노출(ms) | 동작 |
|---|---|---|
| `gif/idle.gif` | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 | 원반은 안정적이며 짧은 뒤팔과 두 가는 비단 끝의 접힘이 변한다. |
| `gif/attack.gif` | idle_a 240 → windup 280 → move 140 → attack 220 → recover 220 → idle_a 360 | 두 팔을 접어 준비 → 어깨/뒤팔을 벌리고 비단을 뒤로 흘림 → 연결된 앞손 접촉 → 팔/숄 회수. |

## 기술의 실제 기점 — native 0-based 좌표

- `skill_a`: 오른손 `(65,36)` 부근이 은빛 핵 `(66,32–34)`을 직접 받친다. 핵은 손바닥에 닿는다. 뒤쪽 팔은 `(31–51,43–51)`에서 짧게 접혀 아래의 팔/숄 겹침을 만든다.
- `skill_b`: 오른 손바닥 `(71–75,40–47)`에서 날빛 뿌리 `(73–76,41–47)`가 시작한다. 위 날은 `(76,12)`, 아래 날은 `(64,72)`까지 서로 다른 곡률로 이어진다. 뒤팔은 어깨 `(42,42)`에서 팔꿈치/손목을 거쳐 `(29–36,50–53)`의 손으로 이어진다.
- `skill_c`: 돌아온 손끝 `(64–66,51–54)`에 작은 은빛 군집이 닿는다. `(70,53)` 및 멀리 떨어진 파편은 깨진 잔광이다.
- 이 종의 기술 기점은 손바닥이다. 입/뿔/무기 기점으로 바꾸지 않았다.

## 시간과 관찰 범위

`render.py`가 현재 원본에서 GIF를 다시 저장하고 각 프레임을 복호화했다. 실제 재읽은 노출 시간은 `render-record.json`에 있다. 불투명 픽셀의 RGBA와 전체 알파가 해당 현재 격자와 일치했다. 복호화 프레임 시트 `png/gif-decoded-frames.png`도 실제로 열었다.

위 GIF는 정지 격자를 순서대로 보여 주는 후보 미리보기다. 실제 게임에서의 호핑 위치, 타격 대상과의 접촉 또는 설치된 애니메이션을 검증한 결과는 아니다. 사용자 승인/독립 검수 판정을 이 시간표로 대체하지 않는다.

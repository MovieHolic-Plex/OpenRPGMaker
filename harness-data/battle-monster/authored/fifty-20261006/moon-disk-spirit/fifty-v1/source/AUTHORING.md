# 월륜정령 — 턱·목 윤곽과 수면 호흡 교정

## 최신 교정: poison_b / sleep_b

이번 독립 지적의 두 자세만 수정했다. 모든 쓰기는 `source/` 안에 했다. 18색 팔레트와 나머지16개 격자는 이번 수정 직전과 바이트가 같다. 현재 기본9/추가9자세는 모두 완전한96×96 ASCII 원본이다. 첨부 원안 시트와64px 검객을 실제로 열어 관찰했고 참고 픽셀을 추출하지 않았다.

이번 수정 직전의18격자, 팔레트와 문서는 `before-contour-breath-repair/`에 보존했다. `contour_breath_rows.py`가 직접 고른 native ASCII 군집의 현재 교정 기록이다. 같은 자세의 보존 원본에 명시 문자열만 기록하며 다른 자세의 좌표를 복사하거나 전체 프레임을 변형하지 않는다. 자동 연결 보정/구멍 메우기/수식 명암은 사용하지 않았다.

### poison_b — 0-based 좌표

- `(54,37)`, `(53,38–40)`, `(54,41)`에 피부 가장자리를 따라 짙은 `o` 윤곽을 이어 찍었다.
- 그 뒤 `(54–57,37–41)`의 드러난 영역에 `m/s/r` 원반 면·그림자·얇은 테두리를 직접 복원했다. y=40은 x=57 손 외곽 앞에서, y=41은 x=56 손 외곽 앞에서 끝난다.
- 20픽셀을 바꿨다. 기존 피부·옮긴 손·손목·독 기포는 유지했다. 팔 사이의 의도된 투명 공간을 메우지 않았다.

### sleep_b — 실제 팔 처짐과 비단의 호흡

- 얼굴·닫힌 눈·금빛 장식·원반 상단을 유지했다. x=30–71, y=54–70의 목 아래 군집을 각 행의 실제 위치에서 다시 골랐다.
- 목 아래 피부와 옷깃을 이어 두고 어깨·접힌 팔 위 경계를 약1px 낮췄다. 넓은 팔꿈치 면, 소매의 짙은 경계, 금빛 손목과 피부 손을 함께 다시 찍어 쉬는 손도 내려왔다. 손만 떨어뜨리지 않았다.
- 가슴/원반 아래의 접힘 경계를 조정하고, 오른쪽 감긴 숄 y=71–78을 별도 리터럴 행으로 다듬었다. 왼쪽 끝 y=79–87은 조금 안쪽으로 접고 오른쪽 끝 y=88–91은 낮게 굽혔다. 발/밑창 군집을 추가하지 않았다.
- 수정 전 sleep_b 대비457픽셀, 그중 ink/투명 경계113픽셀이 바뀌었다. 이는 외곽선만의 개수가 아니다. 변경 범위는 `(27–78,54–91)`이다. 수치 자체가 자연스러운 호흡을 보증하지 않는다.
- sleep_a는 그대로다. 수면 두 자세의 실제1배에서 짧은 닫힌 눈꺼풀을 확인했으며 평상시 검은 눈 군집으로 대체하지 않았다.

### 현재 그림을 다시 읽고 연 근거

`python source/contour_breath_rows.py`는 이번 보존 원본에서 현재 두 자세를 재현한다. 그 뒤 `python source/render.py`로18PNG/8GIF를 다시 굽는다. `author_rows.py`/`repair_rows.py`는 이전 저작 기록이며 이것만 실행하면 최신 교정이 반영되지 않는다.

수정 전 `png/target-before.png`와 수정 후 `png/target-after.png`를 열어 턱/목·원반 경계 및 수면 양팔을 비교했다. 현재18자세의 `png/contact-light.png`, `contact-dark.png`, `contact-checker.png`도 모두 열어 native1배와 최근접3배를 확인했다. poison_a의 대응 턱/목과 다른 자세의 목·손목/소매도 함께 보았으며 이번 지적과 같은 경계 누락은 추가로 보이지 않았다.

8GIF를 다시 읽은 `png/gif-decoded-frames.png`를 실제로 열어 모든 프레임을 원본1배로 확인했다. 수면은 닫힌 눈을 유지한 상태에서 손·어깨가 낮아지고 숄 끝이 함께 굽는다. `render-record.json`에는 재읽은 실제 노출 시간과 현재 원본의 불투명 RGBA/알파 일치가 기록된다. 실시간 GIF 재생을 직접 관찰하거나 게임에서 전투/호핑을 실행한 기록은 아니다.

현재 해시/변경 범위는 `contour-breath-record.json`이다. 기존 `repair-record.json`은 아래 이전 교정 당시 자료다. 어느 기록도 모델 출처나 독립 검수/승인을 증명하지 않는다. 현재18격자는96×96, 외곽1px 투명이다. 최저 ink는 dead와 sleep_b의 y=91로 y≤92 조건 안이다. 이 종은 떠 있으므로 발 접지를 적용하지 않는다.

### 현재 남은 시각적 한계

- 두 프레임 수면은 작은 호흡이다. 팔/천 실루엣은 변하지만 얼굴과 원반은 정지한다. 실제 표시 크기·재생에서 충분히 읽히는지는 새 하네스 검수의 확인 사항이다.
- 접힌 양팔과 금장 손목은1배에서 조밀하다. 연결은 보이나 확대보다 세부 구별이 약하다.
- 밝은 배경에서 은빛 기술/파편 대비가 약하다. 기술은 보존했다.
- 준비→전진·사망 하강에는 중간 프레임이 없다. 실제 배틀의 접촉·호핑·baseline 배치는 확인하지 않았다.

테스트/게이트나 별도 검수자를 호출하지 않았다. 검수 결과·원장·사용자 선택을 수정하지 않았다. 새 독립 검수는 하네스가 맡는다. 통과나 사용자 승인을 선언하지 않는다.

# 이전 교정 당시 기록 — 뒤팔·비단 끝

아래 내용의 현재/수정본/해시는 이전 뒤팔 교정 시점을 뜻한다. 최신 상태와 재현 절차는 위 절을 따른다.

## 작업 범위와 보존

기존 월륜정령 초안을 수정했다. 작업 대상은 이 후보의 `source`뿐이다. 다른 종, 저장소 코드, 게임 저장소, brief, 원장, 검수 결과는 수정하지 않았다.

- 기본 `poses/` 9개와 추가 `actions/` 9개는 각각 96행 × 96글자의 완전한 ASCII 팔레트 원본이다.
- `palette.json`의 18색과 투명 기호 `.`을 그대로 유지했다.
- 수정 전 18개 격자, 팔레트, 저작 코드와 문서는 `before-repair/`에 보존했다.
- 기존 `author_rows.py`는 최초 저작 기록이다. 현재 수정본을 재현하려면 `python source/repair_rows.py`를 실행한다. 이 코드는 보존한 초안에 아래의 직접 고른 native 행/좌표 문자열만 기록한다. 그 뒤 `python source/render.py`로 그림과 GIF를 굽는다.
- `dead`는 원본과 바이트가 같다. 원반의 넓은 빛/기본/그림자 면, 얼굴, 금장, 앞손 접촉과 기술 효과는 수정을 필요한 부위에 한정하면서 보존했다.

첨부 원안과 64px 검객 참고를 실제로 열었다. 검객은 성인 얼굴의 작은 눈과 손/도구 연결, 상대 크기를 관찰하는 용도로만 썼다. 픽셀 추출·트레이싱·재배포는 하지 않았다.

## 직접 바꾼 군집

좌표는 0부터 세는 native `(x,y)`이다. 각 자세의 위치를 별도로 적은 `repair_rows.py`가 실제 수정 문자열의 정본이다. 다른 프레임을 이동·회전·보간하거나 좌표를 자동 복사해 파생하지 않았다.

### 뒤팔

원반 왼쪽 테두리에서 바로 나온 것처럼 보이던 먼 소매/손을 지웠다. 가려졌던 원반과 숄 면은 기존 재질과 같은 리터럴 행으로 복원했다. 뒤팔은 어깨 가까이 가져와, 넓은 위팔 면 → 방향을 바꾸는 팔꿈치 → 짧은 아래팔 → 금장 손목 → 피부 손의 순서로 다시 찍었다. 짙은 소매 경계로 뒤의 숄과 겹침을 구별했다.

### 숄 끝과 연결

발처럼 보이던 넓은 사각 끝과 밑창 같은 가로 외곽을 제거했다. 하단으로 갈수록 밝은 비단 면과 그림자 폭이 줄어드는 짧은 행을 직접 골랐다. 끝은 서로 길이와 굽음이 다른, 한두 픽셀로 접혀 사라지는 천이다. 신발·발가락·접지선을 추가하지 않았다.

- `idle_a`: 왼쪽 `(20–33,68–84)`과 오른쪽 `(58–72,68–79)`에서 서로 다른 방향의 가는 접힘으로 바꿨다.
- `idle_b`: 왼쪽 `(17–35,69–84)`과 오른쪽 `(55–75,67–78)`에서 바깥으로 흐른 뒤 폭이 줄어드는 끝을 찍었다.
- `idle_c`: 지적된 `(22–29,78–86)`의 넓은 발 군집을 제거했다. 왼쪽은 `(23–34,74–83)`의 접힌 끝, 오른쪽은 `(51–64,69–79)`의 더 짧은 끝이다. `skill_c`도 그 자세의 해당 천 끝을 별도 리터럴 행으로 고쳤다.
- 준비·전진·접촉·회수·피격 및 독/기절의 끝도 각 자세의 마지막 7–16행을 직접 고쳐, 큰 명암 면에서 점차 좁아지는 천으로 유지했다.
- `sleep_a/b`: 이전 `(23–43,85–89)`의 갈라진 발 같은 군집을 제거했다. 왼쪽은 `(27–37,78–87)`의 작은 접힘, 오른쪽은 `(67–78,80–90)`에서 말려 좁아지는 긴 비단 끝이다. 두 수면 프레임은 같은 끝과 팔 구조를 유지하고 가슴/상단 숄의 작은 숨 변화만 남겼다.

두 번째 확대 확인에서 전진/발사의 숄 뿌리와 기절/수면의 낮은 뿌리의 겹침이 약했다. 다음 위치에 넓은 천 면과 짙은 겹침 경계를 직접 기록했다.

- `move`, `attack`, `skill_b`: `(22–37,52–54)`에서 어깨 숄에서 뒤쪽 꼬리로 내려오는 면. 앞에 있는 손끝은 해당 자세의 좌표에 다시 찍었다.
- `stun_a/b`: `(21–40,53–59)`의 늘어진 숄 면. 소매와 금장 손목을 다시 전경에 기록해 팔과 천을 구별했다.
- `sleep_a/b`: `(19–35,62–65)`의 감긴 숄 뿌리. 접힌 팔의 소매/손은 별도의 전경 경계로 유지했다.

연결 진단은 위치를 읽는 데만 사용했다. 자동 구멍 메우기·연결 보완·윤곽 정리는 하지 않았다. 원반 아래의 열린 공간, 팔 사이와 감긴 비단 사이의 빈 공간은 의도된 투명 영역이다.

## 현재 그림에서 확인한 것

현재 18자세의 native PNG와 최근접 3배 확인판을 밝은/어두운/체커 배경에서 열었다. 수정한 뒤팔, 숄 끝, 낮은 숄 뿌리와 다른 자세의 같은 부위를 함께 보았다. 개별 `idle_a`, `idle_c`, `attack`, `stun_a`, `sleep_a`, `sleep_b`도 native 1배로 열었다. 수면의 짧은 닫힌 눈꺼풀은 그대로이며 평상시 검은 눈 군집으로 대체하지 않았다.

8개 GIF를 다시 만들고, GIF에서 복호화한 모든 프레임의 확인판을 열어 전환 순서와 연결을 보았다. `render-record.json`은 실제 GIF의 노출 시간 및 복호화한 불투명 색/알파가 현재 원본과 같은지 기록한다. 실제 게임의 이동·접촉·호핑을 실행한 기록은 아니다.

`repair-record.json`은 파일을 다시 읽은 현재 원본/PNG 해시, 픽셀 변경 수와 ink 범위다. 모델 provenance나 독립 검수 판정이 아니다. 팔레트는 변경되지 않았고 18개의 완전한 격자는 모두 서로 다르다. 모든 캔버스가 96×96이고 외곽 1px은 투명이다. 가장 낮은 ink는 보존한 `dead`의 y=91, 수정한 수면 끝은 y=90이다. 모든 자세는 y≤92이다. 떠 있는 종이므로 발 접지 조건은 적용하지 않는다.

## 남은 시각적 한계와 판단 범위

- 중간 비단 굽음은 native 계단형이다. 끝의 발/밑창 모양을 없앴지만, 접힌 자세의 두 아래 갈래는 여전히 짝으로 보일 수 있다. 이것이 충분히 천으로 읽히는지는 새 독립 검수에서 판단할 사항이다.
- 짧은 뒤팔과 숄이 겹치는 몸 앞 부분은 1배에서 조밀하다. 큰 팔꿈치/소매 면과 금장/피부 손은 구분했으나 확대판보다 세부가 약하다.
- 밝은 배경에서는 은빛 기술의 흰 면과 작은 파편 대비가 약하다. 기술 원본은 이번 교정의 지적 부위가 아니므로 유지했다.
- 독/기절/수면 쌍의 몸 변화는 작다. 수면의 닫힌 눈과 안정 자세는 유지했고 숨은 상단 천 면의 미세한 변화다.
- 준비→전진과 사망 하강은 보간 없는 주요 자세 전환이라 단호하다. 실제 배틀 접촉, 호핑과 baseline 배치는 런타임에서 별도로 확인해야 한다.

테스트/게이트나 별도 검수자를 실행하지 않았다. 독립 검수 및 사용자 선택은 하네스가 관리한다. 이 수정 기록은 통과나 사용자 승인을 선언하지 않는다.

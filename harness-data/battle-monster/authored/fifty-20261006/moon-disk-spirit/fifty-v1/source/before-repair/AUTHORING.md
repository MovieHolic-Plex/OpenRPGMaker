# 월륜정령 원본 저작 기록

## 범위와 원본

이번 후보의 `source` 안에서 월륜정령 한 종의 기본 9자세와 추가 9자세를 새로 저작했다. 기존 pxgrid는 없었다. 종 전체 50개를 제작하거나 다른 후보를 수정한 기록이 아니다.

- `poses/*.pxgrid`: 기본 9자세, 각각 96행 × 96글자의 완전한 ASCII 원본.
- `actions/*.pxgrid`: 기술·독·기절·수면 9자세, 같은 크기와 팔레트.
- `palette.json`: 18색. `.`은 투명이며 팔레트에 없다.
- `author_rows.py`: 직접 선택한 native 행 문자열과 자세별 좌표 변경을 보존한다. 빈 캔버스에 문자열을 기록하고 최종 완전한 행 파일을 저장한다. 움직이지 않는 원반/얼굴 면을 공통으로 읽고, 팔·목·어깨·천·표정·효과는 해당 자세의 실제 좌표에 별도로 썼다.
- `render.py`: 원본 읽기, 정확한 팔레트 PNG/GIF, 진단 배경/최근접 확대/라벨, GIF 재읽기만 담당한다.
- `png/`: 18개 투명 원본 PNG, 밝은/어두운/체커 배경의 1배+3배 확인판, GIF 복호화 프레임 시트.
- `gif/`: 8개 native 동작. `TIMING.md`는 순서·노출·손 앵커를 설명한다.

원/다각형/수식 마스크, 벡터 도형, 자동 명암, 몸 전체 이동·회전·보간, 픽셀 추출, 생성 이미지, 자동 빈틈 메우기는 사용하지 않았다. 참고 검객을 실제로 열어 작은 성인 얼굴, 손과 도구의 연결, 64px 상대 크기를 관찰했으며 그 픽셀은 복제하거나 source에 재배포하지 않았다.

## 외형과 재질

우향 3/4의 작은 성인 얼굴을 넓은 은백 달 원반 오른쪽 면에 넣었다. 금빛 이마 장식, 짧은 두 팔, 목·어깨에서 연결되는 푸른 비단 숄 두 갈래를 유지했다. 발이 없는 공중 정령이므로 지지발 대신 팔의 접힘/펴짐과 숄의 뒤쪽 흘림으로 돌격을 표현했다.

원반은 왼쪽 위의 넓은 흰 빛 면과 옅은 기본 면, 오른쪽으로 물러나는 청회색 그림자·얇은 테두리로 구분했다. 비단에는 밝은 청록 접힘 면과 넓은 파랑/짙은 파랑을, 금장에는 작은 따뜻한 빛 군집을 사용했다. 얼굴은 흰자 없이 작은 눈/눈썹과 코·볼 공간을 둔다.

## 자세별 직접 저작

- `idle_a/b/c`: 손과 어깨는 안정적으로 연결하고 두 숄의 굽음과 끝을 서로 다르게 찍었다. 얼굴의 작은 눈꺼풀 변화도 직접 썼다.
- `windup`: 왼팔과 오른팔을 본체 앞에서 접고 손을 숄 매듭 가까이 모았다.
- `move`: 위쪽 원반 테두리의 작은 기울기, 벌어진 팔꿈치, 앞으로 나온 손, 뒤로 펼쳐진 두 숄을 각각 다시 찍었다.
- `attack`: 준비/이동 손을 확대 변환하지 않고, 연결된 짧은 팔꿈치–넓은 아래팔–손목–세운 손바닥을 별도로 찍었다.
- `recover`: 두 팔꿈치가 돌아오고 손이 내려오는 자세와 안으로 접힌 숄.
- `hit`: 얼굴·목·어깨를 새로 저작해 움츠리고, 반동을 따라 두 숄을 오른쪽으로 흘렸다. 단단한 원반은 변형하지 않는다.
- `dead`: 빈 캔버스부터 낮게 내려온 별도 원반과 닫힌 얼굴, 연결된 접힌 팔, 바닥을 따라 펼쳐지는 두 비단 끝을 저작했다.
- `skill_a/b/c`: 손바닥에서 받치는 은빛 핵, 크기가 다른 두 굽은 초승달 날, 돌아오는 손끝과 작은 파편. 공격 자세/같은 원 오라를 대체 프레임으로 쓰지 않았다.
- `poison_a/b`: 턱을 감싸는 팔, 낮은 왼팔, 아픈 눈썹/입, 서로 다른 위치·크기의 기포. 색만 바꾸지 않았다.
- `stun_a/b`: 고개와 두 팔의 늘어짐, 느슨한 손가락, 서로 다른 별 위치. 독의 턱을 받치는 손과 구별했다.
- `sleep_a/b`: 빈 캔버스부터 낮은 휴식 원반과 감긴 천을 만들고 짧은 닫힌 눈꺼풀을 직접 찍었다. 같은 팔·천 끝을 유지하면서 가슴과 감긴 숄의 군집만 작은 숨으로 바꿨다. 쓰러짐과 서로 다른 실루엣이다.

## 실제로 열어 본 뒤 수정한 위치

1. 첫 idle 확인에서 오른 어깨 뿌리가 약해 보여, `idle_a/b/c`의 (53–65,41–47) 부근에 숄/소매 연결 면을 직접 보강했다. 다른 자세의 같은 어깨는 각 자세의 별도 팔 문자열로 확인했다.
2. 초기 `hit`에서 손으로 바꾼 위쪽 테두리 밖에 이전 원반 테두리가 남았다. (48–61,17–29) 부근의 밝은 배경/체커 확인에서 이를 발견했다. 임시 좌표 보완 후에도 실루엣이 꺾여 보였으므로 해당 변형 테두리 전체를 제거하고 원반의 원래 리터럴 면을 유지했다. 반동 얼굴·목·어깨·팔·숄은 유지했다. `move/attack/skill_b`의 위 테두리도 함께 열어 확인했다.
3. 초기 `skill_b`의 두 날빛이 한 긴 S형 띠처럼 합쳐 보여 (70–91,32–72)에서 위 날 끝을 좁히고 아래 날의 뿌리/외곽을 별도로 다시 찍었다. 손에서 이어지는 작은 은빛 군집을 유지하고 두 날의 길이와 곡률을 다르게 했다.
4. `skill_c`에서 잔광의 손 기점을 더 명확히 하려고 (65–67,51–53)에 손끝에 닿는 은빛 군집을, (70–71,53–54)에 작은 분리 파편을 추가했다.
5. `sleep_a/b`와 `dead`는 개별 native PNG도 열어 닫힌 눈을 확인했다. 수면은 (49–53,43–44) 부근의 짧은 눈꺼풀을 두 프레임 모두 유지한다. 코와 바깥 윤곽을 눈의 큰 검은 군집으로 쓰지 않았다.

## 관찰과 파일 계약

18자세 전체를 밝은/어두운/체커 배경에서 native 1배와 최근접 3배로 열었다. 팔/손/목/숄의 실제 면, 의도하지 않은 투명 단절, 상태이상 구별을 보았다. 천 사이 공간과 감긴 숄의 빈 공간은 의도된 투명 영역으로 보존했다. 연결 좌표 진단은 위치를 읽는 데만 사용했으며 자동으로 픽셀을 채우지 않았다.

모든 격자는 96×96, 1px 외곽 투명, 불투명 알파 255/투명 0이다. 가장 낮은 ink는 `dead`의 y=91이며 모든 자세는 y≤92를 지킨다. 공중형이라 대기 발 접지 규칙은 적용하지 않는다. 8개 GIF를 다시 읽어 원본 RGBA와 비교한 실제 결과와 시간은 `render-record.json`에 보존했다. 이는 파일/복호화 기록이며 독립 시각 검수 결과가 아니다.

## 남아 있는 표현 한계

- 밝은 배경에서는 은빛 날의 흰 중심과 작은 파편 대비가 어두운 배경보다 약하다. 청회색 외곽은 남아 있지만 1배에서 작은 파편은 아주 짧게 보인다.
- 비단 굽음은 native 픽셀의 계단형 곡선이다. 준비→전진과 사망 하강은 중간 보간 없이 직접 저작한 주요 자세를 잇는 짧은 동작이라 전환이 단호하다.
- 수면의 숨은 가슴/천 면의 작은 변화이므로 1배에서는 매우 미묘하다. 닫힌 눈과 감긴 안정 자세가 수면의 주 표식이다.

별도 검수자를 호출하거나 하네스/원장/brief/게임 저장소를 수정하지 않았다. 실제 독립 검수·사용자 선택·모델 provenance는 하네스가 관리하며, 이 문서는 통과/승인이나 사용자 선택을 선언하지 않는다. 테스트/게이트는 실행하지 않았다.

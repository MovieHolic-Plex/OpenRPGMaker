# 은검여협 — 치마·쓰러짐 교정

## 범위와 참고 관찰

이번 수정은 이 후보의 `source/` 안에서만 했다. 제공된 전체 자세 그림과 `references/human-size.png`를 실제로 열어 성인 SD 비율, 작은 눈, 목·어깨·검손 연결을 관찰했다. 참고 픽셀을 추출·추적·복제하지 않았다. 저장소 코드, 게임 저장소, ledger, brief, 다른 후보와 검수 결과는 수정하지 않았다. 별도 검수자를 호출하거나 사용자 선택을 기록하지 않았다.

은백 머리·검은 비녀·장년 여성 얼굴·청록 장포·금 허리띠·은검·짧은 검집을 보존한다. 기존 18색 팔레트와 왼쪽 위 광원을 유지한다. 피부 L/F/K, 천 V/C/T와 U/N/B, 은발·금속 W/S/H의 넓은 면을 쓴다. 점은 투명이고 팔레트에 없다. 대기 본체는 y7–60, 높이 54px이다.

## 직접 고친 군집

### 남청 치마

- **idle_a/b/c:** x22–36, y49–56의 갈라진 하체를 이어진 앞 치마 면으로 저작했다. U/N의 넓은 면에 B의 묶인 주름을 넣고 y56에 어두운 밑단을 남겼다. 신발은 y58–60에 드러난다. 치마는 안정되게 유지하고 기존 가슴·소매의 호흡을 보존했다.
- **windup:** x24–39, y49–56에 폭 있는 준비 자세의 치마와 이어진 밑단을 찍었다. 기존 허리 검손과 접힌 소매를 유지한다.
- **move/attack:** 각 자세의 x17–36, y49–54에 앞으로 들린 치마의 이어진 면과 사선 주름을 별도로 찍었다. 치마 안의 투명 가랑이 틈을 없애고 밑단 아래의 실제 지지 발과 앞 발목은 남겼다.
- **recover/hit/skill_a/skill_c/poison_a/b/stun_a/b:** 각 자세의 실제 옷자락 위치에 맞춰 넓은 면·주름·밑단을 개별 행 문자열로 찍었다. 손·소매·칼날과 상태 효과를 유지한다.
- **skill_b:** x17–40, y48–54에 가장 넓게 펼친 치마와 사선 주름을 찍었다. 앞 발목은 밑단 아래에 드러나고 검끝의 두 검기는 보존된다.
- 새 밑단과 발목 사이에 갇힌 한두 투명 픽셀을 실제 그림에서 확인했다. 대기 (21,57), 준비 (23,56), 이동/공격 (16–17,56), 회수 (21,57), 피격 (23,57), 기술 a (21,57)·b (19,54)·c (22,57), 독 쌍 (22,57), 기절 쌍 (23,57)을 B의 천 끝으로 직접 지정했다. 기절 b의 y50–52 앞 치마는 칼날과의 공간을 열도록 다시 찍었다. 자동 구멍 채우기는 사용하지 않았다. 검집 주변과 손 아래의 의도한 빈 공간은 남겼다.

### 쓰러짐

- 기존 y37–54의 거의 선 머리를 지우고 x13–35, y43–56에 낮게 기울어진 은발 머리와 옆얼굴을 새 리터럴 행으로 찍었다. K의 짧은 눈꺼풀과 주변 피부 면으로 닫힌 눈을 표현했다. 머리 전체 이동·회전이나 리샘플링을 사용하지 않았다.
- x25–42, y51–60에 목의 K/F 부피, W 옷깃, V/C/T 어깨·옆가슴·바닥 소매를 분리해서 저작했다. 이전의 얇은 몸통 띠를 실제 청록 옆몸통으로 고쳤다.
- x40–51, y54–59에 접힌 남청 치마의 N/U 면과 B 겹침 경계를 배치했다. 접힌 발끝도 치마 뒤에 남겼다.
- 목→어깨→소매→바닥 검손이 이어진다. 검손 x31–35, y59–60 → 금 자루/검턱 x37–40, y60 → 은검 날 x41–61, y60도 연속한다. 실제 몸/소매의 하중 윤곽도 y60에 닿는다.
- 첫 진단 시트에서 이전 비녀의 (10–11,41) 두 픽셀이 고립되어 남은 것을 찾아 해당 좌표만 직접 지웠다. 새 머리에 붙은 검은 비녀는 y46에 남긴다.

### 보존한 상태 자세

`sleep_a/b` 원본은 수정하지 않았다. 앉은 치마·무릎·닫힌 눈·낮춘 검과 b에서 내려온 턱·어깨 윤곽의 숨 변화가 유지된다. 독의 턱 받친 팔·기포, 기절의 처진 검·다른 별 위치, 기술의 모으기→검끝 두 은백 검기→깨진 잔상을 유지했다. 18자세는 서로 다른 픽셀 배열이다.

## 원본과 보조 코드

- `poses/*.pxgrid`, `actions/*.pxgrid`: 최종 64줄 × 64글자의 full literal ASCII, 기본9 + 추가9.
- `palette.json`: 기존 ASCII→RGB 18색.
- `before-skirt-fall-repair/`: 이번 교정 전18개 격자·팔레트·저작/시간 문서 사본.
- `author.py`, `literal-rows.txt`, `repair-rows.txt`: 기존 저작 보조 코드와 직접 고른 행 기록.
- `skirt-fall-rows.txt`: 이번 자세별 y/x/리터럴 군집. 각 자세 좌표를 별도로 지정했다.
- `apply-skirt-fall.py`: 명시한 문자열만 적용한다. 도형·명암·포즈·효과 생성, 자동 복사·구멍 채우기·연결 수선을 하지 않는다. `author.py` 마지막에도 이 기록을 적용한다.
- `render.py`: 최종 격자 읽기, native PNG, 진단 확대·라벨, 인덱스 GIF, GIF 재읽기와 실제 파일 해시 계산.

기존 원본부터 재생성하려면 `python source/author.py`, 현재 격자를 렌더링하려면 `python source/render.py`를 실행한다. 하네스 소비 대상은 최종 full literal pxgrid다. 이전 상세 저작 기록은 보존 사본의 AUTHORING.md에 남겼다.

## 실제 그림 확인

18개 PNG와 밝은·어두운·체커 배경의 1배/최근접4배 시트를 열어 얼굴·목·어깨·소매·손·검·치마·발을 함께 비교했다. `preview/motions/`의8개 GIF를 다시 읽어 원본 RGBA와 노출 시간의 일치를 확인했다. GIF에서 읽은 `*-decoded.png` 8장을 실제로 열어 공격 준비→전진→접촉→회수, 피격→쓰러짐, 기술·독·기절·수면 쌍을 비교했다. 확대는 진단에만 사용하며 native 원본은64px 그대로다.

모든 자세의 최저 픽셀은 y60이고 투명 테두리를 유지한다. idle_a의 실제 발이 y60에 닿는다. `preview/source-hashes.json`은 실제 현재 파일의 해시와 잉크 경계이며 검수 결과나 승인 기록이 아니다. 테스트/게이트는 실행하지 않았다.

## 남은 표현 한계

- 밝은 배경에서 은백 검기와 청금 잔상의 대비가 낮다.
- 64px에서 치마 주름과 발목은 압축된 표현이다. 기술 b의 치마는 빠른 펼침에 따라 다른 자세보다 사선으로 길다.
- 쓰러짐은 종결 핵심 자세이며 hit에서 눕기까지 중간 낙하 자세는 없다. 목·소매가 가까이 겹친다.
- GIF 재읽기와 정지 프레임 비교를 수행했다. 실제 게임의 이동·충돌·피해 시점과 표시 크기는 여기서 확인하지 않았다.

이 원본은 새 독립 검수와 사용자 판단을 기다린다. 파일 검사나 자체 관찰을 통과 판정·사용자 승인으로 주장하지 않는다.

# 서리영녀 동작 시간표

GIF는 native 96×96 원본 프레임을 재생한다. 반복은 무한, 투명 인덱스는 0, disposal은 2다. 노출 시간은 10ms 단위이며 전체 프레임 이동·회전·보간을 생성하지 않는다. 바닥 기준은 y=92다.

| 동작 / 파일 | 자세 순서 | 각 노출 시간 (ms) |
|---|---|---|
| 대기 `preview/idle.gif` | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| 공격 `preview/attack.gif` | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 |
| 피격 `preview/hit.gif` | idle_a → hit → idle_a | 700 / 180 / 900 |
| 쓰러짐 `preview/dead.gif` | idle_a → hit → dead | 700 / 150 / 1700 |
| 빙사결 `preview/skill.gif` | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 |
| 독 `preview/poison.gif` | poison_a → poison_b | 420 / 420 |
| 기절 `preview/stun.gif` | stun_a → stun_b | 300 / 300 |
| 수면 `preview/sleep.gif` | sleep_a → sleep_b | 650 / 650 |

## 손과 띠의 실제 앵커

아래 좌표는 0부터 시작하는 원본 픽셀 좌표다. 몸/효과의 중심 상자를 앵커로 대신하지 않는다.

- 준비 `skill_a`: 손가락 x=55–59, y=48–50. 손 바깥의 각진 얼음 핵과 띠가 손 바로 오른쪽에서 이어진다. 접힌 앞 소매가 어깨에서 팔꿈치·커프·손으로 올라온다.
- 발동 `skill_b`: 앞 손가락 x=60–64, y=49–51, 띠 뿌리 x=65 부근, y=50. 손에서 밝은 실크 면이 오른쪽으로 이어지고 x=75–83, y=45–55의 분기에서 세 결정으로 갈라진다. 위 결정은 y=25, 옆 결정은 x=93, 아래 결정은 y=72까지 뻗는다. 효과는 입이나 가상의 중앙 오라에서 나오지 않는다.
- 회수 `skill_c`: 손가락 x=47–50, y=57–59. 손을 접어 내리며 짧은 띠를 회수한다. 분리된 파편은 붕괴된 결정 조각으로 의도한 빈 공간을 갖는다.
- 기본 공격 접촉 `attack`: 손 x=60–66, y=50–52. 밝은 띠 뿌리가 손 오른쪽에 붙고 전방으로 넓어졌다가 가늘어진다. 끝은 y=84에서 접혀 바닥의 지지발과 구분된다.

## 동작 확인과 사용 범위

- 준비 200ms에서 손을 어깨로 당기는 실루엣을 유지한다. 전진 100ms에서 앞발을 들어 옷을 열고, 접촉 120ms에서 앞발을 내려 뒤발로 지지한다. 회수 220ms 뒤 원래 대기로 돌아온다.
- 기술은 260ms 핵 모으기, 160ms 세 결정의 최고점, 240ms 깨진 파편 회수다. 짧은 최고점에서 결정 분기의 각기 다른 모양을 확인할 수 있다.
- 독은 턱/배를 짚은 자세와 입·기포 변화, 기절은 낮은 머리/손과 별 위치 변화, 수면은 감은 눈을 유지한 가슴/무릎 면의 호흡이다.
- `preview/gif-*-frames.png`는 실제 GIF를 다시 디코드한 전 프레임 접촉 시트다. `preview/index.html`에서 8개 GIF를 함께 재생하고 정지 그림으로 전환할 수 있다.
- 이 시간표는 후보 그림의 재생 순서다. 게임의 이동, 피해, 효과음, 전투 구현과 사용자 선택을 대신하지 않는다.

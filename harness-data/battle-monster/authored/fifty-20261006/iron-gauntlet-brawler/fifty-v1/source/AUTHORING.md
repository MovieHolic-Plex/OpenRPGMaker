# 철권무인 — fifty-v1 원본 저작

## 범위와 참고

이 문서는 최초 초안의 저작 기록과 이번 상태 교정 기록을 함께 보존한다.
이번 작업은 이미 있던 팔레트·18자세 초안에서 시작했고, 이 후보의 `source/`만 수정했다.
초기 저작 기록에서 팔레트와 자세 격자는 새로 작성되었다.
`references/human-size.png`를 직접 열어 성인 SD의 머리/몸 크기, 작은 우향 눈,
목과 옷깃의 연결, 손과 도구가 만나는 부분을 관찰했다. 참고 픽셀을 추출하거나
복사/추적/리샘플하지 않았다. 이 후보는 짧은 검은 머리, 붉은 머리띠와 허리띠,
남청 민소매 겉옷, 회갈 바지, 두 회은 철제 건틀릿을 가진 원래의 무인이다.

## 원본과 직접 저작 방식

- `palette.json`: 투명 기호 `.`을 제외한 ASCII 기호 18개, 고정 RGB.
- `poses/`: 기본 9자세의 최종 **64행 × 64열** 리터럴 ASCII 원본.
- `actions/`: 기술 3, 독 2, 기절 2, 수면 2자세의 같은 크기 원본.
- `author_pixels.py`, `pose_rows.py`, `action_rows.py`: 최초에 직접 고른 행별
  x 시작점과 색 문자열. 각 자세의 몸과 효과를 별도 문자열로 적었다.
- `chosen_revisions.py`: PNG를 연 뒤 선택한 자세별 실제 행 교정 기록.
  값은 해당 자세의 x와 전체 행 색 문자열이다. 다른 자세에 좌표를 전파하지 않는다.
- `state_revisions.py`: 이번 sleep_a/b와 dead의 **각기 선택한** native 행 교정.
  `chosen_revisions.py`의 최종 행에도 연결하여 최초 저작 도구를 다시 실행할 때
  이번 교정을 지우지 않게 했다. 실제 납품 원본은 전체 리터럴 `.pxgrid`다.
- `before-state-repair/`: 이번 교정 전 세 원본의 바이트 사본과
  팔레트·18자세 전체의 실제 SHA-256. 이전 얼굴과 현재 얼굴을 비교할 수 있다.
- `render_state_comparison.py`: 보존 원본과 현재 원본을 해독하여 세 배경의
  1배/최근접 4배 전후 비교판만 만든다. 그림 저작에는 관여하지 않는다.
- `render_source.py`: 원본 해독, native PNG/GIF 인코딩, GIF 픽셀 재읽기,
  배경 합성 및 진단판 확대만 한다. 몸/효과를 생성하는 도형·수식은 없다.

문자열을 native 행에 그대로 쓰고 좌우/미사용 행에 투명만 패딩한다.
광원은 왼쪽 위. 피부의 L/s/S, 천의 B/n/N, 바지의 l/p/P,
철판의 W/m/M은 각 재질의 넓은 면으로 직접 선택했다. 금속은 밝은
윗판과 어두운 아랫판, 천은 사선 겹깃과 넓은 접힘을 사용한다.
기본 idle_a 본체는 y=8..60, 높이 53px이다. 기본 머리는 약 20px,
주요 얼굴 피부 면은 14px 안쪽으로 다듬고 코/볼 앞에 여유를 남겼다.

## 자세와 교정 기록

1. 대기 본체를 먼저 그려 밝은 배경 확대 PNG에서 얼굴·목·어깨·주먹·발을
   확인했다. 두 건틀릿, 근육 위팔, V형 겹깃, 허리띠, 두 바지 다리를 완성한 뒤
   나머지를 별도 행 문자열로 그렸다.
2. 기본 공격은 화면 왼쪽의 가까운 어깨에서 시작하는 **같은 팔**을 사용한다.
   windup에서 팔꿈치를 뒤로 보내 주먹을 허리로 당기고, move에서 뒷다리를
   펴며 무게를 앞쪽으로 보낸다. attack은 가까운 위팔→팔꿈치→전완→손목→
   건틀릿을 길게 연결한다. 반대 주먹은 낮은 가드이다.
3. 최초 attack y=40..45에 남은 불필요한 금속 덩어리를 남청 몸통/겉옷
   군집으로 다시 저작했다. 최종 attack y=51..54의 뒷다리는 허벅지/무릎 면을
   넓혀 가는 사선 한 줄처럼 읽히는 문제를 줄였다.
4. idle_b/c의 발바닥, move y=58..60을 각각 따로 그려 실제 발을 y=60에 놓았다.
   attack의 바닥 넘침을 고치고, dead y=56..60에는 피부 팔/옷/접힌 다리의
   하중 윤곽을 그렸다. 초안 dead의 y=45 눈은 짧은 선이었지만 독립 지적에서
   깨어 있는 시선으로 읽혔다. 이번 교정은 아래 별도 기록을 따른다.
   쓰러진 몸과 접힌 다리/작은 신발은 보존했다.
5. skill_a는 가까운 팔을 접어 가슴 앞에서 기를 모은다. skill_b는 같은 팔의
   건틀릿 앞면에서 위/중앙/아래로 갈라지는 은백·청록 충격을 방출한다.
   y=24..44의 효과를 직접 다시 찍어 길고 날카로운 위 조각, 짧고 넓은 중앙 조각,
   꺾여 떨어지는 아래 조각과 서로 다른 끝/음영을 만들었다.
6. skill_c 초기에는 잔전류가 반대 가드 손에 붙어 있었다. 최종 y=32..46에서
   가까운 팔의 접힌 팔꿈치·전완·손목과 가슴 앞 건틀릿을 새로 저작했다.
   작은 전류는 그 손 전면에 붙고, 낮은 반대 손은 빛나지 않게 했다.
7. 독은 가까운 건틀릿으로 턱을 받치고 반대 손으로 배를 누른 자세이다.
   poison_b는 고개/턱과 어깨가 더 내려오고 무릎을 굽힌다. 독 기포 위치와
   내부 투명을 따로 찍었다. poison_a y=12..20의 기포 외곽을 직접 다듬었다.
8. stun은 두 팔과 철권이 무겁게 늘어진 자세, 작은 닫힌 눈과 처진 머리이다.
   두 별의 위치는 두 프레임에서 서로 다르다. poison_b y=50..60,
   stun_a y=52..60, stun_b y=52..60, skill_b y=51..60의 다리/신발을
   각 자세에서 새로 선택해 바닥 초과를 없앴다. 전체 몸을 이동하지 않았다.
9. 초안 수면은 바닥에 앉아 두 무릎에 건틀릿을 놓았고 두 번째 자세의
   머리/어깨/손에 호흡 차이를 그렸다. 초안의 수평 눈 군집과 선 머리는
   독립 지적에서 앉아 지켜보는 모습으로 읽혔다. 아래 교정으로 대체했다.

## 이번 독립 지적에 따른 직접 교정

좌표는 0부터 시작한다. 다른 종·후보·brief·판정·선택·저장소는 수정하지 않았다.
팔레트와 나머지 15개 `.pxgrid`는 이전 SHA-256과 같다.

- **sleep_a:** 지적된 (34–35,38), (39–40,38)의 K 눈을 피부/이마 면으로
  없앴다. 닫힌 눈꺼풀은 H를 (34,40)→(35–36,41),
  (40,40)→(41–42,41)에 직접 찍은 두 굽은 군집이다. 눈썹/흰자/동공은 없다.
  y=33..36 머리띠와 앞머리의 아래쪽 경계, y=37..44 이마·코·볼·입·턱,
  y=45..48 턱 밑 피부·목·겹깃을 따로 그려 머리가 앞으로 숙여지게 했다.
  턱 피부는 y=45의 x=36..40까지 내려와 목의 s/S 면에 겹친다.
  앉은 다리·무릎의 두 건틀릿·작은 신발·접지 y=60은 그대로다.
- **sleep_b:** 지적된 (34–35,39), (39–40,39)도 이마/피부로 교체했다.
  H 눈꺼풀은 (35,41)→(36–37,42), (41,41)→(42–43,42)에
  별도 문자열로 골랐다. 낮아진 고개에 맞춰 두 눈·코·입·턱과 목 경계를
  y=34..49에서 각 행으로 다시 정했다. y=46의 낮은 턱과 압축된 어깨,
  기존 y=53..59 손/가슴의 작은 호흡 차이를 함께 유지한다.
  sleep_a의 좌표를 자동 이동·복사해 이 프레임을 만들지 않았다.
- **dead:** 기존 y=34..39의 높은 정수리 윤곽을 리터럴 투명 행으로 지웠다.
  y=40..48에는 낮고 넓은 정수리/머리띠/옆머리, y=49..55에는
  눕힌 얼굴·처진 턱과 목의 피부 부피를 직접 저작했다. 옛 y=45의
  눈은 이제 머리카락이고, 눈꺼풀은 (20,50)→(21–22,51),
  (24,50)→(25–26,51)의 굽은 H 군집이다. 턱 아래는 어깨의 피부와
  이어지고, y=56의 피부 손목이 y=57..60의 낮고 넓은 건틀릿에 겹친다.
  기존의 높은 팔 지지 삼각형을 없애 머리가 이완된 팔 가까이 내려오게 했다.
  반대 건틀릿·남청 몸통·접힌 바지 다리·작은 신발은 보존했다.
  렌더 뒤 y=54,59의 행 길이로 생긴 1px 경계 어긋남을 각각 직접 고쳤다.
  y=60에서 실제 건틀릿/몸/신발이 접지하며 장식으로 바닥을 대신하지 않는다.

`state_revisions.py`는 위 세 자세에만 각각의 리터럴 행을 적용한다.
모든 final 격자는 64행×64열이며 자동 구멍 채움·회전·전체 프레임 이동·
수식 명암·효과 생성은 사용하지 않았다.

## 실제 그림 확인

이번 교정에서는 18장의 native PNG와 8개 GIF를 기존 리터럴 원본에서 다시 구웠다.
전체 1배/최근접 4배 확인판과 세 상태의 전후 비교판을 밝은/어두운/체커
배경에서 실제 열었다. GIF를 재디코드한 sleep/dead 및 전체 동작 확인판으로
저장 프레임의 얼굴·목·손·접지·호흡 차이를 확인했다.
GIF 바이트에서 읽은 RGBA가 각 native PNG와 일치하는지는 렌더러가 확인했다.
세 비교판에서 얼굴·목·손의 의도하지 않은 내부 투명 홈은 보이지 않았다.
전체 시트로 같은 부위를 다른 15자세와 비교했으며 이번 세 상태에만 격자 교정을 남겼다.
native 체커판도 실제 체커 타일 위에 합성되도록 진단 렌더러를 고쳤다.
테스트/게이트·별도 독립 검수자 호출은 실행하지 않았다.
PNG 팔레트/경계/접지/연결 좌표 진단은 결손 위치 확인용이며 자동 채움에 쓰지 않았다.
모든 본체는 이어진 덩어리이고, 별/독 기포/깨진 전류의 분리와 두 다리 사이의
빈 공간은 의도한 표현이다. 모든 최종 자세의 실제 하단은 y=60이다.

## 남은 표현 한계 / 검토 대기

- 은백 기술과 작은 독 기포는 밝은 배경 1배에서 어두운 배경보다 대비가 약하다.
  짧은 M색 끝/청록 경계로 구분했지만 실제 게임 배경에서 다시 판단할 부분이다.
- 어두운 신발은 어두운 배경에서 면 분리가 약하다. 이번 얼굴/하중 교정에서는
  승인 대기 중인 나머지 자세의 신발·팔레트를 바꾸지 않았다.
- 닫힌 눈꺼풀은 native에서 3px 폭이다. 숙인 머리·낮은 턱·이완된 손과 함께
  수면/쓰러짐을 표현하지만 최종 읽힘은 하네스의 새 독립 검수 대상이다.
- 64px의 주먹 찌르기는 준비/이동/접촉/회수 네 핵심 자세로 압축했다.
  엔진의 실제 이동 거리·적중 순간·피해/소리 동기화는 이 후보에서 확인하지 않았다.
- 쓰러짐은 옆으로 내려앉은 한 자세이고, 그 이후 추가 구르기/경련은 없다.
- GIF 저장 프레임과 노출 시간을 확인했다. 이 작업에서 실제 게임/브라우저의
  실시간 전투 재생이나 별도 독립 검수는 수행하지 않았다.

독립 검수/사용자 선택은 하네스에 남긴다. 사용자 승인이나 검수 통과를 선언하지 않는다.
원본, 선택한 좌표, 실제 계산한 파일 해시는 보존하며 모델/검수 기록을 만들어 넣지 않는다.

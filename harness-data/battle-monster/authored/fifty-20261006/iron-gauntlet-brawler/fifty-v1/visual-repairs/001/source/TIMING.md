# 철권무인 — native GIF 시간표

모든 GIF는 **64×64**, 원본 팔레트 그대로, alpha 0/255, disposal 2,
무한 루프이며 중간 프레임/보간/몸 전체 변환 없이 저작 프레임만 사용한다.
노출은 아래 ms 단위로 지정한다. 디코드 픽셀이 해당 원본 PNG와 같은지 확인한다.

| GIF | 자세 순서 | 각 노출(ms) |
|---|---|---|
| idle.gif | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack.gif | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 |
| hit.gif | idle_a → hit → idle_a | 700 / 180 / 900 |
| dead.gif | idle_a → hit → dead | 700 / 150 / 1700 |
| skill.gif | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 |
| poison.gif | poison_a → poison_b | 420 / 420 |
| stun.gif | stun_a → stun_b | 300 / 300 |
| sleep.gif | sleep_a → sleep_b | 650 / 650 |

## 동작/발원점

좌표는 native의 0부터 시작하는 (x,y)이다. 기본 바닥은 y=60.

- 공격 팔: 관객에게 가까운 화면 왼쪽 어깨의 팔이다. 뒤로 꺾인 팔꿈치와
  허리 주먹을 windup에서 읽고, 뒤 지지발로 밀어 move의 긴 보폭에 들어간다.
  attack에서 같은 위팔/전완이 정면으로 펴진다. 반대 주먹은 낮은 가드로 유지한다.
- **skill_a:** 가슴 앞에 접은 가까운 철권. 실제 철판의 앞면과 W/E 기 군집은
  대략 (42,35)..(46,37)에서 맞닿는다. 팔꿈치에서 전완의 피부를 거쳐 손목과
  건틀릿으로 이어지는 경로를 남긴다. 260ms는 이 모으기를 읽는 시간이다.
- **skill_b:** 같은 팔의 전진 타격. 발원은 건틀릿 앞면 약 (50,35)..(51,37).
  위 조각은 y=24까지, 넓은 중앙 조각은 x=62까지, 꺾인 아래 조각은 y=44까지
  뻗는다. 갈래 사이의 투명은 의도한 틈이며 뿌리는 주먹 전면에 붙는다.
  160ms 동안 접촉의 큰 군집을 보여 준다.
- **skill_c:** 가까운 팔을 가슴으로 접는다. 그 철권 전면 (41,35)..(42,37)에
  짧은 전류가 남고, (44,38)..(46,39)에는 끊어진 잔상이 있다.
  반대편 낮은 가드 건틀릿은 빛나지 않는다. 240ms 뒤 대기로 돌아간다.
- 독: 턱을 받친 손·배를 누르는 손과 아픈 어깨, 더 내려온 다음 고개를 비교한다.
  두 기포/작은 독 먼지는 프레임마다 위치와 외곽이 다르다.
- 기절: 처진 두 철권, 내려간 머리, 위치가 바뀌는 두 작은 별.
- 수면: 앉은 다리/무릎의 손을 유지한다. 두 짧은 닫힌 눈꺼풀을 보존하고
  두 번째 프레임의 머리 꼭대기·턱·목·어깨를 따로 그려 작은 호흡을 표현했다.
  650ms씩 유지하므로 서서 흔들리는 기절과 다른 안정된 쉼이다.

`preview/*-gif-frames.png`는 실제 GIF를 재디코드해 순서와 노출 라벨을 붙인
최근접 진단판이다. `preview/all-gif-decoded.png`에 8종이 모여 있다.
이 시간표는 후보 자세 재생이며 실제 게임 전투 동기화의 증거는 아니다.

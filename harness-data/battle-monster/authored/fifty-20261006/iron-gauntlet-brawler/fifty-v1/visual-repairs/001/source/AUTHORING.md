# 철권무인 — fifty-v1 원본 저작

## 범위와 참고

이 후보의 `source/`만 저작했다. 시작 시 팔레트와 자세 격자는 없었다.
`references/human-size.png`를 직접 열어 성인 SD의 머리/몸 크기, 작은 우향 눈,
목과 옷깃의 연결, 손과 도구가 만나는 부분을 관찰했다. 참고 픽셀을 추출하거나
복사/추적/리샘플하지 않았다. 이 후보는 짧은 검은 머리, 붉은 머리띠와 허리띠,
남청 민소매 겉옷, 회갈 바지, 두 회은 철제 건틀릿을 가진 원래의 무인이다.

## 원본과 직접 저작 방식

- `palette.json`: 투명 기호 `.`을 제외한 ASCII 기호 18개, 고정 RGB.
- `poses/`: 기본 9자세의 최종 **64행 × 64열** 리터럴 ASCII 원본.
- `actions/`: 기술 3, 독 2, 기절 2, 수면 2자세의 같은 크기 원본.
- `author_pixels.py`, `pose_rows.py`, `action_rows.py`: 최초에 직접 고른 행별
  x 시작점과 색 문자열. 각 자세의 몸과 효과를 별도 문자열로 적었다.
- `chosen_revisions.py`: PNG를 연 뒤 선택한 자세별 실제 행 교정 기록.
  값은 해당 자세의 x와 전체 행 색 문자열이다. 다른 자세에 좌표를 전파하지 않는다.
- `render_source.py`: 원본 해독, native PNG/GIF 인코딩, GIF 픽셀 재읽기,
  배경 합성 및 진단판 확대만 한다. 몸/효과를 생성하는 도형·수식은 없다.

문자열을 native 행에 그대로 쓰고 좌우/미사용 행에 투명만 패딩한다.
광원은 왼쪽 위. 피부의 L/s/S, 천의 B/n/N, 바지의 l/p/P,
철판의 W/m/M은 각 재질의 넓은 면으로 직접 선택했다. 금속은 밝은
윗판과 어두운 아랫판, 천은 사선 겹깃과 넓은 접힘을 사용한다.
기본 idle_a 본체는 y=8..60, 높이 53px이다. 기본 머리는 약 20px,
주요 얼굴 피부 면은 14px 안쪽으로 다듬고 코/볼 앞에 여유를 남겼다.

## 자세와 교정 기록

1. 대기 본체를 먼저 그려 밝은 배경 확대 PNG에서 얼굴·목·어깨·주먹·발을
   확인했다. 두 건틀릿, 근육 위팔, V형 겹깃, 허리띠, 두 바지 다리를 완성한 뒤
   나머지를 별도 행 문자열로 그렸다.
2. 기본 공격은 화면 왼쪽의 가까운 어깨에서 시작하는 **같은 팔**을 사용한다.
   windup에서 팔꿈치를 뒤로 보내 주먹을 허리로 당기고, move에서 뒷다리를
   펴며 무게를 앞쪽으로 보낸다. attack은 가까운 위팔→팔꿈치→전완→손목→
   건틀릿을 길게 연결한다. 반대 주먹은 낮은 가드이다.
3. 최초 attack y=40..45에 남은 불필요한 금속 덩어리를 남청 몸통/겉옷
   군집으로 다시 저작했다. 최종 attack y=51..54의 뒷다리는 허벅지/무릎 면을
   넓혀 가는 사선 한 줄처럼 읽히는 문제를 줄였다.
4. idle_b/c의 발바닥, move y=58..60을 각각 따로 그려 실제 발을 y=60에 놓았다.
   attack의 바닥 넘침을 고치고, dead y=56..60에는 피부 팔/옷/접힌 다리의
   하중 윤곽을 그렸다. dead는 목 피부 부피를 남기고 두 눈을 짧은 닫힌 선으로
   다듬었다(y=45). 쓰러진 몸과 접힌 다리/작은 신발을 함께 보존했다.
5. skill_a는 가까운 팔을 접어 가슴 앞에서 기를 모은다. skill_b는 같은 팔의
   건틀릿 앞면에서 위/중앙/아래로 갈라지는 은백·청록 충격을 방출한다.
   y=24..44의 효과를 직접 다시 찍어 길고 날카로운 위 조각, 짧고 넓은 중앙 조각,
   꺾여 떨어지는 아래 조각과 서로 다른 끝/음영을 만들었다.
6. skill_c 초기에는 잔전류가 반대 가드 손에 붙어 있었다. 최종 y=32..46에서
   가까운 팔의 접힌 팔꿈치·전완·손목과 가슴 앞 건틀릿을 새로 저작했다.
   작은 전류는 그 손 전면에 붙고, 낮은 반대 손은 빛나지 않게 했다.
7. 독은 가까운 건틀릿으로 턱을 받치고 반대 손으로 배를 누른 자세이다.
   poison_b는 고개/턱과 어깨가 더 내려오고 무릎을 굽힌다. 독 기포 위치와
   내부 투명을 따로 찍었다. poison_a y=12..20의 기포 외곽을 직접 다듬었다.
8. stun은 두 팔과 철권이 무겁게 늘어진 자세, 작은 닫힌 눈과 처진 머리이다.
   두 별의 위치는 두 프레임에서 서로 다르다. poison_b y=50..60,
   stun_a y=52..60, stun_b y=52..60, skill_b y=51..60의 다리/신발을
   각 자세에서 새로 선택해 바닥 초과를 없앴다. 전체 몸을 이동하지 않았다.
9. 수면은 바닥에 앉아 두 무릎에 이완된 건틀릿을 놓은 모습이다. 두 프레임 모두
   눈썹 대신 얼굴색을 쓰고 각각 두 짧은 수평 눈꺼풀을 그렸다. sleep_b는
   새 머리 꼭대기 군집, 1px 낮은 턱, 좁아진 목/압축된 어깨와 가슴 윤곽으로
   숨을 내쉬며 같은 무릎/손/발 접지를 유지한다. 색만 바꾼 프레임이 아니다.

## 실제 그림 확인

18장의 native PNG, 전체 1배 확인판과 최근접 4배 확인판을 밝은/어두운/체커
배경에서 열었다. 8GIF를 원래 순서로 재디코드한 확인판도 열어 모든 저장 프레임을
확인했다. 회수 손의 오류를 발견한 뒤 skill GIF를 다시 읽고 다시 열었다.
PNG 팔레트/경계/접지/연결 좌표 진단은 결손 위치 확인용이며 자동 채움에 쓰지 않았다.
모든 본체는 이어진 덩어리이고, 별/독 기포/깨진 전류의 분리와 두 다리 사이의
빈 공간은 의도한 표현이다. 모든 최종 자세의 실제 하단은 y=60이다.

## 남은 표현 한계 / 검토 대기

- 은백 기술과 작은 독 기포는 밝은 배경 1배에서 어두운 배경보다 대비가 약하다.
  짧은 M색 끝/청록 경계로 구분했지만 실제 게임 배경에서 다시 판단할 부분이다.
- 64px의 주먹 찌르기는 준비/이동/접촉/회수 네 핵심 자세로 압축했다.
  엔진의 실제 이동 거리·적중 순간·피해/소리 동기화는 이 후보에서 확인하지 않았다.
- 쓰러짐은 옆으로 내려앉은 한 자세이고, 그 이후 추가 구르기/경련은 없다.
- GIF 저장 프레임과 노출 시간을 확인했다. 이 작업에서 실제 게임/브라우저의
  실시간 전투 재생이나 별도 독립 검수는 수행하지 않았다.

독립 검수/사용자 선택은 하네스에 남긴다. 사용자 승인이나 검수 통과를 선언하지 않는다.
원본, 선택한 좌표, 실제 계산한 파일 해시는 보존하며 모델/검수 기록을 만들어 넣지 않는다.

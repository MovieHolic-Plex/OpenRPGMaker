# 백발도객 · fifty-v1 원본 저작

## 범위와 원본

- 이 후보의 `source/` 안에만 작성했다. 게임 저장소, brief, ledger, 다른 후보와 사용자 선택을 수정하지 않았다.
- `palette.json`: 투명 `.`를 제외한 18색. 모든 `poses/` 9장과 `actions/` 9장은 64행 × 64열의 완전한 ASCII 원본이다.
- `author.py`의 각 `y x pixels` 문자열은 직접 고른 픽셀이다. 빈 캔버스에 그 문자열을 기록하고 오른쪽 여백을 보존한다. 자동 도형, 원본 이미지 추출, 재표본화, 전체 프레임 변형, 합성 명암, 자동 구멍 메우기를 사용하지 않았다.
- 첫 대기·준비·전진 원안과 수정 좌표는 `author.py`에 그대로 남아 있다. 최종 그림의 정본은 18개 `.pxgrid`와 팔레트다.
- `render.py`는 원본 읽기, PNG/GIF 저장, 라벨·체커·최근접 확대 진단, 저장한 GIF의 재읽기만 담당한다. 재실행은 `python source/author.py`, 이어서 `python source/render.py`다.

## 참고 관찰

첨부 `references/human-size.png`를 실제로 열었다. 작은 우향 눈, 성인 SD의 머리/몸 비율, 어깨에서 소매와 손을 거쳐 칼자루까지 이어지는 구조만 관찰했다. 픽셀 추출·트레이싱·배포 사본을 만들지 않았다.

## 본체와 재질

은백 묶음머리와 짧은 회백 수염, 피부 얼굴, 피부 목, 먹색 쾌자, 넓은 회백 소매, 갈색 띠, 은도를 원본 크기로 그렸다. 대기 본체는 y=8..60, 53px 높이다. 머리의 주요 덩어리는 약 20px 폭이고 피부 얼굴의 주요 면은 약 13px다. 작은 눈과 짧은 눈썹은 우향 얼굴 안에 두고 코 앞 공간을 남겼다.

왼쪽 위 빛을 적용했다. 먹색 옷은 C/D 넓은 면과 B 그림자, 소매·머리는 G/F/E 면, 은도는 H/G 밝은 날과 E 가장자리, 피부는 K/J/I, 띠는 N/M/L로 구별했다. 옷과 소매를 모두 같은 금속 광택으로 처리하지 않았다.

## 직접 수정한 군집

1. 첫 `idle_a` PNG에서 앞 소매가 짧고 손과 자루 사이가 비었다. y=29..38의 오른쪽 소매·손목·손바닥과 y=35..41의 파지를 직접 다시 그렸다. `idle_b/c`에도 각각의 실제 위치에서 따로 작성했다. 팔 아래의 의도한 빈 공간은 남겼다.
2. 준비 원안에서 칼이 얼굴을 가렸다. `windup`의 y=4..15와 `move`의 y=8..19에 칼·자루·손을 머리 위로 다시 그렸다. 준비 팔은 바깥 팔꿈치에서 같은 오른쪽 어깨까지 넓은 소매 면으로 연결된다.
3. 공격 원안의 자루가 두 방향으로 갈라졌다. `attack` y=34..50에 손 뒤 자루 → 피부 파지 → 금속 코등이 → 아래로 향한 날을 한 축으로 다시 찍었다. 공격은 뒤발 밀기, 넓은 앞 내딛기, 앞 어깨 하강과 같은 공격 손의 내려베기를 보인다.
4. `recover` y=38..56와 `skill_c` y=41..58의 손·자루·날 연결을 각 위치에서 따로 수정했다. 이전 칼 가장자리의 남은 픽셀도 명시한 투명 행으로 제거했다.
5. `skill_a` y=38..44와 `skill_b` y=40..46에서 파지 아래에 단일 갈색 자루 끝만 남겼다. 소매 끝, 피부 손목, 손가락과 코등이의 재질 경계를 구별했다.
6. 기술 방출 원안의 위쪽 칼빛이 날의 단순 연장처럼 보였다. `skill_b` y=6..23을 직접 다시 찍어 왼쪽으로 굽었다가 위·오른쪽으로 빠지는 갈래를 만들었다. 아래쪽 갈래는 오른쪽으로 펼친 뒤 아래·왼쪽으로 회수하는 별도 곡선이다. 두 갈래는 실제 도끝 (53,25) 부근에 연결된다.
7. 수면의 `sleep_a` y=37, x=24..42와 `sleep_b` y=38, x=25..43에서 검은 눈 점을 제거하고 피부 안의 짧은 갈색 감긴 눈꺼풀로 수정했다. 코 윤곽과 눈꺼풀을 분리했다. 같은 앉은 몸·발·내려놓은 칼을 유지하며 머리/턱, 어깨와 가슴/소매 윤곽은 각각 직접 작성한 두 호흡 자세다.
8. 대기 3장의 은도 중앙 면을 각각 6개의 명시 행으로 넓혀 얇은 바늘처럼 보이던 부분을 보완했다.

## 상태와 접지

- 피격: 뒤로 기운 어깨, 작은 찡그린 눈/입, 낮아진 오른손과 은도.
- 쓰러짐: y=41..60에 내려온 몸, 연결된 피부 목과 머리, 감긴 눈, 접힌 다리와 신발, 바닥의 은도.
- 독: 턱을 받치는 접힌 팔과 아픈 어깨, 낮춘 도, 위치·수·크기가 다른 직접 저작 녹색 방울.
- 기절: 더 처진 머리와 팔, 굽힌 무릎, 늘어진 도, 서로 다른 위치의 작은 별.
- 수면: 무릎을 접고 앉은 안정 자세, 감긴 눈, 손을 무릎 가까이 이완하고 도를 바닥으로 낮춤.
- 18장 모두 바깥 1px 테두리를 비웠으며 y>60에 잉크가 없다. `idle_a`의 실제 두 신발 밑면은 y=60이다. 상태 자세와 쓰러짐에서도 실제 발/몸이 y=60에 닿는다.

## 실제 그림 확인과 파일 재읽기

최종 1배 시트 및 밝은/어두운/체커의 3배 시트를 열었다. 8개 저장 GIF의 모든 프레임을 다시 PNG 접촉 시트로 읽고 각각 열어 팔·파지, 목/옷깃, 다리와 발, 눈 및 자세 간 변화 위치를 확인했다. 수면 두 장은 별도의 1배 GIF 재읽기 시트도 열었다.

`previews/readback.json`은 실제 원본/PNG/GIF의 SHA-256과 GIF에서 재읽은 프레임 수·노출 시간·보이는 픽셀 차이를 기록한다. 저장된 GIF 8개의 전 프레임에서 원본과 다른 보이는 픽셀은 0이었다. 이것은 파일 재읽기 관찰이며 독립 시각 검수의 판정이 아니다.

## 남은 시각적 한계와 검수 상태

- 64px 안에서 본체·은도·두 칼빛을 함께 보이므로 방출의 오른쪽 갈래 폭은 제한된다. 최고점은 x=62까지 사용하며 테두리 밖으로 나가지 않는다.
- 우향 먼 눈과 짧은 수염은 아주 작은 군집이다. 1배에서 얼굴은 읽히지만 두 눈의 원근·수염 길이는 독립 검수에서 다시 판단할 부분이다.
- 수면 호흡은 머리/턱과 어깨 윤곽의 1px 변화로 작게 표현했다. 큰 들썩임은 넣지 않았다.
- 별도 검수자를 호출하지 않았다. 독립 검수·통과/선택·모델 출처 기록은 하네스가 수행한다. 사용자 승인 또는 실제 시각 keep를 선언하지 않는다.

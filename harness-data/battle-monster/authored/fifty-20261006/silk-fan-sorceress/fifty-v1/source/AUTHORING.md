# 비단선술사 — fifty-v1 원본 저작

## 납품 원본

- 기본 9자세: `poses/idle_a`, `idle_b`, `idle_c`, `windup`, `move`, `attack`, `recover`, `hit`, `dead`의 `.pxgrid`.
- 추가 9자세: `actions/skill_a/b/c`, `poison_a/b`, `stun_a/b`, `sleep_a/b`의 `.pxgrid`.
- 모든 파일은 실제 64×64 ASCII 팔레트 행이다. `.`은 투명이며 팔레트에 들어가지 않는다. `palette.json`에는 불투명 색 18개가 있다.
- `authored-rows.txt`에는 18자세 각각의 전체 64행 원고를 보존했다. 프레임 복제·변환·보간으로 다른 자세를 만들지 않았다.
- `previews/`에는 각 자세의 투명 native PNG, 8개 투명 native GIF, 밝은/어두운/체커 1배 시트와 최근접 진단 확대판이 있다. `previews/index.html`에서 GIF를 함께 볼 수 있다.

## 참고 관찰과 원안

첨부 `human-size.png`를 직접 열어 작은 우향 눈, 성인 SD 얼굴 크기, 목과 옷깃, 실제 손과 도구 연결을 관찰했다. 참고 픽셀은 추출하거나 원본에 넣지 않았다. 이 후보의 source에는 기존 격자가 없었으므로 비단선술사를 새로 저작했다.

대기 본체는 y=8..60의 53px 높이다. 검은 머리와 약 19px 머리 덩어리, 12~14px 피부 얼굴, 금 비녀, 자주 저고리와 남청 치마, 미백 부채/주홍 테두리를 직접 행으로 찍었다. 머리카락이 뒤쪽 볼을 가리고 작은 먼 눈과 큰 쪽 눈을 함께 보여 우향 3/4를 읽히게 했다. 목의 피부와 흰 옷깃을 실제 픽셀 부피로 연결했다.

왼쪽 위 광원: 머리 위·뒤쪽 왼쪽에 `j/i`, 얼굴 왼쪽 위에 `l`, 턱과 오른쪽에 `k/s`, 어깨/소매 왼쪽에 `n`, 안쪽 접힌 소매에 `p`, 치마 왼쪽 주름에 `d`, 겹침에 `b`를 사용했다. 비단은 넓은 면과 짧은 주름 경계, 금속은 `y/g`의 얇은 반사, 부채는 `w`의 넓은 잎 면과 금빛 살로 구별했다.

## 실제 자세 변화

- 대기 3장: 펼친 부채, 들어 올린 손목과 가슴, 조금 오므린 부채 및 머리카락 끝을 각각 저작했다. 피부 손목·손바닥·자루는 각 위치에서 이어진다.
- 공격: 동일한 오른쪽 부채손을 추적한다. 준비의 손은 가슴 쪽 (35..37,35..36), 전진에서는 (38..40,34..36), 접촉에서는 (41..45,33..35), 회수에서는 (40..42,36..37)에 있다. 어깨→소매 위팔→접힌 팔꿈치→아래팔→손바닥 경로를 직접 변경했다. 뒤 지지발, 벌어진 치마, 앞쪽 다리와 발목을 별도로 그렸고 전진과 접촉의 앞발/뒷발이 y=60에 닿는다.
- 피격: 찡그린 눈, 비대칭 어깨, 가슴 쪽으로 모인 보조 팔, 뒤로 벌어진 머리카락과 내려간 부채.
- 쓰러짐: y=36..60에서 옆으로 내려앉은 머리·목·몸, 감긴 눈, 포개진 소매와 치마, 바닥에 내려온 손·부채·발을 별도 배열로 저작했다. 목 피부가 옷깃에 이어지고 하중을 받는 몸/치마 윤곽이 y=60에 닿는다.
- 비단풍: 부채 안에 금빛 핵을 모으는 준비, 부챗살 끝에서 위/아래 두 갈래로 휘는 주홍 바람, 부채를 접고 짧은 실빛을 남기는 회수. 원형 오라는 쓰지 않았다.
- 독: 턱을 짚는 접힌 팔과 배를 짚는 손, 낮아진 어깨, 오므려 내린 부채. 두 장의 독방울은 크기와 위치가 다르고 자세도 다르다.
- 기절: 고개/턱을 앞으로 처뜨리고 보조 팔과 부채를 낮췄다. 두 장에서 손과 턱의 작은 군집, 별의 위치, 접힌 부채의 기울기가 다르다.
- 수면: 앉은 무릎, 유지되는 긴 머리/비녀, 쉬는 손과 낮춘 접힌 부채. `sleep_a` y=33과 `sleep_b` y=34에는 먼 쪽의 짧은 `ss` 눈꺼풀과 가까운 쪽의 `ooo` 눈꺼풀을 직접 찍었다. 평상시 눈 군집을 남기지 않았다. 두 번째 장은 턱을 한 줄 내리고 어깨/가슴/소매의 바깥 윤곽과 손 위치를 별도로 압축해 호흡을 표현했다. 같은 무릎과 접지 발을 유지했다.

## 실제 그림을 보고 고친 좌표

`cluster-edits.py/json`과 `final-adjustments.py/json`에 개별 자세의 직접 선택 좌표를 남겼다. 좌표를 다른 자세로 자동 전파하지 않았다.

1. 첫 대기의 치마가 큰 사선 한 면으로 보인 것을 y=47..53에서 폭이 다른 `d/c/b` 주름 면으로 나눴다.
2. 시전 자세의 바닥이 y=57로 보였으므로 다리와 발목의 세 행을 직접 추가해 y=60까지 연결했다. 프레임 전체를 옮기지 않았다.
3. 대기·공격·기술·상태 각각의 실제 손 위치에서 손가락, 피부 손목과 금빛 축의 경계를 고쳤다. 예: idle_a (40..44,36..38), move (39..45,35..37), attack (43..48,34..36). 아래 자루는 하나의 축으로 읽히게 남겼다.
4. 첫 손 교정 때 hit (40,37)에 잘못 놓인 군집을 실제 PNG에서 발견했다. 해당 y=37..39 행을 직접 복구하고, 실제 소매 끝의 손 (35..38,40..41)과 부채 목 (37..40,42)을 확인했다. 떠 있는 손을 최종 원본에 남기지 않았다.
5. 독 (27..34,29..36)/(26..32,38..44), 기절 (23..29,40..48)에서 접힌 팔/처진 손의 경계를 보완했다. 기절의 턱/목은 각 프레임 y=28..34에서 다시 저작했다.
6. 얼굴이 옆모습에 가까웠으므로 먼 눈을 각 프레임의 실제 얼굴 좌표에 직접 추가했다. 대기에서는 (28,19), 준비 (27,19), 전진 (30,21), 공격 (33,21), 회수 (29,19)이다. 수면과 쓰러짐은 감긴 눈꺼풀 군집을 따로 선택했다.
7. skill_a (43..46,26..30)의 금빛 핵을 넓혔고 skill_b (43..46,29..30)에 핵의 밝은 중심을 남겼다.

## 확인과 저작 보조 코드

`render.py`는 전체 리터럴 행을 읽어 정확한 색으로 PNG/GIF를 굽는다. 확대는 진단판에만 최근접으로 적용한다. 도형·명암·프레임을 합성하지 않는다. `inspect-previews.py`는 저장된 GIF를 다시 읽어 native/3배 프레임판과 실제 파일 해시·범위·시간을 `previews/readback.json`에 기록한다. 편집 기록 스크립트는 이미 적용되어 있으므로 재생성에는 다음 두 명령만 사용한다.

```bash
python source/render.py
python source/inspect-previews.py
```

18자세를 1배와 확대, 밝은/어두운/체커 배경으로 열어 윤곽·얼굴·목·팔·자루·발을 확인했다. 8개 GIF를 열고 저장 GIF에서 다시 읽은 모든 프레임도 나란히 확인했다. 최하단 잉크는 모두 y=60이며 native 경계의 1px 이상 투명 여백을 유지한다. 저장 PNG/GIF의 색과 투명은 팔레트의 native 픽셀에서 나온다. 테스트/게이트 및 별도 검수자 호출은 실행하지 않았다.

## 남은 표현 한계와 검수 상태

- 1배에서 손가락은 2~3px 규모라 손바닥/엄지와 금빛 자루의 작은 경계가 복잡하게 보일 수 있다.
- 64px 안의 두 바람 갈래는 위/아래로 길게 휘는 구도다. 넓은 화면을 가로질러 날아가는 별도 투사체는 이 원본에 포함하지 않았다.
- 쓰러짐 GIF는 피격→바닥 자세 두 장이어서 중간 낙하 자세가 없다. 공격과 기술도 저작된 핵심 자세만으로 재생한다.
- 수면 호흡은 턱과 소매 외곽의 1px 변화라 확대보다 native에서 미묘하다.

이 문서는 후보의 저작·자체 그림 확인 기록이다. 독립 판정은 하네스가 담당하며 사용자 승인이나 통과 판정을 선언하지 않는다.

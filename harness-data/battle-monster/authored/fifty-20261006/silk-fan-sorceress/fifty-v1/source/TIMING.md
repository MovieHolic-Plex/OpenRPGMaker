# 비단선술사 — native GIF 시간표

모든 GIF는 64×64, 원본 18색과 투명 인덱스 0, 반복 재생이다. 자세 생성·보간·전체 프레임 이동은 없다. 노출 시간만 지정한다. 좌표는 0부터 시작하며 실제 접지는 y=60이다. 아래 시간은 저장 GIF에서 다시 읽은 값과 같다.

| 동작 | 자세 순서 | 각 노출 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 300, 200, 100, 170, 220, 300 |
| hit | idle_a → hit → recover → idle_a | 350, 260, 200, 400 |
| dead | hit → dead | 180, 1100 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 300, 330, 250, 320, 300 |
| poison | poison_a → poison_b | 400, 400 |
| stun | stun_a → stun_b | 380, 380 |
| sleep | sleep_a → sleep_b | 650, 750 |

## 공격 손과 도구 추적

준비에서 동일한 오른쪽 손이 가슴으로 부채를 당긴다. 준비 손 (35..37,35..36) → 전진 손 (38..40,34..36) → 접촉 손 (41..45,33..35) → 회수 손 (40..42,36..37). 팔꿈치와 소매의 접힘, 앞쪽 어깨와 두 발을 각각 저작했다. 전진 100ms 뒤 접촉 170ms를 유지해 펼쳐 휘두른 부채가 읽히게 했다. 회수에는 부채가 손 아래로 내려간다.

## 비단풍의 발원점

| 자세 | 실제 앵커 | 표현 |
|---|---|---|
| skill_a | 손 (39..41,35), 부채 목 (42..45,33..36), 핵 (43..46,26..30) | 손목에서 부채 축으로 연결된 채 금빛 핵을 모은다. |
| skill_b | 손 (38..40,33), 부채 목 (41..45,32..35), 위 갈래 뿌리 (48..50,27..29), 아래 갈래 뿌리 (49..52,31..33) | 실제 잎/살 끝에서 두 주홍 바람이 갈라진다. 위쪽은 y=9..29로 올라갔다 휘고, 아래쪽은 y=31..50으로 내려갔다 감긴다. 서로 다른 끝과 폭을 직접 저작했다. |
| skill_c | 손 (40..41,36..37), 접힌 부채 목 (40..42,38..39) | 부채를 아래로 접는다. (48..51,30..37), (48,42..43)의 작은 실빛 조각이 깨져 남는다. |

## 상태 루프

독은 턱/배를 짚는 손과 독방울 크기가 바뀐다. 기절은 처진 턱과 보조 손, 내려간 부채, 머리 옆 별의 서로 다른 위치가 바뀐다. 수면은 감긴 눈을 유지하고 두 번째 자세의 턱·눈꺼풀이 한 줄 내려가며 어깨/소매 윤곽이 압축된다. 무릎과 접지 발을 유지하고 650/750ms로 작은 숨을 반복한다.

GIF 확인판 `gif-readback-1/2-1x.png`, `gif-readback-1/2-3x.png`는 저장된 GIF의 프레임을 다시 읽어 만든 진단판이다. 게임 런타임에 설치하거나 스킬 시스템을 연결한 결과는 아니다.

# 적갑문지기 — 직접 픽셀 저작 기록

## 원본과 범위

이 후보의 빈 source에서 18자세를 새로 저작했다. 결과와 보조 코드·문서는 모두 이 source 안에 있다.
참고 `human-size.png`를 실제로 열어 작은 우향 눈, 얼굴 앞의 볼·코 여유, 손과 무기 연결, 인간형의 크기를 관찰했다. 참고 픽셀을 추출하거나 소재로 넣지 않았다.

- `palette.json`: 투명을 제외한 18색, ASCII 한 글자 → #RRGGBB.
- `poses/*.pxgrid`: 기본 9자세. 각 128행, 모든 행 정확히 128글자.
- `actions/*.pxgrid`: 기술 3, 독 2, 기절 2, 수면 2. 동일한 native cell과 팔레트.
- `author.py`: 각 자세에 따로 선언한 좌표와 리터럴 ASCII 행, 지목한 좌표 교정. 빈 캔버스에 그 행을 기록한다. 본체 도형·수식 명암·프레임 변형·참고 추출이 없다.
- `render.py`: 격자를 읽어 PNG, native 3×3 시트, 1배/최근접3배 진단 시트, 8GIF를 기록한다. 확대는 확인판에만 쓰인다.
- `inspect.py`, `READBACK.json`: 저장된 격자·PNG·GIF의 실제 바이트를 다시 읽은 자료. 해시는 이 읽기에서 계산한 값이다.
- `gallery.html`: 8종 GIF와 전체 자세를 로컬에서 보는 그림판.

## 형태와 재질

둥근 청록 얼굴, 작은 금빛 눈, 두 짧은 청동 뿔, 넓은 주홍/청동 갑옷, 회은 관절, 짧은 붉은 망토와 큰 두 부츠를 유지했다. 얼굴 앞쪽에 코·볼 면을 남겼다.

왼쪽 위 광원에 맞춰 청록 피부의 윗왼쪽 면은 U, 안쪽은 T, 아래턱은 t로 직접 나눴다.
갑옷은 H/V/R/r의 넓은 면과 g/b/c의 청동 테두리, 은색 관절은 h/s/d로 나눴다.
천은 금속처럼 반사 띠를 넣지 않고 V/R/r의 접힌 면으로 그렸다.
가슴 청동 장식은 팔이 가리는 자세에서 드러나는 부분만 남겼고, 쓰러짐에서는 눕는 방향의 별도 면으로 찍었다.

## 직접 열어 본 결과

밝은/어두운/체커 배경의 1배와 최근접3배 전체 시트를 열었다.
저장된 attack GIF를 열었으며, 8GIF를 다시 읽은 1배 필름스트립도 실제로 열어 자세·파지·발·프레임 간 변화와 노출 시간을 비교했다.
수면 두 얼굴의 짧은 감긴 눈, 앉은 무릎과 발, 내려오는 턱·어깨를 1배에서도 확인했다.

READBACK의 현재 자료: 18개의 서로 다른 원본, 18색, 128×128, 알파 0/255, 모든 자세의 실제 몸/발 최저 y=124.
가장 오른쪽 픽셀은 skill_b의 광날 x126으로, x127은 투명이다. 다른 가장자리도 투명이다.
8GIF에서 다시 읽은 모든 프레임의 표시 픽셀은 해당 native PNG와 일치했다.

## 남은 표현 한계

- 기본 9자세라 세운 창을 눕히는 중간 각도는 별도 프레임이 없고 준비 자세로 빠르게 전환된다.
- 적문쇄의 위쪽 날은 긴 직선 광날에 가까운 표현이다. 회수의 세 잔광은 작은 파편이라 밝은 배경에서 금백 중심 대비가 어두운 배경보다 약하다.
- 수면의 호흡은 native에서 작은 턱·어깨·소매 변화다. 과장된 전신 들썩임은 저작하지 않았다.

독립 검수와 사용자 선택은 하네스에서 진행할 단계다. 이 문서는 사용자 승인이나 검수 통과를 선언하지 않는다.

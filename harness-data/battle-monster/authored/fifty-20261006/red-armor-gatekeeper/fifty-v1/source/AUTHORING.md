# 적갑문지기 — 현재 독립 지적에 대한 픽셀 교정

## 작업 범위와 원본

기존 후보의 18자세를 읽고, 제공된 일곱 지적에 해당하는 7자세만 수정했다.
모든 쓰기는 이 후보의 `source/` 안에서 했다. 저장소·게임 저장소·brief·ledger·검수 결과·사용자 선택은 수정하지 않았다.

`reference.png`와 `references/human-size.png`를 실제로 열어 보았다.
청록 얼굴·작은 금빛 눈·짧은 뿔, 주홍 갑옷과 회은 관절의 구분, 성인 검객의 작은 우향 얼굴과 손/무기 관계를 관찰했다.
참고 이미지 픽셀을 추출하거나 원본에 넣지 않았다.

- `poses/`: 기본 9자세의 완전한 ASCII 원본. 각 128행 × 128글자.
- `actions/`: skill_a/b/c, poison_a/b, stun_a/b, sleep_a/b의 완전한 ASCII 원본.
- `palette.json`: 기존 18색을 그대로 보존. `.`은 투명이며 팔레트에 없다.
- `author.py`: 이전 직접 저작 코드와 현재 교정 적용 진입점.
- `repair.py`: 이번 교정의 모든 짧은 리터럴 행과 개별 좌표. 문자열에 명시한 `.`만 지운다.
- `repair-baseline/`: 수정 전 7자세 원본과 이전 `author.py`의 사본.
- `render.py`: 완전한 격자를 읽어 native PNG·시트·8GIF를 기록한다.
- `inspect.py`, `READBACK.json`: 실제 저장된 원본/PNG/GIF의 크기·알파·경계·해시와 GIF 재읽기 자료.
- `repair_preview.py`: 저장된 PNG와 GIF 프레임을 읽어 진단 확대판을 만든다.

이번 변경은 자세마다 직접 고른 ASCII 군집이다. 본체 도형 생성, 명암 합성, 다른 자세에서 좌표 전파,
프레임 이동·회전·보간, 자동 구멍 메우기는 사용하지 않았다. 확대는 진단 그림에만 적용했다.
`python source/author.py`는 기존 저작 후 현재 `repair.py`의 별도 교정을 적용한다.
현재 격자에 교정만 다시 적용하려면 `python source/repair.py`를 사용한다.

## 실제 그림 확인

현재 18자세의 밝은/어두운/체커 배경 native1배와 최근접3배 시트를 열었다.
교정한 move/attack/dead/skill_a는 밝은 배경4배도 열어 팔꿈치, 파지, 발목, 효과 경계를 확인했다.
처음 교정한 move에서 치마 가장자리의 오래된 작은 돌기가 보였으므로 x34–43/y77–82를 다시 직접 수정했다.

저장된 attack.gif를 열었다. 8GIF 모두 다시 디코딩한 native1배 필름스트립을 열어
대기 연결, 준비→전진→접촉→회수, 기술 발원점, 독/기절, 수면의 감긴 눈과 턱/어깨 변화를 비교했다.
수정한 동작의 실제 GIF 프레임은 별도의3배 재읽기판에서도 확인했다.
라이브 전투 재생·화면 크기·피해 접촉 타이밍은 이번 source 작업에서 확인하지 않았다.

실제 재읽기 자료:

- 원본 18개는 모두 128×128이며 서로 다르다. 기존 팔레트 18색, PNG 알파 0/255.
- 모든 자세의 몸/발 최저점은 y124. idle_a의 실제 장화가 y124에 닿는다.
- 모든 가장자리 1px는 투명하다. 가장 오른쪽 효과는 기존 skill_b의 x126이며 x127은 투명이다.
- move 창끝 x105 → attack 창끝 x123: 접촉 때18px 전진한다.
- 앞 장화 밑창의 오른쪽 끝은 move x92 → attack x110: 18px 전진한다.
- 저장된 8GIF의 각 표시 프레임은 대응 native PNG와 일치한다. 해시는 `READBACK.json`에서 실제 바이트로 계산했다.

이 자료는 파일 계약과 작가의 시각 확인 기록이며 독립 검수 판정이 아니다.
검수자 호출·판정 파일 편집·사용자 승인 선언은 하지 않았다. 새 독립 검수는 하네스가 맡는다.

## 남은 시각적 한계

- 기본 공격은 4단계라 세워진 창→수평 준비, 긴 내딛음→회수 사이의 중간 관절 각도는 없다. 재생 중 전환 속도는 별도 전투 검토 대상이다.
- 쓰러진 두 다리의 일부와 장화 하부는 흉갑과 수평 창 뒤에 겹친다. 무릎·은색 발목·발끝 경계를 추가했지만 각 다리 전체가 노출된 자세는 아니다.
- 준비 기의 청동 경계는 밝은 바탕에서 보이지만 어두운 바탕보다 대비가 약하다. 두 기술 광날의 길고 곧은 면과 회수의 작은 파편은 기존 표현을 유지했다.
- 수면 호흡은 기존의 작은 턱·어깨·소매 군집 변화다. 실제 전투 크기에서의 가독성은 이번 정적 확인만으로 판정하지 않는다.

# 적갑문지기 — 8동작 시간표

원본은 128×128. 모든 동작은 직접 저작된 자세의 노출 시간만 바꾼다.
프레임 사이의 이동·회전·보간은 없다. PNG 3×3 시트의 각 칸도 native128이다.

| GIF | 순서 | 각 노출 시간(ms) |
| --- | --- | --- |
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 320 / 240 / 100 / 150 / 240 / 320 |
| hit | idle_a → hit → recover | 300 / 260 / 250 |
| dead | hit → dead | 230 / 1000 |
| skill | skill_a → skill_b → skill_c → recover | 360 / 220 / 300 / 240 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 450 / 450 |
| sleep | sleep_a → sleep_b | 600 / 650 |

## 창격

- 준비: 두 어깨에서 내려온 위팔·팔꿈치·아래팔이 서로 다른 두 파지로 이어진다. 창을 몸 아래쪽으로 당기고 두 발에 하중을 싣는다.
- 전진: 뒤 지지다리의 접힌 무릎·발목과 망토를 유지하며 두 팔꿈치를 뒤로 접었다. 현재 두 파지는 대략 (47,83), (80,83), 창 뒤끝 x5/앞끝 x105다. 무기 길이를 유지하며 두 손과 창을 함께 당겼다.
- 접촉: 엉덩이에서 앞 허벅지를 기울이고 큰 앞 무릎·정강이·장화를 별도 저작했다. 앞 밑창 x84–110/y124, 창끝 x123. move 대비 창끝과 앞 밑창 끝이 각각18px 전진한다. 두 공격 손의 파지 (약66,80 및102,80), 연결된 팔과 뒤 무릎/발목은 유지한다.
- 회수: 두 팔꿈치를 다시 접고 창을 당긴다. 기본 대기 그림을 이동한 자세가 아니다.

## 적문쇄 — 무기 발원점

좌표는 원본의 왼쪽 위가 (0,0)이다.

- `skill_a`: 두 손의 창자루 파지 중심은 대략 (51,82), (79,82). 청동 창끝에서 금백 기의 뿌리가 만나는 곳은 (102,83). 위로 모이는 기와 낮은 곁가지가 그 점에 연결된다. 현재 x100–114/y62–88에 기존 금백 중심 밖 청동1px 경계를 직접 추가했다.
- `skill_b`: 양손은 대략 (59,83), (91,83). 실제 창날을 남긴 채 (100,83) 주변에서 두 주홍 광날이 갈라진다. 위쪽은 꺾여 올라가는 넓은 날, 아래쪽은 앞으로 뻗는 사선 날이다. 가장 밝은 중심을 금백색으로 찍었다.
- `skill_c`: 창을 두 손으로 몸 쪽에 당긴다. 현재 파지는 대략 (48,89), (59,89). 위·가운데·아래 잔광은 각각 x106/y49, x112/y76, x103/y100에서 시작하는 서로 다른 리터럴 군집이다. 잔광 사이의 투명 공간은 의도된 분리다.

## 상태와 휴식

- 독: 첫 자세는 아픈 가슴을 감싸고, 둘째는 턱을 받친다. 두 자세의 고개·어깨·팔꿈치와 독 방울 크기·위치를 따로 저작했다.
- 기절: 무게가 내려간 두 팔, 낮은 창, 처진 머리를 유지한다. 두 번째 자세의 머리는 더 내려오고 금색 별은 다른 위치에 있다.
- 수면: 앉아 접힌 두 무릎과 두 발을 남긴다. 두 자세 모두 눈꺼풀은 짧은 청록 음영 선이고, 대기의 검은 눈과 금색 눈동자를 사용하지 않았다. 둘째 자세는 턱·옷깃·어깨·소매 윤곽을 압축했다.
- 쓰러짐: 몸통과 접힌 다리는 바닥에 내려오고 머리는 청록 목 부피로 이어진다. 감긴 눈, 낮은 창, 바닥에 놓인 팔이 수면의 앉은 자세와 다르다.

GIF는 비교용으로 반복 재생된다. `dead` 반복의 처음으로 돌아가는 부분은 게임의 부활 동작을 저작한 것이 아니다.
`png/gif-readback-all-1x.png`에는 저장된 8GIF를 다시 읽은 실제 프레임과 노출 시간이 있다.

## 이번 교정의 재생 범위

위 노출 시간과 자세 순서는 보존했다. 원본이 바뀐 GIF는 실제 새 격자에서 다시 구웠다.
8GIF를 저장 바이트에서 다시 디코딩하고 각 프레임을 native PNG와 대조했다.
기술의 두 광날·세 잔광, 독 두 자세, 기절 별 위치, 수면 두 자세의 기존 독립 배열은 보존했다.
실제 게임의 이동 경로·피해 발생 시각은 이 source 미리보기로 검증한 범위가 아니다.

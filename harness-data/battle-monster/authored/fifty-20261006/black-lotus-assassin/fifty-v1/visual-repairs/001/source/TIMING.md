# 흑련자객 — 8 GIF 시간표

모든 프레임은 64×64 원본 도트다. 추가 중간 프레임/이동/보간은 없다.
GIF는 원본 18색과 투명 인덱스를 그대로 쓰고 disposal=2로 앞 프레임 잔상을 지운다.
미리보기는 반복하며, 쓰러짐 GIF의 대기 복귀도 미리보기 루프다.

## 공격 팔

하나의 오른쪽 단검 팔을 추적한다. 준비 때 오른쪽 어깨에서 가슴 앞으로
위팔/팔꿈치를 접어 뒤 허리의 파지로 잇는다. 왼쪽 손은 가슴 가드로 구별한다.
move는 뒤 발로 밀며 단검을 뒤에 유지한다. attack에서 앞 무릎/오른쪽 어깨가
전진하고 팔꿈치를 펴 실제 칼끝으로 찌른다. recover는 파지/어깨를 몸으로 회수한다.
기본 대기의 파지는 x=43..46/y=40..42 근처, 공격 파지는 x=51..55/y=42..44,
공격 칼끝은 x=62/y=43..44다. 좌표는 native canvas 기준 0-based다.

## 흑련절 — 손/날 앵커

- **skill_a, 360ms:** 오른쪽 어깨에서 아래로 접힌 팔꿈치와 올라간 손목으로
  단검을 든다. 손바닥 x=45..48/y=36..37, 손목/소매 x=45..49/y=38,
  실제 날 x=44..49/y=31..35. 날의 W 끝 (49,31) 가까이 V/R/A 핵을 모은다.
- **skill_b, 240ms:** 오른팔을 앞으로 펴고 파지 x=43..46/y=38..39에서
  은날 x=47..51/y=38..39로 잇는다. 칼끝 옆 W 픽셀 **(50,37)**을 발원점으로
  위/앞/아래의 세 꽃잎을 펼친다. 위 끝 (56,20), 중간 끝 x=62/y=31..32,
  아래 끝 x=57..58/y=46. 서로 다른 길이·폭·끝과 경계 사이의 작은 틈을 직접 저작했다.
- **skill_c, 280ms:** 손바닥 x=43..46/y=43..44, 회수한 은날 x=44..51/y=45..48.
  어깨와 무기를 낮추고 두 분리된 어둔 파편을 x=49..53/y=27..31과
  x=54..57/y=36..39에 남긴다. 이 두 파편은 몸에서 떨어진 팔/손이 아니다.

## 상태 변화

독: 보조 손을 턱 쪽에 붙이고 어깨/무릎을 움츠린다. 서로 다른 위치와
크기의 자주 독기 방울을 두 자세에 직접 저작한다. 피부/옷 전체 색을 바꾸지 않는다.

기절: 낮아진 머리·양어깨·팔·단검을 유지하며 별 위치를 바꾼다.
stun_a의 큰 별은 x=18..24/y=4..10, 작은 별은 x=48..53/y=10..14.
stun_b의 큰 별은 x=31..37/y=4..10, 작은 별은 x=13..18/y=15..19.

수면: 두 프레임 모두 앉아 접은 두 다리와 낮춘 단검을 유지한다.
짧은 닫힌 눈꺼풀은 x=31..32 및 x=36..37, y=32다. 가슴의 L/B 경계와
묶은 머리 끝만 별도 픽셀 군집으로 바꿔 느린 호흡을 표현한다. 쓰러짐을 재사용하지 않는다.

## 관찰 근거

`previews/decoded-*.png`는 생성된 GIF 파일을 다시 읽은 프레임으로 만든 관찰판이다.
원본 RGBA와 GIF RGBA/노출시간의 실제 대조 결과는 `previews/pixel-report.json`에 있다.
관찰용 HTML 확대와 PNG 확대는 최근접이며 GIF 원본은 64px다.
이 시간표는 미리보기 연출이고, 실제 게임 스킬/상태 이벤트 적용이나 독립 검수 판정이 아니다.

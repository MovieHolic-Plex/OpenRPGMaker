# 옥날사마귀 — 8GIF 시간표와 날끝 앵커

64×64 native, 우향 3/4, 왼쪽 위 광원, 최저 잉크 y=60. PNG/GIF는 원본 크기이며 확대는 진단 표시만 최근접으로 한다. 이번 교정은 기존 노출 시간을 유지했다.

| GIF | 자세 순서 | 노출(ms) |
|---|---|---|
| idle.gif | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack.gif | idle_a → windup → move → attack → recover → idle_a | 240 / 220 / 100 / 130 / 220 / 240 |
| hit.gif | idle_a → hit → recover → idle_a | 250 / 180 / 200 / 300 |
| dead.gif | idle_a → hit → dead | 240 / 180 / 1100 |
| skill.gif | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 350 / 170 / 300 / 240 |
| poison.gif | poison_a → poison_b | 420 / 420 |
| stun.gif | stun_a → stun_b | 450 / 450 |
| sleep.gif | sleep_a → sleep_b | 650 / 650 |

## 공격과 회수 — 0부터 세는 (x,y)

windup은 두 낫을 벌리고, move는 낮아진 목/어깨와 옮긴 지지발을 보여 준다. attack의 위 앞다리는 어깨 약 (33,32) → 팔꿈치 (44,29) → 내려오는 날끝 (62,35), 아래 앞다리는 어깨 (31,35) → 팔꿈치 (40,41) → 올라가는 날끝 (61,28)로 이어진다. (49..51,32..33)의 짧은 어두운 겹침 경계로 두 비취 날이 교차한다. recover는 원안의 어깨 복귀와 낫 자세다. 동작별 관절 배열을 보존했으며 프레임 전체를 옮기거나 회전해 만들지 않았다.

## 옥엽절 — 모음 → 발사 → 접힘·잔엽 회수

- skill_a, 350ms: 두 낫 안쪽 약 (50,26)/(49,27), (46,37)/(43,38)의 `c/w` 기를 모은다. 좋은 준비 자세를 유지했다.
- skill_b, 170ms: 위 실제 비취 날끝 (54,23) → 첫 cyan (55,23), 아래 실제 비취 날끝 (54,36) → 첫 cyan (55,36). 위 갈래는 (61,19)로 오르고 아래 갈래는 (62,41)로 굽는다. 첫 빛 클러스터는 각 날끝에 붙으며 날을 가리는 원형 오라는 없다.
- skill_c, 300ms: 위 낫은 가슴/목 쪽 (41,26), 아래 낫은 (35..37,35)로 되접는다. 가장 가까운 잔엽은 각각 (39..40,26), (35..36,34)에서 돌아오는 날에 붙는다. 외부의 작은 깨진 잔엽은 위 (53..54,24)/(51..52,25), 아래 (52..53,36)/(50..51,37)이다. 지지발은 이 자세의 원안과 같다.

독은 아픈 턱/팔과 다른 크기의 방울, 기절은 처진 머리/팔과 다른 위치의 별, 수면은 닫힌 눈과 웅크린 지지다리·머리/목의 작은 숨 변화다. 각 두 자세는 별개의 기존 ASCII 배열이며 색조 변환이나 공격 재사용이 아니다.

## 저장·재읽기와 한계

`preview/index.html`에는 native와 확대 표시의 8GIF가 있다. `preview/motions-readback.png`는 저장 GIF를 디코드한 프레임 순서와 시간표, `render-notes.json`은 실제 색·알파·노출 재읽기다. 진단 그림에서 연속 자세의 연결을 살폈다. 실제 엔진의 피해 프레임·날아가는 투사체·실시간 전투 재생은 확인하지 않았다. 이번 작업은 후보 픽셀 교정이며 사용자 선택이나 독립 검수 통과를 선언하지 않는다.

64×64 native, 우향 3/4, 왼쪽 위 광원. 접지 y=60. 이번 교정은 기존 노출 시간과 순서를 유지했다. GIF 원본을 확대·보간하지 않는다.

## 공격·피격 — 0부터 세는 (x,y)

windup은 두 낫을 벌리고, move는 낮아진 목/어깨와 옮긴 지지발을 보여 준다. attack 위 앞다리는 어깨 약 (33,32) → 팔꿈치 (44,29) → 내려오는 날끝 (62,35), 아래 앞다리는 어깨 (31,35) → 팔꿈치 (40,41) → 올라가는 날끝 (61,28)이다. (49..51,32..33)의 어두운 겹침 경계는 원안대로다. recover는 어깨와 낫을 복귀한다.

hit의 두 번째 앞다리를 추가했다. 어깨 (30..33,32) → 짧은 팔 (35..40,31) → 되접힌 낫 x=35..45,y=24..30으로 이어진다. 기존 아래 앞낫 x=40..50,y=35..43과 함께 반동에도 두 앞다리가 보인다. dead는 바닥에 누운 닫힌 눈과 본체를 그대로 유지한다.

## 옥엽절 — 실제 낫에서 모음 → 두 잎 발사 → 접힘·잔엽 회수

- skill_a, 350ms: 낫 안쪽 (50,26)/(49,27), (46,37)/(43,38)의 청록 기를 모은다. 기존 준비 자세를 유지했다.
- skill_b, 170ms: 위 실제 비취 날끝 (54,23) → 첫 청록 (55,23), 아래 실제 날끝 (54,36) → 첫 청록 (55,36). 앵커 두 곳은 유지했다. 위 잎은 x=55..62,y=18..23의 넓은 몸체에서 (62,18)로 솟는다. 아래 잎은 x=55..62,y=35..41의 더 짧고 넓은 몸체에서 (62,41)로 내려간다. 넓은 흰/청록 중심과 비취 면, 어두운 청록 가장자리를 직접 찍었다.
- skill_c, 300ms: 위 낫은 가슴/목 쪽 (41,26), 아래 낫은 (35..37,35)로 되접는다. 가까운 잔엽은 (39..40,26), (35..36,34)에서 돌아오는 날에 붙는다. 외부 깨진 잔엽은 위 (53..54,24)/(51..52,25), 아래 (52..53,36)/(50..51,37)다. 이전 교정의 좋은 회수 자세를 유지했다.

## 상태 쌍

poison_a/b는 아픈 턱/팔·굽은 어깨와 다른 보라 방울, stun_a/b는 처진 머리/팔/낫과 서로 다른 위치의 별, sleep_a/b는 죽음과 다른 낮은 웅크림·닫힌 눈·작은 머리/목 숨 변화다. 기존 상태별 두 ASCII 배열을 보존하고 지지다리 면만 좌표별로 보강했다. 공격 자세 재사용이나 색조 변환이 아니다.

## 보기·재읽기·한계

`preview/index.html`에서 8GIF를 native와 확대 표시로 볼 수 있다. `preview/motions-readback.png`는 저장된 GIF를 디코드한 실제 프레임/시간표다. 원본의 보이는 RGB·알파·각 hold가 일치한 재읽기는 `preview/render-notes.json`에 남겼다. 최종 디코드 연속 시트를 실제로 열어 관절과 배열 변화를 확인했다.

한 개 cast 자세의 두 칼날이며 실제 투사체 비행의 중간 프레임을 추가한 것은 아니다. 실제 게임 전투의 피해 타이밍·실시간 대시 속도·엔진 연결은 확인하지 않았다. 하네스 독립 검수와 사용자 판단을 기다리는 후보이며 통과/승인 선언이 아니다.

# 옥날사마귀 — fifty-v1 저작 기록

## 범위와 원본

이 후보의 source 안에서만 빈 원본부터 저작했다. 기본 9자세와 추가 9자세는 각각 poses/와 actions/의 64행 × 64열 ASCII pxgrid다. palette.json은 15색이며 `.`은 투명이다. 행과 짧은 좌표 문자열의 모든 실루엣·명암·효과 픽셀은 직접 골랐다.

author_pixels.py에는 자세별 독립 행 문자열, 실제 PNG를 본 뒤 선택한 교체 행, 짧은 좌표 교정 문자열을 보존했다. 코드는 명시한 문자열을 격자에 쓰는 역할만 한다. 도형 마스크, 수식 명암, 전체 프레임 이동·회전·보간, 자동 구멍 채우기는 사용하지 않았다. 최종 pxgrid는 모든 투명 행까지 포함하는 완전한 리터럴 원본이다.

참고 human-size.png를 직접 열어 작은 원본에서 머리·어깨·팔다리가 이어져 읽히는 크기를 관찰했다. 참고 그림의 픽셀을 읽어 추출하거나 복제하지 않았다. 다른 종의 원본은 사용하지 않았다.

## 외형과 재질

- 우향 3/4 삼각 머리, 두 검은 눈, 가느다란 더듬이 두 개, 긴 목과 연결된 어깨.
- 대기 머리는 대략 x=30..46, y=11..21이며, 몸체와 발은 y=60까지 차지한다. 빈 캔버스 중심에 작은 몸을 넣지 않았다.
- 접힌 잎날개는 왼쪽 위 밝은 연두 면, 넓은 비취 기본 면, 아래쪽 청록 그림자 면으로 찍었다. 개별 짧은 `v/t` 잎맥과 복부 마디의 `jss/gso` 색 덩어리를 좌표로 추가했다.
- 두 낫은 상완과 팔꿈치에 이어진 밝은 갑각 칼날이다. 두 쌍의 보행 다리 중 먼 다리는 어두운 `oso/ogso`로, 가까운 다리는 더 밝은 비취 면으로 구별했다.

## 직접 교정한 부위

1. 처음 PNG에서 먼 낫이 얇은 막대처럼 읽혀 대기 3자세·이동·공격·회수·피격의 팔 행을 개별 교체했다. idle_a의 낫 면은 y=22..33과 y=37..49를 다시 골랐다. 팔꿈치와 안쪽 빈 공간은 남겼다.
2. 더듬이 밑부분의 끊김을 확인하고 idle_a (46,11) `oggggo`, idle_c (45,12) `oggggo`, move (51,14) `oggggo`를 직접 찍었다. 모든 좌표는 0부터 센다.
3. windup의 앞 지지다리와 엉덩이 사이에 (19,43) `og`를, skill_b의 같은 부위에 (20,40) `ogjgo`를 추가했다. 연결 진단은 위치를 찾는 보조였으며 자동으로 채우지 않았다.
4. 독 자세에는 턱을 감싼 먼 낫과 아래로 처진 가까운 낫을 각각 찍었다. 기절 자세에는 두 팔을 떨어뜨리고 먼 낫의 어두운 갑각 면을 따로 그렸다. 수면에는 두 낫을 낮게 접고 네 지지다리를 짧게 굽혔다.
5. skill_a의 먼 낫 안쪽 (48,26), (47,27), (46,28)에 청록 기를 더했다. skill_b는 위쪽 잎칼날을 y=19..28, 아래쪽 잎칼날을 y=35..41에 서로 다른 폭·끝 모양으로 다시 찍었다. skill_c는 낫을 접는 몸과 분리된 잔엽을 따로 저작했다.
6. 독 두 번째 자세의 작은 방울이 먼 발에 붙어 보였다. 기존 (42,49), (41,50), (42,51)의 방울만 지우고 새 방울을 (49,46), (48,47), (49,48)에 직접 찍었다.
7. 쓰러짐은 지면에 내려온 날개·몸·목·얼굴, 닫힌 두 눈, 접힌 보행 다리와 오른쪽으로 누운 두 더듬이를 별도로 저작했다. 수면 몸을 쓰러짐으로 재사용하지 않았다.

## 동작

공격 준비에서 낫을 벌리고, 전진에서 머리와 어깨를 낮추면서 뒤 지지발의 밀기와 앞 지지발의 간격을 바꿨다. 접촉 자세는 두 낫이 몸 앞에서 가위처럼 모이고, 회수는 팔꿈치를 펴던 몸이 다시 일어선다. 각 자세의 목·어깨·날개·팔·발 행을 직접 작성했다.

독은 내려온 턱과 움츠린 팔, 기절은 늘어진 머리와 팔 및 위치가 다른 별 두 개, 수면은 닫힌 눈과 웅크린 몸을 갖는다. 수면 두 자세는 발과 접힌 팔을 안정적으로 유지하면서 머리·목의 숨 변화만 별도 행으로 찍었다. 상태이상은 공격 재사용이나 단순 색조 변화가 아니다.

## 실제로 연 그림과 저장된 결과

preview/idle-study.png, contact-light.png, contact-dark.png, contact-checker.png를 열어 원본 1배와 최근접 확대를 확인했다. 최종 native 3×6 sheet.png와 저장 GIF에서 다시 읽은 motions-readback.png도 직접 열었다. 팔·목·지지다리의 연결과 의도한 팔다리 사이 투명 공간을 확인하고 위 좌표들을 고쳤다.

render_pixels.py는 격자를 PNG로 굽고 팔레트 인덱스를 그대로 GIF에 넣는다. 저장된 8개 GIF의 각 프레임을 재읽어 원본의 보이는 RGB/알파 및 노출 시간과 일치하는지 확인했다. 결과는 preview/render-notes.json이다. 본체에 대한 연결 진단에서는 기본 9자세의 분리된 조각이 남지 않았다. 기술 잔엽·독 방울·기절 별의 독립 조각은 의도한 효과다.

모든 원본의 바깥 1px은 투명하며 최저 잉크는 y=60이다. idle_a의 가까운 두 발이 정확히 y=60에 닿는다. 18자세 모두 서로 다른 픽셀 배열이다. 테스트·게이트와 별도 검수자 호출은 실행하지 않았다.

## 남은 시각적 한계

- 먼 보행 다리는 얇고 어두워 어두운 배경에서 가까운 다리보다 약하게 읽힌다.
- 접힌 낫과 먼 보행 다리가 일부 자세에서 겹치는 작은 구간은 64px 원본에서 분리가 덜 선명하다. 날개 아래·두 지지다리 사이의 큰 빈 공간은 보존했다.
- 쓰러짐은 별도 중간 낙하 원본 없이 hit → dead로 낮아지므로 빠른 하강으로 보인다.
- 자세표와 GIF를 통한 작가 자체 확인까지 완료했다. 실제 게임 적용과 독립 하네스 검수 결과는 이 저작 기록에서 판정하지 않는다. 사용자 승인 또는 통과를 선언하지 않는다.

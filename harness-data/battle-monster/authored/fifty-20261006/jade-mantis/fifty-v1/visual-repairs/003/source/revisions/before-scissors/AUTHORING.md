# 옥날사마귀 — fifty-v1 원안 교정 기록

## 범위와 보존

기존 후보의 기본 9자세와 추가 9자세를 수정했다. 이번 작업의 쓰기는 이 후보의 `source/` 안에서만 수행했다. 원안 격자 18개, 팔레트, 기존 저작 보조 코드와 두 문서는 `original/`에 보존했다. 쓰러짐 원본은 그대로다. 머리의 삼각형과 두 검은 눈, 긴 목, 접힌 잎날개, 복부 마디, 기존 자세별 지지발 위치와 상태이상 구도는 보존했다.

첨부 `reference.png`와 `references/human-size.png`를 실제로 열어 본체 크기·관절 연결·광원을 관찰했다. 참고 이미지의 픽셀을 추출하거나 원본으로 변환하지 않았다. 다른 종의 원본은 사용하지 않았다.

## 원본과 직접 저작 방법

`poses/`와 `actions/`는 각각 9개의 완전한 64행 × 64열 ASCII 격자다. `palette.json`의 기존 15색과 기호를 그대로 썼다. `.`은 투명이고 팔레트에 없다.

`repair_pixels.py`에는 프레임별로 직접 선택한 `y x 픽셀문자열`을 남겼다. 명시한 행의 오른쪽 투명 저장 여백만 점으로 채우며, 본체·명암·효과는 모두 리터럴 문자열이다. 재실행은 보존한 원안 격자를 읽고 이 좌표들을 적용한다. `author_pixels.py` 끝에서도 같은 현재 교정을 적용한다. 도형 래스터화·자동 음영·전체 프레임 이동/회전/보간·자동 구멍 채우기는 사용하지 않았다.

## 자체 그림 확인 중 추가로 고친 좌표

- 첫 아래 낫 교정에서 idle_a y=40..41의 상완 연결이 끊겨 보였다. x=38의 `jgo`와 `osjjgo`로 연결을 다시 골랐다.
- 새 갈고리 아래에 원안의 긴 날이 남아 여분의 가지처럼 읽혔다. idle_a/b/c·recover·hit·skill_a/c의 옛 y=44..49 부근을 개별적으로 지웠다. 그 행을 지나가는 원래 먼 지지다리 `oso`는 좌표를 읽고 그대로 남겼다. skill_c (34,47)의 옛 가지도 제거했다.
- 행 끝 교정이 목/턱과 겹치는 부분을 다시 보았다. idle_a (40,21) `ggoo`, idle_b (41,21) `goo`, idle_c (40,22) `oo`, windup (42,16..18), move (42,22..25)의 기존 목·턱 픽셀을 명시적으로 보존했다. skill_b의 위 날 상단도 얼굴 오른쪽으로 따로 배치했다.
- skill_a (36,34)/(35,35)/(34,36)의 이전 기 모음 잔여점은 지웠다. 청록 기는 두 낫의 안쪽 오목부에만 남겼다.
- 독·기절·수면은 좋은 원안의 아픈 턱/처진 팔/웅크린 자세와 방울·별·닫힌 눈을 유지했다. 접힌 날에는 소수의 기존 팔레트 날 면만 조정했다. 수면 두 자세의 머리/목 숨 변화도 유지했다.

## PNG·8GIF와 재읽기

`render_pixels.py`로 native PNG 18개, 3×6 native 시트, 밝은/어두운/체커 진단 시트와 실제 팔레트 GIF 8개를 다시 저장했다. 각 진단 시트는 원본 1배 칸과 최근접 확대를 포함한다. 마지막 `contact-light.png`, `contact-dark.png`, `contact-checker.png`, `repair-details.png`, 저장 GIF를 디코드한 `motions-readback.png`를 실제로 열어 팔·목·낫 끝·발과 의도한 투명 공간을 확인했다.

저장 GIF의 모든 프레임을 다시 열어 원본의 보이는 RGB/알파와 duration을 비교한 기록은 `preview/render-notes.json`이다. 현재 격자/PNG 크기·팔레트·테두리·현재 파일의 실제 SHA-256은 `readback_pixels.py`가 `preview/source-readback.json`에 읽기 사실로 남긴다. 이것들은 그림 승인이나 독립 검수 결과가 아니다.

현재 18개 격자는 모두 서로 다르며 64×64, 바깥 1px 투명, 최저 잉크 y=60이다. idle_a 발도 정확히 y=60이다. 팔레트는 원안과 같고 native PNG 알파는 0/255다. 테스트·게이트·별도 검수자 호출은 실행하지 않았다.

## 남은 시각적 한계

- 64px 접촉부에서는 두 날이 겹치는 작은 부분의 앞뒤 관계가 확대보다 덜 선명하다. 독립 하네스가 실제 새 그림을 판정해야 한다.
- 먼 지지다리는 이제 중간 녹색으로 읽히지만, 아래 윤곽과 더듬이는 의도적으로 어둡고 가까운 팔다리보다 약하다.
- 짧은 잎칼날의 밝은 핵은 밝은 배경에서 대비가 낮아진다. 청록 외곽은 유지했다.
- 원안의 hit → dead 전환에는 중간 낙하 원본이 없으며 수면의 숨 변화는 작다.
- GIF 파일의 프레임/시간표와 정적 순서표를 확인했다. 실제 게임의 타격 위치·발 미끄러짐·실시간 재생 인상은 이 작업에서 확인하지 않았다.

이 결과는 교정된 후보다. 사용자 승인, 검수 keep, 일괄 통과를 선언하거나 판정 파일에 기록하지 않았다.

# 심연현무 — 갑각·돌진·현해진 수정 후보

## 현재 원본과 범위

기본 `poses/` 9자세와 `actions/` 9자세는 각각 **128행 × 128글자의 완전한 ASCII 팔레트 인덱스 원본**이다. 기존 18색 `palette.json`을 유지했다. 점은 투명하고 팔레트에 없다. 전 자세의 x=0/127, y=0/127은 투명하며 최하단 실제 몸/발 윤곽은 y=124다. 특히 idle_a의 가까운 발바닥이 y=124에 직접 닿는다.

이번 변경은 이 후보의 `source/`에만 저장했다. 제공된 현재 시트와 64px 검객 그림을 실제로 열어 외형·얼굴·연결·명암을 관찰했다. 참고 픽셀 추출·추적·재배포는 하지 않았다. 저장소 코드, 게임 저장소, brief, 장부, 다른 후보, 검수 결과를 수정하지 않았다. 사용자 승인 및 새 독립 검수 통과를 선언하지 않는다. 별도 검수자는 호출하지 않았다.

## 직접 저작 방식과 보존

- 최종 정본: `poses/*.pxgrid`, `actions/*.pxgrid`, `palette.json`.
- 이번 직접 좌표 기록: `edits/dome-impact-mouth/<pose>.rows`. 각 파일은 해당 자세의 y/x와 직접 고른 ASCII 문자열을 별도로 보존한다. 다른 프레임에서 좌표를 읽어 복사하거나 계산해 전파하지 않는다. 변하지 않는 같은 갑각 재질은 같은 색 군집을 유지하되 머리·목·기·별의 겹침에서는 해당 자세의 실제 위치에 맞춰 문자열 길이를 선택했다.
- `apply_native_edits.py`: 위 명시된 문자열만 기존 격자에 대입한다. 윤곽 추론, 원·다각형·선 래스터화, 자동 채우기, 수식 명암, 전체 프레임 이동·회전·보간, 이미지 생성은 없다.
- `revisions/before-dome-impact-mouth/`: 이번 작업 전 18개 전체 격자 및 이전 AUTHORING/TIMING 문서를 보존했다. 그보다 이전 `before-targeted-repair/`, `author.py`, `repair.py`, 갑각 리터럴 기록도 보존했다.
- 옛 저작안부터 재현하는 순서: `author.py` → `repair.py` → `apply_native_edits.py`. 현재 완전한 격자의 PNG/GIF를 만들 때는 **render.py만 실행**한다.
- `render.py`, `diagnostics.py`는 격자를 읽고 직접 팔레트를 배정하며 진단 배경·라벨·최근접 확대와 PNG/GIF를 만든다. 진단 확대는 자산 원본에 되쓰지 않는다.

## 지목 부위의 수정

좌표는 native 셀의 좌상단을 (0,0)으로 한다.

### 갑각의 곡면과 두께 — idle_a 및 다른 직립 14자세

- x=58…96/y=34…66 부근의 그림자와 오른쪽 윤곽을 별도의 행 문자열로 다시 골랐다. 기존 y=45…68의 긴 수직 가장자리를 중간의 완만한 팽창 뒤 y=53…66에서 안으로 들어오는 계단 곡면으로 바꿨다. 낮춘 머리가 있는 준비·피격·독·기절·기술 회수에서는 y=67…80까지 아래 앞쪽 돌 윤곽을 따로 마무리했다. 머리가 올라온 대기·회수에서는 실제 목이 가리는 위치에서 돌 편집을 끝냈다.
- g/j의 큰 면 경계를 위에서 아래로 일정한 직선으로 밀지 않고 곡률이 바뀌는 군집으로 나눴다. 실제 3배에서 y=46…47/x=72…76의 짧은 녹청 돌출이 그림자에 접힌 쐐기로 보이는 것을 확인해, 각 직립 자세에 해당 지점의 j 문자열을 직접 추가했다.
- 오른쪽 금 홈을 짧고 휘는 r/a 군집으로 다시 넣었다. 왼쪽 위의 u/t 밝은 돌 면, 중앙 금 문양과 검푸른 살색은 유지했다.
- y=89…96/x=21…73 부근에 j/s의 넓은 아래 두께 띠를 찍고 금색 분절 테두리 아래에 어두운 돌 재질을 남겼다. 대기의 목 외곽을 덮었던 초기 편집은 idle_a y=91…94/x=70…71의 O 윤곽을 직접 복구하고 각 행의 돌 띠를 목 앞에서 끝내는 문자열로 조정했다.
- 죽음·수면 세 자세는 이번 지목이 직립 갑각에 관한 것이므로 기존 접힌 네 발, 말린 꼬리, 감긴 눈과 호흡 원본을 보존했다.

### 공격 — 큰 갑각 어깨의 전진과 앞발 지지

- x=58…115/y=42…87의 앞 갑각을 직접 다시 그렸다. 상단과 뒤쪽 몸은 유지하고 중간·앞쪽 돌 부피가 앞으로 기울어 커지는 접촉 윤곽, 넓은 녹청 기본면과 검푸른 그림자, 아래쪽 굵은 돌 입술을 별도 군집으로 저작했다. 기존 작은 앞 쐐기를 접촉 덩어리로 사용하는 대신 본 갑각의 큰 앞 어깨가 밀도록 했다.
- 머리는 x=103…117/y=88…95에서 어깨 아래로 당겼다. 작은 금 눈과 짧은 턱을 남기고 굵은 밝은 목 면이 어깨 아래 가슴으로 접혀 이어진다.
- 가까운 앞다리는 어깨 → 굵은 위팔 → 압축된 손목 → 넓은 받침 앞발로 다시 찍었다. x=88…116/y=118…124의 넓은 발과 짧은 v 발톱은 move의 길게 뻗는 보행 발과 다르다. 실제 지지 발바닥은 y=124다.
- move에서 뒤로 미는 가까운 뒷다리와 공격의 뒤 지지발을 유지해 준비 → 뒤발 밀기 → 갑각 접촉 → 목/앞발 회수가 이어지게 했다. 전체 프레임을 옮겨 전진을 만들지 않았다.
- 최초 수정의 앞다리 확대가 먼 앞발을 가리는 것을 PNG에서 확인했다. attack x=111…122/y=99…113에서 먼 앞다리의 B/C 부피와 O 겹침 경계, 작은 별도 발톱 발을 직접 다시 저작했다. 네 발의 크기 차이와 원래 꼬리를 남겼다.

### 현해진 — 실제 열린 입에서 넓은 두 물 파문

- skill_b의 옛 x=107…125/y=41…103 효과는 명시적인 점 문자열로 지우고 새 효과를 직접 찍었다. 머리·위턱·어두운 입 안·아래턱을 각각 다른 행으로 저작해 머리를 조금 당겼다. 작은 금 눈은 입 위에 유지했다.
- 실제 입 안은 x=95…102/y=72…75의 O/D 군집이며, 그 안의 e/w 출구가 오른쪽으로 나와 분기한다. 위턱과 아래턱 사이에 어두운 목구멍과 물의 뿌리를 함께 남겼다. 마지막 얼굴 1배/확대 확인에서 입이 너무 얕게 보이는 것을 보고 x=94…104/y=72…76의 다섯 ASCII 구간으로 입의 어두운 깊이와 별도 아래턱 C/L 면을 직접 보강했다. 이 최종 입을 다시 세 배경에서 열어 확인했다. 입 위·턱 밖에만 효과를 붙이지 않았다.
- 첫 파문은 x=103…126/y=49…74, 두 번째는 x=104…125/y=76…100 부근이다. 서로 다른 윗 물마루와 아래 말린 끝, 넓은 e 물벽, C/L 그늘과 w 밝은 물마루를 골랐다. 두 곡면의 볼록한 앞이 오른쪽을 향하며 사이 빈 공간은 유지했다. 최대 효과 잉크 x=126, 셀 가장자리 x=127은 투명하다.
- skill_a는 새 갑각 곡면의 금 홈에서 목 쪽으로 이어지는 청금 기를 해당 자세의 x=86…95/y=48…60에서 따로 재저작했다. 기술 준비의 목과 네 발을 보존했다.
- skill_c는 낮아진 원래 목과 입앞/위/아래 **세 개의 별도 잔물보라**를 유지했다. 새로운 갑각 오른쪽 곡면 편집이 그 잔물보라에 닿지 않도록 해당 자세의 문자열 범위를 선택했다.

## 실제 그림 확인과 파일 진단

최종 PNG를 다시 연 뒤 다음 사항을 확인했다.

- `previews/light-native.png`, `dark-native.png`, `checker-native.png`: 18자세의 실제 1배에서 얼굴, 발, 꼬리, 테두리 및 상태 구분을 비교했다.
- `previews/light-3x.png`, `*-repair-backgrounds.png`: 세 배경의 native 1배/최근접 3배에서 갑각 굴곡·돌 아래 띠·목과 어깨·네 다리와 발톱·열린 입과 물 뿌리·의도하지 않은 투명을 확인했다.
- `previews/repair-before-after.png`: 이번 작업 직전 전체 격자와 최종 idle_a/attack/skill_b를 각각 읽은 3배 비교 그림이다. 참고 PNG에서 픽셀을 뽑아 만든 비교가 아니다. `compare_revision.py`에 읽기·렌더 코드를 보존했다. `face-diagnostic-4x.png`도 최종 PNG의 얼굴로 갱신했다.
- `previews/*-gif-strip.png`: 내보낸 실제 GIF를 디코딩한 각 프레임의 대기, 공격, 피격, 쓰러짐, 기술, 독, 기절, 수면 순서와 발 접지를 비교했다. 공격의 갑각 전진 및 기술의 head retraction은 직접 저작한 동작이다. 게임 이동이나 보간으로 만든 동작이 아니다.
- 18개 전체 격자를 읽어 128행/행당128글자, 팔레트 문자, 투명 테두리, 최하단 y=124를 진단했다. 원본 팔레트는 18색이다. PNG/GIF는 native128 셀이고 GIF 알파 및 불투명 색을 원본 PNG와 재읽기 비교했다. 이는 원본 파일·렌더 저장 확인이며 독립 검수 판정이 아니다.
- 수면 두 자세·죽음의 격자는 이번 수정 전 원본과 동일하다. 독/기절의 아픈 목과 처진 얼굴, 다른 거품/별 군집을 보존했다. 18개 최종 격자는 각각 서로 다른 자세다.

테스트·게이트 및 별도 검수 호출은 실행하지 않았다. 게임에 설치하거나 런타임 전투를 검증한 작업은 아니다.

## 남은 시각적 한계

- 금 홈과 넓은 돌 윗면은 일부 각진 분할로 읽힐 수 있다. 이번 수정은 오른쪽 곡면과 아래 띠를 중심으로 했으며 자연석 요철을 추가하지 않았다.
- 강한 갑각 접촉에서 머리와 먼 앞다리는 큰 앞 어깨·가까운 앞발에 일부 가려진다. 금 눈과 별도 작은 발은 남겼지만 1배에서는 작다.
- 물 파문은 한 128px 셀에 캐릭터와 함께 들어가므로 실제 화면을 가로지르는 물 투사체 규모를 보여 주지는 못한다. 열린 입의 어두운 목구멍은 작은 군집이다.
- 수면의 원래 숨 변화는 작다. 접힌 발·꼬리·닫힌 눈은 유지했으며 이번 세 지목과 관계없는 휴식 자세를 새 몸으로 바꾸지 않았다.
- GIF는 저작 자세의 비교용 반복 재생이다. 실제 돌진 거리, 적과의 접촉, 피해/음향 시점은 확인하지 않았다.

완전한 원본과 자체 검토 산출물을 저장했다. 새로운 독립 판정 및 사용자 선택은 하네스에서 별도로 이루어진다.

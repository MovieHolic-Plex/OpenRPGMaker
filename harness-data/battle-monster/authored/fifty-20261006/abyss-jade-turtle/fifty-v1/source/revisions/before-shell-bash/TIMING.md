# 심연현무 — 18자세 / 8GIF 시간표

셀은 native 128×128, 팔레트는 기존 18색이다. 직접 저작한 격자를 그대로 노출하고 전체 프레임 이동·회전·보간으로 동작을 만들지 않는다. 기존 유지 시간을 보존했다. 아래 ms는 최종 저장 GIF를 다시 읽어 확인한 값이다.

| GIF | 자세 순서 | 유지 시간 ms |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 320 / 300 / 120 / 200 / 240 / 320 |
| hit | idle_a → hit → recover → idle_a | 360 / 220 / 240 / 400 |
| dead | idle_a → hit → dead | 450 / 200 / 1200 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 350 / 420 / 240 / 360 / 400 |
| poison | poison_a → poison_b | 460 / 460 |
| stun | stun_a → stun_b | 500 / 500 |
| sleep | sleep_a → sleep_b | 720 / 820 |

전체 GIF는 후보 비교용 무한 루프다. dead GIF가 다시 대기로 돌아가는 것은 비교 재생이며 실제 부활 동작이 아니다.

## 돌진: 준비 → 전진 → 접촉 → 회수

- **windup, 300ms:** 목과 가까운 앞발을 갑각 밑으로 당긴다. 뒤 지지발은 y=124에 있다.
- **move, 120ms:** 뒤 허벅지·무릎·발목으로 밀며 앞발을 넓게 내딛는다. 이 기존 자세를 보존했다.
- **attack, 200ms:** 앞 갑각의 과도한 팽창을 줄이고 x=100 부근의 앞면에서 아래 테두리로 돌아오는 돌판을 직접 다시 저작했다. 윗빛/금 홈 분기, 중앙 금 문양과 앞면 홈을 함께 조금 기울인 배열로 바꿨다. 앞 테두리는 x=89…97/y=88…96의 밝은 청색 어깨 관절과 이어져 밀치기를 지지한다. 작은 머리와 기존 압축된 손목/넓은 타격 앞발, 먼 앞다리의 상완/팔꿈치/아래팔은 유지했다. y=97…127의 모든 원본 행이 수정 전과 같으며 실제 가까운 발바닥은 x=88…105/y=124다. 전체 몸 이동/회전이나 중간 프레임 합성은 사용하지 않았다.
- **recover, 240ms:** 목을 세우고 앞발을 몸 쪽으로 회수하는 기존 자세다. 뒤발·꼬리와 네 발의 해부는 이어진다.

## 현해진: 실제 입 앵커

이 종은 손에 든 무기가 없는 거북이다. 기술은 갑각 앞쪽 청금 기를 모아 **실제 입에서** 두 물 파문을 내보낸다. 두 물 파문은 이전 수리에서 직접 교정한 원본이며, 이번 공격/기절 교정에서는 기술 세 격자와 유지 시간을 모두 보존했다.

- **skill_a, 420ms:** 앞 갑각의 금 홈 x=86…95/y=48…60에서 청금 기가 모여 목 쪽으로 이어진다.
- **skill_b, 240ms:** 위턱/아래턱 사이 x=95…102/y=72…75의 어두운 입 안에 e/w 출구가 있다. x=94…102/y=76에는 별도 아래턱 C/L 면이 있다. 발원점 x=101…105/y=72…75에서 위 갈래는 x=102…109/y=70…74로 올라가고, 아래 갈래는 x=101…107/y=75…81로 내려간다. 위의 둥근 호 x=105…126/y=49…71과 아래 호 x=107…126/y=80…100에는 각각 e 몸통, w 물마루와 C/L 안쪽 면, 말린 끝이 있다. x=111…126/y=72…79의 배경 공간으로 두 큰 호를 분리했다. x=127 투명 열을 유지한다.
- **skill_c, 360ms:** 낮춘 목과 입에서 기를 회수한다. 입앞 x=103…110/y=88…99, 위 x=111…118/y=70…84, 아래 x=110…116/y=104…114의 세 잔물보라는 별도로 직접 저작된 군집이다.

## 상태와 수면 호흡

- **poison, 각 460ms:** 턱/목/앞발의 서로 다른 아픈 자세와 두 크기·위치의 보라 독 거품을 보존했다.
- **stun, 각 500ms:** 목 아래의 넓은 삼각 끝과 가는 갈고리 주둥이를 좁은 목 굽힘/별도 둥근 머리/짧은 붙은 턱으로 교정했다. stun_a의 닫힌 금빛 눈꺼풀은 x=106…109/y=108, stun_b는 x=106…109/y=109다. 검은 코/입 경계는 눈 앞쪽 x=114…116에 떨어져 있다. 두 번째 머리의 윗면·볼·아래턱과 목 관절 압축은 별도 좌표 문자열로 고른 작은 하강이다. y=0…100의 갑각/어깨 위쪽과 기존 두 별의 위치 변화, 지지발은 유지했다.
- **sleep_a, 720ms:** 닫힌 눈 x=97…99/y=102, 들린 턱, 그 아래 짧게 접힌 앞팔과 앞발을 유지한다. 접힌 뒷발과 말린 꼬리는 남아 있다.
- **sleep_b, 820ms:** 닫힌 눈 x=98…100/y=103, 내려오는 머리/아래 턱과 목 아래 압축을 자세별 문자열로 저작했다. 갑각 상단은 sleep_a의 y=54에서 y=55로 작게 내려오며, 같은 접힌 앞발과 y=124의 지지를 유지한다. 내부 색만 바꾸거나 몸 전체를 자동 이동한 호흡이 아니다.

8개의 실제 GIF 디코딩 프레임 띠를 열어 자세 순서와 연결을 비교했고, 최종 파일의 노출 시간도 재읽었다(`previews/rigid-shell-rounded-stun-observations.json`). 프레임 정지 비교이며 재생 중 체감 타이밍과 실제 게임의 돌진 거리·접촉·피해 시점·상태 루프를 검증한 자료는 아니다. 호흡 변화는 작다. 사용자 승인이나 독립 검수 통과를 뜻하지 않는다.

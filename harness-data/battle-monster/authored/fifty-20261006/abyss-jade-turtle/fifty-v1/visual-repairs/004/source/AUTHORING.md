# 심연현무 — 공격 갑각·기절 얼굴·수면 앞발 교정

## 원본과 이번 범위

정본은 `palette.json`, `poses/*.pxgrid` 9개, `actions/*.pxgrid` 9개다. 각 격자는 128행 × 128글자의 완전한 ASCII 팔레트 인덱스 원본이다. 점은 투명하고 팔레트에 없다. 기존 18색 팔레트는 바이트까지 그대로 보존했다.

제공된 현재 시트와 64px 검객 참고를 실제로 열어 갑각 부피, 머리 비율, 목·사지 연결과 크기를 관찰했다. 참고 픽셀을 추출·추적·재배포하지 않았다. 이번 작업의 모든 쓰기는 이 후보의 `source/` 안에만 있다.

수정한 자세는 `attack`, `stun_a`, `stun_b`, `sleep_a`, `sleep_b`다. 나머지 13자세, 현해진의 입과 두 물 파문·세 잔물보라, 독 거품, 기절 별, 금 홈의 기본 체계, 물결 꼬리와 다른 자세의 발은 보존했다. 추가 동작 9개도 전체 캐릭터와 효과를 가진 완전한 격자로 남아 있다.

## 직접 선택한 픽셀과 이전 원본

- `revisions/before-round-rim-rest/`: 이번 수정 직전 18개 전체 격자, 팔레트, AUTHORING/TIMING 사본.
- `edits/round-rim-rest/*.rows`: 각 자세의 y/x와 직접 선택한 ASCII 픽셀 문자열. 점 문자열도 실제 지운 윤곽을 명시한다. 첫 수정과 그림을 열어 본 뒤의 추가 얼굴 교정이 순서대로 보존된다.
- `apply_round_rim_rest.py`: 위 문자열을 해당 자세에 대입하는 보조 코드. 다른 자세에서 좌표나 픽셀을 읽어 자동 전파하지 않는다. 본체·명암·효과 생성, 도형 래스터화, 전체 프레임 이동·회전·보간, 자동 구멍 채우기를 하지 않는다.
- 기존 `author.py`, `repair.py`, 다른 편집 기록과 과거 revision 폴더도 보존했다. 과거 초안 작성 코드를 현재 격자에 다시 실행하면 이번 수리가 덮이므로, 현재 그림을 굽는 입구는 `render.py`다.
- `inspect_round_rim_rest.py`: 현재/직전 격자를 읽어 비교 그림과 파일 진단을 만든다. 픽셀 선택·보정은 하지 않는다.

## 지목 부위의 실제 수정

좌표는 각 128px 셀의 좌상단을 (0,0)으로 한 native x/y다.

### attack — (104,82) 갑각 앞쪽과 금 홈

- x=90…117/y=62…79의 이전 앞으로 늘어난 돌 쐐기를 명시적인 j/s/O와 점 문자열로 교정했다. y=64…72의 오른쪽 테두리는 x=109 부근에서 완만하게 팽창하며, 이후 y=73…88에서 안으로 돌아온다.
- x=80…104/y=80…88의 금 홈과 돌 입술을 각각 다시 골랐다. r/a의 홈은 둥근 앞판 쪽으로 짧게 돌아가고, j/s의 돌 두께와 어두운 O 외곽이 그 아래를 받친다. x=94…102/y=89…91의 접합도 따로 정리했다.
- 위쪽·뒤쪽 갑각과 왼쪽 위 u/t의 넓은 밝은 면, 중앙 g 기본면, j 그림자, 기존 문양은 유지했다. 접촉의 기울어진 앞 어깨가 같은 돌판으로 읽히도록 앞 윤곽만 수리했다.

### attack — (99,105) 목·가까운 앞다리·발목

- x=80…122/y=97…124를 실제 팔레트 문자열로 다시 저작했다. 작은 금 눈이 있는 낮은 머리는 보존하고, 그 아래 목의 D/O 경계를 y=99…105에서 어깨 쪽으로 돌아가게 했다. 머리와 목이 바로 앞발 전체로 합쳐지던 넓은 겹침을 줄였다.
- 가까운 앞다리는 밝은 위팔 → 굵은 팔꿈치와 앞팔 → 압축된 손목 → 넓고 짧은 타격 앞발로 이어진다. 목 아래의 어두운 경계와 다리 오른쪽 외곽이 각각 읽힌다. y=121…123의 세 v 발톱 군집은 앞을 향하며, 가까운 발바닥 O 윤곽은 x=88…105/y=124에 직접 닿는다.
- 먼 앞다리는 B/C의 작은 별도 면과 O 윤곽, 짧은 발톱을 남겼다. 뒤에서 밀어 주는 기존 뒷다리와 몸통·꼬리는 그대로다. move의 긴 보행 앞발과 attack의 압축된 받침 발이 다르다.

### stun_a / stun_b — (102,109) 처진 작은 머리

- x=86…118/y=99…118의 목 끝·턱·주둥이·먼 앞발 겹침을 자세별로 따로 골랐다. 기존 아래로 접힌 목과 어깨, 실제 지지하는 가까운 앞다리를 유지하며, 목 끝의 두꺼운 주머니를 더 짧은 볼과 내려온 주둥이·턱으로 나눴다.
- 마지막 얼굴 교정은 x=98…110 부근의 L/H/C 볼 면, 짧은 D 턱, O 주둥이 외곽을 다시 선택했다. 닫힌 눈꺼풀은 stun_a의 x=103…105/y=106, stun_b의 x=103…105/y=107에 OOO로 명시했다. 눈 아래의 L/C 볼과 더 오른쪽 D 주둥이를 남겨 눈과 코를 구분했다.
- 두 번째의 볼·턱은 조금 더 내려오고 압축된다. 뒤의 먼 앞다리는 별도 어두운 B/C 면과 짧은 발끝으로 정리했다. 별의 다른 위치와 모양은 이번 수정 전과 같다.

### sleep_a / sleep_b — (96,106) 감긴 눈과 턱 아래 접힌 앞발

- sleep_a 눈꺼풀은 x=97…99/y=102, sleep_b는 x=98…100/y=103의 짧은 OOO다. 그 아래 L/C 볼 면을 직접 골랐다. 평상시 금 눈이나 검은 눈 군집을 복사하지 않았다.
- x=80…107/y=107…124의 목 밑·가까운 앞팔·손목·발을 각각 저작했다. 기존 앞으로 길게 펼친 발을 턱 아래로 당긴 짧은 팔과 두툼한 접힌 앞발로 바꿨다. 팔과 발의 겹침은 O/B 경계로 나눴으며, 발의 위쪽 밝은 면과 짧은 발톱은 아래 턱을 받치는 휴식 형태다. y=124의 발바닥을 유지했다.
- 쓰러짐의 힘없이 앞으로 뻗은 두 앞발과 낮게 떨어진 얼굴은 수정하지 않았다. 새 수면은 머리가 접힌 앞발 위에 남고, 앞발의 끝이 짧아 쓰러짐과 다른 실루엣이다. 뒤의 접힌 발과 말린 물결 꼬리도 보존했다.
- sleep_b의 x=94…105/y=96…107에서 머리 윗선·볼·닫힌 눈·아래 턱을 별도 문자열로 선택했다. 기존 갑각 상단의 y=54 → 55 작은 호흡 변화에 실제 내려오는 머리/턱 윤곽과 목 아래 압축이 더해진다. 전체 몸을 옮기거나 내부 색만 바꾼 호흡이 아니다.
- 확대에서 sleep_b의 갑각/목 경계 x=86/y=100에 남은 작은 투명 틈을 확인했다. x=85의 O 외곽과 x=86…87의 LL 목 면을 직접 저작했다. 목·앞발 사이와 말린 꼬리 가운데의 의도한 빈 공간은 유지했다.

## 현재 산출물과 실제 확인

`python source/render.py`로 18 native PNG, 두 native 3×3 시트, 세 배경의 전체 시트, 8개 GIF와 GIF 디코딩 프레임 띠를 다시 만들었다. GIF는 직접 저작된 격자를 순서대로 보여 주며 중간 자세를 합성하지 않는다. 저장한 GIF의 알파와 불투명 색은 원본 PNG와 재읽기 대조된다.

이번에 실제로 열어 본 최종 그림:

- `previews/light-native.png`, `dark-native.png`, `checker-native.png`: 18자세 전체의 1배 얼굴·사지·갑각·접지·투명·상태 구분.
- `previews/<수정 자세>-round-rim-rest.png`: 수정한 다섯 자세 각각의 밝은/어두운/체커 배경 native 1배와 최근접 3배.
- `previews/round-rim-rest-before-after.png`: 수정 직전 전체 격자와 현재 다섯 자세의 비교. 참고 PNG에서 픽셀을 뽑은 그림이 아니다.
- `previews/{idle,attack,hit,dead,skill,poison,stun,sleep}-gif-strip.png`: 저장한 실제 8GIF를 디코딩한 모든 자세. 공격의 준비·뒤발 밀기·접촉·회수, 수면의 두 머리와 접힌 앞발, 기절의 두 턱과 먼 앞발을 함께 비교했다.

파일 진단은 `previews/round-rim-rest-file-diagnostics.json`에 있다. 18개 모두 128행/행당128글자, 알려진 팔레트 문자, 투명 테두리, 최하단 y=124이며 서로 동일한 격자는 없다. idle_a의 실제 발은 그대로 y=124에 닿는다. 수정 픽셀 수는 attack 1036, stun_a 317, stun_b 310, sleep_a 298, sleep_b 382이며 다른 13자세는 0이다. 파일 진단은 시각 승인 근거가 아니다.

`previews/index.html`은 현재 PNG와 8GIF를 배경/배율별로 볼 수 있는 후보 확인판이다. 예전 이름의 `repair-before-after.png` 등은 이전 수리의 역사 자료이며, 이번 비교는 `round-rim-rest-before-after.png`를 사용한다.

## 남은 시각적 문제와 표현 한계

- 어두운 배경에서는 먼 앞다리의 검푸른 B/D 외곽 대비가 여전히 약하다. 가까운 발보다 작은 뒤쪽 다리로 남겼으며 팔레트를 밝게 바꾸지는 않았다.
- 기절의 작은 주둥이와 눈꺼풀, 공격의 작은 금 눈은 1배에서 몇 픽셀로 읽힌다. 큰 목·어깨와 일부 겹치므로 실제 게임 표시 크기에서 독립 검수가 필요하다.
- 수면의 낮은 갑각은 쓰러짐과 같은 종의 형태다. 이번 구분은 들린 닫힌 눈의 머리와 턱 아래 접힌 앞발에 있다. 호흡은 갑각/머리의 작은 윤곽 변화이며 큰 가슴 들썩임은 아니다.
- GIF는 후보 자세의 반복 비교 자료다. 실제 돌진 거리, 충돌, 피해/소리 시점과 게임 상태 루프의 자연스러움은 확인하지 않았다.

테스트·게이트와 별도 검수 호출은 실행하지 않았다. 사용자 승인이나 새 독립 검수 통과를 선언하지 않는다. 다음 판정은 하네스의 실제 독립 검수와 사용자 선택에 맡긴다.

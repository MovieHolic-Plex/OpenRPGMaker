# 심연현무 — 먼 앞다리 어깨와 현해진 두 물 파문 교정

## 원본과 범위

현재 그림 원본은 `palette.json`, `poses/*.pxgrid` 9개와 `actions/*.pxgrid` 9개다. 모두 128행 × 128글자의 완전한 리터럴 ASCII 팔레트 인덱스 격자이며 점은 투명이다. 기존 18색 팔레트를 그대로 보존했다. 이번에 수정한 격자는 `poses/attack.pxgrid`와 `actions/skill_b.pxgrid`뿐이다. 다른 16자세와 기본/상태 동작의 정체성은 보존했다.

제공된 현재 시트와 64px 검객 참고를 실제로 열어 갑각의 큰 명암 면, 작은 머리, 목·어깨·네 발, 크기를 관찰했다. 참고에서 픽셀을 추출·추적·리샘플하거나 참고 이미지 바이트를 산출물에 넣지 않았다. 모든 쓰기는 이 후보의 `source/` 안에서만 했다.

## 직접 선택한 native 픽셀

좌표는 셀의 좌상단 (0,0) 기준 x/y다. 코드로 도형·명암·효과를 생성하거나 전체 프레임을 이동·회전·보간하지 않았다. 자동 구멍 채우기와 다른 자세로의 좌표 전파도 사용하지 않았다.

### attack — 먼 앞다리 상완과 턱 분리

- 변경 범위 x=99…117/y=99…108, 변경 픽셀 116개.
- 턱 아래 x=110…117/y=99…102에 매달려 보이던 세로 기둥 윗부분을 직접 고른 점 문자열로 제거했다. 원래 작은 금 눈과 머리/목의 윤곽은 유지했다.
- x=101…107/y=103의 어깨 시작에서 x=102…115/y=104…107의 두꺼운 굽은 상완을 B/C/L 면으로 직접 저작했다. x=106…117/y=108에서 기존 먼 앞다리 팔꿈치·아래팔로 이어진다. 얇은 연결선 대신 상완의 넓은 청색 면과 짧은 밝은 면을 남겼다.
- 턱과 상완 사이 x=108…117/y=101…102의 배경 틈은 의도적으로 유지한다. 가까운 앞다리/먼 앞다리 사이 공간도 자동으로 메우지 않았다.
- 밝은/어두운/체커 확대에서 이전 기둥의 잔여 B/O 두 픽셀을 확인해 x=116…117/y=105와 x=117/y=106에서 직접 제거했다.
- y=109…127의 모든 행은 수정 전과 같다. 먼 발끝, 가까운 타격 앞발, 뒤 지지발의 좌표와 y=124 하중 윤곽은 유지했다.

### skill_b — 입에서 나오는 두 독립 물 파문 호

- 변경 범위 x=102…126/y=49…100, 변경 픽셀 506개.
- 실제 입의 e/w 발원점을 보존하면서 앞의 물줄기를 가늘게 나눴다. 위 갈래는 x=102…109/y=70…74에서 위 호의 왼쪽 아래 끝으로 이어진다. 아래 갈래는 x=101…107/y=75…81에서 먼저 아래로 내려간 뒤 아래 호의 왼쪽 위 끝에 닿는다.
- 위 파문은 x=105…126/y=49…71이다. 말린 위쪽 끝, 둥글게 팽창하는 오른쪽 배, 넓게 돌아오는 아래 물마루를 행별로 직접 저작했다. 과거의 긴 사선 하단을 넓은 곡선으로 바꿨다.
- 아래 파문은 x=107…126/y=80…100이다. 자체의 말린 윗끝, 둥근 오른쪽 배와 더 넓은 아래 물마루를 따로 선택했다. 위 파문의 좌표를 이동하거나 복사해 만들지 않았다.
- 두 호에는 e 청색 물 몸통, w 밝은 물결 가장자리, C/L 안쪽 푸른 면이 있다. x=111…126/y=72…79는 배경으로 남아 두 큰 호가 맞붙지 않는다. 공통 연결은 실제 입과 그 앞의 작은 발원점에 있다.
- 원래 아래턱과 목/네 발/갑각, 기술 준비와 목을 낮추는 회수/세 잔물보라는 보존했다. x=127 투명 열도 유지한다.

## 보존한 기록과 보조 코드

- `revisions/before-shoulder-water/`: 이번 수정 직전 두 격자, 팔레트와 AUTHORING/TIMING 원본.
- `edits/shoulder-water/attack.rows`, `skill_b.rows`: y/x와 직접 고른 ASCII 문자열. 삭제한 픽셀도 점 문자열로 명시한다.
- `apply_shoulder_water.py`: 해당 두 격자에 기록된 문자열을 대입한다. 완성 격자는 항상 전체 128×128 리터럴 행으로 저장한다.
- `inspect_shoulder_water.py`: 수정 전/후 원본을 읽어 라벨과 진단 배경, 비교 PNG, 변경 범위와 행 크기 관찰 JSON을 만든다. 원본 격자를 교정하지 않는다.
- 기존 `author.py`, 과거 수리 코드와 revision 폴더는 역사 자료로 보존했다. 현재 그림을 굽는 입구는 `render.py`다. 과거 작성 코드를 현재 격자 위에 다시 실행하지 않는다.

## 현재 산출물과 실제 그림 확인

`render.py`로 18 native PNG, 기본/추가 3×3 시트, 밝은/어두운/체커 전체 시트, 8GIF와 실제 저장 GIF의 디코딩 프레임 띠를 갱신했다. 그림 확대는 확인판에만 최근접 배율로 적용하며 native PNG/GIF는 128px 원본 그대로다. 중간 프레임을 합성하지 않는다. GIF에는 고정 원본 팔레트를 사용하며 재읽은 불투명 색과 알파가 해당 PNG와 일치한다.

실제로 열어 본 현재 자료:

- `previews/attack-shoulder-water.png`, `skill_b-shoulder-water.png`: 세 배경의 native 1배와 최근접 3배. 턱 아래 의도한 빈틈, 상완 연결과 면, 발끝, 물 파문의 곡률·두께·간격을 확인했다.
- `previews/shoulder-water-before-after.png`: 수정 직전/현재 격자의 비교 그림. 제공 참고에서 픽셀을 추출한 그림이 아니다.
- `previews/light-native.png`, `dark-native.png`, `checker-native.png`: 18자세 전체의 갑각/목/네 발과 상태 얼굴·접지·투명.
- `previews/{idle,attack,hit,dead,skill,poison,stun,sleep}-gif-strip.png`: 저장한 실제 8GIF를 디코딩한 모든 프레임. 공격의 준비/밀기/접촉/회수와 기술의 준비/두 파문/잔기 회수, 독/기절/수면의 별도 자세를 비교했다.

`previews/shoulder-water-observations.json`에는 변경 픽셀/범위, 팔레트 보존, 공격 발끝 행 보존과 파일별 128행/128글자·먹힌 영역·알 수 없는 글자 목록, 실제 GIF 유지 시간이 있다. 18개 격자의 테두리는 투명이고 최하단은 y=124다. idle_a의 실제 발은 y=124에 있다. 파일 관찰은 시각 승인이나 독립 검수 결과를 뜻하지 않는다.

## 남은 시각적 문제와 표현 한계

- 먼 앞다리의 검푸른 겹침 경계는 어두운 배경에서 대비가 낮다. 밝은 상완 면을 남겼지만 가까운 다리 뒤에 겹치는 작은 원근 다리로 읽히는지 독립 검수가 필요하다.
- 두 파문은 입의 작은 발원점을 공유한다. 본체와 셀 오른쪽 사이의 제한된 폭 안에 있는 부분 호이며 완전한 원형 고리 두 개가 아니다. 아래 갈래에는 호에 닿기 전 짧은 세로 물줄기가 있다. 1배에서 물 파문이 별개의 호로 읽히는지 다음 검수에서 확인할 부위다.
- 수면의 호흡은 기존 갑각/머리의 작은 윤곽 변화다. 이번 수정 대상이 아니며 큰 가슴 움직임을 추가하지 않았다.
- 실제 저장 GIF의 프레임을 정지 띠로 비교하고 유지 시간을 재읽었다. 실제 게임 돌진 거리·충돌·피해/소리 시점과 재생 중 체감 타이밍을 확인한 자료는 아니다.

테스트/게이트, 별도 검수자 호출, 게임 저장소/ledger/brief/다른 후보 변경은 하지 않았다. 사용자 승인과 독립 검수 통과를 선언하지 않는다. 다음 판단은 하네스의 실제 독립 검수와 사용자 선택에 맡긴다.

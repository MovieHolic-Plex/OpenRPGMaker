# 심연현무 시간표

격자·PNG·GIF 프레임은 모두 native 128×128. 전체 프레임의 이동·회전·보간 없이 직접 고른 자세를 순서대로 노출한다. GIF는 0번 색만 투명, 원본 팔레트 그대로 사용하며 각 프레임을 다시 읽어 알파 및 불투명 색을 비교한다. 아래 시간은 ms이며 GIF의 10ms 단위로 정확하게 표현된다.

| GIF | 자세 순서 | 유지 시간 |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 320 / 300 / 120 / 200 / 240 / 320 |
| hit | idle_a → hit → recover → idle_a | 360 / 220 / 240 / 400 |
| dead | idle_a → hit → dead | 450 / 200 / 1200 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 350 / 420 / 240 / 360 / 400 |
| poison | poison_a → poison_b | 460 / 460 |
| stun | stun_a → stun_b | 500 / 500 |
| sleep | sleep_a → sleep_b | 720 / 820 |

전부 검토용 반복 재생이다. 쓰러짐 GIF가 다시 대기로 돌아오는 것은 비교 루프이며 실제 부활 동작을 뜻하지 않는다.

## 공격 하중

- windup: 긴 목을 갑각 아래로 당기고 가까운 앞발의 팔꿈치·손목을 안쪽으로 접는다. 뒤 지지발은 y=124에 놓는다.
- move: 가까운 뒤발의 허벅지부터 발끝까지 뒤로 미는 자세, 가까운 앞발의 무릎과 발목은 전방으로 뻗는다. 먼 앞발도 어깨에서 이어진다.
- attack: 앞발의 손목을 압축하고 짧은 발톱이 붙은 넓은 앞발을 받친다. 갑각 앞쪽의 어깨 면이 (92…104, 66…89)로 돌출되며 목은 낮다. 접촉의 주체는 갑각 어깨다.
- recover: 앞발을 몸 쪽으로 회수하고 목의 턱·가슴 면을 다시 세운다.

## 현해진 발원점

좌표는 좌상단 (0,0), x 오른쪽/y 아래 기준이다.

- skill_a: 갑각 앞쪽 금 홈 (79…94, 41…55)에서 청금 기가 이어지고, 앞쪽 세 작은 기 덩어리가 목에 접근한다. 확장된 턱·목을 별도 행으로 찍었다.
- skill_b: 입 안의 어두운 줄과 물 출구는 (108…110, 72…75). 이 픽셀이 (108,72)의 물 주경로에 직접 닿는다. 윗 파문은 y=41…71의 안쪽 빈 공간과 말려 들어가는 거품 끝, 아랫 파문은 y=74…102의 더 두꺼운 바깥 물결과 펼쳐진 하단 거품으로 구별된다. 효과의 최우측 잉크는 x=125이다.
- skill_c: 머리를 y=81…105로 낮추고 굵은 실제 목을 가슴에 연결한다. 입 앞 잔물은 (103…110, 88…99), 위쪽 찢어진 잔기는 (111…118, 70…84), 아래 물보라는 (110…116, 104…114). 세 군집을 각각 직접 찍었다.

## 상태 동작

- 독: 턱을 아래로 늘어뜨리고 앞발을 안쪽으로 접는다. 두 번째 자세에서는 턱·목·앞발 군집을 더 압축하고, 독 거품의 크기·위치·빈 속을 각각 바꿨다.
- 기절: 길고 굵은 목이 아래로 꺾이고 머리가 앞발 바깥으로 처진다. 두 번째 자세에서는 감긴 눈과 아래턱을 한 줄 낮추고 이완된 목 면을 바꾸며 별 두 개를 다르게 배치한다.
- 수면: 눈은 sleep_a (96…97,102), sleep_b (94…95,103)의 2px 수평 눈꺼풀이다. 다리와 꼬리를 유지한 채 두 번째 자세의 턱·목과 갑각 상단 외곽이 직접 고른 다른 행으로 내려온다. 색만 바꾸는 호흡이 아니다.

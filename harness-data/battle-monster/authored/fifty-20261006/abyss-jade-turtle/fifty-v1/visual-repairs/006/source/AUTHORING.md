# 심연현무 — 공격 돌갑각과 기절 주둥이 교정

## 원본과 범위

현재 원본은 palette.json, poses/*.pxgrid 9개와 actions/*.pxgrid 9개다. 모두 128행 × 128글자의 완전한 리터럴 ASCII 격자이며 점은 투명이다. 기존 18색 팔레트와 거대한 녹청 돌갑각/금 홈/작은 금 눈/긴 목/네 발/물결 꼬리의 정체성을 유지했다.

이번 변경은 poses/attack.pxgrid, actions/stun_a.pxgrid, actions/stun_b.pxgrid 세 개다. 다른 15개 격자, 기술의 준비/두 입 파문/세 잔물보라, 독/수면과 기존 GIF 노출 시간을 보존했다. 모든 쓰기는 이 후보의 source/ 안에서만 했다.

제공된 현재 18자세 시트와 64px 검객 참고를 실제로 열어 크기/얼굴/광원/해부를 관찰했다. 참고 픽셀 추출·추적·리샘플·재배포는 하지 않았다. 전체 몸의 수학적 이동/회전, 도형이나 명암 합성, 자동 연결/구멍 채우기, 다른 자세로의 자동 좌표 전파를 사용하지 않았다.

## 직접 고른 native 픽셀

좌표는 셀 좌상단 (0,0) 기준이다. 실제 문자열은 edits/rigid-shell-rounded-stun/*.rows에 y/x/ASCII로 보존했다. 완성 pxgrid는 변경 부분만이 아니라 전체 원본 행이다.

### attack — 단단한 앞면과 붙은 어깨

- 총 1,234픽셀 변경, 변경 범위 x=40…109/y=30…96.
- 과거 x=109까지 부풀던 앞쪽 갑각을 x=100 부근의 좁은 앞면으로 다듬었다. 앞 윤곽의 곡률과 j/s의 어두운 큰 면, 아래 테두리를 함께 다시 찍었다.
- 윗빛 면/금 홈 분기 x=40…60/y=30…46, 중앙 금 문양 x=49…65/y=58…67, 아래 사선 금 홈과 가로 홈 합류 x=70…88/y=67…83을 함께 골랐다. 문양과 홈이 같은 돌판 방향을 따라 조금 기울어 보이게 했다.
- x=89…97/y=88…96에 O/D 겹침 경계와 L/H/C의 넓은 청색 어깨 관절 면을 저작했다. 갑각 아래 어깨가 압축된 가까운 앞발의 상완으로 실제 이어진다. 분리된 충격 입자가 아니다.
- 첫 PNG에서 보인 사선 홈의 한 행 역방향 꺾임과 겹친 가로 홈을 별도 문자열로 교정했다.
- y=97…127의 모든 행은 수정 전과 같다. 기존 목/작은 머리/먼 앞다리 상완·팔꿈치·아래팔, 짧은 타격 앞발/지지발/발톱, y=124의 실제 하중 윤곽을 보존했다.

### stun_a — 둥근 주둥이와 짧은 턱

- 총 259픽셀 변경, 범위 x=91…117/y=101…116.
- 넓은 삼각 목 끝을 좁은 C/B/D의 굽은 목으로 다듬고, x=100…116/y=104…115에 별도 머리 윗빛/볼/둥근 앞면/붙은 짧은 턱을 골랐다. 얇게 꺾여 내려가던 끝을 제거했다.
- 닫힌 금빛 눈꺼풀은 x=106…109/y=108의 akka다. 평상시 둥근 눈 군집을 복사하지 않았다. 코/입의 어두운 경계는 x=114…116 쪽에 있어 눈과 분리된다.
- 첫 1배/확대 확인에서 주둥이 끝이 아직 뾰족해 보였다. y=106…112의 앞면/아래턱 문자열을 다시 골라 짧은 둥근 끝으로 마무리했다.

### stun_b — 같은 해부의 작은 처짐

- 총 274픽셀 변경, 범위 x=91…118/y=101…117.
- 같은 재질/크기의 머리를 유지하며 x=91…100의 목 관절 압축, 머리 윗면/볼/아래턱의 작은 하강을 별도 행 문자열로 저작했다. 전체 프레임이나 머리 영역을 코드로 이동하지 않았다.
- 닫힌 금빛 눈꺼풀은 x=106…109/y=109다. 둥근 앞면과 붙은 턱도 이 자세의 실제 위치에서 따로 골랐다.
- 기절 두 자세의 y=0…100 원본 행은 그대로다. 갑각/어깨 위쪽, 별의 서로 다른 배치, 기존 지지발 접지를 유지했다.

## 원본 보존과 보조 코드

- revisions/before-rigid-shell-rounded-stun/: 수정 직전 세 격자, 팔레트, AUTHORING/TIMING 문서.
- edits/rigid-shell-rounded-stun/: 직접 고른 변경 문자열. 첫 그림 확인 뒤의 후속 교정도 순서대로 명시했다.
- apply_rigid_shell_rounded_stun.py: 명시된 문자열을 지정 좌표에 대입하고 전체 격자를 저장한다. 자동 픽셀 선택/합성 기능은 없다.
- inspect_rigid_shell_rounded_stun.py: 원본 읽기/라벨/진단 배경/최근접 확대/파일 관찰만 한다. 그림을 고치지 않는다.
- render.py: 원본 격자를 native PNG/고정 팔레트 GIF로 굽는다. 과거 저작 보조 코드와 revision 폴더는 역사 자료로 보존했다. 과거 작성 코드를 현재 격자 위에 다시 실행하지 않는다.

## 실제 그림 확인과 산출물

18 native PNG, 기본/추가 시트, 밝은/어두운/체커 전체 시트와 8GIF를 갱신했다. 저장 GIF를 다시 디코딩한 프레임은 원본 PNG의 불투명 색/알파와 일치한다. 노출 시간은 TIMING.md에 있다. 확대는 확인판에만 사용했고 PNG/GIF 셀은 128px 원본이다.

실제로 열어 확인한 최종 자료:

- previews/{attack,stun_a,stun_b}-rigid-shell-rounded-stun.png: 세 배경의 native 1배와 최근접 3배. 갑각 앞면/금 홈/어깨와 기절 목/눈/코/턱의 연결을 비교했다.
- previews/stun-face-inspection.png: 두 머리의 진단 확대. 닫힌 눈과 둥근 끝, 짧은 턱을 확인했다.
- previews/{light,dark,checker}-native.png: 18자세 전체의 갑각/목/발과 의도한 빈틈을 비교했다. 같은 눈/목/테두리 부위의 명백한 새 결손은 보이지 않았다.
- previews/{idle,attack,hit,dead,skill,poison,stun,sleep}-gif-strip.png: 실제 저장 8GIF의 모든 디코딩 프레임. 준비/전진/접촉/회수, 별 배치와 작은 머리 처짐, 나머지 동작을 정지 비교했다.
- previews/rigid-shell-rounded-stun-before-after.png: 이번 수정 직전/현재 세 격자 비교.

previews/rigid-shell-rounded-stun-observations.json에 실제 변경 수/범위, 팔레트 보존, 18개 파일의 행 수/길이/먹힌 영역/알 수 없는 글자/테두리와 GIF 노출 시간을 남겼다. 모두 128×128, 알 수 없는 글자/불투명 테두리는 0개, 최하단 ink는 y=124다. idle_a의 실제 발 접지도 y=124다. 이 파일 관찰은 미감 판정이 아니다.

## 남은 시각적 문제와 표현 한계

- 접촉 자세의 돌갑각 앞면은 준비/전진보다 조금 앞으로 기운 배열이다. 팽창을 줄였지만 제한된 프레임에서 단단한 갑각의 전진/어깨 밀치기로 읽히는지는 새 독립 검수에서 확인할 부위다.
- 기절 눈꺼풀은 작은 금빛 가로 군집이다. 1배에서 닫힌 눈으로 보였지만 머리/목/먼 다리의 어두운 겹침은 작은 화면에서 대비가 낮고, 두 머리의 처짐 차이는 작다.
- 기존 수면 호흡과 독 상태 쌍의 움직임도 작다. 이번 수정에서 그 원본은 보존했다.
- GIF 디코딩 프레임과 시간표를 확인했다. 실제 게임 돌진 거리/접촉/피해/소리 시점과 재생 중 체감 타이밍을 확인한 자료는 아니다.

테스트/게이트나 별도 검수자 호출은 하지 않았다. 저장소/게임 저장소/ledger/brief/다른 후보와 판정 기록은 변경하지 않았다. 새 독립 검수는 하네스가 맡으며 사용자 승인이나 검수 통과를 선언하지 않는다.

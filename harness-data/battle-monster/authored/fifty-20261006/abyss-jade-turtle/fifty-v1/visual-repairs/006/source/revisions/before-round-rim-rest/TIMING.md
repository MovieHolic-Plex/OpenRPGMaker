# 심연현무 — 18자세 / 8GIF 시간표

모든 셀은 native 128×128이다. 전체 프레임 이동·회전·보간 없이 직접 고른 서로 다른 격자를 차례로 노출한다. 원본 18색 고정 팔레트와 투명 인덱스0을 사용한다. 시간은 ms이며 GIF의 10ms 단위로 표현된다.

| GIF | 순서 | 유지 시간 |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 320 / 300 / 120 / 200 / 240 / 320 |
| hit | idle_a → hit → recover → idle_a | 360 / 220 / 240 / 400 |
| dead | idle_a → hit → dead | 450 / 200 / 1200 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 350 / 420 / 240 / 360 / 400 |
| poison | poison_a → poison_b | 460 / 460 |
| stun | stun_a → stun_b | 500 / 500 |
| sleep | sleep_a → sleep_b | 720 / 820 |

기존 유지 시간을 보존했다. 모두 후보 비교용 루프다. 쓰러짐 GIF가 다시 대기로 돌아가는 것은 재생 비교이며 실제 부활 동작이 아니다.

## 돌진의 준비 → 전진 → 접촉 → 회수

- **windup / 300ms:** 목과 가까운 앞발을 갑각 밑으로 당긴다. 가까운 뒤 지지발은 y=124에 있다.
- **move / 120ms:** 뒤 허벅지·무릎·발목이 뒤로 밀며 가까운 앞발은 앞으로 뻗는다. 새 갑각 곡면 아래 앞 어깨와 목이 이어진다.
- **attack / 200ms:** 본 갑각의 넓은 앞 어깨가 x=105…115/y=64…87 부근으로 밀려 나오는 큰 접촉 덩어리다. 머리는 x=103…117/y=88…95에서 그 아래로 당겨지고, 목은 굵은 살 면으로 어깨와 앞다리에 연결된다. 가까운 앞발은 x=88…116/y=118…124의 압축된 손목 아래 넓은 받침이며 짧은 발톱을 갖는다. 먼 앞발은 x=111…122/y=110…113의 작은 별도 발이다. 가까운 실제 발바닥은 y=124에 놓인다.
- **recover / 240ms:** 큰 접촉 어깨를 원래 곡면으로 회수하고 목을 세우며 앞발을 몸 쪽으로 당긴다. 가까운 발바닥은 y=124다. 전체 몸을 이동해 회수를 합성하지 않았다.

## 현해진의 입 앵커

좌표는 native (0,0)에서 오른쪽 x/아래쪽 y 기준이다. 이 종에는 손에 쥔 무기 발원점이 없다.

- **skill_a / 420ms:** 갑각 앞쪽의 금 홈 x=86…95/y=48…60을 따라 청금 기가 모이고 목 쪽으로 이어진다. 실제 돌 면과 금 홈에서 출발한다.
- **skill_b / 240ms:** 당긴 머리의 위턱과 아래턱 사이 x=95…102/y=72…75에 어두운 입 안과 e/w 물 출구가 있다. x=94…104/y=76에는 별도 아래턱의 C/L 면과 앞 물줄기가 있다. 짧은 청색 덩어리가 입 **안에서** 나와 x=103…112/y=71…78에서 분기한다. 위쪽은 x=103…126/y=49…74의 넓은 첫 파문, 아래쪽은 x=104…125/y=76…100의 다른 두 번째 파문으로 펼쳐진다. C/L의 물벽 그림자, e 기본면, w 물마루가 오른쪽으로 볼록한 전면을 만든다. 두 물벽 사이 빈 공간과 마지막 x=127 투명 열을 유지한다.
- **skill_c / 360ms:** 목과 머리를 낮추고 청금 기를 회수한다. 입앞 잔물 x=103…110/y=88…99, 위 찢어진 잔기 x=111…118/y=70…84, 아래 물보라 x=110…116/y=104…114는 서로 다른 세 군집이다. casting의 큰 물벽을 줄이거나 회전해 만들지 않았다.

## 상태의 원래 서로 다른 해부

- **독:** 턱과 앞발을 움츠리는 sick posture. 두 번째의 턱/목/앞발은 더 압축되고 독 거품의 크기·위치·빈 속이 다르다. 이번에는 직립 갑각 재질만 보완했다.
- **기절:** 굵은 목이 아래로 접혀 머리가 처진다. 두 번째의 눈과 턱, 이완된 목 및 두 별의 위치가 다르다. 별의 실제 겹침을 남기면서 갑각을 따로 고쳤다.
- **수면:** sleep_a 눈꺼풀은 x=96…97/y=102, sleep_b는 x=94…95/y=103이다. 실제1배에서 짧은 감긴 눈을 확인했다. 접힌 네 발과 말린 꼬리를 유지하며 두 번째에서 턱/목과 등 상단 윤곽이 작게 내려간다. 색만 바꾸는 숨이 아니다. 이번에는 두 격자를 그대로 보존했다.

GIF를 다시 디코딩해 원본 PNG의 알파와 불투명 색, 프레임 순서를 확인했다. 시간표와 GIF는 저작 후보의 비교 산출물이며 게임에서의 실제 이동·충돌·피해·소리 시점을 검증하지 않는다. 사용자 선택이나 독립 검수 통과를 뜻하지 않는다.

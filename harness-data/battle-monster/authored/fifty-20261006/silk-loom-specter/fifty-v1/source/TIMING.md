# 비단직조귀 — GIF 시간표

GIF는 native 96×96, 원본 18색과 투명 인덱스를 유지한다.
보간/합성 중간 프레임은 없다. 아래 ms는 저장된 GIF를 재읽어 확인한 표시 시간이다.
각 GIF는 검토용 무한 반복이며 쓰러짐의 마지막 유지 뒤에는 대기로 다시 시작한다.

| GIF | 원본 순서 | 각 프레임 유지 ms |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 280, 220, 120, 150, 220, 320 |
| hit | idle_a → hit → recover → idle_a | 320, 280, 220, 340 |
| dead | idle_a → hit → dead | 300, 180, 1100 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 280, 380, 340, 280, 340 |
| poison | poison_a → poison_b | 480, 480 |
| stun | stun_a → stun_b | 500, 500 |
| sleep | sleep_a → sleep_b | 700, 700 |

## 공격의 무게와 접촉

준비에서 북을 어깨로 당기고 뒤 신을 굽힌다. 전진은 치마 앞을 들어
앞발을 내놓으며 뒤 지지발로 민다. 접촉 자세는 더 뻗은 소매와 북,
앞발에 실린 무게, 뒤 발의 밀기를 갖는다. 회수에서는 북을 아래로 거두고
앞발의 간격과 치마를 가라앉힌다. 접촉은 `attack`의 150ms 유지 구간이다.

## 홍사결 앵커 — 좌표는 0부터

- `skill_a`: 북을 쥔 손은 대략 (55…57,45…47), 나무 북은 (58…63,44…46).
  반대 손의 실타래와 이 손 사이에 붉은 매듭이 모인다. 작은 매듭은
  두 손의 피부 군집에 연결되어 있다.
- `skill_b`: 전방 손은 (64…67,42…45), 북 끝은 (71…73,43…45).
  세 가지 붉은 끈의 뿌리는 (72…75,42…46)에서 이 북 끝에 닿는다.
  위 끈은 y=25까지 감겨 올라가고, 가운데 끈은 y=39…49의 짧은 굽음,
  아래 끈은 y=45…67의 긴 곡선을 갖는다. 반대 손에서 전방 손으로 감기는
  실도 직접 찍었다. 접촉/시전 최고점은 이 프레임의 340ms다.
- `skill_c`: 북을 쥔 손이 (54…57,44…46)으로 돌아온다. (52…64,47…54)의
  실을 손 쪽으로 회수하고, 더 오른쪽에는 위치/길이가 다른 끊긴 실 세 토막을 남긴다.
- 입은 이 기술의 발사 앵커가 아니다. 이 종의 도구/양손에서 실을 모으고 시전한다.

독은 480ms마다 손의 높이와 독 방울을 바꾸고, 기절은 500ms마다 떨어진 도구와 별을 바꾼다.
수면은 700ms마다 가슴과 치마 앞면이 작게 바뀌며, 닫힌 눈과 무릎 위 손/도구는 유지한다.


## 공격 실 교정 후 유지 사항

공격의 6프레임 순서와 각 유지 시간은 그대로다. `attack` 150ms 접촉 프레임만
붉은 실을 직접 다시 찍었다. 전방 손 (73…76,45…46)과 나무 북 (77…84,45…46)을
보존하고, 북 하단의 (81…82,47)에서 (79…82,48)을 지나 y=64의 실타래 가장자리
(46…52,64)까지 계단 군집이 이어진다. 드문 밝은 빨강은 실의 읽힘을 위한 고정 픽셀이며
별도의 자동 점멸이나 보간을 넣지 않았다. 홍사결의 양손/북 앵커와 3개 원본 자세,
독·기절·수면의 2프레임 순서 및 표시 시간도 보존했다.

이번 저장에서 8 GIF/28개 실제 해독 프레임의 원본 RGBA와 유지 시간이 일치했다.
이는 파일 확인 기록이며 실전 hop/타격 시점 또는 독립 시각 검수 판정은 아니다.

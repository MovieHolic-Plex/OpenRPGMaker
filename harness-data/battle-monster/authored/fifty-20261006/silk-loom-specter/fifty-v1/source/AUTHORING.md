# 비단직조귀 — 원본 후보 저작 기록

## 범위와 원본

최초 저작 기록: 이 후보의 `source/`만 작성했으며 당시 poses 폴더는 비어 있었다.
이번 교정은 이미 존재하는 기본 9자세/추가 9자세를 읽어 공격 실만 수정했다.
팔레트 18색, 기본 9자세와 추가 9자세를 각각 96×96의 완전한 ASCII 행으로 저장했다.
`.`은 투명하고 팔레트에 없다. `poses/*.pxgrid`와 `actions/*.pxgrid`가 현재 픽셀 원본이다.
저장소 코드, brief, ledger, 다른 후보, 게임 저장소는 변경하지 않았다.
사용자 승인이나 독립 검수 판정을 기록하지 않았다.

참고 `human-size.png`를 실제 열어 작은 우향 얼굴, 어깨부터 손까지의 연결,
성인형 비율을 관찰했다. 참고의 픽셀·색을 추출하거나 이미지를 재배포하지 않았다.
이 종은 96px 요괴 규격으로, 대기 본체의 세로 범위는 y=9…92이다.

## 직접 저작 방법

`author.py`와 `frames.py`에 직접 고른 ASCII 행과 짧은 좌표 문자열을 보존했다.
빈 캔버스에 리터럴 행을 기록하고 여백을 직렬화한다. 움직이지 않는 머리나 치마의
기존 행은 명시적으로 재사용했으며, 바뀌는 어깨·팔·손·옷·발·얼굴·효과는 새 행이나
좌표 문자열로 따로 선택했다. 전체 프레임 이동·회전, 보간, 수식 본체, 도형 채우기,
자동 명암, 자동 투명 구멍 보완을 사용하지 않았다.

`render.py`는 원본 한 글자를 PNG 한 픽셀로 읽고 같은 원본으로 GIF를 저장한다.
최근접 3배/4배 확대와 배경·라벨은 진단용 그림에만 쓰며 native 원본에는 없다.
재생성은 `python source/frames.py`, 이어서 `python source/inspect_render.py`이다.
두 명령 모두 결과를 이 source 안에 저장한다. 필요한 라이브러리는 Pillow이다.

## 본체와 재질

- 검은 머리와 작은 묶음머리, 금 비녀를 모든 상태에서 유지했다.
- 작은 피부 얼굴에 좁은 눈과 코 앞 볼 공간을 두었다. 목은 옷깃과 직접 이어진다.
- 자주색 저고리의 왼쪽 위 밝은 면과 넓은 소매의 어두운 안쪽을 나눴다.
- 청록 치마는 왼쪽 위 큰 밝은 면에서 아래의 꺾인 주름으로 이어지고, 오른쪽 옆면은 어둡다.
- 북은 밝고 좁은 금갈색 나무 면으로 찍고, 비녀의 더 짧은 금빛 반사와 구별했다.
- 붉은 실타래는 손의 피부색 군집과 겹쳐 쥔 모습으로, 당겨진 실은 북의 손까지 이어진다.

## 자세별 저작

대기 3장은 어깨/옷깃의 숨 변화, 쥔 손가락과 실타래, 치마 아래 주름이 다르다.
준비는 북을 어깨 쪽으로 당긴 팔꿈치, 전진은 들린 치마와 앞으로 내민 발,
접촉은 이어진 긴 소매·손·북과 뒤 지지발, 회수는 접힌 팔과 낮아진 북으로 찍었다.
피격에서는 어깨 높이, 눈 주위, 입, 배 쪽 손을 바꿨다.
쓰러짐은 옆으로 낮아진 몸과 바닥의 도구, 닫힌 눈과 치마 밖으로 나온 뒤 발을 갖는다.

홍사결 준비는 두 손 사이의 작은 실 매듭, 시전은 북 끝의 세 갈래 붉은 비단 끈,
회수는 손으로 당긴 실과 끊어진 세 잔상으로 구성했다. 시전의 위쪽 굽은 고리,
가운데 짧은 매듭, 아래쪽 긴 S자 끈은 각각 리터럴 좌표로 찍었다.

독은 낮춘 턱과 배/가슴을 감싼 손, 입 근처의 짧은 독기와 위치가 달라지는 작은 방울을
갖는다. 기절은 더 낮은 머리, 양쪽 처진 소매와 도구, 위치가 다른 금빛 별을 갖는다.
수면은 죽음보다 높은 안정된 앉은 자세, 무릎 위 두 손과 낮춘 북, 짧은 닫힌 눈꺼풀을
유지한다. 수면 두 장의 손·발·도구는 안정되게 유지하고 가슴과 치마 면만 작게 바꿨다.

## 실제 그림에서 발견해 고친 곳 — 좌표는 0부터

1. 첫 대기의 오른쪽에 달렸던 실타래를 다시 그렸다. y=48…67의 팔·손·실을
   직접 저작하여 왼쪽 소매 끝의 손과 실타래가 연결되도록 하고, 북까지의 실을 이어 놓았다.
2. 독 b, 기절 b 얼굴 패치가 볼의 오른쪽 경계를 벗어나는 것을 확대판에서 발견했다.
   독 b의 (45…50,36…40), 기절 b의 (42…46,40…45)에 한정해 눈·볼을 다시 선택했다.
3. 기절의 y=79…84에서 치마 왼쪽 면이 너무 일찍 사라져 하단이 가로로 단절돼 보였다.
   a와 b 각각의 해당 행을 다시 찍어 낮춘 손 뒤 치마의 부피를 보완했다.
   손과 북 아래 실 사이의 의도한 빈 공간은 보존했다.
4. 쓰러짐의 (10…23,86…89)에 연결된 발과 신을 찍었다. 수면 두 장의
   (29…35,90…92), (58…66,90…92)에 접힌 발/신을 드러냈다.
5. 독기 출발점을 먼 허공에서 입 가까운 (52…60,37…41)로 직접 옮겨 찍었다.
6. 홍사결 시전의 오른쪽 효과를 세 독립 경로로 다시 저작해 굽은 끈 끝 세 개를 구별했다.

## 확인한 산출물

- `poses.png`, `actions.png`: native 96px 셀의 3×3 투명 시트.
- `png/`: 각 자세 native PNG 18개.
- `contact-native-light.png`, `contact-native.png`: 실제 1배 전체 자세.
- `contact-light.png`, `contact-dark.png`, `contact-checker.png`: 세 배경 최근접 3배 확인판.
- `detail-motion.png`, `detail-status.png`: 최근접 4배 연결/얼굴 확인판.
- `gif/`: 대기·공격·피격·쓰러짐·스킬·독·기절·수면 8개.
- `gif-frames/`: 실제 저장된 GIF를 다시 읽은 프레임 비교판. 1배와 3배를 직접 열었다.
- `render-info.json`: 실제 파일 해시, 경계, GIF 노출 시간 및 원본 RGBA 일치 자료.

18개 원본은 모두 서로 다르다. 모든 캔버스는 96행×96글자이며 투명 외곽을 보존한다.
최저 픽셀은 모두 y≤92, idle_a의 신 밑창은 정확히 y=92다.
GIF 8개의 실제 28프레임을 다시 읽어 원본 RGBA와 노출 시간이 일치함을 확인했다.
투명 영역 위치 진단은 조회에만 썼다. 소매/몸 사이, 발 사이, 실 매듭 속의 빈 공간은
그림을 보고 의도한 것으로 남겼으며 자동 채우지 않았다. 테스트나 게이트는 실행하지 않았다.

## 남은 표현 한계

- 공격 실의 투명 틈은 이번 교정에서 연결했다. 실은 얇은 native 계단 군집이며,
  아주 작은 전투 표시나 치마의 어두운 부분에서는 일부 어두운 빨강의 대비가 낮을 수 있다.
- 대기·수면의 숨 변화는 의도적으로 작다. 수면은 눈꺼풀의 두 픽셀과 손/도구 높이로 읽는다.
- 기절의 압축된 치마 하단은 대기보다 주름이 적고 직선적인 면이 남는다.
- 고정된 원본 자세를 유지하므로 쓰러짐 전환은 짧게 떨어지며 중간 낙하 자세는 없다.
- 이는 검토 후보다. 실제 전투 화면 적용이나 하네스의 독립 시각 검수 완료를 주장하지 않는다.


## 이번 지적에 따른 공격 실 교정

첨부된 현재 시트와 human-size 참고를 실제 열었다. 참고는 시각 관찰에만 사용했다.
기존 팔레트 18색과 다른 17개 격자는 보존했고, `attack`만 39픽셀을 직접 바꿨다.
정확한 이전/이후 글자와 좌표는 `THREAD_REPAIR.md`에 기록했다. 원래 공격 격자와
native PNG, 교정 전 문서는 `repair-before/`에 보존했다.

- 북 아래 (81,47)에 어두운 빨강을 찍어 기존 (82,47) 실을 나무 북에 접속했다.
- y=48…55의 기존 x=79…66 대각선에는 직접 고른 2~4픽셀 행을 넣어 투명 틈을 잇고,
  (80,48), (77,50), (73,52), (70,54)에 기존 밝은 빨강 `R`을 드물게 넣었다.
- 치마 위 y=56…64에서도 기존 실의 경로를 따라 명시한 짧은 행으로 연결했다.
  y=64, x=46…52에서는 실타래 가장자리까지 잇는다. 치마 위 실은 천 색 위에 겹쳐 보인다.
- 손목/북/소매/얼굴/치마 윤곽/발의 기존 형태는 보존했다. 실과 소매 사이의 빈 공간은
  당겨진 실 아래의 의도한 공간이며 채우지 않았다. `skill_c`의 끊긴 잔상도 보존했다.
- `frames.py` 마지막에 `ATTACK_THREAD_REPAIR`의 리터럴 좌표 문자열을 보존했다.
  재저작 보조 명령으로도 이 수정이 남는다. 다른 자세로 좌표를 복사하지 않았다.

### 실제 열어 본 이번 결과

`contact-native-light.png` 및 `contact-light.png`, `contact-dark.png`,
`contact-checker.png`에서 18자세 전체를 열어 기존 관절/목/손과 도구/발을 함께 살폈다.

지적된 분절 실은 이어진 계단 군집으로 바뀌었고, 어두운 배경에서도 드문 `R` 군집으로
경로를 따라갈 수 있다. 새 신체 결손은 관찰하지 않았다. 기존 다른 자세의 가는 실은
이번 공격 지적과 같은 자동 패치 대상으로 취급하지 않았다.

8 GIF를 원본으로 다시 굽고 재읽었다. 28개 실제 저장 프레임의 RGBA와 표시 시간이
원본 및 `TIMING.md`의 순서/유지 시간과 일치했다. `gif-native-review.png`에서 실제 GIF를
해독한 28개 native 프레임을 열어 자세 전환을 살폈다. 공격→회수에서 뻗은 실이 접힌
팔로 돌아오는 변화가 있다. 이 정지 비교판만으로 실시간 재생의 체감이나 전투 접촉,
런타임 hop 적용을 확인했다고 주장하지 않는다. 쓰러짐의 중간 낙하 자세 부족과
수면/대기의 작은 숨 변화는 남아 있다.

테스트/게이트와 별도 검수자는 호출하지 않았다. 파일은 이 후보 `source/` 안에만 저장했다.
사용자 승인 또는 새로운 하네스 독립 검수 통과를 기록하지 않았다.

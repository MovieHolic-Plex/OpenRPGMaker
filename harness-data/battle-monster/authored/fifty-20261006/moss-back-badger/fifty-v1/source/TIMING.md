# 이끼등오소리 동작 시간표

64px native 원본. 모든 바닥 좌표는 y≤60, 대기 지지발 접지는 y60.
전체 프레임을 이동하거나 회전하지 않는다. GIF는 아래 원본을 그대로 유지하며
팔레트 재양자화 없이 저장한다. 리뷰용 반복이고 실제 게임 동작 코드는 아니다.

| GIF | 원본 순서 | 각 원본 유지 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240, 220, 90, 140, 180, 240 |
| hit | idle_a → hit → recover → idle_a | 280, 220, 180, 280 |
| dead | idle_a → hit → dead | 240, 180, 1100 |
| skill | skill_a → skill_b → skill_c → idle_a | 360, 240, 240, 360 |
| poison | poison_a → poison_b | 400, 400 |
| stun | stun_a → stun_b | 360, 360 |
| sleep | sleep_a → sleep_b | 600, 600 |

## 공격/기술 연결 앵커

좌표는 0부터 센다. 짐승이므로 도구/무기는 없다.

- 기본 공격은 windup에서 뒷지지발을 누르고 move에서 뒤로 뻗는다.
  attack의 near 어깨는 대략 x34..40/y46..50,
  압축된 손목은 x34..40/y53..55, 두꺼운 타격 앞발은 x34..48/y55..59,
  접촉 밑면은 x35..45/y60이다. 별도 지지 앞발은 x25..31/y54..60이며,
  두 앞발 사이 투명 틈을 남긴다. 어깨와 손목은 실제 갈색 픽셀로 이어진다.
- skill_a: 어깨 x33..41/y47..52 → 접힌 앞다리 → 손바닥 x44..50/y53..56.
  발톱/발바닥에 황토 기가 붙는다. 360ms 모으기.
- skill_b: 지지 어깨 x31..38/y47..53 → 내려친 앞발 x33..42/y55..60.
  돌 효과의 발바닥 접점은 x38..45/y57..60.
  세 갈래는 짧은 왼쪽 끝 x46/y33, 가장 높은 가운데 끝 x53/y21,
  오른쪽으로 뻗은 끝 x58/y29에서 시작해 같은 바닥 능선에 이어진다.
  접촉 최고점 240ms. 위로 솟고 화면 오른쪽으로 기울어진 돌 면이다.
- skill_c: 손목을 x44..50/y53..56으로 다시 든다.
  x50..60/y32..58에 서로 연결되지 않는 깨진 돌 조각,
  x44..48/y59..60에 낮은 흙 찌꺼기를 남긴다. 240ms 회수.
- poison은 턱 아래를 받치는 앞발을 유지하며 얼굴이 낮아진다.
- stun은 귀/목과 눈 띠를 내려놓고, 별 두 개의 위치와 크기를 직접 바꾼다.
- sleep은 낮게 웅크린 등 윗면과 가슴/이끼가 작게 움직이며 지지발은 바닥에 남는다.

GIF 파일은 `previews/`에 있다. `gif-decoded.png`는 실제 인코딩 파일에서
재읽은 연속 자세와 유지 시간을 표시한다. 개별 GIF는 투명 native64,
PNG 접촉 시트의 확대와 라벨은 관찰용이다.

## 이번 좌표 수정 후 관찰 범위

여섯 장의 해부/눈꺼풀 수정에 맞추어 8GIF를 다시 저장했다. 위 순서와 노출 시간은
유지했다. 실제 저장 파일을 디코드해 모든 프레임을 원본 RGBA와 비교하고
연속 시트를 열었다. 실시간 재생이나 런타임의 이동/충돌 시점은 검증하지 않았다.
수면은 sleep_a의 x42..43/y48, sleep_b의 x43..44/y47에 짧은 닫힌 눈꺼풀을
두며, 기존 가슴/이끼의 작은 호흡 차이를 유지한다.

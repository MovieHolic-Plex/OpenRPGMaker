## 공격 / 종손 추적

대기에서 몸 오른쪽에 내려온 종손을 준비 때 가슴 앞을 가로질러 왼쪽 뒤로 모은다. 같은 손의 소매 겹침이 오른쪽 어깨에서 앞가슴·팔꿈치·아래팔로 이어진다. 반대편 손은 끈을 지지하며 낮게 남는다.

전진은 뒤 짚신의 밀기와 두 허벅지의 벌림, 앞으로 옮긴 어깨를 새로 저작한 자세다. 타격의 접촉은 오른쪽으로 뻗은 종의 실제 청동 림과 면이다. 별도 주먹 효과나 종과 떨어진 가짜 무기를 사용하지 않는다. 회수에서 종손·소매·앞무릎을 몸쪽으로 접는다.

## 금종파 앵커

0 기반 좌표이며 각 프레임의 직접 찍은 군집을 가리킨다.

- **skill_a:** 손바닥·손가락 x=40…44, y=33…36이 청동 목과 겹친다. 종 입구의 밝은 핵은 x=42…45, y=40…41에 있다. 입구 아래 y=42…44에 붙은 작은 금빛 군집은 축적된 울림이다.
- **skill_b:** 손은 x=42…46, y=33…36, 종의 입구 핵은 x=43…48, y=39…41이다. 실제 종에서 오른쪽의 연결 군집을 거쳐 가까운 파문 x≈52…54, 먼 파문 x≈56…59로 벌어진다. 두 파문은 위끝·아래끝의 길이와 굽힘이 다르며 캐릭터 전체를 감싸는 원 오라가 아니다.
- **skill_c:** 손·종은 아래로 회수한다. 잔광 세 조각은 대략 x=57…58/y=30…34, x=51…53/y=37…40, x=55…57/y=45…48에 따로 남는다. 잔광의 틈은 의도된 투명이다.

## 상태 동작

독은 턱·소매·어깨가 실제로 압축되고 서로 다른 거품 군집이 나타난다. 기절은 머리와 팔·종이 내려오고 두 별의 위치가 달라진다.

수면은 두 프레임 모두 앉은 다리, 짚신, 무릎 위 손과 바닥에 낮춘 종을 유지한다. a의 머리 윗면 y=23에서 b의 y=24로 작은 머리·턱 군집이 내려오며, 어깨·가슴·소매의 외곽도 압축된다. 닫힌 눈꺼풀은 a의 y=33, b의 y=34에 남는다. 죽음의 엎드린 몸과 다른 앉은 휴식 자세다.

쓰러짐 GIF의 반복은 검토판의 비교를 위한 것이다. 실제 게임의 마지막 프레임 정지 정책은 변경하지 않았다.

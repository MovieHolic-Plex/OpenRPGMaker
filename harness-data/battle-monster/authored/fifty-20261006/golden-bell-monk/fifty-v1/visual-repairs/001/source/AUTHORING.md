# 금종승 — fifty-v1 원본 저작

## 범위와 원본

이 후보의 `source/` 안에만 저작했다. 기본 9자세와 추가 9자세, 18색 팔레트, 보조 코드, PNG와 8GIF를 보존한다. 사용자 선택이나 독립 검수 통과를 기록한 문서는 아니다. 별도 검수자를 호출하지 않았다.

`references/human-size.png`를 실제로 열어 성인 SD의 얼굴 크기, 작은 눈, 어깨·팔·무기 연결과 짧은 발을 관찰했다. 참고 픽셀을 추출하거나 원본을 재배포하지 않았다. 이 종의 민 머리, 회갈·황토 승복, 붉은 염주, 청동 종, 끈과 짚신은 별도로 직접 고른 ASCII 군집이다.

최종 원본은 `palette.json`, `poses/*.pxgrid`, `actions/*.pxgrid`다. 각 격자는 64행 × 64글자이며 `.`는 투명이다. `author_rows.py`에는 각 자세를 독립적으로 적은 리터럴 행과 그 행의 시작 좌표를 남겼다. 이 코드는 지정한 문자열을 빈 캔버스에 기록한다. 본체 도형 생성, 프레임 복사·변환, 보간, 자동 명암이나 구멍 채우기를 사용하지 않는다.

## 외형과 재질

- 기본 대기의 실제 잉크 높이는 y=8…60, 53px다. 얼굴 앞에 코와 볼의 피부를 남기고 작은 눈을 우향 3/4 얼굴 안에 배치했다.
- 피부는 `s/k/h`의 넓은 면, 승복은 `C/B/L/H`와 깊은 접힘 `D`, 금속은 `m/n/g/Y`의 서로 다른 면으로 저작했다. 광원은 왼쪽 위다.
- 머리 아래 피부 목과 겹친 옷깃을 연결했다. 붉은 염주는 가슴의 U형 군집이며 옷을 뚫는 투명 장식이 아니다.
- 오른손은 종의 목을 잡고, 반대 손은 끈을 지지한다. 대기의 종손은 소매 끝의 밝은 피부 → 손바닥 → 짙은 손가락 → 청동 목으로 이어진다.
- 두 짚신과 각 자세의 실제 하중 윤곽을 y=60에 직접 찍었다. 쓰러짐은 바닥의 몸통·팔 윤곽, 수면은 접힌 다리와 짚신이 접지한다.

## 자세별 직접 변경

## 실제 그림을 열어 고친 부분

좌표는 각 64px 프레임의 0 기반 좌표다.

1. 준비 자세의 y=30…39, x=16…39에서 소매 겹침과 팔꿈치를 다시 적었다. 처음 길게 뻗었던 뒤손을 몸 가까이 모으고, y=37의 오른쪽 끝 2px 돌출도 줄였다. 가슴을 가로지르는 종팔과 반대편 끈손을 구분했다.
2. `dead` y=45…46의 눈 군집을 주변 피부와 짧은 닫힌 눈꺼풀로 다시 적었다. y=56…60 오른쪽의 종에 청동 윗면·명암·하중 외곽과 손의 끈 연결을 추가했다.
3. `sleep_a` y=33, `sleep_b` y=34의 가까운 눈꺼풀을 3px, 먼 눈꺼풀을 2px로 찍고 주변 피부를 유지했다. 대기의 검은 눈 군집을 그대로 남기지 않았다.
4. 수면 두 자세의 y=52…54에 소매 끝과 무릎 위 손바닥의 피부 군집을 다시 적었다. y=58…59의 발 근처 피부색을 천과 짚신의 면으로 바꾸어 손과 발의 위치가 혼동되지 않게 했다.
5. 기절 두 자세의 y=58…60에 발목·짚신 끈·바닥 윤곽을 직접 다시 적었다.
6. 확대 PNG에 1배 그림을 겹쳐 놓으면 쓰러짐의 종 등 오른쪽 하단이 가려졌다. 진단판의 1배 그림을 별도 공간에 배치하여 모든 원본 픽셀이 보이도록 했다. 원본 격자 변형은 아니다.

밝은·어두운·체커 배경의 전체 18자세 PNG와 1배 시트를 실제로 열었다. 목·옷깃·팔꿈치·손목·종 목·허벅지·발목을 비교했고, 다리 사이와 팔 아래의 의도된 빈 공간을 유지했다. 최종 GIF는 모두 디코딩하고 재읽기 PNG를 열어 프레임별로 확인했다. `gif-readback.png`와 `.json`에 실제 내보낸 프레임 순서와 유지 시간이 남는다. 움직이는 브라우저 재생은 확인하지 않았으며, 여기서는 실제 GIF의 디코딩 결과와 노출 시간을 확인했다.

## 확인 범위와 남는 표현 한계

- `render.py`의 렌더링 과정에서 18개 격자의 크기, 팔레트 기호, 투명 테두리, y≤60 및 idle_a의 y=60 접지를 확인했다. GIF 재읽기에서 불투명 RGBA·알파와 노출 시간이 원본과 일치했다. 이것은 파일 계약 확인이며 미감 판정이 아니다.
- 공격은 네 핵심 동작을 사용하는 RM2003식 단계 표현이라 준비에서 전진으로 넘어가는 구간의 변화가 크다. 자동 중간 프레임은 만들지 않았다.
- 1배에서 끈과 종의 작은 추는 1~2px여서 확대판보다 약하게 읽힌다. 밝은 배경에서는 금빛 파문이 어두운 배경보다 낮은 대비로 보인다.
- 실제 게임 적용·전투 재생·독립 검수와 사용자 판단은 이 저작 범위에 포함하지 않았다. 테스트·게이트는 실행하지 않았다.

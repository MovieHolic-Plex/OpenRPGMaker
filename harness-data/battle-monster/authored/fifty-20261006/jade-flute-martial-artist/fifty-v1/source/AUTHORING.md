# 옥적무인 — 지적 좌표 수정 기록

## 이번 수정 범위

기존 후보의 참고 시트 `reference.png`와 크기 참고 `references/human-size.png`를 실제로 열어 보았다. 참고는 얼굴/성인 SD 비율과 관절/파지 관찰에만 사용했으며 그림에서 픽셀을 추출하거나 복제하지 않았다.

최상위 원본에서는 `actions/skill_a.pxgrid`, `actions/skill_b.pxgrid`, `actions/sleep_b.pxgrid`만 수정했다. 다른 15자세와 18색 팔레트는 보존했다. 원본은 여전히 각 64×64의 전체 ASCII 행이다. 아래 좌표는 모두 0 기반이다.

## 원본 보존과 실제 미리보기

- `history/review-repair-before/`: 이번 수정 전 세 격자와 당시 `author.py`, `AUTHORING.md`, `TIMING.md`의 사본. 기존 `history/first-pass/`도 보존했다.
- `preview/repair-1x-3x.png`: 수정한 두 기술 프레임과 수면 두 프레임을 밝은/어두운/체커 배경에서 1배 및 정확한 최근접 3배로 표시한 진단판. 실제 파일을 열어 입술/피리 접점, 닫힌 눈꺼풀, 턱/목/어깨 연결, 의도한 팔 사이 여백과 소매 외곽을 확인했다.
- `preview/native.png`, `sheet-light.png`, `sheet-dark.png`, `sheet-checker.png`: 전체 18자세도 다시 열었다. 원치 않은 새 내부 투명 사각 홈은 보이지 않았다.
- `preview/skill-decoded.png`, `sleep-decoded.png`: 새로 저장한 GIF를 다시 읽은 프레임 판도 실제로 열었다. 서로 다른 수면 눈꺼풀/턱/소매가 읽히며 손과 무릎/피리는 같은 자리에서 지지한다.
- PNG 18개, 기본/추가 3×3 시트와 8개 GIF를 `render.py`로 다시 구웠다. 유지 시간은 `TIMING.md`에 적었다. GIF 디코딩 자료는 현재 실제 파일에서 산출된 `preview/artifact-info.json`에 있으며 각 불투명 픽셀과 alpha가 해당 원본과 일치한다. 이 자료는 시각 합격이나 사용자 선택 기록이 아니다.

모든 현행 원본의 최저 잉크는 y=60이며 1px 이상 투명 가장자리를 유지한다. 수면의 최저 픽셀은 실제 접힌 다리/신발이고 효과만 접지한 것이 아니다. 파일 읽기/렌더/좌표 차이 진단만 실행했으며 테스트/게이트와 별도 검수자 호출은 실행하지 않았다. 변경 파일과 새 미리보기는 모두 `source/` 안에 있다.

## 남은 표현 한계

- 수면의 고개 끄덕임과 소매 이완은 작은 native 변화다. 1배에서도 앞눈꺼풀과 턱 위치가 달라지지만 큰 동작처럼 보이지는 않는다. 720ms씩 노출해 안정된 무릎 자세의 숨으로 보여 준다.
- 입술은 세 native 픽셀의 음영으로 표현했다. 피리 입구와 바로 연결되며 밝은 흰자를 추가하거나 얼굴 전체를 바꾸지 않았다. 실제 배경/전투 축척에서의 가독성은 별도 확인 대상이다.
- 기존 스킬의 세 갈래와 쓰러짐의 겹친 먼 다리는 작은 64px 공간에서 구분해야 하는 표현 한계가 남는다.
- 실제 전투 접촉, 상태 전환 및 게임 안 재생은 확인하지 않았다. 하네스의 새 독립 검수나 사용자 승인은 이 작업에서 만들어 내지 않았다.

아래 내용은 이전 파일에 있던 저작 이력이며, 이번 교정 내용과 충돌하는 입/수면 설명은 위 기록이 최신이다.

## 범위와 방식

이 후보의 `source/` 안에서만 새 파일을 만들고 수정했다. 시작 시 `poses/`는 비어 있었으며 9 기본 자세와 9 추가 동작을 새로 저작했다. 게임 저장소, 다른 후보, brief, 선택/검수 ledger는 수정하지 않았다. 테스트/게이트, 이미지 생성, 독립 검수자 호출은 실행하지 않았다. 사용자 승인이나 검수 통과를 선언하지 않는다.

참고 `references/human-size.png`를 실제로 열어 성인 SD 크기, 차분한 작은 눈, 몸에 붙은 팔과 손/무기 연결만 관찰했다. 픽셀 추출·추적·복제·재배포는 하지 않았다.

- `palette.json`: 투명 점을 제외한 18색. 검은 짧은 머리, 비취 머리띠/피리/허리띠, 따뜻한 피부, 회백 천, 작은 남색 신발. 광원은 왼쪽 위.
- `poses/*.pxgrid`, `actions/*.pxgrid`: 각 원본은 정확한 64×64 전체 ASCII 행. 투명은 `.`뿐이다.
- `author.py`: 직접 고른 행의 x 시작점과 문자열, 이후 좌표별 명시적 교정 문자열을 보존한다. 빈 여백을 붙여 전체 행을 저장하며, 다른 프레임을 복사하거나 변환해 자세를 만들지 않는다. 도형·회전·보간·수식 명암·자동 구멍 메우기가 없다.
- `render.py`: 원본 팔레트를 그대로 PNG/GIF로 읽어 굽는다. 최근접 확대는 진단판에만 적용한다. 네이티브 아트/모션 파일은 64px이다.
- `history/first-pass/`: 18자세 첫 완성본과 당시 팔레트/저작 코드를 보존한다. 현재 사용 원본은 이 폴더 밖의 최상위 `poses/`, `actions/`다.

## 실제로 열어 보고 바꾼 군집

1. 기본 `idle_a`를 먼저 렌더해 확인했다. 뾰족하게 길어진 볼/코 주변의 행을 직접 줄였고, 의도한 53px 키와 접지 y=60을 위해 바짓단 두 행을 저작했다. 목 피부, 교차 옷깃, 어깨와 천의 넓은 빛/그림자 면을 먼저 마무리했다.
2. 준비·전진·접촉·회수는 같은 오른손 피리를 추적한다. 뒤 지지다리의 밀기, 앞 허벅지/무릎 압축, 어깨와 소매 방향을 각각 따로 그렸다.
3. `move`의 첫 GIF에서는 피리 손이 허리 아래로 떨어졌다. y=23~32의 피리/손과 y=31~41의 소매를 새 문자열로 교정해 어깨 가까이 준비를 유지했다. y=42~47의 옛 피리는 지우고 그 위치의 앞 허벅지 천을 직접 저작했다. 손목 `(43,32)`에 피부/중간 천 면을 넣었다.
4. `attack` y=35~37, x=42~50의 손목/소매에 중간 천과 피부 겹침을 넣었다. 두 검은 외곽선의 접촉만으로 파지를 표현하지 않게 했다.
5. `skill_b`의 첫 날빛은 실처럼 얇고 작은 갈래가 섞여 있었다. 위/가로/아래 가지의 끝과 청록/밝은 중심 군집을 다시 저작했다. 준비와 발동에서 피리 길이가 달라 보이는 문제도 고쳐 `(39..49,23)`의 실제 피리 끝 다음 `(50,23)`부터 세 가지가 시작하게 했다. y=44~60은 발동 하중에 맞춘 넓은 바지/발 배열로 다시 그렸다.
6. 독 자세의 턱 손은 첫 판에서 아래팔 경로가 불분명했다. `poison_a` y=32~41, `poison_b` y=31~40의 접힌 소매와 피부 손목을 각 자세의 좌표에서 직접 다시 저작했다.
7. 수면의 첫 2px 눈 선은 1배에서 작은 열린 눈으로도 읽혔다. 두 자세의 `(26..42,33)` 눈꺼풀 행을 3px 수평 선과 얼굴색으로 교정하고 바로 아래 볼 음영을 별도로 찍었다. 동일하게 검은 눈 군집을 복사하지 않았다.
8. `dead` y=48의 닫힌 눈과 y=56~60의 두 번째 접힌 다리/작은 신발 경계를 고쳤다. 머리와 몸 사이에는 y=50~55에 실제 피부 목 부피가 남는다.
9. `hit`, `poison_a`의 마지막 신발/외곽 행을 y=60까지 직접 보완했다. 다른 모든 자세도 실제 지지 발 또는 쓰러진 몸이 y=60에 닿는다.

## 실제 이미지 확인

밝은·어두운·체커 배경의 4배 전체 시트와 1배 `preview/native.png`를 열었다. 공격/스킬의 최종 GIF를 다시 읽은 연속 프레임 판을 열었으며, 독/기절/수면/피격/쓰러짐/대기도 디코딩한 프레임 판에서 확인했다. 수정된 손·도구·목 연결, 의도한 팔/다리 사이 여백, 옷깃의 투명 결손, 닫힌 눈을 보았다. 확대 진단은 원본 픽셀의 최근접 표시다.

`preview/artifact-info.json`은 현재 실제 파일에서 계산한 SHA-256, 크기, 잉크 범위와 GIF 디코딩 정보다. 픽셀 비교는 투명 픽셀의 alpha와 불투명 픽셀의 RGBA를 비교한다. 이는 파일 형식 자료이며 독립 시각 검수나 승인 기록이 아니다.

## 남은 표현 한계 / 검수 대상

- 64px 안에 3갈래를 넣었으므로 가운데 음파는 가장 짧고 위/아래 가지는 각진 계단 윤곽이다. 실제 게임 배경에서 빛의 가독성은 별도 확인 대상이다.
- 쓰러짐은 접힌 먼 다리가 몸 아래 겹쳐 보이는 낮은 자세라 서 있는 자세보다 다리 구분이 약하다. 짧은 겹침 경계와 두 신발은 남겼다.
- 대기·수면의 숨은 작은 가슴 면 변화로 절제했다. 검토 GIF는 반복하지만 실제 게임의 상태 전환과 쓰러짐 종료는 이 작업에서 확인하지 않았다.

현재 결과는 하네스의 실제 독립 검수와 사용자 판단을 위한 후보다. 모델/검수 출처나 사용자 선택을 이 문서가 대신 만들지 않는다.

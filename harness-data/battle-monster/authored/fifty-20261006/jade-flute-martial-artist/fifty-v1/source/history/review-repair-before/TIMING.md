# 옥적무인 — native 64 동작 시간표

모든 좌표는 0 기반 `(x,y)`. 최종 원본은 `poses/`와 `actions/`의 전체 64행 × 64열 ASCII 격자다. 아래 GIF는 `preview/`에 있으며, 새로운 중간 그림을 만들지 않고 지정한 원본을 그대로 노출한다.

| GIF | 원본 순서 | 유지 시간 ms |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240 / 240 / 120 / 180 / 180 / 280 |
| hit | idle_a → hit → recover → idle_a | 240 / 360 / 200 / 280 |
| dead | idle_a → hit → dead | 240 / 180 / 1000 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 420 / 360 / 320 / 260 |
| poison | poison_a → poison_b | 500 / 500 |
| stun | stun_a → stun_b | 500 / 500 |
| sleep | sleep_a → sleep_b | 720 / 720 |

`hit`의 저작 시간표에는 같은 hit의 160+200 ms 유지가 있으며 GIF 인코더가 360 ms 한 노출로 합친다. 새 그림으로 세지 않는다. GIF는 검토를 위해 반복한다. 게임 쓰러짐 상태의 종료/유지는 하네스와 런타임이 결정한다.

## 공격의 동일 오른손

- 준비: 오른손을 목/어깨 오른쪽으로 접고 팔꿈치는 몸 가까이 둔다. 피리 축은 `(36,31)` 부근 파지에서 `(55,27)` 방향으로 보인다.
- 전진: 뒤다리는 길게 밀고 앞 무릎을 압축한다. 손바닥 `(46,31)`과 피부 손목 `(43,32)`은 회백 소매를 거쳐 어깨로 이어진다. 피리는 `(47,32)`부터 `(56,23)` 방향으로 든다.
- 접촉: 오른팔을 옆으로 펴며 `(46,36)` 손목과 `(47,37)` 손바닥이 실제 가로 피리 위에 겹친다. 피리의 가로 축은 y=38~39에 있다. 접촉 노출 180 ms.
- 회수: 앞팔을 다시 몸쪽으로 접고 다리를 회수한다. 준비/접촉에 다른 팔로 교대하지 않는다.

## 옥음살의 입·손·피리 앵커

- `skill_a`: 입 끝 `(41,23)`에서 피리 윗축 `(43..51,23)`으로 이어진다. 파지는 `(47,25)` 중심, 피부 손목과 접힌 회백 소매는 y=26~31. 청록 기는 피리 끝 `(51,23)`에 모인다.
- `skill_b`: 입 끝 `(39,23)`, 피리 끝 `(49,23)`. 준비와 같은 11px 입→끝 수평 범위를 유지한다. 손은 `(44,25)` 부근에서 y=24의 자루 아래를 받치고 소매와 이어진다. 효과 발원은 바로 다음 픽셀 `(50,23)`. 위 날빛 끝은 `(61,12)`, 가로 날빛 끝은 `(62,23)`, 아래 굽은 날빛은 `(62,33)`에서 돌아 `(52,37)`로 가늘어진다. 세 갈래 사이의 투명 틈은 의도한 것이다.
- `skill_c`: 입에서 피리를 떼고 오른손을 낮춘다. 기는 도구 끝에 남고, 그 위의 작고 끊어진 두 잔음은 떨어지는 잔상이다. 평상시 머리만 덧붙이거나 효과를 원 오라로 바꾸지 않았다.

## 상태

독: 왼손이 턱을 받치며 팔꿈치와 아래팔이 옷깃 앞에 접힌다. 두 프레임의 어깨/목과 거품 위치·수가 다르다.

기절: 무릎을 굽히고 양팔과 피리를 늘어뜨린다. 두 별의 위치와 팔/바짓단 노출이 달라진다.

수면: 앉아서 두 무릎을 접고 손을 무릎에 두며 피리를 낮춘다. y=33의 짧은 수평 닫힌 눈꺼풀은 서 있는 눈/눈썹과 다르게 저작했다. 두 프레임은 같은 손·무릎·발·피리를 유지하고 가슴의 빛 면과 입 주변으로 작은 숨을 보인다.

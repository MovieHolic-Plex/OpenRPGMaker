# 황혼부적매 — native GIF 시간표

모든 동작은 96×96 원본 프레임만 재생한다. 좌표 보간, 전체 프레임 이동, 합성 중간 자세는 없다. 팔레트 원색과 알파를 유지하며 GIF는 무한 반복, disposal=2다. 시간 단위는 ms.

| idle | idle_a 240 → idle_b 240 → idle_a 240 → idle_c 240 | 고정 발끝, 작은 목·가슴·종이 탭의 변화 |

## 부익참 발원점

손이나 무기를 가진 종이 아니다. 효과는 실제 종이 **날개 끝**에서 시작한다.

- `skill_a`: 왼쪽 깃 금빛 모으기는 (14,20)–(18,26), 먼 깃 금빛은 대략 (65,21)–(72,29). 몸의 어깨와 날개 접힘까지 종이 면이 이어진다.
- `skill_b`: 위 갈래는 실제 종이 깃의 (67,48) 부근에서 금빛 뿌리가 이어져 (91,24)까지 길게 오른다. 아래 갈래는 별도의 깃 (67,57) 부근에서 시작해 (86,78) 방향으로 굽는다. 두 날빛의 폭·방향·끝·종이 뿌리가 서로 다르다.
- `skill_c`: 접힌 날개는 (48,40) 이후 가슴에 붙어 내려오고, 주홍 잔빛/회백 종이 부스러기는 x=74–87, y=41–69에서 각각 부서진 작은 군집이다. 회수 프레임을 일반 대기로 대체하지 않았다.

## 발톱 접촉과 지면

`attack`의 먼 발은 발목에서 앞쪽 발가락으로 x≈58–78, y≈70–82에 이어진다. 가까운 발은 별도 종이 허벅지에서 x≈52–79, y≈78–92까지 이어지며 갈고리 두 끝이 안쪽으로 굽는다. 검은 발가락 사이의 투명 틈은 잡는 구조이므로 유지했다. 착지의 펼친 발바닥과 다른 배열이다.

대기·준비·회수·상태 자세는 실제 지지 발이 y=92에 닿는다. 이동은 낮은 도약을 시작하는 뒤발 밀기 프레임이라 뒤발이 아직 y=92를 지지한다. 접촉은 낮게 내려온 가까운 발톱 끝이 y=92에 닿는 순간이다. 쓰러짐은 몸/포갠 날개와 접힌 발이 y=92를 지지한다.

`previews/*-gif-frames.png`에 실제 GIF 디코딩 순서와 시간표를 보존했다. `previews/render-manifest.json`의 시간과 현재 이미지 해시는 실제 파일에서 계산한 값이다. 독립 검수·게임 내 적용·사용자 선택 정보는 포함하지 않는다.

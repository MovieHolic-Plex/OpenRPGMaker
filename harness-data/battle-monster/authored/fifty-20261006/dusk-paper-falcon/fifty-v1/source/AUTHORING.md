# 황혼부적매 — 원본 저작 기록

## 범위와 원본

이 후보의 `source` 안에만 저작했다. 기본 9자세와 추가 9자세는 각각 완전한 96×96 ASCII 격자이며, `.`은 투명이다. 팔레트는 16색, 알파는 0/255다. 모든 자세에 1px 이상의 투명 외곽이 있고 가장 낮은 잉크는 y=92이다. 대기 A의 실제 발끝이 y=92에 닿는다.

`author.py`에는 처음 선택한 행, 각 자세의 별도 행, 위치를 지정한 수정 문자열을 보존했다. 빈 캔버스의 투명 여백만 코드로 채운다. 본체·명암·효과는 리터럴 행과 명시 좌표 문자열이다. 원/다각형 래스터화, 전체 프레임 이동·회전·보간, 명암 합성, 자동 연결·구멍 채우기는 사용하지 않았다. 납품 정본은 `palette.json`, `poses/*.pxgrid`, `actions/*.pxgrid`다.

## 참고 그림 관찰

첨부된 64px 검객을 실제 열었다. 작은 검은 윤곽 속 얼굴의 밝은 면, 작은 눈, 밝은 소매와 어두운 옷의 분리, 손과 칼자루가 이어지는 실루엣을 관찰했다. 이 종에는 검객의 픽셀이나 장비를 가져오지 않았다. 참고 그림을 복사·추출·리샘플링하거나 납품 폴더에 다시 넣지 않았다.

## 종의 구조와 재질

- 오른쪽을 보는 매의 우향 3/4 얼굴, 두 금빛 눈, 앞쪽으로 걸린 검은 부리, 종이 관깃.
- 목에서 가슴으로 이어진 회백 종이 면. 왼쪽 위에 W/L, 넓은 P 기본면, M/S 그늘, D/K 접힘과 외곽.
- 앞날개는 주홍 부적 깃과 회백 종이 깃이 포개진 면, 먼 날개는 어깨에 연결된 회백 접힌 면. 글자·문양 글리프는 없다.
- 엉덩이에 연결된 부피 있는 종이 허벅지, 황갈색 발목, 검은 발톱. 착지 발은 벌어지고 공격 발은 앞으로 뻗은 발가락에서 아래·안쪽으로 굽는다.
- 공격은 웅크려 모으기 → 뒤발로 밀고 날개 펼치기 → 두 발목과 앞쪽 갈고리 발톱 접촉 → 날개·발목 접기다.
- 부익참은 실제 두 종이 깃 끝의 금빛 모으기, 위쪽으로 길게 뻗는 날빛과 아래쪽으로 굽는 넓은 주홍 날빛, 종이 부스러기 회수다. 입에서 나오는 효과나 원형 오라로 바꾸지 않았다.

## 관찰과 진단 산출물

`render.py`는 격자를 읽어 native PNG와 GIF를 굽는다. 확대는 진단판에서만 최근접 2배를 쓴다. `previews/*-inspect.png`는 밝은/어두운/체커 배경의 1배와 2배다. 18자세의 실제 검사판을 모두 열어 얼굴, 목, 어깨, 날개, 허벅지, 발끝과 의도한 틈을 확인했다.

연결 좌표 진단은 결손 위치를 찾는 데만 사용했다. 모든 몸체는 4방향 진단에서 하나의 큰 연결 요소이고, 독 기포·기절 별·종이 부스러기는 별도 효과 요소다. 진단으로 픽셀을 자동 채우지 않았다. 그림의 합격을 연결 수로 판단하지 않는다.

8개 GIF를 실제 파일로 만들고 다시 디코딩했다. `*-gif-frames.png`는 각 GIF에서 읽은 실제 프레임과 노출 시간을 1배/2배로 보여 준다. 잉크 픽셀과 알파가 해당 원본 PNG와 같음을 렌더러에서 비교했다. `render-manifest.json`은 실제 파일에서 계산한 현재 해시와 경계, GIF 시간 기록이며 승인/독립 검수 기록이 아니다.

## 남은 시각 검토점

- 검은 발톱과 부리는 매우 어두운 배경에서 K 외곽이 약해진다. D 중간 면과 금빛 발목으로 구조를 구분하도록 그렸으나 배경별 가독성은 독립 검수 대상이다.
- 펼친 종이 깃은 원래 재질에 맞춰 넓고 각진 면이다. 자연 깃털의 둥근 결 대신 부적 종이의 평평한 겹침으로 읽히는지 판단이 필요하다.
- 쓰러짐은 작은 머리가 포갠 종이 면 아래 가까이 낮아진다. 얼굴 눈꺼풀은 흐리게 그렸으며 수면처럼 위로 세운 머리와 구별된다.
- 여기서는 원본·진단 PNG·8GIF만 저작했다. 실제 게임 재생이나 독립 하네스 검수는 이 작업에서 실행하지 않았다. 사용자 승인이나 검수 통과를 선언하지 않는다.

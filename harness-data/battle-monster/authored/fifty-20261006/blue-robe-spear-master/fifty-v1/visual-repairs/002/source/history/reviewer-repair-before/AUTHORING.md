# 청포창객 — fifty-v1 저작 기록

## 범위와 원본

이 후보의 `source/` 안에서만 저작했다. 현재 원본은 `palette.json`, 기본 9장의
`poses/*.pxgrid`, 기술·상태 9장의 `actions/*.pxgrid`다. 모든 격자는 64행 × 64개의
ASCII 팔레트 문자이며 `.`만 투명하다. 팔레트는 불투명 RGB 18색이다.
게임 저장소·저장소 코드·brief·ledger·다른 후보는 수정하지 않았다.
독립 검수자를 호출하지 않았고, 사용자 선택이나 하네스 판정을 작성하지 않았다.

첨부 `references/human-size.png`를 실제 열어 얼굴 비율, 성인 SD 실루엣,
우향 작은 눈과 손/무기 겹침을 관찰했다. 참고 픽셀을 추출하거나 복제하지 않았다.
청포창객의 남청 두건, 묶은 검은 머리, 청색 도포, 회갈 바지, 검은 신발,
금빛 창날과 갈색 자루는 이 후보의 문자 행으로 새로 저작했다.
대기 본체는 y=8..60의 53px, 머리 전체 폭 약 20px, 얼굴 피부의 넓은 행은
12~14px다. 목의 피부와 겹친 옷깃, 왼쪽 위의 넓은 소매 빛 면을 먼저 정했다.

## 저작 보조 코드

- `author_rows.py`: 직접 선택한 `(y, x, "literal run")`와 자세별 교정 행.
  빈 캔버스에 이 문자열을 그대로 써서 완전한 64×64 pxgrid로 저장한다.
  얼굴/관절/주름/효과의 위치와 색은 문자 문자열에 명시되어 있다.
- `render_source.py`: 격자 해독, 원본 PNG, 확인 시트, 고정 팔레트 GIF 저장.
  원본 그림을 변형하거나 중간 자세를 생성하지 않는다.
  최근접 확대는 진단 PNG에만 사용한다. GIF는 native 64×64다.
- `inspect_source.py`: 읽기 전용 연결·투명 좌표 진단과 PNG 아틀라스 배치,
  실제 GIF를 다시 읽은 스토리보드. 자동 구멍 채우기/윤곽 변경 기능은 없다.
- `history/first-pass/`: 18장 첫 완성 단계의 원본/팔레트/저작 코드 보존.
  이 스냅샷은 사용자 승인본이나 독립 검수 결과가 아니다.

재현은 이 `source`의 부모에서 `python source/author_rows.py`,
`python source/render_source.py`, `python source/inspect_source.py` 순서다.
이 명령들은 이 후보의 `source`에만 쓴다.

## 직접 고른 자세와 교정

### 기본 9자세

대기 3장에서는 머리/발 위치를 유지하고 어깨·앞 소매와 가슴의 작은 빛 면을
따로 찍었다. 준비에서는 팔꿈치를 접어 창을 허리로 당겼다. 전진에서는 뒤
허벅지를 낮추고 뒷발로 밀며 앞무릎을 굽혔다. 접촉에서는 앞 어깨/긴 소매/
손목을 펼치고 뒷다리와 앞 허벅지를 별도로 넓게 저작했다. 회수는 두 손을
당기고 창을 다시 올리는 독립 자세다. 전체 프레임 이동/회전으로 만들지 않았다.
피격은 움츠러든 어깨, 찡그린 눈과 입, 가슴을 감싼 손이다. 쓰러짐은 바닥에
내려온 도포/접힌 바지/신발과 피부 목, 닫힌 눈을 남긴 낮은 자세다.

실제 PNG에서 확인한 뒤 다음 군집을 직접 수정했다. 좌표는 0부터 센다.

- `windup` y=37..41: 뒤집힌 창날 조각을 하나의 금빛 날로 정리하고,
  x=29..34의 앞 아래팔 면을 넣어 손목과 앞 소매를 이어 주었다.
- `move` y=36..40: 금빛 날의 위/아래 외곽과 앞 아래팔 x=29..35를 따로 수정했다.
- `idle_a/b/c` y=31..41: 앞 손을 한 자루의 축 위로 옮겨 피부 손바닥·손가락,
  소매 끝과 손 아래 갈색 자루를 각각 저작했다. 각 자세의 실제 행을 별도로
  지정했다. 두 갈래로 보이던 손 오른쪽의 짧은 자루를 없앴다.
- `attack` (31,38): 두 손 사이 창자루에 빠졌던 한 픽셀을 밝은 목재 `t`로
  직접 지정했다. 공격 팔은 넓은 위팔/아래팔 면으로 어깨에서 손까지 이어진다.
- `recover` y=39: 세 번째 손처럼 보이던 피부를 소매 겹침과 실제 창자루로 교체했다.
- `hit` y=42..49: 오른손과 닿지 않았던 창을 실제 손목/파지 위치에 맞춰 저작했다.
- `dead` y=50..57: 피부 목과 옷깃, 겹친 소매/손, 바닥에 내려온 몸의 하중
  면을 남겼다. 검은 머리와 몸을 외곽선 하나로만 붙이지 않았다.

### 기술·상태 9자세

- `skill_a`: 두 손으로 올린 창날에 청빛 핵을 모은다. 준비 파지와 자루는
  y=31..41에서 다시 정리했으며 중간의 세 번째 피부 손 군집을 제거했다.
- `skill_b`: 창끝에서 위로 길게 뻗는 밝은 중심의 물빛 창기와 아래로 짧게
  휘며 끝이 말리는 갈래를 독립 행으로 찍었다. 실제 날/효과 접점은
  x=42..47, y=35..40이다. 몸은 앞으로 누르며 발을 넓히는 자세다.
- `skill_c`: 창을 낮게 당기는 두 손과 짧은 물빛 날 잔광, 위/아래의 깨진
  잔물결이다. y=40..46에서 팔/파지/자루 축을 다시 정했다. (31..34,41)의
  직선 투명 틈은 팔 아래쪽 소매 `dbbd`, (29,43)은 옷 면 `d`로 직접 교정했다.
  별도 물 조각의 의도된 빈 공간은 유지했다.
- `poison_a/b`: 턱을 감싼 손, 굽힌 목/어깨, 다른 입과 두 독 기포의 위치/크기를
  따로 저작했다. 나머지 한 손은 낮은 창을 잡는다. 첫 그림의 배에 있던
  세 번째 피부 군집은 a의 y=44..46, b의 y=45..47에서 푸른 옷 면으로 수정했다.
  기포 내부의 투명 1~2px는 의도한 공간이다.
- `stun_a/b`: 처진 머리와 팔, 서로 다른 위치의 금빛 별, 풀린 손에 잡힌
  아래로 향한 창이다. 첫 단계의 떠 있는 창을 제거하고 y=43..58의
  손 안 자루→파지→손 아래 자루→금빛 날을 각 자세에서 직접 저작했다.
- `sleep_a/b`: 앉은 몸, 양쪽의 접힌 바지/무릎, 낮게 놓은 창과 닫힌 눈이다.
  닫힌 눈꺼풀은 y=36의 짧은 검은 가로 군집이고 그 아래 y=37은 피부다.
  두 장의 얼굴/손/무릎/창은 안정적으로 유지하며 y=46..49의 가슴과
  소매 면만 바꾸어 숨을 표현했다. 양 무릎은 y=53..60에서 넓은 회갈 면과
  별도의 짧은 신발 경계로 다시 찍었다. 죽음 자세를 재사용하지 않았다.

## 실제 열람과 출력

`rendered/sheet-native.png`의 실제 1배, `sheet-light.png`, `sheet-dark.png`,
`sheet-checker.png`의 최근접 4배를 열어 얼굴/목/어깨/손목/발과 투명을 확인했다.
8개 native GIF를 만들었고 각 GIF의 모든 디코딩 프레임과 hold를 원본 RGBA와
다시 대조했다. `gif-storyboard-light/dark.png`는 실제 저장된 GIF를 디코딩한
연속 프레임이다. GIF 순서에서 준비→전진→접촉→회수, 기술 발원점, 수면
얼굴과 무릎의 유지 여부를 확인했다.

현재 기본 본체/무기는 각 자세에서 하나의 8방향 연결 군집이다. 독의 기포,
기절의 별, 기술 회수의 물 조각은 의도적으로 분리되어 있다. 닫힌 내부 투명
좌표는 독 기포의 가운데에만 남는다. 이 연결 수치는 해부/미감 합격 판정이 아니다.
모든 현재 자세의 가장 낮은 잉크는 y=60이며 대기 신발이 그 행에 닿는다.
각 자세의 실제 source SHA-256과 진단 수치는 `rendered/diagnostics.json`에 있다.

## 남은 시각 한계

- native 64px라 파지의 손가락은 2~4px 군집이다. 어두운 배경에서는 갈색 자루와
  검은 외곽이 합쳐 보일 수 있어 독립 검수에서 1배 파지를 다시 살필 필요가 있다.
- 회수→대기의 창 각도 변화는 지정된 원본 자세 수 안에서 한 번에 바뀐다.
  추가 중간 프레임이나 자동 보간은 만들지 않았다.
- 앉은 수면의 겹친 바지는 다리를 접은 탓에 압축되어 있으며, 독 기포는
  18색 공용 팔레트의 청록색을 쓴다. 죽음/수면과 독/기술은 몸의 자세로 구별한다.

이 기록은 후보 저작과 자체 관찰 기록이다. 실제 독립 검수와 사용자 선택은 하네스가 맡는다.

# 청포창객 — 현재 후보 저작·교정 기록

## 범위와 원본

이번 작업은 이 후보의 `source/` 안에서만 이루어졌다. 첨부 전체 시트와
`references/human-size.png`를 실제 열어 성인 SD 비율, 목/소매/손/창 연결을
관찰했다. 참고 그림에서 픽셀을 추출하지 않았다.

기존 후보의 기본 9자세와 기술·상태 9자세를 보존하면서, 이번 독립 지적의
`attack`과 `skill_b`만 직접 선택한 ASCII 문자열로 고쳤다. 현재 원본은
`palette.json`, `poses/*.pxgrid`, `actions/*.pxgrid`다. 18장 모두 완전한
64행 × 64열이며 `.`는 투명, 나머지는 기존 불투명 18색이다.
대기 본체는 y=8..60의 53px 성인 SD이고 남청 두건, 푸른 도포, 회갈 바지,
검은 신발, 갈색 장창과 금빛 창날을 유지했다. 광원은 왼쪽 위다.

게임 저장소·저장소 코드·brief·ledger·다른 후보는 수정하지 않았다.
테스트/게이트와 독립 검수자 호출은 하지 않았다. 통과 판정이나 사용자 승인을
작성하지 않았다. 이 문서는 저작과 자체 시각 관찰 기록이다.

## 이번 직접 교정 — 좌표는 0부터 센다

### attack: 앞손 하나와 연속된 창자루

수정 범위는 x=40..52, y=36..40, 실제 변경 32픽셀이다.

- y=36의 x=40..42에 `dcl` 소매 끝을 남기고 x=43..47에 `feefs`를
  찍어 중간색 피부 손목에서 밝은 손등으로 이어지게 했다.
- y=37의 x=40..42는 `bcd` 소매 겹침, x=43..49는 `feeeffs`의
  하나의 앞 손바닥이다. 손목은 푸른 커프에 실제 옆 픽셀로 이어진다.
- y=38의 x=40..52는 `ttttteftstttt`다. 자루 위의 손가락을
  x=45..48에 모으고 목재 `t`를 파지 중간과 그 양쪽에 남겼다.
- y=39의 x=45..47은 `fss`의 짧은 아래쪽 파지다. 그 오른쪽의
  이전 x=48..52 피부 군집을 목재와 손 경계로 교체했다.
- y=40의 소매 아래 어두운 겹침과 투명 바깥 공간을 직접 정리했다.

기존 뒤손 x=23..31,y=38..40과 그쪽 자루는 그대로다. 앞손과 뒤손 두 개가
읽히며, 별도의 피부 섬을 손으로 남기지 않았다. 나머지 어깨/몸/다리/발과
금빛 창날은 이번 작업에서 변경하지 않았다.

### skill_b: 창끝에서 앞으로 갈라지는 물빛 창기

실제 변경 215픽셀이다. 기존 x=53..62,y=19..50의 세로로 긴 효과를
명시한 투명 문자열로 지우고, 작은 두 갈래를 각각의 행 문자열로 다시 찍었다.

- 창 뒤끝은 x=2,y=38..39까지 이어지는 밝은/어두운 목재 두 행이다.
  기존 몸, 뒤손 x=21..27 및 앞손 x=36..39의 파지는 유지했다.
- 손 앞 자루는 y=38..39에서 x=42..44까지 연속된다. 금빛 날은
  x=45..53,y=36..40에 직접 다시 저작했다. 무기 전체 가로 범위는
  이전 x=8..59와 같은 52px인 x=2..53이다. 앞쪽 여백을 확보하면서
  손 뒤의 긴 자루도 남겼다. 몸/팔/손 전체를 이동시키지 않았다.
- 실제 금빛 끝은 (53,38), 청빛 접점은 (54,38)이다.
- 위 갈래는 (54,37)의 `ulu`에서 x=55..60의 밝은 중심/푸른 물 가장자리로
  이어지고 x=62,y=31의 한 픽셀 끝까지 오른쪽 위로 좁아진다.
- 아래 갈래는 (54,39)의 `ulu`에서 x=55..61의 별도 중심/그림자 면을 거쳐
  x=61..62,y=43의 짧은 끝으로 오른쪽 아래를 향한다.
- 두 갈래 사이 x=56..62,y=37..39의 투명한 공간을 남겼다.
  오른쪽 끝을 다시 세로 띠로 연결하지 않았다.

회수 `skill_c`의 긴 창, 두 손과 깨진 잔물결은 기존 원본을 유지했다.

## 보존한 자세와 보조 코드

나머지 16격자와 팔레트는 변경 전 파일과 바이트/해시가 동일하다. 기술 준비,
독의 턱을 감싼 손과 기포 쌍, 기절의 처진 창과 별 쌍, 수면의 앉은 몸/닫힌 눈/
접힌 무릎/낮은 창을 유지했다. 수면 b에는 기존의 낮게 압축된 어깨/가슴 외곽이
남아 있다. 이번 두 지적을 고치면서 다른 자세에 좌표를 자동 전파하지 않았다.

- `author_rows.py`: 원래 자세별 문자 행과 이번 `GRIP_BRANCH_RUNS`를 보존한다.
  각 `(y,x,literal)`을 적용하고 완전한 64×64 행으로 저장한다. 수식 도형,
  자동 프레임 변형, 보간, 음영 합성이나 구멍 채우기가 없다.
- `render_source.py`: 격자를 native PNG와 고정 팔레트 GIF로 해독한다.
  최근접 확대는 확인판에만 쓴다. 실제 GIF를 다시 해독해 원본 RGBA와
  각 hold가 일치하는지도 확인한다.
- `inspect_source.py`: 읽기 전용 좌표 진단과 원본 PNG/GIF 확인판 배치다.
  연결이나 내부 투명 수치로 해부/미감 판정을 대신하지 않는다.
- `render_repair.py`: 공격/기술/수면을 실제 1배와 최근접 3배로 비교하고,
  저장된 공격/기술/수면 GIF의 프레임을 해독해 배치한다.
- `history/grip-branches-before/`: 이번 변경 전 두 격자, 저작 코드, 문서와
  18격자 해시를 보존한다. 이전 단계 원본들도 `history/` 안에 남아 있다.

재현 명령은 이 `source`의 부모에서 아래 순서다. 출력도 source 안에만 쓴다.

```sh
python source/author_rows.py
python source/render_source.py
python source/inspect_source.py
python source/render_repair.py
```

## 실제 열어 본 출력

교정 뒤 `repair-light.png`, `repair-dark.png`, `repair-checker.png`의
실제 1배/최근접 3배에서 앞손의 소매 연결과 창축, 기술의 금빛 끝/청빛 접점/
분리된 두 끝을 확인했다. `sheet-native.png`와 전체 `sheet-light.png`,
`sheet-dark.png`, `sheet-checker.png`에서도 18자세의 같은 신체 부위를 함께
살폈다. 새로 저장한 `repair-gif-frames.png`의 실제 디코딩된 공격/기술/수면
프레임으로 준비→전진→접촉→회수와 발/무기 변화, 닫힌 눈의 유지를 확인했다.
실시간 GIF 재생이나 게임 내 전투는 관찰하지 않았다.

이번 두 자세에 새로 생긴 의도 없는 투명 몸통 홈은 보이지 않았다.
원본 진단에서도 두 자세의 닫힌 내부 투명 좌표는 없다. 모든 격자는 64×64,
1px 이상의 가장자리 여백과 최하단 y=60을 유지하며 idle_a의 신발이 y=60에
닿는다. 각 실제 원본 해시는 `rendered/diagnostics.json`에 있다.
18장 native PNG와 8개 native GIF를 다시 저장했다.

## 남은 시각 한계

- 물빛 갈래는 64px 칸의 앞쪽 9px 정도를 사용하는 짧은 분기다. 두 갈래는
  앞을 향하지만 긴 투사체 이동은 이 후보에 없다. 대비가 낮은 배경에서
  밝은 끝의 가독성과 효과 규모는 새 독립 검수에서 확인할 부분이다.
- native 손가락은 몇 픽셀로 압축된다. 어두운 배경에서는 목재/검은 경계와
  검은 신발의 대비가 낮다. 실제 런타임 배경에서의 가독성은 확인하지 않았다.
- 수면의 호흡은 기존 어깨/가슴 외곽의 작은 변화이고 머리/턱 변화는 없다.
  실제 1배에서 두 장의 차이가 미묘하다. 이번 지적의 두 자세 외에는 고치지 않았다.
- 접촉에서 회수로 넘어가는 창 각도와 발 너비는 지정된 자세 사이에서 바뀐다.
  추가 중간 프레임이나 자동 보간은 없다. 런타임 접촉/타격감/재생 매끄러움은
  이 정적 PNG와 디코딩 프레임 관찰로 확인할 수 없다.

하네스의 새 독립 검수와 사용자 선택은 별도다.

# 청포창객 GIF 시간표

모든 GIF는 native 64×64, 원본 18색 + 투명 인덱스, disposal=2, 무한 반복이다.
프레임을 좌표 이동/회전/보간하지 않는다. 시간만 아래대로 유지한다.

| GIF | 원본 순서 | 각 hold (ms) |
| --- | --- | --- |
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 |
| hit | idle_a → hit → idle_a | 700 / 180 / 900 |
| dead | idle_a → hit → dead | 700 / 150 / 1700 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 300 / 300 |
| sleep | sleep_a → sleep_b | 650 / 650 |

## 攻撃の重心 / 공격 무게

준비는 앞 소매와 뒤 팔꿈치를 접어 창을 허리로 당기고 무릎을 굽힌다.
전진의 뒷발은 왼쪽으로 밀고 앞 무릎이 아래/오른쪽으로 나온다.
접촉의 앞 어깨/손목은 실제 더 펼쳐지며 앞 허벅지와 지지 뒤다리의 넓은 면을
별도로 찍었다. 회수는 창을 당기고 앞발의 너비를 줄이는 자세다.
외곽 신발의 가장 낮은 하중 행은 y=60을 유지한다.

## 청류관 앵커 (0부터 세는 native x,y)

- `skill_a`: 앞 손 파지는 대략 x=36..41, y=31..33; 허리 쪽 손은
  x=23..30, y=39..40. 두 손 사이에 한 자루가 있다.
  금빛 날과 청빛 핵은 x=53..60, y=10..16. 청빛은 실제 창날에 붙는다.
- `skill_b`: 준비에서 사용한 같은 창을 허리 높이로 내민다. 뒤 손은
  x=21..28, y=37..39, 앞 손은 x=33..38, y=36..39.
  손 앞 갈색 자루는 x=42..50,y=38..39이고 금빛 날은 x=51..59,y=36..40이다.
  실제 금빛 끝/물빛 발원점은 x=59..60,y=38이다.
  위 갈래는 x=53..62,y=19..37의 긴 굽은 흐름, 아래 갈래는
  x=56..62,y=39..50의 짧은 굽은 흐름이다. 양쪽 뿌리는 이 창끝에 이어진다.
- `skill_c`: 앞 손 x=32..38,y=40, 허리 손 x=22..29,y=41..42.
  자루를 낮은 사선으로 당긴다. 허리 뒤 자루는 x=5..27,y=44..50,
  손 앞 자루는 x=38..58,y=34..39이고 날은 x=56..61,y=31..33이다.
  실제 작은 날 잔광은 x=59..61,y=32..33에 붙어 있다.
  물 잔상은 x=58..61,y=26..29와 x=59..62,y=40..43의 별개 군집이다.
  발원점은 입이나 화면 중앙이 아닌 실제 날이다.

## 상태 루프

독은 목/입/턱 손의 변화를 420ms마다 보이며, 두 기포의 구멍은 의도한 투명이다.
기절은 이완된 팔과 낮은 창을 유지하고 별 위치를 두 장에서 따로 찍었다.
수면은 y=36의 닫힌 눈꺼풀과 y=53..60의 손/접힌 무릎/낮은 창을 고정한다.
a는 편안히 들이쉰 어깨, b는 y=44..52를 직접 다시 찍어 낮게 접힌
어깨/가슴 외곽으로 내쉬는 자세다. 외곽 경계 13픽셀의 차이와 천의 면 변화를
650ms마다 보여 준다. 머리나 몸 전체를 자동 이동하지 않았다.

`motions/timing.json`은 실제 GIF 인코더에 사용한 순서/hold다.
`rendered/gif-storyboard-dark.png`는 저장한 GIF의 실제 디코딩 결과다.
`rendered/repair-gif-frames.png`는 교정한 기술/수면 GIF의 1배/3배 디코딩 확인판이다.
이번 교정에서 순서와 hold는 유지했다. 실시간 재생과 런타임 타격감은 확인하지 않았다.
출력은 후보 관찰용이며 런타임 전투에 설치하거나 사용자 승인 기록을 만들지 않았다.

# 청동종귀 — native 96px 저작 기록

## 원본과 범위

- 기본 9자세: `poses/idle_a,b,c`, `windup`, `move`, `attack`, `recover`, `hit`, `dead`.
- 추가 9자세: `actions/skill_a,b,c`, `poison_a,b`, `stun_a,b`, `sleep_a,b`.
- 모든 `.pxgrid`는 96행 × 96개의 리터럴 ASCII 글자다. `.`은 투명이며 팔레트에 없다.
- `palette.json`의 18색을 모든 자세가 공유한다. 왼쪽 위의 W/V 녹청 빛 면, U 기본 면, T/S 그림자와 G/H 청동 반사를 직접 정했다. 얼굴 F, 외곽 K, 붉은 술 R/r/p, 진혼음 a/b, 독 기포 q를 구분했다.
- 참고 검객 PNG를 직접 열어 작은 눈, 큰 재질 면, 손에서 자루까지의 연결을 관찰했다. 참고 픽셀을 추출하거나 이 폴더에 복사하지 않았다.
- `author.py`는 직접 고른 `(x, y, ASCII 문자열)` 기록이다. 빈 native 캔버스에 해당 글자만 새기며, 바뀌지 않는 본체 픽셀은 유지한다. 원/다각형/수식 본체, 자동 명암, 프레임 회전·이동·보간을 사용하지 않았다.
- `render.py`는 원본 읽기, 직접 팔레트 렌더링, PNG/GIF 내보내기, 진단 확대·배경·라벨만 담당한다. 확대는 검토판에만 적용하며 PNG/GIF 원본은 96×96이다.
- `drafts/`에 접촉·목·고리·독 어깨 수정 전의 네 원본을 보존했다. 저작 코드에도 초안과 명시적인 후속 픽셀 문자열을 남겼다.

## 본체 설계

커다란 종 몸체가 주 실루엣이다. 종의 왼쪽은 넓고 밝은 녹청 면, 오른쪽은 어두운 청동 면으로 보인다. 비대칭 어깨와 종입의 타원형 안쪽 어둠으로 우향 3/4를 표시했다. 고리, 고리 아래 금속 목, 붉은 술, 어깨의 돌기 장식, 앞면 어두운 얼굴, 몸통 양각 문양, 청동 입구 테두리, 추와 작은 두 손을 연결했다.

발 없는 부유 요괴이므로 공격의 지지점은 종 몸체의 기울기와 굽은 팔이다. 준비·전진·접촉의 어깨선과 입구 기울기는 각각 다른 native 행으로 저작했다. 쓰러짐은 낮게 눕힌 몸과 감긴 눈, 수면은 세운 고리·낮고 압축된 몸·접힌 두 손·감긴 눈으로 구분했다.

## 실제 그림을 보고 고친 좌표

좌표는 0부터 시작한다.

1. 초기 기본 종의 폭이 좁아 보였다. `BODY_FINISH`에서 y=30..71의 어깨·배·종입을 더 넓은 리터럴 행으로 다시 썼다. 대기 본체와 손의 외곽은 x=14..75, y=9..82이다. 오른손 뿌리를 (64,70) 부근에 붙이고 추 줄을 (42,72) 부근으로 정리했다.
2. 눈 부분을 덧쓰는 좌표가 잘못되어 얼굴에 밝은 점이 추가되었다. 기본/대기/회수의 x=48, y=42..44를 전체 얼굴·윤곽 문자열로 다시 썼다. 두 눈은 대기 a에서 x=52..53과 x=57..58, y=43에 위치한다. 코와 오른쪽 볼의 어두운 여백을 남겼다.
3. 전진 자세에 이전 손의 검은 픽셀이 남았다. y=56..72의 몸·테두리를 직접 다시 쓰고 x=80..90, y=58..67의 잔여 조각을 명시적으로 지웠다. 전진 팔·손·추도 y=66..81에서 새 문자열로 마무리했다.
4. 피격 자세의 오른쪽 면과 고리 목에 이전 윤곽이 남았다. x=48, y=39..53을 단일 윤곽으로 다시 쓰고, x=29..62, y=20..24의 목 영역을 직접 지운 뒤 새로운 목과 붉은 술을 다시 찍었다. 왼쪽 양각 문양은 x=28..35, y=44..55에 이어 붙였다.
5. 초기 공격은 종추가 종입에서 떨어져 있었다. `ATTACK_CONTACT_FINISH`에서 오른손과 추 머리, 휘어진 줄을 재저작했다. 추 머리는 x=63..74, y=58..66, 접촉은 (64,60) 부근이다. 오른팔은 (66,55)에서 굽어 내려와 추를 쥔 손까지 이어진다. 왼팔은 종 아래에서 줄을 받친다.
6. 쓰러짐의 술 사이 투명 글자가 금속 면을 잘라냈다. 눈으로 확인한 목 아래 홈을 (25,70): `W`, (26,71): `VV`, (26,72): `VVV`, (24,73): `WVVVV`, (22,74): `KWWVVVV`로 직접 수정했다. 자동 구멍 채우기는 하지 않았다.
7. 독 자세 확대판에서 x=66..69, y=35..38에 예전 어깨 테두리가 남아 뾰족한 돌기와 홈으로 보였다. x=59..69, y=33..38의 명암·윤곽을 직접 다시 찍어 오른쪽 어깨 면을 이어 주고 이전 테두리를 명시적인 투명 글자로 지웠다.

## 동작별 저작

- 대기: 눈꺼풀, 술 끝, 손가락과 손목, 추의 줄과 머리가 각각 다른 클러스터다.
- 공격: 고리와 어깨를 왼쪽으로 기울인 준비, 우향 전진과 벌어진 두 손, 종입에 닿는 추, 가운데로 모이는 회수.
- 피격: 접힌 고리/어깨, 닫힌 눈과 찌그러진 입, 비대칭 팔과 비스듬한 추.
- 쓰러짐: 옆으로 낮게 내려온 종, 가라앉은 얼굴, 바닥에 놓인 손과 추. 가장 낮은 금속은 y=92.
- 진혼음: 추를 가운데서 붙잡고 청록 기를 모음 → 추와 종의 안쪽에서 오른쪽으로 이어지는 서로 다른 두 파문 → 종입의 빛 조각과 흩어진 잔광을 남기며 회수.
- 독: 가라앉은 눈과 찡그린 입, 턱을 감싼 손과 오른쪽으로 굽은 팔, 가운데 늘어진 추. 두 자세의 기포 크기·위치, 턱 손가락, 왼손과 추 머리가 다르다.
- 기절: 고리를 몸 가까이 접고 몸의 윗면을 낮춤, 늘어진 두 팔과 긴 추, 닫힌 눈. 각 자세의 별·손목·추·입을 직접 다르게 찍었다.
- 수면: 죽음과 다른 안정된 낮은 종 몸체, 세운 고리, 접힌 손, 감긴 눈. 두 번째 자세의 어깨·옆면·양각 문양·입·추에 작은 숨 변화가 있다. 문자/Z 표시는 없다.

## 확인 자료

- `previews/poses-native.png`, `actions-native.png`: 투명 1배 3×3 시트. 두 시트를 실제로 열었다.
- `previews/study-light.png`, `study-dark.png`, `study-checker.png`: 전체 18자세, 최근접 3배. 세 배경을 실제로 열었다.
- `previews/*-detail.png`: 각 자세 최근접 6배. 공격·피격·쓰러짐·모으기·독·기절·수면의 연결과 얼굴을 추가로 확인했다.
- `previews/*.gif`: 8개 동작, 원본 크기와 원본 팔레트. 렌더러가 실제 GIF를 다시 읽고 매 프레임 RGBA를 해당 원본 PNG와 비교했다.
- `previews/*-decoded.png`: 실제 GIF에서 읽은 프레임 순서와 유지 시간의 2배 진단판.
- `previews/review.html`: 8GIF와 배경 전환을 보는 로컬 검토 화면.
- `previews/format-report.json`: 실제 현재 원본의 외곽/픽셀 수/SHA-256. 검수·선택 판정이 아니다.

모든 본체는 8방향 연결 진단에서 하나의 연결 덩어리였다. 분리된 파문 끝·잔광·독 기포·기절 별은 의도적인 효과다. 고리 중심, 술과 목 사이, 굽힌 팔 안쪽의 공간은 보존했다. 연결 진단으로 픽셀을 자동 생성하거나 채우지 않았다.

## 남은 표현 한계

- 중앙 녹청 면은 1배에서 큰 단순한 색 면으로 보인다. 양각 문양과 청동 입구가 재질을 보완하지만 작은 표면 부식 묘사는 제한했다.
- 기본 9자세 안에서 피격→쓰러짐의 낙하 중간 자세가 없어 그 전환이 크게 보인다. 공격도 준비→전진에서 고리 위치 변화가 큰 편이며 중간 프레임은 만들지 않았다.
- 수면의 숨 변화는 작은 면·손·추 변화라 원본 1배에서 미세하다.
- GIF 파일과 프레임 진단판을 확인한 후보이다. 실행 게임에서의 배경/타격음/피해 시점과 결합된 움직임은 확인 범위에 포함되지 않는다.

독립 검수와 사용자 선택은 하네스의 후속 단계이다. 이 문서는 사용자 승인이나 검수 통과를 선언하지 않는다.

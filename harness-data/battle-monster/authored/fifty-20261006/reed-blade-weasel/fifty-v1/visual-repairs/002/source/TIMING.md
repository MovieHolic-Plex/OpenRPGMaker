# 갈잎족제비 — 수정 후보 GIF 시간표

현재 native64 격자를 그대로 표시한다. 자동 변형/보간/중간 자세 생성은 없다. `render.py`의 `MOTIONS`와 같은 순서와 노출 시간을 쓴다. 자체 확인용 GIF는 반복한다.

| GIF | 자세 순서 | 노출 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240 / 180 / 100 / 140 / 200 / 240 |
| hit | idle_a → hit → recover → idle_a | 300 / 240 / 200 / 300 |
| dead | idle_a → hit → dead | 240 / 160 / 1000 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 350 / 180 / 280 / 240 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 480 / 480 |
| sleep | sleep_a → sleep_b | 650 / 650 |

## 공격과 회수

`windup`은 뒤 지지다리를 굽히고 잡은 잎을 아래로 모은다. `move`에서 뒤발을 펴고 낮은 허리와 앞 어깨를 내민다. `attack`은 어깨에서 이어진 앞팔과 압축된 손목, 그 아래의 큰 앞발에서 잎을 바깥으로 펼친다. `recover`는 팔을 접어 잎과 꼬리를 되돌린다. 앞으로 나간 손/잎의 방향은 지지 앞발과 구별된다.

쓰러짐 GIF의 idle로 돌아가는 반복은 후보 비교용이다. 게임에서 부활한다는 뜻은 아니다.

## 갈엽참의 실제 손/잎 앵커

모든 좌표는 0부터 시작한다.

- `skill_a` 준비 350ms: 어깨에서 이어진 앞발은 x48–56,y41–44 부근이다. 손과 연결된 잎은 x53–60,y38–42에서 위로 꺾이고 끝의 기는 x55–58,y18–22에 모인다. 낮은 몸의 넓은 털 면과 잎의 실루엣을 함께 유지한다.
- `skill_b` 접촉 180ms: 손의 쥠은 x48–51,y45–46. 실제 잎의 공통 발원 부위는 x54–57,y43이다. 윗칼날의 밝은 몸은 y10–34에서 끝을 가지며, 가는 녹색 기 x56,y35–39와 x55,y40–42가 잎까지 내려온다. 아랫칼날은 같은 잎에서 x57,y44 → x58,y45 → x59–60,y46으로 따로 나가 밝은 몸 y47–55를 만든다. 아랫끝은 x53–55,y55. 지지 앞발과 아랫칼날 사이에는 배경이 있다.
- `skill_c` 회수 280ms: 앞팔을 접고 실제 잎을 x56–61,y51–60 부근으로 낮춘다. 손과 줄기가 남으며 위의 잔바람은 x49–60,y12–27의 작은 끊어진 군집으로 해체된다.

## 상태별 변화

- 독 420/420ms: 두 장 모두 낮은 목과 턱을 받치는 아픈 앞발, 굽힌 다리와 잡은 잎을 남긴다. 두 번째 장은 머리·어깨가 더 내려가며 독 기포는 다른 높이와 개수로 직접 찍었다. 색조 변환이 아니다.
- 기절 480/480ms: 낮게 처진 머리와 팔/잎, 짧은 다리를 유지한다. 별의 위치와 몸/어깨의 행은 두 장에서 다르다. 글자를 넣지 않았다.
- 수면 650/650ms: 옆으로 웅크린 안정 자세, 접힌 앞발/뒷발과 감긴 꼬리, 바닥의 낮춘 잎을 유지한다. 눈꺼풀 x44–45,y46은 짧은 닫힌 선이며 코 x53,y47과 분리된다. 둘째 장의 등 윗면/가슴 면으로 작은 들숨을 표현한다. 죽음 프레임을 재사용하지 않는다.

저장한 8GIF를 다시 읽어 원본 프레임 RGBA와 이 시간표를 확인했다. 1배/3배 GIF storyboard로 자세 변화와 연결을 자체 확인했다. 실제 전투의 접촉/재생 타이밍 또는 독립 검수 통과를 뜻하지 않는다.

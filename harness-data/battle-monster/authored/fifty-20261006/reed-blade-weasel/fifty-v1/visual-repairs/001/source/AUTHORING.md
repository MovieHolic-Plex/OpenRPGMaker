# 갈잎족제비 — native64 직접 도트 저작

## 범위와 원본

- 이 후보의 `source/` 안에만 파일을 작성했다. 저장소 코드, brief, 원장, 다른 후보, 프로젝트 저장소는 수정하지 않았다.
- `poses/` 9개와 `actions/` 9개는 각각 64행 × 64글자의 완전한 ASCII 팔레트 격자다. `.`만 투명이며 팔레트에는 없다.
- `palette.json`: 불투명 18색. 털은 황갈 기본면 / 황금빛 윗면 / 갈색 아래면, 턱·가슴은 따뜻한 흰색 / 누런 그림자다. 갈잎에는 녹색 3색, 갈엽참에는 연녹 기, 독에는 보라 기포를 사용했다.
- `author_native.py`의 각 자세는 독립적으로 적은 `y x ASCII문자열` 목록이다. 같은 부위를 유지할 때도 해당 자세의 행을 명시했다. 별도의 `PATCHES`에 이미지 확인 후 직접 고른 좌표 수정을 남겼다. 캔버스 초기화와 이 문자열의 기록만 수행하며, 본체 수식·도형·프레임 복사·이동·회전·보간·자동 음영·구멍 메우기는 없다.
- `render.py`는 완성 격자를 읽어 PNG와 GIF를 만든다. 최근접 확대는 진단판에만 사용한다. GIF는 원본 팔레트를 직접 사용하며 프레임 색상 양자화나 자세 합성을 하지 않는다.

## 참고 그림 관찰

첨부 `human-size.png`를 실제로 열어 보았다. 작은 눈과 코 사이의 얼굴 여유, 옷의 넓은 명암면, 팔에서 손과 무기로 이어지는 연결, 64px 안에서 발까지 읽히는 크기를 관찰했다. 사람의 피부·모자·검 픽셀을 추출하거나 족제비 그림으로 옮기지 않았다. 참고 원본은 이 `source`에 복사하지 않았다.

## 실루엣과 해부

오른쪽을 보는 긴 허리, 작은 귀 두 개, 검은 눈과 돌출된 검은 코, 흰 턱·가슴, 왼쪽으로 길게 굽은 꼬리다. 대기 본체는 가장자리의 작은 장식에 의존하지 않고 x4–58, y15–60 안의 넓은 털 면을 차지한다. 빛은 왼쪽 위에서 온다.

서 있는 그림에는 가까운 뒷다리의 넓은 허벅지와 꺾인 발목, 몸 아래 갈색 먼 뒷다리, 가슴에서 내려오는 지지 앞다리, 어깨에서 앞으로 이어져 잎을 잡는 다른 앞발을 따로 저작했다. 가슴의 흰색이 지지 앞다리로 이어지며 발목과 발끝에는 갈색 면이 있다. 목에서 가슴을 가로로 지우거나 도구를 손 밖에 띄워 놓지 않았다.

공격의 몸통은 전체 그림의 변형으로 만들지 않았다. 준비에는 허벅지를 접고 잎을 뒤로 낮췄다. 전진에는 뒤 지지발에서 골반으로 이어지는 다리를 펴고 허리를 낮추며 어깨를 앞으로 보냈다. 접촉에는 팔꿈치–손목–앞발의 새 면과 몸 밖으로 펼친 잎을 찍었다. 회수에는 팔을 아래로 접고 꼬리와 목을 세운다.

피격에는 뒤로 물러난 머리와 감긴 눈, 기울어진 목·어깨를 찍었다. 쓰러짐은 낮은 옆누움으로, 접힌 다리 경계·짧은 발끝·꼬리 끝·놓인 잎을 유지했다. 수면은 더 높은 안정된 웅크림과 몸 아래로 감기는 꼬리다. 다리 사이와 배 아래의 빈 공간은 의도한 공간이며 자동으로 채우지 않았다.

## 실제 그림을 열고 수정한 좌표

좌표는 0부터 시작한다. 모든 수정은 저작 보조 원본에도 남아 있다.

1. 대기 세 장의 지지 앞다리 `x39–45, y46–55`: 처음의 가는 기둥에서 위팔·팔꿈치의 6px 면과 아래쪽 5px 면으로 넓혔다. 발목의 꺾임과 발끝은 유지했다.
2. `attack`, `x45–62, y48–57`: 몸 쪽으로 말려 지지다리와 겹치던 잎을 직접 지우고, 앞발 아래의 덩어리와 오른쪽 바깥으로 휘는 잎을 새 문자열로 찍었다. 원래 손과 어깨 연결은 유지한다.
3. `skill_a`, `x55–61, y30–37`: 얼굴과 겹치던 잎의 중간 면을 오른쪽으로 다시 저작했다. 끝과 손 앵커는 유지하고 사이의 잎 곡률을 직접 정했다.
4. `skill_b`, `x53–62, y39–43`: 코·턱 외곽을 덮던 기의 면을 밖으로 고쳤다. 잎에서 상단의 긴 칼날과 하단의 짧은 칼날이 나가는 갈래는 손까지 이어진다.
5. `poison_a`, `x50–61, y40–53` / `poison_b`, `x51–62, y41–54`: 턱을 받치는 아픈 앞발에 잎을 다시 연결했다. 두 장의 기포 위치와 목·어깨는 따로 찍었다.
6. `dead`, `x42–59, y57–60`: 접힌 앞발 옆에 내려놓은 잎을 추가했다. `x46,y52`의 눈 밑 남은 어두운 점은 얼굴색으로 고쳤다.
7. `sleep_a/b`, `x46,y47`: 닫힌 눈 아래의 사선 검은 점을 털색으로 바꿨다. 눈꺼풀은 `x44–45,y46`의 짧은 수평 두 픽셀이고 코는 `x53,y47`에 별도로 있다. `x50–61,y58–60`에는 낮춘 잎의 넓은 면을 찍었다. 두 장의 발·꼬리·눈 배열은 같다. 등과 가슴의 작은 면으로 숨을 표현한다.

## 확인 자료

- `previews/sheet.png`: 투명 배경의 native64 3열 × 6행 PNG.
- `previews/<자세>.png`: 18개의 원본 1배 PNG.
- `previews/contact-light.png`, `contact-dark.png`, `contact-checker.png`: 세 배경 최근접 4배 확인판. 실제로 열어 윤곽, 목과 가슴, 팔/잎 연결, 다리 사이 빈 공간, 눕거나 접힌 발·꼬리를 확인했다.
- `gifs/`: 대기·공격·피격·쓰러짐·스킬·독·기절·수면의 8개 GIF.
- 저장한 GIF를 다시 열어 각 프레임 RGBA와 노출 시간이 원본과 일치하는지 확인했다. `gif_storyboards.py`로 그 실제 GIF 프레임을 1배와 최근접 3배로 나란히 표시한 `previews/gif-storyboard-combat.png`, `gif-storyboard-actions.png`도 실제로 열어 확인했다. 그중 수면 눈은 1배에서 코와 떨어진 짧은 선이다.
- `preview.html`은 같은 8GIF와 PNG를 보는 로컬 후보 확인 화면이다.
- `previews/render-report.json`은 렌더러의 잉크 경계와 픽셀 수 기록이다. 모든 자세의 외곽 1px은 투명이고 가장 아래 잉크는 y60 이하이다. 대기 `idle_a`의 실제 발바닥은 정확히 y60에 있다.

## 남은 시각적 한계와 판정 상태

- 작은 먼 뒷다리는 갈색 아래면과 가까워 어두운 배경의 1배에서 대비가 낮다. 밝은 배경에서는 무릎과 짧은 발끝이 더 잘 읽힌다.
- 접촉 잎과 기술 칼날이 오른쪽 x62까지 사용하므로 한 픽셀 여백은 있으나 오른쪽 공간이 좁다.
- 수면과 쓰러짐의 먼 다리 일부는 가까운 접힌 다리에 가려진다. 각각의 드러난 면과 발끝 경계를 유지했지만 네 발을 모두 펼친 자세와 같은 가독성은 아니다.
- 기술의 긴 윗칼날은 작은 화면에서 굽은 리본처럼도 보일 수 있다. 하단 칼날의 짧은 갈래와 손/잎의 앵커로 두 베기 방향을 구별했다.

이는 작가의 자체 이미지 확인 기록이며 독립 검수 결과 또는 사용자 승인 기록이 아니다. 하네스의 실제 독립 검수와 판정을 기다리는 완성 후보다. 모델명·해시·keep/Allow 기록을 만들어 넣지 않았다. 게임 실행이나 저장소 테스트/게이트는 수행하지 않았다.

# 갈잎족제비 GIF 시간표

64×64 원본 프레임을 그대로 사용한다. 보간 프레임은 없다. 아래 시간은 `source/gifs/` 자체 확인용 GIF의 실제 노출 시간이며 `render.py`의 `MOTIONS`와 같다. 모든 GIF는 반복 재생한다. 쓰러짐의 반복 시작은 후보 비교용이며 게임의 부활 동작을 뜻하지 않는다.

| GIF | 자세 순서 | 노출 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240 / 180 / 100 / 140 / 200 / 240 |
| hit | idle_a → hit → recover → idle_a | 300 / 240 / 200 / 300 |
| dead | idle_a → hit → dead | 240 / 160 / 1000 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 350 / 180 / 280 / 240 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 480 / 480 |
| sleep | sleep_a → sleep_b | 650 / 650 |

## 공격의 접촉

`windup`은 뒤 지지다리를 굽히고 잎을 몸 뒤 아래로 모은다. `move`에서 뒤발이 밀고 긴 허리가 앞으로 낮아진다. `attack`에서 앞으로 나간 어깨와 팔의 연결을 유지한 채 압축된 손목 아래 앞발이 잎을 바깥으로 펼친다. `recover`는 팔을 접어 잎을 아래로 거두고 목과 꼬리를 다시 세운다. 전체 몸 이동으로 프레임을 만들지 않았다.

## 갈엽참 — 손·갈잎 앵커

0부터 시작하는 원본 좌표다.

- `skill_a`: 앞발은 대략 x48–53,y41–44에 있다. 잡은 잎의 줄기는 x51–53,y39–42에서 손과 이어진다. 잎은 위로 휘어 x53–61,y20–37을 지나고, 끝의 연녹 기는 x55–58,y18–20에 모인다. 준비를 350ms 유지한다.
- `skill_b`: 전진한 앞발에서 잎과 기가 만나는 앵커는 대략 x54,y44이다. 오른쪽에 긴 윗칼날과 짧은 아랫칼날을 서로 다른 행과 군집으로 저작했다. 윗칼날은 y5까지 올라가고 x62 부근에서 굽어 내려온다. 아랫칼날은 손 아래에서 갈라져 y58까지 휘어 끊긴다. 입이나 빈 캔버스 중심에서 효과를 만들지 않는다. 접촉 180ms.
- `skill_c`: 같은 앞발이 잎을 다시 낮춰 쥔다. 잎은 x50 부근,y51부터 아래로 내려온다. 위쪽 기는 (57,12), (50,17), (56,21), (59,26) 부근의 작은 서로 다른 파편으로 해체된다. 280ms 동안 회수하고 대기로 돌아간다.

## 상태의 프레임 차이

- 독: 턱을 받치는 앞발과 움츠러든 목·어깨, 내려간 허벅지를 직접 찍었다. 기포는 첫 장의 x54–61,y21–31에서 둘째 장의 x52–62,y17–35로 각각 다른 배열이다. 잎은 계속 손과 연결된다.
- 기절: 머리와 잎·팔이 아래로 처진다. 별은 첫 장에 x31–37,y17–21와 x49–55,y23–27, 둘째 장에 x43–49,y19–23와 x26–32,y24–28이다. 별과 몸의 색을 통째로 바꾸지 않았다.
- 수면: 앉듯이 웅크린 몸과 감긴 눈, 접힌 앞발·뒷발, 몸 아래로 돌아오는 꼬리와 낮춘 잎이다. 눈꺼풀 x44–45,y46과 코 x53,y47은 분리했다. 두 장의 발·꼬리·눈은 유지하며 둘째 장의 등 윗면과 작은 가슴 면만 숨에 맞게 직접 다르게 찍었다.

저장된 8GIF의 모든 프레임을 재로드했으며, 원본 RGBA와 위 노출 시간의 일치를 확인했다. 실제 GIF에서 뽑은 1배/3배 그림을 열어 순서별 관절·잎 위치와 자세 변화를 확인했다. 런타임 전투 적용이나 독립 검수의 승인 상태를 의미하지 않는다.

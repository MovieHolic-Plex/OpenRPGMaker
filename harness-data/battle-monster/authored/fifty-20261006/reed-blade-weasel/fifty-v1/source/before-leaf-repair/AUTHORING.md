# 갈잎족제비 — 지정 좌표 교정 기록

## 원본과 저작 방식

이 문서는 수정한 후보의 작가 확인 기록이다. 독립 검수의 통과나 사용자 승인을 선언하지 않는다.

- `poses/` 9자세와 `actions/` 9자세를 모두 64×64의 완전한 ASCII 행으로 저장했다. `.`은 투명이다.
- 원안 격자·팔레트·당시 문서는 `original/`에 보존했다. 황갈색 털, 흰 턱/가슴, 작은 검은 코, 굽은 긴 꼬리, 녹색 갈잎의 정체성과 18색 팔레트를 유지했다.
- `author_native.py`는 원안 저작 보조 코드다. 이번 수정의 직접 고른 행/좌표 문자열은 `repair_native.py`의 `REVISED`와 `DETAILS`에 있다. `python source/repair_native.py`는 보존된 원안에 그 문자열을 기록하여 현재 격자를 재작성한다.
- 각 자세의 머리·허리·다리·손·잎·기 배열을 해당 자세의 좌표에서 따로 적었다. 다른 자세로 좌표를 자동 복사하거나 몸 전체를 이동/회전/보간하지 않았다. 형상 수식, 자동 음영, 자동 구멍 채우기를 사용하지 않았다.
- `render.py`는 완성 격자에서 PNG/팔레트 GIF와 진단 확대·배경·라벨만 만든다. 확대본을 저작 원본으로 사용하지 않는다.

## 참고 관찰

작업 전에 첨부한 현재 18자세 시트와 자체 검객 참고 이미지를 실제로 열었다. 현재 시트에서 높은 다리/짧은 등/큰 뾰족귀, windup의 발목 틈, skill_b의 긴 S 띠를 확인했다. 검객은 native64 크기에서 얼굴·명암면·손과 도구 연결이 읽히는 정도를 관찰했다. 참고 픽셀 추출·추적·리샘플링·참고 이미지 재배포는 하지 않았다.

## 지적별 직접 수정

### 1. 길고 낮은 허리와 작은 귀

- `idle_a`: 기존 x40/46,y21 귀 꼭짓점 대신 x40–42,y25의 작은 둥근 윗면, x39–42,y26의 귀 안쪽, x46–47,y26의 먼 귀를 찍었다. 머리는 얕은 이마와 앞으로 긴 주둥이로 정리했다. 눈 x44,y32와 코 x54,y34는 떨어져 있다.
- x24–38,y37–40의 긴 등과 윗면 빛, x20–42,y43–49의 낮은 옆구리/배를 직접 저작했다. 밝은 윗면→황갈 기본면→갈색 아래면으로 부피를 유지한다. 가까운 허벅지는 x22–29,y49–53, 먼 다리는 x32–39,y50–57의 더 어두운 면과 경계로 구분한다. 발은 y60에 닿는다.
- `idle_b/c`, `recover`, `hit`, `skill_a/c`, `poison_a/b`도 각자의 낮은 몸통/짧은 다리/작은 귀를 별도 문자열로 수정했다. 대기 세 장의 발 접지는 유지하고, 등과 잎·꼬리의 작은 변화는 각 장에 따로 남겼다.
- 이미 낮고 긴 `move`, `attack`, `skill_b`는 돌격 실루엣을 유지하면서 둥근 귀, 낮은 배의 면, 먼 허벅지와 전진한 어깨를 보완했다. 준비는 접은 뒤 지지발, 전진은 편 뒤발, 접촉은 앞으로 나온 어깨/손목/앞발, 회수는 접은 팔을 보여 준다.
- `stun_a/b`는 기존 처진 몸과 낮춘 잎을 유지하고 귀·얼굴·어깨 면을 따로 정리했다. `dead`, `sleep_a/b`는 이미 긴 낮은 몸, 접힌 발 경계, 꼬리와 닫힌 눈을 보존하고 귀 주변 몇 행만 수정했다.

### 2. windup의 먼 다리와 발

- x33–37,y53에 `ObbsO`를 직접 찍었다. 특히 x34–36,y53은 `bbs`이며 위의 무릎과 아래의 발목을 잇는다.
- y54–58의 발목/발 경계를 직접 그려 y59–60의 발바닥 x30–34까지 이어지게 했다. 가까운 뒷발 x17–24,y59–60은 별도 경계로 유지했다.
- 잎은 손 x40–44,y53에서 내려와 x43–48,y54–58을 지나 끝 x43,y60으로 거둔다. 발바닥과 잎 사이에는 배경이 있다. 잎이 발목 연결을 대신하지 않는다.

### 3. skill_b의 두 바람 칼날

- 원안의 y5–58에 이어진 밝은 S 띠를 지우고 두 칼날과 잎의 발원점을 따로 저작했다.
- 윗칼날: 끝 x48–49,y10부터 오른쪽으로 굽어 x60–62,y23–27을 지나, 아래 끝 x56–58,y34로 가늘어진다. 밝은 칼날은 여기서 끝난다. x56,y35–39 → x55,y40–42의 가는 녹색 기가 실제 잎으로 이어진다.
- 실제 잎/공통 발원 부위는 x54–57,y43의 `glhg`다. 손은 x48–51,y45–46에서 그 잎을 잡는다. 몸·어깨·팔·손·잎은 실제 격자에서 이어져 있다.
- 아랫칼날: 잎 끝 x57,y44 → x58,y45 → x59–60,y46의 가는 줄기에서 따로 굽어진다. 밝은 몸은 x60–62,y47–48을 거쳐 x53–55,y55의 독립 끝으로 내려간다. 윗칼날과 크기·곡률·끝 위치가 다르다.
- 아랫칼날은 지지 앞발 x38–43,y48–60과 떨어져 있다. 종전처럼 밝은 면이 발목을 덮지 않는다.
- 준비 `skill_a`의 올라간 실제 갈잎과 모인 기, 회수 `skill_c`의 손에 남은 갈잎과 깨진 잔바람은 보존했다.

### 이미지 확인 후의 추가 교정

- 첫 수정판을 열어 `move`/`attack`에서 잎이 지지 앞발과 겹치는 것을 보고 잎과 다리를 각 행의 명시 좌표로 다시 분리했다. `move`의 잎은 대략 x49–55,y48–57, `attack`의 펼친 잎은 x53–62,y48–57에 있다. 손까지 이어지고 지지 다리와의 배경 틈이 읽힌다.
- windup의 발과 잎을 나눌 때 가까운 뒷발이 지워진 중간 결과를 실제 PNG에서 발견했다. x17–28,y53–60의 무릎/발목/발 행을 직접 복원한 뒤 PNG와 GIF 프레임을 다시 열었다.
- 격자 문자열 일부가 오른쪽 x63에 닿는 중간 오류는 해당 자세의 잎 좌표를 직접 고쳤다. 최종 모든 잉크는 x1–62,y1–60 안이다.
- 수면 두 장의 닫힌 눈꺼풀 x44–45,y46과 검은 코 x53,y47은 유지했다. 눈 아래 x46,y47은 얼굴색이다. 두 장의 접힌 발과 감긴 꼬리는 같고 등/가슴의 작은 변화로 숨을 표현한다.

## 자체 PNG/GIF 확인

- `previews/review-light.png`, `review-dark.png`, `review-checker.png`: 18자세 각각의 실제 native 1배와 최근접 3배를 실제로 열었다. 수정 후 머리/목/어깨, 가까운/먼 다리, 손/갈잎, 바람 갈래, 접힌 발/꼬리, 수면 눈을 확인했다.
- `previews/<pose>.png`와 `sheet.png`: 투명 native PNG 원본.
- `gifs/`: 대기·공격·피격·쓰러짐·스킬·독·기절·수면 8GIF를 현재 격자로 다시 만들었다. 원본 RGBA와 저장 GIF의 각 프레임, 실제 노출 시간을 렌더러에서 다시 읽어 확인했다.
- `gif_storyboards.py`: 실제 저장 GIF에서 프레임을 읽어 1배/3배로 나란히 보여 준다. 두 storyboard PNG를 실제로 열어 준비→전진→접촉→회수, 기/독/별의 변화와 수면의 작은 숨을 확인했다.
- `previews/render-report.json`: 잉크 경계/수 기록. 18장의 팔레트·크기·투명 테두리를 렌더링할 때 확인했고 idle_a의 발바닥은 정확히 y60이다. 이 파일은 미감 판정이 아니다.

## 남은 시각적 한계

- 어두운 배경에서 짙은 윤곽과 먼 다리의 갈색 아래면은 대비가 낮다. 발끝의 밝은 갈색과 다리 경계를 유지했지만 가까운 다리만큼 눈에 띄지는 않는다.
- 윗바람 칼날과 아랫바람 칼날은 이 64px 셀의 오른쪽 x62까지 사용한다. 서로 다른 끝과 밝은 면/가는 발원 줄기를 나눴으나 여유가 좁고, 아주 작은 표시에서는 가는 기 줄기를 알아보기 어려울 수 있다.
- 정지 PNG와 저장 GIF의 프레임 순서만 자체 확인했다. 실제 전투 재생, 접촉 판정과 런타임 적용은 확인하지 않았다.

18자세/8GIF가 있는 수정 후보를 남긴다. 하네스의 새 독립 검수 결과는 아직 받지 않았다. 검수 결과/원장/사용자 선택을 작성하지 않았으며 테스트/게이트를 실행하지 않았다.

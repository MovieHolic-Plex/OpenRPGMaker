# 갈잎족제비 — 갈잎 동작 지정 교정

## 범위와 원본

이번 작업은 기존 후보의 `windup`, `attack`, `skill_b` 세 격자만 직접 수정했다. 나머지 15자세와 18색 팔레트는 유지했다. 모든 `poses/` 9장과 `actions/` 9장은 완전한 64×64 ASCII 행이다. `.`은 투명이며 팔레트에 없다.

- 이전 저작 원본과 당시 문서/보조 코드는 `original/`에 있다.
- 이번 교정 직전 세 격자와 팔레트/문서는 `before-leaf-repair/`에 별도로 보존했다.
- 기존 `author_native.py`, `repair_native.py`를 보존했다. 이번에 직접 선택한 픽셀 문자열은 `repair_leaf_native.py`의 `PATCHES`에 있다. 이 코드는 교정 직전 격자를 읽고 해당 좌표의 명시 문자열만 기록한다. 출력 `.pxgrid`는 전체 리터럴 행을 포함한다.
- 본체 이동/회전/보간, 도형 생성, 수식 음영, 자동 구멍 채우기, 다른 자세로 좌표 복사를 하지 않았다. 렌더링 확대는 진단용이다.
- 후보 그림을 교정한 기록이며 독립 검수 판정이나 사용자 승인을 뜻하지 않는다.

## 참고 관찰

첨부한 현재 18자세 시트와 64px 검객 이미지를 먼저 열었다. 시트의 긴 황갈색 허리, 흰 턱/가슴, 작은 검은 코, 굽은 꼬리, 연결된 다리와 왼쪽 위 털 빛 면을 관찰했다. 검객은 원본 크기에서 얼굴과 손/도구가 읽히는 정도만 참고했다. 참고 이미지에서 픽셀을 추출하거나 추적하지 않았으며 참고 이미지를 source에 복제하지 않았다.

## 직접 수정한 군집

좌표는 0부터 시작한다.

### windup — 뒤로 당긴 앞발과 갈잎

- 어깨 x41–46,y43 → 굽힌 팔 x38–45,y44 → 쥔 발 x36–43,y45–46을 황갈색/밝은 털/갈색 아래면과 짙은 경계로 직접 찍었다. 쥔 발은 가슴보다 뒤인 왼쪽에 놓인다.
- 잎 밑동 x36,y44에서 x35,y42–43으로 이어지고, 잎 면은 x26–37,y31–40을 지나 뒤쪽 위 끝 x25,y29까지 뻗는다. 준비 잎은 몸 뒤쪽으로 기울며 등 위로 드러난다. 아래로 매달린 잎과 다른 방향이다.
- 옛 잎 x43–48,y54–58과 y59–60의 끝을 지웠다. 앞발 끝 x44,y53은 녹색 대신 짙은 털 경계로 마감했다. 기존 뒤 지지발과 먼 무릎/발목은 유지했다.
- 첫 PNG 확인에서 y59,x44와 y60,x43에 옛 잎의 녹색 잔여점이 남은 것을 발견해 그 두 좌표를 직접 투명으로 교정했다.

### attack — 오른쪽으로 펼친 베기

- 기존 긴 허리와 뻗은 뒷발, 지지 앞다리를 유지하고 어깨 밖 팔/압축된 손목/쥔 앞발을 x45–51,y44–48에 다시 찍었다. 발의 털 면과 밑 경계를 남겼다.
- 쥠과 연결된 잎 밑동 x49–52,y46–47에서 넓은 녹색 잎 면 x54–61,y44–45로 이어지고 오른쪽 위 끝 x62,y42에 도달한다. 명시한 `glhhlllg` 등 행으로 밝은 잎맥과 어두운 밑면을 나눴다.
- 종전 y49–57에 내려가던 잎을 지웠다. 준비의 뒤쪽 위, 이동의 아래쪽, 접촉의 오른쪽 위라는 서로 다른 방향을 유지했다.
- 첫 확인 뒤 잎 면을 더 길게 펼치고 y47의 이전 녹색 마디도 직접 정리했다. 몸통이나 전체 프레임을 옮기지 않았다.

### skill_b — 실제 잎 면과 두 칼날의 발원

- 손 x48–51,y45–46 바깥에 줄기 x52–55,y43–45, 잎 면 x55–61,y38–42, 실제 잎 끝 x59,y37을 남겼다. 이전의 작은 녹색 마디 대신 1배에서도 구분할 수 있는 잎맥/잎 면을 직접 찍었다. 검은 코와 흰 턱은 덮지 않았다.
- 윗칼날의 기존 밝은 곡선 끝 x56–58,y34에서 x57,y35 → x58,y36 → 실제 잎 끝 x59,y37으로 발원 줄기를 이어 찍었다.
- 아랫칼날의 새 시작은 같은 잎 끝에서 x60,y37 → x61,y38 → x62,y39–44 → x61,y45 → x60–61,y46이다. 기존 밝은 아랫칼날 y47–55로 연결된다. 둘은 곡률과 길이가 다르다.
- 옛 발원 줄기 x55,y40–42와 작은 녹색 마디 부근, y44–46의 중복 기 점을 명시 문자열로 지우고 새 잎/줄기에 맞췄다. 지지 앞다리와 효과 사이의 빈 공간은 유지했다.

## 실제 이미지 확인

`render.py`로 18장의 native PNG, 시트, 밝은/어두운/체커 배경의 1배+최근접 3배 시트와 8GIF를 갱신했다. 렌더러는 64행/64열, 팔레트 글자, 투명 테두리, 최하단 y≤60과 idle_a의 y60 접지를 확인했다. 저장 GIF의 프레임 픽셀과 노출 시간을 원본에 대조하는 기존 렌더링 진단도 완료했다. 테스트/게이트는 실행하지 않았다.

- 세 배경의 18자세 PNG를 실제 열어 얼굴/목/어깨, 꼬리 밑동, 등 빛 면, 사지 경계, 손과 잎을 비교했다. 기존 자세에서 같은 갈잎 발원 결손을 새로 발견하지 않았다. 상태 자세와 수면의 닫힌 눈은 그대로 유지했다.
- 첫 시트 확인 후 준비의 남은 녹색 끝과 공격/기술의 잎 주변 군집을 다시 직접 교정했다. 마지막 체커 시트 및 밝은/어두운 시트를 다시 열었다.
- `gif_storyboards.py`가 실제 저장한 8GIF의 모든 프레임을 다시 읽어 만든 두 storyboard를 실제 열었다. 준비→전진→접촉→회수와 기술의 준비→두 갈래→잔상 순서, 독/별 변화, 수면의 작은 숨 면을 비교했다. 전체 몸 자동 변형이나 중간 프레임 합성은 없다.

## 남은 시각적 문제와 확인 한계

- 가슴 아래 겹친 앞다리의 앞뒤 구분은 여전히 강하지 않다. 준비의 당긴 발은 털/가슴 위에 겹치며, 어두운 배경에서는 짙은 경계와 먼 다리 대비가 낮다.
- 시점은 측면 성격이 강하다. 이번 세 지정 부위 교정으로 전신의 시점을 다시 만들지는 않았다.
- 준비 잎은 뒤쪽 위로 모으고 접촉 잎은 오른쪽 위로 펼친다. 이동에서 잠깐 아래로 향하는 잎의 방향 전환은 6장 비교용 GIF에서 급하게 읽힐 수 있다. 보간을 추가하지 않았다.
- 기술 접촉의 실제 잎은 이제 면이 남지만 준비보다 단축되어 보인다. 64px 오른쪽 끝 x62를 사용하므로 두 곡선과 잎 주변 여유가 좁으며 가는 기 줄기는 축소 표시에서 약할 수 있다.
- GIF의 저장 프레임과 노출표를 확인했다. 실시간 움직임의 매끄러움, 실제 전투 접촉/판정/런타임은 확인하지 않았다.

현재 결과는 새 독립 검수와 사용자 선택을 위한 수정 후보다. 검수자 호출, 검수 결과/원장 수정, 사용자 승인 선언을 하지 않았다. 모든 쓰기는 source 안에서만 했다.

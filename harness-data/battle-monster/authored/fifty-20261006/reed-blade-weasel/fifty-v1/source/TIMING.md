# 갈잎족제비 — 교정 후보 GIF 시간표

현재 native64 리터럴 격자를 그대로 재생한다. 자동 변형/보간/중간 프레임 생성은 없다. 순서와 노출 시간은 `render.py`의 `MOTIONS`에 기록되어 있다. 자체 비교 GIF는 반복한다.

| GIF | 자세 순서 | 노출 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240 / 180 / 100 / 140 / 200 / 240 |
| hit | idle_a → hit → recover → idle_a | 300 / 240 / 200 / 300 |
| dead | idle_a → hit → dead | 240 / 160 / 1000 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 350 / 180 / 280 / 240 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 480 / 480 |
| sleep | sleep_a → sleep_b | 650 / 650 |

## 공격 — 준비·전진·접촉·회수

- `windup` 180ms: 뒤 지지다리를 굽히고 앞발을 가슴 뒤쪽으로 당긴다. 어깨 x41–46,y43 → 굽힌 팔 x38–45,y44 → 쥔 발 x36–43,y45–46. 잎 밑동 x36,y44에서 뒤쪽 위 끝 x25,y29까지 기울여 모은다.
- `move` 100ms: 뒤발을 펴고 낮은 긴 허리/앞 어깨를 내민다. 원래 아래쪽 잎을 유지한다.
- `attack` 140ms: 어깨에서 이어진 팔/압축된 손목/쥔 앞발 x45–51,y44–48. 잎 밑동 x49–52,y46–47에서 오른쪽 위 끝 x62,y42로 넓게 펼쳐 베기 방향을 보인다. 지지 앞다리와 손은 별도로 읽히는 경계를 남겼다.
- `recover` 200ms: 기존 접힌 팔과 낮아진 잎, 되돌린 꼬리를 유지한다.

쓰러짐 GIF가 마지막에서 idle로 돌아가는 것은 후보 비교용 반복이다.

## 갈엽참 — 실제 앞발/갈잎 앵커

좌표는 0부터 시작한다. 입에서 발사하지 않는다.

- `skill_a` 준비 350ms: 기존 연결된 앞발 x48–56,y41–44. 실제 잎은 쥠에서 위로 꺾여 올라가고 연녹 기를 x55–58,y18–22 부근에 모은다. 이 격자는 보존했다.
- `skill_b` 접촉 180ms: 손 x48–51,y45–46 → 실제 줄기 x52–55,y43–45 → 잎 면 x55–61,y38–42 → 실제 끝 x59,y37. 윗칼날은 x57,y35와 x58,y36을 거쳐 이 끝으로 이어지고 밝은 곡선은 y10–34에 있다. 아랫칼날은 같은 끝에서 x60,y37 → x61,y38 → x62,y39–44 → x61,y45 → x60–61,y46으로 갈라지고 밝은 곡선 y47–55로 이어진다. 기존 손발/허리/지지발을 전체 이동하지 않았다.
- `skill_c` 회수 280ms: 기존 앞팔을 접고 실제 잎을 x56–61,y51–60 부근으로 낮춘다. 손과 줄기는 남고 위의 잔바람 x49–60,y12–27은 분리된 작은 군집으로 해체된다.

## 상태 변화

- 독 420/420ms: 아픈 앞발, 낮춘 턱/어깨, 굽힌 다리와 독 기포의 위치/개수 변화가 있는 기존 두 리터럴 격자를 유지한다.
- 기절 480/480ms: 처진 머리/팔/잎과 바뀐 별 위치, 다른 어깨/다리 행을 유지한다.
- 수면 650/650ms: 접힌 앞발/뒷발과 말린 꼬리, 바닥의 잎, 짧은 닫힌 눈꺼풀 x44–45,y46을 유지한다. 검은 코 x53,y47과 떨어져 있으며 둘째 장의 등/가슴 면이 작은 들숨을 보인다. 죽음 자세를 대신 쓰지 않는다.

저장 GIF 전 프레임의 픽셀/노출 시간 재읽기와 두 native/3배 storyboard 열람을 완료했다. 실제 게임의 접촉/피해 시점 또는 실시간 재생의 매끄러움은 확인하지 않았다. 독립 검수 통과나 사용자 승인을 선언하지 않는다.

# 해주영사 — 8동작 시간표

모든 GIF는 native 128×128. 각 자세는 직접 저작한 별도 pxgrid이며, GIF 인코딩은 픽셀을 바꾸지 않는다. GIF의 시간 단위에 맞춰 모두 10ms 배수로 지정했다. 아래는 `preview/motions/`에 보존한 자체 GIF의 실제 시간표다. 하네스가 게시 단계에서 만드는 GIF 시간표와는 별도다.

| 동작 | 자세 순서 | 각 노출(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600, 280, 120, 160, 220, 650 |
| hit | idle_a → hit → recover → idle_a | 600, 240, 220, 600 |
| dead | idle_a → hit → dead | 500, 180, 1200 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700, 350, 220, 300, 900 |
| poison | poison_a → poison_b | 480, 480 |
| stun | stun_a → stun_b | 480, 480 |
| sleep | sleep_a → sleep_b | 720, 720 |

## 물기

준비는 목을 왼쪽 뒤로 굽히고 코일을 모은다. 이동은 목·턱을 앞으로 낮추고 코일의 중심 공간을 길게 펼친다. 접촉은 같은 주둥이의 윗턱을 x=111까지 뻗고 아랫턱·입천장·혀·이빨을 별도로 찍었다. 회수는 턱을 닫고 목의 밑부분을 감아 원래 코일로 돌아간다. 셀 전체의 이동·회전·보간은 없다.

## 해주식의 입 앵커

- `skill_a`: 입을 벌린 상태의 어두운 구강 안에 M/N/O 청백 핵을 직접 배치한다. 목에 매단 진주는 별개의 장식으로 유지한다.
- `skill_b`: 구강의 밝은 핵에서 (73,48)–(84,53)의 직접 저작 연결 군집을 통해 두 물결로 이어진다. 윗갈래는 위로 뻗은 파도 마루, 아랫갈래는 두꺼운 흐름과 안쪽으로 되감긴 끝이다. 원형 오라를 쓰지 않는다.
- `skill_c`: 낮춘 머리와 닫힌 턱을 새로 찍고, (94,35), (109,56), (96,70)에 시작하는 독립 물보라 세 군집을 남긴다. 잔기는 의도적으로 분리되어 있다.

## 상태

독은 벌어진 아픈 턱과 뒤틀린 목, 다른 위치·크기의 보라 기포를 사용한다. 기절은 짧아진 처진 목과 두 눈의 피곤한 군집, 다른 위치의 두 별을 사용한다. 수면은 닫힌 짧은 눈꺼풀과 코일 위의 턱·진주를 유지한다. 두 번째 수면 자세는 턱/귀/목 군집을 낮추고 코일 윗면 윤곽을 이완한 별도 원본이다.

`render.py`가 저장된 GIF를 다시 열어 모든 프레임의 RGBA 바이트와 노출 시간을 원본과 비교한다. `preview_gifs.py`는 실제 GIF에서 읽은 프레임으로 1배·2배 비교 그림을 만든다. 화면에서 GIF를 열었으나 도구는 첫 프레임만 보여 주므로, 시간 순서의 시각 확인은 이 비교 그림으로 수행했다. 실시간 움직임은 `preview/index.html`에서 볼 수 있다.

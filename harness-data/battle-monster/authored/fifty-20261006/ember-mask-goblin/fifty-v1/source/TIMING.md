## 2026-10-06 연결부 교정

skill_c의 native (54,39), dead의 (69,65)를 투명 점에서 기존 윤곽 문자 o로 바꿨다. 기술 회수의 올라간 턱/붉은 목 연결과 쓰러짐의 뿔/탈 연결을 닫는 수정이며 GIF 순서·노출 시간·입 핵/세 불꽃 갈래/두 재 불씨 앵커를 바꾸지 않았다. 아래 상태 얼굴 교정 설명은 이전 작업의 기록이다.

현재 8개 GIF를 다시 굽고 모든 저장 프레임의 원본 RGBA와 노출 시간을 다시 읽었다. 실제 엔진의 hop·타격 시점 확인은 수행하지 않았다.


원본은 96×96, 기존 18색과 투명 인덱스 0, 알파 0/255다. 중간 자세 합성이나 전체 그림의 이동/회전은 없다. GIF의 각 프레임은 해당 격자 원본 그대로다. 최근접 확대는 진단판에서만 사용한다. 경로는 `gifs/<동작>.gif`, 시간 단위는 ms.

이번 교정은 노출 시간을 유지했다. `disposal=2`로 프레임마다 지우며, GIF는 검토용으로 반복한다. 죽음 GIF 반복은 부활 동작을 뜻하지 않는다.

## 같은 오른손으로 이어지는 공격

- **windup / 200ms:** 가까운 어깨 x≈51..59,y≈46..48에서 위팔이 몸통을 가로질러 왼쪽 아래로 이어지고, 팔꿈치 x≈34..43,y≈55..61에서 아래팔을 뒤로 접는다. 공격 주먹은 몸통과 탈의 뒤쪽인 화면 왼쪽 x≈16..29,y≈46..52에 당겨져 있다. 주먹의 위쪽 밝은 손마디, 짧은 손목, 굵은 아래팔과 팔꿈치를 직접 새로 찍었다. 낮은 보조 손과 무릎·발은 유지했다.
- **move / 100ms:** 뒤 지지다리가 밀고 앞 무릎이 받는다. 오른쪽 어깨→팔꿈치→짧은 손목→x≈62..74, y≈55..60의 주먹으로 이어진다. 왼손은 몸 뒤로 낮춘 균형 동작이다.
- **attack / 120ms:** 가까운 팔이 아래로 내려가 손목 밑의 큰 주먹으로 접촉한다. 주먹은 대략 x59..74, y69..78이다. 준비·전진과 같은 오른팔이며 원래의 접촉 원본은 유지했다.
- **recover / 220ms:** 같은 팔을 굽혀 주먹을 배 앞으로 회수한다. 어깨→위팔→팔꿈치→아래팔→배 앞 주먹이 이어진 기존 원본을 유지했다.

## 탈화폭의 입 앵커

좌표는 각 원본 좌상단 (0,0) 기준이다. 이 종은 맨주먹이며 무기/자루 앵커가 없다. 손은 균형·긴장 자세이고 실제 발사점은 탈의 입이다.

- **skill_a / 모으기 260ms:** 입 홈 내부 x61..65, y40..43에 금빛 핵 `n/p/f`를 모은다. 가까운 손은 몸 앞에 접혀 있다.
- **skill_b / 발동·접촉 160ms:** 입 핵 x59..63, y37..41과 불꽃 뿌리 x61..65, y38..42가 이어진다. 상향 끝은 x≈80,y≈21, 전방 끝은 x≈89,y≈29, 하향 끝은 x≈82,y≈52다. 각 갈래의 길이·꺾임·불꽃 혀는 다르며 금색 중심과 주홍 가장자리를 갖는다.
- **skill_c / 깨진 잔상 회수 240ms:** 오른쪽 눈썹과 입을 올리고 턱을 짧게 그려 고개를 든다. 입의 남은 금빛은 x≈61..63,y≈29..33이며, 붉은 목은 턱 밑 x≈42..54,y≈38..42에서 조끼 어깨로 이어진다. 입 앞의 끊어진 잔상은 x70..76,y32..37, 두 재 불씨는 x77..86,y18..27 및 x82..90,y40..48이다. 분리된 덩어리는 의도한 날아간 재 불씨다.

## 상태 얼굴의 홈과 기존 동작 유지

이번 교정은 아래 얼굴 군집만 바꿨고 모든 GIF 순서·노출 시간과 기술 입 앵커를 유지했다.

- **poison / 각 420ms:** 첫 얼굴의 x55..62,y41..44와 둘째 얼굴의 x56..63,y43..46에서 깊은 눈 홈을 입에 연결했다. 배를 움켜쥔 손·웅크린 지지발·서로 다른 독방울은 기존 리터럴 원본이다.
- **stun / 각 300ms:** 첫 얼굴 x56..65,y44..48, 둘째 얼굴 x57..66,y45..49의 처진 눈→입 홈을 직접 이었다. 늘어진 팔과 다르게 배치된 별을 유지했다.
- **sleep / 각 650ms:** 두 얼굴의 위치는 동일하다. x55..67,y47..57에 연결된 눈·코·입 홈을 찍고, x56..58 및 x63..65,y49에 m의 짧은 닫힌 눈꺼풀을 넣었다. 작은 수면 입은 아래쪽 y56..57이며 깊은 홈의 오른쪽 가지로 이어진다. 두 번째 가슴 가장자리 x≈47,y78..81의 기존 1px 변화로 숨을 표현한다. 손·접힌 발·낮은 접지는 유지했다. 눕힌 쓰러짐과 다른 안정된 웅크림이다.

`gif-decoded.json`은 실제 저장 파일에서 다시 읽은 프레임 수와 노출 시간이다. 모든 저장 프레임의 확인판은 `gif-decoded-native.png`와 `gif-decoded-contact.png`다. 격자/GIF 일치와 진단 시트 확인은 실제 엔진의 피해 이벤트·hop·접촉 시점 검증을 뜻하지 않는다.

# 잿불탈귀 — 턱/목과 뿔/탈 연결부의 두 픽셀 교정

## 작업 범위와 원본 보존

첨부된 현재 18자세 시트와 64px 검객 참고를 실제 열었다. 큰 주홍 나무 탈, 뿔 하나, 회갈 조끼, 검붉은 짧은 팔다리, 넓은 발과 재 덩어리, 왼쪽 위 광원 면을 관찰했다. 참고는 관찰에만 사용했으며 추출하거나 복사하지 않았다.

기존 기본 자세 9개와 기술·상태 자세 9개를 보존하고 지정된 두 좌표만 고쳤다. 모든 현재 pxgrid는 96행 × 96문자의 전체 ASCII 원본이다. 이번 작업은 기존 나머지 픽셀의 저작 출처를 새로 증명하거나 주장하지 않는다.

수정 직전의 18개 격자, palette.json, AUTHORING.md, TIMING.md는 `history/before-join-pinhole-repair/`에 보존했다. 이전 저작·교정 보조 코드와 기록도 그대로 남겼다. 과거 관찰 기록의 결손 없음 표현은 이번에 지적된 두 구멍의 부재를 증명하지 않는다.

## 직접 선택한 리터럴 픽셀

좌표는 native 좌상단 (0,0) 기준이다. 기존 팔레트의 `o = #211B23`를 사용했다.

| 원본 | x | y | 변경 | 연결부 |
|---|---:|---:|---|---|
| actions/skill_c.pxgrid | 54 | 39 | `.` → `o` | 올려 든 탈의 아래턱/목 접합에서 좌우 윤곽 사이 투명 한 점을 닫았다. |
| poses/dead.pxgrid | 69 | 65 | `.` → `o` | 누운 탈과 뒤로 휜 뿔의 밑동 사이, 네 방향 윤곽에 둘러싸인 투명 한 점을 닫았다. |

`repair_join_pinholes.py`의 두 명시 좌표만 적용했다. 자동 구멍 채우기, 연결 성분에 따른 보정, 전체 자세 이동·회전, 보간, 음영 합성은 사용하지 않았다. 최종 전체 행은 각 pxgrid에 저장했다.

`join-pinhole-changes.json`은 수정 전/후 원본 해시, 실제 문자 차이 두 개, 팔레트 보존 여부, 현재 두 PNG 해시와 수정 좌표 RGBA를 기록한다. 실제 차이는 위의 2픽셀뿐이다. 다른 16자세와 팔레트는 직전 보존본과 바이트가 같다. skill_c와 dead에서도 지정된 좌표 외의 몸·효과·외곽·외부 빈 공간을 보존했다. 기록의 해시는 검수 결과나 모델 출처를 대신하지 않는다.

## 생성 파일과 실제 관찰

기존 `render.py`로 리터럴 격자를 기존 팔레트 색에 그대로 매핑하여 native RGBA PNG 18개와 GIF 8개를 갱신했다. 저장된 GIF 각 프레임을 다시 읽어 원본 RGBA 및 TIMING.md의 노출 시간과 일치하는지 확인했다. `diagnose.py`는 원본을 쓰지 않고 행 크기·문자·투명 테두리·접지와 저장 GIF를 읽으며 진단판을 갱신했다. 연결 성분 측정은 픽셀 변경이나 미감 판정에 쓰지 않았다.

`inspect_join_pinholes.py`는 현재/수정 전 격자를 읽어 관찰판만 만들었다. 다음 그림을 실제 열었다.

- `join-pinhole-light.png`, `join-pinhole-dark.png`, `join-pinhole-checker.png`: 수정된 두 자세의 원본 1배, 최근접 3배, 연결부 전후 최근접 8배. 밝은/체커 배경의 배경 한 점이 닫힌 것을 확인했다. skill_c의 턱 아래 붉은 목 면과 바깥 빈 공간, dead의 뿔 외곽 및 탈/목 부피는 보존됐다.
- `contact-native.png`: 전체 18자세의 원본 1배를 열어 탈·뿔·목·어깨·손·다리·발과 다른 자세의 대응 부위를 관찰했다. 다른 자세에서 같은 형태의 추가 결손을 특정하지 못했으므로 추가 픽셀 변경은 하지 않았다.
- `gif-decoded-native.png`: 저장한 8개 GIF의 모든 프레임을 native 크기로 다시 읽은 판을 열어 공격 팔의 준비→전진→접촉→회수, 기술의 입 핵→세 불꽃 갈래→올린 턱과 두 재 불씨, 독·기절·수면의 자세별 차이를 확인했다.

파일 재읽기에서는 18개 서로 다른 원본, 18색 팔레트, 96×96 행, 1px 투명 테두리, 모든 최저 잉크 y≤92와 idle_a 실제 발바닥 y=92를 확인했다. 확대는 관찰판에만 사용했고 원본/동작에는 적용하지 않았다.

## 남은 시각적 문제와 관찰 한계

지적된 두 투명 점은 현재 밝은/어두운/체커 관찰판에서 보이지 않는다. 어두운 배경에서는 검붉은 사지의 외곽 대비가 낮다. 수면의 짧은 눈꺼풀과 작은 가슴 호흡은 native 크기에서 섬세하며, 재의 회색 큰 면은 가루보다 매끈한 탄화 덩어리로 읽힐 수 있다. 이번 범위에서 이 기존 표현을 바꾸지 않았다.

정적 PNG와 GIF 디코딩 판은 연속 재생 시 인상, 실제 전투 타이밍·hop 경로·피해 이벤트·런타임 배치를 확정하지 못한다. 해당 런타임 사항은 이번 작업에서 확인하지 않았다. 새 독립 시각 검수는 하네스가 맡는다.

모든 쓰기는 source 안에서만 수행했다. 테스트/게이트나 별도 검수자 호출은 실행하지 않았다. 검수 결과·사용자 선택·ledger·brief·게임 저장소는 편집하지 않았다. 이 문서는 두 픽셀 교정과 자체 관찰의 기록이며, 검수 통과·사용자 승인·50종 전체 완료를 선언하지 않는다.

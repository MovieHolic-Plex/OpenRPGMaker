# 잿불탈귀 — 독·기절·수면의 나무 탈 홈 교정

## 원본과 작업 범위

첨부된 현행 18자세 시트와 자체 64px 검객 참고를 실제 열어 주홍 단일 뿔 나무 탈, 검붉은 짧은 팔다리, 회갈 조끼, 넓은 발, 재 덩어리와 왼쪽 위 광원을 관찰했다. 참고 그림은 관찰에만 사용했다.

현재 원본은 poses의 기본 9장과 actions의 기술·상태 9장이며, 모두 96행 × 96문자의 전체 ASCII 격자다. 기존 18색 palette.json과 투명 점을 유지했다. 변경 전 18개 격자·팔레트·AUTHORING·TIMING은 history/before-status-carving에 보존했다. 이전 교정 원본과 보조 코드도 source 안에 남아 있다.

repair_status_carving.py의 (x, y, literal pixels)는 내가 직접 선택한 짧은 ASCII 행 군집이다. 각 자세의 실제 좌표를 별도로 적었으며 다른 자세의 좌표를 코드로 옮기지 않았다. 전체 변형, 자동 면/음영 생성, 연결 검사에 따른 채움은 하지 않았다. 최종 pxgrid 파일은 전체 리터럴 행이다.

## 직접 수정한 군집

좌표는 native 좌상단 (0,0) 기준이며 범위는 실제 변경 픽셀의 경계다. 얼굴 내부의 불투명 색만 교체했다.

| 자세 | 실제 변경 범위 | 픽셀 수 | 직접 찍은 내용 |
|---|---|---:|---|
| poison_a | x55..62, y41..44 | 19 | 찡그린 눈 밑의 좌우 깊은 홈 e를 입 안쪽에 연결하고 코 능선 주변에 나무 그림자 w를 남겼다. |
| poison_b | x56..63, y43..46 | 19 | 내려온 얼굴 위치에서 눈→코 옆→입 홈을 별도로 지정했다. 기존 눈 모양과 열린 입·작은 치아를 유지했다. |
| stun_a | x56..65, y44..48 | 31 | 작은 눈 아래의 홈을 넓히고 처진 코 옆에서 입까지 이어지는 e/w 군집을 찍었다. |
| stun_b | x57..66, y45..49 | 31 | 이 자세의 실제 얼굴 좌표에 홈을 직접 지정했다. 바뀐 별 위치와 내려온 팔을 보존했다. |

| sleep_b | x55..67, y47..57 | 70 | 현재 두 수면 자세의 얼굴 위치는 같다. 이 좌표의 홈과 눈꺼풀을 명시하고 기존 머리 외곽·손·발·가슴 호흡 차이를 유지했다. |

총 240픽셀을 바꿨다. status-carving-facts.json에는 실제 변경 전/후 원본 해시, 현재 PNG 해시, 좌표별 이전/현재 문자, 변경 수와 범위를 기록했다. 파일 해시는 모델 출처나 검수 판정을 대신하지 않는다.

나머지 12자세와 팔레트는 이번 작업 직전 사본과 바이트가 같다. 큰 주홍 탈·뿔·광원 면, 피부·조끼, 목·어깨·손목, 등짐·다리·발을 보존했다. 독의 배를 움켜쥔 웅크림과 독방울, 기절의 늘어진 팔과 별, 수면의 낮은 접지와 가슴 호흡 변화도 유지했다. 이전 교정의 뒤 주먹 windup, 같은 팔의 move→attack→recover, 입에서 세 갈래로 나가는 기술도 그대로다.

## 실제 연 그림과 파일 재읽기

- status-carving-light.png, status-carving-dark.png, status-carving-checker.png: 6자세의 원본 1배와 최근접 3배를 실제 열었다. 연결된 홈, 닫힌 눈꺼풀, 목·조끼 경계, 손목·발 접지를 관찰했다.
- status-carving-faces.png: 수정 전/후 얼굴 확대를 실제 열었다. 첫 수정에서 수면 눈꺼풀이 짙은 홈에 묻혀 보여 y49 눈꺼풀과 코·입 주변을 다시 직접 골랐다. 최종 판을 다시 열었다.
- contact-native.png: 전체 18자세를 원본 크기로 실제 열어 같은 탈 재질과 다른 자세의 얼굴·관절·의도한 빈 공간을 함께 봤다.
- gif-decoded-native.png, gif-decoded-contact.png: 저장한 8GIF의 모든 프레임을 다시 읽은 판을 실제 열어 자세 순서와 얼굴·사지·효과의 프레임별 차이를 확인했다.

render.py로 18개 native RGBA PNG와 대기·공격·피격·쓰러짐·기술·독·기절·수면 8GIF를 다시 구웠다. 문자를 기존 팔레트 색으로 그대로 매핑했으며 최근접 확대는 진단판에만 사용했다. 저장 GIF의 각 프레임을 다시 읽어 해당 원본 RGBA와 노출 시간이 일치함을 확인했다.

diagnose.py는 원본을 수정하지 않고 크기·문자·테두리·접지와 저장 GIF를 재읽었다. 원본 18개가 모두 서로 다르며, 96×96 행·18색·1px 투명 테두리·최저 잉크 y≤92·idle_a 실제 발바닥 y=92를 유지한다. inspect_status_carving.py는 읽기 전용 관찰판과 차이 기록을 만든다. 연결 성분 수로 그림을 자동 보정하지 않았다.

## 남은 시각적 문제와 확인 한계

어두운 배경에서는 검붉은 팔다리 외곽의 대비가 낮다. 수면의 나무색 닫힌 눈꺼풀은 3px짜리 작은 표현이며, 연결된 깊은 홈 안에서의 표정 가독성은 새 독립 검수에서 다시 판단해야 한다. 수면의 1px 가슴 호흡 변화는 작다. 재의 큰 회색 면은 거친 재 가루보다 매끈한 탄화 덩어리로 읽힐 수 있다.

이번에 연 PNG와 GIF 디코딩 판에서 새 투명 구멍이나 떨어진 손·목·발은 보이지 않았다. 디코딩 판의 프레임 관찰은 화면 연속 재생이나 실제 엔진의 hop·전투 배치·피해 이벤트·타격 접촉 확인을 뜻하지 않는다. 실제 전투 배경과 재생 타이밍은 이번 작업에서 확인하지 않았다.

모든 쓰기는 source 안에서만 수행했다. 테스트/게이트나 별도 검수자 호출은 실행하지 않았다. 새 독립 검수는 하네스가 맡는다. 이 문서는 자체 저작·관찰 기록이며 검수 통과, 사용자 승인, 50종 전체 완료를 선언하지 않는다.

# 잿불탈귀 — 검수 지적 교정 기록

현재 원본은 `poses/` 9장과 `actions/` 9장이다. 모든 파일은 전체 96×96 ASCII 팔레트 행이다. `palette.json`의 기존 18색과 투명 `.`을 유지했다. 가장자리 1px은 투명, 최하단 잉크는 y≤92이며 `idle_a` 발은 정확히 y=92다. 아래 좌표는 0부터 센다.

## 참고와 보존

첨부된 현행 18자세 시트와 자체 64px 검객 참고 이미지를 실제 열었다. 탈의 비율, 얼굴 홈, 목·어깨·팔·발의 연결, 왼쪽 위 광원의 넓은 면을 관찰했다. 참고 이미지 픽셀을 추출하거나 원본으로 복사하지 않았다.

이번 작업 전 18개 격자와 팔레트, 기존 문서는 `history/before-review-repair/`에 보존했다. 최초 초안은 기존 `history/draft-1/`에 있다. 이번 교정은 직접 고른 좌표와 ASCII 문자열인 `repair_review.py`에 남겼다. 각 수정 파일에는 변경 군집을 포함한 전체 리터럴 행을 저장했다. 도형 생성, 전체 프레임 이동·회전·보간, 명암 합성, 자동 구멍 채우기와 좌표의 자세 간 자동 복사를 사용하지 않았다.

공격 오른팔은 준비의 들린 주먹→전진의 짧게 접힌 주먹→접촉의 아래로 내려친 큰 주먹→회수의 배 앞 주먹이다. `attack`과 `recover`의 어깨·팔꿈치·손목 군집을 실제 시트에서 함께 확인하고 원본을 유지했다. 맨주먹 종이므로 무기나 자루는 없다.

`skill_a`의 입 금빛 핵과 `skill_b`의 입에서 이어지는 세 불꽃 갈래는 보존했다. 회수는 대기 탈의 복사 대신 새 눈썹·입·턱 군집과 노출된 목으로 고개 들기를 표현했다. 독은 배를 감싸는 아픈 자세와 다른 독방울, 기절은 처진 머리·팔과 다른 별, 수면은 접힌 다리·짧게 닫힌 눈꺼풀과 작은 가슴 호흡이다. 해당 6개 상태 원본과 대기 3장, 피격, 공격·회수, 기술 준비·발동을 포함한 다른 14장은 바이트 그대로 유지했다. 팔레트도 바이트 그대로 유지했다. 실제 원본 차이는 `repair-facts.json`에 있다.

## 실제 그림 확인과 산출물

- `png/`: 현재 18개 96×96 RGBA PNG.
- `gifs/`: 대기·공격·피격·쓰러짐·기술·독·기절·수면 8개 GIF.
- `contact-native.png`, `contact-light.png`, `contact-dark.png`, `contact-checker.png`: 전체 자세 진단 시트.
- `repair-light.png`, `repair-dark.png`, `repair-checker.png`: 수정 전/현재 4자세의 1배와 최근접 3배 비교. 세 배경 모두 실제 열어 목·턱·어깨·팔·재 지지와 의도한 빈 공간을 관찰했다.
- `repair-detail.png`: 현재 공격 흐름과 기술 흐름의 최근접 4배 진단.
- `gif-decoded-native.png`, `gif-decoded-contact.png`: 저장된 8GIF를 다시 읽은 실제 모든 프레임의 1배/2배 시트. 이를 열어 순서별 사지·얼굴·상태 표현을 확인했다.

`render.py`는 원본 격자 색을 그대로 굽고 저장된 GIF 각 프레임의 RGBA와 노출 시간을 다시 읽어 원본과 비교한다. `diagnose.py`는 크기·팔레트 문자·여백·접지·실제 해시·연결 성분을 기록하며, 격자를 고치거나 미감 판정을 만들지 않는다. `inspect_review.py`는 원본 격자로 비교판과 실제 파일 차이만 만든다. 기술 회수의 불씨와 상태 효과의 분리 성분은 의도한 효과다.

## 남은 시각적 한계

재의 넓은 회색 면은 가루보다 매끈한 탄화 덩어리처럼 읽힐 수 있다. 어두운 배경에서 검붉은 피부의 최외곽 대비는 낮다. 독·기절의 두 번째 자세 변화와 수면의 1px 가슴 호흡은 작다. 정지/디코딩 시트로 관절과 순서는 보았지만 실제 전투 배경, 엔진의 hop·접촉 시점·화면 재생 타이밍은 확인하지 않았다.

이 문서는 교정 저작과 자체 관찰 기록이다. 새 독립 검수 통과나 사용자 승인, 50종 전체 완료를 주장하지 않는다. 독립 검수는 하네스가 맡는다. 이번 작업은 source 안에서만 수행했고 테스트/게이트와 별도 검수자 호출은 실행하지 않았다.

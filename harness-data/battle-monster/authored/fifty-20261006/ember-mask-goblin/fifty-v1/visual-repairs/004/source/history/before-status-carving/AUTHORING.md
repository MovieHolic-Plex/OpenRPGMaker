# 잿불탈귀 — 뒤로 당긴 준비 주먹 교정

## 범위와 원본 보존

이번 교정은 독립 검수에서 지적한 `windup`의 전방 가드 실루엣을 고치는 작업이다. 첨부된 현행 18자세 시트와 자체 64px 검객 이미지를 실제 열어 탈·목·어깨·짧은 팔·넓은 발과 왼쪽 위 광원의 면을 관찰했다. 참고 픽셀을 추출하거나 복사하지 않았다.

현재 원본은 `poses/` 9장과 `actions/` 9장, 모두 전체 96×96 ASCII 팔레트 행이다. `palette.json`의 기존 18색과 투명 `.`을 유지했다. 이번 수정 직전의 18개 원본·팔레트·저작 기록·시간표는 `history/before-backward-windup/`에 보존했다. 더 이른 저작 기록과 보조 코드도 source 안에 그대로 남겼다.

변경한 원본은 `poses/windup.pxgrid` 한 장이다. 나머지 17장과 팔레트는 수정 직전 사본과 바이트가 같다. `actions/skill_a/b/c`, `poison_a/b`, `stun_a/b`, `sleep_a/b`는 기존 직접 저작 격자를 보존했다. 실제 차이와 파일 해시는 `backward-windup-facts.json`에 기록했다. 사용자 승인이나 검수 결과를 작성하지 않았다.

## 직접 고른 픽셀 군집

좌표는 각 원본 좌상단 (0,0) 기준이다. `repair_windup.py`에는 이번 교정의 개별 좌표와 ASCII 행 문자열을 보존했다. 투명 점도 직접 선택한 삭제 픽셀이며, 연결 검사 결과로 채우거나 지운 것이 아니다.

| 위치 | 직접 수정한 내용 |
|---|---|
| x69..81 / y44..47 및 x60..81 / y48..61 | 얼굴보다 오른쪽에 있던 전방 주먹·접힌 아래팔·낮은 팔꿈치를 지웠다. |
| x54..59 / y48..61 | 팔 밑에 가려졌던 조끼 기본 면과 오른쪽 그림자·윤곽을 직접 복원했다. |
| x37..59 / y46..54 | 가까운 어깨에서 왼쪽 아래로 몸통을 가로지르는 위팔을 찍었다. 붉은 피부의 넓은 윗면과 오른쪽 아래 그림자, 어두운 외곽이 조끼 면과 구별된다. |
| x24..46 / y55..61 | 몸통 중심보다 뒤쪽인 왼편에서 팔꿈치를 굽혔다. 굵은 관절의 아래 윤곽을 둥글게 닫고, 위팔과 아래팔이 만나는 면을 직접 이어 찍었다. |
| x18..34 / y51..54 | 뒤 주먹에서 팔꿈치로 내려오는 짧은 손목·아래팔을 찍었다. 이 경로는 상완과 꺾이는 방향이 다르다. |
| x16..29 / y46..52 | 탈 왼쪽이자 조끼 뒤쪽에 당긴 주먹을 새로 찍었다. 밝은 왼쪽 위 손마디 `f/t`, 피부 기본색 `t`, 아래 그림자 `s/r`, 어두운 `o` 윤곽을 직접 골랐다. |

실제 변경은 580픽셀, 전체 변경 범위는 x16..81 / y44..61이다. 새 주먹은 재 덩어리의 아래 왼쪽 앞에 겹치며 붉은 피부와 어두운 손 외곽이 재의 회색 면을 가른다. 낮은 보조 손은 그 아래에 남아 있고, 준비 주먹과 별도로 읽힌다. 탈·뿔·눈과 입 홈·목 상단·등의 재 상단·골반·두 다리·발·접지 위치는 보존했다. 몸 전체 이동·회전이나 다른 프레임의 좌표 복사를 사용하지 않았다.

현재 공격 흐름은 뒤로 당긴 주먹과 팔꿈치 → 몸을 앞으로 내딛는 move → 아래로 내려친 attack의 큰 주먹 → 배 앞에 접은 recover다. 대기와 기술·상태의 같은 어깨·팔 부위도 전체 PNG에서 함께 관찰했다. 다른 자세에서 이번 지적에 해당하는 전방 가드 준비 문제는 보이지 않아 원본을 보존했다.

## 직접 연 산출물과 관찰

- `png/`: 18개 현재 96×96 RGBA PNG.
- `gifs/`: 대기·공격·피격·쓰러짐·기술·독·기절·수면 8개 GIF. 이번 픽셀 변경을 포함해 다시 구웠다.
- `backward-windup-light.png`, `backward-windup-dark.png`, `backward-windup-checker.png`: 수정 직전 windup과 현재 windup/move/attack/recover를 원본 1배와 최근접 3배로 나란히 표시한다. 세 판을 실제 열어 뒤 주먹 위치, 어깨부터 손까지의 피부 면, 목·조끼 경계와 의도한 팔다리 사이 공간을 확인했다.
- `contact-native.png`, `contact-checker.png`: 전체 18자세를 실제 열어 얼굴·관절·상태 표현을 함께 확인했다. 수면 두 장의 눈은 짧은 닫힌 눈꺼풀이며, 평상시 큰 검은 눈 홈과 다르다.
- `gif-decoded-native.png`: 저장된 8GIF의 모든 프레임을 다시 읽은 1배 판을 실제 열어 공격 순서, 유지되는 얼굴·사지, 기술과 상태별 순서를 확인했다.

`render.py`는 문자에 대응하는 색을 그대로 PNG/GIF로 굽고 실제 GIF 프레임과 노출 시간을 원본과 비교한다. `diagnose.py`는 원본을 변경하지 않는 파일 진단과 GIF 디코딩 판 생성 보조다. 18개 서로 다른 원본, 96×96 행, 18색, 투명 테두리, y≤92와 idle_a 발바닥 y=92를 확인했다. 연결 성분으로 그림을 자동 보정하지 않았다. `inspect_windup.py`는 읽기 전용 비교판과 실제 파일 차이를 만든다. 최근접 확대는 진단판에만 사용한다.

## 남은 시각적 문제와 확인 한계

어두운 배경에서 검붉은 피부의 최외곽 대비가 낮다. 재의 넓은 회색 면은 재 가루보다 매끈한 탄화 덩어리처럼 읽힐 수 있다. 독·기절 쌍과 수면의 1px 가슴 호흡 변화는 작다. 뒤로 접힌 공격 팔은 조끼 윗면 일부를 가리므로 팔의 붉은 면과 조끼의 회갈 면 경계로 관절을 읽어야 한다.

PNG와 저장 GIF의 디코딩 프레임에서 몸 내부의 새 투명 구멍이나 주요 관절 단절은 보이지 않았다. 실제 전투 배경과 엔진의 hop 이동·타격 대상 접촉·피해 이벤트·화면 재생 타이밍은 확인하지 않았다. 새 독립 검수는 하네스가 맡는다. 이 기록은 자체 교정과 관찰 기록이며 검수 통과·사용자 승인·50종 전체 완료를 주장하지 않는다.

모든 쓰기는 source 안에서만 수행했다. 테스트/게이트나 별도 검수자 호출은 실행하지 않았다.

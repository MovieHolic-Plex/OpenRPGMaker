# 잿불탈귀 GIF 시간표

모든 GIF는 원본 96×96, 팔레트 18색과 투명 1칸, 알파 0/255다. 각 프레임은 리터럴 격자 그대로이며 중간 자세 합성이나 전체 그림의 이동/회전은 없다. 최근접 확대는 관찰 시트에만 적용했다. 저장 경로는 `gifs/<동작>.gif`다. 노출 시간은 ms.

| GIF | 자세 순서 | 노출 시간 |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 |
| hit | idle_a → hit → idle_a | 700 / 180 / 900 |
| dead | idle_a → hit → dead | 700 / 150 / 1700 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 300 / 300 |
| sleep | sleep_a → sleep_b | 650 / 650 |

GIF는 관찰을 위해 반복한다. 죽음 GIF의 반복이 게임의 부활 동작을 뜻하지 않는다. `disposal=2`, 투명 인덱스 0으로 프레임마다 잔여 픽셀을 지운다.

## 탈화폭의 실제 앵커

좌표는 각 원본의 좌상단 (0,0).

- **skill_a / 모으기 260ms:** 입의 금빛 핵은 대략 x=61..65, y=40..43. 탈의 입 홈 안에 `n/p/f`를 직접 넣었다. 가까운 손은 턱 아래/배 옆으로 접힌 팔의 끝이며 효과의 발사점은 입이다.
- **skill_b / 발동·접촉 160ms:** 열린 입 핵은 x=59..63, y=37..41, 연속된 불꽃 뿌리는 x=61..65, y=38..42. 상향 끝은 x≈80,y=21, 전방 끝은 x≈89,y=29, 하향 끝은 x≈82,y=52다. 세 갈래의 길이·곡선·불꽃 혀가 다르다. 금색 중심과 주홍 가장자리가 입부터 이어진다. 동작상 피해 접촉에 해당하는 프레임이며 게임 이벤트는 연결하지 않았다.
- **skill_c / 깨진 잔상 회수 240ms:** 입의 남은 불씨는 x≈62,y≈37. 입 앞 x=66..73,y=35..40에서 불꽃을 끊고, 두 재 불씨를 x=77..86,y=18..27 및 x=82..90,y=40..48에 그렸다. 고개를 들고 팔을 내린다. 이때 분리된 덩어리는 몸에서 떨어진 신체가 아니라 의도한 재 불씨다.

가까운 공격 주먹은 준비의 배 옆 → 전진의 어깨 앞 → 접촉의 손목 아래 → 회수의 배 앞으로 이어진다. 먼 팔은 균형 동작이다. 무기/자루 앵커는 없는 맨주먹 종이다.

수면은 650ms씩 숨을 쉬며 두 번째의 가슴 옆 가장자리 x=47,y=78..81가 1px 넓어진다. 눈꺼풀·손·접힌 발 위치는 고정한다. 독방울과 기절 별은 두 원본에서 각각 다른 위치와 크기로 직접 저작했다.

실제 저장 GIF를 다시 읽은 프레임 수/시간은 `gif-decoded.json`, 모든 실제 프레임의 1배 및 최근접2배 시트는 `gif-decoded-native.png`, `gif-decoded-contact.png`다. 전투 엔진 재생 속도는 이 후보 저작에서 확인하지 않았다.

# 붉은턱늑대 — native GIF 시간표

전체 셀 64×64. 아래 시간은 ms이며 GIF에는 10ms 단위로 그대로 저장한다.
보간/전체 프레임 이동/자동 회전 없이 원본 자세만 재생한다. 각 GIF는 loop=0, disposal=2,
투명 인덱스 0이다. 전경 RGB는 팔레트 원본 값 그대로다.

| GIF | 원본 순서 | 각 hold (ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600, 200, 100, 120, 220, 900 |
| hit | idle_a → hit → idle_a | 700, 180, 900 |
| dead | idle_a → hit → dead | 700, 150, 1700 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700, 260, 160, 240, 900 |
| poison | poison_a → poison_b | 420, 420 |
| stun | stun_a → stun_b | 300, 300 |
| sleep | sleep_a → sleep_b | 650, 650 |

## 동작과 접촉 위치

좌표는 native 픽셀, 0부터 시작한다.

- 대기: 세 자세의 접지 발은 y60. tail/볼/갈비 면의 작은 변화와 idle_c의 눈 감기가 호흡이다.
- 준비: 턱과 머리가 낮아지고 뒤 무릎이 접힌다. 뒤 발의 바닥 지지에서 돌격을 시작한다.
- 전진: 몸의 등선이 펴지고 뒤 지지발을 x1–7, y58–60에서 민다.
  먼 뒷다리는 배 밑에 접힌 상태며 가까운/먼 앞발이 각각 다른 굽힘으로 이어진다.
- 물기 접촉: 열린 입의 상악/송곳니는 x47–57, y29–33 부근,
  아래턱은 y35–40 부근에 있다. 가까운 앞발은 어깨에서 x46 부근으로 뻗으며
  다른 앞발은 아래로 뻗는다. 물기 뒤 recover에서 턱을 닫고 다리를 회수한다.
- 피격: 눕는 귀와 닫힌 눈, 뒤로 당겨진 어깨, 든 가까운 앞발을 짧게 보여 준다.
- 쓰러짐: 몸이 y36–60으로 내려가고 눈이 닫힌 옆누움에서 길게 멈춘다.

## 적아후의 실제 입 앵커

- skill_a: 턱/목털의 붉은 면에 O/F를 모은다. 주둥이 아래와 연결된 목털의
  x38–48, y23–35 부근이 빛을 모으는 부위다. 지팡이/손 도구는 없는 짐승이다.
- skill_b: 실제 열린 입의 x40–47, y28–35 부근에 첫 붉은 픽셀이 붙는다.
  주 포효는 위쪽 x57–61, y15–25와 아래쪽 x49–62, y35–46으로 벌어진다.
  아래 갈래 안쪽은 찢어진 작은 갈래로 나뉜다. 별도의 원 오라를 사용하지 않았다.
- skill_c: 턱을 닫고 붉은 빛을 줄인다. 분리된 잔기 세 덩어리는
  x56–59/y17–20, x57–60/y29–32, x52–56/y42–45에 있다.
  회수 순간 떠 있는 잔기는 의도한 효과다.

## 상태 구분과 GIF 읽기

독은 목을 감싸는 앞발의 굽힘/복부 수축과 독 방울의 다른 위치 및 크기다.
기절은 숙인 머리와 지지 앞발 굽힘, 두 별의 자리 변화다.
수면은 안정된 웅크림/닫힌 눈이며 주둥이와 발을 고정하고 윗등을 1px 높여 숨을 쉰다.
죽음과 다른 원본 자세다. 문자를 효과로 넣지 않았다.

`preview/gif-readback.json`에 실제 GIF에서 읽은 프레임 수와 hold를 저장했다.
전체 프레임의 RGBA는 대응하는 리터럴 원본 디코드와 byte 단위로 비교했다.
`gif-basic-contact.png`, `gif-actions-contact.png`는 실제 GIF를 다시 읽은 프레임과 hold 라벨이다.
독립 시각 검수나 사용자 선택 기록은 아니다.

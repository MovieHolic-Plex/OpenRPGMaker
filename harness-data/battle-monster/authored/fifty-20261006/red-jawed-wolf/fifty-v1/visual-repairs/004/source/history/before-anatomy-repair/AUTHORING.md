# 붉은턱늑대 — 원본 18자세 후보

## 범위와 참고 관찰

이 후보의 `source/`만 작성했다. 게임 저장소·다른 후보·brief·ledger·선택 기록은 수정하지 않았다.
참고 `references/human-size.png`를 실제로 열어 64px 안에서 작은 얼굴, 가느다란 검과 잡은 손,
실루엣의 가독성을 관찰했다. 참고 픽셀을 추출하거나 복제하지 않았다.
그림은 신규 늑대 원안이다. 검푸른 털, 붉은 턱/목털, 긴 주둥이, 두 귀,
작은 금빛 눈과 흰 송곳니, 가늘고 긴 몸, 네 다리와 털이 넓게 퍼지는 꼬리를 직접 찍었다.
왼쪽 위 광원이며 얼굴·어깨 위·허벅지 위·꼬리 윗면이 밝고 배와 먼 다리는 어둡다.

## 원본 및 저작 방식

- `palette.json`: 16색, 한 ASCII 기호당 한 RGB. `.`은 팔레트에 없는 투명 픽셀.
- `poses/`: idle_a/b/c, windup, move, attack, recover, hit, dead.
- `actions/`: skill_a/b/c, poison_a/b, stun_a/b, sleep_a/b.
- 모든 현재 pxgrid는 독립된 64행 × 64열 리터럴 ASCII 원본이다.
- `author_rows.py`: 직접 고른 행과 투명 여백의 직렬화. 자세마다 전부 작성한 행이 있다.
- `fix_clusters.py`: 실제 PNG를 본 뒤 직접 지정한 `(x, y, ASCII 문자열)` 수정.
  좌표는 0부터 시작한다. 행 재지정과 투명 여백 외에는 자동 변형을 하지 않는다.
- `history/first-pass/`: 시각 수정 전 18개 원본 및 팔레트 보존.
- `render.py`: 원본 읽기, RGB/alpha 디코드, native PNG/GIF 인코드와 진단 확대/라벨.
  그림 합성, 보간, 자동 채움, 자동 음영, 프레임 회전/이동, 참고 이미지 입력은 없다.

색 역할: K 외곽, S 배/먼 다리 깊은 그림자, B 털 기본면, M/L/H 위쪽 밝은 털;
r/R/C/O 붉은 턱과 목털; W 송곳니/발톱, Y 금빛 눈;
p/P/G 독 방울, F 포효의 뜨거운 핵과 기절 별.

## 직접 수정 기록

1. 첫 idle_a 그림을 열고 앞발/뒷발이 두꺼운 두 기둥으로 읽히는 문제를 확인했다.
   y46–60의 행을 다시 작성해 먼 뒷다리와 두 앞다리 사이를 분리했다.
   배 아래의 의도한 빈 공간과 뒤 무릎 굽힘은 남겼다.
2. idle_b의 최초 발이 y59에 끝나며 대기 때 들리는 것을 확인했다.
   y45–60을 직접 재지정해 세 idle의 하단 발 배열을 고정했다.
   몸 전체를 이동시키지 않았다. 현재 idle_a는 정확히 y60에 닿는다.
3. 최초 꼬리가 짧은 둥근 덩어리로 읽혀 standing/status 포즈의 왼쪽 꼬리 부분을
   x2–16에서 직접 새 털 덩어리로 작성했다. idle_a y25–34, idle_b y24–34,
   idle_c y27–36에 각각 굽힘을 넣었다. 돌격 move의 꼬리는 y31–38에서 뒤로 펼쳤다.
4. move/attack의 먼 뒷다리가 실루엣에서 잘 보이지 않아 x21–29, y44–53에
   엉덩이에서 이어지는 접힌 허벅지·무릎·발을 직접 작성했다.
   move에는 x40–51, y46–51에 어깨부터 이어지는 먼 앞발의 뻗기를 추가했다.
5. windup의 먼 뒷발(x19–31, y47–59)과 먼 앞발(x35–45, y48–59)을
   각각 무릎/팔꿈치가 접힌 별도 연결로 그렸다.
6. hit는 눈을 감고 귀를 눕히며 가까운 앞발을 든 자세다.
   먼 앞발의 독립된 어깨 연결을 x27–34, y46–55에서 보강했다.
7. dead의 몸을 바닥 가까이 내려놓고 눈을 닫았다. y39–44에 접힌 먼 귀를 더했다.
   sleep_a/b는 등과 꼬리가 감긴 높은 웅크림이며 dead와 원본 배열이 다르다.
   sleep의 먼 귀를 x34–40, y34–38에 따로 작성했다.
8. sleep_b의 얼굴이 숨과 함께 미끄러지는 것을 확인해 x28–63, y34–60의
   주둥이/눈/앞발 행을 직접 재지정했다. 숨 변화는 상단 등 윤곽 1px와 갈비 면에 남겼다.
9. skill_a는 붉은 목털 안에 빛이 모이고, skill_b는 실제 열린 입에 주홍 효과가 붙는다.
   skill_c는 턱을 닫고 떨어진 잔기 세 덩어리만 남긴다.
   독 방울/기절 별의 개수와 좌표 변화는 상태의 별도 직접 저작이다.

## 실제로 연 그림과 읽은 파일

`preview/sheet-native.png`의 1배 그림과 `sheet-light.png`, `sheet-dark.png`,
`sheet-checker.png`의 최근접 확대를 열었다. 다시 수정한 결과도 열었다.
8개 native GIF를 이미지 도구로 열고, GIF를 직접 디코드한
`gif-basic-contact.png`, `gif-actions-contact.png`에서 모든 프레임을 순서대로 봤다.
PNG의 다리 사이, 벌린 입, 꼬리와 등 사이 공간은 의도한 외부 빈 공간이다.
목/어깨의 사각 내부 투명 구멍이나 가로 삭제 띠를 넣지 않았다.
연결 진단은 읽기만 했고 자동으로 픽셀을 채우지 않았다.

`preview/gif-readback.json`은 8GIF의 프레임 수·노출 시간·원본 RGBA 일치 읽기 기록이다.
`preview/source-facts.json`은 원본 크기, alpha, 실제 경계, 서로 다른 18프레임 수를 기록한다.
`preview/source-sha256.json`은 현재 파일에서 계산한 로컬 소스 해시다.
하네스 검수/승인 해시를 대신하지 않는다.

## 남은 표현상 한계 및 작업 상태

- 1배 어두운 배경에서는 먼 다리의 깊은 그림자가 가까운 다리보다 약하게 읽힌다.
  밝은/체커 배경에서는 다리 사이 공간과 발의 분리가 더 분명하다.
- 공격은 지정된 네 핵심 자세라 준비에서 돌격으로 갈 때 등 길이와 무릎 변화가 빠르다.
  중간 자세를 자동 생성하지 않았다. GIF는 지정된 원본과 hold만 사용한다.
- 수면은 높게 웅크린 등을 크게 강조한 원안이다. 죽음의 낮은 옆누움과 구별되지만
  접힌 뒷다리 대부분이 몸/꼬리 뒤로 가려진다.
- 실제 게임 배치/실전 전투는 이 source 저작 범위에서 실행하지 않았다.
  독립 검수자는 호출하지 않았다. 독립 검수와 최종 판정은 하네스가 맡는다.
  사용자 승인이나 50종 전체 통과를 선언하지 않는다.

재생성은 이 폴더 안에서 `PYTHONDONTWRITEBYTECODE=1 python author_rows.py`,
`PYTHONDONTWRITEBYTECODE=1 python render.py`로 한다. 테스트/게이트 명령은 실행하지 않았다.

# 붉은턱늑대 — move 가까운 앞발 교정

## 현재 교정: 손목 뒤로 긴 발 돌출부

첨부 reference.png와 references/human-size.png를 실제로 열어 관찰했다.
참고 이미지를 추출·추적·리샘플링하지 않았다. 기존 늑대의 실루엣, 얼굴,
검푸른 털/붉은 목털, 왼쪽 위 광원과 16색 팔레트를 보존한다.

이번에는 `poses/move.pxgrid`의 **24픽셀**만 수정했다. 실제 변경 범위는
x32–41, y54–56이다. 나머지 **17자세와 팔레트는 수정 직전 파일과 바이트가 같다.**
기본9/추가9자세의 완성 리터럴 원본을 모두 유지하며 모든 쓰기는 source 안에서 했다.
이전 쓰러짐/수면의 접힌 발·꼬리·닫힌 눈 교정도 보존했다.

좌표는 0부터 시작한다. 직접 고른 세 행 문자열을 `repair_move_paw.py`에 보존했다.
pxgrid는 수정 후에도 전체 64행 × 64열 리터럴 ASCII 원본이다.

| 시작 x | y | 직접 고른 x32–49 문자열 |
|---|---|---|
| 32 | 54 | `.......KSBLHMBSWK.` |
| 32 | 55 | `.......KSBMMMSSWWK` |
| 32 | 56 | `........KKKKKKKKK.` |

- x32–38/y54–56의 뒤쪽 수평 돌출부를 명시적으로 선택한 투명 픽셀로 줄였다.
  몸통/관절의 구멍을 만드는 위치가 아니라 손목 뒤의 불필요한 발 돌출부다.
- x39/y54–55에 K 뒤 경계, x40–41/y55에 S/B 그림자·털 면을 찍었다.
  기존 x42–44의 L/H/M 윗면과 x47–48의 오른쪽 짧은 발톱은 이어 보존한다.
  아래 경계는 x40–48/y56의 짧은 K 군집이다.
- x38/y53에서 이어지는 손목과 그 위 어깨/다리 연결을 그대로 유지했다.
  들린 앞발의 최하단은 y56이며 뒷다리 지지발의 y60과 구별된다.
  move의 발 폭은 11px 이내로 줄어 attack의 짧은 발 군집과 형태 차이가 줄었다.
- 도형 본체/음영 합성/자동 구멍 채움/전체 프레임 이동·회전·보간을 사용하지 않았다.

### 현재 파일 및 실제 시각 확인

`history/before-move-paw-repair/`에 수정 직전 18격자·팔레트·AUTHORING/TIMING과
실제 로컬 파일 해시를 남겼다. `repair_move_paw.py`는 명시 좌표 교정 기록,
`inspect_move_paw.py`는 읽기/진단 확대/변경 비교만 하는 도구다.
palette/poses/actions의 현재 실제 해시는 `preview/source-sha256.json`이다.
이것은 하네스 검수나 승인 해시가 아니다.

`preview/move-paw-repair.png`를 실제로 열었다. 밝은/어두운/체커 배경 각각에서
전후 native1배, 현재 nearest3배, 보존한 attack을 비교했다. 손목 뒤 긴 덩어리가
사라지고 짧은 발 하단과 오른쪽 발가락으로 읽힌다. 수정 부위의 어깨/손목 연결은
남고 본체의 투명 홈은 생기지 않았다.

현재 `sheet-native.png`, 실제 GIF를 디코드한 `gif-basic-contact.png`와
`gif-actions-contact.png`도 열었다. move→attack에서 발의 후방 길이가 튀던
차이가 줄었다. 기존 기술/상태/수면 해부 구조는 그대로다.
8GIF를 다시 인코딩하고 실제 파일의 모든 프레임 RGBA/hold를 원본/시간표와
재대조했다. `preview/gif-readback.json`에 결과를 저장했다.
contact sheet에서의 순서 확인은 실시간 재생/게임 전투 확인과 구별한다.

`preview/move-paw-repair-readback.json`에 24개 변경 좌표와 다른17자세·팔레트의
바이트 보존, 모든 격자의64×64·투명 테두리·최하단 y≤60을 기록했다.
`preview/source-facts.json`에는 서로 다른18프레임·16색·alpha0/255·idle_a 최하단
y60·8GIF를 기록했다. 형식 읽기 결과는 미감/검수 통과의 증명이 아니다.

현재 격자로 미리보기를 재생성하는 명령:

```bash
PYTHONDONTWRITEBYTECODE=1 python source/render.py
PYTHONDONTWRITEBYTECODE=1 python source/inspect_move_paw.py
```

### 현재 남은 시각적 한계와 상태

- 준비→돌격과 돌격→물기의 큰 자세 전환은 기존대로다. 중간 자세 추가나
  실제 게임 이동 거리·명중·반복 속도 확인은 하지 않았다.
- 어두운 배경에서 S/K 다리 경계의 대비가 낮다. 1배에서 발톱과 웅크린
  몸 안쪽의 접힌 발/꼬리는 작은 군집이며 이전 실루엣을 보존했다.
- 테스트/게이트를 실행하지 않았고 독립 검수자를 직접 호출하지 않았다.
  하네스의 새 독립 검수가 남아 있다. 이 후보나50종 전체의 통과, 사용자
  승인을 선언하지 않으며 저작 모델 신원도 이 문서에서 만들지 않는다.

## 이전 교정 기록 — 세 자세 해부 구조 보완

아래는 이전 작업 기록이다. 이번 변경 범위와 현재 확인 결과는 위 절을 따른다.

## 범위와 참고 관찰

이 작업은 후보의 `source/` 안에서만 수행했다. 기존 18개 64×64 리터럴 ASCII
원본 중 `dead`, `sleep_a`, `sleep_b`만 수정했다. 다른 15개 자세와 16색 팔레트는
수정 전 파일과 바이트가 같다. 게임 저장소, brief, ledger, 다른 후보, 검수 결과는 수정하지 않았다.

첨부 `reference.png`와 `references/human-size.png`를 실제로 열었다.
늑대의 긴 주둥이, 두 귀, 검푸른 털, 붉은 턱/목털, 왼쪽 위 광원을 보존했다.
64px 검객은 크기와 얼굴/손 연결을 관찰하는 용도로만 봤다.
참고 그림을 추출·추적·복제·리샘플링하지 않았다.

## 직접 선택한 픽셀 수정

좌표는 각 64×64 셀의 좌상단을 (0,0)으로 한다.
모든 수정은 `repair_anatomy.py`의 명시적인 `(x, y, ASCII 문자열)`이다.
수정 결과는 전체 64행 × 64열 원본 pxgrid에 저장되어 있다.
자동 프레임 변형, 도형 본체, 음영 합성, 자동 구멍 채움은 사용하지 않았다.

### dead — 103픽셀 변경

- 실제 변경 범위: x12–39, y51–59. 기존 바닥 윤곽 y60은 보존했다.
- x24–29/y51–56에 어깨에서 내려오는 B/M 털 면과 S/K 경계를 찍었다.
  접힌 팔꿈치에서 x25–33/y57–58의 손목으로 이어진다.
- x28–39/y58–59에 수평으로 놓인 짧은 앞발과 작은 발톱, 먼 앞발의 어두운
  경계를 나눴다. 기존 긴 하단 덩어리에 앞다리의 꺾임과 발끝이 생기도록 했다.
- x14–22/y52–56에는 엉덩이 안쪽의 접힌 허벅지/발목 경계를,
  x12–22/y57–59에는 짧은 뒷발 면과 발끝을 찍었다.
- 기존 닫힌 눈, 낮은 몸통, 귀와 주둥이, 붉은 목털의 위쪽은 보존했다.

### sleep_a — 138픽셀 / sleep_b — 136픽셀 변경

- 실제 변경 범위: x8–42, y42–59. 외곽의 y60 접지선은 보존했다.
- x8–26/y49–58에 꼬리가 배 아래를 감싸는 S/K 안쪽 경계를 찍고,
  M/B 털 면이 굽이를 따라 이어지게 했다. x24–28/y51–54의 짧은
  털 끝으로 꼬리의 끝을 구분했다. 꼬리는 바깥 등 광택선과 별개의 하단 면이다.
- x29–35/y51–56에 턱 아래로 내려오는 접힌 앞다리와 손목을 찍었다.
  먼 앞발은 x36–42/y54–56의 작은 면, 가까운 앞발은
  x31–41/y57–59의 낮고 짧은 면으로 분리했다. 경계는 불투명 S/K 픽셀이며
  몸 안에 투명 홈이나 가로 삭제 줄을 만들지 않았다.
- x37–38/y42의 두 픽셀 닫힌 눈꺼풀과 그 아래 x38–39/y43의
  얼굴색을 직접 골랐다. 검은 코와 떨어진 짧은 눈꺼풀이다.
- 두 수면 자세의 발·꼬리·눈 좌표는 같은 해부 위치에 유지한다.
  기존 sleep_b의 높아진 등 윤곽과 갈비/가슴 면 차이로 호흡을 남겼다.
  몸 전체를 이동시키거나 회전하지 않았다.

## 원본 및 보조 코드 보존

- `poses/`: 기본 9자세 전체 리터럴 격자.
- `actions/`: 기술3, 독2, 기절2, 수면2 전체 리터럴 격자.
- `palette.json`: 기존 16색. `.`은 투명이며 팔레트에 없다.
- `history/first-pass/`: 이전 최초 원안.
- `history/before-anatomy-repair/`: 이번 수정 전 18격자, 팔레트,
  AUTHORING/TIMING 문서와 실제 파일 SHA-256 기록.
- `author_rows.py`, `fix_clusters.py`: 기존 직접 저작 행/좌표 기록.
- `repair_anatomy.py`: 이번 세 자세의 직접 고른 픽셀 문자열.
- `render.py`: 원본 디코드 및 PNG/GIF 저장, 진단 확대, 실제 GIF 재읽기.
- `inspect_repair.py`: 수정 전후를 1배/최근접3배, 세 배경으로 보여주는 읽기 전용 도구.

후보 폴더에서 다음 순서로 재생성한다.

```bash
PYTHONDONTWRITEBYTECODE=1 python source/render.py
PYTHONDONTWRITEBYTECODE=1 python source/inspect_repair.py
```

`author_rows.py`는 이전 저작 기록이며 현재 교정본의 재렌더 명령이 아니다.

8개 GIF를 다시 만들었다. `render.py`에서 실제 인코딩된 GIF를 읽어 모든 프레임의

idle_a 최하단 y60, 8GIF.

`preview/source-sha256.json`: 현재 로컬 원본 해시. 하네스 검수/승인 해시가 아니다.

## 남은 시각적 한계와 상태

- 수면의 높은 웅크린 등과 몸에 가려진 뒷다리는 기존 실루엣을 유지한다.
  이번에 추가한 꼬리/앞발도 1배에서는 작은 군집으로 읽히며, 어두운 배경에서
  깊은 S/K 경계의 대비가 밝은 배경보다 낮다.
- 쓰러짐의 먼 앞발은 가까운 앞발 뒤에서 짧게 드러난다. 사족 구조를 보완했지만
  네 다리가 모두 펼쳐진 옆누움은 아니다.
- 준비→돌격 전환은 기존 핵심 자세의 빠른 변화가 남아 있다.
  중간 자세 자동 생성이나 게임 런타임 변경은 하지 않았다.
- 실제 게임 전투는 실행하지 않았고 테스트/게이트도 실행하지 않았다.
  독립 검수자는 직접 호출하지 않았다. 하네스의 새 독립 검수와 사용자 선택이 남아 있다.
  이 후보 또는 50종 전체의 통과, 사용자 승인을 선언하지 않는다.

# 붉은턱늑대 — 세 자세 해부 구조 보완

## 범위와 참고 관찰

이 작업은 후보의 `source/` 안에서만 수행했다. 기존 18개 64×64 리터럴 ASCII
원본 중 `dead`, `sleep_a`, `sleep_b`만 수정했다. 다른 15개 자세와 16색 팔레트는
수정 전 파일과 바이트가 같다. 게임 저장소, brief, ledger, 다른 후보, 검수 결과는 수정하지 않았다.

첨부 `reference.png`와 `references/human-size.png`를 실제로 열었다.
늑대의 긴 주둥이, 두 귀, 검푸른 털, 붉은 턱/목털, 왼쪽 위 광원을 보존했다.
64px 검객은 크기와 얼굴/손 연결을 관찰하는 용도로만 봤다.
참고 그림을 추출·추적·복제·리샘플링하지 않았다.

## 직접 선택한 픽셀 수정

좌표는 각 64×64 셀의 좌상단을 (0,0)으로 한다.
모든 수정은 `repair_anatomy.py`의 명시적인 `(x, y, ASCII 문자열)`이다.
수정 결과는 전체 64행 × 64열 원본 pxgrid에 저장되어 있다.
자동 프레임 변형, 도형 본체, 음영 합성, 자동 구멍 채움은 사용하지 않았다.

### dead — 103픽셀 변경

- 실제 변경 범위: x12–39, y51–59. 기존 바닥 윤곽 y60은 보존했다.
- x24–29/y51–56에 어깨에서 내려오는 B/M 털 면과 S/K 경계를 찍었다.
  접힌 팔꿈치에서 x25–33/y57–58의 손목으로 이어진다.
- x28–39/y58–59에 수평으로 놓인 짧은 앞발과 작은 발톱, 먼 앞발의 어두운
  경계를 나눴다. 기존 긴 하단 덩어리에 앞다리의 꺾임과 발끝이 생기도록 했다.
- x14–22/y52–56에는 엉덩이 안쪽의 접힌 허벅지/발목 경계를,
  x12–22/y57–59에는 짧은 뒷발 면과 발끝을 찍었다.
- 기존 닫힌 눈, 낮은 몸통, 귀와 주둥이, 붉은 목털의 위쪽은 보존했다.

### sleep_a — 138픽셀 / sleep_b — 136픽셀 변경

- 실제 변경 범위: x8–42, y42–59. 외곽의 y60 접지선은 보존했다.
- x8–26/y49–58에 꼬리가 배 아래를 감싸는 S/K 안쪽 경계를 찍고,
  M/B 털 면이 굽이를 따라 이어지게 했다. x24–28/y51–54의 짧은
  털 끝으로 꼬리의 끝을 구분했다. 꼬리는 바깥 등 광택선과 별개의 하단 면이다.
- x29–35/y51–56에 턱 아래로 내려오는 접힌 앞다리와 손목을 찍었다.
  먼 앞발은 x36–42/y54–56의 작은 면, 가까운 앞발은
  x31–41/y57–59의 낮고 짧은 면으로 분리했다. 경계는 불투명 S/K 픽셀이며
  몸 안에 투명 홈이나 가로 삭제 줄을 만들지 않았다.
- x37–38/y42의 두 픽셀 닫힌 눈꺼풀과 그 아래 x38–39/y43의
  얼굴색을 직접 골랐다. 검은 코와 떨어진 짧은 눈꺼풀이다.
- 두 수면 자세의 발·꼬리·눈 좌표는 같은 해부 위치에 유지한다.
  기존 sleep_b의 높아진 등 윤곽과 갈비/가슴 면 차이로 호흡을 남겼다.
  몸 전체를 이동시키거나 회전하지 않았다.

## 원본 및 보조 코드 보존

- `poses/`: 기본 9자세 전체 리터럴 격자.
- `actions/`: 기술3, 독2, 기절2, 수면2 전체 리터럴 격자.
- `palette.json`: 기존 16색. `.`은 투명이며 팔레트에 없다.
- `history/first-pass/`: 이전 최초 원안.
- `history/before-anatomy-repair/`: 이번 수정 전 18격자, 팔레트,
  AUTHORING/TIMING 문서와 실제 파일 SHA-256 기록.
- `author_rows.py`, `fix_clusters.py`: 기존 직접 저작 행/좌표 기록.
- `repair_anatomy.py`: 이번 세 자세의 직접 고른 픽셀 문자열.
- `render.py`: 원본 디코드 및 PNG/GIF 저장, 진단 확대, 실제 GIF 재읽기.
- `inspect_repair.py`: 수정 전후를 1배/최근접3배, 세 배경으로 보여주는 읽기 전용 도구.

후보 폴더에서 다음 순서로 재생성한다.

```bash
PYTHONDONTWRITEBYTECODE=1 python source/author_rows.py
PYTHONDONTWRITEBYTECODE=1 python source/render.py
PYTHONDONTWRITEBYTECODE=1 python source/inspect_repair.py
```

현재 `preview/sheet-native.png`, `sheet-light.png`, `sheet-dark.png`,

마지막 그림에는 세 수정 자세의 전후 1배와 현재 최근접3배가 밝은/어두운/체커
배경마다 있다. 접힌 발과 꼬리 경계, 닫힌 눈과 코의 분리, 기존 외곽을 확인했다.

8개 GIF를 다시 만들었다. `render.py`에서 실제 인코딩된 GIF를 읽어 모든 프레임의
RGBA와 hold를 원본 디코드/시간표와 비교했다. 재읽기 결과로 만든

수면 발과 꼬리는 두 프레임에서 같은 위치에 남으며 등·가슴의 작은 호흡 변화가 있다.
GIF contact sheet 확인은 실시간 게임 전투의 속도·명중 확인과는 별개다.

`preview/source-facts.json`: 18개 서로 다른 프레임, 64×64, 알파 0/255,
idle_a 최하단 y60, 8GIF.
`preview/anatomy-repair-readback.json`: 세 변경 파일과 실제 변경 픽셀 수/범위,
15개 원본 보존, 팔레트 보존, 각 격자의 64행/64열·투명 테두리·최하단 좌표.
`preview/gif-readback.json`: 8GIF의 실제 프레임 수/hold/원본 RGBA 일치.
`preview/source-sha256.json`: 현재 로컬 원본 해시. 하네스 검수/승인 해시가 아니다.

## 남은 시각적 한계와 상태

- 수면의 높은 웅크린 등과 몸에 가려진 뒷다리는 기존 실루엣을 유지한다.
  이번에 추가한 꼬리/앞발도 1배에서는 작은 군집으로 읽히며, 어두운 배경에서
  깊은 S/K 경계의 대비가 밝은 배경보다 낮다.
- 쓰러짐의 먼 앞발은 가까운 앞발 뒤에서 짧게 드러난다. 사족 구조를 보완했지만
  네 다리가 모두 펼쳐진 옆누움은 아니다.
- 준비→돌격 전환은 기존 핵심 자세의 빠른 변화가 남아 있다.
  중간 자세 자동 생성이나 게임 런타임 변경은 하지 않았다.
- 실제 게임 전투는 실행하지 않았고 테스트/게이트도 실행하지 않았다.
  독립 검수자는 직접 호출하지 않았다. 하네스의 새 독립 검수와 사용자 선택이 남아 있다.
  이 후보 또는 50종 전체의 통과, 사용자 승인을 선언하지 않는다.

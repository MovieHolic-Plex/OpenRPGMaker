# 뇌각기린 — 18자세 / 8GIF 타이밍과 실제 앵커

현재 리터럴 원본으로 8GIF를 다시 기록했다. 기존 유지 시간을 보존했다. 별도 중간 프레임 생성, 프레임 전체 이동·회전·보간은 없다. 아래 GIF 반복은 비교용이며 쓰러짐의 재시작도 진단용이다.

|---|---|---|

## 금뿔 돌격: 준비 → 밀기 → 접촉 → 회수

좌표는 native 0부터 시작한다.

- **windup / 260ms:** 뒤 허벅지와 무릎을 접어 압축한 원안의 지지 다리를 유지했다. 새 금뿔 밑동 x94–99/y62–64는 이마의 비취 부피에 붙고 끝은 x123–124/y46–48에 있다. 두 귀·볼·눈·턱은 긴 뿔 아래에서 직접 다시 구성했다.
- **move / 110ms:** 기존 뒤발의 긴 밀기와 당긴 앞발을 유지했다. 새 금뿔 밑동 x95–100/y62–64에서 끝 x124–125/y48–50까지 이어진다. 준비보다 앞쪽으로 향한 머리와 실제 어깨·먼 가슴 면이 있다.
- **attack / 180ms:** 머리·목을 낮춘 실제 접촉 자세다. 새 금뿔은 낮은 이마 x93–100/y78–81에서 x125/y70–72의 끝까지 이어진다. 끝 윤곽 x126과 투명 x127을 구분했다. 주둥이는 뿔 끝보다 뒤에 있다. 가까운 앞다리는 x78/y107 부근에서 오른쪽으로 뻗어 x100–110/y124의 실제 굽 밑면으로 지지한다. 먼 앞다리는 그 뒤의 x76–83/y109–111 부근에서 따로 내려가 짧은 어두운 굽으로 이어진다. 어깨·가슴·관절 경계를 직접 골랐다.
- **recover / 200ms:** 별도로 저작된 세워지는 목과 회수하는 지지발을 유지하고, 가까운 어깨 / 먼 가슴 / 먼 다리 뿌리의 깊이를 보수했다.

이는 셀 안의 뿔 접촉 표현이다. 실제 상대 위치·게임의 피해 발생·충돌 좌표·발 슬라이딩을 확인하지 않았다.

## 뇌각격: 손 / 입 / 도구 대신 실제 뿔 발원점

이번 보수는 기술의 원래 효과 픽셀과 순서를 보존했다. 각 기술 자세의 어깨와 먼 가슴 면만 별도 좌표에서 보수했다.

- **skill_a / 모으기 / 380ms:** 실제 금뿔 끝 `(102,20)` 부근에서 x96–108/y9–20의 금백 기 군집으로 연결된다. 세운 목·두 귀·가까운 어깨·접지한 발을 유지한다.
- **skill_b / 방전 접촉 / 260ms:** 금뿔 끝 `(94,39)` 부근에서 x94–98/y35–38의 연결 줄기를 거쳐 큰 상향 / 하향 번개로 갈라진다. 상향은 x112/y2 부근과 x117/y10–16의 갈래로 뻗는다. 하향은 x104–113/y53–58에서 다시 갈라져 본줄기 x101–105/y82–84, 옆가지 x111/y60 부근과 x121/y69의 끝으로 이어진다. 분기 사이의 의도된 빈 공간과 서로 다른 끝을 보존했다.
- **skill_c / 잔전류 회수 / 300ms:** 다시 든 뿔 끝 `(111,23)` 부근에 짧은 연결 전류를 남긴다. x110–113/y15–19 및 x120–123/y31–36의 끊어진 잔상은 의도된 파편이다. 실제 목·턱·지지발의 회수 자세를 유지한다.

## 상태 쌍

- **독 / 430 + 430ms:** 아픈 턱과 낮은 어깨, 압축된 다리 배열이 실제로 다르다. 두 자세의 서로 다른 보라 기포를 유지했다.
- **기절 / 480 + 480ms:** stun_a의 턱 y100과 stun_b의 턱 y104, 서로 다른 앞무릎·지지굽, 별 위치를 유지했다. 처진 몸의 가까운 어깨와 뒤 가슴을 각각 보수했다.
- **수면 / 700 + 700ms:** sleep_a의 감긴 눈꺼풀 x91–93/y105와 sleep_b의 x92–94/y106은 검은 코와 분리된 짧은 군집이다. sleep_b는 턱이 y116으로 내려오고 등·목 능선 y82 → y81 및 가슴 윤곽이 따로 달라진다. 같은 접힌 네 발·꼬리·실제 y124 하중 윤곽을 유지했다. 금뿔은 각각 x123/y83 및 x123/y85 부근의 끝으로 낮게 이어진다. 이번 어깨 명암 보수에서도 눈과 호흡의 기존 윤곽 차이를 보존했다.

## 관찰 범위

실제 저장 GIF를 재디코딩한 `previews/eight-gifs-decoded-1x.png`를 열어 프레임 배열과 연결을 비교했다. 파일에서 읽은 실제 유지 시간과 계산한 파일 해시는 `previews/gif-decoding.json`에 있다. 실제 시간의 GIF 재생 감각이나 게임 내 전투·음향은 관찰하지 않았다. 이 기록은 검수 통과나 사용자 승인을 의미하지 않는다.

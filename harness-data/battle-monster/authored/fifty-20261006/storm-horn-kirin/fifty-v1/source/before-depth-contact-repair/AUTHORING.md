# 뇌각기린 — 지적 좌표 직접 수정 기록

## 범위와 보존

이 작업은 기존 `fifty-v1` 초안의 수정이다. 모든 쓰기는 이 후보의 `source/` 안에서만 했다. 저장소 코드, 게임 저장소, brief, ledger, 다른 후보와 검수 결과를 수정하지 않았다. 별도 검수자는 호출하지 않았고 테스트/게이트도 실행하지 않았다. 독립 검수와 사용자 선택은 하네스가 맡는다. 통과 또는 사용자 승인을 선언하지 않는다.

첨부 현재 18자세 시트와 64px 검객 참고를 실제로 열었다. 검객에서는 작은 얼굴과 상체/손/무기의 연결, 인간과 보스의 크기감을 관찰했다. 참고에서 픽셀을 추출하거나 추적하지 않았다. 수정 전 원본 18격자와 팔레트, 이전 문서는 `prior-draft/`에 보존했다.

팔레트 18색은 바이트 단위로 유지했다. 현재 원본은 `poses/`의 9개 및 `actions/`의 9개 완전한 128×128 ASCII 행이다. 넓은 비취 밝은 면/녹청 그림자, 남청 갈기, 금색 배판/긴 한 뿔, 두 작은 귀와 네 발굽을 유지했다. 빛은 왼쪽 위다.

## 직접 고른 수정 좌표

좌표는 0부터 시작하는 native `(x,y)`다. 아래 수정은 자세별로 고른 실제 문자열이며 좌표를 다른 자세에 자동 복사하지 않았다.

| 자세 | 명시 변경 |
|---|---|
| idle_a | `(45..47,70)`을 `jjj`, `(47,69)`와 `(51,66)`을 남청 갈기 `b`로 닫았다. 5px 변경. |
| idle_b | `(44..47,70)`을 `jjjj`, `(47..48,71)`을 `jj`, `(47,69)`을 `b`로 닫았다. 7px 변경. |
| idle_c | `(45..47,71)`을 `jjj`, `(48,72)`를 `j`로 닫았다. 4px 변경. |
| recover | `(49..52,74)`를 `jjjj`, `(53,71)`과 `(54,70)`을 `b`, `(51..52,73)`을 `bb`로 닫았다. 8px 변경. |
| skill_a | 같은 접합부를 실제 이미지에서 따로 확인해 `(44..46,70)`의 `jjj`와 `(47,71)`의 `j`를 기록했다. 4px 변경. |
| windup | y105–124의 두 뒷다리를 별도로 다시 찍었다. 가까운 넓은 허벅지는 엉덩이 x29–40에서 무릎 x35–45로 압축되고, hock은 x34–43에서 접혀 발목 x30–38/받친 굽 x28–38로 돌아온다. 가까운 굽 밑면은 y124, 먼 굽은 y121이다. 444px 변경. |
| attack | 내려간 머리/뿔/목은 보존했다. 어깨 x80–89/y102의 위다리를 오른쪽 무릎 x89–99/y112로 내딛고, 굽은 발목 x98–107/y118에서 넓은 발굽 x99–111/y121–123 및 실제 밑면 y124로 이어진다. 먼 앞다리는 어깨 아래 x75–92의 별도 어두운 면/굽으로 남겼다. 새 배열의 `(69,105)` 한 구멍도 `j`로 고쳤다. 618px 변경. |
| sleep_a | 높고 팽팽한 목/머리/뿔을 직접 지우고, 등갈기에서 이어지는 접힌 목 능선 y82–98, 낮아진 머리/턱 y98–115를 새 문자열로 찍었다. 눈은 x91–93/y105의 3px 닫힌 선, 코는 x101–102/y108 부근의 별도 군집이다. 두 귀는 y91–98에 접혀 있으며 금뿔은 실제 이마 x95–102/y99–101에서 x123/y83의 끝까지 이어진다. 접힌 앞/뒷발과 말린 꼬리를 보존했다. 1709px 변경. |
| sleep_b | 첫 수면 프레임을 이동시키지 않았다. y81의 조금 부푼 등/목 능선, 따로 압축한 가슴, y99–116의 내려온 고개를 각각 찍었다. 닫힌 눈은 x92–94/y106, 코는 x102–103/y109 부근이다. 뿔 끝은 x123/y85이며 긴 금뿔의 재질과 이마 연결을 유지한다. 같은 네 발/꼬리와 y124 하중 윤곽을 유지했다. 1628px 변경. |

읽기 전용 투명 공간 진단은 위치를 찾는 보조 자료로만 썼다. 다리 사이, 접힌 발 안쪽, 꼬리 안쪽, 번개의 가지 사이에 있는 의도된 빈 공간은 남겼다. 자동 구멍 채우기를 하지 않았다.

## PNG를 열고 다시 고른 부분

첫 수정 PNG에서 수면 머리 면이 두 귀를 덮은 것을 확인해 각 수면 자세의 귀를 따로 복구했다. 목/볼 겹침의 작은 투명 틈은 `sleep_a` `(82..83,97)`, `sleep_b` `(82..83,96)`, `(81..83,97)`, `(84,98)`, `(95..96,100)`에 직접 비취 픽셀을 골랐다. 첫 얼굴 문자열의 여분 검은 점 `(89,105)`도 `sleep_a`에서 `j`로 고쳐 눈꺼풀을 한 짧은 선으로 정리했다.

18자세를 밝은/어두운/체커 배경의 1배 PNG로 열었다. 18자세의 최근접 체커 확대와 밝은/어두운 확대, 변경된 준비/접촉/수면의 세 배경 3배 확인판을 열었다. 대기/회수/기술의 갈기-몸 면이 닫히고, 의도된 다리 사이 틈은 남아 있다. 발굽과 접힌 발, 말린 꼬리는 본체와 연결된다. 실제 저장 GIF를 재디코딩한 1배 8동작 프레임판도 열어 준비의 압축 → 전진의 밀기 → 앞발의 넓은 접촉 → 회수 및 수면의 고개/가슴 변화를 비교했다. 이 확인은 실제 게임의 타격 위치나 재생 품질 판정을 대신하지 않는다.

## 원본/보조 코드/결과

- `authored-rows.txt`, `repairs.txt`: 기존 원본과 이전 명시 저작 기록, 보존.
- `reviewer-repair-runs.txt`: 이번 갈기 접합부와 돌격 두 다리의 직접 `(y,x,ASCII)` 기록.
- `sleep-rest-runs.txt`: 수면 쌍의 별도로 선택한 목/머리/귀/뿔/면 문자열.
- `visual-followup-runs.txt`: 실제 PNG를 열고 고른 추가 교정.
- `author.py`: 위 명시 기록을 읽어 최종 완전한 ASCII 행으로 기록. 도형/수식/회전/프레임 이동/음영 합성 없음.
- `render.py`: 원본 그대로 투명 PNG, 3×3 기본/추가 시트, 8개 GIF를 기록하고 GIF를 재디코딩한다.
- `repair_diagnostics.py`: 원본을 읽기만 하며 1배 전후 비교와 세 배경 진단 그림/사실 JSON을 만든다.
- `inspect_pixels.py`: 읽기 전용 크기/여백/군집 정보. 연결 수치는 예술적 합격 근거로 쓰지 않는다.

재현 순서는 후보 폴더에서 `python source/author.py`, `python source/render.py`, `python source/repair_diagnostics.py`다. 결과는 모두 source 안에만 기록된다. 최종 팔레트/격자는 이미 저장되어 있어 재저작 명령을 실행할 필요 없이 읽을 수 있다.

현재 자료:

- `previews/*-1x.png`, `previews/*-3x.png`: 현재 원본의 밝은/어두운/체커 비교 그림.
- `previews/repair-comparison-*-1x.png`: 변경 9자세의 원안/수정본 비교.
- `previews/battle-sheet.png`, `previews/actions-sheet.png`: 각각 현재 9자세 투명 PNG.
- `previews/{idle,attack,hit,dead,skill,poison,stun,sleep}.gif`: 현재 8동작.
- `previews/eight-gifs-decoded-1x.png`, `gif-decoding.json`: 실제 저장된 GIF의 재읽기 프레임/시간/계산 해시.
- `previews/repair-facts.json`, `pixels.json`, `native-diagnostics.json`: 현재 격자/PNG 해시와 읽기 전용 파일 사실.
- `review.html`: 현재 PNG/GIF를 연결하는 로컬 비교 화면. 사용자 선택 기능 없음.

18격자는 모두 128×128, 알 수 없는 팔레트 기호 없음, 1px 투명 테두리 침범 없음, 최저 본체/발 픽셀 y124다. `idle_a`의 실제 발굽이 y124에 닿는다. 9자세(`move`, `hit`, `dead`, `skill_b/c`, `poison_a/b`, `stun_a/b`)는 수정 전과 바이트 단위로 동일하다. 이 사실들은 형식 관찰이며 독립 검수 통과 선언이 아니다.

`checkpoints/`와 `prior-draft/`는 과거 저작 자료이고 현재 그림이 아니다. 이전 판본의 오래된 `file-facts.json`, `pixel-report.txt`도 `prior-draft/previews/`로 옮겼다.

## 남은 시각적 한계

- 대형 보스의 긴 목 때문에 접촉에서 회수로 목 높이가 크게 바뀐다. 현재 GIF hold를 유지했으며 중간 자세를 자동 합성하지 않았다.
- 접촉 앞다리는 넓은 전진 발걸음이며 몸통/어깨의 기울기는 보존했다. 실제 게임에서 뿔의 닿는 위치, 상대와의 거리, 충격 순간은 확인하지 않았다.
- 어두운 배경에서는 먼 발굽과 수면의 목 아래 겹침 경계 대비가 낮다. 수면 두 귀는 접혀 작은 군집으로 읽힌다.
- 수면 머리는 이번 낮은 목 자세에 맞춰 새로 찍었다. 대기 머리와의 형태 일관성 및 호흡 크기는 다음 실제 독립 검수에서 확인할 사항이다.

수정본은 재검수용 후보다. 사용자의 선택과 하네스의 독립 판정은 아직 이 문서로 대체하지 않는다.

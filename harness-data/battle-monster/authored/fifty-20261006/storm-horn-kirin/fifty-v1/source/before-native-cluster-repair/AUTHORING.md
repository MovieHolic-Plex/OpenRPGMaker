# 뇌각기린 — 얼굴 깊이·돌격 접촉·번개·기절 수정

## 범위와 원본

기존 후보의 `source/` 안에서만 수정했다. 수정 전 18격자, 팔레트, 문서와 저작 코드는 `before-depth-contact-repair/`에 보존했다. 이전 `prior-draft/`, `checkpoints/`와 기존 저작 문자열도 남겼다. 저장소, 게임 저장소, ledger, brief, 다른 후보와 검수 결과는 수정하지 않았다.

첨부 18자세 시트와 64px 검객 이미지를 실제로 열었다. 비취 사족의 긴 목, 한 금뿔, 두 귀, 푸른 갈기, 금 배판, 가까운 다리와 먼 다리의 겹침을 관찰했다. 검객은 얼굴·크기·관절 연결 참고로만 보았다. 참고 픽셀의 추출·추적·재배포는 하지 않았다.

현재 원본은 `poses/` 9개와 `actions/` 9개의 완전한 128×128 ASCII 행이다. 18색 팔레트를 그대로 유지했다. 모든 픽셀은 기존 리터럴 행 또는 자세별로 직접 고른 `(y, x, ASCII)` 문자열이다. 전체 프레임 이동·회전·보간, 도형 래스터화, 수식 음영, 자동 구멍 채우기, 생성 이미지를 사용하지 않았다. 최근접 확대는 진단 표시이며 원본 저작에는 반영하지 않았다.

## PNG를 열고 다시 고른 부분

첫 수정 후 18자세의 1배/확대 PNG와 선택 부위의 밝은·어두운·체커 PNG를 열었다. 다음 문제를 발견해 `depth-visual-followup-runs.txt`로 고쳤다.

- attack의 x114 부근/y85–86에 주둥이 끝 군집이 떠 있었다. x93부터의 y84–89 실제 행을 다시 골라 볼 → 입끝 → 턱을 끊김 없이 연결했다. 작은 이중 외곽도 정리했다.
- stun_a의 새 지지 굽 왼쪽에 이전 굽 x66–67/y120–123 윤곽이 남아 직접 지웠다. stun_b의 x64/y120–123 잔여 점도 직접 지웠다.
- 기절 어깨 수정이 금 목판 일부에 겹친 것을 원본 행과 대조했다. 해당 금판 문자열을 각각 복원하고 깊이 면은 실제 비취 어깨 쪽에서 따로 골랐다.

최종 18자세의 밝은·어두운·체커 1배 PNG와 전체 체커 확대를 실제로 열었다. 지적된 다섯 프레임을 밝은 확대에서 다시 열어 주둥이 연결과 잔여 윤곽 제거를 확인했다. 다리 사이, 접힌 발 안쪽, 꼬리 안쪽과 번개 가지 사이의 의도된 빈 공간은 남겼다.

8개 실제 저장 GIF를 재디코딩한 `eight-gifs-decoded-1x.png`를 열어 전체 프레임도 비교했다. 준비의 뒤다리 압축 → 이동의 밀기 → 접촉의 낮아진 뿔/목 → 회수, 기절의 엇갈린 무릎/턱, 감긴 수면 눈과 호흡 차이를 보았다. 이것은 정지 프레임 비교다. 실제 시간의 재생 감각과 게임 충돌·거리·슬라이딩은 관찰하지 않았다.

## 원본·보조 코드·출력

- `authored-rows.txt`와 기존 수리 기록: 이전 직접 저작 원본, 보존.
- `depth-contact-runs.txt`: 18자세의 자세별 주둥이/볼/어깨 문자열.
- `ram-head-runs.txt`: 접촉의 낮은 뿔/두 귀/머리/목의 명시 삭제와 새 픽셀.
- `bolt-fork-runs.txt`: 실제 뿔 접합부와 아래 번개의 큰 분기.
- `dazed-anatomy-runs.txt`: 두 기절 자세의 머리·목·앞무릎·발목·굽.
- `depth-visual-followup-runs.txt`: PNG를 실제로 열고 고른 후속 수정.
- `author.py`: 명시 기록을 읽어 완전한 ASCII 행을 기록. 도형/프레임 변형 기능 없음.
- `render.py`: 원본 그대로 투명 PNG, 두 3×3 시트, 8GIF와 실제 GIF 재디코딩 프레임을 기록.
- `repair_diagnostics.py`: 수정 직전 원본과 최종 격자를 읽어 세 배경 1배/확대/전후 비교와 현재 파일 사실을 기록. 격자 수정 없음.
- `inspect_pixels.py`: 과거 읽기 전용 진단 코드, 보존. 이번에는 실행하지 않았다.
- `before-depth-contact-repair/`: 이번 수정 전 원본. 오래된 진단 출력도 이 폴더의 `previews/`로 분리했다.
- `review.html`: 현재 18PNG/8GIF와 배경/배율 선택을 제공하는 로컬 비교 화면. 선택/승인 기록 기능 없음.

현재 출력은 `previews/`에 있다. `light/dark/checker-1x.png`는 18자세 세 배경이고 `light/dark/checker-3x.png`는 전체 확대다. `depth-contact-*-3x.png`는 주요 변경 부위, `repair-comparison-*-1x.png`는 18자세 수정 전후다. `battle-sheet.png`, `actions-sheet.png`는 투명 3×3 시트다. 8개 GIF와 실제 저장 GIF의 재디코딩 판도 보존했다.

팔레트는 수정 직전과 동일하다. 현재 파일 사실의 18격자 행 수/폭은 모두 128이며 최저 잉크 y124다. idle_a의 실제 발굽과 접촉·기절의 실제 지지 굽도 y124에 있다. 여백/기호 정보와 실제 계산된 파일 해시는 `previews/repair-facts.json`, `pixels.json`, `gif-decoding.json`에 있다. 이 읽기 전용 자료는 그림 승인이나 저작 방식의 인증이 아니다.

## 남은 시각적 한계

- 주둥이 끝/볼/어깨의 앞쪽 면은 native 2–3px로 제한적이다. 긴 목의 우향 실루엣은 여전히 측면 성격이 강하므로 3/4 깊이의 충분함은 새 독립 검수에서 판단해야 한다.
- 접촉에서 회수로 목 높이가 크게 달라진다. 중간 자세를 합성하지 않았고 기존 hold를 유지했다. 실제 게임 충돌 위치·타격 시점·프레임 튐은 확인하지 않았다.
- 밝은 배경에서는 금백 번개와 별의 대비가 낮다. 어두운 배경에서는 먼 발굽과 일부 목 아래 경계가 약하다. 팔레트와 기존 재질을 유지했다.
- 기절 머리는 강하게 접힌 새 각도다. 대기 머리와의 동일성과 다리 흔들림의 자연스러움은 실제 재검수 대상이다.

테스트/게이트와 별도 검수자는 실행하거나 호출하지 않았다. 검수 결과·모델 기록·승인 상태를 만들거나 바꾸지 않았다. 현재 자료는 사용자 판단과 하네스의 새 독립 검수를 위한 수정 후보이며 통과 또는 사용자 승인을 선언하지 않는다.

# 뇌각기린 — 어깨 깊이 / 긴 돌진 뿔 / 먼 굽 보수

## 범위와 원본

이번 작업은 이 후보의 `source/` 안에서만 진행했다. 수정 직전의 18격자·팔레트·저작 코드·문서는 `before-volume-horn-repair/`에 보존했다. 이전 저작 행과 보수 기록도 유지했다. 현재 원본은 `poses/` 9개와 `actions/` 9개의 완전한 128×128 ASCII 격자이며 기존 18색 팔레트를 사용한다.

첨부 현재 시트와 64px 검객 그림을 실제로 열어 관찰했다. 기린의 긴 비취 목, 두 귀, 푸른 갈기, 금뿔·배판, 네 다리의 겹침과 왼쪽 위 광원을 기준으로 삼았다. 검객은 크기와 얼굴의 참고로만 보았다. 참고 이미지에서 픽셀을 추출하거나 추적하지 않았다.

## 직접 고른 변경

좌표는 native 0부터 시작한다. 정확한 `(y, x, ASCII)` 선택과 PNG 확인 뒤의 후속 선택은 `volume-horn-runs.txt`에 보존했다. 보조 코드는 그 명시 문자열만 적용한다. 모든 현재 격자는 전체 리터럴 행으로 저장되어 있다.

### 1. 가까운 어깨와 그 뒤의 좁은 가슴 면

- **idle_a:** x60–72/y76–96에 작은 왼쪽 위 밝은 cap과 넓은 비취 어깨 덩어리를 직접 찍었다. 예: `(61,77)`의 `jllhhllllj`, `(60,87)`의 `jlllhlllljjjttsstjt`. 큰 밝은 면에서 기본색으로 돌아오는 곡선과 아랫면의 `t/s` 접힘을 만들었다. 원래 금 어깨 장식은 보존했다.
- **idle_a 먼 가슴:** x74–82/y98–103에서 금판 하단이 좁은 비취 면을 덮도록 다시 골랐다. y98/x76의 `tjtkvkO` → y99/x75의 `tjtsvkO` → y100/x74의 `OtjtssO` → y101/x74의 `OstjtO`는 금판 아래의 먼 가슴과, 그 뒤에서 나오는 먼 앞다리의 뿌리를 구분한다. 다리 사이의 의도된 빈 공간은 보존했다.
- **idle_b / idle_c:** 각 자세의 실제 어깨·장식 높이를 읽고 다른 밝은 cap, 아랫면, 먼 가슴 행을 별도로 골랐다. idle_c는 장식과 cap이 내려온 높이를 따른다. 기록의 좌표를 다른 자세에 자동 적용하지 않았다.
- **windup / move / attack:** 압축된 또는 뻗은 기존 다리를 유지하면서 낮아진 어깨 덩어리와 먼 가슴 면을 다시 찍었다. attack의 겹친 앞다리는 가까운 밝은 다리와 뒤쪽 `s/t/j` 다리의 경계를 유지했다.
- **recover / hit:** 올라오는 목 또는 뒤로 기울어진 어깨에 맞춰 밝은 cap과 뒤쪽 가슴 면을 별도로 골랐다. hit의 기울어진 어깨·놀란 눈·뻗은 다리는 유지했다.
- **dead:** x62–78/y99–108의 내려온 어깨와 접힌 앞다리 연결을 명암 면으로 나눴다. 바닥으로 접힌 다리, 머리·갈기, 꼬리와 실제 하중 윤곽을 보존했다.
- **skill_a/b/c:** 준비·방전·회수의 실제 어깨 위치에 각각 넓은 가까운 면과 좁은 먼 가슴을 찍었다. 모든 뿔 발원점과 효과 픽셀은 보존했다.
- **poison_a/b / stun_a/b:** 가라앉은 턱·목과 서로 다른 무릎·지지발을 유지하면서, 해당 자세의 어깨와 먼 다리 뿌리를 직접 보수했다. 기포와 별은 그대로다.
- **sleep_a/b:** 원래 접힌 몸·감긴 눈·낮은 금뿔·네 발·꼬리와 호흡 실루엣을 유지했다. 말린 가까운 어깨의 넓은 면과 뒤에 접힌 앞다리의 작은 비취 면을 따로 골랐다. 등을 새 둥근 덩어리로 덮지 않았다.

### 2. 준비 / 이동 / 접촉의 긴 금뿔

대기 뿔의 길이와 밑동 두께를 기준으로, 기존 돌진의 짧은 투영을 유지하지 않고 실제 금뿔을 길게 다시 저작했다.

| 자세 | 직접 고른 구조 |
|---|---|
| windup | 금 밑동 x94–99/y62–64에서 밝은 끝 x123–124/y46–48로 이어진다. `w/v` 윗빛, `k` 중간면과 `g` 밑면을 별도 행으로 찍었다. 이마·눈·볼·턱을 뒤쪽 위치에서 다시 구성해 긴 뿔을 받을 부피를 남겼다. |
| move | 금 밑동 x95–100/y62–64에서 끝 x124–125/y48–50로 이어진다. 뿔 아래의 앞으로 향한 볼·눈과 연결된 귀를 새로 찍었다. 뒤발 밀기와 기존 다리 배열은 유지했다. |
| attack | 낮은 금 밑동 x93–100/y78–81에서 끝 x125/y70–72까지 이어지는 긴 뿔이다. y77/x94의 `OOOOwvvvvkkkggOO`, y79/x92의 `OwvvvkkkggOO` 등으로 넓은 밑동과 명암 띠를 직접 골랐다. 이마·두 귀·볼·눈·주둥이·목 연결을 더 왼쪽에서 새 배열로 구성했다. 금뿔이 주둥이보다 앞으로 나가며, 오른쪽 끝 윤곽 x126 뒤의 x127은 투명하다. |

프레임 전체를 이동·회전·보간하지 않았다. 뿔·머리의 각 행과 연결 군집을 직접 다시 골랐다. 몸통, 배판, 푸른 갈기와 기존 뒤발 밀기 / 지지 다리는 필요한 접합부 외에 보존했다.

### 3. 어두운 배경의 먼 굽

- idle_a/b/c의 먼 앞굽 x79–84/y115–119에서 기존 `r` 회색 면 옆에 작은 `d` 청회색 윗면을 직접 골랐다. 예: y117/x80의 `nrddnn`, y118/x79의 `nrddnn`. 아래쪽 `n`과 어두운 외곽은 남겼다.
- 세 idle의 먼 뒤굽 x43–46/y114–116에도 짧은 `d/r` 윗면을 골랐다. 가까운 발과의 높이·겹침 차이를 유지했다.
- 회수·피격·기술 자세의 대응 굽에서도 실제 위치에 작은 청회색 면을 찍었다. 모든 굽을 밝은 색으로 바꾸지 않았다.

## 실제 이미지 확인과 후속 교정

1. 첫 수정의 native PNG와 밝은 확대 PNG를 열었다. attack의 위쪽 귀와 이마 사이가 비어 있는 것을 발견했다. `(88,77)`의 `OljjtO`, `(86,78)`의 `OljjllO` 등으로 귀 밑동을 실제 이마에 이어 고쳤다.
2. move에서 남은 이전 귀 cap을 발견했다. y58–61의 명시 짧은 투명 문자열로 해당 잔여 군집만 지우고 y58–64에 연결된 새 귀를 직접 골랐다. windup/attack도 함께 확인했다.
3. 전체 18자세를 밝은·어두운·체커 배경의 native 1배와 최근접 3배 PNG로 열었다. 어깨·가슴·목·먼 다리·굽, 배판·갈기·꼬리의 연속성과 의도된 다리 사이 빈 공간을 확인했다.
4. 먼 가슴의 뿌리가 금판 아래에서 충분히 드러나지 않는 부위를 발견해, 각 자세의 금판 하단과 비취 뿌리를 다시 골랐다. 일부 첫 패치의 겹친 발목 외곽도 그 자세의 실제 좌표에서 정리했다. 자동 구멍 채우기나 연결 검사에 의한 변경은 없다.
5. 최종 18자세의 세 배경 1배 PNG, 전체 세 배경 확대 PNG, 수정 전후 1배 비교와 저장한 8GIF를 재디코딩한 native 프레임판을 열었다. 이것은 실제 파일의 정지 프레임 관찰이다. 시간에 따른 GIF 재생 감각이나 게임 충돌을 관찰했다고 주장하지 않는다.

## 남은 시각적 문제와 확인 한계

- 긴 사족의 외곽 진행 방향은 측면 성격이 강하다. 이번 3/4 깊이는 큰 가까운 어깨, 좁은 먼 가슴, 겹친 다리와 볼 면으로 표현했다. 전체 시점의 설득력은 새 독립 시각 검수에서 판단해야 한다.
- attack의 긴 뿔 끝은 오른쪽 여백에 가깝다. 셀 안에서 원본 끝을 보존했지만 실제 전투의 상대 거리와 접촉 범위는 확인하지 않았다.
- attack → recover의 목 높이 변화가 크다. 기존 hold를 유지했으며 실제 재생의 튐·발 슬라이딩·타격 타이밍을 검증하지 않았다.
- 먼 굽의 아래 외곽은 여전히 어둡고, 밝은 배경에서는 금백 번개와 별의 대비가 약하다. 효과 원안은 보존했다.
- 수면의 호흡 변화는 native 1배에서 작다. 감긴 눈·낮아진 턱·어깨 능선의 기존 차이는 유지했다.

테스트 / 게이트 / 별도 검수자는 실행하지 않았다. 검수 결과, ledger, brief, 게임 저장소, 다른 후보나 사용자 승인 상태를 작성·수정하지 않았다. 독립 검수 통과 또는 사용자 선택을 선언하지 않는다.

# 뇌각기린 — fifty-v1 직접 도트 원본

## 저작 범위와 참고 관찰

이 후보의 `source/`에만 팔레트, 기본 9자세, 추가 9자세, 저작 보조 코드와 자체 PNG/GIF를 작성했다. 저장소 코드·게임 저장소·ledger·brief·다른 후보는 수정하지 않았다. 프로젝트 SQLite는 이 후보 폴더와 저장소 루트에서 발견되지 않았으며, 이번 작업은 요청된 격자 후보 저작 범위다.

첨부 `human-size.png`를 실제 열어 작은 얼굴, 피부/옷/금속 면, 발과 무기의 연결 및 64px 인간의 크기감을 관찰했다. 참고의 픽셀은 추출·복제·확대 저작하거나 납품물에 포함하지 않았다. 기린의 모든 색 군집은 새로 선택했다.

## 원본과 보조 코드

- `palette.json`: 투명 기호 `.`을 제외한 18색. 비취의 넓은 밝은 면은 왼쪽 위, 아래/먼 다리는 녹청 그림자. 갈기는 짙은 남색과 청색의 길게 겹친 털 군집, 뿔·배판은 금색과 금백 면, 발굽은 차가운 회색 금속/각질 면이다.
- `poses/*.pxgrid`, `actions/*.pxgrid`: 각각 128행 × 128글자의 완전한 ASCII 원본. 다른 프레임을 변형해서 만들지 않았다.
- `authored-rows.txt`: 프레임별로 직접 고른 `(y, x, ASCII 가로 문자열)` 기록. 각 프레임의 몸/목/머리/다리/효과를 별도로 적었다.
- `repairs.txt`: 실제 그림을 연 뒤 고른 해당 프레임 좌표. 다른 자세에 수정 좌표를 자동 전파하지 않았다.
- `author.py`: 빈 투명 격자에 위의 명시적 문자열을 기록하고 완전한 리터럴 행으로 저장한다. 윤곽 수식, 도형, 포즈 변환, 음영 합성, 구멍 채우기가 없다.
- `render.py`: 격자를 그대로 RGBA PNG와 고정 팔레트 투명 GIF로 인코딩한다. 최근접 확대는 진단판에만 사용한다. 시트는 원본 128px 칸을 그대로 패킹한다.
- `inspect_pixels.py`: 크기·기호·여백·연결 군집을 읽기만 한다. 예술적 판정이나 자동 픽셀 교정을 하지 않는다.

원본을 다시 쓰려면 `python source/author.py`, 그림을 다시 굽려면 `python source/render.py`를 후보 폴더에서 실행한다. 두 명령은 source 안에만 기록한다.

`checkpoints/`의 진단 그림은 저작 도중 연 체크포인트이며 현재 판본이 아니다. 현재 판본은 `previews/`의 18개 PNG, 8개 GIF, `native-1x.png`, 세 배경 `*-3x.png`와 계산된 해시에 해당한다.

## 실제 자세 변화

1. **대기 3장:** 넓은 엉덩이/어깨, 긴 S자 목, 두 작은 귀, 우향 얼굴, 한 금뿔, 네 발굽을 먼저 완성했다. 두 번째는 등·목의 이완, 세 번째는 턱·등·배판이 낮아지는 군집을 별도로 찍었다. 먼 뒷다리는 엉덩이 아래에서 무릎→발목→발굽으로 이어진다.
2. **준비→전진→접촉→회수:** 목과 뿔의 축이 점차 낮아진다. 준비는 지지발을 굽히고, 전진은 뒤발을 밀면서 앞발을 접어 들어 올린다. 접촉은 뒷다리를 펴고 낮은 목과 실제 금뿔을 오른쪽으로 내민다. 회수는 목을 세우고 앞 지지발과 뒷무릎을 다시 모은 별도 배열이다.
3. **피격:** 눈을 찡그리고 어깨/목을 뒤로 기울였다. 다리 아래쪽도 눌린 체중에 맞춰 따로 찍었다.
4. **쓰러짐:** 목과 머리를 바닥으로 낮추고 눈을 감았다. 접힌 앞/뒷발, 말린 꼬리와 남색 털 끝을 남겼다. 마지막 확인에서 누운 금뿔을 `(125,102)`의 끝까지 다시 저작해 서 있는 뿔과 길이감을 맞췄다.
5. **기술:** 실제 뿔 끝의 금백 기 → 공통 발원점에서 위쪽/오른쪽 아래로 나뉘는 큰 두 번개 → 뿔을 들어 끊어진 짧은 잔전류. 기술 몸체도 준비/하중/회수에 따라 각각 그렸다.
6. **독:** 턱을 내리고 어깨/무릎을 움츠린 두 별도 배열. 보라색 기포는 위치와 크기가 바뀐다. 몸의 팔레트를 독색으로 바꾸지 않았다.
7. **기절:** 늘어진 귀와 낮은 목/뿔, 꺾인 앞 지지발을 찍었다. 두 번째는 머리/어깨가 더 처지고 금백 별의 위치가 달라진다.
8. **수면:** 접힌 네 다리와 말린 꼬리를 유지하는 웅크린 안정 자세. 두 번째의 고개/턱은 2px 낮고 등/가슴 윤곽은 따로 압축·이완한다. 눈꺼풀은 짧은 3px 선이며 검은 코와 분리했다. 색만 바꾼 호흡이 아니다.

## 실제 PNG에서 발견해 고친 좌표

- `idle_a`: 목 갈기의 가는 폭을 y52–71의 개별 남색/청색 군집으로 넓혔다. 먼 뒷무릎은 y103–114에서 5px 이상 재질 면을 갖도록 다시 찍었다.
- 수면의 최초 눈꺼풀 문자열은 얼굴보다 오른쪽 바깥에 잘못 놓였다. `sleep_a` `(103,80)`/`(103,81)`, `sleep_b` `(103,82)`/`(103,83)`의 분리 조각을 직접 지웠다. 실제 얼굴의 `sleep_a` `(94,73)`, `sleep_b` `(94,75)`에 `jOOOjt`를 기록하고 아래 볼 면과 코 군집도 각각 고쳤다. 최종 1배에서도 닫힌 선으로 확인했다.
- `attack` `(127,58)`, `stun_a` `(127,65)`, `stun_b` `(127,67)`의 뿔 끝 외곽을 x126에서 닫아 1px 투명 테두리를 복구했다.
- 쓰러짐의 세워진 꼬리는 y77–95의 해당 좌표를 지우고 엉덩이 경계와 y102–124의 말린 꼬리/끝 털을 직접 다시 저작했다.
- 어깨 금판, 두 큰 옆구리 비늘 군집, 넓은 등갈기는 18자세의 실제 해당 위치에서 각각 저작했다. 자동 반복 무늬나 프레임 간 좌표 복사는 없다.

## 열어 본 결과와 진단

대표 대기 확대 PNG를 먼저 열었고, 이후 기본 자세·기술·상태의 실제 PNG를 밝은/어두운/체커 배경과 1배/최근접 확대에서 열었다. 최종 저장된 8개 GIF도 다시 디코딩해 실제 프레임 및 저장된 hold를 담은 `previews/eight-gifs-decoded-1x.png`를 열어 확인했다. GIF의 현재 해시·실제 프레임 수·읽힌 시간은 `previews/gif-decoding.json`, 원본/PNG 해시는 `previews/pixels.json`에 계산한 값으로 남겼다.

현재 18격자의 크기는 128×128이고 테두리 침범은 없다. 최저 본체/발 픽셀은 각 프레임 y124이며 `idle_a`의 실제 발굽이 y124에 닿는다. 기본 9자세와 수면의 본체는 각각 한 8방향 연결 군집이다. 상태 기포/별과 깨진 잔전류의 별도 군집은 의도된 효과다. 이 수치들은 하네스 합격이나 미감 판정이 아니다.

## 남은 시각적 한계

- 제한된 9개 기본 자세에서 접촉→회수의 목 높이 변화가 빠르다. 추가 보간이나 몸 전체 이동을 넣지 않고 실제 저작 자세와 hold로만 표현했다.
- 어두운 배경의 먼 발굽과 가슴 아래 어두운 겹침은 1배에서 대비가 낮다. 최종 판정에서 이 부분과 긴 목/금배판의 각진 겹침을 확인할 필요가 있다.
- 최종 게임 배경, 실제 충돌 위치, 사운드와의 동기화는 이 source 후보 작업에서 확인하지 않았다.

별도 검수자를 호출하지 않았다. 독립 시각 판정과 사용자 선택은 하네스에 남아 있으며, 이 문서는 승인 또는 통과 선언이 아니다. 저장소 테스트/게이트는 실행하지 않았다.

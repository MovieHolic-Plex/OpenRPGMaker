# 뇌각기린 — 8개 GIF 시간표

기존 hold를 보존했다. 모든 프레임은 native 128×128 리터럴 격자를 고정 18색+투명 팔레트로 인코딩한다. 전체 몸 이동/회전/보간/자동 효과 생성은 없다. 아래는 비교용 반복 순서이며 죽음 GIF의 반복 재시작도 진단용이다.

| GIF | 순서 | 각 hold (ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_b | 240 / 260 / 110 / 180 / 200 / 240 |
| hit | idle_a → hit → recover → idle_a | 280 / 220 / 180 / 300 |
| dead | idle_a → hit → dead | 240 / 160 / 1000 |
| skill | skill_a → skill_b → skill_c → idle_a | 380 / 260 / 300 / 240 |
| poison | poison_a → poison_b | 430 / 430 |
| stun | stun_a → stun_b | 480 / 480 |
| sleep | sleep_a → sleep_b | 700 / 700 |

## 돌격의 하중과 접촉

준비는 두 뒷다리의 접힌 무릎과 뒤꿈치로 압축한다. 가까운 지지 굽 밑면은 y124이다. 이동은 기존 뒤발 밀기와 접힌 앞발을 유지한다. 접촉에서는 내려간 실제 금뿔의 축을 유지하고 가까운 앞다리를 어깨 x80–89/y102 → 무릎 x89–99/y112 → 발목 x98–107/y118 → 넓은 앞굽 x99–111/y121–124로 내딛는다. 회수에서는 별도로 저작된 목/지지발이 돌아온다. 정지된 격자와 저장된 hold를 확인했으며 실제 전투의 충돌/타격 시점은 이 후보에서 확인하지 않았다.

## 뇌각격 발원점

이 종은 손/입/도구 대신 실제 금뿔이 발원점이다. native `(x,y)`는 0부터 시작한다.

- **skill_a, 모으기:** 금뿔 끝은 `(102,20)` 부근. x96–108/y9–20의 금백 기 군집이 실제 뿔과 이어진다. 세운 목/갈기/가슴 아래의 접합부 구멍 4px만 이번에 보완했다.
- **skill_b, 큰 방전:** 뿔의 금백 끝과 공통 발원점은 x94–99/y35–39. 큰 위쪽 가지는 `(112,2)` 부근으로 뻗고 x117/y10–16의 곁가지와 갈라진다. 다른 굵은 줄기는 오른쪽으로 떨어져 `(104,84)` 부근까지 이어진다. 두 갈래의 끝/폭/방향이 다르며 뿔 → 머리 → 목 → 어깨 연결을 유지한다. 이 그림은 보존했다.
- **skill_c, 회수:** 실제 목/턱과 뿔을 다시 들고 금뿔 끝 `(111,23)` 및 금백 핵 `(111,24)`에서 x115 부근의 짧은 잔전류를 남긴다. x110–113/y15–19 및 x120–123/y31–36의 작은 떨어진 파편은 의도된 잔상이다. 이 그림은 보존했다.

## 상태와 수면 호흡

독 쌍은 아픈 턱/어깨/무릎과 별도 보라 기포를 보존한다. 기절 쌍은 처진 머리/귀/뿔과 위치가 달라지는 금백 별을 보존한다. 수면은 이들과 달리 접힌 발과 감긴 눈을 둔 낮은 안정 자세다.

- `sleep_a`: 접힌 목 능선 y82부터 머리/턱 y98–115로 내려온다. 짧은 닫힌 눈꺼풀은 x91–93/y105, 코는 x101–102/y108 부근이다. 뿔은 낮은 이마 x95–102/y99–101에서 x123/y83의 끝까지 이어진다.
- `sleep_b`: 등/목 위 윤곽이 y81로 이완되고, 가슴 면은 압축된다. 따로 찍은 턱은 y116으로 낮아진다. 닫힌 눈꺼풀은 x92–94/y106, 코는 x102–103/y109 부근이며 뿔 끝은 x123/y85다. 같은 접힌 발/발굽/말린 꼬리와 y124 하중 윤곽을 유지한다.

두 수면 프레임은 전체 몸을 옮기지 않고 목/고개/어깨/가슴 군집을 별도로 찍었다. 현재 PNG와 저장 GIF를 재디코딩한 1배 프레임에서 쌍을 비교했다.

`previews/gif-decoding.json`에는 실제 GIF에서 읽은 프레임 수/hold/현재 SHA-256이 있다. `previews/eight-gifs-decoded-1x.png`는 그 프레임의 확인판이다. 이 시간표는 독립 검수 또는 사용자 승인을 의미하지 않는다.

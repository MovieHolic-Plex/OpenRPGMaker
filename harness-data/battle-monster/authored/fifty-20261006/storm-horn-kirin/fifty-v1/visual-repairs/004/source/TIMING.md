# 뇌각기린 — 8GIF 순서와 발원점

현재 18개의 리터럴 128×128 격자와 기존 18색 팔레트로 GIF를 다시 기록했다. 기존 hold를 유지했다. 전체 몸 이동/회전/보간과 자동 효과 생성은 없다. 아래 반복은 비교용이며 쓰러짐의 재시작도 진단용이다.

| GIF | 프레임 순서 | hold (ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_b | 240 / 260 / 110 / 180 / 200 / 240 |
| hit | idle_a → hit → recover → idle_a | 280 / 220 / 180 / 300 |
| dead | idle_a → hit → dead | 240 / 160 / 1000 |
| skill | skill_a → skill_b → skill_c → idle_a | 380 / 260 / 300 / 240 |
| poison | poison_a → poison_b | 430 / 430 |
| stun | stun_a → stun_b | 480 / 480 |
| sleep | sleep_a → sleep_b | 700 / 700 |

## 뿔 돌격: 준비 → 전진 → 접촉 → 회수

준비는 넓은 뒤 허벅지/무릎/뒤꿈치를 접어 압축하고 이동은 뒤발로 밀며 앞발을 당긴다. 접촉은 실제 머리/목을 낮춰 뿔이 앞서게 했다. 금뿔은 이마 x105–109/y78–80에서 x125–126/y76의 끝으로 연속된다. 주둥이 끝은 x112–114/y84–86으로 뿔 끝보다 뒤에 있다. 짧게 압축된 밝은 목과 남청 갈기는 어깨로 이어진다.

이번 보수에서 접촉의 금뿔은 x105–126/y74–81의 명시 군집으로 다시 찍었다. 금색 밑동, 밝은 윗빛과 어두운 밑면이 실제 이마에 붙으며 끝은 x125/y75–76 부근이다. 오른쪽 마지막 열 x127은 투명하다. 몸 전체 이동 없이 낮아진 뿔의 재질 두께를 보수했다.

접촉의 기존 가까운 앞다리 경로는 어깨 x80–89/y102 → 무릎 x89–99/y112 → 발목 x98–107/y118 → 앞굽 x99–111/y121–124다. 실제 지지 굽 밑면 x100–110/y124를 유지했다. 회수는 별도 저작된 세워지는 목과 지지발이다. 피격의 먼 앞발은 x86–94/y118–121에서 짧은 발목 금테와 어두운 굽을 보수했고, 가까운 발의 y124보다 높은 회피 위치를 유지했다. 이것은 정지 프레임의 접촉 표현이며 게임 충돌 좌표와 실제 상대 거리는 확인하지 않았다.

## 뇌각격의 실제 발원점

이 사족은 손/입/도구 대신 실제 금뿔에서 기술을 낸다. 모든 좌표는 native 0부터 시작한다.

- **skill_a, 모으기, 380ms:** 금뿔 끝 `(102,20)` 부근에서 x96–108/y9–20의 금백 기 군집으로 이어진다. 세운 목, 두 귀, 넓은 어깨와 접지한 발을 유지한다.
- **skill_b, 방전 접촉, 260ms:** 실제 금뿔의 금백 끝 `(94,39)` 부근이 x94–98/y35–38의 좁은 줄기로 공통 접합부와 이어진다. y35–38에는 상향/하향 줄기를 나누는 2–4px 의도된 틈을 따로 찍었다. 상향 경로는 x112/y2 부근 및 x117/y10–16의 기존 갈래로 뻗는다. 하향 경로는 x104–113/y53–58에서 크게 갈라진다. 본줄기는 x101–105/y82–84로, 새 옆가지는 x111/y60 부근의 꺾임을 거쳐 x121/y69의 가늘어진 끝으로 향한다. 두 경로는 실제 뿔 발원점을 공유하고 분기 뒤에는 별도의 끝이 보인다.
- **skill_c, 잔전류 회수, 300ms:** 뿔을 다시 들어 끝 `(111,23)` 부근에서 짧은 연결 전류를 남긴다. x110–113/y15–19와 x120–123/y31–36의 작은 끊어진 파편은 의도된 잔상이다. 목/턱/지지발의 회수 자세를 유지했다.

이번에는 skill_b 지지 굽 `(80,120)`의 작은 투명 점과 skill_c 목판 x69–88/y75–81을 직접 보수했다. 기술 발원점·가지·잔전류의 효과 픽셀과 hold는 그대로다.

## 상태 쌍의 차이

**독:** 아픈 턱, 낮은 어깨, 압축된 네 다리와 서로 다른 보라 기포를 유지했다. 두 프레임은 실제 자세 차이가 있고 단순 색조 변환이 아니다.

**기절:** stun_a는 턱 y100, 처진 눈 x100–102/y92, 오른쪽으로 꺾인 앞무릎 x77–90/y113–114와 가까운 지지 굽 x77–87/y124다. stun_b는 턱 y104, 처진 눈 x101–103/y96, 반대로 접힌 무릎 x65–77/y113–114와 지지 굽 x79–89/y124다. 먼 다리는 별도 경로/짧은 어두운 굽을 유지한다. 별은 서로 다른 위치의 기존 명시 픽셀이다. 별 이외에도 실제 목/턱/무릎 배열이 바뀐다.

**수면:** 접힌 네 발과 말린 꼬리를 가진 안정 자세를 유지했다. sleep_a 눈꺼풀은 x91–93/y105, 코는 x101–102/y108 부근의 별도 군집이다. sleep_b 눈꺼풀은 x92–94/y106이고 턱은 y116으로 조금 내려온다. 등/목 능선 y82→81과 압축되는 가슴은 별도 저작된 호흡 변화다. 두 프레임의 같은 접힌 발·꼬리·실제 y124 하중 윤곽을 유지했다. 금뿔은 낮은 이마에서 각각 x123/y83 및 x123/y85의 끝으로 이어진다.

## 확인 범위

8개의 실제 GIF를 저장하고 재디코딩한 1배 프레임판을 열어 그림과 프레임 순서를 비교했다. 현재 파일에서 읽은 hold와 계산 해시는 `previews/gif-decoding.json`에 있다. 실제 시간의 GIF 재생 감각과 전투 엔진의 타격/슬라이딩/음향은 관찰하지 않았다. 이 시간표는 독립 검수 통과나 사용자 승인을 의미하지 않는다.

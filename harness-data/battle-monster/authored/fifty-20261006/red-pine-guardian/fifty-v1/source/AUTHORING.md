# 적송목령 — 들린 뿌리 발과 수면 가지 팔 교정

## 보존과 저작 범위

이번 교정은 `source/poses/move.pxgrid`, `source/actions/sleep_a.pxgrid`,
`source/actions/sleep_b.pxgrid`에만 적용했다. 나머지 15자세와 18색 팔레트는
`history/before-root-arm-repair/source-hashes.json`의 수정 전 SHA-256과 같다.
기본 9자세와 기술·독·기절·수면 9자세 모두 96행 × 96열의 완전한 ASCII 원본이다.

수정 전 세 격자, 저작 코드, AUTHORING/TIMING과 이전 이미지 재읽기 기록은
`history/before-root-arm-repair/`에 보존했다. 앞선 교정 원본도 기존 history에 남아 있다.
`repair_root_arms.py`는 자세마다 직접 고른 `y x ASCII` 문자열을 기록한다.
수면 두 자세는 각자의 행 목록을 가지며 다른 자세의 좌표를 자동 복사하지 않는다.
저장 코드는 지정 문자열과 투명 여백만 기록한다. 본체 도형 생성, 명암 합성,
전체 프레임 이동·회전·보간, 자동 연결·구멍 채우기·윤곽 정리는 사용하지 않았다.
이전 보조 코드의 재실행 끝에도 새 교정을 적용하도록 연결했다.
정본은 `poses/`와 `actions/`의 전체 리터럴 격자다.

## 참고 관찰

첨부 현재 시트와 64px 검객 PNG를 저작 전에 실제로 열었다. 넓고 겹겹인
솔잎 관, 오른쪽 매달린 솔가지, 갈라진 우향 줄기 얼굴, 굽은 뿌리와
왼쪽 위의 따뜻한 목재 밝은 면을 유지했다. 검객은 얼굴 가독성과 크기만
관찰했다. 참고 이미지의 픽셀 추출·추적·축소·재배포는 하지 않았다.

## 직접 교정한 군집

좌표는 0부터 시작한다.

| 자세 | 이번 교정 |
|---|---|
| move | 136픽셀, 실제 변경 범위 `(40..65,80..91)`. 기존 들린 무릎의 밝은 윗면과 y=75..79의 연결을 유지했다. 무릎 아래 줄기를 뒤로 접고 발목에서 다시 오른쪽으로 굽혔다. 발목 윗면에 짧은 `h/s`, 아래에 `r/b/k`를 찍고 뿌리 끝을 길이가 다른 두 갈래로 가늘게 나눴다. y=87..88의 끝 사이에 의도한 틈을 남겼다. 들린 발의 최하단은 y=88이며 그 아래 y=89..91은 비었다. 반대쪽 지지 뿌리와 y=92의 하중 행은 변경하지 않았다. |
| sleep_a | 652픽셀, 실제 변경 범위 `(27..64,59..87)`. 낮은 관과 닫힌 눈을 보존했다. 두 어깨에서 위팔을 바깥으로 내려 팔꿈치에서 안쪽으로 접었다. 먼 팔은 대략 `(28..44,60..74)`, 가까운 팔은 `(52..64,60..74)`에 있다. 두 아래팔과 가지 끝은 무릎 위에서 쉬며 팔 아래 양쪽에 투명한 틈을 남겼다. 몸통은 가운데의 연속된 목재 면으로 유지하고, 팔 아래 y=73..75의 짧고 어두운 겹침과 골반 면으로 팔·배·허벅지를 나눴다. 다리의 연속된 큰 밝은 띠를 작은 무릎·정강이 면으로 줄이고 기존 두 뿌리 발의 접지를 유지했다. |
| sleep_b | 661픽셀, 실제 변경 범위 `(27..64,59..87)`. 이 자세의 원래 조금 내려앉은 닫힌 얼굴에 맞춰 가슴의 밝은 면을 따로 저작했다. 어깨 위치와 가지 팔 길이, 무릎 위 이완된 가지 끝, 두 뿌리 발은 sleep_a와 같은 구조다. 두 자세는 전체 134픽셀이 다르며 차이는 `(35..64,25..69)` 안의 관·얼굴·상체에 한정된다. y=70..92의 팔 끝·골반·뿌리 하중 배열은 유지되어 호흡 때 발이 미끄러지지 않는다. |

수면의 닫힌 눈은 sleep_a의 y=53, x=46..48와 x=51..53,
sleep_b의 y=54, x=47..49와 x=52..54에 있는 짧은 갈색 눈꺼풀이다.
코·볼과 분리된 기존 표현을 유지했다. 큰 솔잎 관과 매달린 가지도 유지해
수면을 죽음이나 새 지그재그 생물로 대체하지 않았다.

기술 세 자세의 붙은 발원점과 서로 다른 세 솔잎 다발, 회수 조각,
독 두 자세의 아픈 몸과 변화하는 방울, 기절의 처진 가지와 별은 보존했다.
다른 15자세의 동일 부위도 전체 PNG에서 함께 확인했다.

## 실제 이미지 열람과 재읽기

`render_previews.py`로 18개 native PNG와 8개 GIF를 저장했다.
수정한 세 자세의 밝은/어두운/체커 4배 확대판과 전체 18자세의 같은 세
배경 1배 시트를 실제로 열었다. 이동의 들린 발 아래 틈, 무릎·발목의
방향 변화, 수면의 붙은 두 팔과 팔 아래 빈 공간, 닫힌 눈을 확인했다.
눈·목·어깨가 새로 떨어지거나 뜻하지 않은 몸통 구멍이 생긴 모습은 보이지 않았다.

8개 GIF 파일을 이미지 도구로 각각 열었다. 이 도구가 보여 주는 GIF 정지
이미지와 실제 GIF에서 디코드한 전체 프레임의 2배 시트를 열어 순서와
자세 사이의 구조를 비교했다. 수면의 팔 끝과 지지 발은 두 프레임에서
유지된다. 이 열람은 실시간 GIF 재생의 박자 확인과 구별한다.

`readback_previews.py`는 원본을 수정하지 않는 이미지 재읽기 보조다.
`preview-readback.json`은 실제 원본/PNG/GIF 해시와 파일 대조 결과다.

- 18개 원본 모두 96×96이며 서로 다른 배열이다.
- 팔레트는 18색, PNG 알파는 0/255이다.
- 1px 바깥 테두리는 투명하며 모든 자세의 최하단 잉크는 y=92다.
- grounded idle_a의 실제 뿌리 발도 y=92에 닿는다.
- 저장 PNG와 원본 RGBA의 차이는 0이다.
- GIF의 모든 디코드 프레임은 해당 PNG와 같고 노출 시간도 시간표와 같다.

이는 파일 재읽기 자료와 작가의 시각 확인이다. 독립 검수 통과나 사용자
승인을 뜻하지 않는다. 테스트·게이트·독립 검수자 호출은 하지 않았다.
brief, 장부, 검수 결과, 다른 후보, 저장소 코드와 게임 저장소는 수정하지 않았다.

## 남은 시각적 한계

수면의 가지 끝·골반·무릎은 같은 갈색 목재가 겹친 작은 군집이어서 1배
어두운 배경에서는 경계가 조밀하다. 닫힌 눈의 갈색 대비와 호흡 변화도 작다.
이동의 두 갈래 뿌리 끝은 얇아 어두운 배경에서 일부 끝이 약하게 보인다.
실시간 재생의 박자와 실제 전투의 hop 이동·접촉 거리는 이번 정지 이미지
및 GIF 프레임 열람으로 확인하지 않았다. 새 독립 검수는 하네스가 담당한다.

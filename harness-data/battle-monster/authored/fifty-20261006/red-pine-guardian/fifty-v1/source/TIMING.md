# 적송목령 GIF 시간표

원본은 96×96이며 좌표는 0부터 시작한다. 현재 GIF에서 재읽은 노출 시간이다.
중간 자세의 자동 이동·회전·보간은 없다. `gifs/timing.json`은 렌더 시간표이고
`preview-readback.json`은 실제 파일 재로드 기록이다.

| GIF | 자세 순서 | 각 노출 ms |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600, 200, 100, 120, 220, 900 |
| hit | idle_a → hit → idle_a | 700, 180, 900 |
| dead | idle_a → hit → dead | 700, 150, 1700 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700, 260, 160, 240, 900 |
| poison | poison_a → poison_b | 420, 420 |
| stun | stun_a → stun_b | 300, 300 |
| sleep | sleep_a → sleep_b | 650, 650 |

`dead.gif`는 확인판에서 반복하며 게임의 부활 규칙을 뜻하지 않는다.

## 공격 가지 추적

가까운 오른쪽 어깨의 같은 굵은 가지를 준비에서 뒤로 모으고,
move에서 위로 펴며 앞 뿌리의 무릎을 든다. attack에서는 어깨를 내려
그 가지로 내려친다. 이번 교정의 가지 굽힘과 세 끝은 `(61..82,74..85)`다.
앞 뿌리와 가지 사이의 투명 틈을 남겼으며 attack의 두 지지 뿌리는 y=92에 닿는다.
move의 들린 뿌리는 기존 무릎에서 뒤로 접은 정강이와 앞으로 굽힌 발목으로
이어진다. 두 가는 뿌리 끝의 최하단은 y=88이며 y=89..91에 빈 공간이 있다.
반대쪽 뿌리가 y=92에서 몸을 지지한다. 전체 프레임을 옮겨 만든 동작이 아니다.
recover에서 같은 가지를 접어 회수한다. 먼 왼쪽 가지는 보조다.

## 송침탄의 실제 가지 끝 앵커

- skill_a: 가지손 끝 `(63..73,61..65)`에서 모이는 녹기
  `(61..72,56..62)`가 이어진다. 짧은 갈래 솔잎 기를 모으는 준비다.
- skill_b: 뻗은 가지와 손끝에서 위 `(71..75,53..56)`, 가운데
  `(73..76,58..61)`, 아래 `(75..78,62..65)`의 녹빛 발원점이 이어진다.
  큰 세 다발은 각각 y=42..55, y=55..62, y=63..75에 있고 가닥 사이에
  의도한 틈이 있다. 마지막 잎 x=94 뒤에 1px 여백을 남긴다.
- skill_c: 가지를 접는다. 가지 끝과 연결된 작은 잔침은
  `(49..56,74..76)`다. 떨어진 다섯 부러진 솔잎은 각각
  `(74..79,63..66)`, `(80..84,70..72)`, `(66..70,75..77)`,
  `(78..82,80..82)`, `(72..76,85..87)`에 직접 찍었다.
  앞 세 조각의 상승 방향과 뒤 두 조각의 낙하 방향을 다르게 남겼다.
  회수 조각은 떨어져 있으며 준비/시전의 붙어 있는 발원점과 구별된다.

## 상태 자세

독 두 자세는 턱·배를 감싼 목재 몸과 달라지는 독 방울을 유지한다.
기절 두 자세는 처진 얼굴과 가지팔, 다르게 놓인 별을 유지한다.
수면 두 자세는 같은 관·큰 늘어진 가지·접힌 두 팔·두 뿌리다리와 닫힌 눈이다.
sleep_a의 눈은 y=53, x=46..48와 x=51..53이고, sleep_b의 눈은
내려앉은 얼굴에 맞춰 y=54, x=47..49와 x=52..54에 별도로 저작했다.
두 프레임의 코·볼·턱 변화와 왼쪽 가슴 면의 작은 들숨을 함께 보여 준다.
이번 교정의 두 팔은 어깨에서 바깥으로 내려가 팔꿈치에서 안쪽으로 접힌다.
가지 끝은 무릎 위에 놓이며 몸통과 팔 아래의 틈을 유지한다.
두 자세의 차이는 관·얼굴·가슴 `(35..64,25..69)`의 134픽셀이다.
y=70..92의 팔 끝·골반·뿌리 발 배열은 같고 두 발의 하중 윤곽은 y=92에 닿는다.
650ms씩 한 숨은 1300ms다.

실제 8개 GIF 파일의 정지 표시 및 모든 디코드 프레임을 열었다.
이번 열람은 실시간 재생의 박자 확인을 포함하지 않는다. 이 시간표는 런타임 hop·전투 접촉 또는 독립 검수 통과를 뜻하지 않는다.

# 적송목령 — 수면 두 자세 직접 교정

## 범위와 원본

이번 작업은 이 후보의 `source/` 안에서 진행했다. 기존 팔레트 18색과 기본
9자세, 기술·독·기절 7자세의 원본 격자는 유지했다. 교정 대상은
`actions/sleep_a.pxgrid`, `actions/sleep_b.pxgrid`다. 모든 최종 원본은
96행 × 96열의 완전한 ASCII 행이며 `.`은 투명하다.

교정 전 수면 격자·저작 기록·시간표·저작 보조 코드는
`history/before-sleep-repair/`에 보존했다. `repair_sleep.py`에는 두 프레임의
각각 직접 고른 `y x ASCII` 문자열을 별도로 적었다. 코드는 그 문자열과
투명 여백을 전체 행으로 저장한다. 다른 프레임의 좌표를 자동 복사하거나
몸체를 이동·회전·보간하지 않는다. 도형 마스크, 명암 합성, 자동 연결·구멍
채우기, 참고 픽셀 추출은 사용하지 않았다. `author_pixels.py`를 재실행할
경우에도 마지막에 현재 수면 저작 문자열을 적용하도록 연결했다.

## 참고 관찰

첨부된 현재 18자세 시트와 `references/human-size.png`를 실제로 열었다.
현재 시트의 넓은 솔잎 관, 오른쪽 늘어진 가지, 따뜻한 목재 면, 줄기 얼굴,
꺾인 가지팔과 뿌리발을 관찰했다. 검객 그림은 작은 얼굴과 크기 관찰에만
사용했다. 참고 이미지를 추적·추출·축소·재배포하지 않았다.

## 직접 고친 native 군집 (좌표는 0부터)

| 부위 | 수면 a/b의 실제 변경 |
|---|---|
| 솔잎 관 `(14..77,23..54)` | 좁은 대각 판을 중앙 관·겹친 왼쪽 가지·오른쪽 매달린 가지로 다시 저작했다. 왼쪽 작은 관의 밑면에 `g/v` 경계를 넣고 오른쪽에는 위 가지와 아래 늘어진 잎 사이의 어두운 겹침선, 각각의 `l/a` 빛 면을 넣었다. |
| 오른쪽 가지 `(49..77,29..52)` | 중앙 관에서 나오는 잎·가지 폭을 유지하며 아래로 꺾여 내려오는 군집과 두 갈래 끝을 찍었다. 관 아래 열린 틈은 의도한 솔가지 사이 공간이다. |
| 작은 왼쪽 솔가지 `(18..40,47..54)` | 첫 교정 PNG에서 줄기와 떨어져 보였다. 각 프레임 y=49..51의 녹색 가지와 갈색 밑동 연결을 직접 다시 골랐다. |
| 얼굴 `(38..60,58..64)` | 코가 있는 오른쪽 얼굴을 유지하고 y=62, x=48..49와 x=53..54에 각각 짧은 `kk` 닫힌 눈꺼풀을 찍었다. 그 아래는 따뜻한 수피·볼 색이며 평상시 금빛 눈을 복사하지 않았다. |
| 접힌 먼 팔 `(28..49,65..78)` | 어깨에서 굵은 위팔이 왼쪽 팔꿈치로 내려가고, 아래팔이 몸 앞으로 접히는 따뜻한 목재 면을 저작했다. 몸통과 팔 사이의 짧은 `b/k` 겹침선을 남겼다. |
| 접힌 가까운 팔 `(45..61,66..78)` | 오른쪽 어깨→바깥 팔꿈치→안쪽 아래팔을 따로 읽히게 했다. 겹친 팔 위의 밝은 나무 면과 가지손 끝 `(50..61,74..78)`을 직접 찍었다. 두 팔은 흉부와 연결되지만 평면 줄기 무늬로 합쳐지지 않도록 경계를 남겼다. |
| 두 뿌리다리 `(20..62,79..92)` | 각각의 허벅지·굽은 무릎·좁은 발목·짧은 뿌리발을 다시 저작했다. y=82부터 벌어지는 다리 틈은 투명하게 유지했다. 바닥 y=92에는 뒤 발 x=21..37, 앞 발 x=43..59의 실제 하중 윤곽이 닿는다. |
| 숨 변화 | 두 번째 프레임의 y=55..66에서 가슴·목의 왼쪽 면을 국소적으로 1px 넓히고 목재 빛 면을 골랐다. 상부 솔잎과 오른쪽 끝의 작은 군집도 다르다. 얼굴의 눈꺼풀 위치, 접힌 팔, 무릎, 두 발끝과 바닥 접지는 유지한다. 최종 두 프레임은 57픽셀이 다르다. |

## 실제 그림 열람과 재로드

`render_previews.py`로 원본 18개 PNG와 8개 GIF를 다시 만들었다.
최종 밝은/어두운/체커 배경의 1배 전체 시트, 수면 두 자세의 최근접 4배
확대판, 실제 GIF를 디코드한 1배 프레임 시트를 열었다. 기존 자세의 같은
목·어깨·팔·다리 연결도 전체 시트에서 함께 확인했다. 수면 이외의 원본
좌표에 이번 지적에 해당하는 결손을 새로 발견하지 않아 그대로 보존했다.

`readback_previews.py`는 이미지를 읽는 진단 보조이며 교정하지 않는다.
`preview-readback.json`에는 현재 파일에서 실제 계산한 SHA-256, 크기,
여백, 접지, PNG/GIF 재로드 비교와 GIF 노출 시간을 기록했다.

- 원본 18개: 모두 96×96, 각각 다른 픽셀 배열.
- 모든 바깥 테두리는 투명하며 최저 불투명 y=92, PNG 알파는 0/255다.
- PNG와 원본의 픽셀 차이 0, GIF와 PNG의 RGBA 차이 0, 노출 시간 차이 0.
- 수면 두 프레임의 본체·관·가지·발은 각각 하나의 8방향 연결 군집이다.
  이 진단은 미감 합격의 근거로 삼지 않았으며 자동으로 픽셀을 채우지 않았다.
- 테스트·게이트·독립 검수자 호출은 실행하지 않았다. 검수 결과, 사용자
  선택, 장부, brief, 다른 후보, 저장소 및 게임 저장소는 수정하지 않았다.

## 남은 시각적 한계

닫힌 눈꺼풀은 각각 2px의 작은 갈색 표현이어서 어두운 배경 1배에서는
가독성이 제한된다. 접힌 가지팔의 교차점도 목재 색끼리 겹치므로 확대판보다
1배에서 경계가 약하다. 수면 관은 낮고 압축된 형태이며 평상시의 더 높은
중앙 관과 완전히 같은 실루엣은 아니다. 숨 변화는 작은 2프레임 변화다.
실제 전투에서의 hop 이동, 공격 접촉 거리와 재생 연출은 확인하지 않았다.

이 문서는 교정·자체 열람 기록이다. 새 독립 검수의 통과나 사용자 승인을
선언하지 않는다. 실제 독립 검수와 현재 원본 연결은 하네스가 관리한다.

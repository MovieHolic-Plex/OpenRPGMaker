# 적송목령 — 공격 가지·수면 얼굴·회수 솔잎 교정

## 범위와 보존

수정은 이 후보의 `source/`에만 저장했다. 기존 18색 팔레트, 솔잎 관,
갈라진 갈색 줄기, 가지팔, 두 뿌리발과 왼쪽 위 광원을 유지했다.
현재 기본 9자세와 추가 9자세는 각각 96행 × 96열의 완전한 ASCII 원본이다.
변경한 원본은 `poses/attack.pxgrid`, `actions/sleep_a.pxgrid`,
`actions/sleep_b.pxgrid`, `actions/skill_c.pxgrid`의 네 개다.
다른 14개 원본은 이전 기록의 실제 SHA-256과 같다.

수정 전 네 격자, 저작 보조 코드, 저작 문서, 시간표와 이미지 재읽기 기록을
`history/before-requested-repair/`에 보존했다. 더 이전 수면 원본도
`history/before-sleep-repair/`에 남아 있다.

`repair_requested.py`에는 각 자세에서 직접 고른 `y x ASCII` 교체 문자열을
따로 기록했다. 점은 의도한 투명 픽셀이다. 코드는 이 문자열을 해당 위치에
기록하고 전체 행을 저장한다. 도형 마스크, 명암 합성, 자동 구멍 채우기,
다른 자세로 좌표 전파, 본체 전체 이동·회전·보간을 사용하지 않았다.
`author_pixels.py` 재실행의 마지막 단계와 `repair_sleep.py`의 수면 재실행에도
현재 교정 문자열을 적용하도록 연결했다. 정본은 완전한 `.pxgrid` 파일이다.

## 참고 관찰

첨부 현재 시트와 자체 검객 참고 PNG를 실제로 열었다. 현재 시트에서 넓은
솔잎 관, 오른쪽 늘어진 솔가지, 우향 줄기 얼굴, 따뜻한 목재 명암과 굽은
뿌리를 관찰했다. 검객 참고는 작은 얼굴과 크기 관찰에만 사용했다.
참고 픽셀의 추출·추적·축소·재배포는 하지 않았다.

## 직접 바꾼 군집

좌표는 0부터 시작한다.

| 자세 | 실제 교정 |
|---|---|
| attack | `(61..82,74..87)`의 158픽셀을 바꿨다. 아래로 내려오는 가지의 목을 좁히고 끝을 서로 길이가 다른 세 나무 갈래로 나눴다. 가지 굽힘 위쪽의 `h/s` 면을 손목·끝으로 이어 주고 아래쪽에 `r/b/k` 경계를 넣었다. y=79..82의 가지와 앞 뿌리 사이에 실제 투명 틈을 남겼다. 앞 뿌리의 기존 윤곽과 y=92 전체 하중 행은 보존했다. |
| sleep_a | `(36..58,49..64)`의 115픽셀을 바꿨다. 위쪽 줄기에 어두운 갈색 눈썹과 닫힌 눈꺼풀, 따뜻한 볼, 오른쪽 코를 찍었다. 닫힌 눈은 y=53의 x=46..48, x=51..53에 있는 짧은 `kkk` 군집이다. 눈 밑 볼과 코를 분리하고 y=58..64의 이전 낮은 얼굴 흔적은 줄기 명암으로 다시 저작했다. |
| sleep_b | `(36..58,49..64)`의 126픽셀을 독립적으로 골랐다. 얼굴을 조금 내려앉은 우향 각도로 찍었으며 눈꺼풀은 y=54의 x=47..49, x=52..54다. 눈썹·코·볼·턱이 함께 작게 달라진다. 기존 왼쪽 목·가슴의 들숨 면, 접힌 팔·무릎·두 발과 관의 작은 변화는 유지했다. 두 수면 원본은 현재 131픽셀이 다르다. |
| skill_c | `(65..85,62..87)`의 98픽셀을 바꿨다. 다섯 둥근 녹색 입자를 지우고, 위로 뻗은 시전 다발의 방향을 이어 받는 세 짧은 상승 대각 조각과 아래 갈래에서 떨어지는 두 하강 대각 조각을 각각 찍었다. 얇은 `t` 빛과 `n/g` 옆면이 있는 짧은 부러진 솔잎이다. 접힌 가지와 연결된 기존 잔침 `(49..56,74..76)`은 유지했고, 떨어진 다섯 조각 사이의 투명 공간도 남겼다. |

수면의 솔잎 관·늘어진 큰 가지, 연결된 두 팔, 접힌 두 뿌리발을 유지했다.
기술 준비/시전, 독 두 자세, 기절 두 자세는 원래의 서로 다른 직접 저작
배열을 유지하며 색조 변환이나 다른 공격으로 대체하지 않았다.

## 실제 이미지 열람과 저장 후 재읽기

`render_previews.py`로 18개 native PNG와 8개 GIF를 다시 저장했다.
교정한 네 자세의 밝은/어두운/체커 배경 4배 확대판과 18자세 전체의 같은
세 배경 1배 시트를 실제로 열었다. 다른 자세의 가지팔·어깨·목·뿌리 연결도
함께 보았으며 이번 지적에 해당하는 추가 결손은 발견하지 않았다.
공격 끝과 앞 뿌리의 틈, 수면의 짧은 닫힌 눈, 조각 솔잎의 대각 방향을 확인했다.

8개 실제 GIF 파일을 열었고, GIF에서 다시 읽은 모든 프레임의 1배/2배 시트도
열어 자세 순서와 프레임별 연결을 비교했다. `readback_previews.py`는 이미지
읽기 전용 보조다. `preview-readback.json`은 실제 파일에서 계산한 해시,
크기, 알파, 여백, PNG/GIF 원본 대조와 노출 시간을 기록한다.

- 원본 18개는 모두 서로 다르며 각각 96×96이다.
- 바깥 테두리에 불투명 픽셀은 없고 모든 자세의 최저 불투명 y=92다.
- PNG 알파는 0/255이며 원본과 PNG의 픽셀 차이는 0이다.
- GIF를 디코드한 RGBA는 해당 PNG와 일치하고 노출 시간도 시간표와 같다.
- 이 결과는 파일 계약 및 저장 재읽기 자료이며 미감 통과나 사용자 선택이 아니다.

`capture_gifs.cjs`로 로컬 확인판의 실시간 브라우저 재생을 열려고 했으나
Chromium이 환경의 sandbox 제한으로 실행되지 않았다. 브라우저 재생 캡처는
생성하지 못했다. GIF 디코드 프레임 열람을 실시간 재생 확인으로 보고하지 않는다.
테스트·게이트·독립 검수자 호출은 실행하지 않았다. 검수 결과나 사용자 선택을
쓰지 않았고 장부·brief·다른 후보·게임 저장소는 수정하지 않았다.

## 남은 시각적 한계

수면의 눈꺼풀은 3px의 갈색 표현이며 1배 어두운 배경에서 대비가 작다.
접힌 팔과 무릎은 같은 목재색이 겹치므로 작은 화면에서 경계가 조밀하다.
호흡은 두 프레임의 작은 얼굴·가슴 변화다. 공격 가지의 손끝은 단순한
세 목재 갈래이며 1배에서 미세한 밑면 명암이 생략되어 보일 수 있다.
실시간 GIF의 박자 인상, 실제 전투의 hop 이동·접촉 거리·타격 연출은 확인하지 않았다.

이번 문서는 교정·자체 열람 기록이다. 새 독립 검수의 통과나 사용자 승인을
선언하지 않는다. 실제 독립 검수와 현재 원본의 연결은 하네스가 관리한다.

# 적송목령 — fifty-v1 원본 저작

## 범위와 원본

이 후보의 `source`만 저작했다. 기본 9자세는 `poses/`, 기술·상태 9자세는
`actions/`에 있는 완전한 96행 × 96열 ASCII `.pxgrid`다. `.`은 투명이며
팔레트에는 없다. 팔레트는 불투명 18색, 최종 PNG 알파는 0/255다.
저작 승인이나 독립 검수 판정을 이 문서에서 만들지 않는다. 실행 모델·job 식별의
정본은 하네스가 관리하는 출처 기록이며 이 작업에서 수정하지 않았다.

`author_pixels.py`는 직접 고른 `y x ASCII 문자열`과 명시한 행 교정을 보존한다.
빈 캔버스에 그 문자열을 쓰고 투명 여백을 붙여 최종 전체 행을 저장한다.
원/다각형/직선 마스크, 명암 수식, 전체 프레임 이동·회전·보간, 자동 구멍 채우기는 없다.
대기·기술·상태 중 변하지 않는 관·얼굴 재질은 같은 위치에서 유지하고, 바뀌는
관절·명암·솔잎은 해당 자세의 문자열을 직접 선택했다. 기존 후보 원본은 없었다.

## 참고 관찰

작업 전에 `references/human-size.png`를 실제로 열었다. 작은 우향 3/4 눈,
코 앞 공간, 얼굴의 따뜻한 면, 손과 무기 자루가 만나는 짧은 연결을 관찰했다.
이 파일을 추적·추출·축소·복제하지 않았고 참고 바이트를 source에 넣지 않았다.
적송목령은 검객의 사람 구조를 복제하지 않고 나무 얼굴과 가지 관절을 새로 찍었다.

## 재질과 신체

- 넓은 비대칭 솔잎 관: 중앙의 높은 가지, 왼쪽의 넓은 두 층, 오른쪽의 휘어 내려온
  가지를 `g/v/n/l/a`의 큰 면으로 구분했다. 솔잎 층 사이 열린 공간은 의도된 것이다.
- 적갈색 줄기: `k/b/r/s/h/i`로 왼쪽 위 빛, 밝은 목재 면, 오른쪽 그림자를 만들고
  목·흉부·뿌리에 갈라진 짧은 수피 군집을 직접 넣었다. 관 밑 밝은 나무 마디는
  얼굴 위 줄기의 일부다. 작은 금빛 눈은 그 아래 줄기 얼굴에 있다.
- 두 가지 팔: 먼 팔은 뒤의 가드, 가까운 오른팔은 공격·기술을 담당한다.
  준비에서 가까운 팔이 가슴 앞으로 접혀 뒤로 모이고, 이동에서 오른쪽 위로 펴진 뒤
  공격에서 굵은 가지 끝과 두 갈래 손이 아래로 내려온다. 팔 사이 빈 공간을 보존했다.
- 뿌리 다리: 뒤 뿌리는 밀기, 앞 뿌리는 들기와 접지를 담당한다. 무릎의 볼록한 면,
  좁아진 발목, 갈라진 바닥 뿌리 끝을 구분했다. 18자세 모두 실제 본체 하중 윤곽이 y=92에 있다.

## 동작별 직접 저작

| 동작 | 저작한 변화 |
|---|---|
| 대기 | 관 끝의 서로 다른 솔잎과 국소 줄기 숨 변화. 발은 고정. |
| 공격 | 뒤로 접힌 가까운 가지 팔 → 앞 뿌리의 들린 무릎과 뒤 뿌리 밀기 → 어깨와 가지의 내려치기 → 접힌 팔과 회수 뿌리. |
| 피격 | 목·눈썹이 뒤로 꺾이고 어깨가 낮아지며 가까운 가지가 밖으로 벌어짐. |
| 쓰러짐 | 솔잎 층을 낮고 넓게 다시 저작. 어두운 눈꺼풀, 이어진 나무 목, 바닥 몸통, 접힌 가지와 오른쪽 뿌리 끝. |
| 송침탄 | 위로 편 가지 끝에서 녹빛 모으기 → 실제 끝에서 위·가운데·아래 세 솔잎 다발 → 접힌 가지 끝의 잔침과 떨어지는 다섯 파편. |
| 독 | 목이 내려오고 한 가지가 턱을 감싸며 다른 가지가 배를 받침. 자주색 독 방울은 두 프레임에 서로 다른 위치·크기·터짐을 직접 저작. |
| 기절 | 금빛 눈을 없애고 얼굴·어깨를 처짐. 두 팔이 떨어져 있으나 어깨부터 손끝까지 실제 나무 면으로 이어짐. 별 위치가 다름. |
| 수면 | 낮아진 솔잎 관, 앉아 접힌 뿌리, 무릎 위 가지, 금빛 눈 대신 2px/3px 수피 눈꺼풀. 국소 가슴 면으로 숨을 표현하고 발끝을 유지. |

## 실제 PNG를 보고 고친 위치 (0부터 시작하는 native 좌표)

1. 대표 대기 그림에서 관의 오른쪽 폭이 부족해 보였다. 오른쪽 관 `(49..76,13..38)`과
   왼쪽 솔잎 끝 `(10..21,24..39)`을 개별 행으로 저작했다. 손끝 `(10..19,69..76)`,
   `(51..60,73..79)`에도 연결된 짧은 가지 갈래를 추가했다.
2. 송침탄 준비의 목 아래 y=56..59가 비어 있었다. `skill_a`의 따뜻한 목·어깨 면
   `(28..52,56..59)`을 해당 행 문자열로 직접 복구했다.
3. `hit`에서 오른쪽 관 하부가 떨어져 있었다. `(59..71,29)`의 솔잎 연결을 다시 찍었다.
4. 기절 아래팔이 이전 팔꿈치와 떨어져 있었다. `stun_a/b` 각각 `(53..74,73..88)`에서
   자기 팔꿈치에 맞춰 위팔·아래팔·손끝을 별도로 다시 저작했다. 연결 검사로 채우지 않았다.
5. 송침탄 세 다발이 매끈한 창처럼 보이고 오른쪽 끝이 x=95에 닿았다. `skill_b`의
   `(76..95,42..75)`를 명시한 투명 행으로 지운 다음 서로 다른 중심 침과 옆 솔잎을 다시 골랐다.
   최종 가장 오른쪽 불투명 픽셀은 x=94이며 x=95는 투명하다.
6. `attack`, `skill_b` 앞 뿌리의 면이 긴 네모 기둥처럼 보였다. `(46..65,75..92)`의
   굵은 무릎·좁은 발목·두 갈래 뿌리 끝을 각 자세에서 직접 재저작했다.
7. `skill_c` 가까운 뿌리는 가는 외곽선만으로 이어져 보였다. `(42..50,78..81)`에
   실제 나무 부피를 저작했다. 접힌 가지 끝 `(49..56,74..76)`에는 녹빛 잔침을 연결했다.
8. 수면 눈에는 대기의 검은 눈 군집을 쓰지 않았다. 두 수면 원본 `(43..53,63..64)`에서
   두 짧은 갈색 눈꺼풀과 그 아래 얼굴 면을 직접 선택했다. 코와 금빛 눈은 분리했다.
9. 여러 자세의 바닥 뿌리 끝과 목·배 수피도 해당 자세의 좌표에서 직접 고쳤다.
   다른 자세에 좌표 패치를 자동 전파하지 않았다.

## 실제 열람과 이미지 재로드

최종 PNG를 원본 1배의 밝은/어두운/체커 시트와 4배 최근접 6페이지에서 열었다.
최종 회수 자세는 별도의 세 배경 확대판도 다시 열었다. GIF 8개는 실제 인코딩 파일을
다시 디코드해 원본 크기 프레임·노출 시간을 읽고 그 프레임 접촉 시트를 열었다.
`preview-readback.json`은 최종 파일에서 계산한 해시, 여백, PNG/GIF 픽셀 비교,
접지와 실제 노출 시간을 기록한다. 검수 추천·사용자 승인·미감 합격 증거가 아니다.
연결 군집 진단은 떨어진 부분을 찾는 보조로만 사용했고 자동 교정은 하지 않았다.

- 18개 원본: 모두 96×96, 18개 서로 다른 픽셀 배열.
- 최종 PNG/원본의 픽셀 차이 0, GIF/원본 RGBA 차이 0, GIF 노출 시간 차이 0.
- 바깥 테두리 불투명 픽셀 0, 모든 자세 최저 불투명 y=92.
- 기본 9자세의 본체는 각각 하나의 8방향 연결 군집. 독 방울·별·회수 파편은 의도적으로 분리.
- 테스트/게이트와 독립 검수 호출은 실행하지 않았다. 등록·선택·게임 저장은 이 작업 범위가 아니다.

## 남은 시각적 한계와 검수 사항

관의 가는 솔잎과 수면의 2px/3px 눈꺼풀은 native 1배에서 작은 표현이다.
어두운 배경에서는 솔잎 외곽과 닫힌 눈의 미세한 모양이 확대판보다 덜 또렷하다.
공격의 이동→접촉은 계약상 두 정지 자세여서 GIF에서 빠른 내리치기로 읽히며 중간 궤적 프레임은 없다.
실제 전투 상대와의 접촉 거리·연출은 여기서 적용하지 않았다.
최종 자체 열람에서는 남아 있는 분리된 본체나 테두리 접촉을 발견하지 않았지만,
미감·동작 가독성과 위 세부의 충분성은 하네스의 독립 시각 검수가 판단해야 한다.

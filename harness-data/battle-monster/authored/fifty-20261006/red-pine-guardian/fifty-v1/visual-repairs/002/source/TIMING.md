# 적송목령 GIF 시간표

원본 한 칸 96×96. 좌표는 0부터 시작한다. 본체를 자동으로 옮기거나 회전한 중간
프레임은 없다. 아래 시간은 실제 `gifs/*.gif`에서 재읽은 ms이며 하네스 동작 순서와 맞췄다.
`gifs/timing.json`은 렌더 보조 시간표, `preview-readback.json`은 실제 GIF 재로드 기록이다.

| GIF | 원본 순서 | 각 노출 ms |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600, 200, 100, 120, 220, 900 |
| hit | idle_a → hit → idle_a | 700, 180, 900 |
| dead | idle_a → hit → dead | 700, 150, 1700 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700, 260, 160, 240, 900 |
| poison | poison_a → poison_b | 420, 420 |
| stun | stun_a → stun_b | 300, 300 |
| sleep | sleep_a → sleep_b | 650, 650 |

`dead.gif`도 확인용으로 반복한다. 마지막 몸이 다시 일어나는 게임 규칙을 뜻하지 않는다.

## 공격의 추적 부위

가까운 오른쪽 어깨에서 나온 같은 굵은 가지를 추적한다.
준비에서 팔꿈치가 접혀 가슴 앞을 가로질러 왼쪽 뒤로 모인다.
이동에서는 가지가 오른쪽 위로 펴지고 앞 뿌리의 무릎이 들린다.
접촉에서는 그 어깨가 내려오며 가지 끝 `(66..79,80..87)`이 내려친다.
뒤 뿌리와 앞 뿌리가 y=92에서 하중을 받는다. 회수에서는 같은 팔이 다시 접힌다.
먼 왼쪽 가지는 보조이고 타격 팔로 교체하지 않았다.

## 송침탄의 실제 가지 끝 앵커

- `skill_a`: 가까운 팔은 아래에서 가지 끝을 받쳐 위로 편다. 나무 손끝은
  `(63..73,61..65)`, 모이는 녹기는 `(61..72,56..62)`에 직접 이어져 있다.
  원형 오라가 아닌 짧게 갈라진 솔잎 기이다.
- `skill_b`: 뻗은 나무 가지와 세 손끝에서 위 `(71..75,53..56)`, 가운데
  `(73..76,58..61)`, 아래 `(75..78,62..65)`의 녹빛 뿌리가 나온다.
  위 다발은 y=42..55, 가운데는 y=55..62, 아래는 y=63..75에 있다.
  각 다발의 밝은 침, 어두운 옆가닥과 투명 틈을 별개로 저작했다.
  마지막 솔잎은 x=94까지이며 오른쪽 1px 여백을 남긴다.
- `skill_c`: 가지를 접어 회수한다. 가지 끝 `(49..56,74..76)`의 작은 잔침은
  실제 나무와 이어져 있다. 다섯 개 부서진 솔잎은 `(65..85,62..86)`의 서로 다른 위치에 있다.
  기술 이후의 파편이므로 이 다섯 조각 사이 투명 공간은 의도적이다.

## 상태 변화

독은 나무 재질을 자주색으로 바꾸지 않았다. 턱·배를 감싼 자세와 실제 독 방울이 변한다.
기절은 처진 얼굴·분리된 두 팔 경로와 별의 위치가 변한다.
수면은 접힌 두 가지팔·두 뿌리다리·닫힌 눈을 유지한다. 눈꺼풀은 두 프레임 모두
y=62의 x=48..49와 x=53..54에 있으며 코의 오른쪽 면과 구분된다.
`sleep_a`는 숨을 내쉰 면, `sleep_b`는 y=55..66의 왼쪽 가슴·목 면이
국소적으로 1px 넓어진 들숨이다. 솔잎 끝에도 작은 직접 저작 변화가 있다.
각 프레임 650ms로 한 숨의 반복은 1300ms다. 접힌 팔·무릎·발은 유지하며
두 뿌리발의 하중 윤곽은 y=92의 x=21..37, x=43..59에 닿는다.
카메라나 본체 전체 이동·회전으로 호흡을 만들지 않았다.

이 시간표는 자체 GIF 미리보기의 재로드 결과다. 런타임 hop·전투 접촉이나
새 독립 검수의 통과를 의미하지 않는다.

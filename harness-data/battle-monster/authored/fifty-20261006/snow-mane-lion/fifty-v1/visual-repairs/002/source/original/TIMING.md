# 설갈사자왕 — 자체 GIF 시간표

모든 cel은 native 128×128. `render.py`가 아래 순서와 시간을 사용한다.
`preview/*.gif`는 어두운 배경 위의 관찰용 GIF이며 투명 원본은 pxgrid/PNG다.
루프는 0(반복). 실제 프레임은 두 `gif-decoded-*.png`에서 재읽었다.

| GIF | 순서 | 각 hold(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 300, 240, 100, 150, 180, 300 |
| hit | idle_a → hit → recover → idle_a | 360, 240, 200, 360 |
| dead | idle_a → hit → dead | 360, 180, 1000 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 300, 320, 300, 240, 300 |
| poison | poison_a → poison_b | 400, 400 |
| stun | stun_a → stun_b | 420, 420 |
| sleep | sleep_a → sleep_b | 650, 650 |

## 근접 타격의 추적 부위

같은 밝은 앞발을 준비에서 굽히고, move에서 길게 내딛고,
attack에서 큰 타격 발과 짧은 발톱으로 압축하고, recover에서 몸으로 당긴다.
뒤의 어두운 앞다리는 별도 지지 역할이다. 뒷다리의 밀기와 두꺼운 발목을
각 cel의 실제 문자열로 그렸다. 타격 발 중심은 대략 `(108,105)`이다.
이 GIF는 애니메이션 관찰이며 피해 판정·사운드·게임 내 이동은 포함하지 않는다.

## 설왕후 발원점

이 종의 앵커는 손/무기가 아닌 **실제 입**이다. 아래는 0-based native 좌표다.

- skill_a: 입 안의 청백 핵 `(113..116,63..68)`과 갈기 속 빛
  `(64..76,43..50)`. 턱이 작게 열리고 가슴은 긴장한다.
- skill_b: 입 안/입술 앞 `(113..121,62..69)`에서 연결된 눈바람.
  위 갈래는 오른쪽으로 솟아 `(109..124,27..64)`에서 다른 곡률로 감기며,
  아래 갈래는 `(106..125,65..98)`에서 길게 내려와 왼쪽으로 돌아간다.
  밝은 중심과 청록 경계가 따로 있다. 몸과 분리된 임의 원형 오라가 아니다.
- skill_c: `(114..117,62..67)`의 입/턱 회수와 얇은 잔향.
  위 `(118..125,45..52)`, 중간 `(121..126,73..78)`,
  아래 `(116..123,83..89)`에 서로 다른 세 깨진 눈보라 군집이 남는다.
  얇은 잔향과 조각 사이의 의도한 틈을 유지한다.

## 상태 루프

독: 앞다리를 안으로 굽혀 버티며 턱과 손목을 압축한다. 두 번째 장에서
거품을 아래/앞쪽으로 별도 배치하고 큰 거품 하나와 두 작은 거품으로 바꾼다.
기절: 감긴 눈, 내려온 머리와 턱을 유지하며 왕관 갈기가 더 처지고 별 위치가 바뀐다.
수면: 접힌 발과 감긴 꼬리/술을 유지하고 두 번째 장의 갈기 위·등·어깨·턱을
직접 압축한다. 눈꺼풀은 닫혀 있으며 죽음의 낮은 옆으로 누운 몸과 다르다.

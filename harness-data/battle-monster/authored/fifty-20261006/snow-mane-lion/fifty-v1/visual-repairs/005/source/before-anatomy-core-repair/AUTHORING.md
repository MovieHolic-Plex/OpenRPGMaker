# 설갈사자왕 — 관절·갈기·입·쓰러짐 교정

## 원본과 범위

이 후보의 `source/` 안에서만 수정했다. 전달 원본은 `poses/*.pxgrid` 9개와
`actions/*.pxgrid` 9개이며, 각 파일은 128행×128글자의 완전한 ASCII 격자다.
기존 18색 `palette.json`, 미백 몸, 은백 갈기, 검푸른 그림자, 금빛 눈과
목고리, 분홍 코, 청록 꼬리술 및 왼쪽 위 광원을 유지했다.

첨부 18자세 그림과 64px 검객 참고를 실제로 열어 관찰했다. 참고 그림은
관찰에만 사용했으며 추적, 픽셀 추출, 재샘플링 또는 사본 배포에 사용하지 않았다.

- `before-joint-repair/`: 이번 수정 직전의 18격자, 팔레트와 두 문서.
- `original/`, `before-mane-repair/`: 기존 원안과 이전 수정 단계의 보존 자료.
- `repairs/joint-<pose>.runs`: 이번에 직접 고른 자세별 좌표와 ASCII 문자열.
  좌표는 0-based이며 형식은 `y x pixels`다. 뒤쪽 행은 실제 PNG를 보고
  다시 고른 픽셀로 앞선 행을 덮는다. 투명 픽셀 제거도 명시한 점 문자열이다.
- `joint_revision.py`: 보존 원본에 각 자세의 개별 리터럴 문자열만 적용한다.
  자세끼리 좌표를 복사하거나 본체를 이동·회전·보간하지 않는다.
- 기존 저작 코드와 패치 기록은 보존했다. 이번 단계 재현에는 아래 순서를 쓴다.

```bash
python source/joint_revision.py
python source/render.py
python source/joint_focus.py
python source/observe_joints.py
```

코드는 파일 읽기/쓰기, 명시한 픽셀 적용, PNG/GIF 렌더와 진단 확대만 보조한다.
도형 본체, 자동 명암, 자동 구멍 채우기, 이미지 생성, 전체 프레임 변형을
사용하지 않았다. 최종 격자는 패치 목록과 별도로 전체 행을 보존한다.

## 실제 그림을 보고 재교정한 내용

- 대표 대기 다리를 먼저 고친 뒤 밝은/어두운/체커 PNG를 열었다.
- 독 앞발, 기술 입, 쓰러진 목을 같은 세 배경에서 열었다.
- 전체 18자세를 세 배경의 원본 1배 시트와 최근접 확대에서 함께 확인했다.
- `preview/joint-focus-3x.png`에서 주요 부위를 원본 1배와 세 배경의 3배로
  확인했다. 확대는 저작 입력이 아닌 최종 픽셀의 진단 표시다.
- 회수 아래팔의 가는 면, 공격 발톱 끝의 잔여 윤곽, windup (56,116)의
  떨어진 옛 무릎 한 픽셀, dead (67..70,70)의 옛 갈기 끝을 실제 좌표로 고쳤다.
  연결 관찰 결과로 빈 곳을 자동으로 채우지 않았다.
- 저장한 8GIF의 실제 cel과 hold를 재읽은 `gif-decoded-motion.png`와
  `gif-decoded-status.png`를 열어 순서대로 비교했다. 전체 프레임 이동이나
  새 보간 cel 없이 기존 준비→전진→타격→회수와 상태 동작을 유지했다.

현재 파일 관찰은 `preview/joint-revision-observations.json`에 보존한다.
18개 격자는 128×128이고, 미등록 기호와 테두리 잉크가 없으며 최하단은 y=124다.
idle_a의 실제 발 윤곽은 y=124에 닿는다. 팔레트 바이트는 보존 원본과 같고
PNG alpha는 0/255다. 8GIF를 재읽은 픽셀은 해당 PNG를 관찰 배경에 놓은 픽셀과
같다. 기록된 SHA-256은 실제 파일에서 계산한 값이다. 이것은 파일 관찰이며
저작 주체, 미감, 사용자 선택 또는 독립 검수 통과를 증명하는 판정이 아니다.

## 남은 시각 문제와 확인 범위

- 갈기는 여전히 큰 겹털 면으로 양식화되어 있다. 가슴 앞면에 짧은 반복 명암이
  남아 있으며, 모든 털을 개별 가닥으로 표현한 그림은 아니다.
- 독의 들린 먼 앞발과 회수의 먼 앞발은 원근 때문에 작다. 밝은 배경에서는
  밝은 발가락과 청백 기술 잔상의 대비가 약해진다.
- 쓰러짐은 목 연결을 보완했지만 넓게 겹친 갈기/어깨에 비해 오른쪽 얼굴이
  작게 읽힌다. 낮은 접힌 앞발과 뒷발의 경계는 남아 있다.
- GIF의 저장 cel/순서/hold와 프레임별 자세는 확인했다. 실시간 재생 캡처나
  실제 전투 화면에서 대시 거리, 충돌, 피해/음향 타이밍을 확인하지는 않았다.

독립 검수와 사용자 선택은 하네스의 다음 단계다. 승인이나 통과를 선언하지
않는다. 별도 검수자를 호출하지 않았고 brief, ledger, 검수 결과, 다른 후보,
저장소 또는 게임 저장소를 수정하지 않았다. 테스트와 gates는 실행하지 않았다.

# 설갈사자왕 — 지적 좌표 직접 수정 기록

## 범위 / 보존

이 후보의 `source/` 안에서만 작업했다. 기본 9자세와 추가 9자세를 모두
native 128×128 전체 ASCII 행으로 저장했다. 팔레트는 기존 18색 그대로다.
`original/poses/`, `original/actions/`, `original/palette.json`은 수정 직전 원본이다.
이전 AUTHORING/TIMING도 `original/`에 보존했다. `dead`는 좋은 쓰러짐을 그대로
보존했으며 원본과 바이트가 같다. 사용자 선택이나 검수 결과는 기록하지 않았다.

`author.py`는 이전 저작 보조 코드다. 이번 수정의 직접 선택한 좌표와 최종 색 문자열은
`repairs/<각 자세>.runs`에 있다. 각 파일의 형식은 **y x ASCII색문자열**이고 좌표는
0부터 시작한다. 주석 아래의 덧붙인 수정이 같은 파일의 앞선 시도를 덮을 수 있다.
`repair.py`는 보존 원본을 읽고 그 자세에 지정된 리터럴 문자열만 적용한다.
공유 패치를 다른 자세에 자동 전파하거나 프레임 전체를 옮기지 않는다.
최종 전달 원본은 `poses/*.pxgrid`, `actions/*.pxgrid`의 전체 행이다.

재현: 이 source에서 `python repair.py` → `python render.py` → `python inspect.py`.
`author.py`는 이전 판을 재현하므로 새 격자를 유지하려면 위 수정 순서를 사용한다.
렌더러는 PNG/GIF 디코딩과 진단 확대/라벨만 한다. 연결 진단은 읽기 전용이며
빈 공간을 자동 채우지 않는다. 생성 이미지, 도형 래스터화, 자동 명암,
프레임 이동/회전/보간, 참고 그림 픽셀 추출을 사용하지 않았다.

## 참고 관찰

첨부 현재 18자세 시트와 64px 검객 그림을 실제로 열었다. 사자의 은백 몸,
금빛 눈/목고리, 분홍 코, 청록 꼬리 술, 밝은 왼쪽 위 면을 유지했다.
검객은 얼굴과 작은 크기의 읽힘을 관찰하는 용도로만 봤다. 참고 이미지 바이트를
source에 복제하거나 그림의 픽셀을 추출하지 않았다. 후보 폴더의 project.sqlite와
브라우저 기록 파일은 제공되지 않았으며, 작업 근거는 전달된 원문과 현 원본이다.

## 실제 그림을 열고 다시 고친 곳

- windup의 옛 코 끝 x=115..116, y=68..69와 hit의 옛 귀 x=101..106,
  y=31..34가 새로운 윤곽 밖에 남았다. 해당 문자열을 직접 투명으로 지웠다.
- poison_b/stun_b의 옛 귀 x=86, y=33..35와 한 점의 옛 목 끝을 지웠다.
- 기술 방출의 이전 가슴 리본 끝을 지우다 먼 앞다리 위쪽 겹침이 잘렸다.
  skill_b x=94..109, y=89..100에 별도의 어깨/윗다리/아랫다리 면을 직접 그렸다.
- 그 뒤 1배 기술 이미지에서 두 굽음이 여전히 세로 리본처럼 붙어 읽혔다.
  skill_b의 주둥이/벌린 턱을 x=82..109에 다시 그리고, 입 안 핵과 두 별도의
  말린 눈바람 전선을 공간이 확보된 x=110..126에 새로 찍었다. 이전 좁은 S를
  최종 파문으로 남기지 않았다. x=97, y=27..28의 옛 효과 조각도 직접 지웠다.
- 배경별 1배 전체 시트, 2배 확대 시트, 개별 자세의 세 배경 PNG를 열었다.
  반격/독/기절의 먼 앞다리 연결을 함께 확인해 각 자세의 실제 위치에서 고쳤다.
- 저장한 8GIF를 다시 읽은 `gif-decoded-motion.png`, `gif-decoded-status.png`를 열어
  실제 cel 순서와 hold를 비교했다. 이 기록은 정지 cel 및 GIF 파일 관찰이며
  게임의 실제 돌격 이동/전투 접촉 영상은 아니다.

## 현재 파일 관찰

`preview/source-observations.json`에 실제 파일 해시와 변경 픽셀 수가 있다.
18개 모두 128행×128글자이고 모두 서로 다르다. 알 수 없는 팔레트 기호와
테두리 잉크는 없으며, 모든 장의 최하단 실제 신체 픽셀은 y=124다.
idle_a의 y=124 잉크는 54픽셀이다. PNG 투명은 0/255이고 팔레트는 18색이다.
17개 자세를 수정했고 `dead`/팔레트는 보존했다. 작은 분리 군집은 독 거품과
기절 별/반짝임 같은 의도한 효과다. 연결 성분 결과는 미감 판정을 대신하지 않는다.

## 남은 시각 문제 / 다음 독립 검수에서 볼 점

- 은백 갈기의 큰 사선 겹침은 여전히 양식화가 강하다. 짧은 바깥 털 끝과 넓은
  곡면이 1배에서 충분히 털로 읽히는지 확인이 필요하다.
- 최종 방출 자세는 턱을 뒤로 당긴 포효이며 두 파문에 공간을 준다. 준비→포효→
  닫는 턱 사이의 얼굴 변화는 크다. 실제 표시 크기에서 이 반동/방출 타이밍과
  눈바람의 크기가 적절한지 독립 시각 검수에서 확인할 부분이다.
- windup→move는 낮아진 목이 빠르게 솟는 강한 체중 변화다. 현재 보존한 100ms
  전진 hold와 맞는지는 실제 재생/전투 이동을 함께 볼 필요가 있다.
- 금 목고리는 큰 갈기와 앞다리에 많이 가려진다. 특히 공격/독/기절에서 짧은
  먼쪽 반환면이 금속 부착으로 읽히는지 확인할 부분이다.
- 수면 호흡은 갈기/가슴 윤곽의 작은 팽창이며 두 장만 사용한다.
  밝은 배경에서 청백 효과 대비도 어두운 배경보다 약하다.

테스트/gates, 별도 검수자 호출, 저장소/게임 저장소/ledger/brief 수정은 하지 않았다.
이 문서는 저작과 관찰 기록이며 사용자 승인 또는 하네스 통과 선언이 아니다.

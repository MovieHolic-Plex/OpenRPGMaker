# 설갈사자왕 — 갈기·회수 발·쓰러진 목 직접 수정

## 작업 범위와 원본

이번 수정은 이 후보의 `source/` 안에서만 수행했다. 기본 9자세와 추가
9자세의 최종 원본은 `poses/*.pxgrid`, `actions/*.pxgrid`다. 모두 128×128의
전체 ASCII 행이다. 기존 18색 팔레트와 종의 미백 몸, 은백 갈기, 금빛 눈과
목고리, 분홍 코, 청록 꼬리술, 왼쪽 위 광원을 유지했다.

- `original/`은 이전 수정 단계가 보존했던 최초 원본이다.
- `before-mane-repair/`는 이번 지적을 수정하기 직전의 18격자, 팔레트,
  AUTHORING/TIMING, 저작 보조 코드와 당시 파일 관찰 기록이다.
- `author.py`와 이전 `repairs/*.runs`는 이전 저작 기록으로 보존했다.
- **이번에 직접 고른 최종 픽셀 문자열**은 `repairs/mane-<자세>.runs`에 있다.
  형식은 `y x ASCII문자열`, 좌표는 0부터 시작한다. 같은 파일의 뒤쪽 행은
  실제 그림을 보고 다시 고른 수정으로 앞선 행을 덮는다.
- `revise_mane.py`는 수정 직전 원본에 해당 자세의 리터럴 문자열만 적용한다.
  다른 자세의 좌표를 읽어 옮기거나 공유 패치를 자동 전파하지 않는다.

원본을 다시 굽는 순서:

```bash
python source/revise_mane.py
python source/render.py
python source/inspect.py
python source/record_revision.py
```

`repair.py`는 이전 단계를 재현하는 보조 코드이며 이번 `mane-*.runs`를
별도 단계로 남긴다. 위 순서는 이번 수정 직전 스냅샷에서 최종 격자를 재현한다.
격자의 최종 전달 형태는 패치 목록이 아닌 128개의 완전한 행이다.

도형 생성, 자동 명암, 자동 구멍 채우기, 본체/프레임 이동·회전·보간,
생성 이미지, 참고 이미지의 추적/픽셀 추출을 사용하지 않았다. 확대와 잘라 본
그림은 우리 원본의 진단용 PNG이며 저작 입력으로 재샘플링하지 않았다.

## 참고 관찰

첨부 현재 18자세 시트와 64px 검객 이미지를 실제로 열었다. 사자의 큰 몸,
네 발, 얼굴 앞 여유, 목과 어깨의 겹침, 금 목고리와 청록 꼬리술을 관찰했다.
검객은 작은 크기에서 얼굴과 해부가 읽히는 정도를 보는 용도로만 사용했다.
두 참고 이미지의 픽셀을 추출하거나 `source`에 사본으로 배포하지 않았다.

## 실제 이미지 관찰과 파일 재읽기

1. 대표 idle_a를 먼저 고쳐 밝은·어두운·체커 배경의 PNG를 열었다.
2. recover와 dead를 고쳐 같은 세 배경에서 발과 목 접합을 확인했다.
3. 같은 갈기 부위가 있는 나머지 자세를 각 자세의 실제 위치에서 직접 수정했다.
4. 최종 18자세 시트를 native 1배와 최근접 2배로 열었다. `revision-focus.png`는
   핵심 부위의 native 그림과 최근접 3배 부분 확대다. `dead-4x.png`와
   `recover-4x.png`도 최종 픽셀을 표시한다.
5. 저장된 8개 GIF를 재읽은 `gif-decoded-motion.png`, `gif-decoded-status.png`를
   열어 준비→전진→타격→회수, 피격/쓰러짐, 기술과 세 상태 루프의 실제 cel을
   비교했다. 모든 GIF의 디코딩 픽셀은 해당 native PNG를 GIF 배경 위에 놓은
   픽셀과 같았다. 움직임을 보간하거나 전체 프레임을 옮긴 cel은 추가하지 않았다.

현재 읽은 파일 사실은 `preview/mane-revision-observations.json`에 있다.
최초 원본과의 관찰 기록은 `preview/source-observations.json`에 별도로 있다.
이번 수정 전후 source SHA-256, 현재 PNG/GIF SHA-256은 실제 파일에서 계산했다.
모델 실행 메타데이터나 검수 결과를 새로 꾸며 기록하지 않았다.

- 기본/추가 총 18개 격자는 모두 128행×128글자이며 서로 다른 원본이다.
- 팔레트는 기존 18색과 바이트가 같고 미등록 기호는 없다.
- 모든 자세의 최하단 실제 신체 잉크는 y=124이고 1px 테두리에 잉크가 없다.
- idle_a의 y=124에는 실제 발의 54픽셀이 있다.
- PNG alpha는 0과 255뿐이다.
- 8GIF의 순서/노출시간과 native 픽셀 재읽기 결과를 기록했다.
- 연결 관찰 코드는 읽기 전용이며 빈 곳을 채우지 않는다. 독 거품/기절 별과
  기술 잔상 사이의 의도한 빈 공간을 보존했다.

## 남은 시각 한계와 독립 검수에서 볼 부분

- 갈기는 큰 둥근 털 덩어리로 양식화했다. 위쪽 바깥 능선과 쓰러진 갈기의 긴
  접힌 실루엣은 여전히 각진 면이 있어, native 크기에서 털로 충분히 읽히는지
  새 독립 검수에서 확인할 부분이다.
- 회수한 먼 앞발은 원근 때문에 앞쪽 타격 발보다 작고 발톱 대비가 약하다.
  연결과 접힌 형태는 이번 PNG에서 확인했으나 실제 표시 크기의 가독성은
  독립 검수의 판단이 필요하다.
- 준비→전진의 목 높이 변화와 포효 얼굴의 반동은 원래 동작을 보존했다.
  GIF cel/hold를 관찰했으며 실제 전투의 대시 거리·접촉·피해 타이밍을
  실행해 확인한 것은 아니다.
- 수면 호흡은 두 cel의 갈기·가슴 윤곽 변화다. 밝은 배경에서는 청백 기술의
  대비가 어두운 배경보다 약하다.

이 문서는 저작과 자체 관찰 기록이다. 사용자 승인이나 새 하네스 검수 통과를
선언하지 않는다. 별도 검수자를 호출하거나 검사 결과·ledger·brief·다른 후보·
저장소·게임 저장소를 수정하지 않았다. 테스트와 gates도 실행하지 않았다.

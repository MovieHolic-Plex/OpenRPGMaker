# 설갈사자왕 — 현재 자체 GIF 시간표

모든 cel은 native 128×128 리터럴 원본이다. 아래 노출 시간은 `render.py`와
실제 저장 GIF를 재읽은 값이 같다. GIF는 어두운 배경의 관찰용이며 투명 원본은
각 PNG/pxgrid다. 전체 프레임을 옮겨 이동을 만드는 연출은 넣지 않았다.

| GIF | 순서 | 각 hold (ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 300, 240, 100, 150, 180, 300 |
| hit | idle_a → hit → recover → idle_a | 360, 240, 200, 360 |
| dead | idle_a → hit → dead | 360, 180, 1000 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 300, 320, 300, 240, 300 |
| poison | poison_a → poison_b | 400, 400 |
| stun | stun_a → stun_b | 420, 420 |
| sleep | sleep_a → sleep_b | 650, 650 |

## 근접 타격 추적

준비에서 목/갈기를 낮추고 뒷 hock과 앞 무릎을 굽힌다. 전진에서 같은 밝은
앞다리가 넓게 내딛고, 공격에서 연결된 팔꿈치→압축된 손목→큰 앞발이 오른쪽을
친다. 접촉 앞발은 x=102..125, y=101..112이며 세 짧은 발톱과 어두운 발가락
경계가 있다. 다른 어두운 앞다리와 뒷발은 지지 역할이다. 회수에서는 타격 발을
몸으로 당긴다. 피격은 얼굴/목을 갈기 쪽으로 젖히며 지지 발로 버틴다.

## 설왕후 — 손/무기 대신 실제 입에서 발원

좌표는 0-based native (x, y). 이 짐승은 손이나 무기를 쓰지 않는다.

- **skill_a / 모으기, 320ms:** x=110..118, y=63..68의 작은 어두운 입 안에서
  청백 핵이 보인다. 갈기 겹침 안 x=64..82, y=49..57에 넓은 빛이 모이며
  턱/볼이 조금 벌어진다. 코 위에 독립 디스크를 얹는 효과가 아니다.
- **skill_b / 방출, 300ms:** 얼굴/목을 x=82..109에서 포효하며 당기는 별도
  군집으로 그렸다. x=102..111, y=64..68의 크게 열린 입 안에서 불투명 핵과
  두 짧은 경로가 갈라진다. 위쪽 긴 파문은 x=110..126, y=26..62,
  아래쪽 짧고 두꺼운 파문은 x=109..126, y=69..98이다. 넓은 청백 면,
  청록 그림자 가장자리, 두 전선 사이의 빈 간격과 다른 말린 끝을 직접 찍었다.
  가장 오른쪽 잉크는 x=126이며 x=127은 투명하다.
- **skill_c / 회수, 240ms:** 볼/턱 x=100..116, y=62..78을 닫으며 조금 당긴다.
  잔향은 실제 입 x=114..117, y=62..67에서 이어진다. 위 x=118..125,
  y=45..52, 중간 x=121..126, y=73..78, 아래 x=116..123, y=83..89에
  서로 다른 세 깨진 얼음 군집을 유지했다. 사이의 틈은 의도한 분리다.

## 상태 루프

- **독 400/400ms:** a의 무거운 반감긴 눈과 굽힌 앞다리에서 b의 낮아진 얼굴,
  처진 목/어깨/목고리로 이어진다. 거품도 서로 다른 위치/크기다.
- **기절 420/420ms:** 감긴 눈과 이완된 턱을 유지한다. b에서 머리/목이 작게
  내려오며 오른쪽으로 흔들리고 어깨가 비대칭으로 가라앉는다. 별만 옮기지 않았다.
- **수면 650/650ms:** 접힌 앞발/뒷발과 배를 감싼 꼬리/술, 짧은 닫힌 눈꺼풀을
  유지한다. b에서 갈기 위가 y=48까지 올라오고 가슴이 조금 부풀어 들숨을
  표현한다. a는 그보다 눌린 날숨이다. 죽음의 옆으로 누운 자세와 다르다.

`preview/gif-decoded-motion.png`와 `preview/gif-decoded-status.png`는 실제 8GIF의
프레임/hold를 다시 읽은 관찰판이다. 게임의 이동 거리, 피해 판정, 사운드, 실제
상태 적용은 이 후보 원본 저작 범위에 포함되지 않는다. 승인/통과 기록도 아니다.

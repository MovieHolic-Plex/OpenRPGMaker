# 설갈사자왕 — fifty-v1 원본 저작

## 범위와 원본

이번 결과는 이 후보의 `source/` 안에 있는 18개 native 128×128 ASCII 격자,
18색 팔레트, 자체 PNG/GIF 관찰 자료다. 저장소·게임 저장소·brief·ledger·다른 후보는
수정하지 않았다. 인간 선택이나 독립 검수 판정을 기록하지 않았다.

- `poses/`: idle_a, idle_b, idle_c, windup, move, attack, recover, hit, dead.
- `actions/`: skill_a, skill_b, skill_c, poison_a, poison_b, stun_a, stun_b,
  sleep_a, sleep_b.
- `palette.json`: 한 글자→RGB. `.`은 투명하며 팔레트에 없다.
- `author.py`: 저작 중 직접 선택한 `(y, x, ASCII 색 문자열)`과 수정 이력.
  빈 캔버스 초기화, 문자열 배치, 파일 저장만 수행한다. 보존된 본체의 변경하지 않은
  픽셀은 유지하고, 자세마다 다른 관절·턱·효과를 해당 자세의 문자열로 그렸다.
  모든 최종 pxgrid는 축약되지 않은 128개 전체 행이다.
- `render.py`: 원본 디코딩, PNG/GIF 저장, 관찰용 최근접 확대와 라벨.
- `inspect.py`: 원본 크기·색·경계·연결 성분·실제 파일 해시의 읽기 전용 관찰.
  원본을 보정하거나 연결 성분을 자동으로 채우지 않는다.

도형 마스크, 생성 이미지, 원본 리샘플, 프레임 전체 이동/회전/보간,
자동 명암 생성, 자동 빈틈 채우기를 사용하지 않았다.

## 참고 관찰

첨부 `references/human-size.png`를 실제로 열었다. 작은 얼굴의 명암 분리,
팔과 검의 연결, 제한된 실루엣 면적으로 얼굴을 읽히게 하는 점을 관찰했다.
픽셀을 추출하거나 추적하지 않았고 참고 그림을 결과물에 넣지 않았다.
현재 후보 폴더에는 기존 pxgrid 및 project.sqlite가 없었다.

## 큰 면과 정체성

오른쪽을 향한 은백 사족 사자. 왼쪽 위 크림색 빛, 은회색 기본 면,
검푸른 갈기 겹침과 배/다리 그림자를 사용했다. 귀 두 개, 작은 금빛 눈,
분홍 코, 밝은 주둥이, 짧은 검은 수염 뿌리, 금 목고리,
청록 꼬리 술을 남겼다. 갈기는 큰 층으로, 몸통은 넓은 등과 엉덩이 면으로
구별했다. 발끝은 털 면과 짧은 밝은 발톱/어두운 발가락 사이를 나눴다.

## 실제 그림을 보고 직접 바꾼 곳

1. 첫 갈기 초안의 사선 띠가 몸 전체를 좁은 쐐기로 보이게 했다.
   초안 본체를 폐기하고 넓은 등/엉덩이, 두꺼운 네 다리, 겹친 갈기,
   귀와 돌출된 주둥이를 다시 저작했다.
2. 대기 얼굴 뒤 `(87..91, 39..68)`의 윤곽이 목을 분리해 보였다.
   해당 행에 중간 털색과 겹침 그림자를 직접 넣었다. 주둥이
   `(100..116, 55..77)`에서 코, 볼, 수염 뿌리, 닫힌 턱을 다시 나눴다.
3. windup의 갈기 위 `(54..90, 22..38)`를 낮춘 별도 군집으로 그렸다.
   뒷다리는 굽힌 허벅지/발목, 앞다리는 압축된 어깨/팔꿈치를 그렸다.
   최종 확대에서 `(101..106, 95..100)`의 남은 가는 윤곽을 지웠고,
   `(61..111, 101..124)`를 두 앞다리의 서로 다른 경로로 다시 그렸다.
4. move의 뒷발을 왼쪽에서 밀고 앞다리를 넓게 내딛도록 저작했다.
   처음 distal 앞다리가 가늘었고 오른쪽 x=127에 닿았다.
   `(91..127, 101..124)`를 직접 지우고 팔꿈치→두꺼운 아래다리→발목→발을
   새 문자열로 그렸다. 현재 오른쪽 최외곽은 x=125다.
5. attack: `(78..119, 83..110)`에 어깨에서 이어진 큰 타격 앞발,
   압축된 손목, 짧은 발톱을 그렸다. `(102..119, 66..82)`는 벌린 입,
   이빨, 어두운 입 안, 분홍 혀와 아래턱이다. 타격 앞발 뒤
   `(82..101, 100..124)`에 하중을 받는 먼 앞다리를 다시 저작했다.
6. attack/recover에서 `(64..71, 116..124)`의 이전 발 잔여 군집을
   해당 자세의 좌표로 직접 지웠다. recover의 아래팔과 발을
   `(72..101, 103..124)`에서 더 두껍게 다시 그렸다.
7. dead는 서 있는 몸을 옮긴 결과가 아닌 별도 낮은 원본이다.
   닫히고 흐려진 눈, 내려온 목/턱, 접힌 앞발/뒷발, 말린 청록 꼬리를 그렸다.
   확대에서 목 뒤 빈틈을 발견해 `(69..99, 91..114)`를 실제 털 부피로 다시
   연결했다. 머리는 목 면과 이어지며 몸/발이 y=124에서 하중을 받는다.
8. sleep 두 장은 별도의 웅크린 사족 자세다. `(99..102, 91)` 및
   두 번째 장 `(99..102, 92)`의 짧은 닫힌 눈꺼풀을 코와 분리했다.
   겹친 갈기, 접힌 다리, 발끝, 배를 감싼 꼬리와 술을 남겼다.
   첫 확대의 어깨/목 빈틈을 `(60..85, 81..113)`와 두 번째 장의
   `(61..85, 82..113)`에서 각각 다른 문자열로 고쳤다.
   두 번째 장은 crown y=52부터 시작하며 등/어깨 윤곽을 눌렀고 턱 군집도
   작게 내려온다. 전체 프레임 이동이나 내부 색만 바꾸는 호흡이 아니다.
9. poison은 아픈 턱과 안으로 굽힌 앞다리, 두 번째 장의 더 압축된 손목,
   서로 다른 독 거품으로 구별했다. stun은 내려온 갈기/머리, 감긴 눈,
   늘어진 턱과 각각 두 개/세 개의 다른 위치 별 군집이다.
10. skill은 실제 입과 갈기의 청백 핵, 입에서 나가는 위·아래 굽은 두
    눈바람, 닫는 턱과 세 개의 서로 다른 잔상 조각으로 그렸다.

## 관찰 결과물

`preview/`에 개별 투명 native PNG 18개, native 3×6 시트,
1배/2배 전체 시트와 개별 세 배경 확대, 8개 동작 GIF가 있다.
밝은·어두운·체커의 실제 PNG를 열어 위 좌표들을 고쳤다.
실제 저장된 GIF를 다시 디코드한 `gif-decoded-motion.png`,
`gif-decoded-status.png`도 열어 실제 cel과 노출 시간을 비교했다.
이는 GIF 자세 관찰이며 게임 런타임 전투 영상이 아니다.

`preview/source-observations.json`은 현재 실제 파일의 읽기 자료다.
18장 모두 128×128 전체 행이고 최하단 실제 신체 픽셀은 y=124다.
모든 최외곽은 x=5..126, y=13..124 안에 있다. 별/독 거품/얼음 잔상 조각의
의도한 분리는 보존했다. 신체 자세의 연결 확인은 품질 판정을 대신하지 않는다.
테스트·gates·독립 검수 호출은 하지 않았다.

## 남은 시각 문제 / 독립 검수 대상

- 큰 갈기의 긴 세로 은빛 층이 매우 양식화되어 있다. 목/가슴이 연결되어도
  모발 띠 또는 갑옷처럼 읽히는 정도와 몸통을 가리는 정도는 추가 판단이 필요하다.
- 큰 갈기에 비해 얼굴은 작은 측면 주둥이로 읽힌다. 정면 성분 및 사자 볼의
  설화풍 표현이 충분한지 독립 검수에서 봐야 한다.
- 돌격의 보폭과 준비/접촉 사이 어깨 각도 변화는 과장되어 있다.
  100ms 전진 cel에서 부드러움보다 강한 자세 변화가 남는다.
- 밝은 배경에서 설왕후의 청백 핵/잔상은 어두운 배경보다 대비가 약하다.
- 수면 호흡은 두 장의 작은 윤곽 변화다. 실제 사용 크기의 가독성은 하네스의
  독립 관찰이 필요하다.

이 문서는 저작 기록이다. 사용자 승인이나 하네스 통과를 주장하지 않는다.

# 설갈사자왕 — 자체 GIF 시간표

모든 cel은 native 128×128의 완전한 리터럴 격자다. 이번 갈기·회수 발·목 수정은
기존 순서와 hold를 유지했다. GIF는 관찰용 어두운 배경이며 투명 PNG와 pxgrid가
원본이다. 실제 저장 GIF를 재읽은 hold와 아래 시간이 같다.

| GIF | 순서 | 각 hold (ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 300, 240, 100, 150, 180, 300 |
| hit | idle_a → hit → recover → idle_a | 360, 240, 200, 360 |
| dead | idle_a → hit → dead | 360, 180, 1000 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 300, 320, 300, 240, 300 |
| poison | poison_a → poison_b | 400, 400 |
| stun | stun_a → stun_b | 420, 420 |
| sleep | sleep_a → sleep_b | 650, 650 |

## 타격과 회수

windup은 낮춘 목/갈기와 굽힌 뒤 지지발로 하중을 모은다. move는 같은 밝은
앞다리가 넓게 내딛고, attack은 어깨에서 이어진 팔꿈치→압축된 손목→큰 앞발을
앞으로 친다. 접촉 발은 x=102..125, y=101..112이며 짧은 발톱과 발가락 경계가
있다. 어두운 먼 다리와 뒷발은 지지 역할이다.

recover에서는 앞쪽 큰 발이 뒤로 회수되며 바닥 y=124를 딛는다. 뒤쪽 앞다리의
수정한 팔꿈치/손목/작은 접힌 발은 x=97..109, y=94..108이고 공중에 들려 있다.
이 작은 발을 바닥까지 늘리지 않았다. hit은 움츠린 어깨와 젖힌 얼굴을 유지한다.
dead는 몸과 머리가 낮은 목 면으로 이어지고 접힌 발/꼬리가 바닥에 놓인다.

## 설왕후 — 실제 입에서 시작하는 기술

이 종은 사족 짐승으로 손이나 무기를 들지 않는다. 좌표는 0-based native다.

- **skill_a / 모으기, 320ms:** 실제 어두운 입 안 x=110..118, y=63..68의
  청백 핵을 보존했다. 새 갈기 겹침의 x=66..81, y=49..56 부근에 청백빛을
  직접 골라 넣었다. 코 위에 독립 구체를 얹는 효과가 아니다.
- **skill_b / 포효, 300ms:** 당겨진 얼굴과 벌린 턱을 유지했다. 입 안
  x=102..111, y=64..68의 핵에서 두 짧은 경로가 갈라진다. 위쪽 파문은
  x=110..126, y=26..62, 아래쪽은 x=109..126, y=69..98에 있는 서로 다른
  굽은 전선이다. 말린 끝, 넓은 청백 면, 청록 그림자, 둘 사이의 빈 공간을
  유지했다. 갈기와 얼굴이 만나는 x=80..87의 긴 수직 띠만 굽은 털로 수정했다.
- **skill_c / 회수, 240ms:** x=100..116, y=62..78에서 조금 뒤로 당겨져 닫히는
  턱을 보존했다. 입 x=114..117, y=62..67에 잔향이 연결된다. 위 x=118..125,
  y=45..52, 중간 x=121..126, y=73..78, 아래 x=116..123, y=83..89의
  서로 다른 세 얼음 잔상과 그 사이의 의도한 틈은 그대로다.

## 상태 루프

- **독 / 400, 400ms:** 반감긴 눈과 굽힌 앞다리에서 낮아진 얼굴·목·어깨로
  이어진다. 두 장의 독 거품은 위치와 크기가 다르다. 갈기만 새 털 구조로 바꿨다.
- **기절 / 420, 420ms:** 닫힌 눈과 이완된 턱을 유지하며 b에서 머리가 내려오고
  어깨가 기울어진다. 서로 다른 위치의 별도 유지했다.
- **수면 / 650, 650ms:** 접힌 앞발/뒷발과 감긴 꼬리/청록 술, 짧게 닫힌 눈을
  유지한다. a는 낮은 날숨, b는 y=48까지 올라간 갈기와 넓어진 가슴의 들숨이다.
  이번 곡면은 각각의 실루엣에 맞춘 별도 ASCII 행이며 전체 몸 이동이 아니다.

`preview/gif-decoded-motion.png`와 `preview/gif-decoded-status.png`는 저장 GIF의
cel/hold를 실제 재읽은 관찰판이다. 파일별 실제 해시와 PNG 대비 디코딩 픽셀
관찰은 `preview/mane-revision-observations.json`에 있다. 실제 게임의 이동 거리,
피해 판정, 사운드나 상태 적용에 대한 승인/통과 기록은 아니다.

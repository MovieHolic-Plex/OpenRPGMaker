# 설갈사자왕 — 앞다리 관절·기절 볼 경계 교정

## 현재 후보와 범위

이 작업은 source 안에서만 기록했다. 기본 poses 9개와 추가 actions 9개는
각각 128행×128글자의 전체 literal ASCII 격자다. 기존 18색 palette.json과
나머지 15자세는 수정 직전 파일과 바이트까지 같다. 미백 사족 몸, 겹친 은백
갈기, 검푸른 그림자, 금 목고리/눈, 분홍 코와 청록 꼬리술을 보존했다.
광원은 왼쪽 위이며 참고 그림에서 픽셀을 추출하거나 재샘플링하지 않았다.

첨부 reference.png와 references/human-size.png를 실제로 열어 관찰했다.
검객은 얼굴/크기 참고이며 이 짐승의 격자에 복사하지 않았다.

## 직접 고른 픽셀 (0-based native)

| 자세 | 실제 변경 범위 | 픽셀 수 | 변경 |
|---|---|---:|---|
| move | x=101..111, y=83..94 | 60 | 턱 아래 먼 앞다리의 평평한 윗면과 긴 수직 외곽을 수정했다. 어깨 아래 윗다리 면은 중간색/푸른 그림자로 이어지고, 외곽은 y=84의 x=107에서 y=86..87의 x=110으로 둥글게 벌어졌다가 y=93의 x=106으로 좁아져 가까운 내딛는 다리 뒤에 가려진다. 아래쪽 지지 다리/발과 가까운 앞다리의 밝은 큰 면은 유지했다. |
| skill_b | x=92..108, y=95..102 | 100 | 두 개의 직사각형 세로 띠와 네모 돌기를 없앴다. 기존 어깨→위다리의 기울기에서 둥근 팔꿈치로 이어지고, x=99..108/y=97..98의 넓은 관절 면에서 안쪽으로 좁아지는 손목→지지 아래다리로 연결된다. 가까운 지지 앞다리와의 의도된 빈 공간/짙은 겹침을 남겼다. 입과 두 굽은 눈바람 파문, 아래 발은 바꾸지 않았다. |
| stun_a | x=94..105, y=56..77 | 138 | x=100을 따라 내려오던 볼 안쪽 수직 선을 다시 찍었다. 이마 아래 경계는 x=99/y=56에서 x=96/y=59..61로 굽고, 볼 아래에서는 x=99/y=66..67→x=101/y=70..73→x=103/y=75로 돌아 턱 음영에 합쳐진다. 옆 그림자 폭도 별도 문자열로 넓히거나 줄여 볼 부피를 읽히게 했다. 닫힌 작은 눈꺼풀, 분홍 코, 금 목고리와 별은 보존했다. |

합계 298픽셀이다. 수정은 자세별 명시 좌표/ASCII 문자열을 적용한 뒤 전체
128×128 행을 저장했다. 다른 자세에 좌표를 자동 복사하지 않았다. 도형 본체,
명암 합성, 전체 프레임 이동/회전/보간, 자동 구멍 채우기, 생성 이미지는
사용하지 않았다. 연결 검사로 픽셀을 채우지 않았다.

## 보존 원본과 저작 보조 코드

- before-contour-repair/: 이번 수정 직전 18격자·팔레트·문서·렌더러와 비교 PNG.
- original/, before-mane-repair/, before-joint-repair/, before-anatomy-core-repair/:
  앞선 단계의 원본 보존본. 기존 보조 코드도 남겼다.
- contour_revision.py: 이 수정의 자세별 직접 고른 y/x/pixels 문자열.
- repairs/contour-move.runs, contour-skill_b.runs, contour-stun_a.runs: 같은 좌표 기록.
- render.py: 현재 전체 격자를 PNG/8GIF로 읽어 굽는 보조 코드.
- contour_focus.py: 저장 PNG의 native와 최근접 3배 전후 관찰판.
- observe_contours.py: 원본/PNG/GIF 파일 사실을 읽는 보조 코드. 판정/승인이 아니다.

과거 저작 스크립트는 과거 격자를 다시 쓰므로 현재 후보에 실행하지 않는다.
이번 수정 재현 순서는 다음과 같다.

```bash
python source/contour_revision.py
python source/render.py
python source/contour_focus.py
python source/observe_contours.py
```

## 실제 이미지 관찰

수정 전 move/skill_b/stun_a/stun_b의 실제 PNG를 먼저 열었다. 수정 뒤
preview/contour-focus-3x.png에서 native와 밝은/어두운/체커 3배를 실제로
열어 비교했다. move-backgrounds.png, skill_b-backgrounds.png,
stun_a-backgrounds.png에서도 전체 실루엣과 국소 관절을 함께 확인했다.

preview/contact-light-1x.png, contact-dark-1x.png, contact-checker-1x.png와
contact-light-2x.png를 열어 18자세의 같은 신체 부위를 함께 봤다. 대기와
기술 준비/회수의 먼 앞다리는 가슴 뒤에서 이어지는 면을 유지하고, 독의
들린 앞발과 수면의 접힌 발/감긴 꼬리는 각 자세의 기존 구조를 유지했다.
stun_b의 더 내려온 이마/볼/턱과 비교해 stun_a의 볼 경계를 교정했다.
수면 두 얼굴의 짧은 닫힌 눈과 코의 분리, 같은 발/꼬리 및 호흡 윤곽을
native에서 함께 확인했다. 이번 세 부위와 같은 네모 돌기나 추가 볼 세로
선이 다른 15자세에 반복된 것으로 보이지 않아 해당 격자는 보존했다.

8GIF를 다시 만들고 실제 저장 GIF를 디코드한 gif-decoded-motion.png와
 gif-decoded-status.png를 열어 전체 cel 순서/지지 위치를 비교했다.
공격 준비→전진→큰 앞발 접촉→회수와 기술 모으기→입에서 두 파문→세 조각
회수는 기존 순서다. 관찰 GIF는 어두운 배경이며 투명 PNG/pxgrid가 원본이다.

preview/contour-observations.json에 실제 파일 관찰을 보존했다. 18격자는
128×128이고 서로 다르다. 미등록 기호나 테두리 잉크가 없으며 alpha는 0/255다.
모든 자세의 최하단은 y=124이고 idle_a의 실제 발이 그 선에 닿는다.
저장 GIF의 cel 픽셀은 현재 PNG를 같은 배경에 놓은 결과와 일치하고
hold는 TIMING.md의 값과 같다. 이는 형식/파일 사실이며 미감 PASS가 아니다.

## 남은 시각 문제와 확인 범위

- move의 먼 앞다리는 가까운 앞다리에 많이 가려진다. 작은 둥근 노출 면은
  보이지만 실제 전투 축척에서 어깨/관절을 충분히 읽을 수 있는지는 별도다.
- skill_b의 굽힌 다리는 푸른 그림자 면이 강하다. 두 지지 앞발의 겹침과
  몸의 하중 표현은 새 독립 검수에서 다시 판단할 수 있다.
- 기절 두 얼굴은 높이/각도가 다르고 갈기는 큰 양식적 겹털 면이다.
  stun_a의 곡선 경계와 stun_b의 처진 얼굴이 같은 해부로 읽히는지 재검수 대상이다.
- GIF 디코드 cel과 hold는 관찰했으나 실시간 재생 영상이나 게임 내 대시 거리,
  충돌/피해/음향 타이밍을 확인한 기록은 아니다. 작은 수면 호흡의 재생 가독성도
  실제 전투 표시 크기에서 확인할 여지가 있다.

별도 검수자를 호출하지 않았다. 수정본의 독립 검수는 하네스가 맡는다.
사용자 선택·승인 또는 검수 통과를 선언하지 않았고 검수 결과/모델 정보를
꾸미지 않았다. 저장소·게임 저장소·brief·ledger·다른 후보에는 쓰지 않았다.
테스트/gates는 실행하지 않았다.

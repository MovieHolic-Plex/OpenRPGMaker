# 설갈사자왕 — 먼 앞다리·접힌 뒷다리·준비 핵 교정

## 범위와 보존

이번 수정은 이 후보의 source 안에서만 했다. poses 9개와 actions 9개는
각각 128행×128글자의 전체 literal ASCII 원본이다. 기존 18색 팔레트는
바이트까지 보존했다. 미백 사족 몸, 은백 갈기, 검푸른 그림자, 금빛 눈/목고리,
분홍 코, 청록 꼬리술과 왼쪽 위 광원을 유지했다.

첨부 현재 시트와 64px 검객 이미지를 실제로 열었다. 참고 픽셀을 추출·추적하거나
격자에 재샘플링하지 않았다.

- before-anatomy-core-repair/: 이번 수정 직전 18격자·팔레트·문서.
- original/, before-mane-repair/, before-joint-repair/: 이전 단계 보존본.
- anatomy_core_revision.py: 직접 고른 자세별 y x pixels 문자열.
- repairs/anatomy-core-<pose>.runs: 같은 명시 좌표의 보존 기록.
- anatomy_core_focus.py: 최종 PNG의 native/최근접 3배 진단 표시.
- observe_anatomy_core.py: 원본/PNG/GIF를 읽는 관찰 보조 코드.

격자는 명시한 문자열만 바꿨다. 다른 자세에 좌표를 자동 복사하지 않았다.
도형 본체·명암 합성·전체 프레임 이동/회전/보간·자동 구멍 채우기·이미지
생성은 사용하지 않았다. 이전 보조 코드와 원본을 보존했다. 과거 단계
스크립트는 과거 격자를 다시 쓰므로 현재 수정 뒤에 실행하지 않는다.

수면 두 자세의 같은 발/꼬리를 유지하면서 위쪽 갈기·가슴·턱의 기존 작은
호흡 변화를 보존했다. 첫 렌더에서 꼬리 옆 x=49..50/y=117..118에 추가
청록 군집이 생긴 것을 보고 털/그림자 문자열로 다시 교정했다.

skill_b는 다른 위다리 구조와 실제 입에서 이어지는 두 굽은 파문을 보존했다.
독 두 자세는 이미 들린 먼 앞발의 넓은 연결과 말린 발이 있어 보존했다.
windup/move/attack/recover/hit/dead와 poison_a/b 및 skill_b는 수정 직전
격자와 동일하다. 총 9개 자세에 831개 native 픽셀을 수정했다.

## 실제 이미지 관찰

preview/contact-light-1x.png, contact-dark-1x.png, contact-checker-1x.png를
실제로 열어 18자세의 윤곽·지지 발·갈기·목·꼬리·닫힌 눈을 함께 봤다.
수정 부위는 anatomy-core-focus-3x.png의 native와 밝은/어두운/체커 3배를
실제로 열어 비교했다. 개별 배경 PNG에서도 첫 수정의 잔여 윤곽을 교정했다.

8GIF는 render.py로 구웠고, 저장 파일을 다시 디코드한 gif-decoded-motion.png와
 gif-decoded-status.png를 실제로 열어 순서를 비교했다. 모든 cel의 RGB는
해당 PNG를 같은 관찰 배경에 놓은 픽셀과 일치했다. GIF는 관찰용 배경이며
투명 PNG/pxgrid가 원본이다.

preview/anatomy-core-observations.json은 실제 파일 관찰 기록이다.
18격자는 128×128이며 서로 다르다. 미등록 기호·테두리 잉크가 없고 alpha는
0/255다. 모든 자세의 최하단은 y=124이며 idle_a의 실제 발이 그 선에 닿는다.
이 기록은 기술 검사 판정이나 미감/독립 검수 통과 기록이 아니다.

현재 수정 재현 순서:

```bash
python source/anatomy_core_revision.py
python source/render.py
python source/anatomy_core_focus.py
python source/observe_anatomy_core.py
```

## 남은 시각 문제와 확인 범위

- 먼 앞다리는 근경 앞다리보다 어둡고 작으며 기절의 처진 어깨가 겹친다.
  PNG에서 관절 면은 보였지만 실제 전투 크기에서의 가독성은 별도 확인이다.
- 수면 뒷발은 꼬리와 앞발 사이에 작게 접혀 있다. 발가락/발톱 군집은 밝은
  배경에서 대비가 약하다. 갈기는 여전히 큰 겹털 면의 양식이다.
- 준비 핵의 어두운 경계는 강해졌다. 갈기 안 발광 결절로 읽히는지는 새
  독립 검수가 판단하며 실제 광원 번짐을 추가하지 않았다.
- GIF cel/순서/hold는 재읽었으나 실시간 재생 영상이나 실제 전투의 대시 거리,
  충돌/피해/음향 타이밍을 확인한 기록은 아니다.

별도 검수자를 호출하지 않았다. 하네스의 새 독립 검수와 사용자 선택은 별도다.
승인·통과를 선언하거나 모델/검수 해시를 만들지 않았다. 저장소·게임 저장소·brief·
ledger·다른 후보를 수정하지 않았고 테스트/gates는 실행하지 않았다.

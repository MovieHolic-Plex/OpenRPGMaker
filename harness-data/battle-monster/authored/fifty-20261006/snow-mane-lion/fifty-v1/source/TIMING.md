## 공격 관절 경로

windup은 목과 갈기를 낮추고 굽힌 뒤 지지 무릎에 하중을 모은다. move는
같은 밝은 앞다리가 넓게 내딛으며 뒤발로 민다. attack은 어깨에서 이어진
팔꿈치/아래팔에서 압축된 손목과 큰 타격 앞발로 이어진다. 접촉 앞발은
x=100..126, y=101..112이며 발가락에서 짧은 발톱 끝이 나온다. 먼 앞다리와
뒷발은 지지 역할이다. recover는 같은 앞발을 바닥으로 당기며 넓힌 아래팔
면에서 발목/발로 이어진다. 별도의 먼 앞발은 작게 접혀 들려 있다.

기본 대기 및 서 있는 상태의 실제 지지 발, 쓰러진 몸과 수면의 접힌 몸은
native y=124를 유지한다. 독의 들린 먼 앞발은 y=114/115에 끝나며 접지 발과
구별한다. dead는 낮아진 갈기→금 목고리→압축된 목→오른쪽 머리의 경로다.

## 설왕후 — 실제 입 앵커

이 종은 손이나 무기를 들지 않는 사족 짐승이다. 아래 좌표는 0-based native다.

- **skill_a / 모으기, 320ms:** 분홍 코 아래 입 공간은 x=108..119,
  y=62..69다. 청백 핵은 x=111..117, y=64..68의 어두운 입 안에 있다.
  윗입술과 아래턱을 직접 그렸으며 별도의 볼 옆 구체가 아니다. 갈기 속
  x=66..77, y=48..57의 준비 핵은 직접 교정했다. x=70..73/y=51..53의
  청백 중심을 청록 내부 면과 어두운 털 경계가 감싼다. 갈기 외곽은 유지했다.
- **skill_b / 포효, 300ms:** 실제 입은 당겨진 얼굴과 벌린 턱 사이
  x=102..111, y=63..68이다. 핵에서 위/아래 파문으로 이어지는 두 경로가
  갈라진다. 위 파문은 x=110..126, y=26..62, 아래 파문은 x=109..126,
  y=69..98이다. 두 굽은 파문의 말린 끝, 청백 면과 청록 그늘, 둘 사이의
  의도한 빈 공간을 보존했다. 발원점은 준비와 같은 해부상의 입이다.
- **skill_c / 회수, 240ms:** 뒤로 당겨져 닫히는 턱 x=100..116,
  y=62..78을 유지한다. 입 x=114..117, y=62..67에 잔향이 연결되고,
  위 x=118..125/y=45..52, 중간 x=121..126/y=73..78,
  아래 x=116..123/y=83..89에 서로 다른 세 눈보라 조각이 남는다.

## 상태 루프

- **독, 400/400ms:** 반감긴 눈, 처진 얼굴/어깨와 굽힌 앞다리를 유지한다.
  a의 들린 먼 앞발은 x=97..110/y=95..114, b는 x=96..109/y=95..115다.
  손목 아래 연결된 말린 발의 밝은 발등과 짙은 밑면이 다르며 독 방울도 변한다.
- **기절, 420/420ms:** 닫힌 눈과 이완된 턱, b에서 더 처지는 머리/어깨를
  유지한다. 서로 다른 별 위치와 모양은 별도 literal 효과 픽셀이다.
- **수면, 650/650ms:** 두 cel의 닫힌 눈, 접힌 앞발/뒷발, 감긴 꼬리와
  청록 술을 보존했다. a는 날숨, b는 올라간 갈기와 넓어진 가슴의 들숨이다.
  두 원본의 호흡 윤곽 차이는 그대로이며 색만 바꾸거나 프레임 전체를 옮기지 않았다.
  x=49..66/y=110..124의 뒷다리는 두 자세에 각각 직접 문자열을 써서
  굽은 비절·접힌 발·발가락/작은 발톱으로 구별했다. 같은 발/꼬리와 y=124
  하중 윤곽을 유지했고 목고리 앵커는 바꾸지 않았다.

## 이번 관절·얼굴 교정의 시간표 영향

move의 먼 앞다리 x=101..111/y=83..94는 어깨 아래 둥근 노출 면에서
가까운 내딛는 앞다리 뒤로 좁아진다. skill_b의 x=92..108/y=95..102는
연속된 팔꿈치/손목으로 다시 찍었으며 지지 발과 입 발원 효과는 유지했다.
stun_a의 x=94..105/y=56..77 볼 경계는 직접 고른 계단형 곡선이고,
닫힌 눈/코/별과 stun_b의 머리 높이 차이는 유지했다.

세 cel의 국소 픽셀만 바뀌었다. 8동작의 pose 순서/hold, 대시의 같은 공격
앞발 경로, 기술의 실제 입 앵커와 두 파문/세 잔향은 보존했다.
저장 GIF를 다시 디코드하여 현재 PNG와 cel을 비교하고 위 표의 실제 hold를
읽었다. 관찰은 실시간 재생/실제 전투 접촉이나 새 독립 검수를 대신하지 않는다.

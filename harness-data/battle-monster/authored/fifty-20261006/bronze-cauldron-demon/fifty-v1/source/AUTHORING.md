# 청동정마 — 원본 저작 기록

## 납품 범위

이 후보의 `source`에만 작성했다. 128×128 리터럴 ASCII 원본 18장,
18색 공통 팔레트, native PNG, 3×3 시트 2장, 8동작 GIF를 보존한다.
사용자 선택이나 독립 검수 통과를 선언하지 않는다. 하네스·게임 저장소·ledger·brief를 수정하지 않았다.
테스트/게이트 및 별도 검수자 호출을 실행하지 않았다.

## 참고 관찰

첨부 `references/human-size.png`를 실제로 열었다. 검객의 1배 얼굴 크기,
몸보다 작은 손 군집, 손과 검자루의 연결, 밝은 면과 어두운 옷 면을 관찰했다.
이 그림의 픽셀 추출·트레이싱·복사·재배포는 하지 않았다.
청동정마는 별도로 만든 거대한 녹청 솥 요괴다.

## 직접 선택한 구조와 재질

- 녹청 몸체의 왼쪽 위에는 H/T/L의 넓은 밝은 면, 오른쪽에는 S/D의 넓은 그림자 면을 찍었다.
- 솥입은 두꺼운 금테의 안쪽/바깥쪽 높이가 다르게 보이는 3/4 입체다. 내부는 어둡고 깊다.
- 몸 앞면의 금빛 두 눈은 오른쪽을 향하는 크기 차이와 눈썹 기울기를 가진다.
  넓은 입은 금테, 검은 입안, 붉은 안쪽, 작은 금빛 이빨로 구분했다.
- 붉은 술은 몸에 박힌 금속 고리 → 붉은 매듭 → 좁은 직물 끝으로 연결된다.
- 양팔은 솥에 붙은 청동 손잡이다. 금색 손잡이의 밝은 테두리/그림자와
  녹청 주먹의 손목/손가락 구획을 따로 찍었다. 손잡이 내부 빈 공간은 의도적이다.
- 세 솥발은 왼쪽 하중 발, 작고 어두운 뒤 발, 오른쪽 굽은 발이다.
  장식 입자로 접지를 대신하지 않는다. 모든 자세의 실제 신체 최하단은 y=124다.

`author.py`는 직접 쓴 행 문자열과 선택한 좌표를 보존하는 저작 보조 코드다.
투명 캔버스 초기화와 리터럴 문자열 기록만 한다. 원/다각형/수식으로
몸체·명암·효과를 생성하거나 전체 프레임을 이동/회전/보간하지 않는다.
변하지 않는 주물 몸의 원본 면은 재사용하고, 자세의 관절·발·얼굴·술·효과는
해당 프레임에 명시한 문자열로 변경했다. 최종 pxgrid는 축약 없는 전체 128행이다.

## 실제 PNG를 보고 수정한 부위

1. 최초 몸통 연구는 얼굴과 오른쪽 어깨를 지탱할 폭이 부족했다.
   y=54…109의 몸통 면을 더 넓은 새 리터럴 행으로 다시 저작했다.
2. 18자세 시트에서 오른쪽 솥발의 뿌리가 몸과 떨어져 보였다.
   각 기립 자세의 x≈77…99, y=94…106에서 엉덩이/허벅지/무릎 면을
   그 자세를 보며 다시 선택했다. 전진과 접촉에서는 다른 꺾임과 발 디딤을 사용했다.
   `inspected_joint_repairs()`에 자세별 전체 문자열을 각각 보존했다.
3. 수면 쌍의 오른쪽 발도 x≈77…92, y=106…113에서 접힌 허벅지 면을 보강했다.
   x≈78…90, y=84…93의 어깨 고정구를 별도로 두껍게 찍어 손잡이와 연결했다.
4. 손 주변에 잘못 붙인 긴 색 문자열과 피격 어깨의 튀는 그림자 줄을 제거/교정했다.
5. 수면은 검은 평상시 눈을 쓰지 않는다. 짧은 금색 닫힌 눈꺼풀과 주변 녹청 면을
   1배에서 확인했다. 두 번째 수면에는 더 낮은 뚜껑 윤곽, 내려온 눈꺼풀/입,
   작은 어깨 압축을 직접 저작했다. 접힌 세 발과 손잡이 구조는 유지한다.

## 동작과 상태

- 공격: 오른쪽 손잡이 주먹을 머리 위로 모음 → 뒤 지지발이 밀고 오른발이 전진
  → 같은 주먹이 오른쪽으로 접촉 → 팔과 세 발이 회수된다.
- 피격: 눈이 찡그려지고 어깨 손잡이가 낮아지며 입이 찌그러진다.
- 쓰러짐: 몸통 옆면이 바닥에 내려오고, 솥입은 옆으로 기울며,
  흐린 닫힌 눈·펼쳐진 솥발·바닥 손잡이·누운 술을 남긴다.
- 정화폭: 실제 상단 솥입에 금백 핵을 모으고 서로 다른 두 주홍 불기둥을 분출한다.
  회수에는 접힌 뚜껑 기와 뿌리가 다른 세 잔불을 남긴다.
- 독: 눈의 아픈 찡그림, 턱 가까이에 댄 손잡이 주먹, 독 거품의 서로 다른 위치/크기.
- 기절: 두 손잡이가 아래로 처지고 눈/입이 힘을 잃는다. 두 프레임의 별 위치와
  오른쪽 손목/주먹 높이를 각각 저작했다.
- 수면: 낮은 안정 자세와 감긴 눈, 낮아진 손잡이, 별도 뚜껑/얼굴/어깨 호흡 변화.

## 그림 재읽기와 남은 한계

`preview/native-backgrounds-1.png`, `native-backgrounds-2.png`를 실제 열어
전체 18자세의 밝은/어두운/체커 배경 1배를 확인했다.
확대 시트와 개별 `*-inspect.png`에서 관절과 투명을 확인했다.
8개 GIF를 저장 후 다시 디코드해 `gif-decoded.png`로 열었고,
실제 디코드 지속 시간과 SHA-256은 `preview/readback.json`에 기록했다.
이 해시는 파일에서 계산한 값이며 독립 검수/사용자 승인 기록이 아니다.

남은 표현 한계: 솥몸은 단단한 주물이라 돌격에서 몸통 자체의 변형은 작고,
손잡이/주먹/세 발의 변화가 운동을 주도한다. 뒤쪽 세 번째 발은 의도적으로 작고 어둡다.
수면 호흡은 작은 native 변화다. GIF는 저작 자세 확인용으로, 실제 게임의
대상 접촉·피해·효과음·런타임 돌격 이동을 검증한 영상이 아니다.

### 실제 재열람

- 첨부 현재 시트와 인간 크기 참고를 먼저 열어 실루엣/재질/손 연결을 관찰했다.
- 세 수정 자세의 `*-inspect.png`에서 native 1배와 checker 3배를 실제로 열었다.
- 세 자세의 `*-repair-comparison.png`를 실제로 열어 수정 전/후의
  밝은·어두운·체커 1배/최근접 3배를 비교했다.
- `native-backgrounds-1.png`, `native-backgrounds-2.png`의 18자세를 열어
  같은 부위에 보이는 추가 결손과 다른 자세의 손/발/수면 얼굴을 함께 살폈다.
- 새 8GIF를 다시 디코드한 `gif-decoded.png`를 실제 열어 공격의 같은 오른쪽 손과
  전진→접촉→회수 순서, 기술의 핵→두 불기둥→세 잔불, 상태 쌍을 확인했다.
  GIF 실제 노출 시간과 현재 파일 해시는 `preview/readback.json`에 있다.
  디코드한 8GIF의 각 프레임을 현재 원본+같은 진단 배경과 재읽기 비교한 결과,
  모든 프레임의 다른 픽셀 수는 0이었다. 실제 측정은 `preview/gif-pixel-readback.json`에 남겼다.
- 18장 모두 128×128이며 최하단 잉크 y124, 테두리는 투명하다.
  `preview/repair-readback.json`은 변경 경계와 실제 소스 해시의 로컬 재읽기 기록이다.

### 남은 표현 문제와 검수 범위

타격은 금속 손잡이 내부 빈 공간을 보존해서 여전히 삼각형에 가까운 팔 경로가 보인다.
이번에는 주먹이 전진 자세보다 오른쪽으로 13 native픽셀 더 뻗고 접촉면이 넓어졌지만,
실제 런타임 대상에 닿는 시점·거리와 돌격 중 발 미끄러짐은 이 미리보기로 판정할 수 없다.
솥 몸통의 큰 면은 주물 재질로 유지하므로 어깨 변화보다 본체 변형은 작다.
회수의 세 잔불은 좁은 솥입에 모여 있어 native1배에서 작은 군집으로 보인다.
수면 호흡과 뒤쪽 솥발의 깊이 표현도 기존의 작은 변화/어두운 면을 유지한다.
새로운 의도 없는 몸통 구멍이나 떨어진 타격 손은 이번 열람에서 보이지 않았다.
이는 작가의 로컬 그림 확인이며, 새 독립 검수 결과나 사용자 선택을 대신하지 않는다.
독립 검수자를 호출하거나 판정/ledger/brief를 수정하지 않았다. 테스트와 게이트도 실행하지 않았다.

### 실제 그림을 열어 추가로 고른 좌표

피격 확대판에서 새 왼 손잡이 바깥에 예전 윤곽의 가느다란 조각이 남아 있었다.
`hit`, x10…11, y57…66의 해당 글자를 직접 투명 점으로 교정했다.
이 좌표는 위 피격 변경 픽셀 수에 포함된다. 연결 진단은 읽기만 했으며
윤곽을 자동으로 채우거나 빈 공간을 메우지 않았다.

세 자세의 `preview/*-repair-003-comparison.png`를 실제 열어 수정 전/후를
밝은·어두운·체커 배경의 native1배 및 최근접3배에서 확인했다.
또한 `native-backgrounds-1.png`, `native-backgrounds-2.png`, `contact-2x.png`의
18자세를 열어 같은 몸체의 금테/손잡이/다리와 상태 쌍을 함께 살폈다.
수면은 짧은 감긴 눈꺼풀과 낮은 솥몸을 유지하며, 죽음의 옆으로 누운 몸과 구분된다.
솥테·몸통·손잡이의 의도 없는 새 투명 구멍이나 떨어진 주먹은 이번 열람에서 보이지 않았다.

18개의 native PNG와 8개의 GIF를 현재 원본으로 다시 구웠다.
8GIF를 실제 파일에서 디코드한 `preview/gif-decoded.png`를 열어
준비 → 전진 → 접촉 → 회수, 피격 → 회수, 핵 → 두 불기둥 → 세 잔불,
독/기절/수면 쌍의 순서를 확인했다. 이는 디코드한 자세의 시각 확인이다.
재생 시간을 읽은 기록과 원본/PNG/GIF의 실제 SHA-256은 `preview/readback.json`,
이번 변경 경계와 8GIF 디코드 픽셀 비교는 `preview/repair-003-readback.json`에 있다.
각 GIF 프레임을 같은 진단 배경의 현재 격자와 비교한 실제 차이는 모두 0픽셀이었다.
18장 모두 128×128, 투명 테두리, 실제 최하단 신체 y124이며 전체 격자는 서로 다르다.
해시와 형식 재읽기는 독립 검수 결과나 사용자 선택을 뜻하지 않는다.

### 현재 남은 시각 표현 한계

- 피격은 상단 솥테/어깨와 다리의 반동으로 읽힌다. 단단한 주물의 아래 몸통과
  얼굴 입 군집은 상당 부분 유지해서 몸 전체가 찌그러지는 큰 변형은 없다.
- 쓰러진 솥입은 세워진 대기 솥입보다 좁은 세로 공동이다. 주먹은 접지한 낮은
  군집이라 native1배에서 손가락 구획이 작다. 뒤쪽 세 발도 짧고 어두운 기존 군집이다.
- 금백 핵의 가장 밝은 색은 기존 18색의 W다. 좁은 공동 안에서 작은 충전 덩어리로
  보이며, 강한 흰색 섬광이나 외부 광원 연출은 이 원본에 추가하지 않았다.
- 기존 공격의 주물 몸통 변화와 상태 쌍의 호흡 변화는 작다. 8GIF는 source 안의
  자세 미리보기이며 실제 전투 이동·타격 접촉·피해 시점은 이 그림으로 확인하지 않았다.

이번 교정은 작가의 원본 수정과 로컬 그림 재열람이다. 새 독립 검수자는 호출하지 않았고,
하네스의 판정/선택을 만들거나 편집하지 않았다. 사용자 승인이나 검수 통과를 선언하지 않는다.
저장 범위는 이 후보의 `source`뿐이며 테스트·게이트는 실행하지 않았다.

## 현재 교정 — repair_004: 피격 왼쪽 솥벽 홈

첨부 현재 시트와 64px 인간 크기 참고를 먼저 실제로 열었다. 이번 작업은
기존 18자세 중 `poses/hit.pxgrid`의 왼쪽 솥벽만 직접 교정했다.
기존 9개 `actions/*.pxgrid`를 포함한 나머지 17자세와 18색 팔레트는
수정 전 파일 해시와 동일하다. 이전 문단의 repair_003은 제작 이력이며,
현재 원본에는 아래 repair_004를 마지막으로 적용한다.

지적된 홈은 y57…65의 밝은 솥벽이 x34에서 시작하다가 y66에 x27로
갑자기 넓어지고 y72까지 가느다란 투명 이음매를 남긴 부분이었다.
`repair_004.py`의 16개 좌표/ASCII 문자열로 벽을 직접 다시 찍었다.
금테 아래 손잡이에 가려진 벽은 (32,57)에서 시작해 (25,65)까지
단계적으로 넓어지고, 배와 손목이 겹치는 아래쪽은 (26,72)로 이어진다.
O 윤곽, B 기본면, L/H 빛 면, 기존 T의 가장 밝은 군집으로 주물의
왼쪽 위 광원과 볼륨을 유지했다. 손잡이 내부의 의도된 투명 구멍은
변경하지 않았다. 자동 채움·실루엣 수식·전체 프레임 변환은 사용하지 않았다.

실제 변경은 **91픽셀**, 경계는 **x25…40, y57…72**(0부터 시작, 양끝 포함)다.
전체 격자는 축약 없는 128행이며, 이전 원본/문서/보조 코드는
`before-repair-004/`에 보존했다. `author.py`의 재저작 마지막 단계에도
repair_004의 명시적 행 교정을 연결했다. 이번에는 전체 저작기를 실행하지 않았다.

### 실제 이미지 확인과 파일 재읽기

- `preview/hit-repair-004-comparison.png`의 수정 전/후를 실제로 열어
  밝은·어두운·체커 배경의 native1배와 최근접3배에서 벽의 연속성과
  보존한 손잡이 구멍을 확인했다. 배경이 깊게 들어오던 직각 홈은 보이지 않는다.
- `preview/native-backgrounds-1.png`, `native-backgrounds-2.png`를 실제로 열어
  다른 17자세의 같은 벽/손잡이 부위와 손/발 연결을 함께 살폈다.
  이번에 지적된 깊은 벽 홈과 같은 추가 결손은 이 열람에서 보이지 않았다.
- 현재 격자로 native PNG 18장과 GIF 8개를 다시 저장했다.
  실제 GIF 파일에서 디코드한 `preview/gif-decoded.png`를 열어 공격 순서,
  피격/쓰러짐 전환과 기술/상태 쌍을 확인했다. 이는 재생 영상이 아닌
  디코드 프레임을 나란히 본 시각 확인이다.
- 실제 파일 재읽기는 `preview/repair-004-readback.json`에 남겼다.
  18장 모두 128×128, 투명 테두리, 최하단 신체 y124를 유지하고 서로 다르다.
  각 GIF 디코드 프레임과 같은 배경 위 현재 격자의 픽셀 차이는 모두 0이다.
  `preview/readback.json`에는 현재 PNG/GIF의 파일 해시와 디코드 노출 시간이 있다.

### 남은 시각 문제와 판단 범위

이번 지적의 국소 윤곽 결손은 위 비교판에서 해소된 것으로 보인다.
기존의 작은 대기 변화와 수면 호흡, 어두운 뒤쪽 세 번째 발은 유지했다.
수면 쌍의 변화는 native1배에서 여전히 작다. 단단한 주물 몸통의 변형보다
손잡이와 솥발의 변화가 운동을 주도한다. 실제 게임의 돌격 이동, 대상 접촉,
피해 시점과 발 미끄러짐은 이 로컬 PNG/GIF로 확인하지 않았다.

이 기록은 실제 원본 수정과 작가의 로컬 그림 확인이다. 새 독립 검수나
사용자 승인을 뜻하지 않는다. 별도 검수자를 호출하거나 reviewer 결과,
ledger, brief, 게임 저장소를 편집하지 않았다. 테스트·게이트는 실행하지 않았고,
이번 작업의 모든 출력은 이 후보의 `source` 안에 저장했다.

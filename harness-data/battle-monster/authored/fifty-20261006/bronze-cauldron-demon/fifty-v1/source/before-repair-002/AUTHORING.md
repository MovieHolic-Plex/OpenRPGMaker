# 청동정마 — 원본 저작 기록

## 납품 범위

이 후보의 `source`에만 작성했다. 128×128 리터럴 ASCII 원본 18장,
18색 공통 팔레트, native PNG, 3×3 시트 2장, 8동작 GIF를 보존한다.
사용자 선택이나 독립 검수 통과를 선언하지 않는다. 하네스·게임 저장소·ledger·brief를 수정하지 않았다.
테스트/게이트 및 별도 검수자 호출을 실행하지 않았다.

## 참고 관찰

첨부 `references/human-size.png`를 실제로 열었다. 검객의 1배 얼굴 크기,
몸보다 작은 손 군집, 손과 검자루의 연결, 밝은 면과 어두운 옷 면을 관찰했다.
이 그림의 픽셀 추출·트레이싱·복사·재배포는 하지 않았다.
청동정마는 별도로 만든 거대한 녹청 솥 요괴다.

## 직접 선택한 구조와 재질

- 녹청 몸체의 왼쪽 위에는 H/T/L의 넓은 밝은 면, 오른쪽에는 S/D의 넓은 그림자 면을 찍었다.
- 솥입은 두꺼운 금테의 안쪽/바깥쪽 높이가 다르게 보이는 3/4 입체다. 내부는 어둡고 깊다.
- 몸 앞면의 금빛 두 눈은 오른쪽을 향하는 크기 차이와 눈썹 기울기를 가진다.
  넓은 입은 금테, 검은 입안, 붉은 안쪽, 작은 금빛 이빨로 구분했다.
- 붉은 술은 몸에 박힌 금속 고리 → 붉은 매듭 → 좁은 직물 끝으로 연결된다.
- 양팔은 솥에 붙은 청동 손잡이다. 금색 손잡이의 밝은 테두리/그림자와
  녹청 주먹의 손목/손가락 구획을 따로 찍었다. 손잡이 내부 빈 공간은 의도적이다.
- 세 솥발은 왼쪽 하중 발, 작고 어두운 뒤 발, 오른쪽 굽은 발이다.
  장식 입자로 접지를 대신하지 않는다. 모든 자세의 실제 신체 최하단은 y=124다.

`author.py`는 직접 쓴 행 문자열과 선택한 좌표를 보존하는 저작 보조 코드다.
투명 캔버스 초기화와 리터럴 문자열 기록만 한다. 원/다각형/수식으로
몸체·명암·효과를 생성하거나 전체 프레임을 이동/회전/보간하지 않는다.
변하지 않는 주물 몸의 원본 면은 재사용하고, 자세의 관절·발·얼굴·술·효과는
해당 프레임에 명시한 문자열로 변경했다. 최종 pxgrid는 축약 없는 전체 128행이다.

## 실제 PNG를 보고 수정한 부위

1. 최초 몸통 연구는 얼굴과 오른쪽 어깨를 지탱할 폭이 부족했다.
   y=54…109의 몸통 면을 더 넓은 새 리터럴 행으로 다시 저작했다.
2. 18자세 시트에서 오른쪽 솥발의 뿌리가 몸과 떨어져 보였다.
   각 기립 자세의 x≈77…99, y=94…106에서 엉덩이/허벅지/무릎 면을
   그 자세를 보며 다시 선택했다. 전진과 접촉에서는 다른 꺾임과 발 디딤을 사용했다.
   `inspected_joint_repairs()`에 자세별 전체 문자열을 각각 보존했다.
3. 수면 쌍의 오른쪽 발도 x≈77…92, y=106…113에서 접힌 허벅지 면을 보강했다.
   x≈78…90, y=84…93의 어깨 고정구를 별도로 두껍게 찍어 손잡이와 연결했다.
4. 손 주변에 잘못 붙인 긴 색 문자열과 피격 어깨의 튀는 그림자 줄을 제거/교정했다.
5. 수면은 검은 평상시 눈을 쓰지 않는다. 짧은 금색 닫힌 눈꺼풀과 주변 녹청 면을
   1배에서 확인했다. 두 번째 수면에는 더 낮은 뚜껑 윤곽, 내려온 눈꺼풀/입,
   작은 어깨 압축을 직접 저작했다. 접힌 세 발과 손잡이 구조는 유지한다.

## 동작과 상태

- 공격: 오른쪽 손잡이 주먹을 머리 위로 모음 → 뒤 지지발이 밀고 오른발이 전진
  → 같은 주먹이 오른쪽으로 접촉 → 팔과 세 발이 회수된다.
- 피격: 눈이 찡그려지고 어깨 손잡이가 낮아지며 입이 찌그러진다.
- 쓰러짐: 몸통 옆면이 바닥에 내려오고, 솥입은 옆으로 기울며,
  흐린 닫힌 눈·펼쳐진 솥발·바닥 손잡이·누운 술을 남긴다.
- 정화폭: 실제 상단 솥입에 금백 핵을 모으고 서로 다른 두 주홍 불기둥을 분출한다.
  회수에는 접힌 뚜껑 기와 뿌리가 다른 세 잔불을 남긴다.
- 독: 눈의 아픈 찡그림, 턱 가까이에 댄 손잡이 주먹, 독 거품의 서로 다른 위치/크기.
- 기절: 두 손잡이가 아래로 처지고 눈/입이 힘을 잃는다. 두 프레임의 별 위치와
  오른쪽 손목/주먹 높이를 각각 저작했다.
- 수면: 낮은 안정 자세와 감긴 눈, 낮아진 손잡이, 별도 뚜껑/얼굴/어깨 호흡 변화.

## 그림 재읽기와 남은 한계

`preview/native-backgrounds-1.png`, `native-backgrounds-2.png`를 실제 열어
전체 18자세의 밝은/어두운/체커 배경 1배를 확인했다.
확대 시트와 개별 `*-inspect.png`에서 관절과 투명을 확인했다.
8개 GIF를 저장 후 다시 디코드해 `gif-decoded.png`로 열었고,
실제 디코드 지속 시간과 SHA-256은 `preview/readback.json`에 기록했다.
이 해시는 파일에서 계산한 값이며 독립 검수/사용자 승인 기록이 아니다.

남은 표현 한계: 솥몸은 단단한 주물이라 돌격에서 몸통 자체의 변형은 작고,
손잡이/주먹/세 발의 변화가 운동을 주도한다. 뒤쪽 세 번째 발은 의도적으로 작고 어둡다.
수면 호흡은 작은 native 변화다. GIF는 저작 자세 확인용으로, 실제 게임의
대상 접촉·피해·효과음·런타임 돌격 이동을 검증한 영상이 아니다.

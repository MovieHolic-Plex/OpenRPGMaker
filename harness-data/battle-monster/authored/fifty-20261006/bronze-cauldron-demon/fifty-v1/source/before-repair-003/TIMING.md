# 청동정마 — GIF 순서와 앵커

모든 원본은 native128, 우향 3/4, y=124 실제 신체 접지다.
GIF는 native128을 유지하며 어두운 진단 배경으로 굽는다. 확대는 PNG 진단판에만 쓴다.

| GIF | 자세 순서 | 유지 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240 / 270 / 110 / 130 / 220 / 240 |
| hit | idle_a → hit → recover → idle_a | 240 / 190 / 230 / 300 |
| dead | idle_a → hit → dead | 240 / 130 / 1200 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 360 / 270 / 350 / 240 |
| poison | poison_a → poison_b | 430 / 430 |
| stun | stun_a → stun_b | 400 / 400 |
| sleep | sleep_a → sleep_b | 700 / 780 |

## 공격 손과 발

타격 주체는 화면 오른쪽의 같은 손잡이 팔이다.
준비 주먹은 대략 (94,25), 전진 주먹은 (106,68), 접촉 주먹은 (116,59),
회수 주먹은 (93,82)다. 손잡이의 어깨 고정구는 몸의 오른쪽 상단에 붙는다.
이번 접촉 팔은 고정구 x87…96, y55…61에서 상부 금속 손잡이→손등으로 이어지고,
아래쪽 손잡이는 x91…114, y65…77에서 같은 주먹의 손목을 받친다.
주먹의 최우측 접촉 윤곽은 x123, y54…61 부근이다. x124…127의 투명 여백을 남긴다.
전진은 뒤쪽/왼쪽 발이 밀고 오른쪽 솥발이 앞쪽으로 디딘다.
접촉 자세의 앞쪽 솥발은 더 넓고 낮게 체중을 받으며, 회수에서 원래 굽힘으로 돌아온다.
이 수치는 원본 군집 관찰 좌표이며 프레임 이동용 변환값이 아니다.

## 정화폭 발원점

기술은 얼굴의 웃는 입이 아닌 **실제 상단 솥입 안쪽**에서 시작한다.
기본 발원 면은 대략 x=49…82, y=38…46이며 금테 앞쪽이 열기 밑을 감싼다.

- skill_a: 금백 핵을 (62,39) 부근에서 모은다. 오른쪽 주먹은 솥입 옆에서
  실제 손잡이 경로로 몸에 이어져 버틴다. 핵 밑은 솥입에 붙는다.
- skill_b: 왼쪽 불기둥은 갈라지는 말린 끝, 오른쪽 불기둥은 바깥으로 치솟는
  다른 끝과 다른 폭을 가진다. 두 불기둥은 x≈50…81, y≈42…46의 뜨거운
  밑면으로 솥입에 이어진다. 두 손잡이는 아래에서 반동을 지지한다.
- skill_c: 뚜껑 기가 상단 왼쪽으로 접힌다. 세 잔불은 솥입의
  (52,43), (60,42), (68,43) 부근에 각각 남고 서로 다른 끝/높이로 식는다.
  오른쪽 잔불의 끝은 위에서 오른쪽으로 기울지만, 하단은 안쪽 공동으로 굽는다.
  가운데 잔불 하단도 별도 행으로 좁혀 오른쪽 불뿌리와 틈을 남겼다.

## 상태 쌍

독은 430ms마다 아픈 턱/손과 세 독거품이 달라진다.
기절은 400ms마다 서로 다른 별 군집과 처진 오른쪽 손의 높이가 달라진다.
수면은 700/780ms의 느린 호흡으로 닫힌 눈을 유지하며 뚜껑과 얼굴/어깨를 압축한다.
독·기절·수면은 공격 자세의 색조 변환이 아니다.

`render.py`의 `TIMELINES`와 이 표는 같은 순서다. 저장된 GIF의 실제 디코드 시간은
`preview/readback.json`, 디코드된 그림은 `preview/gif-decoded.png`에 보존한다.

이번 교정에서 순서와 유지 시간은 바꾸지 않았다. 기록된 앵커는 격자의 관찰 위치이며
전체 프레임을 이동하거나 런타임 접촉 거리를 자동 계산하기 위한 변환값이 아니다.
8GIF는 source 안의 자세 미리보기다. 실제 전투의 피해/이동/접촉 타이밍 검증은 포함하지 않는다.

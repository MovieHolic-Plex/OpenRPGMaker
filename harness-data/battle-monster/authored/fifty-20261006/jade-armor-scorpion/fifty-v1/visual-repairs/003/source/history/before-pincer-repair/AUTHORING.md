# 옥갑전갈왕 — 독립 검수 지적에 따른 원본 수정

## 작업 범위와 원본

이번 작업은 기존 옥갑전갈왕 초안의 교정이다. 첨부 `reference.png`와
`references/human-size.png`를 실제 열어 실루엣, 재질, 관절과 크기를 관찰했다.
참고 그림을 추출·추적·리샘플링하거나 산출물로 복사하지 않았다.
모든 변경 파일은 이 후보의 `source/` 안에 있다.

`palette.json`의 기존 18색을 그대로 유지했다. 투명은 팔레트에 없는 `.`이다.
기본 9자세와 추가 9자세는 각각 128행 × 128자의 완전한 ASCII 원본이다.
`review_repair_pixels.py`에 실제로 고른 행 번호, 시작 x와 짧은 색 문자열을 보존했다.
프레임마다 별도 리터럴을 적었으며 좌표를 다른 자세에 자동 전달하지 않았다.
도형 래스터, 자동 채움, 자동 명암, 이미지 생성, 몸 전체 이동·회전·보간은 없다.

수정 전 18격자·팔레트·저작 기록·시간표는
`history/before-review-repair/`에 보존했다. 현재 정본은 `poses/`와 `actions/`다.
기존 저작 보조 코드도 보존하고 `build_all.py`의 마지막 저작 단계에 교정 코드를 추가했다.
확정 모델·독립 검수·사용자 선택의 출처를 새로 꾸미지 않았다.

수면 2자세의 10격자는 수정 전과 동일하다. 팔레트도 바꾸지 않았다.
`REPAIR_EXPORT.json`은 이전 격자와 비교한 실제 변경 수·범위 및 현재 파일 해시를 기록한다.
이것은 검수 판정이 아니다.

## 실제 그림 열람과 내보내기

- 밝은·어두운·체커 배경의 18자세 native 1배 PNG를 실제 열었다.
- 체커의 좌/우 3배 확인판, 공격/전진/피격/기절 개별 4배 그림과
  수정 동작·꼬리의 1배/2배 확인판을 실제 열었다.
- `gif-decoded-sequences-1x.png`를 실제 열어 저장된 8GIF의 자세 순서와
  관절·갑각·꼬리·효과 위치를 함께 비교했다.
- 갑각의 가로 늘어남이 사라지고, 공격의 움직이는 손가락에 옥색 내부 면이 보인다.
  피격/독/기절의 끝 꼬리는 굽은 마디에서 주홍 침까지 재질 부피로 이어진다.
  기절 두 번째 별과 침은 이제 서로 떨어져 보인다.
- 접촉 GIF의 파일 프레임을 재읽은 결과는 모두 대응 원본 RGBA와 동일했다.
  PNG 18개와 GIF 8개를 다시 저장했으며 모든 격자는 서로 다르다.
- 모든 자세의 실제 신체 최하단은 y124, idle_a 실제 지지발도 y124다.
  투명 테두리와 알파 0/255를 유지했다. 18색 및 현재 바운드/해시는
  `INSPECTION.json`과 `REPAIR_EXPORT.json`에 있다.

`render_source.py`는 격자를 그대로 PNG/GIF로 읽는 내보내기 도구다.
`review_preview.py`는 배경·정수 최근접 확대·진단 라벨만 만들고 원본을 바꾸지 않는다.
`previews/index.html`에서 8GIF와 native 확인판을 볼 수 있다.
테스트·게이트 및 별도 검수자 호출은 실행하지 않았다.

## 남은 시각 문제와 확인 한계

- 여섯 다리 중 먼 다리와 큰 집게가 일부 겹친다. 특히 독·기절과 낮은 자세에서
  모든 지지 마디를 1배로 한눈에 세기 어렵다.
- 집게의 두 손가락은 원래 디자인처럼 비대칭이다. 새 닫힘은 실체가 있는 양쪽
  끝을 맞물리게 했지만 게임의 실제 표시 배율에서 접촉 강도는 새 검수 대상이다.
- 수면 쌍의 감긴 눈, 접힌 다리/집게와 등·턱 윤곽 변화는 보존했다.
  호흡의 진폭은 작아 1배에서 움직임이 약하게 보인다.
- PNG/GIF 파일 순서 비교는 실제 전투 거리, 접촉 판정이나 런타임 상태 효과를
  검증하지 않는다. 독립 검수 재판정과 사용자 선택은 하네스가 처리한다.

이 기록은 저작 변경과 파일 열람의 기록이며, 새 검수 통과나 사용자 승인을 선언하지 않는다.

# 옥갑전갈왕 — GIF 시간표와 실제 앵커

GIF는 원본 128×128, 동일 RGB 팔레트와 투명 배경이다. 자세는 완전한 리터럴
격자로 저장되며 전체 프레임 이동·회전·보간으로 만들지 않았다. 아래 순서는
현재 저장 GIF를 다시 읽어 확인한 노출 순서다. 시간 단위는 ms다.

| attack | idle_a → windup → move → attack → recover → idle_a | 650, 260, 120, 160, 240, 650 |

## 집게 공격

공격 주체는 화면 아래의 큰 앞집게다. 어깨→두꺼운 팔/관절→손목→손바닥→두
손가락을 추적한다. 준비에서 집게를 벌리고 당기며, 이동에서 뒤 지지발로 밀고
앞 지지발과 어깨를 전진시킨다. 타격은 옥색의 실체가 있는 두 손가락을 닫는
160ms 접촉 자세다. 큰 삼각 구멍 대신 좁은 턱 틈을 남겼다.

현재 접촉 앵커는 먼 집게 x99–103/y61–64, 앞집게 x103–107/y82–85 부근의
끝 군집이다. 이 좌표는 이전 초안의 바깥 금테 좌표에서 갱신했다. 손바닥 아래
경계는 앞 지지발의 아래쪽 경로와 구별된다. 회수는 별도 리터럴 손목/집게 자세다.

## 옥침독 — 실제 주홍 꼬리 독침

기술은 입이나 손에서 발사하지 않는다. 꼬리의 마디·끝 마디·주홍 침이 연결된
실제 침이 발원점이며, 두 집게는 준비와 발사 동안 몸 앞의 가드다.

- skill_a, 300ms: x43–49/y37–44의 주홍 침 안에 V/P/F 자주 핵을 모은다.
- skill_b, 180ms: 굽힌 꼬리 끝의 주홍 침은 x49–69/y37–45에 있다.
  x67–75/y42–45의 자주 목에서 위쪽 가는 독기와 아래쪽 넓은 독기가 갈라진다.
  위 갈래는 y17–39, 아래 갈래는 y44–66에 서로 다른 끝과 밝은 중심을 가진다.
- skill_c, 340ms: 꼬리를 접고 세 독방울을 남긴다. 방울은 x75–80/y54–61,
  x91–97/y70–78, x58–64/y79–88 부근이다. 아래 방울은 접힌 침 아래에 이어지고
  나머지는 끊어진 독기 잔상이다. 집게 교정에서 이 효과는 보존했다.

## 독·기절·수면·죽음

독 첫 자세는 턱 밑으로 집게를 모으고 두 번째에서 턱/손바닥을 더 낮춘다.
방울 크기와 위치가 바뀐다. 기절은 두 손바닥과 굽은 손가락이 처지고 두 번째
집게가 한 단계 낮아지며 별은 다른 위치에 있다. 길게 늘어진 집게 띠를 제거하고
실제 지지발 위에 접힌 집게를 남겼다.

수면은 감긴 눈·접힌 지지 다리·낮은 집게를 유지한다. sleep_b는 작은 등/턱의
윤곽 압축으로 숨을 표현한다. 두 원본을 보존했으며 native 1배에서 호흡은 작다.
죽음은 바닥에 내려온 더 평평한 몸이다. dead GIF의 마지막 1500ms 뒤 반복되는
초기화는 미리보기 재생이며 게임 부활을 나타내지 않는다.

`previews/timing.json`과 `INSPECTION.json`은 실제 파일 순서·노출·RGBA 대응을
기록한다. 대시보드/런타임 타이밍이나 검수 판정을 바꾸지 않았다.

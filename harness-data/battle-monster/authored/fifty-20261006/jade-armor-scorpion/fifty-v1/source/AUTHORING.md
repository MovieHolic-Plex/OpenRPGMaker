# 옥갑전갈왕 — 몸통 소켓과 집게 공격 교정

## 현재 원본과 보존

현재 저작 원본은 `palette.json`, `poses/*.pxgrid` 9개와 `actions/*.pxgrid` 9개다.
모든 격자는 ASCII 128행 × 128자 전체 행이며 `.`은 투명이다. 기존 18색 팔레트를
바이트 그대로 유지했다. 이번 수정 직전 원본·문서·보조 코드는
`history/before-body-socket-repair/`에 보존했다. 앞선 history 폴더도 유지했다.

15자세를 수정했다. `dead`, `sleep_a`, `sleep_b`는 이번 수정 전과 바이트가 같다.
큰 갑각의 옥색 밝은 면, 금테, 문양, 마디 꼬리와 주홍 독침을 유지했다.
기술의 자주 핵/두 갈래 독기/세 방울, 독 방울, 기절 별도 보존했다.
첨부 전갈 그림과 64px 검객 그림은 실제 열어 크기·재질·관절을 관찰했으며
참고 이미지 픽셀을 추출·추적·재배포하지 않았다.

## 직접 저작

수정 보조 코드는 자세별로 직접 기입한 `y x 색문자열`만 적용한다.
배경으로 지우는 자리 역시 리터럴 `.` 문자열이다. 행 쓰기 이후 pxgrid에는 항상
완전한 128자 행을 저장한다. 서로 같은 신체 위치를 유지하는 대기·기술 자세에서도
블록을 별도로 기입했다. 다른 자세에서 좌표나 군집을 가져오는 전파 루프는 없다.
전체 프레임 이동/회전/보간, 도형 래스터, 합성 명암, 자동 구멍 채움, 생성 이미지는
사용하지 않았다.

- `body_socket_pixels.py`: 대기 첫 자세의 소켓·두 지지 다리와 집게 아래 금테.
- `pinch_sequence_pixels.py`: 준비의 큰 개방, 타격의 긴 손가락과 접촉 틈.
- `support_pose_pixels.py`: 다른 각 자세의 실제 몸통 위치에서 지지 경로 교정.
- `final_joint_pixels.py`: 실제 PNG 열람 후 굽은 무릎/정강이와 잔여 윤곽 교정.

기존 저작 보조 코드는 남겼고 `build_all.py`에 새 리터럴 단계를 순서대로 추가했다.
이번 최종 내보내기는 현재 격자를 `render_source.py`로 읽어 만들었다.
`review_preview.py`는 배경 합성·라벨·정수 최근접 확대만 담당한다.
`body_socket_export.py`와 `INSPECTION.json`/`REPAIR_EXPORT.json`은 실제 파일 관찰과
해시를 기록한다. 이 파일들은 저작 모델 출처, 독립 미감 판정, 사용자 선택의 증명이 아니다.

좌표는 0부터 시작한다.

그 실제 행에서 다시 마무리했다. 다리를 단순 가는 사선으로 끝내지 않기 위해
가까운 앞다리는 무릎에서 정강이 방향을 꺾고 별도 금색 발목과 넓은 발끝을 남겼다.

## 실제 그림을 보고 다시 고친 부분

- 첫 대기 교정의 x104–117/y113–121 부근에 남은 옛 먼 다리 조각을 직접 지웠다.
- 첫 타격 저작에서 지우기 문자열이 먼 손바닥과 이마 일부를 잘랐다.
  x64–101/y69–80의 먼 집게 군집과 x73–92/y78–87의 이마/눈 주변을 다시 저작했다.
  의도한 집게 틈은 유지했다.
- 타격 오른쪽 x104–126/y81–101의 옛 둥근 턱 테두리 잔여점을 실제 행에서 지웠다.
- 대기·준비·상태 자세의 가까운 앞다리는 무릎 아래 경로를 꺾었다.
  전진·타격에서는 더 앞으로 놓인 발을 유지하면서 각각 다른 압축 각도를 찍었다.

최종 `contact-{light,dark,checker}-1x.png` 세 장과
`left/right-{light,dark,checker}-3x.png` 여섯 장을 실제 열어 18자세 전체를 확인했다.
또한 `review-motion.png`, `review-tail.png`, 개별 타격 확대와
`gif-decoded-sequences-1x.png`를 열어 대응 집게/지지발과 상태 쌍을 비교했다.
최근접 확대는 진단용이며 원본 그림을 확대 재저작한 것이 아니다.

## 내보내기 관찰

현재 PNG 18개와 GIF 8개를 `previews/`에 저장했다. 저장된 GIF의 28개 노출 프레임을
다시 읽었으며 각 대응 원본 RGBA와 일치했다. 서로 다른 18개 격자를 확인했다.
전부 128×128 ASCII/기존 팔레트/투명 테두리를 유지하고 최하단 실제 잉크는 y124다.
idle_a의 가까운 지지발은 y124에 실제로 닿는다. 이 기록은 파일 계약 관찰이며
테스트·게이트 또는 독립 검수 결과가 아니다.

`previews/index.html`에서 8GIF와 배경별 확인판을 함께 볼 수 있다.

## 남은 시각적 문제와 범위

- 몸통 앞쪽 x50–80/y95–108에서 두 소켓, 팔과 다리가 가까이 겹친다.
  어두운 경계와 밝기 차이를 두었지만 native 1배의 먼 경로 가독성은 독립 검수에서
  다시 판단해야 한다. 먼 앞 정강이는 나머지 다리보다 옆으로 길게 뻗는다.
- 타격은 긴 두 손가락의 좁은 접촉을 보여 주지만 얼굴·두 손바닥의 겹침이 조밀하다.
- 독과 기절은 기존 lowered-claw 디자인이 비슷하다. 방울/별과 턱·집게 및 무릎 변화로
  구별되지만 몸통 처짐 차이는 크지 않다.
- 보존한 수면 쌍은 감긴 눈과 작은 갑각/턱 윤곽의 숨 변화다. 호흡 진폭은 작다.
- GIF의 접촉/발 이동은 원본 자세 순서를 확인한 것이다. 실제 전투의 dash 거리,
  발 미끄러짐, 타격 판정이나 런타임 표시 배율을 검증하지 않았다.

작업은 이 후보의 `source/`에만 저장했다. 테스트·게이트와 별도 검수자를 실행하지
않았으며 검수 결과·ledger·brief·게임 저장소를 수정하지 않았다.
새 독립 검수는 하네스가 맡는다. 새 검수 통과나 사용자 승인을 선언하지 않는다.

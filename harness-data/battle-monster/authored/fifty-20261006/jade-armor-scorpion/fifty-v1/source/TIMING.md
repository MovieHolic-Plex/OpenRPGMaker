# 옥갑전갈왕 — 8GIF 시간표와 발원점

GIF는 native 128×128, 기존 18색 팔레트와 투명 배경이다.
모든 자세는 완전한 리터럴 격자다. 보간 프레임이나 전체 프레임 이동/회전은 없다.
시간은 ms이며 현재 저장 GIF를 재읽어 확인한 순서/노출이다.

| GIF | 원본 순서 | 노출 ms |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 650, 260, 120, 160, 240, 650 |
| hit | idle_a → hit → recover → idle_a | 600, 280, 240, 600 |
| dead | idle_a → hit → dead | 650, 200, 1500 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700, 300, 180, 340, 900 |
| poison | poison_a → poison_b | 420, 420 |
| stun | stun_a → stun_b | 500, 500 |
| sleep | sleep_a → sleep_b | 650, 650 |

## 공격 — 같은 앞집게의 준비·전진·접촉·회수

주 공격 집게는 화면 아래의 큰 앞집게다. 몸통 앞 관절→팔→손목→손바닥→고정
손가락/경첩/상대 손가락 경로를 유지한다. 별도의 지지 다리는 몸통 아래에서 나온다.

- **준비 260ms:** 앞집게 고정 끝 x111–114/y70–73, 상대 끝 x120–126/y99–103.
  상대 손가락을 바깥으로 벌려 대기보다 큰 배경 쐐기를 남긴다. 먼 집게도 함께 연다.
- **전진 120ms:** 기존 뒤 지지발의 밀기와 앞 어깨/손바닥의 전진 자세를 유지한다.
  앞쪽 두 지지 경로는 집게에서 분리해 몸통 소켓과 연결했다.
  가까운 앞발의 실제 하중 윤곽은 대기의 x73–86/y124에서 전진의 x87–100/y124로 간다.
- **접촉 160ms:** 긴 고정 끝과 길게 닫히는 상대 끝을 유지한다.
  먼 접촉 군집은 x109–113/y49–52, 앞 접촉 군집은 x118–123/y71–73 부근이다.
  안쪽의 좁은 틈과 어두운 접촉 경계를 남긴다. 가까운 앞발은 x89–102/y124에서 받친다.
- **회수 240ms:** 손바닥과 손가락은 별도 회수 격자로 당긴다.
  지지발은 몸통에 붙은 경로를 유지하고 가까운 앞발은 x73–86/y124로 돌아간다.

이 좌표는 원본 도트의 추적 위치다. 런타임 hitbox나 이동량을 설정한 것이 아니다.
발 변화는 각 자세에서 직접 저작했으며 실제 배틀 dash의 미끄러짐은 별도 관찰이 필요하다.

## 옥침독 — 실제 꼬리 독침에서 발사

입이나 손에서 쏘지 않는다. 마디 꼬리→끝 마디→주홍 독침이 실제 발원점이다.
집게는 앞쪽의 가드이며 기술 효과는 같은 침에서 나온다.

- **skill_a / 300ms:** x43–49/y37–44의 주홍 침에 V/P/F 자주 핵을 모은다.
- **skill_b / 180ms:** 굽힌 꼬리의 실제 주홍 침은 x49–69/y37–45 부근이다.
  x67–75/y42–45의 자주 목에서 위의 가는 독기와 아래의 넓은 독기가 갈라진다.
  위 끝은 y17–39, 아래 끝은 y44–66이며 서로 다른 굵기와 계단형 끝을 유지한다.
- **skill_c / 340ms:** 꼬리를 접고 세 방울을 남긴다.
  x75–80/y54–61, x91–97/y70–78, x58–64/y79–88의 방울은 별도 군집이다.
  아래 방울은 접힌 침 아래, 나머지는 깨진 독기 잔상이다.

이번 교정에서 기술 핵/분기/세 방울은 보존하고, 해당 자세의 앞 지지 다리와
집게 하부 겹침을 실제 좌표 문자열로 교정했다.

## 독·기절·수면·쓰러짐

독 쌍은 아픈 턱과 모은 집게, 크기/위치가 다른 방울을 가진다. 두 번째 자세의
가까운 앞 무릎을 더 낮췄다. 기절 쌍은 처진 집게와 서로 다른 별 위치를 유지한다.
기절 두 번째의 앞 무릎도 낮아지지만 독과의 기본 몸통 디자인은 가까운 편이다.

수면 두 원본은 이번에 그대로 보존했다. 감긴 눈, 접힌 다리와 낮은 집게,
작은 갑각/턱 윤곽의 숨 변화가 있다. 죽음은 더 평평하게 바닥에 놓인 별도 자세다.
dead GIF가 마지막 1500ms 뒤 처음으로 돌아가는 것은 미리보기 루프다.

`previews/timing.json`과 `INSPECTION.json`은 실제 저장 순서·노출·RGBA 대응을
기록한다. 하네스/런타임 타이밍, 독립 검수 또는 사용자 선택은 수정하지 않았다.

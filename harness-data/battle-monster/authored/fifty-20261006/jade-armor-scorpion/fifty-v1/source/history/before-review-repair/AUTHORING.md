# 옥갑전갈왕 — native 128px 완성 후보

## 범위와 참고

이 후보의 `source`만 작성했다. 빈 원본에서 시작한 전갈의 18자세다. 다른 종의 그림을 복제하지 않았다. `human-size.png`를 실제 열어 작은 눈, 넓은 명암 면, 얼굴/목 연결과 크기를 관찰했다. 참고 픽셀을 추출하거나 재배포하지 않았다.

`palette.json`은 18개의 ASCII 기호와 직접 정한 RGB 색이다. 점은 투명이다. `poses/`와 `actions/`의 18개 파일은 각각 **128개의 완전한 128자 ASCII 행**이며 그림 정본이다. 원/다각형/선 래스터, 자동 명암, 프레임 이동/회전/보간, 자동 빈틈 채우기, 생성 이미지는 사용하지 않았다. 코드의 빈 캔버스에 직접 선택한 native 행/좌표 문자열을 쓰고, 최종 전체 행을 저장했다.

## 직접 저작한 구조와 동작

- 갑각: 기본 y=63–100. H/L 왼쪽 윗면, 넓은 J 옥색 면, T/S 그림자, G/Y 금 테두리와 B 아래 베벨. 중앙 금옥 장식과 복부 판을 따로 찍었다.
- 꼬리: 기본 y=8–80. 두꺼운 뿌리, 위로 돌아오는 마디, 금 관절 띠와 주홍 독침. 코일 안쪽의 빈 공간은 의도한 투명이다.
- 다리: 먼 세 개와 가까운 세 개. 허벅지/무릎/아래마디/발끝을 구분했다. 가까운 위마디는 9–13px 정도의 넓은 군집이다.
- 양 집게: 어깨/관절/손목/손바닥과 각각 위·아래 손가락을 연결했다. 열린 손가락 사이의 틈은 보존했다.
- 얼굴: 우향 눈썹/주홍 눈, 옥색 이마와 금 턱, 작은 밝은 구기. 수면과 죽음에는 평상시 눈 덩어리 대신 짧은 닫힌 눈꺼풀을 직접 넣었다.

| 자세 | 실제 배열 변화 |
|---|---|
| idle_a/b/c | 독침 끝, 집게 아래 손가락, 턱, 등 윗윤곽/얼굴 군집을 따로 저작. |
| windup | 같은 앞집게를 당겨 벌리고 뒤 무릎을 압축. 먼 뒷발은 뒤에서 지지. |
| move | 갑각 앞쪽 면/어깨/머리/앞집게가 전진. 뒤 지지발의 밀기와 앞으로 디딘 다리 경로를 바꿈. |
| attack | 앞집게 손목 압축, 위 손가락은 아래로/아래 손가락은 위로 굽혀 실제 끝을 닫음. 먼 집게도 닫음. 앞 무릎/발목은 별도 하중 군집. |
| recover | 집게와 머리를 당겨 다시 벌리는 중간 자세. |
| hit | 처진 눈썹/턱/어깨, 당긴 집게, 낮게 늘어진 독침, 뒤 무릎 변화. |
| dead | y=99–124의 떨어진 갑각, 낮은 머리/감긴 눈, 접힌 여섯 다리/집게, 옆으로 내려온 분절 꼬리. 실제 몸 하중 윤곽이 y=124에 닿음. |
| skill_a/b/c | 독침 자주 핵 → 실제 침에서 서로 다른 두 독기 갈래 → 접힌 꼬리와 세 방울. |
| poison_a/b | 턱 밑에 집게를 끌어안는 통증과 다시 처지는 자세. 턱/눈썹/집게와 독방울 위치/크기가 다름. |
| stun_a/b | 머리와 양 집게가 처짐. 두 번째 이마/턱/집게 끝도 별도로 눌러 찍고 별 위치/크기를 바꿈. |
| sleep_a/b | 낮은 갑각, 접힌 다리와 집게, 감긴 눈. 두 번째는 등/머리/턱 윤곽이 내려오며 목을 따로 저작. 색 변화로 숨을 대신하지 않음. |

## 실제 그림을 열고 고친 좌표

좌표는 0부터 세는 native 좌표다.

1. 처음 기본 그림의 좁은 갑각과 가는 집게를 넓은 갑각/손바닥과 두 손가락의 새 리터럴로 다시 찍었다. 처음 선택한 문자열도 `author_pixels.py`에 보존했다.
2. 앞집게 뒤에 전부 묻히던 먼 앞발은 y=103–121의 아래마디/발끝을 따로 찍어 오른쪽 지지면이 드러나게 했다.
3. 전진/접촉에서 꼬리 뿌리가 등 판 위에 사선 띠처럼 겹쳤다. 잘못된 마지막 덧그리기를 제거해 실제 뒤쪽 겹침으로 복구했다.
4. 접촉에서 긴 위 손가락 끝이 열린 형태로 남아 있었다. 최종 `ATTACK_CLAW`/`ATTACK_FAR`의 위·아래 곡선을 새로 저작했다. 앞 집게 (123,94), 먼 집게 (113,72) 부근에서 실제 끝이 맞물린다. 닫힌 집게 안의 작은 틈은 의도한 공간이다.
5. 수면 얼굴이 외곽선만으로 갑각에 걸려 보였다. sleep_a x=60–82/y=98–112와 sleep_b의 내려온 머리에 맞는 y=99–113 목/어깨를 **별도 문자열**로 찍었다.
6. sleep_b의 새 등 윤곽이 꼬리 뿌리를 잘랐다. 해당 자세의 (26,85) `KGGYYLJJTTTBK`, (29,86) `GYYJJTT`를 직접 골라 금/옥색 연결 부피를 복구했다.
7. 준비/피격/기술 준비의 뒷무릎 수정이 먼 뒷발 일부를 잘랐다. 세 자세의 y=101–114를 각각 다른 문자열로 다시 저작했다. 연결 진단으로 자동 채우지 않았다.
8. skill_b 독기 오른쪽 말단 y=62–66이 캔버스를 넘었다. 줄마다 직접 고른 짧아지는 문자열로 고쳤다. 잘라내기/리샘플링은 하지 않았다.

## 실제 열람과 파일 근거

밝은/어두운/체커 배경의 `contact-…-1x.png`와 `left-…-3x.png`, `right-…-3x.png`를 실제 열었다. 개별 native 얼굴/집게와 접촉 확대도 열어 관절/투명/광원을 봤다. 실제 8GIF를 다시 디코드한 `gif-decoded-sequences-1x.png`를 열어 저장된 순서를 비교했다. 모든 GIF 프레임 RGBA는 대응 native PNG와 같다. 계산한 현재 원본/PNG/GIF 해시, 실제 노출 시간과 바운드는 `INSPECTION.json`에 있다.

모든 자세의 최하단 신체 픽셀은 y=124이며 idle_a 실제 지지발도 정확히 y=124다. 1px 투명 외곽과 알파 0/255를 유지했다. 확대/배경/라벨은 진단 그림에만 사용했다.

## 남은 시각 검토사항

- 독·기절/바닥 자세에서는 양 집게와 먼 다리 일부가 겹친다. 1배에서 여섯 다리를 한눈에 세는 가독성은 독립 미감 검수 대상이다.
- 열린 집게의 위 손가락이 아래 손가락보다 길다. 접촉에서는 실제 끝이 맞물리지만 이 비대칭 형태의 전갈다움은 추가 미감 검토 대상이다.
- 대기/수면의 숨은 작은 윤곽 변화다. 수면 쌍에는 실제 등/머리/턱 변화와 닫힌 눈이 있지만 게임 표시 배율에서의 작은 숨 가독성은 후속 확인 대상이다.
- 실제 전투 거리/타격/독 상태 적용을 실행한 결과는 아니다. 이 폴더는 원본과 동작 미리보기 후보다.

별도 검수자를 호출하지 않았다. 독립 검수나 사용자 승인, 선택, 패킹/설치를 대신 기록하지 않았다. 테스트/게이트를 실행하지 않았다.

## 보존

`poses/*.pxgrid`, `actions/*.pxgrid`, `palette.json`이 최종 원본이다. `author_pixels.py`, `motion_pixels.py`, `status_pixels.py`, `skill_pixels.py`, `collapse_pixels.py`, `correct_pixels.py`는 직접 선택한 행/좌표 문자열이다. `build_all.py`는 저장/렌더 순서이며 `python source/build_all.py`로 재현한다. `render_source.py`는 정확한 native RGBA 읽기/PNG·GIF 저장/진단 확대를 맡고 도형을 생성하지 않는다. `TIMING.md`, `INSPECTION.json`, `previews/`에 시간표와 현재 산출물을 보존했다.

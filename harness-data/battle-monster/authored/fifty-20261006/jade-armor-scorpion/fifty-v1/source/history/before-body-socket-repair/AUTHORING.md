# 옥갑전갈왕 — 집게 해부 연속성 교정

## 범위와 보존

현재 초안의 독립 검수 지적에 따라 집게를 수정했다. 쓰기 범위는 이 후보의
`source/`뿐이다. 저장소·게임 저장소·brief·ledger·다른 후보·검수 결과를 수정하지
않았고, 별도 검수자를 호출하지 않았다. 테스트와 게이트도 실행하지 않았다.

첨부 `reference.png` 및 `references/human-size.png`를 실제 열어 실루엣·크기·광원과
관절을 관찰했다. 참고 이미지의 픽셀을 추출하거나 추적하지 않았다.
기존 18색 `palette.json`을 그대로 유지했다. `.`은 팔레트에 없는 투명 문자다.
기본 9개와 추가 9개 원본은 각각 ASCII 128행 × 128자 전체 격자로 저장되어 있다.

이번 수정 직전의 격자·팔레트·문서·보조 코드·내보내기 기록은
`history/before-pincer-repair/`에 보존했다. 이전 수정의 보존 폴더도 유지했다.
현재 원본은 `poses/`와 `actions/`다. 총 15격자를 직접 수정했다.
`dead`, `sleep_a`, `sleep_b`의 좋은 낮은 자세는 원본 바이트를 보존했다.

## 직접 저작 방식

`pincer_repair_pixels.py`는 자세별로 별도 기입한 `y x 색문자열`을 적용한다.
모든 바뀐 군집은 직접 고른 리터럴이다. 배경으로 지우는 위치도 `.` 문자열로
명시했다. 도형 래스터·자동 채움·합성 명암·자동 포즈 이동/회전/보간·다른 자세에서
좌표를 가져오는 루프·이미지 생성은 사용하지 않았다. 완전한 결과 행을 pxgrid로 남겼다.

기존 저작 보조 코드는 그대로 보존하고 `build_all.py`에 이번 리터럴 교정 단계를
추가했다. `render_source.py`와 `review_preview.py`는 격자를 PNG/GIF로 내보내거나
배경·진단 라벨·정수 최근접 확대를 만드는 보조 코드다. 참고 이미지에는 적용하지 않았다.
`pincer_export.py`는 현재 파일을 읽어 크기·문자·여백·변경 수·실제 해시를 기록한다.
이 기록들은 저작 모델 출처, 독립 미감 판정 또는 사용자 선택의 증명이 아니다.

## 지적별 실제 수정

좌표는 0부터 시작하는 native 좌표다. 여러 번 그림을 열어 본 뒤 마지막 교정까지
보조 코드에 남겼다. 아래 범위는 집게의 주요 저작 영역이다.

| 자세/영역 | 변경 |
|---|---|
| idle_a/b/c 먼 집게, x88–112 / y62–83 | 작은 타원 돌기를 긴 곡면 손가락으로 교체. 손바닥에서 J/T 옥색 면이 이어지고 H/L 윗빛, B 밑면, 금빛 경첩을 둔다. 끝은 위·안쪽으로 돌아가는 별도 군집이다. 세 대기의 끝 위치를 각각 리터럴로 선택했다. |
| idle_a/b/c 앞집게, x98–126 / y89–114 | 두 번째 손가락을 손바닥 아래에서 앞으로 뻗었다가 위·안쪽으로 접히는 실체로 저작. 끝과 첫 손가락 사이의 열린 턱 공간을 보존하고, 손바닥 아래 윤곽과 앞 지지발 경로를 따로 찍었다. |
| windup / move / recover | 같은 대칭이 아닌 두 손가락 구조를 각 준비·전진·회수의 실제 손바닥 위치에서 저작. 준비의 넓은 개방, 전진의 어깨/앞발, 회수의 당긴 손목을 기존 자세에 맞춰 유지했다. |
| attack 먼 집게, x90–118 / y62–80 | 긴 얇은 삼각 윤곽을 두꺼운 옥색 손가락으로 바꾸었다. 손바닥에서 이어지는 넓은 안쪽 면과 어두운 밑면을 저작했다. 기존 큰 삼각 구멍을 좁은 턱 틈으로 줄였다. 접촉 군집은 x99–103 / y61–64 부근이다. |
| attack 앞집게, x101–121 / y82–111 | 같은 방식으로 넓은 곡면 손가락과 좁은 닫힘 틈을 찍었다. x103–107 / y82–85 부근의 두 끝 맞물림이 닫힘 앵커다. 첫 확대에서 남아 있던 x123–124 / y93–94의 옛 테두리 점을 직접 지우고 아래 손바닥 경계를 복구했다. |
| hit, x74–114 / y78–121 | 길게 늘어진 두 평행 띠를 지웠다. 몸 쪽 팔에서 이어진 두 손바닥과 접힌 손가락을 별도로 저작하여 두 작은 턱 틈과 되굽은 끝을 남겼다. 아래 지지 다리/발목/발끝을 드러냈다. |
| poison_a/b, stun_a/b | 같은 결손을 각 원본의 실제 위치에서 고쳤다. 턱을 받치는 독 첫 자세, 더 낮은 독 두 번째 자세, 처진 기절 쌍의 집게 높이/면을 각각 선택했다. 자주 방울과 금빛 별은 기존 개별 위치를 보존했다. |
| poison_b, stun_a/b 하부 | 확대에서 남은 옛 장선형 금색 윤곽을 y107–124의 실제 행에서 직접 지웠다. 두 지지 다리는 두꺼운 옥색 면·금색 관절·연결된 발끝으로 다시 노출하고 손가락 아래에는 배경 통로를 남겼다. |
| skill_a/b/c | 준비·발사·회수의 손바닥에서 같은 두꺼운 상대 손가락을 각각 저작했다. 자주 독침 핵, 실제 침에서 나온 두 갈래 독기, 세 독방울은 유지했다. skill_c의 방울이 집게와 겹치는 영역은 보존하며 주변 손가락 면을 따로 찍었다. |

갑각 큰 밝은 면·두 금띠·꼬리 밑동·끝 마디·주홍 침은 이번 집게 교정에서 유지했다.

## 실제 파일 열람과 내보내기

수정 중 개별 대기/공격/전진/피격/독/기절/수면/쓰러짐 PNG를 실제 열었다.
수정 후에는 아래 현재 이미지도 실제 열어 비교했다.

- `contact-light-1x.png`, `contact-dark-1x.png`, `contact-checker-1x.png`: 18자세 전체 native 확인.
- `left/right-{light,dark,checker}-3x.png`: 세 배경의 전체 18자세 최근접 확대.
- `attack-review-4x.png`, `hit-review-4x.png`, `stun_b-review-4x.png`: 접촉·손가락·지지발 상세.
- `review-motion.png`, `review-tail.png`: 대응 관절과 집게 높이 비교.
- `gif-decoded-sequences-1x.png`: 저장된 8GIF의 실제 프레임을 재읽어 준비→전진→닫힘→회수와 상태 쌍 비교.

현재 PNG 18개와 GIF 8개를 다시 저장했다. GIF의 저장 프레임 28개를 대응 원본
RGBA와 비교했으며 색/투명이 모두 일치했다. 모든 18격자는 서로 다르다.
격자 크기·팔레트 문자·투명 테두리·최하단 y124를 확인했으며 idle_a의 실제 발은
y124에 닿는다. 팔레트는 수정 전과 바이트가 같다. `INSPECTION.json`과
`REPAIR_EXPORT.json`에는 현재 실제 원본/PNG/GIF 해시와 파일 관찰만 저장한다.

`previews/index.html`은 8GIF와 배경별 native 확인판을 연결한다.

## 남은 표현 문제와 한계

- 집게는 긴 고정 손가락과 짧게 굽는 상대 손가락이 있는 비대칭 디자인이다.
  피격·독·기절에서는 겹친 손바닥과 되굽은 끝 때문에 길이가 짧게 투영된다.
  1배에서 두 집게와 얼굴 일부의 겹침은 여전히 조밀하다.
- 기절과 독의 기본 몸통 처짐은 원안에서 서로 가까운 디자인이다. 방울/별,
  턱과 집게 높이 변화는 구별되지만 동작 차이가 크게 과장되지는 않는다.
- 수면의 감긴 눈·접힌 다리/집게와 작은 등/턱 윤곽 변화는 원본을 유지했다.
  호흡 진폭은 작다. 수면 쌍은 낮게 웅크린 자세이고 죽음은 더 평평하게 바닥에 놓인다.
- 먼 다리와 집게의 겹침 때문에 여섯 지지 경로를 1배에서 동시에 세기는 어렵다.
- 파일 확인과 GIF 프레임 비교는 실제 전투 이동 거리·접촉 판정·표시 배율의 검증이 아니다.
  새 독립 검수와 선택 처리는 하네스에 맡긴다. 이 문서는 새 검수 통과나 사용자 승인을 선언하지 않는다.

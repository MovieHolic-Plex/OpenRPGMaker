# 설익부엉이 — 동작 시간표

모든 GIF는 native64, 투명 바탕, loop=0(반복), disposal=2다. 동일 프레임 복제나 중간 자세 합성 없이 아래 원본 격자를 지정 시간 동안 유지한다. 시간 단위는 ms.

| GIF | 원본 순서와 유지 시간 | 읽을 변화 |
|---|---|---|
| `idle.gif` | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 | 가슴 들숨, 어깨가 낮아지는 짧은 눈 깜박임 |
| `attack.gif` | idle_a 200 → windup 180 → move 110 → attack 160 → recover 180 → idle_a 220 | 지지발로 밀기, 날개를 연 낮은 도약, 연결된 두 발톱 접촉, 날개·발 회수 |
| `hit.gif` | idle_a 220 → hit 180 → recover 180 → idle_a 260 | 감기는 눈과 기울어진 어깨, 낮은 착지 |
| `dead.gif` | idle_a 240 → hit 150 → dead 1000 | 피격 뒤 바닥에 옆으로 내려온 몸과 닫힌 눈 |
| `skill.gif` | idle_a 180 → skill_a 260 → skill_b 220 → skill_c 220 → idle_a 260 | 날개 아래 냉기 모음, 세 얼음 깃털 발현, 날개 낮추고 깨진 파편 회수 |
| `poison.gif` | poison_a 340 → poison_b 340 | 아픈 턱·어깨, 가까운 날개의 접힘과 독 방울 변화 |
| `stun.gif` | stun_a 380 → stun_b 380 | 처진 머리·날개, 두 번째 눈 표정과 별 위치 변화 |
| `sleep.gif` | sleep_a 600 → sleep_b 600 | 앉은 자세의 닫힌 눈, 고정된 바닥 위 작은 가슴 들숨 |

## 발·몸의 앵커

좌표는 native canvas의 0-based (x,y)다. `idle_a`의 두 발목은 (23–27,56), (33–37,56)에 있고 두 발의 최하단은 y=60이다. `windup`의 뒤 지지발 끝은 (13,60) 부근으로 넓혀 밀어내는 자세를 만든다. `move`는 날개·배·다리의 모양을 바꾸어 발을 y=57까지 든다. `attack`의 두 발 뿌리는 (36–45,52), (49–55,52)에서 몸 아래로 이어지고 최하단은 y=56이다. 이번 수정에서 y=53–56의 두 발가락을 앞으로 뻗고 굽는 모양으로 직접 고쳤다. 긴 왼쪽 갈고리 끝은 x=47–50, 짧은 오른쪽 갈고리 끝은 x=59–62에서 안쪽으로 돌아온다. 접촉의 가시 핵심 자세는 `attack`의 160ms 유지 구간이다. 회수·착지 뒤 `idle_a`로 돌아온다. GIF 순서와 유지 시간은 바꾸지 않았다.

## 설익진 앵커

이 종은 도구나 사람 손 대신 실제 날개로 시전한다. `skill_a`의 두 접힌 날개 아래 `A/F/L` 덩어리는 깃의 청회색 경계에 닿아 있다.

`skill_b`의 세 갈래는 가까운 펼친 날개의 서로 다른 깃 끝에서 이어진다.

- 위쪽 긴 얼음 깃털: (49,24) 밑동. (60–61,10)의 날카로운 끝까지, 좁고 비스듬한 결정 면.
- 가운데 짧고 넓은 얼음 깃털: (50,31) 및 (49,32) 밑동. (59–60,29), (56–61,30)의 끝으로 이어지는 수평에 가까운 결정 면.
- 아래쪽 사선 얼음 깃털: (49–52,35–36)의 흰 날개 끝에서 (53,35)의 청빛 밑동으로 이어진다. 오른쪽 아래 (61,43)까지 벌어지는 별도 결정 면이다. 오른쪽 바깥 면은 x=62/y=38–41까지이며 x=63은 투명이다. 기존 배 옆 (48–61,43–54)의 긴 청색 돌출은 제거했다.

`skill_c`의 냉기는 낮아진 날개 끝의 작은 결정으로 돌아오며, 바깥 파편은 (56–58,44–45), (55–58,49–50), (50–52,52–53)에서 따로 부서진다. 같은 원 오라를 크기만 바꾸는 기술이 아니다.

## 실제 GIF 재읽기

`inspection/gif-readback.json`은 실제 저장 GIF에서 읽은 프레임 수·크기·노출 시간이다. `inspection/measurements.json`에는 같은 프레임의 가시 픽셀을 대응하는 원본 격자와 비교한 측정값이 있다. `*-decoded.png`는 그 실제 GIF 프레임을 최근접 확대하고 이름·유지 시간만 붙인 확인판이다.

이 시간표는 자세 후보의 반복 미리보기다. 게임의 이동 속도·피해 판정·사망 반복 중지는 하네스/런타임 적용 단계에서 별도로 연결한다.

이번 수정 후 8종 GIF를 원본 순서·시간표대로 다시 저장하고 실제 프레임을 재읽었다. 이 원본의 독립 재검수 결과나 사용자 승인을 시간표에 기록하지 않는다.

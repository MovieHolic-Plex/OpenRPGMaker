# 설익부엉이 — 동작 시간표

모든 GIF는 native64, 투명 바탕, loop=0(반복), disposal=2다. 원본 격자를 아래 시간 동안 유지한다. 중간 자세 합성이나 전체 프레임 변형을 하지 않는다. 시간은 ms이며 이전 시간표를 보존했다.

## 발·몸 앵커 — 0-based 좌표

`idle_a`의 발목은 (23–27,56), (33–37,56)이며 바닥 발끝은 y=60이다. `windup`의 뒤 지지발은 (13,60) 부근까지 넓혀 밀어내는 자세다. `move`는 본체·날개·다리의 실제 모양이 바뀌며 발을 y=57까지 든다.

`attack`의 첫 발목은 x=39–45/y=52에서 몸에 닿는다. 첫 발등은 x=41–44/y=53–55, 바깥 갈고리는 x=47–49/y=54–56, 안으로 돌아오는 끝은 x=44–48/y=57–58이다. 둘째 발목은 x=51–55/y=52, 발등은 x=53–57/y=53–55, 바깥 갈고리는 x=60–62/y=54–56, 반환 끝은 x=56–60/y=57–58이다. 두 발톱 내부의 x=45–46/y=55–56, x=58–59/y=55–56은 의도한 작은 빈 공간이다. 접촉은160ms 유지하며 최하단 y=58이다. 회수 자세의 두 발과 접힌 날개는 기존 원본을 유지한다.

## 설익진의 실제 시전 앵커

이 종은 도구·사람 손·입 대신 실제 날개로 시전한다. `skill_a`의 `A/F/L` 냉기는 접힌 두 날개 아래 청회색 깃 경계에 붙어 있다.

`skill_b`의 세 깃털은 가까운 오른쪽 날개의 별도 깃 끝에서 이어진다.

- 위쪽: 밝은 깃대 밑동 (50,27) → (49,24) 부근 → (60–61,10)의 끝. y=14/17/20의 파인 틈과 y=15/18/21의 넓은 깃가지를 가진 가장 긴 사선 깃털.
- 가운데: 밑동 (49–51,32), y=32/x=51–59의 밝은 수평 깃대. 위쪽 y=29–31과 아래쪽 y=33–34의 서로 다른 짧은 가지. 원래 실제 날개 끝 (48–51,31–36)과 연결된다.
- 아래쪽: 밑동 (53–54,36), (54,36)에서 (61,43)까지 내려가는 창백한 깃대. y=37/39/41의 길이가 다른 가지와 y=38의 바깥 틈. 가운데 깃털과 별도 밑동에서 벌어진다.

모든 효과의 오른쪽 최댓값은 x=62이며 x=63은 투명이다. `skill_c`는 낮춘 날개 끝의 작은 결정과 바깥 (56–58,44–45), (55–58,49–50), (50–52,52–53)의 깨진 부스러기를 유지한다.

## GIF 재읽기와 한계

`inspection/gif-readback.json`에는 실제 저장8GIF의 프레임 수·크기·시간이 있다. `inspection/measurements.json`에는 원본 격자와 GIF 디코드 프레임의 가시 픽셀 비교가 있다. 현재 지정 순서·시간은 같으며 가시 픽셀 차이는0이다. `*-decoded.png`는 저장 GIF를 직접 디코드한 진단 이미지다.

이 문서는 후보 미리보기 시간표다. 실제 속도의 연속 재생과 게임 이동·피해 판정은 이번 작업에서 확인하지 않았다. 사망 반복 중지와 실제 기술/상태 연결은 런타임 적용 단계에서 다룬다. 독립 재검수나 사용자 승인을 시간표로 선언하지 않는다.

# 설익부엉이 — 공격·기절 수정 기록

## 현재 후보와 작업 범위

이 `source`에는 기본 9자세와 추가 9자세의 native64 리터럴 원본, 18개 PNG와 8개 GIF가 있다. 이번 작업은 제공된 독립 검수의 `attack`, `stun_a`, `stun_b` 지적을 수정했다. 사용자 승인이나 새 독립 검수 통과를 선언한 기록이 아니다.

모든 수정과 출력은 이 후보의 `source` 안에 저장했다. 팔레트 18색과 나머지 15자세는 보존했다. 저장소·게임 저장소·brief·ledger·검수 결과·다른 후보는 수정하지 않았다. 테스트/게이트와 별도 검수자 호출은 하지 않았다.

## 참고 그림과 직접 저작 방식

첨부된 현재 자세 시트와 `references/human-size.png`를 실제로 열어 보았다. 현재 부엉이의 둥근 얼굴, 두 금색 눈, 목과 어깨의 연결, 넓은 흰 깃털 면, 검푸른 오른쪽 그림자, 두 발의 연결을 관찰했다. 검객은 64px 캐릭터의 크기와 얼굴·팔·손·검 연결을 관찰하는 데만 사용했다. 참고 이미지의 픽셀·팔레트를 추출하거나 복사하지 않았다.

광원은 왼쪽 위다. 흰 깃털의 빛/기본 면은 `H/W`, 청회색 그림자는 `C/M/S/D`, 윤곽은 `O`다. 금색 눈은 `B/G/Y`, 발톱은 `K/T/I`, 얼음은 `A/F/L`을 유지했다.

`repair_contact_stun.py`의 `ROWS`에 각 행의 최종 ASCII 군집을 직접 골라 기록했다. 좌표는 0부터 시작한다. 코드가 선택한 리터럴을 해당 행에 쓰며, 지정하지 않은 행은 보존한다. 명암·윤곽·효과를 수식으로 만들거나 전체 프레임을 이동/회전/보간하지 않았다. 연결 검사로 빈 공간을 채우지 않았다. 최종 `.pxgrid`에는 각 자세의 64행 × 64글자가 모두 들어 있다.

## 이번에 직접 고친 군집

### attack — 발목 아래 두 움켜쥔 발톱

- 몸과 두 발목의 y=52 연결은 그대로다. 실제 변경 범위는 x=39–62, y=53–56이며 73픽셀이 다르다.
- 기존 발가락의 끝 x=61–62를 지우고 두 발의 발등을 짧게 압축했다. 첫 발의 아래쪽 군집은 x=39–48, 둘째 발은 x=51–60 부근이다.
- y=54의 `OKTIITKIKO`는 압축된 발등과 굽힘 시작이다. y=55의 `OIKO.OIKO`와 y=56의 `OKKO.OKKO`는 각각 아래로 내려간 두 발가락이 안쪽으로 돌아오는 갈고리다. 두 발가락 사이의 짧은 투명 틈은 의도한 공간이다.
- 첫 수정의 y=54 `OKTIIIITKO` 면도 확대에서 길고 평평해 보여, 최종 리터럴을 다시 골라 위의 짧은 굽힘으로 교정했다. 두 발은 몸 아래의 서로 다른 발목에 연결되어 있다.

### stun_a — 둥근 배와 짧게 접힌 날개

- 실제 변경 범위는 x=24–46, y=41–58이며 191픽셀이 다르다. 머리·눈·별은 그대로다.
- 가슴의 흰 면을 목 아래에서 넓히고, 배의 오른쪽 경계를 y=49–54에서 점차 닫았다. 기존에 x=44–46/y=55–58까지 내려오던 물결 모양의 날개/배 돌출을 제거했다.
- 가까운 접힌 날개의 `CCSD` 경계와 `S/D/O`의 짧은 끝을 y=44–53에 직접 찍었다. 날개 끝이 발까지 긴 흰 띠로 이어지지 않도록 배의 흰 면과 구분했다.
- y=55–58의 넓적다리 깃과 짧은 굽힌 발목은 배 아래에서 두 발로 이어진다. 기존 바닥의 발끝 y=59–60은 보존했다.

### stun_b — 반대쪽 무게 중심과 굽힌 무릎

- 실제 변경 범위는 x=10–46, y=41–60이며 332픽셀이 다르다. 머리·눈과 두 별은 그대로다.
- 왼쪽 어깨와 날개를 x=10까지 벌리고, 둥근 배 중심은 `stun_a`보다 왼쪽에 두었다. 가슴의 빛 면과 날개 접힘을 이 자세의 리터럴로 따로 찍었다.
- 오른쪽 접힌 날개는 별도의 짧은 어두운 경계로 끝낸다. 이전의 y=57–60 물결 끝을 지웠다.
- y=55–60의 깃·발목·발가락도 다시 골라 짧게 굽힌 무릎 위로 몸이 지지되게 했다. 머리 높이/표정의 기존 차이와 서로 다른 몸 중심으로 두 자세의 휘청거림을 유지했다.

## 보존된 15자세

`idle_a/b/c`, `windup`, `move`, `recover`, `hit`, `dead`, `skill_a/b/c`, `poison_a/b`, `sleep_a/b`는 수정 직전 파일과 바이트 단위로 동일하다. 특히 설익진의 실제 날개 끝에 연결된 세 얼음 깃털, 독의 턱·어깨와 방울 변화, 수면의 닫힌 눈·앉은 몸·작은 가슴 변화는 보존했다.

## 원본과 보조 자료

- `poses/`, `actions/`: 최종 전체 리터럴 격자 18개.
- `palette.json`: 기존 ASCII 기호 18색. `.`은 투명이며 팔레트에 없다.
- `before-contact-stun-repair/`: 이번 수정 직전 18자세 전체 격자와 저작 기록·시간표·행 문자열.
- `original-before-repair/`, `first-pass-rows.txt`, 기존 좌표 기록과 보조 코드: 이전 저작 과정 보존.
- `repair_contact_stun.py`, `contact-stun-rows.txt`: 이번에 직접 고른 y/x/ASCII 문자열.
- `authored-rows.txt`: 최종 전체 격자의 리터럴 행을 손실 없이 직렬화한 기록.
- `render.py`: 리터럴을 PNG/GIF로 기록하는 보조 코드. 최근접 확대·배경·라벨은 진단에만 사용한다.
- `inspect_contact_stun.py`: 수정 전후 차이와 실제 현재 격자 해시를 읽고 진단 이미지를 만든다.
- `png/`, `sheet.png`, `gifs/`, `index.html`: native PNG, 시트, 8동작 GIF, 로컬 확인판.
- `inspection/contact-stun-light.png`, `contact-stun-dark.png`, `contact-stun-checker.png`: 세 자세의 수정 전후 1배/최근접 3배 비교.
- `inspection/native.png`, 각 `*-decoded.png`: 전체 1배 시트와 실제 저장 GIF의 디코드 프레임 시트.

## 실제 열어 확인한 결과

수정 후 세 배경의 수정 전후 비교를 모두 열어, 발목→갈고리 연결, 가슴·배의 둥근 면, 짧은 접힌 날개 끝, 무릎→발 연결을 확인했다. 전체 18자세의 native1배 시트와 8종 저장 GIF에서 디코드한 프레임 시트도 열어 자세 전환을 비교했다. 본체 내부에 새로 생긴 투명 홈은 보이지 않았다. 발가락 사이·두 발 사이의 공간 및 독 방울·기절 별·얼음 파편의 분리는 의도한 투명이다.

파일 재읽기 수치는 `inspection/measurements.json`과 `contact-stun-readback.json`에 있다.

- 18자세 모두 64 × 64, 팔레트 18색, 알파 0/255.
- 테두리 잉크 0픽셀. 모든 자세의 최하단 y≤60, `idle_a`의 발은 정확히 y=60.
- 18자세의 RGBA 배열은 서로 다르다.
- PNG와 원본 격자의 다른 픽셀 0개. 저장 GIF와 지정 격자의 다른 가시 픽셀 0개. GIF 노출 시간은 시간표와 동일하다.
- 변경은 세 자세뿐이며 다른 15격자는 수정 전과 동일하다. 연결 수치는 보조 관찰 자료이며 그림 승인으로 사용하지 않는다.

## 남은 시각 검토점

- 압축된 갈고리는 native64의 작은 군집이다. 160ms 접촉 중 두 발톱의 움켜쥠이 충분히 강하게 읽히는지는 하네스의 새 독립 검수에서 확인해야 한다.
- 기절은 둥근 배와 짧은 날개를 복원했다. 두 무게 중심의 변화가 실제 크기에서 충분한 휘청거림으로 읽히는지도 새 독립 검수 대상이다.
- 이번 확인은 저장 GIF의 프레임 디코드·순서·유지 시간 및 PNG 시각 확인이다. 실제 속도의 연속 재생과 전투 이동/피해 판정은 확인하지 않았다.

현재 결과는 재검수용 수정 후보다. 사용자 선택·독립 검수 판정·게시 기록을 대신하지 않는다.

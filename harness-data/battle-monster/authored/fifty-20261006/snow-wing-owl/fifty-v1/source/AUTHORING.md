# 설익부엉이 — 발톱·얼음 깃털 재수정

## 범위와 현재 상태

현재 후보에는 기본 9자세와 추가 9자세의 64×64 전체 ASCII 격자, 기존 18색 팔레트, native PNG 18개와 GIF 8개가 있다. 이번에는 제공된 검수 지적의 `attack`과 `skill_b`만 직접 수정했다. 다른 16자세와 팔레트는 수정 직전 파일과 바이트 단위로 같다. 앞선 기절 수정도 그대로 보존했다.

이번 결과는 하네스 재검수용 후보이며 사용자 승인이나 독립 검수 통과를 선언하지 않는다. 별도 검수자를 호출하지 않았으며 테스트/게이트를 실행하지 않았다. 모든 쓰기는 이 후보의 `source` 내부에 한정했다.

## 참고 관찰과 저작 방식

첨부 현재 시트와 `references/human-size.png`를 실제로 열었다. 부엉이의 둥근 금색 눈, 목·어깨·날개 연결, 넓은 흰 깃털과 검푸른 그림자, 낮은 도약의 본체를 관찰했다. 검객은 얼굴 크기와 사지·도구 연결을 관찰하는 참고로만 사용했다. 참고 픽셀을 추출·추적·복사·재배포하지 않았다.

광원은 왼쪽 위다. 기존 `H/W` 빛·흰 기본 면, `C/M/S/D` 청회색 그림자, `O` 윤곽, `B/G/Y` 금색 눈, `K/T/I` 발톱, `A/F/L` 얼음을 유지했다. 이번 발톱은 밝은 발등과 어두운 아래쪽 경계를 구별했고, 얼음은 창백한 `L` 깃대를 `F/A` 깃가지와 구별했다.

최종 픽셀은 `repair_talons_feathers.py`의 `ROWS`에 직접 고른 y/x/ASCII 문자열이다. 코드는 해당 원본 행의 지정 구간을 그대로 쓰고, 다른 픽셀은 유지한다. 수식 본체·도형 마스크·합성 명암·전체 프레임 이동/회전/보간·자동 구멍 채우기를 사용하지 않았다. 전체 원본 18개는 각각 64행, 행마다 64글자의 리터럴이다. `authored-rows.txt`는 그 현재 격자 픽셀의 손실 없는 기록이다.

## 직접 수정한 좌표 — 0부터 시작

### attack: 오른쪽으로 뻗고 안으로 말리는 두 발톱

실제 변경은 x=37–62, y=52–58의 113픽셀이다. 머리·날개·몸통과 y≤51의 그림은 그대로다.

- 첫 발은 몸 아래 x=39–45/y=52의 발목에서 x=41–44/y=53–55의 발등으로 이어진다. 굽힌 바깥 발가락은 x=47–49/y=54–56에서 내려와 x=44–48/y=57–58로 안쪽으로 돌아온다.
- 둘째 발은 x=51–55/y=52의 별도 발목에서 x=53–57/y=53–55의 발등으로 이어진다. x=60–62/y=54–56의 바깥 발톱은 x=56–60/y=57–58로 돌아온다. 두 발목 사이의 본래 공간을 유지했다.
- 발가락 뿌리는 위의 `T/I` 발등에 닿으며, 짧은 안쪽 발가락의 `K/O` 끝과 긴 바깥 갈고리를 구별했다. 첫 갈고리 안의 x=45–46/y=55–56, 둘째 갈고리 안의 x=58–59/y=55–56은 의도한 열린 틈이다. 자동 연결/채움으로 닫지 않았다.
- 평평한 착지 발가락을 짧은 아래쪽 반환 끝과 열린 갈고리 윤곽으로 바꿨다. 접촉 발의 최하단은 y=58로, 대기 접지 y=60보다 위다. 두 발이 몸의 서로 다른 발목에서 앞쪽으로 움켜쥔다.

### skill_b: 깃대·계단형 깃가지를 가진 세 얼음 깃털

실제 변경은 x=48–62, y=10–43의 168픽셀이다. 얼굴·몸·왼쪽 날개·두 발은 유지했다. 원래의 실제 오른쪽 날개 끝과 연결을 보존했다.

- 위쪽 긴 깃털은 (50,27) 근처의 밝은 밑동에서 (60–61,10) 방향으로 올라간다. `L` 깃대를 비스듬히 직접 잇고, y=14/17/20에 짧은 바깥 틈, y=15/18/21에 더 넓은 계단형 깃가지를 찍었다. 이전의 평행한 긴 칼날 가장자리를 불규칙한 깃가지 외곽으로 바꿨다.
- 가운데 깃털의 독립 밑동은 (49–51,32)다. y=32/x=51–59의 창백한 깃대를 중심으로 y=29–31의 위쪽 가지와 y=33–34의 짧고 긴 아래쪽 가지를 따로 찍었다. 위쪽 깃털과 달리 수평에 가까운 짧은 빗살 윤곽이다.
- 아래쪽 깃털의 독립 밑동은 (53–54,36)이다. (54,36)에서 (61,43)까지 밝은 깃대를 아래로 벌렸다. y=37의 짧은 위쪽 가지, y=38의 파인 틈, y=39의 넓은 가지, y=41의 더 작은 가지와 끝의 단계적 좁아짐을 따로 찍었다. 가운데 깃털과 밑동·방향·외곽 리듬이 다르다.
- 세 효과는 날개에 붙어 있으며 분리된 원 오라나 떠 있는 삼각형을 덧붙이지 않았다. 가지 사이의 투명 홈은 의도한 깃털 외곽이다.

## 보존 자료와 자체 출력

- `before-talons-feathers-repair/`: 이번 수정 직전 전체 18격자, 팔레트, 저작 기록, 시간표, 리터럴 기록.
- `before-contact-stun-repair/`, `original-before-repair/`, 이전 저작·수정 코드와 행 기록: 앞선 과정 보존.
- `repair_talons_feathers.py`, `talons-feathers-rows.txt`: 이번 직접 선택한 좌표와 최종 ASCII 군집.
- `poses/`, `actions/`, `palette.json`, `authored-rows.txt`: 현재 전체 리터럴 원본.
- `render.py`: PNG/GIF 저장과 진단용 최근접 확대·배경·라벨만 제공한다.
- `inspect_talons_feathers.py`: 변경 범위·실제 격자 해시·수정 전후 확인판을 기록한다. 해시는 실제 파일에서 계산하며 승인 근거로 쓰지 않는다.
- `png/`, `sheet.png`, `gifs/`, `index.html`: 현재 PNG 18개·시트·8GIF·로컬 확인판.
- `inspection/talons-feathers-{light,dark,checker}.png`: 두 수정 자세의 전후 native1배/최근접3배.
- `inspection/talons-feathers-details.png`: 좌표를 표시한 발톱·깃털 진단 확대.
- `inspection/native.png`, `inspection/*-decoded.png`: 전체 원본1배와 실제 저장 GIF를 디코드한 프레임 확인판.
- `inspection/talons-feathers-readback.json`, `inspection/measurements.json`, `inspection/gif-readback.json`: 현재 파일을 다시 읽은 변경·크기·색·프레임·시간 측정.

## 실제 그림 확인과 파일 재읽기

수정한 두 자세의 밝은/어두운/체커 배경 전후 1배·3배 이미지를 모두 열었다. 두 발목에서 각각의 발톱으로 이어지는 면, 오른쪽으로 뻗는 외곽, 안쪽의 열린 틈을 확인했다. 기술은 서로 다른 세 밑동과 밝은 깃대·계단형 가지를 확대에서 확인했다. 본체 안에 새 투명 사각 홈은 보이지 않았다.

전체18자세 native1배와 실제 저장8GIF의 디코드 프레임 확인판도 열어 자세 순서·관절·표정·전환 폭을 비교했다. 수면은 앉은 몸과 코에서 분리된 짧은 눈꺼풀, 독은 아픈 턱·어깨와 방울 변화, 기절은 처진 몸과 별 변화가 유지된다. 기술 회수의 흩어진 얼음은 의도한 분리 효과다.

파일 재읽기 결과: 18격자 모두 64×64, 팔레트18색, 미등록 기호0, 알파0/255, 테두리 잉크0, 모든 자세 최하단 y≤60, idle_a 발 y=60. 18자세의 RGBA 배열은 모두 다르다. 원본과 PNG의 다른 픽셀0, 지정 원본과 실제 GIF의 다른 가시 픽셀0, GIF 유지 시간 차이0이다. 이 수치는 파일 계약 관찰이며 예술적 합격 판정이 아니다.

## 남은 시각 검토점

- 두 갈고리의 내부 공간은 native에서 각2×2px로 작다. 실제 전투 표시 크기와 160ms 접촉 유지에서 두 발의 움켜쥠이 충분히 읽히는지는 하네스 재검수 대상이다.
- 얼음 깃털은 오른쪽 여백 안의 좁은 군집이다. 가운데·아래 깃털의 짧은 가지가 실제 표시에서 깃털로 충분히 읽히는지 새 독립 검수가 필요하다. 확대 진단만으로 그 판정을 대신하지 않는다.
- 저장 GIF의 프레임을 디코드해 확인했으며, 실제 속도의 연속 재생·게임 이동·피해 접촉은 확인하지 않았다. 실제 전투 연결은 이번 원본 수리 범위 밖이다.

현재 후보를 사용자 승인/Allow로 기록하지 않으며 검수 결과를 수정하지 않는다.

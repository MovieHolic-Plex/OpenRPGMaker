# 바위등거북 — fifty-v1 저작 기록

## 범위와 원본

이 후보의 source 안에서 기본 9자세와 추가 9자세를 새로 저작했다. 시작 시 기존 pxgrid와 팔레트는 없었다. 원본은 poses/*.pxgrid, actions/*.pxgrid와 palette.json이다. 각 격자는 64행 × 64열의 완전한 ASCII 행이고, 점은 투명이다. 팔레트는 17색이다.

references/human-size.png를 실제로 열어 작은 눈, 피부와 옷의 큰 명암 면, 작은 캔버스에서 이어지는 팔다리와 도구의 가독성을 관찰했다. 참고 그림의 픽셀을 추출하거나 복사하지 않았다. 이 거북에는 무기나 손잡이가 없으며 목·어깨·다리와 껍질 홈을 동작 앵커로 삼았다.

원본 저작 보조 기록은 author_pixels.py에 보존했다. 모든 비투명 픽셀은 직접 적은 ASCII 행 또는 명시한 (x, y, 문자열) 기록이다. 변형 함수는 전체 행 교체와 명시한 좌표 문자열 교체만 한다. 빈 캔버스와 오른쪽 투명 여백을 초기화하며, 본체·명암·효과를 수식이나 도형으로 만들지 않는다. 프레임 전체의 이동·회전·보간도 하지 않는다. 최종 pxgrid는 다른 파일이나 코드 실행 없이 읽을 수 있는 전체 행이다.

## 실루엣·재질

- 우향 3/4 사족. 짧은 왼쪽 꼬리, 회갈색 돌등껍질, 올리브색 목·다리, 작은 금빛 눈을 유지했다.
- idle_a의 비투명 범위는 x=2..56, y=22..60이다. 두 가까운 발의 바닥을 y=60에 찍었다. 모든 자세에서 y=61..63은 투명이며 사방 최소 1px 여백이 있다.
- 등 윗면의 큰 L/H 면과 D 육각 홈, 옆면의 넓은 S 면과 작은 B 갑석 면을 구분했다. 왼쪽 위의 면이 밝고 오른쪽·배 밑이 어둡다.
- 다리는 h/l의 위쪽 면, g의 기본 면, v의 아래쪽 면으로 두껍게 저작했다. 먼 앞발은 목 아래에서 이어지고, 먼 뒷발은 배 밑의 엉덩이 군집에서 내려온다. 의도한 다리 사이 투명 공간은 유지했다.

## 자세별 변화

- idle_a/b/c: 발 위치를 고정하고 목·어깨의 작은 면 변화와 짧은 눈깜박임을 찍었다.
- windup: 목과 얼굴을 껍질 앞쪽으로 거두고, 가까운 앞발을 접고 뒷발을 굽혀 지지한다.
- move: 뒷다리의 넓은 허벅지·발목을 왼쪽으로 뻗고 앞어깨와 앞다리를 내민다. 몸통 전체를 이동시킨 복사본이 아니다.
- attack: 오른쪽 돌 어깨의 윤곽과 면을 확대해 접촉 지점을 만들고 턱을 뒤로 거둔다. 압축한 앞 손목 아래에 넓고 낮은 앞발과 짧은 밝은 발톱 군집을 붙였다. 뒷발은 계속 지면을 민다.
- recover: 목을 반쯤 펴고 앞발을 다시 몸 밑으로 회수하며 뒷다리의 지지 폭을 좁힌다.
- hit: 머리를 움츠리고 눈을 짧게 찡그리며 뒤쪽 무릎을 안으로 꺾는다. 상단 갑석 윤곽도 따로 고쳤다.
- dead: y=37부터 내려앉은 낮은 껍질을 새 행으로 그렸다. 힘이 빠진 목과 눈, 접힌 앞발·뒷발의 경계와 발끝, 왼쪽 짧은 꼬리를 남겼다.
- skill_a: 목을 세우고 지지발을 버티며 껍질 홈에 청록 기를 모은다.
- skill_b: 서로 다른 높이·폭·경계의 세 돌방패를 등 앞쪽에 솟게 했다. 돌 내부는 기존 갑석 색을 쓰고, 청록 경계와 밝은 기의 줄기가 껍질 홈까지 이어진다.
- skill_c: 방패를 별개의 깨진 돌조각으로 해체하고 홈의 기를 짧은 군집으로 접는다. 몸도 목과 어깨를 이완한 별도 배열이다.
- poison_a/b: 턱을 내리고 앞 무릎을 꺾고 뒷발을 안으로 돌린 아픈 자세. 눈꺼풀·턱·다리 면을 바꾸며, 서로 다른 크기와 위치의 보라 독 거품을 직접 찍었다. 몸 전체의 색조 변환은 없다.
- stun_a/b: 목이 어깨 아래로 처지고 앞가슴을 좁힌 넓은 지지 자세. 얼굴·목과 두 별 군집 위치를 각각 바꿨다.
- sleep_a/b: y=28부터 안정되게 웅크린 껍질과 앞발에 기댄 얼굴을 별도로 그렸다. 접힌 발과 꼬리를 두 프레임에서 유지하고 등·턱·가슴 면의 작은 군집으로 숨을 표현했다. 죽음의 낮게 무너진 실루엣과 구별된다.

## 실제 이미지 확인과 직접 교정

render_source.py는 격자를 그대로 PNG로 디코드하고, 같은 17색과 투명 인덱스로 GIF를 만든다. 예술 픽셀을 생성하거나 원본을 고치지 않는다. 진단 그림의 확대는 최근접이며 최종 PNG·GIF는 원래 크기이다.

확인한 그림:

- preview/sheet-native.png: 18자세 원본 1배.
- preview/sheet-light.png, sheet-dark.png, sheet-checker.png: 같은 원본의 최근접 4배와 세 배경.
- preview/*-gif-frames.png: 실제 8종 GIF를 다시 열고 디코드한 전 프레임의 최근접 3배. 순서와 저장된 노출 시간을 표시했다.

직접 고친 위치(좌표는 0부터):

1. 기본 자세의 먼 앞다리가 실처럼 읽히던 x=44..51, y=49..55를 굵은 g/v 면과 발끝 a 군집으로 다시 적었다. x=21..27, y=52..55에는 배 밑에서 이어지는 먼 뒷발의 경계를 찍었다.
2. idle_b의 처음 눈/턱 수정에서 불필요한 돌출이 생겼다. y=35..39는 본래 얼굴 행으로 돌리고 y=40..42와 앞어깨 y=50..51만 새 행으로 적어 숨 변화와 턱 면을 정리했다.
3. idle_c에서 금빛 눈이 중복되던 부분을 제거했다. x=49..50, y=38은 얼굴색, x=49..50, y=39는 짧은 O 눈꺼풀로 직접 고쳤다. 원래 얼굴의 앞쪽 윤곽과 밝은 볼 면은 유지했다.
4. sleep_a/b의 눈은 x=46..48, y=51의 짧은 OOO 눈꺼풀이다. x=49..50의 얼굴색이 앞쪽 코/머리 경계와 눈꺼풀을 분리한다. 1배에서 열린 금빛 눈이 남지 않은 것을 확인했다.
5. 공격 GIF의 준비·전진·접촉·회수, 기술 GIF의 세 방패와 붕괴, 수면 두 프레임의 발·꼬리를 실제 GIF 디코드 그림으로 비교했다. 자동 연결·구멍 채우기를 적용하지 않았다.

## 남은 시각적 한계

먼 두 발의 근위부는 큰 껍질에 일부 가려지므로 1배에서 가까운 다리만큼 뚜렷하지 않다. 금빛 눈과 짧은 닫힌 눈꺼풀은 작은 군집이라 실제 화면의 배경에 따라 가독성이 달라질 수 있다. 수면 숨 변화는 의도적으로 작다. 8GIF는 자세 순서 미리보기이며 게임 안의 이동·피해·상태 적용을 검증한 영상은 아니다.

독립 검수자 호출이나 사용자 승인 기록을 만들지 않았다. 이 결과는 하네스의 실제 독립 검수와 사용자 판단을 위한 후보다. 저장소·게임 저장소·ledger·brief·다른 후보를 수정하지 않았다. 테스트·게이트는 실행하지 않았다.

# 금각사슴 — fifty-v1 직접 픽셀 저작

## 범위와 원본

이 후보의 `source/`만 작성했다. 처음에는 `source/poses/`가 비어 있었으며 새 금각사슴을 저작했다.
원본은 `palette.json`, `poses/*.pxgrid` 9장, `actions/*.pxgrid` 9장이다.
모든 pxgrid는 64행 × 64개의 리터럴 ASCII 기호이며 `.`은 투명이다.
16색 팔레트는 모든 자세에 공통으로 쓰고 알파는 0/255다.

첨부 `references/human-size.png`는 실제로 열어 작은 눈, 얼굴 앞쪽 여유, 넓은 명암 면과
64px에서의 가독성만 관찰했다. 참고 그림의 픽셀을 추출하거나 원본을 재배포하지 않았다.
사슴의 본체와 자세는 이 종의 외형·공격·금각섬 설명에서 새로 저작했다.

`author_pixels.py`에는 독립적인 자세별 좌표와 ASCII 가로 문자열, 수정 전 문자열 및
직접 고른 수정 행/좌표가 남아 있다. 빈 캔버스에 그 문자열을 기록하는 것만 수행한다.
도형/수식 본체, 자동 명암, 프레임 이동·회전·보간, 다른 종 복제, 자동 구멍 채우기는 없다.
최종 그림의 정본은 완전한 리터럴 행으로 저장된 pxgrid다.

## 실루엣과 재질

- 작은 갈색 사슴, 오른쪽을 보는 3/4 얼굴, 두 뿔의 세 갈래 가지와 검은 네 발굽.
- 기본 자세의 본체/뿔 범위는 x6–59, y4–60. 눈은 `idle_a`의 (51,26)에 한 점으로 둔다.
- 왼쪽 위 광원: 넓은 `h/t` 엉덩이·등·목 면, `b/B/D` 아래쪽과 먼 다리의 털 그림자.
- 흰 털의 `w/c/s` 면은 턱 밑→목→가슴→배로 이어진다. 배의 색 경계는 완만하게 내려간다.
- 뿔은 `Y/G/g`의 가느다란 방향성 반사, 털은 넓고 부드러운 색 덩어리로 구분한다.
- 검은 발굽은 `O/K`. 안정 대기의 가까운 두 발은 y60, 먼 두 발은 y59에 닿는다.

## 자세별 직접 변화

| 자세 | 실제 배열의 변화 |
| --- | --- |
| idle_a/b/c | 발은 고정. 귀 각도, 1–2px의 턱/눈 위치, 흰 가슴의 폭, 꼬리와 숨 면을 바꿈. |
| windup | 어깨와 몸통을 낮춤. 뒷발을 뒤에 받치고 앞쪽 관절을 접어 다리 간격을 좁힘. |
| move | 몸통을 길고 높게 펴며 뒤 지지발은 왼쪽 끝까지 밀고 앞다리는 오른쪽으로 뻗음. 먼 다리는 골반/어깨에서 이어진 채 들어 올림. |
| attack | 머리와 뿔을 앞으로 낮춤. 뒷다리의 긴 밀기, 기울어진 가슴과 앞발 관절로 들이받는 무게를 표현. |
| recover | 뿔/머리를 다시 올리고 몸통과 다리를 회수. 완전히 접지한 idle_a로 마무리. |
| hit | 목과 얼굴을 뒤로 물리고 눈 위의 어두운 표정, 기울어진 어깨, 앞다리 꺾임을 별도 저작. |
| dead | 몸통·머리를 바닥에 눕힘. 두 점의 수평 닫힌 눈, 오른쪽으로 누운 뿔, 무너진 다리. |
| skill_a | 머리를 들고 뿔 끝에 5px 내외의 불규칙한 밝은 기를 모음. |
| skill_b | 어깨를 낮춰 버티고 뿔에서 오른쪽 위의 긴 번개와 오른쪽 중간의 짧고 굵은 번개를 발사. 각 갈래에 다른 길이와 짧은 가지를 찍음. |
| skill_c | 목을 다시 올려 회수. 오른쪽 위에서 뿔로 돌아오는 끊어진 빛 조각을 각각 직접 배치. |
| poison_a/b | 처진 턱과 아픈 눈, 앞다리가 꺾였다가 안쪽으로 회수되는 자세. 독 방울은 위치·크기·안쪽 빈칸을 다르게 찍음. |
| stun_a/b | 낮게 처진 목과 닫히는 눈, 흔들리는 앞 무릎. 큰 별/작은 별의 위치와 크기를 서로 바꿈. |
| sleep_a/b | 죽음보다 높은 안정적인 웅크림, 접은 네 다리와 닫힌 눈. 발/뿔은 고정한 채 등/가슴/흰 목의 숨 면만 변화. |

## 그림을 열고 고친 좌표

좌표는 0부터 센다. 아래는 자동 진단 결과를 채우기로 연결한 것이 아니라,
실제로 열린 확대/원본 PNG에서 보고 각 색 또는 가지 배열을 직접 고른 수정이다.

- 대기/기술 준비·회수: y48–59의 다리 행을 새로 골라 먼 발 두 개를 길게 내려 y59에 접지시켰다.
  앞쪽의 먼 발 x32–35와 가까운 발 x38–41이 각각 읽히게 했다.
- `idle_a`: 귀/뿔 뿌리 (39,21), (41,22), (48,21), 골반의 (23,47)을 갈색·그림자로 이어 붙였다.
  `idle_b/c`, `skill_a/c`도 자기 귀/골반 좌표를 별도로 명시했다.
- `windup`: (40,25), (42,26), (44,27)의 귀 밑과 (33,51)의 앞다리 뿌리를 직접 교정했다.
- `move`: (42,23), (43,24), (45,25)의 귀 뿌리. `attack`: (45,31), (46,32)의 귀 밑.
- `recover`: y7–24의 뿔 가지를 다시 골라 닫힌 고리처럼 보이던 실루엣을 열린 갈래로 바꿨다.
  (38,21)의 귀 뿌리, (23,46)/(36,47)의 다리 뿌리도 직접 이어 붙였다.
- `hit`: (30,22), (32,23), (39,22)의 귀/얼굴 연결을 갈색 면으로 교정했다.
- `dead`: y30–46을 명시적으로 다시 저작하여 머리 위로 솟던 뿔을 낮게 누웠다.
- `poison_a/b`: y10–28의 뿔을 열린 가지로 다시 저작. 금색 줄기의 (33,20), (41,24), (42,25)를 직접 연결하고
  (18,47)의 뒷다리 뿌리를 그림자로 마무리했다. 독 방울 안 (52,45)/(58,42)의 투명 한 칸은 의도한 빈칸이다.
- `stun_a/b`: (18,48)의 골반 연결. `stun_a` (36,30)의 귀 밑도 교정했다.
- `sleep_a/b`: y16–33의 뿔을 열린 가지로 다시 저작하고 (36,26), (44,30), (45,31)의 금색 줄기를 직접 마무리했다.
- `skill_c`: y11–21의 빛 조각을 세로 줄에서 뿔 쪽으로 굽는 깨진 경로로 직접 바꿨다.
- `skill_b`의 (54,26)은 갈라지는 빛 내부의 의도한 투명 한 칸이다.

## 확인 자료

`previews/`에 자세별 native PNG, 기본/추가 3×3 투명 시트, 18자세 확인 시트가 있다.
밝은/어두운/체커 배경의 1배와 최근접 4배를 생성하고 실제 파일을 열어 보았다.
8동작의 GIF를 만들고 자세 순서/시간 라벨이 있는 `*-sequence.png`를 열어
기본 실루엣, 관절 연결, 뿔·가슴 변화와 준비→접촉→회수의 프레임 변화를 확인했다.
GIF 파일도 열었다. 이미지 뷰어는 정지 대표 프레임을 표시하므로 연속 자세 판단은
전 프레임 시퀀스와 각 프레임의 PNG를 함께 사용했다.

`render.py`는 격자 해독, PNG 저장, 확인판의 최근접 확대/라벨, 명시적 시간표로 GIF 저장만 한다.
GIF 팔레트는 원본 RGB를 그대로 쓰며 각 GIF를 재읽어 보이는 픽셀과 알파, 저장된 노출 시간을 기록한다.
실제 파일에서 계산된 격자 SHA-256과 GIF 디코딩 결과는 `previews/decode-report.json`에 남긴다.
`inspect_pixels.py`의 연결/빈칸 진단은 읽기 전용이며 그 결과로 도트를 수정하지 않는다.
최종 그림에서 본체는 각 자세마다 하나의 8방향 연결 덩어리다. 떨어진 덩어리는 의도한 별/방울/빛 조각이다.
다리 사이 큰 투명 공간은 유지했다.

## 남은 표현 한계와 검토 상태

- 64px에서 먼 다리는 3px 폭으로 가늘고, 어두운 배경에서는 검은 발굽과 경계가 약하다.
- 두 금뿔이 겹치는 자세에서는 먼 뿔의 세 번째 가지가 일부 가려진다.
- 등은 넓은 면을 우선해 윤곽이 다소 평평하다. 작은 사슴의 말랑한 털 질감은 색 덩어리로만 표현했다.
- 독/기절 두 프레임은 비교적 큰 앞다리 변화가 있어 반응이 뚜렷하다. 느린 상태 리듬에 맞는지는 사용자 검토 대상이다.
- 돌격/기술은 제한된 원본 자세 사이를 잇는 미리보기다. 실제 게임의 이동 거리·접촉·피해·카메라를 검증한 전투 영상은 아니다.

18자세를 갖춘 **검토 후보**다. 사용자 승인 또는 독립 검수 통과를 선언하지 않는다.
독립 검수/선택은 하네스가 진행한다. 테스트/게이트, 정본 저장, 팩 설치는 실행하지 않았다.

# 금각사슴 GIF 시간표

원본 셀 64×64, 알파 0/255, 오른쪽을 보는 적. 단위는 ms.
모든 GIF는 `source/previews/`에 있으며 아래 순서를 그대로 저장했다.
`loop=0`은 검토용 무한 반복, `disposal=2`는 매 프레임 투명 바탕으로 복원한다.
프레임 생성·보간·전체 이동 없이 명시된 pxgrid를 노출한다.

| GIF | 순서와 유지 시간 | 합계 |
| --- | --- | --- |
| idle.gif | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 | 960 |
| attack.gif | idle_a 260 → windup 180 → move 110 → attack 150 → recover 180 → idle_a 320 | 1200 |
| hit.gif | idle_a 260 → hit 240 → recover 160 → idle_a 380 | 1040 |
| dead.gif | idle_a 260 → hit 180 → dead 1000 | 1440 |
| skill.gif | idle_a 240 → skill_a 320 → skill_b 180 → skill_c 280 → idle_a 320 | 1340 |
| poison.gif | poison_a 440 → poison_b 440 | 880 |
| stun.gif | stun_a 480 → stun_b 480 | 960 |
| sleep.gif | sleep_a 620 → sleep_b 620 | 1240 |

## 攻撃 / 돌격

`windup`에서 몸과 어깨를 낮춰 뒷발을 받치고 앞 관절을 접는다.
`move`에서 뒷발 밀기와 긴 앞 보폭을 보인다. `attack`의 낮아진 뿔을 접촉 자세로 150ms 유지한다.
`recover`는 네 발 회수 과정이며 최종 `idle_a`에서 네 발 접지가 완성된다.
여기서 유지하는 접촉은 그림의 박자이며 게임의 실제 피해 판정이 아니다.

## 금각섬의 뿔 앵커

좌표는 각 원본 프레임의 0 기준 좌표다. 손/무기는 없는 짐승이며 실제 발사 부위는 뿔이다.

- **모으기 `skill_a`:** 가까운 뿔 맨 위 (44,4) 부근, 오른쪽 가지 끝 (52,8) 부근.
  작은 불규칙한 `E/Y/G` 기가 뿔의 `Y/G/g` 줄기에서 이어진다. 목은 준비 자세에서 위로 올라간다.
- **발사 `skill_b`:** 낮춘 머리 위 y30–34의 뿔 뿌리가 본체와 이어진다.
  윗 갈래는 (46,19) 부근에서 x59–62/y8–15의 오른쪽 위 끝으로 뻗는다.
  아랫 갈래는 (45,29) 부근에서 x56–62/y21–33으로 뻗는다.
  위쪽은 길고 비스듬하며 아래쪽은 짧고 굵게 갈라진다. 중앙에서 길이를 달리한 작은 가지도 찍었다.
  (54,26)의 빈 한 칸은 갈라진 빛의 안쪽 공간이다.
- **회수 `skill_c`:** 머리/뿔이 다시 올라온다. 조각은 x59–60/y5–7,
  x55–56/y11–13, x54–55/y16–18에서 뿔 쪽으로 돌아오고 (52,20–21)에서 뿔 가까이 잦아든다.
  끊어진 조각은 의도적으로 분리되어 있으며 본체 전체 이동이나 원형 오라가 아니다.

## 상태이상

- 독: 아픈 턱/눈과 앞 관절을 바꾸고 방울을 오른쪽으로 흩뿌린다. 두 프레임은 본체와 방울이 모두 다르다.
- 기절: 처진 목을 유지하며 앞 무릎의 흔들림과 크기/위치가 달라지는 별을 480ms 박자로 보인다.
- 수면: 접은 다리와 닫힌 눈은 고정하며 등의 높이·가슴의 흰 면을 천천히 부풀린다.
  죽음의 낮고 수평적인 얼굴/몸통과 다른 웅크린 자세다.
- 쓰러짐 GIF의 마지막 자세는 1000ms 머물다가 검토 편의를 위해 다시 시작한다.
  게임의 죽음 상태에서 되살아나도록 지시하는 시간표가 아니다.

`render.py`의 `TIMELINES`가 실제 저장 순서이며 `previews/decode-report.json`은 GIF를 다시 읽은
각 프레임의 시간과 원본 가시 RGBA 일치 여부를 기록한다.

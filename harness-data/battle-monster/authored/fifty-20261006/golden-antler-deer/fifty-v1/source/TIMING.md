# 금각사슴 — 8GIF 시간표와 접촉 앵커

원본 셀은64×64, 알파0/255, 오른쪽을 보는 적이다. 단위는ms.
기존 GIF 박자를 보존하고 수정한 리터럴 자세를 같은 순서에 넣었다.
전체 프레임의 이동/회전/보간 없이 원본 pxgrid를 노출한다.
`loop=0`은 확인용 무한 반복, `disposal=2`는 프레임마다 투명 바탕으로 복원한다.

## 돌진

- 준비180ms: 낮춘 어깨, 접힌 앞 관절, 뒤 지지발.
- 전진110ms: 뒤에서 밀어 낸 긴 보폭과 앞으로 편 목.
- 접촉150ms: x47–54/y30–32의 뿔 뿌리에서 (62,28)까지 이어지는 금색 가지가 접촉 앵커다.
  코의 최우측은 x60이므로 뿔이 2px 먼저 닿는 실루엣이다. 눈은(51,35).
  낮은 몸과 버티는 앞다리를 유지한다.
- 회수180ms: 뿔/머리를 들고 앞발을 몸 아래로 회수한다.
  이어지는 idle_a320ms에서 가까운 두 발y60, 먼 두 발y59의 안정 접지가 완성된다.

이 앵커는 그림의 위치이며 런타임 피해 판정이나 상대 위치를 지정하는 데이터가 아니다.

## 금각섬 — 실제 발사 부위는 뿔

사슴은 손/무기가 없는 짐승이다. 목과 귀에 이어진 뿔이 준비와 발사의 원점이다.
각 프레임의 좌표는0부터 센다. 세 자세 모두 전체 본체를 포함한다.

- `skill_a`,320ms: 가까운 뿔 끝(44,4) 부근에서 작고 불규칙한 `E/Y/G` 기를 모은다.
  오른쪽 가지 끝은(52,8) 부근이다. 얼굴/가슴은 위로 들린 준비 자세다.
- `skill_b`,180ms: y30–34의 뿔 뿌리와 머리가 연결된 채 두 갈래를 발사한다.
  긴 위쪽 갈래는(46,19) 부근에서 x59–62/y8–15로 뻗는다.
  짧고 굵은 아래쪽 갈래는(45,29) 부근에서 x56–62/y21–33으로 뻗는다.
  두 갈래는 길이·굵기·작은 분기의 배열이 다르며 창백한 핵과 금색 가장자리를 갖는다.
  (54,26)의 빈 칸은 갈라진 빛 안쪽의 의도한 공간이다. 본체는 앞발로 버틴다.
- `skill_c`,280ms: 목과 뿔을 다시 올린다. 금빛 조각은 x59–60/y5–7,
  x55–56/y11–13, x54–55/y16–18에서 끊어져 있고 (52,20–21) 부근에서 잦아든다.
  서로 분리된 잔상과 본체 회수이며 같은 원형 오라의 크기 변형이 아니다.

## 상태 동작

- 독440/440ms: 아픈 눈/턱, 꺾이거나 회수하는 앞 관절, 서로 다른 독 방울 배열.
  b의 작은 방울은 얼굴에서 분리된 x55–56/y33–34에 있다.
- 기절480/480ms: 처진 목과 닫히는 눈, 무릎 흔들림. 큰 별/작은 별의 위치와 크기가 달라진다.
- 수면620/620ms: 닫힌 눈, 안정된 웅크림과 접힌 네 다리. 등에 작은 높이 차이가 있고
  흰 목/가슴의 숨 면이 변한다. 바닥에 누운 죽음과 구별한다.
- 쓰러짐의 마지막1000ms 뒤 반복은 확인용 재생이다. 게임에서 되살리는 지시가 아니다.

`render.py`의 `TIMELINES`가 실제 저장 순서다. `previews/decode-report.json`은8GIF의
전 프레임을 다시 읽어 보이는 픽셀/알파와 노출 시간을 기록한다.
8GIF와 전 프레임 시퀀스 PNG를 실제 열었다. 뷰어는 GIF의 정지 대표 프레임을 표시하므로
실시간 전투의 자연스러움이나 타깃 접촉을 승인하지 않는다. 독립 검수/선택은 하네스 담당이다.

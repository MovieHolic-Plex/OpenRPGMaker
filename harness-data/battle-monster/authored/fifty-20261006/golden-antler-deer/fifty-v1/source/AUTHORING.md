# 금각사슴 — 얼굴·가슴의 3/4 면과 뿔 돌진 수정

## 작업 범위와 보존

기존 `fifty-v1`의 18자세를 고친 후보다. 이 작업의 쓰기는 `source/` 안에서만 수행했다.
원안의 9개 기본 자세, 9개 기술·상태 자세, 팔레트, 저작 보조 코드와 문서는
`original-before-three-quarter-repair/`에 수정 전 그대로 보존했다.
현재 원본은 `poses/*.pxgrid` 9장과 `actions/*.pxgrid` 9장이다. 모두 64×64의 완전한
리터럴 ASCII 행이다. `palette.json`의 16색은 수정 전 파일과 바이트 단위로 동일하다.

첨부 `reference.png`와 `references/human-size.png`를 실제로 열어 보았다.
현재 사슴 시트에서는 뿔/털/흰 목의 정체성과 좋은 자세를, 검객 그림에서는
64px의 얼굴 여유와 넓은 명암 면을 관찰했다. 참고 그림을 추출·추적·리샘플하지 않았다.
참고 이미지 바이트는 이 source에 복사하지 않았다.

## 직접 고른 수정

### 1. 얼굴의 가까운 면과 먼 면

원안의 한 점 눈과 길게 이어진 옆얼굴을 수정했다. `idle_a` 기준 좌표는 다음과 같다.

- y24–32, x37–59: 이마/볼/주둥이/턱의 ASCII 문자열을 다시 골랐다.
- 가까운 눈은 (48,27)의 `O`, 눈썹은 (46,26)의 `B`다. 먼 눈은 (54,26)의 작은 `K`다.
  눈 높이를 달리하고 눈 사이에 밝은 콧등 면을 남겼다.
- y28–31의 `h/t` 볼 면과 `c/w/s` 턱 면이 서로 비껴 이어진다. 가까운 볼은
  주둥이 바로 밑으로 내려오며, (57,29)–(58,29)의 검은 코 면은 오른쪽 끝에 있다.
- 먼 얼굴의 갈색 그림자와 가까운 크림색 턱은 서로 다른 폭으로 마무리했다.
  얼굴 전체를 이동하거나 회전해서 만든 변경이 아니다.

대기 b/c, 준비, 이동, 회수, 피격과 기술·상태 자세에서도 각 자세의 별도 행과
좌표를 고른다. 닫힌 눈이 필요한 쓰러짐/기절/수면은 기존 표정의 성격을 유지했다.

### 2. 가슴의 정면 면과 앞다리의 깊이

`idle_a`의 y33–43, x31–48을 수정했다. 어깨의 넓은 `h/t` 면이 목에서 이어지고,
(41,39)을 포함한 앞가슴의 `w` 면은 옆배보다 넓다. 가슴 오른쪽은 `c/s`로 돌아가며
턱 아래부터 배까지 의도 없는 투명 홈 없이 이어진다.

가까운 앞다리 뿌리는 y44–48에서 밝은 `h/t/b` 면으로 앞으로 나오고,
먼 앞다리 뿌리는 `D/B` 면으로 안쪽에 놓았다. 안정 대기의 가까운 앞발은 x38–42/y60,
먼 앞발은 x33–36/y59다. 뒷발 두 개의 좋은 실루엣은 보존했다.
다리 사이의 큰 투명 공간도 보존했다.

다른 자세의 낮아진 어깨와 굽은 앞 관절 역시 그 자세별 문자열로 수정했다.
뒷다리의 밀기, 이동 자세의 긴 보폭, 피격의 꺾인 무릎은 유지했다.
본체·그림자·다리 연결을 수식으로 생성하거나 연결 검사로 채우지 않았다.

### 3. 앞으로 뻗는 뿔 돌진

`attack`의 y20–33 뿔과 y34–48 머리/목/가슴 행을 직접 다시 골랐다.
원안의 y20 위쪽으로 솟는 끝은 지우고, y24–31에서 오른쪽으로 갈라지는 가지를 저작했다.

- 뿔 뿌리는 x47–54/y30–32에서 귀와 두개골에 이어진다.
- 앞쪽 타격 가지는 (62,28)까지 뻗는다. 위쪽 가지는 x60–61/y24에서 끝난다.
- 가까운 눈은 (51,35)에 있고, 코는 (58,36)–(59,36)이다.
  주둥이의 최우측 윤곽은 x60이며 뿔 끝 x62보다 뒤에 있다.
- 원안의 눈 부근 (46,37)에 비해 머리의 읽히는 표정과 목을 앞으로 연결했다.
  낮은 몸통과 뒤 지지발의 긴 밀기, 버티는 앞다리는 보존했다.
- 확대 그림에서 뿔 사이에 닫힌 금색 고리처럼 보이던 두 칸을 확인했다.
  y28의 (54,28)/(55,28)을 투명으로 직접 골라 두 가지가 열린 틈으로 보이게 했다.
- 마지막 확인에서는 주둥이가 뿔 끝과 같은 x까지 나와 보였다. y35의 x58–60과
  y36의 x58–60을 다시 골라, 뿔이 코보다 2px 먼저 닿는 외곽으로 마무리했다.

`move`의 올라온 목/긴 보폭 → `attack`의 전진한 머리/낮은 뿔 → `recover`의 들린
목/회수하는 앞발로 읽히게 했다. 개별 클러스터 수정이며 전체 프레임 변형이 아니다.

## 18자세의 범위

| 자세 | 이번 수정과 보존한 동작 |
| --- | --- |
| idle_a/b/c | 비껴 보이는 두 눈, 볼/턱 면, 넓은 앞가슴, 가까운/먼 앞다리 뿌리. 기존 숨 변화와 귀/꼬리 차이를 보존. |
| windup | 낮은 어깨의 밝은 면과 앞가슴의 깊이, 접힌 앞다리 뿌리. 뒤 지지발 보존. |
| move | 뻗은 목에 새 얼굴/가슴 면, 앞 관절 깊이. 뒤 밀기와 긴 보폭 보존. |
| attack | 앞으로 뻗는 머리와 열린 수평 성격의 뿔 가지. 낮은 몸과 버팀다리 보존. |
| recover | 올라온 목의 새 볼/가슴, 앞다리 회수 면. 기존 들린 먼발과 뿔 보존. |
| hit | 뒤로 물린 얼굴의 눈썹/볼, 기울어진 가슴/앞 관절. 반동 실루엣 보존. |
| dead | 바닥에 누운 얼굴의 닫힌 눈, 비껴 보이는 턱/목 면. 낮은 몸과 누운 뿔/다리 보존. |
| skill_a | 들린 머리의 볼/가슴/앞다리 면. 작은 뿔 끝의 준비 불꽃 보존. |
| skill_b | 숙인 얼굴의 찡그린 눈/볼과 버티는 가슴/앞다리. 뿔에서 나가는 서로 다른 두 번개 갈래 보존. |
| skill_c | 다시 올린 얼굴/가슴/다리 면. 원안의 분리된 금빛 잔상 보존. |
| poison_a/b | 아픈 눈과 턱/가슴의 면, 다른 앞다리 자세 보존. b의 작은 독 방울만 새 볼과 분리. |
| stun_a/b | 닫히는 눈/처진 볼과 앞가슴의 면. 꺾인 무릎과 서로 다른 별 위치/크기 보존. |
| sleep_a/b | 닫힌 눈과 가까운 볼/흰 목의 면. 웅크린 다리와 서로 다른 등/가슴 호흡 면 보존. |

`poison_b`를 확대했을 때 기존 작은 방울 x52–53/y37–38이 넓어진 얼굴과 붙어 보였다.
그 네 픽셀을 직접 지우고 x55–56/y33–34에 `pP / pp`를 다시 찍었다.
큰 방울과 의도한 방울 속 빈칸은 유지했다.

## 보조 코드와 재현

- `author_pixels.py`: 원안의 직접 저작 문자열 및 이전 보정 기록을 유지한다.
  실행 끝에는 이번 수정의 `repair_three_quarter.apply()`를 호출한다.
- `repair_three_quarter.py`: 18자세 각각의 리터럴 좌표/ASCII 문자열 표.
  보존한 원안을 읽고 표에 적힌 픽셀만 기록한다. 최종 pxgrid는 완전한 64행이다.
- `render.py`: pxgrid 해독 → native PNG/시트 → GIF 저장 및 GIF 재읽기.
  최근접 확대와 배경/라벨은 확인판에서만 사용한다.
- `compare_repair.py`: 원안/수정본의 1배+4배 비교 PNG와 변경 수/범위를 기록한다.
- `inspect_pixels.py`: 읽기 전용 연결/투명 진단. 원본을 수정하지 않는다.

도형 마스크, 수식 명암, 이미지 생성, 전체 프레임 이동/회전/보간, 자동 구멍 채우기는
이번 수정 과정에 사용하지 않았다. 코드는 직접 고른 픽셀을 기록하거나 읽는 보조다.
격자/해시/진단만으로 저작 방식의 독립 증명이나 미감 승인을 주장하지 않는다.

## 실제로 연 확인 자료

밝은/어두운/체커 배경의 18자세 1배 시트와 최근접 4배 시트를 실제로 열었다.
`idle_a-comparison.png`, `attack-comparison.png`의 원안/수정본도 열었다.
8개 GIF 파일을 열고 8개의 `*-sequence.png`에서 전 프레임의 연결부와 변화 순서를 보았다.
이미지 뷰어의 GIF 출력은 정지 대표 프레임이므로 연속 동작의 시간적 인상은
GIF 파일을 제공하되 여기서는 전 프레임 시퀀스와 저장된 노출 시간으로 확인했다.

현재 파일 측정에서 18자세 모두 64행/행폭64이고 1px 테두리는 투명하다.
`idle_a`의 가까운 앞/뒤 발은 정확히 y60에 닿으며 모든 자세의 최하단은 y60 이하이다.
본체는 각 자세마다 하나의 8방향 연결 덩어리로 관찰된다. 독/별/회수 빛 조각의 분리는 의도적이다.
몸 안의 의도 없는 사각 투명 홈은 현재 열어 본 그림과 읽기 전용 진단에서 발견하지 못했다.
남아 있는 enclosed transparency는 독 방울 속 (52,45)/(58,42)와 기술 갈래 사이 (54,26)이다.

8GIF를 다시 읽어 각 프레임의 보이는 RGB/알파가 native PNG와 일치하고 노출 시간이
시간표와 같은 것을 기록했다. 결과는 `previews/decode-report.json`에 있다.
`previews/repair-report.json`에는 실제 변경 수/범위, 캔버스 폭, 테두리와 최하단 측정이 있다.
PNG: `suite-native.png`(192×384), `poses-native.png`와 `actions-native.png`(각192×192).
`previews/index.html`에서 8GIF를 1배/4배로 함께 볼 수 있다.

## 남은 시각적 한계와 검수 상태

- 64px에서 먼 눈은 한 점, 가까운 볼/코 면은 몇 픽셀이다. 작은 표시에서는 두 얼굴 면의
  구분이 약해질 수 있다. 몸통은 여전히 긴 옆구리 면을 많이 보여 주는 완만한 3/4 방향이다.
- 가는 먼 다리와 검은 발굽은 어두운 배경에서 대비가 낮다. 뿔이 겹치는 자세에서는
  먼 뿔의 작은 가지가 일부 가려진다.
- 접촉 뿔은 오른쪽 x62까지 사용한다. 셀 안에서 더 긴 전방 효과를 넣을 여유는 작다.
- 준비/이동/접촉/회수는 4개의 핵심 자세라 높이 변화가 분명하다. 실제 전투 중 목표와의
  거리, 미끄러짐, 접촉 및 피해 시점은 이 source 작업에서 확인하지 않았다.

이 작업은 해당 종의 원본 수정과 확인 자료 저장까지다. 사용자 승인이나 독립 검수 통과를
기록하거나 주장하지 않았다. 별도 검수자를 호출하지 않았으며 검수 결과/원장/brief/게임 저장소를
변경하지 않았다. 테스트·게이트는 실행하지 않았다. 현재 원본에 대한 독립 검수는 하네스가 맡는다.

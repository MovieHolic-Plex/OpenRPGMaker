# 황금이삭귀 — fifty-v1 저작 기록

## 범위와 원본

이 후보의 `source` 안에서만 저작했다. 외부 그림은 64px 검객 참고를 실제로 열어 얼굴 앞쪽 여유, 작은 눈, 손과 무기의 연결을 관찰했다. 참고 그림의 픽셀을 추출하거나 복제하지 않았다.

- `palette.json`: 투명 점을 제외한 16색. 검갈색 윤곽, 갈색 짚 본체, 황금색 모자·어깨·발·이삭, 붉은 허리끈, 독의 보라색과 작은 녹색 잔방울.
- `poses/*.pxgrid`, `actions/*.pxgrid`: 각각 96행 × 96문자, 완전한 최종 ASCII 원본. 총 18자세.
- `native.rows`: 각 자세를 따로 고른 리터럴 가로 픽셀 문자열과 실제 좌표. 같은 머리·복식의 유지 부분도 각 자세에 명시했다. 전체 프레임 이동·회전·보간으로 자세를 만들지 않았다.
- `corrections.rows`: 실제 PNG 관찰 후 지목한 위치의 짧은 문자열 교정. 자세마다 대응 위치를 따로 적었으며 자동 전파·구멍 채우기를 하지 않았다.
- `first-block.rows`: 최초 대기 습작 보존. 최종 후보에는 사용하지 않는다.
- `author.py`: 빈 캔버스에 위 문자열을 전사하여 완전한 행 파일을 저장한다. 신체나 명암을 계산하지 않는다.
- `render.py`: 원본 픽셀을 PNG와 같은 팔레트의 투명 GIF로 해독한다. 확대는 검토용 최근접 표시뿐이다. GIF 효과도 원본에 적힌 픽셀이다.
- `inspect.py`, `inspection.json`: 파일 크기·알파·실제 해시·연결 덩어리 등 읽기 진단. 시각 합격이나 사용자 선택을 나타내지 않는다.

## 외형과 재질

오른쪽을 보는 3/4 작은 짚 요괴다. 비대칭으로 솟은 볏짚 모자, 모자 아래의 작은 검은 눈과 앞으로 나온 볼, 실제 갈색 목, 두 황금 어깨 덮개, 묶은 갈색 몸과 굵은 팔다리, 붉은 매듭을 남겼다. 왼쪽 위의 넓은 밝은 면과 오른쪽 아래의 갈색/황토 그림자 면을 사용했다. 모자 사선의 짚 결, 불규칙한 아래 술, 몸통과 다리의 짧은 짚 결을 별도로 골랐다.

이삭손은 가까운 오른쪽 어깨에서 위팔 → 팔꿈치 → 아래팔 → 손바닥으로 이어진다. 여러 이삭 줄기는 손 위에서 모이며 한 자루가 파지와 손 아래까지 이어진다. 반대 팔은 허리의 보조 손, 독의 턱/배를 누르는 손, 기절의 늘어진 손, 수면의 무릎 위 손으로 구별했다.

## 실제 수정

1. 첫 습작에서 모자와 몸이 좁고 이삭팔이 분리되어 보였다. 대기 원본 전체를 직접 다시 썼다. 최초 습작은 `first-block.rows`에 남겼다.
2. 18자세 밝은 확대판과 1배에서 대기 3자세, 회수, 기술 준비/발사의 어깨 틈을 발견했다. 예를 들어 `idle_a`의 `(48,48)`부터 `(59,57)`까지 각 행의 위치를 따로 지정해 어깨 덮개와 위팔 면을 잇고 기존 아래팔로 연결했다. 다른 자세도 자신의 실제 어깨 좌표를 별도로 고쳤다.
3. `dead`의 어깨와 가슴이 너무 평평했다. `(45,77)`부터 `(42,89)` 사이의 실제 행을 직접 다시 찍어 황금 어깨, 갈색 목·가슴, 바닥의 팔을 나눴다. 접힌 먼 다리와 가까운 다리·황금 발의 경계를 유지했다.
4. `skill_b`의 `(55,50)`, `(56,51)`, `(57,52)`에서 팔꿈치 아래의 여분 돌기를 지우고 압축된 관절 면을 직접 남겼다. 실제 파지 아래의 자루는 유지했다.
5. `move`와 `attack`의 뒤쪽 허벅지는 각각 y69–75와 y72–78의 실제 위치에서 밝은 갈색 면을 넓혔다. 긴 사선의 가는 연결선으로만 보이지 않도록 했다.
6. 수면 이삭 아래의 불필요한 가로 잔줄 `(77,87)`에서 10픽셀을 직접 지웠다. 손 위의 단일 자루와 실제 이삭 팬은 유지했다.
7. 수면 얼굴의 눈 위 어두운 모서리가 열린 눈처럼 보였다. 두 수면 자세 모두 `(50,58)`의 면을 밝은 얼굴색으로, `(50,59)`를 짧은 수평 `KKK` 눈꺼풀로, `(50,60)`을 얼굴색으로 직접 바꿨다. 코는 오른쪽 별도 군집으로 남겼다. 쓰러진 얼굴도 자기 좌표에서 짧은 닫힌 눈을 찍었다.

## 동작 구별

- 대기: 양 발을 고정하고 어깨/가슴의 부피, 모자의 미세한 기울임과 이삭손의 관절 위치를 각각 바꿨다.
- 공격: 같은 이삭손을 뒤로 접는 준비 → 뒤 발을 밀고 앞 지지발을 내는 전진 → 어깨와 팔꿈치를 펴 이삭을 앞에 휘두르는 접촉 → 넓은 발 자세를 좁히며 회수.
- 피격: 뒤로 눌린 어깨, 찡그린 눈, 낮아진 손과 굽힌 무릎.
- 쓰러짐: 머리·목·두꺼운 가슴과 팔·접힌 두 다리가 바닥에 누웠다. 실제 신체가 y92에 닿는다.
- 풍년광: 이삭 끝의 모인 밝은 핵 → 위/앞/아래의 서로 다른 세 금빛 알갱이와 연결 통로 → 손을 아래로 내려 갈라지는 알갱이 잔상.
- 독: 턱 또는 배를 누르는 별도 보조 팔, 아픈 어깨·무릎, 서로 다른 독 방울.
- 기절: 머리와 팔이 늘어지고 이삭 끝이 아래로 처진다. 별 두 군집의 위치와 모양을 따로 바꿨다.
- 수면: 앉은 몸과 접힌 두 다리, 무릎의 이완된 손, 눕힌 이삭, 닫힌 수평 눈꺼풀. 두 자세는 같은 발/머리를 유지하며 가슴과 가까운 팔의 작은 숨 변화만 직접 찍었다.

## 시각 확인과 남은 한계

18자세의 밝은/어두운/체커 3배 판, 원본 1배 판, 얼굴 1배/7배 판을 실제로 열었다. 실제 생성 GIF 8개를 다시 디코딩한 동작 접촉판에서 순서와 원치 않은 튐을 비교했다. `previews/animation-contact.png`는 그 디코딩 결과다. 브라우저에서 실시간 재생을 관찰한 기록은 아니다.

모자의 높은 비대칭 꼭짓점은 특유의 실루엣이지만 짚 삿갓보다 뾰족한 모자로 읽힐 여지가 있다. 갈색 본체의 짚 결은 절제되어 있어 1배에서는 목재와 비슷하게 보일 수 있다. 기본 공격은 4개의 핵심 자세로 이루어져 준비→전진과 회수→대기의 변화가 빠르다. 추가 보간 그림은 만들지 않았다. 이는 현재 후보의 표현 한계이며 다음 독립 검수의 판단을 대신하지 않는다.

여기에는 독립 검수 결과, 사용자 승인 또는 하네스 게시 기록을 만들지 않았다. 모델 실행 정보는 하네스가 실제 호출 출처로 기록해야 하며 계약의 모델명을 실제 호출 증거처럼 꾸미지 않았다.

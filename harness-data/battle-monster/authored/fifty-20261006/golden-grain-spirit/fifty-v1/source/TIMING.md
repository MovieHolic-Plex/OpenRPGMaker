# 황금이삭귀 — 로컬 GIF 시간표

원본 96×96. 원본을 확대·회전·보간하지 않고 각 리터럴 자세를 그대로 사용한다. PNG는 투명 RGBA, GIF는 같은 팔레트를 직접 인덱싱하며 점을 투명 인덱스 0으로 둔다. 아래 값은 실제 저장된 GIF hold다.

| GIF | 순서 | 각 hold (ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240 / 260 / 120 / 140 / 240 / 360 |
| hit | idle_a → hit → recover → idle_a | 300 / 200 / 240 / 300 |
| dead | hit → dead | 200 / 1100 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 360 / 220 / 300 / 360 |
| poison | poison_a → poison_b | 460 / 460 |
| stun | stun_a → stun_b | 520 / 520 |
| sleep | sleep_a → sleep_b | 700 / 700 |

GIF들은 검토를 위해 반복한다. `dead` 반복의 피격 복귀는 검토 루프일 뿐 실제 게임에서 부활시키라는 지시가 아니다.

## 이삭손과 기술 발원점 (0-based native coordinates)

- 대기 `idle_a`: 가까운 어깨 약 (51,49), 팔꿈치 (65,57), 파지 (76,58). 같은 자루가 (76,60–65)까지 이어지고 세 갈래 이삭이 위 (77,36–44)에서 시작한다.
- 공격 준비: 같은 어깨에서 뒤로 접힌 팔꿈치 (49,57), 뒤로 모은 손 (32,61), 뒤 이삭 끝 (22,41). 보조 손은 몸 앞 가드다.
- 전진: 손 (63,54), 앞에 모은 이삭 끝 (61,39). 앞 지지발 y92, 뒤 밀기 발 y91.
- 접촉: 어깨 (68,51), 팔꿈치 (75,53), 파지 (82,53), 앞 이삭 접촉 끝 약 (91,42–53). 회수의 파지는 (77,58) 부근으로 낮아진다.
- `skill_a`: 파지 (72,47–49), 실제 이삭 끝의 핵 (76,30–33). 원형 몸 오라를 사용하지 않는다.
- `skill_b`: 파지 (67,41–43), 이삭 발원점 (79,26–28). 여기서 직접 저작한 세 길이 위 알갱이 (84,11–15), 앞 알갱이 (90,29–33), 아래 알갱이 (88,41–45)로 갈라진다. 각 알갱이는 다른 끝과 금빛 면/황토 껍질을 갖는다.
- `skill_c`: 손 (72,67–69), 이삭 끝 (69,81–85)으로 내린다. 오른쪽의 알갱이를 작은 껍질과 서로 떨어진 금빛 잔상으로 직접 깨뜨렸다. 발은 다시 굽혀 지지한다.
- 수면: 이삭손은 무릎 위 (68–71,83–85), 이삭은 몸 앞으로 눕혔다. 두 프레임의 머리·발과 닫힌 눈은 유지하고 가슴 면과 가까운 팔의 숨 변화만 남겼다.

`previews/animation-contact.png`에는 저장된 GIF를 재읽은 실제 프레임 순서와 hold를 표시한다. 애니메이션 프레임에 글자/라벨을 넣지 않았다. `render.py`의 시간표가 이 문서와 같다.

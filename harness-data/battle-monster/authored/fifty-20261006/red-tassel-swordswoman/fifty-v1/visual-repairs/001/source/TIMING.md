# 홍영검희 — PNG/GIF 시간표

원본은 64×64. 모든 GIF는 원본 팔레트를 그대로 넣고 확대 없이 저장한다.
투명 인덱스 0, 프레임 disposal=2, 반복 재생. 각 프레임의 노출은 아래 ms 값이다.
GIF의 실제 프레임을 다시 읽어 원본 RGBA와 대조한 뒤 시간표가 적힌 PNG 스트립으로 보았다.

| GIF | 원본 순서 | 각 노출 ms |
|---|---|---|
| idle.gif | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack.gif | idle_a → windup → move → attack → recover → idle_a | 240 / 180 / 110 / 140 / 180 / 260 |
| hit.gif | idle_a → hit → recover → idle_a | 260 / 220 / 180 / 340 |
| dead.gif | idle_a → hit → dead | 240 / 170 / 1000 |
| skill.gif | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 280 / 180 / 220 / 300 |
| poison.gif | poison_a → poison_b | 420 / 420 |
| stun.gif | stun_a → stun_b | 400 / 400 |
| sleep.gif | sleep_a → sleep_b | 650 / 650 |

모든 파일은 `preview/`에 있다. dead.gif의 반복 때 다시 일어나는 것은 검토용 루프의
재시작이다. 실제 죽음 상태는 마지막 dead 그림을 유지해야 한다.

## 홍영참 앵커 — 0 기반 x,y

- **준비 skill_a:** 가슴 앞 손 (40..42,33..35)과 금색 자루/가드 (41..44,32..34)가
  실제로 이어진다. 검 끝 (60,14), 날 위 주홍 핵은 (48..53,23..28)의 E/L 덩어리다.
  핵이 무기 주변에 모이는 280ms 준비를 준다.
- **시전 skill_b:** 오른손 (43,30)에서 자루 (44..46,28..30), 수평 은색 날
  (46..54,29)로 이어진다. 날 끝/효과 뿌리 **(54,29)**에서 위 검기는
  x=51..61,y=5..29로 꺾여 뻗고, 아래 검기는 x=45..61,y=30..51로 길게 내린다.
  위 끝의 짧은 갈래와 아래 끝의 끊어진 갈래는 다른 행 문자열이다.
  칼끝 접촉 핵심은 180ms 유지한다.
- **회수 skill_c:** 손 (43,40..41), 가드 (42..45,42), 낮은 검 끝 (57,55).
  위 잔기는 x=54..60,y=32..39, 아래 잔기는 x=53..60,y=46..52에서 부서진다.
  검과 소매를 거두는 220ms 회수 후 대기로 돌아간다.

## 공격 체중과 상태 루프

windup의 약간 넓힌 양발 → move의 뒤발 밀기와 크게 전진한 앞발 →
attack의 앞 무릎/손목/사선 날 → recover의 좁아진 보폭 순서다.
몸 전체를 자동 이동시키거나 중간 프레임을 합성하지 않는다.

독은 두 컷 사이 턱을 받치는 손·어깨·무릎과 기포의 위치/내용이 바뀐다.
기절은 처진 팔·손·눈선의 작은 변화와 두 별의 자리 변화다.
수면은 앉은 체형을 유지하며 가슴/소매/바지 면과 술을 직접 바꿔 숨을 표현한다.
상태 GIF는 다른 공격 프레임이나 색조 변환으로 대체하지 않았다.

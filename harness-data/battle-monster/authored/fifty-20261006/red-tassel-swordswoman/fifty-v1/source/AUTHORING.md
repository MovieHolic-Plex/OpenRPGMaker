## 현재 수정 — skill_b 전방 검손과 칼끝의 두 굽은 검기

첨부 시트와 human-size 참고 그림을 실제 열어 관찰한 뒤, 지적된 `skill_b`만
리터럴 ASCII 행과 명시 좌표 문자열로 다시 저작했다. 참고 픽셀을 추출하거나
복사하지 않았다. 작업 파일은 전부 이 후보의 `source/` 안에 있다.
아래 이전 기록은 당시 수정의 이력이며 현재 skill_b 앵커는 이 절과 TIMING.md다.

### 직접 바꾼 픽셀 — 좌표는 0 기반

- **옷깃과 검손 분리:** y=28..31의 목 옆 금색 가드/피부와 수평 날을 지우고
  목·흰 옷깃·진홍 저고리의 K/W/G/r/R 면을 직접 복원했다. 얼굴·목의 원래
  윤곽은 보존했다. 검손은 `(42..44,34)=FFF`, `(41..43,35)=SSs`로 앞으로 옮겼다.
  금색 손목 테 `(41,34)=g`, `(40,35)=G`가 소매와 손을 잇는다.
- **어깨→소매→팔꿈치→손:** `(34..37,32)=LLLL`의 윗어깨에서 y=33..35의
  넓은 L/r/R 소매를 앞으로 펼쳤다. 팔꿈치는 x=37..40,y=34..36에 두고,
  손 밑의 K 윤곽으로 닫았다. 첫 수정판에서 손 아래에 남은 불필요한 피부
  `(43..45,36)`를 직접 제거하고 그 행을 진홍 아랫소매와 어두운 윤곽으로 다시 썼다.
  y=37의 돌출 윤곽도 지워 팔 아래/허리 위의 의도한 빈 공간을 남겼다.
- **손→자루→검날:** 손 옆 자루 `(45,34)=D`, `(44,35)=D`가 가드
  `(42..45,33)=GgGG` 및 날 뿌리 `(44..46,32)=gGm`와 이어진다.
  은색 날은 y=12..31의 각 행에서 직접 고른 W/WM/WMm 계단이다.
  가드 부근 `(44,33)`에서 칼끝 `(54,12)`까지 약 23 native px의 사선 길이를
  유지했다. 옷깃 앞의 수평 날이 사라져 접힌 팔/활시위 조합을 해소했다.
- **두 검기:** 실제 은색 칼끝 `(54,12)=W` 바로 옆 `(55,12)=E`를 공통
  발생점으로 두었다. 짧은 위 검기는 x=55..62,y=3..11에서 앞으로 휘며
  `(61,3)=L`로 끝난다. 더 긴 아래 검기는 x=55..62,y=13..27에서 넓은
  E 핵과 L/r 가장자리를 가진 굽은 덩어리로 뻗고 `(59,27)=r`로 끝난다.
  발생점 밖의 두 검기 사이에는 투명 간격이 있고, 끝에서 다시 합쳐지지 않는다.
  처음의 가는 S선은 이 직접 선택한 넓은 덩어리로 다시 찍었다.

실제 원본 차이는 **403픽셀**, x=31..62,y=3..51이다. 기존 아래쪽 활 궤적을
지운 자리도 이 범위에 포함된다. 다른 **17자세와 18색 팔레트는 수정 전 바이트
해시와 같다**. 머리·얼굴·목·왼팔·허리·다리·발의 위치는 움직이지 않았다.
자동 프레임 변형, 도형/선 래스터화, 합성 명암, 자동 연결 보정이나 구멍 채우기는 없다.

`repair_skill_contact.py`는 직접 고른 좌표 문자열과 최종 **64행 전체 리터럴 원본**을
보존한다. `author_pixels.py`의 마지막에 이 전체 원본을 적용해 과거 수평 날로
돌아가지 않게 했다. 수정 직전 원본/PNG는 `history/skill_b-before-contact.*`,
전체 원본의 실제 수정 전 해시는 `history/before-contact-hashes.json`이다.
현재 원본/이미지 해시와 실제 픽셀 차이는 `preview/skill-contact-info.json`에 있다.
이 파일은 저작 진단 기록이며 하네스의 독립 검수 결과가 아니다.

독립 검수는 하네스가 맡는다. 검수자/저작 모델 정보를 새로 주장하거나 판정을
고치지 않았으며, 전부 통과했다는 선언이나 사용자 승인/Allow를 만들지 않았다.
테스트/게이트는 실행하지 않았다.

첨부 현재 시트와 human-size 그림을 실제 열어 관찰한 뒤, 요청된 두 자세의

- **skill_b:** 기존 날 x=46..53,y=29의 짧은 은색 면을 긴 검으로 다시 찍었다.
  쥔 손은 `(31..32,30)=FF`, `(31..33,31)=SSs`로 가슴 옆에 당겼다.

## 범위와 저작 방식

이 후보의 source 안에서 빈 원안부터 만든 64×64 인간형 18자세다. 최종 원본은
palette.json과 poses/9개, actions/9개의 **64행 × 64 ASCII 글자** pxgrid다.
점은 투명이며 팔레트에 없다. 18색, 불투명/투명 두 알파 값만 사용한다.
idle_a의 머리 끝 y=8, 양발 바닥 y=60: 실제 서 있는 키 53 native px.
주 머리는 약 20px, 노출 얼굴은 약 13px 폭이고 작은 눈·눈썹·코 앞의 볼 면을 남겼다.
좌표는 전부 0부터 세는 x,y다.

`author_pixels.py`는 직접 고른 행/좌표 문자열을 기록하고 최종 완전한 격자를 쓴 저작 보조 코드다.
서로 달라지는 몸·관절·효과는 명시한 문자열이다. 그대로 유지하는 머리/옷 부분과
대기·상태의 호흡 부분만 원본 행과 명시 패치를 공유한다. 도형 래스터화, 광원 수식,
프레임 전체 이동·회전·보간, 자동 구멍 채우기는 없다.
`render.py`는 그 격자를 읽어 PNG/GIF/진단 확대/라벨을 만든다.
참고 그림은 눈으로 크기와 얼굴·손·무기를 관찰했고 픽셀을 읽거나 추출하지 않았다.

## 본체와 재질

- 검은 포니테일: H 기본 면, h 왼쪽 위 덩어리 반사, K 아래/안쪽 윤곽. 머리 뒤와
  목 뒤의 열린 공간은 머리카락과 몸의 분리를 위한 공간이다.
- 짧은 진홍 저고리: L 왼쪽 어깨/소매, r 넓은 몸통, R 겨드랑이/아랫소매.
  금색 깃과 허리띠는 g/G/D 면으로 구분한다. 목과 흰 옷깃은 직접 이어진다.
- 먹색 바지: 넓은 H 면과 h 허벅지/앞 정강이 면. 두 다리는 엉덩이에서 이어지고
  넓은 돌격의 다리 사이 공간은 보존한다.
- 얼굴/손: F 왼쪽 위, S 기본 피부, s 귀/턱/손 아래. 평상시 눈은 작은 K,
  수면/쓰러짐은 짧은 닫힌 눈 선이다.
- 긴 검: W 날 끝, M 넓은 은색, m 뒷날. G/D 자루와 실제 손이 맞닿는다.
  죽음에서는 검을 놓았으므로 바닥의 별도 물체로 그렸다.
- 주홍 E는 홍영참의 실제 검날 핵과 갈라진 검기에만 쓴다. 독 P/Q는 기포에만
  썼으며 몸 전체의 색조를 바꾸지 않았다.

## 자세별 의도

대기는 팔꿈치가 굽고 검이 우상향한다. windup은 손을 어깨 쪽으로 당겨 검을 세운다.
move는 후방 지지발을 밀고 머리·상체를 앞에 내밀며 앞발을 크게 내딛는다.
attack은 손목/자루가 연결된 상태로 우하향 사선 검날을 내린다. recover는 검과 소매를
낮추며 보폭을 거둔다. hit는 눈썹과 눈이 찡그려지고 어깨가 비스듬히 떨어지며
한 팔을 몸 앞으로 접는다. dead는 옆으로 누운 낮은 몸과 닫힌 눈, 놓인 검이다.

skill_a는 양손/검을 가슴 쪽으로 모으며 날에 작은 주홍 핵을 찍었다.
skill_b는 낮춘 무릎과 편 손, 수평으로 뻗은 검 끝에서 서로 다른 위/아래 두 검기와
각각의 갈래를 찍었다. skill_c는 검을 낮추고 깨진 두 곡선 잔기를 남겼다.
poison은 턱을 받치는 손과 몸을 굽힌 다리, 새 위치/크기의 독 기포를 갖는다.
stun은 낮게 처진 머리·양팔·검, 서로 다른 위치의 별을 갖는다.
sleep은 접어 앉은 다리, 닫힌 눈과 무릎 위의 낮은 검, 작은 가슴/소매 호흡이다.

## 실제 그림을 보고 고른 수정

1. 기본 포니테일 y=24..41의 직선 벽을 각 행의 굽은 덩어리로 다시 찍고
   y=18..23에 붉은 술을 명시했다.
2. 대기 손목 (39,36), (40,36), (39,37), (40,37)을 S로 찍어 소매에서
   자루까지 이어지는 손을 읽기 쉽게 만들었다.
3. 전진의 분리된 손/검 사이를 (37,37)의 `LrrrgFFSDGK`,
   (37,38)의 `rrgFFSSssK` 등 명시 문자열로 다시 그렸다. 자동 연결 보정은 없다.
4. 시간 순서의 공격 그림에서 앞발이 평상시보다 충분히 전진하지 않는 것이 보였다.
   move/attack의 y=45..60 앞 허벅지·무릎·발목·부츠를 별도로 다시 그려
   move 앞 부츠를 x=44..51, attack 부츠를 x=42..50에 놓았다.
   뒤 지지발·얼굴·몸통·팔은 그 좌표를 유지했다.
5. 새 전진 다리 사이에 남은 이전 윤곽 (31,51), (31,52), (31,53)을 직접 지웠다.
   다리 사이의 의도한 빈 공간을 채우지 않았다.
6. sleep 두 장의 (37,56)은 검 밑의 바지 면이므로 H로 수정했다.
   dead (48,59)의 부츠 아래 단일 투명 홈도 H로 수정했다.
7. idle_b의 붉은 술 연결을 (16,16), (14,17)의 명시 행으로 다시 찍고,
   attack은 (20,16), (18,17), (15,18), (11,19)에서 술을 머리끈까지 이었다.
8. stun 두 장에서 검집 입구 (26,48)=`GD`, (25,49)=`DK`를 직접 이어
   허리에서 떨어져 있던 작은 검집을 고쳤다. sleep의 검집은
   (14,55)=`DGK`, (13,56)=`HKK`로 접힌 무릎 뒤에 기대도록 이었다.

## 열어 본 근거와 파일

- 참고 `human-size.png`를 먼저 열어 관찰했다. 이 파일을 source로 복사하지 않았다.
- 1배 `preview/contact-native.png`와 4배 최근접 확대의 밝은/어두운/체커 판을
  실제로 열어 얼굴·목·옷깃·손·검·허벅지·발과 빈 공간을 확인했다.
- 여덟 실제 GIF를 디코드한 `preview/*-gif-frames.png` 시간 순서 그림을 열었다.
  생성 GIF의 각 native RGBA 프레임은 해당 격자 PNG와 일치한다.
  프레임 사이의 위치 변화는 이 시간 순서 그림으로 확인했다. 실시간 브라우저 재생 검수는 하지 않았다.
- native 3×3 `poses-sheet.png`, native 3×3 `actions-sheet.png`, native 3×6
  `suite-sheet.png`와 18개의 개별 PNG는 preview 안에 있다.
- `preview/image-info.json`의 원본 해시는 실제 현재 격자 바이트에서 계산한다.
  18장은 서로 다른 원본이며 모든 잉크는 y<=60, 1px 투명 테두리를 지킨다.

## 남은 시각적 한계 / 검토 대상

- 짙은 남청 배경에서는 검은 머리와 먼 다리의 어두운 면 대비가 낮다.
  밝은 배경에서는 전체 윤곽과 명암이 읽히지만 실제 전투 배경별 가독성은 아직 미확인이다.
- 대기·수면 호흡은 소매/가슴/술의 작은 native 변화여서 1배에서는 미묘하다.
- 9개 기본 자세의 키 포즈만으로 검의 큰 방향 전환을 표현하므로 베기→회수는
  날 각도가 빠르게 바뀐다. 추가 자동 중간 프레임을 만들지 않았다.
- GIF는 자세 검토용이다. 게임 안의 접촉, 피격 시간, 피해, 이동과 배경은 확인하지 않았다.

이 문서는 작가의 확인 기록이다. 독립 검수 결과나 사용자 Allow/승인을 주장하지 않는다.

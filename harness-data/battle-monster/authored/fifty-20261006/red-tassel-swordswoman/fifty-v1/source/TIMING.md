# 홍영검희 — PNG/GIF 시간표

원본은 64×64. 모든 GIF는 원본 팔레트를 그대로 넣고 확대 없이 저장한다.
투명 인덱스 0, 프레임 disposal=2, 반복 재생. 각 프레임의 노출은 아래 ms 값이다.
GIF의 실제 프레임을 다시 읽어 원본 RGBA와 대조한 뒤 시간표가 적힌 PNG 스트립으로 보았다.

| GIF | 원본 순서 | 각 노출 ms |
|---|---|---|
| idle.gif | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack.gif | idle_a → windup → move → attack → recover → idle_a | 240 / 180 / 110 / 140 / 180 / 260 |
| hit.gif | idle_a → hit → recover → idle_a | 260 / 220 / 180 / 340 |
| dead.gif | idle_a → hit → dead | 240 / 170 / 1000 |
| skill.gif | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 280 / 180 / 220 / 300 |
| poison.gif | poison_a → poison_b | 420 / 420 |
| stun.gif | stun_a → stun_b | 400 / 400 |
| sleep.gif | sleep_a → sleep_b | 650 / 650 |

모든 파일은 `preview/`에 있다. dead.gif의 반복 때 다시 일어나는 것은 검토용 루프의
재시작이다. 실제 죽음 상태는 마지막 dead 그림을 유지해야 한다.

## 홍영참 앵커 — 0 기반 x,y

- **준비 skill_a:** 가슴 앞 손 (40..42,33..35)과 금색 자루/가드 (41..44,32..34)가
  실제로 이어진다. 검 끝 (60,14), 날 위 주홍 핵은 (48..53,23..28)의 E/L 덩어리다.
  핵이 무기 주변에 모이는 280ms 준비를 준다.
- **시전/접촉 skill_b:** 앞쪽 어깨 (34..37,32) → 펼친 진홍 소매/팔꿈치
  (37..40,34..36) → 손목 테 (41,34)/(40,35) → 전방 검손
  **(42..44,34)/(41..43,35)** → 자루 (45,34)/(44,35) →
  가드 **(42..45,33)** → 날 뿌리 (44..46,32) → 긴 사선 은검 →
  **실제 칼끝 (54,12)** 순으로 연결된다. 옷깃과 검손 사이에 공간을 둔다.
  칼끝 옆 **(55,12)=E**가 두 굽은 주홍 검기의 공통 발생점이다.
  짧은 위 갈래는 x=55..62,y=3..11, 끝 (61,3)이고,
  더 긴 아래 갈래는 x=55..62,y=13..27, 끝 (59,27)이다.
  발생점 밖에서는 두 갈래 사이의 투명 간격을 유지하고 끝에서 재결합하지 않는다.
  접촉 핵심은 기존과 동일하게 **180ms** 유지한다.
- **회수 skill_c:** 손 (43,40..41), 가드 (42..45,42), 낮은 검 끝 (57,55).
  위 잔기는 x=54..60,y=32..39, 아래 잔기는 x=53..60,y=46..52에서 부서진다.
  검과 소매를 거두는 220ms 회수 후 대기로 돌아간다.

## 공격 체중과 상태 루프

windup의 약간 넓힌 양발 → move의 뒤발 밀기와 크게 전진한 앞발 →
attack의 앞 무릎/손목/사선 날 → recover의 좁아진 보폭 순서다.
몸 전체를 자동 이동시키거나 중간 프레임을 합성하지 않는다.

독은 두 컷 사이 턱을 받치는 손·어깨·무릎과 기포의 위치/내용이 바뀐다.
기절은 처진 팔·손·눈선의 작은 변화와 두 별의 자리 변화다.
수면은 앉은 체형을 유지하며 가슴/소매/바지 면과 술을 직접 바꿔 숨을 표현한다.
상태 GIF는 다른 공격 프레임이나 색조 변환으로 대체하지 않았다.


## 현재 windup 수정의 공격 앵커

공격 GIF의 순서와 노출은 그대로이며 수정된 windup은 **180ms** 유지한다.
어깨 옆 손 `(33..35,30)` → 자루 `(35,31)` / `(36,30)` →
가드 `(32..35,29)` → 날 뿌리 `(35..37,28)` → 칼끝 `(54,5)` 순으로 이어진다.
소매는 팔꿈치 `(35..39,35)`에서 손목으로 되접힌다. 발은 y=60에 고정한 준비 자세다.
그 뒤 move의 뒤 지지발 밀기/넓은 앞발/뻗은 팔, attack의 우하향 베기,
recover의 낮춘 검/거둔 보폭으로 연결한다. 전체 프레임을 이동하거나 자동 중간
프레임을 만들지 않았다. 준비에서 전진까지의 손 위치 변화는 키 자세 사이 큰 전환이다.

8GIF는 수정 후 재생성했다. 실제 디코드 프레임을 source PNG와 대조하고,
`preview/motions-basic.png`와 `preview/motions-states.png`를 열어 순서를 보았다.
실시간 GIF 재생과 게임 안 이동/접촉 시간은 아직 관찰하지 않았다.
수면의 이전 수정은 sleep_b (29,44)의 K 윤곽 복원이며 호흡과 650ms 노출을 유지한다.

## 현재 skill_b 전방 팔/분기 검기 수정

위의 홍영참 앵커는 현재 원본 좌표다. 옛 목 옆 검손·수평 날·세로 활 모양 궤적은
현재 skill_b에서 제거했다. 기술 3자세는 준비의 검날 핵 → 전방 검손/칼끝에서
두 굽은 검기 방출 → 낮춘 검과 두 깨진 잔기의 회수다. 입에서 발사하는 기술은 아니다.
얼굴/허리/발을 고정하고 어깨·소매·손·검·검기의 배열만 직접 바꿨다.
준비→접촉의 검 각도와 접촉→회수의 큰 전환은 중간 자세 없는 키 자세 전환이다.

이번 수정 후 8GIF와 디코드 시간 순서 판을 다시 만들고 실제 판을 열어 확인했다.
모든 GIF 순서/노출값은 동일하다. 프레임 자동 이동·회전·보간이나 효과 합성은 없다.
실시간 재생 속도·게임 안 접촉은 미확인이고, 이 기록은 독립 검수나 사용자 승인 선언이 아니다.

# 먹붓귀 — 어두운 배경 재질 대비 보수

## 작업 범위와 원본

2026-10-06에 전달된 실제 지적 세 가지(대기 붓털 하단, 신발 발등/밑창, 묵류격 발사부)를 직접 보수했다. 현재 기본 9자세와 추가 9자세 모두 96행 × 96문자의 전체 ASCII 리터럴 pxgrid다. 18개 배열은 모두 다르다. 팔레트는 기존 18색을 그대로 유지했다. 변경한 기호는 기존 슬레이트 `h` (#5D6973)와 더 어두운 기본색 `n` (#353E49)이다.

첨부 reference.png와 references/human-size.png를 실제 열어 갓, 성인 우향 얼굴, 짧은 수염, 큰 도포/소매, 작은 신발, 손과 붓 자루의 연결을 관찰했다. 참고 이미지의 픽셀 추출·트레이싱·재배포를 하지 않았다. 기존 정체성, 자세, 큰 광원 면, 파지와 관절을 보존했다.

수정 전 18개 격자, 팔레트, 저작 보조 코드와 이전 문서는 `originals/before-dark-material-repair/`에 보존했다. 더 이전의 보수 이력도 `originals/`에 남아 있다. 이번에 고른 모든 좌표와 짧은 ASCII 문자열은 `repair_dark_material.py`에 기록했다. 각 자세는 별도의 명시 좌표 목록을 가진다. 최종 원본은 `poses/*.pxgrid`, `actions/*.pxgrid`의 생략 없는 전체 행이다. 기존 `repair.py`의 마지막에 이번 좌표 보수를 연결해 `author.py`로 다시 저작할 때도 보수가 유지되게 했다. 이번 작업에서는 기존 저작기를 재실행하지 않았다.

전체 프레임 이동·회전·보간, 도형 래스터, 합성 명암, 자동 구멍 채우기, 생성 이미지, 다른 종의 복제는 사용하지 않았다. 보조 코드는 직접 선택한 색 문자열을 지정 위치에 기록하고 원본을 읽어 PNG/GIF 및 진단 배경/최근접 확대를 만든다.

## 직접 고른 군집

좌표는 각 native 96px 셀의 (0,0) 기준이다. 이번 변경은 총 518픽셀, 15자세다. 불투명 픽셀의 색만 바꾸었으며 18자세 모두 투명 마스크는 수정 전과 정확히 같다.

### 대기 3자세의 검은 붓털

`idle_a`, `idle_b`, `idle_c` 각각에서 x69/y73–74, x68/y75–76, x68/y78–79에 짧은 `h` 결을 찍고 x68/y80을 `n`으로 골랐다. y77의 어두운 끊김과 가장 바깥 `O` 윤곽은 남겼다. 검은 붓털의 오른쪽/아래쪽이 어두운 배경에서도 끝으로 가늘어지는 것을 읽히게 했다. 위 왼쪽의 기존 `v/h` 빛 면이 여전히 가장 밝고 넓다. 손 위 자루→파지→손 아래 목→붓털의 단일 축을 건드리지 않았다.

### 공격·피격의 같은 붓 재질

- `attack`: x90/y69–70, y72–74, y76에 `h`, x90/y77에 `n`을 찍었다. 내려친 붓의 실제 오른쪽 그림자 면에서 각각 직접 선택했다. 가운데 y71·y75의 끊김과 아래 윤곽을 보존했다.
- `hit`: x78/y73–74, x79/y75–76, y78–79에 `h`, x79/y80과 x78/y81에 `n`을 찍었다. 움찔하며 기울어진 붓의 실제 면을 따라 별도로 골랐다. 공격 좌표를 자동 이동/복사하지 않았다.

### 신발의 짧은 발등/발끝 면

대기3자세와 회수·기술 준비/회수·독2자세·기절2자세의 양쪽 신발에서 기존 발등 빛을 넓히고 밑창 바로 위에 짧은 `n/h` 면을 찍었다. 대기의 뒤 신발은 x28–33/y87–89, 앞 신발은 x44–49/y87–89 부근이다. y91에는 뒤 x29–31, 앞 x44–47의 더 어두운 `n` 띠를 두어 바닥과의 경계를 읽히게 했다. y92의 접지 윤곽은 그대로다.

`windup`의 굽힌 신발, `move`와 `skill_b`의 뻗은 뒤 신발/앞 신발, `attack`의 압축된 지지발과 비스듬한 뒤 발, `hit`의 다르게 놓인 양쪽 신발도 해당 실제 위치를 읽고 별도 좌표 목록으로 보수했다. 공중의 `move`/`skill_b` 최하단 y90도 유지했다. 허벅지/무릎/발목과 발의 형태를 바꾸지 않았다. 수면2자세와 쓰러짐 원본은 바이트 단위로 보존했다.

### 묵류격 발사부와 준비/회수 먹

- `skill_b`: x86/y40→x85/y41, x84/y43→x83/y44, x83/y46→x82/y47, x81/y49→x80/y50–51을 따라 발사부 왼쪽 위의 끊어진 1px `h` 군집을 직접 찍었다. 실제 고체 붓털에서 오른쪽으로 꺾이는 아랫갈래에도 x81/y53, x82/y54, x83/y55, x85/y57의 `h`를 별도로 찍었다. 어두운 내부 면과 갈래 사이의 빈 간격을 보존했다. 기존 위/가운데/아래 세 먹 덩어리의 작은 밝은 면과 서로 다른 크기는 그대로다.
- `skill_a`: 모이는 먹의 x82/y22–24, y26, x81/y27 및 붓 끝 안쪽 x82/y29·y32, x81/y33에 짧은 `h`를 찍었다. 끝 x80/y35는 `n`이다. 작은 방울 x86/y18–19에도 좁은 빛 면을 찍었다. 자루·손·붓털은 그대로 연결된다.
- `skill_c`: 기존 작은 먹방울의 `v` 최고 빛 옆에 x76/y15, x77/y16, x81/y20, x82/y21, x80/y36–37, x85/y45의 `h`를 찍고 하단 x85/y46을 `n`으로 골랐다. 올린 붓털의 x70/y30, x69/y31, x68/y33에도 작은 결을 두었다. 이전에 고친 주먹/손목/손 아래 자루는 보존했다.

## 실제 PNG와 GIF 확인

- `previews/dark-material-light.png`, `dark-material-dark.png`, `dark-material-checker.png`를 모두 실제 열었다. 대기·공격·피격·기술 발사의 수정 전/후 전체 1배와 최근접 3배를 비교했다. 붓 하단의 결, 신발의 짧은 발끝 면, 붓에서 시작하는 굽은 발사부가 어두운 배경에서 더 읽힌다. 빛 군집이 외곽을 둘러싼 연속 테두리가 되지 않도록 끊긴 결을 유지했다.
- 현재 18자세 `native-light.png`, `native-dark.png`, `native-checker.png`와 전체 3배 `board-dark.png`를 실제 열었다. 대기3자세, 공격/피격, 기술3자세와 상태의 같은 신체 부위를 함께 보았다. 이번 색 보수로 손/도구가 떨어지거나 목·옷깃·배에 투명 홈이 생기지 않았다. 수면은 그대로 닫힌 눈과 낮게 앉은 몸이며, 평상시 눈과 다른 짧은 눈꺼풀이 남아 있다.
- 개별 native PNG, 투명 3×3 `poses-sheet.png`/`actions-sheet.png`, 8GIF를 현재 격자에서 다시 저장했다. 저장된 GIF를 실제 다시 읽어 만든 `gif-decoded.png`도 열었다. 공격의 준비→전진→접촉→회수, 기술의 모으기→발사→깨진 방울, 서로 다른 독/기절/수면 배열을 확인했다. 실시간 재생이나 게임 런타임을 보았다는 뜻은 아니다.
- 렌더 진단에서 모든 원본은 96×96, 기존 팔레트 기호, 1px 투명 테두리, 최하단 y≤92를 유지했다. `idle_a`의 최하단은 정확히 y92다. 저장 PNG의 알파값은 0/255다. 기존 18색과 투명 마스크를 비교해 보존을 확인했다. 8GIF의 디코딩 픽셀은 원본에 밝은 검토 배경을 합성한 RGB와 전부 정확히 일치하고 hold는 TIMING.md와 같다.
- `previews/dark-material-report.json`에 실제 변경 좌표/전후 기호, 현재 격자/PNG 해시, 보존된 투명 마스크와 디코딩 GIF의 색/hold 비교를 기록했다. `file-report.json`/`gif-report.json`도 현재 이미지에서 갱신했다. 이 파일들은 원본/출력 진단이며 검수자·모델 출처·사용자 선택의 증거가 아니다.

## 남은 시각 문제와 확인 범위

가장 어두운 `O` 외곽과 일부 `k` 면은 어두운 배경에서 여전히 대비가 낮다. 이를 전부 밝힌 테두리로 바꾸지 않고 내부의 짧은 결과 발등 면으로 끝/부피를 읽히게 했다. 대기 붓털의 낮은 빛 결은 1px 폭이라 실제 1배에서는 작다. 기술 발사부의 빛도 끊어진 군집이며 검은 내부 갈래는 여전히 절제된 대비다. 독2자세와 수면2자세의 몸 변화는 작고 각각 방울/가슴 면 변화로 박자가 읽힌다.

기술은 세 핵심 자세다. 실제 발사체 진행, 전투 hop 궤적, 피해·소리 동기화는 확인하지 않았다. 공격/쓰러짐에 자동 중간 프레임을 추가하지 않았다. GIF 디코딩 시트는 저장된 프레임/박자 확인 자료이며 실시간 재생 품질을 증명하지 않는다.

모든 변경과 출력은 source 안에 저장했다. 테스트/게이트와 별도 검수자 호출은 하지 않았다. 검수 결과·ledger·brief·게임 저장소·다른 후보를 수정하지 않았다. 새 독립 검수는 하네스가 수행한다. 검수 통과 또는 사용자 승인/선택을 선언하지 않는다.

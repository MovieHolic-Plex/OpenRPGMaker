# 먹붓귀 — 8동작 GIF 시간표

96×96 리터럴 자세를 그대로 hold한다. 전체 프레임 이동·회전·보간·자동 중간 자세는 없다. 아래 순서와 hold는 현재 저장된 GIF를 다시 읽어 확인했다. 각 디코딩 프레임의 색은 원본 PNG에 검토 배경 (#DCD9CD)을 합성한 결과와 정확히 같다.

8개 GIF는 검토용 반복이다. 쓰러짐 GIF의 반복은 게임에서 부활한다는 뜻이 아니다. 자세/재질 교정만 반영했고 기존 노출 시간은 유지했다.

## 공격·피격 연결

- **대기:** 위 자루 x71–72/y52–54 → 손 y55–59 → 나무 붓목 x68–70/y60–62 → 붓털로 이어지는 기존 단일 축을 유지한다. 붓털과 신발 왼쪽 위의 짧은 밝은 면을 보강했다. idle_a의 발은 정확히 y92에 닿는다.
- **준비:** 뒤 붓털 → 드러난 나무 축 y49–54 → 피부색 주먹 x32–40/y53–58 → 손 아래 목 x36–38/y58–59 → 작은 끝 y60. 긴 밝은 소매 주름을 끊었다. 뒤 지지발과 굽힌 앞 무릎은 그대로다.
- **전진:** 앞 어깨/큰 소매와 옷자락이 펼쳐지고 뒤 신발이 밀어내는 별도 원본 자세다. 최하단 y90의 짧은 도약이다.
- **접촉:** 앞 엉덩이/굵은 허벅지/굽힌 무릎과 지지발이 y92로 내려온다. 잡은 손에서 오른쪽 아래 붓털로 이어지는 사선 타격을 100ms 유지한다.
- **회수:** 팔꿈치를 접은 넓은 소매, 손 x65–74/y63–69, 수평 자루 y67–69의 기존 구조다. 새 피격과 구별되는 회복 단계로 사용한다.
- **피격:** 가슴과 어깨를 안으로 접고 위팔–높은 팔꿈치–돌아오는 아래팔–손 x54–61/y57–61을 직접 다시 찍었다. 사선 자루는 손 아래 x59–64/y62–65 → 붓털 x65/y65 부근으로 이어져 무기가 아래로 처진다. 기존 신발의 위치와 접지를 유지한다. 움찔 200ms 뒤 회수로 넘어간다. 쓰러짐 전에도 같은 새 피격을 180ms 사용한다.

## 묵류격의 실제 붓 앵커

좌표는 native 셀의 0-based 좌표다. 기술은 입에서 나오는 효과가 아니라 오른손이 든 붓의 실제 털에서 나온다. 글자/한자는 없다.

| 단계 | 손과 자루 | 붓털/효과 뿌리 | 역할 |
|---|---|---|---|
| skill_a | 손 약 (72,50), 자루 (72,49) | 붓털 x72–86/y21–36, 모으는 먹 x78–89/y17–29 | 400ms 준비, 실제 붓끝에 먹이 모임 |
| skill_b | 손 x73–79/y54–57, 자루 y54–56 | 고체 붓털 x74–80/y48–54, 오른쪽 분출 뿌리 x78–86/y50–58 | 180ms 발사, 위/가운데/아래의 비대칭 세 먹물 덩어리 |
| skill_c | 주먹 x64–71/y51–54, 위 자루 x65–67/y43–49 → 파지 → 아래 자루 x66–67/y55–58 | 붓털 x62–71/y22–33, 흩어진 파편 x69–87/y14–47 | 320ms 회수, 올린 붓과 깨진 먹방울 |

skill_b의 고체 붓 윗면과 위 x84–86/y29–32, 가운데 x89–91/y43–46, 아래 x85–88/y60–63 먹 덩어리의 밝은 면을 각각 직접 보강했다. 분출 시작점과 분리된 세 덩어리 사이의 기존 빈 간격은 유지한다. 준비/회수 붓의 같은 먹 재질도 해당 자세의 실제 좌표에서 보강했다.

## 상태 박자

독은 턱을 짚는 손/배를 감싼 팔과 변하는 녹색 독방울이다. 기절은 낮춘 머리/처진 소매/무기와 서로 다른 위치의 별이다. 수면은 앉아 접힌 무릎, 바닥 가까운 붓, y54의 짧은 닫힌 눈을 유지하고 작은 가슴/등 면 변화로 숨을 표현한다. 수면의 두 신발과 무기 앵커는 유지한다. 상태는 공격 재사용이나 색조 변환이 아니다.

## 이번 파지 교정

skill_c의 펼친 손을 자루 주위의 작은 주먹으로 다시 찍었다. y52의 엄지와 y54의 아래 손가락이 나무 축을 가리고, y53에서는 손가락 사이의 나무가 보이며, y55–58에는 주먹 아래 자루가 드러난다. 소매 외곽과 나무 경계는 어두운 윤곽으로 구별한다. 손 앵커는 약 (67,53)이다. 실제 붓털과 깨진 먹방울의 위치 및 320ms hold는 보존했다.

poison_a/b는 손목 x40–47/y69–70에서 내려오는 손을 x44–50/y71–75에 직접 이어 찍었다. 수평 자루 y73–75를 엄지/손가락이 감싸고, 주먹 왼쪽과 오른쪽에서 같은 목재 축이 드러난다. y69의 고립된 목재 조각은 피부색으로 다시 저작했다. 턱손과 각각 다른 독방울/몸의 미세 변화는 보존했다. 독 두 프레임의 엄지 빛과 손가락 배열도 별도로 골랐다. 440/440ms hold는 유지한다.

실제 저장 GIF의 프레임 순서/색/hold와 디코딩 시트는 확인했다. 실시간 게임 전투, hop 궤적, 발사체 진행, 피해/소리 동기화는 이 원본 교정에서 확인하지 않았다. 검수/사용자 승인 기록이 아니다.

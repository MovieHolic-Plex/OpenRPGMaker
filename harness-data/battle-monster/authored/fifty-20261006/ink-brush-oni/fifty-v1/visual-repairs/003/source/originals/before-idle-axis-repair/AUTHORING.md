# 먹붓귀 — 원본 18자세

## 이번 교정: 손/수평 자루 결합과 먹물의 어두운 배경 명암

기존 완성 원안을 수정했다. 이번 작업은 `source` 안의 원본·저작 보조 코드·문서·미리보기만 기록했다. 첨부 현재 18자세 판과 `references/human-size.png`를 실제 열어 얼굴, 어깨, 소매, 손/도구 연결을 관찰했다. 참고에서 픽셀을 추출하지 않았다. 아래 이전 저작 기록은 보존하며, 이번 변경 좌표가 현재 격자의 최종 수정이다.

좌표는 0부터 시작하고 모두 직접 고른 ASCII 문자열이다. `repair.py`는 아래 리터럴 좌표만 적용한다. `author.py` 끝에서도 같은 교정을 적용하므로 원본을 재생성할 때 수정이 사라지지 않는다. 교정 전 18자세·팔레트·저작 코드·문서는 `originals/before-grip-ink-repair/`에 보존했다. 별도 검수자 호출·승인 기록 변경은 하지 않았다.

- **recover:** x65–74/y63의 손바닥 경계를 다시 찍고 x65–72/y64, x65–70/y65, x65–69/y66을 손가락과 어두운 윤곽으로 연결했다. x65–68/y67과 x65–67/y68의 손가락은 긴 수평 자루의 나무 면 앞에 겹친다. y69의 작은 아래 윤곽으로 쥔 손을 닫았다. 붓털 윗면을 만지는 떠 있는 손끝을 낮은 자루를 감싸는 형태로 바꿨다. 팔/소매와 붓털의 기존 큰 면은 유지했다.
- **hit:** x66–74/y63의 갈색 짧은 자루를 피부색 손가락과 윤곽으로 교체했다. x65–72/y64에서 남아 있던 갈색 부분도 정리했다. y64–69는 회수와 같은 쥠 구조이며, 피격의 기존 기울어진 머리·눈썹·어깨·소매·발은 유지했다. 손가락이 y67–68의 긴 자루와 겹치며 y65의 배경 틈은 없다.
- **skill_b:** 위 먹물 덩어리의 (86,29), (85–86,30), (84,31)에 기존 회청색 `h`를 직접 넣었다. 오른쪽 작은 덩어리의 (91,43), (90,44), (89,45)에도 짧은 왼쪽 위 명암을 넣었다. 검은 내부·외곽·세 덩어리 사이 투명 공간·실제 붓털에 붙은 분출 뿌리는 그대로다.
- **skill_c:** 실제 격자에서 큰 방울은 검수의 대략 범위보다 조금 왼쪽에 있다. 방울을 이동시키지 않고 실제 위치의 (75,15), (76,16), (80,20), (81,21)에 기존 밝은 회청색 `v`를 직접 넣었다. 처음 `h`로 확인했을 때 작은 방울의 native 어두운 배경 가독성이 약해서 해당 6픽셀만 `v`로 다시 선택했다. 오른쪽 아래 두 작은 방울의 (79,36), (84,45)도 각 1픽셀을 같은 재질 규칙으로 바꿨다. 나머지 검은 면과 분리된 실루엣은 유지했다.

### 이번 그림 확인과 남은 문제

`previews/repair-light.png`, `repair-dark.png`, `repair-checker.png`는 교정 전후의 실제 1배 그림과 4배 최근접 부분 확대이다. 손/자루 사이 배경 틈이 사라지고, 먹방울의 작은 윗면이 어두운 배경에서 읽히는 것을 확인했다. `native-light.png`, `native-dark.png`, `native-checker.png`의 18자세 1배와 `board-checker.png`의 3배도 실제 열어 다른 자세의 손/자루·목·옷깃·다리 연결과 수면의 닫힌 눈을 함께 확인했다. 같은 결손이 보이는 다른 자세는 이번 확인에서 찾지 못했다. 의도한 다리 사이/소매 아래 빈 공간은 그대로다.

8개 GIF를 새 격자로 다시 만들고 실제 GIF를 디코딩한 `gif-decoded.png`를 열어 준비→전진→접촉→회수 및 상태 두 프레임의 배열을 확인했다. 브라우저에서 실시간 재생이나 게임의 hop/피해 판정을 관찰한 것은 아니다. 원본 팔레트와 나머지 14자세는 교정 전 파일과 동일하다. 파일 진단은 96×96, 18색, 1px 투명 테두리, 최하단 y≤92, idle_a의 정확한 y92 접지를 확인했다. 저장소 테스트·게이트는 실행하지 않았다.

작은 먹방울은 1–2픽셀 명암으로 구분되므로 아주 어두운 화면에서는 여전히 섬세하게 보인다. 먹색 외곽 자체의 낮은 대비, 기술의 좁은 오른쪽 공간, 쓰러짐 중간 프레임 부재, 상태 두 프레임의 작은 변화량은 기존 한계로 남는다. 이 수정본의 실제 독립 검수는 하네스가 수행해야 한다. 검수 통과나 사용자의 승인·선택을 선언하지 않는다.

## 범위와 방식

이 후보의 source 안에서 새로 저작했다. 다른 종의 원본·반려작·게임 저장소·ledger·brief는 사용하거나 수정하지 않았다. 사용자 승인이나 하네스 검수 통과를 선언하지 않는다. 별도 검수자를 호출하지 않았다.

`palette.json`의 18색과 96×96 native ASCII 행이 원본이다. `author.py`에는 직접 고른 `y / x / ASCII 문자열`을 보존했다. 빈 캔버스에 이 문자열을 기록하고, 바뀌지 않은 갓·얼굴·옷 부위의 리터럴 행을 참조한다. 원/다각형/선 래스터, 수식 명암, 이미지 생성, 참고 픽셀 추출, 프레임 전체 변환, 자동 채움은 없다. `poses/*.pxgrid`, `actions/*.pxgrid`는 모두 생략 없는 96행 × 96문자다. 코드의 초기 배열과 뒤의 명시 교정 배열도 남겨 수정 경위를 볼 수 있다.

## 참고 관찰

첨부 `references/human-size.png`를 실제 열었다. 성인 SD 검객의 작은 우향 눈, 눈 앞의 코·볼 여유, 목과 옷깃, 어깨와 소매의 면, 잡은 손에서 무기까지 이어지는 구조를 관찰했다. 참고는 크기·얼굴 관찰만 했다. 추출·트레이싱·확대 원본 재배포는 하지 않았다.

먹붓귀는 해당 종 brief를 따라 넓은 먹색 갓, 짧은 회백 수염, 회갈색 도포, 굵은 몸, 작은 신발, 굵은 붓털과 갈색 자루로 새로 구성했다. 왼쪽 위 빛은 갓 왼쪽 능선, 왼쪽 어깨의 넓은 천 면, 얼굴 윗부분, 신발의 왼쪽 면에 배치했다. 붓털은 차가운 먹색 넓은 면, 자루는 좁은 나무색 면, 도포는 넓고 낮은 대비의 천 면이다.

## 자세 저작과 직접 교정

좌표는 0부터 시작한다.

- **idle_a/b/c:** 갓 y10–28, 얼굴 y29–42, 목·옷깃 y43–47, 도포 y48–80. 뺨 뒤 작은 눈과 짧은 수염을 마무리한 뒤 나머지 자세를 저작했다. b의 y54–58 어깨/가슴 천과 y38–42 수염, c의 y59–63 배 주름 및 눈 주변은 직접 고른 행으로 바뀐다. idle_a 신발 밑면은 정확히 y92에 닿는다.
- **windup:** 뒤의 붓털 x5–22/y29–43에서 자루가 가슴 앞 손 x31–42/y53–58까지 이어진다. 접은 위팔·팔꿈치는 y48–61의 넓은 소매 면이다. 뒤 지지발과 앞의 굽힌 발은 별도 native 행으로 저작했다.
- **move:** 펼쳐지는 옷자락과 이동하는 어깨, 뒤에서 밀고 올라오는 신발을 새 배열로 그렸다. 첫 확대에서 자루가 손보다 안쪽으로 지나가 보였다. `MOVE_BRUSH_FIXED`의 y48–61 자루와 `MOVE_GRIP`의 x73–78/y55–59를 직접 교정해 손가락이 자루를 감싸게 했다. 기존 자루를 몸 전체와 함께 이동시키지 않았다.
- **attack:** y45–80의 어깨/도포, y80–92의 두 다리, y40–78의 사선 붓을 새로 찍었다. 앞 엉덩이 끝과 허벅지가 대각 한 점으로 닿던 곳을 x53–65/y77–83의 명시 면으로 고쳤다. 허벅지–무릎–발목의 두께를 확보하고 다리 사이 빈 공간은 남겼다.
- **recover:** 팔꿈치를 몸 앞으로 접은 소매와 낮아진 손을 새로 그렸다. 자루는 y67–69에 수평으로 지나고, 오른쪽 붓털은 별도 재질 면을 갖는다.
- **hit:** 갓·얼굴의 기울어진 윤곽을 새 행으로 그렸다. 눈썹/찡그린 눈, 내려간 어깨, 약해진 손과 휘청이는 신발 배열을 바꿨다.
- **dead:** 바닥의 몸통, 접힌 앞 소매/손, 두 신발, 옆으로 쓰러진 얼굴과 닫힌 짧은 눈, 떨어진 갓을 각각 저작했다. 무기는 바닥 y87–92에 놓인다. 수면의 앉은 자세와 다르다.
- **skill_a:** 든 손–자루–붓털에서 작은 먹 덩어리가 모인다. 붓털 x72–86/y21–36과 연결된 먹 기운, 별도 작은 먹방울을 저작했다.
- **skill_b:** 전진한 몸과 옆으로 뻗은 소매/손을 그렸다. 붓털의 실제 오른쪽 끝에서 위·가운데·아래의 비대칭 세 먹물 갈래가 나온다. 큰 끝 덩어리가 하나의 Y 외곽으로만 읽히던 부분을 `CAST_BREAKS`의 y39, y45–49, y58–60 native 좌표로 나눴다. 짧은 뿌리는 붓털에 남고 세 발사 덩어리는 서로 다른 윤곽과 크기로 분리된다.
- **skill_c:** 붓을 다시 세운 팔과 손, 위쪽의 작은 붓털, 흩어진 먹 조각을 새로 저작했다. attack/recover를 색만 바꾼 프레임이 아니다.
- **poison_a/b:** 턱을 짚는 손, 턱으로 이어지는 굽힌 팔, 낮은 붓을 받치는 반대 소매, 아픈 눈 주변을 저작했다. b는 눈·턱손·가슴 면과 녹색 독방울 위치/크기를 직접 바꾼다. 얼굴과 도포를 녹색으로 덮지 않았다.
- **stun_a/b:** 머리와 갓을 낮추고, 목/윗도포, 처진 큰 소매, 약하게 잡은 손과 바닥 가까운 붓을 새로 그렸다. b의 별이 갓 가장자리에 닿던 것을 별도 명시 행 x16–22/y21–25로 다시 그렸다. 두 프레임의 눈꺼풀·수염·손 주변 면과 별 위치가 다르다.
- **sleep_a/b:** 낮은 갓/머리, 앉아서 접힌 도포와 무릎, 두 작은 신발, 바닥의 붓과 그 위 손을 새로 그렸다. 눈은 y54의 짧은 수평 닫힌 눈꺼풀이고 아래 코 음영과 분리된다. b는 y72–77의 가슴/등 천 면과 y60–62의 수염만 직접 바꿔 작은 숨을 표현한다. 같은 신발과 무릎, 무기 위치는 유지한다.

## 실제로 연 그림과 파일 진단

- `previews/native.png`: 18자세 1배. 눈 위치와 수면의 닫힌 눈을 확인했다.
- `previews/board-light.png`, `board-dark.png`, `board-checker.png`: 3배 최근접 확대. 목/옷깃, 배, 팔/다리 경계, 손/자루, 의도한 다리 사이 빈 공간을 확인했다.
- `previews/gif-decoded.png`: 생성된 실제 8개 GIF를 다시 읽은 프레임/hold 표. 배열 순서에서 무기 방향과 발/소매 변화를 확인했다. 라이브 브라우저 재생을 보았다고 주장하지 않는다.
- `render.py`의 파일 진단: 18프레임 모두 정확한 크기와 팔레트 기호, 투명 테두리, 최하단 제한을 확인했다. 이동·시전은 발이 y90에 떠 있는 짧은 도약이다. 나머지는 최하단 y92 이하다. alpha는 0/255다.
- 읽기 전용 연결 진단은 본체/관절 후보 확인에만 썼고, 결손을 자동으로 채우지 않았다. 효과와 떨어진 별/독방울의 분리는 의도한 것이다.
- `file-report.json`, `gif-report.json`의 해시는 파일에서 계산한 값이다. 모델 호출·검수·승인 해시로 가장하지 않는다. 저장소 테스트/게이트는 실행하지 않았다.

## 남은 시각적 한계

- 96px 한 셀 안에서 붓과 세 발사 먹물을 함께 보여야 하므로 시전의 오른쪽 효과 공간이 좁다. 오른쪽 끝은 x94이고 투명 테두리를 지킨다. 실제 게임의 셀 밖 발사체 진행은 이 후보에서 저작하지 않았다.
- 공격의 머리 중심을 유지하고 어깨·소매·도포·발을 바꿨으므로 큰 도약보다는 짧은 전진 타격으로 보인다. 머리의 전후 흔들림은 적다.
- 쓰러짐은 피격에서 바닥 자세로 바로 바뀌는 제한된 키프레임이다. 낙하 중간 자세는 없다.
- 짙은 배경에서는 갓과 먹붓의 어두운 외곽 대비가 작다. 왼쪽의 밝은 넓은 면은 유지했으며 검은 먹 재질을 위해 외곽을 밝은 테두리로 바꾸지는 않았다.

현재 산출물은 사용자와 하네스의 독립 시각 검토를 위한 완성 후보이다. 승인 기록이나 설치 결과는 아니다.

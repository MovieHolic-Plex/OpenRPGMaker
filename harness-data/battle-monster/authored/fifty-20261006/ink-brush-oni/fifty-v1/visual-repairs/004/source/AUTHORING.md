# 먹붓귀 — 준비 파지·피격·먹 재질 교정

## 범위와 원본

2026-10-06의 실제 시각 지적 네 건을 반영한 수정본이다. 모든 쓰기는 이 후보의 `source` 안에만 했다. 기본 9자세와 추가 9자세는 `poses/*.pxgrid`, `actions/*.pxgrid`의 생략 없는 96행 × 96문자 ASCII 원본이며, 기존 `palette.json`의 18색을 그대로 사용한다.

첨부 `reference.png`와 `references/human-size.png`를 실제 열어 얼굴의 작은 우향 눈, 목·옷깃·어깨, 손과 무기 연결을 관찰했다. 참고 픽셀 추출·트레이싱·재배포는 하지 않았다. 먹색 갓, 짧은 회백 수염, 굵은 회갈색 도포, 작은 신발과 큰 먹붓의 기존 정체성을 유지했다.

수정 전 18자세, 팔레트, 저작 코드와 문서는 `originals/before-windup-hit-contrast-repair/`에 보존했다. 이전 두 교정의 원본도 각 `originals/` 폴더에 남아 있다. `author.py`와 이전 `repair.py`를 보존하고, 새 `repair_reaction_contrast.py`에 이번에 직접 고른 행/좌표 문자열을 기록했다. `repair.py`의 마지막 호출은 새 교정을 적용하므로 저작 보조 코드에도 현재 수정이 남는다. 전체 프레임 이동·회전·보간, 형상 래스터, 수식 명암, 자동 결손 채움, 생성 이미지, 다른 종 복제는 사용하지 않았다.

## 직접 수정한 부위

좌표는 각 96×96 셀의 왼쪽 위가 (0,0)이다. 정확한 모든 좌표/ASCII 문자열은 `repair_reaction_contrast.py`에 있고, 최종 전체 행은 pxgrid 파일에 있다.

### 준비 — windup

- 뒤 붓털과 기존 자루에서 어깨 앞을 거쳐 실제 주먹으로 들어가는 갈색 경로를 드러냈다. y49/x21 `.OrtO`, y50/x22 `OcOrtO`, y51/x24 `bOrtO`, y52/x26 `cOrtO`, y53/x27 `cOrtO`, y54/x28 `bbOrtO`로 자루/옷의 경계를 직접 선택했다. 다음 행의 나무 축은 주먹에 가려진다. 다른 방향으로 갈라진 나무 가지는 추가하지 않았다.
- 손은 x32–40/y53–58의 피부색 엄지·손등·손가락과 어두운 외곽으로 다시 찍었다. y58/x33 `OssrtO`에서 손가락 아래의 나무가 보이며, y59/x35 `cOrtO`, y60/x36 `cOO`로 짧은 자루 끝을 닫았다. 붓털 → 뒤 자루 → 피부색 파지 → 손 아래 자루가 한 축으로 읽힌다.
- x53/y49, x50/y50, x47/y51, x43/y52의 긴 밝은 소매 능선을 각각 짧은 `cc` 면으로 끊어 자루와 구별했다. 넓은 접힌 소매와 기존 지지발/앞 무릎은 보존했다.
- 확대에서 접속부를 다시 살펴 이전 자루의 남은 픽셀을 정리했다. 기존 밝은 `h/v`로 붓털의 왼쪽 위 면과 신발 윗면도 보강했다.

### 피격 — hit

회수와 거의 같은 수평 붓/소매를 유지하던 원안 대신, y43–80의 가슴·도포·소매를 직접 고른 새 행으로 찍었다. 갓·얼굴의 기존 기울기와 발 위치를 바탕으로, 뒤쪽 어깨의 넓은 밝은 면, 안으로 접힌 어두운 가슴 면, 더 높은 팔꿈치, 몸 쪽으로 돌아오는 아래팔을 구분했다. 두꺼운 위팔과 팔꿈치 면은 x51–63/y49–61에 별도 천 문자열로 보강했다. 얇은 도구 축을 팔로 대신하지 않았다.

손은 x54–61/y57–61로 당겼다. 붓자루는 (44,46) 부근에서 대각으로 내려와 손에 가려지고, x59–64/y62–65의 드러난 나무 목에서 x65/y65의 붓털로 이어진다. 이전 수평 자루와 오른쪽 파지는 제거했다. 검은 붓털은 별도의 사선 윤곽과 왼쪽 위 밝은 면을 갖는다. 얼굴 y33–34의 눈/눈썹도 짧게 접힌 군집으로 직접 바꿨다. 기존 지지 신발과 y92의 바닥은 유지하고 윗면의 작은 밝은 군집만 더했다.

실제 1배에서 회수의 넓은 앞 소매/수평 붓과 피격의 압축된 가슴/접힌 팔/아래로 처진 사선 붓이 구별된다. 팔 아래와 다리 사이의 외부 빈 공간은 보존했다.

### 붓털·신발 — idle와 다른 대응 자세

idle_a/b/c의 붓털 x61–65/y63–71에 폭 1–2px의 기존 `h/v`를 각 파일의 명시 목록으로 넣었다. 오른쪽 검은 그림자와 끝의 윤곽은 유지했다. x31/y85, x30/y86, x45/y85, x44/y86, x43/y87의 작은 신발 윗면도 보강하여 밝은 윗면과 어두운 밑창을 구분했다. 대기 세 자세의 천/수염/눈 변화와 단일 붓축은 그대로다.

move, attack, recover, dead, skill_a/c, poison_a/b, stun_a/b, sleep_a/b도 실제 대응 부위에서 짧은 붓털 윗면을 골랐다. 서 있는 자세의 신발에도 각각의 실제 위치에 작은 밝은 면을 넣었다. 다른 자세의 좌표를 자동 이동/복사하지 않았다. hit와 windup 이외에는 실루엣·팔·도포·표정·상태 효과를 보존했으며, 밝은 픽셀은 기존 불투명 재질 내부에만 있다.

### 묵류격 — skill_b

- 고체 붓의 x74–76/y50–53과 발사 시작점 근처 x79–84/y54–56에 짧은 `h/v` 면을 넣어 실제 붓털과 방출 먹을 구분했다.
- 위 덩어리 x84–86/y29–32, 가운데 덩어리 x89–91/y43–46, 아래 덩어리 x85–88/y60–63의 왼쪽 위에 각각 별도 밝은 군집을 찍었다. 1배에서 보강이 약하던 위/아래 윗면에는 두 픽셀의 `vv`도 직접 선택했다.
- 실제 붓털에 붙은 분출 시작점, 비대칭 세 덩어리의 검은 내부와 윤곽, 위 덩어리 아래 y39의 틈과 가운데/아래 덩어리 사이의 기존 투명 간격은 유지했다. 밝은 색으로 틈을 연결하거나 원형 오라를 만들지 않았다.

## 실제 이미지 확인과 파일 근거

- `previews/reaction-contrast-light.png`, `reaction-contrast-dark.png`, `reaction-contrast-checker.png`: 수정 전후의 실제 1배, 정확한 최근접 3배 전체와 부분 확대를 모두 열었다. windup의 자루/파지, hit의 가슴/팔꿈치/손/붓목, 대기 붓털, 세 먹물 덩어리를 비교했다.
- `previews/native-light.png`, `native-dark.png`, `native-checker.png`의 현재 18자세를 실제 열었다. 목/옷깃, 소매와 손, 무기 목, 신발, 의도한 빈 공간을 함께 확인했다. 수면의 낮춘 몸과 짧은 닫힌 눈, 독의 턱손, 기절의 처진 소매와 별은 기존 서로 다른 상태를 유지한다. 확대 체커에서도 이번 수정 부위에 의도하지 않은 몸 내부 투명 홈을 찾지 못했다.
- 현재 원본에서 개별 PNG, 기본/추가 3×3 PNG 시트와 8개 GIF를 다시 저장했다. 실제 GIF를 다시 읽은 `previews/gif-decoded.png`를 열어 공격의 준비→전진→접촉→회수, 새 피격→회수, 기술/상태의 프레임 순서를 확인했다. 각 GIF를 다시 읽어 원본 PNG를 검토 배경에 합성한 색과 정확히 일치함을 확인했다. 실제 게임 전투나 실시간 hop 궤적을 보았다고 주장하지 않는다.
- `render.py`의 파일 진단은 18개 모두 96×96, 기존 팔레트 기호, 1px 투명 테두리, 최하단 y≤92, idle_a의 정확한 y92 접지를 확인했다. PNG alpha는 0/255다. 18개 원본 배열은 모두 서로 다르다. 팔레트는 수정 전 파일과 동일하다.
- 전체 1,349픽셀이 바뀌었다. hit 1,086; windup 83; skill_b 31; idle 세 자세 각각 15. 나머지는 각 자세의 짧은 재질 면 보강이다. `previews/reaction-contrast-report.json`에 실제 전후 차이 좌표와 원본 파일 해시를 남겼다. 파일 해시는 검수 모델·승인·선택 기록이 아니다.

## 남은 표현 한계

검은 외곽과 그림자는 어두운 배경에서 계속 낮은 대비다. 짧은 밝은 면으로 붓털 끝과 먹 덩어리를 보강했지만, 가장 어두운 오른쪽 외곽까지 밝은 테두리로 바꾸지는 않았다. 작은 가운데 먹 덩어리는 native에서 여전히 작고, 96px 셀 오른쪽의 효과 공간은 좁다.

피격은 가슴을 접고 붓을 낮추는 단일 키프레임이다. 크게 뒤로 넘어가는 중간 자세는 없다. 공격의 머리 흔들림은 작고, 쓰러짐의 중간 낙하 프레임도 없다. 독/기절/수면 두 프레임의 호흡·표정 변화는 작다. GIF 프레임 비교와 파일 색 일치를 확인했으며 실시간 게임 재생/피해 타이밍은 이 source 수정 범위에 포함되지 않았다.

저장소 테스트·게이트와 별도 검수자 호출은 하지 않았다. 새 독립 검수는 하네스가 수행한다. 검수 결과/ledger/brief/게임 저장소는 수정하지 않았으며, 검수 통과나 사용자의 승인·선택을 선언하지 않는다.

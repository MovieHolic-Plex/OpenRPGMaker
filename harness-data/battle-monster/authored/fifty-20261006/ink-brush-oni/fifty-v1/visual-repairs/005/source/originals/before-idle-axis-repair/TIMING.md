# 먹붓귀 — 8동작 시간표

모든 원본은 96×96이다. 이동 보간, 전체 프레임 이동, 자동 중간 자세는 없다. GIF는 해당 리터럴 자세를 그대로 hold한다. 아래 시간은 저장된 GIF를 다시 읽어 확인했다.

| GIF | 프레임 순서 | hold (ms) |
|---|---|---|
| idle.gif | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack.gif | idle_a → windup → move → attack → recover → idle_a | 320 / 280 / 120 / 100 / 220 / 320 |
| hit.gif | idle_a → hit → recover → idle_a | 400 / 200 / 240 / 400 |
| dead.gif | idle_a → hit → dead | 360 / 180 / 1400 |
| skill.gif | idle_a → skill_a → skill_b → skill_c → idle_a | 320 / 400 / 180 / 320 / 400 |
| poison.gif | poison_a → poison_b | 440 / 440 |
| stun.gif | stun_a → stun_b | 520 / 520 |
| sleep.gif | sleep_a → sleep_b | 800 / 900 |

모든 GIF는 검토용으로 반복한다. dead의 반복도 자세 비교용이며 게임에서 부활한다는 의미는 아니다.

## 공격 연결과 체중

- windup: 손이 가슴 앞에서 자루를 감싼다. 뒤 지지발을 두고 앞 무릎을 굽힌다.
- move: 앞 어깨/넓은 소매가 전진하고 뒤 신발이 펴진다. 양발 최하단 y90인 짧은 도약이다.
- attack: 앞 엉덩이와 굵은 허벅지, 굽힌 무릎과 지지 신발이 다시 바닥 y92로 내려온다. 손목과 자루에서 오른쪽 아래 붓털로 이어지는 접촉 자세다. 타격 hold 100ms.
- recover: 팔꿈치가 몸 앞으로 접히고 손이 내려가 수평 자루를 쥔다. 교정한 손가락 x66–68/y64–66이 손바닥에서 y67–68의 자루까지 이어지고, 피부색 면이 나무 앞을 감싼다. hit도 같은 쥠 구조를 유지한다. 공격/피격 GIF의 시간과 순서는 바꾸지 않았다.

## 묵류격 앵커

좌표는 각 native 프레임의 0-based 좌표이고 프레임 전체 이동용 좌표가 아니다.

| 단계 | 잡은 손/자루 | 실제 붓털/효과 뿌리 | 역할 |
|---|---|---|---|
| skill_a | 손 약 (72,50), 자루 (72,49) | 붓털 x72–86/y21–36, 모으는 먹 x78–89/y17–29 | 400ms 준비, 붓끝에 먹이 모임 |
| skill_b | 손 x73–79/y54–57, 수평 자루 y54–56 | 붓털 오른쪽 약 (80,54), 세 갈래 뿌리 x78–86/y50–58 | 180ms 발사/접촉, 위·중앙·아래의 서로 다른 먹 덩어리 |
| skill_c | 손 약 (65,54), 세운 자루 x63–69/y34–59 | 붓털 x62–71/y22–33, 별도 파편 x69–87/y14–47 | 320ms 회수, 깨진 먹방울 |

붓털/자루/손의 관계는 각 자세에서 새로 고른 픽셀로 이어진다. 글자·한자·원형 오라는 없다. GIF는 효과 자세의 검토용이고 실제 발사체/피해 판정 또는 게임 전투 영상이 아니다.

이번 교정은 skill_b의 위/오른쪽 먹물 덩어리와 skill_c의 네 방울에 기존 회청색의 짧은 윗면만 넣었다. 붓털의 발사 뿌리, 손/자루 앵커, 세 갈래의 분리, 프레임별 hold는 유지했다. skill_c 실제 방울 윗면 좌표는 (75,15), (76,16), (80,20), (81,21), (79,36), (84,45)이다. 검수 메모의 대략 범위에 맞추기 위한 방울 이동은 하지 않았다.

## 상태 박자

독은 턱손·눈·가슴 면과 서로 다른 독방울로 바뀐다. 기절은 아래로 처진 머리/소매/무기를 유지하며 별의 위치와 손/눈/수염 면이 바뀐다. 수면은 앉은 몸의 신발·무기를 유지하고 가슴/등의 천 면과 짧은 수염을 바꾼다. 두 수면 프레임 모두 y54의 짧은 닫힌 눈꺼풀이다.

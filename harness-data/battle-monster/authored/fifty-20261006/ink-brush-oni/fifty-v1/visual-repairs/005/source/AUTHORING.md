# 먹붓귀 — 기술 회수·독 파지 교정

## 범위와 보존

2026-10-06에 전달된 실제 세 지적(skill_c, poison_a, poison_b)을 반영했다. 모든 쓰기는 이 후보의 source 안에서 했다. 다른 15자세의 원본 바이트와 기존 18색 palette.json은 수정 전과 같다. 기본 9자세와 추가 9자세는 모두 96행 × 96문자의 전체 리터럴 ASCII pxgrid이며, 18개 배열은 서로 다르다.

첨부 reference.png와 references/human-size.png를 실제 열어 성인 얼굴의 작은 우향 눈, 넓은 도포/소매, 붓과 손의 경계를 관찰했다. 참고 그림의 픽셀을 추출하거나 트레이싱하지 않았다. 기존 먹색 갓, 짧은 회백 수염, 회갈색 도포, 작은 신발과 나무 자루/검은 붓털의 정체성을 보존했다.

수정 전의 18자세, 팔레트, author.py, repair.py, repair_reaction_contrast.py와 문서는 originals/before-status-grip-repair/에 보존했다. 이전 수정 기록도 originals의 각 폴더에 그대로 남아 있다. 이번에 직접 고른 모든 좌표/행 문자열은 repair_status_grips.py에 있으며, 최종 배열은 actions/*.pxgrid에 생략 없이 저장했다. repair.py의 마지막에 이번 수정을 연결하여 기존 author.py 재저작 경로에서도 현재 파지가 유지되도록 했다.

전체 프레임 이동/회전/보간, 도형 래스터, 자동 구멍 채우기, 합성 명암, 생성 이미지, 다른 종 복제를 사용하지 않았다. 코드는 직접 지정한 짧은 ASCII 문자열을 해당 행에 기록하고, 원본을 읽어 PNG/GIF와 진단 확대를 굽는다.

## 실제 이미지 확인

- previews/status-grip-light.png, status-grip-dark.png, status-grip-checker.png를 모두 실제 열었다. 각각 수정 전후 전체 1배, 전체 최근접 3배와 국소 최근접 4배를 담는다. 기술 회수의 소매 경계/엄지/손 아래 자루와 독 두 자세의 손목/손가락/수평 자루를 확인했다.
- 현재 18자세의 native-light.png, native-dark.png, native-checker.png를 모두 열어 대응 손/붓, 목/옷깃, 어깨/소매, 신발과 의도한 빈 공간을 함께 확인했다. 세 수정 부위에서 새로운 투명 홈이나 떨어진 손 군집을 발견하지 못했다. 다른 15자세의 원본은 바이트 비교로도 동일하다.
- 개별 PNG, poses-sheet.png, actions-sheet.png와 8개 GIF를 현재 원본에서 다시 저장했다. 실제 저장 GIF를 다시 읽은 gif-decoded.png를 열어 기술의 모으기→발사→회수, 독의 두 파지, 기존 공격/피격/쓰러짐/기절/수면 프레임을 확인했다. 실시간 GIF 재생이나 실제 게임 런타임을 보았다고 주장하지 않는다.
- 렌더러의 파일 진단에서 모든 셀은 96×96, 기존 팔레트 기호, 1px 투명 테두리, 최하단 y≤92를 만족했고 idle_a의 최하단은 정확히 y92였다. PNG를 다시 읽어 alpha가 0/255임을 확인했다. 8개 GIF의 다시 읽은 hold는 TIMING.md의 표와 같다. GIF는 불투명 밝은 배경의 검토용이며 PNG/원본의 투명성을 대체하지 않는다.
- 이번 총 변경은 203픽셀이다. previews/status-grip-report.json에는 실제 변경 좌표/기호, 보존된 15자세와 현재 원본 파일 해시를 남겼다. file-report.json과 gif-report.json은 실제 다시 저장한 이미지 파일/hold의 진단 기록이다. 어떤 해시도 검수 모델 호출이나 사용자 선택의 증거로 제시하지 않는다.

## 남은 시각 문제와 확인 범위

검은 갓/붓털/신발의 가장 어두운 외곽은 어두운 배경에서 여전히 대비가 낮다. 기술 회수 주먹과 독 손가락은 작은 군집이므로 실제 1배에서 모든 손가락이 따로 읽히지는 않는다. 독 두 프레임의 몸과 파지 변화는 작고 주로 독방울 위치로 박자가 읽힌다. 이번 수정은 검토자가 지적한 국소 파지 연결에 한정했다.

기술은 세 핵심 자세이며 실제 발사체 진행/피해 동기화는 확인하지 않았다. 공격의 낙하 중간 자세와 쓰러짐의 중간 프레임이 없고, 실시간 hop 궤적과 전투 접촉은 이번 원본 교정에서 검증하지 않았다. GIF 디코딩 시트는 프레임 순서를 확인하는 자료이며 실시간 재생 품질을 증명하지 않는다.

저장소 테스트/게이트와 별도 검수자 호출은 하지 않았다. source 밖의 게임 저장소/ledger/brief/다른 후보/검수 결과는 수정하지 않았다. 새 독립 검수는 하네스가 수행한다. 검수 통과, 모델 출처, 사용자 승인이나 선택을 선언하지 않는다.

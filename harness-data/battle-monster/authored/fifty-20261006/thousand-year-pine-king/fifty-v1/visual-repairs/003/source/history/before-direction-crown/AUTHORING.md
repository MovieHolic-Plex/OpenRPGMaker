# 천년송왕 — 독립 지적에 따른 원본 교정

## 범위와 보존

이번 작업은 이 후보의 `source/`에만 저장했다. 저장소 코드, 게임 저장소, brief, ledger, 다른 후보, 기존 독립 검수 및 사용자 선택 기록은 수정하지 않았다. 별도 검수자를 호출하지 않았으며 통과나 사용자 승인을 선언하지 않는다.

첨부 `reference.png`와 `references/human-size.png`를 실제로 열어 관찰했다. 시트의 넓은 녹청 솔잎 관, 적갈 나무 면, 금빛 눈, 흰 뿌리수염과 가지팔의 연결을 기준으로 기존 정체성을 유지했다. 검객은 얼굴과 상대 크기만 관찰했으며 두 참고 이미지 모두 추출·트레이싱·리샘플·재배포하지 않았다.

- `poses/` 9개와 `actions/` 9개, 총 18개 full literal pxgrid를 유지했다.
- 팔레트 18색과 idle_a/b/c, windup, move, attack, recover, skill_a/c, poison_a/b, stun_a/b는 보존했다.
- 수정 원본은 sleep_a, sleep_b, hit, skill_b, dead의 다섯 장이다.
- 수정 전 다섯 원본은 `history/before-review-repair/`에 보존했다.
- 모든 새 잉크는 `repair_review.py`에 직접 고른 native 좌표와 ASCII 문자열로 기록했다. 자동 연결 채우기, 도형 래스터화, 생성 이미지, 프레임 전체 이동/회전/보간, 자동 명암은 사용하지 않았다. 최종 납품 원본은 전체 행으로 저장된 pxgrid다.

## 직접 고친 군집

### sleep_a

목 x=45–66, y=61–75의 나무 면을 새로 찍었다. 잘린 밝은 삼각 면 아래를 왼쪽 위 H/L 면, 적갈 B/S 그림자와 어두운 D 접힘으로 연결했다. 얼굴 앞에서는 외곽 K를 내부 D 면으로 바꾸어 세로 검은 절단선이 되지 않게 했다. x=62–64와 x=73–74, y=72에 짧은 감긴 눈꺼풀을 남겼다. 뒤팔 안쪽의 의도한 빈 공간과 접힌 두 뿌리발은 보존했다.

### sleep_b

목 x=46–66, y=62–76은 이 자세의 실제 위치에서 따로 저작했다. 노출된 쐐기를 옮기는 대신 같은 목/어깨 부피를 이었다. y=73의 두 짧은 감긴 눈과 내려온 얼굴을 유지했다. x=64–78, y=85–90의 수염 갈래/턱 면은 별도 문자열로 압축해 호흡에서 노출 윤곽도 바뀌게 했다. 수관, 어깨와 하중 발의 기존 쌍 구조는 남겼다.

### hit

얼굴 얼룩과 대기 몸통을 교체했다. 머리/위 줄기를 뒤로 젖히고, 몸통은 어깨에서 뒤로 압축되었다가 골반으로 이어지는 굽은 경로로 다시 찍었다. 같은 오른쪽 가지팔은 어깨→위팔→굵은 팔꿈치→접힌 아래팔→몸 가까운 손으로 연결된다. x=55–76, y=45–52에 어깨의 실제 나무 면을 추가했다. 두꺼운 뒤 뿌리와 꺾인 앞 지지 무릎/발목을 별도 저작하고 발바닥 y=124를 유지했다. 수관은 전체를 수학적으로 옮기지 않고 뒤로 쓸린 다층 윤곽과 면을 새 행으로 찍었다.

### skill_b

기존 두 상부 끝과 앞 뿌리발 연결은 유지했다. x=121–126, y=67–103에 별도 윤곽 끝과 굽은 세 번째 줄기를 찍고, x=112–126, y=95–116에서 굵어진 아래 나무 면을 실제 앞뿌리 접합으로 이었다. 세 상부 끝은 약 (105,49), (118,70), (125,67)이다. 가운데와 새 오른쪽 줄기 사이의 좁은 투명 틈을 남겼다. 낮은 왼쪽 포크를 세 번째 상부 끝으로 세지 않는다. 새 끝은 H/L 밝은 면과 B/S/D 어두운 측면으로 나뉜다.

### dead

x=44–83, y=72–103에 넓은 떨어진 솔잎 가지를 리터럴 군집으로 덧그렸다. 기존 왼쪽 수관 두 층을 지우지 않고 밝은 J 가장자리, G/V 기본 면과 U/K 아래 겹침을 추가해 오른쪽까지 수관 부피를 남겼다. x=42–59, y=94–101에 누운 줄기와 이어지는 굵은 목을 다시 찍었다. 감긴 얼굴, 흰 뿌리수염, 접힌 가지팔과 y=124의 하중 뿌리를 유지했다. 셀 위쪽 빈 공간을 확대하는 방법은 쓰지 않았다.

## 실제 미리보기에서 재교정한 부분

첫 피격 패치의 떨어져 보이는 오른쪽 어깨와 직각 수관 절단을 실제 PNG에서 확인하고 위 좌표의 어깨와 전체 수관 행을 다시 그렸다. 첫 쓰러짐 수관 패치가 기존 층을 지워 만든 직각 끝도 발견해, 기존 원본 위에 직접 고른 잉크만 겹치는 방식으로 고쳤다. 수면 목 수정이 왼쪽 감긴 눈꺼풀을 가리지 않도록 두 자세의 얼굴 띠를 각각 다시 찍었다.

## 원본·PNG·8 GIF

`render_pixels.py`로 전체 원본의 native PNG, 기본/추가 3×3 시트, 밝은/어두운/체커 1배 및 최근접 3배 확인판과 8 GIF를 갱신했다. GIF는 원본 색상 인덱스를 그대로 사용하며 실제 디코드된 각 프레임을 해당 원본 RGBA와 대조한다. `inspect_previews.py`는 실제 GIF 재읽기 확인판과 수정 다섯 장의 배경별 비교판을 만든다.

다음 실제 그림을 열어 확인했다: `png/all-checker-1x.png`, `review-after-light-3x.png`, `review-after-dark-3x.png`, `review-after-checker-1x.png`, `gif-readback-1x.png`. 대기→준비→전진→접촉→회수의 같은 가지팔, 수면 쌍의 얼굴/목과 발, 피격의 지지 무릎, 기술의 실제 앞뿌리 발원, 쓰러진 목/수관과 하중 윤곽을 함께 비교했다.

로컬 렌더에서는 128×128 행/셀, 팔레트 기호, 투명 테두리, 최하단 y≤124와 idle_a의 y=124 접지를 읽었다. `render-observations.json`은 현재 원본에서 계산한 크기/범위/해시 기록이다. 하네스 검사·독립 미감 검수·사용자 선택을 대신하지 않는다. 테스트와 게이트는 실행하지 않았다.

## 남은 시각적 한계

- 세 번째 뿌리의 상부는 셀 오른쪽 가장자리 제약으로 첫 줄기보다 가늘며, 두 줄기 사이 틈은 native 1–2px로 좁다. 독립 검수에서 세 갈래의 가독성을 다시 판단해야 한다.
- 피격 수관은 대기보다 가파른 잎 면으로 재저작되어 280ms 노출에서 변화가 크다. GIF 순서 비교는 실제 전투 속도/돌격 배치 검증이 아니다.
- 수면의 얼굴은 어두운 나무 면에 놓인 작은 감긴 눈이다. 호흡의 턱/수염/어깨 변화는 1배에서 작다. 접힌 팔 안쪽 공간은 의도된 여백이다.
- 쓰러짐은 층이 접힌 넓은 수관을 유지하지만, 세로로 서 있던 부피는 수평 겹침으로 압축된다.

새 독립 검수와 사용자의 선택은 하네스가 맡는다. 기존 검수 판정과 승인 기록을 조작하지 않았다.

## 재현

현재 격자 렌더: `python source/render_pixels.py` → `python source/inspect_previews.py`.
이번 리터럴 교정: `python source/repair_review.py`.
기존 저작부터 재구성: `python source/rebuild.py` (마지막에 이번 교정을 적용한다).
기존 저작 보조 코드도 보존했다. 위 명령은 source 내부 결과만 쓴다.

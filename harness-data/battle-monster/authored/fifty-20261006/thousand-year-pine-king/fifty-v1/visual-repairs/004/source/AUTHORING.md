# 천년송왕 — 피격 부피와 수면 수피 교정

## 작업 범위와 현재 원본

사용자가 지정한 피격 수관/줄기 부피와 수면 쌍의 수피 재질을 수정했다. 이 문서는 후보 저작 기록이며 독립 검수 결과 또는 사용자 승인 기록이 아니다. 별도 검수자를 호출하지 않았고 기존 판정/선택/게시 기록은 변경하지 않았다.

모든 쓰기는 이 후보의 `source/` 안에서만 했다. 최종 원본은 `poses/` 9장과 `actions/` 9장의 128×128 전체 ASCII 행이다. `.`은 투명이며 기존 `palette.json`의 18색은 그대로다. 이번 수정은 `hit`, `sleep_a`, `sleep_b`에만 적용했다. 다른 15자세와 팔레트는 보존 원본과 바이트가 같다. 기술 3자세, 독 2자세, 기절 2자세도 기존 전체 원본을 유지했다.

첨부 `reference.png`와 `references/human-size.png`를 실제로 열었다. 넓은 녹청 솔잎 관, 적갈 갈라진 줄기, 굽은 두 뿌리발, 굵은 가지팔, 오른쪽을 향한 금빛 눈과 흰 뿌리수염의 연결을 관찰했다. 검객은 얼굴 가독성과 크기 관찰에만 사용했다. 참고 이미지의 픽셀을 추출·트레이싱·변환하거나 원본/팩에 넣지 않았다.

## 명시적으로 저작한 픽셀

좌표는 0부터 센다. 새 저작 보조 코드 `repair_mass_bark.py`에는 각 목적 위치의 ASCII 문자열을 직접 기록했다. 수면 두 프레임의 문자열은 각 자세에 따로 썼다. 다른 프레임에서 읽은 좌표/군집을 자동 복사하지 않았다. 생성 이미지, 도형 래스터화, 프레임 전체 이동/회전/보간, 자동 명암, 자동 윤곽 정리나 구멍 채우기는 사용하지 않았다.

### hit — 수관

기존 왼쪽 솔잎 층과 목 접합을 보존하고 x=37–89, y=12–41에 넓은 오른쪽 가지 층을 직접 저작했다. 위쪽의 서로 다른 솔잎 끝, G의 넓은 기본 면, J의 밝은 능선, V/U의 겹침 아래 면과 K의 단계형 끝을 연결했다. 반동은 높은 오른쪽 가지 끝과 젖혀진 목/어깨에서 읽히도록 했다.

첫 렌더에서 새 앞쪽 능선이 길고 매끈한 대각 띠처럼 보였다. x=42–76, y=22–35의 실제 문자열을 다시 골라 불규칙한 기본색 면과 짧게 갈라지는 솔잎 능선으로 바꿨다. 최종 수관의 녹색 잉크 폭은 x=9–88로, 대기 a의 x=9–87과 비슷하다. 녹색 군집의 높이는 hit y=8–43, idle_a y=7–44다. 폭/면적 수치는 질량 연속성 확인용이며 시각적 합격 기준은 아니다.

### hit — 줄기

x=32–71, y=72–99에서 기존 좁은 허리를 두꺼운 휘어진 줄기로 다시 찍었다. 왼쪽 밝은 H/L 면과 B/S의 중간 면, 넓은 D의 갈라진 수피 속, 균열 안쪽에 노출된 각진 B/L 능선을 유지했다. 가장 좁던 부위에 잃어버린 나무 부피를 보탰으며 아래로 이어지는 골반/뿌리의 경계를 기존 발에 연결했다.

얼굴·눈·수염은 수정하지 않았다. 접힌 오른쪽 타격 팔과 왼쪽 가지팔의 기존 관절 경로, 발목/발끝과 y=124 지지 윤곽도 유지했다. 넓어진 줄기와 회수 자세의 큰 수피 면을 실제 1배/확대로 비교했다.

### sleep_a / sleep_b — 수피

각 프레임의 x=50–60, y=60–98에 독립적인 문자열을 썼다. 매끈한 세로 주황 면에 깊은 굽은 D/S 균열을 복원하고, 그 위·아래로 갈라지는 B/L 능선과 짧은 H 밝은 면을 찍었다. 큰 위쪽 수피 cleft, 가슴 옆의 작은 각진 능선, 접힌 골반으로 이어지는 아래 cleft가 같은 나무 재질로 읽히도록 했다.

감긴 눈꺼풀, 우향 코/턱, 흰 뿌리수염, 목/수관, 두 접힌 가지팔과 두 굽은 뿌리발은 보존했다. b의 내려온 턱과 압축된 오른쪽 어깨/팔, 다른 관 끝도 남아 있다. 새 수피는 이 실제 호흡 쌍을 따라 각각 저작한 것이며 몸 전체를 옮기거나 색만 바꾼 프레임이 아니다. 팔 안쪽과 두 발 사이의 의도한 투명 공간은 채우지 않았다.

## 보존과 실제 이미지 확인

수정 직전 18장, 팔레트, 기존 AUTHORING/TIMING은 `history/before-mass-bark-repair/`에 보존했다. 이전 저작과 `history/before-direction-crown/`, `history/before-review-repair/`도 남겼다. `rebuild.py`의 마지막 저작 단계에 이번 명시 좌표 수정을 추가했다.

`render_pixels.py`로 native PNG 18장, 기본/추가 시트, 밝은/어두운/체커 1배 및 최근접 3배 시트와 8 GIF를 갱신했다. GIF는 기존 팔레트 인덱스를 직접 기록하며 모든 프레임을 실제 디코드해 해당 pxgrid 렌더와 대조한다. `inspect_previews.py`는 디코드된 GIF의 프레임 순서/노출 시간을 그림으로 보여 준다. `inspect_mass_bark.py`는 보존 원본과 현재 원본을 읽어 전후 비교판과 실제 차이 수치를 만든다. 확대/배경/라벨은 진단 표시이며 원본 저작에 사용하지 않는다.

실제로 열어 확인한 그림:

- 첨부 두 참고 이미지, 수정 전 `detail-hit-4x.png`, 두 수면 확대와 전체 체커 1배.
- 수정 중/후 hit와 sleep_a/b의 최근접 4배 및 `review-after-light-1x.png`.
- 전체 18자세의 밝은/어두운 1배, 수정 후 체커 3배.
- 최종 `mass-bark-light-1x/3x.png`, `mass-bark-dark-1x/3x.png`, `mass-bark-checker-1x/3x.png`의 전후 비교.
- 실제 8 GIF에서 다시 디코드한 `gif-readback-1x.png` 전체 프레임.

피격의 관-목-어깨 연결과 줄기/팔 사이의 경계, 수면의 짧은 닫힌 눈과 수염 연결, 두 접힌 다리의 발끝을 확인했다. 다른 15자세에도 같은 부위의 의도하지 않은 투명 홈이나 끊긴 팔/발 윤곽이 보이는지 함께 보았다. 이번 확인에서 추가로 고칠 같은 결손은 찾지 않았다. 기준 대기의 실제 발은 y=124에 있고 18장 모두 1px 투명 테두리와 최하단 y=124를 유지한다. 읽기/렌더 관찰은 테스트·게이트·독립 미감 판정이 아니다. 테스트와 게이트는 실행하지 않았다.

`mass-bark-changes.json`은 현재/보존 pxgrid의 실제 해시와 픽셀 차이만 기록한다. hit 1,484픽셀, sleep_a/b 각 235픽셀이 달라졌으며 다른 15장에는 변화가 없다. `render-observations.json` 역시 현재 파일에서 계산한 값이다. 모델·독립 판정·사용자의 선택 또는 출판 해시를 꾸민 기록이 아니다.

## 남은 시각적 문제와 확인 한계

- hit의 앞쪽 솔잎 층은 대기보다 위로 들린 사선이 강하다. 크기 연속성은 개선했으나 같은 관의 반동으로 읽히는지는 새 독립 검수 대상이다.
- 수면 수관의 능선은 여전히 대기보다 촘촘하고 평평하다. 수피 cleft는 복원했으며 호흡 변화는 기존 턱/어깨/관 끝의 작은 변화여서 1배에서는 미묘하다.
- 기존 기술의 가장 오른쪽 뿌리 끝은 셀 여백 제약으로 가늘다. 이번 수피/피격 수정에서 기술을 다시 저작하지 않았다.
- 실제 전투의 돌격 궤적·상대 접촉·보스 표시 크기·재생 시간 감각은 이 로컬 프레임 비교로 확정하지 않았다.

새 독립 검수와 사용자 선택은 하네스가 맡는다. 이 후보의 통과나 승인 상태를 선언하지 않는다.

## 다시 렌더하기

현재 원본 렌더: `python source/render_pixels.py` → `python source/inspect_previews.py` → `python source/inspect_mass_bark.py`.

이번 좌표 수정 적용: `python source/repair_mass_bark.py`.

전체 기존 저작부터 재구성: `python source/rebuild.py` 후 `python source/inspect_mass_bark.py`.

`preview.html`에서 기존 8 GIF를 비교할 수 있다. GIF 순서·노출 시간과 기술 발원점은 `TIMING.md`에 기록했다.

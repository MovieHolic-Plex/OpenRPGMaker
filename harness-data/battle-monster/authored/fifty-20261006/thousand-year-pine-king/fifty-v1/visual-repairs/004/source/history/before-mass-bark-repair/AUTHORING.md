# 천년송왕 — 우향 얼굴·피격·수면 수관 교정

## 현재 작업과 원본

이번 교정은 사용자에게 제시된 세 가지 지적에 따른 **후보 원본 수정**이다. 별도 검수자를 호출하지 않았다. 새 독립 검수 결과나 사용자 승인·선택을 만들지 않았으며, 통과했다고 선언하지 않는다.

첨부 `reference.png`와 `references/human-size.png`를 실제로 열었다. 천년송왕 시트에서 적갈 줄기, 두 굽은 뿌리발, 굵은 가지팔, 넓은 녹청 솔잎 관, 금빛 눈, 흰 뿌리수염과 왼쪽 위 광원의 큰 면을 관찰했다. 검객은 얼굴 가독성과 크기만 관찰했다. 참고 이미지의 픽셀은 추출·트레이싱·리샘플하거나 원본에 넣지 않았다.

최종 원본은 `poses/` 9장과 `actions/` 9장의 **128×128 전체 ASCII 행**이다. `palette.json`은 기존 18색을 그대로 유지한다. `dead`는 이번 교정 전과 바이트가 같다. 다른 17장은 지적된 얼굴·수관·수염 주변의 실제 좌표를 수정했다. 기본 공격 팔과 뿌리발, 기술의 핵/뿌리/파편, 독의 거품, 기절의 별과 수면의 접힌 팔다리는 기존 저작을 보존했다.

수정 전 18개 원본과 문서는 `history/before-direction-crown/`에 있다. 더 이전의 `history/before-review-repair/`와 기존 저작 보조 코드도 남겨 두었다. 이번 저작 보조 코드는 `repair_direction_crown.py`와 `awake_face_rows.txt`다. 각 자세의 목적 좌표와 리터럴 문자열을 따로 기록했다. 한 프레임의 픽셀이나 좌표를 읽어서 다른 프레임에 복사하지 않는다. 생성 이미지, 도형 래스터화, 프레임 전체 이동/회전/보간, 자동 명암, 자동 연결·구멍 채우기를 사용하지 않았다. 피격 수관의 이전 잉크 영역을 지우는 코드는 새 잉크를 선택하지 않으며, 새 수관은 아래에 별도로 쓴 문자열만으로 구성된다.

## 직접 고친 부위 (0부터 세는 좌표)

### 1. 대기와 나머지 깨어 있는 얼굴

`idle_a/b/c`, `windup`, `move`, `attack`, `recover`, `skill_a/b/c`는 각 파일에서 x=54–76, y=49–59의 눈썹·눈·볼 면을 교정했다. 먼 눈은 x=60 부근의 한 픽셀 금빛과 좁은 그늘로 줄였다. 가까운 눈은 x=69–71 부근에 두고 그 앞에 코와 볼의 나무 면을 남겼다. x=77–81, y=53–59의 코 끝과 어두운 겹침 경계가 오른쪽 어깨 앞에 놓인다. 기존 정면의 넓은 눈 두 개와 공격/기술 얼굴에 남아 있던 추가 금빛 얼룩을 제거했다.

x=52–81, y=60–77의 이전 중앙 수염 부착 면을 다시 찍었다. 왼쪽은 붉고 어두운 나무 면으로 돌아가고, 수염은 오른쪽 턱 아래에서 시작한다. F/C/W의 넓은 밝은 뿌리 면, 갈래 사이 어두운 접힘, 가늘어진 끝을 유지했다. 대기 b/c와 전진에서는 수염 갈래를 해당 자세의 문자열로 따로 조절했다. 줄기 외곽, 목과 어깨의 기존 하중 연결은 남겼다.

`poison_a/b`는 x=61–78, y=55–63에서 같은 우향 코/턱을 아픈 작은 눈과 연결했다. 수염은 x=59–81, y=64–77에서 다시 달았다. `poison_b`의 턱을 받치는 실제 가지 손 앞에서는 수염 일부를 겹침 경계로 줄여 손을 덮지 않았다. 거품 위치와 구부린 팔의 차이는 보존했다.

`stun_a/b`는 x=61–78, y=56–63의 처진 눈꺼풀·코·턱을 따로 찍었다. 수염 부착은 x=59–81, y=64–78이며 b에서는 턱 아래로 늦게 시작한다. 처진 가지팔과 서로 다른 별 위치는 보존했다. 기절 표정에 평상시의 활짝 노출된 금빛 눈을 억지로 붙이지 않았다.

### 2. 피격

`hit`의 x=8–81, y=7–43 수관을 새 리터럴 행으로 교체했다. 몇 개의 매끈한 긴 잎 칼날 대신 위로 튀어나온 솔잎 끝, 겹친 넓은 가지 층과 G/J 기본·빛 면, V/U 겹침 그림자를 찍었다. 각 층의 능선은 중간에 갈라지고 합쳐지는 별도 군집이다. 수관 아래의 굵은 가지가 뒤로 젖힌 목으로 이어진다.

x=43–66, y=48–57의 얼굴은 같은 먼 눈/가까운 눈/오른쪽 코 구조를 피격 각도에 맞춰 다시 그렸다. x=43–64, y=58–71의 수염은 이전보다 넓고 길며 두세 갈래 뿌리 면을 남긴다. 기존 뒤로 휜 줄기, 기울어진 어깨, 접힌 오른팔, 굵은 두 지지 뿌리와 y=124 접지는 보존했다.

첫 확대에서 수관 아래의 옛 가는 수평 띠가 새 층과 어색하게 겹치는 것을 발견했다. x=24–41, y=39–43을 별도의 겹친 아래 가지로 다시 찍고, x=10–23, y=43의 남은 띠를 명시적으로 지웠다. 연결 검사 결과로 자동으로 채운 작업이 아니다.

### 3. 수면 쌍

`sleep_a/b`의 수관은 x=8–80, y=26–61에 각각 따로 쓴 행으로 저작했다. 기존보다 위와 왼쪽으로 실제 솔잎 군집을 늘려 여러 겹의 나뭇가지와 바늘 같은 끝을 복원했다. 큰 G 기본 면, J 밝은 능선, V/U 겹침과 K 윤곽이 같은 나무 관의 층을 이룬다. b의 오른쪽 끝은 독립적으로 압축한 군집이며 프레임 전체 이동으로 만들지 않았다.

x=61–79, y=69–77(a) / y=70–78(b)의 얼굴은 짧은 두 감긴 눈꺼풀과 우향 코·턱으로 다시 찍었다. 원본 1배에서 금빛 열린 눈이 남지 않은 것을 확인했다. x=61–81, y=77–91(a) / y=78–91(b)의 수염은 대기와 같은 흰 뿌리 재질의 넓은 면과 갈래를 유지한다. b는 턱과 수염의 시작이 내려오고 코/턱 노출 윤곽이 달라진다. 기존 오른쪽 어깨/팔 압축과 두 접힌 뿌리발의 접지는 유지한다.

수관을 바꾼 첫 확대에서 a의 x=76–80, y=46–51에 이전 오른쪽 잎 끝이 남아 각진 갈고리처럼 보였다. 그 군집을 직접 지우고, 두 수면의 x=68–79, y=52–57은 실제 목의 어두운 나무 면과 단계형 외곽으로 교정했다. 의도한 팔 안쪽과 두 발 사이 공간은 남겼다.

## 실제 PNG와 GIF 확인

`render_pixels.py`로 18개 native PNG, 기본/추가 시트, 밝은·어두운·체커 1배/최근접 3배 시트와 8개 GIF를 갱신했다. GIF는 기존 18색에 투명 인덱스를 더해 원본 픽셀을 그대로 기록한다. 이 렌더러는 GIF를 실제로 다시 디코드하여 각 프레임 RGBA를 해당 pxgrid 렌더와 대조한다. `inspect_previews.py`는 실제 디코드된 프레임 순서와 수정 부위 비교판을 만든다.

이번에 실제로 연 그림:

- 수정 전 첨부 두 이미지, 기존 `all-checker-1x.png`, `detail-hit-4x.png`, `detail-sleep_a-4x.png`.
- 수정 중·후 `idle-a-backgrounds-3x.png`, `review-after-light-3x.png`, `review-after-dark-3x.png`, `review-after-light-1x.png`, `review-after-checker-3x.png`, `detail-hit-4x.png`.
- 전체 자세의 `all-checker-1x.png`, `all-dark-1x.png`, 최종 `all-light-1x.png`와 `gif-readback-1x.png`.

얼굴 수정이 준비→전진→내려치기→회수에서 같은 가지팔을 끊지 않는지, 독에서 수염과 턱을 받치는 손의 경계가 남는지, 수면의 목/관/팔/발이 같은 나무 해부로 이어지는지 함께 보았다. 로컬 렌더에서 18장 모두 128×128, 팔레트 기호, 투명 테두리와 최하단 y=124를 읽었다. 대기 a의 실제 뿌리발도 y=124에 있다. 이 읽기·렌더 관찰은 테스트/게이트 또는 독립 미감 판정이 아니다. 테스트와 게이트는 실행하지 않았다.

`render-observations.json`의 해시는 현재 파일에서 계산한 값이다. `direction-crown-changes.json`은 보존 원본과 현재 원본의 실제 픽셀 차이와 범위만 기록한다. 검수 모델, 판정, 출판 해시나 사용자의 선택을 꾸민 기록이 아니다.

## 남은 시각적 한계

- 먼 눈은 의도적으로 native 1px 금빛이어서 어두운 배경의 1배에서는 작게 읽힌다. 새 얼굴의 우향 가독성은 독립 검수에서 다시 판단해야 한다.
- 수면 수관의 능선은 대기의 불규칙한 넓은 능선보다 촘촘하고 평평하게 포개진다. 관·수염 부피는 복원했지만 같은 재질/층으로 읽히는지는 새 검수 대상이다.
- 수면 호흡은 턱·수염 시작과 오른쪽 관 끝·어깨의 작은 변화다. 크게 들썩이는 동작으로 만들지 않았으며 1배에서 변화는 작다.
- 피격 머리와 관은 뒤로 젖힌 몸에 붙어 있어 대기와 겹침 형태가 달라진다. 실제 전투 충돌, 돌격 배치, 화면상 보스 크기와 시간 감각은 이 정적 PNG/프레임 확인만으로 검증하지 않았다.
- 기존 기술 세 번째 줄기 끝은 셀 오른쪽 제약으로 여전히 가늘다. 이번 지적의 얼굴/관 교정 범위에서 기술 효과 자체를 다시 만들지는 않았다.

새 독립 검수와 사용자의 선택은 하네스가 맡는다.

- 이번 교정 적용: `python source/repair_direction_crown.py`.
- 기존 저작부터 재구성: `python source/rebuild.py` (기존 교정 뒤 이번 교정을 적용).

모든 쓰기 결과는 이 후보의 `source/` 안에 있다.

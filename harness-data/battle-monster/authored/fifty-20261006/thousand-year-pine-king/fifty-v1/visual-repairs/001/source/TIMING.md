# 천년송왕 — native128 동작 시간표

모든 프레임은 128×128 원본이다. 프레임 중간 보간/확대 도트/프레임 회전은 없다.
GIF는 원본 18색과 투명 인덱스를 직접 사용한다. 확대는 확인용 PNG와 HTML 표시에서만 최근접 방식이다.

| GIF | 원본 자세 순서 | 각 노출 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 300 / 330 / 100 / 220 / 240 / 350 |
| hit | idle_a → hit → recover → idle_a | 300 / 280 / 220 / 350 |
| dead | idle_a → hit → dead | 280 / 170 / 1300 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 300 / 420 / 360 / 300 / 350 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 450 / 450 |
| sleep | sleep_a → sleep_b | 720 / 720 |

## 신체·기술 앵커

좌표는 0부터 센다. 기본 발바닥/쓰러진 하중 뿌리는 y=124에 놓였다.

- 같은 오른쪽 가지팔: 어깨 약 (79,53). 준비에서 위팔과 팔꿈치를 위·뒤로 접고 손가락 뿌리를 (84,24) 주변에 모은다. 전진에서 팔꿈치를 (103,59) 주변으로 펼친다. 타격에서는 (103,82)의 압축된 손목 아래 (106,99–111)의 넓은 가지 손바닥과 세 갈래 끝을 내려친다. 반대 팔은 몸 왼쪽 가드로 접는다.
- 천근박 준비: 두 가지 손을 배 앞에 접는다. 발원점은 손이나 화면 중앙이 아닌 **앞 뿌리발**이다. 녹금 핵은 x=86–103, y=106–121이며 실제 앞발 나무 면에 붙는다.
- 천근박 접촉: 앞발 주변 하중 뿌리에서 세 줄기가 솟는다. 큰 위쪽 끝 약 (105,49), 오른쪽 끝 약 (119,70), 낮은 왼쪽 끝 약 (92,77). 각 뿌리의 굽음·너비·끝이 다르며 갈래 사이 투명을 남긴다. 아래 (103,113) 부근에는 금빛 수액 면이 있다.
- 천근박 회수: 접힌 손, 앞발에 연결된 짧은 절단 뿌리와 x=99–126, y=78–104의 직접 저작한 나무 파편. 떠 있는 파편은 의도된 효과다.
- 수면: 두 굽은 뿌리발은 같은 접지로 유지한다. sleep_b는 눈을 감은 채 턱/수염 군집이 한 줄 내려오고 오른쪽 어깨가 압축된다. 수관의 오른쪽 솔잎 가지도 별도로 접힌 윤곽이다.

GIF는 반복 비교용이라 dead도 마지막 노출 뒤 첫 자세로 되돌아간다.
이 시간표는 이 후보의 자체 미리보기용이며 게임 런타임에 동작을 설치한 기록이 아니다.

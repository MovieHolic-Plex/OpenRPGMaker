# 천년송왕 — 원본 18자세 저작 기록

## 범위와 관찰

이 후보의 `source`에만 썼다. brief/기존 후보/게임 저장소/ledger/선택/독립 검수 기록은 수정하지 않았다.
제공된 `references/human-size.png`를 실제로 열어 64px 검객의 작은 얼굴, 몸/팔의 연결, 발과 전체 크기를 관찰했다. 참고 픽셀을 추출·복사·리샘플하거나 이 폴더에 재배포하지 않았다. 나무 왕의 팔/목/뿌리 구조는 별도 원본이다.

- native128 원본 18자세: `poses` 9개 + `actions` 9개.
- `palette.json`: 투명 `.`을 제외한 ASCII 기호 18개. 적갈 나무 6단계, 녹청 솔잎 5단계, 뿌리수염 3단계, 금빛 3단계, 독 보라색 1단계.
- 최종 pxgrid는 모든 파일이 128개 ASCII 행 × 128칸이다. 보조 코드의 각 잉크 군집도 직접 고른 좌표와 리터럴 문자열이다.
- 공유된 불변 나무/솔잎 군집은 보존하고, 바뀐 관절/얼굴/뿌리/효과는 각 자세의 실제 위치에서 직접 저작했다. 원·다각형·선의 래스터화, 자동 명암, 프레임 전체 이동·회전·보간, 자동 구멍 채우기는 사용하지 않았다.

## 외형·광원

왼쪽 위의 황토색 넓은 나무 면, 오른쪽 적갈 그림자, 갈라진 깊은 나무 골을 나누었다.
층이 겹친 녹청 솔잎 관과 굵은 목으로 줄기를 연결했다. 금빛 두 눈과 코 앞 밝은 나무 면, 흰 뿌리수염을 둔다.
수관·몸통·두 굽은 뿌리발의 전체 실루엣은 약 119px의 세로 영역을 사용한다. 팔은 어깨·위팔·팔꿈치·아래팔·가지 손을 잇는 나무 면을 가진다.

## 자세별 실제 변경

- idle_b/c: 수염의 갈래/굽음, 손의 이완과 솔잎의 겹침 면을 각각 직접 바꿨다. 전체 몸 이동은 없다.
- windup: 오른쪽 가지 손을 위·뒤로 접었다. 반대 팔은 왼쪽에서 가드한다.
- move: 긴 앞 뿌리 디딤, 뒤 뿌리의 밀기, 구부러진 배와 전진한 오른팔을 따로 저작했다.
- attack: 동일한 오른쪽 어깨에서 내려온 팔과 압축 손목, 넓은 손바닥 및 세 갈래 끝. 이동과 다른 접촉 자세다.
- recover: 가지팔과 수염을 회수한다.
- hit: 금빛 평상시 눈을 없애 찡그린 눈/턱과 비대칭 어깨를 직접 찍었다.
- dead: 낮게 접힌 두 솔잎 덩어리, 누운 줄기, 이어진 목/감긴 눈, 별도 경계의 두 접힌 가지팔, 하중 뿌리를 독립적으로 저작했다.
- skill_a/b/c: 두 손의 접기, 실제 앞뿌리의 녹금 핵, 서로 다른 세 큰 뿌리 줄기, 절단 뿌리와 파편을 직접 저작했다. 원 오라는 없다.
- poison_a/b: 내려온 머리, 아픈 가슴/턱을 짚는 가지 손, 다른 가드 팔, 각각 다른 크기/위치의 독 방울.
- stun_a/b: 처진 머리와 감긴 눈, 늘어진 가지 손가락, 각각 별도로 찍힌 별의 위치/모양.
- sleep_a/b: 낮아진 다층 수관, 넓은 목과 감긴 짧은 눈꺼풀, 접힌 가지팔, 무릎처럼 굽은 두 뿌리발을 남겼다. 두 번째 프레임의 턱/수염 하강과 어깨 압축, 솔잎 윤곽을 따로 찍어 호흡을 보였다.

## 실제 그림에서 발견하고 고친 좌표

1. 첫 idle_a의 수관/어깨가 떨어져 보여 목 x=43–69, y=31–46과 어깨의 나무 면을 저작했다. 겹침 순서를 정리해 오른쪽 금빛 눈이 어깨에 가려지지 않게 했다.
2. 초기 수관 오른쪽 추가 조각은 떠 있는 솔잎처럼 보여 폐기하고 x=61, y=17에서 시작하는 연결된 오른쪽 가지로 다시 찍었다.
3. 초기 수면은 수관과 몸이 별개였고 sleep_b의 오른쪽 어깨가 없었다. sleep_a의 목 x=45, y=51, sleep_b의 목 x=46, y=52를 직접 저작했다. 두 자세의 머리/짧은 감긴 눈/수염은 각각 x=49, y=64에서 다시 찍었다.
4. 확대 확인 뒤 수면 오른팔의 시작이 목과 여전히 떨어져 보여 sleep_a x=75, y=68과 sleep_b x=75, y=69의 어깨→위팔 경로를 각각 새 문자열로 찍었다. 감긴 눈꺼풀을 그 앞에 다시 남겼다.
5. 초기 dead의 수관이 별개였고 하중 줄기는 y=123보다 위였다. x=31, y=91의 굵은 나무 목, x=38, y=78의 접힌 솔잎 덩어리, x=26, y=115의 굽은 하중 뿌리를 직접 저작해 몸의 실제 윤곽이 y=124에 닿게 했다.
6. move와 attack의 허리/뿌리 접합은 수평 절단처럼 보여 각각 x=45, y=96에서 선택한 나무 면을 직접 고쳤다. 두 다리 사이의 의도한 빈 공간은 남겼다.

## 자체 PNG/GIF 확인

`png/all-light-1x.png`, `all-dark-1x.png`, `all-light-3x.png`, `all-checker-3x.png` 및 실제 GIF를 다시 읽어 만든 `gif-readback-1x.png`를 열어 확인했다.
18개의 원본 PNG, 3×3 기본/추가 시트, 밝은/어두운/체커 확인판과 원본 크기 8개 GIF를 보존했다.
렌더러는 PNG를 원본 색/0·255 알파로 쓰고 GIF의 모든 프레임을 다시 읽어 같은 원본 RGBA와 비교한다.
`render-observations.json`은 실제 원본 해시와 크기/범위에 대한 로컬 렌더 기록이며 독립 검수 판정이 아니다.

## 남은 시각적 한계 / 판단 범위

- 솔잎은 넓은 층과 짧은 계단 윤곽으로 표현되어 개별 바늘보다 덩어리로 읽힌다.
- 공격은 네 핵심 자세를 짧게 연결하므로 대기→전진의 하중 변화가 빠르다. 수관의 대기 운동은 작다.
- 수면 호흡은 턱/수염 1px 변화와 어깨/솔잎 압축이라 1배에서는 작게 보인다.
- 기술 접촉의 세 뿌리는 합류하는 아래 면이 겹친다. 위쪽 세 끝과 갈래 사이 빈틈으로 구별한다.

별도 검수자는 호출하지 않았다. 하네스의 실제 독립 검수와 사용자 판단은 아직 이 저작 기록의 범위 밖이다. 승인/통과를 주장하거나 모델·판정 기록을 만들어 넣지 않았다.

# 천년송왕 — 쓰러짐 가지팔 접합부 교정

## 범위와 원본

이번 작업은 현재 독립 검수에서 지적한 `dead`의 오른쪽 굽은 가지팔 연결부만 수정했다. 후보 저작 기록이며 검수 통과나 사용자 승인을 선언하지 않는다. 별도 검수자를 호출하지 않았다.

쓰기 대상은 이 후보의 `source/`뿐이다. 원본은 `poses/` 9장과 `actions/` 9장의 전체 128×128 ASCII 행이다. 기존 18색 `palette.json`과 다른 17자세는 수정 직전 원본과 바이트가 같다. 기술·독·기절·수면의 9장도 기존 서로 다른 전체 격자를 보존했다. 다른 후보, 저장소 코드, 게임 저장소, brief, ledger와 검수 결과는 변경하지 않았다.

첨부 `reference.png` 및 `references/human-size.png`를 실제로 열었다. 녹청의 층진 솔잎 관, 적갈의 갈라진 큰 줄기 면, 우향 금빛 눈, 흰 뿌리수염과 굵은 가지팔을 관찰했다. 검객은 크기와 얼굴의 읽힘을 관찰하는 용도로만 보았다. 두 참고 이미지에서 픽셀을 추출하거나 트레이싱·변환·복제하지 않았다.

## 직접 고른 변경 군집

좌표는 0부터 센다. 기존 오른쪽 팔의 첫 갈색 면은 x95, y107 부근에 있었고, 본체 쪽으로 거슬러 올라가면 흰 수염이 연결을 대신하는 모습이었다.

`repair_dead_branch.py`에 아래 여섯 ASCII 문자열을 따로 저작했다. 적용 후 `poses/dead.pxgrid`는 부분 패치가 아닌 전체 128행 원본으로 저장되어 있다.

| 시작 x | y | literal pixels |
|---|---|---|
| 84 | 100 | `BLLBBSSK` |
| 84 | 101 | `LLHHLLBBSSK` |
| 84 | 102 | `BLHHHLLBBSSK` |
| 89 | 103 | `SLHHLLBBSSK` |
| 91 | 104 | `SLHHLLBBSSK` |
| 92 | 105 | `SLHHLLBBSSK` |

x84–102, y100–105에 어깨에서 바깥 팔로 내려가는 굵은 갈색 나무 면을 만들었다. H/L의 왼쪽 위 밝은 면, B의 기본 면, S의 아래 그늘과 K의 단계형 바깥 경계가 기존 팔꿈치/아래팔 x95–105, y106–111로 이어진다. 기존 어깨 안쪽의 D/S 면에서 가지 밝은 면으로 넘어가므로 외곽선끼리만 접하는 연결이 아니다.

흰 수염 W/C/F 군집은 한 픽셀도 바꾸지 않았다. 수염 위·오른쪽으로 갈색 연결 경로가 보이고 수염은 그 아래를 겹쳐 덮는 독립 뿌리털로 남는다. 수염 밑과 굽은 팔 안쪽의 의도한 투명 틈도 유지했다. 낮은 수관, 쓰러진 줄기, 접힌 뿌리와 실제 하중 윤곽 y124는 그대로다.

실제 차이는 `dead` 63픽셀이다. 자동 도형, 명암 합성, 프레임 전체 이동/회전/보간, 다른 자세의 좌표 복사, 자동 연결 채우기와 이미지 생성은 사용하지 않았다.

## 보존·재렌더·실제 확인

수정 직전 18장, 팔레트와 AUTHORING/TIMING은 `history/before-dead-branch-repair/`에 보존했다. 기존 저작 보조 코드와 이전 교정 이력도 남아 있다. `rebuild.py`의 마지막 저작 단계에 새 리터럴 패치를 추가해 재구성 시 이번 수정을 잃지 않게 했다. 이번 작업에서는 전체 재저작을 실행하지 않고 현재 원본에 새 패치만 적용했다.

`render_pixels.py`로 18장의 native PNG, 두 3×3 시트, 전체 밝은/어두운/체커 1배·최근접 3배 시트와 8 GIF를 다시 저장했다. 렌더러는 ASCII 인덱스를 그대로 RGBA/GIF 팔레트에 기록한다. GIF를 실제 디코드한 각 프레임은 대응 원본 RGBA와 일치했다. `inspect_previews.py`는 실제 디코드된 GIF에서 프레임과 노출 시간을 다시 표시했다.

실제로 열어 본 결과:

- 첨부 참고 2장과 수정 전 쓰러짐 4배 그림.
- `dead-branch-light-1x.png`, 밝은/어두운/체커의 `dead-branch-*-3x.png` 전후 비교판.
- 전체 18자세의 `all-light-1x.png`, `all-dark-1x.png`, `all-checker-3x.png`.
- 실제 8 GIF 프레임을 다시 읽은 `gif-readback-1x.png`.

1배에서도 어깨 옆에서 시작한 갈색 가지가 수염 위로 지나 오른쪽 굽은 팔에 이어짐을 확인했다. 확대에서는 수염의 밝은 면·어두운 가장자리와 그 뒤의 나무 면을 따로 확인했다. 다른 17자세의 같은 어깨/팔/수염 경로도 전체 그림에서 비교했으며 이번 쓰러짐과 같은 결손은 발견하지 않았다. 기존 공격의 준비→전진→내려치기→회수, 뿌리 기술 3단계와 상태별 서로 다른 자세는 보존되어 있다.

`dead-branch-changes.json`은 보존/현재 원본에서 계산한 해시와 실제 변경 좌표만 기록한다. `render-observations.json`은 현재 격자의 크기·팔레트·투명 경계·최하단 위치를 읽은 기록이다. 모든 원본의 최하단 잉크는 y124이고 idle_a의 실제 발도 y124에 남는다. 이 읽기/렌더 확인은 테스트·게이트나 독립 미감 판정이 아니다. 테스트·게이트는 실행하지 않았다.

## 남은 시각적 문제와 한계

- 쓰러짐의 새 위팔은 작은 사선 면이라 수염에 가려지는 일부 나무 폭의 읽힘은 새 독립 검수에서 다시 판단해야 한다.
- 기존 수면의 호흡 차이는 작고, 수관 능선은 대기보다 촘촘하다. 기존 기술의 가장 오른쪽 뿌리는 여백 제약으로 가늘다. 이번 지정 수정에서는 이 자세를 보존했다.
- PNG/GIF 프레임 확인으로 실제 전투의 돌격 거리·상대 접촉·보스 표시 크기나 재생 시간 감각을 확정하지 않았다.

새 독립 검수는 하네스가 맡는다. 현재 검수 결과나 사용자 선택 기록을 만들거나 바꾸지 않았다.

## 다시 렌더하기

- 명시 좌표 적용: `python source/repair_dead_branch.py`
- 현재 원본 렌더: `python source/render_pixels.py`
- GIF 프레임 표시: `python source/inspect_previews.py`
- 전후 그림과 실제 차이 기록: `python source/inspect_dead_branch.py`

8 GIF는 `gif/` 및 `preview.html`에 있다. 순서·노출 시간·공격/기술 발원점과 쓰러짐 팔 경로는 `TIMING.md`에 기록했다.

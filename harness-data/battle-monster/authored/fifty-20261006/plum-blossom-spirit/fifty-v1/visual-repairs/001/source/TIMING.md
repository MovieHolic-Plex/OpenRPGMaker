# 매화정 GIF 시간표

파일은 native 96×96, 투명 배경, 명시 팔레트다. 반복 재생하며 프레임 보간은 없다.
시간 단위는 ms이고 모두 GIF의 10ms 단위로 저장된다.

| GIF | 순서와 노출 시간 |
|---|---|
| idle | idle_a 240 → idle_b 240 → idle_c 240 |
| attack | idle_a 240 → windup 260 → move 140 → attack 180 → recover 220 → idle_a 300 |
| hit | idle_a 240 → hit 260 → recover 220 → idle_a 300 |
| dead | idle_a 240 → hit 200 → dead 1100 |
| skill | idle_a 240 → skill_a 420 → skill_b 260 → skill_c 380 → idle_a 300 |
| poison | poison_a 380 → poison_b 380 |
| stun | stun_a 440 → stun_b 440 |
| sleep | sleep_a 600 → sleep_b 600 |

## 공격·기술 앵커

- windup: 허리 앞의 두 손으로 꽃을 모은다. 뒷발은 뒤꿈치를 들어 밀 준비를 한다.
- move: 치마 아래 앞무릎·정강이가 나타나며 앞발을 심는다.
- attack: 꽃가지와 손목을 앞으로 편 순간이 접촉 프레임이다.
  꽃은 대략 x=80~87, y=38~44, 손은 그 왼쪽 아래 소매 끝에 있다.
- skill_a: 꽃의 분홍 P 핵은 (68~69, 37~38), 줄기는 y=41~44를 통해
  x=63~68, y=45~48의 실제 손과 소매로 이어진다. 작은 향기 조각은 따로 흩어진다.
- skill_b: 꽃을 어깨 높이로 낮추어 앞에 내민다. 손·자루는 x=64~70,
  y=45~47 부근이다. 핵 주변 꽃잎에서 x=65~75, y=40~48의 명시 뿌리로
  세 날빛이 갈라진다. 위 갈래는 y=20 쪽으로 가늘게 길고,
  가운데는 x=93 쪽으로 넓게 말리며, 아래는 y=59 쪽으로 벌어진 꽃잎이다.
- skill_c: 손은 오른쪽 허리로 돌아오며 꽃자루를 아래로 내린다.
  작은 꽃은 x=59~63, y=64~67 부근이며 흩어진 꽃잎은 각각 다른 위치에 떨어진다.
- sleep: 꽃자루를 무릎 위 손에서 오른쪽으로 낮추고, 닫힌 눈과 두 접힌 발은 유지한다.
  600ms마다 저고리의 가슴 면과 손 주변 천 면이 변해 얕은 숨을 표현한다.

`render.py`가 시간표를 적용한다. `diagnostics/gif-*-decoded.png`는
저장된 GIF를 다시 읽은 실제 프레임·노출 시간 확인판이다.
동작 미리보기는 전투 엔진의 피해·이동·발사체 구현이나 실전 게임 영상이 아니다.

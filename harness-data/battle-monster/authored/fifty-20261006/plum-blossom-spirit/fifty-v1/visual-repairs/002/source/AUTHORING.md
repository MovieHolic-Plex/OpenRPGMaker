# 매화정 — 직접 도트 저작 기록

이 후보의 저작 범위는 이 `source/`뿐이다. 기본 9자세와 기술·상태 9자세를 작성했다.
사용자 선택이나 독립 검수 결과를 기록한 문서가 아니다. 별도 검수자를 호출하지 않았다.

## 관찰과 원본

첨부 `human-size.png`를 실제로 열어 작은 우향 눈, 눈앞의 코·볼 여백,
목에서 옷깃으로 이어지는 면, 소매 끝의 손과 도구 연결을 관찰했다.
참고 그림의 픽셀 추출·트레이싱·재배포는 하지 않았다.
초기 저작 기록에서는 빈 캔버스에서 매화정을 찍었다. 이번 피격 교정은 이미 존재하는
18장의 source 격자와 첨부된 현재 시트를 읽고 시작했다. 참고 그림은 관찰만 했다.

정본 그림은 `palette.json`, `poses/*.pxgrid`, `actions/*.pxgrid`다.
18장의 최종 격자는 각각 96행 × 96 ASCII 문자이며 점은 투명이다.
팔레트는 18색, RGBA 알파는 0/255다. 모든 자세의 가장자리 1px는 투명하고
최하단 그림은 y=92다. 기본 대기 발도 정확히 y=92에 닿는다.
`diagnostics/format-report.json`은 실제 격자와 RGBA 바이트의 해시 및 형식 관찰값이다.
형식 확인은 그림의 미감 합격을 뜻하지 않는다.

## 그림의 구조

- 검은 올림머리와 붉은 머리핀, 작은 성인 얼굴, 연속된 목·옷깃을 직접 골랐다.
  대기 머리 높이는 약 23px, 서 있는 본체는 y=18~92를 사용한다.
- 광원은 왼쪽 위다. 머리는 h의 짧은 쓸린 면, 피부는 b/a/A의 볼·턱 면,
  저고리는 넓은 W/c 면과 오른쪽 C 그림자, 치마는 P/r/R의 겹친 주름으로 나눴다.
  꽃은 F/p와 Y 꽃술, 기술 핵은 P, 나무는 B/O, 잎은 g/G다.
- 뒤 가지는 실제 어깨 쪽까지 이어지는 나무 군집과 작은 꽃을 갖는다.
  앞 손은 꽃자루를 감싸며 소매·손목·자루가 이어진다.
- windup은 허리에 꽃을 모으는 두 굽힌 팔과 뒤꿈치 밀기다.
  move/attack은 겹치마가 벌어져 앞무릎과 아래 다리 면이 드러나고,
  다른 지지발이 뒤에서 민다. attack은 어깨·팔꿈치·손목을 펴 꽃가지를 휘두른다.
  recover는 팔꿈치를 다시 접고 꽃을 낮춘다.
- 현재 hit은 뒤로 젖힌 머리·목, 감긴 충격 눈과 조인 입, 들린 뒤 어깨와
  허리까지 이어지는 휜 저고리다. dead는 바닥에 놓인 머리·몸·치마와
  접힌 두 신발 및 닫힌 눈이다. 수면은 별도의 앉은 본체와 접힌 치마,
  두 발끝, 무릎 위 손, 낮은 꽃자루를 갖는다.
- poison은 턱을 짚는 손과 배를 감싸는 팔, 굽힌 몸과 서로 다른 녹색 방울이다.
  stun은 앞으로 처진 새 머리, 아래로 늘어진 팔과 꽃, 다른 위치의 별이다.
  sleep 두 장은 짧은 닫힌 눈꺼풀을 유지하고 가슴·옷 면으로 숨을 표현한다.
- skill은 손 꽃송이의 분홍 핵에서 모으고, 꽃잎 가장자리를 뿌리로
  위·앞·아래의 세 꽃잎 날빛을 펼친 뒤, 꽃손을 낮추고 깨진 꽃잎을 남긴다.

## 직접 교정한 좌표

좌표는 0부터 시작한다. 자동 연결 채우기는 사용하지 않았다.

1. 기본 대기의 떨어진 꽃손: x=56~73, y=51~56의 앞소매·팔꿈치·손목을
   새 문자열로 골라 꽃을 쥔 손까지 연결했다. idle_b/c는 각 자세의 손목 높이와
   소매 주름을 개별 행으로 다시 골랐다.
2. 회수의 두 조각 자루: recover의 x=55~68, y=58~63에서 왼쪽으로 향하던
   잘못된 자루를 지우고 손에서 오른쪽 아래 꽃으로 이어지는 B/O 군집을 찍었다.
   hit은 다른 위치인 x=55~66, y=60~64에서 손·나무 연결을 따로 고쳤다.
3. skill_a의 중복 꽃: x=58~78, y=42~48에서 하단의 잘못된 꽃송이를 지우고,
   위쪽 하나의 꽃에서 손으로 내려오는 자루와 손가락·소매를 직접 찍었다.
4. skill_b의 끊긴 날빛 뿌리: x=65~75, y=40~48의 꽃잎 군집을 고쳐
   세 날빛이 실제 꽃 가장자리에서 출발하게 했다.
5. poison_a/b: 각자의 x=52~58, y=35~43에 뺨 아래 손가락·손목·옷 소매를
   다시 골라 턱을 짚는 행동을 보여 줬다.
6. sleep_a/b: x=44~58, y=54~56의 눈·얼굴을 실제 1배로 확인하며,
   동그란 검은 눈 대신 짧은 A 눈꺼풀과 피부 여백을 골랐다.
   sleep_b의 y=68~79는 호흡 중 겹쳐 보이던 손을 없애도록 전체 해당 행을 다시 썼다.
7. sleep_b의 호흡 행에 지워진 뒤 가지: (28,68), (29,69), (30,70),
   (31,71), (32,72)에 각각 `OBBO`를 명시했다. stun_a는 x=24~, y=34~40,
   stun_b는 x=24~, y=35~41의 꽃·갈래를 개별 문자열로 복원했다.

## 이번 독립 지적에 따른 피격 교정

지적은 기존 hit의 (48,38) 주변 머리·목·어깨와 (46,55) 몸통에 반동을 이어 주고,
(51,30) 주변의 평온한 열린 눈을 충격 표정으로 바꾸라는 내용이었다.
기존 hit은 recover와 너무 비슷했다. 다른 자세에 같은 좌표를 복사하지 않았다.

- `repair_hit.py`의 x=24, y=17~57 행 문자열을 직접 골랐다. 새 머리의 뒤쪽
  외곽은 x=29~38, y=20~34로 뻗으며, 붉은 머리핀과 쓸린 머리 빛 면을 다시 찍었다.
  머리 전체를 이동·회전하는 연산은 없다.
- 새 얼굴의 x=38~50, y=26~32에서 열린 검은 눈을 없애고 짧은 `A` 눈꺼풀,
  조인 눈썹·볼 음영과 작은 입을 각각 골랐다. 머리의 새 위치에서 눈앞 피부 여백을 남겼다.
- x=41~49, y=35~40의 목과 옷깃을 피부·천 군집으로 이어 주었다.
  x=29~55, y=41~54의 뒤 어깨·가슴·옆구리는 뒤로 휜 외곽과 넓은 W/c/C 면이다.
  x=37~48, y=54~57에서 저고리가 붉은 허리끈으로 이어진다.
- 첫 PNG 확인에서 y=41~45의 앞 어깨 끝이 안으로 한 번 꺾이는 것을 보고,
  y=42~45의 끝을 개별 행으로 다시 골라 둥근 소매 외곽으로 이었다.
  y=36~37의 목 옆 머리 끝과 y=54의 소매 끝도 직접 정리했다.
- 소매와 실제 손, 손 아래 꽃자루는 연결되어 있다. 팔과 몸통 사이의 빈 공간은
  의도한 팔꿈치 틈이며 메우지 않았다. y=58~95의 손·자루·꽃·치마·두 발은 원본 그대로다.
  발바닥의 최하단은 계속 y=92다.

직전 hit 원본은 `revisions/hit-before-recoil/hit.pxgrid`와 `hit.png`에 보존했다.
같은 폴더의 `source-hashes.json`과 현재 파일을 비교한 결과, 팔레트와 다른 17격자는
바뀌지 않았다. 실제 변경은 hit의 783픽셀, 경계 x=29~58 / y=17~57이다.
`diagnostics/hit-recoil-scope.json`은 파일·좌표 범위 기록이며 검수 판정이 아니다.

`author_pixels.py`의 마지막에 이 직접 행 교정을 적용해, 초기 저작 보조 코드를 다시
실행해도 예전의 곧게 선 hit으로 돌아가지 않게 했다. 현재 최종 원본은 여전히
96행 × 96열 전체 리터럴 `poses/hit.pxgrid`다.

## 보조 코드와 실제 그림 확인

`author_pixels.py`는 직접 고른 행 문자열·좌표의 저작 기록이다.
변하지 않는 부위는 보존하며, 바뀌는 관절·표정·천 면·효과는 명시 문자열로 썼다.
빈 캔버스 초기화와 행 교체 외에 도형 마스크·전체 프레임 이동·회전·보간·
참고 추출·자동 명암·자동 구멍 채우기는 없다.

`render.py`는 최종 격자 읽기, PNG/GIF 기록, 최근접 확대, 배경·라벨만 담당한다.
그림 픽셀을 새로 만들거나 수정하지 않는다. 재생 파일은 `gif/`의 8개다.
`png/all-18.png`는 투명한 native 3열 × 6행 시트다.

최종 `all-18-{light,dark,checker}-{1x,3x}.png` 여섯 장을 실제로 열었다.
8개 GIF를 다시 디코딩한 `gif-*-decoded.png`도 모두 열어 관절 연결,
손/자루 위치, 치마/다리 전환, 닫힌 눈과 프레임 간 위치 변화를 비교했다.
이것은 연속 프레임 시각 확인이며 실제 게임 전투 재생 검증은 아니다.
초기 교정 전 확인판은 `diagnostics/first-pass/`에 보존했다.

이번 교정에서도 18자세의 밝은·어두운·체커 배경 1배/최근접 3배 시트를 실제로 열었다.
최종 hit은 `diagnostics/hit-recoil-{light,dark,checker}-{1x,3x}.png`에서
직전 hit 및 recover와 나란히 열어 확인했다. 뒤로 젖힌 상체, 눈을 조인 얼굴,
목·옷깃·소매 연결을 비교했다. 새 투명한 목 홈이나 가로 삭제 줄은 지목하지 않았다.
8개 GIF를 재출력했으며, 변경된 hit/dead GIF의 실제 디코딩 프레임도 열어
대기→피격→회수와 대기→피격→바닥 쓰러짐을 비교했다.
독립 검수자를 호출하거나 검수 결과·사용자 선택을 수정하지 않았다. 새 독립 판정은 아직 없다.

## 남은 표현 한계

- 어두운 배경에서는 검은 머리와 신발의 가장 바깥 윤곽 대비가 낮다.
  머리의 왼쪽 h 면과 신발의 h/c 면으로 구조를 읽히게 했지만 최종 미감 판단이 필요하다.
- idle과 수면의 숨 변화는 작다. 큰 몸 이동 없이 옷 면과 손목으로 표현했으므로
  실제 표시 크기에서 느껴지는 정도를 사용자가 판단해야 한다.
- 꽃송이는 작은 물체여서 1배의 다섯 꽃잎과 손가락은 간략한 군집이다.
  기술의 긴 꽃잎 날빛이 꽃잎으로 충분히 읽히는지는 독립 검수에서 확인할 대상이다.
- 현재 작가의 마지막 육안 확인에서 추가로 지목한 끊긴 관절은 없다.
  이는 독립 검수 통과나 사용자 승인을 선언하는 문장이 아니다.
- 수정된 피격의 머리·몸통 반동은 회수와 구별되지만, 작은 눈꺼풀 음영의 긴장도와
  260ms 피격 정지의 체감은 실제 전투 화면에서 아직 확인하지 않았다.

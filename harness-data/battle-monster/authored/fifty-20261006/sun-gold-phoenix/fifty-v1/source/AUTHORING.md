# 일금봉황 — 공격 관절 / 두 갈래 일염익 수정

## 원본과 범위

이 후보의 source 안에서만 작업했다. poses 9장과 actions 9장이 현재 전체 리터럴 ASCII 원본이다. 각 장은 128행 × 128글자이며 점만 투명이다. 공격과 기술 발동 두 장만 수정했다. 다른 16장과 17색 팔레트는 이번 수정 전과 바이트가 같다.

제공된 reference.png와 references/human-size.png를 실제로 열었다. 긴 금빛 부리/볏, 넓은 날개, 청동 발, 위왼쪽 광원을 관찰했다. 인간형은 크기와 작은 얼굴의 가독성 관찰에만 사용했다. 참고 이미지를 추출·복사·트레이싱하지 않았다.

이번 수정 직전 18장/팔레트/문서/시간표는 before-joint-flame-repair에 보존했다. 더 이전 원안은 기존 original-before-repair에 남아 있다. 이전 문서의 좌표는 당시 판본의 설명이며 현재 기술 앵커는 아래와 TIMING.md를 따른다.

## 직접 선택한 변경

좌표는 셀 좌상단 기준 0부터 시작한다. 새 행/좌표 문자열은 repair_joint_flame.py에 있다. 코드가 지정 문자열과 선택한 삭제 구역의 투명을 쓰고 최종 파일에 전체 128글자 행을 저장한다. 도형/명암 수식, 전체 프레임 이동·회전·보간, 자동 연결·구멍 채우기, 이미지 생성은 사용하지 않았다. 기존 literal_clusters.py, pose_clusters.py, action_clusters.py, repair_native.py도 보존했다. write_candidate.py는 기존 원본 작성 뒤 이번 리터럴 수정을 적용한다.

| 자세 | 직접 수정한 군집 |

| attack | x80–123, y94–117. 가슴 아래 주홍/금빛 허벅지를 앞으로 굽히고 청동 무릎을 노출했다. 다리가 뒤로 접혔다가 발목에서 오른쪽으로 돌아 세 굽은 발톱으로 이어지도록 각 행을 찍었다. 옛 x82–84, y106–112의 수직 잔여선을 지웠다. 접지한 반대쪽 지지발과 y124 바닥 픽셀은 그대로다. |

기술에서 새 목이 날개/몸에 닿는 어깨와 가슴 윗면도 직접 연결했다. 첫 출력에서 발견한 x74–96, y63–87의 수평 잘림/직각 가슴 단차를 넓은 깃 면과 완만한 외곽 행으로 고쳤다. 다음 출력의 y76/77 경계도 직접 다시 선택하여 마무리했다. 이는 좌표별 재저작이며 연결 검사로 채운 결과가 아니다.

기본 날개 사이, 다리 사이, 벌어진 부리 틈, 기술 두 갈래 사이는 의도한 공간이다. 다른 상태의 보라 기포·금빛 별·닫힌 눈/웅크림도 보존했다.

## 결과와 실제 확인

- png: 18개 투명 native PNG와 기본/추가 3×3 시트.
- gif: 대기·공격·피격·쓰러짐·기술·독·기절·수면 8개 GIF.
- preview/index.html: 8 GIF, 정지, 배율과 밝음/어두움/체커 배경 선택.
- preview/native-contact.png: 원본 1배. enlarged-contact.png: 최근접 3배. backgrounds-*.png: 세 배경 최근접 4배.
- preview/gif-*-decoded.png: 저장 GIF를 다시 연 전 프레임 비교판.
- preview/artifact-diagnostics.json: 실제 현재 원본/RGBA 해시, ink bounds, 순서/노출 시간.

현재 원본 1배, 3배 시트와 공격/기술의 밝음·어두움·체커 확대판을 실제로 열었다. 허벅지→무릎→접힌 다리→발목→발톱, 입→금백 뿌리→두 갈래, 목/어깨/가슴을 확인했다. 저장한 8개 GIF의 전 프레임 디코드판도 열어 준비→전진→접촉→회수, 독/기절의 입자 변화, 수면의 작은 숨 변화를 살폈다.

package_art.py가 실제 GIF를 다시 열어 각 프레임 RGBA를 해당 원본과 대조했다. 18개가 서로 다른 그림이며 128×128, alpha 0/255, 1px 투명 테두리, 최하단 y≤124, idle_a y124 접지가 유지된다. 테스트/게이트는 실행하지 않았다.

## 남은 시각적 한계

- 불꽃은 128px 안에 담긴 양식화된 두 금빛 혀로 읽힌다. 금백 중심이 강하다. 긴 불꽃의 세부 난류나 중간 진행 프레임은 추가하지 않았다.
- 공격 날개는 기존 이동의 펼친 날개를 보존했다. 접촉 차이는 낮게 뻗은 목과 새로 굽힌 다리/발톱에 집중되어 있다.
- 대기와 상태 두 프레임 변화는 작다. 기술의 머리 뒤젖힘과 회수는 각각 한 장의 핵심 자세이며 중간 보간은 없다.
- 정지 이미지와 저장 GIF 디코드판을 확인했다. 실제 속도로 브라우저/전투를 관찰하지 않았으므로 체감 튐, 피해 접촉과 발 미끄러짐은 확정하지 않는다. dead 끝의 대기 복귀는 미리보기 루프다.

이 문서는 원본 수정 기록이다. 사용자 승인/Allow/검수 합격을 선언하지 않는다. 독립 검수자를 직접 호출하지 않았고 검수 기록·ledger·brief·게임 저장소를 수정하지 않았다. 모델/출처 기록은 실제 하네스 기록에 맡긴다.

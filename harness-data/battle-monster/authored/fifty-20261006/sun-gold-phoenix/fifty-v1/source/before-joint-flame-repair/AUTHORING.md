# 일금봉황 — 지적 좌표 직접 수정

## 범위와 원본

이번 작업은 이 후보의 `source/` 안에만 저장했다. 팔레트 17색은 수정 전과 바이트가 같다. 현재 원본은 `poses/` 9장과 `actions/` 9장의 전체 리터럴 ASCII 격자다. 각 장은 128행 × 128글자이며 점만 투명이다.

수정 전 18장·팔레트·저작 기록·시간표는 `original-before-repair/`에 보존했다. 새로 직접 선택한 행과 좌표는 `repair_native.py`에 있다. 기존 `literal_clusters.py`, `pose_clusters.py`, `action_clusters.py`도 보존했다. 같은 해부 부위의 기존 목 군집은 원래 좌표의 리터럴 문자열을 재사용했고, 지적된 부위는 새 문자열을 직접 골랐다.

`write_candidate.py`는 기존 저작 문자열을 쓰고 마지막에 현재 수정 행을 적용한다. `repair_native.py`는 보존된 수정 전 격자를 읽고 지정한 리터럴 행을 적용한다. 빈칸 패딩은 선택한 구역의 투명 캔버스다. 모양·명암 계산, 원/다각형, 전체 프레임 이동·회전·보간, 자동 구멍 채우기, 이미지 생성이나 참고 픽셀 추출은 사용하지 않았다.

제공된 `reference.png`와 `human-size.png`를 실제로 열었다. 봉황의 넓은 주홍/금빛 날개, 세 갈래 꼬리, 청동 발과 위왼쪽 광원을 관찰했다. 인간 참고는 작은 얼굴의 원본 가독성과 관절 연결 관찰에만 사용했고 참고 이미지를 source에 복사하지 않았다.

## 확대에서 발견하고 직접 교정한 곳

- 가슴을 좁힌 뒤 얇아진 엉덩이/정강이 이음: x80–90, y101–105에 청동 허벅지와 겹친 배 깃을 직접 찍었다. 이동의 대각선 정강이와 공격의 별도 뻗은 발을 유지했다.
- 공격 목을 고친 뒤 남은 옛 윤곽 점: x75–76, y45–47 및 x73–76, y62–64의 지목한 잔여 픽셀만 지웠다.
- 부분 가슴 교체의 수평 경계: 전체 곡면을 먼저 찍고 원래 좌표의 목 리터럴 군집을 앞에 겹쳐 독/이동/기술의 가슴 중간 경계를 없앴다.
- 초기 수면 수정의 곧은 목 뒤와 수평 부리: 낮은 곡선과 하향 갈고리의 새 행으로 다시 고쳤다. 눈 밑 점은 금색으로 바꾸어 닫힌 눈 선만 남겼다.
- 기술 목 앞 직선과 아래 불꽃의 긴 직선: x84–107, y53–80의 목 곡선과 x112–125, y65–95의 휘고 좁아지는 불꽃 행을 새로 골랐다.

다리 사이, 펼친 날개 사이, 부리 아래 갈고리의 빈 공간과 입 틈은 의도한 투명/어두운 구역이다. 자동 연결/구멍 채우기로 수정하지 않았다.

## 저장과 실제 확인

- `png/`: 현재 18개 native PNG와 기본/추가 3×3 시트.
- `gif/`: 대기·공격·피격·쓰러짐·기술·독·기절·수면의 현재 8 GIF.
- `preview/index.html`: 8 GIF, 일시 정지, 원본 배율, 밝음/어두움/체커 배경 선택.
- `preview/native-contact.png`: 원본 1배. `enlarged-contact.png`: 최근접 3배. `backgrounds-1.png`부터 `backgrounds-6.png`: 밝음/어두움/체커 최근접 4배.
- `preview/gif-*-decoded.png`: 저장한 GIF를 실제로 다시 읽은 전 프레임 비교판.

현재 1배 비교판과 밝음/어두움/체커 확대판을 열어 부리, 가슴 외곽, 목/어깨, 허벅지/발목 연결을 확인했다. 8개 GIF의 디코드 비교판도 열어 준비→전진→접촉→회수와 상태 두 프레임의 배열을 확인했다. 이는 저장된 프레임의 시각 확인이며 실시간 전투 재생을 관찰한 것은 아니다.

`package_art.py`는 격자를 디코드하고 저장한 GIF의 RGBA를 같은 원본 PNG와 다시 대조한다. 현재 18개가 서로 다른 그림이고 128×128/불투명 17색/alpha 0·255/1px 투명 테두리/최하단 y≤124/idle_a y124 접지가 유지된다. 실제 파일 및 RGBA SHA-256, 노출 시간과 ink bounds는 `preview/artifact-diagnostics.json`에 있다. 테스트·게이트는 실행하지 않았다.

## 남은 시각적 한계

- 가슴 덮깃은 몇 개의 큰 밝은 면으로 강조되어 있다. 촘촘한 잔깃보다 양식화된 넓은 면으로 읽힌다.
- 공격은 이동의 펼친 날개 군집을 보존했다. 전진한 낮은 목과 뻗은 세 발톱으로 접촉을 구분하며 날개 자체의 추가 변형은 작다.
- 기술 두 갈래는 셀 오른쪽 가장자리 안에 들어오므로 하향 갈래가 다시 안쪽으로 굽는다. 실제 대상 접촉 위치/피해 시점은 런타임에서 확인하지 않았다.
- 수면 호흡과 대기 변화는 작다. 죽음 GIF 마지막에서 대기로 돌아오는 것은 검토 루프이며 게임 사망 복구를 뜻하지 않는다.
- 디코드판은 프레임 배열을 보여 준다. 실시간 속도감, 프레임 사이의 체감 튐, 실제 전투 접지는 독립 하네스의 재생 검토가 남아 있다.

이번 문서는 수정 기록이다. 검수 합격·사용자 승인·Allow를 선언하거나 기록하지 않았다. 독립 검수자를 직접 호출하지 않았으며 검수 결과·ledger·brief·게임 저장소는 수정하지 않았다. 저작 모델/출처는 하네스의 실제 기록에 맡긴다.

# 일금봉황 — 현재 8 GIF 시간표

각 프레임은 전체 128×128 리터럴 원본이다. 원본 팔레트를 그대로 디코드하며 전체 프레임 이동·회전·보간을 사용하지 않는다. 아래 시간은 ms이며 저장 GIF 재읽기 시간은 `preview/artifact-diagnostics.json`에도 있다.

| GIF | 순서 | 유지 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240 / 180 / 110 / 160 / 220 / 280 |
| hit | idle_a → hit → recover → idle_a | 240 / 280 / 180 / 280 |
| dead | idle_a → hit → dead | 240 / 200 / 1100 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240 / 360 / 300 / 260 / 300 |
| poison | poison_a → poison_b | 360 / 360 |
| stun | stun_a → stun_b | 360 / 360 |
| sleep | sleep_a → sleep_b | 600 / 600 |

## 물리 공격

windup: 목/어깨를 굽히고 날개를 접어 준비한다. move: 펼친 날개와 전진 착지발, 뒤발 밀기를 보여 준다. attack: 목을 더 낮고 길게 앞으로 뻗으며 눈은 (102,62), 금 부리 접촉 끝은 약 (120,66)에 있다. 오른쪽으로 뻗은 발가락/굽은 발톱은 약 (120,102), (121,109), (114,112)이고 허벅지/발목과 연결된다. 뒤 지지발은 y124에 남는다. recover: 목과 날개를 회수한다.

공격의 펼친 날개는 이동의 좋은 군집을 유지했다. 타격 차이는 목과 발가락의 새 배열에 집중한다. 위 시간은 검토 GIF용이며 실제 런타임 피해 판정 시점을 정의하지 않는다.

## 일염익 — 입 앵커

손이나 무기를 쓰지 않는 생물이며 발사 앵커는 실제 입이다.

- **skill_a / 360ms:** 가까운 날개 밑 약 (69,78)의 금백 핵에 힘을 모은다. 몸/깃의 금빛 흐름과 핵이 닿는다.
- **skill_b / 300ms:** 위아래 부리가 벌어진다. 입 안 짙은 틈은 x92–98, y47–49이고 금백 핵은 x101–104, y47–50이다. 핵은 입 틈과 오른쪽 불꽃 뿌리에 연속된다. 위 갈래는 (121,34) 쪽으로 솟고 아래 갈래는 x112–125, y55–92를 따라 길게 휘고 찢어진다. 옛 목 아래 발사 핵은 제거했다.
- **skill_c / 260ms:** 목/날개를 접고 세 잔불을 약 (107,54), (117,74), (103,92)에 남긴다. 세 잔불은 각기 다른 리터럴 군집이다.

## 상태와 루프

독: 아픈 턱/볼과 긴장한 날개, 서로 다른 위치의 기포. 기절: 처진 목/깃과 위치가 다른 별. 수면: 낮게 웅크린 살아 있는 몸, 아래로 숙인 부리와 (77–79,89)의 닫힌 눈. 두 수면 프레임의 눈/부리 위치는 같고 어깨/배와 목 빛 면에 작은 숨 변화가 있다.

dead의 1100ms 유지 후 idle로 돌아오는 것은 검토 반복이다. 실제 사망 상태가 되살아나는 동작을 지정하지 않는다. 실제 전투 속도/접촉/루프 자연스러움은 이번 source 저작에서 확인하지 않았다.

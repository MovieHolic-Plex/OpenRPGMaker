# 일금봉황 — fifty-v1 저작 기록

## 범위와 원본

- 이 후보의 `source` 안에서만 저작했다. 다른 종·저장소·프로젝트 저장소·brief·ledger·provenance는 수정하지 않았다.
- 128×128 원본 18장: `poses` 9장, `actions` 9장. 각 파일은 128개 ASCII 행, 각 행은 정확히 128글자다. 점은 투명이다.
- 팔레트는 불투명 17색. 알파는 0/255. 1px 투명 테두리와 최하단 y≤124를 유지하며, idle_a 청동 발바닥은 y=124에 닿는다.
- 참고 `human-size.png`를 실제 열어 작은 얼굴, 어깨에서 손까지의 연결, 칼자루를 잡은 손의 연결과 원본 크기 가독성을 관찰했다. 참고 픽셀을 추출하거나 그림을 복제하지 않았다.
- `literal_clusters.py`, `pose_clusters.py`, `action_clusters.py`에 직접 선택한 x 좌표와 ASCII 색 행을 보존했다. 초기 시안 군집과 수정 군집이 함께 있으며, 마지막 정의가 현재 저작본이다. `write_candidate.py`는 이 고정 문자열을 빈 격자에 복사하고 명시한 좌표 수정만 적용한다.
- 원·다각형·선 마스크, 수식 명암, 이미지 생성, 트레이싱, 전체 프레임 이동/회전/보간, 자동 투명 구멍 채우기는 사용하지 않았다. 그림 확대는 진단판에만 최근접 방식으로 적용했다.

## 본체와 재질

우향 3/4, 왼쪽 위 광원. 머리 볏과 긴 굽은 부리에는 크림/연금색 넓은 빛 면, 목에는 금색 밝은 면과 뒤쪽 주홍 면을 잡았다. 몸통은 주홍 기본 면, 오른쪽 자주색 그림자, 왼쪽 금빛 깃 패널로 나눴다. 가까운 접힌 날개의 큰 어깨에서 긴 깃 끝까지 실제 픽셀로 연결했다. 먼 날개는 목 뒤의 다른 어깨 면으로 읽힌다.

꼬리는 왼쪽 뒤 큰 갈래와 아래로 휜 두 갈래로 분리하고, 두 아래 깃 끝에 청록 눈무늬를 넣었다. 무릎·정강이·발톱에는 청동 녹색의 무광 명암을 사용했다. 넓은 깃 면과 단단한 부리/발톱의 작은 반사를 다르게 찍었다.

## 실제 확인 자료

`png/`의 개별 18 PNG와 기본/추가 3×3 시트, `gif/`의 8 GIF를 만들었다. native-contact 및 밝은/어두운/체커 확대판을 직접 열어 얼굴, 목, 날개 이음, 엉덩이, 발톱과 투명 경계를 확인했다. 저장한 GIF 전 프레임을 디코드한 비교판으로 준비→전진→접촉→회수와 상태 프레임 차이를 확인했다. GIF 디코드 픽셀은 해당 원본 PNG의 RGBA와 대조했다.

`preview/artifact-diagnostics.json`에는 실제 현재 격자 SHA-256, 디코드 RGBA SHA-256, ink bounds, 픽셀 수, GIF의 실제 노출 시간을 기록했다. 이는 파일 형식과 저장 결과의 진단이며 예술적 합격이나 사용자 승인의 근거가 아니다.

## 남은 시각 검토 항목

- 가까운 날개와 가슴은 큰 깃 패널 위주라 잔깃 장식은 절제되어 있다. 더 화려한 장식량이 필요한지는 사용자 판단 대상이다.
- 공격은 핵심 네 자세를 빠르게 잇는 방식이며, 날개의 큰 변화가 짧은 전진 구간에 집중된다. 실제 전투 화면에서의 속도·타격감은 확인하지 않았다.
- 수면 호흡과 대기 변화는 의도적으로 작다. 1배에서도 변화가 충분히 느껴지는지는 하네스 GIF 검수 대상이다.

별도 독립 검수자를 호출하지 않았고, 하네스 검수 결과나 사용자 Allow를 만들지 않았다. 실제 실행 모델/작업 출처의 기록은 기존 하네스 job provenance에 맡긴다. 이 문서는 그 기록을 대체하지 않는다.

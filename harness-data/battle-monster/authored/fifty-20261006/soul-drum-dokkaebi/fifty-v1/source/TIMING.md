# 혼고도깨비 동작 시간표

원본은 모두 96×96이며 GIF는 원본 픽셀을 그대로 재생한다. 각 GIF는 반복한다. 시간을 유지하기 위해 보간 프레임이나 복제 원본을 추가하지 않는다. 기본 접지선은 native y=92다.

| GIF | 순서 | 각 노출 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 220 / 280 / 140 / 180 / 240 / 280 |
| hit | idle_a → hit → recover → idle_a | 300 / 280 / 220 / 300 |
| dead | idle_a → hit → dead | 240 / 180 / 1100 |
| skill | skill_a → skill_b → skill_c → idle_a | 380 / 260 / 320 / 320 |
| poison | poison_a → poison_b | 450 / 450 |
| stun | stun_a → stun_b | 480 / 480 |
| sleep | sleep_a → sleep_b | 700 / 850 |

## 공격 접촉

`windup`에서 두 손과 북채를 올린다. 화면 왼쪽 손은 x16..26,y32..37 부근, 오른쪽 손은 x71..81,y30..35 부근에 있다. 손가락 아래에 각각 팔꿈치와 위팔이 이어진다. `move`의 뒤 다리는 왼쪽 아래로 펴져 밀고 앞다리는 오른쪽 지지 발로 하중을 받는다.

`attack`의 왼손은 x30..44,y58..61 부근, 오른손은 x66..76,y56..59 부근이다. 왼 북채는 x38..47,y62..67, 오른 북채는 x63..71,y60..65에 이어진다. 접촉은 각 목재 자루의 아래 끝이 붉은 북가죽/가장자리와 만나는 부분이다. `recover`는 같은 두 손을 북 양옆으로 다시 접는다. 공격 팔이 준비 중에 반대 팔로 바뀌는 콤보는 없다.

## 혼고진 앵커

- `skill_a`: 새로 접은 왼손은 x34..47,y58..61 부근, 왼 자루의 아래 끝은 x46..50,y66..67 부근이다. 오른손은 x66..76,y56..59 부근이며 자루가 북 오른쪽 가죽 쪽 x60..64,y65..69로 내려간다. 황금 핵은 북가죽 x46..58,y61..72의 중앙 군집이다. 별도 입·뿔 발사 앵커는 쓰지 않는다.
- `skill_b`: 두 북채의 접촉 자세에서 위 파문은 x60,y63 부근에서 오른쪽 위로 뻗어 x87..94,y46..60의 갈고리 끝으로 굽는다. 아래 파문은 x58,y66 부근에서 아래로 벌어져 x73..85,y76..85 부근으로 되감긴다. 접촉점과 핵의 금빛이 연결되며 두 끝은 서로 다른 형상이다.
- `skill_c`: 두 팔을 들어 올리며 위 잔광은 x81..88,y44..50, 아래 잔광은 x76..82,y72..78에 남긴다. 핵은 x51..54,y65..67의 작은 군집으로 줄어든다. 잔광 사이의 빈 공간은 의도적으로 보존한다.

## 상태 동작

독은 턱을 짚은 손을 유지하고 반대 손을 늘어뜨린 상태에서 배를 감싸는 상태로 바꾼다. 방울 수와 모양도 직접 바꾼다. 기절은 머리를 낮추고 북채를 바닥 쪽으로 내린다. 둘째 기절 자세는 팔 하중·눈꺼풀과 별 군집을 바꾼다. 수면은 두 다리와 파지를 같은 앉은 배열에 두고 가슴·목 아래 명암을 바꿔 호흡한다. 수면 눈꺼풀은 두 프레임 모두 native y48, x52..54 및 x60..61에 있고 열려 있는 눈과 구분된다.

`preview/gif-storyboard.png`는 생성된 8GIF를 다시 디코드한 그림과 위 노출 시간을 나란히 보여 준다. 동작 GIF는 그림 검토용이다.

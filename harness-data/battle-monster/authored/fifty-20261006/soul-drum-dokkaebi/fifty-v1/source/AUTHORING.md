# 혼고도깨비 — fifty-v1 원본 저작

## 범위와 원본

시작 시 `source/poses`는 비어 있었다. 이번 작업은 이 종의 새로운 후보 원본이며, 다른 종이나 반려된 후보를 가져오지 않았다. 모든 쓰기는 이 후보의 `source` 안에만 했다. 프로젝트 저장소·brief·ledger·다른 후보는 수정하지 않았다. 사용자 선택이나 독립 검수 통과를 기록한 문서는 아니다.

원본은 `palette.json`, 기본 9개 `poses/*.pxgrid`, 추가 9개 `actions/*.pxgrid`다. 각 파일은 생략 없는 ASCII 96행 × 96열이다. `.`은 투명이며 팔레트에 없다. 팔레트는 18색, 알파는 0/255다. 모든 자세의 몸이나 지지 발 최하단은 native y=92이고, 테두리는 투명하다. 기술 발사 자세의 가장 오른쪽 픽셀은 x=94다.

`author_pixels.py`에는 직접 고른 행 문자열과 각 군집의 좌표를 보존했다. 변하지 않는 머리·북·골반의 리터럴 배열은 여러 자세에서 그대로 유지한다. 팔·파지·다리·상태 얼굴·효과의 변화는 명시한 문자열로 저작했다. 보조 코드는 빈 캔버스에 그 문자열을 놓고 완전한 원본 행을 저장한다. 몸 도형 생성, 수식 명암, 프레임 이동·회전·보간, 자동 결손 메우기는 없다. 최종 편집 가능한 정본은 완전한 `.pxgrid` 파일이다.

## 참고 관찰

제공된 `references/human-size.png`를 실제로 열었다. 관찰한 것은 작은 눈 앞의 코·볼 여유, 얼굴과 목의 구분, 손과 무기 자루의 연결, 64px 인간과의 상대 크기다. 참고 픽셀은 추출하거나 복사하지 않았으며 참고 이미지도 source에 재배포하지 않았다.

## 형태와 재질

- 흰 짧은 갈기와 하나의 외뿔, 우향 3/4의 푸른 얼굴, 짧은 엄니와 작은 황금 눈을 저작했다. 밝은 면은 왼쪽 위의 이마·갈기·어깨에 둔다.
- 피부는 H/L/B/S의 넓은 면과 O의 어두운 윤곽으로 부피를 나눈다. 갈기는 W/I, 금테는 K/Y/G, 북가죽은 F/C, 북채는 T/D로 재질을 구별한다.
- 가슴끈은 목 아래에서 북 윗테로 이어진다. 북은 몸 앞에 걸려 있으며 두 팔은 어깨에서 위팔·팔꿈치·아래팔·손으로 연결한다. 작은 두 발은 넓은 허벅지에서 발목으로 좁아진다.
- `windup`은 양손을 올리고 무릎을 벌린 준비, `move`는 뒷발을 펴 밀면서 앞다리를 내딛는 자세, `attack`은 두 손과 북채를 북가죽으로 내리는 접촉, `recover`는 팔꿈치를 접고 북채를 북 옆으로 회수한다.
- `hit`은 찡그린 눈·벌어진 입·낮아진 어깨를 따로 찍었다. `dead`는 바닥에 놓인 옆몸, 낮아진 머리, 닫히거나 흐린 눈, 접힌 두 다리와 떨어진 북채를 새로 저작했다. 턱 아래에는 푸른 목의 면이 남는다.
- 독은 한 손으로 턱을 짚고 반대 팔을 늘어뜨리거나 배를 짚는다. 기절은 낮아진 머리와 양쪽 늘어진 팔·북채, 두 위치의 별 군집으로 구별한다. 수면은 앉은 자세로 북을 무릎에 놓고 눈을 닫는다.
- 혼고진은 북가죽 중앙의 황금 핵, 접촉에서 이어진 위·아래의 서로 다른 굽은 파문, 들어 올린 북채와 두 깨진 잔광으로 구성한다.

## 실제로 보고 고친 군집

1. 첫 PNG에서 북 오른쪽 면이 컴포넌트의 투명 문자 때문에 잘리는 것을 발견했다. 투명 문자는 비어 있는 레이어로 처리하고 원래 직접 고른 북테·어깨 픽셀을 보존하도록 보조 배치를 고쳤다. 자동 채우기로 원본을 보정하지 않았다.
2. 기본 골반의 x33..57, y78..82에 넓은 푸른 면을 직접 저작해 오른쪽 허벅지가 외곽선 두 픽셀에만 매달리지 않게 했다. 다른 기본 자세도 해당 골반과 각자의 다리 군집을 열어 확인했다.
3. 대기·준비·회수·독·기절·수면의 일부 얼굴 교체 행이 원래 코의 끝보다 길게 나갔다. 해당 행을 제거하고 원래 얼굴 경계를 유지한 뒤 눈은 실제 x50..63 부근의 짧은 문자열로 다시 골랐다. 눈 옆에 길게 뻗은 줄을 남기지 않았다.
4. `idle_b`의 오른손·아래팔(x64..79, y43..65)이 어깨와 떨어져 있는 것을 관찰했다. x62..75, y54..63에 실제 위팔·팔꿈치·손목 면을 저작해 연결했다. 다른 두 대기 자세와 공격 네 단계를 함께 열어 대응 관절을 확인했다.
5. `skill_a`에서 손에 잡히지 않은 보조 자루가 생긴 초안을 수정했다. 준비의 왼팔과 파지를 새 리터럴 행으로 다시 찍고, 오른쪽 자루는 손 아래에서 북가죽까지 연속되는 짧은 목으로 정리했다.
6. `skill_b`의 위 파문 끝(x87..94, y46..60)을 굽은 갈고리 군집으로 다시 찍었다. 아래 파문의 긴 되감기는 끝과 다른 실루엣을 유지했다.
7. `dead`의 뒤 허벅지·접힌 무릎(x17..34, y76..85)과 앞쪽 발등·두 짧은 발끝(x25..40, y86..92)을 따로 저작해 북 뒤에 다리가 전부 사라지지 않게 했다.
8. `stun_b`의 목 교체가 만든 작은 투명 홈을 원래 목 면과 짧은 새 명암 문자열로 바로잡았다. 왼쪽 별은 갈기에서 떨어진 새로운 군집(x21..27, y29..33)으로 저작했다.
9. 수면을 실제 1배에서 열어 확인했다. 눈꺼풀은 y48의 x52..54와 x60..61에 있는 짧은 어두운 선이고, 아래의 푸른 코 면과 분리된다. 두 수면 자세에는 열린 눈의 E 군집이 없다. 같은 앉은 다리·발·파지를 유지하고 목 아래와 가슴의 작은 밝은 면으로 호흡을 바꿨다.

## 관찰 자료

`preview`에 18개 native PNG, 투명 3×3/3×6 시트, 밝은/어두운/체커 최근접 3배 시트, 1배 접촉 시트, 8GIF와 GIF에서 다시 읽은 순서 시트를 보존했다. 1배 얼굴·공격·수면 PNG, 세 배경의 접촉 시트와 실제 GIF 재읽기 스토리보드를 열어 관절, 의도하지 않은 투명, 코 윤곽, 닫힌 눈과 동작 순서를 관찰했다.

`render.py`는 원본 색을 그대로 PNG/GIF에 넣는 렌더러다. `preview/gif-readback.json`의 27개 표시 프레임은 디코드한 RGBA가 각 원본과 일치하고 노출 시간이 시간표와 맞는다. `inspect_source.py`는 원본 크기·해시·연결 성분·투명 영역을 읽는 진단 보조이며 원본을 고치지 않는다. `preview/source-readback.json`의 해시는 실제 파일을 계산한 것이다.

팔 안쪽과 북 사이의 좁은 사선 틈, 접힌 오른팔 안쪽의 삼각 빈 공간, 독 자세에서 턱을 짚은 팔 안쪽의 공간은 의도한 빈 곳이다. 4방향 투명 영역 진단은 사선 틈을 여러 작은 영역으로 나눠 보고하므로 그 수만으로 메우지 않았다. 떠 있는 독 방울·기절 별·기술 잔광도 의도한 별도 군집이다.

## 남은 시각적 한계와 다음 판단

- 쓰러짐은 한 장의 바닥 자세로 끝나므로 `hit → dead`의 낙하는 급하다. 중간 자세를 자동 생성하거나 보간하지 않았다.
- 북이 몸 앞을 크게 가린다. 특히 쓰러짐의 뒤쪽 다리와 수면의 낮춘 두 북채는 1배에서 겹침이 많아 자세 전체와 함께 읽어야 한다.
- 소리 효과는 두 굽은 금빛 리본 형태다. 동일한 원 오라를 피했으며, 파문으로 충분히 읽히는지는 독립 시각 검수와 사용자의 판단이 필요하다.
- 수면의 호흡 변화는 의도적으로 작다. 얼굴·발·무기가 튀지 않는 대신 확대 없이 가슴의 차이가 약하게 보인다.

테스트/게이트나 별도 검수자를 호출하지 않았다. 이 문서는 제작과 자체 관찰 기록이며, 하네스의 현재 원본 독립 검수와 사람의 선택을 대신하지 않는다.

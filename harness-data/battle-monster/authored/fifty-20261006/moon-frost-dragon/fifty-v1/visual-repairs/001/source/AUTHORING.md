# 월상빙룡 · fifty-v1 원본 저작 기록

## 납품 범위

- `palette.json`: 투명 기호 `.`를 제외한 18색. 은백 피부/청록 그림자, 푸른 갈기, 작은 금빛 눈, 상아 뿔, 청백 얼음, 독 기포색.
- `poses/`: 기본 9자세. `actions/`: 기술 3·독 2·기절 2·수면 2. 모두 128행 × 128 ASCII 글자의 완전한 리터럴 원본.
- `preview/`: 개별 투명 PNG 18장, native 3×3 두 장과 3×6 한 장, 밝은/어두운/체커 확인판, 실제 native GIF 8종.
- `preview/review.html`: 8종 GIF와 원본 1배 그림을 함께 보는 로컬 페이지.
- `author_pixels.py`: 초기 윤곽 연구, 직접 저작한 행/좌표 문자열, 자세별 교정 기록을 보존한 저작 보조 코드.
- `render.py`, `bake_motions.py`, `observe.py`: 원본 읽기, 정확한 팔레트 인코딩, 확인판과 관찰 자료 제작. 그림 생성이나 자동 보정은 하지 않는다.

이 폴더는 후보 원본이다. 독립 검수 판정과 사용자 선택은 하네스에서 이루어진다. 이 기록은 사용자 승인이나 하네스 합격을 선언하지 않는다.

## 참고 관찰과 형태

첨부 `human-size.png`를 실제로 열어 작은 눈·얼굴 군집, 차분한 우향, 큰 기본색/밝은 면/그림자 면과 손/도구 연결을 관찰했다. 참고 픽셀을 추출·추적·재배포하지 않았다. 다른 종의 원본이나 이전 반려 몬스터를 읽어 복제하지 않았다.

본체는 날개 없는 큰 은백 용이다. 오른쪽 주둥이, 금빛 근안, 뒤로 휜 작은 두 뿔, 턱 수염과 긴 입 수염, 푸른 목갈기를 남겼다. 하단 몸은 왼쪽으로 돌아 다시 오른쪽 어깨 쪽으로 감긴다. 코일 중심의 빈 공간은 의도한 투명 공간이다. 왼쪽 위의 피부 면은 W/H, 넓은 중간 면은 M, 오른쪽 아래와 겹친 팔/코일 면은 T/S/D를 직접 골라 찍었다.

움직이지 않는 하단 코일의 원본 행은 공유하되, 프레임 전체의 이동/회전/보간은 사용하지 않았다. 움직이는 목, 머리, 턱, 앞발과 효과는 해당 자세의 행/좌표 문자열이다. 출력된 18개 pxgrid는 모두 독립된 전체 리터럴 행 파일이다. 쓰러짐에는 낮게 다시 저작한 별도의 코일을 썼다.

## 자세 설계

- 대기: 세워진 목과 두 앞발. 가까운 어깨에서 위팔·굽은 팔꿈치·짧은 손목·발바닥·세 발톱으로 이어진다. 실제 가까운 발바닥/발톱 외곽이 y=124에 닿는다. b/c는 목·가슴 면, 갈기 윤곽, 눈꺼풀과 수염 끝을 따로 고른 픽셀로 바꿨다.
- 준비: 목을 뒤로 굽히고 같은 가까운 앞발을 접어 모았다. 코일 아래의 지지 앞발은 몸통에서 재질 부피를 가지고 이어진다.
- 전진/접촉: 목과 어깨를 낮추고 가까운 팔을 앞으로 내민다. 접촉의 넓은 타격 앞발과 짧은 발톱은 보행 발보다 크며, 실제 벌린 턱에 이빨과 입 안의 어두운 면을 남겼다. 코일 하중 면도 각각 다시 골랐다.
- 회수: 앞발과 목을 당기며 턱을 부분적으로 닫았다.
- 피격: 머리와 어깨가 뒤로 기울고 눈썹/금빛 눈 군집이 눌린다.
- 쓰러짐: 코일·목·머리를 바닥으로 낮추고 작은 흐린 눈꺼풀, 접힌 두 앞발과 수염/뿔을 유지했다. 피부색 목 부피가 머리와 몸통 사이에 있다.
- 기술: 실제 입 안의 청백 핵 → 입에서 이어지는 두 갈래 얼음 브레스 → 실제 닫힌 턱과 깨진 서로 다른 세 얼음 면. 첫 파편은 입에서 연결된 가는 얼음 잔상 끝에 있고, 나머지 둘은 떨어져 사라지는 면이다.
- 독: 턱 아래에 아픈 앞발을 들어 몸을 웅크렸다. 두 프레임의 턱·팔·기포 위치와 형태가 다르다.
- 기절: 목과 턱을 더 낮추고 처진 앞발을 유지했다. 실제 별 군집 세 개의 위치가 바뀐다.
- 수면: 낮게 접힌 목, 두 짧고 접힌 앞발, 감긴 눈, 같은 코일과 뿔을 유지한다. b에는 턱이 내려온 군집과 압축/이완된 목·어깨·팔꿈치 외곽을 별도로 찍었다. 색 변화만으로 호흡을 대신하지 않았다.

## 실제 그림을 열고 고친 좌표

1. 최초 대기 확대판: 얇은 직선 뿔을 작고 뒤로 굽은 뿔 행으로 교체했다. 하단의 뾰족한 가짜 접지 끝은 넓은 되돌아오는 코일과 y=124의 실제 앞발로 다시 저작했다.
2. 대기 먼 앞발: 어깨 연결이 약해 보여 `(72,71)`, `(72,72)`, `(73,73)`, `(74,74)`에 청록 중간 면과 그림자를 직접 추가했다. 가까운 손목 `(80,108)`–`(82,112)`도 면으로 넓혔다.
3. 대기 수염: 입 앞에 떠 있던 점들을 지우고 `(89,40)`에서 `(114,36)`까지 직접 고른 연속 행 군집으로 곡선을 만들었다.
4. 전체 자세 얼굴: 각 실제 위치에서 푸른 뒤통수 갈기, 눈 위 면, 주둥이의 밝은 면과 분리된 콧구멍을 점검했다. 교정 좌표는 `FINAL`의 각 자세 이름 아래에 따로 남겼다.
5. 기술 접촉: 최초 PNG에서 입과 브레스 사이에 투명이 보였다. `skill_b`의 `(68,58)`–`(74,65)`에 입 안 핵부터 분기점까지 이어지는 청백/청록 군집을 직접 찍었다. 위 끝 `(124,29)`–`(117,36)`과 브레스 면의 얼음 결도 따로 찍었다.
6. 수면: 길게 내민 앞발을 새 `SLEEP_FOLDED_A/B` 행으로 교체해 팔꿈치에서 안쪽으로 접히는 앞발/발톱을 만들었다. 두 눈꺼풀은 금빛 눈을 남겨 두지 않고 얼굴색에 짧은 S/D 선으로 저작했다. 실제 1배 쌍에서 감긴 눈과 턱/어깨 변화가 보이는지 열어 확인했다.
7. 저장된 공격 GIF를 읽은 확인판: 전진/접촉 코일 하단에 옛 검은 윤곽이 겹쳐 있었다. `move`와 `attack`의 y=113–124, x=10–76에 새 전체 행을 직접 써 옛 윤곽을 제거했다. 단순 덧칠이나 자동 구멍 채우기로 처리하지 않았다.
8. 최종 PNG/연결 관찰: `windup (69,45)`, `stun_a (84,82)`, `stun_b (86,83)`, `sleep_b (92,79)`에서 빠진 수염 뿌리를 각 자세의 해당 위치에서 직접 이었다. 연결 관찰 코드는 위치를 보여 줄 뿐 그림을 수정하지 않는다.

## 확인 근거

최종 18자세의 실제 `native-light.png`, `native-dark.png`, `native-checker.png`와 주요 자세의 3배 최근접 확인판을 열었다. 8종 GIF를 다시 디코딩한 `motions/*-decoded.png`를 모두 열어 준비→전진→접촉→회수, 기술 발원점, 접힌 앞발, 감긴 눈과 상태 쌍을 비교했다. 마지막 수염 뿌리 교정 뒤에도 해당 PNG를 다시 열었다.

원본 행 길이/팔레트/경계 관찰은 `pixels.json`과 `connectivity-observation.json`에 있다. 18개 전체 격자는 서로 다르다. 모든 자세는 외곽 1px 이상 투명이며, 최저 그림 행은 124이다. PNG 알파는 0/255이다. GIF 재읽기에서 27개 노출 프레임의 RGBA 픽셀과 시간을 원본과 대조했다. npm 테스트·게이트와 별도 검수 모델은 실행하지 않았다.

## 남은 시각적 유의점

- 코일 안쪽의 긴 밝은 사선 면은 외곽 곡선보다 직선적인 인상이다. 피부의 세밀한 비늘 무늬는 적고 큰 명암 면 중심이다.
- 가장 긴 얼음 끝은 x=126까지 가므로 기술 접촉 자세의 오른쪽 여백은 1px이다.
- 작은 눈꺼풀과 수염은 native 1배에서 절제된 군집이다. 독립 검수에서 가독성/질감에 관한 추가 지적이 나오면 그 자세의 실제 좌표에서 수정해야 한다.

자체 확인은 미감 합격 판정이 아니다. 독립 검수와 사용자 선택을 기다리는 후보다.

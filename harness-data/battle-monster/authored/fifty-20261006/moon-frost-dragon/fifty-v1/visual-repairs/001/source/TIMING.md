# 월상빙룡 · native GIF 시간표

원본 128×128, 18색과 투명 1칸. 시간은 GIF의 10ms 단위에 맞췄다. `preview/motions/`의 GIF들은 실제 저작 프레임만 순서대로 노출한다. 사이 프레임, 이동/회전, 보간, 색조 변형을 만들지 않는다. 반복은 무한, 프레임 disposal=2.

| 동작 | 원본 순서 | 각 노출 ms | 전체 ms |
|---|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 | 960 |
| 공격 | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 | 2140 |
| 피격 | idle_a → hit → idle_a | 700 / 180 / 900 | 1780 |
| 쓰러짐 | idle_a → hit → dead | 700 / 150 / 1700 | 2550 |
| 월빙식 | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 | 2260 |
| 독 | poison_a → poison_b | 420 / 420 | 840 |
| 기절 | stun_a → stun_b | 300 / 300 | 600 |
| 수면 | sleep_a → sleep_b | 650 / 650 | 1300 |

## 실제 발원점과 해부 경로

좌표는 각 cell의 0부터 시작하는 native x/y다. 도구나 무기는 없는 종이며 효과 발원점은 입이다.

- `skill_a`: 열린 실제 턱 안에서 핵을 모은다. 가장 밝은 핵 군집은 x=75–78, y=50–54이다. 목은 코일에 이어지고 가까운 앞발은 긴장한 어깨 아래에 붙어 있다.
- `skill_b`: 실제 입 안 x≈65–73, y≈58–62에서 청백 흐름이 시작된다. `(68,58)`–`(74,65)`의 직접 저작 행이 입과 x≈80, y≈63–66 분기점을 연결한다. 위 갈래는 x≈124, y≈29–36의 뾰족한 얼음 끝으로, 아래 갈래는 x≈116–120, y≈80–87의 넓고 다른 끝으로 이어진다. 두 갈래 사이에는 의도한 투명 틈이 있다. 핵/턱/목은 그대로 실제 본체의 일부다.
- `skill_c`: 턱은 닫히며 살짝 위로 회수된다. 입 앞 `(85,52)`에서 가는 얼음 잔상이 첫 면 x=91–101, y=56–64로 이어진다. 두 번째 면은 x=108–118, y=43–52, 세 번째 면은 x=111–122, y=74–84이다. 서로 다른 윤곽과 음영 면, 분리된 끝을 남겼다.
- 일반 공격은 같은 가까운 앞발의 어깨→위팔→팔꿈치→손목→타격 발바닥을 추적한다. windup에서 뒤로 접힌 앞발을 move에서 앞으로 내고 attack에서 손목을 압축하고 넓은 앞발/짧은 발톱을 보여 준다. 접촉 끝은 대략 x=105–110, y=106–112이다. 회수에서 같은 앞발을 몸 쪽으로 당긴다.
- 대기 가까운 발바닥/발톱은 실제 y=124에 닿는다. 낮은 상태 자세와 쓰러짐은 코일/몸통의 하중 면이 y=124에 닿는다. 독/기절의 입자만으로 접지하지 않는다.
- 수면 a/b는 감긴 눈을 유지하고 같은 두 앞발/발톱과 코일을 남긴다. b의 턱 군집과 어깨/목 외곽, 팔꿈치 압축을 독립 좌표로 바꾸어 작은 숨을 만든다.

`bake_motions.py`가 GIF를 저장한 뒤 각 GIF를 다시 읽는다. 디코딩한 픽셀과 노출 시간이 원본과 정확히 일치해야 시간표를 기록한다. 재읽은 실제 프레임은 `motions/*-decoded.png`, 수치 기록은 `motions/timing.json`과 `pixels.json`에 있다. 이는 인코딩 근거이며 독립 미감 검수/사용자 승인이 아니다.

# 월상빙룡 · 짧은 앞발, 갈고리 발톱, 굽은 뿔 교정

## 작업 범위와 원본

이번 작업은 제공된 fifty-v1 초안의 독립 시각 지적 세 가지를 고친다. 대기 앞발의 긴 부츠 형태, 두 뿔의 직선/수직 형태, 수면과 독 자세의 패들 같은 손끝이 대상이다. source 밖의 후보·brief·ledger·검수 결과·게임 저장소는 수정하지 않았다. 별도 검수자를 호출하거나 테스트/게이트를 실행하지 않았다. 새 독립 검수와 사용자 선택은 아직 없다.

- `palette.json`: 제공된 18색을 바이트 그대로 보존했다. `.`은 투명이며 팔레트에 없다.
- `poses/*.pxgrid` 9개와 `actions/*.pxgrid` 9개: 각각 128행 × 128 ASCII 글자의 완전한 현재 원본이다. 18개 원본은 서로 다르다.
- `before-claws-horns-repair/`: 이번 수정 직전의 18개 원본, 팔레트와 문서를 보존한다. 그 문서의 좌표는 이전 판을 설명한다.
- `before-foreleg-repair/` 및 기존 `author_pixels.py`, `repair_forelegs.py`: 제공된 이전 작업 이력을 보존했다. 예전 저작 스크립트만 실행하면 현재 그림을 되돌리므로 현재 납품물은 위 pxgrid 파일이다.
- `repair_claws_horns.py`: 이번에 직접 고른 자세별 ASCII 군집과 후속 교정 좌표다. 각 자세를 그 자세의 수정 전 원본에서 시작한다. 다른 자세의 군집/좌표를 자동 복사하지 않는다. 리터럴 블록의 남는 선택 영역은 명시적으로 투명이다. 도형 본체, 수식 명암, 프레임 이동/회전/보간, 자동 구멍 채우기를 사용하지 않았다.
- `render.py`, `bake_motions.py`, `repair_inspect.py`: 리터럴 원본의 팔레트 인코딩, 진단 배경/확대/라벨, GIF 노출과 재읽기만 수행한다. 확대판은 진단 자료이고 원본 스프라이트를 확대 저작한 것이 아니다.

## 참고 관찰과 보존한 형태

첨부 현재 시트와 64px 검객 그림을 실제로 열었다. 검객은 작은 얼굴·광원·재질 면을 관찰하는 참고이며 픽셀 추출·트레이싱·참고 그림 복제를 하지 않았다.

은백/청록 피부, 금빛 눈, 우향 긴 주둥이/수염, 푸른 등갈기, 날개 없는 큰 코일, 왼쪽 위 광원을 유지했다. 기존 목·가슴·코일의 넓은 W/H 밝은 면, M 중간 면, T/S/D 그림자 면과 의도한 코일 안 빈 공간을 보존했다. 입의 핵, 입부터 이어진 두 갈래 브레스, 세 잔상 얼음 면과 상태 입자는 보존했다. 팔레트 전체 변환을 하지 않았다.

## 직접 수정한 군집

좌표는 0부터 시작한다. 아래 범위 안에서도 지적과 관계없는 기존 픽셀은 가능한 한 보존했다. 정확한 쓰기 영역/행은 `repair_claws_horns.py`에 있다.

### 대기 세 자세: 팔과 손끝

`idle_a/b/c` 각각 x64–101, y89–124에 독립적으로 고른 행을 썼다. 가까운 어깨 약 (66,95)부터 짧은 위팔, 안쪽 팔꿈치 굽힘, 좁아진 손목, 몸통 가까이 접힌 발바닥으로 이어진다. 가까운 손목/발바닥은 약 x71–82, y102–109, 먼 앞발은 약 x81–92, y96–102다. 기존 y110–124의 긴 아래팔/평평한 부츠를 제거했다. 발끝은 피부색 손가락 뿌리 → P/Q 발톱 면 → 아래로 꺾인 O/Q 끝으로 나누고 사이의 투명 홈을 남겼다. 수평 발바닥에 금색 점을 나열하지 않는다.

팔을 몸 가까이 들었으므로 앞발을 바닥까지 늘리지 않았다. 대기 실제 하중은 원래 코일의 x32–44, y124에 그대로 남아 있다. 기존 가슴/코일 경계와 팔 부착을 확인했고 제거한 긴 앞발 자리에 본체 구멍을 자동으로 채우지 않았다.

### 준비 → 전진 → 접촉 → 회수와 피격/쓰러짐

| 자세 | 직접 수정한 앞팔 영역 | 표현 |
|---|---|---|
| windup | x64–99, y82–99 | 가까운 앞발을 안쪽으로 접음, 먼 발은 보조 |
| move | x73–109, y85–105 | 어깨 전진, 짧은 손목과 펼치는 발바닥 |
| attack | x75–113, y87–114 | 압축된 손목 아래 넓고 짧은 타격 발바닥, 바깥 두 갈고리와 아래 발톱 |
| recover | x73–99, y81–98 | 안으로 돌아오는 팔꿈치와 접히는 앞발 |
| hit | x68–91, y84–100 | 기울어진 어깨에서 들린 짧은 손목, 기존 피격 얼굴 유지 |
| dead | x69–109, y110–124 | 몸 앞의 짧게 접힌 두 발, 납작한 신발 끝 제거 |

같은 가까운 앞발이 준비/전진/접촉/회수에서 추적되게 했다. 몸 전체를 이동하거나 회전시켜 새 자세를 만들지 않았다. 짧아진 발에도 넓은 위팔과 팔꿈치 면을 남겼으며 목·몸통·코일·쓰러진 얼굴을 새 덩어리로 덮지 않았다.

### 기술과 상태

- `skill_a`, `skill_b`, `skill_c`: 각각 실제 팔 위치에서 앞발 길이와 손끝을 직접 고쳤다. 준비 핵/브레스/회수 조각의 원본 효과와 입 연결을 유지했다.
- `poison_a`: x73–93, y77–86의 턱 가까이 올린 손끝을 피부 손바닥과 갈고리 둘로 나누었다. x67–92, y96–107의 다른 앞발도 짧게 접었다.
- `poison_b`: 올린 손끝은 x73–93, y79–88에서 따로 골랐고 다른 앞발은 x64–92, y97–109에 따로 썼다. 기존 아픈 턱/어깨 차이와 서로 다른 독 방울을 유지했다.
- `stun_a/b`: 각 x66–98, y98–118에서 늘어진 앞발을 짧게 낮췄다. 처진 머리, 어깨와 별의 다른 위치는 유지했다.
- `sleep_a/b`: x76–98, y92–103의 먼 앞발에 어깨 연결 → 팔꿈치 굽힘 → 손목 → 작은 발바닥 → 분리된 갈고리 끝을 찍었다. x63–98, y101–124의 가까운 앞발도 따로 줄였다. 최초 자체 PNG에서 가까운 팔 교정이 먼 발톱 마지막 세 행을 덮은 것을 발견하여 (82–92,101), (83–85,102), (84,103)의 실제 끝을 리터럴로 복원했다. 두 프레임의 같은 앞발과 코일, 감긴 눈을 보존했고 b의 낮아진 턱과 가슴/어깨·접힌 가까운 팔의 작은 윤곽 차이를 유지했다. 검은 평상시 눈을 복사하지 않았다.

### 두 뿔

18자세 각각 원래 두 뿔의 뿌리 위치에서 따로 저작했다. 옛 긴 사선/직립 끝을 지우고 근위 뿔의 짧은 곡선과 왼쪽을 향하는 가는 끝, 먼 뿔의 작은 되굽힘을 찍었다. 대기 가까운 뿔은 x57–64, y16–22, 뿌리는 x60–63, y22다. 먼 뿔은 x68–75, y16–22, 뿌리는 x69–72, y22다. 뿌리는 구별되어 두개골에 붙는다. 자체 확대판에서 가까운 뿔의 사선 인상이 남아 있어 FINISH의 실제 좌표로 길이를 한 번 더 줄이고 중간 굽힘을 강조했다. 공격/쓰러짐/상태에서도 해당 얼굴의 실제 뿌리에서 같은 해부를 유지한다.

## 실제 그림 관찰과 파일 기록

`preview/native-light.png`, `native-dark.png`, `native-checker.png`의 실제 1배 18칸을 열었다. `overview-3x.png`, `forelegs-3x.png` 및 대기/준비/공격/피격/쓰러짐/기술/독/수면의 실제 3배 배경판도 열었다. 앞발을 짧게 접은 실루엣, 손목 아래 발바닥과 발톱 틈, 목과 코일 연결, 두 뿔 뿌리, 감긴 수면 눈을 관찰했다. 코일 중심과 발톱 사이 빈 공간은 의도한 것이며 이를 연결 검사로 메우지 않았다. 연결 성분 진단은 읽기 관찰만 했고 자동 보정에 쓰지 않았다.

현재 18칸은 모두 128×128이고 기존 팔레트만 사용한다. 원본 인코더가 가장자리 1px 투명과 최저 잉크 y≤124를 읽어 확인했으며, 모두 실제 코일/몸이 y124에 남아 있다. 8개 GIF의 27개 노출 프레임은 저장 뒤 다시 읽어 원본 RGBA와 시간을 대조했다. 각 GIF의 실제 재읽은 프레임 스트립 8개를 열어 준비/전진/접촉/회수, 피격/쓰러짐, 기술과 상태 쌍을 비교했다.

`preview/pixels.json`, `preview/motions/timing.json`은 현재 원본/실제 이미지/GIF의 계산된 해시와 시간을 담는다. `preview/claws-horns-change-record.json`은 수정 전후 다른 픽셀 수와 범위를 기록한다. 이는 파일·노출 기록이며 화질 합격이나 사용자 승인 근거가 아니다.

## 남은 시각 문제와 관찰 한계

- 발톱의 끝 굽힘은 원본에서 1–2px 수준이다. 3배에서는 두 갈고리와 아래 발톱이 분리되지만 어두운 배경의 1배에서는 Q/O 끝의 굽힘이 작게 읽힌다. 더 굵게 과장할지는 실제 새 독립 검수에 맡긴다.
- 기존 대기와 수면의 작은 호흡은 이번에 보존했다. 큰 목/어깨 이동으로 과장하지 않았으므로 자체 정지판의 차이는 미세하다.
- 자체 GIF는 저작한 자세의 노출이다. 실제 전투의 이동 거리, 접촉/피해 순간과 효과 정렬은 여기서 확인하지 않았다. 새 검수 결과를 꾸미거나 전부 통과했다고 기록하지 않는다.

# 월상빙룡 · 현재 원본 GIF 시간표

128×128, 기존 18색과 투명 인덱스. `preview/motions/`의 8개 GIF는 현재 18개 리터럴 프레임만 노출한다. 기존 노출 시간을 유지했다. 무한 반복, disposal=2. 사이 프레임과 전체 이동/회전/보간은 없다.

| 동작 | 원본 순서 | 각 노출 ms | 전체 ms |
|---|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 | 960 |
| 공격 | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 | 2140 |
| 피격 | idle_a → hit → idle_a | 700 / 180 / 900 | 1780 |
| 쓰러짐 | idle_a → hit → dead | 700 / 150 / 1700 | 2550 |
| 월빙식 | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 | 2260 |
| 독 | poison_a → poison_b | 420 / 420 | 840 |
| 기절 | stun_a → stun_b | 300 / 300 | 600 |
| 수면 | sleep_a → sleep_b | 650 / 650 | 1300 |

## 실제 입과 앞발 앵커

0부터 시작하는 native 좌표다. 무기 없는 용의 기술 발원점은 입이다. 짧게 교정한 앞발은 보조 자세이며 효과 발원점으로 바꾸지 않았다.

- `skill_a`: 실제 열린 턱 안 x75–78, y50–54의 청백 핵으로 모은다. 목/턱의 기존 연결과 발원 위치를 보존했다.
- `skill_b`: 실제 입 안 x65–73, y58–62에서 시작한다. x68–74, y58–65의 청백 군집부터 분기점 x80 부근, y63–66이 이어진다. 위 갈래는 x117–124, y29–36, 아래 갈래는 x116–120, y80–87의 서로 다른 끝에 이른다. 입부터 분기까지 연속하고 두 갈래 사이 투명 틈은 의도한 것이다.
- `skill_c`: 닫히며 회수하는 기존 턱과 목을 유지한다. 입 앞 (85,52)부터 가는 잔상이 첫 면 x91–101, y56–64에 이어진다. 나머지 면은 x108–118, y43–52와 x111–122, y74–84다. 세 얼음 면의 다른 윤곽/음영/간격을 보존했다.
- 대기 가까운 어깨 약 (66,95) → 짧은 팔꿈치 → 손목/발바닥 x71–82, y102–109. 먼 어깨 약 (79,89) → 굽은 팔 → 발바닥/발톱 x81–92, y96–102. 이전 긴 부츠가 닿던 바닥 앵커는 사용하지 않는다. 실제 코일 하중 윤곽 x32–44는 y124에 남는다.
- 일반 공격: 가까운 앞발이 준비에서 몸 안으로 접힘 → 전진 어깨와 짧은 팔 → 접촉의 압축 손목/타격 발바닥 → 접힌 회수로 이어진다. 접촉 발바닥은 대략 x81–94, y94–99, 바깥 갈고리 끝은 x92–102, y96–99, 아래 발톱은 x84–86, y100–102다. 먼 앞발은 보조다. 몸 전체 변형으로 이 동작을 합성하지 않았다.
- 독의 턱 근처 올린 앞발은 손끝이 분리되어 있고 아픈 어깨/턱과 독 방울 변화가 유지된다. 기절은 짧게 낮춘 팔과 처진 머리, 움직이는 별을 유지한다.
- 수면 두 자세의 감긴 눈과 낮은 턱, 같은 앞발/코일을 유지했다. b의 가까운 팔 아래 윤곽이 작게 이완되고 기존 가슴/턱 면 차이가 호흡을 표현한다. 먼 손목 아래 세 행의 갈고리 끝은 가까운 팔과 겹쳐도 따로 남는다.
- 대기/공격/기술/독/기절/수면/쓰러짐 모두 실제 코일 또는 쓰러진 몸의 하중 윤곽이 y124에 남는다. 입자만으로 접지하지 않는다.

## 저장과 관찰

`bake_motions.py`로 8개 GIF를 저장하고 27개 노출 프레임의 실제 RGBA와 시간을 다시 읽었다. 재읽은 그림은 `preview/motions/*-decoded.png`, 실제 계산된 해시/노출은 `preview/motions/timing.json`과 `preview/pixels.json`이다. 8개 재읽은 스트립을 실제로 열어 프레임 간 어깨/앞발 변화, 접지, 감긴 수면 눈과 기술 입 연결을 관찰했다.

이 시간표는 자체 미리보기용이다. 실제 런타임 타격/피해 시점과 브레스 정렬은 확인하지 않았다. 독립 검수 합격이나 사용자 선택을 선언하지 않는다.

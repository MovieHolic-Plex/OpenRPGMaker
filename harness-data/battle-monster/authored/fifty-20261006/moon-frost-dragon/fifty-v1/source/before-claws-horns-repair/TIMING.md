# 월상빙룡 · 현재 native GIF 시간표

128×128, 기존 18색과 투명 1칸. preview/motions의 GIF 8종은 실제 저작 프레임만 노출한다. 이전 후보의 노출 시간을 유지했다. 무한 반복, disposal=2. 사이 프레임·전체 이동/회전·보간을 만들지 않는다.

| 동작 | 원본 순서 | 각 노출 ms | 전체 ms |
|---|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 | 960 |
| 공격 | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 | 2140 |
| 피격 | idle_a → hit → idle_a | 700 / 180 / 900 | 1780 |
| 쓰러짐 | idle_a → hit → dead | 700 / 150 / 1700 | 2550 |
| 월빙식 | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 | 2260 |
| 독 | poison_a → poison_b | 420 / 420 | 840 |
| 기절 | stun_a → stun_b | 300 / 300 | 600 |
| 수면 | sleep_a → sleep_b | 650 / 650 | 1300 |

## 입과 앞발 앵커

0부터 시작하는 native 좌표다. 무기 없는 용이므로 기술의 실제 발원점은 입이다. 연결된 앞발은 보조 자세이며 효과를 내는 손/도구로 바꾸지 않았다.

- skill_a: 열린 실제 턱 안 x75–78, y50–54의 밝은 핵. 목/턱과 발원 위치는 기존 직접 저작 군집을 유지했다.
- skill_b: 실제 입 안 x65–73, y58–62에서 흐름이 시작된다. x68–74, y58–65의 청백 군집이 입부터 분기점 x80 부근, y63–66에 이어진다. 위 갈래는 x117–124, y29–36, 아래 갈래는 x116–120, y80–87의 넓고 다른 끝으로 간다. 두 갈래 사이의 투명 틈을 남겼다. 팔 교정으로 브레스 면을 지우지 않았다.
- skill_c: 닫히며 회수되는 턱을 유지했다. 입 앞 (85,52)부터 가는 잔상이 첫 면 x91–101, y56–64에 이어진다. 나머지 면은 x108–118, y43–52와 x111–122, y74–84다. 서로 다른 윤곽/음영과 의도한 간격을 유지했다.
- 대기 가까운 어깨 (66,95), 먼 어깨 (79,89) 부근이 같은 가슴에 붙는다. 가까운 앞발의 실제 지지 윤곽은 x74–84, y124다. 대기 세 자세에서 부착/접지를 유지했다.
- 일반 공격: 같은 가까운 앞발의 접힌 준비 팔꿈치 → 전진 어깨/위팔 → 압축 손목/타격 발바닥 → 접힌 회수 앞발. 접촉 발바닥은 x86 이후 y104–110, 바깥 발톱은 x99–107, y107–110, 아래 발톱은 y111–113이다. 긴 패들 끝을 제거했다.
- 공격/기술에서 앞발을 들 때에는 코일 하중 윤곽이 y124에 남는다. 독/기절/수면/쓰러짐에서도 실제 몸/발이 접지하며 입자만으로 바닥에 닿지 않는다.
- sleep_a/b는 감긴 눈을 유지한다. b의 턱·어깨/가슴·접힌 앞발의 별도 윤곽 변화가 작은 호흡을 표현한다. 수면/독/기절 쌍의 원본과 노출 시간을 보존했다.

bake_motions.py가 저장한 8개 GIF를 다시 읽어 27개 노출 프레임의 RGBA와 시간을 원본에 대조했다. 실제 재읽은 프레임은 preview/motions/*-decoded.png, 실제 해시/시간은 preview/motions/timing.json과 preview/pixels.json에 있다. 자체 GIF는 저작 자세의 노출만 보여 준다. 런타임 이동·타격/피해 시점·효과 정렬의 확인 근거로 쓰지 않으며 독립 검수나 사용자 승인을 선언하지 않는다.

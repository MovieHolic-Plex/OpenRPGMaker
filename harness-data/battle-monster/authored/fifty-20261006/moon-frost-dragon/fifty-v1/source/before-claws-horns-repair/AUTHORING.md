# 월상빙룡 · 앞발/피격 목 교정 기록

## 범위와 보존

기존 fifty-v1의 구체적인 해부 지적을 고친 후보 원본이다. 모든 변경/확인 자료는 source 안에 있다. 저장소 코드, brief, ledger, 게임 저장소, 다른 후보와 검수 결과는 수정하지 않았다. 별도 검수자, npm 테스트와 게이트를 실행하지 않았다. 독립 검수 합격이나 사용자 승인을 선언하지 않는다.

- palette.json: 기존 18색을 바이트 그대로 보존. 점은 투명이며 팔레트에 없다.
- poses 9개 + actions 9개: 각 128행 × 128 ASCII 글자의 독립된 전체 리터럴 격자.
- before-foreleg-repair: 수정 전 18개 격자·팔레트·이전 저작/시간표 문서를 보존. 그 안의 문서는 수정 전 그림의 기록이다.
- author_pixels.py: 이전 저작 기록. 이것만 재실행하면 이전 그림이 되므로 현재 교정에는 뒤이어 repair_forelegs.py를 적용한다.
- repair_forelegs.py: 이번에 직접 고른 자세별 좌표와 ASCII 행 문자열. 지정 영역의 나머지를 투명으로 기록하고 그 밖의 기존 행을 보존한다. 다른 자세의 좌표를 자동 전파하지 않는다. 본체 도형 생성, 프레임 이동/회전/보간, 명암 합성, 자동 구멍 채우기를 하지 않는다.
- render.py / bake_motions.py / observe.py / repair_inspect.py: 원본 읽기, 정확한 팔레트 인코딩, 확인용 최근접 확대/라벨과 좌표·해시 관찰. 연결 관찰로 그림을 수정하지 않는다.

## 참고와 재질

첨부된 현재 18자세 시트와 human-size.png를 실제로 열었다. 검객은 얼굴/비율/재질 면 관찰용이다. 참고 픽셀을 추출·추적하거나 참고 이미지를 이 납품물에 복제하지 않았다.

은백 피부, 금빛 눈, 작은 두 뿔, 긴 우향 주둥이/수염, 푸른 등갈기, 날개 없는 코일과 왼쪽 위 광원을 보존했다. W/H 밝은 면, M 중간 면, T/S/D 그림자 면으로 어깨·팔꿈치·손목을 직접 나눴다. 코일 중심과 팔 사이의 의도한 빈 공간은 남겼다.

## 직접 수정한 좌표/군집

### 대기 세 자세

기존 (79,77) 부근 작은 부속지와 (77,93) 부근 큰 부속지가 작은 팔/긴 다리처럼 보였다. idle_a/b/c의 x60 이후 y65–124에 자세별 리터럴 행을 따로 기록했다.

높은 작은 팔을 지우고 y86–100에 목 아래 가슴이 코일 앞을 덮는 밝은/중간/그림자 면을 이어 찍었다. 먼 어깨는 대략 (79,89), 가까운 어깨는 (66,95)다. 두 어깨는 같은 가슴 부피에서 나오며 검은 선만으로 붙지 않는다. 먼 앞발은 위팔·팔꿈치·안쪽으로 접힌 짧은 손목·발바닥/발톱으로 이어진다. x82 이후 y98–109를 별도로 마무리해 작은 돌기로 되돌아가지 않게 했다.

가까운 앞발은 넓은 위팔, y109–113의 안쪽 팔꿈치 굽힘, 압축된 아래팔, 짧은 세 발톱을 가진다. 원안의 길게 앞으로 내민 신발 같은 발과 직선적인 정강이를 줄였다. 첫 교정에서는 발을 들어 대기의 발바닥 접지가 빠졌다. 그 판을 최종으로 두지 않고 가슴/어깨 면과 접힌 앞팔을 다시 저작했다. 최종 가까운 앞발의 실제 하중 윤곽은 x74–84, y124에 닿고 코일도 y124에 닿는다. b/c도 각각 같은 부착/접지를 직접 기록했다.

### 준비 → 전진 → 접촉 → 회수

windup/move/attack/recover는 각 실제 위치에서 가슴과 두 어깨, 위팔의 밝은 면, 팔꿈치 그림자 경계, 짧은 손목과 발바닥을 따로 찍었다. 같은 가까운 앞발이 준비에서 안쪽으로 접혔다가 전진에서 나오고 접촉에서 발바닥/발톱을 펼친 뒤 회수에서 다시 접힌다. 먼 앞발은 보조 자세다.

attack의 x64 이후 y85–114를 수정하고 x84 이후 y103–114에서 발바닥/발톱을 한 번 더 마무리했다. 긴 패들을 지우고 짧은 손목과 넓지만 짧은 발바닥, 바깥 두 발톱과 아래 발톱을 찍었다. 바깥 발톱은 x99–107, y107–110, 아래 발톱은 y111–113으로 꺾인다. 발톱 사이의 작은 투명 홈은 의도한 틈이다. 첫 확대판에 남아 있던 옛 끝 4픽셀 (105–108,114)을 직접 행 교체로 제거했다. 회수와 기술도 해당 자세의 실제 위치에서 같은 손목/발바닥 비율로 고쳤다.

### 피격 목

hit의 x39–65, y63–70에 직접 고른 행을 넣었다. 특히 x44–51, y64–70에서 목의 M/T/S 면이 뒤로 젖혀진 가슴에 넓게 이어지고 H/W 밝은 목 면은 가슴 곡선으로 흘러간다. 가늘게 집힌 검은 접합점과 투명 단절을 없애면서 반동을 보존했다. 이 자세의 앞발도 가슴에 붙은 위팔·팔꿈치·발톱으로 고쳤다.

### 기술과 보존한 상태

skill_a/b/c의 앞팔은 각각 짧은 위팔·팔꿈치·손목·발톱으로 고쳤다. skill_b y78–85는 오른쪽 x97 이전에 수정 범위를 멈춰 브레스 면을 보존했다. skill_c도 파편 앞에서 멈추는 한정 영역을 썼다. 입 안 핵, 실제 입부터 나온 두 갈래 얼음, 닫히는 턱과 세 회수 파편은 기존의 별도 저작 군집을 유지했다.

dead, poison_a/b, stun_a/b, sleep_a/b의 7개 격자는 수정 전과 바이트가 같다. 전체 PNG에서 접힌 팔/꼬리·코일, 상태별 얼굴/기포/별, 수면의 닫힌 눈과 호흡 차이를 함께 살폈다. 상태 쌍은 서로 다른 기존 리터럴 원본이다. 색조 변경이나 공격 재사용으로 만들지 않았다.

## 남은 시각적 문제와 범위

- 대기의 지지 앞발은 올려 든 먼 앞발보다 길고 크다. 가슴 부착과 팔꿈치/발톱을 고쳤지만 1배에서 원근 차이가 자연스러운지는 독립 검수 판단을 남긴다.
- 대기에서 준비로 넘어갈 때 지지 앞발을 들어 접고 가슴을 수축하는 변화가 크다. 실제 여섯 노출 자세만 쓰므로 중간 자세의 부드러움에는 한계가 있다.
- 코일 안쪽의 긴 밝은 사선은 외곽 곡선보다 직선적이며 피부 비늘 묘사는 절제되어 있다.
- 기술 위쪽 얼음 끝은 x126까지 가므로 오른쪽 여백은 1px이다.
- GIF 재읽기는 픽셀/노출 시간을 확인한다. 게임 속 돌격 이동량, 접촉, 효과 정렬과 실제 전투 적용은 source 전용 작업에서 확인하지 않았다.

자체 확인을 새 독립 검수나 사람의 선택으로 기록하지 않는다. 현재 후보의 독립 검수와 사용자 선택은 하네스가 맡는다.

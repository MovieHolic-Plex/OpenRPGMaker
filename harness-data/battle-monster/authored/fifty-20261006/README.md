# 신규50종 목표 · 실제 통과 원본

사용자 원문: 그래 한 50개 만들고 전부 통과시켜.
manifest.json은 실제 검사/독립 keep/현재 Allow/선택 팩을 확인하고 지속 보관한 후보만 담는다.
expectedSpecies=50이며 전체 완료 수를 줄이지 않는다. 미완성/불통과 종은 완료로 넣지 않는다.
각18자세/팔레트/직접 저작 코드·notes/actual author·review job/생산 시간표/선택 기록을 보존한다.
visual-repairs는 이전 rework 원본/검수/지적 좌표와 실제 교정 권한을 그대로 남긴다.
외부 참고 이미지 바이트와 raw events.jsonl은 복사하지 않는다. source의 PNG/GIF는 자체 도트 진단이다.
저장한 source/brief를 다시 읽어 실제 live binding과 같음을 확인한다. API의 by=user-delegated-goal은
명시적 사용자 일괄 통과 지시이며 사용자가 마우스로50번 클릭했다고 주장하지 않는다.
기존 다른 종/원래 선택을 이관하거나 변경하지 않는다. 게임 프로젝트 설치는 별도다.

# 금익대붕 GIF 시간표

모든 GIF는 native 128×128, 17색 원본 팔레트, 투명 인덱스 0, disposal=2, 반복 재생이다.
중간 그림 생성/이동/회전/보간 없이 아래 원본 파일을 순서대로 인코딩한다.
대기 `idleFrameMs=240`을 사용한다. 쓰러짐의 반복 복귀는 후보 미리보기용이다.

| GIF | 원본 순서 | 각 노출 시간(ms) |
| --- | --- | --- |
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240, 180, 110, 170, 200, 240 |
| hit | idle_a → hit → idle_b | 240, 220, 240 |
| dead | idle_a → hit → dead | 240, 180, 1100 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240, 360, 240, 300, 240 |
| poison | poison_a → poison_b | 360, 360 |
| stun | stun_a → stun_b | 420, 420 |
| sleep | sleep_a → sleep_b | 640, 760 |

## 타격과 기술 발원점

좌표는 native canvas의 0 기반 (x,y)다.

- 타격은 오른쪽에 보이는 같은 앞 다리다. 전진의 엉덩이 (73,96) → 무릎 (77,104)
  → 든 발목 (80,109)이 접촉에서 넓은 허벅지 (82,100) → 압축 발목 (88,106)
  → 앞 파지/갈고리 (104–120,109–121)로 변한다. 뒤 발의 실제 접지는 y=124에 남는다.
- 기술 준비: 위 날개의 실제 끝 (31,9) 주변과 아래 주깃 끝 (48,99) 주변에 금백 핵.
  밝은 `w/j/k` 픽셀은 날개 재질에 붙어 있으며 화면 중앙에 띄운 원 오라가 아니다.
- 기술 시전: 펼친 뒤 날개의 두 주깃 가장자리 약 (61,25), (60,44)에서 상단/중단 깃 칼날의
  밝은 깃대가 이어지고, 앞 날개 끝 약 (91,76)에서 하단 깃대가 이어진다. 세 끝은 각각
  (121,8), (121,30), (123,65) 쪽으로 향한다. 서로 다른 크기의 깃가지/겹침 경계가 있다.
- 기술 회수: 실제 날개 팔꿈치와 주깃을 접는다. 두 갈라진 깃 잔광은 x=86–118,y=23–43 및
  x=94–122,y=62–79에 남는다. 시전처럼 세 연속 칼날을 유지하지 않는다.
- 독 거품은 벌어진 은백 부리 오른쪽에서 위로 변한다. 기절 별은 처진 머리 주변에만 둔다.
  수면은 별/거품/공격 광선을 쓰지 않으며 닫힌 눈과 작아진 턱/가슴 윤곽으로 숨을 보인다.

`gif-reload.json`과 `png/gif-timelines-native.png`는 실제 저장된 GIF의 디코드 결과다.
게임의 피해 판정/소리/이동 시간은 이 후보 원본 작업에 포함되지 않는다.

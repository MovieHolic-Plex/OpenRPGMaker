# 금익대붕 — 원본 18자세

## 저작 범위와 원본

이 후보의 `source` 안에서만 저작했다. 정본은 `palette.json`, `poses/*.pxgrid` 9장,
`actions/*.pxgrid` 9장이다. 각 파일은 투명 `.`를 포함한 **128행 × 128열의 리터럴 ASCII**다.
팔레트는 17색이며 `.`는 팔레트에 없다. 모든 그림의 바깥 테두리는 투명하고 최저 잉크는
native y=124 이하다. `idle_a`의 실제 두 발바닥이 y=124에 닿는다.

`author.py`에 직접 고른 행/좌표 문자열과 교정 과정을 보존했다. 동일 해부의 바뀌지 않는
행은 유지하고, 자세가 바뀌는 머리·날개·가슴·허벅지·발목·발톱·효과는 명시한 행으로
다시 저작했다. 도형 마스크, 수식 몸체/명암, 프레임 전체 이동/회전, 보간, 자동 구멍 채우기는
사용하지 않았다. `render.py`는 격자 읽기, 정확한 팔레트 PNG/GIF 인코딩, 진단 배경/라벨,
최근접 진단 확대만 담당한다. 모든 native PNG/GIF는 128px 그대로다.

## 참고 관찰

`../references/human-size.png`를 실제 열어 작은 우향 눈, 차분한 색 면과 64px 인간 크기를
관찰했다. 얼굴/크기의 시각 관찰만 했으며 픽셀을 추출하거나 원본 그림을 복사하지 않았다.
이 종은 인간형이 아닌 128px 맹금 보스다.

## 외형과 재질

- 우향 3/4 금갈색 맹금: 뒤로 쓸린 금빛 볏, 서로 다른 폭의 두 금안, 눌린 검은 눈썹.
- 은백의 굽은 부리와 목털: 넓은 크림빛 면, 청회 그림자, 부리 아래의 짧은 검은 갈고리 경계.
- 두 황금 날개: 어깨의 연결 면, 꺾인 팔꿈치/손목, 밝은 깃대와 어두운 깃 겹침, 갈라진 주깃 끝.
- 세 꼬리깃: 금갈색 뿌리와 서로 다른 끝. 준비/휴식 때도 세 어두운 겹침 경계를 유지한다.
- 두 회은 다리: 금빛 넓적다리 → 굵은 은회 발목 → 밝은 발가락 → 어두운 안쪽 발톱 끝.
- 왼쪽 위 광원: 금은 h/k, 은백은 j/w의 큰 밝은 면, 오른쪽/아래는 g/b/s 및 v/t로 분리했다.

## 자세와 실제 교정

1. 대기: 목과 어깨가 이어진 원본을 먼저 열었다. 초기 목털의 긴 사선, 배 아래의 수평 단절,
   먼 허벅지 연결 부족을 직접 새 행으로 바꿨다. 몸통을 넓게 만들고 두 허벅지를 연결했다.
   대기 b는 어깨/가슴 윤곽이 부풀고, c는 먼 눈꺼풀과 아래 주깃의 끝이 달라진다.
2. 준비: 두 날개를 접고 무릎을 굽혔다. 전진: 두 날개를 펼치며 뒤 발로 밀고 앞 발을 든다.
   접촉: 같은 앞 다리의 넓적다리/발목을 압축하고 앞쪽으로 뻗는 발가락과 안쪽 갈고리를 그렸다.
   회수: 팔꿈치와 주깃을 내려 접고 앞 발을 다시 내린다.
3. 전진/접촉의 꼬리 밑동 y=94–103은 눈으로 보니 몸과 떨어져 있었다. 두 자세 각각의 실제
   좌표 x=25–59에 넓은 금갈색 뿌리를 찍었다. 전진의 먼 허벅지 x=66–84, y=92–100도
   별도 넓은 면으로 다시 찍었다. 연결 진단으로 자동 채우지 않았다.
4. 접촉의 앞발 x=85–120, y=106–121을 큰 파지 면/굽은 끝/내부 빈 틈으로 다시 찍고,
   그 뒤에 남은 전진 발의 옛 픽셀은 명시한 점 행으로 지웠다. 지지 발은 y=124를 유지한다.
5. 피격: 머리/눈썹과 어깨가 처진 별도 형태. 떨어졌던 위 날개 조각을 연결된 처진 날개로
   새로 그렸다. 피격과 독 a의 옛 부리 잔여 2px (93–94,48)을 직접 제거했다.
6. 쓰러짐: 머리와 은백 목의 실제 부피를 낮은 몸에 연결하고 눈을 감겼다. 접힌 날개,
   두 은회 발, 세 꼬리깃을 남기고 몸의 하중 윤곽을 y=124에 둔다.
7. 독: 날개로 가슴을 누르고 부리를 벌리는 구역을 그렸다. 두 번째 기침은 턱/목과 날개
   윤곽을 바꾸고 거품을 다른 위치에서 깨뜨린다. 본체 전체 색조 변환은 없다.
8. 기절: 머리와 목이 크게 내려온 새 자세와 이완한 날개/굽은 다리. 두 번째는 눈꺼풀,
   가슴과 두 별의 위치를 바꿨다.
9. 수면: 살아 있는 앉은 몸의 넓은 배, 접힌 날개/허벅지/두 발, 세 꼬리깃을 유지한다.
   두 눈은 짧은 닫힌 눈꺼풀로 직접 찍었다. b는 볏/턱의 낮아짐과 가슴의 압축 윤곽을 바꾸며
   발과 꼬리를 유지한다. 두 수면을 1배 및 2배 GIF 재읽기 시트에서 비교했다.
10. 기술: 준비의 실제 주깃 끝에 금백 핵, 시전의 펼친 두 날개에서 서로 다른 세 황금 깃
    칼날, 회수의 접힌 날개와 두 끊긴 깃 잔광. 깃대와 계단형 가지/어두운 골을 직접 찍었다.

## 열어 본 그림과 인코딩 근거

- `png/*-backgrounds.png`: 원본 1배의 어두운/밝은/체커 배경.
- `png/*-inspection.png`: 같은 원본의 최근접 확대. 원본 저작에 확대를 역으로 쓰지 않았다.
- `png/contact-native.png`, `png/contact-inspection.png`: 전체 18자세 비교.
- `png/gif-*-native.png`, `png/gif-*-inspection.png`: 실제 저장된 GIF를 다시 읽은 순서/시간 시트.
- `gif-reload.json`: 8 GIF의 모든 디코드 프레임이 해당 native RGBA와 일치한다(차이 0px).
- `diagnostics.json`: 최종 격자 폭/행/색/경계와 연결 구역의 읽기 전용 기록. 미감 판정이 아니다.

## 남은 시각적 한계

금빛 주깃의 큰 면과 팔꿈치 꺾임은 강하게 각진 디자인이다. 깃 가지의 세부는 1배에서
큰 깃대보다 약하게 읽힌다. 수면 호흡은 작은 턱/가슴 변화라 빠른 속도에서는 섬세하다.
원본의 최종 미감과 실제 전투 속도에서의 읽힘은 하네스의 독립 검수/사용자 판단 대상이다.
이 작업에서 독립 검수자 호출, 검수 파일/모델 출처 꾸미기, 사용자 승인 선언, 게임 설치,
저장소·원격 DB·ledger 변경, 테스트/게이트 실행은 하지 않았다.

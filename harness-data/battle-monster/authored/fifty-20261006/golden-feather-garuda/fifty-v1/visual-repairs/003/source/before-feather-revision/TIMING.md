## 같은 공격 발의 추적

좌표는 0부터 시작하는 native (x,y)다. 오른쪽에 보이는 앞 다리가 타격한다.
준비에서 두 날개/발을 접고, 전진에서 뒤 지지 발이 밀며 앞 발목을 든다.
접촉의 엉덩이/허벅지 (82–98,96–103) → 압축 은회 발목 (86–103,106–112)
→ 두꺼운 발바닥 (102–112,108–117) → 세 굽은 발톱 (113–122,110–120)이
이어진다. 세 끝의 안으로 굽는 위치는 각각 y112, y116, y120이다. 이 발은 착지 때
펼친 발가락과 다른 파지 형태다. 지지 다리의 실제 발끝은 y124에 남는다.
회수는 같은 앞 다리를 내려 새 갈고리 발끝으로 다시 접지한다.

## 금익폭의 두 날개와 세 칼날

이 종의 기술 발원점은 손/무기/입 대신 **실제 황금 날개 끝**이다.

- 준비 `skill_a` 360ms: 먼 위 날개 끝 (31,10) 주위에 넓은 금백 핵,
  가까운 접힌 주깃 끝 (39,96) 주위에 두 번째 핵을 둔다. 두 핵은 흰 `w` 중심,
  금색 `k/h/o` 테두리로 날개에 직접 붙는다. 가까운 주깃이 안으로 모인다.
- 시전 `skill_b` 240ms: 먼 날개를 크게 펼친다. 상단 바깥 주깃/칼날 접합부
  대략 (77,19), 중단의 별도 바깥 주깃 끝 대략 (64,40), 가까운 날개 끝 대략
  (98,73)에서 각 밝은 깃대가 시작한다. 넓은 날개 내부에 새 칼날 밑동을 놓지 않는다.
  끝은 각각 (121,8), (121,30), (122,62) 방향이다. 세 금색 가지 면의 폭과 길이는
  다르고 밝은 깃대가 날개의 실제 외부 경계에 이어진다.
- 회수 `skill_c` 300ms: 두 날개를 다시 접으며, 상단 경로의 잔광은 x102–122,
  y10–19에, 하단 경로는 x104–122,y56–67에 남는다. 각 잔광은 깃대와 갈라진
  금색 가지가 끊어진 형태다. 부리/얼굴 (x88–102,y39–47)과 떨어져 있으므로
  입에서 새로 발사되는 모양을 만들지 않는다.

## 상태 동작

독의 두 장은 가슴을 누르는 날개와 벌어진 턱을 유지하며 기침/거품 위치가 다르다.
기절의 두 장은 힘이 빠진 날개와 처진 머리, 위치가 다른 별을 쓴다.
수면 a의 볏 시작은 y58, b는 y60이며 닫힌 눈·낮아지는 턱/압축되는 은백 목 면을
따로 그렸다. 접힌 두 발/발톱과 세 꼬리깃은 동일한 안정 위치에 두고 y124를 유지한다.
수면에는 독 거품/기절 별/기술 광선이 없다.

`gif-reload.json`은 저장된 실제 GIF의 프레임/노출 시간과 native 원본의 차이를 기록한다.
`png/gif-*-native.png`는 실제 GIF를 다시 읽은 그림이며 8종을 열어 확인했다.
시간순 그림으로 자세 경로를 확인한 범위다. 실제 게임에서의 연속 재생·피해 판정·소리와
대상 충돌 시간은 이 source 후보에 포함되지 않는다.

# 금익대붕 — 지적 좌표의 원본 교정

## 보존과 저작 범위

이번 수정은 이 후보의 `source/` 안에서만 했다. 정본은 `palette.json`,
`poses/*.pxgrid` 9장과 `actions/*.pxgrid` 9장이다. 파일마다 128행 × 128열의
완전한 리터럴 ASCII 원본이 있으며 18장 모두 서로 다르다. 기존 17색 팔레트를 그대로
유지했다. 투명은 팔레트에 없는 `.`이고 모든 외곽 1px은 투명이다. 최저 잉크 y=124,
대기 a의 실제 발톱 지지 끝도 y=124다.

수정 전 원본과 팔레트는 `original-before-repair/`에 보존했다. 기존 `author.py`를
보존하고, 새 `repair.py`에는 각 자세 이름, native 시작 좌표와 직접 고른 ASCII 행을
기록했다. 수정은 각 자세에 따로 명시한 행으로 적용한다. 수정 좌표를 다른 자세로
자동 전파하지 않는다. 코드는 리터럴 문자열을 저장하고 생략한 캔버스 바깥을 투명으로
패딩할 뿐, 본체·명암·효과를 도형이나 수식으로 만들지 않는다. 전체 프레임의 이동,
회전, 보간, 자동 구멍 메우기를 하지 않았다. `python source/repair.py`는 보존 원본에
이 명시된 교정을 다시 적용한다. `author.py`만 실행하면 이전 초안이므로 최종 수정본을
재구성할 때는 그 뒤에 `repair.py`를 적용한다.

첨부 `reference.png`와 `references/human-size.png`를 직접 열어 관찰했다. 참고 검객은
작은 우향 얼굴과 64px 크기 관찰에만 썼다. 참고 그림을 추출·추적·리샘플링하지 않았다.

## PNG를 열어 발견하고 다시 고친 부분

1. 처음 날개 구역을 바꾸면서 꼬리 윗면을 잘못 지운 것을 밝은/체커 PNG에서 확인했다.
   y95–105의 실제 꼬리 금색 면과 세 깃 경계를 명시한 행으로 복구했다.
2. 새 주깃 옆에 남은 옛 수직 끝 x49–53,y90–95를 PNG에서 지목해 제거했다. 날개와
   몸통 사이의 의도된 바깥 빈 공간은 보존했다.
3. 기술 시전 아래쪽에 옛 칼날 조각이 남아 네 갈래처럼 보였다. 실제 앞 날개의 오른쪽
   가장자리 y65–95를 다시 마무리하고 세 번째 깃 칼날만 해당 끝에서 이어지게 했다.
4. 회수 잔광의 옛 조각 x95 이상,y23–32와 부리 위 효과를 지우고 눈/부리 원본 색 면을
   직접 복구했다. 시전의 옛 내부 잔여 (72–73,50)도 제거했다.
5. 바뀐 지지 발 옆에 남은 옛 발바닥 끝 x78–79,y124 등을 각 자세의 실제 위치에서
   지웠다. 대기 c의 옛 주깃 1px (51,90)도 PNG와 좌표를 확인해 제거했다.

## 열어 본 결과와 파일 관찰

- `png/all-backgrounds-{1,2,3}-native.png`: 18자세 전체를 어두운/밝은/체커 배경에서
  원본 1배로 열었다. `*-inspection.png`에서는 문제가 있는 부위를 최근접 3배로 확인했다.
- `png/contact-native.png`, `png/contact-inspection.png`: 각 자세의 어깨, 목, 날개 겹침,
  발목과 꼬리를 함께 비교했다. 확대 그림은 진단용이며 native 원본은 모두 128px이다.
- `render.py`로 18 PNG와 8 GIF를 저장했다. 실제 GIF를 다시 디코드한 `png/gif-*-native.png`
  8종을 열었다. 공격/기술은 확대 시간순 시트도 열고 같은 앞발 및 두 날개 경로를 보았다.
  수면 두 장은 원본 1배 시간순 시트에서 닫힌 눈과 내려오는 턱을 비교했다.
- `gif-reload.json`: 저장된 모든 GIF 프레임의 native RGBA와 격자 렌더의 픽셀 차이는 0이다.
- `diagnostics.json`, `repair-observations.json`: 폭/행/색/잉크 범위와 실제 파일 해시의
  읽기 전용 관찰이다. 형식 게이트 결과나 미감 판정·사용자 선택을 뜻하지 않는다.
  연결 수치로 그림을 자동으로 고치지 않았다. 독 거품, 별, 두 회수 잔광의 분리는 의도적이다.

## 남은 시각적 한계

먼 날개의 큰 밝은 면과 준비·기절·수면의 접힌 이중 날개는 여전히 각진 원안 디자인이다.
현실적인 맹금의 넓은 부채꼴 깃보다 장식적인 황금 깃으로 읽힐 가능성이 남는다. 새 가까운
날개 끝의 짧은 겹침과 공격의 세 작은 갈고리는 원본 1배에서 확대 때보다 약하게 읽힌다.
수면 호흡은 2px 정도의 작은 머리/턱 변화다. PNG와 디코드된 시간순 그림을 확인했으며,
실제 게임의 타격 판정/접촉 시간과 재생 화면은 확인하지 않았다.

별도 검수자를 호출하거나 기존 검사/검수/선택 파일을 바꾸지 않았다. 테스트/게이트,
게임 저장소·ledger 변경과 설치를 하지 않았다. 이번 결과는 새 원본 수정 후보이며,
통과·사용자 승인·하네스의 현재 독립 판정을 주장하지 않는다.

## 공격 발

준비에서 두 날개/발을 모으고 move에서 뒤 지지 발이 밀며 같은 앞 발목을 든다.
attack의 앞 엉덩이/허벅지 (82–98,96–103) → 압축 은회 발목 (86–103,106–112)
→ 두꺼운 발바닥 (102–112,108–117) → 세 굽은 발톱 (113–122,110–120)이 이어진다.
발가락이 앞으로 뻗고 아래/안쪽으로 꺾이며 작은 내부 틈을 남긴다. 착지 발가락과
다른 파지 형태다. 반대 지지 발은 y124에 남고 recover에서 앞발도 다시 접지한다.

## 금익폭: 실제 날개 끝의 세 칼날

이 종은 손/무기/입 대신 실제 황금 주깃 끝에서 발사한다. 좌표는 native 0기준이다.

- skill_a,360ms: 먼 날개 첫 핵 (24–29,6–11), 둘째 핵 (12–17,19–22), 가까운
  마지막 주깃 핵 (34–38,94–96)이 금색 깃 면에 직접 붙는다. 원 오라는 없다.
- skill_b,240ms: 먼 첫 끝 (75–79,19–22), 별도 중간 주깃 끝 (78–82,39–42),
  가까운 끝 (98–107,72–75)에서 각 핵과 밝은 깃대가 이어진다. 칼날 끝은 상단
  (121,5), 중단 (120,27), 하단 (121,58) 방향이다. 세 황금 깃은 다른 길이/폭/가지와
  넓은 몸통 안의 w/k 중심 축을 갖는다. 중간 발사점은 넓은 날개 가장자리가 아닌
  돌출한 실제 주깃 끝이다.
- skill_c,300ms: 세 주깃을 접는다. 상단 x102–123,y5–17, 하단 x104–122,y60–71에
  깃가지가 끊긴 두 잔광이 남는다. 중간 잔광은 소멸한다. 입/얼굴은 발사점이 아니다.

## 상태 쌍

독은 처진 날개로 가슴을 누르고 열린 부리의 기침 턱과 변화하는 거품을 유지한다.
기절은 힘 빠진 날개와 처진 머리, 위치가 다른 별이다. 수면은 더 낮은 머리와
짧은 닫힌 눈꺼풀, 목털과 구분된 아래 갈고리 부리, 안정된 두 접힌 발을 유지한다.
sleep_a 볏은 y58, b는 y60에서 시작하며 b의 고개/턱이 낮아지고 가슴이 압축된다.
새 부리 군집도 a는 y74, b는 y75에서 시작하는 별도 행이다. 색조만 바꾸거나 전체
몸을 옮긴 호흡이 아니다. 접지 y124와 접힌 꼬리/날개 해부는 유지한다.

실제 GIF를 재읽은 gif-reload.json과 png/gif-*-native.png 8종을 열었으며 native RGBA
차이는 0픽셀이다. 시간순 그림 확인 범위이며 실시간 게임 재생·피해/소리/충돌 시간과
실제 독립 시각 검수는 포함하지 않는다.

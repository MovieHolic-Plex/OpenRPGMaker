# 금익대붕 — 해부·날개 발원점 수정 기록

## 작업 범위와 원본

이번 작업은 이 후보의 `source/` 안에서만 이루어졌다. 저장소, 게임 저장소,
brief, ledger, 다른 후보, 독립 검수 결과는 수정하지 않았다.
수정 전 18개 격자·팔레트·저작 기록·시간표는 `before-anatomy-repair/`에 보존했다.
`original-before-repair/`와 `before-feather-revision/`은 이전 단계의 보존본이다.

현재 정본 그림은 `poses/*.pxgrid` 9개와 `actions/*.pxgrid` 9개다.
모두 리터럴 ASCII 128행 × 128열이다. 팔레트 17색은 이번에 바꾸지 않았다.
점은 투명이며 palette.json에는 없다. 새 연결·명암·윤곽·효과는 각 자세에
대응하는 좌표와 ASCII 문자열로 직접 골랐다. 현재 수정 경위는
`anatomy_repair.py`에 남겼으며 입력은 `before-anatomy-repair/`다.
블록의 명시한 영역 안 남는 점은 옛 윤곽의 지우기다. 본체의 수식·도형 생성,
자동 구멍 채우기, 자세 간 좌표 전파, 몸 전체 이동/회전/보간은 사용하지 않았다.
이전 author.py/repair.py/feather_revision.py는 과거 저작 보조 기록이다.
이번 원본을 재현할 때는 anatomy_repair.py만 사용한다.

첨부한 현재 시트와 64px 검객 그림을 먼저 열었다. 검객은 얼굴 크기와 작은
눈·몸의 비례를 관찰하는 용도로만 보았고 픽셀 추출이나 복제에 쓰지 않았다.
원본 금익대붕의 은백 목털·부리, 금색 얼굴, 금갈색 큰 깃과 세 꼬리깃,
회은 발·갈고리 발톱, 왼쪽 위 광원과 우향 정체성을 유지했다.

## 실제 그림을 열어 확인한 범위

- `png/all-backgrounds-{1,2,3}-native.png`: 18자세 각각의 어두운/밝은/체커 배경 1배.
- 각 수정 자세의 `png/*-inspection.png`: 같은 세 배경의 최근접 3배.
- 목/어깨와 날개 뿌리, 몸통 투명 틈, 꼬리 뿌리, 모은 준비 발, 앞날개 핵,
  아래 칼날의 발원점, 접힌 회수 실루엣을 실제로 비교했다.
- 수면 a/b의 감긴 눈을 1배에서 보았으며 부리와 별개의 작은 눈꺼풀임을 확인했다.
  고개/턱, 가슴과 날개 윤곽의 변화도 쌍을 비교했다.
- `png/gif-*-native.png` 8종은 저장한 실제 GIF를 다시 디코드한 시간순 그림이다.
  공격·기술·기절·수면과 나머지 대기·피격·쓰러짐·독을 모두 열었다.
  렌더러가 보간 프레임을 만드는 경로는 없다.

`render.py`는 현재 리터럴 원본의 PNG/8GIF와 확인판만 굽는다.
`gif-reload.json`에는 실제 GIF의 각 프레임을 다시 읽어 현재 격자 RGBA와 비교한
결과가 있다. 이번 인코딩의 다른 픽셀은 0이다.
`observe_anatomy.py`와 `anatomy-repair-observations.json`은 현재 실제 파일의
해시·변경 픽셀 수·행/열/색·알파·외곽·바닥을 기록한 자료다. 모든 격자는
128×128, 모르는 팔레트 문자가 없고 1px 외곽은 투명하다. 모든 자세의 최하단
잉크는 y124이며 idle_a의 실제 지지 발도 y124에 닿는다. 알파는 0/255다.

이전 *observations.json은 이전 단계의 기록이다. 현재 파일 근거는
anatomy-repair-observations.json과 gif-reload.json을 사용한다.
자동 연결/투명 영역 진단은 읽기만 했다. 관찰된 모든 빈 공간을 메우는 방식은
쓰지 않았으며 정상적인 날개/몸 사이의 공간과 발가락 틈은 남겼다.

## 남은 표현 한계와 후속 검수

접힌 먼 날개의 세 깃은 큰 평행 면이 강해 사실적인 새보다 장식적 황금 깃으로
읽힐 수 있다. 기술 발사의 상단 두 큰 깃과 칼날도 직선적인 면이 강한 기존 표현이다.
준비의 접힌 날개에서 이동의 큰 펼침, 기술 발사에서 접힌 회수로 바뀌는 폭은
키 자세 사이에서 크다. 시간순 그림에서는 개폐 순서를 확인했지만 실제 전투
표시 크기에서의 재생, 엔진 이동/충돌, 피해·소리 동기는 확인하지 않았다.
작은 핵의 밝음과 수면의 작은 호흡은 1배에서 확대보다 약하게 읽힌다.

현재 원본의 새 독립 시각 검수는 하네스가 맡는다. 별도 검수자를 호출하지
않았으며 검수 통과·사용자 승인·모델 실행 출처를 추정하거나 꾸미지 않았다.
테스트/게이트는 실행하지 않았다. 이 기록은 수정한 후보 그림의 저작/관찰 기록이다.

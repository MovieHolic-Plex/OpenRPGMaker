# 금익대붕 — 현재 8 GIF 시간표와 날개 발원점

128×128 native 원본, 기존 17색과 0/255 알파.
리터럴 격자만 인코딩한다. GIF 중간 자세, 몸 전체 이동/회전/보간은 없다.

| GIF | 자세 순서 | 각 노출 시간(ms) |
| --- | --- | --- |
| idle | idle_a → idle_b → idle_c → idle_b | 240, 240, 240, 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 240, 180, 110, 170, 200, 240 |
| hit | idle_a → hit → idle_b | 240, 220, 240 |
| dead | idle_a → hit → dead | 240, 180, 1100 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 240, 360, 240, 300, 240 |

노출 시간과 순서는 기존 후보대로 유지했다. disposal=2, 투명 인덱스=0,
loop=0이며 쓰러짐에서 대기로 돌아오는 반복은 후보 미리보기용이다.

## 공격의 무게와 발

준비 windup은 날개를 접고 낮은 엉덩이 아래 두 다리/발을 모은다.
현재 엉덩이/허벅지의 하중 면은 y100–110, 은회 발목은 y110–118,
실제 발가락/굽은 끝은 y118–124다. 양발 모두 실제 몸과 연결되고 접지한다.
move에서 낮게 펼친 날개와 뒤 지지 발의 밀기를 읽고, 같은 앞다리가 공격으로 이어진다.

보존한 attack의 앞 엉덩이/허벅지 x82–98/y96–103 → 압축 은회 발목
x86–103/y106–112 → 두꺼운 발바닥 x102–112/y108–117 → 앞으로 뻗어
아래/안쪽으로 꺾인 세 발톱 x113–122/y110–120이 이어진다.
반대 지지 발은 y124에 남으며 recover에서 앞발도 다시 접지한다.

## 금익폭 앵커: 손/입/무기가 아닌 실제 날개 끝

모든 좌표는 각 128px 셀의 0기준이다. 부리/목털에서 발사하지 않는다.

- **skill_a, 360ms — 모으기:** 먼 날개 첫 금백 핵 x24–29/y6–11,
  둘째 핵 x12–17/y19–22를 보존했다. 가까운 앞날개 끝 x20–28/y82–91에
  h/k/w 금백 핵을 새로 찍었다. 기존 끝 x34–38/y94–96의 작은 빛도 유지했다.
  큰 앞날개 주깃에서 핵으로 이어지며 원 오라는 없다.
- **skill_b, 240ms — 발사:** 먼 첫 끝 x75–79/y19–22, 별도 중간 주깃 끝
  x78–82/y39–42에서 두 상단 칼날이 이어진다. 가까운 날개는 어깨
  x63–70/y78–85 → 넓은 깃 면 x76–97/y79–92 → 들어 올린 끝
  x90–98/y74–79 → 금백 핵 x90–95/y72–75 → 아래 깃 칼날의 밝은 축으로
  이어진다. 부리/목털과 발사부 사이에는 구분되는 틈과 어두운 깃 경계가 있다.
  세 칼날 끝은 각각 (121,5), (120,27), (121,58) 방향이다. 서로 다른
  길이·폭·계단형 가지와 금백 중심 깃대를 가진 기존 황금 깃 칼날을 유지했다.
- **skill_c, 300ms — 회수:** 먼 날개를 둥근 앞전과 세 겹의 아래 주깃으로
  접고, 가까운 날개도 x49–74/y60–94에서 몸쪽으로 접은 별도 실루엣이다.
  상단 x102–123/y5–17, 하단 x104–122/y60–71의 두 끊긴 잔광은 발사 방향을
  이어간다. 중간 잔광은 없다. 이후 idle_a에서 날개를 다시 편다.

## 상태 쌍

독은 아픈 날개/턱과 변화하는 거품을, 기절은 처진 날개/머리와 다른 별 위치를 유지한다.
이번 피격/독의 변경은 가슴의 같은 투명 결손 4픽셀씩이다. 상태 효과나 자세를
공격에서 재사용하지 않았다.

수면은 감긴 눈과 낮은 머리, 안정된 접힌 발, 꼬리 및 포개진 실제 깃을 유지한다.
sleep_a 볏은 y58, b는 y60에서 시작하는 기존 별도 얼굴 군집이다. b에서는
고개/턱과 가슴의 압축에 맞춰 가까운 날개의 윤곽도 별도 좌표 행으로 찍었다.
두 프레임 모두 실제 지지 발은 y124에 닿는다. 색 변경만으로 숨을 대신하지 않는다.

## 인코딩과 확인 범위

render.py로 PNG/8 GIF를 저장했다. 실제 GIF를 다시 읽은 gif-reload.json의
모든 프레임은 현재 격자 RGBA와 다른 픽셀이 0이다. png/gif-*-native.png
8종을 실제로 열어 시간순 윤곽을 확인했다. preview.html은 같은 GIF를 재생한다.
실제 전투 엔진의 표시 크기/시간/충돌/피해와 실시간 브라우저 루프 재생은
이번 확인 범위에 포함하지 않았다. 새 독립 검수나 사람 선택을 의미하지 않는다.

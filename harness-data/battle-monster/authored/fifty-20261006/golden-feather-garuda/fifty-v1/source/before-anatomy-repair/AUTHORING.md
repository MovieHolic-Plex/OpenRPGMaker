# 금익대붕 — 황금 깃·가슴·수면 부리 교정

## 원본과 보존

정본은 palette.json, poses/*.pxgrid 9장, actions/*.pxgrid 9장이다.
모두 완전한 128×128 ASCII 행이며 기존 17색을 유지한다. 이번 작업은 이 후보의
source 안에서만 했다. 게임 저장소, brief, ledger, 검수 결과와 다른 후보는 수정하지
않았으며 별도 검수자를 호출하지 않았다.

첨부 현재 시트와 자체 64px 검객 참고 이미지를 실제로 열었다. 검객은 우향 얼굴과
크기 관찰용이다. 참고 이미지의 픽셀 추출·추적·복제는 없다. 황금 깃의 왼쪽 위 밝은
면, 갈색 아래 면, 은백 부리와 목털, 회은 발의 정체성을 보존했다.

수정 직전 18격자·팔레트·문서는 before-feather-revision/에 보존했다. 이전의
original-before-repair/, author.py, repair.py도 남겨 두었다. 이번 저작 코드는
feather_revision.py다. 각 호출에 자세 이름, native y, 각 행의 x와 직접 선택한
ASCII 문자열이 있다. 각 자세의 교정을 별도로 명시했다. 전체 프레임 이동·회전·보간,
도형 래스터화, 명암 합성, 자동 구멍 채우기나 다른 자세로의 좌표 전파는 없다.
문자열 뒤 투명 패딩은 명시한 옛 그림 교체 구역을 지우는 용도다. 최종 격자는
패치 목록이 아닌 전체 리터럴 행이다.

재구성은 python source/feather_revision.py 후 python source/render.py다.
이번 코드는 보존한 수정 직전 원본을 읽는다. 옛 author.py 또는 repair.py만 실행하면
이번 수정 전 그림이므로 최종본과 다르다.

다른 18자세의 같은 부위를 함께 비교했다. hit·poison_a/b에서도 판 모양을 확인해
그 자세의 실제 어깨 위치에서 짧게 처진 세 주깃과 금색 뿌리를 따로 저작했다.
그 앞날개의 은백 띠도 금색 깃 면으로 고쳤다. move·attack의 펼친 먼 날개에는
세 번째 넓은 주깃 끝과 겹침선을 추가했다. 공격 발목/파지 발톱, 반대 지지 다리,
독 거품과 기침 턱은 보존했다. dead와 stun_a/b는 원본 그대로 보존했다.

## PNG를 열어 발견하고 다시 교정한 부분

- 첫 위 날개 부채와 어깨 사이가 벌어진 것을 확인해 x50–67,y44–58의 금색 뿌리를
  넓혔다. 가는 검은 선만으로 연결하지 않았다.
- 가까운 날개 교체 때 지워진 가슴 가장자리는 각 자세의 실제 곡선 좌표에서 다시
  찍었다. x58,y72에서 x54,y76 이후로 내려오는 원래 몸통 면을 복구했다.
- 꼬리 변경 뒤 남은 옛 x52–56,y124 조각은 직접 지웠다. 실제 은회 발과 발톱이
  y124에 닿는다. 분리된 조각으로 접지를 맞추지 않았다.
- 수면 부리의 첫 수정이 지나치게 큰 내부 홈을 만든 것을 확인해 은회 재질로 다시
  찍고 짧은 아래 부리 끝과 목털의 경계만 남겼다.
- 피격·독의 새 주깃과 옛 뿌리 사이 직각 간격은 덮깃 면과 계단 윤곽으로 이었다.

## 실제로 열어 확인한 파일

png/all-backgrounds-{1,2,3}-native.png의 18장 전체를 어두운/밝은/체커 배경의
원본 1배로 열었다. 대기·준비·이동·피격·독·기술·수면의 *-inspection.png 최근접
확대에서도 수정 부위를 확인했다. contact-inspection.png로 전체 해부와 겹침을
함께 비교했다. 확대는 진단 표시이며 native 원본은 128px 그대로다.

8 GIF를 저장한 뒤 실제 GIF를 다시 디코드했다. png/gif-*-native.png 8종을 모두
열었고 공격·기술·수면은 확대 시간순 시트도 확인했다. gif-reload.json은 실제 GIF와
격자 RGBA 차이를 기록하며 이번 인코딩의 차이는 0픽셀이다.
feather-revision-observations.json에는 실제 현재 파일 해시, 수정 픽셀 수,
행/폭/색/외곽/바닥 관찰을 남긴다. 시각 검수 판정이나 사용자 선택이 아니다.

## 남은 시각적 한계

접힌 준비·기절·수면 날개는 원안의 각진 접힘이 강하다. 펼친 이동/공격/기술의 날개
안쪽에도 넓은 기하적 금색 면이 남아 현실적인 맹금보다 장식적 황금 깃으로 읽힐 수
있다. 대기 깃 부채에서 돌격의 낮은 펼침으로 바뀌는 폭은 커서 110ms 이동 노출에서
급하게 느껴질 수 있다. 작은 발톱·깃가지, 수면 부리 경계와 작은 호흡은 1배에서
확대보다 약하게 읽힌다. 확인은 PNG와 GIF의 디코드 시간순 그림 범위다. 실제 전투
표시 크기·충돌·돌격 이동과 실시간 루프 재생은 확인하지 않았다.

테스트/게이트는 실행하지 않았다. 새 독립 검수는 하네스가 맡는다. 이번 원본의 통과,
모델 출처에 대한 추정, 검수자 판정 또는 사용자 승인을 주장하지 않는다.

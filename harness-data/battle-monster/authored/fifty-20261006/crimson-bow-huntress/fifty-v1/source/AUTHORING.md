# 적궁궁녀 · 활시위/홍우시 직접 교정

## 이번 작업 범위

기존 초안의 기본 9자세와 추가 9자세를 읽고 수정했다. 모든 쓰기는 이 후보의 `source/` 안에서 이루어졌다. 팔레트 18색, 성인 여성의 얼굴·포니테일·붉은 리본·녹청 저고리·바지·화살통·두 신발을 보존했다. 쓰러짐은 원본과 동일하다. 다른 16자세에는 활 상단 시위의 금색 픽셀만 추가했고, `skill_b`는 활팔·활·시위·화살 효과를 따로 다시 찍었다.

첨부 `reference.png`와 `references/human-size.png`를 실제로 열어 얼굴 비율·어깨·손/무기 연결을 관찰했다. 참고 픽셀을 추출하거나 복제·재배포하지 않았다. 격자 원본과 저작 보조 코드만 그림의 픽셀을 결정하며, 생성 이미지·도형 래스터화·프레임 전체 이동/회전·보간·자동 음영·자동 연결/구멍 채우기를 사용하지 않았다.

## 보존한 원본과 리터럴 수정

- 수정 직전 18개 격자, 팔레트, 이전 저작 기록/시간표/코드: `checkpoints/before-nock-arrow-repair/`.
- 최종 원본: `poses/*.pxgrid` 9개와 `actions/*.pxgrid` 9개. 각 파일은 완전한 64×64 ASCII 행이다.
- 이번에 직접 선택한 `(y,x,문자열)`은 `revise_pixels.py`에 보존했다. 각 자세에 다른 좌표를 명시했다. 특정 프레임의 좌표를 다른 프레임으로 자동 전파하지 않는다.
- `author_rows.py`는 기존 저작 기록을 유지하며 마지막에 이번 리터럴 교정을 적용한다. `render.py`는 완성된 격자를 읽어 PNG/GIF와 진단판을 만든다.

## 2. skill_b의 긴 홍색 화살

기존 y=23–38의 넓은 흰색/주황색 삼각 섬광과 y=40–41의 불필요한 잔점을 지웠다. 얼굴·머리·몸통·골반·다리는 유지하고, y=30–33의 활팔/소매/손목을 짧게 접힌 경로로 직접 재저작했다. 전체 프레임을 왼쪽으로 옮긴 것이 아니다.

활 상단은 (44–46,16), 실제 화살자리는 (45,31), 손가락 피부는 (43–44,31), 그 아래 파지는 (45,32)다. 상단 시위는 (44,17)→(43,18)→(42,19)에서 시작해 소매 뒤로 이어진다. 하단 시위는 x=42에서 내려와 (42–44,46)의 활 끝과 만난다. 피부 손목/손바닥과 G/R/X 파지 경계를 남겼다.

화살은 x=45–62, y=31의 직접 쓴 `hvhhhhhhhhhvveeevh` 축으로 18px 길이를 확보했다. 좁은 붉은 윗면/아랫면과 작은 밝은 핵을 두고, x=56–62, y=28–34에는 오른쪽 끝 (62,31)로 모이는 별도 화살촉을 찍었다. 긴 축 앞의 작은 화살촉으로 읽히며, 활 전체를 덮는 큰 섬광으로 만들지 않았다. 셀 오른쪽 x=63은 투명하다. 준비의 주홍 핵과 회수의 작은 깃 잔광은 원본을 유지했다.

## 실제 열어 본 결과와 출력

18개 자세 모두 밝은/어두운/체커 배경의 1배+최근접 3배 진단 PNG를 직접 열었다. 얼굴·목·어깨·팔꿈치·소매/손·파지·허벅지·발을 확인했고, 의도 없는 본체 투명 홈은 추가로 보이지 않았다. 수면 두 자세의 눈꺼풀과 턱/가슴 압축, 기존 무릎과 신발을 함께 확인했다. 전체 18자세 시트와 공격/기술/수면의 저장 GIF 디코딩 순서판도 직접 열어 비교했다.

`previews/`에 native PNG 18개와 진단판/전체 시트, `poses-sheet.png` 및 `actions-sheet.png`에 native 3×3 시트, `motions/`에 8개 GIF를 갱신했다. 렌더러가 저장된 GIF를 다시 읽어 원본 불투명 RGBA/투명 영역 및 유지 시간을 대조했다. 실제 파일 SHA-256과 GIF 디코딩 정보는 `render-inventory.json`에 계산되어 있다. 출력의 전체 잉크 범위는 x=8–62, y=8–60이고, 기본 대기 신발은 y=60이다.

## 남은 시각적 한계

- 어두운 배경에서 검은 머리/신발 외곽의 대비가 약하다. 이번 한정 교정에서는 원래 팔레트와 본체 명암을 유지했다.
- `skill_b`에서 활팔을 접어 화살 공간을 만든 만큼 준비→방출 사이의 활/손 위치 변화가 보인다. 순서판은 확인했지만 실시간 재생의 자연스러움이나 실제 전투 배치는 확인하지 않았다.
- 화살은 64px 셀의 x=62에서 끝난다. 셀 밖 장거리 비행이나 실제 피해 판정은 이 원본에 포함되지 않는다.
- 화살통과 뒤쪽 팔의 겹침, 작은 수면 호흡, 피격→쓰러짐의 중간 자세 부재는 기존 초안의 한계로 남아 있다.

별도 검수자를 호출하지 않았다. 하네스의 새 독립 검수와 사용자 선택은 아직 이 작업의 완료 근거가 아니다. 검수 결과·사용자 승인·모델 provenance를 만들거나 수정하지 않았으며 테스트/게이트를 실행하지 않았다.

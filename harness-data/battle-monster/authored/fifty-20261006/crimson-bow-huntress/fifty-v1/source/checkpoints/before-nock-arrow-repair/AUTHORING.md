# 적궁궁녀 · fifty-v1 직접 도트 저작

## 범위와 원본

- 이 후보의 `source/`만 작성했다. 종/후보/브리프/ledger/게임 저장소/저장소 코드는 수정하지 않았다.
- 시작 때 원본 격자가 없었다. `poses/` 9개와 `actions/` 9개를 각각 독립적으로 저작했다. 각 최종 `.pxgrid`는 64줄 × 64개의 리터럴 ASCII 글자이며 점은 투명이다.
- 공통 팔레트는 18색, 불투명 픽셀의 alpha는 255이다. 일반 대기 본체는 y=8–60의 53px 높이이며 두 작은 신발이 y=60에 닿는다. 모든 최종 그림은 x=1–62, y=1–60 안에 있다.
- `author_rows.py`에 직접 선택한 행 문자열과 수정 좌표를 보존했다. 도구가 하는 일은 빈 캔버스 초기화와 리터럴 행/좌표 기록뿐이다. 프레임 변형, 도형 래스터화, 음영 합성, 자동 구멍 채우기를 하지 않았다.
- `checkpoints/idle_a-first.pxgrid`는 이번 저작의 첫 대기 체크포인트다. 과거 승인본 또는 다른 종의 그림이 아니다.
- 참고 검객 그림은 실제로 열어 작은 눈·눈썹, 성인 SD 비율, 팔과 도구의 겹침을 관찰했다. 참고 픽셀 추출·트레이싱·복제·배포를 하지 않았다.

## 본체와 재질

성인 여성의 검은 포니테일, 붉은 리본, 녹청 저고리, 회갈색 바지, 붉고 검은 굽은 활, 금색 띠의 등 화살통을 유지했다. 피부의 큰 밝은 면은 왼쪽 위, 턱과 오른쪽 볼은 피부 그림자로 구별한다. 머리카락은 H/K/X의 넓은 면, 천은 u/t/T, 바지는 q/p/P로 저작했다. 활의 h/r/R은 천 리본과 같은 색 계열이지만 얇은 곡선 테두리와 파지로 구별한다. 회갈 바지는 허벅지와 무릎에 넓은 색 면이 있어 가는 실처럼 보이지 않도록 했다.

## 실제 그림을 보고 고친 군집

1. 첫 `idle_a`의 활손이 도구에서 떨어져 있었다. y=38–42의 아래팔/소매/피부 손목을 다시 찍고 x=49–52의 단일 파지로 연결했다. 이후 `idle_b/c`의 같은 부위도 각각 완전한 행 문자열로 다시 정리하여 덧쓰기 뒤 남은 검은 돌기를 지웠다.
2. `windup/move`의 금색 화살이 아래팔 면을 가로질렀고 파지 표시가 두 번 보였다. y=30의 화살자리와 y=31–33의 넓은 소매/손을 분리해 직접 다시 썼다. 현손은 목 아래에서 당기며 접힌 팔꿈치를 거쳐 뒤 어깨에 붙는다. 활손은 앞으로 뻗고 파지는 하나만 남겼다.
3. `poison_a/b`의 활과 손이 떨어져 있었다. 각각 y=43–49, y=45–51에서 반대 팔을 배 앞으로 굽혀 소매 끝→손목→손가락→활 파지를 직접 이어 붙였다. 아픈 손은 턱 쪽에 따로 남았다.
4. 첫 수면의 가로놓은 활이 바지와 발을 가렸다. 두 수면 모두 활을 오른쪽으로 낮춰 쥐게 다시 그렸고, 두 무릎의 q/p/P 면과 두 신발을 따로 남겼다. 무릎 사이의 작은 의도한 빈 공간은 보존했다.
5. 얼굴은 가까운 작은 눈/먼 눈/앞쪽 피부 여유를 직접 찍었다. 수면은 `sleep_a`의 y=31, `sleep_b`의 y=32에서 검은 열린 눈 대신 s/H의 짧은 수평 눈꺼풀을 썼다. 수면 둘째 그림은 턱과 어깨/가슴 윤곽이 1px 내려오고 몸통이 압축되지만 무릎·발·손·파지를 유지한다. 전체 프레임을 이동시킨 결과가 아니다.
6. 전진/방출의 기울어진 얼굴에서 잘못 선택한 코/눈 픽셀이 윤곽 밖으로 나온 것을 GIF 디코딩 시트에서 발견했다. `move` y=19–26, `attack` y=18–25, `skill_b` y=18–25의 얼굴/머리 경계를 각 자세의 전체 행으로 다시 썼다. 연속 피부 면과 코 앞 여유를 회복했다.
7. 쓰러짐의 오른쪽 신발 바닥이 x=63에 닿았다. `dead` y=60의 실제 신발 끝을 x=56–61로 새로 그려 투명 테두리를 회복했다. 닫힌 눈, 피부 목, 접힌 바지와 머리 뒤 포니테일을 유지했다.

## 자세와 동작

- 대기 3자세: 머리/눈을 안정시키고 어깨·소매·가슴과 화살통의 작은 숨 변화를 각각 찍었다.
- 준비→전진→방출→회수: 현손 당김, 뒤 지지발의 밀기, 벌어진 허벅지와 앞쪽 무릎, 뻗은 활팔, 회수하는 현손을 별도로 저작했다.
- 피격: 어깨가 왼쪽으로 무너지고 눈썹/눈과 작은 입이 아픈 표정으로 바뀐다.
- 쓰러짐: 머리와 피부 목이 낮은 옷 몸통에 이어지며, 몸과 신발의 하중 윤곽이 바닥에 닿는다.
- 홍우시: 실제 활 화살자리에서 밝은 주홍 핵을 모으고, 오른쪽으로 긴 밝은 화살과 위/아래의 다른 깃 갈래를 내보낸다. 회수는 낮아진 활 옆에 끊어진 작은 깃 잔광을 남긴다.
- 독: 턱 쪽 손과 움츠린 어깨, 배 앞 활팔, 다른 위치/크기의 녹청·황금 거품.
- 기절: 처진 머리/어깨와 늘어진 팔, 낮은 활, 각각 다른 위치의 작은 별.
- 수면: 닫힌 눈, 앉은 두 무릎과 발, 낮춰 든 활, 두 번째 자세의 작은 턱/가슴 압축.

## 확인한 산출물

`render.py`로 18개 native PNG, 밝은/어두운/체커 배경의 1배+최근접 3배 진단 PNG, 전체 시트, native 3×3 두 시트, 8개 GIF를 만들었다. 실제 PNG와 전체 18자세 시트를 열어 관절/파지/목/눈/발을 관찰했다. 저장된 GIF를 다시 디코딩했고 불투명 RGBA와 투명 영역이 원본과 일치했다. 8동작의 디코딩 순서 시트를 실제로 열어 공격과 수면 쌍의 윤곽을 비교했다. 현재 원본과 PNG의 실제 SHA-256은 `render-inventory.json`에 계산해 보존했다.

브라우저에서 GIF를 시간에 따라 재생해 보는 작업은 실패했다. 설치된 Chrome과 headless shell이 이 실행 환경의 소켓 제한(`Operation not permitted`)으로 시작하지 못했다. 따라서 브라우저 재생을 관찰했다고 보고하지 않는다. `preview.html`과 `inspect-animation.cjs`는 재생 가능한 환경에서 확인할 수 있도록 보존했다. GIF 자체를 읽고 각 실제 디코딩 프레임을 확인한 근거는 `previews/*-gif-decoded.png`다.

## 남은 표현 한계

- 64px 셀 안의 화살 비행 길이가 짧다. 일반 화살 끝과 홍우시의 밝은 끝은 x=62까지이며, 셀 밖 장거리 탄도는 표현하지 않는다.
- 등 화살통과 뒤쪽 팔은 앞쪽 옷/머리카락에 일부 가려져 있다. 1배에서 작은 구별이 약해질 수 있다.
- 피격→쓰러짐은 두 자세의 전환이라 바닥까지 내려가는 중간 자세가 없다. 시간표에서 쓰러짐을 오래 유지했다.
- 수면 호흡과 대기 호흡은 작은 변화다. 실시간 반복 재생의 자연스러움은 브라우저 제한 때문에 추가 확인이 필요하다.

독립 검수자나 사용자 선택을 대신하지 않는다. 검수자를 별도로 호출하지 않았고, 통과/승인 사건이나 모델 실행 provenance를 만들어 쓰지 않았다. 저장소 테스트·게이트를 실행하지 않았다.

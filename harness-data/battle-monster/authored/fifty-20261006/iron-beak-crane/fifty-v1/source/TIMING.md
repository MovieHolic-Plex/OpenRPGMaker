# 철취학 GIF 시간표

모든 GIF는 native 64×64px, 팔레트 16색과 투명 index 0이다. 실제 원본 자세를 아래 시간만큼 유지하며 프레임 이동, 회전, tween, 자동 효과를 넣지 않는다. `previews/index.html`에서 8개 동작을 동시에 볼 수 있다.

| GIF | 순서와 유지 시간(ms) | 합계 |
|---|---|---:|
| idle.gif | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 | 960 |
| attack.gif | idle_a 300 → windup 220 → move 120 → attack 140 → recover 220 → idle_a 320 | 1320 |
| hit.gif | idle_a 320 → hit 260 → recover 240 → idle_a 320 | 1140 |
| dead.gif | idle_a 300 → hit 180 → dead 1000 | 1480 |
| skill.gif | idle_a 260 → skill_a 280 → skill_b 200 → skill_c 280 → idle_a 320 | 1340 |
| poison.gif | poison_a 480 → poison_b 480 | 960 |
| stun.gif | stun_a 480 → stun_b 480 | 960 |
| sleep.gif | sleep_a 600 → sleep_b 600 | 1200 |

좌표는 각 원본의 왼쪽 위 (0,0) 기준이다. 모든 자세의 최하단 잉크는 y=60, idle_a 발끝은 정확히 y=60이다. 배치/전투 카메라 이동은 이 원본에 굽지 않았다.

## 물리 공격

- windup: 목을 접고 머리를 뒤로 당긴 220ms 준비.
- move: 뒤 지지발이 밀고 앞발이 나가며 먼 날개가 어깨에서 반쯤 벌어진다.
- attack: 목을 뻗어 부리 끝으로 쪼는 실제 접촉 자세, 140ms. 몸/목/얼굴/쇠 부리가 이어진다.
- recover: 목을 들어 당기고 날개와 다리 간격을 줄이는 220ms 회수.

## 철취풍 앵커

손/무기가 없는 새 종이므로 **실제 쇠 부리**가 시전 앵커다.

| 원본 | 부리와 효과 연결 좌표 | 연출 |
|---|---|---|
| skill_a | 금속 끝 M=(54,18), 바로 이웃 바람 A=(55,18)부터 오른쪽 훅 | y=11..26의 회백 바람을 부리 옆에 모은다. 끝 픽셀 하나는 모은 바람으로 덮여 실제 접촉을 보인다. |
| skill_b | 금속 M=(47,27), 바로 이웃 바람 C=(48,27); 아래 금속 끝 M=(48,28) 옆 C=(49,28) | 위쪽 갈래는 (59,14)까지 길게 올라가고 아래쪽 갈래는 (60,37)로 더 짧게 떨어진다. 두 가지의 길이/너비/끝 계단이 다르다. 준비 훅을 확대하지 않았다. |
| skill_c | 금속 끝 M=(53,15), 바로 이웃 잔상 B=(54,15) | 목을 다시 들고 부리에 남은 한 조각을 해체한다. 다른 조각은 x=49..61, y=10..34에 끊어진 짧은 픽셀 묶음으로 흩어진다. |

skill_b는 200ms의 발동/접촉 자세다. 실제 게임의 피해/소리 시점을 지정하거나 검증한 기록은 아니다.

## 상태 동작

- 독: 두 프레임의 아픈 머리 높이, 가슴/날개의 처짐, 독 방울 수·위치를 바꿨다. 480ms씩 느리게 흔들린다.
- 기절: 늘어진 목과 부리를 한 박자 더 내려 그렸고 별 위치/형태를 바꿨다. 다리는 지면을 지킨다.
- 수면: 접은 다리 위치를 고정하고 가슴과 목의 숨을 600ms씩 번갈아 보인다. 닫힌 눈과 낮춘 부리를 유지한다. 죽음처럼 옆으로 눕지 않는다.

검토용 GIF는 반복(loop=0)한다. dead.gif의 마지막 자세 이후 처음으로 돌아오는 것은 반복 미리보기의 재시작이다. 실제 게임의 부활 동작을 저작한 것이 아니다.

## 확인 자료

- `gif-filmstrip-attack.png`: 저장된 공격/피격/쓰러짐/기술 GIF에서 읽은 프레임과 실제 hold.
- `gif-filmstrip-idle.png`: 저장된 대기/독/기절/수면 GIF에서 읽은 프레임과 실제 hold.
- `encoding-report.json`: 현재 PNG/격자 해시와 인코딩 시간표. 독립 검수/사용자 승인 결과를 포함하지 않는다.

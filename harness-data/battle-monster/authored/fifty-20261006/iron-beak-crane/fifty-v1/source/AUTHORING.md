# 철취학 — 원본 18자세 저작 기록

## 범위와 원본

이 후보의 `source/` 안에서만 저작했다. 외부 저장소, 게임 저장소, brief, ledger, 다른 후보는 수정하지 않았다. 사용자 승인이나 독립 검수 판정은 작성하지 않았다. 실제 모델 실행 출처와 후속 검수는 호출한 하네스의 기록을 따른다.

- `palette.json`: 투명 `.`을 제외한 ASCII 기호 16개와 RGB 색.
- `poses/`: 기본 9자세, 각각 64행 × 64글자의 완전한 리터럴 pxgrid.
- `actions/`: 기술·독·기절·수면 9자세, 같은 크기의 완전한 리터럴 pxgrid.
- `author.py`: 직접 고른 `y x ASCII행` 원본과 발가락 교정 좌표. 빈 캔버스에 해당 글자를 쓰고 전체 행으로 저장하는 보조 코드다. 도형 그리기, 음영 계산, 프레임 이동·회전·보간이 없다.
- `render.py`: 원본을 읽어 PNG/GIF로 저장하고 검토판을 만드는 코드. 확대는 진단용 최근접 보기에서만 한다. 실제 PNG/GIF는 원본 64px이고 기본/추가 시트는 192×192px이다.
- `history/first-pass/`: 발가락/바람 외곽 교정 전의 18격자, 팔레트와 저작 코드를 보존했다.
- `previews/encoding-report.json`: 실제 현재 격자·PNG 해시, 경계와 ink 수, GIF 순서/시간. 미감 판정이나 승인 기록이 아니다.

## 참고 관찰

첨부된 `references/human-size.png`를 직접 열었다. 64px 안에서 모자/머리, 얼굴, 어깨, 손과 도구의 연결, 지면까지 내려오는 실루엣이 어떻게 읽히는지 관찰했다. 철취학에는 얼굴이나 무기를 복사하지 않았다. 참고 바이트, 추출 픽셀, 리샘플링한 참고 그림을 source에 넣지 않았다.

## 본체와 재질

우향 3/4 두루미다. 정수리 `R/r`, 작은 황금색 눈 `Y`, 검은 눈 주변 `O/K`, 밝은 볼과 긴 S자 목, 회백색 접힌 날개, 검푸른 날개 끝, 긴 두 다리와 세 갈래 발가락을 직접 찍었다.

- 깃털: 왼쪽 위의 `H/C` 넓은 면, 중간 `B`, 오른쪽 목·배·겹친 깃의 `A/S` 면.
- 부리: 좁은 위쪽 `I` 반사, 넓은 `M` 금속 면, 아래쪽 `K/S`와 끝 `O`. 목/얼굴에서 실제로 이어진다.
- 날개 끝: `K/S/O`로 큰 어두운 깃 덩어리를 유지했다. 펼친 날개도 어깨에 붙어 있다.
- 다리: `L` 밝은 힘줄 면, `G` 어두운 면, `O` 가장자리. 몸에서 발끝까지 이어지며 두 다리 사이의 투명 공간은 보존했다.

기본 자세는 y=8..60, x=7..57을 사용한다. 작은 몸을 가운데 넣어 여백으로 키우지 않았다. 대기 다리의 발끝은 정확히 y=60에 닿는다.

## 자세별 저작

| 자세 | 실제 픽셀 변화 |
|---|---|
| idle_a/b/c | 발 위치를 고정하고 목 길이/굽음, 어깨의 밝은 면, 접힌 깃의 하단을 조금씩 다시 찍었다. |
| windup | 머리를 뒤로 당기고 목을 접었다. 부리를 아래로 기울였고 무게를 뒤쪽 다리에 실었다. |
| move | 어깨에서 연결된 먼 날개를 들어 벌리고, 뒤 지지발을 뻗고 앞발을 내디뎠다. |
| attack | 낮아진 머리, 수평으로 뻗은 목/부리, 압축된 몸, 넓어진 다리 간격을 별도로 찍었다. |
| recover | 목을 들어 당기고 날개를 접으며 다리 간격을 줄였다. |
| hit | 눈을 감은 짧은 검은 선, 뒤로 젖은 머리, 틀어진 목/어깨, 밀린 무게를 찍었다. |
| dead | 몸을 바닥에 내려놓고 목을 가로로 눕혔다. 눈은 닫혔고 다리는 몸 아래에 구부러져 이어진다. |
| skill_a/b/c | 부리 끝의 굽은 바람 모으기 → 길이가 다른 위/아래 절삭 돌풍 → 목을 올리고 깨진 조각으로 해체. |
| poison_a/b | 굽은 목과 아픈 눈, 아래로 처진 가까운 날개, 구부러진 앞다리, 크기/위치가 다른 녹색 독 방울. 몸 색조를 바꾸지 않았다. |
| stun_a/b | 어깨보다 낮게 늘어진 목/머리와 부리, 처진 날개, 닫힌 눈. 두 별의 모양/위치도 다시 찍었다. |
| sleep_a/b | 접은 다리로 안정되게 앉고 머리를 어깨에 낮췄다. 눈은 닫고 가슴의 부풀음과 머리의 작은 숨 변화를 찍었다. 쓰러짐의 누운 자세와 다르다. |

## 실제로 열어 본 그림과 교정

원본 1배 `native-backgrounds.png`와 4배 `sheet-light.png`, `sheet-dark.png`, `sheet-checker.png`를 직접 열었다. 저장된 8GIF를 다시 디코딩한 `gif-filmstrip-attack.png`, `gif-filmstrip-idle.png`도 열어 준비/전진/접촉/회수와 상태 변화의 배열을 확인했다. 실시간 게임 장면 검증은 이 후보 저작 범위에 포함되지 않는다.

1. 첫 본체에서 가슴/접힌 날개 면이 지나치게 가늘었다. `idle_a` y=30..44의 원본 행을 다시 골라 회백색 가슴과 아래쪽 깃 면을 넓힌 뒤 나머지 자세를 찍었다.
2. 부리 끝의 투명 테두리를 침범한 긴 행을 직접 줄였다. `attack` y=29의 마지막 금속 면, `dead` y=56..58의 끝/밑면을 각각 명시한 행으로 교정했다. 최종 잉크는 x=1..62, y=1..60 안에 있다.
3. 검토판에서 발끝이 검은 가로 덩어리처럼 보였다. 18자세의 y=59/60(쓰러짐은 y=60)을 각 자세의 발 위치에서 다시 찍었다. 예: `idle_a` y=59 x=20 `OLGLGLO..OLGLGLO`, y=60 x=19 `OGO.G.OGO.OGO.G.OGO`. `CORRECTIONS`에 모든 자세의 정확한 문자열을 남겼다. 발가락 사이의 투명 점은 의도된 틈이다.
4. 밝은 배경에서 철취풍 외곽 대비가 부족했다. `skill_a` y=14..26의 훅 바깥쪽, `skill_b` y=16..36의 두 돌풍 오른쪽/아래쪽, `skill_c` y=15/16/24/28/34의 잔상에 직접 고른 `A/S` 끝 픽셀을 추가했다. 같은 원 오라나 자동 윤곽을 사용하지 않았다.
5. 연결 진단은 읽기만 했다. 기본 9자세와 수면은 하나의 8방향 연결 본체로 읽혔다. 기술 준비/발동은 부리와 바람이 이어졌다. 독 방울, 기절 별과 해체된 바람 조각의 분리는 의도했다. 자동 구멍 채우기는 하지 않았다.

PNG와 GIF는 원본 팔레트 그대로 저장한다. GIF를 다시 열어 모든 프레임의 가시 RGB, alpha와 hold가 원본/시간표와 맞는지 인코딩 단계에서 확인했다. 18개 현재 격자는 서로 다른 해시를 가진다. 테스트 스위트, 게이트, 별도 검수자를 실행하지 않았다.

## 남은 시각적 한계

- 1배에서 눈은 작은 점/선이고 세 갈래 발가락도 작다. 확대 화면보다 세부 가독성이 낮다.
- 밝은 배경의 회백 돌풍은 그림자 끝을 보강했어도 어두운 배경보다 대비가 낮다.
- 쓰러짐은 한 개의 마지막 자세를 길게 유지한다. 중간 낙하 자세가 없어 피격에서 바닥 자세로 넘어갈 때 변화가 크다. 움직임을 보간하여 감추지 않았다.

후속 하네스의 실제 독립 검수와 사용자 판단을 위한 완전한 후보 원본이다. 승인/통과를 이 문서에서 선언하지 않는다.

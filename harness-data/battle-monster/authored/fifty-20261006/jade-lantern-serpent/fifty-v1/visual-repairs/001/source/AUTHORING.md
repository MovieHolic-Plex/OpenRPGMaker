# 옥등사 — 직접 픽셀 저작 기록

## 범위와 원본

- 이 후보의 `source/` 안에서만 파일을 작성했다. 시작 시 `poses/`는 비어 있었다.
- 기본 9자세와 추가 9자세를 새로 저작했다. 다른 종이나 반려 원본을 가져오지 않았다.
- `palette.json`은 18개의 ASCII 기호와 RGB 색이다. `.`은 투명이며 팔레트에 없다.
- 모든 `poses/*.pxgrid`, `actions/*.pxgrid`는 독립적인 96행 × 96문자 ASCII 원본이다.
- `write_literal.py`에는 처음 찍은 행, 고정된 본체 군집, 자세별 새 행과 이후 교정 좌표를 보존했다. 코드는 직접 적은 문자열을 지정 좌표에 놓고 전체 행을 저장한다. 도형·수식으로 본체나 명암을 만들지 않는다.
- 움직이지 않는 코일과 꼬리/등롱 군집은 일부 자세에서 그대로 유지했다. 변한 목·턱·표정·광원 면·효과는 해당 자세의 native 행/좌표로 따로 찍었다. 전체 프레임 이동·회전·보간은 사용하지 않았다.

## 참고 관찰

첨부 `references/human-size.png`를 실제로 열었다. 작은 눈, 얼굴 앞쪽 여유, 큰 명암 군집, 팔과 도구의 연결을 관찰했다. 사람 그림의 픽셀을 추출하거나 복사하지 않았다. 이 종은 96px 뱀 요괴이므로 사람의 팔·발·무기 대신 목, 턱, 코일, 꼬리와 등롱의 연결을 저작했다. 참고 이미지 사본을 결과물에 넣지 않았다.

## 외형과 재질

- 우향 3/4 머리, 검은 두 눈, 길게 굽은 목, 둥근 아래 코일, 금빛 배판, 왼쪽 꼬리 끝의 녹청 등롱. 뿔과 다리는 없다.
- 왼쪽 위 빛: `H/L`의 넓은 비취 광택 면 → `J` 기본색 → `S/T` 깊은 옆면. 흰 반사 점을 몸 전체에 흩뿌리지 않았다.
- `B/G/Y/D`는 배판과 금속 테두리. 배판의 작은 횡 경계는 몸을 삭제한 투명 줄이 아니라 연결된 갈색/금빛 픽셀이다.
- 등롱은 금속 지붕과 바닥 테두리, `E/F/C/W`의 녹청 몸통과 밝은 핵을 따로 구분했다.
- `P/N`은 독 상태의 기포에만 썼다. 본체 전체를 독 색으로 바꾸지 않았다.
- 코일 가운데 구멍, 쓰러짐 꼬리의 작은 고리, 열린 턱, 기포 가운데 빈 공간은 의도한 투명이다.

## 실제 PNG를 보고 교정한 위치

좌표는 0부터 시작한다. 아래는 원본을 다시 찍은 위치이며 자동 연결 보정이 아니다.

1. **대기 목과 배판:** `idle_a/b/c`, 대략 x=34–63, y=51–63. 처음의 뾰족한 배판 돌출을 매 자세의 행으로 다시 찍었다. 남아 있던 x=64, y=59의 고립된 외곽 한 점은 세 자세 각각 명시적으로 지웠다.
2. **코일 앞쪽:** y=64–92, x=49–64의 배판 경계를 직접 정했다. 밝은 비취 면과 어두운 옆면이 이어지고 배판이 매 행마다 다른 폭으로 튀지 않게 수정했다. 코일 중심의 빈 공간은 유지했다.
3. **회수와 피격:** `recover` y=53–63, `hit` y=54–63. 목 아래에 덧붙여 보이던 테두리와 배판 경계를 해당 위치에서 다시 찍었다. 피격의 이전 코일 수정 행이 만든 가로 경계도 제거했다.
4. **시전:** `skill_b`, x=48–69, y=40–44. 입 안의 빛과 독기 뿌리 사이의 빈 틈을 직접 연결했다. 목 아래 y=51–63을 다시 찍어 본체가 가로로 잘린 듯한 돌출을 없앴다. 독기 끝이 오른쪽 경계 밖으로 나가던 행도 짧은 굽은 군집으로 다시 저작했다.
5. **기술 회수:** `skill_c`, y=47–63의 목/배판. 시전 자세와 별도로 폭을 좁혀 아래 몸에 이어지게 했다. 외곽이 배판의 명암 행마다 1px씩 튀는 곳을 직접 수정했다.
6. **독 상태 두 자세:** `poison_a` y=55–63, `poison_b` y=56–63. 넓어지던 목 면이 코일 위에서 가로로 끊기던 부분을 각자의 목 군집으로 다시 찍었다. 기포는 의도한 별도 효과이며 본체를 채우는 데 쓰지 않았다.
7. **기절 두 자세:** y=57–63. 처진 턱 아래의 목과 배판이 같은 본체로 이어지게 두 프레임 각각 수정했다. 별과 작은 반짝임은 다른 위치에 남겼다.
8. **수면 눈:** 두 자세의 y=57, 가까운 눈 x=48–51와 먼 눈 x=57–58을 짧은 `T` 눈꺼풀로 저작했다. 이 얼굴 구역에 평상시 검은 `K` 눈 군집은 없다. 실제 1배와 확대 PNG에서 닫힌 눈을 확인했다.
9. **물기 접촉:** `attack`, x=31–89, y=40–64. 처음의 짧은 아래턱을 길게 다시 찍고 위턱 끝도 확장했다. 윗송곳니는 위 잇몸에, 아랫송곳니는 아래 잇몸에 연결했다. 아래턱에는 밝은 상면과 금빛/갈색 아랫면을 따로 찍었다.

## 확인한 그림과 보존 파일

- `artifacts/all-native.png`: 모든 18자세를 실제 1배로 비교.
- `artifacts/all-3x.png`: 모든 자세의 어두운 배경 최근접 확대.
- `artifacts/<pose>-inspection.png`: 밝은/어두운/체커 배경을 나란히 놓은 3배 확대.
- `artifacts/checker-1.png`부터 `checker-3.png`: 18자세의 실제 투명 경계와 코일 빈 공간을 함께 확인한 시트.
- `artifacts/poses-sheet.png`, `actions-sheet.png`, `suite-sheet.png`: 투명 native 시트. 확대나 라벨을 원본에 넣지 않았다.
- `artifacts/*.gif`: 원본 팔레트를 그대로 사용하는 8개 동작.
- `artifacts/*-decoded-strip.png`, `motions-decoded-native.png`: 실제 GIF를 다시 열어 얻은 프레임과 노출 시간. GIF 재읽기 픽셀은 해당 원본 RGBA와 일치했다.
- `render.py`: 격자 읽기, PNG/GIF 굽기, 진단 배경/라벨/최근접 확대만 담당한다.
- `artifacts/geometry.json`의 해시는 실제 렌더 결과로 계산했다. 검수나 사용자 선택의 해시로 주장하지 않는다.

확인된 파일 계약: 18개의 서로 다른 RGBA, 팔레트 18색, 모든 격자 96×96, 알파 0/255, 1px 투명 여백, 가장 낮은 잉크 y≤92. `idle_a`의 아래 코일은 정확히 y=92에 닿는다. 테스트/게이트와 독립 검수자 호출은 실행하지 않았다.

## 남은 시각적 한계

- 핵심 자세 수가 고정되어 준비→홉→접촉의 목/코일 변화는 빠른 박자로 읽힌다. 추가 중간 자세로 보간하지 않았다.
- 접촉의 긴 턱에서는 두 검은 눈이 대기보다 가늘고 기울어 보인다. 1배에서 물기와 대기의 얼굴 인상이 얼마나 일관적인지는 독립 시각 검수에서 판단할 부분이다.
- 독기 두 갈래는 96px 안에서 끝나는 짧은 효과다. 실제 상대와의 거리·게임의 타격 위치는 이 후보 PNG/GIF만으로 확인하지 않았다.
- 이 기록은 저작자의 직접 그림 점검이다. 독립 하네스 검수 결과나 사용자 승인을 의미하지 않는다.

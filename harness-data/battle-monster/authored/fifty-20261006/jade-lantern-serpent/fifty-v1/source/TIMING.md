# 옥등사 — GIF 시간표와 연결 앵커

## 원본 재생

모든 GIF는 96×96 원본 자세를 그대로 사용한다. 프레임을 이동·회전·보간하거나 중간 그림을 합성하지 않는다. GIF 투명 인덱스와 RGB는 원본 팔레트에서 직접 배정한다. 노출 시간은 10ms 단위이며 아래 값은 실제 GIF를 다시 읽어 확인한 값이다.

| GIF | 자세 순서 | 각 노출 시간(ms) | 총 루프(ms) |
|---|---|---|---:|
| idle.gif | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 | 960 |
| attack.gif | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 | 2140 |
| hit.gif | idle_a → hit → idle_a | 700 / 180 / 900 | 1780 |
| dead.gif | idle_a → hit → dead | 700 / 150 / 1700 | 2550 |
| skill.gif | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 | 2260 |
| poison.gif | poison_a → poison_b | 420 / 420 | 840 |
| stun.gif | stun_a → stun_b | 300 / 300 | 600 |
| sleep.gif | sleep_a → sleep_b | 650 / 650 | 1300 |

`dead.gif`의 처음 자세 복귀는 비교용 GIF 루프다. 죽은 몸이 게임에서 다시 일어나는 동작을 뜻하지 않는다.

## 공격의 무게

1. `windup`: 낮춘 목과 압축 코일로 준비한다. 기준 코일의 바닥을 유지한다.
2. `move`: 뒤쪽 코일을 넓게 풀어 민다. 하단 잉크는 y=87에서 끝나며 5px 들린 홉을 보여 준다. 머리와 코일을 각각 새 행으로 저작했다.
3. `attack`: 긴 위/아래 턱을 벌리고 송곳니를 잇몸에서 이어 접촉한다. 아래 코일이 다시 y=92에 놓인다.
4. `recover`: 목을 세우고 몸 앞의 금빛 배판을 회수한다.

## 옥등식 앵커 — 0부터 시작하는 native 좌표

이 종에는 손·무기·뿔이 없다. 실제 앵커는 **꼬리 끝의 등롱**과 **입**이다.

- **모으기 / skill_a, 260ms:** 등롱 내부 x≈11–20, y=50–58에 넓은 `C/W` 핵을 찍었다. 꼬리 x=20–29, y=63–70에도 짧은 청록 군집이 이어진다. 입 안 y≈32에도 작은 녹청 빛을 보인다.
- **시전 / skill_b, 160ms:** 열린 입 x≈49–58, y=40–43이 실제 출발점이다. x=48–69, y=40–44의 입/독기 군집이 연결되고, 이 공통 뿌리에서 위와 아래 경로가 갈라진다.
  - 위 경로는 y≈38에서 위로 휘어 x≈88, y=18의 좁은 끝으로 이어진다.
  - 아래 경로는 y≈44에서 아래로 굽고, x≈94, y≈49에서 돌아 x≈83, y=65의 끝으로 회수되는 갈래다.
  - `W/C` 중심, `F/E` 가장자리로 넓은 옥빛 독기 면을 직접 찍었다. 원형 오라가 아니다.
- **잔기 / skill_c, 240ms:** 턱을 닫는다. x≈82–87, y=24–29와 x≈78–85, y=34–39의 위쪽 두 잔기만 남긴다. 아래 경로의 두 덩이는 native 효과 픽셀을 직접 투명으로 지워 회수의 두 잔기 계약에 맞췄다.

효과가 입과 붙어야 하는 시전 자세와, 입에서 이미 분리되어야 하는 회수 잔기를 구분했다. 청록 효과를 눈이나 코일 중심에 붙이지 않았다.

## 상태 동작

- 독: 턱/목의 수축과 옆면 변화. 보라 기포의 개수·위치·크기도 다르다.
- 기절: 처진 머리와 다른 눈꺼풀 방향. 별은 프레임마다 다른 native 좌표에 있다.
- 수면: 두 눈은 y=57의 짧은 닫힌 눈꺼풀. 접힌 꼬리와 코일 위치를 유지하고, 정수리/가슴의 작은 면 변화로 숨을 표현한다. 650ms씩 천천히 노출한다.
- 쓰러짐: 낮은 머리, 접힌 꼬리 고리, 옆으로 놓인 등롱을 함께 남긴다. 수면 자세와 다르다.

# 가시관마귀 GIF 시간표

원본은96×96, 각 픽셀 알파0/255. PNG와 GIF는 원본 크기이며, 확인판만 최근접 확대했다. 모든 GIF는 무한 반복, disposal=2이며 투명 팔레트 항목이 별도로 있다. 인코딩 후 각 GIF 프레임을 다시 읽어 원본 RGBA 픽셀과 노출 시간을 확인한다. 아래 값은 ms다.

| GIF | 원본 자세 순서 | 각 노출 |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 |
| hit | idle_a → hit → idle_a | 700 / 180 / 900 |
| dead | idle_a → hit → dead | 700 / 150 / 1700 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 300 / 300 |
| sleep | sleep_a → sleep_b | 650 / 650 |

## 공격 추적

오른쪽에 보이는 가까운 긴 팔을 공격 팔로 유지했다. 준비의 낮은 손과 압축된 두 무릎 → 전진의 뒤 지지발 밀기/들린 앞무릎/올라온 공격 어깨 → 접촉의 뻗은 아래팔과 굽은 긴 손가락 → 몸 쪽으로 돌아오는 팔이다. `move`의 앞발은 들리고 뒤발이 y=92에서 지지하며, `attack`에서는 두 발을 벌려 하중을 받는다. 몸 전체를 이동한 프레임은 없다.

## 자극진의 실제 손끝 앵커

좌표는 native 캔버스의0기준이다.

- `skill_a`: 앞 손가락은 x=57–64/y=63–68. x=61–66/y=67–70의 작은 자주 기와 x=61–70/y=59–66의 짧은 줄기는 이 손끝에서 모인다.
- `skill_b`: 손바닥/손가락은 대략 x=60–69/y=54–62. 상향 줄기는 x=63/y=55에서 손과 겹쳐 위로 굽으며 x=85–89/y=25–34의 끝에 이른다. 하향 줄기는 x=65/y=58의 손가락 부근에서 출발해 x=75–90/y=67–74에서 갈라지고 x=69–78/y=77–80으로 되굽는다. 짧은 옆가시와 서로 다른 말단을 직접 저작했다.
- `skill_c`: 같은 앞팔을 당긴 손 부근 x=64–70/y=69–73에 짧은 연결 잔상이 남는다. x=78–83/y=37–41, x=85–89/y=46–49, x=84–88/y=77–80의 분리된 작은 조각은 회수 파편이다.

## 상태와 땅

독은 배를 누르는 팔과 굽은 목/표정이 기포와 함께 바뀐다. 기절은 내려온 머리/늘어진 팔과 서로 다른 별이다. 수면은 같은 접힌 발과 닫힌 눈을 유지하면서 가슴/배의 면으로 작게 숨 쉰다. 쓰러짐은 수면과 달리 옆으로 내려간 몸과 접힌 두 다리이다. 실제 발 또는 몸의 하중 윤곽이 y=92에 닿는다.

`motions/<동작>-decoded.png`는 해당 GIF를 다시 읽은 프레임 순서의 확인판이다. 실제 게임의 피해/소리/상태 적용은 이 후보의 저작 범위에 포함하지 않았다.

## 이번 손·무릎 교정의 앵커와 시간표

순서와 노출 시간은 위 표를 유지했다. 현재 8 GIF는 수정된 18장 원본으로 다시 인코딩했다.

- `windup`: 뒤손은 x10–21/y74–83에서 낮춰 준비하고, 가까운 공격 손은 x57–75/y76–84에서 무릎 밖에 놓인다. 이 가까운 팔을 `move → attack → recover`에서 추적한다.
- `attack`: 기존 어깨와 전완에서 이어진 손바닥은 x74–80/y52–60이다. 위쪽 끝은 x84–88/y56–61, 가운데 끝은 x80–84/y59–65, 아래쪽 끝은 x74–78/y63–68에서 각각 아래로 굽는다. 열린 작은 틈은 손가락 분리이며 각 뿌리는 손바닥과 연결된다.
- `sleep_a/b`: 전완은 x59–69/y77–82에서 손목으로 접히고, 손바닥/느슨한 손가락은 x55–67/y83–85에서 앞무릎 위에 놓인다. 무릎 면은 x57–70/y86–88이며 닫힌 눈과 두 발의 위치를 유지했다. 두 프레임의 위 가슴/배·전완 면이 작게 호흡한다.

기술 3장의 실제 손끝/줄기 앵커는 위 기록과 같고 원본 픽셀도 유지했다. PNG와 모든 GIF 프레임을 다시 읽은 픽셀/시간표 결과는 `rendered/READBACK.json`에 있다. 8개의 `motions/*-decoded.png`는 실제 GIF에서 읽은 프레임 순서 확인판이다.

실제 속도 재생의 매끄러움과 게임의 hop 경로·타격 판정은 별도 확인이 필요하다. 파일 재읽기는 독립 시각 검수 통과나 사용자 승인이 아니다.

# 가시관마귀 — 앞팔·갈고리 손 보완 기록

## 현재 후보와 보존 원본

기존 fifty-v1의 18자세를 대상으로 독립 검수에서 지목된 대기 앞팔과 공격 손만 직접 보완했다. 이번 수정은 `source/`에 저장했다. 수정 전 18장 격자, 팔레트, 저작 행 원본과 문서는 `before-arm-repair/`에 보존했다. 그곳의 AUTHORING.md는 이전 저작 기록이며 이번 세션의 행동을 증명하는 문서가 아니다.

현재 원본은 `poses/`의 9장과 `actions/`의 9장이다. 모두 96행 × 96글자의 완전한 ASCII 팔레트 인덱스 격자다. `palette.json`의 기존 18색과 투명 기호 `.`를 유지했다. 외곽 1px는 투명하며, 모든 자세의 실제 발 또는 쓰러진 몸의 하중 윤곽은 y=92에 닿는다. 좌표는 0부터 센다.

첨부 현재 시트와 참고 검객 PNG를 실제로 열어 우향 얼굴, 목·어깨 연결, 크기와 명암을 관찰했다. 참고 이미지의 픽셀은 원본에 사용하지 않았다. 암자주 본체, 흰 가시관, 녹청 허리띠, 회갈 갈고리 발과 왼쪽 위 광원은 기존 개체의 정체성으로 유지했다.

## 이번에 직접 고른 픽셀

### 대기 앞팔: 상완 → 팔꿈치 → 전완 → 손목

기존 앞팔은 복부의 D/S 그림자에 합쳐져 길이와 굽힘이 읽히지 않았다. 어깨 아래에 좁은 P 중간색 면을 두고, 복부 쪽에 D/S 경계를 찍었다. 상완은 안쪽으로 내려오고 팔꿈치의 작은 L 면을 거쳐 전완이 바깥쪽 손목으로 돌아간다. 밝은 면은 뒷팔보다 좁게 유지해 오른쪽 그늘의 광원 관계를 보존했다. 복부와 팔 사이에 새 투명 구멍을 만들지 않았다.

| 자세 | 직접 수정한 좌표 범위 | 수정 픽셀 수 |
|---|---|---:|
| idle_a | x=52–62, y=44–68 | 84 |
| idle_b | x=53–63, y=44–68 | 84 |
| idle_c | x=51–62, y=45–68 | 82 |

각 자세의 실제 어깨·복부·손목 위치에서 행 문자열을 따로 지정했다. 프레임 전체 이동이나 다른 자세에서의 자동 좌표 복사는 사용하지 않았다. 기존 손가락과 허리띠 아래의 의도한 빈 공간은 남겼다.

### 공격: 전완의 면과 세 갈고리 손가락

`attack`의 x=65–88/y=49–66에서 182픽셀을 보완했다. x=65–73 부근에는 전완 윗면의 L/P와 아랫면의 S/D를 나누고, 손목에서 손등으로 이어지는 넓은 피부 연결을 남겼다. 손가락은 아래로 곧게 처진 모양에서 오른쪽으로 뻗고 끝을 안쪽으로 굽힌 세 군집으로 바꿨다. 위쪽 끝은 x=83–88/y=55–58, 가운데 끝은 x=80–84/y=60–64, 아래쪽 끝은 x=73–79/y=63–66 부근이다. 세 손가락은 같은 손바닥에서 이어지고 말단의 작은 틈과 음영 경계로 갈라진다.

첫 보완 PNG에서는 손가락이 하나의 고리처럼 뭉쳐 보였다. 실제 확대를 연 뒤 y=56–66의 행을 다시 골라 끝을 서로 다른 높이로 벌리고 손가락 사이에 작은 열린 틈을 두었다. 그 두 번째 보완도 리터럴 문자열로 남겼다.

`move → attack → recover`의 실제 PNG와 GIF 디코딩 시트에서 같은 가까운 앞팔의 어깨·상완·팔꿈치·손목을 추적했다. 전진/회수의 손은 이미 세 손가락과 굵은 전완이 구별되어 해당 원본을 유지했다. 공격 팔의 근위부와 지지 다리는 바꾸지 않았다.

## 그대로 보존한 14자세

`windup`, `move`, `recover`, `hit`, `dead`와 추가 동작 9장은 수정 전 격자와 바이트가 같다. 추가 동작도 모두 완전한 리터럴 원본으로 존재한다.

- 기술: 앞 손끝의 짧은 자주 기 → 손에서 실제로 이어지는 굽은 두 가시 줄기 → 손을 당긴 짧은 잔상과 세 파편. 각기 다른 몸·팔·효과 배열이다.
- 독: 배를 누르는 팔, 낮은 목·아픈 턱/표정과 서로 다른 기포 위치·크기.
- 기절: 처진 머리와 늘어진 양팔, 서로 다른 별 위치와 작은 목/가슴/손 변화.
- 수면: 앉아 접힌 다리, 무릎 위 손, 짧은 닫힌 눈꺼풀. 두 장에서 e색의 열린 눈 군집을 사용하지 않고 작은 가슴/배 면으로 숨을 표현한다.
- 쓰러짐: 바닥 가까이 누운 몸과 피부 부피가 남은 목, 두 접힌 다리와 발. 수면과 다른 수평 실루엣이다.

팔 사이, 다리 사이, 갈고리 끝, 손가락 사이, 기술 줄기와 파편 사이의 의도한 빈 곳을 보존했다. 연결 검사로 자동 채우거나 그림을 합성하지 않았다.

## 저작 보조 코드와 실제 확인

- `authored_rows.txt`: 이전 저작 행과 이번 자세별 보완 문자열. 해당 섹션 뒤에 직접 고른 변경을 덧붙였다.
- `repair_arm_clusters.py`: 대기 세 장과 공격 전완/손의 첫 보완 좌표 문자열.
- `repair_hook_tips.py`: 첫 PNG를 보고 세 손가락 끝을 다시 고른 두 번째 보완 문자열.
- `render.py`: 리터럴 격자를 PNG로 인코딩하고 기존 시간표의 8 GIF를 만든다. 그림의 도형 생성·이동·회전·보간을 하지 않는다.
- `inspect_repair.py`: 원본 읽기, 전후 차이 기록, 배경/라벨/최근접 진단 확대만 수행한다.

현재 18장 전체를 밝은/어두운/체커의 1배 PNG와 체커 3배 PNG로 실제 열었다. `repair-after-detail.png`에서 세 대기 팔과 전진·공격·회수의 손을 함께 확대해 확인했다. 공격의 세 갈고리 군집은 확대에서 분리되고, 대기 팔꿈치의 중간색 굽힘은 1배에서도 복부 음영과 구별된다. 목·복부에 새 투명 결손은 보이지 않는다. 수면 두 장의 닫힌 눈과 접힌 발도 원본 1배에서 확인했다.

8개 GIF를 다시 인코딩한 뒤 모든 프레임을 디코딩해 원본 RGBA 및 노출 시간과 비교했다. 이 실제 디코딩에서 만든 `motions/*-decoded.png` 8장도 모두 열었다. `rendered/READBACK.json`에는 현재 격자/PNG/GIF의 실제 해시와 재읽기 결과가 있으며, `REPAIR-READBACK.json`에는 전후 픽셀 수와 크기/여백/접지 실측이 있다. 기록은 파일 진단과 정적 시각 확인이다. 저장소 테스트나 게이트를 실행한 결과가 아니다.

## 남은 시각적 한계와 검수 상태

96px 원본에서 갈고리의 작은 내부 틈과 관의 짧은 안쪽 가시는 확대보다 덜 또렷하다. 대기·수면 변화는 작고 절제되어 있다. 공격은 준비·전진·접촉·회수의 네 핵심 자세여서 전진에서 뻗은 팔로 넘어가는 변화가 빠르다. GIF 디코딩 시트로 팔 경로와 인코딩 결과를 확인했으나 실제 게임의 hop 이동, 접촉 위치, 피해 연출과 실시간 재생의 매끄러움은 확인하지 않았다.

이번 수정 뒤의 독립 검수는 하네스가 수행할 단계다. 이 문서는 검수 통과, 사용자 선택 또는 승인을 선언하지 않는다.

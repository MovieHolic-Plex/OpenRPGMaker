# GIF 순서·정지 시간·입 발원점

각 GIF는 저장한 128×128 원본 격자를 그대로 사용한다. 모든 hold는 10ms 단위이며 자동 중간 프레임이나 전신 좌표 이동은 없다. 팔레트는 고정이고 투명 인덱스는 0이다.

| GIF | 순서 | hold (ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 |
| hit | idle_a → hit → idle_a | 700 / 180 / 900 |
| dead | idle_a → hit → dead | 700 / 150 / 1700 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 300 / 300 |
| sleep | sleep_a → sleep_b | 650 / 650 |

## 준비 → 전진 → 물기 → 회수

windup은 앞다리와 턱을 낮게 접는다. move에서 뒤 엉덩이와 연결된 위마디를 굽힌 무릎으로 옮기고, 아래마디를 뒤쪽에 경사지게 심어 밀기 실루엣을 만든다. 얼굴과 같은 가까운 앞다리는 이미 전진한 원안 군집을 유지한다. attack의 두 송곳니는 각자 머리 뿌리에서 이어져 x=84–85, y=90 부근의 좁은 접촉으로 모인다. recover는 그 앞다리와 턱을 당긴 원안을 유지한다. 움직임의 거리는 런타임에서 관찰한 것이 아니다.

## 구목독의 실제 입 발원점

이 종에는 손이나 무기가 없다. 발원점은 입과 두 송곳니 사이이며 얼굴/턱이 연결돼 있다.

- skill_a: x=75–80, y=77–81의 자주 핵과 작은 밝은 중심. 얼굴이 올라가며 두 송곳니 뿌리는 유지된다.
- skill_b: 실제 입 안쪽 x=76–79, y=80–83에서 x=77–92, y=81–84의 연속 실을 통해 큰 두 갈래로 이어진다. 상단은 오른쪽 위 x=117, y=40 부근, 하단은 오른쪽 아래 x=118, y=111 부근으로 뻗는다. 하단의 가로실과 빈 공간은 거미줄 구조다. 두 격자는 원안을 그대로 보존했다.
- skill_c: 수정한 짧은 두 송곳니가 x=77–80, y=85–87 부근으로 모이고 검은 입틈이 좁아진다. 기존 세 잔여 독방울은 x=96–102, y=88–93 / x=106–112, y=95–100 / x=116–120, y=87–91에 유지했다. 방울은 의도한 분리 효과다.

## 상태와 호흡

poison은 앓는 낮은 턱/앞다리와 크기·높이가 달라지는 기포를, stun은 처진 얼굴/송곳니와 다르게 놓인 두 별을 사용한다. 해당 네 격자는 원안을 보존했다.

sleep_a/b는 아홉 짧은 회색 눈꺼풀을 유지한다. 붉은 대기 눈을 복사하지 않았다. 두 송곳니는 이완된 머리 바로 아래로 모이고 머리는 접힌 지지 마디 위에 놓인다. sleep_b의 갑판 꼭대기는 y=54로 한 픽셀 높아지고 머리의 덮개/턱은 낮게 쉬며 긴 가까운 다리는 넓은 무릎에서 접힌다. 배·머리·다리 변화는 각 자세의 별도 ASCII 좌표 문자열이며 프레임 전체를 옮긴 결과가 아니다. 원래의 나머지 발과 양쪽 실제 접지 y=124를 유지한다. dead의 낮게 무너진 배/이완된 다리와 구별하는 생전 갑판의 높은 안정 자세다.

preview/timing.json은 실제 GIF에 저장한 순서와 hold다. preview/*-decoded.png는 저장된 GIF에서 다시 읽은 프레임이며 all-gifs-decoded.png는 여덟 동작을 함께 놓은 확인판이다. 이 자료는 새 독립 검수, 사용자 승인 또는 전투 런타임 검증을 뜻하지 않는다.

# 심연구목거미 — 원안의 명시 좌표 수정

## 작업 범위와 보존

이 작업은 이 후보의 `source/`만 수정했다. 첨부 현재 시트와 64px 검객 참고를 실제 열어 관찰했다. 참고의 픽셀이나 색을 추출하지 않았다. 기존 회은 갑판의 좌상단 광원, 검자주 몸, 아홉 붉은 눈, 여덟 다리와 두 송곳니를 유지했다.

정본은 `palette.json`, `poses/*.pxgrid` 아홉 개와 `actions/*.pxgrid` 아홉 개다. 각 파일은 128행 × 128글자 전체 ASCII 격자다. 점은 투명이며 팔레트에 없다. 팔레트 16색은 기존 파일과 동일하다. `idle_a`, `idle_c`, `windup`, `recover`, `hit`, `dead`, `skill_a`, `skill_b`, `poison_a/b`, `stun_a/b`의 12개 원본 격자는 바꾸지 않았다.

수정 전 18개 격자, 팔레트, 저작 보조 코드, 렌더러와 두 기록은 `original-before-repair/`에 보존했다. 그 원본 격자를 해독한 PNG/8GIF도 해당 폴더의 `preview/`에 있다. 이 자료는 원안 보존용이며 새 결과의 승인 기록이 아니다.

## 직접 고른 수정 군집

좌표는 왼쪽 위 원점, 0부터 센 native 픽셀이다. `repair.py`에 각 자세의 개별 좌표와 리터럴 색 문자열을 보존했다. 점으로 지운 부분도 명시했다. 다른 자세로 좌표를 자동 복사하거나, 프레임을 이동·회전·보간하거나, 도형·명암을 합성하거나, 연결 검사로 구멍을 메우지 않았다.

| 자세 | 직접 수정한 곳 | 표현 |
|---|---|---|
| idle_b | 먼 송곳니 x=82–103, y=87–90; 턱 뿌리 x=83–88, y=79–80 | 수평으로 길게 늘어난 밝은 돌기를 지웠다. 기존 대기와 같은 길이의 굽은 송곳니에 어두운 외곽과 가늘어진 끝을 남겼다. 작은 변화는 뿌리의 반사면에 있다. |
| move | 뒤 다리 x=3–33, y=64–107; 갑판 앞쪽 상부 x=50–65, y=25–32 | 엉덩이에서 짧고 넓은 위마디를 내려 굽힌 무릎으로 잇고, 무릎에서 뒤쪽으로 경사진 아래마디를 펼쳤다. 짧은 발끝이 y=107에 붙는다. 원근상 뒤 발은 올라온 바닥선이고 가까운 실제 지지발은 y=124를 유지한다. 이미 전진한 얼굴/앞다리를 보존하며 갑판 윗곡률과 밝은 면을 작게 압축했다. |

| sleep_b | 갑판 윗곡률 x=35–62, y=54–58; 머리/겹친 먼 앞다리 x=70–114, y=82–109; 가까운 앞마디/무릎/발 x=71–100, y=105–124 | 갑판 꼭대기를 한 픽셀 높게 팽창시키고 낮은 머리의 덮개를 정리했다. 얼굴에 가려진 먼 다리는 밝은 면이 끊기거나 톱니처럼 보이지 않도록 각 행에서 다시 골랐다. 가까운 앞다리는 목 아래 위마디 → 넓은 무릎 x=83–96, y=114 → 경사진 아래마디 → 실제 발끝 x=91–100, y=124로 이어진다. 짧은 계단형 토막을 긴 접힌 마디로 바꾸었다. 닫힌 눈은 유지한다. |

최초 수정 PNG에서 수면의 먼 마디에 잘못 선택한 어두운/밝은 군집과 잔여 윤곽이 보였다. x=92–114, y=86–101을 실제 확대 그림과 비교하면서 연속된 갑각 면과 별도의 뒤 다리 테두리로 다시 정리했다. 수면 두 자세의 원래 다리 사이 빈 공간은 유지했다.

## PNG와 실제 GIF 확인

`render.py`는 격자의 색을 그대로 해독한다. PNG에 새 신체를 그리지 않으며 최근접 확대는 진단 그림에만 쓴다. 실제 저장한 8개 GIF를 다시 읽어 대응 PNG의 RGBA와 비교하고, 그 GIF 프레임들로 만든 `preview/all-gifs-decoded.png`를 실제 열었다. 공격의 준비/전진/접촉/회수, 기술의 모으기/두 갈래/닫힌 턱, 수면의 두 프레임을 함께 관찰했다.

밝은·어두운·체커 배경의 1배 및 최근접 3배 그림을 실제 열어 확인했다. 전체 상태에서 송곳니/목/다리의 대응 부위를 함께 살폈으며, 수정이 필요한 현재 여섯 자세에만 개별 행을 적용했다. `preview/native-part-*.png`, `preview/*-part-*.png`, `preview/sleep-native.png`와 `preview/sleep-knee-detail.png`가 현재 확인판이다. `repair-before.png`와 `details-first.png`는 각각 수정 전/중간 진단 그림이다.

`preview/repair-summary.json`은 실제 격자의 크기·투명 테두리·잉크 범위·원안 대비 변경 수를 기록한다. 모든 행 폭과 높이는 128이다. 바깥 1px은 투명하고 모든 자세의 최하단 실제 신체/발 잉크는 y=124다. `idle_a`의 원래 지지발도 정확히 y=124다. `preview/source-hashes.json`은 현재 파일의 실제 SHA-256이며 검수 binding 또는 사용자 선택이 아니다.

## 남은 시각 한계

- 위쪽 먼 두 다리는 가까운 다리보다 가늘다. 이 수정은 지적된 밀기 다리와 턱/수면에 한정했으며 모든 먼 다리의 무게감을 다시 저작하지 않았다.
- 돌격에서 갑판 전체의 무게 이동은 작고 얼굴/앞다리/뒤 무릎의 변화가 크다. 실제 전투의 이동 거리, 적중과 자연스러운 런타임 연결은 여기서 관찰하지 않았다.
- 수면의 머리는 앞다리 위에 낮게 놓이며 생전의 큰 둥근 갑판을 유지한다. 그러나 갑각을 입은 접힌 마디들이 겹치는 오른쪽 얼굴 뒤에서는 먼 다리의 전체 경로를 1배에서 세기 어렵다. 두 번째 프레임은 눈을 닫은 채 갑판 윗곡률/머리/지지 마디가 함께 달라지고 발은 바닥을 받친다.
- 물기와 기술 회수는 작은 native 턱 군집이다. 배경·인게임 크기에서의 가독성은 새 독립 검수와 실제 런타임에서 추가로 판단해야 한다.

별도 검수자를 호출하거나 테스트/게이트를 실행하지 않았다. 검수 결과, 승인, 합격, 모델 식별 또는 사용자 선택을 작성하지 않았다. 새 독립 검수는 하네스가 맡는다.

## 보조 코드 실행

현재 수정본은 `python source/repair.py` 후 `python source/render.py`로 다시 저장할 수 있다. repair.py는 보존한 같은 자세의 원안 전체 리터럴 행을 읽고 그 자세에 명시한 좌표만 적용한다. 원안의 `author.py`와 교정의 `repair.py`는 별개로 보존한다. 새 검수의 지적은 해당 자세의 실제 좌표에서 추가 수정해야 한다.

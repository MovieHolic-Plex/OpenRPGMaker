# 심연구목거미 — 현재 독립 지적의 직접 픽셀 교정

## 범위와 원본 보존

첨부한 현재 18자세 시트와 64px 검객 참고를 실제 열어 관찰했다. 참고는 얼굴·실루엣·크기의 관찰에만 사용했고 픽셀·색을 추출하지 않았다. 이 작업의 모든 파일 쓰기는 이 후보의 `source/` 안에서 이루어졌다.

현재 정본은 기존 16색 `palette.json`, 기본 아홉 `poses/*.pxgrid`, 추가 아홉 `actions/*.pxgrid`다. 각 격자는 128행 × 128 ASCII 글자이며 `.`은 투명하다. 회은 복부 갑판의 넓은 좌상단 광원, 검자주 갑각, 실제 아홉 눈, 여덟 다리와 두 송곳니를 유지했다.

이번 교정 직전의 18개 전체 격자·팔레트·저작 코드·기록은 `before-review-correction/`에 보존했다. 그 원본을 그대로 해독한 PNG/8GIF도 그 폴더의 `preview/`에 있다. 더 이른 초안은 기존 `original-before-repair/`에 남아 있다. 보존본은 선택 또는 승인 기록이 아니다.

## 자세별 직접 고른 군집

좌표는 좌상단 원점, 0부터 세는 native 픽셀이다. `review_correction.py`에는 각 자세의 좌표와 리터럴 ASCII 색 문자열을 남겼다. 지운 픽셀도 `.`으로 명시했다. 다른 자세로 좌표를 자동 적용하거나 전체 프레임을 이동·회전·보간하지 않았다. 도형·음영 합성, 자동 구멍 채우기, 이미지 생성도 사용하지 않았다.

| 자세 | 실제 변경 범위 | 직접 수정한 내용 |
|---|---|---|
| attack | x=65–113, y=57–119 | 흉부에서 이어지는 검자주 목을 앞으로 넓히고, 얼굴의 은색 덮개를 우향 경사로 다시 찍었다. 아홉 눈을 이 새 얼굴 면 안에 각각 남겼다. 두 턱의 뿌리에서 오른쪽으로 뻗는 송곳니를 따로 저작하여 x=106–107, y=87 부근에서 만나게 했다. 준비 자세의 아래로 접힌 입과 다른 전방 물기다. 입 아래 앞다리의 가려진 위마디와 명암 경계도 해당 행에서 다시 드러냈다. |
| attack 발끝 | x=100–117, y=110–119 안의 개별 군집 | 넓고 평평한 자주색 쐐기를 지우고 밝은 아래마디에서 가는 발목·굽은 끝으로 좁혔다. 기존 착지 높이 y=119를 유지했고 다른 실제 지지발은 y=124에 남겼다. 확대에서 발견한 옛 쐐기의 남은 x=101,y=116 / x=100–101,y=117 / x=100–101,y=119도 직접 지웠다. |
| poison_a | x=45–96, y=59–118 | 목·흉부의 밝은 가장자리를 아래로 처뜨리고 얼굴 덮개·눈·턱을 새 낮은 윤곽으로 저작했다. 가까운 지지다리는 위마디가 안쪽으로 꺾이고 넓은 무릎에서 다시 아래로 펴져 같은 발로 하중을 받는다. 새 머리 아래의 턱/앞마디는 서로 어두운 경계로 나누고 입 사이 빈 공간을 유지했다. 기포는 보조 표식으로 남겼다. |
| poison_b | x=45–92, y=58–118 | 같은 아홉 눈과 갑각을 지닌 얼굴의 덮개·턱을 조금 더 낮게 다시 찍고 목 윗면과 무릎 폭을 별도 행에서 바꾸었다. 독 쌍의 작은 떨림은 얼굴 윤곽·턱·지지무릎이 함께 변한다. 기존 다른 높이/크기의 기포를 유지했다. |
| sleep_a | (88,107), (88,108) | 의도한 입–앞다리 사이 투명 공간에 있던 떨어진 검은 두 픽셀만 지웠다. 송곳니를 덧붙이거나 빈 공간을 채우지 않았다. |

독 자세를 처음 렌더링했을 때 새 얼굴 위에서 먼 다리의 사선이 끝나는 단절이 보였다. poison_a의 x=83–91,y=68–70과 poison_b의 x=83–93,y=68–71에 각자 고른 은색 위마디/어두운 경계를 붙여 머리 뒤로 연결했다. 자동 연결 검사로 채운 결과가 아니다. poison_a 기포의 x=96,y=74–76 외곽도 원래의 작은 자주 테두리로 직접 보존했다.

이번 변경 수는 attack 1,251픽셀, poison_a 1,312픽셀, poison_b 1,279픽셀, sleep_a 2픽셀이다. 팔레트와 나머지 14개 격자는 교정 직전 원본과 바이트가 같다. `sleep_b`, 기술 세 자세, 기절 쌍, 대기 셋과 나머지 기본 자세의 좋은 원안은 보존했다.

## 실제 그림 확인과 보조 코드

`render.py`는 저장한 격자의 팔레트 색을 그대로 PNG/GIF로 해독한다. 신체나 효과를 새로 그리지 않는다. 확대와 잘라보기는 진단 그림에만 쓰며 원본으로 되돌려 쓰지 않는다.

- `preview/correction-native.png`: 수정 관련 자세를 밝은·어두운·체커 배경의 실제 1배로 비교한 그림.
- `preview/correction-detail.png`: 입/발끝/독의 목과 턱을 최근접 6배로 확인한 그림.
- `preview/correction-comparison.png`: 이번 교정 직전/현재 네 자세의 최근접 3배 비교.
- `preview/native-part-1/2/3.png`, `preview/*-part-1/2/3.png`: 전체 18자세의 1배와 밝은·어두운·체커 확대판.
- `preview/all-gifs-decoded.png`: 실제 저장한 8GIF를 다시 읽어 배치한 프레임 확인판.

저장한 8GIF를 다시 읽어 각 프레임의 RGBA가 해당 PNG와 같은 것을 렌더러에서 확인했다. 그 GIF의 실제 해독 그림과 전체 자세 PNG를 열어 목–얼굴–턱, 아래마디–발목–발끝, 독 쌍의 지지무릎, 수면의 빈 공간을 관찰했다. 확대에서 발견한 다리 단절과 옛 발끝 잔여는 위에 기록한 실제 좌표로 교정했다.

`preview/correction-facts.json`은 실제 파일의 크기·변경 수·잉크 범위·SHA-256을 기록한다. 18개 모두 128×128이고 서로 다른 격자다. 기존 팔레트는 그대로 16색이다. 모든 바깥 1px은 투명하며 모든 자세의 최하단 잉크는 y=124다. 대기의 실제 지지발도 y=124에 남아 있다. 해시는 파일 사실이며 검수 binding이나 사용자 선택이 아니다.

재현 순서: `python source/review_correction.py`, `python source/render.py`, `python source/before-review-correction/render.py`, `python source/inspect_correction.py`. 현재 교정 코드는 이번 직전 보존본에서 시작하며, 이전 교정의 `repair.py`는 더 이른 초안을 위한 별도 기록이다.

## 남은 시각 한계

- 먼 다리의 가는 검자주 아래마디는 어두운 배경에서 대비가 낮다. 기존 좋은 실루엣을 유지한 부분이다.
- 공격에서 큰 복부 갑판의 이동은 작고 목·얼굴·송곳니·앞발의 변화가 크다. 두 곡선 송곳니가 만나는 접촉의 강도는 현재 1배 그림에서 확인했으나 실제 전투 상대와의 충돌/돌격 거리/타이밍은 관찰하지 않았다.
- 독 쌍은 처진 목과 새 머리, 굽힌 지지다리로 구별되지만 커다란 복부 갑판은 기존 높이에 남아 있다. 작은 떨림은 머리/턱/무릎 군집이고 전신의 큰 흔들림은 아니다.
- 수면의 접힌 마디는 머리 뒤에서 겹쳐 먼 다리의 전 경로를 1배에서 세기 어렵다. 두 수면 자세의 닫힌 눈과 기존 호흡 변화는 보존했다.

별도 검수자를 호출하거나 테스트/게이트를 실행하지 않았다. 이번 수정에 대한 독립 검수와 사용자 선택은 아직 기록하지 않았다. 새 원본의 독립 검수는 하네스가 맡는다.

# GIF 순서·정지 시간·입 발원점

기존 8동작의 순서와 hold를 유지했다. 각 GIF는 해당 128×128 전체 리터럴 격자를 그대로 사용한다. 자동 중간 프레임과 전신 이동은 없고 hold는 10ms 단위다.

|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 |
| hit | idle_a → hit → idle_a | 700 / 180 / 900 |

## 준비 → 전진 → 물기 → 회수

windup의 앞마디와 송곳니는 아래로 접힌다. move는 뒤 엉덩이에서 이어지는 위마디/무릎과 뒤쪽으로 심은 아래마디로 밀기를 표현한다. 이번 attack은 그 뒤 흉부와 이어진 목을 앞으로 넓히고 머리 덮개/아홉 눈의 면을 우향 경사로 저작했다. 두 송곳니는 각각 실제 턱 뿌리에서 오른쪽으로 뻗어 x=106–107,y=87 부근에서 접촉한다. 얼굴 바로 아래에만 말린 준비 입과 다른 윤곽이다. 앞발 끝은 은색 아래마디에서 가는 관절과 끝으로 좁아지고 y=119에 놓인다. 별도의 가까운 지지발은 y=124에서 하중을 받는다. recover는 기존 얼굴/턱/앞마디 회수 자세를 유지한다.

120ms의 접촉 hold는 기존 값이다. 실제 런타임에서의 대시 거리, 상대 접촉 또는 충돌 판정은 이 원본 GIF로 검증한 것이 아니다.

## 구목독의 입 발원점

이 종에는 손이나 무기가 없다. 얼굴/목에 연결된 입과 두 송곳니 사이에서 효과가 시작한다. 기술 세 격자는 이번 교정 전 원본을 그대로 유지했다.

- skill_a: x=75–80,y=77–81의 자주 핵과 작은 밝은 중심을 두 송곳니 사이에서 모은다.
- skill_b: 입 안쪽 x=76–79,y=80–83에서 연속된 실을 통해 두 독 거미줄 갈래를 펼친다. 상단은 오른쪽 위 x=117,y=40 부근, 하단은 오른쪽 아래 x=118,y=111 부근이다. 하단의 가로실과 의도한 빈 공간을 유지한다.
- skill_c: 얼굴에 연결된 짧은 두 송곳니를 안으로 모으며 x=77–80,y=85–87 부근의 좁아진 입틈을 유지한다. 세 잔여 독방울은 x=96–102,y=88–93 / x=106–112,y=95–100 / x=116–120,y=87–91 부근이다. 분리된 방울은 의도한 회수 효과다.

## 독·기절·수면

poison_a는 낮아진 얼굴·이완된 턱·길게 처진 연결 목과 안쪽으로 굽힌 지지무릎을 사용한다. poison_b는 얼굴 덮개/턱을 조금 더 내려 찍고 목 면과 무릎 폭을 별도 행으로 바꾸어 작은 떨림을 남긴다. 아홉 흐린 붉은 눈과 실제 지지발은 유지한다. 서로 다른 높이와 크기의 기포는 보조 표식이다. 이는 windup에 기포만 더한 동일 자세가 아니다.

stun_a/b는 기존 처진 얼굴/송곳니와 다르게 놓인 작은 두 별을 유지한다. sleep_a/b는 기존 아홉 짧은 닫힌 눈꺼풀, 접힌 마디와 이완된 턱을 유지한다. sleep_a의 투명 입–다리 틈에서 (88,107),(88,108)의 떨어진 윤곽 두 픽셀만 제거했다. sleep_b는 기존 갑판 윗곡률, 낮은 머리/턱과 넓은 접힌 무릎의 호흡 변화를 그대로 남겼다. 수면의 실제 지지 윤곽은 y=124에 있으며 더 낮게 무너진 dead와 구별된다.

`preview/timing.json`은 실제 GIF 저장 순서/hold다. `preview/*-decoded.png`와 `preview/all-gifs-decoded.png`는 저장된 GIF에서 다시 읽은 그림이다. 새 독립 검수나 사용자 승인 기록은 아니다.

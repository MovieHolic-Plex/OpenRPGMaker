# 심연구목거미 — fifty-v1 저작 기록

## 범위와 원본

이 후보의 `source/` 안에서만 저작했다. 기존 pxgrid는 없었으며, 참고 `human-size.png`를 실제 열어 얼굴 크기, 좌상단 명암, 작은 군집의 가독성을 관찰했다. 참고의 픽셀·색을 추출하지 않았다. 저장소, brief, ledger, 게임 저장소, 다른 후보는 수정하지 않았다.

정본 그림은 `palette.json`, `poses/*.pxgrid` 9개, `actions/*.pxgrid` 9개다. 모든 최종 격자는 128행 × 128글자의 리터럴 ASCII이며, 점은 투명이다. 팔레트는 16색이다. `author.py`는 직접 선택한 행·좌표 문자열을 보존하는 저작 보조 기록이다. 동일 개체의 변하지 않는 배/갑판을 유지하며 각 자세에서 달라지는 얼굴·턱·관절·효과를 명시한 native 행으로 교체했다. 전체 프레임 이동, 회전, 보간, 도형 마스크, 수식 명암, 구멍 채우기를 사용하지 않았다. `wipe`는 지정한 교체 영역을 비우는 보조 동작이며, 잉크는 뒤따르는 리터럴 행에만 있다.

## 형태와 재질

- 대기 배: 대략 x=24–70, y=25–79. 큰 회은 갑판의 넓은 밝은 면을 왼쪽 위에 놓고, 오른쪽 아래의 강철 회색과 검자주 배로 부피를 나눴다. 세로 겹침 경계는 판금의 가장자리다.
- 얼굴: 대기 x=61–90, y=53–80. 세 줄에 세 개씩 **아홉 개**의 붉은 작은 눈을 배치했다. 흰자 대신 작은 붉은 군집과 제한된 따뜻한 반사를 사용했다.
- 다리: 양쪽 네 경로. 넓은 근위 마디 → 밝은 무릎 갑판 → 가는 아래 마디 → 짧은 굽은 끝의 순서다. 먼 다리는 앞 갑각과 가까운 다리에 부분적으로 가려진다.
- 송곳니: 두 별도 뿌리와 두 오른쪽으로 굽은 끝을 그렸다. 관절 뒤의 다리와 턱 앞의 송곳니를 다른 겹침 경계로 나눴다.

## 자세별 직접 변경

- `idle_b/c`: 갑판 위 윤곽/밝은 면과 서로 다른 발목·턱 끝 군집으로 작은 긴장 변화를 만들었다. 눈 군집을 건드리던 초기 볼 수정은 제거해 아홉 눈을 보존했다.
- `windup`: 얼굴을 낮추고 같은 가까운 앞다리를 안으로 접었다. 뒤 지지발을 넓게 벌리고, 두 송곳니를 수직에 가까운 준비 각도로 좁혔다.
- `move`: 목/얼굴의 전진 경계, 뻗는 앞다리의 위마디·무릎, 뒤발의 지지 배열을 별도로 찍었다.
- `attack`: 머리와 연결된 송곳니를 전방으로 벌리고, 앞다리 마디를 펴며 끝을 압축했다.
- `recover`: 타격한 앞다리를 다시 당기고 턱을 반쯤 회수했다.
- `hit`: 기울어진 얼굴 테두리, 눌린 눈, 무릎 판의 꺾임을 따로 저작했다.
- `dead`: 낮게 바닥으로 내려온 배, 접힌 여덟 다리, 흐린 아홉 눈꺼풀과 이완된 턱을 새 행으로 그렸다. 서 있는 프레임을 돌리거나 이동하지 않았다.
- `skill_a/b/c`: 실제 송곳니 사이 핵 → 입에서 이어지는 서로 다른 두 독 거미줄 갈래 → 닫히는 턱과 세 독방울. 하단 갈래에는 별도의 가로실/사선실과 의도한 빈 공간을 남겼다.
- `poison_a/b`: 앓는 낮은 머리, 턱 가까이 접은 앞다리, 다른 높이/크기의 독 기포. 본체 색조 변환을 하지 않았다.
- `stun_a/b`: 기운 얼굴과 늘어진 송곳니, 다른 실제 위치의 두 별 군집. 잠든 눈과 달리 어두운 붉은 눈이 일부 남는다.
- `sleep_a/b`: 둥근 갑판과 여덟 접힌 다리를 유지하는 낮은 안정 자세. 붉은 눈을 없애고 짧은 회색 눈꺼풀을 세 줄로 찍었다. 두 번째 자세는 배 윗윤곽이 팽창하고 턱/목과 가까운 다리의 겹침이 압축된다.

## 실제 그림을 보고 고친 군집

1. 최초 대기의 송곳니가 U자로 붙어 보였다. x=65–96, y=77–93의 턱/송곳니를 별도 굽은 두 끝으로 다시 찍었다.
2. 투명한 앞 레이어가 뒤 다리 마디까지 지우고 있었다. 리터럴 군집을 겹칠 때 투명 글자는 뒤 해부를 지우지 않도록 보조 기록의 겹침 처리를 고쳤다. 의도적으로 지울 위치는 별도 점 행으로 남겼다.
3. 대기 턱 아래의 네 번째 가까운 다리 뿌리: x=64–73, y=83–94에 실제 중간색 갑각 면을 저작했다.
4. 준비/회수의 옛 발끝 잔여 x=115, y=113–116은 점으로 제거했다. 준비의 지지 발목은 x=72–80, y=116–124에 별도 행을 찍었다.
5. 쓰러짐의 배와 얼굴 사이에는 x=57–73, y=98–114의 검자주 목 부피를 추가했다. 분리되던 접힌 위마디는 x=43–56, y=109–116에서 직접 이어 그렸다.
6. 수면의 배/목/얼굴 간 간격과 두 번째 가까운 다리의 뿌리를 실제 각 자세의 행에서 수정했다. `sleep_a`의 목은 x=52–72, y=80–108, `sleep_b`는 x=53–73, y=81–108. 두 번째 호흡의 아래 위마디는 x=81–97, y=111–118에서 새로 찍었다.
7. 시전의 핵과 큰 효과 사이에는 x=77–92, y=81–84의 자주/밝은 실을 찍어 **입에서 시작하는 색 경로**를 보였다. 기존 송곳니에 닿기만 하는 연결에 의존하지 않는다.

## 확인한 산출물

`render.py`는 기존 격자를 해독해 PNG와 고정 팔레트 GIF를 만든다. 새 그림/중간 프레임을 합성하지 않는다. 밝은·어두운·체커 배경의 1배 및 최근접 3배 확인판을 실제 열었다. 특히 수면 1배와 공격/스킬의 GIF 재해독 연속 그림을 열어 턱, 눈꺼풀, 마디 연결과 프레임 사이 변화를 확인했다. 나머지 여섯 GIF도 `remaining-gifs-decoded.png`의 재해독 연속 그림으로 실제 열어 확인했다. GIF를 다시 읽은 RGBA는 각 대응 원본 PNG와 동일하다.

모든 자세의 최하단 잉크는 실제 신체/다리 y=124다. 대기 `idle_a`의 실제 발도 y=124에 닿는다. 바깥 한 픽셀은 투명하며, 기술 갈래의 가장 오른쪽 잉크는 x=126이다. 이런 파일 계약 확인은 독립 시각 검수나 사용자 선택을 뜻하지 않는다. 테스트/게이트와 별도 검수자를 실행하지 않았다.

## 남은 시각 문제 / 검토할 한계

- 먼 위쪽 두 다리의 긴 사선은 가까운 위마디보다 가늘다. 1배에서 원근에 따른 가는 마디로 보이지만, 큰 보스에 필요한 육중함은 가까운 마디/갑판에 더 집중돼 있다.
- 서 있는 공격 시퀀스에서는 배의 큰 갑판이 안정돼 있고 머리·턱·앞다리의 변화가 주동작이다. 전신의 돌격 거리는 게임 런타임에서 따로 처리할 부분이며, 이 GIF는 자세의 순서만 보여 준다.
- 수면/쓰러짐의 접힌 판금 다리는 살아 있는 얇은 거미다리보다 장갑을 입은 절지류 느낌이 강하다. 1배에서는 서로 겹친 먼 다리의 전체 경로를 한눈에 세기 어려운 부분이 있다.

하네스의 새 독립 검수와 사용자 판단이 필요하다. 승인, Allow, 합격, 검수 모델 또는 검수 binding을 이 기록에서 만들지 않았다. `preview/source-hashes.json`은 실제 파일의 SHA-256만 기록한다.

# GIF 시간표와 발원점

모든 GIF는 128×128 native 격자를 그대로 사용한다. 프레임 사이 이동·회전·보간을 넣지 않는다. 확대는 확인용 CSS/최근접 PNG뿐이다.

| GIF | 순서 | 각 hold (ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c → idle_b | 240 / 240 / 240 / 240 |
| attack | idle_a → windup → move → attack → recover → idle_a | 600 / 200 / 100 / 120 / 220 / 900 |
| hit | idle_a → hit → idle_a | 700 / 180 / 900 |
| dead | idle_a → hit → dead | 700 / 150 / 1700 |
| skill | idle_a → skill_a → skill_b → skill_c → idle_a | 700 / 260 / 160 / 240 / 900 |
| poison | poison_a → poison_b | 420 / 420 |
| stun | stun_a → stun_b | 300 / 300 |
| sleep | sleep_a → sleep_b | 650 / 650 |

## 구목독 발원점

- **skill_a 모으기:** 입/송곳니 사이 x=75–80, y=77–81에 자주 핵과 밝은 작은 중심. 얼굴이 올라가며 두 송곳니 뿌리는 턱에 붙어 있다.
- **skill_b 시전:** 실제 입 안쪽 x=76–79, y=80–83에서 시작해 x=77–92, y=81–84의 연속 실로 큰 두 갈래에 연결한다. 상단 갈래는 오른쪽 위 x=117, y=40 부근으로 길게, 하단 갈래는 오른쪽 아래 x=118, y=111 부근으로 넓게 갈라진다. 가로실과 작은 빈 칸은 거미줄 구조다.
- **skill_c 회수:** 얼굴/턱을 회수하며 두 송곳니를 닫는 각도로 좁힌다. 잔여 독방울 세 개는 각각 x=96–102, y=88–93 / x=106–112, y=95–100 / x=116–120, y=87–91. 떨어진 방울은 의도한 효과이며 신체가 아니다.

## 무게와 상태

준비에서 뒤 지지발을 벌리고 앞다리를 접는다. 이동/접촉에서는 같은 가까운 앞다리가 펴지고 턱이 앞쪽으로 나온다. 회수는 그 다리를 안으로 당긴다. 피격은 별도의 비스듬한 얼굴이다.

쓰러짐은 저하된 배/목/얼굴과 이완된 다리이며, 수면은 접힌 다리로 몸을 받치고 짧은 닫힌 눈꺼풀을 유지한다. 수면 두 번째 프레임은 배 윗윤곽 팽창, 낮아진 턱/목, 압축된 앞마디를 새 군집으로 저작했다. 독 기포와 기절 별은 별도로 놓인 효과이고, 어떤 GIF에도 글자나 상태 텍스트를 그리지 않았다.

`preview/*-decoded.png`는 **저장된 실제 GIF**의 프레임을 다시 읽은 1배 연속 확인판이다. `preview/timing.json`에 동일 순서/hold를 저장했다. GIF 재생은 전투 런타임 검증이나 사용자 승인을 뜻하지 않는다.

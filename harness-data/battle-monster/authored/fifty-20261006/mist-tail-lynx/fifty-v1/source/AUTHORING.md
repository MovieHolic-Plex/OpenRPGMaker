# 안개삵 — 지적 좌표의 국소 픽셀 교정

## 범위와 원본

이 후보의 `source/` 안에서 작업했다. 정본 그림은 `palette.json`, `poses/` 기본 9자세, `actions/` 추가 9자세의 전체 64×64 ASCII 행이다. 모든 행은 직접 고른 팔레트 인덱스다. 기존 18색을 보존했다.

첨부 현재 시트와 검객 참고 이미지를 실제 열어 몸 크기, 얼굴, 관절 연결을 관찰했다. 참고 픽셀 추출·트레이싱·재배포는 하지 않았다. 회갈색 짧은 털, 검은 귀 술, 황금 눈, 적은 반점 군집, 짧은 안개빛 꼬리, 왼쪽 위의 큰 빛 면을 유지했다.

이번에는 지적된 9자세의 총 287픽셀을 수정했다. idle_a/b/c, move, recover, hit, dead, sleep_a/b의 9자세와 팔레트는 수정 전 파일 해시와 같다. 다른 후보, 저장소 코드, 게임 저장소, brief, ledger, 검수 결과는 변경하지 않았다.

## 직접 선택한 좌표

좌표는 0부터 센다. 아래 범위와 수는 보존한 수정 전 격자와 최종 격자를 비교한 실제 값이다. 모든 변경 픽셀의 이전/현재 글자는 `reviewed-clusters-diagnostics.json`에 있다.

| 자세 | 실제 변경 x / y | 변경 픽셀 | 교정 |
|---|---|---:|---|
| windup | 30..31 / 53..60 | 10 | 중복 먼 뒷다리 외곽 기둥과 바닥 돌기 삭제 |
| attack | 56..59 / 47..52 | 9 | 넓은 흰 발끝을 짧은 세 발톱과 어두운 틈으로 분리 |
| skill_a | 31..37 / 34..36 | 10 | (31,36) 몸색으로 메움, 어깨 윗윤곽 연결 |
| skill_b | 49 / 40 | 1 | 파문 사이 고립된 어두운 픽셀 삭제 |
| skill_c | 31..38 / 34..38 | 23 | 깊은 어깨 절개를 얕고 연속된 목 연결로 변경 |
| poison_a | 31..37 / 34..38 | 23 | 해당 머리 높이에 맞게 등/목 연결 재저작 |
| poison_b | 31..37 / 34..37 | 16 | 별도 머리 위치를 유지하며 어깨 연결 재저작 |
| stun_a | 30..52 / 35..60 | 101 | 어깨 연결, 뒤로 굽은 팔꿈치와 접지 앞발 |
| stun_b | 30..52 / 35..60 | 94 | 어깨 연결, 같은 위치를 지지하는 앞발 |

### 준비 자세의 먼 뒷다리

windup에서 x=31, y=53..58의 여분 O 기둥과 x=30..31, y=59..60의 끝 돌기를 투명으로 바꿨다. x=26..29의 채워진 기존 먼 뒷다리와 y=59의 한 발을 남겼다. 가까운 뒷다리와의 의도한 간격은 그대로다. 다리 전체나 몸을 옮기지 않았다.

### 어깨와 목

skill_a의 (31,36)을 B, RGB (137,123,107)로 직접 선택했다. (33,35)은 O로 윗선에 연결하고 x=34..37, y=34에 명시 O 행을 두어 윤곽이 목으로 얕게 올라간다.

skill_c는 x=33..37, y=34의 O 윗선 아래에 B/L의 넓은 털 면을 놓았다. y=35의 x=33..37, y=36의 x=31..36, y=37의 x=32..34, (32,38)의 과도한 틈을 직접 선택한 행으로 교정했다. 기존 목 왼쪽 선 중 몸 안으로 들어온 픽셀도 몸색으로 바꾸었다. poison_a/b와 stun_a/b는 각자의 머리 높이와 기울기를 유지하며 대응하는 어깨 행을 따로 선택했다. 눈, 주둥이, 귀 술, 독 방울과 별은 바꾸지 않았다. 자동 구멍 채움이나 윤곽 추론은 하지 않았다.

### 공격 발끝

attack의 연결된 갈색 손목과 어깨는 유지했다. 위 발톱은 x=59..60, y=47..48, 가운데 발톱은 x=58..59, y=50, 아래 발톱은 x=57, y=52의 W로 끝난다. x=58..59, y=49와 x=56..57, y=51에 어두운 갈라짐을 두고, x=58, y=51..52를 투명으로 남겨 세 끝을 나눴다. 발톱 뿌리의 C와 갈색 B 면을 직접 고른 행으로 이어 좁아지는 손목을 보존했다. 기존 발끝의 바깥 범위를 넓히지 않았다.

### 기절의 체중 지지

stun_a/b의 가까운 앞다리는 x=36..43, y=52..54에서 뒤로 접힌 팔꿈치로 이어지고, x=39..46, y=56..58의 발목을 지나 x=40..46, y=59..60의 발로 내려온다. 두 프레임 모두 y=60의 행은 x=40에서 시작하는 `OOWOOWO`다. 뒷발과 함께 지면을 지지한다.

먼 앞발은 x=48..51, y=58의 작은 별도 발로 남았다. x=47, y=57..60의 투명 간격으로 지지발과 분리했다. 어깨와 머리의 기존 좌우 흔들림, 닫힌 눈, 다르게 놓인 별은 유지했다. 떠 있던 양쪽 발을 하나의 긴 발톱 막대로 이어 붙이지 않았다.

## 보존 자료와 출력

- `revisions/reviewed-clusters-before/`: 수정한 9격자, 이전 AUTHORING/TIMING, 팔레트 사본과 전체 18격자/팔레트의 수정 전 실측 해시. 앞선 원본 및 저작 보조 코드도 그대로 보존했다.
- `repair_reviewed_clusters.py`: 이번 교정의 직접 고른 `(y, x, ASCII)` 행 문자열. 몸체 생성·회전·전체 프레임 이동·보간·명암 합성은 없다.
- `author_corrections.txt`: 명시 좌표의 누적 기록. `author_clusters.txt`와 함께 전체 리터럴 원본을 재구성할 수 있다.
- `preview_reviewed_clusters.py`: 원본/현재 격자를 읽어 1배/최근접 3배의 전후 비교판을 출력하고 실제 차이/해시만 계산한다. 변경하지 않은 9자세와 팔레트의 보존도 확인한다.
- `render.py`, `inspect_exports.py`: 실제 격자 PNG/GIF 출력과 저장된 GIF의 픽셀/알파/시간 재읽기. 진단 확대와 라벨은 원본 그림에 포함되지 않는다.
- `preview/png/`: 원본 크기 PNG 18장. `preview/poses-sheet.png`, `actions-sheet.png`, `native-sheet.png`: 전체 격자 시트.
- `preview/`: 대기·공격·피격·쓰러짐·기술·독·기절·수면 GIF 8개. `preview/index.html`에서 1배/4배로 볼 수 있다.

## 실제 그림 관찰과 파일 진단

`preview/reviewed-clusters-light.png`, `-dark.png`, `-checker.png`를 실제 원본 해상도로 열어 native 1배와 최근접 3배의 전후를 비교했다. 어깨 내부의 틈과 깊은 홈, windup의 여분 다리 윤곽, skill_b의 고립된 어두운 점이 사라졌다. 공격 발끝의 짧은 세 갈래와 기절 지지발을 확인했다. 의도한 다리 사이 공간과 기술 파문 사이 간격은 남아 있다.

최종 전체 체커 시트와 저장된 GIF 8개를 해독한 `preview/gif-strips/`의 확인판을 모두 실제 열었다. 공격의 낮춤→전진→접촉→회수는 서로 다른 자세이고, 기절 두 프레임의 가까운 앞발 접지는 동일하다. 수면은 쓰러짐과 다른 웅크림/닫힌 눈/작은 호흡 변화로 유지된다. 기술은 앞발 준비광→연결된 세 파문→발 내림/두 잔안개다.

자체 파일 진단은 18개 격자의 64행×64열, 서로 다른 원본, 기존 18색, 투명 1px 테두리, 최하단 y=60과 idle_a의 발 접지를 확인했다. PNG의 RGBA와 저장된 GIF의 보이는 색/알파는 격자와 같고 GIF의 프레임 순서/유지 시간도 시간표와 일치한다. 근거는 `preview/export-diagnostics.json`이다. 이는 파일 진단과 자체 관찰이며 독립 검수 판정이 아니다.

## 남은 시각적 문제와 확인 한계

- 어두운 배경에서 귀 술과 먼 다리의 어두운 윤곽은 대비가 약하다.
- 밝은 배경에서 무영조의 은빛 효과는 대비가 낮다. 발톱 뿌리 가까이 세 갈래가 좁게 모인다.
- 공격의 세 발톱은 작아 1배에서 짧은 두 밝은 틈과 하단 끝으로 읽힌다. 확대에서보다 분리는 약하다.
- 기절은 한 앞발과 뒷발이 지지하고 먼 앞발은 들려 있다. 두 앞발 모두 접지하는 자세는 아니다.
- 기술은 3개 핵심 자세여서 중간 궤적 없이 단계가 전환된다. GIF 해독 프레임과 시간은 확인했지만 실시간 재생의 체감 박자, 실제 게임 접촉/피해 시점, 런타임 통합은 확인하지 않았다.

별도 검수자는 호출하지 않았다. 모델 실행 증빙·독립 검수 판정·사용자 승인·50종 일괄 통과를 만들거나 선언하지 않았다. 저장소 테스트/게이트는 실행하지 않았다. 하네스가 현재 원본과 출력 그림을 대상으로 독립 재검수를 맡는다.

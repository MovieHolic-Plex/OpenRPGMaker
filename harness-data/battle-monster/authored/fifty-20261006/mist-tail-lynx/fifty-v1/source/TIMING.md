# 안개삵 — 8동작 시간표

원본 64×64, 접지 기준 y=60, 1px 투명 바깥 테두리. 시간은 ms다. 원본 프레임을 보간 없이 표시한다. GIF는 기존 18색 팔레트, 투명 인덱스 0, disposal=2, loop=0을 사용한다.

## 순서와 유지 시간

| GIF | 격자 순서와 유지 시간 | 읽히는 변화 |
|---|---|---|
| idle.gif | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 | 낮은 앞몸, 발 고정, 등/어깨 호흡, 꼬리와 짧은 눈 감음 |
| attack.gif | idle_a 240 → windup 180 → move 100 → attack 140 → recover 180 → idle_a 260 | 어깨와 앞발 낮춤 → 뒷발 밀기/전진 → 세 발톱 훑기 → 회수 |
| hit.gif | idle_a 300 → hit 220 → recover 180 → idle_a 300 | 어깨 반동과 앞발 벌림 → 낮은 지지 자세 복귀 |
| dead.gif | idle_a 320 → hit 180 → dead 1000 | 반동 뒤 바닥에 내려온 몸과 닫힌 눈 |
| skill.gif | idle_a 240 → skill_a 260 → skill_b 200 → skill_c 260 → idle_a 320 | 앞발 준비광 → 굽은 세 발톱 파문 → 발 내림과 두 잔안개 |

이번 국소 교정에서 시간은 바꾸지 않았다. 유지 시간은 GIF 노출 시간으로 설정하고 중간 자세를 합성하지 않는다. 쓰러짐 GIF의 대기 복귀는 후보 비교용 반복 구성이다.

## 무영조의 실제 앞발 앵커

좌표는 0부터 센다. 이 짐승은 무기를 들지 않으며 기술은 가까운 앞발에서 나온다. 입의 붉은 픽셀은 표정이다.

- **skill_a / 준비 260ms:** x=35..44, y=42..46의 어깨/앞다리에서 x=45..50, y=47..49의 앞발로 이어진다. x=50..53, y=47..50의 V/I/W 군집이 작은 준비광이다. 어깨 (31,36)의 틈을 B로 교정했으며 발/빛의 앵커는 유지했다.
- **skill_b / 접촉 200ms:** x=43..47, y=43..45의 발끝에서 x=44..48, y=43..46의 은빛 뿌리로 연결된다. 위 호 x=48..60, y=32..44, 가운데 호 x=48..62, y=39..45, 아래 호 x=49..60, y=46..51의 세 굽음이 벌어진다. 길이와 돌아오는 끝은 서로 다르다. (49,40)의 고립된 O만 제거했고 발과 파문의 연결은 유지했다.
- **skill_c / 회수 260ms:** 앞발을 y=55..60으로 내린다. 잔안개는 x=30..36, y=59..60과 x=55..59, y=56..58의 두 별도 군집이다. 머리 위치와 효과를 유지하며 x=31..38, y=34..38의 어깨/목을 연결했다.

일반 공격의 발톱 접촉은 위 끝 x=59..60, y=47..48, 가운데 끝 x=58..59, y=50, 아래 끝 x=57, y=52다. 이 좌표는 그림의 접촉 표현이며 게임 피해 판정을 지정하지 않는다.

## 지지발과 프레임 변화

windup의 x=31, y=53..58과 x=30..31, y=59..60에 있던 중복 먼 뒷다리 외곽을 제거했다. x=26..29의 실제 먼 뒷다리는 남아 있으며 준비→move의 뒷발 추진과 앞발 전진을 유지한다.

stun_a/b의 가까운 앞발은 모두 x=40..46, y=60의 `OOWOOWO`로 접지한다. x=36..43, y=52..54에서 뒤로 굽은 팔꿈치를 지나 내려오고, 먼 앞발 x=48..51, y=58은 들려 있다. x=47, y=57..60에는 두 발 사이의 의도한 간격이 있다. 머리/어깨의 흔들림과 별 배치는 서로 다르며 지지발은 사라지지 않는다.

poison_a/b는 각자의 머리/앞발/독 방울 배열을 보존하고 어깨 틈만 연결했다. sleep_a/b의 독립적인 작은 호흡과 닫힌 눈도 보존했다. 모든 18격자가 서로 다르다.

## 출력 확인의 범위

저장된 8개 GIF를 다시 해독해 보이는 픽셀/알파와 노출 시간이 원본 및 이 표와 일치하는지 확인했다. `preview/export-diagnostics.json`에 실제 파일 해시와 시간 기록이 있다. 각 GIF의 해독 확인판 `preview/gif-strips/`를 실제 열어 발/목/효과 연결과 프레임 간 변화를 비교했다. `preview/index.html`은 실제 GIF의 1배/최근접 4배 보기다.

실시간 연속 재생의 체감 박자와 런타임 전투 이동/접촉/피해 시점은 확인하지 않았다. 하네스의 독립 재검수와 사용자의 선택은 이 자체 진단으로 대신하지 않는다.

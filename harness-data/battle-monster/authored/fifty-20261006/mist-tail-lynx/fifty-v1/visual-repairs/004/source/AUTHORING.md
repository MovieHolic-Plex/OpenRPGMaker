# 안개삵 — 낮은 앞몸과 무영조 발톱 교정

## 범위와 원본

이번 작업은 이 후보의 `source/` 안에서만 수행했다. 현재 원본은 `palette.json`, `poses/`의 기본 9개, `actions/`의 기술·상태 9개 전체 64×64 ASCII 격자다. 기존 팔레트 18색과 다른 12자세의 격자는 수정 전 실제 해시와 같다. 다른 종·후보·게임 저장소·brief·ledger·검수 결과를 변경하지 않았다.

첨부 현재 시트와 64px 검객 참고를 실제 열어 얼굴/몸 크기와 연결을 관찰했다. 참고 픽셀이나 팔레트를 추출하지 않았다. 원본의 회갈색 털, 황금 눈, 귀 끝의 검은 술, 소수 반점, 짧은 안개빛 꼬리와 왼쪽 위 광원을 이어 갔다.

## 직접 선택한 변화

좌표는 0부터 센다. 다음 범위와 수는 수정 전 격자와 최종 격자의 실제 차이다.

| 자세 | 변경 범위 x / y | 변경 픽셀 | 변화 |
|---|---|---:|---|
| idle_a | 31..55 / 19..60 | 466 | 머리·목·어깨를 낮추고 가슴 아래 면을 내려 짧고 굽은 앞다리로 이어짐 |
| idle_b | 31..55 / 19..60 | 463 | 같은 해부 구조, 기존 등/꼬리 호흡과 별도 어깨 빛 면 유지 |
| idle_c | 31..55 / 19..60 | 466 | 같은 낮은 체형, 닫힌 눈과 기존 꼬리 변화 유지 |
| recover | 32..56 / 22..60 | 341 | 회수한 어깨/가슴을 낮은 대기 체형에 연결, 대기보다 조금 낮고 오른쪽인 얼굴 유지 |
| windup | 32..55 / 26..60 | 401 | 목 밑과 어깨 윗면을 함께 낮추고 앞다리 뿌리·팔꿈치를 압축 |
| skill_b | 48..62 / 28..56 | 160 | 높은 각진 파문을 짧고 돌아오는 세 은빛 발톱 호로 교체 |

### 대기와 회수의 해부

대기 귀 끝은 y=19에서 y=22로 낮아졌다. 황금 눈은 y=34, 볼/주둥이는 y=35..40에 배치했다. 머리 구역의 행을 직접 다시 선택했고, 목 밑·어깨·큰 털빛 면·가슴 그림자도 각각 새 행으로 연결했다. 전체 프레임 이동은 하지 않았다.

어깨 윗선은 x=32..35, y=36을 통해 등에서 이어진다. 밝은 목 아래가 y=43..47까지 내려오고, 가슴 아래 그림자는 y=49..52에서 두 앞다리로 갈라진다. 가까운 팔꿈치는 x=37..43, y=53..54로 뒤로 접히고 아래다리는 x=39..46, y=56..58로 앞으로 기운다. 먼 다리는 x=46..52의 사선 발목을 통해 x=49..54의 따로 넓어진 발로 끝난다. 가까운 앞발 x=41..47과 먼 앞발 x=49..54는 모두 y=60에 닿고 그 사이 x=48은 투명이다. 의도한 다리 사이 공간과 몸통 뒤 지지 구조는 보존했다.

recover는 자체 얼굴 배열을 유지하면서 귀 끝을 y=23에 두고, 어깨 빛 면을 대기와 조금 다르게 이어 회수→대기의 변화를 남겼다. idle_b는 배와 등 호흡뿐 아니라 어깨의 L 면도 독립적으로 다르다. idle_c의 눈꺼풀은 닫혀 있다.

### 준비 자세

windup의 귀 끝은 y=28, 눈은 y=38이다. 등에서 목으로 올라가던 이전 높은 어깨를 x=32..37, y=36으로 눌렀고, 목 아래 밝은 면과 앞다리 뿌리도 y=44..54로 낮췄다. 앞발은 몸 아래에서 접히며 y=60의 별도 두 발로 끝난다. x<32의 기존 뒷다리/발목/지지발 픽셀은 그대로다. 이어지는 move의 뒤로 펴지는 추진 다리, 앞으로 내딛는 앞발과 대비된다.

### 무영조

skill_b의 발끝 시작점 x=43..47, y=43..45와 그 왼쪽 본체는 변경하지 않았다. 새 효과는 그 뿌리 오른쪽에서 시작한다.

- 위 호: x=48..60, y=32..44. 끝이 x=56, y=32에서 시작해 바깥쪽으로 돌아 아래의 발끝으로 이어진다.
- 가운데 호: x=48..62, y=39..45. x=59, y=39의 안쪽 끝에서 x=62, y=41..42의 바깥 굽음으로 돌고, y=45의 낮은 면을 통해 뿌리에 이어진다.
- 아래 호: x=49..60, y=46..51. 아래로 벌어져 오른쪽을 돈 뒤 x=59, y=47의 작은 끝으로 돌아온다.

갈래 사이에는 투명 공간을 직접 남겼다. 위·가운데·아래의 길이와 굽음은 다르고, 같은 오라를 반복하지 않았다. skill_a의 작은 발끝 준비광과 skill_c의 내려온 발/분리된 두 잔안개는 기존 좋은 원본을 보존했다.

## 실제 그림을 보고 추가 교정한 곳

첫 출력에서 idle_a/b/c의 주둥이 위쪽 검은 경계가 아래 행보다 1칸 왼쪽이었다. x=32, y=37의 명시 문자열을 다시 선택하여 두 주둥이 경계를 맞췄다.

기술 프레임 비교에서 가운데 갈래가 거의 직선으로 보였다. skill_b의 x=48..62, y=38..45를 다시 선택하여 오른쪽 외곽 굽음과 안쪽으로 돌아오는 끝을 분명히 했다. 이 추가 교정도 좌표/ASCII 문자열이며 자동 윤곽 처리나 연결 검사에 의한 채움이 아니다.

## 보존한 저작/진단 자료

- `repair_low_stance_claws.py`: 첫 교정의 직접 고른 국소 행 문자열.
- `refine_low_stance_claws.py`: 실제 PNG를 연 뒤 고른 주둥이/가운데 호의 추가 교정.
- `author_corrections.txt`: 순서대로 적용한 명시 좌표와 문자열. `render.py --write-literals`의 원본 재출력에도 반영된다.
- `revisions/low-stance-claws-before/`: 교정 전 6개 격자, 이전 AUTHORING/TIMING 문서와 수정 전 전체 격자/팔레트의 실측 해시. 앞선 교정 기록도 기존 `revisions/`와 보조 코드에 보존했다.
- `low-stance-claws-diagnostics.json`: 최종 변경 픽셀의 좌표/이전/현재 색 인덱스와 원본 해시.
- `preview_low_stance_claws.py`: 원본과 수정본을 읽어 진단용 전후 비교판만 출력한다.
- `render.py`, `inspect_exports.py`: 격자 PNG/GIF 출력과 저장된 GIF의 픽셀/시간 재읽기. 본체·명암·효과 생성은 하지 않는다.

## 확인한 범위

`preview/low-stance-claws-light.png`, `-dark.png`, `-checker.png`의 native 1배와 최근접 3배를 실제 열어 전후 윤곽·관절·발 연결·투명을 비교했다. 최종 기술 수정 뒤 세 배경의 비교판을 다시 열었다. 전체 native 시트와 저장된 8개 GIF를 해독한 `preview/gif-strips/` 확인판도 실제 열었다. 목과 앞발에 새 내부 투명 홈은 보이지 않으며 다리 사이의 빈 공간은 남아 있다. 대기 쌍의 발은 고정되고 준비→전진→접촉→회수는 별도 본체 배열이다.

현 격자에서 PNG 18장, 기본/추가 3×3 시트, 전체 배경 확인판, GIF 8개를 다시 출력했다. 자체 파일 진단에서 18개 원본의 64행×64열, 서로 다른 격자, 기존 18색, 1px 투명 테두리, 모든 자세 최하단 y=60과 idle_a의 발 접지를 확인했다. PNG와 GIF의 보이는 RGBA/알파가 원본과 같고 GIF의 프레임 순서/유지 시간도 일치한다. 결과는 `preview/export-diagnostics.json`에 있다.

이 확인은 자체 그림 관찰과 파일 진단이다. 별도 검수자는 호출하지 않았다. 독립 검수 결과, 사용자 선택이나 승인, 일괄 통과 판정을 만들지 않았다. 저장소 테스트/게이트는 실행하지 않았다.

## 남은 시각적 문제와 확인 한계

- 아주 어두운 배경에서는 귀 술과 먼 다리의 어두운 윤곽이 약하다. 먼 발목의 기본색과 넓어진 발끝이 분리를 보조하지만 대비 자체에는 한계가 있다.
- 대기는 낮아졌지만 높은 귀와 경계하는 얼굴 때문에 완전히 이완한 고양이 자세보다 긴장한 인상이 남는다.
- 무영조는 준비·접촉·회수의 3개 핵심 자세다. 호의 진행을 여러 중간 프레임으로 표현하지 않아 단계 전환은 또렷하게 끊긴다.
- 기술 기운은 밝은 배경에서 대비가 낮고, 뿌리 가까이에서 세 갈래가 좁게 모인다.
- GIF를 해독한 프레임 배열과 유지 시간을 확인했다. 실시간 연속 재생의 체감 박자, 실제 전투 이동·접촉·피해 시점은 이 작업에서 확인하지 않았다.

하네스가 현재 원본/그림을 대상으로 새 독립 검수를 해야 한다. 이 문서는 사용자 선택을 대신하지 않는다.

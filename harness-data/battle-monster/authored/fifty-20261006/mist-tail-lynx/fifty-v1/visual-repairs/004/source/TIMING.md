# 안개삵 — 8동작 시간표

native 64×64, 발 기준선 y=60, 1px 투명 바깥 테두리. 아래 시간은 ms다. 프레임은 원본 그대로 표시하고 보간하지 않는다. GIF는 기존 18색 팔레트와 투명 인덱스 0, disposal=2, loop=0을 사용한다.

## 순서와 유지 시간

| GIF | 격자 순서와 유지 시간 | 읽히는 변화 |
|---|---|---|
| idle.gif | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 | 낮은 앞몸, 발 고정, 등/어깨 호흡, 꼬리와 짧은 눈 감음 |
| attack.gif | idle_a 240 → windup 180 → move 100 → attack 140 → recover 180 → idle_a 260 | 목·어깨를 함께 낮춤 → 뒷발 밀기와 앞발 전진 → 발톱 훑기 → 어깨/발 회수 |

원본을 반복 복제해 시간을 늘리지 않고 GIF 노출 시간으로 유지한다. 쓰러짐 GIF가 반복될 때 대기로 돌아오는 것은 후보 비교용 구성이다.

## 무영조의 실제 발 앵커

0부터 세는 좌표다. 이 종은 도구를 들지 않는다. 가까운 앞발에서 기술이 나온다.

- **준비 skill_a:** 어깨 x=35..44, y=42..46에서 팔이 발 x=45..50, y=47..49로 이어진다. x=50..53, y=47..50의 V/I/W 군집은 작은 준비광이다.
- **접촉 skill_b:** 연결된 앞다리와 발끝 x=43..47, y=43..45는 이전 원본 그대로다. 이번 교정은 x≥48의 효과에만 적용했다. 위 호 x=48..60, y=32..44, 가운데 호 x=48..62, y=39..45, 아래 호 x=49..60, y=46..51이 이 발끝에서 서로 다른 굽음으로 벌어진다. 가운데 호의 바깥 끝은 x=62, y=41..42에서 돌아오며 아래 호는 x=59, y=47의 짧은 끝으로 돌아온다. 갈래 사이는 투명이고 뿌리는 발에 붙어 있다.
- **회수 skill_c:** 앞발을 y=55..60으로 내린다. 잔안개는 x=30..36, y=59..60과 x=55..59, y=56..58의 별도 두 군집이다.

입의 붉은 면은 표정이며 기술 발동 지점은 아니다. 일반 공격의 접촉점은 오른쪽으로 뻗은 앞발의 밝은 발톱 끝이다.

## 이번 교정과 프레임 비교

시간표는 변경하지 않았다. idle_a/b/c는 귀 끝 y=22, recover는 y=23로 낮은 목/가슴을 유지한다. 가까운 앞발 x=41..47과 먼 앞발 x=49..54는 y=60에 접지하고 x=48의 발 사이 공간은 투명이다. windup의 귀 끝 y=28과 눌린 어깨/앞다리 뿌리는 move의 펴지는 추진 다리와 대비된다. 몸 전체를 옮기거나 회전해 자세를 만들지 않았다.

저장된 GIF를 다시 읽어 각 프레임의 보이는 픽셀/알파와 실제 유지 시간을 원본과 비교했고, 8개의 해독 확인판을 실제 열어 연결과 순서를 보았다. 최종 기록은 `preview/export-diagnostics.json`, 그림은 `preview/gif-strips/`에 있다. 실시간 연속 재생의 체감 박자와 런타임 전투 피해/이동 시점은 이 파일로 확정하지 않는다.

`preview/index.html`은 8개 GIF의 native 1배와 최근접 확대 보기다. 현재 원본에 대한 독립 검수와 사용자 선택은 하네스 후속 단계에 남는다.

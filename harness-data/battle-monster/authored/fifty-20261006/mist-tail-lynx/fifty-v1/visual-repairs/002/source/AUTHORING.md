# 안개삵 — fifty-v1 직접 도트 원본

## 이번 중복 얼굴 교정

첨부 현재 시트와 64px 검객 참고를 먼저 실제 열고, 기존 전체 ASCII 격자와 대조했다. 이번 작업은 검수 지적 네 자세의 목/어깨만 수정했다. 아래 좌표는 0부터 세며 범위는 실제 변경 픽셀의 최소/최대다.

| 자세 | 실제 변경 범위 | 변경 수 | 교정 내용 |
|---|---|---|---|
| windup | x=27..39, y=34..41 | 55 | (29,36), (30,36), (35,36)의 눈과 뒤쪽 주둥이·검은 얼굴 경계를 B/L 털 면으로 교체. 실제 눈 (42,36), (43,36), (48,36) 보존. |
| move | x=28..41, y=34..41 | 46 | (35,35), (36,35)의 눈과 아래 크림색 주둥이·작은 윤곽을 어깨 털로 연결. 실제 눈 (44,35), (45,35), (50,35)과 내딛는 앞다리 보존. |
| attack | x=29..42, y=34..41 | 49 | (36,35), (37,35)의 눈, (34,38)의 옛 붉은 입, (34,39)의 옛 흰 이빨과 주변 얼굴 조각을 목/어깨 면으로 교체. 실제 눈 (45,35), (46,35), (51,35), 실제 입 (54,38), 훑는 앞발 보존. |
| recover | x=28..40, y=34..40 | 40 | (38,34), (39,34)의 눈과 겹친 볼/주둥이 조각을 연속된 목 털로 교체. 실제 눈 (43,34), (44,34), (49,34)과 회수하는 앞다리 보존. |

총 190픽셀의 색 인덱스를 직접 골랐다. 뒤 얼굴의 C/N/O 조각을 제거하고, 왼쪽 위 빛을 받는 L 면이 B 기본 털 면으로 내려가도록 행마다 다른 길이의 군집을 찍었다. 실제 얼굴의 밝은 볼은 남겨 목과 볼이 한 덩어리로 이어지게 했다. 실루엣/발 좌표와 투명 픽셀은 바꾸지 않았다. 자동 연결/구멍 채우기는 사용하지 않았다.

`repair_neck.py`에 명시한 좌표와 문자열을 보존했다. 같은 내용을 `author_corrections.txt` 뒤에 추가하여 리터럴 원본 재출력에도 반영한다. 이번 수정 전 네 격자는 `revisions/duplicate-face-before/poses/`에 보존했다. `before-repair-hashes.json`은 수정 전 원본/팔레트의 실제 해시이고, `repair-diagnostics.json`은 각 변경 픽셀의 이전/현재 인덱스와 보존한 파일 목록이다.

나머지 14자세와 18색 팔레트는 수정 전 해시와 같다. 특히 `actions/`의 기술/독/기절/수면 9개 전체 리터럴 격자를 그대로 보존했다.

### 이번 출력에서 실제 확인한 범위

현 격자에서 PNG 18장과 GIF 8개를 다시 출력했다. 밝은/어두운/체커 배경의 전체 확대판, 원본 1배 시트, 저장한 GIF를 다시 해독한 8개 동작의 모든 프레임 시트를 실제 열었다. 네 자세에서 뒤쪽 황금 눈과 주둥이 조각이 사라지고 한 얼굴의 볼→목→어깨가 이어지는 것을 확인했다. 다리 사이와 접힌 앞발 안쪽의 의도한 투명은 유지했다. 변경 구간에 새로운 투명 홈은 없다.

파일 진단에서 18개 격자의 64×64 크기, 서로 다른 원본, 1px 투명 테두리, 최하단 y=60과 idle_a 접지를 확인했다. 8개 GIF의 해독 프레임/유지 시간/보이는 RGBA가 원본과 일치한다. 이는 후보의 자체 관찰과 내보내기 진단이다. 실시간 재생의 체감 박자나 런타임 전투 접촉을 검증한 기록은 아니다. 독립 검수자 호출, 검수 결과 수정, 사용자 승인 기록, 저장소 테스트/게이트 실행은 하지 않았다.

### 남은 시각적 문제

- 대기/회수의 앞다리가 겹쳐 고리처럼 읽히는 실루엣은 남아 있다. 이번에는 지적된 중복 얼굴 영역만 고쳤다.
- 어깨의 넓은 빛 면은 움직임을 읽게 하지만 도약의 털 볼륨은 다소 단단하게 보인다.
- 수면 두 자세의 숨 변화는 작으며, 기술 세 핵심 자세 사이의 파문 진행도 계단처럼 끊긴다.
- 어두운 배경에서는 검은 윤곽과 먼 다리의 분리가 약하다. 실제 전투 크기/배경에서의 평가는 하네스 후속 검수에 남는다.

## 범위와 원본

이 후보의 `source` 안에 기본 9자세와 추가 9자세를 저작했다. 각 `.pxgrid`는 64×64 전체 ASCII 행이다. `palette.json`은 투명 `.`를 제외한 18색이다. 좌표는 왼쪽 위 `(0,0)` 기준이다.

- `poses/`: idle_a, idle_b, idle_c, windup, move, attack, recover, hit, dead.
- `actions/`: skill_a, skill_b, skill_c, poison_a, poison_b, stun_a, stun_b, sleep_a, sleep_b.
- `author_clusters.txt`: 직접 선택한 원래 행과 좌표 문자열.
- `author_corrections.txt`: 실제 그림을 연 뒤 직접 선택한 교정 행. 같은 자세의 후속 기록은 해당 좌표 문자열만 교체한다.
- `render.py`: 행 문자열을 기록하고 PNG·GIF·진단 확대판을 출력하는 보조 코드.
- `inspect_exports.py`: 출력 GIF를 다시 읽고 원본 색/알파/시간을 비교하며 해독한 프레임 확인판을 출력하는 보조 코드.

본체·명암·자세·효과를 만드는 도형, 수식, 자동 이동/회전/보간, 자동 구멍 채우기는 저작 코드에 없다. 확대는 관찰용 최근접 표시뿐이다. 완성 원본은 패치 목록이 아닌 `poses/`와 `actions/`의 전체 리터럴 행이다.

## 참고 관찰과 종의 외형

첨부 `human-size.png`를 실제 열어 얼굴의 작은 눈, 얼굴과 목의 연결, 원본 64px 화면에서 읽히는 크기와 밝은 면을 관찰했다. 참고 그림의 픽셀·색·형태를 추출하거나 복사하지 않았다.

안개삵은 오른쪽을 보는 사족 동물이다. 짧고 굵은 청회색 안개 꼬리, 검은 귀 끝 술, 작은 황금 눈, 크림색 볼과 목, 회갈색 짧은 털을 직접 찍었다. 등 왼쪽의 넓은 H/L 면에서 어깨의 B 면과 배/먼 다리의 M/S 면으로 내려간다. 반점은 등·엉덩이의 소수 M/S 군집에 한정했다. 대기 본체는 x=3..55, y=19..60을 사용한다. 네 다리는 몸 아래에서 분기한다.

## 자세별 직접 변화

- 대기: 발과 기준선을 유지하며 등·옆구리의 호흡 면을 바꾸고 꼬리 덩어리와 눈꺼풀을 교체했다. idle_c의 눈은 짧게 감긴다.
- 준비: 귀·머리와 어깨를 낮추고 앞다리 팔꿈치를 접었다. 뒷다리는 눌러 지지한다.
- 전진: 뒤 가까운 발을 왼쪽으로 뻗어 밀고, 반대 뒷발은 몸 아래로 접는다. 먼 앞발은 지지하고 가까운 앞발은 오른쪽으로 내딛는다.
- 접촉: 어깨에서 이어지는 가까운 앞다리를 가로로 펴고 발끝의 W 발톱을 노출했다. 입에 작은 붉은 면과 이빨을 추가했다.
- 회수: 앞다리를 몸 아래로 다시 접고 머리는 대기보다 조금 낮은 높이로 복귀한다.
- 피격: 눈꺼풀을 닫고 어깨를 뒤로 기울이며 한 앞발을 오른쪽으로 벌려 지지한다.
- 쓰러짐: 몸통과 다리를 y=44..60으로 내려 접고, 머리와 귀를 바닥 옆으로 낮췄다. 눈은 검은 짧은 닫힌 선이다.
- 무영조: 별도 준비 자세의 앞발에 작은 은빛 기를 모은다. 접촉에서는 그 앞발을 뻗어 길이와 굽음이 다른 세 발톱 파문을 낸다. 회수에서는 앞발을 내리고 바닥에 잔안개 두 덩어리를 둔다.
- 독: 턱의 붉은 면과 무거운 어깨, 접힌 가까운 앞발로 아픈 자세를 찍었다. 두 번째 자세는 발꿈치와 팔꿈치의 지지를 바꾸고 독 방울을 더 위로 흩었다.
- 기절: 눈과 턱을 처지게 하고 앞다리를 접어 몸무게를 받친다. 두 번째 자세는 머리와 어깨를 조금 더 기울이고 별의 위치와 가장자리를 교체했다.
- 수면: 머리가 바닥에 눕는 죽음과 구별되는 웅크린 자세다. 앞발을 몸 밑에 접고 눈을 닫았다. 등과 옆구리의 작은 호흡 면을 직접 바꿨다.

## 실제 그림을 본 뒤 고친 좌표

1. 첫 대기판의 목이 가늘고 볼 아래가 왼쪽으로 급히 꺾여 보였다. idle_a/b/c의 y=32..42, x=33..55 행을 직접 다시 찍어 볼→목→가슴을 넓게 연결했다. 앞어깨/다리 y=43..60도 다시 저작했다.
2. 대기판의 먼 뒷발이 빠져 있었다. y=52..59, x=24..30 부근에 어두운 다리와 발끝을 직접 추가하고 엉덩이 아래에서 이어지도록 했다.
3. 준비/전진/접촉/회수/피격의 얼굴 아래 행 위치 때문에 목 연결이 얇아 보였다. 각 프레임의 얼굴 아래와 어깨를 해당 자세의 좌표로 개별 교정했다.
4. 전진과 접촉에 남은 예전 앞다리 흔적을 y=52..60, x=23..35에서 직접 지웠다. 전진의 고립된 O 두 픽셀 `(34,56)`, `(34,57)`도 이 교정에 포함된다. 먼 뒷다리와 두 앞다리의 실제 지지는 보존했다.
5. 피격의 예전 발 윤곽 한 점 `(29,60)`을 지웠다.
6. poison_b의 독 방울이 귀 술에 붙어 잎처럼 보였다. 이전 방울 좌표를 직접 비우고 x=56..60, y=17..20에 분리된 방울 군집을 새로 찍었다.
7. skill_b의 초기 파문이 가는 직선으로 보였다. x=47..62, y=28..56의 실제 행을 직접 교체해 굽은 넓은 상단, 짧은 중단, 아래로 휘어 깨지는 하단을 만들었다. 발끝과 효과의 뿌리는 연결되어 있다.

교정은 모두 명시한 문자열 교체이며 연결 검사 결과로 픽셀을 자동 채우지 않았다. 다리 사이와 접은 앞다리의 내부 빈 공간은 의도한 투명이다. 독 방울·기절 별·잔안개의 분리도 의도했다.

## 확인한 결과

원본 1배 시트, 밝은/어두운/체커 배경 4배 최근접 시트를 실제 열었다. 8개 GIF도 재개방했고, 실제 GIF를 해독한 모든 프레임 확인판을 열어 목/어깨/발 연결, 투명 홈, 공격 순서와 프레임 사이의 위치 변화를 비교했다. 최종 형식·내보내기 진단은 `preview/export-diagnostics.json`에 있다.

- 전체 18개 원본이 서로 다르다.
- 모든 원본이 64행 × 64열이며 1px 바깥 테두리는 투명이다.
- 모든 자세의 최하단 잉크는 y=60이고 idle_a의 발도 정확히 그 선에 닿는다.
- PNG와 해독한 GIF의 보이는 색/알파가 각 원본과 일치한다. GIF는 고정된 원본 팔레트를 사용한다.
- 실제 그림 검토용 원본 PNG 18장, 3×3 기본/추가 시트, 전체 1배 시트, 배경 3종 확인판, GIF 8개와 해독 확인판을 `preview/`에 보존했다.

이는 후보의 자체 관찰 및 파일 진단 기록이다. 독립 검수와 사용자 선택은 하네스의 별도 단계다. 승인이나 검수 판정을 작성하지 않았다. 저장소 테스트/게이트는 실행하지 않았다.

## 남은 시각적 한계

- 무영조는 준비·접촉·회수 3장의 핵심 자세라 곡선의 진행이 연속적인 다중 프레임 효과보다 단단하게 끊겨 보인다.
- 대기의 귀가 높고 가슴이 넓어 1배에서는 낮은 야생 삵보다 긴장해서 서 있는 작은 삵의 인상이 강하다.
- 독/기절의 접힌 앞발과 먼 다리는 겹쳐 1배에서 발 네 개를 각각 읽기는 어렵다.
- 수면과 대기의 호흡 변화는 작다. 확대판에서 더 잘 보인다.

## 재출력

이 후보 폴더에서 `python source/render.py`로 현 원본 PNG/GIF를 다시 출력한다. `python source/render.py --write-literals`는 보존한 직접 좌표 문자열과 교정을 전체 원본 행으로 다시 기록한다. `python source/inspect_exports.py`는 GIF 재읽기와 출력 진단을 갱신한다. 모든 출력 경로는 이 `source` 안이다.

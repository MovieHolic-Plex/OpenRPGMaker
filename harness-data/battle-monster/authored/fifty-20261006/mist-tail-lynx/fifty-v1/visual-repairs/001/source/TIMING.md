# 안개삵 동작 시간표

원본은 native 64×64, 투명 테두리 1px, 발 기준선 y=60이다. 시간 단위는 ms이며 각 프레임은 보간 없이 원본 픽셀 그대로 표시한다. GIF는 투명 인덱스 0, disposal=2, 반복 0으로 저장했다. 반복되는 동일 자세는 노출 시간으로 유지한다.

| GIF | 원본 순서와 유지 시간 | 표현 |
|---|---|---|
| idle.gif | idle_a 240 → idle_b 240 → idle_c 240 → idle_b 240 | 지지발 고정, 옆구리 호흡, 꼬리, 짧은 눈 감음 |
| attack.gif | idle_a 240 → windup 180 → move 100 → attack 140 → recover 180 → idle_a 260 | 몸 낮춤 → 뒷발로 밀며 전진 → 앞발 발톱 접촉 → 어깨/발 회수 |

## 무영조의 앵커

좌표는 0부터 센다. 동물의 가까운 앞발이 발동 부위다.

- **skill_a:** 어깨 x=35..44, y=42..46에서 앞다리가 발 x=45..50, y=47..49로 이어진다. 발 끝 x=50..53, y=47..50에 V/I/W 은빛 기를 직접 찍었다. 작은 준비광이다.
- **skill_b:** 팔은 x=35..47, y=41..46에 이어지고 앞발 끝의 효과 뿌리는 x=46..51, y=43..46이다. 이 연결에서 상단 파문은 `(60,28)`까지 길게 올라 굽고, 중단은 `(61,37)` 쪽으로 짧게 벌어지며, 하단은 x=49..60, y=46..56에서 내려 굽어 끊긴다. 세 갈래는 길이/두께/끝 방향을 별도 행으로 저작했다.
- **skill_c:** 앞발을 y=55..60 지지 위치로 내린다. 잔안개는 x=30..36, y=59..60과 x=55..59, y=56..58의 서로 다른 두 군집이다. 작은 한 군집은 내려온 발 곁에 붙고, 오른쪽 군집은 분리되어 있다.

입은 기술 발동 앵커가 아니다. 공격 시 입의 붉은 면은 표정이고, 일반 공격 접촉점은 오른쪽으로 뻗은 앞발의 밝은 발톱 끝이다. 이 종은 손에 도구를 쥐지 않는다.

## 시간과 위치 확인

`preview/gif-strips/`는 실제 저장한 GIF를 다시 해독한 순서/유지 시간 확인판이다. 원본 PNG 시트를 대신 재사용한 결과가 아니다. 각 해독 프레임의 보이는 RGBA와 유지 시간을 원본과 비교한 결과는 `preview/export-diagnostics.json`에 기록했다.

`preview/index.html`에서 8개 GIF를 1배와 최근접 4배로 함께 볼 수 있다. 쓰러짐 GIF의 반복 시작은 비교용 대기 자세로 돌아온다. 실제 런타임 사망 연출의 상태 유지/피해 시점 연결은 이 후보의 범위 밖이다.

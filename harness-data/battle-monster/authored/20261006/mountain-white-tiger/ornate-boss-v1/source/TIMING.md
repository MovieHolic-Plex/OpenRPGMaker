# 산군 백호 — 제안 프레임 순서와 표시 시간

좌표는 native 128×128 원본의 좌상단 (0,0) 기준이다. 아래 시간은 그림 검토용 제안이며 게임의 판정/이동/피해 시점과 실제 동기화했다는 뜻이 아니다.

| 클립 | 순서 | 각 프레임 표시 시간(ms) |
|---|---|---|
| 대기 | idle_a → idle_b → idle_c → idle_b | 280 / 280 / 280 / 280 |
| 일반 공격 | idle_a → windup → move → attack → recover → idle_a | 280 / 220 / 120 / 140 / 200 / 280 |
| 피격 | idle_a → hit → recover → idle_a | 280 / 180 / 200 / 280 |
| 쓰러짐 | hit → dead | 180 / 1000, dead 유지 |
| 산군포효 | idle_a → skill_a → skill_b → skill_c → idle_a | 280 / 300 / 240 / 300 / 280 |
| 독 | poison_a → poison_b | 420 / 420 |
| 기절 | stun_a → stun_b | 340 / 340 |
| 수면 | sleep_a → sleep_b | 650 / 650 |

## 접촉과 연결점

- 일반 공격 준비: 낮춘 목/견갑 아래 두 앞발을 모으고 후지에 체중을 싣는다.
- `move`: 후지 보폭과 앞팔의 대각선 신장. 전체 프레임을 옮긴 그림이 아니다.
- `attack`: 입 접촉 중심 약 (116,80). 펼친 앞발의 세 발톱 끝 약 (124,107), (123,113), (122,116). 손목→발바닥→발가락→발톱이 연결되어 있다.
- `recover`: 손목을 굽히고 앞다리를 몸 쪽으로 당겨 후지와 다시 받친다.
- `skill_a`: 목고리의 옥 면 약 (88,68)과 입 약 (107,57)에서 청록 압축. 턱과 가슴을 들어 올린다.
- `skill_b`: 실제 벌어진 입의 방출점 약 (106,58). 위/아래의 두 충격면이 여기서 오른쪽으로 갈라진다. 가장 오른쪽 잉크 x=126, 원본 테두리 안이다. 턱·이빨과 몸은 충격파 뒤에도 읽히도록 남겼다.
- `skill_c`: 턱·발을 내리고 오른쪽의 세 잔류 파편이 분리된다. 잔류 중심 약 (120,34), (122,57), (120,86).
- 독/기절/수면은 각각 두 상태를 반복하는 제안이며 일반 공격 프레임을 클립 대신 사용하지 않는다.

`progress/`의 PNG와 시트는 최종 격자를 직접 디코딩한 확인 자료다. 독립 리뷰 및 하네스의 native 8배 GIF 렌더링은 후속 단계다.

# 원본 GIF 자세와 제안 유지 시간

128×128 원본 팔레트 GIF는 `progress/*-native.gif`에 있다. 투명 배경, 최근접 표시용 원본 크기이며 중간 자세를 합성하지 않는다. 시간은 검토용 제안이다. 실제 게임의 데미지·소리·피격 처리와 동기화되었다는 뜻이 아니다.

| GIF | 자세 순서 | 각 유지 시간(ms) |
|---|---|---|
| idle | idle_a → idle_b → idle_c | 300 / 300 / 300 |
| attack | windup → move → attack → recover → idle_a | 240 / 120 / 140 / 250 / 250 |
| hit | hit → recover → idle_a | 180 / 240 / 300 |
| dead | hit → dead | 160 / 1000 |
| skill | skill_a → skill_b → skill_c → idle_a | 340 / 160 / 360 / 300 |
| poison | poison_a → poison_b | 450 / 450 |
| stun | stun_a → stun_b | 350 / 350 |
| sleep | sleep_a → sleep_b | 700 / 700 |

## 무기와 접촉 좌표

좌표는 왼쪽 위 (0,0)에서 세는 원본 픽셀 좌표다.

- 대기: 화면 오른쪽 손은 대략 (102,81), 자루를 감싸는 엄지가 금속 앞에 놓인다.
- 준비: 양손은 대략 (34,60)과 (35,66). 화면 오른쪽 팔이 흉갑 앞을 가로질러 같은 자루를 잡는다. 철퇴 머리는 몸 뒤쪽 (16,38) 부근이다.
- 이동: 두 손이 대략 (98,49)와 (79,71)에서 자루를 지지하고 앞발을 내딛는다.
- 일반 공격: 양손은 대략 (85,85)와 (92,89). 청동 머리는 우하단 (107,103) 부근으로 떨어지고 바닥 쪽 접촉 면은 (108,112) 부근이다. `attack`이 제안 접촉 자세다.
- 회수: 무기를 허리 쪽으로 당기는 손은 대략 (99,89), 무기 머리는 (103,72) 부근이다.
- `skill_a`: 위쪽 철퇴 머리 (108,22)의 금속 홈에 압축을 표시한다. 원형 아우라를 사용하지 않았다. 양손은 이동보다 더 단단한 그립이고 두 발은 넓게 버틴다.
- `skill_b`: 번개 두 줄기와 비취 충격 전면의 발생점은 실제 철퇴 아래쪽 (109,111) 부근이다. 주 줄기는 오른쪽 위로 꺾이고, 두 번째는 왼쪽 위로 갈라진다. 굵은 줄기에 작은 가지가 붙는다. `skill_b`가 제안 기술 접촉 자세다.
- `skill_c`: 팔과 무기는 몸 쪽으로 회수된다. 떨어져 나간 금빛 잔전류는 대략 (120,51), (118,92)에 있고, 아래 청록 조각이 가라앉는다.
- 수면: 손에서 힘을 빼고 자루를 y≈111…114의 바닥 쪽에 놓았다. 엄지로 무기를 쥐는 대기 동작을 수면에 재사용하지 않았다.

`dead-native.gif`는 반복 검토용이다. 실제 런타임에서 사망을 반복하거나 대기로 복귀하도록 지정한 자료가 아니다.

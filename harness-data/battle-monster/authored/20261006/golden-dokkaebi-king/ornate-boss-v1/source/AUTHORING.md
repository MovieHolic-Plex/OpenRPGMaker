# 금갑 도깨비왕 — ornate-boss-v1

## 원본과 크기

- `palette.json`: 불투명 색 18개. `.`은 투명하며 팔레트에 없다.
- 전투 9장: `poses/idle_a`, `idle_b`, `idle_c`, `windup`, `move`, `attack`, `recover`, `hit`, `dead.pxgrid`.
- 기술·상태 9장: `actions/skill_a`, `skill_b`, `skill_c`, `poison_a`, `poison_b`, `stun_a`, `stun_b`, `sleep_a`, `sleep_b.pxgrid`.
- 모든 원본은 128×128의 완전한 ASCII 행이다. 확대된 작은 캐릭터가 아니다. 대기 원본의 잉크 범위는 x=10…120, y=13…124: 높이 112px, 철퇴·망토를 포함한 폭 111px. 중립 자세의 어깨갑 외곽은 대략 x=26…92이고, 위로 솟은 장식은 별도 돌출부다.
- 두 발의 실제 밑창이 `idle_a`의 y=124에 닿는다. 모든 프레임은 1px 투명 테두리를 보존하고 마지막 잉크는 y≤124다. 상태·기술 입자도 같은 제한을 따른다.

## 선택한 해부와 재료

오른쪽을 보는 비취 피부의 두 뿔 거구. 넓은 이마, 낮은 눈썹, 돌출된 코와 네모난 턱, 두 개의 흰 송곳니를 유지했다. 굵은 팔과 분리된 두 발, 앞으로 뻗는 허벅지와 접히는 무릎을 직접 골랐다. 원본 검객과 생물 참고는 윤곽·광원·크기의 시각 연구에만 사용했다.

피부는 B/C/D의 큰 근육 면, 갑주는 E/F/G/H의 청동 그림자와 금빛 넓은 면, 송곳니와 가장 밝은 금속은 I/Q, 망토는 J/L/M, 허리 가죽은 N/O로 나눴다. 광원은 왼쪽 위다. 수호 얼굴 모양 어깨 문양, 위로 말린 구름·불꽃 장식, 비취 흉갑 보석, 금속 단차와 붉은 술이 장식의 중심이다. 철퇴는 굵은 금속 머리와 명확한 자루가 있고, 엄지가 자루 앞을 덮는다.

## 직접 선택한 자세 변화

- 대기: 목·근육 면, 손가락, 망토 주름과 술의 짧은 픽셀 군집을 각각 변경했다.
- 공격: 양손을 뒤쪽 자루에 모으고 무릎을 굽힘 → 앞발 내딛기와 철퇴 들어 올리기 → 새로 쓴 머리·목·금갑의 전방 기울기와 우측 내려찍기 → 낮아진 철퇴를 당기는 회수.
- 피격: 찌그러진 눈과 처진 턱, 펼쳐진 손, 꺾인 무릎. 쓰러짐은 빈 캔버스에서 낮은 머리·옆으로 기운 흉갑·누운 무기·느슨한 무릎을 별도로 저작했다.
- 금강뇌쇄: 금속 홈 안에 번개를 압축하고 양손과 두 발을 고정한다. 접촉에서는 철퇴 하단에서 황백 두 줄기와 짧은 가지, 비취빛으로 꺾이고 말리는 충격 전면이 나온다. 회수에는 분리된 잔전류 두 조각이 남는다.
- 독: 낮춘 머리와 긴장한 눈꺼풀, 배를 움켜쥔 팔, 서로 다른 독 기포. 두 번째 상태는 팔꿈치·복부 손의 접힘도 다르다.
- 기절: 떨어진 어깨와 팔, 늘어진 턱, 굽은 다리, 위치와 가지가 다른 작은 금빛 별.
- 수면: 닫힌 눈, 느슨한 턱, 접힌 무릎, 내려놓은 무기. 두 장에 목·가슴·손의 호흡 차이를 선택했다.

## 관찰과 수정

`progress/idle.png`와 `idle-4x.png`를 먼저 열어 원본과 최근접 확대를 확인했다. 이후 두 펼침 시트의 실제 디코드를 확인했다. 독립 시각 검수에서 지적한 수면 목/발목 연결, 준비 자세의 손 바뀜, 그립의 원반처럼 보이는 손을 수정했다. 공격 머리·목과 상부 금갑을 새 행으로 기울였고, 쓰러짐의 무릎과 큰 어깨 장식을 보강했다.

`author.py`는 직접 쓴 문자 블록·선택한 좌표의 색 문자열을 완전한 행으로 저장한다. 몸체 도형 생성, 자동 명암, 전체 프레임 변형·보간, 참고 추적, 이미지 생성은 사용하지 않았다. `render.py`는 원본을 디코드하고 최근접 시트와 원본 크기 팔레트 GIF 8개를 만든다. `progress/geometry.json`에 실제 잉크 범위와 원본 해시를 남겼다.

## 남은 시각적 한계

갑주와 정강이의 면은 의도적으로 각지고 단순하다. 더 세밀한 세공이나 망토 자수는 넣지 않았다. 독·기절·수면의 두 상태 간 변화는 짧은 반복용이라 공격보다 작다. 원본 셀 안에 두 갈래 번개를 유지하기 때문에 접촉 전면은 좁은 오른쪽 공간에 모인다. 실제 게임에서의 화면 크기·피격 동기화는 확인하지 않았다. 사용자 판단을 기다리는 후보이며 승인된 자산이라는 주장은 하지 않는다.

독립 재검수는 수면의 목·발목 연결과 준비/접촉 자세의 양손 자루 연결을 확인했다. 마지막으로 쓰러짐의 허리와 비취 무릎 사이에 붉은 접힌 허벅지를 직접 추가했고, 검수자가 해당 투명 틈의 해소를 확인했다. 이는 구체적인 연결 결함에 대한 관찰이며 사용자 미술 승인이나 실제 플레이 검증을 뜻하지 않는다.

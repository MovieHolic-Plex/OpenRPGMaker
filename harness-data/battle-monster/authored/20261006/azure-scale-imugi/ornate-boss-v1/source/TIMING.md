# 청린 이무기 — 진단 애니메이션 시간표

아래 좌표는 원본 128px의 `(x,y)`, 왼쪽 위가 `(0,0)`이다. 시간은 검토용 GIF 권장 노출이다. 실제 엔진의 피해·효과음·충돌 동기화를 검증했다는 뜻이 아니다.

| 묶음 | 순서와 프레임 유지 시간(ms) |
|---|---|
| 대기 | `idle_a` 300 → `idle_b` 300 → `idle_c` 300, 반복 |
| 물기 | `idle_a` 350 → `windup` 280 → `move` 120 → `attack` 150 → `recover` 240 → `idle_a` 350 |
| 벽해용식 | `idle_a` 350 → `skill_a` 450 → `skill_b` 180 → `skill_c` 320 → `idle_a` 350 |
| 독 | `poison_a` 420 → `poison_b` 420, 반복 |
| 기절 | `stun_a` 360 → `stun_b` 360, 반복 |
| 수면 | `sleep_a` 650 → `sleep_b` 650, 반복 |
| 쓰러짐 진단 | `hit` 180 → `dead` 1100 |

## 해부와 접촉 앵커

- 대기 입술은 대략 `(101,33)`, 작은 여의주는 `(111,44)`. 발은 없으며 아래 코일이 y=124에 닿는다.
- `windup`: 머리와 목을 뒤로 접어 압축한다. 입은 약 `(83,43)`, 여의주 `(87,54)`.
- `move`: 목을 낮고 길게 오른쪽으로 뻗는다. 입은 약 `(120,58)`.
- `attack`: 윗 송곳니 약 `(120,56)`, 아래 턱 약 `(121,70)`. **물기 접촉 후보 앵커는 `(124,61)`**. 두 긴 수염은 주둥이와 턱에서 셀 안으로 휘어 돌아온다. 작은 여의주는 약 `(114,85)`이다. 오른쪽 공격 자세가 이미 셀 안 끝 가까이 있으므로 추가 확장/전체 이동 없이 사용해야 한다.
- `recover`: 입이 약 `(108,47)`로 돌아오고 목이 올라온다.
- `skill_a`: 입/여의주 사이 황백 응축 핵의 중심 약 `(110,46)`. 아래쪽 작은 물의 접힌 덩어리는 준비 단계다.
- `skill_b`: **입에서 물이 이어지는 원점 `(92,55)`**, 두 갈래 분기는 약 `(100,58)`. 윗 큰 물말림은 약 `(119,33)`, 아래 큰 물말림은 약 `(119,80)`. 분출/접촉 후보는 오른쪽 물결 가장자리 `(125,77)`이다. 별도 원거리 투사체를 만들어 게임에 연결한 결과가 아니다.
- `skill_c`: 끊어진 물덩어리는 약 `(111,69)`, `(121,77)`, `(105,85)`, `(118,91)`에서 떨어진다. 입은 회복 자세로 돌아오며 물줄기는 이어지지 않는다.
- 독: 낮은 턱 아래 독기와 입 옆 거품이 바뀐다. 두 자세 사이 전체 몸 이동은 없다.
- 기절: 턱이 처지고 작은 별이 다른 위치에서 나타난다. 눈은 좁거나 닫힌다.
- 수면: 머리를 코일 위에 놓고 눈을 닫는다. 수염·볼·배판과 코일의 국소 호흡을 바꾼다. 무기는 없는 종이다.
- 죽음: 머리와 목이 바닥에 놓이고 눈을 닫는다. 뒷 코일은 낮게 풀리며, 여의주도 바닥 높이에 내려온다.

`progress/*-8x.gif`는 실제 저장된 격자를 네이티브에서 해독하고 최근접 8배로 표시한 검토 자료다. GIF의 짙은 배경은 진단용이며 원본 격자의 `.`는 완전 투명이다.

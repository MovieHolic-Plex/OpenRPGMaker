# 독립 원본 그림 검수

- 검수자: 별도 `gpt-6.1-sol` 에이전트, high effort. 수정 권한 없이 이 후보의 실제 `source/progress` PNG만 시각 검토했다.
- 대상: 18장 네이티브 PNG와 대기·공격·회복/피격/죽음·스킬·독/기절·수면 확대 시트.
- 사용자 승인·게임 설치·실제 전투의 히트 동기화에 대한 판정은 아니다.

## 첫 검토의 교정 지적과 처리

| 지적 | 직접 픽셀 수정 |
|---|---|
| 목/코일 연결이 각지고 갈기 일부가 떠 보임 | 연결부의 새 행, 비취 갈기 뿌리 묶음, 둥근 코일 회전면 |
| 원본 1배에서 큰 비늘 면이 매끈한 민트 띠처럼 읽힘 | 큰 상단 비취 면과 넓은 남청 하단 면, 선택한 비늘 하단 가장자리 |
| 브레스의 흰 직선이 얼음/번개에 가까움 | 청록·백청의 넓은 물 주름, 큰 말림 덩어리, 짧은 보조 물갈래 |
| `idle_b` 금 배판이 사각 덩어리로 갑자기 팽창 | 비늘 면 복구 후 배판 경계만 작은 호흡으로 수정 |
| `attack` 두 수염이 오른쪽 경계에서 사라져 읽힘 | 주둥이/턱의 별도 뿌리에서 셀 안으로 돌아오는 두 긴 금색 수염, 여의주 위치 변경 |

## 최종 독립 의견

수정된 대기와 물기의 네이티브·4배 PNG를 다시 검토한 결과, 두 마지막 교정 지적은 해결됐고 중대한 시각적 차단 문제는 남지 않았다는 의견을 받았다. 뿔·사지·날개 없는 뱀형 해부, S자 코일, 금 목장식, 큰 비늘 면, 낮아진 독 표정, 늘어진 기절 턱, 감은 눈의 누운 수면, 납작하게 쓰러진 죽음 자세는 읽힌다.

남는 표현 한계:

- `attack` 약 x=116…126, y=55…78: 네이티브 1배에서 얇은 수염과 금색 턱 가장자리가 일부 겹쳐 읽힌다.
- `skill_b` 약 x=101…123, y=63…84: 아래 물결의 굽힘이 아직 일부 각져 보인다. 큰 말림과 흰 물마루는 물로 읽히도록 개선됐다.

이 기록은 후보 검수 의견이며 사용자 선택·승인을 대신하지 않는다.

# 신규50종·전부 통과 · 사용자 목표

사용자 원문: **그래 한 50개 만들고 전부 통과시켜**

`fifty-monsters-plan.json`의 서로 다른 신규50종을 만든다. 기존23종/사용자 Allow·Modify·Deny는
이 목록에 포함하거나 변경하지 않는다. 짐승10·요괴16·인간형12·대형 보스12, 원본64/96/128,
각18자세/8GIF, 총900자세/400GIF가 최종 목표다. 색만 바꾼 복제나 기본 자세만으로 수를 채우지 않는다.

## 통과의 근거

- 현재 원본의 실제 팔레트/격자/투명/접지/자세·PNG/GIF 재읽기 검사 PASS.
- 실제 별도 GPT6.1sol/high 독립 검수 job/result가 현재 원본/실제 첨부 PNG에 묶이고 추천이 keep.
- 지적이 나오면 지정한 자세/좌표를 직접 교정하고 별도 새 검수를 받는다. 이전 원본·실제 rework
  결과·출처는 남긴다. 결과/점수/해시를 고쳐서 통과시키지 않는다.
- 사용자의 이번 일괄 통과 지시를 근거로 대시보드 API에 위임된 Allow를 저장한다.
  원문/현재 원본 binding/실제 검수 job/요청 UUID를 남기며 사용자가 버튼50개를 눌렀다고 주장하지 않는다.
- 이후 직접 들어온 사용자 Modify/Deny는 앞선 일괄 지시보다 우선한다. 실패한 결과는 통과로 세지 않는다.
- 원본을 지속 보관하고 같은 자산 원본/선택/선택 팩을 다시 읽어 확인한다. 게임 프로젝트 설치는 별도다.

## 제작

하네스 `wave --visual-repairs 4 --visual-repair-authorization <사용자 원문 파일>`의 명시적 경로를 쓴다.
기존 wave/Modify의 기본 동작은 동일하다. 이번 사용자가 전부 통과하라고 지시했으므로 실제 지적 좌표
교정을 허용한다. 이 모드에서 rework인 결과는 게시하지 않는다. 제한에 닿으면 실패로 남고 감독이
현 원본/실제 호출 상태를 확인해 이어서 교정한다. 자동 점수 조작/전면 랜덤 재생성은 하지 않는다.

대표는 금각사슴64·청동종귀96·일금봉황128이다. 사슴·종귀의 실제 keep/Allow를 확인한 뒤
같은 규격의 사마귀·초롱도깨비를 두 빈 작가 자리에서 먼저 제작한다. 봉황은 교정/검수를 이어가며
추가128 보스는 봉황의 실제 그림 확인 뒤 시작한다. 세 대표의 확인 뒤 나머지45종을 이어간다.
초기 추가2종이 진행 중이면 후속 작가1명, 두 작업이 끝나면3명으로 유지해 전체 동시 호출은 최대3명이다.
실제 빈 세 번째 자리에는 홍영검희64를 별도 source에서 먼저 제작해 여성 얼굴/예복/검술을
중간에 확인한다. 기존 안개삵 wave의 실제 종료 경계에서 배차기를 교체하며 실행 중인 원본/
검수 호출을 보존한다. 초기/여성의 실제 진행 체인과 모델 PID를 예약해 남는1/2/3명만 후속을
진행하고, 외부 체인이 끝나면 나머지는3명 풀로 이어간다. 후속 대상에서 여성 파일을 분리해
동일 종을 두 작가가 동시에 쓰지 않는다. 최신 note-file은 다음 저작/교정 호출에 반영한다.
각 작가가 서로 다른 후보/source만 편집하며 게임 정본/공통 코드/ledger를 쓰지 않는다.
실제 모델은 GPT6.1sol/high, 최대3명 병렬. 자체 검객은 크기/얼굴 관찰용이며 외부 이미지 복제가 아니다.
프레임마다 명확한 관절/도구 연결, 광원/재질/부피, 큰 실루엣/표정과 공격·스킬·상태이상의 구분을 본다.

실제 중간 PNG와 완성 GIF 대시보드를 사용자에게 공유한다. 제작 중 수는 대시보드에서 표시하되
미완성/불통과 원본은 완료 후보로 노출하지 않는다. 목표는50종 전체이며 먼저 완성된 몇 종을
전체 완료로 바꾸지 않는다.

## 후속42종 실행 확인과 실제 교정

안개삵·홍영검희까지8종의 실제18자세/8GIF·선택 팩·출처 재로드·화면 확인을 완료한 뒤,
이전 삵 wave의 실제 종료를 확인해 후속42종을3명으로 시작했다. transient service의
restart가5로 실패한 것은 실제 종료 뒤 unit이 사라졌기 때문이며, 감독이 기존 모델 핸들이
없음을 확인하고 같은 이름으로 배차기/observer를 새로 실행했다. 진행 중 모델을 죽이지 않았다.
첫 세 종은 붉은턱늑대·이끼등오소리·설익부엉이다. 후속은 각 실제 지적/원본을 보존하며
최대8회 직접 좌표 교정을 허용하고,8회에도 rework면 실패/미게시로 남긴다. 통과를 꾸미지 않는다.

오소리의 실제 독립 검수는 얇은 앞다리·보행처럼 읽히는 타격 발·잠든 눈 군집을 지적했다.
현재 후보 교정은 해당 실제 지적으로 진행하고, note-file에는 다음 새 저작/교정을 위해
관절의 읽히는 면/타격 발과 지지다리 구분/실제 닫힌 눈꺼풀을 더 명확히 적었다.
이를 기본 자세만 그리거나 전부 통과됐다고 보고할 근거로 사용하지 않는다. 전체 목표는50종이다.

늑대의 실제 첫 검수는 쓰러짐/수면의 접힌 발과 말린 꼬리가 큰 둥근 덩어리에 사라지는
세 좌표를 지적했다. 현재 원본과 실제 rework를 보존하고 같은 곳을 새 작가 호출로 직접
교정한다. 후속 note-file에도 접힌 사족 발/감긴 꼬리의 구분을 추가했다. 이 지적 전
감독의 임시 초안 관찰은 통과 판정이 아니며 새 keeper를 확인하기 전에는 계속 미통과다.

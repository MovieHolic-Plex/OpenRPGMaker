## 저작과 크기

먼저 구미호 한 종의 실제 그림을 완성하고 본 뒤 나머지5종을 격리 폴더에서 저작한다.
모델은 실제 GPT6.1sol/high를 호출한다. 독립 리뷰어는 별도 새 호출로 실제 PNG를 본다.
각 종은 새 팔레트/18자세/8동작의 리터럴 격자 원본을 갖는다. 모든 종이 같은 팔레트
어휘/왼쪽 위 광원/측면3/4 계열을 따르되 꼬리·갑주·갈기·비늘·예복의 형태가 서로 다르다.

96의 본체는 약78~86px,128 보스의 본체는 약104~118px를 목표로 직접 찍는다.
기존 검객의 실제 본체 약52px와 같은 픽셀 비율로 비교해 실제 크기 차이를 본다.
작은 원본을 확대하거나 큰 빈 상자에 작은 몸만 넣지 않는다. 기존 종/전역 style을 보존하며
원본 cell의 허용값에128을 추가한다. 접지/테두리/GIF 재읽기는 기존 cell 기반 계약을 쓴다.
기술 재수정 문구도 접지를 `cell-4`로 말한다.

화려함은 넓은 금속 면·겹친 옷·굽은 꼬리·비늘/갈기·속성의 큰 덩어리에서 읽혀야 한다.
무작위 반짝이·반복 원 오라·수식 줄무늬/꼬리나 몸 확대/회전으로 형체를 만들지 않는다.
준비/접촉/붕괴 기술은 실제 입/손/뿔/철퇴에 이어지도록 각각 직접 찍는다.
상태이상은 아픈 자세/축 처진 무게/닫힌 눈과 이완으로 보여 준다.

[공식 바람의나라:연 소개](https://baramy.nexon.com/)에서 수호신/백호·도깨비·뇌운 등
판타지 어휘를 확인했다. 이번6종은 자체 디자인이며 공식 몬스터 픽셀을 복제하지 않는다.
첨부 그림은 자체 검객의 실제 native64 원본 한 장이며 공통 재질/크기의 관찰용이다.

## 결과와 사람 선택

저작 중 actual source의 PNG를 중간 그림으로 공유한다. 완성/검사/실제 독립 검수가
끝난18자세만 원자적으로 대시보드에 게시한다. AI 추천은 사용자 Allow가 아니다.
원본/실제 job/검수/시간표를 지속 출처에 저장하고 같은 source binding으로 다시 읽는다.
사용자는 기존 대시보드에서8동작 GIF를 함께 보고 Allow/Modify/Deny로 고른다.
대형 결과에서는 검토 가능한64px 인간형과 같은 배율/발 기준의 별도 비교칸을 제공한다.
게임 정본 설치·실전 전투 타격 동기화는 이번 검토용 에셋 제작과 구별한다.

## 백호 줄무늬 보완

초기 `mountain-white-tiger/ornate-boss-v1`은 짧은 반점이 많아 백호의 줄무늬가 약하게 읽혔다.
감독의 좁은 교정 지시로 별도 `ornate-boss-stripes-v2`를 저작하고 새 독립 검수를 받았다.
18자세에서 직접 고른 털색 좌표2179개만 바꿨다. 팔레트·모든 alpha 윤곽·생산 GIF 시간표는
바이트/픽셀 대조로 보존했다. 눈·코·입·발톱·장식·스킬과 몸의 크기/자세도 유지했다.
이 교정은 AI 작업 지시이며 사용자 Modify/Allow를 만든 것이 아니다. 원본도 출처에 보존한다.
원본이 검토 대기인 경우 최신 자식만 대기 목록에 보이며 원본은 이전 결과에서 볼 수 있다.
실제 사용자 선택은 기존 ledger에 남고, 새 후보도 사용자가 판단한다.

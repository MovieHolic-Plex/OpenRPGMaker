# Field kit authoring

README와 references/source.json → 실제 원본 이미지 → 수정 레시피 순서로 읽는다.
범위는 필드 몬스터 / UI / 음악이다. 사람 NPC와 전투 그림을 이 규격에 끼워 넣지 않는다.

- 작은 원본 크기에서 명시적으로 픽셀을 수정한다. 원작 판형 출처, 소스 SHA, 보호된 보행을 보존한다.
- 규격 통과는 미감 승인과 다르다. 실제 GIF와 디코드한 프레임을 확인한다.
- 음악은 원본 악보를 저장한다. 청취하지 않았으면 청취했다고 쓰지 않는다.
- 세 영역을 사람이 따로 Allow/Deny 한다. 에이전트가 실제 `.data`에 판정 영수증을 쓰거나 자동 승인하지 않는다.
- 수정 후 package.mjs로 해시를 갱신한다. 기존 후보 승인으로 변경된 그림/음원/UI를 배포하지 않는다.
- 합성 승인 경로 검사는 임시 `.data` 사본에서만 한다. 원본 판정/게임 저장소를 건드리지 않는다.
- 플레이어 모양의 화면은 시안임을 명시한다. 실제 프로젝트와 저장/구매/회복이 연결됐다고 주장하지 않는다.
- 에디터 의존성을 추가하지 않는다. 게임 적용은 승인 후 외부 어댑터 + 정본 저장/재로드 작업이다.

# 상인 v2 — 외형 재설계 표본

사용자 피드백: 초기 후보는 색과 작은 장식만 바뀌어 원작과 너무 비슷하다.
이 안은 머리의 외곽을 청록 두건/매듭으로, 얼굴을 콧수염 있는 인상으로,
몸통을 가죽 조끼/작업 앞치마로 바꾼다. 원작의 보행과 28~31행 발 픽셀은 유지한다.

`comparison.gif`: 왼쪽 원작 / 가운데 v1 / 오른쪽 v2. 네 방향 걷기.
자동 검사 통과는 미감 승인과 다르며, 이 안은 사용자 승인 대기다.

독립 폴더에서 새 출력 경로로 등록:

```bash
node cli.mjs render --draft variants/merchant-v2 --out /path/to/new-merchant-v2-bundle
```

`author.py`는 저작자가 쓴 명시적 픽셀 행을 template.json으로 기록한다.
특정 사람/모델이 저작했다고 임의 표시하지 말고 candidate.json의 author와 출처를 맞춘다.

다음 변형의 검토 기준: 색을 지워도 보이는 머리 외곽 변화, 읽히는 얼굴 인상,
옷 구조와 직업 장식의 차이를 먼저 정한다. 수정 픽셀 개수로 새 캐릭터 여부를 판정하지 않는다.

# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/MovieHolic-Plex/OpenRPGMaker/security/advisories/new), or contact the repository maintainers through the security contact listed in the repository profile. Include the affected commit, reproduction steps, and impact.

Credentials that may have appeared in Git history must be revoked and
reissued immediately, even after the history is rewritten.

If a credential was committed, do not paste the value into an issue or pull request. State which provider and repository path were affected, when it was exposed, and whether the provider has confirmed revocation.

## Supported versions

Only the default branch and the latest published release receive security
fixes.

지금 게임에서 되는 것 (Phase A 복습)

전부 실제 플레이 중인 브라우저 캡처입니다.

철력·스태미나 HUD + 배회하는 슬라임좌상단 HP 바와 ST 바가 항상 보입니다. 슬라임 5마리는 걷기 캐릭터칩으로 걸어다닙니다.
검 스윙 명중 — "39"Space를 누르면 전방 부채꼴로 공격. 맞은 슬라임은 하얗게 점멸하고 노란 데미지 숫자가 뜹니다.
몬스터 철력바 (옵션)한 번 맞은 몬스터 머리 위에 철력바가 표시됩니다. 설정: 항상 / 맞은 것만 / 끄기. 플레이어가 붉은 건 방금 맞았다는 뜻.
격파와 보상HP를 다 깎으면 몬스터가 사라지고 골드·드롭을 얻습니다. 잠시 뒤 스폰 지점에서 리스폰.

Phase B — 몬스터의 3가지 공격 패턴

모든 공격은 같은 리듬을 따릅니다. 예고(선딜)가 보이니까, 피할 수 있습니다.

추격기존 A* AI로 접근
→
선딜 (예고)붉은 점멸 + 바닥 경고
→
공격타격 / 탄 / 돌진
→
후딜 (빈틈)플레이어 반격 찬스
→
추격쿨다운 후 반복

탄 쏘기 projectile

초원 슬라임 (spawn_b 구역) — 실제 캡처: 탄 2발이 동시에 날아오는 중, 맞은 플레이어는 붉게 점멸

멀리 있으면 붉게 예고한 뒤 주황색 탄을 쏩니다. 탄은 직선으로 날아가 벽에 막히고, 플레이어에게 닿으면 데미지. 옆으로 걸어서 피할 수 있습니다.

attack: { kind: "projectile", windupMs: 600,
  recoverMs: 500, damage: 4, range: 8,
  projectileSpeedTilesPerSec: 6 }

돌진 dash

동굴 박쥐 (spawn_c 구역) — 실제 캡처: 붉은 직선 경고가 플레이어 열을 덮고, 박쥐가 그 길로 돌진

플레이어와 같은 줄에 서면 바닥에 붉은 직선 경고가 깔리고, 잠시 뒤 그 길로 빠르게 돌진합니다. 경고가 보이면 옆으로 빠지면 됩니다.

attack: { kind: "dash", windupMs: 450,
  recoverMs: 700, damage: 5, range: 5 }

근접 후려치기 melee

슬라임 (spawn_a 구역) — 실제 캡처: 타격이 적중해 플레이어가 붉게 점멸하고 HP가 361 → 354로 감소

가까이 오면 붉게 예고한 뒤 전방 부채꼴로 후려칩니다. 플레이어의 검과 같은 판정이라, 예고를 보고 뒤로 빠지면 맞지 않습니다. 기본 접촉 데미지와는 별개입니다.

attack: { kind: "melee", windupMs: 500,
  recoverMs: 600, damage: 6, range: 1 }

어떻게 동작하나 — 4개의 쉬운 개념

엔진 구조를 몰라도 읽히도록 쓴 설명입니다.

1. 몬스터마다 작은 상태기계

각 몬스터는 "추격 → 선딜 → 공격 → 후딜"을 돕니다. 선딜·후딜 시간은 몬스터 데이터(EnemyRecord.actionProfile.attack)에 적으므로, 코드를 고치지 않고 몬스터마다 다른 리듬을 만들 수 있습니다.

2. 선딜 동안은 얼린다 (freeze)

추격 이동은 기존 NPC 묘버가 담당합니다. 선딜에 들어가면 actionFrozen 플래그로 묘버를 얼려 제자리에 세우고, 후딜이 끝나면 다시 풉니다. 기존 추격 AI는 한 줄도 고치지 않았습니다.

3. 경고는 바닥에 그린다 (텔레그래프)

공격이 닿을 칸을 선딜 시작 시점에 붉게 칠해 보여줍니다. 근접은 부채꼴, 돌진은 직선, 탄은 비행 경로. 플레이어의 흰색 스윙 표시와 같은 그리기 도구를 재사용했습니다.

4. 탄은 매 프레임 전진하는 작은 점

발사 순간의 플레이어 위치를 향해 직선으로 납니다. 매 프레임 벽·사거리·플레이어와의 겹침을 검사해 소멸 또는 명중시키고, 화면 밖으로는 못 나갑니다. 관통·유도 같은 물리는 의도적으로 넣지 않았습니다.

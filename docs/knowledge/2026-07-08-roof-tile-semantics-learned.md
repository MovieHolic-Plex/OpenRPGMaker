> 기준 집 2채**이며, 나머지 연습 맵은 삭제됐다. 하네싱 설계도(타일별 역할·연속 방향·레이어):

> 이 문서 최초판과 달라진 점:
> 1. **벽 기본 높이 = 3행**(상단·중단·하단 나인슬라이스). 2행 벽은 오답. 2층 이상 = 중단 행만 세로 반복.
>    파랑 집 페어 벽 = 석벽 15/16/17·45/46/47·75/76/77, 오렌지 페어 벽 = 흰 회벽 12/13/14·42/43/44·72/73/74.
> 2. **파랑 지붕에서 좌측 수직 가장자리 437은 쓰지 않는다** — 몸통행 좌측 끝도 406, 우측 끝만 407.
> 3. 파랑 지붕 3단 정본: 처마 467(벽과 같은 폭, 좌우 끝에 상위 386/387 겹침) → 몸통 406+우끝 407 →
>    최상행 406(좌우 1칸 인셋, 빈 모서리에 상위 356/357).

## 핵심 교훈 (현 빌드 엔진과의 차이)

1. **지붕의 대각/외곽 마감은 상위 레이어 오버레이다.** 하위 레이어만으로 지붕을 조립하던
   현 `stampHouse`/`fillRoof`는 모서리가 각져 보인다. 정석은: 몸통·처마는 하위,
   용마루 캡·수직 트림·대각 모서리는 상위(투명 배경으로 풀이 비침).
2. **밝은 오렌지 세트의 용마루(374)는 지붕 사각형의 "위 한 줄"에 상위 레이어로 얹는다.**
   (기존 엔진은 374를 지붕 최상단 행의 하위 타일로 깔았음 — 연습08 기준 오답.)
3. **처마는 지붕 몸통보다 좌우로 1칸씩 넓다**(오버행). 연습08 실측.
4. 파랑과 오렌지는 **완전히 다른 세트**이며 섞지 않는다 (기존 규칙 재확인).

## 파랑 직선 지붕 세트 (연습02)

```
상위:  356 ................. 357     ← NW/NE 대각 모서리 캡 (상위)
하위:   .  406 406 406 406 406  .    ← 최상행(몸통, 좌우 1칸 인셋)
하위:  437 406 406 406 406 406 407   ← 좌가장자리 437 / 몸통 406 / 우가장자리 407
하위:  437 406 406 406 406 406 407
하위:  467 467 467 467 467 467 467   ← 처마(최하행, 전폭)
상위:  386 ................. 387     ← SW/SE 대각 모서리 캡 (처마 행 위에)
```

| 타일 | 레이어 | 역할 |
|---|---|---|
| 406 | 하위 | 파랑 지붕 몸통(좌사면 셰이드) |
| 407 | 하위 | 파랑 지붕 우측 가장자리/우사면 |
| 437 | 하위 | 파랑 지붕 좌측 가장자리(수직) |
| 467 | 하위 | 파랑 지붕 처마(최하행) |
| 356/357 | 상위 | 대각 모서리 NW/NE (투명부에 배경 비침) |
| 386/387 | 상위 | 대각 모서리 SW/SE |

## 사선(피라미드) 지붕 오버레이 (연습03)

행이 내려갈수록 1칸씩 밖으로 벌어지는 대각선: 상위 356(좌상 사선)·357(우상 사선)이
계단식으로, 하위는 좌반 406 / 우반 407로 채움. 하단은 386/387이 같은 계단식으로 마감.
→ 356/357/386/387은 "모서리 1칸"이 아니라 **사선 라인을 잇는 계단 오버레이**로도 쓴다.

## 밝은 오렌지 ㄱ자 집 (연습08)

```
상위: 354 374 374 374 374 355        ← 용마루 캡+라인: 지붕 사각형 "위 한 줄"
상위: 376  .   .   .   .  377        ← 수직 트림: 지붕 좌우 바깥 열
하위:      404 404 404 404           ← 지붕 몸통
하위:  405 405 405 405 405 405       ← 처마: 몸통보다 좌우 +1 오버행
하위:  12  13  13  13  14            ← 벽 나인슬라이스 상단
하위:  42  43  43  43  44            ← 벽 중단
하위:  72  73  73  73  74            ← 벽 하단
상위: 384 ............. 385          ← 트림 하단 캡
```

| 타일 | 레이어 | 역할 |
|---|---|---|
| 404 | 하위 | 밝은 오렌지 지붕 몸통 |
| 405 | 하위 | 처마(몸통보다 좌우 +1) |
| 374 | **상위** | 용마루 라인(지붕 위 한 줄) |
| 354/355 | 상위 | 용마루 좌/우 끝 캡(대각) |
| 376/377 | 상위 | 지붕 좌/우 수직 트림 |
| 384/385 | 상위 | 트림 하단 캡 |
| 12/13/14, 42/43/44, 72/73/74 | 하위 | 흰 회벽 3×3 나인슬라이스(상/중/하 × 좌/중/우) |

ㄱ자 평면: 좌상 날개(지붕→처마→벽 3행이 위쪽에서 끝남) + 우하 날개(지붕이 더 내려간 뒤
처마→벽 3행) — 날개별로 "벽 공간 먼저, 지붕으로 채움" (HousePlan 명세와 일치).

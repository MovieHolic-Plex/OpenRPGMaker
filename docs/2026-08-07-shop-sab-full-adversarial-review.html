S 8종+A 6종+B 6종, 총 20개 상점 패턴을 코드·에디터·런타임·세이브 네 축에서 동시에 때려봤다. 단일 목록 상점은 닫힌다. 그러나 되사기·장바구니·동적물가·전당포·암시장이 한 상점에 겹치면 골드·재고·충성도·마이글리지가 서로를 속인다. 이 문서는 “좋은 상점”을 칭찬하지 않는다 — 어디서 돈이 복사되고, 어디서 거래가 원자성을 잃는지만 적는다.

TL;DR — 60초 판정

닫힌 것

  • 단일/계절 재고 + merchantGold + socialShop 0.5 하한 + sellFloor 가드
  • S: displayTileId 동기화·리스톡(daily/weekly)·충성도 티어·마일리지·투자 0..5
  • 타입·lint·세이브: S/A/B 필드 pass-through, overflow 경고, session shop* 필드

가드 없으면 터지는 것

  • A/B 동적물가+흥정+충성+마감 4중 스택이 15% 캡 없으면 마진 역전
  • 장바구니 비원자성: 중간에 골드 부족이면 앞줄만 결제되는 찢김
  • 되사기 영속/만료 미정의: 세이브에 남고 무한 되사기
  • 전당/암시장/경매 스위치 게이트 미흡 시 진행도 우회
한 줄 처방: 스택 할인 단일 합산 후 Math.min(0.15, sum) 하드캡 + 장바구니는 검증→차감→지급 원자 트랜잭션 + 동적물가 0.8..1.2 밴드 유지 + 전당 이자는 단리·상한·만료 소각. 이 넷이 없으면 A/B는 출시 불가.

경제 루프 & 누수점

골드가 상점을 돌며 어디서 새고 어디서 복사되는지. 빨간 점이 누수·복사 지점이다.

그림 1 — 상점 경제 루프와 4대 누수점. 상단 가격 스택과 장바구니가 P0, 되사기·암시장이 P1, 세이브 경계가 영속 오염점.
가격 스택
loyalty + closingSale + haggle + investment 합이 0.22에 도달하면 100G짜리가 78G. 15% 캡 없으면 역마진.
장바구니 원자성
검증 없이 줄별로 changeGold 하면 3줄 중 2줄만 결제되고 골드는 음수 클램프에 걸린다.
동적물가 드리프트
sold/bought 누적치가 세이브에 남는다. ±20% 밴드 없으면 30회 거래 후 0.4~1.6배 왜곡.

각 카드: 의도 → 공격 표면 → 재현 경로 → 현 방어 → 잔여 갭 → 처방(P).

S S-tier — 지금 붙여도 되는 것 (가드 포함)

P1되사기(buyback)
buyback 8줄 FIFO · 영속 — 팔자마자 되사면 판 가격보다 싸게 되사는 역마진. 재현: socialShop 0.7 할인 + sellFloor 50G → 되사기 55G면 5G 이득 루프. 방어: clampShopBuyback + sellFloor 하한. 잔여 갭: 만료·세이브 영속 정책 미고정. 처방: 되사기가는 max(sellPrice, discountedBuy) + 만료일키 + 저장 시 슬라이스.
P0장바구니(cart)
12줄 합계 원자 결제. 재현: 3줄 90G·90G·90G 중 270G 필요인데 200G 보유 → 줄별 결제면 2줄만 가고 1줄 유실. 방어: clampShopCart + 합계 선검증. 처방: 검증→차감→지급 단일 트랜잭션으로 고정.
P2리스톡·진열 동기화
restockPolicy daily/weekly/onDemand + displayTileId. 공격: 매일 자정 리스톡이 shouldRestock 없이 매 프레임 리필. 방어: shopLastRestockDayKey + dayKey 비교. 잔여 갭: 타일 통행 불가 검증 없음. 처방: displayTileId는 lint warn으로만.
가드됨단골등급·VIP
shopLoyaltySpend + resolveLoyaltyDiscount 0/3/6/10% 4티어, 15% 캡. 공격: 티어 합산 없이 할인 중첩. 방어: 단일 합산 후 하드캡. 처방: 티어 변경 시 세이브 마이그레이션.
가드됨투자·확장
investmentLevel 0..5 lint range. 공격: 99 레벨 주입. 방어: shape 0..5 + lint overflow. 처방: 투자 시 해금 재고는 stock 필터로만.
P1행상(트래블링)
travelingRouteId + festivalFlag 스위치 게이트. 재현: 플래그 없이 전 맵에서 상점 노출. 방어: isFestivalShopOpen·조건 분기. 처방: 이동 상점은 항상 조건 이벤트로 감싸기.
P1수리
shopServiceKind=repair. 공격: 내구도 없는 아이템에 수리비만 빠져나감. 방어: 서비스 분기 UI + 미리보기. 처방: 수리 대상 필터 + 실패 시 골드 환불.
P1감정
appraisal + appraisalUnidentifiedPool. 공격: 미감정 풀 비어 있는데 감정비 청구. 방어: 풀 선검증. 처방: 빈 풀은 메뉴 비활성.

A A-tier — 조건부 (가드 필수)

P1발주(indent order)
다음날 배송. 재현: 발주 후 세이브→로드하면 배송 유실. 방어: session 영속 키. 처방: dayKey 기반 큐 + 재시작 시 재스케줄.
P1마감세일(closing sale)
resolveClosingSaleDiscount 20~22시 15%. 재현: 마감세일+충성 10%+흥정 10% = 35% 중첩. 방어: 스택 합산 캡. 처방: 마감세일은 단일 할인으로 합산 후 캡.
P1위탁(consignment)
16건 상한, 수수료. 재현: 16건 넘게 위탁 시 뒤에만 잘림. 방어: SHOP_CONSIGNMENT_MAX + lint. 처방: 위탁 수수료 선차감 + 만료 시 자동 반환.
P2기부(donation)
donation.totalDonated 누적. 공격: 기부 후 보상 스위치 미설정. 방어: ledger 영속. 처방: 임계치 달성 시 스위치 자동 ON.
P2축제 한정(festival)
festivalFlag 스위치 게이트. 처방: 축제 맵은 별도 shopType으로 분리, 평시 숨김.
P2마일리지·스탬프
mileageRate 0..0.1 + shopMileagePoints. 공격: 0.9 주입 시 90% 캐시백. 방어: shape 0..0.1 클램프. 처방: 적립은 결제 성공 시에만, 환불 시 차감.

B B-tier — 스위치 없이 열면 사고

P0흥정(haggle)
applyHaggleDiscount 매력/협상 10당 1% + 베이스 5%, 상한 15%, 하한 sellFloor. 재현: 흥정 미니게임 스팸으로 무한 15% 고정. 방어: 하한/상한 캡. 처방: 흥정은 1거래 1회, 실패 시 가격 상승 페널티.
P0동적물가(dynamic pricing)
applyDynamicMarkup 0.8..1.2 밴드. 재현: 50회 팔고 0회 사면 0.0배로 수렴. 방어: 밴드 클램프. 처방: shopTradeCounts 주기적 감쇠(decay) 또는 캡 리셋.
P0차익거래(arbitrage)
tradeRouteMarkup mapId→배수. 재현: A마을 100G 매입→B마을 200G 매도로 2배 차익, merchantGold로 증폭. 방어: 마크업 상한 + merchantGold 한도. 처방: 차익은 재미—단, 1.5배 상한 + 쿨다운.
P0전당포(pawn)
pawnTickets 8건, dueDayKey 이자. 재현: 0% 이자로 무한 보관. 방어: 상한 8 + 만료 키. 처방: 이자 단리 10%/일, 30일 소각, 세이브에 dueDayKey 필수.
P0암시장(black market)
blackMarketFlag 없으면 항상 오픈. 재현: 초반에 엔드템 구매. 방어: isBlackMarketOpen 게이트. 처방: 진행도 스위치 없이 배치 금지 — lint error로.
P1경매(auction)
최고가 스위치 경합. 재현: 경매 중 세이브→로드하면 입찰 유실. 방어: 세션 영속. 처방: 경매는 단일 맵·단일 진행도에서만.

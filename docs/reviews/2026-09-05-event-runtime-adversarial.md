# 이벤트 런타임 후속 적대적 리뷰 및 Visual QA

검토 대상: PR #595, 기존 `aed6d2e1` 이후. 이전 통과 보고를 근거로 생략하지 않고, 최신 Supabase 프로젝트를 새로 읽어 Chromium을 다시 실행했다. 데스크톱 DISPLAY가 없는 환경이므로 Xvfb 가상 화면에서 `headless:false` 창을 열었다. 사용자 화면에 원격 브라우저 창을 공유한 것은 아니다.

## 실제 플레이와 화면 판정

- 원격 프로젝트 `rpg-zzu-cheolsu-memory-20260905-df12`를 새로 읽음. SHA-256 `32625f7b4d717e4f708e57b90861f1546ca1d1b43cd410badd2e86f6004ae2b8`, 이전 저장 결과와 동일. 원격 콘텐츠를 다시 저작하거나 저장하지 않았다.
- 「철수의 기억」: 방향키/Enter만으로 17개 대사, 회상 진입, 아버지 장면, 현재 귀환, 상자 재조사, 이동 복구. 대사 없는 정지 5.5초 상한. 핵심 PNG를 직접 열어 대사 줄바꿈, 화자 이름표, 인물 위치, 맵 표시를 확인했다.
- 1280×720 및 640×480으로 창 크기를 바꿔 각 방향으로 걸었다. 카메라/플레이어 좌표 213표본에서 맵 경계 이탈 없음. 100ms 이하 인접 표본의 최대 카메라 이동은 논리 9px로, 이번 시나리오에서 걸음 도중 스냅을 발견하지 못했다. 두 화면 크기의 PNG에서 게임 영역 잘림이나 잘못된 늘어남을 발견하지 못했다.
- 명령 계약 플레이: 조건 생산자 대기, NPC 장애물 우회, 메뉴 닫기 전 진행 차단, 로드 패널 취소/실제 슬롯 로드, 영상 playing/ended, 로드 후 기존 이벤트 종료와 조작 복구. 메뉴·로드·영상·종료 화면 PNG 확인.
- 반례 브라우저 시나리오 6개: 이동 중 목적지 변경, 현재 착지 칸으로 변경, 시작 전 예약 취소, 이동 중 정지, NPC 착지 대기, 도달 불가 목적지에서 안전한 종료. 모두 실제 인터프리터를 통해 실행하며 위치 조작 훅은 호출하지 않는다.

## 검증 한계와 하네스 자체 점검

- 카탈로그 모든 명령과 모든 맵을 전수 플레이했다는 뜻은 아니다. 화면 판정은 Chromium/Xvfb 환경이며 모바일 터치나 다른 브라우저는 포함하지 않았다.
- 경로 실행 중 새 장애물이 나타나면 정지하는 기존 정책을 유지한다. 실시간 재탐색을 추가하지 않았다.
- 최초 반례 하네스는 `stopAllMovement` 내부 실행 단계 이름을 저작 명령으로 넣어 로드에 실패했다. 실제 저장 명령 `m2-059-stop-all-movement`로 고쳤으며 엔진 결함으로 집계하지 않았다. NPC 위치를 영구 재배치 저장소에서 읽던 하네스도 현재 런타임 이벤트 뷰로 바꿨다.
- 새 회귀 5개를 포함한 관련 11파일 / 227개 통과. 전체 게이트 판정은 증거 폴더 README의 최종 결과를 따른다.

# 게임 메뉴 디자인 수정·확장 — 2026-09-18

자료집 → 시스템 → 화면 → 게임 메뉴 디자인에서 기존 5종과 새 3종을 선택한다.

| 새 디자인 | 구성 |
|---|---|
| 클래식 · 청색 창 | 청색 이중 테두리, 왼쪽 명령 창, 오른쪽 파티 |
| 여행 수첩 · 종이와 잉크 | 밝은 종이, 파티 기록, 오른쪽 책갈피 명령 |
| 하단 바 · 파티 카드 | 네 장의 파티 카드, 아래 가로 명령 여섯 개 |

## 수정한 결함

1. 신규 스킨의 사이드 파티 때문에 아이템 효과·사용 조건·소모 표와 장비 능력치
   비교가 숨겨졌다. 이 정보와 탭이 있는 화면은 상세 공간을 확보하고 표를 유지한다.
2. 레일 DOM 재사용 시 새 요약 텍스트를 버렸다. 버튼·포커스는 유지하면서 요약과
   라벨을 갱신한다. 마지막 회복약 사용 후 아이템 종류 수와 위험 파티원 수가 바뀐다.
3. 허브 시스템 요약의 전투 대기 표시가 ON으로 고정돼 있었다. 실제 모드를 전달한다.
4. 격자 메뉴에서 Left로 돌아오면 잘못된 Right-to-enter 안내가 나왔다. 현재 스킨의
   열 수를 전달한다.
5. 파티 명령을 선택하면 기존 파티 패널과 새 첫 화면의 파티 표시가 중복됐다.
   기존 패널은 해당 하위 화면에서만 보인다(기본 작업대 미리보기는 유지).

## 실제 플레이 검증

명령: `node scripts/qa/runtime/menu-design.probe.mjs`

편집기 플레이 대신 전용 `startPlayerQaServer`에서 출하 `player.html`과
export store shim을 사용한다. 기존 `item-runtime-qa-v3.json`의 분리된 테스트
사본만 이용하며 원격 게임 콘텐츠를 변경하지 않는다.

- 8종 모두 실제 키보드로 필드 (14,18) → (14,19) 이동.
- 회복약 효과 표가 보이고 상세 영역 안에 배치됨.
- 회복약 마지막 1개 사용: 수량 0, HP 100 → 150. 허브 요약도 갱신.
- 하위 화면 진입/복귀, 격자 이동, 파티 패널 중복 방지.
- 성장 스킬 탭 전환 및 장비 능력치 비교 표시.
- 전투 대기 변경과 허브 OFF 표시.
- 실제 저장 슬롯 기록 및 불러오기, 선택한 디자인 유지.
- 960×720 플레이, 640×480·1280×800 화면 안 배치.
- 실행 중 pageerror가 없어야 통과.

에디터 명령:
`OPRN_QA_EDITOR_URL=http://127.0.0.1:9827 node scripts/qa/menu-design-editor.mjs`

8개 선택지, 새 3종 선택·정규화 왕복·미리보기 이미지 디코딩,
기본 선택 시 선택값 삭제를 실제 브라우저에서 확인했다.

결과와 즉시 확인 캡처 목록:
`verify-shots/runtime-qa/menu-design/SUMMARY.md`, `EDITOR.md`, `results.json`.
등록용 실제 플레이 캡처는 `public/assets/ui/menu-skins/classic.png`,
`journal.png`, `ribbon.png`에 포함한다.

단위 회귀 테스트도 갱신했으나 Vitest·전체 typecheck·전체 게이트는 실행하지 않았다.
브라우저 검증은 위의 메뉴 경로와 화면 크기에 한정한다.

# Four era-inspired menu designs — 2026-09-18

Requested reference → editor option:

| Reference | Editor option | Distinct presentation |
|---|---|---|
| RPG Maker 2000 | 레트로 2000 · 청색 픽셀 창 | Cobalt, square silver border, right commands, numeric HP/MP |
| RPG Maker 2003 | 레트로 2003 · 청록 입체 창 | Teal/slate, beveled borders, inset gauges, right command window |
| RPG Maker XP | 클래식 XP · 안개빛 창 | Translucent slate, walking party characters, left command/time/gold windows |
| RPG Maker VX | 클래식 VX · 보랏빛 초상 창 | Violet windows, bright rounded borders, portrait rows and coloured gauges |

These are interpretations using CSS frames and the project's own actor resources.
Reference context: [official VX menu example](https://rpgmakerofficial.com/product/products/rpgvx/lecture/09/index.html),
[XP product page](https://www.rpgmakerweb.com/products/rpg-maker-xp),
[2003 product page](https://www.rpgmakerweb.com/products/rpg-maker-2003).

All four use the existing menu controller and existing item/equipment/save/load
behavior. The total is now 12 choices. Old IDs and missing-value behavior remain
compatible. XP's standing characters use the same actor appearance/session override
as the field player and the canonical charset crop/transparent-colour helper.

## Evidence

Runtime:

```sh
OPRN_MENU_QA_OUT=verify-shots/runtime-qa/menu-eras node scripts/qa/runtime/menu-design.probe.mjs retro-2000 retro-2003 classic-xp classic-vx
```

The dedicated player.html harness exercises keyboard movement (14,18) → (14,19),
item effect visibility, last potion consumption, HP 100 → 150, menu return,
party submenu, skill tabs, equipment stat comparison, wait setting and real
save/load. It captures 960×720, 640×480 and 1280×800. It also measures both HP and
MP against each party row; early screenshot inspection caught the fourth member's
MP clipping and the corrected window geometry is covered by this assertion.

`SUMMARY.md` and `results.json` in that directory contain the run result.
Main screenshots are copied into `public/assets/ui/menu-skins/<id>.png` only after
the corresponding gameplay checks pass. Images are actual player screenshots.

Editor:

```sh
OPRN_QA_EDITOR_URL=http://127.0.0.1:9827 OPRN_MENU_QA_OUT=verify-shots/runtime-qa/menu-eras node scripts/qa/menu-design-editor.mjs retro-2000 retro-2003 classic-xp classic-vx
```

Checks 12 options; all four new choices write the right system value and survive
normalization, preview images decode, and selecting workbench removes the optional
key. `EDITOR.md` records the result. No remote game content is authored by these
engine/UI probes. Vitest and full gates were not run.

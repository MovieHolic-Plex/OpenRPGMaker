# 에디터에서 만드는 멀티 게임 오버

제작 경로: **자료집 → 시스템 → 게임 오버 → 새 게임 오버**.
이름별로 연출·미디어·시간·결과를 만들고, 이벤트의 **게임 오버 / 주인공 사망 → 실행할 게임 오버**에서 선택한다.
기존 조건 분기의 각 가지에 다른 항목을 연결하면 멀티 게임 오버다. 전투 전멸 등 자동 호출의 기본 항목도 지정한다.

- 생성·복제·이름 변경·삭제. 기본값과 참조 중인 항목은 삭제 보호.
- 텍스트/그림/영상/음성 시퀀스, 배경·음악·문구와 암전/정적/대기 시간.
- 화면 연출과 결과를 독립 선택: 선택 메뉴, 진행 유지·파티 회복·귀환, 타이틀 자동 복귀.
- 전체 미리보기: 실제 플레이어 렌더러. 게임 상태 변경 없이 결과를 시뮬레이션. Esc 중지.

`report.html`에 에디터 화면과 실제 인게임 GIF를 함께 배치했다. GIF는 실시간 녹화(1배속, 12fps, 무음)다.
`evidence.json`에 확인 항목을 기록했다. `scripts/qa/runtime/game-over-library.probe.mjs`가 재현 스크립트다.

브라우저에서 세 항목 저작, 복제 격리, 기본값/참조 삭제 보호, 이벤트 선택과 메시지 변경, 직렬화 재로드를 확인했다.
독립 player.html에서 각 ID와 기본값 호출, canLose 전투 안의 명시적 항목 호출, 귀환 후 진행 변수 37 보존 및 이동, 타이틀 복귀, 종단 후 명령 미실행을 확인했다.
이는 **메모리 전용 QA fixture**다. 실제 프로젝트 SQLite 저장을 수행했다고 주장하지 않는다.
Vitest·전체 typecheck·gates는 세션 규칙에 따라 실행하지 않았다. 새 회귀 테스트는 추가만 했다.

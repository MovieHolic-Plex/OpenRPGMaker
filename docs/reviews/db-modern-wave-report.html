스프레드시트가 아니라 문으로

RM 폼을 복원하는 대신, 사람이 매일 만지는 칸을 클릭·점프·한글로 갈아끼웠습니다. 저장 모양과 탭 이름은 그대로입니다.

바뀌지 않은 바닥

화면만 바꿨습니다. 프로젝트 JSON, 더티 세 버튼, 모달을 다시 열지 않는 점프, 기존 필드 이름은 계약입니다.

1

문과 레일

개요는 장식이 아니라 입구입니다. 접힌 도크에도 이름이 남습니다.

이전

  • 통계 칩이 눌러지지 않는 상자
  • 성장 곡선이 세션 파티를 읽음
  • 공격 정체 이슈가 스킬 탭으로 점프
  • 도크에 첫 글자만 있고 이름 없음

지금

  • 칩이 버튼 — 누르면 그 탭
  • 곡선 제목 시작 파티 성장, 체력/공격 범례
  • 정체 이슈는 직업으로
  • 도크에 짧은 글자 + 호버 이름
2

파티 짐

아이템 탭의 가짜 장비 폼을 치우고, 직업 습득 스킬을 진짜 행으로 고칩니다.

이전

  • 아이템 종류가 무기면 장비처럼 보이는 폼
  • 직업 습득 스킬 첫 행을 고치면 목록이 한 칸으로 덮임
  • 빈 장식 12행

지금

  • 장비 탭 열기 문만 남김
  • 어느 행을 고쳐도 그 칸만 바뀜
  • 추가 / 삭제로 실제 목록만 보임
3

싸움

프레임을 눌러도 그림이 안 바뀌던 길을 고쳤고, 전투 명령 탭을 한글로 직업에 연결했습니다.

이전

  • 프레임을 눌러도 상태만 바뀌고 화면은 그대로
  • 전투 명령에 RM 경로와 영어 종류

지금

  • 누르면 활성 행과 셀이 따라감
  • 직업 탭에서 메뉴 순서 정하기
4

설정이 말로

상성표는 미리보기가 아닙니다. 하루 끝 이벤트는 함부로 지워지지 않습니다.

이전

  • “미리 본다”고 써 놓고 클릭이 배율을 바꿈
  • 타입 목록을 비우면 표가 경고 없이 사라짐
  • 하루 끝 공용 이벤트를 지워도 막지 않음
  • 지형에 RM 경로와 raw id 칸

지금

  • 칸을 누르면 배율이 바로 바뀝니다
  • 비우기 전에 확인, 취소하면 표 유지
  • 「시간 시스템(하루 끝)」이 막고 이유를 말함
  • 전투 배경·발소리 설정… 피커

타일셋 그래픽은 설정… 피커로 고르고, EasyRPG 칩셋·업로드 chipset/tileset은 480칸·통과 배열을 맞춥니다. 사이드바 그룹(파티 / 전투 / 수집 / 맵 / 시스템)은 표준·전문가 모드입니다. 초보자는 짧은 공통 탭만 둡니다. 몬스터·적 무리·전투 지형은 전투에, 종족은 수집에 있습니다.

# 데이터베이스·이벤트 편집기 적대적 리뷰

## 범위와 개선

데이터베이스 레코드와 삭제 참조, 이벤트 명령 목록·페이지, 초안 저장/취소, 공통 이벤트 호출 검사를 세 에이전트로 분담했다. 코드 수정은 격리 워크트리에서 진행하고 이 작업 브랜치에 통합했다.

| 경로 | 확인한 결함과 수정 |
| --- | --- |
| DB 레코드 삭제 | 아이템 학습/발동 스킬, 직업 전투 명령 스킬, 직업·장비·아이템의 액터 권한 참조를 삭제 방어에 추가했다. 삭제 뒤 불러오기 검증 실패를 예방한다. |
| 중첩 이벤트 참조 | 공통 이벤트·리소스 검사가 전투 결과, 상점 실패, 승급·진화 분기를 공용 분기 순회기로 검사한다. 전투 대상 변수 참조도 보호한다. |
| 미적용 초안 | 작업본과 저장/취소 가능한 편집 초안 원본의 참조를 함께 보호한다. 새 초안 기준본과 원격 삭제된 원본은 제외한다. |
| 원격 삭제 충돌 | 초안 취소가 오래된 원본을 복원하지 않고 원격 삭제를 유지한다. |
| 명령 드래그 | 전용 드래그 형식과 해당 렌더의 소유권을 확인한다. 외부 텍스트·다른 편집기·오래된 드래그를 거부하고 재사용 목록은 최신 콜백을 쓴다. |
| 페이지 붙여넣기 | 페이지 없는 레거시 이벤트의 기존 명령·트리거를 기본 페이지로 보존한 뒤 붙여넣는다. |
| 호출 그래프 경고 | 존재하지 않는 공통 이벤트 pages 대신 commands를 읽고, 현재 페이지에서 도달 가능한 순환·8단계 초과를 호출 위치에 경고한다. 반복 탐색은 중복 제거와 완료 캐시로 제한한다. |
| 저장 피드백 | 기록을 건너뛴 임시 세션은 성공/clean으로 처리하지 않는다. SQLite 저장을 온라인 저장으로 오표시하지 않는다. |

## 검토와 관측 근거

- 독립 리뷰에서 새 호출 검사에 지수적인 재탐색 위험을 발견했고, 인접 목록 중복 제거와 깊이별 완료 캐시로 보완한 뒤 재검토했다.
- 이벤트 드래그는 Chromium의 실제 포인터 동작으로 관측했다. 외부 `[0]` 텍스트 드롭은 수정 콜백 0회, 목록 재렌더 후 명령 드롭은 이전 콜백 0회/현재 콜백 1회였다. 감독자가 결과 이미지와 관측 범위를 직접 확인했다.
- 브라우저 증거와 재현 스크립트: `verify-shots/event-drag-audit/`. 최소 스타일을 사용한 격리 컴포넌트이며 명령 저장·되돌리기·전체 모달·정본 재로드의 실행 근거는 아니다.
- 참조 삭제, 원본 보존/취소, 드래그 소유권, 레거시 페이지, 호출 그래프, 저장 피드백의 회귀 테스트 소스를 추가·보완했다.
- 최종 독립 코드 리뷰에서는 추가로 재현 가능한 차단 결함을 발견하지 못했다. 변경된 TypeScript 20개 파일의 구문 파싱 오류는 0개이며 `git diff --check`도 통과했다. 구문 검사는 타입·동작 검증이 아니다.
- 저장소 지침에 따라 단위 테스트, 게이트, 타입 검사는 실행하지 않았다. 테스트 소스가 추가됐다는 사실을 통과 근거로 사용하지 않는다.
- 실제 사용자 프로젝트나 원격 저장소는 수정하지 않았다. 이 변경은 편집기 코드 개선이며 전체 기능의 무결함이나 실제 저장소 왕복 성공을 주장하지 않는다.

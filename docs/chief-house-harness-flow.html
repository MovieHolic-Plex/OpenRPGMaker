촌장 집 하네싱 — 쉽게 보기

“주문 메모 → 바깥 ㄱ자 집 찍기 → 안 L자 도면 → 칩셋 타일로 시공 → 문 연결 → 저장” 순서입니다. 아래 타일 그림은 실제 프로젝트 칩셋을 잘라 보여 줍니다.

한 줄 요약

데모가 0번 집 = 파란돌 + ㄱ자 외관 + ownerName/program 명시로 적어 두면, 코드가 바깥은 Combined Town으로 ㄱ자를 찍고, 안은 Interior 칩셋으로 진짜 L 바닥(오른쪽 아래 비움)을 채운 뒤 문으로 이어 붙입니다.

외관 지붕 외관 벽 주방 돌바닥 나무 바닥 화덕 침대

1. 주문 (데모 스크립트)

공사 지시서에 이렇게 적혀 있습니다.

  • 집 0번 키트: blue-stone
  • 집 0번 모양: templateId: "l" (ㄱ자)
  • NPC 0번 이름: 촌장 로안
  • seed: 77, 실내/문 이벤트 켜기

파일: scripts/build-editor-demo-village.mts

쓰는 칩셋

바깥 = Combined Town

2. 바깥집 찍기 (ㄱ자 외관)

마을 맵에 ㄱ자 템플릿만 골라 찍습니다. 세로 날개 + 가로 날개 두 덩어리입니다. 

wings:
  [x, y, 3×8]  // 세로
  [x+3, y, 3×6] // 가로 팔

housePlans[0].templateId === "l" 이면 다른 직사각 후보는 전부 건너뜁니다.

3. 안집 성격 정하기

program 필드

housePlans[0].program = "manor" (1급)

이름 정규식은 폴백. 데모는 ownerName/program을 직접 넣음.

층수 보고

stories = 1 → scale = cottage-l

2층 이상 manor만 큰 mansion

벽 재질

1F cottage-l → 키트 벽 (blue-stone=stone). gold-brick은 mansion(2F+)만.

크림 벽면 골드 리틴트(맨션)

5. 타일 시공 순서

floor

방 마스크대로 바닥 칠하기. SE는 안 칠함 → L 유지.

돌 12 나무 72
walls

바닥 바깥에 벽 링 1칸. 껍데기도 L.

다크월 366 벽면
furniture

방 테마마다 가구.

화덕 위 21 화덕 아래 51 모닥불 124 침대 L 355 침대 R 356 탁자 325 통 205 상자 295
entrance

남쪽 홀 문에 출구 이벤트. 마을 문 앞 칸으로 돌아감.

파이프라인: plan → floor → walls → furniture → entrance → critique

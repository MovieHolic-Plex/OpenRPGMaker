비표준 키를 허용한 이벤트 도구 검증의 허점과 요청 범위를 벗어난 배열 재정렬은 미해결이다. 이 빈 키를 정상적인 commands로 간주하거나 전체 동일이라고 보고하지 않는다. 기존storyFlag 설명 수정 기능도 여전히 없으며 내부 설명의 옛 지명은 남아 있다. [전용 플레이어](saesol-camp-names-play-548-proof.json)에서는 ‘새솔마을’ 보급 메뉴,일지,완료 후 재보고 무보상과 페이지 오류0을 확인했다.

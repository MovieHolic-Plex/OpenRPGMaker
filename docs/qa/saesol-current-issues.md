## 해결했거나 범위를 확인한 문제

- **라이벌 캐릭터 누락:** AI가 리소스 ID 자리에 엔진 `textureKey`를 넣었다. 등록된 업로드 캐릭터로 수정하고 실제 필드 표시를 확인했다. 이후 플레이어와 구분되도록 08번 칩을 사용했다.
- **트레이너를 야생으로 소개:** `trainerBattle`을 먼저 판정하도록 런타임을 수정했다. 전용 플레이어의 전환 완료 화면과 운영 번들 일치를 확인했다. PR #1437이 main에 병합됐다.
- **잘못된 전투 배경·아이템 안내:** 관문의 눈밭 배경을 풀밭으로 수정했다. 만능약이 마비를 치료한다는 잘못된 안내도 실제 DB 효과에 맞게 고쳤다.
- **완료 플래그 누락 오인:** 오래된 운영 워커가 전투 결과 분기의 스위치 쓰기를 찾지 못했다. 실제 이벤트를 불필요하게 다시 쓰지 않고 워커 검사 경로를 갱신했다.
- **일지 누락·긴 문장 겹침:** 누락 일지를 연결하고 표시·스크롤을 수정했다. 현재 총 12개 퀘스트이며 실제 완료 기록과 대조했다.
- **검증 도구의 오래된 접근칸:** `(24,19)`로 접근하지 못한 깃털 관찰점은 `(23,18)`에서 정상 조사됐다. 지도 수정이나 순간이동 없이 실제 도보로 확인했다.
- **검증 도구의 잘못된 보상 가정:** 라이벌 첫 전투의 정상 기본 보상 220G를 오류로 판단했던 검사를 고쳤다. 기본 전투 보상과 최종 퀘스트 보상을 구분한다.

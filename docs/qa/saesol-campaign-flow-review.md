## 그대로 버그로 채택하지 않은 의견

- AI는 진석의 생태조사 조건을 “은닉”이라고 평가했다. 실제 `sr2_gym_leader`는 조사원(18,6)→숲 세 단서→수현(18,28) 보고를 명시하므로 숨겨진 조건이라는 주장은 과하다.
- 해일의 광산/등대 조건과 세하의 유적 조건도 실제 실패 분기에 안내 대사가 있다. 이를 즉시 진행 불능으로 분류하지 않는다. 안내가 플레이어에게 충분한지는 정상 플레이의 별도 평가 대상이다.
- 선택 의뢰를 “10개”로 묶었지만 목록은11개이며 생태조사처럼 본편 선행인 것도 포함한다. 분류/개수를 그대로 인용하지 않는다.
- AI의2.5~3시간은 실측 없는 추정이다. 완료 판정 근거로 쓰지 않는다. 콘텐츠 수나 자동 입력 시간으로 인간 플레이 시간을 대체하지 않는다.

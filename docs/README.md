# docs/ — 시점 기록 아카이브

이 폴터는 **시점별 기록·증거 아카이브**다. 여기 있는 문서를 현행 설계 문서로 신뢰하지 말 것.

## 현행 문서는 어디인가

- 에이전트용 프로젝트 위키(정본): `openwiki/` — `AGENTS.md`의 읽기 순서를 따른다. AGENTS.md 규칙상 코드 변경과 같은 변경 단위에서 갱신하도록 되어 있다 (실제 갱신 여부는 최근 커밋으로 판단).
- 디자인 시스템: `DESIGN.md` (shipped 상태를 기술하는 source of truth).
- 사용자용 실행법: `README.md`.

## 이 폴터의 문서 분류 규칙

- **파일명에 날짜가 있는 것** (`2026-07-07-*.md`, `2026-07-18-*.html` 등): 작성 시점의 리뷰·크리틱·증거 스냅샷. 의도적으로 freeze된 기록이며 갱신되지 않는다.
- **자동 생성물**: `tool-catalog.md` — `src/editor/tools/` 레지스트리에서 파생. 직접 편집 금지, 재생성으로 갱신.
- **날짜 없는 문서**: 상단에 `Status:` 헤더가 없으면 상태 미검증으로 간주한다. 코드 근거 없이 인용하지 말 것.

새 리뷰/증거를 추가할 때는 파일명에 날짜를 붙인다. 살아있는 설계 지식은 여기가 아니라 `openwiki/` 해당 페이지에 반영한다.

## Observed Theme Buckets

These buckets are title/body-derived research tags used for proposal synthesis. They are intentionally broader than the Indiside categories because RPG ZZU should absorb useful authoring patterns into native editor workflows rather than clone plugin syntax.

- Event authoring and text/input UX: Cutscenes, enhanced message controls, face/name text, keyboard/numeric input, choice helpers, event-command utility articles.
- Quest and achievement systems: Quest logs, persistent quest markers, achievement/trophy systems, and menu-visible progress records.
- Map presentation and dynamic maps: Layer maps, dynamic tile mutation, mirrors/reflections, overlays, map-bound pictures, minimaps, map names, zoom, and transition effects.
- Movement and interaction primitives: 8-direction movement, half-tile movement, followers, footsteps, jump/side-scroll movement, proximity/pathfinding, and event auto tracking.
- Database-backed gameplay systems: Crafting, item limits/categories, storage, shops, enemy books, troop/enemy count extensions, and stat/battle metadata.
- Runtime options and persistence: Autosave/save slots, preload, input device support, mobile pads, controller/mouse helpers, and project-level options.
- Battle presentation and rules: Battle HUD, damage popups/localization, ATB/action sequences, battle fog/weather, battle member swap, and enemy layout scaling.
- Localization and Korean authoring polish: Korean name input, Korean particles, font/outline/shadow text, Korean database data, and readable text presentation.

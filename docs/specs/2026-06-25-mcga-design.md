# Make Chosun Great Again (MCGA) — 기획 디자인

> **장르:** 웹 기반 멀티플레이 정치·전략 숏폼 (문명식 + 조선 역사 배경)
> **핵심 한 줄:** AI가 왕, 사람이 신하. 동아시아 역사 제국들 틈에서 조선을 부흥시켜 천하를 통일하라. 3~5분 접속, 사약·반정·망명이 도는 지속형 세계.
> **상태:** 기획 확정 (MVP 스펙) · 2026-06-25

## 0. 핵심 결정 요약

| 결정 항목 | 선택 | 이유 |
|---|---|---|
| 왕-신하 관계 | 협력(PvE) + 다른 왕 명령 받는 멀티 | 왕=AI, 신하=사람, 복수 왕국 경쟁 |
| 사형/징벌 의미 | 일상=징벌(강등/투옥/몰수), 사약=캐릭터 사망+새 신하 부활(명성 손실) | 징벌은 캐릭터 보존, 사약은 죽음(재출발) |
| 진행 리듬 | 지속형 세계(24시간 자동) + 숏 단위 접속 | 자주 접속 유도, 롱 턴 배제 |
| 국가 흥망 | 영토 점령식 (문명/RoK) | 점진적 몰락 → 난민·망명·반란 연쇄 |
| AI 왕 구조 | 하이브리드 (코드=전략, GPT=성격 판결) | 공정성 + 성격, 비용 통제 |
| 신하 역할 | 듀얼 (평시 부문 / 전시 영토 통제) | 부문 갈등 + 전쟁 직접 통제 |
| 종료 조건 | 통일 엔딩 + 시즌제 | 목표 + 재플레이성 |
| 멀티 아키텍처 | 서버 오케스트레이션 + 폴링 | GPT 키 보호, 세계 틱, 공정성 |
| 스케일링 | 단일 월드 + 역사 세력 다수 | 사람 늘면 세력 증가, NPC는 코드 봇 |
| 렌더링 | 인라인 SVG + CSS | 빠른 MVP, 자원 최소 |

## 1. 핵심 루프 & 세계 리듬

### 백그라운드(지속 세계) + 포어그라운드(숏 경험) 분리
- **세계는 24시간 자동 진행.** 자원·병력·연구·외교가 서버 세계 틱으로 갱신. 내가 안 봐도 감.
- **왕의 조회 판결**: 정해진 주기(예: 현실 1~2시간)마다 AI 왕이 사건 심판 — 포상/징벌/사약/명령 하달.
- **봇 인계**: 사람이 접속 안 한 자리는 봇(코드 or LLM)이 즉시 채움. 게임이 절대 멈추지 않음.

### 숏 단위 (60~90초, 포어그라운드)
```
접속 → 쌓인 사건 중 "이번 숏" 1개 선택
  ├─ 왕 등장 + 상황 브리핑 (LLM 대사)
  ├─ 내 선택 (탭 A/B/C 또는 짧은 입력)
  ├─ 즉시 결과 + 다른 신하 반응
  ├─ 왕의 판결 (포상/징벌/사약)
  └─ 다음 숏으로 스와이프
```

### 핵심 훅
- 접속 보상이 숏 단위로 즉시 떨어짐 → 자주 접속 유도.
- 비접속 사건 = "놓친 조회" 하이라이트 피드로 짧은 컷 회수 ("다녀오니 왕이 다른 신하 사약 내림").
- 문명식 축(내정/군사 등)은 이번 숏의 주제로 압축 — 한 숏엔 한 축.

### 사약(사형) vs 징벌 (정확한 효과)
| 조치 | 효과 |
|---|---|
| 징벌(강등/투옥/몰수) | 캐릭터 보존. 관직 강등, 공명(명성) 감소, 곡물/재산 몰수. 일상적. |
| 사약(사형) | **캐릭터 사망.** 플레이어는 같은 세력에 새 신하로 부활, 공명은 일부 손실. 하드 리셋이지만 영구 밴은 아님. 명분 점수 임계치 도달 시에만 코드가 승인. |
| 추방(망명) | 조정 멸망 시 자동. 살아남은 다른 세력에 투항 or 새 세력 건국. 사약보다 덜하지만 원 소속에게 보복 위험. |

> 핵심: 사약은 "이 캐릭터의 죽음"이지 "플레이어 밴"이 아님. 즉시 새 신하로 재출발 → 패널티는 크지만 게임 오버는 아님.

### 시즌
- 1~2주 = 1시즌(역사). 통일 시 즉시 종료 + 승리 정산.
- **통일 조건**: 한 세력이 전체 고을의 **과반(>50%)** 점령 + 나머지 7개 세력 전부 멸망(또는 속국화). 교착 방지.
- 미통일 시 기간 만료 종료. 시즌 보상(명성/타이틀/스킨) → 세계 리셋 → 새 시즌.
- 새 시즌마다 AI 왕 성격·지도 배치 변주.

## 2. 국가(조정) & 영토(고을) 시스템

### 모델
```
조정 (Nation)
 ├─ 왕 (1명): 사람 or AI. 성격 결정.
 ├─ 신하단: 사람 + 봇 혼성
 │    ├─ 영의정(내정), 병조판서(군사) — 부문 담당
 │    └─ 수령들 — 할당된 고을 통치
 └─ 고을들 (1~K개): 점령식으로 흥망
      └─ 각 고을: 인구/곡물/병력/전투력 보유
```

### 고을 = SVG 헥스/타일 그리드
- 세계 = 큰 SVG 그리드. 각 칸 = 고을.
- 고을 색 = 소속 세력 색. 점령 시 색 전환(즉시 시각 피드백).
- 미니멀 아이콘: 인구/병력/자원량.
- 수도 = 별표. 수도 함락 = 세력 위기.

### 멸망 조건 (점령식)
1. 고을을 모두 잃으면 → 조정 멸망.
2. 왕 폐위/사망(퇴장). AI 왕 종료, 사람 왕은 관전자 or 새 왕 부활.
3. 소속 신하 전원 → 실직 망명 신분:
   - 살아남은 다른 세력에 투항
   - 난민으로 새 조정 건국
   - (드물게) 왕을 따라 망명 정부

### 신하 듀얼 역할
- 평시: 부문 담당 (영의정=내정, 병조판서=군사).
- 전시: 전쟁 중인 고을에 직접 군사 통제(병력 배치/공격/철수).
- 왕이 전시에 누구에게 군사 통제를 줄지도 판결 항목.

### MVP 단순화
- 부문: 2개만(군사 + 내정). 외교/학술은 시즌2.
- 신하 1인당 부문 1개 + 고을 0~1개.

## 3. AI 왕 두뇌 (하이브리드) + 멀티플 아키텍처

### 3-A. 뼈대와 살의 분리
```
결정론적 엔진 (코드)
  전투 결과, 세금, 곡물, 영토 점령, 역병...
  → 공정·예측 가능. GPT 안 씀.
                ▲ 수치·사실
                │
왕의 전교/사약 (GPT 5.4 mini)
  "이 신하의 소행을 어찌 평가하느냐?"
  "이 전쟁(왜란/호란)에 출병할까?"
  "포상, 징벌, 사약, 방기?"
  → 왕 성격 프롬프트로 개성
```

### 왕 성격 3종 (MVP) → 역사적 왕 매핑
| 성격 | 왕 | 판결 경향 |
|---|---|---|
| 잔혹한 폭군 | 연산군 | 실패=사약 선호. 공격적 확장. |
| 자비로운 성군 | 세종대왕 | 실패=관대. 직언 포상. 무능엔 엄격. |
| 편집증 왕 | 인조(반정주) | 공로신 의심. 처결 빈도 높음. |

### 사형 안전장치
사약은 GPT가 선고해도 **코드가 최종 승인**(명분 점수 임계치). 왕이 막 사약 못 내림 → 공정성 유지.

### GPT 호출 시점 (비용 통제)
- 조회 판결 주기(1~2시간)마다 batch 판결.
- 긴급 숏 트리거(침공/반란) → 즉시 판결 1건.
- 미시 결정(자원/전투)은 코드 실시간.

### 프롬프트 구조 (MVP)
```
[SYSTEM] 당신은 {왕 이름}, {성격}의 군주다.
현재 세력 상태: {코드 생성 요약 - 자원/전쟁/신하 성과}
최근 사건: {쌓인 이벤트 리스트}
[USER] 다음 신하들의 행동을 평가하고, 각각 포상/징벌/사약/방기 중
        하나를 판결하라. 이유를 한 줄로 대사로 말하라.
[OUTPUT → JSON] { 신하ID: { 판결, 이유대사 } }
```

### 안전장치
- GPT 출력 정해진 스키마(판결 enum + 대사)로 강제 (JSON 모드/function calling).
- 시스템 위반(자원 부족인데 포상) → 코드 보정 또는 징벌 강제 하향.

### 3-B. 멀티플 아키텍처 (서버 오케스트레이션)
```
브라우저 (SVG 클라이언트)
  상태 표시 + 행동 제출           폴링 (수 초 간격)
               │ REST/JSON
               ▼
API 서버 (Node / Edge function)
  ├─ 행동 검증 + 적용
  ├─ GPT 왕 판결 호출 (키 보호)
  └─ 봇 인계 로직
               │
               ▼
Postgres (Supabase)
  세계 상태 = 단일 진실
  + 세계 틱 워커 (cron/scheduled)
```

### 핵심 설계 원칙
1. 서버가 단일 진실(source of truth). 클라는 thin client.
2. 세계 틱 워커가 서버에서 자동 실행 → 아무도 접속 안 해도 세계 변함.
3. GPT API 키는 서버에만.
4. 동기화: MVP엔 폴링. WebSocket은 시즌2.
5. 부모 리포의 Supabase 재사용 → 인프라 비용 절감.

### 세계 틱 (예: 5분 간격, 서버 cron)
```
1. 자원/병력/연구 갱신 (코드)
2. 진행 중 전쟁 틱 처리 (코드)
3. 봇 신하/봇 왕 행동 결정 (코드 or LLM)
4. 조회 판결 주기 도래 시 → GPT batch 호출
5. 사건 로그 저장 → 클라이언트 폴링으로 소화
```

## 4. 신하 & 부문 행동

### 듀얼 역할
평시 → 부문 담당 (영의정=내정 / 병조판서=군사)
전시 → 전쟁 중인 고을에 직접 군사 통제 권한

### 부문 행동 카드 (MVP 2개 부문)

**내정 (영의정)**
| 행동 | 효과 | 리스크 |
|---|---|---|
| 세율 올림 | 세수 ↑ | 민심 ↓ (반란 위험) |
| 곡물 징수 | 군량 ↑ | 민심 ↓, 기민 발생 |
| 치수·양잠 | 장기 자원 ↑ | 즉효 없음 → 왕의 인내 시험 |
| 진휼(기민 구제) | 민심 ↑ | 재정 ↓ |

**군사 (병조판서)**
| 행동 | 효과 | 리스크 |
|---|---|---|
| 징병 | 병력 ↑ | 민심 ↓, 곡물 ↓ |
| 훈련 | 전투력 ↑ | 시간 소요 |
| 출병 (전시만) | 인접 고을 공격 | 패전 = 병력 손실 + 왕의 진노 |
| 철수/수비 | 병력 보존 | 영토 상실 가능 |

### 숏 안에서 행동 제출
한 숏은 하나의 결정만 요구. 부문 전체를 한 번에 안 봄.
```
이번 숏의 주제: "왜군 쳐들어옴 (병조판서 숏)"
  왕(연산군): "병조판서, 어찌 할 터이냐. 출병이냐, 화친이냐."
  ① 출병 (병력 200 소모, 승률 65%)
  ② 화친 (곡물 500 바침)
  ③ 회피 (시간 끌기, 왕 분노)
  → 내 선택 → 즉시 결과 → 왕 판결 (포상/징벌/사약)
```
행동 옵션마다 코드가 미리 승률/비용을 계산해 표시. GPT는 결과 해석 + 판결만.

### 봇 인계 시 행동 결정
| 자리 | 봇 결정 방식 |
|---|---|
| 영의정(내정) 봇 | 코드 규칙: 재정 부족→세율↑, 민심 위험→진휼 |
| 병조판서(군사) 봇 | 코드 규칙: 위협 감지→징병, 전쟁 시 승률 60%↑ 출병 |
| 왕 봇 | LLM (핵심이니까). 성격 프롬프트로 판결 |
| 사람이 돌아오면 | 봇이 내린 최근 결정을 "놓친 하이라이트"로 브리핑 |

### 숏 생성 흐름
```
접속 → 서버가 "이 플레이어에게 줄 숏" 결정
  ├─ 긴급 숏 우선 (내 부문 관련 사건)
  ├─ 없으면 일상 숏 (왕의 일상 명령, 동료 신하 이벤트)
  └─ 숏 1개 반환 → 플레이어 결정 → 결과+판결 즉시
```

## 5. 숏(Short) & UI 흐름

### 메인 화면 = 숏 피드 (세로 스와이프, TikTok식)
```
┌─────────────────────────────────┐
│  조선 제7년 · 세종(왕) 치세      │  헤더 (시대/왕)
├─────────────────────────────────┤
│   ┌─────────────────────┐       │
│   │  👑 세종             │       │  왕 초상 (SVG)
│   │  "병조판서, 왜군이   │       │  LLM 대사 (말풍선)
│   │   부산을 침공했도다. │       │
│   │   어찌 할터이냐?"    │       │
│   └─────────────────────┘       │
│   📍 부산진 (적병 300)           │  상황 브리핑 (코드 요약)
│   ⚔️ 내 병력 200 · 승률 55%     │
│   ┌─────────────┐               │
│   │ ① 출병 (55%)│ ← 카드 탭     │  행동 옵션 (비용/확률)
│   ├─────────────┤               │
│   │ ② 화친(500) │               │
│   ├─────────────┤               │
│   │ ③ 철수·수비 │               │
│   └─────────────┘               │
│     [한 고을 더] [왕께 아뢰기]   │  하단 액션
└─────────────────────────────────┘
   ↑ 다음 숏으로 스와이프 ↑
```

### 숏의 4단계 라이프사이클
```
① 브리핑   왕 등장 + 상황 (코드 요약 + LLM 대사)
② 선택     탭 A/B/C (코드가 비용·확률 미리 계산 표시)
③ 결과     즉시 결정 (코드) + 다른 신하 반응 (LLM 단문)
④ 판결     왕이 포상/징벌/사약 선고 (LLM, 코드 승인)
```

### 비접속 사건 = "놓친 조회" 피드
```
┌─ 놓친 조회 (3시간 전) ──────────┐
│ ⚠️ 잠수 중 사건                 │
│ • 왜군이 부산 점령 (병조판서   │
│   봇이 화친 선택 → 곡물 500손실)│
│ • 동료 영의정, 세율 인상 건의   │
│ • 왕, 병조판서(나) 징계 경고 🔔 │  ← 나 관련
└──────────────────────────────────┘
[대응하기] [넘기기]
```

### 화면 구성 (MVP 최소 4개)
| 화면 | 설명 |
|---|---|
| 숏 피드 (메인) | 세로 스와이프, 한 숏씩. 90% 체류. |
| 팔도 지도 | 상단 탭. SVG 그리드. 내 고을/전쟁 상황 표시. |
| 내 신분 | 내 직책, 공명(명성), 관직, 최근 판결 이력. |
| 시대 현황 | 순위, 시즌 남은 일수, 통일 진행도. |

### SVG 활용
- 왕 초상: SVG 일러스트 (성격별 3종 고정). 애니메이션은 CSS.
- 팔도 지도: SVG 헥스/타일 그리드. 고을 색 = 세력 색.
- 말풍선/카드: HTML + CSS. 무거운 프레임워크 안 씀.
- 아이콘: 인라인 SVG (⚔️🏛️🌾). 이모지 fallback.

### 어그로 요소 (UI)
- 사약 알림: 푸시 + 빨간 전체화면 "사약이 내려졌습니다".
- 시즌 종료: "역사는 그를 이렇게 기억한다" + LLM 생애 요약.

## 6. 세계 구성 & MVP 범위 & 기술 스택

### 6-A. 세계 구성: 단일 공유 월드 + 역사 세력 다수

**단일 월드.** 조선만 있는 게 아니라 동아시아 역사 세력들이 한 맵에 공존.

```
              ┌─────── 명(明) ───────┐
              │    (거대 제국, 중앙)   │
              ├──┬────────┬──────────┤
        여진/   조선    왜(일본)    류큐
        건주   (고립     (전국란    (조공
        (북쪽)  반도)    후통일)    교역)
              │
        안남/   참파  캄보디아
        베트남 (남쪽 해안)
```

### 역사 세력 (8종, 문명식 보너스 + 역사 고증)
| 세력 | 위치 | 특성/보너스 | 역사적 훅 |
|---|---|---|---|
| 조선(플레이어 기본) | 반도 | 균형형, 방어전 강함 | 이순신/거북선, 임란 방어 |
| 명(明) | 서북 거대 | 압도적 영토/병력, 단 느림 | 조공 요구, 느슨한 종주권 |
| 여진/건주 | 북방 | 기병 우세, 약탈 강함 | 훗날 청 건국, 조선 북방 위협 |
| 왜(일본) | 동쪽 섬 | 해전/침략 공격적 | 임진왜란 주적, 해상 강함 |
| 류큐 | 남쪽 섬 | 교역/외교 강함, 군 약함 | 조공-교역 중계국 |
| 안남/베트남 | 극남 | 게릴라 방어, 쌀 생산 | 남북조 혼란, 명의 남진 저지 |
| 참파 | 베트남 남부 | 해상 교역, 소국 | 안남에 흡수되는 위기 소국 |
| 몽골/북원 | 초원 | 기병 최강, 내란 많음 | 명과 대립, 조선에도 압박 |

### 비용의 핵심 원칙
> **LLM 왕은 "사람이 소속된 세력"에만 둔다.** 사람 없는 NPC 세력은 코드 봇 왕.

- 사람 플레이어가 있는 세력 수 = LLM 비용의 유일한 결정 인자.
- 수백 개 NPC 세력(또는 NPC 동세력 빈자리)은 GPT 한 푼 안 쓰고 코드로 굴러감.
- → 플레이어가 수백 명이 돼도 LLM 비용은 사람 있는 세력 수에만 비례. 1인당 비용 안정.

### 플레이어 배치 흐름
```
신규 플레이어 접속
  ├─ 초대 코드 O → 그 세력에 신하로 합류 (빈 자리 있을 때)
  ├─ 초대 코드 X →
  │    ├️ 사람 부족 세력에 자동 배정 (봇 자리 인계)
  │    └️ 또는 빈 땅에 새 세력 건국 (NPC 세력 틈에 끼어듦)
  └─ 모든 경우 내 세력의 왕은 LLM (사람 있으니까)
```

### 플레이어 기본 = 조선
- 입장 시 기본 조선, 다른 세력 선택 가능(명·왜 등).
- 어그로 제목과 정합: "Make Chosun Great Again" = 주변 제국들 틈에서 조선 부흥.

### 6-B. MVP 범위 (In/Out)

**In (시즌 1 / MVP)**
| 항목 | 범위 |
|---|---|
| 왕 성격 | 3종 (연산군/세종/인조) |
| 부문 | 2개 (내정·군사) |
| 관직 | 영의정, 병조판서 (세력당 2~3명) |
| 고을/영토 | 세력당 1~3칸, 전체 맵 수십~100+ 칸 |
| 세력 | 8개 역사 세력 (사람 조정 소수 + NPC 조정 다수) |
| 신하 1인 | 부문 1개 + 고을 0~1개 |
| 숏 타입 | 전쟁, 세금, 곡물, 반란, 외교제안 (5종) |
| 봇 인계 | 일반 신하=코드, 왕=LLM |
| 동기화 | 폴링 |
| 인증 | 간단 닉네임 (소셜로그인은 시즌2) |
| 초대 코드 | 특정 세력 입장 (포함) |

**Out (시즌 2+)**
- 부문 확장(외교/학술), 당색(정파) 시스템, 인척/혼인
- WebSocket 실시간, 소셜 로그인, 랭킹/리그
- 사약 외 사형 종류, 투옥·유배 단계 세분화
- 사람 왕 모드, 세력 내 계층화(정승-참판-수령-말단)

### 6-C. 기술 스택 (MVP)
| 계층 | 선택 | 이유 |
|---|---|---|
| 프론트 | Vite + 바닐라 TS + SVG/CSS | 부모 리포 스택 재사용, 무거운 프레임워크 배제 |
| 렌더링 | 인라인 SVG + CSS | 그림 자원 최소, 빠른 MVP |
| 백엔드 | Node (Hono 또는 Express) | 가벼운 API, Edge 배포 가능 |
| DB | Supabase (Postgres) | 부모 리포 재사용, RLS/인증/Realtime 내장 |
| 세계 틱 | Supabase scheduled function (pg_cron) 또는 별도 Node 워커 | 24시간 자동 진행 |
| LLM | GPT 5.4 mini (JSON 모드) | 왕 판결·대사 |
| 배포 | Vercel (프론트) + Supabase (DB/함수) | 서버리스, 비용 최소 |

### 6-F. MVP 성공 기준
1. 접속 → 60~90초 숏 1개 경험 → 판결 → 다음 숏 (루프 작동)
2. 접속 안 해도 세계 틱이 돌아 봇이 채움 (재접속 시 변화 확인)
3. 사약(사형)이 드물지만 발생하고 패널티 작동
4. 8개 역사 세력이 경쟁해 한 세력이 천하 통일하면 시즌 종료 + 정산
5. 전체 흐름이 모바일 세로 화면에서 3~5분 접속 단위로 성립

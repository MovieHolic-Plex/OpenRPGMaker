## 시나리오별 여정 서술

**S1 첫인상/온보딩**: 콜드 진입은 P0 오류 화면(D01). fresh/blank 진입 시 AI 패널은 우측에 크게 자리해 발견성 자체는 좋고, "무엇을 만들까요?" + 스킬 카드 6개 + 입력창 힌트(/, Ctrl+K)로 시작 안내는 준수. 그러나 키 미설정 상태에서 첫 전송이 곧바로 중복 오류+막다른 재시도(D12)로 이어져 첫 5분 이탈 위험이 큼. 경고 배너는 내부 파라미터명을 노출(D14).

**S2 마을 만들기**: 44초 후 "적용됨"인데 화면은 빈 잔디(D02). 프로포절 카드는 도구명 나열(D04), 도중 내부 실패 로그 노출(D15). 결과적으로 "마을"은 이 턴에 만들어지지 않음.

**S3 후속 수정**: 대화 맥락 유지는 됨(이전 계획을 기억) — 오히려 과하게 이월되어 "길만" 요청에 마을 전체 12건이 승인 단위로 묶임(D06). 우물 추가는 성공(집 2채 사이 석조 광장+우물, `s3-well-done.png`)했으나 응답은 내부 용어 벽(D16) + 매 턴 업셀 질문. 수락 전 완료형 서술(D05)이 반복.

**S4 NPC**: NPC는 정확히 배치됐고 이동 시행착오까지 카드에 노출(D17). 생성 후 편집 동선 안내가 전무하고, 기본 모드에서 더블클릭이 무반응(D13). 이벤트 레이어 모드의 목록/에디터 자체는 RM2003 스타일로 완성도 높음.

**S5 적대 테스트**: 모호 요청은 폭주+예산 소진(D09), 불가능 요청은 허위 롤플레이 적용(D08), 대형 요청은 4분+ 무완료(D10), 연타는 무피드백 방치+중단 불가(D07). 실행 중 맵 트리/캔버스 클릭(s5d)은 크래시 없이 견딤(콘솔 에러 0) — 견고성 자체는 합격.

## 가장 먼저 고칠 5개

1. **D07 중단 버튼** — AbortSignal이 이미 있으니 배지 옆 "중단" 하나로 최악의 방치 경험(4분 감금)을 제거. 최소 비용, 최대 효과.
2. **D04 프로포절 카드 재설계** — 전/후 미니맵 썸네일 + 사람 언어 요약. 에이전트 신뢰의 중심 UI가 현재 원시 도구 로그 수준.
3. **D02+D03 첫 턴 경험** — "마을 만들어줘"가 빈 잔디+텍스트 질문으로 끝나지 않게: 질문은 원탭 버튼, 준비-작업만 한 턴은 상태를 정직하게 표기.
4. **D01 콜드 진입 폴백** — 무결성 실패 시 예제 프로젝트 자동 부팅. 첫 화면 P0.
5. **D12 키 온보딩** — 오류 버블에 "설정 열기" 버튼 + 전송 전 사전 점검. 신규 사용자 첫 전송의 막다른 골목 제거.

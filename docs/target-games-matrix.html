4. 12 Phase가 7게임을 어떻게 해금했는지

로드맵 원칙: 각 phase는 대상 게임 1개의 “플레이 가능한 10분 수직 슬라이스”로 검증. A 연출 / B 전투 / C 생활 트랙 병렬 가능.

P1

런타임 코어 + 장면 검증

카메라, spawn/remove, scene test — 전 게임 공통 바닥

P2

컷신 타임라인 → 투더문

script_cutscene, 픽처/오디오 동기, 컷신 락

P3

사망·체크포인트·멀티엔딩 → 호러 공통

트랩, 리트라이, ending graph

P4

조사·퍼즐 저작 → 이브/마녀의집

examine hotspots, puzzle DSL

P5

동행·추격자 → 이브/마녀의집

follower, A* chase, safe zones

P6

분위기 연출 → 호러 완성도

lighting, weather, map animation

P7

전투 코어 확장 → 영웅서기/포켓몬

strict 턴, 교체, 보스 이벤트

P8

성장·직업·사냥 → 바람의 나라

승급, 보상 정책, 필드 스폰

P9

몬스터 수집 → 포켓몬

species/instance, capture, evolution, typeChart

P10

시간·농사 → 스타듀 1

GameTime, farmPlots, crops

P11

생활·NPC 사회 → 스타듀 2 / 바람

스케줄, friendship, 계절 상점

P12

대형 월드 + 익스포트

worldGraph, web player bundle, (Tauri 후속)

해금 맵: 투더문 2–3 · 이브 3–5 · 마녀의집 3–6 · 영웅서기 7(+8) · 포켓몬 7+9 · 바람 8+11+12 · 스타듀 10–11

5. 2026-07-09 성적표 하이라이트

자연어 원큐, 후속 지시 없음, M8 배포본 기준. 총평: DB/시스템형은 강하고, 공간+이벤트 복합(실내 공포)이 가장 어려움.

원큐 결과

포켓몬완주 84s종 3 + 타입 + 스타터 + 진화
스타듀완주 175s밭 + 농가 내부 + 농부
영웅서기완주 180sstrict + 보스 페이지 + 맵 스펙
바람의 나라부분 173s사냥터 지형 OK · 승급 NPC 미완
투더문부분 150s컷신 OK · NPC 순서 꼬임
마녀의 집부분 534s루프 도달 · 외벽 품질↓
이브0건 104s설명만 종료 · 재킥 미발화

당시 결론 (지금도 유효)

  • 병목은 기능 부재보다 툴/패턴 선택과 저수준 인자 마찰
  • 전투·수집·농사 같은 DB/시스템 요구는 안정
  • 실내 공포(벽 라인, 조사 밀도, 오케스트레이션)가 최약
  • 서사/의미 계층·도메인 컴파일러 우선 전략과 일치
2026-07-15 기준으로 엔진 슬롯은 더 두꺼워짐: 몬스터 케어, 우정도 프레젠테이션, 생일 보너스, 상점 할인, 포켓몬 전투 UI 다듬기 등.

6. 7게임 ↔ 현재 제품 표면 매핑

사용자가 지금 에디터에서 “어떤 문”으로 들어갈 수 있는지.

웰컴 칩 → 목표 게임

칩직접 대응간접 대응
포켓몬 같은 몬스터 수집 포켓몬 바람(사냥) 일부
디지몬 같은 파트너 육성 (7종 외 인접축) 포켓몬 케어/진화/유대
스타듀 같은 농장 생활 스타듀 밸리 바람 생활 루프
모험 JRPG 영웅서기 제로 바람 성장/던전

칩에 없는 목표: 투더문 · 이브 · 마녀의 집 — 자유 입력 또는 전문가 툴로 진입.

지금 “어떻게든 구현 가능” 쪽

  • 포켓몬 수직 슬라이스 (스타터→풀숲→포획→진화)
  • 스타듀 수직 슬라이스 (밭→수확→선물→상점)
  • 영웅서기식 마을/필드/보스 10분

반쯤 — 수동/다턴이면 됨

  • 투더문식 회상 컷신 + 엔딩 분기
  • 마녀의집 트랩/체크포인트 루프
  • 바람 사냥터 + 승급 1차

아직 먼 쪽 (제품 비목표 포함)

  • 이브 갤러리 원큐 자동 생성
  • 스타듀 풀 라이프심(결혼·축제 시뮬)
  • 포켓몬 온라인 교환 / 바람 MMO성

7. 한 장 결론 + 다음에 밀 축

한 장 결론

예전에 목표로 박은 건 장르 4개가 아니라 레퍼런스 게임 7개였습니다. 그중 포켓몬·스타듀·영웅서기 축은 엔진과 잘 맞고, 호러/연출 축은 “가능은 한데 자동 생성이 약하고”, 바람은 “뼈대는 있는데 스케일 연결”이 남은 일입니다.

수집 가능 농장 가능 JRPG 가능 연출 부분 호러 부분 대형 월드 부분

우선순위 제안 (제품 관점)

  1. 이미 되는 3축을 데모로 고정 — 포켓몬/스타듀/영웅서기 샘플 프로젝트를 “증명 가능한 플레이”로
  2. 호러/연출은 템플릿 컴파일러 — 방 밀도·트랩 루프·컷신 프리셋 (원큐 실패 줄이기)
  3. 바람은 월드 그래프 연결 — 마을↔사냥터↔승급 1줄 파이프라인
  4. 웰컴 칩 확장 여부는 선택 — 투더문/호러 칩을 넣을지, 자유입력으로 둘지

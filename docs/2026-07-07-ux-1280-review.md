# 1280px 폭 에디터 UX 평가 (2026-07-07)

- 대상: `feat/ux-1280` (base 7899181), dev `/?freshProject=1`
- 뷰포트: 1280×800 / 1280×720, 무회귀 기준 1720×900
- 캡처 스크립트: 실측 `getBoundingClientRect` + `scrollWidth-clientWidth` 오버플로
- 증거: `evidence/ux-1280/*.png`

## 근본 원인

1. `src/editor/panels/editor.ts` `LEFT_PANEL_DEFAULT_WIDTH = 526` — 뷰포트 폭과 무관한 고정 기본값.
2. `applyLayout()`의 좌패널 상한식 `min(leftWidth, max(184, innerWidth-420))` 가 **AI 도킹 인셋(404px)을 반영하지 않음**. 따라서 좌 526 + AI 404 + 리사이저 6 = 936px 를 먼저 먹고 캔버스에 344px 만 남김.
3. AI 도킹 인셋 `--ai-docked-panel-inset: calc(min(400px,46vw)+4)` = 1280에서 404px. 좁은 화면에서도 축소 없음.

## 결함 목록 (심각도)

### [치명] C1 — 캔버스 가시폭 붕괴 (344px)
기본 상태(AI 도킹 ON)에서 맵 작업 영역이 344px. 좌 팔레트(526)와 AI(404)가 화면의 73%를 점유. 맵을 거의 못 보고 팬/줌 작업 불가 수준. **1순위.**

### [치명] C2 — 확대 툴바 잘림 (112px overflow)
캔버스 상단 플로팅 바(`확대 / 1x 2x 3x 4x 6x 8x / 맵저장`)가 344px 캔버스 위에서 우측이 잘림(`8x`·`맵저장` 소실). `overflow` 숨김이라 스크롤도 안 됨. 스크린샷 `before-1280x800-01-default.png`에서 `8` 만 보이고 절단.

### [높음] H1 — 상태바 항목 잘림 (609px overflow)
하단 상태바(모드/맵/타일/도구/줌/DB 연동/편집상태)가 344px 폭에서 609px 넘침. `overflow-x:auto` 라 스크롤은 되지만 DB연동·편집상태·가져오기 셀이 화면 밖. AI 접힘 상태(748px)에서도 205px 넘쳐 마지막 셀 잘림.

### [중간] M1 — 좌 팔레트 과폭 (526px 고정)
팔레트가 1280에서도 526px(화면 41%) 고정. 타일 그리드는 360px 안에서도 충분히 표시 가능. 뷰포트 대비 상한이 없어 캔버스를 압박.

### [낮음] L1 — AI 접힘 레일이 topbar 우측 버튼과 겹침
AI 접힘 시 우측 세로 레일("어시스턴트")이 topbar 오른쪽 툴 아이콘 위로 올라와 일부 겹침(`before-1280x800-02-ai-collapsed.png` 우상단). topbar 자체 오버플로는 0.

### 이상 없음 (평가만)
- **테스트 플레이 모달**: 1280에서 중앙 정렬·비율 정상, 잘림 없음(`-03-testplay.png`). 런타임 스케일 계약 대상 — 미수정.
- **DB 편집기**: 풀폭 모달, 탭 20개 한 줄 수용, 4열 레코드 레이아웃 정상(`-04-database.png`). 미수정(타 스트림).
- **topbar**: 1280에서 topbarOverflow 0, 줄바꿈/잘림 없음.

## 수정 방향 (2단계)

1. **C1/M1** — `editor.ts applyLayout()`: 좌패널 상한을 "실제 usable 폭(= layout.clientWidth − paddingLeft − paddingRight, 즉 AI 인셋 반영) − MIN_CANVAS − 리사이저"로 계산. `MIN_CANVAS_WIDTH` 상수 도입해 캔버스 최소폭 보장. 1720에서는 상한이 526보다 커 무변화(무회귀).
2. **C2** — `.canvas-toolbar` ≤1320px 축약: 버튼 min-width·padding·폰트 축소 + `flex-wrap` 허용(1행 초과 시 2행). "확대" 라벨 축약/숨김.
3. **H1** — `.editor-statusbar-cell` ≤1320px 폰트·패딩 축소, 우선순위 낮은 셀(가져오기 등) 축약 표기.
4. **AI 인셋** — `--ai-docked-panel-inset` ≤1320px 축소(min 360px)로 좌패널 여유 확보. (선택, 좌 팔레트 폭 개선용)

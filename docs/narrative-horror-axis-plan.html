1. 결론 먼저

풀 게임 복제가 아니라, AI가 각 축의 상호작용 패턴을 10분 데모로 컴파일할 수 있느냐가 목표입니다.

핵심 진단: 투더문·마녀·이브는 “없는 엔진” 문제가 아니라 “있는 툴을 한 방에 조립하는 컴파일러/템플릿” 문제입니다. 포켓몬 3축과 같은 방식으로 갭 매트릭스 → 계약 테스트 → 레드팀을 호러/연출 축에도 적용하면 됩니다.

4. 투더문 — 연출 스토리 축

“감동”을 자동화하지 않습니다. 호흡이 있는 컷신 + 엔딩 분기를 안정적으로 컴파일하는 게 목표입니다.

8. 실행 로드맵 (추천 순서)

실패 레버리지 → 맵 품질 → 연출 품질 순. 각 단계는 포켓몬 3축과 동일한 “구현 → 계약 테스트 → 레드팀” 리듬.

Step A · 이브 갤러리 원큐 파이프 (P0)

make_gallery_room + successTools 고정 + walkthrough 골든. 원큐 0건 → 부분/완주 전환이 목표.

Step B · 마녀 호러 루프 + 실내 QA (P0)

interior 벽/방 그래프 수리, make_horror_loop, 사망/성공 경로 scene_test.

Step C · 투더문 컷신/엔딩 프리셋 (P0–P1)

beat 프리셋 + 타이밍 lint + ending walkthrough matrix.

Step D · 3축 계약 테스트 + 레드팀

narrativeHorrorVerticalSlice / narrativeHorrorRedTeam — 포켓몬 3축 스위트 대칭.

Step E · 웰컴 칩 · 프롬프트 프리셋 (선택)

story-cutscene / horror-mansion / investigation-gallery.

Step F · 데모 프로젝트 LegacyDb 저장 (콘텐츠 단계)

툴 파이프가 안정된 뒤 10분 데모 3종 원격 저장 + 재로드 증명. AGENTS 하드 룰 적용 구간.

지금 해도 됨

엔진/툴 작업

템플릿 툴, lint, 테스트 — LegacyDb 콘텐츠 저장 의무 없음 (AGENTS 예외).

파이프 안정 후

데모 콘텐츠

맵·이벤트 저작물은 원격 저장 + 재로드 필수.

하지 말 것

풀 클론 환상

장편 캠페인, OS 메타, 상용 아트 파이프를 원큐 목표로 잡지 말 것.

9. Ultragoal 스토리 초안 (G004–G006)

포켓몬 3축(G001–G003) 패턴을 그대로 복제. 실행 승인 전 초안.

G004P0

조사·호러 템플릿 감사 & 갭 클로즈

이브/마녀/투더문 툴 인벤토리, 실내 QA 갭, 오케스트레이터 부재 목록. 누락 상위 툴만 구현 + unit. 산출: gap matrix 아티팩트.

G005P1

수직 슬라이스 계약 테스트

(1) 회상 컷신+엔딩 (2) 트랩→체크포인트→추격 (3) 갤러리 조사+퍼즐+게이트. headless scene_test / walkthrough 우선.

G006P1

레드팀 공격 스위트

타이밍 0 컷신, 체크포인트 없는 트랩, 불능 퍼즐, 핫스팟 0, 추격자 벽 스폰, 엔딩 조건 충돌. pass/fail 매트릭스 아티팩트.

성공 정의 (공통): 자연어/칩 한 방 → 10분 루프 플레이 가능. 품질 게이트 없이 complete 금지. Fail closed on red-team.

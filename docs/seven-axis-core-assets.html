1. 핵심은 “5층 자산 스택”

각 축은 이 다섯 층이 갖춰질 때 원큐로 성립합니다. 타일 미형 밀도는 별층(보류 가능).

L0 Shared
공통 엔진 — 맵/이벤트/스위치·변수/인터프리터/세션/저장 · LegacyDb 프로젝트 행
L1 Runtime
축별 런타임 슬롯 — 몬스터 파티, 시간·농사, 전투 strict, 컷신 락, kill/checkpoint, follower/chase…
L2 Tools
상위 툴 + 템플릿 컴파일러 — primitive 툴 + 원큐 조립기(successTools 고정)
L3 Proof
계약 테스트 · 레드팀 · scene_test/walkthrough — 슬라이스가 깨지지 않음을 증명
L4 Entry

4. 축 × 자산 매트릭스 (한눈에)

“없으면 축이 성립하지 않는” 최소 자산만 적었습니다.

축 10분 루프 런타임 슬롯 핵심 툴 / 템플릿 상태
포켓몬 스타터·포획·진화 species / party / capture / type configure_monster_system 외 강
스타듀 밭·수확·선물 time / farm / crop / gift configure_time_system · farm tools 강
영웅서기 필드·보스 전투 strict battle / troop events set_encounter_table · battle tools 강
바람 사냥·승급·연결 fieldSpawn / promotion / worldGraph make_hunting_ground · define_promotion · world tools 부분
투더문 회상·엔딩 cutscene / picture / ending script_cutscene_preset · define_ending 템플릿
마녀의 집 트랩·리트라이·추격 kill / checkpoint / chase / mood make_horror_loop 템플릿
이브 조사·퍼즐·게이트 hotspot / puzzle / inventory make_gallery_room 템플릿
타일/아트 밀도는 7축 “성립”의 필수 자산이 아닙니다. 원큐 성적의 병목은 대부분 템플릿 조립 · plan successTools · 진입 UX였고, 실내 9-slice는 의도적으로 후순위입니다.

6. “핵심만” 고를 때 — 우선 자산 15

전부 중요하지 않습니다. 7축 커버리지 대비 ROI가 큰 것만.

# 자산 커버 축 왜 핵심인가
1이벤트 인터프리터 + 페이지 조건전체모든 축의 뼈대
2전투 런타임 (strict 포함)영웅서기 · 포켓몬 · 바람전투 축 공통
3몬스터 수집 레이어포켓몬수집 축 전용 슬롯
4시간·농사 런타임스타듀생활 축 전용 슬롯
5컷신 시퀀서 + 엔딩 그래프투더문연출 축
6kill / checkpoint / chase마녀 · (이브)호러 공통
7조사 핫스팟 + 퍼즐 DSL이브 · 마녀조사 밀도
8script_cutscene_preset투더문원큐 조립
9make_horror_loop마녀원큐 조립
10make_gallery_room이브원큐 조립 (실패 축 해소)
11WorkPlan successTools 라우팅연출·호러 3축설명만 종료 방지
12사냥터 + 승급 + worldGraph바람성장월드 연결
13scene_test / walkthrough전체헤드리스 증명
14LegacyDb save+reload전체정본·데모
15웰컴 칩 + 딥링크 UX전체사람이 들어가는 문
한 줄 요약: 7축 핵심 자산 = 공통 엔진 + 축별 런타임 슬롯 7세트 + 원큐 템플릿 툴 + successTools 라우팅 + 테스트/데모 정본. 타일 미형은 “예뻐 보이게” 하는 자산이지, 축 성립의 1차 조건이 아닙니다.

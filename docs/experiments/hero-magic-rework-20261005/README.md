# 주인공 마법 재수정 · 2026-10-05

직전 `snes-study-redraw-20261005` 판은 사용자의 “너무 허접하다 ..” 평가로 반려됐다.
원본과 공개 PNG 사본은 그 폴더의 `rejected-release/`에 보존한다.
이번 판은 사용자의 “그래 뭐 이거 반영하고, 커밋 머징 PR 해라” 요청으로 반영 승인됐다.
`review-decision.json`에 승인 당시 원본/PNG 해시를 묶었다. 픽셀이 바뀌면 재패킹 상태는 검토 대기로 돌아간다.
FF6 장면 관찰은 [앞선 조사](../ff6-reference-study-20261005/README.md)를 따른다.

## 이번에 바꾼 그림

| 기존 공용 스킬 | 변경 | 원본 |
|---|---|---|
| 파이어볼 | 더 긴 불기둥, 갈라지는 내부 명암, 찢어지는 불 조각, 잔불 | `flame_cels.py` |

| 심판의 빛 | 큰 빛의 팽창·갈라짐, 긴 물결 띠 | `aether_cels.py`, `water_band_cels.py` |
| 용권 멸살 | 기존 청록 히드라 원화 유지, 긴 파동 띠와 새 착탄 | `summon-hydra-reuse.json`, 위 빛/물결 원본 |

소환 본체는 **새로 그린 용이 아니다.** 프로젝트의 기존 `pixel-enemies/hydra-three.png`
첫 96px 셀을 사용한다. 명시한 색 치환만 적용했고 원화의 픽셀 위치/투명도를 유지한다.
128px 셀 안 (16,16)에 배치해 1,400ms 유지한다. 날개나 별도 공격 자세를 추가하지 않았다.
이번에 새로 그린 용 초안 두 개도 내부 검토에서 버려 `rejected-*`로 보관한다.
반려된 24종 공용 팩은 재등록하지 않았다.

화염·빙결·번개와 빛의 주요 셀은 직접 쓴 팔레트 문자 행/좌표다. 조각 재사용과 유지 셀이 포함되며,
10장/64칸을 서로 다른 신규 그림 64장으로 보고하지 않는다. 홀리 구슬과 작은 접촉/잔광은 직전 저작을 유지한다.
물결은 128px 폭의 두 띠 원화를 명시한 위치에 반복 배치한다. 어두운 단색 바탕만 32px 평면 타일을 반복한다.
게임 화면에서는 이 128px 배경 셀이 고정 도트 크기로 반복된다.
FF6 스프라이트/소리/ROM을 추출해 사용하지 않았다. 실제 소환 개체 생성은 추가하지 않았다.

## 패킹과 공용 연결

`scripts/asset-gen/pixel-fx/hero_magic_rework.py`가 위 원본을 묶고,
`snes_study_redraw.py`가 완전한 `hand-authored/*.study.px.json`, 공용 PNG 10장,
배경 셀 사본 4장을 패킹한다. 중앙 파일의 이전 그림 상수는 역사이며 활성 교체는 `replacements()`를 따른다.

```bash
python3 scripts/asset-gen/pixel-fx/snes_study_redraw.py --install
python3 docs/experiments/hero-magic-rework-20261005/inspect-assets.py
```

`manifest.json`에 원본/PNG 해시, 노출 시간, 재사용 출처와 검토 상태를 남긴다.
형식 확인: 모든 층의 원본/PNG 픽셀 일치 및 PNG 바이트 재현, 개별 진입점 5개의 RGBA 일치,
native64/128, 이진 알파, 불투명색 3~13색. 미감 승인 근거가 아니다.
개별 키 폴더의 접촉 시트·어두운/밝은/체커 GIF는 원본 셀 검토용이다.
대형 임시 프로젝트 사본과 원본 전투 WebM은 로컬 기록이며 Git에는 포함하지 않는다.
녹화 하네스로 재생성한다. 화면/사건 로그와 최종 전투 GIF는 함께 보존한다.

기존 다섯 공용 프리셋 ID를 그대로 사용한다. 화염의 셀별 노출 시간/설명을 갱신했다.
앞뒤 층·셀별 시간·착탄 시점은 직전 구현을 유지한다. PWA 이미지 캐시는 v11이다.
사용자 프로젝트 정본 SQLite/외부 저장소는 수정하지 않았다. 공용 코드/자산 변경이므로 별도 프로젝트 저장 작업이 아니다.

## 표시 확인

[확인 요약](../../../verify-shots/hero-magic-rework-20261005/SUMMARY.md)을 먼저 읽는다.
실제 전투는 `player.html` + 내보내기 shim + 키보드 입력을 통과한 임시 녹화 사본이다.
소환은 시작 실패를 보존한 뒤 일반 Chromium 설정에서 주인공에게 공용 연출을 연결한 사본으로 확인했다.
원래 무도가 파티의 시작 문제 해결을 의미하지 않는다. GIF는 무음이고 소리는 사건 로그만 기록한다.
자료집은 실제 `renderSkillRetroStage`를 다섯 스킬에 직접 마운트했다.

대화 비교판의 왼쪽은 직전 반려 판의 대표 셀, 오른쪽은 이번 원본의 단회 재생이다.
준비 시간을 줄인 별도 무음 합성이므로 실제 전투 전체 시계와 같다고 보고하지 않는다.
다섯 선택/시간 이동/단회 재생 종료, 736/320px 폭과 어두운 테마를 확인했다.
gates/vitest/전체 typecheck는 세션 지침에 따라 실행하지 않았다.

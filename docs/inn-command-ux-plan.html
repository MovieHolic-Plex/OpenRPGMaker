요금 칸 하나만 있는 허접 폼이 아니라, 플레이어가 보는 예/아니오 창·회복 효과·요금 프리셋이 한눈에 보이는 숙박 세션 편집기로 만든다.

상태 P0~P2 구현 완료 범위 inn 명령 에디터 + 프리뷰 + 런타임 연출 날짜 2026-07-17 앵커 commandBodyCommerce.ts · playSceneCommerce.ts

TL;DR 결정

  1. 한 명령 유지 — inn { price } 공용. 장르별 여관 명령을 쪼개지 않는다.
  2. 폼 = 요금 + 프리셋 + 대화 목업 — “숫자 하나” 금지. 플레이어 창을 편집 시점에 보여 준다.
  3. 효과는 명시 — 골드 차감 · 파티 전원 회복 · 부족 시 거절 문구를 카드에 박아 둔다.
  4. P0 스키마 동결 — 요금 UX만 살리고, 커스텀 대사/시간 경과/분기 훅은 P1.
  5. 이미 한 일 — 프리셋(무료~100G), 예/아니오 목업, 우측 여관 창 프리뷰, 요약 N G · 전원 회복.
런타임 이미 있음: 요금 차감 → HP/MP 회복 → 암전 휴식 → “좋은 아침” 웨이크 (playInn).

페이즈

P0 지금 체감

  • 프리셋 5종
  • 대화 목업 + 우측 창
  • 요약 “N G · 전원 회복”
  • 스키마 변경 없음

Exit: 요금만 바꾸면 질문/프리뷰가 같이 바뀜. 테스트 통과.

P1 작가 제어

  • 인사/질문 커스텀 필드
  • 회복 범위 토글 (HP / HP+MP)
  • 숙박 후 시간(아침) 옵션

Exit: 스키마 optional 필드 + 런타임 반영 + 프리뷰 동기화.

P2 분기·연출

  • 골드 부족 분기 바디
  • 거절 후 대사 훅
  • 암전 연출 길이 옵션

Exit: 상점 branchOnTransaction 과 같은 패턴.

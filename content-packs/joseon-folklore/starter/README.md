# 조선 설화 시작 프리셋

새 게임의 예제 목록에서 고르는 여섯 지도짜리 시작 세계다. 기존 `adventure-jrpg` 엔진,
조선 칩셋, Actor1과 얼굴, 공용 `joseon-folklore` 레코드를 사용한다.
마을·사냥터·동굴·주막·서당·약방, 네 직업 선택, 의뢰·상점·회복·시련을 포함한다.
이후 지역/퀘스트 전체가 완성됐다는 뜻은 아니다.

`data.json`은 정본 SQLite 게임에서 다시 읽은 이벤트·초기 파티·세션과 현재 공용
`joseon-baram` 하네스의 지도 여섯 장을 결합한 배포 데이터다. 옛 게임의 지형 칸 번호를
최신 칩셋에 그대로 붙이면 사냥터 길이 늪으로 바뀌므로, 현재 공용 지도 원본을 사용한다.
그림·지도 칸을 직접 그리거나 atlas를 다시 패킹하지 않는다. 인물 좌표는 새 지도 범위를 검사한다.
실내 NPC와 출입문·전송 시작점은 현재 공용 지도 앵커를 사용한다.
개인 메타데이터, 업로드 그림, 전체 참고문서, 사용하지 않는 옛 장비/직업은 넣지 않는다.
현재 공용 `joseon_baram` 정의와 새 팩 레코드는 시작 프로젝트를 만들 때 합친다.
지도와 칩셋의 count/열 수가 달라지면 재생성을 요구한다.

```sh
node scripts/content/prepare-joseon-folklore-starter.mjs <정본 프로젝트 폴더>
```

출처 project id/revision/SHA, 원본 지도와 현재 공용 지형 해시는 `provenance.json`에 있다.
이벤트 원본은 버들마을 게임 revision 13이다. 분기 안의 의뢰 보상도 쑥단을 사용한다.
실제 생성은 `src/project/contentPacks/joseonFolkloreStarter.ts`가 소유한다.
프로젝트마다 깊은 사본을 만들며, 이미 열린 게임에 세계를 덮어쓰는 경로는 제공하지 않는다.

카드 그림은 실제 플레이 화면이다. Actor1/얼굴/칩셋의 출처는
`public/assets/ATTRIBUTION.md`의 해당 항목을 따른다. 팩 그림 출처는 역할별 폴더에 있다.

# 조선 설화 그래픽 교정 후보 — 2026-10-05

상태: **숲은 현재 그림 유지, 적은 새 후보 방향으로 교정**.
사용자는 비교 뒤 “숲은 현재가 낫고, 적은 후보가 낫다. 적이나 좀 더 고치자.”로 지시했다.
앞선 19개 플레이 확인은 작동 근거이며 그래픽 합격 기록이 아니다.

## 확인한 문제

- 기본 프리셋은 현재 `joseon_baram` 공용 시트를 사용한다. 앞서 다시 그린 나무·기와집은
  별도 Joseon pilot 작업트리의 후보로 남아 있고 공용 시트에 들어가지 않았다.
- 기존 잔디의 단일 화소 질감, 잎 수관의 점묘가 화면 전체에서 경쟁한다.
- 기존 몬스터는 몸 비례와 윤곽·명암 방식이 Actor1 캐릭터와 맞지 않는다.

## 비교에 보존한 후보

- `quiet-grass.py`: 기존 잠금 팔레트의 3색으로 직접 찍은 16px 풀 칸.
  두 빈 칸 슬롯과 두 잎 무리 슬롯으로 바닥 질감의 빈도를 낮춘다. 새 색을 잠금에 추가하지 않았다.
- `trees/B.pxg`, `B.png`, `palette.pal`: 앞선 `p1004-105553`의 B 수정 나무를 보존한 사본.
  팔레트 지시문의 상대경로만 다시 잡았다. 원본·사본 해시는 `provenance.json`.
  선택 장부에는 기록하지 않았고 200색 후보 팔레트는 현재 91색 잠금을 변경하지 않는다.
- `monsters/source/*.pxgrid`: 요청한 GPT 6.1 sol high 작업자의 새 산멧돼지·볏짚 도깨비·처녀귀신.
  64×64 문자 격자에 직접 찍었다. `monsters/bake.py`로 PNG를 다시 만든다.
  결과 해시·원본 크기·색 수는 `monsters/result.json`, 구체적인 남은 결함은 `monsters/REVIEW.md`.

풀·나무 후보는 이번 비교에서 선택되지 않았다. 공용 숲 그림과 지도는 유지한다.
적3종은 후보의 비례와 도트 방향을 유지하면서 세부 표현과 전투 자세를 이어서 교정한다.
이는 다른12종이나 최종 그림 전체를 승인한 기록은 아니다.

수관/풀 비교는 기존 Joseon pilot 하네스 `compose.Sheet`/`road_example`을 사용한 동일 배치의
조립 그림이다. 실제 게임 스크린샷이 아니다. 길과 Actor1 원본 프레임은 양쪽이 같다.
옛 풀/나무는 현재 SQLite에서 추출한 참고문서의 칸 배열과 현재 공용 시트를 사용했다.
별도 땅 후보의 길에 녹색 구멍이 생겨 그 길 후보는 이 비교에서 제외했다.

## 적3종 추가 교정과 배포

`monsters/refinement/`는 후보에서 이어 그린 산멧돼지·볏짚 도깨비·처녀귀신의 원본이다.
얼굴·엄니·볏짚·손·주름을 정리하고, 각9개 전투 자세를 직접 찍었다. 작업자는 요청한
GPT 6.1 sol high다. 초안의 벌어진 몸통·끊긴 손잡이·귀신 허리 틈은 포즈 검토 후 고쳤다.
한계는 그 폴더의 `REVIEW.md`에 남겼으며 최종 사용자 승인 기록으로 간주하지 않는다.

현재 공용 팩에는 이3종의9포즈 시트와 초상이 반영된다. 재생성도
`monsters/source/refined.py`와 `refined-grids/`를 사용하므로 옛 도형 그림으로 돌아가지 않는다.
기존15종 중 나머지12종의 그림과 적 ID·수치·행동·배치, 숲·지도는 유지한다.

정본 `f84dfa19-5b71-43f1-8523-b10910d23be7`을 같은 SQLite API로 저장하고 닫은 뒤 다시 열었다.
revision6이며 프로젝트 문서 SHA는 revision5와 같다. 그림은 공용 builtin 경로가 소유하고
프로젝트별 업로드를 만들지 않는다. 내보낸 플레이어에도 새 PNG를 넣었다.
근거: `verify-shots/joseon-enemy-refinement/`. 실제 게임의2종 조우와 비교용3종 편성을 구분한다.

풀·나무 후보는 보존 자료이며 게임에 넣지 않았다. 타일 교정을 다시 진행할 때에는
`joseon-baram` 하네스의 칸 번호/통행·팔레트·시각 검수·지도 관문을 거쳐야 한다.

## 출처

풀·몬스터·나무 후보는 이 프로젝트에서 저작한 코드 도트다. 생성 이미지를 사용하지 않았다.
시각 비교의 Actor1은 기존 `public/assets/easyrpg/charset/Actor1.png`의 원본 24×32 프레임이며

바람의나라 원본 그림이나 스크린샷을 이 폴더에 복사하지 않았다.

# 목업 대조 채점표

채점: **3** = 목업과 같다 · **2** = 구조는 같고 값이 다르다 · **1** = 구조가 다르다 · **0** = 없다

라운드마다 이 표를 갱신한다. **점수를 올리려면 근거 스크린샷을 봤어야 한다.**

| 영역 | 점수 | 근거 · 남은 격차 |
|---|---|---|
| **A. 모달 셸 / 3열 비율** | 2 | 5행 구조와 3열 배치는 있다. 다만 **좌측 레일이 목업(312px)보다 눈에 띄게 넓어** 레일 하단이 통째로 비고 캔버스가 눌린다. ※ 실측 안 함 — 다음 라운드에서 세 열의 `getBoundingClientRect().width` 를 찍어 표에 적고, `312 / 1fr / 348` 로 맞춰야 3점. |
| **B. 페이지 탭** | 2 | 이름 + 조건 요약 + 검사 배지 다 있고 대비도 고쳤다. 비활성 탭에 **시각적 컨테이너가 없어** 스트립 위를 떠다니고, 번호 배지 아래 정체불명의 숫자 한 글자가 겹쳐 보인다. |
| **C. 좌측 레일** | 2 | 이벤트 카드가 최상단에 있고 접이식 요약도 붙는다. **그래픽 슬롯이 빈 상자를 크게 잡아** 세로를 먹고, 레일 하단 약 150px 이 죽는다. |
| **D. 블록 캔버스** | 2 | 분기 들여쓰기 · 세로 가이드 · 거터 색 · 마커 줄 모두 목업대로 산다. **카테고리 범례가 아직 툴바와 같은 줄**에 있어 툴바와 경쟁한다(목업은 캔버스 아래 독립 줄). |
| **E. 우측 인스펙터** | 2 | 선택된 명령이 있을 때는 목업에 가깝다. **선택이 없을 때 348px 이 힌트 한 줄만 남고 통째로 죽는다.** SPEC §4-E 대로 읽을 것을 채워야 3점. |
| **F. 검증 스트립** | 3 | 위치 · pill · 클릭 이동 · 104px 천장 + 얇은 스크롤바까지 목업과 같다. |
| **G. 명령 팔레트** | — | **미채점.** `min-height: 220px` 를 걷어낸 뒤 `06-palette.png` 를 아직 눈으로 확인하지 않았다. 다음 라운드에서 재캡처 후 채점할 것. |

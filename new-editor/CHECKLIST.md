# 목업 대조 채점표

채점: **3** = 목업과 같다 · **2** = 구조는 같고 값이 다르다 · **1** = 구조가 다르다 · **0** = 없다

라운드마다 이 표를 갱신한다. **점수를 올리려면 근거 스크린샷을 봤어야 한다.**

| 영역 | 점수 | 근거 · 남은 격차 |
|---|---|---|
| **A. 모달 셸 / 3열 비율** | 3 | 실측 완료(1500×1000): `312 / 10 / 1fr(760) / 348`. `--event-editor-settings-track` 기본값을 540px clamp → 312px 으로 바꾸고 인스펙터 트랙을 `minmax(240,320)` → `348px` 고정. 드래그 하한도 320→288 로 내려 기본값이 범위 안에 들어온다. 근거: `01-shell.png`, `[parity] 열 폭 312·348`. |
| **B. 페이지 탭** | 3 | 정체불명의 숫자는 옛 세로 레일 시트의 `position:absolute; bottom:0; left:0; right:0` 이 남아 번호 배지가 탭 아래 189px 폭으로 깔린 것이었다(실측 y=31, w=189). 썸네일·번호·조건배지 3종의 절대배치를 끊고 플로우로 복원, 비활성 탭에 `--mk-raised` 컨테이너 + 3px 챔퍼. 조건 요약은 목업 표기(`SW[0001] ON 외 1`)로 압축. 근거: `04-page-tabs.png`. |
| **C. 좌측 레일** | 3 | 그래픽 슬롯 `min-height:66px` → 내용 기준, 썸네일 52×62, 버튼 26px. 312px 로 좁아지자 카드에서 이름 입력과 "캐릭터 ID" 라벨이 **겹쳤다** — 목업처럼 이름 / 캐릭터 ID / ID·X·Y 세 줄로 쌓았고 겹침 회귀 가드를 e2e 에 넣었다. 근거: `08-card.png`. |
| **D. 블록 캔버스** | 3 | 범례를 툴바 children 에서 빼고 `event-contents-fieldset` 의 cmdList 다음 형제로 옮겼다. DOM 만으로는 부족했다 — 이 fieldset 은 `[1fr auto] × [auto 1fr]` 그리드라 범례가 툴바 옆 빈 칸으로 auto-place 됐다. `grid-column: 1/-1; grid-row: 3` 으로 못박았다. 근거: `01-shell.png`, `[parity] 범례가 캔버스 아래`. |
| **E. 우측 인스펙터** | 3 | 선택이 없을 때 348px 이 힌트 한 줄이던 것을 페이지 요약 카드로 채웠다: 명령 수 · 분기 최대 깊이 · 출현 조건 수 · 트리거 · 우선순위 · 그래픽 · 검사 오류/경고 7행(점선 리더) + 최근 명령 8건(카테고리 거터 색) + 하단 안내. `setCommandInspectorEmptyRenderer` 로 주입하므로 인스펙터 모듈은 편집 책임만 유지한다. 근거: `09-inspector-idle.png`. |
| **F. 검증 스트립** | 3 | 천장 84px → **104px**(SPEC §4-F) + `scrollbar-gutter: stable` 로 얇은 스크롤바 상시. 사선 해칭으로 콘솔 상태바 질감. 근거: `01-shell.png`. |
| **G. 명령 팔레트** | 3 | `06-palette.png` 눈 검수 완료. 결과 1건이면 모달도 1건 높이(바닥값 없음), 카테고리 탭 + 검색 + 결과 + 하단 범례(`부분 실행` / `에디터 전용`) 모두 목업대로. |

## 기계 검증

`npx playwright test eventEditorMockupShots.spec.ts` 의 `[parity]` 줄 — **현재 15/15**.

```
가로 페이지 탭 · 탭 조건 요약 · 이벤트 카드 · 카드가 레일 최상단 · 3열 배치 ·
열 폭 312·348 · 블록 캔버스 거터 다색 · 인라인 인스펙터 · 카테고리 범례 ·
범례가 캔버스 아래 · 인스펙터에 읽을 것 · 하단 검증 스트립 · 황동 확인 버튼 ·
헤드 행 32 정렬 · 범례 명령 수
```

이 13항목은 대부분 **"있다/없다"만 본다.** `열 폭`·`범례가 캔버스 아래` 두 항목만 기하를 본다.
여백·대비는 여전히 못 잡으므로 위 표의 눈 검수를 대체하지 못한다.
새 계약을 만들면 이 스펙에 항목을 **추가**한다(기존 항목을 지우지 마라).

추가된 회귀 가드:
- `08-card.png` / `09-inspector-idle.png` 근접 캡처 (셸 샷으로는 A·E 를 볼 수 없다).
- 카드 이름 입력 ↔ 캐릭터 ID 라벨 겹침 가드 (`name input overlaps the character-id label`).

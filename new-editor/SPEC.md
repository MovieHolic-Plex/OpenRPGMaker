# 이벤트 에디터 — 목업 대조 스펙 (정본)

> **정본은 `mockup/event-editor-mockup.html` 이다.** `mockup/event-editor-mockup.png` 는
> 그 파일의 렌더일 뿐이므로, 목업을 바꾸려면 HTML 을 고치고 `node new-editor/render-mockup.mjs`
> 로 PNG 를 다시 뽑는다. 이 문서는 "그 그림을 실제 에디터에서 어떻게 만족시킬 것인가"를 적는다.

## 0. 이 문서를 읽는 에이전트에게

- **작업 단위는 "영역 하나"다.** §4 의 A~G 중 **가장 점수가 낮은 영역 하나만** 고른다.
  한 번에 여러 영역을 건드리면 회귀 원인을 못 가린다.
- **렌더 없이 끝내지 마라.** 코드를 고쳤으면 반드시 §5 의 캡처를 다시 돌려서
  `output/evidence/event-editor-mockup/*.png` 를 눈으로 확인한다. 숫자만 보고 "됐다"고 하면 안 된다.
- **목업 CSS 를 복사하지 마라.** `mockup/event-editor-mockup.html` 은 정적 목업이고 선택자 체계가 다르다.
  목업이 정하는 것은 **배치 · 비율 · 위계 · 상태**이지 CSS 규칙이 아니다.
- **이미 고친 것을 다시 고치지 마라.** §6 의 "해결됨" 목록을 먼저 읽는다.

## 1. 목표 한 줄

이벤트 편집기를 열었을 때 **"이 이벤트가 언제 돌고, 무엇을 하고, 지금 무엇이 잘못됐는지"**를
클릭 없이 한 화면에서 읽을 수 있어야 한다. 목업은 그 상태를 그린 것이다.

## 3. 전역 규칙

### 3.1 색 토큰
`event-editor.mockup.css` 상단의 `--mk-*` 를 쓴다. 새 헥스값을 인라인으로 박지 마라.

| 용도 | 토큰 | 값 |
|---|---|---|
| 본문 글자 | `--mk-t1` | `#e9ecf3` |
| 보조 글자 | `--mk-t2` | `#9aa3b5` |
| 장식 전용 | `--mk-t3` | `#626b7d` |
| 액센트(황동) | `--mk-accent` | `#d9a441` |

**`--mk-t3` 는 본문에 쓰지 마라.** 이 다크 표면 위에서 약 3.4:1 이라 WCAG AA(4.5:1) 미달이다.
구분선·비활성 아이콘 같은 장식에만 허용한다.

### 3.2 카테고리 거터 색
색은 **스캔 보조**일 뿐이고 식별은 항상 함께 있는 명령 텍스트가 한다.
6색을 all-pairs 로 구분하는 것은 불가능하므로, 상위 3종만 색 단독으로 갈리고
나머지 3종(맵·연출·시스템)은 **45° 사선 텍스처**를 2차 채널로 얹는다.

`dialogue #3987e5` · `flow #d95926` · `reward #199e70` ·
`map/actor #9085e9` · `screen/sound #d55181` · `battle/system/modern #c98500`

### 3.3 액센트 사용
황동 `#d9a441` 은 **"진행" 하나**에만 쓴다 — 확인 버튼, 활성 탭 상단선, 명령 추가 토글.
경고 배지에도 같은 황동을 쓰되 채움이 아니라 **테두리+글자**로만 쓴다.

### 3.4 아이콘 어휘
툴바는 **기호만** 쓴다: `↶ ↷ ↑ ↓ ▣ ✂ ＋ ☠`.
한글 한 글자를 아이콘 자리에 넣지 마라(잘린 라벨로 읽힌다). 뜻은 `title` 이 든다.

### 3.5 죽은 여백 금지
어떤 영역도 **자기 높이의 40% 이상을 빈 채로** 두지 않는다.
- 내용이 적으면 컨테이너가 줄거나(내용 기준 높이), 내용을 가운데로 모은다.
- `min-height` 바닥값으로 빈 상자를 만들지 마라. 필요한 건 `max-height` 천장이다.

### 3.6 잘림 정직성
카운트가 N 이면 목록도 N 을 보여 주거나, **잘렸다는 신호**(부분 노출 줄 + 보이는 스크롤바)를 준다.
"오류 1 · 경고 3" 이라 세어 놓고 2건만 보여 주는 상태는 버그로 취급한다.

## 4. 영역별 계약

각 영역은 **0~3점**으로 채점한다. 3 = 목업과 같다, 2 = 구조는 같고 값이 다르다,
1 = 구조가 다르다, 0 = 없다.

### A. 모달 셸 (52 / 56 / 1fr / auto / 64px 5행)
- 세로 순서: 제목 → 페이지 탭 → 본문 → 검증 스트립 → 푸터.
- **본문만 늘어난다.** 나머지는 내용 기준 높이.
- 본문은 3열 `312px / minmax(0,1fr) / 348px`. 가운데가 남는 폭을 전부 먹는다.
- 좌우 열은 각자 스크롤한다. 모달 전체가 스크롤되면 안 된다.
- 푸터(64px): 좌측 2행 상태(`편집 세션 — …` / `원격 저장 — …`, `t2`), 우측 액션
  `삭제(위험 고스트) · 이 이벤트 테스트 · 취소 · 적용 · 확인(황동) · 도움말`.
  액션은 푸터 우측 한 줄, 상태는 좌측. 가운데 빈 공간 금지.

### B. 페이지 탭 (상단 전폭 가로)
- 탭 하나 = `번호 배지 | 이름 + 조건 요약 | 검사 배지`.
- **조건 요약이 핵심이다.** 탭을 눌러 보지 않고 "이 페이지가 언제 도는가"를 읽게 한다.
  조건이 여럿이면 `첫 조건 외 N`.
- 활성 탭: 상단 2px 황동선 + 표면 올림 + 글자 `t1`.
- 비활성 탭 조건 요약도 **`t2` 이상**. `t3` 금지(§3.1).
- 우측 끝에 `＋ 새 페이지 / 페이지 복사 / 페이지 삭제`.

### C. 좌측 레일 (312px)
- **최상단은 이벤트 카드**: 썸네일 + 이름 + 캐릭터 ID + ID/X/Y. "지금 무엇을 편집 중인가"를 한 덩어리로 답한다.
- 그 아래는 **접이식 섹션**: 출현 조건 / 그래픽 / 트리거·우선순위 / 이동·기타.
- 접힌 섹션은 **오른쪽에 요약**을 붙인다(`정지 · x2 느림` 처럼). 열어 보지 않고 값을 읽게 한다.
- 열림/닫힘 삼각형 방향이 상태와 일치해야 한다(`▾` 열림 / `▸` 닫힘).
- 그래픽 슬롯은 빈 상자를 크게 잡지 않는다 — 썸네일 52×62 + 조작 버튼만.

### D. 블록 캔버스 (가운데)
- 명령 한 줄 = `3px 카테고리 거터 | 글리프 | 요약 텍스트 | (hover 시 액션)`.
- **분기 들여쓰기가 반드시 보여야 한다.** 한 단계 `18px`, 그리고 깊이 1 이상은
  왼쪽에 **세로 가이드선 1px**. 들여쓰기만으로는 3단부터 안 읽힌다.
- 분기 마커(`: 맡는다`, `: 선택지 종료`)는 명령이 아니므로 **블록으로 그리지 않는다** — 흐름색 텍스트 줄.
- 선택된 블록은 황동 테두리 + `box-shadow 0 0 0 1px`.
- 값(스위치 ID · 리소스명)은 파랑, 숫자는 초록으로 텍스트 안에서 구분한다.
- **카테고리 범례는 툴바와 같은 줄에 두지 않는다** — 캔버스 바로 아래 독립 줄.
- 빈 이벤트일 때: 시작 유형 6버튼을 **캔버스 세로 가운데**로 모은다. 폭은 `min(100%, 620px)`.

### E. 우측 인라인 인스펙터 (348px)
- 머리: `카테고리 · 명령 이름` (황동 소문자 라벨) + 대상 요약 한 줄.
- 몸: 접이식 섹션들. 각 섹션도 닫히면 오른쪽에 요약.
- 꼬리: "더블클릭하면 전체 편집 창이 열린다" 한 줄 안내.
- **선택된 명령이 없을 때도 이 열은 비어 보이면 안 된다** — 최근 명령 요약이나
  현재 페이지 통계처럼 읽을 것을 둔다. (지금은 힌트 한 줄만 있어 348px 이 통째로 죽는다.)

### F. 검증 스트립 (하단, 캔버스 아래)
- 요약 줄: `검사 · 오류 N · 경고 N · 안내 N`.
- 목록: 심각도 pill + 메시지. 클릭하면 해당 명령/필드로 이동.
- 높이 천장 `104px`(≈3.5줄), 얇은 스크롤바 상시. §3.6 을 지킨다.
- 오류가 0 이면 접힌 채로 둔다.

### G. 명령 추가 팔레트
- 결과가 1건이면 모달도 1건 높이로 줄어야 한다. `min-height` 바닥값 금지.
- 리스트 천장은 `min(52vh, 460px)`.
- 카테고리 탭 + 검색 + 결과 + 하단 범례(`부분 실행` / `에디터 전용`).

## 6. 이미 해결됨 (다시 손대지 마라)

- 분기 들여쓰기가 죽어 있던 문제 — `--cmd-depth` 를 `.cmd-head` 에만 심어서
  부모 `.cmd-item` 에서 읽히지 않던 것. 이제 `item` 에도 심는다.
- 툴바 `"몬"` → `☠`.
- 빈 이벤트 캔버스 중앙 정렬.
- 팔레트 `min-height: 220px` 제거 → 천장 `min(52vh,460px)`.
- 검증 스트립 `max-height: 58px` → `104px` + 얇은 스크롤바(`scrollbar-gutter: stable`).
- 비활성 탭 조건 요약 `t3` → `t2`(대비 미달 해소).
- **열 폭**: `--event-editor-settings-track` 기본 `clamp(320,36vw,540)` → `312px`,
  인스펙터 `minmax(240,320)` → `348px`. 드래그 하한 320→288.
- **탭 내부 절대배치**: 옛 세로 레일 시트가 썸네일/번호/조건배지에 준
  `position:absolute; inset:0` 을 끊었다(번호 배지가 탭 아래 189px 폭 유령 숫자로 보였다).
  탭 썸네일은 아이콘이 36×48 `!important` 로 고정돼 있어 `transform: scale()` 로만 줄인다.
- **범례 위치**: `event-contents-fieldset` 은 `[1fr auto] × [auto 1fr]` 그리드다. DOM 순서를
  cmdList 뒤로 옮기는 것만으로는 툴바 옆 빈 칸으로 auto-place 된다 —
  `grid-column: 1/-1; grid-row: 3` 을 함께 줘야 한다.
- **카드 겹침**: 레일 312px 에서 이름 입력과 "캐릭터 ID" 라벨이 겹쳤다. 카드 안 필드는
  세 줄로 쌓는다. 2열 그리드는 `.event-character-id-label` 에 걸어야 한다
  (래퍼 `.event-character-id-field-inline` 에 걸면 입력이 0폭이 된다).
- **인스펙터 유휴 상태**: `setCommandInspectorEmptyRenderer` 로 content.ts 가 페이지 요약을
  주입한다. 한글 라벨에 mono + uppercase + 자간을 주면 글자가 짓눌린다 — 라벨은 산세리프.
- **푸터**: 목업과 동일 — 좌측 2행 상태, 우측 액션(삭제=위험 고스트 · 이 이벤트 테스트 ·
  취소 · 적용 · 확인=황동 · 도움말). 옛 `footer-leading` 래퍼와 `margin-right:auto` 는 제거.
  버튼 높이 30px · `min-width:0` · 패딩 13px 로 6개 액션이 1280 에서도 한 줄.
- **레일 gfx/trig 겹침(1280×800)**: `.event-page-props` 의 auto 행이 `overflow:hidden`
  필드셋의 자동 최소 크기 0 때문에 내용보다 줄어드는 문제. `grid-auto-rows: min-content`
  로 고정(`.event-editor` 에 쓴 기법과 동일). 매트릭스 invariant 9번째
  (`레일 gfx/trig 겹침 없음`)로 가드.
- **게임 필 레이어**: `src/styles/editor/event-editor.gamefeel.css` (마지막 @import).
  베벨 프레임 · 인셋 릴리프 · 챔퍼 탭 · 사선 해칭 검증 스트립 · 기계식 :active 등 표면 전용.
  이 파일은 `display/position/grid-template/width/height` 를 건드리지 않는다 —
  레이아웃을 고칠 일이 생기면 `mockup.css` 로 가라.
  ⚠ `.btn.event-editor-footer-button.primary` 의 `background-color` 는 절대 바꾸지 마라.
  parity 검사가 `rgb(217,164,65)` 를 정확히 비교한다(그라디언트도 실패한다).

## 8. 남은 큰 과제 (별도 작업 — 이 루프 범위 밖)

- 명령 100개짜리 이벤트에서의 스케일: 분기 접기, 가상 스크롤, 미니맵.
- 툴바 기호의 초보 학습 곡선: 첫 사용 시 라벨 노출 또는 온보딩.

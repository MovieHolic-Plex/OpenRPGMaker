GIF 변환: `python3 scripts/qa/assistant-human-work-gifs.py`.
모든 프레임은 실제 제품 UI의 PNG 캡처다. 실제 포인터 입력·도구 실행·공간 도구 증명·체크포인트 적용·권위 검사·커밋 게이트를 통과한다.
재현용 fixture와 대본 세션 이벤트/NDJSON/검수 이벤트를 사용한 결과이며 라이브 모델 품질이나 정본 SQLite 저장의 증거는 아니다.
GIF는 상태 변화별 캡처를 순서대로 재생하며 연속 화면 녹화는 아니다.

최종 성공 실행 전에 재현 대본에서 계획/검수 단계를 빠뜨려 추가 실행기 확인이 멈춘 시도가 있었다.
한 시도는 실제 이미지 검수 호출까지 이어졌다. 최종 성공 실행에서는 팀 검수 이벤트를 대본으로 공급했으며 그 시도를 GIF 근거로 사용하지 않는다.
전체 Vitest/게이트/typecheck는 세션 규칙에 따라 실행하지 않았다. 회귀 계약 테스트는 추가/갱신했고 TS 구문 변환·JSON 파싱·diff 공백 검사를 수행했다.

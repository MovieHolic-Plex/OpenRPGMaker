## 측정

- 속도 0.6/1/1.6: approach 216/131/82 ms, 첫 hitstop 시작 720/438/281 ms, 전체 1572/941/587 ms.
- 무게 hitstop: light 없음, normal ≈112 ms, heavy ≈211 ms.
- 색조(계산 filter): 얼음 `hue-rotate(148deg) saturate(3.4) brightness(1.12) contrast(1.02)`, 번개 `6deg 4.6 1.15 1.05`, 독 `58deg 3.6 1.0 1.08`, 원본 `none`.
- 화면: flash 최고 휘도 243, dim 최저 56, cutIn 파란 띠, shake dx 7~10px.

## 자동 추천 예

파이어볼 3타 → 파이어볼(타마다), 아군 전체 회복 → 대치유, 단일 회복 → 치유의 빛, 자기 버프 → 함성, 적 전체 수면 → 자장가, 적 전체 번개 마법 → 연쇄 번개, 얼음 단일 마법 → 파이어볼 + 얼음 색조, 물리 5타 → 백열권, 독 물리 → 맹독 칼날, 훔치기 → 훔치기.

## 정직한 한계

- 독 자동 추천은 `hero_cross`(파랑-흰 베기)로 재생되고 초록 색조가 붙지 않았다.
- regen 오라는 다른 것보다 약하다.
- shake 는 정지 화면에서 안 보인다. 무게 프레임은 시간 정렬이 아니다.
- cap-3 는 DOM 이 아니라 함수 호출로 증명했다.
- 적/몬스터 스킬은 옛 경로 그대로다. 오라용 그림 시트는 없다(CSS 전용).
- 편집기 캡처는 `?freshProject=1` 메모리 세션이며 정본 저장 증거가 아니다.

세부 목록은 `SHOTS.md`.

## 실제 생성 결과

- 장면 계획: 1,457개. 네 장르의 각 364개 경로 + 공통 첫 화면 1개. 모든 장면 키·부모·자식·누적 답변 수를 실제 질문 원본에서 확인했다.
- 기본 제공 image_gen: 초기 스타일 실험 1개 + 공식 첫 배치 10개 동시 요청 + 지적 후 수정 후보 3개 = 실제 이미지 14개.
- 공식 후보 13개를 view_image로 직접 열고 이전 후보 및 장르별 장면과 비교했다. 하네스 ledger에 원본·고정 프롬프트·정확한 생성 요청 해시와 시각 판정을 남겼다.
- 공식 후보는 전부 1672×941, 실제 색 수 207,548–539,164였다. 320×180 또는 정확한 정수 픽셀 확대·64색 원본 관문을 통과한 후보는 **0개**다. 수정 무도회 인물과 추리 문서 글자 문제는 개선됐지만 원본 규격은 실패했다.
- 배포 매니페스트는 `published: 0, complete: false`. 미완성을 합격으로 바꾸거나 그림을 복제해 1,457개를 채우지 않았다.
- 후보 PNG와 정확한 요청: `qa-runs/harnesses/interview-scene-bank/` (gitignored). 검수/해시 기록: `harness-data/interview-scene-bank/ledger.json`.
- 별도 출력 도구를 사용한 도트 규격화 후 재검수 경로는 사용자 선택 요청 중이다. 현재 시점에 그 변환을 실행하지 않았다.

## 실제 컴포넌트 브라우저 QA

`scripts/qa/interview-scene-bank.mjs`가 production dialog, 키 해석기, 이미지 캐시를 사용했다. **카탈로그는 검증용으로 주입했고 그림 파일은 실제 생성 원본이지만 도트 관문 탈락작이다.** `artApproval: false`다. 이 실행은 출하 배경 준비 완료나 AI 조수 게임 제작 성공의 근거가 아니다.

`browser-proof.json`에서 확인하는 계약:

- 1,457개의 고유 키와 연결 관계·누적 답변 수.
- 현재/다음 선택지를 미리 읽고, 준비된 배경을 클릭 이벤트 안에서 바로 교체. 이미지 생성 API 호출 0회.
- 앞 질문을 편집할 때 뒤 답을 보존한 정확한 전체 경로; 직접 입력/메모/혼합/빠진 앞 답의 잘못된 고정 그림 조회 거부.
- 없는 그림은 기존 생성 경로를 사용하고 provider 오류에서는 마지막 그림 유지.
- 닫은 뒤 추가 그림 작업 없음 / pageerror 없음.

`warm-click-qa.png`는 이 검증용 카탈로그를 사용하는 production 컴포넌트 화면이다. `review-gallery.png`는 실제 생성 후보의 검수 화면이다. 갤러리 원본 파일을 축소한 표시는 검수 편의용이며, 그 축소본의 색 수/크기를 원본 관문 판정으로 사용하지 않는다.

렌더러 `npm run build:app` 성공. 전체 typecheck·Vitest·npm run gates는 이번 요청과 저장소 실행 제한에 따라 돌리지 않았다. 실제 앱에서 새 배경이 준비됐다는 주장은 아직 할 수 없다.

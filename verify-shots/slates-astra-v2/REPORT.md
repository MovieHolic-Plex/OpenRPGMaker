# Slates Astra v2 — 돌샘 굽이 마을 최종 저작 제출

50×50 새 배치와 요청된 전달 파일을 작성했다. **실험 품질 합격/원격 저장 완료 주장은 하지 않는다.** 구조와 구성은 partial이며, 로컬 통행은 통과했지만 엔진 QA·저장은 감독자 담당이다. 아래 그림은 최종 bundle의 아틀라스와 lower/upper 배열로 직접 그렸다.

## 구역 중심으로 다시 만든 구성

첫 30개 배치의 다섯 가로 띠는 감독자가 구성 reject로 판정했다. 전폭 가로길을 줄이는 중간 수정만으로 해결되지 않아 폐기했다. 점유율을 맞추기 위해 여섯 띠로 늘리는 중간안도 채택하지 않았다. 최종은 다음 공간의 형태와 목적을 먼저 정하고 고정 건물을 배치했다.

1. **북서 길드 회랑:** 본동과 서고를 나란히 두고 제본 공방·서기 집을 다른 깊이에 놓았다. 작은 L자 포장 중정이 이어진다.
2. **동북 상점 거리:** 이미 높이가 다른 붙은 상점 모듈들을 계단 모양으로 배치했다. 통로가 상점 앞을 따라 꺾이며 남쪽 여관으로 이어진다.
3. **중앙 시장 광장:** 별도의 14×10칸 광장. 우물·두 판매대 군·벤치를 가장자리와 중심에 나누었다. 주도로가 광장에 들어오기 전 두 번 꺾인다.
4. **서남 나무그늘 정원:** 직사각 상자밭을 없애고 L자 잔디·활엽수/침엽수·꽃·덤불·산책길·여관으로 구성했다. 건물 안에 겹친 꽃은 제거했다.
5. **동남 장인 중정:** 긴 두 공방과 주거 사이에 폭이 넓고 얕은 흙 작업 마당을 두었다. 시장 광장이나 길드 회랑과 바닥/형태가 다르다.

건축 **26개**, 종류 **4개**: 돌출집 11, 붙은 상점 5, 옆동 여관 4, 낮은 공방 6. 성벽·탑·판매대·수목을 집 종류로 세지 않았다. 같은 건축 실루엣 3개를 가로로 연속 배치하지 않았다. 기존 집/상점의 폭은 늘리지 않았다.

**밀도는 여전히 부족하다.** 성벽 내부 native `[96,128,1408,1344]`에서 바닥·그림자·나무·소품을 제외한 건축 알파 합집합은 538529.54px² / 1892352px² = **28.46%**다. 알파>0의 이진 커버리지도 540620px²로 별도 기록했다. 실습 사각 패딩 면적이나 충돌 사각형으로 점유율을 부풀리지 않았다. 지침 제안 45~60%에 미달하므로 구성 pass로 표현하지 않는다. 구역 구분과 공공 공간을 확보한 이번 배치의 한계다.

주도로는 2칸, 문 앞/정원 산책길은 1칸 이상을 목표로 저작했다. 넓은 중정/광장은 도로 폭 평균에 포함하지 않았다. 모든 모래 바닥 역시 통행 가능한 지면이며 포장 띠만 통행 가능하다고 제한하지 않았다.

## 부품·반복·자체 수정 근거

- 세 지정 JSON의 패치 해독은 source 0=v2, source 1=v1, 기본 16px와 필요한 8px 목적지 오프셋/그리는 순서를 사용한다. 7개 카드 2478개 연산을 대조한 기록은 catalog-decoding.json에 있다.
- 집·상점은 색차 맞춤 레시피에 섞인 바닥/배경을 좌표와 부품 용도로 제외했다. RGB 키색 삭제를 하지 않았다. 최종 지도에서는 각 모듈 floor를 제외했다.
- 큰 사각 그림자를 오른쪽 8px/아래 4px 접촉 띠로 바꿨다. street와 실루엣을 직접 열어 배경 사각 스탬프가 다시 들어오지 않은 것을 확인했다.
- **낮은 공방 초기판은 구조 reject였다.** 지붕 귀 부재를 가운데 반복한 톱니를 발견했고, 첫 교체에서도 사면이 섞인 37이 남아 원본 번호판을 다시 확인했다. 최종 중앙은 순수 평면 540, 지붕창은 542, 꼭짓점/좌우 귀는 고정한다. 반칸 방향별 가장자리로 옆면을 닫았다. 수정 complete PNG를 직접 열고 톱니 반복이 사라진 뒤에만 최종 배치했다.
- 여관 옆동은 inn 카탈로그의 **v1 지붕 사각형**과 v2 전면 부재를 조립했다. 북쪽 직선 절단 지적 후 원본 가로 마감 부재를 더했다. 얕고 직선적인 북쪽 끝은 여전히 partial이다. 대형 회관으로 확대하지 않았다.
- 잔디는 가장자리 0을 반복하던 오류를 고쳐 중심 57을 사용했다. 최종 전체 그림에서 검고 밝은 32px 바둑판이 사라졌다.
- 성벽은 회전하지 않은 방향별 부재다. 최종 가로 단면은 뒤 흉벽→32px 상부 면→앞 흉벽→석조 면으로 정렬했다. 모서리를 탑으로 가리지 않았다. 서쪽의 얇은 외벽 표현은 partial이다.
- 남문은 hold 격자문 복원이 아니다. 새 얕은 아치와 열린 지상 통로다. 지상 탑 끝 482를 사용하고 최종 위치에 맞춰 반복 몸통 한 행만 줄였다. 문 양옆 흉벽 아래 원본 포장을 연속 공급하여 풀색 틈을 없앴고 gate-join-final.png를 직접 열었다.

## 실제 전달 메타를 사용한 통행

시작점은 **(24,49)**. 접근 목표 **47개**, 도달 실패 **0개**. `bundle.map`의 lower/upper ID를 읽고 `tileset.passability`의 출발 방향과 도착 반대 방향을 모두 결합하여 flood fill했다. 저작 중 blockedSet을 통과 결과로 대신 사용하지 않았다. 같은 RGBA도 layer 또는 통행이 다르면 별도 타일 ID다.

남문 `layout.gates[0].passageCells`는 **x=24,25 / y=46,47,48,49**의 전역 8칸이다. 내부 목표 (24,45), 외부 착지 (24,49). 이 실제 통로만 봉쇄한 뒤 광장 (24,26)에서 다시 탐색하면 경계 도달 **0칸**, 즉 로컬 마스크 기준 성벽 우회 누출은 없다. 개방 시 통로 8칸 모두 도달한다. 자세한 수치는 metrics.json에 있다.

이 결과는 **앱/출하 플레이어 실행 결과가 아니다.** 허용 입력 제한으로 앱 코드를 읽거나 실제 엔진을 실행하지 않았다. 캐릭터 가림·이벤트 이동·저장된 칩셋의 엔진 해석은 감독자 확인이 남는다.

## 두 레이어 렌더와 직접 PNG 열람

최종 아틀라스를 PNG로 직렬화한 뒤 그 아틀라스와 배열로 lower 전체→upper 전체를 다시 그린 `map-from-bundle.png`가 `map.png`와 같다. ID 범위/배열/메타 길이는 맞는다. 원본 연산을 직접 그린 저작 Canvas와 파생 타일 PNG를 거친 렌더 사이에는 **31픽셀**, 최대 채널 차이 **1**가 있다. 반투명 픽셀을 중간 아틀라스에 합성·PNG로 전달하는 경로의 작은 차이이며, 픽셀 완전 동일이라고 숨기지 않는다. 최종 미리보기는 실제 전달 배열 쪽으로 통일했다.

실제로 연 그림: 초기/수정 house·joined-shops·wall-corner·open-gate complete, 실루엣과 충돌, 원본 부품 선택판, 추가 inn/workshop complete의 반복 교정판, street, street-joins, 각 단계 map, 최종 map-from-bundle, 남문 확대. 참고 비교 PNG는 눈으로 보는 구조 근거이며 재료로 붙이지 않았다.

## 네 가지 판정

| 축 | 판정 | 근거 |
|---|---|---|
| 구조 | partial | 공방 reject 교정, 집/상점 고정 구조 유지. 상점 결 전환·여관 북쪽 끝·얇은 성벽·얕은 아치의 한계 |
| 구성 | partial | 균일한 띠 폐기, 성격/형태가 다른 구역과 독립 시장 광장. 밀도 28.46%로 제안 미달 |
| 통행 | partial (로컬 통과) | 47개 목표 연결, 남문 봉쇄 시 외부 누출 0. 실제 엔진 QA 전 |
| 저장 | partial (감독자 대기) | 작성자는 DB/.env 미접근. LegacyDb 저장·재로드 성공 주장을 하지 않음 |

## 입력/쓰기/실행 범위

읽은 문서·PNG·JSON 원본은 read-inputs.json에 있다. stage1-report의 v1 미사용 설명은 **초기 1~3단계 시점**의 기록이며 최종 여관 옆동에는 v1이 사용된다. 최종 규격/수치는 이 REPORT와 metrics.json을 따른다. 카탈로그의 sourceParts/patches/rects만 해독했고 카탈로그의 완성 rows 타일 배열은 배치에 사용하지 않았다.

기존 생성기·완성 맵/프로젝트 JSON·앱 코드·이전 대화·웹·DB/.env를 읽지 않았다. 저작은 이 작성자 한 명이며 하위 에이전트 호출, stash, 커밋, 전체 test/gates/vitest/typecheck를 하지 않았다. 시각 렌더·사각형 해독·요청된 통행 관찰은 새 생성기 내부에서 수행했다.

수정 범위: `scripts/content/build-slates-astra-v2.mjs`와 `verify-shots/slates-astra-v2/`뿐. 재생성 명령: `node scripts/content/build-slates-astra-v2.mjs`. 전체 산출 파일 목록/해시는 artifacts.json에 있다. 문서의 보류 경고를 해결했다고 덮어쓰지 않았으며, 허용 쓰기 범위 밖의 OpenWiki는 수정하지 않았다.

LegacyDb 프로젝트 `rpg-zzu-slates32-38e6` 연결·최신 SHA 확인 및 최종 병합·저장·재로드는 감독자 담당이다. 이 산출물은 감독자가 저장할 수 있는 새 독립 번들이며 기존 프로젝트를 수정하지 않았다.

# 최종 출하 플레이어 시각 검수

검토: 세 번째 원화의 실제 손→시계 관계, 두 번째/세 번째 컷의 다른 구도와 자막 표시를 확인했다. 전환의 흰 WebGL 잔상이 제거됐다.
기능 비트 판정과 시각 판정은 별도이다. 장편 오프닝이나 인물 프레임 애니메이션의 완성을 의미하지 않는다.

즉시 확인: ../keep/03-opening-2.png, ../keep/04-opening-3.png

한계: 여러 스틸 원화의 컷 연출이다. 원경의 공간 규모는 실제 픽셀 서재보다 크다. 조수 검수만으로 고급 RPG의 연출 수준이라고 판정하지 않는다.

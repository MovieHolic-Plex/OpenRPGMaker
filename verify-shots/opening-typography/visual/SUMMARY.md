# 실제 저장된 오프닝의 연속 영상 검토

최종 main 통합 코드의 수정하지 않은 ZIP → player.html → 정상 재생의 영상.

즉시 확인: contact.png, 01-prologue.png, 04-reach.png, 05-first-play.png.

서문의 한 글자씩 표시 → 장면 와이프 → 시계 빛/기억 자막 → 손을 뻗는 원화와 상승 자막 → 마지막 원화를 유지하는 맵 준비 → 실제 픽셀 맵을 직접 확인했다. 첫 서문 시간이 먼저 소모되던 수정 전 영상과 다르게 글자 진행이 보인다. 인물/손은 정지 원화다. 마지막 그림 유지가 맵 준비 시간을 줄이는 기능은 아니다.

원본 영상 시계와 DOM 관측 시계의 시작점이 다르므로 PNG는 실제 영상의 그림으로 대조하여 추출했다. DOM 통과와 원화/글자의 시각 확인을 구별한다.

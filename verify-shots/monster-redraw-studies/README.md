# 갓파 재저작 이후 세 종 기본 그림

사용자가 새 갓파 그림을 긍정 평가하고 다른 몬스터 몇 종 추가 제작을 요청하여,
회색 늑대·동굴 박쥐·해골 전사의 기본 자세를 각각 새로 그렸다.

이후 요청으로 세 종과 갓파의 9포즈를 공용 전투 자산에 배선했다.
최신 결과는 `tiledata/monster-battle-four/README.md`, `verify-shots/monster-battle-four/SUMMARY.md`를 본다.
아래 상태 설명은 기본 그림만 제작한 시점의 기록이다.

## 원본과 미리보기

원본: `scripts/asset-gen/pixel-enemy/monster-redraw-studies.py`.
재생성: `python3 scripts/asset-gen/pixel-enemy/monster-redraw-studies.py`.

| 종 | 직접 저작한 원본 | 최종 확대 그림 |
|---|---|---|
| 회색 늑대 | `wolf-grey-native.png` | `wolf-grey-6x-v2.png` |
| 동굴 박쥐 | `bat-cave-native.png` | `bat-cave-6x-v2.png` |
| 해골 전사 | `skeleton-knight-native.png` | `skeleton-knight-6x-v2.png` |

모두 최종 64×64px 격자에 정수 좌표로 직접 그린 한 장짜리 초안이다.
늑대의 낮은 몸통·목털·송곳니, 박쥐의 날개 손가락뼈·막·귀, 해골의 두개골·갈비뼈·
녹슨 철제 장비를 각각 따로 저작한다. 공통 부분은 픽셀 배치 함수이며 몸통 템플릿은 공유하지 않는다.
생성형 이미지·입력 비트맵·큰 그림 축소를 쓰지 않는다. 3배/6배 미리보기만 nearest로 확대한다.

## 확인 범위와 현재 상태

세 원본 PNG를 저장 후 재로드하여 원본 픽셀 일치, 알파 0/255, 경계 안 좌표를 확인했다.
실제 색 수는 늑대 14, 박쥐 17, 해골 16이다. `pixels.json`에 기록한다.
세 장의 6배 확대를 직접 보고 늑대 귀와 해골 코·턱·발 위치를 다듬었다.

사용자 그림 검토 전 초안이다. 아직 9포즈·게임 배선·정본 프로젝트 저장의 결과물이 아니다.
공용 카탈로그 파일은 수정하지 않았다. 기존 늑대/해골은 48px 셀이므로 향후 적용할 때
이 새 원본의 64px 셀 계약을 명시적으로 배선해야 한다. 축소해 기존 48px 셀에 넣지 않는다.
이 기록은 전체 139종 리프레시 승인이나 테스트/게이트 실행 근거가 아니다.

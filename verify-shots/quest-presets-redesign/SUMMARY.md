# 퀘스트 만들기 UI 개편 — 2026-10-01

## 실제 화면

AI 더보기 → 퀘스트 프리셋 → 「퀘스트 만들기」.

- `errand.png`, `lost_item.png`, `hunt.png`: 실제 편집기 메뉴에서 각 유형을 선택한 1440×900 캡처.
- `width-1024.png`: 지원하는 데스크톱 최소 폭 1024×768에서 입력·미리보기·하단 액션 확인.
- 이전 화면: `../quest-presets/`. 이 폴더는 목업이 아니라 실제 에디터 캡처다.

전용 창에 유형 선택 / 이야기 편집 / 구성 미리보기를 배치했다.
유형별 초안(이야기·보상)을 창이 열려 있는 동안 따로 보존하고, 두 가지 예시를 실제
편집 가능한 입력값으로 제공한다. 빠른 보상(0/100/300G)과 직접 입력을 함께 제공하며
이야기·보상 변경이 미리보기에 즉시 반영된다. 「요청 확인하기」는 AI 입력창으로
요청을 전달한다. 다음 화면의 전송은 사용자가 한다.

# 현재50종 생산 제어 기록

이 파일은 실행한/실행 대기 output/*.py 제어 코드의 감사 사본이다.
실행 경로는 저장소 output/이며 이 감사 폴더에서 직접 실행하지 않는다.
작품을 그리거나 판정/승인/성공을 만들어 내지 않고 기존 battle-monster 단계를 호출한다.
원래3대표→초기2종→여성1종/남는자리 후속의50종 전체 계획을 기록한다.
전환기는 기존 안개삵 wave의 실제 PID/시작 식별자 종료를 기다린 뒤 배차기만 교체한다.
최신 note-file은 다음 새 작가/교정 호출의 실제 prompt에 남는다. 기존 job과 그림은 보존한다.
observer는 실제 keep/사용자 명시 목표/현재 원본을 확인한 API Allow만 요청하고,
원본/GIF/선택 ZIP 감사·실제 브라우저·출처 재로드를 모은다.
50종 근거가 모여도 최종 감독 그림/저작 코드 검토를 기다리며 목표 완료를 선언하지 않는다.

후속은 실제 연속 지적이 남는 종을 최대8번 직접 교정하고 각각 새 독립 검수를 받는다.
초기4번 제한에 닿은 미게시 후보도 보존된 count/원본에서 이어갈 수 있다.
8번 후에도 실제 keep가 없으면 실패로 남긴다. 한도를 올려 판정을 통과시키지 않는다.

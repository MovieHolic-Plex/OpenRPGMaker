# 전투 동작 적대적 검토 — 2026-10-02

## 검토에서 실제로 찾은 결함

| 반례 | 수정 |
|---|---|
| 달리는데 카메라를 보는 칸 / 공격 칸으로 뒤로 미끄러짐 | 이동→준비→타격→후속→후방 도약→착지. 보행 왕복은 걷기 칸 순환과 방향 전환 |
| 점프 정점에 이미 목표 X에 도착해 수직 낙하 | 중간 앵커, 가로 선형 진행과 세로 중력 분리 |
| 공중 대상과 타격 그림의 위치 분리 | 같은 시계로 대상 위치를 따라가는 FX. 사람/몬스터 미리보기에도 적용 |
| 연타 전에 FX 세 개가 겹침 | 반복 FX를 각 접촉으로 재배치하고 꼬리 재생을 단축 |
| 던지기 명중 전에 대상 이동 | 명중 시각까지 원점 유지. 방향에 맞는 포물선 |
| 최대 연타를 편집 경로로 펼치면 복귀가 잘림 | 16타도 48지점 안에 준비/타격/복귀 보존 |
| 순간이동이 두 번 반전되어 앞에 나타남 | 기존 behind 배치를 프로그램 경로에서 해제 |
| 기능 녹화 통과 후에도 압살 타격 자세가 실제 위치보다 앞섬 | WAAPI 자유 재생을 없애고 pauseable clock의 elapsedMs로 직접 샘플링 |

마지막 항목은 기능 검사 결과가 PASS인 상태에서 실제 프레임을 열어 발견했다. 검토 숫자를 애니메이션 품질 점수로 쓰지 않는다.

## 근거

- `trajectory-review.json`: 공용 32종, 명중/빗나감, 접촉 1/3/16개. 좌우 반전, 접촉 전 피해자 정지, 공중 접촉 높이, 홈 복귀, 경로 정규화 보존, 부수 피해의 착지 지연 방지.
- `clock-review.json`: 실제 Chromium에서 반복 히트스톱 4회, 메인 스레드 지연, 양쪽 배우와 자세 콜백의 시각 일치, 종료 정리 확인.
- `native-review.json`: `player.html` 출하 shim에서 실제 입력으로 녹화. 12종 검토 후 시계/순간이동 수정, 영향 있는 6종 재녹화. 빗나감 2종 별도 확인. 히트스톱 중 FX/자세/이동 정지와 후처리 검사 포함.
- `jump-after.gif`, `sky-crush-after.gif`: 최종 시계·몬스터 피격/후속 칸 수정 후 녹화의 480px/15fps 축소본. 원본은 `../adversarial-delivery/`의 640px/20fps.
- `../adversarial-pass1/`: 첫 녹화는 FAIL. 검사기의 스킬 id/연출 id 혼동을 발견해 수정했으며 실패 결과를 덮어쓰지 않았다.
- `../adversarial-final/`: 중간 12종 기능 검토. 여기서 통과했어도 프레임 검토의 시계 결함이 남아 있었으므로 최종 시계 근거로 사용하지 않는다.

- 기존 도트 시트의 자세 칸을 재배치하고 공용 동작/재생기를 수정했다. 전용 도트 그림을 새로 그리지는 않았다. 32종 모두를 고유한 새 원화로 완성했다는 의미가 아니다.
- 카메라/피해 수치/밸런스 규칙을 추가해서 문제를 가리지 않았다. 판정은 기존 엔진 소유다.

- QA용 프로젝트 사본이며 사용자 정본 SQLite 저장의 증거가 아니다.

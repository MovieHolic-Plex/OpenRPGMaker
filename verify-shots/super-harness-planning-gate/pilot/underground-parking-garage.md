### 현대 건물 지하 1층 승용차 주차장

**용도** 현대 건물 이용자가 승용차를 입차·주차·출차하고 안전한 보행로를 통해 계단실로 건물에 출입하는 지하 1층 주차시설. 총12면의 두 주차열과 분리된 입출차 경사로를 갖춘다.

**경험·활동** 콘크리트 천장과 조명 아래에서 주차열 번호로 차를 찾고, 넓은 회전 공간을 이용하며 보행 표시를 따라 계단으로 이동한다. 추적·호러의 배경으로 쓸 수 있지만 기본 시설 이용에 임의 전투·함정·구출 조건은 없다.

**축척** 도면 1칸 ≈ 4타일. ASCII 1칸=가로4×세로4 실제 타일. 도면16×19칸은 계획 범위64×76타일이며 #은 벽 또는 범위 밖. 타일의 미터 환산/법규 인증은 이 기획의 대상이 아니다. 승용차 카탈로그5×3타일을8×4타일 주차면에 수용한다. 주차차로2칸=8타일, 외측 보행로1칸=4타일, 입출차 경사로/방화문/외부 출구1칸=4타일. 회전부8×3칸=32×12타일, 차량 길이5타일에 대해 양 끝을 돌릴 여유를 둔다. 기물/벽을 더하여 유효폭을 깎지 않는다. 경사로는 지하 접속 구간이며 전체 높이/기울기/길이는 후속 구조 설계가 필요하다. 벽/보의 구조 하중 검토는 별도이고 이 계획에서는 차로/회전부 기둥을 요구하지 않는다.

`#` 벽/구역 밖 · `.` 통로 · `+` 문 · `E` 진입 · `X` 외부 출구. 좌표는 왼쪽 위 (0,0).

- **R — 입차 경사로**: (7,1..5), 유효폭1칸=4타일. E(7,0)는 입차 전용이며 남쪽 T로 직진한다. 하단 평탄부 정지선/차단기까지 대기하고, 보행 출입은 계단실을 이용한다.
- **S — 출차 경사로**: (9,1..5), 유효폭4타일. 북쪽 X(9,0)로 올라간다. R과 사이 x=8의 연속 벽은 두 흐름을 분리한다.
- **T — 상하 회전 및 횡단 공간**: 북쪽 (4..11,6..8), 남쪽 (4..11,15..17) 각각32×12타일. C와 경사로 사이 회전 및 끝 주차면 후진 여유. 주차/기둥 금지. 북쪽 y=8과 남쪽 y=15에 동서 보행 횡단 띠를 두고 차량이 양보한다.
- **C — 양방향 주차 차로**: (7..8,9..14), 폭8타일·길이24타일. P/Q 90도 주차 진입과 후진 출차, 양끝 T에서 방향 전환. 정차/가구/기둥 금지.
- **P — 서쪽 주차열**: (5..6,9..14), 한 행마다8×4타일 주차면 하나, 총6면. 승용차5×3타일 그림을 가로로 놓고 C 쪽으로 전진 출차하도록 후진 주차한다. 외측 W쪽 끝에 스토퍼. 주차면 폭4 중 최소1타일은 승하차 및 W 접근 여유이며 전면 차량 배치로 닫지 않는다. 구역 칸은 점유 물체가 아닌 면적 표기다.
- **Q — 동쪽 주차열**: (9..10,9..14), P와 대칭인8×4타일 주차면6개. 차량 전면은 C 쪽, 후단 W 접근 공간과 최소1타일 승하차 여유를 남긴다. P/Q 번호로 자기 차량을 찾는다.
- **W — 외측 보호 보행로**: 서쪽 x=4, 동쪽 x=11의 y=9..14. 폭4타일, 주차면 후단을 따라 이동하며 북/남 T의 표시된 횡단부로 연결. 차로 C를 따라 걷도록 유도하지 않는다. 서쪽 (4,10)에서 +로 L 접근.
- **L — 계단실 전실**: (1..2,9..11),8×12타일. 동쪽 문 +(3,10) 유효폭4타일, 서쪽 X(0,10) 폭4타일은 계단으로 연결되는 추가 보행 외부 출구다. 대기와 계단 첫 단/난간은 통행을 침범하지 않게 배치. X 바깥 계단 전체는 범위 밖.

- **연결 그래프**: E → R → T → C → P → Q → W → L → X — 간선은 E-R, R-북T, 북T-S-X(9,0), 북T-C-남T, C-P, C-Q, P-서W, Q-동W, 두W-북/남T, 서W-+(3,10)-L-X(0,10). via는 노드 목록이고 이 항목만으로 순차 이동을 뜻하지 않는다. 구역 T/W는 서로 다른 위치의 같은 기능을 묶은 기호이며 좌표로 분기한다.
- **입차 및 주차**: E → R → T → C → P — E(7,0)→R 남진→평탄한 북T의 입차 차단기→C 남진→빈 P 또는 Q로 후진 주차. 정산/인식 후 차단기가 열리며 열쇠 퀘스트 없음. 차단기는 북T 접속부 경사로 전폭과 측벽에 맞물려 차량 옆 우회 불가. 보행로는 요금통제 구획이 아니다.
- **출차와 회전**: Q → C → T → S → X — P/Q에서 C로 전진 출차→북T에서 방향을 맞춰 S→X(9,0). 남행 차량은 남T의32×12타일 공간에서 회전 후 C 북진. 차단기는 S 하단 평탄한 북T 경계에 설치하며 출차 인식 후 열림. 차량은 너비3타일 이하·길이5타일 이하 승용차로 한정; 트럭/버스 제외.
- **주차 후 계단 이동**: Q → W → T → W → L → X — Q에서 동W→북T y=8 또는 남T y=15의 표시 횡단부→서W→+(3,10)→L→보행 X(0,10). P는 곧바로 서W에 접속. 차가 있는 면에서도 최소1타일 승하차 틈으로 W에 닿도록 한다. 횡단 시 양방향 C 차량 양보; 경사로 R/S는 걷지 않는다.
- **계단에서 차량으로 복귀**: X → L → W → P — 보행 X(0,10)→L→+→서W→번호 표시된 P; Q는 W→T 횡단→동W→Q. 방화문은 평상시 닫힘, 양쪽에서 열 수 있고 잠금 없음. +(3,10)을 막으면 L과 차고 사이는 완전히 끊기며 y=9/11 x=3 벽으로 옆 우회 불가. L의 외부 계단 X는 별도의 정상 출구이며 통제 우회가 아니다.

**필수 재료**

- 현대 지하 주차장 회색 콘크리트/에폭시 바닥, 경사로 미끄럼 방지 바닥. 도로 아스팔트로 대체하지 않는다.
- 현대 철근 콘크리트 외벽, 경사로 중앙 분리벽, 계단실 구획벽과 연속 모서리.
- 현대 콘크리트 천장과 보. 천장 구조를 잘라 보는 표현에서도 지하 실내임을 식별할 보/설비 재료가 필요하다.
- 8×4타일 주차면 테두리와 구역 번호, 차로 방향 화살표, 정지선, 보행로 및 횡단 표시. 기존 차선 칩으로 주차선을 대신하지 않는다.
- 4타일 유효 폭의 하향/상향 경사로, 측벽, 경사 시작/끝 단차 표현, 배수 홈. 도면은 지하 연결 구간이며 지상까지 전체 경사 길이는 범위 밖이다.
- modern_city 카탈로그 mc-veh-sedan-a/b 계열 5×3타일 승용차. 차체와 접지 영역은 주차면에만 놓고 보행/차로를 침범하지 않는다.
- 진입/출차 차단기 각각의 닫힘·열림 실제 그림과 카드 판독기. 4타일 경사로 전폭을 차량 통제하며 두 정지선은 평탄한 T 쪽에 둔다.
- 현대 천장형 LED/형광등과 회전 공간·보행로 조명. 등기구 실제 그림이 필요하다.
- 천장 배기 덕트, 환기구, 배수구, 벽 붙임 소화 설비. 차량 유효 폭이나 보행로를 차지하지 않는다.
- 폭4타일 보행 띠, 주차면 후단 보호 경계와 횡단 표시. 보행 출입 틈은 각 주차면에 연결하고 돌출 턱으로 보행을 막지 않는다.
- 각 주차면의 외측 후단 휠 스토퍼. W 쪽으로 차량이 돌출되지 않도록 한다.
- 현대 계단실 평탄한 전실과 외부 계단 연결부, 난간과 계단 첫 단 그림. 차량 경사로와 구분한다.
- 계단실 유효폭4타일 방화문의 열린/닫힌 그림. 열려 있을 때 W/L 연결을 확보하고 닫히면 옆벽 우회가 없어야 한다.
- B1/주차열 P·Q 번호, 입차·출차 및 계단/출구 표지. E와 두 X의 기능을 도면 좌표에 맞춰 구분한다.

### 기획 검수 A — PASS


- **modern-b1-parking / identity / PASS**: P(5..6,9..14)/Q(9..10,9..14)의 승용차 12면, C 주차 차로, R/S 분리 경사로, L 계단 전실이 주차시설의 정체성을 만든다. 콘크리트 바닥·벽·천장, B1 표지, 현대 조명·환기·차단기를 요구해 현대 지하 실내로 식별된다. 이용 목적은 입차·주차·계단 출입·출차이며 전투·구출·열쇠 퀘스트를 부가하지 않았다.
- **modern-b1-parking / use / PASS**: 건물 이용자가 E에서 입차 인식 후 빈 P/Q에 후진 주차하고 차량 번호를 확인하여 W로 내려 L의 계단 연결을 이용한다. P/Q는 각 행 1면으로 구분되고 차체 5×3타일 외에 승하차 틈 최소 1타일과 후단 접근 공간을 남긴다. 외측 스토퍼와 보호 경계는 W 통행을 막지 않도록 명시했다. C 및 북·남 T에 주차·가구·기둥을 금지해 차량 조작 공간과 횡단 시야를 확보하며, L(1..2,9..11)의 난간·계단 첫 단·대기는 통행 밖에 배치한다. 공용 차량 구역과 보행 전실의 기능이 구분되고 별도 사적 구역은 필요하지 않다.
- **modern-b1-parking / routes / PASS**: 직접 좌표 추적: E(7,0)→R(7,1..5)→북T(7,6..8)→C(7,9..14)에서 서쪽 P 또는 동쪽 Q로 진입한다. Q(9..10,10)에서 남기는 승하차 틈으로 동W(11,10)→(11,8)→북T 횡단(10..4,8)→서W(4,9..10)→+(3,10)→L(2..1,10)→보행 X(0,10)가 이어지고 복귀도 역순으로 성립한다. 남쪽 횡단은 y=15로 대체할 수 있다. 차량은 P/Q→C→북T→S(9,5..1)→차량 X(9,0), 남행 시 남T(4..11,15..17)에서 회전한다. 보행 횡단과 C의 교차는 표시된 y=8/15에서 양보로 처리하며 R/S 보행을 유도하지 않는다. 열린 문 상태 BFS에서 모든 비벽 칸이 연결되고 +(3,10)을 막으면 차고에서 L 및 X(0,10)에 도달하지 못한다. 방화문은 양쪽 개방 가능·무잠금이고 차단기는 R/S 전폭과 측벽에 맞물리므로 열쇠 순환이나 옆 우회가 없다.
- **modern-b1-parking / boundaries / PASS**: 북쪽 경계 y=0은 E(7,0)와 차량 X(9,0)만 개방되며 R/S 사이 x=8,y=0..5는 연속 #이다. 서쪽 경계는 보행 X(0,10)만 개방되고 동쪽 x=15 및 남쪽 y=18은 전부 #이다. L은 북쪽 y=8,x=1..3 및 남쪽 y=12,x=1..3으로 닫히고 동쪽 x=3,y=9/11의 벽 사이 +(3,10)만 W(4,10)와 연결된다. 북·남 T와 W/C/P/Q의 접속은 명시된 좌표와 일치하며 두 X는 차량·계단 출구로 각각 구별된다.
- **modern-b1-parking / scale / PASS**: 도면은 16×19칸, cellScale=4이므로 범위 64×76타일이다. P/Q 한 면은 2×1칸=8×4타일로 5×3타일 차량을 수용하고 길이 방향 잔여 3타일·폭 방향 잔여 1타일을 확보할 수 있다. C는 2×6칸=8×24타일로 폭 3타일 이하 차량 두 흐름과 90도 주차 조작을 위한 공간이 있다. R/S는 각각 1×5칸=4×20타일의 접속 구간으로 폭 3타일 차량이 통과한다. 각 T는 8×3칸=32×12타일로 길이 5타일 차량의 회전 및 끝면 조작을 수용하고 경사로 연결·횡단 기능이 있어 무용한 홀이 아니다. W·문·출구는 1칸=4타일, L은 2×3칸=8×12타일이다. 경사로 전체 높이·기울기와 구조 하중은 후속 설계 범위로 명시되어 있다.
- **modern-b1-parking / requirements / PASS**: P/Q의 주차선·번호·승용차·후단 스토퍼, C/T의 방향·정지·횡단 표시, W의 보호 띠와 출입 틈, R/S의 경사·측벽·배수·차단기·판독기, L의 전실·계단 첫 단·난간·방화문을 요구한다. 전체 지하 공간에 콘크리트 바닥·벽·천장·보와 환기·소화·배수 설비 및 실제 천장 등기구가 포함된다. R/S 차단기와 +(3,10) 방화문은 열린/닫힌 실제 그림을 요구하고 투명 이벤트나 텍스트로 장치를 대체하지 않는다. 표지는 E(7,0), X(9,0), X(0,10)의 기능을 구분한다. 재고 확보 여부는 이 판정에서 판단하지 않았다.

### 기획 검수 B — PASS


- **modern-b1-parking / identity / PASS**: P(5..6,9..14)/Q(9..10,9..14)의 12개 승용차 주차면, 중앙 C, 분리된 R/S 경사로, L 계단 전실이 지하 주차장 기능을 식별시킨다. concrete-floor/wall/ceiling과 B1 표지, 천장 조명·환기 설비가 현대 지하 실내의 재료와 시대를 뒷받침한다. 추적·호러는 배경 활용만 언급하며 입출차에 전투·구출·열쇠 퀘스트를 붙이지 않는다.
- **modern-b1-parking / use / PASS**: 건물 이용자가 E에서 입차해 P/Q에 후진 주차하고 W를 통해 L 계단으로 이동한다. P/Q는 각 행을 독립 주차면으로 명시하며 차체를 면 안에 두고 최소 1타일 승하차 틈과 후단 W 접근 공간을 남긴다. C(7..8,9..14)와 T(4..11,6..8 및 15..17)는 정차·가구·기둥을 금지하여 주차 조작과 시야를 확보한다. L(1..2,9..11)의 대기·난간·첫 단도 통행 밖에 둔다. 전체는 공용 주차시설이며 차량 통제는 R/S 차단기, 보행 출입은 L로 구분된다.
- **modern-b1-parking / routes / PASS**: 좌표를 따라 E(7,0)→R(7,1..5)→북T(7,6..8)→C(7,9..14)에서 같은 행의 P 또는 Q로 들어갈 수 있다. 출차는 P/Q→C→북T에서 동쪽으로 정렬→S(9,5..1)→X(9,0), 남행 차량은 남T(4..11,15..17)에서 회전해 복귀한다. Q(10,10)→동W(11,10)→(11,8)→북T y=8을 서쪽 (4,8)까지 횡단→서W(4,9..10)→+(3,10)→L(2,10),(1,10)→X(0,10)가 연속이며 역순 귀환도 가능하다. 보행 횡단은 차량과 공유하지만 y=8/15 표시와 차량 양보를 명시하고 R/S 보행은 금지한다. 열린 문 상태에서 두 X가 도달 가능하며 +(3,10)을 차단한 격자 탐색에서는 L과 보행 X가 도달 불가로 확인되어 옆 우회가 없다. 방화문은 양쪽 개방 가능·무잠금이고 차단기는 인식으로 열려 열쇠 순환 문제가 없다.
- **modern-b1-parking / boundaries / PASS**: 도면은 16×19칸이다. 북쪽 y=0은 E(7,0), 차량 X(9,0)만 열리고 서쪽 x=0은 보행 X(0,10)만 열린다. 동쪽 x=15와 남쪽 y=18은 모두 #이다. R/S 사이 x=8,y=0..5는 연속 #이며 북T에서 두 차로가 합류한다. L의 동쪽 경계 x=3,y=9/11은 #, 가운데 (3,10)만 +이고 L의 북·남 경계 y=8/12,x=1..2도 #이라 문을 피해 내부로 들어갈 틈이 없다. 두 X의 역할과 도면 좌표가 범례·동선 설명에서 분리되어 있다.
- **modern-b1-parking / scale / PASS**: cellScale=4이므로 전체 범위는 16×19칸=64×76타일이다. P/Q 각 면은 2×1칸=8×4타일로 5×3타일 승용차를 수용하고 길이 방향 3타일, 폭 방향 1타일의 여유가 남는다. C는 2칸=8타일로 너비 3타일 차량 두 대의 통과 폭을 확보하며 R/S는 각각 1칸=4타일이다. 북·남 T 각각 8×3칸=32×12타일은 길이 5타일 차량의 방향 전환 및 끝 주차면 조작에 쓰이고 횡단 띠를 포함한다. W와 + 및 외부 출구는 각 4타일, L은 8×12타일이다. 벽·기물로 유효폭을 줄이지 않는 조건이 명시되어 있다. R/S의 20타일 길이는 지하 접속 구간으로 한정되어 지상까지 전체 경사 길이나 법규 적합성을 입증한 것으로 간주하지 않는다.
- **modern-b1-parking / requirements / PASS**: P/Q에 parked-sedan·parking-lines·wheel-stop, R/S에 entry-exit-ramp·barrier-state, T/C/W에 선·횡단 표시와 실제 천장 등기구, L에 stair-lobby·fire-door-state가 연결된다. 전체 재료 목록에는 콘크리트 바닥·외벽·분리벽·천장/보, 배수·환기 덕트·벽 붙임 소화 설비, B1 및 입출차/계단 표지도 포함된다. 차단기는 경사로 전폭의 열림/닫힘 실제 그림과 판독기를 요구하고 +(3,10) 방화문도 양 상태 그림을 요구하여 투명 이벤트나 텍스트만으로 장치를 대신하지 않는다. 재고 부족이 예상되는 주차선·경사로·차단기·현대 조명을 필수 재료에서 지우지 않았다.

### 성 지하의 소규모 수감 시설

**용도** 성의 간수가 수감자 세 명을 개별 감방에 수용하고 기록·열쇠·생활 보급을 관리하는 중세 지하 감옥.

**경험·활동** 상층에서 내려와 간수실의 기록과 열쇠 걸이를 지나면 쇠창살 복도와 세 개의 침상 감방이 보인다. 관리 구역과 수감 구역의 경계, 제한된 출입, 작은 생활 공간으로 감옥임을 알아본다.

**축척** 도면 1칸 ≈ 1타일. 한 칸=1타일의 순 바닥 또는 약식 벽 경계. 복도 2칸=2타일, 모든 + 문 1칸=1타일 유효 폭이다. 감방은 5×3타일, 침상 1×2와 오물통 1×1을 두어도 사용 통로 1타일을 확보한다. 계단 그림은 폭 3타일이며 A의 5타일 폭 안에 들어간다. #은 구조 표현의 중심 경계로, 이후 실내 조립 시 북벽의 비통행 벽면 2줄은 순 바닥과 별도로 확보해야 한다. ASCII는 원본 타일 배치가 아니다.

```text
################
#HHHHH#CC#DDDDD#
#HHHHH#CC+DDDDD#
#HHHHH#CC#DDDDD#
###+###CC#######
#BBBBB#CC#FFFFF#
#BBBBB#CC+FFFFF#
#BBBBB+CC#FFFFF#
#BBBBB#CC#######
###+###CC#GGGGG#
#AAAAA#CC+GGGGG#
#AAAAA#CC#GGGGG#
#AAAAA##########
###E############
```

`#` 벽/구역 밖 · `.` 통로 · `+` 문 · `E` 진입 · `X` 외부 출구. 좌표는 왼쪽 위 (0,0).

- **A — 계단 대기실**: 상층 계단에서 내려온 간수와 호송 인원이 신원을 확인하고 잠깐 대기하는 5×3타일의 순 바닥. 계단 하단 접근과 간수실 문까지 중앙 폭 2타일을 비운다.
- **B — 간수실**: 간수 1~2명이 기록·열쇠 관리·출입 통제를 하는 5×4타일의 순 바닥. 탁자 2×1, 의자 1×1을 한쪽에 두고 A/H/C를 잇는 통로 최소 1타일, 관리 철문 앞 2×2타일은 비운다.
- **H — 보급실**: 침구·식기·물의 보관과 반출을 위한 5×3타일의 순 바닥. 상자와 물통을 벽 쪽에 두고 중앙 작업 폭 2타일, 문 앞 1타일을 비운다.
- **C — 감방 복도**: 간수가 순찰하고 식사·침구를 운반하는 남북 11타일, 폭 2타일의 관리 복도. 동쪽 감방 세 곳의 창살과 문이 보여 목적 공간을 찾기 쉽다. 양 끝은 감방 순찰을 위한 되돌아오는 지점이며 별도 외부 출구는 없다.
- **D — 북쪽 감방**: 수감자 1명이 지내는 5×3타일의 순 바닥. 침상 1×2, 오물통 1×1, 벽면 족쇄를 갖추고 문에서 침상 옆·오물통 앞까지 최소 1타일 연속 통로를 비운다.
- **F — 중앙 감방**: 수감자 1명이 지내는 5×3타일의 순 바닥. D와 같은 기물 무리와 사용 여유를 확보하고 독립 잠금으로 관리한다.
- **G — 남쪽 감방**: 수감자 1명이 지내는 5×3타일의 순 바닥. D와 같은 기물 무리와 사용 여유를 확보하고 독립 잠금으로 관리한다.

- **공간 연결 그래프**: E → A → B → H → B → C → D → C → F → C → G — 노드와 간선: E-A, A-B(3,9), B-H(3,4), B-C(6,7), C-D(9,2), C-F(9,6), C-G(9,10). 이외 연결은 없다. 호송·관리·보급 기능으로 정한 나무형 시설이며 임무나 던전 순환을 필수로 넣지 않는다.
- **출근과 열쇠 인수**: E → A → B — E(3,13)에서 A를 북쪽으로 지나 (3,9) 나무문으로 B에 들어간다. 간수가 B의 열쇠 걸이에서 권한을 확보한 뒤 (6,7) 관리 철문을 연다. 열쇠는 잠긴 철문 안에 있지 않다. A-B 문은 근무 시 열려 있고 비근무 시 상층 근무자가 소지한 열쇠로 연다.
- **호송과 감방 출입**: E → A → B → C → D → C → B → A → E — B의 간수가 (6,7) 철문을 열어 C로 호송하고 북쪽 (9,2) 감방문을 별도 열쇠로 연다. F는 (9,6), G는 (9,10)에서 각각 출입한다. 이동이 끝나면 각 문을 다시 잠그며 모든 귀환은 원래 경로이다. 감방문이나 관리 철문 한 칸을 #으로 바꾸면 해당 구역은 완전히 차단되며 옆 우회가 없어야 한다.
- **보급과 순찰**: B → H → B → C → G → C → F → C → D → C → B — (3,4)로 보급실에서 물·침구를 가져와 B를 거쳐 C로 반출한다. C의 2타일 폭은 사람 두 명의 교행과 한 명의 손 운반을 위한 것으로 수레는 사용하지 않는다. 간수가 각각의 감방문을 열고 생활 물품을 전달하며 돌아온다. 복도 남단과 북단에서 돌아설 수 있고 순찰은 감방 바닥을 통과해 다른 감방으로 이어지지 않는다.

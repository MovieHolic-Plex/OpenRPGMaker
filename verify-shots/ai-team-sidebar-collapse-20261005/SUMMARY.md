# 오른쪽 AI 팀 창 접기 · 2026-10-05

실제 편집기 UI를 Chromium에서 조작했다. 기존 실제 모델 실행의 spawn/tool 기록을 화면 상태로 재생하고 완료 상태 하나를 주입했다. 새 모델 호출이나 정본 콘텐츠 쓰기는 없다. 녹화는 실제 브라우저 화면이며 첫 로딩을 생략했다.

`report.json`: 17개 확인 모두 성공, 브라우저 오류 없음.

- 기본 창: 팀 폭 300 → 44px, 캔버스 폭 538 → 794px.
- 접힌 본문은 inert. 펼치기 버튼에 aria-expanded와 표시 상태가 일치한다.
- 조수 완료 상태를 갱신해도 접힘 유지, 실행 중 숫자 2 → 1 갱신.
- 다시 펼치면 같은 textarea 노드·지시 초안·선택 구간 2–6 유지.
- 새로고침 뒤 접힘 복원, 새 팀 활동을 받아도 접힘 유지.
- 크게 보기: 1600/1024px에서 접으면 분할선이 사라지고 대화 폭 확보. 700px에서는 하단 44px 행으로 접힘. 다시 펼치면 상세 영역 복원.
- 크게 보기에서 돌아오면 같은 팀 노드가 원래 편집기 레이아웃으로 복귀.

먼저 볼 증거: `02-collapsed.png`, `03-restored-draft.png`, `04-wide-collapsed-700.png`, `team-sidebar-collapse.mp4`.

첫 관찰은 편집기 부팅 완료 전에 textarea를 조작해서 실패했다. QA 스크립트가 편집기 캔버스가 보일 때까지 기다리도록 보정한 뒤 위 결과를 얻었다. 첫 관찰을 제품의 접기 실패로 집계하지 않았다.

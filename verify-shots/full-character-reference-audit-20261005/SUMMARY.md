## 재현과 검증

시각 검수와 기계 검사를 구분한다. `audit-character-reference-catalog.mts`와 `audit-charset-mappings.mts`로 읽기 전용 스냅샷을 만든 뒤 각 렌더러로 원본 연락 시트를 만든다. `verify-character-reference-routes.mts`는 실제 도구를 호출하고 모든 얼굴·초상을 페이지별로 열거하며 각 걷기 이름의 NPC/리소스 도구 결과와 프레임을 검사한다. 모델 호출 수는 0이며 이를 조수 실모델 시험으로 보고하지 않는다.

실제 Pi 입력·기존 대사 보존·전용 플레이어·SQLite 저장과 새 context 재로드 검증은 `assistant-capability`의 `npc-golem`/`npc-king` 과제로 별도 수행한다. 최종 결과와 원시 로그는 이 폴더에 추가한다. 실패한 최초 검사를 성공 결과로 덮어쓰지 않는다.

몬스터 이름·태그·설명의 독립적인 두 번째 대조에서 20개 누락을 추가 교정했다. 회갈색 박쥐를 보라색으로 부르는 항목, 여섯 다리 상어를 사족보행으로 부르는 항목도 포함된다. 반대로 불지네는 이름의 자줏빛이 실제 픽셀과 맞았고 설명의 붉은색이 틀려 설명을 고쳤다. 첫 도구 전수 검사는 몬스터 원시 ID 검색 160개를 모두 빠뜨리는 문제를 발견했다. 리소스 검색에 정확한 ID 조회를 추가하고 최초 결과를 별도로 보존했다.

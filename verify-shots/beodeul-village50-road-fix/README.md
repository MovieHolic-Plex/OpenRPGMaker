# 버들항 50×50 — 남쪽 포석길 끊김 보정

## 원인

길을 먼저 만들고 건물 전체 영역에 겹친 길을 지웠다. 남쪽 민가 (15,41)의 영역이 대각선 포석길을 잘랐다. 기존 검사는 다른 도로로 우회해 도달해도 통과했으므로 교회에서 북쪽 다리를 돌아 남쪽 다리까지 가는 경로가 이 결손을 숨겼다.

또 흙길과 포석길은 같은 재료의 이웃만 기준으로 가장자리를 골랐다. 두 재료가 붙는 내부 접점에도 잔디 경계가 남아 길이 분리되어 보였다.

## 수정

- 교회 앞 (9,44) → 남쪽 다리 서안 (22,37)을 건물 전체 영역을 피해 이어 붙였다. 북쪽 우회가 불가능하도록 y≥37로 제한했다.
- 새로 포석길로 바꾼 13칸과 실제 통행 근거는 `repair-proof.json`. 지면 레이어의 161칸이 달라졌다. 집·나무·소품·그림자·이벤트·팔레트와 지면 외 모든 맵 필드는 수정 전과 같다.
- 흙길·포석길·다리 갑판 전체의 이웃을 기준으로 도로 경계를 칠한다. 서로 다른 재료 사이의 잔디 틈을 제거했다.
- 남쪽 경로는 포석길과 실제 다리 갑판만 사용하는 canMove로 별도 확인했다. 모든 18개 문 앞과 네 다리 둑의 실제 도로 연결도 유지했다.
- 새 마을 생성기와 공용 참고문서에 동일한 보정을 반영했다. `bd-ground-village50-road-continuity`에 원인·좌표·배치·검사 계약을 추가했다. 새 기본 프로젝트와 현재 프로젝트 모두 공용 문서를 갖는지 확인했다.

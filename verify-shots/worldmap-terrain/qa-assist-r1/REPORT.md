## 도구 사용성 결함 (심각도 순)

1. 글자 지도·도식이 실제 렌더와 다르다.
   - 3번에서 'j' 인 칸이 그림에서는 모래로 나왔다.
   - 도식은 테마를 무시하고 늘 판타지 색이다. snow-north 와 desert-east 도식이 fantasy 와 같다.
   - 조수는 미리보기만 보고 「정글 완료」라고 보고하게 된다.
   - 고칠 것: 미리보기 글자·도식을 최종 렌더의 바닥 판정(후처리·테마 팔레트 반영 뒤)에서 뽑는다. 아니면 최종 빌드 결과에 「요청 바닥 대비 실제 렌더 바닥」 차이 경고를 붙인다.

2. 장소별 숨은 여정 규칙이 안 보인다.
   - 사막 신전은 비공정 열쇠이고 사구 바다에서만 닿아야 한다.
   - 화산은 화염 요새와 길로 묶여 있다.
   - 실패해야 알고, 실패 문장도 「설계 4막 / BFS 3막 / R2」 같은 내부 용어다.
   - 고칠 것:
     - places 줄마다 「설계 막·처음 닿는 수단(걷기/통행증/배/사막선/비공정)·길로 이어진 상대 장소·이동 제약」을 넣는다.
     - 막 불일치 문장은 「사막 신전은 사막선(사구 건너기)으로만 처음 닿아야 하는데 걸어서/배로 닿는다 — 둘레를 사구로 두르고 길·해안에서 떼라」처럼 사람 말로 풀어 쓴다.

3. 「길을 낼 수 없다」에 막힌 자리와 길 목록이 없다.
   - 조수는 어느 '=' 줄이 그 길인지 모른다.
   - 바다는 길이 못 건너고 강에만 다리가 생긴다는 규칙도 없다.
   - 고칠 것:
     - 실패 문장에 「막힌 칸 x,y(작업 n 이 만든 바다/산)」를 넣는다.
     - read 의 data 에 길 목록(장소쌍과 지나는 칸 몇 개)을 준다.
     - OP_HELP 에 「길은 바다를 못 건넌다(강은 다리). 해협을 길이 가로지르면 둑길을 남겨라」를 넣는다.

4. edit_world_terrain 이 여정 검사에 실패하면 ascii·그림·경고를 돌려주지 않는다.
   - read_world_terrain 에 같은 ops 를 넣으면 보인다는 사실을 조수가 알 길이 없다.
   - 고칠 것: journey-check-failed 오류에도 ascii(문제 장소 주변 발췌)와 warnings 를 싣는다. 또는 오류 문장에 「read_world_terrain 에 같은 ops 로 지형을 보라」를 적는다.

5. 바닥이 말없이 바뀐다.
   - biome dune 을 x≥60 에 칠하면 모래(s)로 바뀐다. 사구는 서남 사구 바다에만 남는다.
   - 경고가 없다. 스키마의 ground 영문 이름과 범례 글자(d 모래언덕·s 사막·D 흙)를 잇는 표도 없다.
   - 고칠 것:
     - kit_terrain 의 「작업이 실제로 먹은 양」 경고를 biome 에도 적용한다(「dune 칸 40 중 0 — 동쪽 사구는 모래로 바뀐다」).
     - ground 설명에 「글자: grass . / sand s / dune d / dirt D …」 대응표를 넣는다.

6. 범례에는 있는데 만들 수 없는 지형이 있다.
   - V 화산, o 분화구, L 용암, x 독늪, c 균열이 그렇다. 「화산섬」 요청을 이룰 수 없다.
   - 고칠 것: ridge kind 에 volcano(분화구·용암 포함)를 더한다. 못 하면 설명에 「화산·용암·균열은 만들 수 없다」를 적는다.

7. 경고의 작업 번호가 0부터 센다.
   - 「작업 2(forest)」는 ops[2] 다. 3번에서 ops[1]·ops[2] 가 모두 forest 라 어느 것인지 헷갈렸다.
   - 고칠 것: 1부터 세거나, 「ops[2]」로 쓰고 note 를 함께 보인다.

8. 숲 경고 문장이 사실과 다르다.
   - 「바닥 jungle 16 … 숲은 sand·dune·물·길·장소 둘레에는 안 자란다」라고 하지만 바닥은 전부 정글이었다. 그런데 16칸 중 2칸만 숲이 됐다.
   - 고칠 것: 정글 바닥에서도 숲이 적게 나는 실제 이유(density 문턱·장소/길 둘레 여백)를 쓰거나, 남은 칸 원인을 나눠 센다.

9. 테마의 지형 의미가 설명에 없다.
   - desert-east·snow-north 도 같은 지형 배치이고 그림만 다시 칠한다.
   - 사용자 말(「동대륙 사막」「북쪽 설원」)과 실제 배치가 다를 수 있다는 것을 조수가 모른다.
   - 「사막 신전」 같은 장소 이름도 모든 테마에서 같다.
   - 고칠 것: read 결과에 「테마는 화풍만 바꾼다. 지형·장소 배치는 공용 shared-v9」를 넣고, 대륙별 주요 바닥 요약(서대륙 남쪽 대사막 등)을 한 줄로 준다.

10. river 의 widen 이 기대대로 안 된다. widen 0 을 줘도 한 칸 폭이었다.
    - 고칠 것: 설명에 「widen 은 하류 비율, 0 이면 처음부터 두 칸」이 맞는지 확인한다. 아니면 폭(width)을 직접 받는다.

11. 「작업이 없으면 공용 캐시를 쓴다(즉시)」는 주석과 다르다. desert-east 빈 ops 빌드가 109초 걸렸다.
    - 고칠 것: 테마별 기본 지도 캐시를 미리 굽거나, 설명에 「첫 빌드는 테마마다 2분」을 적는다.

12. 도식 그림에 칸 눈금 숫자가 없다(가장자리 틱뿐). 그림만 보고는 좌표를 읽기 어렵다.
    - 고칠 것: 10칸마다 숫자 라벨이나 옅은 격자를 넣는다.

# AI 첫 요청 화면 개선 — 2026-10-05

## 근거

실제 편집기에서 초기 사용자 화면과 기존 조수/로그 조작을 확인했다.
`QA_HTTP_RELAY=1 node scripts/qa/ai-first-user.mjs`로 재현한다.
로컬 Vite의 실제 응답을 Playwright HTTP 클라이언트로 전달하여 이 호스트의
`ERR_NETWORK_CHANGED`를 우회했다. 큰 프로젝트 자료(`/__oprn/`)는 원래 HTTP 경로를
유지한다. 모듈/화면 데이터를 바꾸거나 화면 DOM을 검수용으로 교체하지 않았다.
선택한 팀 실행 영수증만 제어된 UI 재생이다. 모델 호출·콘텐츠 저작·SQLite 저장 검수가 아니다.

- 선택한 조수·전체 실행·보관 기록의 복사/TXT/JSON은 실제 클립보드와 다운로드로 확인했다.

- MP4: `ai-first-user.mp4`, 32.76초, H.264/yuv420p, 1600×1000. 실제 조작 녹화에서 로딩 구간만 잘랐다.

## 확인의 범위

전체 gates/Vitest/typecheck는 세션 실행 제한에 따라 로컬에서 실행하지 않았다.
변경 TS 파일의 esbuild 구문 검사, QA 스크립트 구문 검사, 카탈로그 JSON 파싱,
`git diff --check`를 통과했다. 재로드 검증은 포함하지 않으며 저장된 보기 값과
현재 화면의 접힘/복원을 확인한다. CI 결과는 GitHub PR 체크에서 별도로 확인한다.

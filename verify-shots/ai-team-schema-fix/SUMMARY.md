# 팀 실행에서 발견한 오류 수정

- before: 글꼴 스키마의 빈 enum 문자열 때문에 Gemini가 두 조수 실행을 HTTP 400으로 거부했다. 실패 보드와 마지막 성공 문구가 불일치했다.
- after: 같은 종류의 실제 조회 작업에서 두 조수가 완료했다. 배정 전 지시 초안이 유지됐고 SQLite 재로드가 일치했다.
- after는 폴더 아래 형제 맵으로 요청했지만 정본 로드가 폴더를 첫 맵으로 바꾸는 문제를 추가 확인했다. 이 상태에서 배정이 직렬화된 것은 올바른 소유권 보호다. 별도 실제 맵 루트를 사용하는 병렬 실측으로 분리한다.
- `../ai-team-failure-copy-probe/`는 실제 실패 사례를 재현하는 통제된 브라우저 응답이다. 모델 실행 근거와 구분한다. 최종 팀 보고 표시, 실패 캡션, 거짓 성공 문구 제거를 확인했다.
- `../ai-team-review-probes/`는 배정 시 초안·커서 보존, 완료 시각 정렬, 중단 도구의 성공 오표시 방지를 확인한 통제된 브라우저 조사다.
- 단위 테스트 사례는 추가했으며 AGENTS 세션 제한에 따라 실행하지 않았다.

## 수정

- 나무/작은 구형 덤불을 겹침 없이 흩어 놓던 배치를 원본 수관이 앞뒤로 겹치는 숲 8덩어리로 교체했다. 각 합성은 실제 지면 접점 y 순서로 원본 3종의 수관/목/뿌리를 합성한다. 수관끼리 실제로 가리는 픽셀은 조각당 489~1,772개다. 밝은 기본 잔디와 집 위치·길·마당을 유지했다.
- 풀이 마당 가운데 독립된 수평 줄처럼 보이지 않도록 숲 밑동에 겹쳤다. 풀에는 밑그늘·짙은 뿌리·서 있는 잎·밝은 잎끝이 있다. ★ 풀은 아래 줄기 X를 상속한다. 모든 숲 줄기/울타리 접점의 실제 충돌을 확인했다.
- 남쪽 잔디에 짧은 문틈 울타리 2개를 따로 놓은 것을 제거했다. 실제 텃밭 서/동/남변을 연속 레일·수직선·모서리로 연결하고 북쪽은 큰길에서 들어가는 열린 면으로 남겼다.
- 위쪽 세 번째 집의 회벽 박공을 아래층과 같은 원본 돌벽 질감으로 통일했다. 원래 지붕·알파 윤곽·한 문·원형창·집 위치를 보존했다. 지붕 상단 행 안에도 박공 벽이 있으므로 하네스는 stone의 밝은 회벽 픽셀만 허용하고 실제 지붕 픽셀은 그대로인지 검사한다.

# 버들항 — RPG 시설과 작업 마당

## 반영한 것

기존 50×50 마을의 18개 건물과 황록 나무를 유지하고 다섯 건물에 생활 역할을 부여했다.

| 시설 | 원래 건물 원점 | 주변 조각 |
|---|---|---|
| 약초사 집 | (3,6) | 약초 말리는 틀, 두 약초 이랑 |
| 발명가 집 | (42,7) | 혼천의, 태양계 모형 |
| 강바람 술집 | (28,20) | 술병 좌판, 입간판, 기존 주막 마당 |
| 항구 창고 | (14,30) | 상자·자루 더미, 생선 궤짝 |
| 나루터 사무소 | (28,39) | 널판 잔교, 계선주, 나룻배, 입간판 |

기존 대장간 곁에도 모루와 주괴를 놓았다. 잔교는 (25,46)의 완전한 3×3 조각으로 물가 경계까지 덮는다. 육지 (28,47) → (27,47) → 잔교 (26,47)를 실제 canMove로 연결했다. 지면은 이 잔교의 9칸만 바뀌었다. 원래 존재한 모든 상위 조각, 건물/지붕/창문/벽색/나무, 2·4층 그림자·접점, 이벤트, 기존 네 맵과 이미 쓰던 타일의 통행·우선순위는 대조해 보존했다.

## 공용

- `bd-facility-*` 외장 조립안 32종: 완전한 기존 건물 하나와 작업 마당 소품 둘을 합성한다. 여러 역할이 같은 원본 건물을 사용한다. 새 건물 그림 32개를 그린 작업은 아니다.
- 새 city 정의와 기존 프로젝트 보충 경로 모두 배선했다. 실제 `defaultTilesets()`의 32개 키트와 기존 프로젝트의 32개 키트/공용 자료를 확인했고, 반복 적용은 no-op이다 (`fresh-proof.json`).
- source 정본 `tiledata/beodeul-facilities/`, 준비기 `scripts/content/prepare-beodeul-facilities-references.mts`, 번들 `src/assets/beodeulFacilitiesReferences.json`. 독립 용도 `beodeul-facilities`, MD 17쪽·정적 그림 10개. JSON에 이미지 바이트가 없다.
- 모든 32개 조립안의 완전한 배열/입구/통행/source graft, 실제 네 층 표본, 현재 마을 전체 네 층과 배치표를 제공한다. 코드와 native PNG를 실제 렌더했으며 시설 도안 판을 열어 확인했다. 학습 사본만 128색이고 사용자의 그림은 RGB 무손실이다.
- 약초사 문앞 (5,12)에 실제 칼통을 놓은 `blocked-facility-entrance` 오류에서 (5,13)→(5,12) canMove가 true→false로 바뀐다. 정상/오류 그림을 열었다 (`assembly-proof.json`).
- 시설 키트는 외장·작업 마당 도안이다. 판매/회복/은행/훈련/대화 시스템과 새 실내·전이 이벤트는 이 변경에서 저작하지 않았다.

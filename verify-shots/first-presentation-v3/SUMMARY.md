# 실제 첫 제작: 타이틀·그림 오프닝

## 수정

첫 제작 도구 목록에 타이틀 저작이 빠져 있었고, 기존 첫 장면 지침은 오프닝을 끄도록 했다.
Pi의 그림 생성 도구도 실제 생성 대신 UI 요청만 반환했다.
전용 제작 단계와 실제 이미지 생성·등록·연결을 추가했고, 활성화된 그림 오프닝과 실제 원화 전달을 독립 검수의 필수 조건으로 만들었다.
실제 플레이어에서 발견한 효과 캔버스의 원화 도트 확대, 오프닝 그림 여백, 한국어 자막의 낱말 중간 줄바꿈도 수정했다.

- 원문: `actual-first-task.txt` — 39,767자. 새 프로젝트의 첫 AI 요청 한 번으로 제작했다.

- 타이틀은 빛·입자·시계 발광·카메라 효과와 로고/메뉴 등장 순서를 가진다.
- 오프닝은 서재와 회중시계를 보여 주는 그림, 줌, 짧은 서술, 5.5초 자동 진행, 건너뛰기로 구성됐다.

- 최초 생성 호출에 들어간 예제 부제는 AI가 최종 타이틀 설정에서 한국어 작품 부제로 수정했다.
- 게임 데이터와 그림을 손으로 보수하지 않았다. 표시 엔진을 수정한 뒤 같은 저장본을 다시 내보냈다.

## 검증 범위와 남은 문제

- `build:app`, `build:player`를 수행했다. 로컬 Vitest·gates·전체 typecheck는 세션 규칙에 따라 실행하지 않았다.
- 기본 headless Chrome의 첫 탭은 AI 요청 전 충돌했다(v1). 성공한 첫 제작은 6GiB 힙 설정으로 관찰했다. 일반 데스크톱의 메모리 안정성을 증명한 결과는 아니다.
- v2는 진입 안내 단계가 다음 단계에서 만들 오프닝을 미리 요구하는 오류를 발견해 중단했다. 단계 경계를 고친 뒤 v3를 새 프로젝트에서 처음부터 실행했다.
- 첫 사용자 확정→첫 저장 173.421초. AI 요청까지 약 136.7초, 모델 요청→첫 저장 약 36.7초였다.
- 모델 실행 952,816ms(약 15분 53초), 142턴·180도구 호출·10도구 오류. 확정→완료 관찰/재로드까지 1,105초였다. 별도 이미지 생성/맞춤 호출의 비용 전체를 산출한 수치는 아니다.
- 회상 게임에도 체력 HUD가 붙는다. 이미지 원화와 실제 도트 맵의 외형 차이도 남아 있다. 이번 결과를 베타 완성이나 전체 게임 품질 합격으로 판정하지 않는다.
- 초기 여백/도트 확대 증거는 `qa-before-smooth-cover/`에 남겼다. 빌드 순서 실수로 플레이어 산출물이 지워져 내보내기가 실패한 기록도 `export-build-order-failure.json`으로 보존했다.
- 전체 플레이어는 앱 빌드 다음 플레이어 빌드 순서로 재구성했다.

## 최종 플레이어 검증

- 내려받은 ZIP을 수정하지 않고 풀어 `player.html` 전용 런타임 경로로 확인했다. 에디터 play 경로를 사용하지 않았다.
- ZIP 350,202,865바이트, 4,170항목. 내보내기 오류·누락 요청 없음. 이 큰 패키지 크기는 남은 개선점이다.
- 플레이어 SDK artifact `4c88079802161cab`, sourceDigest `320ea9f9b9ea4a4fb81b991300646a936942fb4c3237cab9ff5543ab60299c3a`, sourceRevision `d27f12e3f6`, schema 4. 이후 통합한 main 변경은 문서/QA 기록뿐이며 표시 코드가 바뀌지 않았다.
- 두 선택 각각 7개 확인 지점(타이틀→그림 오프닝→조작 반환→시계 조사→선택 결과 대사→기억의 길→엔딩), **14/14 통과**, 런타임 오류 없음.
- 실제 프로젝트의 system/database/endings와 저장된 맵·이벤트·타일 레이어를 비교했다. 원화 파일의 SHA256 및 길이도 정본과 같다.
- 타이틀의 실제 WebGL/animation, smooth 합성, 표시 무대에 맞는 캔버스 크기를 확인했다. SwiftShader의 기존 0.5 해상도 배율은 유지한다.
- 오프닝의 실제 1376×768 그림 로드, zoom, cover, keep-all 자막을 확인했다. 오프닝을 건너뛰지 않고 자연 재생했다.
- 전체 무대는 4:3 비율을 유지한다. 1280×900 녹화 창에서는 좌우 40px 여백, 게임 무대는 1200×900이다. 원화는 이 무대를 채운다.
- 실제 방향키·Enter·선택 번호만 사용했다. 위치 순간이동이나 이벤트/세이브 조작, reduced motion으로 연출을 생략하지 않았다.
- 첫 갈래 영상에는 읽기 시간을 위한 대화 2.5초/샷 1.8초 대기만 추가했다. 게임 내용·재생 속도는 바꾸지 않았다.
- SUMMARY를 먼저 읽은 뒤 타이틀·오프닝·첫 필드·양쪽 엔딩 샷을 직접 검토했다. 원화가 더 이상 큰 도트로 확대되지 않고, 오프닝 그림과 자막이 제대로 표시된다. 공간 구성과 전체 게임 경험의 품질 합격은 별개다.
- `title-opening-to-first-play.gif`는 실제 첫 갈래 녹화에서 타이틀 등장부터 첫 선택 결과까지 시간 구간만 잘라 만든 1배속 GIF다. 자세한 범위는 `gif.json`에 기록한다.
- CI는 PR의 Actions에서 별도 실행된다. 로컬 전체 게이트를 수행했다고 보고하지 않는다.

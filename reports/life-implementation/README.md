# 갱신 — 실제 표면 검증 확장 (Task 18 완료 시점)

이전 판에서 "하네스 한계로 미증명"이라 적었던 항목들이 **실제로는 잘못된 하네스를 쓴 결과**였다.
`scripts/qa/runtime` 은 `input.ts:injectActionEdge()` 로 **Phaser 키 매니저**에 엣지를 주입하는데,
상태 메뉴는 **DOM 이 window keydown 을 듣는다**. 그래서 월드 조작(경작·수확)은 되고 메뉴만 안 열렸다.
계획서가 처음부터 지정한 `playwright.runtime.config.ts` 를 쓰자 첫 시도에 열렸다.

- 계획이 요구한 **행별 happy+failure** 중 failure 는 `기부중복` 만 라이브다. 나머지 실패·경계 계약은 `rows.json` 이 행마다 지목하는 **모듈 테스트**로 덮인다.

진단 — 왜 허접한가

코드로 확인된 7가지. 숫자로 보면 바로 보인다.

Before 실화면 — 고치기 전 에디터final-01-overview (보정 전)
고치기 전 전체 뷰. AI 패널 도킹 + 맵 + 타일 팔레트. 버블 96% 폭에 여백 없이 붙고, 휘발존 경계 없음 — 어디가 채팅이고 어디가 맵인지 구분이 흐리다.
Before 클로즈업 — 입력·상태final-02-panel
입력창 32px 높이, placeholder에 3가지 규칙이 한 줄. 상태는 idle이면 숨김, 큐 표시는 2px 패딩 텍스트. 스킬은 TUI 한 줄 목록에 묻힘.
2

버블·입력 — 읽히게

P0. 96% 꽉 찬 TUI를 72% 프리미엄 버블로. 말풍선 꼬리·대비·여백이 스캔을 만든다.

Before → Premium — 버블 대비04-chat-bubbles-proposals.css
바뀐 파일: 04-chat-bubbles-proposals.css — 버블 14px radius + 꼬리(4px/14px), max-width 72%/78%, line-height 1.6, 입력 44px + focus ring, 전송 버튼 hover lift. aiChatPanel.ts placeholder를 한 줄 암호에서 "어떤 맵을 만들까요?"로 단축.

왜 이렇게 했나

채팅은 스캔이 생명이다. 96% 꽉 찬 블록은 눈이 쉴 곳이 없고, transparent AI 버블은 "누가 말했는가"를 300ms 안에 알려주지 못한다. 72% + 꼬리 + 대비는 화자 구분 1순위를 복원한다. 입력 44px는 터치 타깃(44×44) 기준을 만족한다.

입력 placeholder는 규칙 나열이 아니라 초대다. "어떤 맵을 만들까요?"가 "Enter 규칙 3개"보다 전송률을 높인다 — 후자는 입력창 아래 힌트로 옮겼다.

빈 상태·피드백 — 길을 잃지 않게

P1. 빈 화면이 막막하지 않게, 진행 중엔 뭘 하는지 보이게.

휘발존 — 사라지지 않게assistant-rising-overlay.css + helpers.ts
Before: opacity:0 + translateY(8px) + pointer-events:none — 사라짐.
Premium: opacity:0.42 + translateY(4px) + pointer-events:auto — 옅어지되 남아있음. 6s → 12s.
ai-chat-log — 18vh/200px → 22vh/240px, min-height 72px + 8px pad + blur 10px + 14px radius. chat-log가 텅 비어 보여도 최소 높이 유지.
idle 상수 — VOLATILE_OVERLAY_IDLE_MS 6000 → 12000 (helpers.ts). 빈 방에서 휘발존이 2배 오래 버틴다.

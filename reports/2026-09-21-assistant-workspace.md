# 조수 작업창 재구성

- 상단에 제목·표시 수준·축소를 모으고 팀 상세의 중복 표시 설정을 제거했다.
- 대화/팀 기본 너비는 70:30이다. 경계선 드래그와 키보드 조절, Home/더블클릭 복원을 지원한다.
- 팀은 이름·상태·최근 작업을 목록으로 보여 주고 선택한 팀원 기록을 아래에 표시한다.
- 기본 표시는 짧은 타임라인, 매우 자세히는 시간·담당·작업·상태·소요 시간을 정렬한 목록이다.
  실행 ID는 펼친 행 상세에만 표시한다. 별도로 전달된 경고·설명은 추가 안내로 남긴다.
- 카드 테두리와 중복 제목을 줄이고 입력은 기본 두 줄 높이로 조정했다.

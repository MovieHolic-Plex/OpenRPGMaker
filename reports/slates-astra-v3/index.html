같은 17×15칸 범위로 비교하기

참고 그림은 약 17×15칸의 장면이다. 넓은 50×50 지도를 축소한 화면만 비교하지 않고, 새 지도의 세 구역을 같은 범위로 확대했다.

다음 에이전트가 읽을 문서를 어떻게 바꿨나

  1. 밀도 50~65%를 필수 조건으로. 미달하면 배치를 다시 만든다. 건물 수나 사각 스탬프 면적으로 대신하지 않는다.
  2. 길 주변의 모든 빈 땅을 검사. 기본 골목은 1칸, 주거리는 2칸. 우물 공터 4×4·정원 5×5 이외의 넓은 빈 공간을 남기지 않는다.
  3. 이미 배운 건물의 원본 조립 연산을 재사용. 비교용 패딩을 제거하고 실제 몸통·문앞 좌표로 배치한다.
  4. 줄 맞춘 배치와 건물 겹침을 반려. 앞선과 길을 꺾고, 창·문·기단이 다른 건물에 잘리지 않는지 확인한다.
  5. 전체 지도와 확대 세 곳을 함께 제출. 밀도 수치, 원본 출처, 통행, 실제 저장 근거를 각각 남긴다.

확인 및 저장 근거

실제 에디터에서 68개 접근 지점·700칸 연결을 확인했다. 성문을 막으면 외곽으로 누출되지 않는다. 남문 밖에서 안쪽으로 실제 이동했고, Supabase와 로컬 SQLite 저장 후 재로드가 일치했다. 원본 1,232슬롯을 보존하고 합성 타일 165개를 추가했다.

영역 다듬기 — 선택한 칸을 주변에 이어붙이기

선택 영역 AI 작업에 「주변과 어울리게 다듬기」 경로를 추가했다. 영역 안에서는 타일·이벤트 전권을 주고, 대신 주변을 읽어 브리핑하고, 결과가 주변과 얼마나 맞물리는지 숫자로 검토시킨다. 화면·수치는 모두 실제 실행에서 캡처한 것이다.

3새 모듈 (626줄)
36새 단위 테스트
146관련 테스트 전체 통과
12수정 파일 (+516/−48)
6E2E 캡처 시나리오

01한 줄로

기존 영역 AI 작업은 영역 안만 봤다. 그래서 마을 한복판을 8×6 으로 잡아 무엇을 만들면, 만들어진 것 자체는 그럴듯해도 경계에서 뚝 끊긴 네모난 흉터가 남았다. 다듬기는 같은 파이프라인에 세 가지를 더한다. 주변 3칸 띠를 읽어 브리핑으로 넣고, 검토 화면에 여백을 포함한 프리뷰와 어울림 점수·경고를 붙이고, 적용 시 경계 오토타일 이음새를 자동 마감한다.

주변을 읽는다

regionSurroundings.ts — 영역 밖 3칸 띠의 재료 구성, 길이 맞닿는 칸, 걸어 들어오는 칸, 이웃 이벤트를 뽑아 한 문단으로 만든다.

전권을 준다

regionPolish.ts — "새로 만들지 말고 이어붙여라". 영역 안은 바닥·소품·이벤트 전부 재배치 가능, 영역 밖은 금지.

맞물림을 잰다

regionBlend.ts — 초안이 경계에서 어긋난 칸, 새로 막은 진입, 끊은 길을 세어 0~100 점과 경고로 돌려준다.

02들어가는 문 — 선택 → 다듬기

영역을 잡으면 칩 바에 다듬기 가 붙는다. 기존 AI 작업 옆이라 한 번의 클릭으로 다듬기 모드로 모달이 열린다.

즉 입구가 셋이다. 선택 칩 다듬기, 모달 하단 버튼 주변과 어울리게 다듬기, 추천 칩 주변과 어울리게. 어디로 들어와도 같은 mode: "polish" 실행이다.

03AI 가 실제로 받는 것

브리핑은 좌표까지 박아 넣는다. 아래는 실제 프리셋 지형(왼쪽 호수, 위쪽 숲, 가로지르는 흙길)에서 analyzeRegionSurroundings → formatRegionSurroundingsBrief 를 돌린 출력이다.

주변 상황 (영역 밖 3칸 띠, 좌표는 절대 맵 좌표):
- 위쪽: Grass 24칸 · 위층: Tree 8칸
- 오른쪽: Grass 15칸, Dirt road 3칸
- 아래쪽: Grass 24칸
- 왼쪽: Grass 10칸, Lake water 5칸, Dirt road 3칸
- 길이 영역과 맞닿는 칸(안쪽 좌표) — 영역 안에서 끊지 말고 이어라: (8,8) (15,8)
- 바깥에서 걸어 들어오는 칸(막지 말 것): (8,6) (8,11) (9,6) (9,11) (10,6) (10,11) (11,6) (11,11) …외 20곳
- 주변 이벤트: ev_guard(18,8), ev_shop(6,9)
현재 영역 안 (8×6=48칸): Grass 40칸, Dirt road 8칸
- 영역 안 이벤트 1건: ev_chest[ev_chest](10,8)

이 브리핑이 다듬기 지시문 안에 들어가 총 1,781자 / 39줄의 메시지가 된다. 핵심은 두 문단이다. 영역 안 전권을 열어 주는 문단, 그리고 밖을 건드리지 말라는 제약 문단.

다듬기 메시지 전문 보기 (실제 전송 형태) 
이 영역을 주변과 자연스럽게 어울리도록 다듬어줘

(영역 다듬기: 타일 지형 길 물 나무 소품 이벤트 npc)
이번 작업은 「다듬기」다 — 새로 무엇을 세우는 것이 아니라, 이 영역이 주변에 이어붙인 듯 보이게 만드는 것이 목표다.
영역 안에서는 전권이다:
- 바닥·지형을 전부 갈아도 된다 (fill_region / paint_road / tile_erase). 주변 우세 재료를 영역 안까지 끌고 들어와라
- 소품은 다시 배치해도 된다 (place_props). 주변에 나무가 있으면 영역 경계 쪽에도 나무를 물려 심어 띠가 끊기지 않게 한다
- 영역 안 이벤트(NPC·상자)는 move_event 로 옮기거나 필요하면 지워도 된다. 단 **영역 밖으로는 옮기지 말 것** — 밖으로 나간 좌표는 원위치로 되돌려진다
지켜야 할 것:
- 영역 밖 타일·이벤트는 수정하지 말 것 (경계 오토타일 이음새는 시스템이 자동으로 마감한다)
- 주변에 없는 재료를 새로 들여오지 말 것. 지금 주변에 깔린 재료로 맞춰라
- 통행을 막지 말 것 — 바깥에서 걸어 들어오는 칸은 영역 안에서도 걸을 수 있어야 한다
- 길 연결 필수: (8,8) (15,8) 칸은 영역 안에서 길로 이어져야 한다. paint_road 의 points 에 이 좌표를 포함시켜라
- 진입 유지: (8,6) (8,11) (9,6) (9,11) (10,6) (10,11) (11,6) (11,11) 는 통행 가능해야 한다

다듬기 도구 규칙:
- 먼저 get_map_region 으로 영역과 그 주변을 한 번 확인한 뒤 손대라(아래 브리핑으로 부족할 때만)
- 지면/수역: fill_region { material:"잔디"|"물" … } — 원형·둥근 지형은 shape=circle
- 길: paint_road { mapId, style:"dirt"|"sand", points:[{x,y},…] }
- 소품: place_props + material(타일 라벨, 예 "침엽수"·"꽃"). 그룹 id·가방 금지. 물 칸 위 금지

- tile_query ask:"labels" 는 mapId:"m_report" 를 넣어 이 맵 타일셋 라벨만 조회
- 새 맵을 만들지 말 것 (create_map / duplicate_map / start_interior_room_session 금지). 대상은 지금 열린 이 맵뿐이다
- 지원하지 않는 요청 부분은 시도하지 말고, 마지막 응답에 '못 한 것: …' 한 줄로 명시하라
- 결과는 사용자 승인 후에만 반영된다. propose_tile_vocabulary 댄스는 하지 말 것

04검토 — 여백이 보이는 프리뷰

다듬기는 "주변과 맞물리는가"를 보는 작업이라, 영역만 잘라 보여 주면 판단이 불가능하다. 그래서 다듬기 검토는 프리뷰를 영역 + 바깥 2칸으로 넓히고 영역 경계를 점선 액자로 표시한다.

「이전 | 이후」 토글은 같은 프레임을 그대로 쓰므로 배경이 고정된 채 영역 안만 갈린다.

05경고 — 길을 끊거나 문을 막으면

더 나쁜 초안을 넣어 봤다. 영역 안을 벽으로 채워 바깥에서 들어오던 길과 진입을 전부 막은 경우다.

  • 주의 · 바깥 길이 영역 경계 (10,10)에서 끊깁니다 — 영역 안으로 이어지지 않았습니다. [map_village_30_100x100 10,10]
  • 주의 · 바깥 길이 영역 경계 (6,7)에서 끊깁니다 — 영역 안으로 이어지지 않았습니다. [map_village_30_100x100 6,7]
  • 주의 · 바깥에서 들어오던 칸 (6,5)이 새로 막혔습니다. [map_village_30_100x100 6,5]
  • 주의 · 바깥에서 들어오던 칸 (6,10)이 새로 막혔습니다. [map_village_30_100x100 6,10]
계약: 다듬기 경고는 적용을 막지 않는다. 위 화면에서 적용 · 48칸 버튼은 그대로 활성이다. 막힌 길이 의도일 수도 있기 때문이다(성벽, 폐쇄된 구역). 판단은 사용자에게 남기고, 시스템은 무엇이 끊겼는지 좌표로 말한다. 반대로 영역 밖으로 이벤트를 옮기는 것은 경고가 아니라 되돌림이다 — 좌표를 원위치로 클립한다.

06이음새 — 딱 1칸의 예외

영역 밖은 건드리지 않는 게 원칙인데, 오토타일 경계는 예외가 필요하다. 잔디와 모래가 만나는 칸의 모양은 양쪽이 결정하므로, 영역 안만 고치면 밖의 경계 칸이 옛 모양으로 남아 이가 어긋난다.

그래서 적용 시 경계 마감 패스가 영역 밖 1칸까지 오토타일을 다시 계산한다. 위 모래 초안을 실제로 적용한 뒤 영역 밖 1칸 링을 전수 비교한 결과, 바뀐 칸은 1칸(10,11) 이었다. 클립 검사도 이 1칸을 차단 사유가 아니라 seamCells 로 따로 보고한다.

09남은 것

  • 어울림 점수의 절대값은 아직 거칠다. 경계 어긋남·막힌 진입·끊긴 길의 가중 합이라, 점수 자체보다 이전 → 이후 변화와 경고 목록이 신뢰할 만한 신호다.
  • 브리핑 띠는 3칸 고정에 가깝다. 영역이 아주 클 때 3칸 띠는 상대적으로 얇다 — 영역 크기 비례 확장은 후속.
  • 위층(소품) 어울림은 부분적이다. 재료 구성은 읽지만, 나무 띠가 이어지는지 같은 형태 판단은 아직 점수에 안 들어간다.
  • 실내에는 붙이지 않았다. 다듬기는 지금 야외 맵 기준이다.
